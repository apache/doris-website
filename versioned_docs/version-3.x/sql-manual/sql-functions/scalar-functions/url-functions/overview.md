# URL Functions Overview

URL functions extract components such as domains, protocols, and query parameters, or encode and decode URL strings. Use the function reference pages below for syntax, input requirements, and examples.

| Function | Purpose |
| --- | --- |
| [DOMAIN](../string-functions/domain.md) | Extract the domain from a URL. |
| [DOMAIN_WITHOUT_WWW](../string-functions/domain-without-www.md) | Extract the domain and remove a leading `www.`. |
| [TOP_LEVEL_DOMAIN](../string-functions/top-level-domain.md) | Extract the top-level domain. |
| [FIRST_SIGNIFICANT_SUBDOMAIN](../string-functions/first-significant-subdomain.md) | Extract the first significant subdomain. |
| [CUT_TO_FIRST_SIGNIFICANT_SUBDOMAIN](../string-functions/cut-to-first-significant-subdomain.md) | Keep the domain up to the first significant subdomain. |
| [PROTOCOL](../string-functions/protocol.md) | Extract the protocol from a URL. |
| [PARSE_URL](../string-functions/parse-url.md) | Extract a specified URL component. |
| [EXTRACT_URL_PARAMETER](../string-functions/extract-url-parameter.md) | Extract a named URL query parameter. |
| [URL_ENCODE](../string-functions/url-encode.md) | Encode a string for use in a URL. |
| [URL_DECODE](../string-functions/url-decode.md) | Decode a URL-encoded string. |
