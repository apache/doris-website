Apache Doris コミュニティバッジを受け取る

Apache Doris コミュニティバッジ · 申請期限なし
Apache Doris にプルリクエストがマージされましたか？ Contributor バッジを受け取りましょう。
Apache Doris に貢献した方のためのデジタルバッジです。Holopin で無料で受け取れます。受け取った後に LinkedIn に投稿すれば、実物のバッジも郵送します。
✓
Apache Doris プロジェクトでプルリクエストが一件でもマージされていれば対象です。PR の件数やマージされた時期は問いません。三年前のドキュメント修正も対象です。
デジタルバッジを受け取る →すでに Holopin の招待メールを受け取っている場合は、ステップ 3 に進んでください。
ステップ 1～3 デジタルバッジ→ステップ 4 バッジを公開→ステップ 5～6 実物のバッジステップ 5 と 6 は任意です。デジタルバッジを受け取った後に進めます。

五種類のコミュニティバッジ​

それぞれのバッジは、異なる形の貢献をたたえるものです。Contributor バッジは現在受け取れます。Committer バッジと PMC Member バッジは PMC から送られるため、申請は不要です。2026 年の二種類のバッジはコミュニティが授与します。授与基準と手順が決まり次第、このページに追記します。

Contributorコード、ドキュメント、アイデアなどで貢献し、PR が少なくとも一件マージされた方。提供中Committer継続的で信頼される貢献によって得られるコミット権限を持つ方。提供中PMC Memberプロジェクトの技術的な方向性とコミュニティの運営を担う方。提供中
Active Contributor 2026年間を通じて継続的かつ大きな影響を与える貢献をした方。近日公開
Community Champion 2026主要機能、ユーザー事例、講演、イベントなどのコミュニティ活動に貢献した方。近日公開

デジタルバッジを受け取る​

Contributor バッジを受け取る方は、四つのステップをすべて行ってください。Holopin が招待メールを送る前に各申請を手作業で確認するため、最初の二つのステップで GitHub アカウントが本人のものか確認します。コミッターと PMC メンバーは、PMC から招待メールが届くため、最初の二つのステップを省略し、ステップ 3 から始めます。

1
Contributor バッジのみ

GitHub プロフィールの README に確認用フレーズを追加する​

プロフィールの README（username/username リポジトリ）の任意の場所に、次の行を一時的に追加してください。

Apache Doris Community Badge
理由： フォームには誰でも GitHub ID を入力できるため、アカウントが本人のものであることを確認する必要があります。バッジを受け取ったら、この行を削除して代わりにバッジを掲載できます。
2
Contributor バッジのみ

申請フォームに入力する​

マージされた PR を確認するための GitHub ID と、バッジの招待メールを送るためのメールアドレスを入力してください。

申請フォームを開く →所要時間は一分ほどです。
PMC

コミッターまたは PMC メンバーの方はこちらから​

この二種類のバッジには申請が必要ありません。Doris PMC は公式のコミッター一覧とPMC メンバー一覧を確認し、掲載されている方全員に Holopin の招待メールを直接送ります。コミッターには Committer バッジ、PMC メンバーには PMC Member バッジと Committer バッジの両方が届きます。メールが届いたらステップ 3 から進んでください。その後のバッジの公開方法と実物のバッジの申請方法は、Contributor バッジと同じです。

Contributor バッジも希望しますか？ マージ済みのプルリクエストがあれば対象となるので、ステップ 1 と 2 から申請してください。

まだメールが届いていない場合は、まずプロモーションタブと迷惑メールフォルダーを確認し、その後 Slack でお問い合わせください。
3

Holopin でバッジを受け取る​

Holopin から招待メールが届きます。Contributor バッジの場合は PR の確認後、Committer バッジと PMC Member バッジの場合は PMC が招待を送った後です。Claim Badge をクリックしてください。Holopin のアカウントは無料で作成できます。

メールアドレスでサインイン

現在、GitHub から直接サインインする際に問題があるため、ご自身のメールアドレスで Holopin に登録し、サインインすることをお勧めします。

メールが見つからない場合は、プロモーションタブまたは迷惑メールフォルダーを確認してください。Holopin の招待メールがそこに振り分けられることがあります。

受け取ったバッジは Holopin の認証情報ページに表示されます。このページは誰でも開いて確認できるため、好きな場所からリンクできます。
4

バッジを公開する​

このバッジには、あなたの貢献をコミュニティが評価しているという意味があります。好きな場所に掲載してください。

  • GitHub プロフィール
  • LinkedIn
  • その他の場所
  1. Holopin で Your Profile を開きます。
  2. Apache Doris のバッジを Board に追加します。複数のバッジがある場合は、移動、サイズ変更、回転ができます。
  3. Board の下に表示されるコードをコピーし、GitHub プロフィールの README に貼り付けます。

コードは一行の Markdown です。次は morningman アカウントの例です。自分のコードには自分のユーザー名が入ります。

[![An image of @morningman's Holopin badges, which is a link to view their full Holopin profile](https://holopin.me/morningman)](https://holopin.io/@morningman)

表示例は github.com/morningman と、その元となる README で確認できます。

LinkedIn プロフィールの Licenses & Certifications に追加します。

  • 名前：Apache Doris Contributor（または、お持ちのバッジに応じて Committer / PMC Member）
  • 発行組織：Apache Doris
  • 資格情報の URL：Holopin のバッジへのリンク

投稿で紹介することもできます。たとえば、バッジ画像を添えて次のように一行書くだけで十分です。

@Apache Doris コミュニティから Contributor バッジをいただきました。 #ApacheDoris #ApacheDorisCommunityBadge

受け取ったバッジが Committer または PMC Member の場合は、名称を置き換えてください。実物のバッジも希望する場合、この投稿がステップ 5で必要になります。

Holopin の認証情報ページは、誰でも確認できる固定リンクです。貢献の記録が役立つ場所に追加してください。

  • 履歴書 / CV
  • 個人のウェブサイトやポートフォリオ
  • その他の開発者プロフィールやコミュニティプロフィール
  • カンファレンスの登壇者紹介

実物のバッジも希望する場合：あと二ステップ​

デジタルバッジを受け取ったら、すぐに申請できます。ステップ 5 の LinkedIn 投稿では、そのバッジを表示する必要があります。Contributor、Committer、PMC Member のいずれかのデジタルバッジを持つ方は全員対象です。デジタルバッジを複数持っている場合も、実物のバッジはお一人につき一個お送りします。

5

LinkedIn でバッジを共有する​

新しいバッジについて LinkedIn に投稿してください。作成・修正したものや、コミュニティに参加したきっかけなど、内容は自由です。必要な条件は以下の三つだけです。短い投稿にしたい場合は、ステップ 4 の LinkedIn タブにある投稿例にバッジ画像を添えるだけで構いません。

  • 投稿に必要なもの
  • 公式 LinkedIn ページ @Apache Doris へのメンション
  • ハッシュタグ #ApacheDorisCommunityBadge
  • バッジ画像または Holopin のバッジへのリンク
6

配送先情報を送信する​

投稿を公開したら、実物のバッジの申請フォームに投稿へのリンクと配送先住所を入力してください。

実物のバッジを申請する →
投稿を確認した後、発送の準備を始める際にメールでお知らせします。
世界各地に発送しますが、お届けを保証するものではありません

配送にかかる時間は国によって大きく異なります。税関の規則や配送業者の制限により、荷物をお届けできない地域もあります。できる限りお届けできるよう努めますが、すべての住所への到着は保証できません。

ご質問がある場合​

Apache Doris の Slack に参加してご質問ください。

コミュニティチームが、フォームや配送を含むバッジに関する質問に Slack で回答します。

Slack コミュニティに参加する →

大きく目立つ貢献もあれば、誰かの日々の作業を少し楽にする小さな修正もあります。そのすべてがオープンソースを支えています。このバッジには、そうした貢献への感謝を込めています。

このプログラムに終了日はありません。いつでも貢献できます。プルリクエストがマージされたら、バッジを受け取ってください。
