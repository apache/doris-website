モダンなデータウェアハウスで、
実現する リアルタイムの インサイト

バッチとストリーミングのデータを統合し、BI を高速化。信頼できる業務指標を、単一のリアルタイム分析データベースから大規模に提供します。

モダンなデータウェアハウスがビジネスを変える理由。

ウェアハウスを統合し、高速・リアルタイム・柔軟な拡張を実現すると、4 つの点が変わります。

  • データへの信頼
  • 分析の速さ
  • 意思決定に使うデータの鮮度
  • 基盤全体の運用コスト
  1. 01

    統一されたビジネスの全体像

    受注、顧客、決済、CRM、ERP、広告、ログを、信頼できる 1 つの分析基盤に集約し、全チームが同じ指標で業務を進められます。

  2. 02

    高速な BI とセルフサービス分析

    1 秒未満で応答する SQL により、Tableau、Power BI、Superset、Looker でドリルダウンやアドホック分析を対話的に実行できます。

  3. 03

    リアルタイム監視

    CDC、Kafka、Flink から継続的に取り込み、ダッシュボード、アラート、業務レポートを現在の状況に追従させます。

  4. 04

    拡張性とコスト効率

    分析データが TB から PB に増え、BI の同時利用者が増えても、システム、パイプライン、配信層を追加せずに対応できます。

本番環境ですでに稼働。

Apache Doris をデータウェアハウスの分析エンジンに採用し、実際の同時アクセスと最新の業務データを大規模に処理する 3 チームの事例です。

事例 01・SF Technology

SF Express：BI とアドホック分析を Presto から Apache Doris へ

SF Technology は、1 日 100 万件超のクエリを処理する主要 BI 基盤を Presto から Apache Doris に移行しました。すべてのアドホック分析と BI を移行し、P95 レイテンシを約 70% 削減しました。

成果
  • P95 クエリレイテンシを約 70% 削減。10 秒未満のクエリの割合が 72% から 88% に増加
  • ハードウェアを 48% 削減し、レイクハウスクエリのデータキャッシュ命中率は 96%
  • SQL 互換率 97% で、アドホック分析と BI の全処理を移行
SF EXPRESS
事例 02・Xiaomi

Xiaomi：Apache Doris と Apache Paimon による統合レイクハウス

Xiaomi は Presto、Druid、複数のストレージ形式を、Apache Doris と Apache Paimon による 1 つのレイクハウスに統合し、クエリを従来の 6 倍に高速化しました。

成果
  • 平均クエリレイテンシを 60 秒から 10 秒に、集約を 40 秒から 8 秒に短縮
  • 同時処理スループットが Presto の 5 倍に向上し、負荷時のレイテンシを 25～75% 削減
  • Doris のホットデータと Paimon のコールドデータを、ユーザー行動、デバイス、業務分析で統一的に利用
XIAOMI
事例 03・Cainiao

Cainiao：グローバル物流のリアルタイムレイクハウス

“データ更新は数秒で完了し、クエリには数百ミリ秒で応答できます。”

成果
  • リアルタイムデータ基盤のコストを 90% 削減し、平均応答時間を 72% 短縮
  • ポイントクエリは 1,000～2,000 QPS で 10～100 ms、複数テーブル結合は 200～300 QPS で 1 秒未満
  • 3 リージョンの 25 以上のクラスタと 10,000 以上の CPU で、1 日 8,000 万個の荷物に関する在庫・配送・注文を追跡
CAINIAO
