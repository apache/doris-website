Logstash Doris 出力プラグイン

Logstash は、データの収集、前処理、ストレージシステムへの送信を担うログ ETL フレームワークです。Logstash Doris 出力プラグインは、Logstash から Apache Doris へデータを書き込むための出力プラグインです。TEXT または JSON のログを Doris にリアルタイムで取り込み、ログの検索や分析に使用できます。

このプラグインは Doris Stream Load の HTTP インターフェースを呼び出してデータをリアルタイムで書き込みます。また、複数スレッドによる並列処理、失敗時の再試行、Stream Load の形式とパラメータのカスタマイズ、書き込み速度のログ出力に対応します。

ユースケースとワークフロー​

ログの形式に応じて、適切な例を選択してください。

ユースケース対象データ参照する例
プレーンテキストのログや、Java のスタックトレースなどの複数行のログを収集する一件の業務ログが複数行にわたることがある TEXT ログ複数行の TEXT ログを収集する
各行に一つの JSON オブジェクトを含む構造化ログを収集する各行を直接フィールドに解析できる JSON Lines 形式のログJSON Lines 形式のログを収集する

Logstash Doris 出力プラグインを使用する際のワークフローは次のとおりです。

  1. Logstash Doris 出力プラグインを入手してインストールします。
  2. Doris に書き込み先のデータベースとテーブルを作成します。
  3. Logstash の入力、変換、Doris への出力のパラメータを設定します。
  4. Logstash を起動して、ログを Doris にリアルタイムで書き込みます。
  5. Stream Load の応答と書き込み速度のログで、取り込み結果を確認します。

プラグインのインストール​

プラグインの入手​

Logstash Doris 出力プラグインは、インストールパッケージをダウンロードするか、ソースからビルドして入手できます。

方法適したケース操作
公式サイトからダウンロード依存関係を含むインストールパッケージを直接入手する場合logstash-output-doris-1.2.0-java.gem をダウンロードします。
ソースからビルドプラグインのソースを入手済みで、パッケージを自分でビルドする場合gem build を extension/logstash/ ディレクトリで実行します。

公式サイトからダウンロードする場合:

# Installation package that includes dependencies
wget https://apache-doris-releases.oss-cn-beijing.aliyuncs.com/extension/logstash-output-doris-1.2.0-java.gem

ソースからビルドする場合:

cd extension/logstash/
gem build logstash-output-doris.gemspec

標準インストール​

${LOGSTASH_HOME} は Logstash のインストールディレクトリです。${LOGSTASH_HOME}/bin/logstash-plugin コマンドを実行してプラグインをインストールします。その際、<plugin_file>.gem を実際のプラグインパッケージのファイル名に置き換えてください。

${LOGSTASH_HOME}/bin/logstash-plugin install <plugin_file>.gem

インストールに成功すると、Logstash は次のような結果を出力します。

Validating logstash-output-doris-1.2.0.gem
Installing logstash-output-doris
Installation successful

標準インストールでは、プラグインが依存する Ruby モジュールも自動的にインストールされます。ネットワークを利用できない場合、インストールが途中で停止したり、完了しなかったりすることがあります。その場合は、依存関係を含むインストールパッケージをダウンロードして、オフラインでインストールできます。

オフラインインストール​

オフラインでインストールするには、まず JAR の依存関係の処理をスキップし、ローカルファイルシステム上のプラグインパッケージを使用します。ローカルパスを指定する際は、Logstash の要件に従って file:// を使用します。

export JARS_SKIP="true"
${LOGSTASH_HOME}/bin/logstash-plugin install file:///path/to/<plugin_file>.gem

設定パラメータ​

Logstash Doris 出力プラグインは、次の設定項目に対応しています。

設定項目説明
http_hostsStream Load の HTTP アドレス。一つ以上の要素を持つ文字列配列で指定します。各要素は host:port の形式です。例: ["http://fe1:8030", "http://fe2:8030"]。
userDoris のユーザー名。このユーザーには、書き込み先の Doris データベースとテーブルに対するインポート権限が必要です。
passwordDoris ユーザーのパスワード。
db書き込み先の Doris データベース。
table書き込み先の Doris テーブル。
label_prefixDoris Stream Load の Label のプレフィックス。生成される Label の形式は <label_prefix>_<db>_<table>_<yyyymmdd_hhmmss>_<uuid> です。デフォルト値は logstash です。
headersDoris Stream Load の headers パラメータ。Ruby のマップ構文を使用します。例: headers => { "format" => "json" "read_json_by_line" => "true" }。
mappingLogstash のフィールドから Doris テーブルのフィールドへのマッピング。使用方法は以下の例を参照してください。
message_onlymapping の特殊な形式で、Logstash の @message フィールドだけを Doris に出力します。デフォルト値は false です。
max_retriesDoris Stream Load リクエストが失敗した後の再試行回数。デフォルト値は -1 で、データの信頼性を確保するために無制限に再試行します。
log_requestトラブルシューティングのために、Doris Stream Load のリクエストとレスポンスのメタデータをログに出力するかどうかを指定します。デフォルト値は false です。
log_speed_interval書き込み速度をログに出力する間隔。単位は秒です。デフォルト値は 10 です。0 に設定すると、速度のログ出力を無効にします。

複数行の TEXT ログを収集する​

この例では、Doris FE のログを使用して、TEXT ログを収集し Doris に書き込む方法を示します。

シナリオの説明​

FE のログファイルは通常、Doris のインストールディレクトリ内の fe/log/fe.log にあります。この種の Java アプリケーションログには、タイムスタンプ、ログレベル、スレッド名、コードの位置、ログ内容などのフィールドが含まれます。

FE のログには、単一行のエントリと、スタックトレースを含む例外ログの両方があります。スタックトレースは複数行にわたるため、収集時に主となるログエントリとスタックトレースを一件のログにまとめる必要があります。

Doris にテーブルを作成する​

書き込み先のテーブルには、ログの生成時刻、収集時刻、ホスト名、ログファイルのパス、ログの種類、ログレベル、スレッド名、コードの位置、ログ内容などのフィールドを含めます。

Logstash を設定する​

Logstash では、主に次の二種類の設定ファイルを使用します。

設定ファイル用途
config/logstash.ymlLogstash のグローバル設定ファイル。バッチサイズとバッチ遅延を設定して、Doris への書き込み性能を向上できます。
logstash_doris_log.conf一つのログ収集タスクの設定ファイル。通常、input、filter、output の三つのセクションで構成されます。

各エントリが平均で数百バイトのログでは、バッチサイズを 1,000,000 行、バッチ遅延を 10 秒に設定します。config/logstash.yml で次のように指定できます。

pipeline.batch.size: 1000000
pipeline.batch.delay: 10000

logstash_doris_log.conf は、次の三つのセクションで構成されます。

セクション用途この例の主な設定
input生データを読み取ります。file 入力で FE のログを読み取り、タイムスタンプで始まらない行を multiline コーデックで前の行に追加します。
filterデータを変換します。grok を使用して、log_time、level、thread、position を message フィールドから抽出します。
outputDoris に出力します。doris 出力で Stream Load を介して Doris に書き込み、mapping でフィールドを対応付けます。

設定例を次に示します。

# 1. input: read FE logs and merge stacktraces using the multiline codec
input {
    file {
        path => "/mnt/disk2/xiaokang/opt/doris_master/fe/log/fe.log"
        add_field => {"type" => "fe.log"}
        codec => multiline {
            # valid line starts with timestamp
            pattern => "^%{TIMESTAMP_ISO8601} "
            # any line not starting with a timestamp should be merged with the previous line
            negate => true
            what => "previous"
        }
    }
}

# 2. filter: extract log fields from the message using grok
filter {
    grok {
        match => {
            # parse log_time, level, thread, position fields from message
            "message" => "%{TIMESTAMP_ISO8601:log_time} (?<level>[A-Z]+) \((?<thread>[^\[]*)\) \[(?<position>[^\]]*)\]"
        }
    }
}

# 3. output: write to Doris through Doris Stream Load
output {
    doris {
        http_hosts => ["http://localhost:8630"]
        user => "root"
        password => ""
        db => "log_db"
        table => "doris_log"
        headers => {
            "format" => "json"
            "read_json_by_line" => "true"
            "load_to_single_tablet" => "true"
        }
        mapping => {
            "log_time" => "%{log_time}"
            "collect_time" => "%{@timestamp}"
            "host" => "%{[host][name]}"
            "path" => "%{[log][file][path]}"
            "type" => "%{type}"
            "level" => "%{level}"
            "thread" => "%{thread}"
            "position" => "%{position}"
            "message" => "%{message}"
        }
        log_request => true
    }
}

output の設定では、headers で Stream Load のデータ形式を JSON に指定し、mapping で Logstash のフィールドと JSON のフィールドの対応関係を指定します。headers に "format" => "json" が設定されているため、Stream Load は JSON のフィールドを自動的に解析し、Doris テーブルの対応するフィールドに書き込みます。

Logstash を実行する​

次のコマンドで Logstash を起動します。

${LOGSTASH_HOME}/bin/logstash -f config/logstash_doris_log.conf

            "type" => "%{type}"
            "public" => "%{public}"
            "actor.id" => "%{[actor][id]}"
            "actor.login" => "%{[actor][login]}"
            "actor.display_login" => "%{[actor][display_login]}"
            "actor.gravatar_id" => "%{[actor][gravatar_id]}"
            "actor.url" => "%{[actor][url]}"

            "repo.id" => "%{[repo][id]}"
            "repo.name" => "%{[repo][name]}"
            "repo.url" => "%{[repo][url]}"
            "payload" => "%{[payload]}"
            "host" => "%{[host][name]}"
            "path" => "%{[log][file][path]}"
        }
        log_request => true
    }
}

よくある問題とトラブルシューティング​

問題対処方法
ネットワーク障害で標準インストールが途中で停止する依存関係を含むインストールパッケージを使用してオフラインでインストールし、file:// でローカルファイルシステム上のパスを指定します。
Doris への各リクエストとレスポンスを確認したいlog_request => true を doris 出力で設定します。Stream Load のリクエストパラメータとレスポンス結果がログに出力されます。
書き込み速度を確認したいlog_speed_interval のデフォルト値を使用します。Logstash は 10 秒ごとに、累積データ量、全期間の平均速度、直近 10 秒間の速度を出力します。
書き込み速度のログを無効にしたいlog_speed_interval を 0 に設定します。
TEXT ログのスタックトレースが複数のログエントリに分かれるmultiline コーデックを file 入力で使用し、タイムスタンプで始まらない行を前の行にまとめます。
