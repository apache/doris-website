26.0.1​

출처: 릴리스 노트 26.0.1

이 패치 릴리스에서는 Doris 4.1.3과의 DDC 축소 호환성을 개선하고, 저장소에서 관리하는 릴리스 자동화 도구를 추가했으며, 외부 기여자의 풀 리퀘스트에 대해서도 라이선스 검사를 안전하게 수행하도록 했습니다.

기능 및 개선 사항​

  • 환경 검사, 소스 패키징, 서명 및 업로드, 투표 이메일 생성, 릴리스 완료를 위한 저장소 관리 릴리스 도구와 자동화된 워크플로 테스트를 추가했습니다. #507

버그 수정​

  • 확장된 SHOW FRONTENDS 및 SHOW BACKENDS 결과를 처리하고, 노드를 하나씩 제거하며, 정상적인 백엔드 정리를 재시도해도 안전하게 만들어 Doris 4.1.3에서 DDC FE 및 컴퓨트 그룹 축소가 작동하도록 수정했습니다. #510

안정성​

  • 권한이 낮은 pull_request 워크플로에서 라이선스 검사를 실행하고 체크아웃 처리 방식을 업데이트하여 포크에서 생성된 풀 리퀘스트도 안전하게 검사할 수 있도록 했습니다. #511

감사의 말​

  • Al-assad

26.0.0​

출처: 릴리스 노트 26.0.0

이 버전에서는 컴퓨트 그룹의 정상 종료 롤아웃, 설정 가능한 준비 상태 프로브 정책, DCR mTLS 지원, 더 명확한 DDC 상태 보고를 포함해 DDC 수명 주기 관리와 안정성을 개선했습니다. Helm 차트 설정도 강화하고 여러 유효성 검사 및 안정성 관련 문제를 수정했습니다.

기능 및 개선 사항​

  • 롤링 업데이트, 축소, 삭제 작업 중 DDC 컴퓨트 그룹이 정상적으로 종료되도록 롤아웃 기능을 추가했습니다. 지원하지 않는 이미지에서는 일반 StatefulSet 흐름으로 돌아가도록 sentinel 호환성 게이트도 적용했습니다. #502
  • DorisCluster 및 DorisDisaggregatedCluster Pod에 설정 가능한 준비 상태 프로브 정책을 지원합니다. #486
  • DCR에 mTLS를 지원합니다. #483
  • 더 원활한 업그레이드와 트래픽 전환을 위해 DDC 컴퓨트 그룹 서비스를 내부 headless 서비스와 외부 서비스로 분리했습니다. #484
  • Helm 차트에 구성 요소별 secret 지원을 추가했습니다. #465
  • Helm 차트에서 배포된 Pod의 serviceAccount 설정을 구성할 수 있도록 했습니다. #470

버그 수정​

  • MetaService의 성능 저하가 클러스터 상태에 반영되도록 DDC MetaService 상태 집계를 수정했습니다. #500
  • CompareConfigmapAndTriggerRestart에서 dcr.Annotations가 nil일 때 발생하는 nil 맵 패닉을 수정했습니다. #493
  • FE 엔드포인트 주소의 JSON 태그를 수정하고 DorisCluster CRD를 다시 생성했습니다. #497
  • feSpec.replicas < feSpec.electionNumber인 잘못된 DorisDisaggregatedCluster FE 사양을 거부하도록 했습니다. #498
  • 변경할 수 없는 StatefulSet 볼륨 클레임 템플릿을 적용하기 전에 DDC 컴퓨트 그룹 스토리지 템플릿 변경을 거부하도록 했습니다. #496
  • DorisDisaggregatedCluster BE Helm 설정의 기본 storage_root_path를 수정했습니다. #477

안정성​

  • DorisCluster 및 DorisDisaggregatedCluster 웹훅에서 내장 admin 계정을 Operator 관리 사용자로 사용하는 것을 거부하도록 했습니다. #499
  • Go 포맷, vet/lint 검사, Operator 빌드, 생성된 매니페스트 및 아티팩트에 대한 풀 리퀘스트 검사를 추가했습니다. #501

이 버전에서는 BE 스케줄링과 설정 업데이트를 개선하고, 컨트롤러 테스트를 추가했으며, StatefulSet 준비 과정을 수정하고 이미지 태그를 Apache 저장소로 이전했습니다.

기능 및 개선 사항​

  • Operator가 FE를 실행하는 노드에 BE를 우선 배치하도록 BE와 FE 간 어피니티를 추가했습니다. #328
  • ConfigMap 변경을 감시하고 시작 설정이 변경되면 Doris를 다시 시작하도록 했습니다. #331
  • BE가 기본 시스템 초기화를 건너뛸 수 있도록 했습니다. #321
  • 컨트롤러 단위 테스트를 추가했습니다. #322

버그 수정​

  • prepareStatefulsetApply에 전달되는 매개변수를 수정했습니다. #326

기타 변경 사항​

  • 모든 이미지 태그를 SelectDB 저장소에서 Apache 저장소로 이전했습니다. #329

감사의 말​

  • catpineapple
  • intelligentfu8

24.2.0​

출처: 릴리스 노트 24.2.0

이 버전에서는 DorisDisaggregatedCluster의 다중 secret 지원과 컴퓨트 그룹의 decommission 기반 BE 축소 기능을 추가했습니다. Arrow Flight SQL 포트 노출, 리소스 정리, 테스트, 문서, 예제도 개선했습니다.

기능 및 개선 사항​

  • decommission을 통해 DDC 컴퓨트 그룹의 BE를 축소할 수 있도록 했습니다. #306
  • DDC의 사용자 이름 및 비밀번호 설정과 다중 secret을 지원합니다. #312
  • Arrow Flight SQL 포트를 컨테이너 포트로 노출했습니다. #295
  • 분리형 서비스에 Arrow Flight SQL 포트를 노출했습니다. #307
  • 단위 테스트 범위를 확대했습니다. #315
  • 컴퓨트 그룹 리소스 정리 코드를 리팩터링했습니다. #318

버그 수정​

  • 컴퓨트 그룹을 제거할 때 SQL 클라이언트의 동작을 수정했습니다. #314
  • 서비스 레이블을 수정했습니다. #318
  • UniqueId에 하이픈이 포함된 경우 컴퓨트 그룹이 제거되지 않는 문제를 수정했습니다. #318
  • 클러스터 업데이트 중 FE 축소에 대한 안전성 검사를 추가했습니다. #320

기타 변경 사항​

  • README를 개선했습니다. #303
  • 오래된 Dockerfile과 DDM 코드를 비롯한 사용하지 않는 파일을 제거했습니다. #309 #314
  • DorisDisaggregatedCluster CRD 예제를 개선했습니다. #313

감사의 말​

  • jonasbrami
  • hechao-ustc
  • intelligentfu8
  • catpineapple

24.1.0​

출처: 릴리스 노트 24.1.0

이 버전에서는 DorisCluster에 워크로드 그룹 지원을 추가하고 롤링 재시작을 도입했으며, FE 배포 및 접근 문제를 수정했습니다.

워크로드 그룹을 사용하려면 공식 Apache Doris 2.1.7 이상 이미지가 필요합니다. 이전 Doris 버전에서는 호환되는 이미지를 직접 빌드하세요.

기능 및 개선 사항​

  • Doris BE에 워크로드 그룹 지원을 추가했습니다. #289
  • Doris 클러스터에 롤링 재시작 기능을 추가했습니다. #292
  • Makefile의 controller-gen 버전을 업데이트했습니다. #275
  • GitHub Actions에 라이선스 검사를 추가했습니다. #278 #279 #280
  • 기본 이슈 템플릿을 추가했습니다. #288

버그 수정​

  • DorisCluster 리소스에 FE electionNumber가 설정되지 않았을 때 발생하는 nil 포인터 오류를 수정했습니다. #285
  • FE 접근 주소가 서비스 이름과 네임스페이스를 사용하도록 수정했습니다. #291

감사의 말​

  • intelligentfu8
  • catpineapple

24.0.0​

출처: 릴리스 노트 24.0.0

이 버전에서는 스토리지와 컴퓨트를 분리한 Apache Doris 클러스터를 배포하기 위한 DorisDisaggregatedCluster(DDC) 사용자 지정 리소스를 도입했습니다. DorisCluster(DCR)를 통한 스토리지와 컴퓨트가 결합된 배포 지원도 확대했습니다.

DDC를 사용하려면 Apache Doris 3.0.2 이상이 필요합니다.

새로운 기능​

DorisDisaggregatedCluster​

  • FoundationDB 모듈 접근 기능을 추가했습니다. #186
  • MetaService 모듈 배포 기능을 추가했습니다. #194
  • FE 모듈 배포 기능을 추가했습니다. #199
  • 컴퓨트 그룹 모듈 배포 기능을 추가했습니다. #185 #189 #192 #197
  • 분리형 Doris 구성 요소의 이미지 진입점 지원을 추가했습니다. #195 #196
  • FE 축소 기능을 추가했습니다. #225
  • 컴퓨트 그룹 축소 및 리소스 정리 기능을 추가했습니다. #238
  • SQL 인터페이스를 통한 FE 축소 기능을 추가했습니다. #255
  • SQL 인터페이스를 통한 컴퓨트 그룹 축소 기능을 추가했습니다. #256

DorisCluster​

  • 외부 서비스를 통해 Arrow Flight SQL 포트를 노출했습니다. #251

개선 사항​

DorisDisaggregatedCluster​

  • be.conf 및 PVC 설정을 통한 컴퓨트 그룹 생성을 지원합니다. #198
  • README 및 DDC 예제 YAML 파일을 개선했습니다. #203 #210 #211 #214
  • 최신 버전을 사용하도록 README 예제를 업데이트했습니다. #220
  • DDC 배포를 활성화하는 Operator 스위치를 추가했습니다. #204
  • 시스템 환경을 준비하기 위해 SystemInitialization을 추가했습니다. #212
  • 컴퓨트 그룹 용어를 Doris의 명칭 변경에 맞췄습니다. #215 #245
  • MetaService 복제본 CRD를 제거했습니다. #227
  • MetaService CRD를 DorisDisaggregatedCluster CRD에 통합하도록 재구성했습니다. #234
  • 새로운 SQL 인터페이스에 맞춰 컴퓨트 그룹 식별자를 UniqueId로 변경했습니다. #239
  • FE SQL 이미지 진입점과 클러스터 ID 해시 코드를 추가했습니다. #249
  • DDC 작업을 HTTP 인터페이스에서 SQL 인터페이스로 이전했습니다. #254
  • Pod 활성 상태 프로브에 timeoutSeconds를 추가했습니다. #257
  • FE가 로그 PVC 생성을 건너뛸 수 있도록 logNotStore를 추가했습니다. #266
  • DDC 예제와 문서를 업데이트했습니다. #268

DorisCluster​

  • Pod 활성 상태 프로브에 timeoutSeconds를 추가했습니다. #257

기타 변경 사항​

  • 공통 유틸리티에 대한 단위 테스트를 추가했습니다. #226
  • 리소스 및 컨트롤러 모델에 대한 단위 테스트를 추가했습니다. #232
  • Artifact Hub용 Helm 차트 설정을 업데이트했습니다. #244
  • 조직 이름을 SelectDB에서 Apache로 변경했습니다. #247

버그 수정​

DorisDisaggregatedCluster​

  • Pod 어피니티와 StatefulSet PVC 포인터 처리를 수정했습니다. #209
  • 기본 BE 스토리지 경로를 수정했습니다. #243
  • 중복된 ms_token 환경 변수로 인해 초기 배포 중 Pod가 다시 시작되는 문제를 수정했습니다. #259
  • 이미지 진입점에서 사용하는 BE ConfigMap 경로를 수정했습니다. #261
  • electionNumber가 nil인 배포 문제를 수정하고 서비스가 계속 업데이트되지 않도록 했습니다. #262 #266
  • 반복적인 조정을 수정했습니다. #263 #265
  • 기본 BE 캐시 경로를 수정했습니다. #266

DorisCluster​

  • Operator 업그레이드 시 Doris Pod가 다시 시작되지 않도록 했습니다. #226
  • 공유 Pod 환경 변수 배열을 병합할 때 깊은 복사본을 사용하도록 했습니다. #236
  • 네임스페이스를 가로질러 FE를 축소할 때 발생하는 MySQL 클라이언트 오류를 수정했습니다. #240
  • electionNumber가 nil일 때 발생하는 배포 실패를 수정했습니다. #260

기타 변경 사항​

  • StatefulSet의 리소스 모델 단위 테스트를 수정했습니다. #252
