## Description

Converts a Bitmap into its raw serialized bytes and returns them as a VARBINARY value.

This is the byte-level counterpart of `bitmap_to_base64`. Compared with the Base64 representation, the binary form is more compact and is the recommended form when exporting Bitmaps into binary file formats such as Parquet or ORC, or into Hive `binary` columns.

## Syntax

```sql
BITMAP_TO_BINARY(<bitmap>)
```

## Parameters

| Parameter  | Description                     |
|------------|---------------------------------|
| `<bitmap>` | A Bitmap type column or expression |

## Return Value

Returns a VARBINARY value containing the serialized bytes of the Bitmap.
Returns `NULL` if the Bitmap is `NULL`.

::: note

The BE configuration option `enable_set_in_bitmap_value` changes the specific format of bitmap values in memory, which affects the result of this function.
Due to the non-guaranteed order of elements in a bitmap, the generated bytes may not always be the same for the same content. However, the bitmap decoded by `bitmap_from_binary` will be the same.

:::

## Examples

To convert a `NULL` Bitmap to its binary form:

```sql
select bitmap_to_binary(null);
```

The result will be:

```text
+------------------------+
| bitmap_to_binary(null) |
+------------------------+
| NULL                   |
+------------------------+
```

To convert an empty Bitmap to its binary form, displayed with `to_base64_binary`:

```sql
select to_base64_binary(bitmap_to_binary(bitmap_empty()));
```

The result will be:

```text
+----------------------------------------------------+
| to_base64_binary(bitmap_to_binary(bitmap_empty())) |
+----------------------------------------------------+
| AA==                                               |
+----------------------------------------------------+
```

To convert a Bitmap with a single element to its binary form, displayed with `to_base64_binary`:

```sql
select to_base64_binary(bitmap_to_binary(to_bitmap(1)));
```

The result will be:

```text
+--------------------------------------------------+
| to_base64_binary(bitmap_to_binary(to_bitmap(1))) |
+--------------------------------------------------+
| BQEBAAAAAAAAAA==                                 |
+--------------------------------------------------+
```

To convert a Bitmap with multiple elements to its binary form, displayed with `to_base64_binary`:

```sql
select to_base64_binary(bitmap_to_binary(bitmap_from_string("1,9999999")));
```

The result will be:

```text
+---------------------------------------------------------------------+
| to_base64_binary(bitmap_to_binary(bitmap_from_string("1,9999999"))) |
+---------------------------------------------------------------------+
| BQIBAAAAAAAAAH+WmAAAAAAA                                            |
+---------------------------------------------------------------------+
```

The round trip with `bitmap_from_binary` preserves the Bitmap contents:

```sql
select bitmap_to_string(bitmap_from_binary(bitmap_to_binary(bitmap_from_string("0, 1, 2, 3, 4294967296"))));
```

The result will be:

```text
+------------------------------------------------------------------------------------------------------+
| bitmap_to_string(bitmap_from_binary(bitmap_to_binary(bitmap_from_string("0, 1, 2, 3, 4294967296")))) |
+------------------------------------------------------------------------------------------------------+
| 0,1,2,3,4294967296                                                                                   |
+------------------------------------------------------------------------------------------------------+
```
