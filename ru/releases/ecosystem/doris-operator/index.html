Doris Operator

В этом документе перечислены примечания к выпускам Doris Operator в обратном хронологическом порядке.

26.0.1​

Источник: Примечания к выпуску 26.0.1

В этом исправляющем выпуске улучшена совместимость уменьшения масштаба DDC с Doris 4.1.3, добавлены средства автоматизации выпуска в самом репозитории и обеспечена безопасная проверка лицензий в запросах на включение изменений от внешних участников.

Новые возможности и улучшения​

  • В репозиторий добавлены инструменты выпуска для проверки окружения, упаковки исходного кода, подписания и загрузки, создания письма для голосования и завершения выпуска, а также автоматические тесты рабочих процессов. #507

Исправления ошибок​

  • Исправлено уменьшение масштаба FE и групп вычислительных узлов DDC с Doris 4.1.3: обработка расширенных результатов SHOW FRONTENDS и SHOW BACKENDS, поочерёдное удаление узлов и возможность безопасно повторять корректное удаление BE. #510

Надёжность​

  • Проверка лицензий перенесена в рабочий процесс pull_request с минимальными привилегиями; обновлена обработка получения кода, чтобы безопасно проверять запросы на включение изменений из форков. #511

Благодарности​

  • morningman
  • Al-assad

26.0.0​

Источник: Примечания к выпуску 26.0.0

В этой версии улучшены управление жизненным циклом DDC и надёжность: добавлены поэтапное корректное завершение работы групп вычислительных узлов, настраиваемые политики проверки готовности, поддержка mTLS для DCR и более понятное отображение состояния DDC. Также расширены возможности настройки Helm chart и внесены исправления, связанные с проверкой конфигурации и стабильностью.

Новые возможности и улучшения​

  • Добавлено поэтапное корректное завершение работы групп вычислительных узлов DDC при последовательных обновлениях, уменьшении масштаба и удалении. Проверка совместимости sentinel позволяет использовать обычный процесс StatefulSet для неподдерживаемых образов. #502
  • Добавлена возможность настраивать политику проверки готовности pod для DorisCluster и DorisDisaggregatedCluster. #486
  • Добавлена поддержка mTLS для DCR. #483
  • Сервис группы вычислительных узлов DDC разделён на внутренний headless service и внешний сервис для более плавных обновлений и переключения трафика. #484
  • В Helm chart добавлена поддержка секретов на уровне компонентов. #465
  • В Helm chart открыта настройка serviceAccount для развёрнутых pod. #470

Исправления ошибок​

  • Исправлено сведение данных о состоянии MetaService в DDC: ухудшение состояния MetaService теперь отражается в состоянии кластера. #500
  • Исправлена паника из-за nil-карты в CompareConfigmapAndTriggerRestart, возникавшая, когда dcr.Annotations имеет значение nil. #493
  • Исправлен JSON-тег адреса конечной точки FE и заново созданы CRD DorisCluster. #497
  • Добавлено отклонение некорректных спецификаций FE для DorisDisaggregatedCluster, в которых feSpec.replicas < feSpec.electionNumber. #498
  • Изменения шаблона хранилища групп вычислительных узлов DDC теперь отклоняются до применения неизменяемых шаблонов заявок на тома StatefulSet. #496
  • Исправлено значение storage_root_path по умолчанию в конфигурации Helm для BE в DorisDisaggregatedCluster. #477

Надёжность​

  • В веб-хуках DorisCluster и DorisDisaggregatedCluster добавлен запрет на использование встроенной учётной записи admin в качестве пользователя управления оператором. #499
  • Для запросов на включение изменений добавлены проверки форматирования Go, vet/lint, сборки оператора, а также создаваемых манифестов и артефактов. #501

24.0.0​

Источник: Примечания к выпуску 24.0.0

В этой версии представлен пользовательский ресурс DorisDisaggregatedCluster (DDC) для развёртывания кластеров Apache Doris с разделёнными хранением и вычислениями. Также расширена поддержка развёртываний с совместными хранением и вычислениями через DorisCluster (DCR).

Для DDC требуется Apache Doris версии 3.0.2 или новее.

Новые возможности​

DorisDisaggregatedCluster​

  • Добавлен доступ к модулю FoundationDB. #186
  • Добавлено развёртывание модуля MetaService. #194
  • Добавлено развёртывание модуля FE. #199
  • Добавлено развёртывание модуля групп вычислительных узлов. #185 #189 #192 #197
  • Добавлена поддержка точки входа образа для компонентов Doris с разделёнными хранением и вычислениями. #195 #196
  • Добавлена поддержка уменьшения числа FE. #225
  • Добавлены уменьшение масштаба групп вычислительных узлов и очистка ресурсов. #238
  • Добавлена поддержка уменьшения числа FE через интерфейс SQL. #255
  • Добавлена поддержка уменьшения масштаба групп вычислительных узлов через интерфейс SQL. #256

DorisCluster​

  • Порт Arrow Flight SQL открыт через внешние сервисы. #251
