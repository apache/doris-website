## Описание {#description}

Эта инструкция отображает доступные для восстановления метаданные баз данных, таблиц или разделов, находящиеся в корзине.

## Синтаксис {#syntax}

```sql
SHOW CATALOG RECYCLE BIN [ WHERE NAME [ = "<name>" | LIKE "<name_matcher>"] ]
```

## Необязательные параметры {#optional-parameters}

Фильтрация по имени

**1. `<name>`**
> Имя базы данных, таблицы или раздела.

Фильтрация по шаблону

**1. `<name_matcher>`**
> Шаблон для сопоставления с именем базы данных, таблицы или раздела.

## Возвращаемые значения {#return-values}

| Столбец        | Тип      | Примечание |
|----------------|----------|------------|
| Type           | String   | Тип метаданных: Database, Table, Partition |
| Name           | String   | Имя объекта метаданных |
| DbId           | Bigint   | Идентификатор базы данных |
| TableId        | Bigint   | Идентификатор таблицы |
| PartitionId    | Bigint   | Идентификатор раздела |
| DropTime       | DateTime | Время перемещения метаданных в корзину |
| DataSize       | Bigint   | Размер данных. Если метаданные относятся к базе данных, это значение включает размер данных всех таблиц и разделов в корзине |
| RemoteDataSize | Decimal  | Размер данных в удалённом хранилище (HDFS или объектном хранилище). Если метаданные относятся к базе данных, это значение включает размер данных всех таблиц и разделов в корзине, хранящихся удалённо |

## Примеры {#examples}

1. Отобразить все метаданные в корзине

    ```sql
    SHOW CATALOG RECYCLE BIN;
    ```

2. Отобразить метаданные объектов с именем 'test' в корзине

    ```sql
    SHOW CATALOG RECYCLE BIN WHERE NAME = 'test';
    ```

3. Отобразить метаданные объектов, имена которых начинаются с 'test', в корзине

    ```sql
    SHOW CATALOG RECYCLE BIN WHERE NAME LIKE 'test%';
    ```
