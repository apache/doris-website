## Описание {#description}

Эта инструкция используется для немедленного удаления баз данных, таблиц или разделов из корзины.

## Синтаксис {#syntax}

```sql
DROP CATALOG RECYCLE BIN WHERE { 'DbId' = <db_id> | 'TableId' = <table_id> | 'PartitionId' = <partition_id> }
```

## Обязательные параметры {#required-parameters}

Удаление базы данных по DbId

**1. `<db_id>`**
> Идентификатор базы данных, которую необходимо немедленно удалить.

Удаление таблицы по TableId

**1. `<table_id>`**
> Идентификатор таблицы, которую необходимо немедленно удалить.

Удаление раздела по PartitionId

**1. `<partition_id>`**
> Идентификатор раздела, который необходимо немедленно удалить.

## Примечания по использованию {#usage-notes}

- При удалении баз данных, таблиц или разделов они удаляются из корзины через `catalog_trash_expire_second` секунд (значение задаётся в `fe.conf`). Эта инструкция удаляет их немедленно.
- `'DbId'`, `'TableId'` и `'PartitionId'` нечувствительны к регистру; допускаются как одинарные, так и двойные кавычки.
- При удалении базы данных, которой нет в корзине, также удаляются все находящиеся в корзине таблицы и разделы с тем же `DbId`. Ошибка возвращается только в том случае, если не удалено ни одного объекта (базы данных, таблицы или раздела). То же правило действует при удалении таблицы, которой нет в корзине.
- С помощью `SHOW CATALOG RECYCLE BIN` можно запросить метаданные, доступные для удаления в данный момент.

## Примеры {#examples}

1. Удаление базы данных, таблиц и разделов с DbId `example_db_id`

    ```sql
    DROP CATALOG RECYCLE BIN WHERE 'DbId' = example_db_id;
    ```

2. Удаление таблицы и разделов с TableId `example_tbl_id`

    ```sql
    DROP CATALOG RECYCLE BIN WHERE 'TableId' = example_tbl_id;
    ```

3. Удаление раздела с PartitionId `p1_id`

    ```sql
    DROP CATALOG RECYCLE BIN WHERE 'PartitionId' = p1_id;
    ```
