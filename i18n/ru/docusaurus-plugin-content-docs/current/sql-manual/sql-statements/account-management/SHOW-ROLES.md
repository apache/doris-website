## Описание {#description}

Оператор `SHOW ROLES` выводит сведения обо всех созданных ролях, включая имена ролей, входящих в них пользователей и привилегии.

## Синтаксис {#syntax}

```sql
SHOW ROLES
```

## Возвращаемое значение {#return-value}

| Столбец               | Тип данных  | Примечание                     |
|-----------------------|-------------|--------------------------------|
| Name                  | string      | Имя роли                       |
| Comment               | string      | Комментарий                    |
| Users                 | string      | Пользователи, входящие в роль  |
| GlobalPrivs           | string      | Глобальные привилегии          |
| CatalogPrivs          | string      | Привилегии на Catalog          |
| DatabasePrivs         | string      | Привилегии на базы данных      |
| TablePrivs            | string      | Привилегии на таблицы          |
| ResourcePrivs         | string      | Привилегии на ресурсы          |
| WorkloadGroupPrivs    | string      | Привилегии на группы рабочей нагрузки |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие привилегии:

| Привилегия    | Объект    | Примечания |
|:--------------|:----------|:------|
| GRANT_PRIV    | USER или ROLE    | Эту операцию могут выполнять только пользователи или роли с привилегией GRANT_PRIV  |

## Примечания по использованию {#usage-notes}

Doris создаёт для каждого пользователя роль по умолчанию. Чтобы отобразить роль по умолчанию, можно выполнить команду ```set show_user_default_role=true;```.

## Пример {#example}

- Просмотр созданных ролей

```sql
SHOW ROLES
```
