## Описание {#description}

Оператор `DROP ROLE` используется для удаления роли.

## Синтаксис {#syntax}

```sql
  DROP ROLE [IF EXISTS] <role_name>;
```

## Обязательные параметры {#required-parameters}

**1. `<role_name>`**：

> Имя роли. 

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать как минимум следующими привилегиями:

| Привилегия     | Объект    | Примечания |
|:--------------|:----------|:------|
| ADMIN_PRIV    | USER или ROLE    | Эту операцию могут выполнять только пользователи или роли с привилегией ADMIN_PRIV  |

## Примечания по использованию {#usage-notes}

- Удаление роли не влияет на права пользователей, которые ранее входили в эту роль. Оно лишь разрывает связь между ролью и пользователем. Права, полученные пользователем от роли, не изменятся.

## Пример {#example}

Подготовка — создайте `role1`, чтобы в примере DROP было что удалять:

```sql
CREATE ROLE role1;
```

- Удаление роли role1

```sql
DROP ROLE role1;
```
