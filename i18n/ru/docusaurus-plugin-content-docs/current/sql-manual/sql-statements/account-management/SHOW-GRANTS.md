## Описание {#description}

Эта команда позволяет просматривать права пользователей.

## Синтаксис {#syntax}

```sql
SHOW [ALL] GRANTS [FOR <user_identity>];
```

## Необязательные параметры {#optional-parameters}

**1. `[ALL]`**

Указывает, нужно ли просмотреть права всех пользователей.

**2. `<user_identity>`**

Указывает пользователя, права которого нужно просмотреть. `user_identity` должен быть создан командой `CREATE USER`.

## Возвращаемые значения {#return-value}

  | Столбец | Описание |
  | -- | -- |
  | UserIdentity | Идентификатор пользователя |
  | Comment | Комментарий |
  | Password | `No` — локальный пароль отсутствует; `Yes` — есть только основной пароль; `Yes (dual)` — также сохранён дополнительный пароль (начиная с версии 4.2.1). |
  | Roles | Роли |
  | GlobalPrivs | Глобальные права |
  | CatalogPrivs | Права на Catalog |
  | DatabasePrivs | Права на базы данных |
  | TablePrivs | Права на таблицы |
  | ColPrivs | Права на столбцы |
  | ResourcePrivs | Права на ресурсы |
  | WorkloadGroupPrivs | Права на WorkloadGroup |

## Требования к правам доступа {#access-control-requirements}

Для выполнения этой SQL-команды пользователю необходимы как минимум следующие права:

| Право | Объект | Примечания |
| :---------------- | :------------- | :---------------------------- |
| GRANT_PRIV        | Пользователь или роль | Пользователь или роль должны обладать правом `GRANT_PRIV`, чтобы просматривать права всех пользователей. В противном случае доступны только права текущего пользователя. |

## Примечания по использованию {#usage-notes}
  - `SHOW ALL GRANTS` позволяет просмотреть права всех пользователей, но требует права `GRANT_PRIV`.
  - Если указан `user_identity`, отображаются права заданного пользователя. При этом `user_identity` должен быть создан командой `CREATE USER`.
  - Если `user_identity` не указан, отображаются права текущего пользователя.
  - Doris управляет правами на основе модели RBAC (Role-Based Access Control). Поэтому здесь отображаются совокупные права всех ролей, назначенных пользователю. Чтобы выяснить, из какой именно роли получено определённое право, воспользуйтесь командой [SHOW ROLES](./SHOW-ROLES.md).

## Примеры {#examples}

1. Просмотр сведений о правах всех пользователей.

   ```sql
   SHOW ALL GRANTS;
   ```

   ```text
   +--------------+---------+----------+----------+----------------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
   | UserIdentity | Comment | Password | Roles    | GlobalPrivs          | CatalogPrivs | DatabasePrivs                                                         | TablePrivs | ColPrivs | ResourcePrivs | WorkloadGroupPrivs |
   +--------------+---------+----------+----------+----------------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
   | 'root'@'%'   | ROOT    | No       | operator | Node_priv,Admin_priv | NULL         | internal.information_schema: Select_priv; internal.mysql: Select_priv | NULL       | NULL     | NULL          | normal: Usage_priv |
   | 'admin'@'%'  | ADMIN   | No       | admin    | Admin_priv           | NULL         | internal.information_schema: Select_priv; internal.mysql: Select_priv | NULL       | NULL     | NULL          | normal: Usage_priv |
   | 'jack'@'%'   |         | No       |          | NULL                 | NULL         | internal.information_schema: Select_priv; internal.mysql: Select_priv | NULL       | NULL     | NULL          | normal: Usage_priv |
   +--------------+---------+----------+----------+----------------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
   ```

2. Просмотр прав указанного пользователя.

    ```sql
    SHOW GRANTS FOR jack@'%';
    ```

    ```text
    +--------------+---------+----------+-------+-------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
    | UserIdentity | Comment | Password | Roles | GlobalPrivs | CatalogPrivs | DatabasePrivs                                                         | TablePrivs | ColPrivs | ResourcePrivs | WorkloadGroupPrivs |
    +--------------+---------+----------+-------+-------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
    | 'jack'@'%'   |         | No       |       | NULL        | NULL         | internal.information_schema: Select_priv; internal.mysql: Select_priv | NULL       | NULL     | NULL          | normal: Usage_priv |
    +--------------+---------+----------+-------+-------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
    ```

3. Просмотр прав текущего пользователя.

   ```sql
   SHOW GRANTS;
   ```

   ```text
   +--------------+---------+----------+----------+----------------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
   ```
