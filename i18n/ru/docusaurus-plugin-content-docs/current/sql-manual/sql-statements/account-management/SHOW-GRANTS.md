## Описание {#description}

 Эта инструкция используется для просмотра прав пользователей.

## Синтаксис {#syntax}

```sql
SHOW [ALL] GRANTS [FOR <user_identity>];
```

## Необязательные параметры {#optional-parameters}

**1. `[ALL]`**

Определяет, нужно ли просматривать права всех пользователей.

**2. `<user_identity>`**

  Укажите пользователя, права которого нужно просмотреть. Пользователь с идентификатором `user_identity` должен быть создан командой `CREATE USER`.

## Возвращаемое значение {#return-value}

  | Столбец | Описание |
  | -- | -- |
  | UserIdentity | Идентификатор пользователя |
  | Comment | Комментарий |
  | Password | Указывает, задан ли пароль |
  | Roles | Роли |
  | GlobalPrivs | Глобальные привилегии |
  | CatalogPrivs | Привилегии Catalog |
  | DatabasePrivs | Привилегии на уровне базы данных |
  | TablePrivs | Привилегии на уровне таблицы |
  | ColPrivs | Привилегии на уровне столбца |
  | ResourcePrivs | Привилегии на уровне ресурса |
  | WorkloadGroupPrivs | Привилегии WorkloadGroup |

## Требования к правам доступа {#access-control-requirements}

Для выполнения этой SQL-команды пользователь должен иметь как минимум следующие привилегии:

| Привилегия | Объект | Примечания                |
| :---------------- | :------------- | :---------------------------- |
| GRANT_PRIV        | Пользователь или роль    | Для просмотра прав всех пользователей пользователь или роль должны иметь привилегию `GRANT_PRIV`; в противном случае можно просматривать только права текущего пользователя |

## Примечания по использованию {#usage-notes}
  - `SHOW ALL GRANTS` позволяет просматривать права всех пользователей, но требует привилегии `GRANT_PRIV`.
  - Если указан `user_identity`, отображаются права указанного пользователя. При этом пользователь с идентификатором `user_identity` должен быть создан командой `CREATE USER`.
  - Если `user_identity` не указан, отображаются права текущего пользователя.
  - В Doris управление доступом реализовано на основе модели RBAC (управление доступом на основе ролей). Поэтому здесь отображается совокупность прав всех ролей, назначенных пользователю. Чтобы узнать, какая именно роль предоставляет определённое право, воспользуйтесь командой [SHOW ROLES](./SHOW-ROLES.md) для просмотра подробной информации.

1. Просмотр информации о правах всех пользователей.

   ```sql
   SHOW ALL GRANTS;
   ```

   ```text
   +--------------+---------+----------+----------+----------------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
   | UserIdentity | Comment | Password | Roles    | GlobalPrivs          | CatalogPrivs | DatabasePrivs                                                         | TablePrivs | ColPrivs | ResourcePrivs | WorkloadGroupPrivs |
   +--------------+---------+----------+----------+----------------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
   | 'root'@'%'   | ROOT    | No       | operator | Node_priv,Admin_priv | NULL         | internal.information_schema: Select_priv; internal.mysql: Select_priv | NULL       | NULL     | NULL          | normal: Usage_priv |
   | 'admin'@'%'  | ADMIN   | No       | admin    | Admin_priv           | NULL         | internal.information_schema: Select_priv; internal.mysql: Select_priv | NULL       | NULL     | NULL          | normal: Usage_priv |
   | 'jack'@'%'   |         | No       |          | NULL                 | NULL         | internal.information_schema: Select_priv; internal.mysql: Select_priv | NULL       | NULL     | NULL          | normal: Usage_priv |
   +--------------+---------+----------+----------+----------------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
   ```

2. Просмотр прав указанного пользователя

    ```sql
    SHOW GRANTS FOR jack@'%';
    ```

    ```text
    +--------------+---------+----------+-------+-------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
    | UserIdentity | Comment | Password | Roles | GlobalPrivs | CatalogPrivs | DatabasePrivs                                                         | TablePrivs | ColPrivs | ResourcePrivs | WorkloadGroupPrivs |

    +--------------+---------+----------+-------+-------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
    ```

3. Просмотр прав текущего пользователя

   ```sql

   ```
