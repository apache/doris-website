## Описание {#description}

Оператор `DROP USER` используется для удаления пользователя.

## Синтаксис {#syntax}

```sql
  DROP USER <user_identity>
```

## Обязательные параметры {#required-parameters}

**1. `<user_identity>`**

> Указанный идентификатор пользователя.

## Требования к управлению доступом {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать как минимум следующими правами:

| Право     | Объект    | Примечания |
|:--------------|:----------|:------|
| ADMIN_PRIV    | USER или ROLE    | Эту операцию могут выполнять только пользователи или роли с правами ADMIN_PRIV  |

## Пример {#example}

- Удаление пользователя jack@'192.%'

```sql
DROP USER 'jack'@'192.%'
```
