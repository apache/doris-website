## Описание {#description}

Эта инструкция используется для удаления базы данных.

## Синтаксис {#syntax}

```sql
DROP DATABASE [IF EXISTS] <db_name> [FORCE];
```

## Обязательные параметры {#required-parameters}

** 1. `<db_name>`**
>  Имя базы данных

## Необязательные параметры {#optional-parameters}

** 1. `FORCE`**
>  Принудительное удаление без перемещения в корзину

## Управление доступом {#permission-control}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Права         | Объект    | Примечания             |
|:-----------|:------|:---------------|
| DROP_PRIV | Соответствующая база данных | Необходимо иметь право на удаление соответствующей базы данных |


## Меры предосторожности {#precautions}

При выполнении DROP DATABASE FORCE система не проверяет, есть ли в базе данных незавершённые транзакции. База данных удаляется сразу без возможности восстановления. Как правило, выполнять эту операцию не рекомендуется.

## Пример {#example}

Подготовка: создайте `db_test`, чтобы в примере с DROP было что удалить:

```sql
CREATE DATABASE db_test;
```

- Удаление базы данных db_test

    ```sql
    DROP DATABASE db_test;
    ```
