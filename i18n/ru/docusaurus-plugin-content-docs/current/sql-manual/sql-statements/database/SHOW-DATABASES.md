## Описание {#description}

Эта инструкция используется для отображения видимых в данный момент баз данных.

## Синтаксис {#syntax}

```sql
SHOW DATABASES [FROM <catalog>] [<filter_expr>];
```

## Необязательные параметры {#optional-parameters}

** 1. `<catalog>`**
>  Соответствующий Catalog

** 2. `<filter_expr>`**
>  Фильтрация по указанным условиям

## Возвращаемое значение {#return-value}

| Столбец | Описание |
|:---------|:-----------|
| Database |  Имя базы данных|

## Управление доступом {#permission-control}

Пользователь, выполняющий эту команду SQL, должен обладать как минимум следующими правами:

| Права         | Объект    | Примечания             |
|:-----------|:------|:---------------|
| SELECT_PRIV | Соответствующая база данных | Требуется право на чтение соответствующей базы данных |

## Примеры {#examples}

- Выводит имена всех текущих баз данных.

   ```sql
   SHOW DATABASES;
   ```

   ```text
   +--------------------+
   | Database           |
   +--------------------+
   | test               |
   | information_schema |
   +--------------------+
   ```

- Выводит имена всех баз данных в `hms_catalog`.

   ```sql
   SHOW DATABASES FROM hms_catalog;
   ```

   ```text
   +---------------+
   | Database      |
   +---------------+
   | default       |
   | tpch          |
   +---------------+
   ```

- Выводит имена всех текущих баз данных, отфильтрованных по выражению `like 'infor%'`.

   ```sql
   SHOW DATABASES like 'infor%';
   ```

   ```text
   +--------------------+
   | Database           |
   +--------------------+
   | information_schema |
   +--------------------+
   ```
