## Описание {#description}

Команда "SHOW CHARSET" используется для отображения наборов символов, доступных в текущей системе управления базами данных, и некоторых свойств каждого набора символов.

Эти свойства могут включать имя набора символов, правило сортировки по умолчанию, максимальную длину в байтах и т. д. Список поддерживаемых системой наборов символов и подробные сведения о них можно просмотреть, выполнив команду "SHOW CHARSET".

## Синтаксис {#syntax}
```sql
SHOW CHARSET
```

## Возвращаемое значение {#return-value}
| Имя столбца | Описание |
| -- |-------------|
| Charset | Набор символов         |
| Description | Описание          |
| Default Collation | Имя правила сортировки по умолчанию      |
| Maxlen | Максимальная длина в байтах      |

## Примеры {#examples}

```sql
SHOW CHARSET;
```

```text
+---------+---------------+-------------------+--------+
| Charset | Description   | Default collation | Maxlen |
+---------+---------------+-------------------+--------+
| utf8mb4 | UTF-8 Unicode | utf8mb4_0900_bin  | 4      |
+---------+---------------+-------------------+--------+
```
