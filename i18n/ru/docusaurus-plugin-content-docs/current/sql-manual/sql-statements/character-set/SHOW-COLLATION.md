## Описание {#description}

В Doris команда SHOW COLLATION используется для отображения доступных в базе данных порядков сортировки для наборов символов. Порядок сортировки представляет собой набор правил, определяющих, как сортируются и сравниваются данные. Эти правила влияют на хранение и извлечение символьных данных.

## Синтаксис {#syntax}

```sql
SHOW COLLATION
```

## Возвращаемое значение {#return-value}

| Имя столбца | Описание  |
| -- |--------------|
| Collation | Название порядка сортировки         |
| Charset | Набор символов          |
| Id | Идентификатор порядка сортировки        |
| Default | Является ли этот порядок сортировки порядком по умолчанию для набора символов |
| Compiled | Скомпилирован ли порядок сортировки        |
| Sortlen | Длина сортировки         |



## Примечания по использованию {#usage-notes}

Хотя Doris поддерживает команду MySQL для настройки порядка сортировки, эта настройка фактически не действует. При выполнении команды в качестве правила сравнения всегда используется utf8mb4_0900_bin.

## Примеры {#examples}

```sql
SHOW COLLATION;
```

```text
+--------------------+---------+------+---------+----------+---------+
| Collation          | Charset | Id   | Default | Compiled | Sortlen |
+--------------------+---------+------+---------+----------+---------+
| utf8mb4_0900_bin   | utf8mb4 |  309 | Yes     | Yes      |       1 |
| utf8mb3_general_ci | utf8mb3 |   33 | Yes     | Yes      |       1 |
+--------------------+---------+------+---------+----------+---------+
```
