## Описание {#description}

Эта инструкция позволяет просмотреть состояние задания по сбору статистики.

## Синтаксис {#syntax}

```SQL
SHOW [AUTO] ANALYZE [ <table_name> | <job_id> ]
    [ WHERE STATE = {"PENDING" | "RUNNING" | "FINISHED" | "FAILED"} ];
```

## Обязательные параметры {#required-parameters}

**Нет**

## Необязательные параметры {#optional-parameters}

**1. `AUTO`**

> Показать информацию об автоматических заданиях. Если параметр не указан, по умолчанию отображается информация о заданиях, запущенных вручную.

**2. `<table_name>`**

> Имя таблицы. Если оно указано, можно просмотреть информацию о заданиях для этой таблицы. Если имя не указано, по умолчанию возвращается информация о заданиях для всех таблиц.

**3. `<job_id>`**

> ID задания по сбору статистики, получаемый при выполнении асинхронного сбора с помощью ANALYZE. Если ID не указан, команда возвращает информацию обо всех заданиях.

**4. `WHERE STATE = {"PENDING" | "RUNNING" | "FINISHED" | "FAILED"}`**

> Условие фильтрации по состоянию задания. Если не указано, по умолчанию отображается информация о заданиях во всех состояниях.

## Возвращаемое значение {#return-value}

| Столбец | Описание           |
| -- |--------------|
| job_id | Уникальный ID задания по сбору статистики           |
| catalog_name |   Имя Catalog         |
| db_name | Имя базы данных           |
| tbl_name | Имя таблицы         |
| col_name | Список имён столбцов           |
| job_type |   Тип задания           |
| analysis_type |  Тип анализа           |
| message | Сообщение об ошибке         |
| last_exec_time_in_ms | Время последнего анализа           |
| state |   Состояние задания          |
| progress | Ход выполнения задания           |
| schedule_type | Тип расписания         |
| start_time | Время начала задания          |
| end_time |   Время завершения задания           |
| priority | Приоритет задания           |
| enable_partition | Флаг включения сбора статистики по разделам         |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту инструкцию SQL, должен иметь как минимум следующие права:

| Право | Объект | Примечания                                    |
|:--------------| :------------- |:------------------------------------------------|
| SELECT_PRIV   | Таблица    | Для выполнения SHOW требуется право SELECT_PRIV на запрашиваемую таблицу. |
