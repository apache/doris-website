## Описание {#description}

Удаляет статистику для указанной таблицы и столбцов. Если имена столбцов не указаны, будет удалена статистика для всех столбцов.

## Синтаксис {#syntax}

```sql
DROP STATS <table_name> [ <column_names> ]
```

Где:

```sql
column_names
  :
  (<column_name>, [ <column_name>... ])
```

## Обязательные параметры {#required-parameters}

**<table_name>**

> Идентификатор (имя) таблицы.

## Необязательные параметры {#optional-parameters}

**<column_names>**

> Список идентификаторов (имён) столбцов.

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие права:

| Право | Объект | Примечания |
| :-------- | :----- | :---- |
| DROP_PRIV | Таблица  |       |

## Примеры {#examples}

- Удаление статистики для всех столбцов таблицы table1

  ```sql
  DROP STATS table1
  ```
- Удаление статистики для столбцов col1 и col2 таблицы table1

  ```sql
  DROP STATS table1 (col1, col2)
  ```
