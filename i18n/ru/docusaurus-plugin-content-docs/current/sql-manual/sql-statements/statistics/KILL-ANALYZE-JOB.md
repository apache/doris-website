## Описание {#description}

Останавливает задание по сбору статистической информации, выполняющееся в фоновом режиме.

## Синтаксис {#syntax}

```sql
KILL ANALYZE <job_id>
```
## Обязательные параметры {#required-parameters}

**<job_id>**

> Указывает идентификатор задания. Получить job_id задания можно с помощью SHOW ANALYZE. Подробное описание использования см. в разделе «SHOW ANALYZE».

## Необязательные параметры {#optional-parameters}

Нет

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право (Право) | Объект (Объект) | Примечания (Примечания) |
| --------------------- | --------------- | ------------- |
| SELECT_PRIV           | таблица         |               |

## Примечания по использованию {#usage-notes}

Уже завершённые задания нельзя остановить.

## Примеры {#examples}

Остановить задание по сбору статистической информации с идентификатором 10036

```sql
kill analyze 10036
```
