## Описание {#description}

Этот оператор используется для просмотра статистики столбцов таблицы.

## Синтаксис {#syntax}

```SQL
SHOW COLUMN [CACHED] STATS <table_name> [ (<column_name> [, ...]) ];
```

## Обязательные параметры {#required-parameters}

**1. `<table_name>`**

> Имя таблицы, для которой необходимо отобразить статистику столбцов.

## Необязательные параметры {#optional-parameters}

**1. `CACHED`**

> Вывести статистику столбцов из кеша FE. Если параметр не указан, по умолчанию отображается информация, сохранённая в таблице статистики.

**2. `<column_name>`**

> Укажите имена столбцов, статистику которых нужно отобразить. Столбцы должны существовать в таблице; несколько имён разделяются запятыми. Если параметр не указан, по умолчанию отображается информация обо всех столбцах.

## Возвращаемое значение {#return-value}

| Столбец | Примечание           |
| -- |--------------|
| column_name | имя столбца           |
| index_name |   имя индекса           |
| count | количество строк в столбце           |
| ndv | количество уникальных значений столбца         |
| num_null | количество значений NULL в столбце           |
| data_size |   общий размер данных столбца           |
| avg_size_byte |  средний размер значения столбца           |
| min | минимальное значение         |
| max | максимальное значение           |
| method |   метод сбора          |
| type | тип сбора           |
| trigger | способ запуска задания         |
| query_times | количество запросов          |
| updated_time |   время обновления           |
| update_rows | количество обновлённых строк при последнем анализе           |
| last_analyze_row_count | количество строк в таблице при последнем анализе         |
| last_analyze_version | версия таблицы при последнем анализе         |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий этот SQL, должен иметь как минимум следующие права:

| Привилегия | Объект | Примечания                                    |
|:--------------| :------------- |:------------------------------------------------|
| SELECT_PRIV   | Таблица    | Для выполнения SHOW требуется привилегия SELECT_PRIV на запрашиваемую таблицу. |
