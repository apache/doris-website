## Описание {#description}

Эта инструкция используется для просмотра сводной статистики таблицы.

## Синтаксис {#syntax}

```SQL
SHOW TABLE STATS <table_name>;
```

## Обязательные параметры {#required-parameters}

**1. `<table_name>`**

> Имя таблицы

## Необязательные параметры {#optional-parameters}

**Нет**

## Возвращаемое значение {#return-value}

| Столбец | Описание           |
| -- |--------------|
| updated_rows | количество обновлённых строк таблицы           |
| query_times |   количество запросов к таблице           |
| row_count | количество строк в таблице           |
| updated_time | время последнего изменения таблицы        |
| columns | список проанализированных столбцов           |
| trigger |   способ запуска последнего анализа           |
| new_partition |  признак первой загрузки новой партиции           |
| user_inject | признак внесения статистики пользователем         |
| enable_auto_analyze | признак включённого автоматического анализа         |
| last_analyze_time |   время последнего анализа          |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту инструкцию SQL, должен обладать как минимум следующими правами:

| Право | Объект | Примечания                                    |
|:--------------| :------------- |:------------------------------------------------|
| SELECT_PRIV   | Таблица    | При выполнении SHOW требуется право SELECT_PRIV на таблицу, к которой выполняется запрос. |
