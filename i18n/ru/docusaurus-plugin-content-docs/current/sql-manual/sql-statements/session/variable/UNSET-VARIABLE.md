## Описание {#description}

Эта инструкция используется для сброса системных переменных Doris. Эти системные переменные можно изменять на глобальном уровне или на уровне сеанса.

## Синтаксис {#syntax}

```sql
UNSET [<effective_scope>] VARIABLE (<variable_name>)
```

## Обязательные параметры {#required-parameters}
**1. `<variable_name>`**
> Указывает имя переменной. Чтобы сбросить все переменные, укажите в этом параметре ключевое слово `ALL`.

## Необязательные параметры {#optional-parameters}
**1. `<effective_scope>`**
> Область действия может принимать одно из значений: `GLOBAL`, `SESSION` или `LOCAL`. Если область действия не указана, по умолчанию используется `SESSION`. `LOCAL` является псевдонимом `SESSION`.

## Требования к правам доступа {#access-control-requirements}
Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие права:

| Право  | Объект | Примечания                                        |
| :--------- | :----- | :------------------------------------------- |
| ADMIN_PRIV | Сеанс  | Для сброса глобальных переменных требуются права администратора |

## Примечания по использованию {#usage-notes}

- Только пользователи ADMIN могут сбрасывать переменные на глобальном уровне
- При сбросе переменной с указанием `GLOBAL` изменение действует только в вашем текущем сеансе и вновь открываемых сеансах. Оно не влияет на другие уже открытые сеансы.



## Пример {#example}

- Сброс значения часового пояса

   ```
   UNSET VARIABLE time_zone;
   ```


- Сброс глобального лимита памяти для выполнения запросов

   ```
   UNSET GLOBAL VARIABLE exec_mem_limit;
   ```


- Сброс всех переменных на глобальном уровне

   ```
   UNSET GLOBAL VARIABLE ALL;
   ```
