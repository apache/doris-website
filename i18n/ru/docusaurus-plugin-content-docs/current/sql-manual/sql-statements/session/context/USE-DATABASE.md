## Описание {#description}

Используется для переключения на указанную базу данных или вычислительную группу.

## Синтаксис {#syntax}

```SQL
USE { [<catalog_name>.]<database_name>[@<compute_group_name>] | @<compute_group_name> }
```

## Обязательные параметры {#required-parameters}

Переключение на указанную базу данных.

**1. `<database_name>`**
> Имя базы данных, на которую нужно переключиться.
> Если каталог не указан, по умолчанию используется текущий каталог.

Переключение только на указанную вычислительную группу.

**1. `<compute_group_name>`**
> Имя вычислительной группы, на которую нужно переключиться.

## Необязательные параметры {#optional-parameters}

Переключение на указанную базу данных.

**1. `<catalog_name>`**
> Имя каталога, на который нужно переключиться.

**2. `<compute_group_name>`**
> Имя вычислительной группы, на которую нужно переключиться.

## Требования к правам доступа {#access-control-requirements}

| Привилегия  | Объект                | Примечания                                                           |
|-------------|-----------------------|----------------------------------------------------------------------|
| SELECT_PRIV | Catalog, база данных  | Для переключения на каталог или базу данных требуется привилегия SELECT_PRIV для соответствующего объекта. |
| USAGE_PRIV  | Вычислительная группа | Для переключения на вычислительную группу требуется привилегия USAGE_PRIV для этой группы. |

## Примеры {#examples}

1. Если база данных `demo` существует, попробуйте использовать её:

   ```sql
   use demo;
   ```

2. Если база данных `demo` существует в каталоге `hms_catalog`, попробуйте переключиться на `hms_catalog` и использовать эту базу данных:

    ```sql
    use hms_catalog.demo;
    ```

3. Если база данных `demo` существует в текущем каталоге и вы хотите использовать вычислительную группу с именем 'cg1', попробуйте переключиться на них:

    ```sql
    use demo@cg1;
    ```

4. Если вы хотите использовать только вычислительную группу с именем 'cg1', попробуйте переключиться на неё:

    ```sql
    use @cg1;
    ```
