## Описание {#description}

Этот синтаксис используется для просмотра сведений о транзакции с указанным идентификатором или меткой.

## Синтаксис {#syntax}

```sql
SHOW TRANSACTION
[FROM <db_name>]
WHERE
[id = <transaction_id> | label = <label_name>];
```

## Обязательные параметры {#required-parameters}

**1. `<transaction_id>`**

Идентификатор транзакции, сведения о которой нужно просмотреть.

**2. `<label_name>`**

Метка транзакции, сведения о которой нужно просмотреть.

## Необязательные параметры {#optional-parameters}

**1. `<db_name>`**

База данных, для которой нужно просмотреть сведения о транзакциях.

## Возвращаемое значение {#return-value}

| Имя столбца         | Описание |
|---|---|
| TransactionId       | Идентификатор транзакции |
| Label               | Метка, связанная с задачей загрузки |
| Coordinator         | Узел, отвечающий за координацию транзакции |
| TransactionStatus   | Состояние транзакции |
| PREPARE             | Этап подготовки |
| COMMITTED           | Транзакция успешно завершена, но данные ещё не видны |
| VISIBLE             | Транзакция успешно завершена, данные видны  |
| ABORTED             | Транзакция завершилась ошибкой |
| LoadJobSourceType   | Тип задачи загрузки |
| PrepareTime         | Время начала транзакции |
| CommitTime          | Время успешной фиксации транзакции |
| FinishTime          | Время, когда данные стали видны |
| Reason              | Сообщение об ошибке |
| ErrorReplicasCount  | Количество реплик с ошибками |
| ListenerId          | Идентификатор связанного задания загрузки |
| TimeoutMs           | Тайм-аут транзакции в миллисекундах |

## Примеры {#examples}

1. Просмотр транзакции с идентификатором 4005:

   ```sql
   SHOW TRANSACTION WHERE ID=4005;
   ```

2. Просмотр транзакции с идентификатором 4005 в указанной базе данных:

   ```sql
   SHOW TRANSACTION FROM db WHERE ID=4005;
   ```

3. Просмотр транзакции с меткой label_name:

   ```sql
   SHOW TRANSACTION WHERE LABEL = 'label_name';
   ```
