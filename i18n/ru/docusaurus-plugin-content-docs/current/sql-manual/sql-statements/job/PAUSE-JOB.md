## Описание {#description}

Когда пользователь приостанавливает задание в состоянии RUNNING, выполняющаяся задача прерывается, а состояние задания меняется на PAUSED. Приостановленное задание можно возобновить с помощью операции RESUME.

## Синтаксис {#syntax}

```sql
PAUSE JOB WHERE jobname = <job_name> ;
```

## Обязательные параметры {#required-parameters}

**1. `<job_name>`**
> Имя задания, которое нужно приостановить.

## Требования к управлению доступом {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Привилегия | Объект | Тип выполнения | Примечания |
|:--------------|:-----------|:------------------------|:------------------------|
| ADMIN_PRIV | База данных | Непотоковое | В настоящее время для выполнения этой операции поддерживаются только права **ADMIN** |
| LOAD_PRIV | База данных | Потоковое |Для выполнения этой операции поддерживаются права **LOAD** |

## Примеры {#examples}

- Приостановить задание с именем example.

   ```sql 
   PAUSE JOB where jobname='example'; 
   ```
