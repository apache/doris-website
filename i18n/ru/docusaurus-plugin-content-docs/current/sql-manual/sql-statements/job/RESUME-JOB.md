## Описание {#description}

Возобновляет задание в состоянии PAUSED, переводя его в состояние RUNNING. Задание в состоянии RUNNING будет выполняться с заданной периодичностью.

## Синтаксис {#syntax}

```sql
RESUME JOB where jobName = <job_name> ;
```
## Обязательные параметры {#required-parameters}

**1. `<job_name>`**
> Параметр `<job_name>` задаёт имя возобновляемого задания.

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Привилегия | Объект | Тип выполнения | Примечания |
|:--------------|:-----------|:------------------------|:------------------------|
| ADMIN_PRIV | База данных | NO Streaming | В настоящее время для выполнения этой операции поддерживаются только права **ADMIN** |
| LOAD_PRIV | База данных | Streaming |Для выполнения этой операции поддерживаются права **LOAD** |

## Пример {#example}

- Возобновить задание с именем example.

   ```sql
   RESUME JOB where jobName= 'example';
   ```
