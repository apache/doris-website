## Описание {#description}

Эта инструкция используется для удаления загруженного файла.

## Синтаксис {#syntax}

```sql
DROP FILE "<file_name>" [ { FROM | IN } <database>] PROPERTIES ("<key>"="<value>" [ , ... ])
```

## Обязательные параметры {#required-parameters}

**1. `<file_name>`**

> Имя файла, заданное пользователем.

**2. `<key>`**

> Ключ атрибута файла.
> - **catalog**: Обязательный параметр. Категория файла.

**3. `<value>`**

> Значение атрибута файла.

## Необязательные параметры {#optional-parameters}

**1. `<database>`**

> Указывает базу данных, к которой относится файл. Если параметр не указан, используется база данных текущего сеанса.

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать следующими минимальными привилегиями:

| Привилегия   | Объект              | Примечания                                                                      |
|:-------------|:--------------------|:--------------------------------------------------------------------------------|
| `ADMIN_PRIV` | Пользователь / роль | Для выполнения этой операции пользователь или роль должны обладать привилегией `ADMIN_PRIV` |

## Пример {#example}

- Удаление файла ca.pem

    ```sql
    DROP FILE "ca.pem" properties("catalog" = "kafka");
    ```
- Удаление файла `client.key`, относящегося к категории `my_catalog`

  ```sql
  DROP FILE "client.key"
  IN my_database
  ```

- Удаление файла `client_1.key`, относящегося к категории `my_catalog`

  ```sql
  DROP FILE "client_1.key"
  FROM my_database
  ```
