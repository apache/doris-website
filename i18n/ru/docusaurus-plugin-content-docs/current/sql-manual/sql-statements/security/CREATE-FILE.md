## Описание {#description}

Эта инструкция используется для создания и загрузки файла в кластер Doris.
Эта возможность обычно используется для управления файлами, необходимыми для выполнения других команд, например сертификатами, открытыми
и закрытыми ключами и т. д.

## Синтаксис {#syntax}

```sql
CREATE FILE <file_name>
        [ { FROM | IN } <database_name>] PROPERTIES ("<key>"="<value>" [ , ... ]);
```

## Обязательные параметры {#required-parameters}

**1. `<file_name>`**

> Имя файла, заданное пользователем.

**2. `<key>`**

> Ключ атрибута файла.
> - **url**: Обязательный. Указывает URL для скачивания по HTTP без аутентификации. После успешного выполнения файл будет
    сохранён
    в Doris, и этот URL больше не потребуется.
> - **catalog**: Обязательный. Имя категории для классификации файлов (задаётся пользователем). Используется для поиска файлов в определённых
    командах (
    например, при плановой загрузке из источника Kafka файлы ищутся в категории 'kafka').
> - **md5**: Необязательный. Контрольная сумма MD5 файла. Если она указана, после скачивания выполняется проверка.

**3. `<value>`**

> Значение атрибута файла.

## Необязательные параметры {#optional-parameters}

**1. `<database_name>`**

> Указывает базу данных, которой принадлежит файл. Если не указана, используется база данных текущего сеанса.

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать как минимум следующими привилегиями:

| Привилегия   | Объект              | Примечания                                                                      |
|:-------------|:--------------------|:--------------------------------------------------------------------------------|
| `ADMIN_PRIV` | Пользователь / роль | Для выполнения этой операции пользователь или роль должны обладать привилегией `ADMIN_PRIV` |

## Примечания по использованию {#usage-notes}

- Правила доступа к файлам

> Каждый файл принадлежит определённой базе данных (Database). Пользователи с правами доступа к базе данных могут обращаться ко всем файлам
> в ней.

- Ограничения размера и количества файлов

> Эта функция предназначена прежде всего для управления небольшими файлами, например сертификатами.  
> **Ограничение размера**: Размер отдельного файла ограничен 1 МБ  
> **Ограничение количества**: В кластер Doris можно загрузить не более 100 файлов

## Пример {#example}

- Создать файл ca.pem с категорией kafka

   ```sql
   CREATE FILE "ca.pem"
   PROPERTIES
   (
       "url" = "https://test.bj.bcebos.com/kafka-key/ca.pem",
       "catalog" = "kafka"
   );
   ```

- Создать файл client.key с категорией my_catalog

   ```sql
   CREATE FILE "client.key"
   IN my_database
   PROPERTIES
   (
       "url" = "https://test.bj.bcebos.com/kafka-key/client.key",
       "catalog" = "my_catalog",
       "md5" = "b5bb901bf10f99205b39a46ac3557dd9"
   );
   ```

- Создать файл client_1.key с категорией my_catalog

  ```sql
    CREATE FILE "client_1.key"
    FROM my_database
    PROPERTIES
    (
       "url" = "https://test.bj.bcebos.com/kafka-key/client.key",
       "catalog" = "my_catalog",
       "md5" = "b5bb901bf10f99205b39a46ac3557dd9"
    );
    ```
