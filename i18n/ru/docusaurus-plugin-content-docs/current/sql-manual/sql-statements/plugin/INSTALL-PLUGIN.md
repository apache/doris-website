## Описание {#description}

Эта инструкция используется для установки плагина

## Синтаксис {#syntax}

```sql
INSTALL PLUGIN FROM <source> [PROPERTIES ("<key>"="<value>", ...)]
```

## Обязательные параметры {#required-parameters}

** 1. `<source>`**
>  Путь к устанавливаемому плагину. Поддерживаются три варианта:
>   1. Абсолютный путь к zip-файлу
>   2. Абсолютный путь к каталогу плагина
>   3. Адрес для скачивания zip-файла по протоколу http или https

## Необязательные параметры {#optional-parameters}

** 1. `[PROPERTIES ("<key>"="<value>", ...)]`**
>  Используется для указания свойств или параметров при установке плагина

## Управление правами доступа {#permission-control}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Права         | Объект   | Примечания            |
|:-----------|:-----|:--------------|
| ADMIN_PRIV | Весь кластер | Требуются права администратора на весь кластер |

## Меры предосторожности {#precautions}

Обратите внимание: необходимо разместить файл md5 с тем же именем, что и у файла .zip, например http://mywebsite.com/plugin.zip.md5 . Этот файл должен содержать значение MD5 файла .zip.

## Пример {#example}

- Установка плагина из локального zip-файла:

    ```sql
    INSTALL PLUGIN FROM "/home/users/doris/auditdemo.zip";
    ```

- Установка плагина из локального каталога:

    ```sql
    INSTALL PLUGIN FROM "/home/users/doris/auditdemo/";
    ```

- Скачивание и установка плагина:

    ```sql
    INSTALL PLUGIN FROM "http://mywebsite.com/plugin.zip";
    ```

- Скачивание и установка плагина с указанием значения md5sum для zip-файла:

    ```sql
    INSTALL PLUGIN FROM "http://mywebsite.com/plugin.zip" PROPERTIES("md5sum" = "73877f6029216f4314d712086a146570");
    ```
