## Описание {#description}

Эта команда показывает инструкцию создания Catalog в Doris.

## Маскирование свойств {#property-masking}

Единая политика маскирования запланирована для Doris 4.2.0, а также для версий 5.0 и новее. Значения конфиденциальных свойств отображаются как `*XXX`; некоторые внутренние свойства опускаются. Явно заданные строки подключения JDBC скрываются целиком, а обычные URI очищаются в зависимости от их значений. См. [правила маскирования свойств Catalog](../../../lakehouse/catalog-property-masking.md). Пример ниже использует эту политику; он не описывает поведение версий 4.0, 4.1 или 3.x. В примере `*XXX` — маркер маскирования; остальные значения `XXX` служат условными обозначениями.

## Синтаксис {#syntax}

```sql
SHOW CREATE CATALOG <catalog_name>;
```

## Обязательные параметры {#required-parameters}

**1. `<catalog_name>`**

Имя Catalog, инструкцию создания которого требуется просмотреть.

## Требования к правам доступа {#access-control-requirements}
| Привилегия                                                                                   | Объект  | Примечание                              |
|:---------------------------------------------------------------------------------------------|:--------|:------------------------------------------|
| ADMIN_PRIV / SELECT_PRIV / LOAD_PRIV / ALTER_PRIV / CREATE_PRIV / SHOW_VIEW_PRIV / DROP_PRIV | Catalog | Требуется одно из перечисленных прав. |


## Пример {#example}

1. Просмотреть инструкцию создания Catalog oracle в Doris

```sql
   SHOW CREATE CATALOG oracle;
   ```
   ```text
   +---------+----------------------------------------------------------------------------------------------------------------------+
    | Catalog | CreateCatalog                                                                                                        |
    +---------+----------------------------------------------------------------------------------------------------------------------+
    | oracle  |
    CREATE CATALOG `oracle` PROPERTIES (
    "user" = "XXX",
    "type" = "jdbc",
    "password" = "*XXX",
    "jdbc_url" = "*XXX",
    "driver_url" = "XXX",
    "driver_class" = "oracle.jdbc.driver.OracleDriver",
    "checksum" = "XXX"
    ); |
    +---------+----------------------------------------------------------------------------------------------------------------------+
   ```
