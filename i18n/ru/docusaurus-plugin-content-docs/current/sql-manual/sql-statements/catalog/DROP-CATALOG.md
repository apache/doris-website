## Описание {#description}

Этот оператор используется для удаления внешнего каталога.

## Синтаксис {#syntax}

```sql
DROP CATALOG [IF EXISTS] <catalog_name>;
```

## Обязательные параметры {#required-parameters}

**1. `<catalog_name>`**
Имя каталога, который требуется удалить.

## Требования к управлению доступом {#access-control-requirements}
| Привилегия | Объект  | Примечания                                                               |
|:----------|:--------|:--------------------------------------------------------------------|
| DROP_PRIV | Catalog | Требуется привилегия DROP_PRIV для соответствующего каталога. |


## Пример {#example}

1. Удаление каталога hive

   ```sql
   DROP CATALOG hive;
   ```
