## Описание {#description}

Показывает свойства указанного Catalog.

## Маскирование свойств {#property-masking}

Единая политика маскирования запланирована для Doris 4.2.0, версии 5.0 и более поздних выпусков. Конфиденциальные свойства отображаются как `*XXX`; некоторые внутренние свойства опускаются. Явно указанные строки подключения JDBC полностью скрываются, а обычные URI очищаются в зависимости от их значений. См. [Правила маскирования свойств Catalog](../../../lakehouse/catalog-property-masking.md). В примере ниже применяется эта политика; он не описывает поведение версий 4.0, 4.1 и 3.x.

## Синтаксис {#syntax}

```sql
SHOW CATALOG <catalog_name>
```


## Обязательные параметры {#required-parameters}

**1. `<catalog_name>`**

Имя Catalog, свойства которого нужно показать.

## Возвращаемое значение {#return-value}

| Имя столбца | Описание                        |
|-------------|---------------------------------|
| Key         | Имя свойства конфигурации.      |
| Value       | Значение свойства конфигурации. |

## Требования к правам доступа {#access-control-requirements}

| Привилегия                                                                                   | Объект  | Примечания                                |
|:---------------------------------------------------------------------------------------------|:--------|:------------------------------------------|
| ADMIN_PRIV / SELECT_PRIV / LOAD_PRIV / ALTER_PRIV / CREATE_PRIV / SHOW_VIEW_PRIV / DROP_PRIV | Catalog | Требуется одна из перечисленных привилегий. |
