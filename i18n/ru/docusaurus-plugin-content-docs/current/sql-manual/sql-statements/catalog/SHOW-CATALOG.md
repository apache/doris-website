## Описание {#description}

Отображает свойства указанного Catalog

## Синтаксис {#syntax}

```sql
SHOW CATALOG <catalog_name>
```


## Обязательные параметры {#required-parameters}

**1. `<catalog_name>`**

Имя Catalog, свойства которого нужно отобразить.

## Возвращаемое значение {#return-value}

| Имя столбца | Описание                      |
|-------------|-------------------------------|
| Key         | Имя свойства конфигурации.    |
| Value       | Значение свойства конфигурации. |

## Требования к правам доступа {#access-control-requirements}

| Право доступа                                                                                | Объект  | Примечания                                |
|:---------------------------------------------------------------------------------------------|:--------|:------------------------------------------|
| ADMIN_PRIV / SELECT_PRIV / LOAD_PRIV / ALTER_PRIV / CREATE_PRIV / SHOW_VIEW_PRIV / DROP_PRIV | Catalog | Требуется одно из перечисленных прав доступа. |
