## Описание {#description}

Эта инструкция используется для просмотра созданных объектов Catalog

## Синтаксис {#syntax}

```sql
SHOW CATALOGS [LIKE <catalog_name>]
```

Пояснение:

1. LIKE: позволяет выполнять запрос по шаблону имени Catalog


## Необязательные параметры {#optional-parameters}

**1. `<catalog_name>`**

Имя объекта Catalog, который нужно отобразить.

## Возвращаемое значение {#return-value}

| Имя столбца    | Описание |
|---|---|
| CatalogId      | Уникальный идентификатор объекта Catalog |
| CatalogName    | Имя объекта Catalog. Встроенный Catalog по умолчанию имеет имя "internal", которое нельзя изменить. |
| Type           | Тип объекта Catalog |
| IsCurrent      | Указывает, является ли этот Catalog текущим активным объектом Catalog |
| CreateTime     | Время создания  |
| LastUpdateTime | Время последнего обновления |
| Comment        | Комментарий к объекту Catalog |

## Требования к правам доступа {#access-control-requirements}
| Привилегия                                                                                    | Объект  | Примечания                                     |
|:---------------------------------------------------------------------------------------------|:--------|:------------------------------------------|
| ADMIN_PRIV / SELECT_PRIV / LOAD_PRIV / ALTER_PRIV / CREATE_PRIV / SHOW_VIEW_PRIV / DROP_PRIV | Catalog | Требуется одна из перечисленных привилегий. |


## Примеры {#examples}

1. Просмотр созданных на данный момент объектов Catalog

   ```sql
   SHOW CATALOGS;
   ```
   ```sql
    +-----------+-------------+----------+-----------+-------------------------+---------------------+------------------------+
    | CatalogId | CatalogName | Type     | IsCurrent | CreateTime              | LastUpdateTime      | Comment                |
    +-----------+-------------+----------+-----------+-------------------------+---------------------+------------------------+
    |    130100 | hive        | hms      |           | 2023-12-25 16:11:41.687 | 2023-12-25 20:43:18 | NULL                   |
    |         0 | internal    | internal | yes       | UNRECORDED              | NULL                | Doris internal catalog |
    +-----------+-------------+----------+-----------+-------------------------+---------------------+------------------------+
    ```

2. Запрос по шаблону имени Catalog

   ```sql
   SHOW CATALOGS LIKE 'hi%';
   ```
    ```sql
    +-----------+-------------+----------+-----------+-------------------------+---------------------+------------------------+
    | CatalogId | CatalogName | Type     | IsCurrent | CreateTime              | LastUpdateTime      | Comment                |
    +-----------+-------------+----------+-----------+-------------------------+---------------------+------------------------+
    |    130100 | hive        | hms      |           | 2023-12-25 16:11:41.687 | 2023-12-25 20:43:18 | NULL                   |
    +-----------+-------------+----------+-----------+-------------------------+---------------------+------------------------+
   ```
