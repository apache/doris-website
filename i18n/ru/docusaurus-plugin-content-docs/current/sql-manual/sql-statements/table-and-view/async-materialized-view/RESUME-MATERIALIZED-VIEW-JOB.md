## Описание {#description}

Эта инструкция используется для временного возобновления выполнения заданий материализованных представлений по расписанию

## Синтаксис {#syntax}

```sql
RESUME MATERIALIZED VIEW JOB ON <mv_name>
```

## Обязательные параметры {#required-parameters}
**1. `<mv_name>`**
> Указывает имя материализованного представления.
>
> Имя материализованного представления должно начинаться с буквы (или символа любого языка, если включена поддержка имён в Unicode) и не может содержать пробелы или специальные символы, если только вся строка имени материализованного представления не заключена в обратные кавычки (например, `My Object`).
>
> В качестве имени материализованного представления нельзя использовать зарезервированные ключевые слова.
>
> Подробнее см. раздел «Зарезервированные ключевые слова».

## Требования к правам доступа {#access-control-requirements}
Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие привилегии:

| Привилегия | Объект | Примечания |
| :--------- | :----- | :------------------------------------------- |
| ALTER_PRIV | Материализованное представление | RESUME выполняет операцию ALTER над материализованным представлением |


## Примечания по использованию {#usage-notes}

- Эта инструкция обычно используется после инструкции приостановки материализованного представления

## Пример {#example}

- Возобновление выполнения заданий материализованного представления mv1 по расписанию

    ```sql
    RESUME MATERIALIZED VIEW JOB ON mv1;
    ```
