## Описание {#description}

Эта инструкция используется для удаления асинхронных материализованных представлений.

Синтаксис:

```sql
DROP MATERIALIZED VIEW (IF EXISTS)? mvName=multipartIdentifier
```


1. IF EXISTS:
   Если материализованное представление не существует, ошибка не возникает. Если это ключевое слово не указано и материализованное представление не существует, будет выдана ошибка.

2. mv_name:
   Имя удаляемого материализованного представления. Обязательное поле.

## Пример {#example}

1. Удаление материализованного представления таблицы mv1

```sql
DROP MATERIALIZED VIEW mv1;
```
2.Удаление материализованного представления указанной базы данных, если оно существует

```sql
DROP MATERIALIZED VIEW IF EXISTS db1.mv1;
```
