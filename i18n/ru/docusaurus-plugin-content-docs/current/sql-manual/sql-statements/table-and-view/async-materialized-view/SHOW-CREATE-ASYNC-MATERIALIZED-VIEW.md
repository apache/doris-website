## Описание {#description}

Просмотр оператора создания материализованного представления.

## Синтаксис {#syntax}

```sql
SHOW CREATE MATERIALIZED VIEW <materialized_view_name>
```

## Обязательные параметры {#required-parameters}

**1. `<materialized_view_name>`**

> Имя материализованного представления.

## Возвращаемые значения {#return-values}

|Имя столбца | Описание   |
| -- |------|
| Материализованное представление | Имя материализованного представления   |
| Создание материализованного представления | Оператор, используемый для создания материализованного представления |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право | Объект | Примечания                                                       |
| --------- | ------ | ----------------------------------------------------------- |
| SELECT_PRIV/LOAD_PRIV/ALTER_PRIV/CREATE_PRIV/DROP_PRIV | Таблица  | |

## Пример {#example}

1. Просмотр оператора создания асинхронного материализованного представления

   ```sql
   SHOW CREATE MATERIALIZED VIEW partition_mv;
   ```
