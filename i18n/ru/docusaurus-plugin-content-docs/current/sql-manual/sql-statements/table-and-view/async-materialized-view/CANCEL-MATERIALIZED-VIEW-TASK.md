## Описание {#description}

Эта инструкция используется для отмены задачи материализованного представления

## Синтаксис {#syntax}

```sql
CANCEL MATERIALIZED VIEW TASK <task_id> ON <mv_name>
```

## Обязательные параметры {#required-parameters}
**1. `<task_id>`**
> Указывает идентификатор задачи материализованного представления.


**2. `<mv_name>`**
> Указывает имя материализованного представления.
>
> Имя материализованного представления должно начинаться с буквы (или символа любого языка, если включена поддержка имён в Unicode) и не может содержать пробелы или специальные символы, если только вся строка имени материализованного представления не заключена в обратные кавычки (например, `My Object`).
>
> В качестве имени материализованного представления нельзя использовать зарезервированные ключевые слова.
>
> Подробнее см. раздел «Зарезервированные ключевые слова».

## Требования к правам доступа {#access-control-requirements}
Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие права:

| Право  | Объект | Примечания                                        |
| :--------- | :----- | :------------------------------------------- |
| ALTER_PRIV | Материализованное представление  | CANCEL является операцией ALTER над материализованным представлением |

## Пример {#example}

- Отменить задачу с идентификатором 1 в материализованном представлении mv1

    ```sql
    CANCEL MATERIALIZED VIEW TASK 1 on mv1;
    ```
