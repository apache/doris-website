## Описание {#description}

Отмена фоновых задач построения индексов.

## Синтаксис {#syntax}


```sql
CANCEL BUILD INDEX ON <table_name> [ job_list ]
```

Где:

```sql
job_list
  : (<job_id1>[ , job_id2 ][ ... ])
```
## Обязательные параметры {#required-parameters}

**<table_name>**

> Задаёт идентификатор (то есть имя) таблицы, который должен быть уникальным в пределах её базы данных (Database).
>
> Идентификатор должен начинаться с буквы (или любого символа языка, если включена поддержка имён в unicode) и не может содержать пробелы или специальные символы, если вся строка идентификатора не заключена в обратные кавычки (например, `My Object`).
>
> В качестве идентификаторов нельзя использовать зарезервированные ключевые слова.
>
> Подробнее см. в разделах «Требования к идентификаторам» и «Зарезервированные ключевые слова».

## Необязательные параметры {#optional-parameters}

**<job_list>**

> Задаёт список идентификаторов задач построения индексов, разделённых запятыми и заключённых в круглые скобки.
>
> Идентификаторы должны быть числами. Их можно просмотреть с помощью SHOW BUILD INDEX.

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Привилегия | Объект | Примечания                                                   |
| :--------- | :----- | :----------------------------------------------------------- |
| ALTER_PRIV | Таблица | CANCEL BUILD INDEX считается операцией ALTER над таблицей |

## Примечания по использованию {#usage-notes}

- В настоящее время команда действует только для инвертированных индексов и не применяется к другим индексам, например к индексу bloomfilter.
- В настоящее время команда действует только в режиме совмещённого хранения и вычислений и не применяется в режиме разделённого хранения и вычислений.
- Задачи построения индексов BUILD INDEX и ход их выполнения можно просмотреть с помощью SHOW BUILD INDEX.

## Примеры {#examples}

- Отмена всех задач построения индексов для таблицы table1

  ```sql
  CANCEL BUILD INDEX ON table1
  ```

- Отмена задач построения индексов jobid1 и jobid2 для таблицы table1

  ```sql
  CANCEL BUILD INDEX ON table1(jobid1, jobid2)
  ```
