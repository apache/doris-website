## Описание {#description}

Эта инструкция используется для удаления из таблицы индекса с указанным именем. В настоящее время поддерживаются только инвертированные индексы и индексы ann.

## Синтаксис {#syntax}

```sql
DROP INDEX [ IF EXISTS ] <index_name> ON [ <db_name> . ] <table_name>;
```

## Обязательные параметры {#required-parameters}

**1. `<index_name>`**: Имя индекса.  

**2. `<table_name>`**：Имя таблицы, которой принадлежит индекс.  

## Необязательные параметры {#optional-parameters}

**1. `<db_name>`**：Имя базы данных, необязательный параметр. Если не указано, по умолчанию используется текущая база данных.  

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право                | Объект             | Примечания                                    |
|:---------------------|:-------------------|:----------------------------------------------|
| ALTER_PRIV           | Таблица            | DROP INDEX — это операция ALTER над таблицей |

## Примеры {#examples}

- Удаление индекса

   ```sql
   DROP INDEX IF EXISTS index_name ON table1 ;
   ```
