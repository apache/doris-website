## Описание {#description}

Создаёт новый индекс для таблицы. Необходимо указать имя таблицы и имя индекса. Тип индекса, свойства и комментарий указывать необязательно.

## Синтаксис {#syntax}


```sql
CREATE INDEX [IF NOT EXISTS] <index_name>
             ON <table_name> (<column_name> [, ...])
             [USING {INVERTED | NGRAM_BF | ANN}]
             [PROPERTIES ("<key>" = "<value>"[ , ...])]
             [COMMENT '<index_comment>']
```

## Обязательные параметры {#required-parameters}

**1. `<index_name>`**

> Задаёт идентификатор (имя) индекса, который должен быть уникальным в пределах таблицы.
>
> Идентификатор должен начинаться с буквы (если включена поддержка имён в Unicode, он может начинаться с символа любого языка). Пробелы и специальные символы допустимы, только если весь идентификатор заключён в обратные кавычки (например, `My Object`).
>
> Идентификатор не может быть зарезервированным ключевым словом.
>
> Дополнительные сведения см. в требованиях к идентификаторам и списке зарезервированных ключевых слов.

**2. `<table_name>`**

> Задаёт идентификатор (имя) таблицы, который должен быть уникальным в пределах базы данных.
>
> Идентификатор должен начинаться с буквы (если включена поддержка имён в Unicode, он может начинаться с символа любого языка). Пробелы и специальные символы допустимы, только если весь идентификатор заключён в обратные кавычки (например, `My Object`).
>
> Идентификатор не может быть зарезервированным ключевым словом.
>
> Дополнительные сведения см. в требованиях к идентификаторам и списке зарезервированных ключевых слов.

**3. `<column_name> [, ...]`**

> Задаёт столбцы, для которых создаётся индекс (в настоящее время поддерживается только один столбец). Имя столбца должно быть уникальным в пределах таблицы.
>
> Идентификатор должен начинаться с буквы (если включена поддержка имён в Unicode, он может начинаться с символа любого языка). Пробелы и специальные символы допустимы, только если весь идентификатор заключён в обратные кавычки (например, `My Object`).
>
> Идентификатор не может быть зарезервированным ключевым словом.
>
> Дополнительные сведения см. в требованиях к идентификаторам и списке зарезервированных ключевых слов.

## Необязательные параметры {#optional-parameters}

**1. `USING {INVERTED | NGRAM_BF}`**

> Задаёт тип индекса. В настоящее время поддерживаются два типа: **INVERTED** (инвертированный индекс) и **NGRAM_BF** (индекс NGram BloomFilter).

**2. `PROPERTIES ("<key>" = "<value>"[ ,  ...])`**

> Задаёт параметры индекса в общем формате PROPERTIES. Поддерживаемые параметры и их значения описаны в документации соответствующего типа индекса.

**3. `COMMENT '<index_comment>'`**

> Задаёт комментарий к индексу для удобства сопровождения.

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право      | Объект   | Примечание                                                |
| ---------- | -------- | --------------------------------------------------------- |
| ALTER_PRIV | Таблица  | CREATE INDEX считается операцией ALTER над таблицей       |

## Примечания по использованию {#usage-notes}

- О том, как создать обычный индекс **INVERTED** для исторических данных, см. в разделе [Управление инвертированными индексами](../../../../table-design/index/inverted-index/overview.md#managing-inverted-indexes).
- Начиная с Doris 4.2, с помощью `variant_index_scope = "values"` можно [добавить индекс значений VARIANT в существующую таблицу](../../../../table-design/index/inverted-index/variant-values-index.md#add-to-existing-table). Пока индекс для исторических данных отсутствует, запросы могут сканировать эти данные.
- После создания индекса NGram BloomFilter типа **NGRAM_BF** в фоновом режиме выполняется изменение схемы для всех данных, чтобы завершить построение индекса. Проверить ход выполнения можно с помощью SHOW ALTER TABLE COLUMN.

## Примеры {#examples}

- Создать инвертированный индекс `index1` для таблицы `table1`



  ```sql
  CREATE INDEX index1 ON table1(col1) USING INVERTED;
  ```

- Создать индекс NGram BloomFilter `index2` для таблицы `table1`



  ```sql
  CREATE INDEX index2 ON table1(col1) USING NGRAM_BF PROPERTIES("gram_size"="3", "bf_size"="1024");
  ```


- Создать индекс ANN `index3` в таблице `table1` для векторного столбца `embedding`.


  ```sql
  CREATE INDEX index3 ON table1 (`embedding`) USING ANN PROPERTIES(
    "index_type"="hnsw",
    "metric_type"="l2_distance",
    "dim"="128"
  );
    ```
