## Описание {#description}

Оператор `CANCEL REBALANCE DISK` используется для отмены высокоприоритетной балансировки данных на дисках узлов Backend (BE). Этот оператор предоставляет следующие возможности:

- Отмена высокоприоритетной балансировки данных на дисках указанных узлов BE.
- Отмена высокоприоритетной балансировки данных на дисках всех узлов BE в кластере.
- После отмены система продолжает балансировать данные на дисках узлов BE, используя стандартный механизм планирования.

## Синтаксис {#syntax}

```sql
ADMIN CANCEL REBALANCE DISK [ ON ( "<host>:<port>" [, ... ] ) ];
```

## Необязательные параметры {#optional-parameters}

**1. `"<host>:<port>"`**

> Задаёт список узлов BE, для которых необходимо отменить высокоприоритетную балансировку данных на дисках.
>
> Каждый узел задаётся именем хоста (или IP-адресом) и портом heartbeat.
>
> Если этот параметр не указан, высокоприоритетная балансировка данных на дисках отменяется для всех узлов BE.

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие права:

| Привилегия      | Объект      | Примечания                                    |
| :-------------- | :---------- | :-------------------------------------------- |
| ADMIN           | Система     | Для выполнения этой команды пользователь должен иметь привилегию ADMIN. |

## Примечания по использованию {#usage-notes}

- Этот оператор лишь указывает, что система больше не будет отдавать приоритет балансировке данных на дисках указанных узлов BE; при этом система продолжит балансировать данные на дисках BE, используя стандартный механизм планирования.
- После выполнения этой команды любая ранее заданная стратегия высокоприоритетной балансировки немедленно перестаёт действовать.

## Примеры {#examples}

- Отмена высокоприоритетной балансировки данных на дисках всех узлов BE в кластере:

    ```sql
    ADMIN CANCEL REBALANCE DISK;
    ```

- Отмена высокоприоритетной балансировки данных на дисках указанных узлов BE:

```sql
ADMIN CANCEL REBALANCE DISK ON ("192.168.1.1:1234", "192.168.1.2:1234");
```
