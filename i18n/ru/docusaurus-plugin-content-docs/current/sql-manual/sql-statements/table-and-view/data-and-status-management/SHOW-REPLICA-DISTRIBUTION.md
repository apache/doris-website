## Описание {#description}

Эта инструкция используется для отображения информации о состоянии реплик таблицы или раздела.

## Синтаксис {#syntax}

```sql
SHOW REPLICA DISTRIBUTION FROM [ <database_name>.]<table_name> [<partition_list>] 
[where_clause]
```
Где:

```sql
partition_list
  : PARTITION (<partition_name>[ , ... ])
```

Где:

```sql
where_clause
: WHERE <output_column_name> = <value>
```

## Обязательные параметры {#required-parameters}

**1. `<table_name>`**

> Идентификатор (то есть имя) таблицы, который должен быть уникальным в пределах базы данных (Database).
>
> Идентификатор должен начинаться с буквы (или любого символа одного из поддерживаемых языков, если включена поддержка имён Unicode) и не может содержать пробелы или специальные символы, если только вся строка идентификатора не заключена в обратные кавычки (например, My Object).
>
> В качестве идентификаторов нельзя использовать зарезервированные ключевые слова.
>
> Подробнее см. требования к идентификаторам и список зарезервированных ключевых слов.


## Необязательные параметры {#optional-parameters}

**1. `<db_name>`**

> Идентификатор (то есть имя) базы данных, который должен быть уникальным в пределах кластера (Cluster).
>
> Идентификатор должен начинаться с буквы (или любого символа одного из поддерживаемых языков, если включена поддержка имён Unicode) и не может содержать пробелы или специальные символы, если только вся строка идентификатора не заключена в обратные кавычки (например, My Object).
>
> В качестве идентификаторов нельзя использовать зарезервированные ключевые слова.
>
> Подробнее см. требования к идентификаторам и список зарезервированных ключевых слов.

**2. `<partition_list>`**

> Разделённый запятыми список идентификаторов (то есть имён) разделов, которые должны быть уникальными в пределах таблицы (Table).
>
> Идентификатор должен начинаться с буквы (или любого символа одного из поддерживаемых языков, если включена поддержка имён Unicode) и не может содержать пробелы или специальные символы, если только вся строка идентификатора не заключена в обратные кавычки (например, My Object).
>
> В качестве идентификаторов нельзя использовать зарезервированные ключевые слова.
>
> Подробнее см. требования к идентификаторам и список зарезервированных ключевых слов.


## Возвращаемое значение {#return-value}

| Столбец     | Тип данных | Описание                                                                          |
|-------------|----------|-----------------------------------------------------------------------------------|
| BackendId   | Int      | Идентификатор узла BE (Backend), на котором расположена реплика.                   |
| ReplicaNum  | Int      | Количество реплик на этом узле BE.                                                |
| ReplicaSize | Int      | Общий объём хранилища, занимаемый всеми репликами на этом узле BE (в байтах).       |
| NumGraph    | String   | Наглядное представление доли реплик по количеству (с помощью символов >).           |
| NumPercent  | String   | Доля реплик по количеству в процентах, например 100.00%.                            |
| SizeGraph   | String   | Наглядное представление доли реплик по занимаемому объёму (с помощью символов >).   |
| SizePercent | String   | Доля реплик по занимаемому объёму в процентах, например 100.00%.                    |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту SQL-команду, должен иметь как минимум следующие права:

| Право      | Объект   | Примечания                                                                                                                       |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------|
| Admin_priv | Database | Требуется для выполнения административных операций с базой данных, включая управление таблицами, разделами и выполнение команд системного уровня. |

- Просмотр распределения реплик разделов таблицы

  ```sql
  SHOW REPLICA DISTRIBUTION FROM db1.tbl1 PARTITION(p1, p2);
  ```
