## Описание {#description}

Эта инструкция используется для создания снимка указанного tablet, главным образом для его локальной загрузки с целью воспроизведения
проблемы.

## Синтаксис {#syntax}

```sql
ADMIN COPY TABLET <tablet_id> PROPERTIES ("<key>"="<value>" [,...]).
```

## Обязательные параметры {#required-parameters}

**1. `<tablet_id>`**

Идентификатор tablet, который нужно скопировать.

## Необязательные параметры {#optional-parameters}

  ```sql
  [ PROPERTIES ("<key>"="<value>" [, ... ]) ]
  ```

Предложение PROPERTIES позволяет задать дополнительные параметры:

**1. `<backend_id>`**

Задаёт идентификатор узла BE, на котором находится реплика. Если параметр не указан, реплика выбирается случайным образом.

**2. `<version>`**

Задаёт версию снимка. Версия должна быть меньше или равна наибольшей версии реплики. Если
параметр не указан, используется наибольшая версия.

**3. `<expiration_minutes>`**

Время хранения снимка. По умолчанию: 1 час. По истечении этого времени снимок автоматически удаляется. Единица измерения: минуты.

## Возвращаемое значение {#return-value}

| Столбец           | Тип данных | Примечание                                                                                                                                                                                                           |
|-------------------|----------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TabletId          | string   | Идентификатор tablet, для которого создан снимок.                                                                                                                                                                    |
| BackendId         | string   | Идентификатор узла BE, на котором хранится снимок.                                                                                                                                                                   |
| Ip                | string   | IP-адрес узла BE, на котором хранится снимок.                                                                                                                                                                        |
| Path              | string   | Путь к месту хранения снимка на узле BE.                                                                                                                                                                             |
| ExpirationMinutes | string   | Время в минутах, по истечении которого снимок будет автоматически удалён.                                                                                                                                             |
| CreateTableStmt   | string   | Инструкция создания таблицы, соответствующей tablet. Это не исходная инструкция создания таблицы, а её упрощённый вариант для последующей локальной загрузки tablet.                                                  |

## Требования к управлению доступом {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать как минимум следующими привилегиями:

| Привилегия | Объект   | Примечания                                                                                                                       |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------|
| Admin_priv | База данных | Требуется для выполнения административных операций с базой данных, включая управление таблицами и разделами, а также выполнение команд системного уровня. |

## Примеры {#examples}

- Создание снимка реплики на указанном узле BE

  ```sql
  ADMIN COPY TABLET 10020 PROPERTIES("backend_id" = "10003");
  ```

  ```text
           TabletId: 10020
          BackendId: 10003
                 Ip: 192.168.10.1
               Path: /path/to/be/storage/snapshot/20220830101353.2.3600
  ExpirationMinutes: 60
    CreateTableStmt: CREATE TABLE `tbl1` (
    `k1` int(11) NULL,
    `k2` int(11) NULL
  ) ENGINE=OLAP
  DUPLICATE KEY(`k1`, `k2`)
  DISTRIBUTED BY HASH(k1) BUCKETS 1
  PROPERTIES (
  "replication_num" = "1",
  "version_info" = "2"
  );
  ```

- Создание снимка указанной версии реплики на указанном узле BE

  ```sql
  ADMIN COPY TABLET 10010 PROPERTIES("backend_id" = "10003", "version" = "10");
  ```
