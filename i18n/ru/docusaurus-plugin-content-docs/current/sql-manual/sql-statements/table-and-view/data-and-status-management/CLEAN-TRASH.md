## Описание {#description}

Этот оператор используется для удаления мусорных данных на узлах BE.

## Синтаксис {#syntax}

```sql
ADMIN CLEAN TRASH [ON ("<be_host>:<be_heartbeat_port>" [, ...])]
```

## Необязательные параметры {#optional-parameters}

**1. `[ON ("<be_host>:<be_heartbeat_port>" [, ...])]`**

Укажите узел BE, на котором нужно выполнить очистку. Если ON не указан, по умолчанию очищаются все узлы BE.


## Требования к управлению доступом {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны обладать как минимум следующими привилегиями:


| Привилегия  | Объект | Примечания                                        |
| :--------- | :----- | :------------------------------------------- |
| ADMIN_PRIV | Пользователь или роль  | Операцию CLEAN TRASH могут выполнять только пользователи или роли с привилегией ADMIN_PRIV. |


## Примеры {#examples}

```sql
-- Clean up the junk data of all be nodes.
ADMIN CLEAN TRASH;
```

```sql
-- Clean up garbage data for '192.168.0.1:9050' and '192.168.0.2:9050'.
ADMIN CLEAN TRASH ON ("192.168.0.1:9050", "192.168.0.2:9050");
```
