## Описание {#description}

Эта инструкция используется для диагностики указанного tablet. Результат содержит сведения о tablet и возможных проблемах.


## Синтаксис {#syntax}

```sql
SHOW TABLET DIAGNOSIS <tablet_id>
```

## Обязательные параметры {#required-parameters}

**1. `<tablet_id>`**

Идентификатор tablet, для которого выполняется диагностика.

## Возвращаемое значение {#return-value}

| Столбец                          | Тип данных | Примечание                                                                          |
|----------------------------------|----------|-------------------------------------------------------------------------------------|
| TabletExist                      | String   | Указывает, существует ли tablet.                                                     |
| TabletId                         | String   | Идентификатор tablet.                                                               |
| Database                         | String   | База данных, к которой относится tablet, и её идентификатор.                          |
| Table                            | String   | Таблица, к которой относится tablet, и её идентификатор.                              |
| Partition                        | String   | Раздел, к которому относится tablet, и его идентификатор.                             |
| MaterializedIndex                | String   | Материализованный индекс, к которому относится tablet, и его идентификатор.           |
| Replicas(ReplicaId -> BackendId) | String   | Реплики tablet и соответствующие им узлы BE.                                         |
| ReplicasNum                      | String   | Указывает, корректно ли количество реплик.                                           |
| ReplicaBackendStatus             | String   | Указывает, исправно ли работает узел BE, на котором размещена реплика.                |
| ReplicaVersionStatus             | String   | Указывает, корректен ли номер версии реплики.                                         |
| ReplicaStatus                    | String   | Указывает, находится ли реплика в нормальном состоянии.                               |
| ReplicaCompactionStatus          | String   | Указывает, в норме ли состояние компактации реплики.                                  |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать как минимум следующими правами:

| Право      | Объект      | Примечания                                                                                                                       |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------|
| Admin_priv | База данных | Требуется для выполнения административных операций с базой данных, включая управление таблицами, разделами и выполнение команд системного уровня. |
