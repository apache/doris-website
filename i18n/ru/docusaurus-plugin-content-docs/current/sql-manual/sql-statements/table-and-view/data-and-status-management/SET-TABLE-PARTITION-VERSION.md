## Описание {#description}

Этот оператор используется в режиме совмещённых вычислений и хранения для ручного изменения видимой версии указанной партиции. В некоторых особых случаях версия партиции в метаданных может не совпадать с версией фактической реплики.

Эта команда позволяет вручную изменить версию партиции в метаданных. Как правило, она используется только для аварийного восстановления после сбоев. Применяйте её с осторожностью.

## Синтаксис {#syntax}

```sql
ADMIN SET TABLE <table_name> PARTITION VERSION PROPERTIES ("<partition_id>" = "visible_version>");
```

## Обязательные параметры {#required-parameters}

<table_name>

> Имя таблицы, для которой задаётся версия партиции.

<partition_id>

> Укажите идентификатор партиции.

<visible_version>

> Укажите версию.

## Примеры {#examples}

1. В метаданных FE установите для партиции с partition_id 10075 версию 100.

  ```sql
  ADMIN SET TABLE __internal_schema.audit_log PARTITION VERSION PROPERTIES("partition_id" = "10075", "visible_version" = "100");
  ```
## Примечания по использованию {#usage-note}

1. Перед установкой версии партиции необходимо проверить версию фактической реплики на машине BE. Как правило, эта команда используется только для аварийного восстановления после сбоев. Применяйте её с осторожностью.
2. Эта команда не поддерживается в режиме разделения хранения и вычислений. В этом режиме её выполнение не даст результата.
