## Описание {#description}

Оператор `SET TABLE STATUS` используется для ручной установки состояния таблицы OLAP. Этот оператор предоставляет следующие возможности:

- Поддерживает установку состояния только для таблиц OLAP.
- Позволяет изменить состояние таблицы на указанное целевое состояние.
- Используется для устранения блокировки задач, вызванной состоянием таблицы.

**Поддерживаемые состояния**:

| Состояние         | Описание                             |
|-------------------|--------------------------------------|
| NORMAL            | Указывает, что таблица находится в нормальном состоянии. |
| ROLLUP            | Указывает, что над таблицей выполняется операция ROLLUP. |
| SCHEMA_CHANGE     | Указывает, что выполняется изменение схемы таблицы. |
| BACKUP            | Указывает, что выполняется резервное копирование таблицы. |
| RESTORE           | Указывает, что выполняется восстановление таблицы. |
| WAITING_STABLE    | Указывает, что таблица ожидает перехода в стабильное состояние. |

## Синтаксис {#syntax}

```sql
ADMIN SET TABLE <table_name> STATUS PROPERTIES ("<key>" = "<value>" [, ...]);
```

Где:

```sql
<key>
  : "state"

<value>
  : "NORMAL"
  | "ROLLUP"
  | "SCHEMA_CHANGE"
  | "BACKUP"
  | "RESTORE"
  | "WAITING_STABLE"
```

## Обязательные параметры {#required-parameters}

**1. `<table_name>`**

> Указывает имя таблицы, для которой необходимо установить состояние.
>
> Имя таблицы должно быть уникальным в пределах её базы данных.

**2. `PROPERTIES ("state" = "<value>")`**

> Указывает целевое состояние таблицы.
>
> Свойство "state" обязательно должно быть задано, а его значение должно соответствовать одному из поддерживаемых состояний.

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие права:

| Привилегия      | Объект      | Примечания                                    |
| :-------------- | :---------- | :-------------------------------------------- |
| ADMIN           | Система     | Для выполнения этой команды пользователь должен иметь привилегию ADMIN. |

## Примечания по использованию {#usage-notes}

- Эта команда предназначена для аварийного восстановления после сбоев; используйте её с осторожностью.
- Поддерживаются только таблицы OLAP; таблицы других типов не поддерживаются.
- Если таблица уже находится в целевом состоянии, команда будет проигнорирована.
- Некорректная установка состояния может привести к нарушениям в работе системы; рекомендуется использовать эту команду под руководством технической поддержки.
- После изменения состояния рекомендуется незамедлительно проверить работу системы.

## Примеры {#examples}

- Установить состояние таблицы в NORMAL:

    ```sql
    ADMIN SET TABLE tbl1 STATUS PROPERTIES("state" = "NORMAL");
    ```

- Установить состояние таблицы в SCHEMA_CHANGE:

    ```sql
    ADMIN SET TABLE tbl2 STATUS PROPERTIES("state" = "SCHEMA_CHANGE");
    ```
