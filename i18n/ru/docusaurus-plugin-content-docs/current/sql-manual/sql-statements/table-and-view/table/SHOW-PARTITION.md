## Описание {#description}

Команда SHOW PARTITION используется для отображения подробной информации об указанном разделе. Эта информация включает имя и ID соответствующей базы данных, имя и ID соответствующей таблицы, а также имя раздела.

## Синтаксис {#syntax}

```sql
SHOW PARTITION <partition_id>
```

## Обязательные параметры {#required-parameters}

**<partition_id>**

> ID раздела. ID раздела можно получить, например, с помощью команды SHOW PARTITIONS. Дополнительную информацию см. в разделе «SHOW PARTITIONS».

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум права `ADMIN_PRIV`.

## Примеры {#examples}

Запрос информации о разделе с ID 13004:

```sql
SHOW PARTITION 13004;
```

Результаты:

```text
+--------+-----------+---------------+-------+---------+
| DbName | TableName | PartitionName | DbId  | TableId |
+--------+-----------+---------------+-------+---------+
| ods    | sales     | sales         | 13003 | 13005   |
+--------+-----------+---------------+-------+---------+
```
