## Описание {#description}

Этот оператор используется для отображения сведений о таблице или представлении.

## Синтаксис {#syntax}

```sql
SHOW TABLE STATUS [ FROM [ <catalog_name>.]<db_name> ] [ LIKE <like_condition> ]
```
## Необязательные параметры {#optional-parameters}

**1. ` FROM [ <catalog_name>.]<db_name>`**
> В предложении FROM можно указать имя Catalog и имя базы данных, к которым выполняется запрос.

**2. `LIKE <like_condition>`**
> Предложение LIKE позволяет выполнять запросы с поиском по шаблону имени таблицы.

## Возвращаемое значение {#return-value}

| Столбец             | Тип данных | Описание |
|:--------------------|:-----------|:---------|
| Name                | String     | Имя таблицы |
| Engine              | String     | Движок хранения таблицы |
| Version             | String     | Версия |
| Row_format          | String     | Формат строки. Для движка MyISAM возможны значения Dynamic, Fixed или Compressed. Строки Dynamic имеют переменную длину, например при наличии полей типов Varchar или Blob. Строки Fixed имеют фиксированную длину, например при наличии полей типов Char и Integer. |
| Rows                | String     | Количество строк в таблице. Для нетранзакционных таблиц это значение точное, а для транзакционных движков оно обычно является оценочным. |
| Avg_row_length      | Integer    | Среднее количество байтов на строку |
| Data_length         | Integer    | Объём данных во всей таблице (в байтах) |
| Max_data_length     | Integer    | Максимальный объём данных, который может вместить таблица |
| Index_length        | Integer    | Объём дискового пространства, занимаемого индексом |
| Data_free           | Integer    | Для движка MyISAM указывает объём выделенного, но неиспользуемого пространства, включая пространство удалённых строк. |
| Auto_increment      | Integer    | Следующее значение Auto_increment |
| Create_time         | Datetime   | Время создания таблицы |
| Update_time         | Datetime   | Время последнего обновления таблицы |
| Check_time          | Datetime   | Время последней проверки таблицы с помощью check table или утилиты myisamchk |
| Collation           | String     | Кодировка таблицы по умолчанию; в настоящее время поддерживается только utf-8 |
| Checksum            | String     | Контрольная сумма, вычисленная для всего содержимого таблицы, если её вычисление включено |
| Create_options      | String     | Все остальные параметры, заданные при создании таблицы |
| Comment             | String     | Комментарий к таблице |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права доступа:

| Право доступа | Объект | Описание |
|:--------------|:-----------|:------------------------|
| ADMIN_PRIV | Таблица, представление | В настоящее время для выполнения этой операции поддерживаются только права **ADMIN** |

## Примечания по использованию {#usage-notes}

- Этот оператор в основном используется для совместимости с синтаксисом MySQL. В настоящее время отображается лишь небольшая часть сведений, например Comment.
