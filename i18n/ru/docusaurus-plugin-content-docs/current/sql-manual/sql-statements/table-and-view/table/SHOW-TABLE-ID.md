## Описание {#description}

Эта инструкция позволяет найти имя базы данных и имя таблицы по идентификатору таблицы.

## Синтаксис {#syntax}

```sql
SHOW TABLE <table_id>
```

## Обязательные параметры {#required-parameters}

**1. `<table_id>`**
> Идентификатор `<table_id>` таблицы, для которой нужно найти имя базы данных и имя таблицы.

## Возвращаемое значение {#return-value}

| Имя столбца (столбец) | Тип (тип данных) | Примечания (примечания) |
|:--------------------|:-------------|:----------|
| DbName | String | Имя базы данных |
| TableName | String | Имя таблицы |
| DbId | String | Идентификатор базы данных |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать как минимум следующими правами:

| Привилегия (привилегия) | Объект (объект) | Примечания (примечания) |
|:--------------|:-----------|:------------------------|
| ADMIN_PRIV | Таблица (таблица) | В настоящее время для выполнения этой операции поддерживаются только права **ADMIN** |

## Примеры {#examples}

- Поиск имени базы данных и имени таблицы по идентификатору таблицы

   ```sql
   SHOW TABLE 2261121
   ```

   ```text
   +--------+------------+---------+
   | DbName | TableName  | DbId    |
   +--------+------------+---------+
   | demo   | test_table | 2261034 |
   +--------+------------+---------+
   ```
