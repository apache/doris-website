## Описание {#description}

Эта инструкция позволяет просмотреть информацию о столбцах таблицы.

## Синтаксис {#syntax}

```sql
SHOW [ FULL ] COLUMNS FROM <tbl>;
```

## Обязательные параметры {#required-parameters}
**1. `<tbl>`**

Необходимо указать имя таблицы, информацию о столбцах которой требуется просмотреть.

## Необязательные параметры {#optional-parameters}
**1. `FULL`**

Если указано ключевое слово `FULL`, возвращается подробная информация о столбцах, включая тип агрегации, права доступа, комментарии и т. д.

## Возвращаемое значение {#return-value}
| Столбец    | Тип данных | Примечание                  |
|------------|----------|-------------------------|
| Field      | varchar  | Имя столбца                 |
| Type       | varchar  | Тип данных столбца          |
| Collation  | varchar  | Правило сортировки столбца   |
| Null       | varchar  | Допускается ли NULL         |
| Key        | varchar  | Первичный ключ таблицы      |
| Default    | varchar  | Значение по умолчанию       |
| Extra      | varchar  | Дополнительная информация   |
| Privileges | varchar  | Права доступа к столбцу     |
| Comment    | varchar  | Комментарий к столбцу       |

## Требования к правам доступа {#access-control-requirements}
Для просмотра информации требуется право `SHOW` на таблицу.

## Примеры {#examples}

1. Просмотр подробной информации о столбцах указанной таблицы

```sql
SHOW FULL COLUMNS FROM t_agg;
```
```text
+-------+-----------------+-----------+------+------+---------+---------+------------+---------+
| Field | Type            | Collation | Null | Key  | Default | Extra   | Privileges | Comment |
+-------+-----------------+-----------+------+------+---------+---------+------------+---------+
| k1    | tinyint         |           | YES  | YES  | NULL    |         |            |         |
| k2    | decimalv3(10,2) |           | YES  | YES  | 10.5    |         |            |         |
| v1    | char(10)        |           | YES  | NO   | NULL    | REPLACE |            |         |
| v2    | int             |           | YES  | NO   | NULL    | SUM     |            |         |
+-------+-----------------+-----------+------+------+---------+---------+------------+---------+
```

2. Просмотр основной информации о столбцах указанной таблицы

```sql
SHOW COLUMNS FROM t_agg;
```
```text
+-------+-----------------+------+------+---------+---------+
| Field | Type            | Null | Key  | Default | Extra   |
+-------+-----------------+------+------+---------+---------+
| k1    | tinyint         | YES  | YES  | NULL    |         |
| k2    | decimalv3(10,2) | YES  | YES  | 10.5    |         |
| v1    | char(10)        | YES  | NO   | NULL    | REPLACE |
| v2    | int             | YES  | NO   | NULL    | SUM     |
+-------+-----------------+------+------+---------+---------+
```
