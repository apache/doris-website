## Описание {#description}

Позволяет просматривать ход преобразования OLAP-таблиц без поддержки облегчённого изменения схемы в таблицы с поддержкой облегчённого изменения схемы.

## Синтаксис {#syntax}

```sql
SHOW CONVERT_LIGHT_SCHEMA_CHANGE_PROCESS [ FROM <db_name> ]
```

## Необязательные параметры {#optional-parameters}

**1. `<db_name>`**
> Имя базы данных, к которой выполняется запрос, можно указать в предложении FROM.

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право доступа | Объект | Примечания |
|:--------------|:-----------|:------------------------|
| ADMIN_PRIV | База данных | В настоящее время для выполнения этой операции поддерживаются только права **ADMIN** |

## Примечания по использованию {#usage-notes}

- Для выполнения этой команды необходимо включить параметр конфигурации `enable_convert_light_weight_schema_change`.

## Примеры {#examples}

- Просмотр хода преобразования в базе данных test

  ```sql
  SHOW CONVERT_LIGHT_SCHEMA_CHANGE_PROCESS FROM test;
  ```

- Просмотр глобального состояния преобразования

  ```sql
  SHOW CONVERT_LIGHT_SCHEMA_CHANGE_PROCESS;
  ```
