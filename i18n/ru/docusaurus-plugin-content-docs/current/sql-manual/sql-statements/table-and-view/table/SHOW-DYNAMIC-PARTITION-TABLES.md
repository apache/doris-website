## Описание {#descriptions}

Эта инструкция используется для отображения состояния всех таблиц с динамическим партиционированием в текущей базе данных.

## Синтаксис {#syntax}

```sql
SHOW DYNAMIC PARTITION TABLES [FROM <db_name>];
```

## Обязательные параметры {#required-parameters}
**1. `<db_name>`**

Укажите имя `DB`, для которой требуется отобразить состояние таблиц с динамическим партиционированием. Если параметр не указан, по умолчанию отображается состояние всех таблиц с динамическим партиционированием в текущей `DB`.
## Возвращаемое значение {#return-value}

| Столбец | Тип данных | Примечание |
|------------------------|----------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TableName | varchar | Имя таблицы в текущей или указанной DB. |
| Enable | varchar | Включено ли для таблицы свойство динамического партиционирования. |
| TimeUnit | varchar | Гранулярность партиций таблицы с динамическим партиционированием. Возможные значения: `HOUR`, `DAY`, `WEEK`, `MONTH`, `YEAR`. |
| Start | varchar | Начальное смещение динамической партиции, задаваемое отрицательным числом. Значение по умолчанию: -2147483648. Оно означает, что исторические партиции не удаляются. В зависимости от атрибута time_unit удаляются партиции, диапазон которых находится до этого смещения относительно текущего дня (недели/месяца). |
| End | varchar | Конечное смещение динамической партиции, задаваемое положительным числом. В зависимости от атрибута time_unit заранее создаются партиции в соответствующем диапазоне относительно текущего дня (недели/месяца). |
| Prefix | varchar | Префикс имени динамически создаваемой партиции. |
| Buckets | varchar | Количество бакетов для динамически создаваемой партиции. |
| ReplicationNum | varchar | Количество реплик для динамически создаваемой партиции. Если не указано, по умолчанию используется количество реплик, заданное при создании таблицы. |
| ReplicaAllocation | varchar | Стратегия распределения реплик для динамически создаваемой партиции. Если не указана, по умолчанию используется стратегия распределения реплик, заданная при создании таблицы. |
| StartOf | varchar | Начальная точка каждого интервала выбранной гранулярности при динамическом партиционировании. Если time_unit имеет значение WEEK, это поле определяет начало каждой недели и принимает значения от MONDAY до SUNDAY. Если time_unit имеет значение MONTH, оно определяет начальную дату каждого месяца и принимает значения от 1-го до 28-го числа. Если time_unit имеет значение MONTH, значение этого поля по умолчанию равно NULL. |
| LastUpdateTime | datetime | Время последнего обновления динамической партиции. Значение по умолчанию: NULL. |
| LastSchedulerTime | datetime | Время последнего запуска планировщика динамического партиционирования. |
| State | varchar | Состояние динамического партиционирования. |
| LastCreatePartitionMsg | varchar | Сообщение об ошибке при последнем выполнении запланированного добавления динамических партиций. |
| LastDropPartitionMsg | varchar | Сообщение об ошибке при последнем выполнении запланированного удаления динамических партиций. |
| ReservedHistoryPeriods | varchar | Диапазон исторических партиций, сохраняемых при динамическом партиционировании. Указывает, какие исторические партиции должны сохраняться в таблице с динамическим партиционированием вместо автоматического удаления. |

## Требования к правам доступа {#access-control-requirements}
1. Если параметр db_name не указан, отображается состояние всех таблиц с динамическим партиционированием в текущей DB. При этом по умолчанию предполагается, что пользователь имеет привилегию `SHOW_PRIV` для текущей DB.
2. Если параметр db_name указан, отображается состояние всех таблиц с динамическим партиционированием в указанной DB. Пользователь должен иметь привилегию `SHOW_PRIV` для этой DB.
