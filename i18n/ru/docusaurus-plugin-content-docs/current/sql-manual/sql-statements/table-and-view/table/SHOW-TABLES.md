## Описание {#description}

Эта инструкция используется для отображения всех таблиц и представлений в текущей базе данных.

## Синтаксис {#syntax}

```sql
SHOW [ FULL ] TABLES [ FROM [ <catalog_name>.]<db_name> ][ LIKE <like_condition> ]
```

## Необязательные параметры {#optional-parameters}

**1. `FULL`**
> Если добавить этот параметр в инструкцию, результат будет содержать три дополнительных столбца: Table_type (тип таблицы), Storage_format (формат хранения) и Inverted_index_storage_format (формат хранения инвертированного индекса).

**2. `FROM [ <catalog_name>.]<db_name>`**
> В предложении FROM можно указать имя Catalog и имя базы данных, к которой выполняется запрос.

**2. `LIKE <like_condition>`**
> В предложении LIKE можно выполнять запросы по шаблону имени таблицы.

## Возвращаемое значение {#return-value}

| Имя столбца (Column) | Тип (DataType) | Примечания (Notes) |
|:--------------------|:-------------|:----------------------------|
| Tables_in_<db_name> | String | Все таблицы и представления в базе данных, указанной в `<db_name>`. |
| Table_type | String | Тип таблицы или представления. |
| Storage_format | String | Формат хранения таблицы или представления. |
| Inverted_index_storage_format | String | Формат хранения инвертированного индекса таблицы или представления. |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Привилегия (Privilege) | Объект (Object) | Примечания (Notes) |
|:--------------|:-----------|:------------------|
| SELECT_PRIV | Таблица (Table), представление (View) | Отображаются только те таблицы и представления, для которых есть права на выполнение запросов. |

## Примечания по использованию {#usage-notes}

- Если в инструкции не указано предложение FROM, перед её выполнением необходимо выбрать соответствующую базу данных.

## Примеры {#examples}

- Просмотр всех таблиц в базе данных

     ```sql
     SHOW TABLES;
     ```

     ```text
     +---------------------------------+
     | Tables_in_demo                  |
     +---------------------------------+
     | ads_client_biz_aggr_di_20220419 |
     | cmy1                            |
     | cmy2                            |
     | intern_theme                    |
     | left_table                      |
     +---------------------------------+
     ```

- Запрос по шаблону имени таблицы

     ```sql
     SHOW TABLES LIKE '%cm%'
     ```

     ```text
     +----------------+
     | Tables_in_demo |
     +----------------+
     | cmy1           |
     | cmy2           |
     +----------------+
     ```

- Использование FULL для запроса таблиц и представлений в базе данных

     ```sql
     SHOW FULL TABLES
     ```

     ```text
     +----------------+------------+----------------+-------------------------------+
     | Tables_in_demo | Table_type | Storage_format | Inverted_index_storage_format |
     +----------------+------------+----------------+-------------------------------+
     | test_table     | BASE TABLE | V2             | V1                            |
     | test_view      | VIEW       | NONE           | NONE                          |
     +----------------+------------+----------------+-------------------------------+
     ```
