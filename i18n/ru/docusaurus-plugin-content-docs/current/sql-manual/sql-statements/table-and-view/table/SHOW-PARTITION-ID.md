## Описание {#description}

Эта инструкция позволяет по идентификатору партиции найти соответствующие имена базы данных, таблицы и партиции.

## Синтаксис {#syntax}

```sql
SHOW PARTITION <partition_id>
```

## Обязательные параметры {#required-parameters}

**1. `<partition_id>`**

> идентификатор партиции

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту инструкцию SQL, должен иметь как минимум следующие права:

| Привилегия                  | Объект | Примечания |
|---------------------|----|----|
| ADMIN_PRIV |    |    |

## Примеры {#examples}

1. Поиск соответствующих имён базы данных, таблицы и партиции по идентификатору партиции.

    ```sql
    SHOW PARTITION 10002;
    ```
