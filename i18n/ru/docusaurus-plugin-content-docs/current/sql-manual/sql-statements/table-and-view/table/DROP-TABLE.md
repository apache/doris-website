## Описание {#description}

Этот оператор используется для удаления таблицы.
## Синтаксис {#syntax}

```sql
DROP [TEMPORARY] TABLE [IF EXISTS] [<db_name>.]<table_name> [FORCE];
```

## Обязательные параметры {#required-parameters}
**1.`<table_name>`**
> Указывает идентификатор (имя) таблицы, который должен быть уникальным в пределах базы данных, в которой она находится.
>
> Идентификаторы должны начинаться с буквы (или любого символа какого-либо языка, если включена поддержка имён Unicode) и не могут содержать пробелы или специальные символы, если только вся строка идентификатора не заключена в обратные кавычки (например, `My Object`).
>
> В качестве идентификаторов нельзя использовать зарезервированные ключевые слова.
>
> Подробности см. в разделах «Требования к идентификаторам» и «Зарезервированные ключевые слова».

## Необязательные параметры {#optional-parameters}

**1. `TEMPORARY` **
> Если указан, оператор удаляет только таблицы TEMPORARY.

**2. `IF EXISTS`**
> Если указан, при отсутствии таблицы ошибка не возникает.

**3.`<db_name>`**
> Указывает идентификатор (имя) базы данных.
>
> Идентификаторы должны начинаться с буквы (или любого символа какого-либо языка, если включена поддержка имён Unicode) и не могут содержать пробелы или специальные символы, если только вся строка идентификатора не заключена в обратные кавычки (например, `My Database`).
>
> В качестве идентификаторов нельзя использовать зарезервированные ключевые слова.
>
> Подробности см. в разделах «Требования к идентификаторам» и «Зарезервированные ключевые слова».

**4.`FORCE`**
> Если указан, система не проверяет наличие незавершённых транзакций в таблице. Таблица удаляется сразу без возможности восстановления. Как правило, выполнять эту операцию не рекомендуется.

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:


| Привилегия      | Объект    | Примечания                 |
|:----------------|:----------|:---------------------------|
| Drop_priv       | Таблица   | DROP TABLE относится к операции DROP для таблицы |

## Примечания по использованию {#usage-notes}

- После выполнения `DROP TABLE` удалённую таблицу в течение некоторого времени можно восстановить с помощью оператора RECOVER. Подробности см. в описании оператора [RECOVER](../../recycle/RECOVER).
- При выполнении `DROP TABLE FORCE` система не проверяет наличие незавершённых транзакций для таблицы. Таблица удаляется сразу без возможности восстановления. Как правило, выполнять эту операцию не рекомендуется.

## Примеры {#examples}

1. Удаление таблицы

    ```sql
    DROP TABLE my_table;
    ```

2. Удаление таблицы из указанной базы данных, если она существует.

    ```sql
    DROP TABLE IF EXISTS example_db.my_table;
    ```

3. Принудительное удаление таблицы из указанной базы данных, если она существует.

    ```sql
    DROP TABLE IF EXISTS example_db.my_table FORCE;
    ```
