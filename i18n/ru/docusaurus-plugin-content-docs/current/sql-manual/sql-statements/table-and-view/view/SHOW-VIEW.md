## Описание {#description}

Эта инструкция используется для отображения всех представлений, созданных на основе указанной таблицы

## Синтаксис {#syntax}

```sql
  SHOW VIEW { FROM | IN } table [ FROM db ]
```

## Пример {#example}

1. Показать все представления, созданные на основе таблицы testTbl

    ```sql
    SHOW VIEW FROM testTbl;
    ```

## Ключевые слова {#keywords}

    SHOW, VIEW
