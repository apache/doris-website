## Описание {#description}

Выводит инструкцию CREATE VIEW, использованную для создания указанного представления.

## Синтаксис {#syntax}

```sql
SHOW CREATE VIEW <name>
```

## Обязательные параметры {#required-parameters}

`**<name>**`  Имя представления, сведения о котором нужно просмотреть.

## Описание результата {#result-description}

- View: Имя запрашиваемого представления.
- Create View: Инструкция SQL, сохранённая в базе данных.
- character_set_client: Значение системной переменной character_set_client в сеансе на момент создания представления.
- collation_connection: Значение системной переменной collation_connection в сеансе на момент создания представления.

## Требования к управлению доступом {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны обладать как минимум следующими привилегиями:

| Привилегия       | Объект  | Примечания |
| ---------------- | ------- | ---------- |
| SHOW_VIEW_PRIV   | Таблица |            |

Информацию о представлениях также можно получить с помощью запроса к таблице INFORMATION_SCHEMA.VIEWS.

## Примеры {#examples}

```sql
CREATE VIEW vtest AS SELECT 1, 'test';
SHOW CREATE VIEW vtest;
```

Результат запроса:

```sql
+-------+------------------------------------------+----------------------+----------------------+
| View  | Create View                              | character_set_client | collation_connection |
+-------+------------------------------------------+----------------------+----------------------+
| vtest | CREATE VIEW `vtest` AS SELECT 1, 'test'; | utf8mb4              | utf8mb4_0900_bin     |
+-------+------------------------------------------+----------------------+----------------------+
```
