## Описание {#description}

Изменяет свойства FRONTEND (далее FE). В настоящее время эта команда позволяет изменять только HOSTNAME FE. Если требуется изменить имя хоста, на котором запущен определённый экземпляр FE в кластере, с помощью этой команды можно изменить имя хоста, зарегистрированное этим FE в кластере, чтобы он продолжал работать корректно.

Эта команда используется только для перевода кластера DORIS на развёртывание с FQDN. Подробности развёртывания с FQDN приведены в главе «FQDN».

## Синтаксис {#syntax}

```sql
ALTER SYSTEM MODIFY FRONTEND "<frontend_hostname_port>" HOSTNAME "<frontend_new_hostname>"
```
## Обязательные параметры {#required-parameters}

**<frontend_hostname_port>**

> Имя хоста и порт edit log, зарегистрированные FE, имя хоста которого требуется изменить. Чтобы просмотреть информацию обо всех FE в кластере, используйте команду SHOW FRONTENDS. Подробное описание её использования приведено в главе «SHOW FRONTENDS».

**<frontend_new_hostname>**

> Новое имя хоста FE.

## Требования к управлению доступом {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум права NODE_PRIV.

## Примеры {#examples}

Изменение имени хоста экземпляра FE в кластере с 10.10.10.1 на 172.22.0.1:

```sql
ALTER SYSTEM
MODIFY FRONTEND "10.10.10.1:9010"
HOSTNAME "172.22.0.1"
```
