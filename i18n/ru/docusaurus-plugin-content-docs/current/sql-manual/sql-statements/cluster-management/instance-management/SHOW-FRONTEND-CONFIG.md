## Описание {#description}

Эта инструкция используется для просмотра конфигурации текущего кластера (в настоящее время поддерживаются только параметры конфигурации FE)

Начиная с версии 4.1.5 непустые значения конфиденциальных параметров конфигурации отображаются как `********` в столбце `Value`, включая первоначальный пароль root и пароли для TLS, HTTPS и MySQL SSL. Пустые значения незаданных параметров остаются пустыми. Маскирование не изменяет фактические значения параметров конфигурации.

## Синтаксис {#syntax}

```sql
SHOW FRONTEND CONFIG [LIKE "<pattern>"];
```

## Необязательные параметры {#optional-parameters}
**`<pattern>`**
> Строка, которая может содержать обычные символы и подстановочные знаки.


## Возвращаемые значения {#return-values}
| Имя столбца | Описание                                            |
|-------------|-----------------------------------------------------|
| Value       | Значение параметра конфигурации                      |
| Type        | Тип параметра конфигурации                           |
| IsMutable   | Можно ли задать значение с помощью команды `ADMIN SET CONFIG` |
| MasterOnly  | Применяется ли параметр только к Master FE            |
| Comment     | Описание параметра конфигурации                      |


## Пример {#example}

1. Просмотр конфигурации текущего узла FE

   ```sql
   SHOW FRONTEND CONFIG;
   ```

2. Использование предиката like для поиска в конфигурации текущего узла Fe

   ```sql
    SHOW FRONTEND CONFIG LIKE '%check_java_version%';
    ```
    ```text
    +--------------------+-------+---------+-----------+------------+---------+
    | Key                | Value | Type    | IsMutable | MasterOnly | Comment |
    +--------------------+-------+---------+-----------+------------+---------+
    | check_java_version | true  | boolean | false     | false      |         |
    +--------------------+-------+---------+-----------+------------+---------+
    ```
