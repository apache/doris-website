## Описание {#description}

Этот оператор используется для изменения атрибутов узлов BE. Изменение атрибутов узлов BE влияет на выполнение запросов, запись и распределение данных на текущем узле. Можно изменить следующие атрибуты:

| Свойство        | Влияние                                                                                                                                                                                                                                                                                                                                             |
|-----------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `tag.location`  | Тег ресурсов узла BE; значение по умолчанию: `default`. Изменение влияет на балансировку данных между узлами BE в одной группе тегов и на выбор узлов BE для распределения данных при создании таблицы. Подробнее см. в разделе [Группа ресурсов](../../../../admin-manual/workload-management/resource-group.md). |
| `disable_query` | Определяет, отключено ли выполнение запросов. Значение по умолчанию: `false`. После установки значения `true` новые запросы не будут направляться на этот узел BE.                                                                                                                                                                                         |
| `disable_load`  | Определяет, отключена ли загрузка данных. Значение по умолчанию: `false`. После установки значения `true` новые запросы на импорт не будут направляться на этот узел BE.                                                                                                                                                                                           |

:::tip
Эта команда не поддерживается в режиме разделения хранения и вычислений.
:::

## Синтаксис {#syntax}

```sql
ALTER SYSTEM MODIFY BACKEND <be_identifier> [, <be_identifier> ... ]
SET (
     "<key>" = "<value>"
)
```

Где:

```sql
be_identifier
  : "<be_host>:<be_heartbeat_port>"
  | "<backend_id>"
```

## Обязательные параметры {#required-parameters}

**1. <be_host>**

> Имя хоста или IP-адрес узла BE.

**2. <heartbeat_port>**

> Порт проверки доступности узла BE, по умолчанию 9050.

**3. <backend_id>**

> Идентификатор узла BE.

:::tip
`<be_host>`, `<be_heartbeat_port>` и `<backend_id>` можно получить с помощью оператора [SHOW BACKENDS](./SHOW-BACKENDS.md).
:::

## Примечания по использованию {#usage-notes}

Эта операция затрагивает весь узел BE и имеет широкую область воздействия. При неосторожном выполнении она может нарушить нормальное выполнение запросов, загрузку данных и даже создание таблиц во всём кластере. Выполняйте её с осторожностью.

## Примеры {#examples}

1. Изменение тега ресурсов узла BE

```sql
ALTER SYSTEM MODIFY BACKEND "127.0.0.1:9050" SET ("tag.location" = "group_a");
```

2. Изменение атрибута `disable_query` узла BE
   
```sql
ALTER SYSTEM MODIFY BACKEND "10002" SET ("disable_query" = "true");
```

3. Изменение атрибута `disable_load` узла BE
   
```sql
ALTER SYSTEM MODIFY BACKEND "127.0.0.1:9050" SET ("disable_load" = "true");
```
