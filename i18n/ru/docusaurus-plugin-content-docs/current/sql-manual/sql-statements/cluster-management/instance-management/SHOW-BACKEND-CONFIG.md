## Описание {#description}

Отображает параметры конфигурации BACKEND (то есть BE) и их текущие значения.

## Синтаксис {#syntax}

```sql
[ ADMIN ] SHOW BACKEND CONFIG [ LIKE <config_key_pattern> ] [ FROM <backend_id> ]
```

## Необязательные параметры {#optional-parameters}

**<config_key_pattern>**

> Задаёт шаблон с подстановочными знаками для поиска параметров конфигурации BE. Правила сопоставления такие же, как для выражений LIKE. Правила составления шаблонов см. в разделе «Выражения сопоставления».

**<backend_id>**

> ID BE. Используется для просмотра конфигурации BE с указанным ID. ID BE можно получить с помощью команды SHOW BACKENDS. Подробнее см. описание команды SHOW BACKENDS.

## Возвращаемое значение {#return-value}

- BackendId: ID BE
- Host: Адрес хоста BE
- Key: Имя параметра конфигурации
- Value: Соответствующее значение параметра конфигурации
- Type: Тип значения параметра конфигурации

## Требования к правам доступа {#access-control-requirements}

Для выполнения этой команды SQL пользователю необходимы как минимум права ADMIN_PRIV.

## Примеры {#examples}

### Запрос всех параметров конфигурации {#query-all-configuration-items}

```sql
SHOW BACKEND CONFIG
```
Результат:

```sql
+-----------+--------------+--------------------------------+-------+--------------------------+-----------+
| BackendId | Host         | Key                            | Value | Type                     | IsMutable |
+-----------+--------------+--------------------------------+-------+--------------------------+-----------+
| 12793     | 172.16.123.1 | LZ4_HC_compression_level       | 9     | int64_t                  | true      |
| 12793     | 172.16.123.1 | agent_task_trace_threshold_sec | 2     | int32_t                  | true      |
...
| 12794     | 172.16.123.2 | zone_map_row_num_threshold     | 20    | int32_t                  | true      |
+-----------+--------------+--------------------------------+-------+--------------------------+-----------+
```

```sql

```

Результат:

```sql
+-----------+--------------+--------------------------------+-------+--------------------------+-----------+
| BackendId | Host         | Key                            | Value | Type                     | IsMutable |
+-----------+--------------+--------------------------------+-------+--------------------------+-----------+

...
| 12793     | 172.16.123.1 | zone_map_row_num_threshold     | 20    | int32_t                  | true      |
+-----------+--------------+--------------------------------+-------+--------------------------+-----------+
```

### Запрос параметров конфигурации, соответствующих указанному шаблону {#query-configuration-items-matching-a-specified-pattern}

```sql
| 12794     | 172.16.123.2 | LZ4_HC_compression_level | 9     | int64_t | true      |
+-----------+--------------+--------------------------+-------+---------+-----------+
```
