## Описание {#description}

Эта инструкция позволяет просмотреть сведения о дисках, на которых расположены важные каталоги узла FE, включая каталоги метаданных, журналов, журналов аудита и временные каталоги.

## Синтаксис {#syntax}

```sql
SHOW FRONTENDS DISKS;
```

## Возвращаемое значение {#return-value}

| Столбец                 | Описание                                              |
|--------------------|-------------------------------------------------|
| Name               | Имя узла FE в bdbje                            |
| Host               | IP-адрес узла FE.                                     |
| DirType        | Типы отображаемых каталогов включают следующие четыре категории: meta, log, audit-log, temp и deploy. |
| Dir           | Пути к каталогам отображаемых типов.                                     |
| FileSystem          | Файловая система Linux, в которой расположены каталоги отображаемых типов.                      |
| Capacity            | Ёмкость файловой системы.                                         |
| Used | Используемый объём файловой системы.                                        |
| Available               | Оставшееся свободное место в файловой системе.                                       |
| UseRate           | Процент использования ёмкости файловой системы.                                      |
| MountOn          | Каталог монтирования файловой системы.                                        |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту инструкцию SQL, должен иметь как минимум следующие права:

| Право               | Объект | Примечания |
|-------------------------|----|----|
| ADMIN_PRIV или NODE_PRIV |    |    |

## Примечания по использованию {#usage-notes}

Для дополнительной фильтрации результатов запроса можно использовать табличную функцию [frontends_disks()](../../../sql-functions/table-valued-functions/frontends_disks.md). SHOW BACKENDS эквивалентна следующей инструкции:

```sql
SELECT * FROM FRONTENDS_DISKS();
```
