## Описание {#description}

Эта инструкция добавляет узел FRONTEND с ролью FOLLOWER (доступна только администраторам!)

## Синтаксис {#syntax}

```sql
ALTER SYSTEM ADD FOLLOWER "<follower_host>:<edit_log_port>"
```

## Обязательные параметры {#required-parameters}

**1. `<follower_host>`**

> Имя хоста или IP-адрес узла FE

**2. `<edit_log_port>`**

> Порт связи bdbje узла FE; значение по умолчанию: 9010

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать как минимум следующими правами:

| Привилегия | Объект | Примечания |
|-----------|----|-------|
| NODE_PRIV |    |       |

## Примечания по использованию {#usage-notes}

1. Перед добавлением нового узла FOLLOWER убедитесь, что он правильно настроен.
2. Перед добавлением узла FOLLOWER убедитесь, что после добавления число узлов FOLLOWER в кластере будет нечётным.
3. После добавления узла FOLLOWER выполните команду [`SHOW FRONTENDS`](./SHOW-FRONTENDS.md), чтобы убедиться, что он успешно добавлен и находится в нормальном состоянии.

## Примеры {#examples}

1. Добавление узла FOLLOWER

   ```sql
   ALTER SYSTEM ADD FOLLOWER "host_ip:9010"
   ```
   Эта команда добавляет узел FOLLOWER в кластер (IP-адрес host_ip, порт 9010)
