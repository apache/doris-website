## Описание {#description}

Этот оператор позволяет просмотреть основные сведения о состоянии узлов FE.

## Синтаксис {#syntax}

```sql
SHOW FRONTENDS
```

## Возвращаемое значение {#return-value}

| Столбец                      | Примечание                                                                                          |
|--------------------|-----------------------------------------------------------------------------------------------|
| Name               | Имя текущего FE в Doris. Обычно это случайная строка с префиксом `fe`. |
| Host               | IP-адрес или имя хоста текущего FE.                                                |
| EditLogPort        | Порт связи bdbje текущего FE.                                               |
| HttpPort           | Порт связи http текущего FE.                                                                             |
| QueryPort          | Порт связи по протоколу MySQL текущего FE.                                                                          |
| RpcPort            | Порт связи thrift RPC текущего FE.                                                                       |
| ArrowFlightSqlPort | Порт связи по протоколу ArrowFlight текущего FE.                                                                    |
| Role               | Роль текущего FE. Возможные значения: FOLLOWER и OBSERVER.                                                           |
| IsMaster           | Указывает, выбран ли текущий FE в качестве Master.                                                                           |
| ClusterId          | ID текущего кластера Doris. Обычно это случайно сгенерированное число.                                                                  |
| Join               | Указывает, успешно ли текущий узел FE присоединился к текущему кластеру Doris.                                                                 |
| Alive              | Указывает, работает ли текущий FE.                                                                                    |
| ReplayedJournalId  | Наибольший ID записи журнала метаданных, воспроизведённой текущим FE.                                                                         |
| LastStartTime      | Метка времени запуска текущего FE.                                                                                  |
| LastHeartbeat      | Метка времени последнего успешного сигнала heartbeat, отправленного текущим FE.                                                                           |
| IsHelper           | Указывает, является ли текущий FE вспомогательным узлом в bdbje.                                                                  |
| ErrMsg             | Сообщение об ошибке при сбое heartbeat текущего FE.                                                                              |
| Version            | Сведения о версии текущего FE.                                                                                   |
| CurrentConnected   | Указывает, установлено ли текущее клиентское соединение с текущим узлом FE.                                                                          |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий этот SQL, должен иметь как минимум следующие права:

| Привилегия  | Объект | Примечания |
|------------|----|----|
| SELECT_PRIV | internal.information_schema | По умолчанию все пользователи имеют права доступа к этой базе данных |

## Примечания по использованию {#usage-notes}

Если нужно дополнительно отфильтровать результаты запроса, можно использовать табличную функцию [frontends()](../../../sql-functions/table-valued-functions/frontends.md). Оператор SHOW FRONTENDS эквивалентен следующему оператору:

```sql
SELECT * FROM FRONTENDS();
```
