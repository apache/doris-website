## Описание {#description}

Позволяет остановить указанное задание прогрева в Doris.

## Синтаксис {#syntax}

```sql
CANCEL WARM UP JOB WHERE id = <id>;
```
## Обязательные параметры {#required-parameters}

> Идентификатор задания прогрева, которое нужно остановить. Его можно узнать с помощью команды `SHOW WARM UP JOB`.

## Управление правами доступа {#permission-control}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум права ADMIN_PRIV.

## Пример {#example}

Запросите список заданий прогрева, которые сейчас выполняются в системе, с помощью `SHOW WARM UP JOB`:

```sql
SHOW WARM UP JOB
```

Результат:

```C++
+----------------+---------------+---------+-------+-------------------------+-------------+----------+------------+--------+
| JobId          | ClusterName   | Status  | Type  | CreateTime              | FinishBatch | AllBatch | FinishTime | ErrMsg |
+----------------+---------------+---------+-------+-------------------------+-------------+----------+------------+--------+
| 90290165739458 | CloudCluster1 | RUNNING | TABLE | 2024-11-11 11:11:42.700 | 1           | 3        | NULL       |        |
+----------------+---------------+---------+-------+-------------------------+-------------+----------+------------+--------+
```

Затем остановите задание с помощью `CANCEL WARM UP`:

```C++
CANCEL WARM UP JOB WHERE id = 90290165739458;
```

Если возвращается следующее сообщение, это означает, что задание прогрева с указанным идентификатором не существует:

```C++
ERROR 1105 (HY000): errCode = 2, detailMessage = job id: 110 does not exist.
```

После успешного выполнения команды можно снова использовать `SHOW WARM UP JOB`, чтобы убедиться, что статус задания изменился с RUNNING на CANCELLED:

```C++
+----------------+---------------+-----------+-------+-------------------------+-------------+----------+-------------------------+-------------+
| JobId          | ClusterName   | Status    | Type  | CreateTime              | FinishBatch | AllBatch | FinishTime              | ErrMsg      |
+----------------+---------------+-----------+-------+-------------------------+-------------+----------+-------------------------+-------------+
| 90290165739458 | CloudCluster1 | CANCELLED | TABLE | 2024-11-11 11:11:42.700 | 1           | 3        | 2024-11-11 11:11:43.700 | user cancel |
+----------------+---------------+-----------+-------+-------------------------+-------------+----------+-------------------------+-------------+
```
