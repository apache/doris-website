## Описание {#description}

Этот оператор используется для изменения существующей политики перемещения данных между горячим и холодным уровнями хранения. Изменять ресурсы могут только пользователи root или admin.

## Синтаксис {#syntax}
```sql
ALTER STORAGE POLICY  '<policy_name>' PROPERTIES ("<key>"="<value>"[, ... ]);
```

## Обязательные параметры {#required-parameters}


1.`<policy_name>`  
> Имя политики хранения. Это уникальный идентификатор политики хранения, которую вы хотите изменить. Необходимо указать имя существующей политики. 

## Необязательные параметры {#optional-parameters}
`PROPERTIES ("<key>"="<value>"[, ... ])` 

1.`retention_days`  
> Срок хранения данных. Определяет, как долго данные остаются в хранилище. По истечении этого срока данные автоматически удаляются. 

2.`redundancy_level`
> Уровень избыточности. Определяет количество реплик данных для обеспечения высокой доступности и отказоустойчивости. Например, значение 2 означает, что у каждого блока данных есть две реплики. 

3.`storage_type`   
> Тип хранилища. Указывает используемый носитель данных, например SSD, HDD или гибридное хранилище. Влияет на производительность и стоимость. 

4.`cooloff_time`    
> Период ожидания перед удалением. Интервал времени между пометкой данных для удаления и их фактическим удалением. Помогает предотвратить потерю данных из-за случайных действий. 

5.`location_policy` 
> Политика географического размещения. Определяет географическое размещение данных, например репликацию между регионами для аварийного восстановления. 

## Примеры {#examples}

1. Изменение cooldown_datetime для перемещения данных между горячим и холодным уровнями хранения:
```sql
ALTER STORAGE POLICY has_test_policy_to_alter PROPERTIES("cooldown_datetime" = "2023-06-08 00:00:00");
```
2. Изменение cooldown_ttl для отсчёта времени до перемещения данных между горячим и холодным уровнями хранения:

```sql
ALTER STORAGE POLICY has_test_policy_to_alter PROPERTIES ("cooldown_ttl" = "10000");
```
```sql
ALTER STORAGE POLICY has_test_policy_to_alter PROPERTIES ("cooldown_ttl" = "1h");
```
```sql
ALTER STORAGE POLICY has_test_policy_to_alter PROPERTIES ("cooldown_ttl" = "3d");
```
