## Описание {#description}

Эта инструкция используется для удаления существующего ресурса. Удалять ресурсы могут только пользователи root или admin.

Начиная с версии 4.1.5, только root может изменять или удалять вновь созданный AI Resource с отметкой о создании пользователем root; другие пользователи с правами `ADMIN` не могут этого делать. На ресурсы, существовавшие до обновления и не имеющие такой отметки, это ограничение задним числом не распространяется. См. [Права доступа к AI Resource](../../../sql-functions/ai-functions/overview.md).

## Синтаксис {#syntax}

```sql
DROP RESOURCE '<resource_name>'
```

## Примечания по использованию {#usage-notes}

Используемые ресурсы ODBC/S3 удалить нельзя.

## Примеры {#examples}

1. Удалить ресурс Spark с именем spark0:
   
     ```sql
     DROP RESOURCE 'spark0';
     ```
