## Описание {#description}

Выводит список вычислительных групп, на использование которых у текущего пользователя есть права.

- **Режим с разделением вычислений и хранения**: возвращает список вычислительных групп, на использование которых у текущего пользователя есть права.
- **Режим с совмещением вычислений и хранения**: поддерживается начиная с версии 4.1.4. В этом режиме группы ресурсов BE (тег `location`) сопоставляются с вычислительными группами. До версии 4.1.4 выполнение этого оператора в данном режиме приводит к ошибке `ERR_NOT_CLOUD_MODE`.

## Синтаксис {#syntax}

```sql
SHOW COMPUTE GROUPS
```

## Возвращаемое значение {#return-value}

Возвращает список вычислительных групп, к которым у текущего пользователя есть права доступа. Набор возвращаемых столбцов зависит от режима.

**Режим с разделением вычислений и хранения:**

- Name - Имя вычислительной группы
- IsCurrent - Использует ли текущий пользователь эту вычислительную группу
- Users - Имена пользователей, которые назначили эту вычислительную группу своей вычислительной группой по умолчанию
- BackendNum - Количество BE в этой вычислительной группе
- SubComputeGroups / Policy / Properties - Сведения о виртуальной вычислительной группе

**Режим с совмещением вычислений и хранения (4.1.4+):**

- Name - Имя вычислительной группы, то есть группы ресурсов (тег `location`) узлов BE
- BackendNum - Количество BE в этой вычислительной группе

Результаты отсортированы по имени вычислительной группы.

## Пример {#example}

Укажите вычислительную группу с именем `compute_cluster` для использования.

```sql
SHOW COMPUTE GROUPS;
```

Результат:

```sql
+-----------------+-----------+-------+------------+
| Name            | IsCurrent | Users | BackendNum |
+-----------------+-----------+-------+------------+
| compute_cluster | TRUE      |       | 3          |
+-----------------+-----------+-------+------------+
```

## Требования к управлению доступом {#access-control-requirements}

Начиная с версии 4.1.4 выполнение этого оператора в режиме с совмещением вычислений и хранения **больше не требует глобальных привилегий `ADMIN_PRIV` или `NODE_PRIV`**, что соответствует режиму с разделением вычислений и хранения: текущий пользователь видит только те группы ресурсов, которые разрешено использовать его вычислительной группе.

## Примечания по использованию {#usage-note}

- Если у текущего пользователя нет прав доступа ни к одной вычислительной группе, `SHOW COMPUTE GROUPS` вернёт пустой список.
- В режиме с совмещением вычислений и хранения пустой набор результатов также возвращается, если вычислительная группа текущего сеанса имеет значение `INVALID_COMPUTE_GROUP`.
- `SHOW CLUSTERS` — эквивалентный оператор. В режиме с совмещением вычислений и хранения его столбцы называются `cluster` и `backend_num`.
