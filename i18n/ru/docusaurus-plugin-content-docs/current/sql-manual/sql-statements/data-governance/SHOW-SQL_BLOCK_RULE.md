## Описание {#description}
Отображает настроенные правила блокировки SQL-запросов. Если имя правила не указано, отображаются все правила.

## Синтаксис {#syntax}
```sql
SHOW SQL_BLOCK_RULE [FOR <rule_name>];
```

## Необязательные параметры {#optional-parameters}

`<rule_name>`

Имя правила блокировки SQL-запросов, которое нужно отобразить. Если не указано, отображаются все правила.

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду, должны обладать следующими привилегиями:

| Привилегия | Объект        | Примечания  |
|-----------|--------------|--------|
| `ADMIN`   | Пользователь или роль | Требуется для выполнения этой операции. |

## Примеры {#examples}

1. Вывести все правила блокировки SQL-запросов  
```sql
SHOW SQL_BLOCK_RULE;
```

```text
+------------+------------------------------+---------+--------------+-----------+-------------+--------+--------+
| Name       | Sql                          | SqlHash | PartitionNum | TabletNum | Cardinality | Global | Enable |
+------------+------------------------------+---------+--------------+-----------+-------------+--------+--------+
| test_rule  | select * from order_analysis | NULL    | 0            | 0         | 0           | true   | true   |
| test_rule2 | NULL                         | NULL    | 30           | 0         | 10000000000 | false  | true   |
+------------+------------------------------+---------+--------------+-----------+-------------+--------+--------+
```

2. Вывести конкретное правило блокировки SQL-запросов  
```sql
SHOW SQL_BLOCK_RULE FOR test_rule2;
```

```text
+------------+------+---------+--------------+-----------+-------------+--------+--------+
| Name       | Sql  | SqlHash | PartitionNum | TabletNum | Cardinality | Global | Enable |
+------------+------+---------+--------------+-----------+-------------+--------+--------+
| test_rule2 | NULL | NULL    | 30           | 0         | 10000000000 | false  | true   |
+------------+------+---------+--------------+-----------+-------------+--------+--------+
```
