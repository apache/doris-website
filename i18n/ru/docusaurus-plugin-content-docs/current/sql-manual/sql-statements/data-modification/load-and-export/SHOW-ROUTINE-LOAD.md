## Описание {#description}

Эта инструкция используется для просмотра состояния выполнения заданий Routine Load. Можно просмотреть сведения о состоянии конкретного задания или всех заданий.

## Синтаксис {#syntax}

```sql
SHOW [ALL] ROUTINE LOAD [FOR <jobName>];
```

## Необязательные параметры {#optional-parameters}

**1. `[ALL]`**

> Необязательный параметр. Если он указан, отображаются все задания, включая остановленные и отменённые. В противном случае отображаются только выполняющиеся задания.

**2. `[FOR <jobName>]`**

> Необязательный параметр. Задаёт имя задания для просмотра. Если не указан, отображаются все задания в текущей базе данных.
>
> Поддерживаются следующие форматы:
>
> - `<job_name>`: отображает задание с указанным именем в текущей базе данных
> - `<db_name>.<job_name>`: отображает задание с указанным именем в указанной базе данных

### Маскирование конфиденциальных свойств {#sensitive-property-masking}

<!-- Knowledge type: Behavior description -->
<!-- Applicable scenarios: Protecting Kafka credentials / Audit compliance -->

:::caution Изменение поведения (4.0.8)

Начиная с версии 4.0.8, конфиденциальные свойства заданий Kafka Routine Load отображаются в виде `******` в `CustomProperties` вместо открытого текста. Вывод `SHOW CREATE ROUTINE LOAD` также маскируется.

:::

Следующие свойства считаются конфиденциальными и маскируются:

| Правило сопоставления | Пример |
| --- | --- |
| Свойство с именем `sasl.jaas.config` | `sasl.jaas.config` |
| Свойство с именем `aws.access_key` | `aws.access_key` |
| Свойство с именем `ssl.keystore.key` или `ssl.key.pem` | `ssl.keystore.key` |
| Имя оканчивается на `.password`, `.secret`, `.secret_key` или `.secret.key` | `ssl.keystore.password`, `sasl.oauthbearer.client.secret` |
| Имя оканчивается на `.session_key` или `.session.token` | `aws.session.token` |
| Имя оканчивается на `.private.key`, `.private_key` или `.passphrase` либо содержит `.private.key.` | `sasl.oauthbearer.assertion.private.key.pem` |

Маскирование влияет только на отображение значений; значения свойств, которые фактически использует задание, не меняются. Чтобы изменить эти свойства, задайте их заново с помощью [ALTER ROUTINE LOAD](./ALTER-ROUTINE-LOAD); исходные значения нельзя получить из результата `SHOW`.

### FirstErrorMsg и OtherMsg {#firsterrormsg-versus-othermsg}

- `FirstErrorMsg`: **первая** ошибка, возникшая при выполнении задания; помогает найти первопричину. Если задание выполняется долго, последующие ошибки часто оказываются следствием первой.
- `OtherMsg`: последнее сообщение о другой ошибке; перезаписывается при последующих ошибках.

:::info Примечание

Эти значения также можно получить запросом к [`information_schema.routine_load_job`](../../../../admin-manual/system-tables/information_schema/routine_load_job). Начиная с версии 4.0.8, запросы к этой таблице обслуживает главный FE, поэтому `FIRST_ERROR_MSG` и `ERROR_LOG_URLS` больше не пусты, когда запрос попадает на FE, который не является главным.

:::

## Примечания {#notes}

- Описание состояний:
  - NEED_SCHEDULE: задание ожидает планирования
  - RUNNING: задание выполняется
  - PAUSED: задание приостановлено
  - STOPPED: задание завершено
  - CANCELLED: задание отменено

- Описание хода выполнения:
  - Для источника данных Kafka отображается смещение потребления для каждой партиции
  - Например, {"0":"2"} означает, что смещение потребления для партиции Kafka 0 равно 2

- Описание задержки:
  - Для источника данных Kafka отображается задержка потребления для каждой партиции
  - Например, {"0":10} означает, что задержка потребления для партиции Kafka 0 равна 10

## Примеры {#examples}

- Показать все задания Routine Load (включая остановленные и отменённые) с именем test1

    ```sql
    SHOW ALL ROUTINE LOAD FOR test1;
    ```

- Показать выполняющиеся задания Routine Load с именем test1

    ```sql
    SHOW ROUTINE LOAD FOR test1;
    ```

- Показать все задания Routine Load (включая остановленные и отменённые) в example_db. Результат может содержать одну или несколько строк.

    ```sql
    use example_db;
    SHOW ALL ROUTINE LOAD;
    ```

- Показать все выполняющиеся задания Routine Load в example_db

    ```sql
    use example_db;
    SHOW ROUTINE LOAD;
    ```

- Показать выполняющееся задание Routine Load с именем test1 в example_db

    ```sql
    SHOW ROUTINE LOAD FOR example_db.test1;
    ```

- Показать все задания Routine Load (включая остановленные и отменённые) с именем test1 в example_db. Результат может содержать одну или несколько строк.

    ```sql
    SHOW ALL ROUTINE LOAD FOR example_db.test1;
    ```
