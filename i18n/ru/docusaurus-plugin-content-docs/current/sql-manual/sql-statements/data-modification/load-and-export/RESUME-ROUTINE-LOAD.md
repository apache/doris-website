## Описание {#description}

Этот синтаксис используется для возобновления одного или всех приостановленных заданий Routine Load. Возобновлённое задание продолжит чтение данных с последнего прочитанного смещения.

## Синтаксис {#syntax}

```sql
RESUME [ALL] ROUTINE LOAD FOR <job_name>
```

## Обязательные параметры {#required-parameters}

**1. `<job_name>`**

> Указывает имя задания, которое нужно возобновить. Если указан ALL, параметр job_name не требуется.

## Необязательные параметры {#optional-parameters}

**1. `[ALL]`**

> Необязательный параметр. Если указан ALL, возобновляются все приостановленные задания Routine Load.

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие привилегии:

| Привилегия | Объект | Примечания |
| :-------- | :----- | :---- |
| LOAD_PRIV | Таблица | Для RESUME ROUTINE LOAD требуется привилегия LOAD на таблицу |

## Примечания {#notes}

- Возобновить можно только задания в состоянии PAUSED
- Возобновлённые задания продолжат чтение данных с последней прочитанной позиции
- Если задание было приостановлено слишком долго, возобновление может завершиться ошибкой из-за истечения срока хранения данных в Kafka

## Примеры {#examples}

- Возобновить задание Routine Load с именем test1.

   ```sql
   RESUME ROUTINE LOAD FOR test1;
   ```

- Возобновить все задания Routine Load.

   ```sql
   RESUME ALL ROUTINE LOAD;
   ```
