## Описание {#description}

Если задача загрузки завершается с ошибкой `ETL_QUALITY_UNSATISFIED`, это указывает на проблемы с качеством загружаемых данных. Эта инструкция позволяет просмотреть такие задачи загрузки.

## Синтаксис {#syntax}

```sql
SHOW LOAD WARNINGS
[FROM <db_name>]
[
   WHERE
   [LABEL  = [ "<your_label>" ]]
   [LOAD_JOB_ID = ["<job_id>"]]
]
```

## Необязательные параметры {#optional-parameters}

**1. `<db_name>`**

> Если `db_name` не указан, используется текущая база данных по умолчанию.

**2. `<your_label>`**

> При использовании `LABEL = <your_label>` выполняется поиск по точному совпадению с указанной меткой.

**3. `<job_id>`**

> Если указан `LOAD_JOB_ID = <job_id>`, выполняется поиск по точному совпадению с указанным JOB_ID.

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие права:

| Право доступа | Объект | Примечания |
| :---------------- | :------------- | :---------------------------- |
| LOAD_PRIV | База данных | Требуются права на загрузку данных в таблицы базы данных. |

## Возвращаемое значение {#return-value}

Возвращает данные с проблемами качества из задач загрузки указанной базы данных.

## Примеры {#examples}

- Показать данные с проблемами качества из задач загрузки указанной базы данных с меткой "load_demo_20210112".

```sql
SHOW LOAD WARNINGS FROM demo WHERE LABEL = "load_demo_20210112" 
```
