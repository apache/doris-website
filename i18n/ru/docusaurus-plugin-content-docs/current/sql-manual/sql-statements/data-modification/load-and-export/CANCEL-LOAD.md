## Описание {#description}

Эта инструкция позволяет отменить задание загрузки с указанной меткой `label` или выполнить пакетную отмену заданий загрузки с помощью нечёткого сопоставления.

## Синтаксис {#syntax}

```sql
CANCEL LOAD
[FROM <db_name>]
WHERE [LABEL = "<load_label>" | LABEL like "<label_pattern>" | STATE = { "PENDING" | "ETL" | "LOADING" } ]
```

## Обязательные параметры {#required-parameters}

**1. `<db_name>`**

> Имя базы данных, в которой находится отменяемое задание загрузки.

## Необязательные параметры {#optional-parameters}

**1. `<load_label>`**

> При использовании `LABEL = "<load_label>"` выполняется точное сопоставление с указанной меткой.

**2. `<label_pattern>`**

> При использовании `LABEL LIKE "<label_pattern>"` выбираются задания загрузки, метки которых содержат `label_pattern`.

**3. STATE = { " PENDING " | " ETL " | " LOADING " }**

> Указание `PENDING` означает отмену заданий со статусом `STATE = "PENDING"`. То же правило действует и для других статусов.

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие права:

| Привилегия | Объект | Примечания |
| :---------------- | :------------- | :---------------------------- |
| LOAD_PRIV | База данных | Требуются права на загрузку данных в таблицы базы данных. |

## Примечания по использованию {#usage-notes}

- Отмена заданий по `State` поддерживается начиная с версии 1.2.0.
- Отменить можно только незавершённые задания загрузки в состояниях `PENDING`, `ETL` или `LOADING`.
- При пакетной отмене Doris не гарантирует атомарную отмену всех соответствующих заданий загрузки. То есть успешно отменены могут быть лишь некоторые задания загрузки. Пользователи могут проверить статус заданий с помощью инструкции `SHOW LOAD` и повторно выполнить инструкцию `CANCEL LOAD`.

## Примеры {#examples}

1. Отмена задания загрузки с меткой `example_db_test_load_label` в базе данных `example_db`.

   ```sql
   CANCEL LOAD
   FROM example_db
   WHERE LABEL = "example_db_test_load_label";
   ```

2. Отмена всех заданий загрузки, метки которых содержат `example_`, в базе данных `example_db`.

   ```sql
   CANCEL LOAD
   FROM example_db
   WHERE LABEL like "%example_%";
   ```

3. Отмена заданий загрузки в состоянии `LOADING`.

   ```sql
   CANCEL LOAD
   FROM example_db
   WHERE STATE = "loading";
   ```
