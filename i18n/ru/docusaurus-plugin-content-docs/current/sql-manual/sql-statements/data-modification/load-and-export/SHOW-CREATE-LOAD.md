## Описание {#description}

Этот оператор используется для просмотра оператора создания задания загрузки.

## Синтаксис {#syntax}

```sql
SHOW CREATE LOAD FOR <load_name>;
```

## Обязательные параметры {#required-parameters}

**`<load_name>`**

> Имя задания регулярной загрузки.

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны обладать как минимум следующими правами:

| Право | Объект | Примечания |
| :---------------- | :------------- | :---------------------------- |
| ADMIN/NODE_PRIV | База данных | Требуются права администратора кластера. |

## Возвращаемое значение {#return-value}

Возвращает оператор создания указанного задания загрузки.

## Примеры {#examples}

- Просмотр оператора создания указанного задания загрузки в базе данных по умолчанию.

```sql
SHOW CREATE LOAD for test_load
```
