## Описание {#description}

Этот синтаксис используется для просмотра выполняющихся в данный момент подзадач указанного задания Routine Load.

## Синтаксис {#syntax}

```sql
SHOW ROUTINE LOAD TASK WHERE JobName = <job_name>;

SHOW ROUTINE LOAD TASK FOR [<db>.]<job_name>;
```

## Обязательные параметры {#required-parameters}

**1. `<job_name>`**

> Имя задания Routine Load, информацию о котором нужно просмотреть.

## Необязательные параметры {#optional-parameters}

**1. `<db>`**

> База данных, в которой находится задание Routine Load. Если параметр не указан, задание Routine Load ищется в текущей базе данных.

## Возвращаемые результаты {#return-results}

Возвращаемые результаты содержат следующие поля:

| Имя поля             | Описание                                                     |
| :------------------- | :---------------------------------------------------------- |
| TaskId               | Уникальный идентификатор подзадачи                            |
| TxnId                | Идентификатор транзакции загрузки, соответствующей подзадаче  |
| TxnStatus            | Статус транзакции загрузки подзадачи. Null означает, что подзадача ещё не запланирована к выполнению |
| JobId                | Идентификатор задания, которому принадлежит подзадача         |
| CreateTime           | Время создания подзадачи                                     |
| ExecuteStartTime     | Время, когда подзадача была запланирована к выполнению; обычно позже времени создания |
| Timeout              | Тайм-аут подзадачи, обычно равный удвоенному значению `max_batch_interval`, заданному в задании |
| BeId                 | Идентификатор узла BE, выполняющего эту подзадачу              |
| DataSourceProperties | Начальное смещение раздела Kafka, из которого подзадача готовится читать данные. Это строка в формате JSON. Ключом служит идентификатор раздела, а значением служит начальное смещение для чтения |

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие привилегии:

| Привилегия | Объект | Примечания |
| :-------- | :----- | :---- |
| LOAD_PRIV | Таблица | Для SHOW ROUTINE LOAD TASK требуется привилегия LOAD для таблицы |

## Примечания {#notes}

- Значение null в TxnStatus не указывает на ошибку задачи: оно может означать, что задача ещё не запланирована к выполнению
- Информацию о смещениях в DataSourceProperties можно использовать для отслеживания хода чтения данных
- По истечении Timeout задача автоматически завершается независимо от того, завершено ли чтение данных

## Примеры {#examples}

- Показать информацию о подзадачах задания Routine Load с именем test1.

    ```sql
    SHOW ROUTINE LOAD TASK WHERE JobName = "test1";
    ```

- Показать информацию о подзадачах задания Routine Load `test1` в текущей базе данных.

    ```sql
    SHOW ROUTINE LOAD TASK FOR test1;
    ```

- Показать информацию о подзадачах задания Routine Load `test1` в базе данных `example_db`.

    ```sql
    SHOW ROUTINE LOAD TASK FOR example_db.test1;
    ```
