## Описание {#description}

Этот оператор используется для отмены задания экспорта с указанной меткой, а также для пакетной отмены заданий экспорта с помощью нечёткого сопоставления.

## Синтаксис {#syntax}

```sql
CANCEL EXPORT
[ FROM <db_name> ]
WHERE [ LABEL = "<export_label>" | LABEL like "<label_pattern>" | STATE = "<state>" ]
```

## Необязательные параметры {#optional-parameters}

**1. `<db_name>`**

  Имя базы данных, к которой относится задание экспорта данных. Если параметр не указан, используется текущая база данных.

**2. `<export_label>`**

  Каждому заданию импорта необходимо назначить уникальную метку Label. Для остановки этого задания необходимо указать метку.

**3. `<label_pattern>`**

  Шаблон метки для нечёткого сопоставления. Чтобы отменить несколько заданий EXPORT, можно использовать `LIKE` для нечёткого сопоставления.

**4. `<state>`**

  Допустимые значения состояния: `PENDING`,`IN_QUEUE`,`EXPORTING`.

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие привилегии:

| Привилегия    | Объект    | Примечания                                    |
|:--------------|:----------|:----------------------------------------------|
| ALTER_PRIV    | База данных | Требуется право на изменение базы данных.   |


## Примечания по использованию {#usage-notes}

1. Отменять можно только незавершённые задания экспорта в состояниях PENDING, IN_QUEUE и EXPORTING.
2. При пакетной отмене Doris не гарантирует атомарность отмены всех соответствующих заданий экспорта. То есть успешно отменена может быть только часть заданий экспорта. Пользователь может проверить состояние заданий с помощью оператора SHOW EXPORT и попробовать повторно выполнить оператор CANCEL EXPORT.
3. При отмене задания в состоянии `EXPORTING` часть данных уже может быть экспортирована в систему хранения, и пользователю необходимо обработать (удалить) эту часть экспортированных данных.

## Примеры {#examples}

- Отменить задание экспорта с меткой `example_db_test_export_label` в базе данных example_db.

   ```sql
   CANCEL EXPORT
   FROM example_db
   WHERE LABEL = "example_db_test_export_label" and STATE = "EXPORTING";
   ```

- Отменить все задания экспорта, содержащие example*, в базе данных example*db.

   ```sql
   CANCEL EXPORT
   FROM example_db
   WHERE LABEL like "%example%";
   ```

- Отменить все задания экспорта в состоянии "PENDING"

   ```sql
   CANCEL EXPORT
   FROM example_db
   WHERE STATE = "PENDING";
   ```
