## Описание {#description}

Этот оператор используется для просмотра задач RESTORE

## Синтаксис {#syntax}

```SQL
SHOW [BRIEF] RESTORE [FROM <db_name>]
```

## Параметры {#parameters}

**1.`<db_name>`**

Имя базы данных, к которой относится задача восстановления.

## Возвращаемое значение {#return-value}

- brief: отображать только основную информацию о задачах RESTORE; столбцы RestoreObjs, Progress, TaskErrMsg не отображаются

| Столбец | Описание |
| -- | -- |
| JobId | Уникальный идентификатор задания |
| Label | Имя резервной копии для восстановления |
| Timestamp | Временная версия резервной копии для восстановления |
| DbName | База данных, к которой относится задание |
| State | Текущий этап: <ul><li>PENDING: Начальное состояние после отправки задания.</li><li>SNAPSHOTING: Создание снимка.</li><li>DOWNLOAD: Снимок создан и готов к скачиванию из репозитория.</li><li>DOWNLOADING: Скачивание снимка.</li><li>COMMIT: Скачивание снимка завершено, снимок готов к применению.</li><li>COMMITTING: Применение снимка.</li><li>FINISHED: Время завершения задания.</li><li>CANCELLED: Задание завершилось с ошибкой.</li></ul> |
| AllowLoad | Разрешён ли импорт во время восстановления (в настоящее время не поддерживается)|
| ReplicationNum | Количество реплик для восстановления |
| ReserveReplica | Нужно ли сохранять копию |
| ReplicaAllocation | Нужно ли оставлять динамическое партиционирование включённым |
| RestoreJobs | Таблицы и партиции для восстановления |
| CreateTime | Время отправки задачи |
| MetaPreparedTime | Время завершения подготовки метаданных |
| SnapshotFinishedTime | Время завершения создания снимка |
| DownloadFinishedTime | Время завершения скачивания снимка |
| FinishedTime | Время завершения задания |
| UnfinishedTasks | Идентификаторы незавершённых подзадач на этапах SNAPSHOTING, DOWNLOADING и COMMITING |
| Progress |  Ход выполнения задачи |
| TaskErrMsg | Сообщения об ошибках задачи |
| Status | Сообщение об ошибке, если задание завершилось с ошибкой |
| Timeout | Время ожидания завершения задания в секундах |

## Пример {#example}

1. Просмотр последней задачи RESTORE в базе данных example_db.

```sql
SHOW RESTORE FROM example_db;
```
