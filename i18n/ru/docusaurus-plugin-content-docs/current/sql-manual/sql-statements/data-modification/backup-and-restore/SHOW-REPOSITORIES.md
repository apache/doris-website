## Описание {#description}

Эта инструкция используется для просмотра созданных репозиториев

## Синтаксис {#syntax}

```sql
SHOW REPOSITORIES;
```

## Возвращаемое значение {#return-value}

| Поле            | Описание                                 |
|-----------------|------------------------------------------|
| **RepoId**      | Уникальный идентификатор (ID) репозитория |
| **RepoName**    | Имя репозитория                          |
| **CreateTime**  | Время создания репозитория               |
| **IsReadOnly**  | Доступен ли репозиторий только для чтения. `false` означает, что репозиторий доступен и для записи, `true` означает доступ только для чтения |
| **Location**    | Корневой каталог для резервного копирования данных в репозитории |
| **Broker**      | -                                        |
| **Type**        | Тип репозитория. В настоящее время поддерживаются S3 и HDFS |
| **ErrMsg**      | Сообщение об ошибке репозитория. Если ошибок нет, обычно содержит `NULL` |


## Примеры {#examples}

Просмотр созданного репозитория:

```sql
SHOW REPOSITORIES;
```
```text
+--------+--------------+---------------------+------------+----------+--------+------+--------+
| RepoId | RepoName     | CreateTime          | IsReadOnly | Location | Broker | Type | ErrMsg |
+--------+--------------+---------------------+------------+----------+--------+------+--------+
| 43411  | example_repo | 2025-01-17 18:50:47 | false      | s3://rep1  | -      | S3   | NULL   |
+--------+--------------+---------------------+------------+----------+--------+------+--------+
```
