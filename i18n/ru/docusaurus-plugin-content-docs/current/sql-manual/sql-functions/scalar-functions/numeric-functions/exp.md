## Описание {#description}

Возвращает значение экспоненциальной функции с аргументом `x` и основанием `e`.

## Псевдоним {#alias}

- DEXP

## Синтаксис {#syntax}

```sql
EXP(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<x>` | независимая переменная |

## Возвращаемое значение {#return-value}

Возвращает значение типа double. Особые случаи:
- Если параметр равен NULL, возвращает NULL
- Если значение параметра достаточно велико, возвращает Infinity

## Пример {#example}

```sql
select exp(2);
```

```text
+------------------+
| exp(2.0)         |
+------------------+
| 7.38905609893065 |
+------------------+
```

```sql
select exp(3.4);
```

```text
+--------------------+
| exp(3.4)           |
+--------------------+
| 29.964100047397011 |
+--------------------+
```

```sql
select exp(1000000);
```

```text
+--------------+
| EXP(1000000) |
+--------------+
|     Infinity |
+--------------+
```
