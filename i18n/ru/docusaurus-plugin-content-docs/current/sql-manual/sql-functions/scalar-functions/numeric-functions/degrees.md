## Описание {#description}

Принимает число с плавающей точкой двойной точности и преобразует его из радиан в градусы.

- Если параметр равен NULL, возвращает NULL.

## Синтаксис {#syntax}

```sql
DEGREES(<a>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<a>` | Значение, которое необходимо преобразовать из радиан в градусы. |

## Возвращаемое значение {#return-value}

Угол, соответствующий параметру a.

- Если параметр равен NULL, возвращает NULL.

## Особые случаи {#special-cases}
- Если `a` имеет значение NaN, возвращает NaN
- Если `a` — положительная бесконечность, возвращает Infinity
- Если `a` — отрицательная бесконечность, возвращает -Infinity
- Если `a` имеет значение NULL, возвращает NULL

## Примеры {#examples}

```sql
select degrees(3.14),degrees(1),degrees(-1),degrees(NULL)
```

