## Описание {#description}

Возвращает факториал `x` или `NULL`, если `x` находится вне диапазона от `0` до `20` (включая `0` и `20`).

## Синтаксис {#syntax}

```sql
FACTORIAL(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |  
| -- | -- |  
| `<x>` | Значение, для которого требуется вычислить факториал |  

## Возвращаемое значение {#return-value}

Факториал значения параметра `x`.

## Особые случаи {#special-cases}

- Если `x` равен 0, возвращает 1
- Если `x` находится вне диапазона [0, 20], возвращает `NULL`
- Если `x` равен NULL, возвращает NULL

## Примеры {#examples}

```sql

```
