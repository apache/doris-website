## Описание {#description}

Возвращает значение константы `Pi`.

## Синтаксис {#syntax}

```sql
PI()
```

## Возвращаемое значение {#return-value}

Возвращает константу Pi в виде числа с плавающей точкой.

## Пример {#example}

```sql
select Pi();
```

```text
+-------------------+
| pi()              |
+-------------------+
| 3.141592653589793 |
+-------------------+
```
