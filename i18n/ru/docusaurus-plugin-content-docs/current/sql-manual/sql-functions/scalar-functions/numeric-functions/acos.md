## Описание {#description}

Возвращает арккосинус `x` или `NULL`, если `x` не входит в диапазон от `-1` до `1`.

## Синтаксис {#syntax}

```sql
ACOS(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |  
| -- | -- |  
| `<x>` | Значение, для которого вычисляется арккосинус |  

## Возвращаемое значение {#return-value}

Значение арккосинуса параметра `x`, выраженное в радианах.

## Особые случаи {#special-cases}

- Если `x` равен 1, возвращает 0
- Если `x` равен 0, возвращает π/2
- Если `x` равен -1, возвращает π
- Если `x` не входит в диапазон [-1, 1], возвращает `NULL`
- Если `x` равен NaN, возвращает NaN
- Если `x` равен положительной или отрицательной бесконечности, возвращает `NULL`
- Если `x` равен NULL, возвращает NULL

## Примеры {#examples}

```sql
select acos(1);
```

```text
+-----------+
| acos(1.0) |
+-----------+
|         0 |
+-----------+
```

```sql
select acos(0);
```

```text
+--------------------+
| acos(0.0)          |
+--------------------+
| 1.5707963267948966 |
+--------------------+
```

```sql
select acos(-1);
```

```text
+--------------------+
| acos(-1.0)         |
+--------------------+
| 3.141592653589793  |
+--------------------+
```

```sql
select acos(-2);
```

```text
+------------+
| acos(-2.0) |
+------------+
|       NULL |
+------------+
```

```sql
select acos(1.0000001);
```

```text
+-----------------+
| acos(1.0000001) |
+-----------------+
|            NULL |
+-----------------+
```

```text
| acos(cast('inf' AS DOUBLE)) |
+---------------------------+

+---------------------------+
```
