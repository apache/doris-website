## Описание {#description}

Возвращает значение `x` в радианах, преобразованное из градусов.

## Синтаксис {#syntax}

```sql
RADIANS(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<x>`   | Угол в градусах, который требуется преобразовать. |

## Возвращаемое значение {#return-value}

Возвращает целое число или число с плавающей запятой. Особый случай:

- Если параметр x равен NULL, возвращается NULL.

## Пример {#example}

```sql
select radians(0);
```

```text
+----------------------------+
| radians(cast(0 as DOUBLE)) |
+----------------------------+
|                        0.0 |
+----------------------------+
```

```sql
select radians(30);
```

```text
+-----------------------------+
| radians(cast(30 as DOUBLE)) |
+-----------------------------+
|          0.5235987755982988 |
+-----------------------------+
```

```sql
select radians(90);
```

```text
+-----------------------------+
| radians(cast(90 as DOUBLE)) |
+-----------------------------+
|          1.5707963267948966 |
+-----------------------------+
```
