## Описание {#description}

Возвращает абсолютное значение `x`

## Синтаксис {#syntax}

```sql
ABS(<x>) 
```

## Параметры {#parameters}

| Параметр | Описание |  
| -- | -- |  
| `<x>` | Значение, для которого требуется вычислить абсолютное значение |  

## Возвращаемое значение {#return-value}

Абсолютное значение параметра `x`. 
Если `x` равен NULL, возвращает NULL.

## Пример {#example}

```sql
select abs(-2);
```

```text
+---------+
| abs(-2) |
+---------+
|       2 |
+---------+
```

```sql
select abs(3.254655654);
```

```text
+------------------+
| abs(3.254655654) |
+------------------+
|      3.254655654 |
+------------------+
```

```sql
select abs(-3254654236547654354654767);
```

```text
+---------------------------------+
| abs(-3254654236547654354654767) |
+---------------------------------+
| 3254654236547654354654767       |
+---------------------------------+
```

```sql
select abs(NULL);
```

```text
+-----------+
| abs(NULL) |
+-----------+
|      NULL |
+-----------+
```
