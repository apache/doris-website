## Описание {#description}

Возвращает обратный гиперболический тангенс `x` или `NULL`, если `x` не входит в диапазон от `-1` до `1` (не включая `-1` и `1`).

## Синтаксис {#syntax}

```sql
ATANH(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |  
| -- | -- |  
| `<x>` | Значение, для которого вычисляется обратный гиперболический тангенс |  

## Возвращаемое значение {#return-value}

Значение обратного гиперболического тангенса параметра `x`.

## Особые случаи {#special-cases}

- Если `x` равен 0, возвращает 0
- Если `x` равен 1 или -1, возвращает `NULL`
- Если `x` находится вне диапазона (-1, 1), возвращает `NULL`
- Если `x` равен NaN, возвращает NaN
- Если `x` равен положительной или отрицательной бесконечности, возвращает `NULL`
- Если `x` равен NULL, возвращает NULL
