## Описание {#description}

Возвращает случайное число от 0 до 1 либо случайное число в соответствии с заданными параметрами.

- Примечание: все параметры должны быть константами.

## Псевдоним {#alias}

- RAND

## Синтаксис {#syntax}

```sql
RANDOM() -- Generates a random number between 0 and 1

RANDOM(<seed>) -- Generates a fixed sequence of random numbers between 0 and 1 based on the seed value

RANDOM(<a> , <b>) -- Generates a random number between a and b
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<seed>` | Начальное значение генератора случайных чисел. Возвращает фиксированную последовательность случайных чисел от 0 до 1. |
| `<a>` | Нижняя граница диапазона случайных чисел. |
| `<b>` | Верхняя граница диапазона случайных чисел. Должна быть больше нижней границы. |

## Возвращаемое значение {#return-value}

- Если параметры не переданы: возвращает случайное число от 0 до 1.

- Если передан один параметр seed: возвращает фиксированную последовательность случайных чисел от 0 до 1.

- Если переданы два параметра a и b: возвращает случайное целое число от a до b.

## Пример {#example}

```sql
select random();
```

```text
+--------------------+
| random()           |
+--------------------+
| 0.8047437125910604 |
+--------------------+
```

```sql
select rand(1.2);
```

```text
+---------------------+
| rand(1)             |
+---------------------+
| 0.13387664401253274 |
+---------------------+
```

```sql
select rand(-20, -10);
```

```text
+------------------+
| random(-20, -10) |
+------------------+
|              -10 |
+------------------+
```
