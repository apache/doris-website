## Описание {#description}

Возвращает гиперболический арккосинус `x` или `NULL`, если `x` меньше `1`.

## Синтаксис {#syntax}

```sql
ACOSH(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |  
| -- | -- |  
| `<x>` | Значение, для которого вычисляется гиперболический арккосинус |  

## Возвращаемое значение {#return-value}

Гиперболический арккосинус значения параметра `x`.

## Особые случаи {#special-cases}

- Если `x` равен 1, возвращает 0
- Если `x` меньше 1, возвращает `NULL`
- Если `x` равен NaN, возвращает NaN
- Если `x` равен положительной бесконечности, возвращает Infinity
- Если `x` равен отрицательной бесконечности, возвращает `NULL`
- Если `x` равен NULL, возвращает NULL
