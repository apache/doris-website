## Описание {#description}

Возвращает значение параметра x с противоположным знаком.

## Синтаксис {#syntax}

```sql
NEGATIVE(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<x>` | Аргумент поддерживает типы `BIGINT, DOUBLE, and DECIMAL` |

## Возвращаемое значение {#return-value}

Возвращает целое число или число с плавающей точкой. Особые случаи:

- Если параметр равен NULL, возвращает NULL.
- Если параметр равен 0, возвращает 0.

## Пример {#example}

```sql
SELECT negative(-10);
```

```text
+---------------+
| negative(-10) |
+---------------+
|            10 |
+---------------+
```

```sql
SELECT negative(12);
```

```text
+--------------+
| negative(12) |
+--------------+
|          -12 |
+--------------+
```

```sql
SELECT negative(0);
```

```text
+-------------+
| negative(0) |
+-------------+
|           0 |
+-------------+
```

```sql
SELECT negative(null);
```

```text
+----------------+
| negative(NULL) |
+----------------+
|           NULL |
+----------------+
```
