## Описание {#description}

Возвращает гиперболический синус `x`.

## Синтаксис {#syntax}

```sql
SINH(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |  
| -- | -- |  
| `<x>` | Значение, для которого необходимо вычислить гиперболический синус |  

## Возвращаемое значение {#return-value}

Значение sinh для параметра `x`.

## Особые случаи {#special-cases}
- Если `x` равен NaN, возвращается NaN
- Если `x` равен положительной бесконечности, возвращается Infinity
- Если `x` равен отрицательной бесконечности, возвращается -Infinity
- Если `x` равен NULL, возвращается NULL

## Пример {#example}

```sql
select sinh(0.0);
```

```
+-----------+
| sinh(0.0) |
+-----------+
|         0 |
+-----------+
```

```sql
select sinh(1.0);
```

```
+--------------------+
| sinh(1.0)          |
+--------------------+
| 1.1752011936438014 |
+--------------------+
```

```sql
select sinh(-1.0);
```

```
+---------------------+
| sinh(-1.0)          |
+---------------------+
| -1.1752011936438014 |
+---------------------+
```

```sql
select sinh(cast('nan' as double));
```
```
+------------------------------+
| sinh(cast('nan' AS DOUBLE))  |
+------------------------------+
| NaN                          |
+------------------------------+
```

```sql
select sinh(cast('inf' as double));
```
```
+------------------------------+
| sinh(cast('inf' AS DOUBLE))  |
+------------------------------+
| Infinity                     |
+------------------------------+
```

```sql
select sinh(cast('-inf' as double));
```
```
+-------------------------------+
| sinh(cast('-inf' AS DOUBLE))  |
+-------------------------------+
| -Infinity                     |
+-------------------------------+
```
