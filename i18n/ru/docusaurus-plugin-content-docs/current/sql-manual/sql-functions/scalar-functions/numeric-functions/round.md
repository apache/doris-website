## Описание {#description}

Округляет число `x` до указанного количества знаков.
- Если `d` не указан, `x` округляется до ближайшего целого числа.
- Если `d` отрицателен, результат округляется на `d` разрядов слева от десятичного разделителя.
- Если `x` или `d` имеет значение `null`, возвращает `null`.
- Если `d` является столбцом, а первый аргумент имеет тип `Decimal`, результирующее значение `Decimal` будет иметь столько же знаков после десятичного разделителя, сколько и входное значение `Decimal`.


## Псевдоним {#alias}

- `DROUND`

## Синтаксис {#syntax}

```sql
ROUND(<x> [ , <d> ])
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<x>` | Число для округления |
| `<d>` | Необязательный параметр, задающий количество знаков после десятичного разделителя для округления |

## Примеры {#examples}

```sql
select round(2.4);
```

```text
+------------+
| round(2.4) |
+------------+
|          2 |
+------------+
```

```sql
select round(2.5);
```

```text
+------------+
| round(2.5) |
+------------+
|          3 |
+------------+
```

```sql
select round(-3.4);
```

```text
+-------------+
| round(-3.4) |
+-------------+
|          -3 |
+-------------+
```

```sql
select round(-3.5);
```

```text
+-------------+
| round(-3.5) |
+-------------+
|          -4 |
+-------------+
```

```sql
select round(1667.2725, 2);
```

```text
+---------------------+
| round(1667.2725, 2) |
+---------------------+
|             1667.27 |
+---------------------+
```

```sql

```

```text
+----------------------+

+----------------------+

+----------------------+
```

## Примечание по использованию {#usage-note}
2.5 округляется до 3. Если нужно округлить до 2, используйте функцию `round_bankers`.
