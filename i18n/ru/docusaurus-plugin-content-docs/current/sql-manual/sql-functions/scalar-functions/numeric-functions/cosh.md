## Описание {#description}

Возвращает гиперболический косинус `x`.

## Синтаксис {#syntax}

`COSH(<x>)`

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<x>` | Значение, для которого вычисляется гиперболический косинус  |

## Возвращаемое значение {#return-value}

Гиперболический косинус параметра `x`

## Особые случаи {#special-cases}
- Если `x` имеет значение NaN, возвращает NaN
- Если `x` равен положительной бесконечности, возвращает Infinity
- Если `x` равен отрицательной бесконечности, возвращает Infinity
- Если `x` имеет значение NULL, возвращает NULL

## Примеры {#examples}

```sql
select cosh(0);
```
```text
+-------------------------+
| cosh(cast(0 as DOUBLE)) |
+-------------------------+
|                     1.0 |
+-------------------------+
```

```sql
select cosh(1);
```
```text
+-------------------------+
| cosh(cast(1 as DOUBLE)) |
+-------------------------+
|       1.543080634815244 |
+-------------------------+
```

```sql
select cosh(-1);
```
```text
+--------------------------+
| cosh(cast(-1 as DOUBLE)) |
+--------------------------+
|        1.543080634815244 |
+--------------------------+
```

```sql
select cosh(cast('nan' as double));
```
```text
+-----------------------------+
| cosh(cast('nan' AS DOUBLE)) |
+-----------------------------+
| NaN                         |
+-----------------------------+
```

```sql
select cosh(cast('inf' as double));
```
```text
+-----------------------------+
| cosh(cast('inf' AS DOUBLE)) |
+-----------------------------+
| Infinity                    |
+-----------------------------+
```

```sql
select cosh(cast('-inf' as double));
```
```text
+------------------------------+
| cosh(cast('-inf' AS DOUBLE)) |
+------------------------------+
| Infinity                     |
+------------------------------+
```
