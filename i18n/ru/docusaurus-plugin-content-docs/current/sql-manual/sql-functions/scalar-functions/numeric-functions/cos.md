## Описание {#description}

Вычисляет косинус значения параметра

## Синтаксис {#syntax}

```sql
COS(<a>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<a>` | Число с плавающей запятой — значение параметра в радианах, для которого вычисляется косинус |

## Возвращаемое значение {#return-value}

Косинус значения параметра `<a>`, заданного в радианах.

## Особые случаи {#special-cases}
- Если `a` равно NaN, возвращает NaN
- Если `a` равно положительной или отрицательной бесконечности, возвращает NaN
- Если `a` равно NULL, возвращает NULL

## Примеры {#examples}

```sql
select cos(1);
```

```text
+---------------------+
| cos(1.0)            |
+---------------------+
| 0.54030230586813977 |
+---------------------+
```

```sql
select cos(0);
```

```text
+------------------------+
| cos(cast(0 as DOUBLE)) |
+------------------------+
|                    1.0 |
+------------------------+
```

```sql
select cos(Pi());
```

```text
+-----------+
| cos(pi()) |
+-----------+
|        -1 |
+-----------+
```

```sql
select cos(cast('nan' as double));
```

```text
+----------------------------+
| cos(cast('nan' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select cos(cast('inf' as double));
```

```text
+----------------------------+
| cos(cast('inf' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select cos(cast('-inf' as double));
```

```text
+-----------------------------+
| cos(cast('-inf' AS DOUBLE)) |
+-----------------------------+
| NaN                         |
+-----------------------------+
```
