## Описание {#description}

Возвращает косеканс x, где x задан в радианах. Для входного и выходного значений поддерживается только тип double. Если на вход передано значение NULL, возвращается NULL.

## Синтаксис {#syntax}

```sql
CSC(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<x>` | Значение, для которого вычисляется косеканс |

## Возвращаемое значение {#return-value}

Возвращает значение типа Double, равное косекансу x.

## Особые случаи {#special-cases}
- Если `x` имеет значение NaN, возвращается NaN
- Если `x` равен положительной или отрицательной бесконечности, возвращается NaN
- Если `x` имеет значение NULL, возвращается NULL

## Пример {#example}

```sql
select csc(1),csc(2),csc(1000);
```

```text
+--------------------+--------------------+------------------+
| csc(1)             | csc(2)             | csc(1000)        |
+--------------------+--------------------+------------------+
| 1.1883951057781212 | 1.0997501702946164 | 1.20936599707935 |
+--------------------+--------------------+------------------+
```

На вход передано значение NULL.

```sql
select csc(null);
```

```text
+--------------------+
| csc(null)          |
+--------------------+
|      NULL          |
+--------------------+
```

```sql
select csc(cast('nan' as double));
```

```text
+---------------------------+
| csc(cast('nan' AS DOUBLE))|
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select csc(cast('inf' as double));
```

```text
+---------------------------+
| csc(cast('inf' AS DOUBLE))|
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select csc(cast('-inf' as double));
```

```text
+----------------------------+
| csc(cast('-inf' AS DOUBLE))|
+----------------------------+
| NaN                        |
+----------------------------+
```
