## Описание {#description}

Возвращает наименьшее положительное решение операции взятия остатка x mod y в системе вычетов, получаемое вычислением (x % y + y) % y.

## Синтаксис {#syntax}

```sql
PMOD(<x> , <y>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<x>` | Делимое |
| `<y>` | Делитель, не должен быть равен 0 |

## Возвращаемое значение {#return-value}

Возвращает целое число или число с плавающей точкой. Особые случаи:

- Если x = 0, возвращает 0.
- Если x равен NULL или y равен NULL, возвращает NULL.

## Пример {#example}

```sql
SELECT PMOD(13,5);
```

```text
+-------------+
| pmod(13, 5) |
+-------------+
|           3 |
+-------------+
```

```sql
SELECT PMOD(-13,5);
```

```text
+--------------+
| pmod(-13, 5) |
+--------------+
|            2 |
+--------------+
```

```sql
SELECT PMOD(0,-12);
```

```text
+--------------+
| pmod(0, -12) |
+--------------+
|            0 |
+--------------+
```

```sql
SELECT PMOD(0,null);
```

```text
+-------------------------------+
| pmod(cast(0 as DOUBLE), NULL) |
+-------------------------------+
|                          NULL |
+-------------------------------+
```
