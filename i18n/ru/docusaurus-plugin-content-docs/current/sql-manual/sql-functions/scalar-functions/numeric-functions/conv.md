## Описание {#description}

Преобразует входной параметр из одной системы счисления в другую.

## Синтаксис {#syntax}

```sql
CONV(<input>, <from_base>, <to_base>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<input>` | Значение для преобразования в виде строки или целого числа |
| `<from_base>` | Числовое значение, задающее основание исходной системы счисления, в диапазоне `[2,36]`. |
| `<to_base>` | Числовое значение, задающее основание целевой системы счисления, в диапазоне `[2,36]`. |

## Возвращаемое значение {#return-value}

Число в целевой системе счисления с основанием `<to_base>` возвращается в виде строки.
Если любой из входных параметров равен NULL, возвращается NULL.
Если `<from_base>` или `<to_base>` выходит за пределы допустимого диапазона, возвращается NULL.

## Примеры {#examples}

```sql
SELECT CONV(15,10,2);
```

```text
+-----------------+
| conv(15, 10, 2) |
+-----------------+
| 1111            |
+-----------------+
```

```sql
SELECT CONV('ff',16,10);
```

```text
+--------------------+
| conv('ff', 16, 10) |
+--------------------+
| 255                |
+--------------------+
```

```sql
SELECT CONV(230,10,16);
```

```text
+-------------------+
| conv(230, 10, 16) |
+-------------------+
| E6                |
+-------------------+
```

```sql
SELECT CONV(230,10,NULL);
```

```text
+-------------------+
| CONV(230,10,NULL) |
+-------------------+
| NULL              |
+-------------------+
```

```sql
SELECT CONV(230,10,56);
```

```text
+-----------------+
| CONV(230,10,56) |
+-----------------+
| NULL            |
+-----------------+
```
