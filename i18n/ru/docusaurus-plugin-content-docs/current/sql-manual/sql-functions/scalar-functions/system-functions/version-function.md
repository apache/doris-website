## Описание {#description}

Не имеет практического значения, служит для совместимости с протоколом MySQL.

## Синтаксис {#syntax}

```sql
VERSION()
```

## Возвращаемое значение {#return-value}

Для совместимости с протоколом MySQL всегда возвращает фиксированное значение "5.7.99".

## Примеры {#examples}

```sql
select version();
```

```text
+-----------+
| version() |
+-----------+
| 5.7.99    |
+-----------+
```
