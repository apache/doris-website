## Описание {#description}

Возвращает имя пользователя и IP-адрес текущего подключения к Doris. Совместима с протоколом MySQL.

## Синтаксис {#syntax}

```sql
SESSION_USER()
```

## Возвращаемое значение {#return-value}

Возвращает имя пользователя и IP-адрес текущего подключения к Doris.
Формат:`<user_name>@<ip>`

## Примеры {#examples}

```sql
select session_user();
```

```text
+----------------------+
| session_user()       |
+----------------------+
| 'root'@'10.244.2.10' |
+----------------------+
```
