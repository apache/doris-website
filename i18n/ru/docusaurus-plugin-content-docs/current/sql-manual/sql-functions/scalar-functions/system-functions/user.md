## Описание {#description}

Получает имя текущего пользователя и IP-адрес, с которого установлено подключение к Doris.

## Синтаксис {#syntax}

```sql
USER()
```

## Возвращаемое значение {#return-value}

Возвращает имя текущего пользователя и IP-адрес, с которого установлено подключение к Doris.
Формат: `<user_name>@<ip>`

## Примеры {#examples}

```sql
select user();
```

```text
+---------------------+
| user()              |
+---------------------+
| 'root'@'10.244.2.5' |
+---------------------+
```
