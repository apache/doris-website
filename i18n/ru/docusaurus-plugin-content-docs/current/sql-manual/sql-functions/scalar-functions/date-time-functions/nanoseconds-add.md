## Описание {#description}

Добавляет заданное количество наносекунд к значению `TIMESTAMP_NS`, сохраняя наносекундную точность.

## Синтаксис {#syntax}

```sql
NANOSECONDS_ADD(<timestamp_ns>, <delta>)
```

## Параметры {#parameters}

| Параметр | Описание |
| --- | --- |
| `<timestamp_ns>` | Исходное значение типа `TIMESTAMP_NS`. |
| `<delta>` | Количество добавляемых наносекунд, тип — `BIGINT`. При отрицательном значении наносекунды вычитаются. |

## Возвращаемое значение {#return-value}

Возвращает `TIMESTAMP_NS`. Возвращает `NULL`, если хотя бы один аргумент равен `NULL`. Выдаёт ошибку, если результат выходит за пределы диапазона `TIMESTAMP_NS`.

## Пример {#example}

```sql
SELECT NANOSECONDS_ADD(
    CAST('1969-12-31 23:59:59.999999999' AS TIMESTAMP_NS), 1
) AS result;
```

```text
+-------------------------------+
| result                        |
+-------------------------------+
| 1970-01-01 00:00:00.000000000 |
+-------------------------------+
```

При отрицательном значении delta наносекунды вычитаются:

```sql
SELECT NANOSECONDS_ADD(
    CAST('1970-01-01 00:00:00.000000001' AS TIMESTAMP_NS), -2
) AS result;
```

```text
+-------------------------------+
| result                        |
+-------------------------------+
| 1969-12-31 23:59:59.999999999 |
+-------------------------------+
```

```sql
SELECT NANOSECONDS_ADD(CAST(NULL AS TIMESTAMP_NS), 1) AS result;
```

```text
+--------+
| result |
+--------+
| NULL   |
+--------+
```
