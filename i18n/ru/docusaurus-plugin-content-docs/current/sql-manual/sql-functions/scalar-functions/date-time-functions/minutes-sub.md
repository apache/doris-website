## Описание {#description}

Функция MINUTES_SUB вычитает указанное количество минут из входного значения даты и времени и возвращает новое значение даты и времени. Функция поддерживает обработку типов DATE, DATETIME, TIMESTAMP_NS и TIMESTAMPTZ.

Поведение этой функции соответствует поведению [функции date_sub](./date-sub) и [функции date_sub](https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_date-sub) в MySQL при использовании MINUTE в качестве единицы измерения.

## Синтаксис {#syntax}

```sql
MINUTES_SUB(`<date_or_time_expr>`, `<minutes>`)
```

## Параметры {#parameters}

| Параметр | Описание |
| --------- | ----------- |
| `<date_or_time_expr>` | Входное значение даты и времени типа DATE, DATETIME, TIMESTAMP_NS или TIMESTAMPTZ. Подробнее о форматах даты и времени см. в разделах [преобразование timestamptz](../../../../sql-manual/basic-element/sql-data-types/conversion/timestamptz-conversion), [преобразование datetime](../../../../sql-manual/basic-element/sql-data-types/conversion/datetime-conversion) и [преобразование date](../../../../sql-manual/basic-element/sql-data-types/conversion/date-conversion). |
| `<minutes>` | Количество минут для вычитания, тип BIGINT. Может быть положительным или отрицательным. |

## Возвращаемое значение {#return-value}

Для входного значения `TIMESTAMP_NS` возвращается значение `TIMESTAMP_NS` с фиксированной точностью дробной части секунды в девять знаков. Результаты проверяются на соответствие диапазону возвращаемого типа; для `TIMESTAMP_NS` используется диапазон `[1677-09-21 00:12:43.145224192, 2262-04-11 23:47:16.854775807]`.

Возвращает результат вычитания указанного количества минут `<minutes>` из исходного времени `<datetime_like_type>`. Возвращаемый тип зависит от типа первого параметра:
- Если первый параметр имеет тип TIMESTAMPTZ, возвращается TIMESTAMPTZ.
- Если первый параметр имеет тип DATETIME, возвращается DATETIME.

Особые случаи:
- Если `<minutes>` имеет отрицательное значение, функция работает так же, как прибавление соответствующего количества минут к исходному времени (то есть MINUTES_SUB(date, -n) эквивалентно MINUTES_ADD(date, n)).
- Если входное значение имеет тип DATE (содержит только год, месяц и день), его временная часть по умолчанию равна 00:00:00.
- Если входное значение даты и времени содержит микросекунды, исходная микросекундная точность сохраняется после вычитания минут (например, '2023-01-01 00:01:00.123456' становится '2023-01-01 00:00:00.123456' после вычитания 1 минуты).
- Если результат вычисления выходит за допустимый диапазон типа DATETIME (от 0000-01-01 00:00:00 до 9999-12-31 23:59:59.999999), выбрасывается исключение.
- Если любой из параметров равен NULL, возвращается NULL.

## Примеры {#examples}

```sql
-- Subtract minutes from DATETIME
SELECT MINUTES_SUB('2020-02-02 02:02:02', 1) AS result;
+---------------------+
| result              |
+---------------------+
| 2020-02-02 02:01:02 |
+---------------------+

-- Time with microseconds (preserves precision)
SELECT MINUTES_SUB('2023-07-13 22:38:18.456789', 10) AS result;
+----------------------------+
| result                     |
+----------------------------+
| 2023-07-13 22:28:18.456789 |
+----------------------------+

-- Negative minutes (equivalent to addition)
SELECT MINUTES_SUB('2023-07-13 22:23:18', -5) AS result;
+---------------------+
| result              |
+---------------------+
| 2023-07-13 22:28:18 |
+---------------------+

-- Input is of DATE type (default time 00:00:00)
SELECT MINUTES_SUB('2023-07-13', 30) AS result;
+---------------------+
| result              |
+---------------------+
| 2023-07-12 23:30:00 |
+---------------------+

-- Example of TimeStampTz type, SET time_zone = '+08:00'
SELECT MINUTES_SUB('2025-10-10 11:22:33.123+07:00', 1);
+-------------------------------------------------+
| MINUTES_SUB('2025-10-10 11:22:33.123+07:00', 1) |
+-------------------------------------------------+
| 2025-10-10 12:21:33.123+08:00                   |
+-------------------------------------------------+

-- Any parameter is NULL, returns NULL
SELECT MINUTES_SUB(NULL, 10), MINUTES_SUB('2023-07-13 22:28:18', NULL) AS result;
+-----------------------+--------+
| MINUTES_SUB(NULL, 10) | result |
+-----------------------+--------+
| NULL                  | NULL   |
+-----------------------+--------+


-- Calculation result exceeds datetime range, throws error
SELECT MINUTES_SUB('0000-01-01 00:00:00', 1) AS result;
ERROR 1105 (HY000): errCode = 2, detailMessage = (10.16.10.3)[E-218]Operation minute_add of 0000-01-01 00:00:00, -1 out of range
```
