## Описание {#description}

Функция TIME_FORMAT преобразует значение времени в строку в соответствии с заданной строкой формата. Она поддерживает значения типов `TIME`, `DATETIME`, `TIMESTAMP_NS` и `TIMESTAMPTZ`.

Поведение этой функции соответствует поведению [функции time_format](https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_time-format) в MySQL.

## Синтаксис {#syntax}

```sql
TIME_FORMAT(<time_or_datetime_expr>, <format>)
```

## Параметры {#parameters}

| Параметр                  | Описание                                                                                                                                                   |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<time_or_datetime_expr>` | Допустимое значение типа `TIME`, `DATETIME`, `TIMESTAMP_NS` или `TIMESTAMPTZ`.                                                                                 |
| `<format>`                | Задаёт формат вывода времени в виде значения типа `varchar`. Если строка формата содержит спецификаторы даты или недопустимые спецификаторы формата, возвращается NULL. |

Поддерживаемые спецификаторы формата:

| Спецификатор | Описание                                   |
| --------- | --------------------------------------------- |
| %f        | Микросекунды (000000-999999)                  |
| %n        | Наносекунды (000000000-999999999). Для типов с меньшей точностью недостающие разряды заполняются нулями. |
| %H        | Часы (00-23)                                  |
| %h        | Часы (01-12)                                  |
| %I        | Часы (01-12)                                  |
| %i        | Минуты в числовом виде (00-59)                      |
| %k        | Часы (0-23)                                   |
| %l        | Часы (1-12)                                   |
| %p        | AM или PM                                      |
| %r        | Время в 12-часовом формате (hh:mm:ss с последующим AM или PM) |
| %S        | Секунды (00-59)                               |
| %s        | Секунды (00-59)                               |
| %T        | Время в 24-часовом формате (hh:mm:ss)                      |
| %%        | Обозначает буквальный символ %              |

## Возвращаемое значение {#return-value}

Отформатированная строка времени типа Varchar.

Особые случаи:
- Если `time_or_datetime_expr` или `format` имеет значение NULL, возвращается NULL.
- Если строка `format` содержит спецификаторы формата даты:
    - `%Y`: возвращается `0000`.
    - `%y`, `%m`, `%d`: возвращается `00`.
    - `%c`, `%e`: возвращается `0`.
    - Другие спецификаторы формата даты (`%a`, `%b`, `%D`, `%j`, `%M`, `%u`, `%U`, `%v`, `%V`, `%w`, `%W`, `%x`, `%X`): возвращается NULL.
- Если количество часов в значении времени превышает 23, спецификаторы формата `%H` и `%k` возвращают значение больше 23. Остальные спецификаторы формата часов возвращают значение часов по модулю 12.

## Примеры {#examples}

```sql
SELECT TIME_FORMAT(
    CAST('2024-02-29 12:34:56.123456789' AS TIMESTAMP_NS),
    '%H:%i:%s.%n'
) AS result;
```

```text
+--------------------+
| result             |
+--------------------+
| 12:34:56.123456789 |
+--------------------+
```
