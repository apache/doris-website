## Описание {#description}

Функция `QUARTERS_DIFF` вычисляет количество кварталов между двумя датами. Она принимает два параметра типа даты и возвращает разницу в кварталах, вычитая вторую дату из первой. Разница в кварталах равна разнице в месяцах, делённой на 3 (с округлением к нулю).

## Синтаксис {#syntax}

```sql
QUARTERS_DIFF(<enddate>, <startdate>)
```

## Параметры {#parameters}

| Параметр     | Описание                                                                           |
|---------------|--------------------------------------------------------------------------------------|
| `<enddate>`   | Конечная дата. Поддерживаются типы `DATE`, `DATETIME` и `TIMESTAMP_NS`. |
| `<startdate>` | Начальная дата. Поддерживаются типы `DATE`, `DATETIME` и `TIMESTAMP_NS`. |

## Возвращаемое значение {#return-value}

Возвращает количество кварталов, полученное при вычитании `<startdate>` из `<enddate>`
- Если хотя бы один из параметров `<enddate>` или `<startdate>` имеет значение NULL, возвращает NULL

## Примеры {#examples}

```sql
select QUARTERS_DIFF('2021-03-25', '2020-10-25'), QUARTERS_DIFF('2020-10-25 10:00:00', '2022-12-25 11:00:00');
```

```text
+------------------------------------------+------------------------------------------------------------+
| QUARTERS_DIFF('2021-03-25','2020-10-25') | QUARTERS_DIFF('2020-10-25 10:00:00','2022-12-25 11:00:00') |
+------------------------------------------+------------------------------------------------------------+
|                                        1 |                                                         -8 |
+------------------------------------------+------------------------------------------------------------+
```
