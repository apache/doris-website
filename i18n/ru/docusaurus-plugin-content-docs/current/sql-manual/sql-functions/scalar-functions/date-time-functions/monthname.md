## Описание {#description}

Функция MONTHNAME возвращает название месяца на английском языке, соответствующее значению даты и времени. Функция поддерживает обработку значений типов DATE, DATETIME и TIMESTAMP_NS и возвращает полное название месяца на английском языке (от January до December).

Язык результата можно задать с помощью переменной сеанса [lc_time_names](#appendix-lc_time_names-may-be-set-to-any-of-the-following-locale-valuescase-insensitive). По умолчанию она имеет значение `en_US`, то есть результат выводится на английском языке.

Эта функция работает так же, как [функция monthname](https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_monthname) в MySQL.

## Синтаксис {#syntax}

```sql
MONTHNAME(`<date_or_time_expr>`)
```

## Параметры {#parameters}

| Параметр | Описание |
| --------- | ----------- |
| `<date_or_time_expr>` | Входное значение даты и времени. Поддерживаются типы DATE/DATETIME/TIMESTAMP_NS. Подробные сведения о форматах даты и времени см. в разделах [Преобразование даты и времени](../../../../sql-manual/basic-element/sql-data-types/conversion/datetime-conversion) и [Преобразование даты](../../../../sql-manual/basic-element/sql-data-types/conversion/date-conversion) |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее название месяца на английском языке:
- Возможные возвращаемые значения: January, February, March, April, May, June, July, August, September, October, November, December
- Если входное значение равно NULL, возвращает NULL
- Первая буква возвращаемого значения — заглавная, остальные — строчные

## Примеры {#examples}

```sql
-- Get English month name from DATE type
SELECT MONTHNAME('2008-02-03') AS result;
+----------+
| result   |
+----------+
| February |
+----------+

-- Get English month name from DATETIME type
SELECT MONTHNAME('2023-07-13 22:28:18') AS result;
+---------+
| result  |
+---------+
| July    |
+---------+

-- Returns NULL when input is NULL
SELECT MONTHNAME(NULL) AS result;
+--------+
| result |
+--------+
| NULL   |
+--------+

-- Control the output language by setting `lc_time_names`
SET lc_time_names='zh_CN';
SELECT MONTHNAME('2023-07-13 22:28:18') AS result;
+--------+
| result |
+--------+
| 七月   |
+--------+

SET lc_time_names='AR_sa';
SELECT MONTHNAME('2023-07-13 22:28:18') AS result;
+------------+
| result     |
+------------+
| يوليو      |
+------------+
```
