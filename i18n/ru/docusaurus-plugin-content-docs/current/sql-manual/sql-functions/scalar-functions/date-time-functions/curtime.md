## Описание {#description}

Получает текущее время и возвращает его в виде значения типа TIME.

Поведение этой функции соответствует [функции curtime](https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_curtime) в MySQL.

## Псевдонимы {#aliases}

- CURRENT_TIME

## Синтаксис {#syntax}

```sql
CURTIME([<precision>])
```

## Параметры {#parameters}

| Параметр      | Описание                                                                                                                                     |
|---------------|----------------------------------------------------------------------------------------------------------------------------------------------|
| `<precision>` | Необязательный параметр, задающий точность дробной части секунд возвращаемого значения. Должен быть константой в диапазоне от 0 до 6. Значение по умолчанию равно 0, что означает отсутствие дробной части секунд. |

## Возвращаемое значение {#return-value}

Возвращает текущее время в виде значения типа TIME.

## Примеры {#examples}

```sql
mysql> select curtime();

+----------------+
| curtime()      |
+----------------+
| 15:25:47       |
+----------------+
```

```sql
mysql> select curtime(0);
+------------+
| curtime(0) |
+------------+
| 13:15:27   |
+------------+
```

```sql
mysql> select curtime(4);
+---------------+
| curtime(4)    |
+---------------+
| 15:31:03.8958 |
+---------------+
```

```sql
mysql> select curtime(7);
ERROR 1105 (HY000): errCode = 2, detailMessage = The precision must be between 0 and 6
```
