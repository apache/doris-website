## Описание {#description}

Эта функция эквивалентна `CAST(<STRING> TO DATE)`.

Функция TO_DATE используется для преобразования значений даты и времени в тип DATE (содержащий только год, месяц и день в формате YYYY-MM-DD). Функция автоматически игнорирует временную часть (часы, минуты, секунды, микросекунды) входного значения и извлекает для преобразования только дату.

## Синтаксис {#syntax}
```sql
TO_DATE(`<datetime_value>`)
```

## Параметры {#parameters}
| Параметр | Описание |
|-----------|-------------|
| `<datetime_value>` | Значение типа `DATETIME` или `TIMESTAMP_NS`. Поля времени и долей секунды игнорируются. |

## Возвращаемое значение {#return-value}

Возвращает значение типа DATE.

## Примеры {#examples}

```sql
-- Extract the date part from datetime
select to_date("2020-02-02 00:00:00");

+--------------------------------+
| to_date('2020-02-02 00:00:00') |
+--------------------------------+
| 2020-02-02                     |
+--------------------------------+

-- Input date, returns itself
select to_date("2020-02-02");
+-----------------------+
| to_date("2020-02-02") |
+-----------------------+
| 2020-02-02            |
+-----------------------+

-- Input NULL, returns NULL
SELECT TO_DATE(NULL) AS result;
+--------+
| result |
+--------+
| NULL   |
+--------+
```
