## Описание {#description}

Функция `MILLISECONDS_ADD` прибавляет указанное количество миллисекунд к значению `DATETIME`, `TIMESTAMP_NS` или `TIMESTAMPTZ` и возвращает результат того же типа.

## Синтаксис {#syntax}

```sql
MILLISECONDS_ADD(`<datetime>`, `<delta>`)
```

## Параметры {#parameters}

| Параметр    | Описание                                                                                   |
|--------------|-----------------------------------------------------------------------------------------------|
| `<datetime>` | Входное значение даты и времени. Поддерживаются типы `DATETIME`, `TIMESTAMP_NS` и `TIMESTAMPTZ`. Подробнее о форматах см. [преобразование даты и времени](../../../../sql-manual/basic-element/sql-data-types/conversion/datetime-conversion), [преобразование TIMESTAMP_NS](../../../basic-element/sql-data-types/conversion/timestamp-ns-conversion.md) и [преобразование TIMESTAMPTZ](../../../../sql-manual/basic-element/sql-data-types/conversion/timestamptz-conversion). |
| `<delta>`    | Количество миллисекунд для прибавления, тип — `BIGINT`. 1 секунда = 1,000 миллисекунд = 1,000,000 микросекунд. |

## Возвращаемое значение {#return-value}

Для входного значения типа `TIMESTAMP_NS` возвращается значение типа `TIMESTAMP_NS` с фиксированной точностью дробной части секунды до девяти знаков. Результаты проверяются на соответствие диапазону возвращаемого типа; для `TIMESTAMP_NS` используется диапазон `[1677-09-21 00:12:43.145224192, 2262-04-11 23:47:16.854775807]`.

Возвращает значение того же типа даты и времени, что и входное значение, представляющее результат прибавления указанного количества миллисекунд к исходному времени.

- Если `<delta>` имеет отрицательное значение, функция вычитает соответствующее количество миллисекунд из исходного времени (то есть `MILLISECONDS_ADD(basetime, -n)` эквивалентно `MILLISECONDS_SUB(basetime, n)`).
- Если входное значение имеет тип `DATE` (содержит только год, месяц и день), временная часть по умолчанию устанавливается в `00:00:00.000`.
- Если результат вычисления выходит за допустимый диапазон типа `DATETIME` (от `0000-01-01 00:00:00` до `9999-12-31 23:59:59.999999`), возникает исключение.
- Если любой из параметров равен `NULL`, функция возвращает `NULL`.

## Примеры {#examples}

```sql
-- Add one millisecond
SELECT MILLISECONDS_ADD('2023-09-08 16:02:08.435123', 1);

+---------------------------------------------------+
| MILLISECONDS_ADD('2023-09-08 16:02:08.435123', 1) |
+---------------------------------------------------+
| 2023-09-08 16:02:08.436123                        |
+---------------------------------------------------+

-- Negative milliseconds, subtracts the corresponding milliseconds from the datetime
SELECT MILLISECONDS_ADD('2023-05-01 10:00:00.800', -300);
+---------------------------------------------------+
| MILLISECONDS_ADD('2023-05-01 10:00:00.800', -300) |
+---------------------------------------------------+
| 2023-05-01 10:00:00.500000                        |
+---------------------------------------------------+

-- Input is of DATE type (default time is 00:00:00.000)
SELECT MILLISECONDS_ADD('2023-01-01', 1500);
+--------------------------------------+
| MILLISECONDS_ADD('2023-01-01', 1500) |
+--------------------------------------+
| 2023-01-01 00:00:01.500000           |
+--------------------------------------+

-- Calculation result exceeds the datetime range, throws an exception
SELECT MILLISECONDS_ADD('9999-12-31 23:59:59.999', 2000) AS after_add;
ERROR 1105 (HY000): errCode = 2, detailMessage = (10.16.10.3)[E-218]Operation milliseconds_add of 9999-12-31 23:59:59.999000, 2000 out of range

-- Any parameter is NULL, returns NULL
SELECT MILLISECONDS_ADD('2023-10-01 12:00:00.500', NULL) AS after_add;
+-----------+
| after_add |
+-----------+
| NULL      |
+-----------+

```
