## Описание {#description}

Преобразует значение даты и времени из указанного часового пояса from_tz в указанный часовой пояс to_tz и возвращает результат. Сведения о настройках часовых поясов см. в документации [Управление часовыми поясами](../../../../admin-manual/cluster-management/time-zone).

Эта функция соответствует [функции convert_tz](https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_convert_tz) в MySQL.

## Синтаксис {#syntax}

```sql
CONVERT_TZ(<dt>, <from_tz>, <to_tz>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- | 
| `<dt>` | Значение для преобразования. Поддерживаются `DATE`, `DATETIME` и `TIMESTAMP_NS`. |
| `<from_tz>` | Исходный часовой пояс значения dt. Этот параметр имеет тип `varchar` |
| `<to_tz>` | Целевой часовой пояс для преобразования. Этот параметр имеет тип `varchar` |

## Возвращаемое значение {#return-value}

При входном значении типа `TIMESTAMP_NS` возвращается значение типа `TIMESTAMP_NS` с фиксированной точностью дробной части секунды до девяти знаков. Результаты проверяются на соответствие диапазону возвращаемого типа; для `TIMESTAMP_NS` используется диапазон `[1677-09-21 00:12:43.145224192, 2262-04-11 23:47:16.854775807]`.

- Преобразованное значение типа datetime
- Число знаков дробной части результата совпадает с числом знаков дробной части входного значения
  - Если входное значение datetime не содержит дробной части, результат также не содержит дробной части
  - Если входное значение содержит дробную часть, результат имеет то же число знаков дробной части

Особые случаи:
- Если какой-либо параметр равен NULL, возвращается NULL.
- Если указан недопустимый часовой пояс, возвращается ошибка. Сведения о настройках часовых поясов см. в разделе [Управление часовыми поясами](../../../../admin-manual/cluster-management/time-zone).
- Для входного значения типа date время автоматически устанавливается в 00:00:00

## Примеры {#examples}


```sql
-- Convert time from Shanghai, China to Los Angeles, USA
mysql> select CONVERT_TZ(CAST('2019-08-01 13:21:03' AS DATETIME), 'Asia/Shanghai', 'America/Los_Angeles');
+---------------------------------------------------------------------------+
| CONVERT_TZ('2019-08-01 13:21:03', 'Asia/Shanghai', 'America/Los_Angeles') |
+---------------------------------------------------------------------------+
| 2019-07-31 22:21:03                                                       |
+---------------------------------------------------------------------------+

-- Convert the time '2019-08-01 13:21:03' in UTC+8 (+08:00) to Los Angeles, USA
mysql> select CONVERT_TZ(CAST('2019-08-01 13:21:03' AS DATETIME), '+08:00', 'America/Los_Angeles');

+--------------------------------------------------------------------+
| convert_tz('2019-08-01 13:21:03', '+08:00', 'America/Los_Angeles') |
+--------------------------------------------------------------------+
| 2019-07-31 22:21:03                                                |
+--------------------------------------------------------------------+

-- For date type input,return datetime type value, the time part is automatically converted to 00:00:00
mysql> select CONVERT_TZ(CAST('2019-08-01 13:21:03' AS DATE), 'Asia/Shanghai', 'America/Los_Angeles');
+-------------------------------------------------------------------------------------------+
| CONVERT_TZ(CAST('2019-08-01 13:21:03' AS DATE), 'Asia/Shanghai', 'America/Los_Angeles')   |
+-------------------------------------------------------------------------------------------+
| 2019-07-31 09:00:00                                                                       |
+-------------------------------------------------------------------------------------------+

-- When conversion time is NULL, output NULL
mysql> select CONVERT_TZ(NULL, 'Asia/Shanghai', 'America/New_York');
+-------------------------------------------------------+
| CONVERT_TZ(NULL, 'Asia/Shanghai', 'America/New_York') |
+-------------------------------------------------------+
| NULL                                                  |
+-------------------------------------------------------+

-- When any time zone is NULL, return NULL
mysql> select CONVERT_TZ('2019-08-01 13:21:03', NULL, 'America/Los_Angeles');
+----------------------------------------------------------------+
| CONVERT_TZ('2019-08-01 13:21:03', NULL, 'America/Los_Angeles') |
+----------------------------------------------------------------+
| NULL                                                           |
+----------------------------------------------------------------+

mysql> select CONVERT_TZ('2019-08-01 13:21:03', '+08:00', NULL);
+---------------------------------------------------+
| CONVERT_TZ('2019-08-01 13:21:03', '+08:00', NULL) |
+---------------------------------------------------+
| NULL                                              |
+---------------------------------------------------+

-- Time with scale
mysql> select CONVERT_TZ('2019-08-01 13:21:03.636', '+08:00', 'America/Los_Angeles');
+------------------------------------------------------------------------+
| CONVERT_TZ('2019-08-01 13:21:03.636', '+08:00', 'America/Los_Angeles') |
+------------------------------------------------------------------------+
| 2019-07-31 22:21:03.636                                                |
+------------------------------------------------------------------------+

-- When the input time zone is invalid, an error is returned.
select CONVERT_TZ(CAST('2019-08-01 13:21:03' AS DATETIME), '+08:00', 'America/Los_Anges');
ERROR 1105 (HY000): errCode = 2, detailMessage = (10.16.10.3)[INVALID_ARGUMENT][E33] Operation convert_tz invalid timezone: America/Los_Anges
```
