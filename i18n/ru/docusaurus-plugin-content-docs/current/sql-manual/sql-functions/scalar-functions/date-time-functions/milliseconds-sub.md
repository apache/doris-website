## Описание {#description}

Функция `MILLISECONDS_SUB` вычитает указанное количество миллисекунд из значения типа `DATETIME`, `TIMESTAMP_NS` или `TIMESTAMPTZ` и возвращает результат того же типа.

## Синтаксис {#syntax}

```sql
MILLISECONDS_SUB(`<datetime>`, `<delta>`)
```

## Параметры {#parameters}

| Параметр     | Описание                                                                                      |
|--------------|-----------------------------------------------------------------------------------------------|
| `<datetime>` | Входное значение даты и времени типа `DATETIME`, `TIMESTAMP_NS` или `TIMESTAMPTZ`. Подробнее о форматах см. в разделах [Преобразование даты и времени](../../../../sql-manual/basic-element/sql-data-types/conversion/datetime-conversion), [Преобразование TIMESTAMP_NS](../../../basic-element/sql-data-types/conversion/timestamp-ns-conversion.md) и [Преобразование TIMESTAMPTZ](../../../../sql-manual/basic-element/sql-data-types/conversion/timestamptz-conversion). |
| `<delta>`    | Количество миллисекунд для вычитания, тип — `BIGINT`. 1 секунда = 1,000 миллисекунд = 1,000,000 микросекунд. |

## Возвращаемое значение {#return-value}

Для входного значения типа `TIMESTAMP_NS` возвращается значение типа `TIMESTAMP_NS` с фиксированной точностью дробной части секунды до девяти знаков. Результаты проверяются на соответствие диапазону возвращаемого типа; для `TIMESTAMP_NS` используется диапазон `[1677-09-21 00:12:43.145224192, 2262-04-11 23:47:16.854775807]`.

Возвращает значение того же временного типа, что и входное значение, представляющее результат вычитания указанного количества миллисекунд из исходного времени.

- Если `<delta>` отрицателен, функция действует так же, как прибавление соответствующего количества миллисекунд к исходному времени.
- Если входное значение имеет тип `DATE` (содержит только год, месяц и день), время по умолчанию устанавливается в `00:00:00.000`.
- Если результат вычисления выходит за допустимый диапазон типа `DATETIME` (от `0000-01-01 00:00:00` до `9999-12-31 23:59:59.999999`), возникает исключение.
- Если любой из параметров равен `NULL`, функция возвращает `NULL`.

## Примеры {#examples}

```sql
-- Subtract 1 millisecond
SELECT MILLISECONDS_SUB('2023-09-08 16:02:08.435123', 1);
+---------------------------------------------------+
| MILLISECONDS_SUB('2023-09-08 16:02:08.435123', 1) |
+---------------------------------------------------+
| 2023-09-08 16:02:08.434123                        |
+---------------------------------------------------+

-- Negative delta (equivalent to addition)
SELECT MILLISECONDS_SUB('2023-05-01 10:00:00.200', -300);
+---------------------------------------------------+
| MILLISECONDS_SUB('2023-05-01 10:00:00.200', -300) |
+---------------------------------------------------+
| 2023-05-01 10:00:00.500000                        |
+---------------------------------------------------+

-- Input is of DATE type (default time is 00:00:00.000)
SELECT MILLISECONDS_SUB('2023-01-01', 1500);
+--------------------------------------+
| MILLISECONDS_SUB('2023-01-01', 1500) |
+--------------------------------------+
| 2022-12-31 23:59:58.500000           |
+--------------------------------------+

-- Calculation result exceeds the datetime range, throws an exception
SELECT MILLISECONDS_SUB('0000-01-01',-1500);
ERROR 1105 (HY000): errCode = 2, detailMessage = (10.16.10.3)[E-218]Operation milliseconds_add of 0000-01-01 00:00:00, -1500 out of range

-- Any parameter is NULL, returns NULL
SELECT MILLISECONDS_SUB(NULL, 100), MILLISECONDS_SUB('2023-01-01', NULL) AS after_sub;
+------------------------------+----------------------------+
| milliseconds_sub(NULL, 100)  | after_sub                  |
+------------------------------+----------------------------+
| NULL                         | NULL                       |
+------------------------------+----------------------------+

```
