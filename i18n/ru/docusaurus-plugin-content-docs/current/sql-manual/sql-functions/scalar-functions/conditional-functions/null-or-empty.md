## Описание {#description}

Функция `null_or_empty` проверяет, является ли заданное значение NULL или пустым. Если входное значение NULL или пустое, функция возвращает true; в противном случае возвращает false.

## Синтаксис {#syntax}

```sql
NULL_OR_EMPTY (<str>)
```

## Параметры {#parameters}
- `<str>`: Тип String; строка, которую нужно проверить на NULL или пустоту.

## Возвращаемое значение {#return-value}
Возвращает true, если строка пустая или равна NULL; в противном случае возвращает false.

## Примеры {#examples}
1. Пример 1
    ```sql
    select null_or_empty(null), null_or_empty(""), null_or_empty(" ");
    ```
    ```text
    +---------------------+-------------------+--------------------+
    | null_or_empty(null) | null_or_empty("") | null_or_empty(" ") |
    +---------------------+-------------------+--------------------+
    |                   1 |                 1 |                  0 |
    +---------------------+-------------------+--------------------+
    ```
