## Описание {#description}

Сравнивает несколько выражений и возвращает наименьшее из их значений. Если хотя бы один аргумент равен `NULL`, возвращает `NULL`.

## Синтаксис {#syntax}

```sql
LEAST(<expr> [, ...])
```

## Параметры {#parameters}
### Обязательный параметр {#required-parameter}
- `<expr>`: Поддерживает типы `TINYINT`, `SMALLINT`, `INT`, `BIGINT`, `LARGEINT`, `FLOAT`, `DOUBLE`, `STRING`, `DATETIME`, `TIMESTAMP_NS` и `DECIMAL`.
### Необязательные параметры {#optional-parameters}
- Поддерживается несколько аргументов.

## Возвращаемое значение {#return-value}
- Возвращает наименьшее из значений заданных выражений.
- Если хотя бы один аргумент равен `NULL`, возвращает `NULL`.

## Примечания по использованию {#usage-notes}
1. Рекомендуется передавать аргументы одного типа. Если типы аргументов различаются, функция попытается привести их к одному типу. Правила преобразования см. в разделе: [Преобразование типов](../../../basic-element/sql-data-types/conversion/overview.md)
2. Если хотя бы один аргумент равен NULL, результат будет NULL.


## Примеры {#examples}
1. Пример 1
    ```sql
    SELECT LEAST(-1, 0, 5, 8);
    ```
    ```text
    +--------------------+
    | LEAST(-1, 0, 5, 8) |
    +--------------------+
    |                 -1 |
    +--------------------+
    ```
2. Аргумент NULL
    ```sql
    SELECT LEAST(-1, 0, 5, NULL);
    ```
    ```text
    +-----------------------+
    | LEAST(-1, 0, 5, NULL) |
    +-----------------------+
    |                  NULL |
    +-----------------------+
    ```
3. Преобразование типов
    ```sql
    SELECT LEAST(6, 9.29, 7);
    ```
    ```text
    +-------------------+
    | LEAST(6, 9.29, 7) |
    +-------------------+
    |              6.00 |
    +-------------------+
    ```
    > Первый аргумент "6" преобразуется в тип Decimal.
4. Тип даты
    ```sql
    SELECT LEAST('2022-02-26 20:02:11', '2020-01-23 20:02:11', '2020-06-22 20:02:11');
    ```
    ```text
    +----------------------------------------------------------------------------+
    | LEAST('2022-02-26 20:02:11', '2020-01-23 20:02:11', '2020-06-22 20:02:11') |
    +----------------------------------------------------------------------------+
    | 2020-01-23 20:02:11                                                        |
    +----------------------------------------------------------------------------+
    ```
