## Описание {#description}

Сравнивает несколько выражений и возвращает наибольшее из их значений. Если хотя бы один аргумент равен `NULL`, возвращает `NULL`.

## Синтаксис {#syntax}

```sql
GREATEST(<expr> [, ...])
```

## Параметры {#parameters}
### Обязательный параметр {#required-parameter}
- `<expr>`: Поддерживает типы `TINYINT`, `SMALLINT`, `INT`, `BIGINT`, `LARGEINT`, `FLOAT`, `DOUBLE`, `STRING`, `DATETIME`, `TIMESTAMP_NS` и `DECIMAL`.
### Необязательные параметры {#optional-parameters}
- Поддерживается передача нескольких аргументов.

## Возвращаемое значение {#return-value}
- Возвращает наибольшее значение среди заданных выражений.
- Если хотя бы один аргумент равен `NULL`, возвращает `NULL`.

## Примечания по использованию {#usage-notes}
1. Рекомендуется передавать аргументы одного типа. Если типы аргументов различаются, функция попытается привести их к одному типу. Правила преобразования см. в разделе [Преобразование типов](../../../basic-element/sql-data-types/conversion/overview.md).
2. Если хотя бы один аргумент равен NULL, результатом будет NULL.

## Примеры {#examples}
1. Пример 1
    ```sql
    SELECT GREATEST(-1, 0, 5, 8);
    ```
    ```text
    +-----------------------+
    | GREATEST(-1, 0, 5, 8) |
    +-----------------------+
    |                     8 |
    +-----------------------+
    ```
2. Аргумент NULL
    ```sql
    SELECT GREATEST(-1, 0, 5, NULL);
    ```
    ```text
    +--------------------------+
    | GREATEST(-1, 0, 5, NULL) |
    +--------------------------+
    | NULL                     |
    +--------------------------+
    ```
3. Преобразование типов
    ```sql
    SELECT GREATEST(6, 4.29, 7);
    ```
    ```text
    +----------------------+
    | GREATEST(6, 4.29, 7) |
    +----------------------+
    |                 7.00 |
    +----------------------+
    ```
    > Третий аргумент "7" преобразуется в тип Decimal.
4. Тип даты
    ```sql
    SELECT GREATEST('2022-02-26 20:02:11', '2020-01-23 20:02:11', '2020-06-22 20:02:11');
    ```
    ```text
    +-------------------------------------------------------------------------------+
    | GREATEST('2022-02-26 20:02:11', '2020-01-23 20:02:11', '2020-06-22 20:02:11') |
    +-------------------------------------------------------------------------------+
    | 2022-02-26 20:02:11                                                           |
    +-------------------------------------------------------------------------------+
    ```
