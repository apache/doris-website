## Описание {#description}

Вычисляет выражения в списке аргументов слева направо и возвращает первое из них со значением, отличным от NULL. Если все аргументы равны NULL, возвращает NULL.

## Синтаксис {#syntax}

```sql
COALESCE( <expr1> [ , ... , <exprN> ] )
```

## Параметры {#parameters}
### Обязательный параметр {#required-parameter}
- `<expr1>`: Выражение любого типа.
### Переменное число параметров {#variadic-parameters}
- Функция `COALESCE` поддерживает переменное число параметров.

## Возвращаемое значение {#return-value}
Возвращает первое выражение в списке аргументов со значением, отличным от NULL. Если все аргументы равны NULL, возвращает NULL.

## Примечания по использованию {#usage-notes}
1. Типы аргументов должны по возможности совпадать.
2. Если типы аргументов различаются, функция попытается привести их к одному типу. Правила преобразования см. в разделе [Преобразование типов](../../../basic-element/sql-data-types/conversion/overview.md)
3. В настоящее время в качестве аргументов поддерживаются только следующие типы:
    * Строковые типы (String/VARCHAR/CHAR)
    * Логический тип (Boolean)
    * Числовые типы (TinyInt, SmallInt, Int, BigInt, LargeInt, Float, Double, Decimal)
    * Типы даты и времени (Date, DateTime, TimestampNs)
    * Тип Bitmap (Bitmap)
    * Полуструктурированные типы (JSON, Array, MAP, Struct)

## Примеры {#examples}
1. Преобразование типов аргументов
    ```sql
    select coalesce(null, 2, 1.234);
    ```
    ```text
    +--------------------------+
    | coalesce(null, 2, 1.234) |
    +--------------------------+
    |                    2.000 |
    +--------------------------+
    ```
    > Поскольку третий аргумент "1.234" имеет тип Decimal, аргумент "2" преобразуется в тип Decimal.

2. Все аргументы равны NULL
    ```sql
    select coalesce(null, null, null);
    ```
    ```text
    +----------------------------+
    | coalesce(null, null, null) |
    +----------------------------+
    | NULL                       |
    +----------------------------+
    ```
