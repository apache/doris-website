## Описание {#description}

Функция `not_null_or_empty` проверяет, что заданное значение не равно NULL и не является пустым. Если входное значение не равно NULL и не является пустым, функция возвращает true; в противном случае возвращает false.

## Синтаксис {#syntax}

```sql
NOT_NULL_OR_EMPTY (<str>)
```

## Параметры {#parameters}
- `<str>`: Строковый тип, строка для проверки на NULL или пустое значение.

## Возвращаемое значение {#return-value}
Возвращает false, если строка пустая или равна NULL; в противном случае возвращает true.

## Примеры {#examples}
1. Пример 1
    ```sql
    select not_null_or_empty(null), not_null_or_empty(""), not_null_or_empty(" ");
    ```
    ```text
    +-------------------------+-----------------------+------------------------+
    | not_null_or_empty(null) | not_null_or_empty("") | not_null_or_empty(" ") |
    +-------------------------+-----------------------+------------------------+
    |                       0 |                     0 |                      1 |
    +-------------------------+-----------------------+------------------------+
    ```
