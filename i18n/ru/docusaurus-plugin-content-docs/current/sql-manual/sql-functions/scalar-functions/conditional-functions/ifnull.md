## Описание {#description}

Если значение `<expr1>` не равно `NULL`, возвращает `<expr1>`; в противном случае возвращает `<expr2>`.

## Псевдоним {#alias}

- NVL

## Синтаксис {#syntax}

```sql
IFNULL(<expr1>, <expr2>)
```

## Параметры {#parameters}
- `<expr1>`: Выражение для проверки на `NULL`.
- `<expr2>`: Значение, возвращаемое, если `<expr1>` равно `NULL`.

## Возвращаемое значение {#return-value}
- Если `<expr1>` не равно `NULL`, возвращает `<expr1>`.
- В противном случае возвращает `<expr2>`.

## Примеры {#examples}
1. Пример 1
    ```sql
    SELECT IFNULL(1, 0);
    ```
    ```text
    +--------------+
    | IFNULL(1, 0) |
    +--------------+
    |            1 |
    +--------------+
    ```
2. Пример 2
    ```sql
    SELECT IFNULL(NULL, 10);
    ```
    ```text
    +------------------+
    | IFNULL(NULL, 10) |
    +------------------+
    |               10 |
    +------------------+
    ```
3. Оба аргумента равны NULL
    ```sql
    SELECT IFNULL(NULL, NULL);
    ```
    ```text
    +--------------------+
    | IFNULL(NULL, NULL) |
    +--------------------+
    |               NULL |
    +--------------------+
    ```
