## Описание {#description}

Преобразует кодировку столбца в кодировку указанного целевого набора символов. Эта функция обычно используется в предложении ORDER BY, чтобы значения в столбцах, содержащих китайские иероглифы, сортировались по пиньиню. В настоящее время поддерживается только преобразование в `'gbk'`.

## Синтаксис {#syntax}

```sql
CONVERT_TO(<column>, <character>)
```

## Параметры {#parameters}

| Параметры      | Описание                                                                 |
|----------------|-----------------------------------------------------------------------------|
| `<column>`     | Столбец типа VARCHAR, кодировку которого необходимо преобразовать.                       |
| `<character>`  | Целевой набор символов. В настоящее время поддерживается только `'gbk'`.             |

## Возвращаемое значение {#return-value}

Возвращает значение VARCHAR с преобразованной кодировкой, обеспечивая правильную сортировку по пиньиню при использовании в предложении ORDER BY.
