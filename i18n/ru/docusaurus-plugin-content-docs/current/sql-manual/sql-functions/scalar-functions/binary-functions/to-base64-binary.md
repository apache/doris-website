## Описание {#description}

Функция TO_BASE64_BINARY преобразует входную двоичную строку в формат кодирования Base64. Кодирование Base64 преобразует произвольные двоичные данные в строку, состоящую из 64 символов.

## Синтаксис {#syntax}

```sql
TO_BASE64_BINARY(<bin>)
```

## Параметры {#parameters}
| Параметр | Описание                                    |
| --------- | ---------------------------------------------- |
| `<bin>` | Двоичные данные для кодирования в Base64. Тип: VARBINARY |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее строку в кодировке Base64.

Особые случаи:
- Если входное значение равно NULL, возвращает NULL
- Если входное значение — пустой VARBINARY (ноль байтов), возвращает пустую строку

## Примеры {#examples}

1. Кодирование одного символа
```sql
SELECT to_base64_binary(x'12');
```
```text
+-------------------------+
| to_base64_binary(x'12') |
+-------------------------+
| Eg==                    |
+-------------------------+
```

2. Кодирование нескольких символов
```sql
SELECT to_base64_binary(x'234AAA');
```
```text
+-----------------------------+
| to_base64_binary(x'234AAA') |
+-----------------------------+
| I0qq                        |
+-----------------------------+
```
