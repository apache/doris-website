## Описание {#description}

Вычисляет 32-битное хеш-значение murmur3.

- Примечание: для вычисления хеш-значений рекомендуется использовать `xxhash_32` вместо `murmur_hash3_32`.

## Синтаксис {#syntax}

```sql
MURMUR_HASH3_32( <str> [ , <str> ... ] )
```

## Параметры {#parameters}

| параметр | описание |
|-----------| -- |
| `<str>`   | 32-битное хеш-значение murmur3, которое необходимо вычислить |

## Возвращаемое значение {#return-value}

Возвращает 32-битный хеш murmur3 входной строки.

-Если параметр равен NULL, возвращает NULL

## Примеры {#examples}

```sql
select murmur_hash3_32(null), murmur_hash3_32("hello"), murmur_hash3_32("hello", "world");
```

```text
+-----------------------+--------------------------+-----------------------------------+
| murmur_hash3_32(NULL) | murmur_hash3_32('hello') | murmur_hash3_32('hello', 'world') |
+-----------------------+--------------------------+-----------------------------------+
|                  NULL |               1321743225 |                         984713481 |
+-----------------------+--------------------------+-----------------------------------+
```
