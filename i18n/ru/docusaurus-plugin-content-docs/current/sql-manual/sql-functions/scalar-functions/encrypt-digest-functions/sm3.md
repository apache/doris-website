## Описание {#description}

Вычисление 256-битного хеша SM3

## Синтаксис {#syntax}

```sql
SM3( <input> )
```

## Параметры {#parameters}


| параметр | описание |
|-----------|-------------|
| `<input>`   | Значение, для которого требуется вычислить хеш sm3. Поддерживаются строковый и двоичный типы.  |

## Возвращаемое значение {#return-value}
Возвращает хеш sm3 входной строки

## Примеры {#examples}

```sql
-- vb (VarBinary) and vc (VarChar) used the same string during insertion.
SELECT * FROM mysql_catalog.binary_test.binary_test;
```

```text
|    2 | 0x78797A   | xyz  |
|    3 | NULL       | NULL |
+------+------------+------+
```
