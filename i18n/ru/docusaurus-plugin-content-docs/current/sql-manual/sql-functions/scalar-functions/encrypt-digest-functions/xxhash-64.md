## Описание {#description}

Вычисляет 64-битное значение xxhash для входной строки или двоичных данных.

- Примечание: тестирование показало, что производительность `xxhash_64` примерно вдвое выше, чем у `murmur_hash3_64`, поэтому при вычислении хеш-значений рекомендуется использовать `xxhash_64` вместо `murmur_hash3_64`.

## Синтаксис {#syntax}

```sql
XXHASH_64( <input> [ , <input> ... ] )
```

## Параметры {#parameters}

| параметр | описание      |
|-----------|------------------|
| `<input>`   | Значение, для которого вычисляется 64-битный хеш xxhash; допускаются строковый и двоичный типы |

## Возвращаемое значение {#return-value}

Возвращает 64-битное значение xxhash для входной строки.

## Примеры {#examples}

```sql
select xxhash_64(NULL), xxhash_64("hello"), xxhash_64("hello", "world");
```

```text
+-----------------+----------------------+-----------------------------+
| xxhash_64(NULL) | xxhash_64('hello')   | xxhash_64('hello', 'world') |
+-----------------+----------------------+-----------------------------+
|            NULL | -7685981735718036227 |         7001965798170371843 |
+-----------------+----------------------+-----------------------------+
```

```sql
-- vb (VarBinary) and vc (VarChar) used the same string during insertion.
SELECT * FROM mysql_catalog.binary_test.binary_test;
```
```text
+------+------------+------+
| id   | vb         | vc   |
+------+------------+------+
|    1 | 0x616263   | abc  |
|    2 | 0x78797A   | xyz  |
|    3 | NULL       | NULL |
+------+------------+------+
```
```sql

```

```text
| 7095089596068863775 | 7095089596068863775 |
|                NULL |                NULL |
+---------------------+---------------------+
```
