## Описание {#description}

Вычисляет количество элементов в Map

## Синтаксис {#syntax}

```sql
MAP_SIZE(<map>)
```

## Параметры {#parameters}
- `<map>` — содержимое входного Map типа [`MAP`](../../../basic-element/sql-data-types/semi-structured/MAP.md).
## Возвращаемое значение {#return-value}
Возвращает количество элементов в Map

## Примечания по использованию {#usage-notes}
1. Ключи и значения NULL также учитываются.
2. Если параметр равен NULL, возвращается NULL.

## Примеры {#examples}
1. Обычные параметры
    ```sql
    select map_size(map()), map_size(map(1, "100", 0.1, 2, null, null));
    ```

    ```text
    +-----------------+---------------------------------------------+
    | map_size(map()) | map_size(map(1, "100", 0.1, 2, null, null)) |
    +-----------------+---------------------------------------------+
    |               0 |                                           3 |
    +-----------------+---------------------------------------------+
    ```
2. Параметры NULL
    ```sql
    select map_size(NULL);
    ```
    ```text
    +----------------+
    | map_size(NULL) |
    +----------------+
    |           NULL |
    +----------------+
    ```
