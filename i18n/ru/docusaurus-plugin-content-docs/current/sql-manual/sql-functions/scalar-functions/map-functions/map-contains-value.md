## Описание {#description}

Определяет, содержит ли заданный `map` указанное значение `value`

## Синтаксис {#syntax}

```sql
MAP_CONTAINS_VALUE(<map>, <value>)
```

## Параметры {#parameters}
- `<map>` — содержимое входного отображения типа [`MAP`](../../../basic-element/sql-data-types/semi-structured/MAP.md).
- `<value>` — искомое значение; поддерживаются различные типы.

## Возвращаемое значение {#return-value}
Определяет, содержит ли заданный `map` указанное значение `value`. Возвращает 1, если значение найдено, и 0, если не найдено.

## Примечания по использованию {#usage-notes}
1. Если параметр `<map>` равен NULL, возвращает NULL.
2. `<value>` может быть NULL. Для сравнения с NULL используется `null-safe-equal`, то есть NULL считается равным NULL.

## Примеры {#examples}
1. Обычные параметры
    ```sql
    select map_contains_value(map(1, "100", 0.1, 2), 100), map_contains_value(map(1, "100", 0.1, 2), 101);
    ```
    ```text
    +------------------------------------------------+------------------------------------------------+
    | map_contains_value(map(1, "100", 0.1, 2), 100) | map_contains_value(map(1, "100", 0.1, 2), 101) |
    +------------------------------------------------+------------------------------------------------+
    |                                              1 |                                              0 |
    +------------------------------------------------+------------------------------------------------+
    ```
2. Параметры NULL
    ```sql
    select map_contains_value(NULL, 100);
    ```
    ```text
    +-------------------------------+
    | map_contains_value(NULL, 100) |
    +-------------------------------+
    |                          NULL |
    +-------------------------------+
    ```
    ```sql
    select map_contains_value(map(null, null), null), map_contains_value(map(null, 100), null);
    ```
    ```text
    +-------------------------------------------+------------------------------------------+
    | map_contains_value(map(null, null), null) | map_contains_value(map(null, 100), null) |
    +-------------------------------------------+------------------------------------------+
    |                                         1 |                                        0 |
    +-------------------------------------------+------------------------------------------+
    ```
