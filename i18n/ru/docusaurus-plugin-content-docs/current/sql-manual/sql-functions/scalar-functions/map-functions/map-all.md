## Описание {#description}

Проверяет каждую запись в карте с помощью лямбда-выражения и возвращает результат проверки того, удовлетворяют ли все записи заданному условию. Лямбда-выражение принимает ключ и значение каждой записи.

## Синтаксис {#syntax}

```sql
MAP_ALL((<key>, <value>) -> <predicate>, <map>)
```

## Параметры {#parameters}

| Параметр | Описание |
| --- | --- |
| `<key>` | Параметр лямбда-выражения, представляющий ключ записи в карте. |
| `<value>` | Параметр лямбда-выражения, представляющий значение записи в карте. |
| `<predicate>` | Логическое выражение, вычисляемое для каждой записи в карте. |
| `<map>` | Выражение типа `MAP<K, V>`. |

## Возвращаемое значение {#return-value}

Возвращает значение типа `BOOLEAN`.

- Возвращает `FALSE`, если предикат возвращает `FALSE` хотя бы для одной записи.
- Возвращает `TRUE`, если предикат возвращает `TRUE` для каждой записи, в том числе если карта пуста.
- Возвращает `NULL`, если ни для одной записи предикат не возвращает `FALSE` и хотя бы для одной записи возвращает `NULL`.
- Если `<map>` имеет значение `NULL`, возвращает `NULL`.

## Примеры {#examples}

```sql
SELECT map_all((k, v) -> v >= 10, map(1, 10, 2, 20)) AS result;
```

```text
+--------+
| result |
+--------+
|      1 |
+--------+
```

```sql
SELECT map_all((k, v) -> v > 10, map(1, 10, 2, 20)) AS result;
```

```text
+--------+
| result |
+--------+
|      0 |
+--------+
```

```sql
SELECT map_all((k, v) -> CAST(NULL AS BOOLEAN), map(1, 10)) AS result;
```

```text
+--------+
| result |
+--------+
| NULL   |
+--------+
```

```sql
SELECT map_all((k, v) -> v > 0, CAST(NULL AS MAP<INT, INT>)) AS result;
```

```text
+--------+
| result |
+--------+
| NULL   |
+--------+
```
