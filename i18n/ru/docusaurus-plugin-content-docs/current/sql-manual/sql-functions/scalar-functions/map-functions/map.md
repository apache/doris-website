# MAP {#map}

## Описание {#description}

Создаёт [`MAP<K, V>`](../../../basic-element/sql-data-types/semi-structured/MAP.md) определённого типа из нескольких групп пар «ключ-значение»

## Синтаксис {#syntax}

```sql
MAP( <key1> , <value1> [, <key2>, <value2> ... ])
```

## Параметры {#parameters}
### Необязательные параметры {#optional-parameters}
- `<key1>` поддерживает различные типы (см. [`MAP<K, V>`](../../../basic-element/sql-data-types/semi-structured/MAP.md)) и используется для формирования ключа MAP
- `<value1>` используется для формирования значения MAP
### Переменное число параметров {#variable-parameters}
Поддерживается несколько групп параметров «ключ-значение»

## Возвращаемое значение {#return-value}

Возвращает `MAP<K, V>` определённого типа, созданный из нескольких групп пар «ключ-значение»

## Примечания {#notes}
1. Количество параметров должно быть чётным (может быть 0), иначе возвращается ошибка.
2. Ключи в параметрах могут повторяться, но Doris удаляет дубликаты ключей.
3. Ключи могут иметь значение NULL; повторяющиеся ключи NULL удаляются.

## Примеры {#examples}
1. Обычные параметры
    ```sql
    select map(1, "100", 0.1, 2),map(1, "100", 0.1, 2)[1];
    ```

    ```text
    +-----------------------+--------------------------+
    | map(1, "100", 0.1, 2) | map(1, "100", 0.1, 2)[1] |
    +-----------------------+--------------------------+
    | {1.0:"100", 0.1:"2"}  | 100                      |
    +-----------------------+--------------------------+
    ```
2. Вызов без параметров
    ```sql
    select map();
    ```
    ```text
    +-------+
    | map() |
    +-------+
    | {}    |
    +-------+
    ```
3. Параметры NULL
    ```sql
    select map(null, 2, 3, null);
    ```
    ```text
    +-----------------------+
    | map(null, 2, 3, null) |
    +-----------------------+
    | {null:2, 3:null}      |
    +-----------------------+
    ```
4. При наличии повторяющихся ключей дубликаты удаляются
    ```sql
    select map(1, 2, 2, 11, 1, 3, null, "null 1", null, "null 2");
    ```
    ```text
    +--------------------------------------------------------+
    | map(1, 2, 2, 11, 1, 3, null, "null 1", null, "null 2") |
    +--------------------------------------------------------+
    | {2:"11", 1:"3", null:"null 2"}                         |
    +--------------------------------------------------------+
    ```
