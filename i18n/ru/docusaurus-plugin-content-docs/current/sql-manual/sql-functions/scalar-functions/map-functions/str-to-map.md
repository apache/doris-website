## Описание {#description}

Создаёт `Map<String, String>` из строки.

:::tip
Эта функция поддерживается начиная с версии 3.0.6.
:::

## Синтаксис {#syntax}

```sql
STR_TO_MAP(<str> [, <pair_delimiter> [, <key_value_delimiter>]])
```

## Параметры {#parameters}
- `<str>` Строка для преобразования в Map.
- `<pair_delimiter>` Разделитель пар в строке, по умолчанию `,`.
- `<key_value_delimiter>` Разделитель между ключом и значением в строке, по умолчанию `:`.

## Возвращаемое значение {#return-value}

Возвращает `Map<String, String>`, созданный из строки.

## Пример {#example}

```sql
select str_to_map('a=1&b=2&c=3', '&', '=') as map1, str_to_map('x:10|y:20|z:30', '|', ':') as map2;
```

```text
+-----------------------------+--------------------------------+
| map1                        | map2                           |
+-----------------------------+--------------------------------+
| {"a":"1", "b":"2", "c":"3"} | {"x":"10", "y":"20", "z":"30"} |
+-----------------------------+--------------------------------+
```
