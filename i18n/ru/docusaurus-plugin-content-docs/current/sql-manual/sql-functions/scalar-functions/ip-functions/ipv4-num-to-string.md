# IPV4_NUM_TO_STRING {#ipv4_num_to_string}

## Описание {#description}
Принимает число типа Int16, Int32 или Int64. Интерпретирует его как IPv4-адрес с порядком байтов big endian. Возвращает строку, содержащую соответствующий IPv4-адрес в формате A.B.C.D (десятичные числа, разделённые точками).

## Псевдоним {#alias}
- INET_NTOA

## Синтаксис {#syntax}

```sql
IPV4_NUM_TO_STRING(<ipv4_num>)
```

## Параметры {#parameters}
| Параметр | Описание                                      |
|-----------|--------------------------------------------------|
| `<ipv4_num>`      | Значение типа Int, полученное преобразованием адреса ipv4  |


## Возвращаемое значение {#return-value}
Возвращает строку, содержащую соответствующий IPv4-адрес в формате A.B.C.D (десятичные числа, разделённые точками). Особый случай:
- Возвращает `NULL`, если входной параметр отрицателен или больше `4294967295` (числового значения адреса `'255.255.255.255'`).

## Пример {#example}
```sql
select ipv4_num_to_string(3232235521);
```
```text
+--------------------------------+
| ipv4_num_to_string(3232235521) |
+--------------------------------+
| 192.168.0.1                    |
+--------------------------------+
```
