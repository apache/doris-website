## Описание {#description}
Принимает IPv4-адрес в строковом представлении и возвращает значение типа IPv4. Если входные данные некорректны или равны NULL, возвращает NULL.

## Синтаксис {#syntax}
```sql
TO_IPV4_OR_NULL(<ipv4_str>)
```

### Параметры {#parameters}
- `<ipv4_str>`: IPv4-адрес в виде строки

### Возвращаемое значение {#return-value}
Тип возвращаемого значения: IPv4

Описание возвращаемого значения:
- Возвращает значение типа IPv4, двоичное представление которого эквивалентно значению, возвращаемому `ipv4_string_to_num`
- Возвращает NULL, если входное значение равно NULL или является некорректным IPv4-адресом

### Примечания по использованию {#usage-notes}
- Эквивалентно преобразованию `to_ipv4_or_null` → тип `IPv4`; подходит для случаев, когда таблицы создаются со столбцами `IPv4`
- При некорректных входных данных возвращает NULL, не вызывая исключений

## Примеры {#examples}

Преобразование текстового представления IPv4-адреса `255.255.255.255` в тип `IPv4`.
```sql
SELECT to_ipv4_or_null('255.255.255.255') as v4;
+-----------------+
| v4              |
+-----------------+
| 255.255.255.255 |
+-----------------+
```

Если на вход подан NULL, возвращается NULL.
```sql
SELECT to_ipv4_or_null(NULL) as v4;
+------+
| v4   |
+------+
| NULL |
+------+
```

Если текстовое представление IPv4-адреса некорректно, возвращается NULL.
```sql
SELECT to_ipv4_or_null('256.1.1.1') as v4;
+------+
| v4   |
+------+
| NULL |
+------+
```
