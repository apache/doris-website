## Описание {#description}
Принимает строку, содержащую адрес IPv4 в формате A.B.C.D (десятичные числа, разделённые точками). Возвращает число типа BIGINT, представляющее соответствующий адрес IPv4 с порядком байтов big endian.

## Псевдоним {#alias}
- INET_ATON

## Синтаксис {#syntax}
```sql
IPV4_STRING_TO_NUM_OR_NULL(<ipv4_string>)
```

## Параметры {#parameters}
| Параметр | Описание                                      |
|-----------|--------------------------------------------------|
| `<ipv4_string>`      | Строка с адресом ipv4, например 'A.B.C.D'  |

## Возвращаемое значение {#return-value}
Возвращает число типа BIGINT, представляющее соответствующий адрес IPv4 с порядком байтов big endian.
- Если входная строка не является допустимым адресом IPv4, возвращается `NULL`.

## Пример {#example}
```sql
select ipv4_string_to_num_or_null('192.168.0.1'); 
```
```text
+-------------------------------------------+ 
| ipv4_string_to_num_or_null('192.168.0.1') | 
+-------------------------------------------+ 
| 3232235521                                | 
+-------------------------------------------+ 
```
