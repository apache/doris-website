## Описание {#description}
Принимает IPv6-адрес в строковом представлении и возвращает значение типа IPv6. Двоичное представление этого значения совпадает с двоичным представлением значения, возвращаемого функцией `ipv6_string_to_num`.

## Синтаксис {#syntax}
```sql
TO_IPV6(<ipv6_str>)
```

### Параметры {#parameters}
- `<ipv6_str>`: IPv6-адрес строкового типа

### Возвращаемое значение {#return-value}
Тип возвращаемого значения: IPv6

Описание возвращаемого значения:
- Возвращает значение типа IPv6
- Вызывает исключение, если входное значение равно NULL
- Вызывает исключение при некорректном IPv6-адресе или входном значении `NULL`

### Примечания по использованию {#usage-notes}
- Эквивалентно преобразованию `to_ipv6` → тип `IPv6`; подходит для случаев, когда таблицы создаются со столбцами типа `IPv6`

## Примеры {#examples}

Преобразование текстового IPv6-адреса `2001:1b70:a1:610::b102:2` в тип `IPv6`.
```sql
SELECT to_ipv6('2001:1b70:a1:610::b102:2') as v6;
+-------------------------------+
| v6                            |
+-------------------------------+
| 2001:1b70:a1:610::b102:2      |
+-------------------------------+
```

Входное значение NULL вызывает исключение
```sql
SELECT to_ipv6(NULL);
ERROR 1105 (HY000): errCode = 2, detailMessage = (...)[INVALID_ARGUMENT]The arguments of function to_ipv6 must be String, not NULL
```

Некорректный IPv6-адрес в текстовом представлении вызывает исключение.
```sql
SELECT to_ipv6('not-an-ip');
ERROR 1105 (HY000): errCode = 2, detailMessage = (...)[INVALID_ARGUMENT]Invalid IPv6 value
```
