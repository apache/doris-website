# IPV6_NUM_TO_STRING {#ipv6_num_to_string}

## Описание {#description}
Принимает IPv6-адрес в двоичном формате в виде значения типа String. Возвращает строковое представление этого адреса в текстовом формате.
- IPv4-адрес, отображённый в IPv6, начинается с ::ffff:111.222.33.44.

## Псевдоним {#alias}
- INET6_NTOA

## Синтаксис {#syntax}
```sql
IPV6_NUM_TO_STRING(<ipv6_num>)
```

## Параметры {#parameters}
| Параметр | Описание                                      |
|-----------|--------------------------------------------------|
| `<ipv6_num>`      | IPv6-адрес в двоичном формате в виде значения типа String  |

## Возвращаемое значение {#return-value}
Возвращает строковое представление адреса ipv6 в текстовом формате.
- Если входная строка не является двоичным представлением допустимого IPv6-адреса, возвращается `NULL`.


## Пример {#example}
```sql
select ipv6_num_to_string(unhex('2A0206B8000000000000000000000011')) as addr, ipv6_num_to_string("-23vno12i34nlfwlsj");
```
```text
+--------------+------------------------------------------+
| addr         | ipv6_num_to_string('-23vno12i34nlfwlsj') |
+--------------+------------------------------------------+
| 2a02:6b8::11 | NULL                                     |
+--------------+------------------------------------------+
```
