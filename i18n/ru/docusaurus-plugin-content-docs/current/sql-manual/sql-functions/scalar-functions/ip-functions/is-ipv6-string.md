## Описание {#description}
Проверяет, имеет ли входная строка допустимый формат адреса IPv6. Возвращает 1, если это допустимый адрес IPv6, и 0 в противном случае.

## Псевдоним {#alias}
- IS_IPV6

## Синтаксис {#syntax}
```sql
IS_IPV6_STRING(<ipv6_str>)
```

### Параметры {#parameters}
- `<ipv6_str>`: строка для проверки

### Возвращаемое значение {#return-value}
Тип возвращаемого значения: BOOLEAN

Значение результата:
- Возвращает 1: входная строка имеет допустимый формат адреса IPv6
- Возвращает 0: входная строка не имеет допустимого формата адреса IPv6
- Возвращает NULL, если входное значение равно NULL

### Примечания по использованию {#usage-notes}
- Проверяет только соответствие формата строки спецификации адресов IPv6
- Не выполняет преобразование IP-адреса, а только проверяет формат
- Поддерживает входное значение NULL и возвращает NULL

## Примеры {#examples}

Проверка допустимого формата адреса IPv6.
```sql
SELECT is_ipv6_string('2001:db8::1') as is_valid;
+----------+
| is_valid |
+----------+
| 1        |
+----------+
```

Проверка различных форматов адресов IPv6.
```sql
SELECT 
  is_ipv6_string('::1') as localhost,
  is_ipv6_string('2001:db8::1') as standard,
  is_ipv6_string('2001:db8:0:0:0:0:0:1') as expanded;
+-----------+----------+----------+
| localhost | standard | expanded |
+-----------+----------+----------+
| 1         | 1        | 1        |
+-----------+----------+----------+
```

Проверка недопустимых форматов адресов IPv6.
```sql
SELECT 
  is_ipv6_string('2001:db8::1::2') as double_colon,
  is_ipv6_string('2001:db8:1') as too_short,
  is_ipv6_string('2001:db8:1:2:3:4:5:6:7') as too_long,
  is_ipv6_string('not-an-ipv6') as not_ipv6;
+--------------+-----------+----------+----------+
| double_colon | too_short | too_long | not_ipv6 |
+--------------+-----------+----------+----------+
| 0            | 0         | 0        | 0        |
+--------------+-----------+----------+----------+
```

Проверка входного значения NULL.
```sql
SELECT is_ipv6_string(NULL) as null_check;
+------------+
| null_check |
+------------+
| NULL       |
+------------+
```
