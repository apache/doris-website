## Описание {#description}

Функция CONCAT последовательно объединяет несколько строк в одну. Она принимает переменное число аргументов и относится к базовым и наиболее часто используемым функциям обработки строк. Она широко применяется для объединения данных, формирования отчётов и динамического построения SQL-запросов. Обратите внимание: если хотя бы один аргумент равен NULL, весь результат будет NULL.

## Синтаксис {#syntax}

```sql
CONCAT(<expr> [, <expr> ...])
```

## Параметры {#parameters}

| Параметр       | Описание           |
|----------|--------------|
| `<expr>` | Строковое выражение для объединения: строковая константа, имя столбца или другое выражение. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее собой строку, полученную объединением всех аргументов.

Правила объединения:
- Строки объединяются в порядке передачи аргументов
- Поддерживается любое число аргументов (не менее 1)
- Поддерживается корректное объединение многобайтовых символов UTF-8
- Числа и значения других типов автоматически преобразуются в строки

Особые случаи:
- Если хотя бы один аргумент равен NULL, возвращается NULL (это основное отличие от CONCAT_WS)
- Если аргументы не указаны, возникает синтаксическая ошибка
- Аргументы с пустыми строками не влияют на результат объединения
- Допускается сочетание строковых значений со значениями других типов

## Примеры {#examples}

1. Простое объединение строк
```sql
SELECT CONCAT('a', 'b'), CONCAT('a', 'b', 'c');
```
```text
+------------------+-----------------------+
| CONCAT('a', 'b') | CONCAT('a', 'b', 'c') |
+------------------+-----------------------+
| ab               | abc                   |
+------------------+-----------------------+
```

2. Обработка значений NULL (ключевая особенность)
```sql
SELECT CONCAT('a', NULL, 'c'), CONCAT('hello', NULL);
```
```text
+------------------------+---------------------+
| CONCAT('a', NULL, 'c') | CONCAT('hello', NULL) |
+------------------------+---------------------+
| NULL                   | NULL                |
+------------------------+---------------------+
```

3. Обработка пустых строк
```sql
SELECT CONCAT('hello', '', 'world'), CONCAT('', 'test', '');
```
```text
+-----------------------------+------------------------+
| CONCAT('hello', '', 'world') | CONCAT('', 'test', '') |
+-----------------------------+------------------------+
| helloworld                  | test                   |
+-----------------------------+------------------------+
```

4. Сочетание чисел и строк
```sql
SELECT CONCAT('User', 123), CONCAT('Price: $', 99.99);
```
```text
+---------------------+---------------------------+
| CONCAT('User', 123) | CONCAT('Price: $', 99.99) |
+---------------------+---------------------------+
| User123             | Price: $99.99             |
+---------------------+---------------------------+
```

5. Объединение нескольких аргументов
```sql
SELECT CONCAT('A', 'B', 'C', 'D', 'E'), CONCAT('1', '2', '3', '4', '5');
```
```text
+----------------------------------+----------------------------------+
| CONCAT('A', 'B', 'C', 'D', 'E') | CONCAT('1', '2', '3', '4', '5') |
+----------------------------------+----------------------------------+
| ABCDE                            | 12345                            |
+----------------------------------+----------------------------------+
```

6. Объединение многобайтовых символов UTF-8
```sql
SELECT CONCAT('ṭṛì', ' ', 'ḍḍumai'), CONCAT('Hello', ' ', 'ṭṛì', ' ', 'ḍḍumai');
```
```text
+------------------------------+--------------------------------------+
| CONCAT('ṭṛì', ' ', 'ḍḍumai') | CONCAT('Hello', ' ', 'ṭṛì', ' ', 'ḍḍumai') |
+------------------------------+--------------------------------------+
| ṭṛì ḍḍumai                   | Hello ṭṛì ḍḍumai                     |
+------------------------------+--------------------------------------+
```

7. Формирование путей и URL
```sql
SELECT CONCAT('/home/', 'user/', 'file.txt'), CONCAT('https://', 'www.example.com', '/api');
```
```text
+--------------------------------------+----------------------------------------------+
| CONCAT('/home/', 'user/', 'file.txt') | CONCAT('https://', 'www.example.com', '/api') |
+--------------------------------------+----------------------------------------------+
| /home/user/file.txt                  | https://www.example.com/api                 |
+--------------------------------------+----------------------------------------------+
```

8. Формирование адресов электронной почты
```sql
SELECT CONCAT('user', '@', 'example.com'), CONCAT('admin.', 'support', '@', 'company.org');
```
```text
+------------------------------------+-----------------------------------------------+
| CONCAT('user', '@', 'example.com') | CONCAT('admin.', 'support', '@', 'company.org') |
+------------------------------------+-----------------------------------------------+
| user@example.com                   | admin.support@company.org                    |
+------------------------------------+-----------------------------------------------+
```
