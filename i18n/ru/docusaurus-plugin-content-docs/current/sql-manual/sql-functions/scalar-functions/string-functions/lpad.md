## Описание {#description}

Функция LPAD (Left Padding) дополняет строку слева указанными символами до заданной длины. Если заданная длина меньше длины исходной строки, строка усекается.

## Синтаксис {#syntax}

```sql
LPAD(<str>, <len>, <pad>)
```

## Параметры {#parameters}

| Параметр | Описание |
|---------|------------------------------|
| `<str>` | Исходная строка, которую нужно дополнить. Тип: VARCHAR |
| `<len>` | Целевая длина строки в символах (не в байтах). Тип: INT |
| `<pad>` | Строка, используемая для дополнения. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее дополненную или усечённую строку.

Правила дополнения:
- Если len > длина исходной строки: строка pad многократно добавляется слева, пока общая длина не достигнет len
- Если len = длина исходной строки: возвращается исходная строка
- Если len < длина исходной строки: строка усекается, возвращаются только первые len символов
- Длина рассчитывается в символах, поддерживаются многобайтовые символы UTF-8

Особые случаи:
- Если любой из параметров равен NULL, возвращается NULL
- Если pad является пустой строкой и len > длина str, возвращается пустая строка
- Если len равен 0, возвращается пустая строка
- Если len отрицателен, возвращается NULL

## Примеры {#examples}

1. Простое дополнение слева
```sql
SELECT LPAD('hi', 5, 'xy'), LPAD('hello', 8, '*');
```
```text
+---------------------+-----------------------+
| LPAD('hi', 5, 'xy') | LPAD('hello', 8, '*') |
+---------------------+-----------------------+
| xyxhi               | ***hello              |
+---------------------+-----------------------+
```

2. Усечение строки
```sql
SELECT LPAD('hi', 1, 'xy'), LPAD('hello world', 5, 'x');
```
```text
+---------------------+------------------------------+
| LPAD('hi', 1, 'xy') | LPAD('hello world', 5, 'x')  |
+---------------------+------------------------------+
| h                   | hello                        |
+---------------------+------------------------------+
```

3. Обработка значений NULL
```sql
SELECT LPAD(NULL, 5, 'x'), LPAD('hi', NULL, 'x'), LPAD('hi', 5, NULL);
```
```text
+---------------------+------------------------+----------------------+
| LPAD(NULL, 5, 'x')  | LPAD('hi', NULL, 'x')  | LPAD('hi', 5, NULL)  |
+---------------------+------------------------+----------------------+
| NULL                | NULL                   | NULL                 |
+---------------------+------------------------+----------------------+
```

4. Пустая строка и нулевая длина
```sql
SELECT LPAD('', 0, ''), LPAD('hi', 0, 'x'), LPAD('', 5, '*');
```
```text
+-----------------+--------------------+------------------+
| LPAD('', 0, '') | LPAD('hi', 0, 'x') | LPAD('', 5, '*') |
+-----------------+--------------------+------------------+
|                 |                    | *****            |
+-----------------+--------------------+------------------+
```

5. Пустая строка дополнения
```sql
SELECT LPAD('hello', 10, ''), LPAD('hi', 2, '');
```
```text
+-----------------------+-------------------+
| LPAD('hello', 10, '') | LPAD('hi', 2, '') |
+-----------------------+-------------------+
|                       | hi                |
+-----------------------+-------------------+
```

6. Более длинная строка дополнения (повторяется до достижения длины len)
```sql
SELECT LPAD('123', 10, 'abc'), LPAD('X', 7, 'HELLO');
```
```text
+------------------------+-----------------------+
| LPAD('123', 10, 'abc') | LPAD('X', 7, 'HELLO') |
+------------------------+-----------------------+
| abcabca123             | HELLOHX               |
+------------------------+-----------------------+
```

7. Дополнение многобайтовыми символами UTF-8
```sql
SELECT LPAD('hello', 10, 'ṭṛì'), LPAD('ḍḍumai', 3, 'x');
```
```text
+-------------------------------+----------------------------+
| LPAD('hello', 10, 'ṭṛì')      | LPAD('ḍḍumai', 3, 'x')     |
+-------------------------------+----------------------------+
| ṭṛìṭṛhello                    | ḍḍu                        |
+-------------------------------+----------------------------+
```

8. Дополнение числовых строк нулями
```sql
SELECT LPAD('42', 6, '0'), LPAD('1234', 8, '0');
```
```text
+--------------------+----------------------+
| LPAD('42', 6, '0') | LPAD('1234', 8, '0') |
+--------------------+----------------------+
| 000042             | 00001234             |
+--------------------+----------------------+
```

9. Отрицательная длина
```sql
SELECT LPAD('hello', -1, 'x'), LPAD('test', -5, '*');
```
```text
+------------------------+-----------------------+
| LPAD('hello', -1, 'x') | LPAD('test', -5, '*') |
+------------------------+-----------------------+
| NULL                   | NULL                  |
+------------------------+-----------------------+
```
