## Описание {#description}

Извлекает доменное имя из URL, представленного строкой

## Синтаксис {#syntax}

```sql
DOMAIN ( <url> )
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|--------------------|
| `<url>`   | `URL`, из которого необходимо извлечь доменное имя |

## Возвращаемое значение {#return-value}

Доменное имя из параметра `<url>`

## Пример {#example}

```sql
SELECT DOMAIN("https://doris.apache.org/docs/gettingStarted/what-is-apache-doris")
```

```text
+-----------------------------------------------------------------------------+
| domain('https://doris.apache.org/docs/gettingStarted/what-is-apache-doris') |
+-----------------------------------------------------------------------------+
| doris.apache.org                                                            |
+-----------------------------------------------------------------------------+
```
