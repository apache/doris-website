## Описание {#description}

Функция STRLEFT возвращает указанное количество символов из начала строки. Длина измеряется в символах UTF8.

## Псевдоним {#alias}

LEFT

## Синтаксис {#syntax}

```sql
STRLEFT(<str>, <len>)
```

## Параметры {#parameters}
| Параметр | Описание                                   |
| --------- | --------------------------------------------- |
| `<str>` | Строка, из которой извлекаются символы. Тип: VARCHAR     |
| `<len>` | Количество возвращаемых символов. Тип: INT |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее извлечённую подстроку.

Особые случаи:
- Возвращает NULL, если хотя бы один аргумент равен NULL
- Возвращает пустую строку "", если значение len меньше или равно 0
- Возвращает всю строку, если len превышает длину строки

## Примеры {#examples}

1. Простое извлечение символов слева
```sql
SELECT STRLEFT('Hello doris', 5), LEFT('Hello doris', 5);
```
```text
+---------------------------+----------------------+
| STRLEFT('Hello doris', 5) | LEFT('Hello doris', 5) |
+---------------------------+----------------------+
| Hello                     | Hello                |
+---------------------------+----------------------+
```

2. Разная длина извлекаемых подстрок
```sql
SELECT STRLEFT('Hello World', 3), STRLEFT('Hello World', 8);
```
```text
+----------------------------+----------------------------+
| STRLEFT('Hello World', 3)  | STRLEFT('Hello World', 8)  |
+----------------------------+----------------------------+
| Hel                        | Hello Wo                   |
+----------------------------+----------------------------+
```

3. Обработка значений NULL
```sql
SELECT STRLEFT(NULL, 5), STRLEFT('Hello doris', NULL);
```
```text
+------------------+------------------------------+
| STRLEFT(NULL, 5) | STRLEFT('Hello doris', NULL) |
+------------------+------------------------------+
| NULL             | NULL                         |
+------------------+------------------------------+
```

4. Пустая строка и нулевая длина
```sql
SELECT STRLEFT('', 5), STRLEFT('Hello World', 0);
```
```text
+------------------+----------------------------+
| STRLEFT('', 5)   | STRLEFT('Hello World', 0)  |
+------------------+----------------------------+
|                  |                            |
+------------------+----------------------------+
```

5. Обработка отрицательной длины
```sql
SELECT STRLEFT('Hello doris', -5), STRLEFT('Hello doris', -1);
```
```text
+-----------------------------+----------------------------+
| STRLEFT('Hello doris', -5)  | STRLEFT('Hello doris', -1) |
+-----------------------------+----------------------------+
|                             |                            |
+-----------------------------+----------------------------+
```

6. Длина превышает длину строки
```sql
SELECT STRLEFT('ABC', 10), STRLEFT('short', 20);
```
```text
+--------------------+----------------------+
| STRLEFT('ABC', 10) | STRLEFT('short', 20) |
+--------------------+----------------------+
| ABC                | short                |
+--------------------+----------------------+
```

7. Многобайтовые символы UTF-8
```sql
SELECT STRLEFT('ṭṛì ḍḍumai hello', 3), STRLEFT('ṭṛì ḍḍumai hello', 7);
```
```text
+---------------------------------+----------------------------------+
| STRLEFT('ṭṛì ḍḍumai hello', 3)  | STRLEFT('ṭṛì ḍḍumai hello', 7)  |
+---------------------------------+----------------------------------+
| ṭṛì                             | ṭṛì ḍḍu                          |
+---------------------------------+----------------------------------+
```

8. Префикс номера и ID
```sql
SELECT STRLEFT('ID123456789', 5), STRLEFT('USER_987654321', 5);
```
```text
+----------------------------+------------------------------+
| STRLEFT('ID123456789', 5)  | STRLEFT('USER_987654321', 5) |
+----------------------------+------------------------------+
| ID123                      | USER_                        |
+----------------------------+------------------------------+
```

### Ключевые слова {#keywords}

    STRLEFT, LEFT
