## Описание {#description}

Функция INITCAP переводит первую букву каждого слова в строке в верхний регистр, а остальные буквы в нижний регистр. Словом считается последовательность букв и цифр, отделённая от других слов символами, не являющимися буквами или цифрами. Эта функция подходит для форматирования имён, заголовков и других случаев, требующих единообразного оформления регистра.

## Синтаксис {#syntax}

```sql
INITCAP(<str>)
```

## Параметры {#parameters}

| Параметр | Описание |
|---------|-----------|
| `<str>` | Строка, в которой нужно преобразовать регистр. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает преобразованную строку типа VARCHAR.

Правила преобразования:
- Первая буква каждого слова переводится в верхний регистр
- Остальные буквы слова переводятся в нижний регистр
- Слова разделяются символами, не являющимися буквами или цифрами (пробелами, знаками препинания, специальными символами и т. д.)
- Регистр цифровых символов не изменяется
- Поддерживается преобразование регистра символов Unicode

Особые случаи:
- Если параметр равен NULL, возвращается NULL
- Если строка пустая, возвращается пустая строка
- Последовательность символов, не являющихся буквами или цифрами, считается одним разделителем
- Буквы в начале строки переводятся в верхний регистр

## Примеры {#examples}

1. Преобразование первых букв слов в заглавные
```sql
SELECT INITCAP('hello world');
```
```text
+------------------------+
| INITCAP('hello world') |
+------------------------+
| Hello World            |
+------------------------+
```

2. Преобразование строки со смешанным регистром
```sql
SELECT INITCAP('hELLo WoRLD');
```
```text
+------------------------+
| INITCAP('hELLo WoRLD') |
+------------------------+
| Hello World            |
+------------------------+
```

3. Обработка значения NULL
```sql
SELECT INITCAP(NULL);
```
```text
+---------------+
| INITCAP(NULL) |
+---------------+
| NULL          |
+---------------+
```

4. Строка с цифрами и символами
```sql
SELECT INITCAP('hello hello.,HELLO123HELlo');
```
```text
+---------------------------------------+
| INITCAP('hello hello.,HELLO123HELlo') |
+---------------------------------------+
| Hello Hello.,Hello123hello            |
+---------------------------------------+
```
