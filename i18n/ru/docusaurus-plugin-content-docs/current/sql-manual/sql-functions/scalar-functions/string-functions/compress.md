## Описание {#description}

Функция COMPRESS сжимает строку с помощью алгоритма сжатия zlib, возвращая двоичные данные. Сжатые данные можно распаковать обратно в исходную строку с помощью функции UNCOMPRESS.

## Синтаксис {#syntax}

```sql
COMPRESS(<str>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -------- | ----------------------------------------- |
| `<str>` | Строка, которую нужно сжать. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, содержащее сжатые двоичные данные (нечитаемые для человека).

Особые случаи:
- Если параметр равен NULL, возвращает NULL
- Если на вход подана пустая строка `''`, возвращает пустую строку `''`

## Примеры {#examples}

1. Базовое использование: сжатие и распаковка
```sql
SELECT uncompress(compress('hello'));
```
```text 
+-------------------------------+
| uncompress(compress('hello')) |
+-------------------------------+
| hello                         |
+-------------------------------+
```

2. Обработка пустой строки
```sql
SELECT compress('');
```
```text 
+--------------+
| compress('') |
+--------------+
|              |
+--------------+
```

3. Обработка значения NULL
```sql
SELECT compress(NULL);
```
```text 
+----------------+
| compress(NULL) |
+----------------+
| NULL           |
+----------------+
```

4. Проверка символов UTF-8
```sql
SELECT uncompress(compress('ṭṛì'));
```
```text
+----------------------------------+
| uncompress(compress('ṭṛì'))      |
+----------------------------------+
| ṭṛì                              |
+----------------------------------+
```
