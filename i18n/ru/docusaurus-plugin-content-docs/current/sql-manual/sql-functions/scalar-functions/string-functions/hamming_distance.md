## Описание {#description}
Функция `HAMMING_DISTANCE` возвращает количество позиций, в которых различаются две строки одинаковой длины.

Эта функция подсчитывает символы в кодировке UTF-8.

## Синтаксис {#syntax}
```sql
HAMMING_DISTANCE(<str1>, <str2>)
```

## Параметры {#parameters}
| Параметр | Описание |
| -- | -- |
| `<str1>` | Первая строка |
| `<str2>` | Вторая строка |

## Возвращаемое значение {#return-value}
Возвращает значение типа BIGINT.

## Примеры {#examples}
```sql
SELECT hamming_distance('karolin', 'kathrin'); -- 3
SELECT hamming_distance('数据库', '数据仓');   -- 1
```

## Примечания {#notes}
- Обе строки должны иметь одинаковую длину. В противном случае возвращается ошибка.
- Поддерживаются символы UTF-8.
- Если на вход подано значение NULL, возвращается NULL.
