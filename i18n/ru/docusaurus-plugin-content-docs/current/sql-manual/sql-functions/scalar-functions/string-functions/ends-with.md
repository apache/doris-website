## Описание {#description}

Функция ENDS_WITH проверяет, заканчивается ли строка указанным суффиксом.

## Синтаксис {#syntax}

```sql
ENDS_WITH(<str>, <suffix>)
```

## Параметры {#parameters}

| Параметр | Описание |
|----------|--------------|
| `str`    | Основная строка для проверки. Тип: VARCHAR |
| `suffix` | Строка суффикса для сопоставления. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа BOOLEAN (в Doris отображается как TINYINT, где 1 означает true, а 0 означает false).

Правила сопоставления:
- Точное совпадение суффикса с учётом регистра
- Пустой суффикс совпадает с окончанием любой строки (возвращается true)
- Поддерживается корректное сопоставление многобайтовых символов UTF-8
- Длина суффикса не может превышать длину основной строки (кроме случая, когда суффикс пуст)

Особые случаи:
- Если хотя бы один из параметров равен NULL, возвращается NULL
- Если суффикс является пустой строкой, возвращается true (любая строка заканчивается пустой строкой)
- Если основная строка пуста, а суффикс непустой, возвращается false
- Если обе строки пусты, возвращается true

## Примеры {#examples}

1. Базовое сопоставление суффикса
```sql
SELECT ENDS_WITH('Hello doris', 'doris'), ENDS_WITH('Hello doris', 'Hello');
```
```text
+-----------------------------------+-----------------------------------+
| ENDS_WITH('Hello doris', 'doris') | ENDS_WITH('Hello doris', 'Hello') |
+-----------------------------------+-----------------------------------+
|                                 1 |                                 0 |
+-----------------------------------+-----------------------------------+
```

2. Учёт регистра
```sql
SELECT ENDS_WITH('Hello World', 'world'), ENDS_WITH('Hello World', 'World');
```
```text
+-----------------------------------+-----------------------------------+
| ENDS_WITH('Hello World', 'world') | ENDS_WITH('Hello World', 'World') |
+-----------------------------------+-----------------------------------+
|                                 0 |                                 1 |
+-----------------------------------+-----------------------------------+
```

3. Обработка значений NULL
```sql
SELECT ENDS_WITH(NULL, 'test'), ENDS_WITH('test', NULL);
```
```text
+--------------------------+--------------------------+
| ENDS_WITH(NULL, 'test')  | ENDS_WITH('test', NULL)  |
+--------------------------+--------------------------+
| NULL                     | NULL                     |
+--------------------------+--------------------------+
```

4. Обработка пустых строк
```sql
SELECT ENDS_WITH('hello', ''), ENDS_WITH('', 'world');
```
```text
+-------------------------+--------------------------+
| ENDS_WITH('hello', '')  | ENDS_WITH('', 'world')   |
+-------------------------+--------------------------+
|                       1 |                        0 |
+-------------------------+--------------------------+
```

5. Полное совпадение строк
```sql
SELECT ENDS_WITH('test', 'test'), ENDS_WITH('testing', 'test');
```
```text
+---------------------------+------------------------------+
| ENDS_WITH('test', 'test') | ENDS_WITH('testing', 'test') |
+---------------------------+------------------------------+
|                         1 |                            0 |
+---------------------------+------------------------------+
```

6. Проверка расширения файла
```sql
SELECT ENDS_WITH('document.pdf', '.pdf'), ENDS_WITH('image.jpg', '.png');
```
```text
+------------------------------------+----------------------------------+
| ENDS_WITH('document.pdf', '.pdf')  | ENDS_WITH('image.jpg', '.png')   |
+------------------------------------+----------------------------------+
|                                  1 |                                0 |
+------------------------------------+----------------------------------+
```

7. Многобайтовые символы UTF-8
```sql
SELECT ENDS_WITH('hello ṭṛì ḍḍumai', 'ḍḍumai'), ENDS_WITH('hello ṭṛì ḍḍumai', 'ṭṛì');
```
```text
+------------------------------------------+---------------------------------------+
| ENDS_WITH('hello ṭṛì ḍḍumai', 'ḍḍumai') | ENDS_WITH('hello ṭṛì ḍḍumai', 'ṭṛì')  |
+------------------------------------------+---------------------------------------+
|                                        1 |                                     0 |
+------------------------------------------+---------------------------------------+
```

8. Проверка пути URL
```sql
SELECT ENDS_WITH('https://example.com/api', '/api'), ENDS_WITH('https://example.com/', '.html');
```
```text
+--------------------------------------------+---------------------------------------------+
| ENDS_WITH('https://example.com/api', '/api') | ENDS_WITH('https://example.com/', '.html') |
+--------------------------------------------+---------------------------------------------+
|                                          1 |                                           0 |
+--------------------------------------------+---------------------------------------------+
```

9. Суффикс строки из цифр
```sql
SELECT ENDS_WITH('123456789', '789'), ENDS_WITH('123456789', '456');
```
```text
+--------------------------------+--------------------------------+
| ENDS_WITH('123456789', '789')  | ENDS_WITH('123456789', '456')  |
+--------------------------------+--------------------------------+
|                              1 |                              0 |
+--------------------------------+--------------------------------+
```

10. Проверка домена электронной почты
```sql
SELECT ENDS_WITH('user@gmail.com', '.com'), ENDS_WITH('admin@company.org', '.com');
```
```text
+------------------------------------+--------------------------------------+
| ENDS_WITH('user@gmail.com', '.com') | ENDS_WITH('admin@company.org', '.com') |
+------------------------------------+--------------------------------------+
|                                  1 |                                    0 |
+------------------------------------+--------------------------------------+
```
