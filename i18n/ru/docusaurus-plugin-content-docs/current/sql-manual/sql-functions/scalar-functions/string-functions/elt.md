## Описание {#description}

Функция ELT возвращает строку по указанному индексу. Отсчёт индексов начинается с 1.

## Синтаксис {#syntax}

```sql
ELT(<pos>, <str>[, <str> ...])
```

## Параметры {#parameters}

| Параметр | Описание |
| -------- | ----------------------------------------- |
| `<pos>` | Индекс (начиная с 1). Тип: INT |
| `<str>` | Список строк. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее собой строку по указанному индексу.

Особые случаи:
- Если `<pos>` меньше 1 или больше количества строк, возвращается NULL
- Если `<pos>` равен NULL, возвращается NULL
- Отсчёт индексов начинается с 1, первая строка имеет индекс 1

## Примеры {#examples}

1. Базовое использование: получение 1-й строки
```sql
SELECT ELT(1, 'aaa', 'bbb', 'ccc');
```
```text
+-----------------------------+
| elt(1, 'aaa', 'bbb', 'ccc') |
+-----------------------------+
| aaa                         |
+-----------------------------+
```

2. Получение 2-й строки
```sql
SELECT ELT(2, 'aaa', 'bbb', 'ccc');
```
```text
+-----------------------------+
| elt(2, 'aaa', 'bbb', 'ccc') |
+-----------------------------+
| bbb                         |
+-----------------------------+
```

3. При выходе индекса за допустимые границы возвращается NULL
```sql
SELECT ELT(0, 'aaa', 'bbb'), ELT(5, 'aaa', 'bbb');
```
```text
+----------------------+----------------------+
| elt(0, 'aaa', 'bbb') | elt(5, 'aaa', 'bbb') |
+----------------------+----------------------+
| NULL                 | NULL                 |
+----------------------+----------------------+
```

4. Обработка значения NULL
```sql
SELECT ELT(NULL, 'aaa', 'bbb');
```
```text
+-------------------------+
| elt(NULL, 'aaa', 'bbb') |
+-------------------------+
| NULL                    |
+-------------------------+
```

5. Если индекс превышает допустимый диапазон, возвращается NULL

```sql
SELECT ELT(5, 'aaa', 'bbb', 'ccc');
```

```text
+-----------------------------+
| elt(5, 'aaa', 'bbb', 'ccc') |
+-----------------------------+
| NULL                        |
+-----------------------------+
```

6. При отрицательном индексе возвращается NULL

```sql
SELECT ELT(-1, 'first', 'second');
```

```text
+----------------------------+
| elt(-1, 'first', 'second') |
+----------------------------+
| NULL                       |
+----------------------------+
```

7. Строка UTF-8

```sql
SELECT 
    ELT(2, 'Hello', 'ṭṛ', 'Hola');
```

```text
+-----------------------------------+
| ELT(2, 'Hello', 'ṭṛ', 'Hola')     |
+-----------------------------------+
| ṭṛ                                |
+-----------------------------------+
```

8. Обработка пустых строк

```sql
SELECT ELT(2, 'first', '', 'third');
```

```text
+------------------------------+
| elt(2, 'first', '', 'third') |
+------------------------------+
|                              |
+------------------------------+
```
