## Описание {#description}

Функция SPLIT_PART разбивает строку на несколько частей по указанному разделителю и возвращает одну из них.

## Синтаксис {#syntax}

```sql
SPLIT_PART ( <str>, <separator>, <part_index> )
```

## Параметры {#parameters}

| Параметр       | Описание                                              |
|----------------|-------------------------------------------------------|
| `<str>`        | Строка, которую нужно разделить                        |
| `<separator>`  | Строка, используемая в качестве разделителя             |
| `<part_index>` | Индекс возвращаемой части. Нумерация начинается с 1     |

## Возвращаемое значение {#return-value}

Возвращает указанную часть строки, разбитой по разделителю. Особые случаи:

- Если любой из параметров равен NULL, возвращается NULL.
- Если `<part_index>` равен 0, возвращается NULL.
- Если `<part_index>` выходит за допустимые границы, возвращается NULL.

## Примеры {#examples}

1. Простое разделение строки
```sql
SELECT SPLIT_PART('hello world', ' ', 1);
```
```text
+----------------------------------+
| SPLIT_PART('hello world', ' ', 1) |
+----------------------------------+
| hello                            |
+----------------------------------+
```

2. Получение второй части
```sql
SELECT SPLIT_PART('apple,banana,cherry', ',', 2);
```
```text
+-------------------------------------------+
| SPLIT_PART('apple,banana,cherry', ',', 2) |
+-------------------------------------------+
| banana                                    |
+-------------------------------------------+
```

3. Индекс равен 0 (возвращается NULL)
```sql
SELECT SPLIT_PART('apple,banana,cherry', ',', 0);
```
```text
+-------------------------------------------+
| SPLIT_PART('apple,banana,cherry', ',', 0) |
+-------------------------------------------+
| NULL                                      |
+-------------------------------------------+
```

4. Отрицательный индекс (отсчёт с конца)
```sql
SELECT SPLIT_PART('apple,banana,cherry', ',', -1), SPLIT_PART('apple,banana,cherry', ',', -2);
```
```text
+--------------------------------------------+--------------------------------------------+
| SPLIT_PART('apple,banana,cherry', ',', -1) | SPLIT_PART('apple,banana,cherry', ',', -2) |
+--------------------------------------------+--------------------------------------------+
| cherry                                     | banana                                     |
+--------------------------------------------+--------------------------------------------+
```

5. Индекс за пределами допустимого диапазона
```sql
SELECT SPLIT_PART('apple,banana', ',', 5), SPLIT_PART('apple,banana', ',', -5);
```
```text
+------------------------------------+-------------------------------------+
| SPLIT_PART('apple,banana', ',', 5) | SPLIT_PART('apple,banana', ',', -5) |
+------------------------------------+-------------------------------------+
| NULL                               | NULL                                |
+------------------------------------+-------------------------------------+
```

6. Обработка значений NULL
```sql
SELECT SPLIT_PART(NULL, ',', 1), SPLIT_PART('test', NULL, 1), SPLIT_PART('test', ',', NULL);
```
```text
+---------------------------+-----------------------------+-------------------------------+
| SPLIT_PART(NULL, ',', 1)  | SPLIT_PART('test', NULL, 1) | SPLIT_PART('test', ',', NULL) |
+---------------------------+-----------------------------+-------------------------------+
| NULL                      | NULL                        | NULL                          |
+---------------------------+-----------------------------+-------------------------------+
```

7. Обработка пустых строк
```sql
SELECT SPLIT_PART('', ',', 1), SPLIT_PART('test', '', 2);
```
```text
+------------------------+---------------------------+
| SPLIT_PART('', ',', 1) | SPLIT_PART('test', '', 2) |
+------------------------+---------------------------+
| NULL                   |                           |
+------------------------+---------------------------+
```

8. Разделитель отсутствует
```sql
SELECT SPLIT_PART('hello world', '|', 1), SPLIT_PART('hello world', '|', 2);
```
```text
+-----------------------------------+-----------------------------------+
| SPLIT_PART('hello world', '|', 1) | SPLIT_PART('hello world', '|', 2) |
+-----------------------------------+-----------------------------------+
| NULL                              | NULL                              |
+-----------------------------------+-----------------------------------+
```

9. Последовательные разделители
```sql
SELECT SPLIT_PART('a,,c', ',', 1), SPLIT_PART('a,,c', ',', 2), SPLIT_PART('a,,c', ',', 3);
```
```text
+----------------------------+----------------------------+----------------------------+
| SPLIT_PART('a,,c', ',', 1) | SPLIT_PART('a,,c', ',', 2) | SPLIT_PART('a,,c', ',', 3) |
+----------------------------+----------------------------+----------------------------+
| a                          |                            | c                          |
+----------------------------+----------------------------+----------------------------+
```

10. Обработка символов UTF-8
```sql
SELECT SPLIT_PART('ṭṛì ḍḍumai ṭṛì', ' ', 2);
```
```text
+--------------------------------------+
| SPLIT_PART('ṭṛì ḍḍumai ṭṛì', ' ', 2) |
+--------------------------------------+
| ḍḍumai                               |
+--------------------------------------+
```

### Ключевые слова {#keywords}

    SPLIT_PART, SPLIT
