## Описание {#description}

Функция FORMAT возвращает строку, отформатированную с использованием указанной строки формата и параметров. Правила форматирования соответствуют [спецификации формата fmt](https://fmt.dev/11.1/syntax/#format-specification-mini-language).

## Синтаксис {#syntax}

```sql
FORMAT(<format>, <args>[, ...])
```

## Параметры {#parameters}

| Параметр | Описание |
| ---------- | ----------------------------------------- |
| `<format>` | Строка формата, содержащая заполнители. Тип: VARCHAR |
| `<args>` | Параметры для форматирования (может быть несколько). Тип: ANY |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее результат форматирования согласно строке формата.

Особые случаи:
- Если хотя бы один параметр равен NULL, возвращается NULL
- В строке формата в качестве заполнителя используется `{}`
- Поддерживаются позиционные параметры (например, `{0}`, `{1}`) и именованные параметры
- Поддерживаются различные настройки форматирования (выравнивание, точность, заполнение и т. д.)

## Примеры {#examples}

1. Базовое использование: форматирование числа с заданной точностью
```sql
SELECT format('{:.2}', pi());
```
```text
+-----------------------+
| format('{:.2}', pi()) |
+-----------------------+
| 3.1                   |
+-----------------------+
```

2. Форматирование нескольких параметров
```sql
SELECT format('{0}-{1}', 'hello', 'world');
```
```text
+-------------------------------------+
| format('{0}-{1}', 'hello', 'world') |
+-------------------------------------+
| hello-world                         |
+-------------------------------------+
```

3. Выравнивание и заполнение
```sql
SELECT format('{:>10}', 123);
```
```text
+-----------------------+
| format('{:>10}', 123) |
+-----------------------+
|        123            |
+-----------------------+
```

4. Обработка значения NULL
```sql
SELECT format('{:.2}', NULL);
```
```text
+-----------------------+
| format('{:.2}', NULL) |
+-----------------------+
| NULL                  |
+-----------------------+
```

5. Обработка строк UTF-8
```sql
SELECT format('{0}-{1}', 'ṭṛṭṛ', 'ṭṛ');
```
```text
+---------------------------------------------+
| format('{0}-{1}', 'ṭṛṭṛ', 'ṭṛ')             |
+---------------------------------------------+
| ṭṛṭṛ-ṭṛ                                     |
+---------------------------------------------+
```
