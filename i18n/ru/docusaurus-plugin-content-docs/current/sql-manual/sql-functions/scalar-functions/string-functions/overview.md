# Обзор строковых функций {#string-functions-overview}

Строковые функции — это встроенные функции для обработки строковых данных. Они помогают выполнять различные операции со строками, такие как объединение, разделение, замена и поиск.

О разборе URL, извлечении доменных имён, а также кодировании и декодировании URL см. раздел [Функции для работы с URL](../url-functions/overview.md).

## Поддержка кодировки UTF-8 {#utf-8-encoding-support}

UTF-8 — это кодировка с переменной длиной символа, способная представить почти все символы мира, включая кириллицу, греческие буквы, китайские иероглифы и эмодзи.

Строковые функции Doris поддерживают кодировку UTF-8, если явно не указано иное.

Например, функция `substring` корректно обрабатывает строки в кодировке UTF-8:

### Символы ASCII {#ascii-characters}

```sql
mysql> SELECT substring('abc1', 2);
+----------------------+
| substring('abc1', 2) |
+----------------------+
| bc1                  |
+----------------------+
```

### Греческие буквы {#greek-letters}

```sql
mysql> SELECT substring('αλφαβητον', 2, 4);
+---------------------------------------+
| substring('αλφαβητον', 2, 4)          |
+---------------------------------------+
| λφαβ                                  |
+---------------------------------------+
1 row in set (0.01 sec)
```

### Китайские иероглифы {#chinese-characters}

```sql
mysql> SELECT substring('你好，世界', 2, 2);
+------------------------------------+
| substring('你好，世界', 2, 2)      |
+------------------------------------+
| 好，                               |
+------------------------------------+
```

### Эмодзи {#emojis}

```sql
mysql> SELECT substring('😊😊a😊 World!', 2, 3);
+-----------------------------------------+
| substring('😊😊a😊 World!', 2, 3)     |
+-----------------------------------------+
| 😊a😊                                  |
+-----------------------------------------+
```

## Особенности производительности {#performance-considerations}

Поскольку символы в кодировке UTF-8 имеют переменную длину, их обработка может влиять на производительность. Некоторые функции доступны в вариантах для ASCII и UTF-8.

Например:
- Функция `length` возвращает длину строки в байтах.
- Функция `char_length` возвращает количество символов в строке.

```sql
mysql> select length('你好');
+------------------+
| length('你好')   |
+------------------+
|                6 |
+------------------+

mysql> select length('αλφαβητον');
+------------------------------+
| length('αλφαβητον')          |
+------------------------------+
|                           18 |
+------------------------------+

mysql> select char_length('你好');
+-----------------------+
| char_length('你好')   |
+-----------------------+
|                     2 |
+-----------------------+

mysql> select char_length('αλφαβητον');
+-----------------------------------+
| char_length('αλφαβητον')          |
+-----------------------------------+
|                                 9 |
+-----------------------------------+
```

## Особые замечания {#special-notes}

Если строковая функция не поддерживает кодировку UTF-8, это отдельно указано в документации. Например, функция `NGRAM_SEARCH` поддерживает только строки в кодировке ASCII.

```sql
mysql> select ngram_search('abcab' , 'ab' , 2);
+----------------------------------+
| ngram_search('abcab' , 'ab' , 2) |
+----------------------------------+
|                              0.5 |
+----------------------------------+
```

Функция `NGRAM_SEARCH` выполняется и для символов вне ASCII, но результат может отличаться от ожидаемого.

```sql
mysql> select ngram_search('αβγαβ' , 'αβ' , 2);
+-----------------------------------------+
| ngram_search('αβγαβ' , 'αβ' , 2)        |
+-----------------------------------------+
|                      0.6666666666666666 |
+-----------------------------------------+
```
