## Описание {#description}

Функция RPAD (Right Padding) дополняет строку справа указанными символами до заданной длины. Если заданная длина меньше длины исходной строки, строка усекается. Эта функция рассчитывает длину в символах, а не в байтах.

## Синтаксис {#syntax}

```sql
RPAD(<str>, <len>, <pad>)
```

## Параметры {#parameters}

| Параметр | Описание |
|---------|----------------------------|
| `<str>` | Исходная строка, которую нужно дополнить. Тип: VARCHAR |
| `<len>` | Заданная длина в символах (не в байтах). Тип: INT |
| `<pad>` | Строка, используемая для дополнения. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее дополненную или усечённую строку.

Правила дополнения:
- Если len > длины исходной строки: строка pad повторно добавляется справа, пока общая длина не достигнет len
- Если len = длине исходной строки: возвращается исходная строка
- Если len < длины исходной строки: строка усекается, возвращаются только первые len символов
- Строка pad используется циклически; при необходимости берётся только часть её символов
- Длина рассчитывается в символах, поддерживаются многобайтовые символы UTF-8

Особые случаи:
- Если любой из параметров равен NULL, возвращается NULL
- Если pad — пустая строка и len > длины str, возвращается пустая строка
- Если len равен 0, возвращается пустая строка
- Если len отрицателен, возвращается NULL

## Примеры {#examples}

1. Простое дополнение справа
```sql
SELECT RPAD('hi', 5, 'xy'), RPAD('hello', 8, '*');
```
```text
+---------------------+-----------------------+
| RPAD('hi', 5, 'xy') | RPAD('hello', 8, '*') |
+---------------------+-----------------------+
| hixyx               | hello***              |
+---------------------+-----------------------+
```

2. Усечение строки
```sql
SELECT RPAD('hello', 1, ''), RPAD('hello world', 5, 'x');
```
```text
+----------------------+------------------------------+
| RPAD('hello', 1, '') | RPAD('hello world', 5, 'x')  |
+----------------------+------------------------------+
| h                    | hello                        |
+----------------------+------------------------------+
```

3. Обработка значений NULL
```sql
SELECT RPAD(NULL, 5, 'x'), RPAD('hi', NULL, 'x'), RPAD('hi', 5, NULL);
```
```text
+---------------------+------------------------+----------------------+
| RPAD(NULL, 5, 'x')  | RPAD('hi', NULL, 'x')  | RPAD('hi', 5, NULL)  |
+---------------------+------------------------+----------------------+
| NULL                | NULL                   | NULL                 |
+---------------------+------------------------+----------------------+
```

4. Пустая строка и нулевая длина
```sql
SELECT RPAD('', 0, ''), RPAD('hi', 0, 'x'), RPAD('', 5, '*');
```
```text
+-----------------+-------------------+--------------------+
| RPAD('', 0, '') | RPAD('hi', 0, 'x') | RPAD('', 5, '*')   |
+-----------------+-------------------+--------------------+
|                 |                   | *****              |
+-----------------+-------------------+--------------------+
```

5. Пустая строка дополнения
```sql
SELECT RPAD('hello', 10, ''), RPAD('hi', 2, '');
```
```text
+-----------------------+-------------------+
| RPAD('hello', 10, '')  | RPAD('hi', 2, '') |
+-----------------------+-------------------+
|                       | hi                |
+-----------------------+-------------------+
```

6. Длинная строка дополнения и циклическое повторение
```sql
SELECT RPAD('hello', 10, 'world'), RPAD('X', 7, 'ABC');
```
```text
+----------------------------+----------------------+
| RPAD('hello', 10, 'world') | RPAD('X', 7, 'ABC')  |
+----------------------------+----------------------+
| helloworld                 | XABCABC              |
+----------------------------+----------------------+
```

7. Дополнение многобайтовыми символами UTF-8
```sql
SELECT RPAD('hello', 10, 'ṭṛì'), RPAD('ḍḍumai', 3, 'x');
```
```text
+---------------------------+--------------------------+
| RPAD('hello', 10, 'ṭṛì')  | RPAD('ḍḍumai', 3, 'x')   |
+---------------------------+--------------------------+
| helloṭṛìṭṛ                | ḍḍu                      |
+---------------------------+--------------------------+
```

8. Форматирование строк с числами
```sql
SELECT RPAD('$99', 8, '.'), RPAD('Item1', 10, ' ');
```
```text
+---------------------+------------------------+
| RPAD('$99', 8, '.') | RPAD('Item1', 10, ' ') |
+---------------------+------------------------+
| $99.....            | Item1                  |
+---------------------+------------------------+
```

9. Выравнивание столбцов таблицы
```sql
SELECT RPAD('Name', 15, ' '), RPAD('Price', 10, ' ');
```
```text
+------------------------+------------------------+
| RPAD('Name', 15, ' ')  | RPAD('Price', 10, ' ') |
+------------------------+------------------------+
| Name                   | Price                  |
+------------------------+------------------------+
```

10. Обработка отрицательной длины
```sql
SELECT RPAD('hello', -1, 'x'), RPAD('test', -5, '*');
```
```text
+------------------------+------------------------+
| RPAD('hello', -1, 'x') | RPAD('test', -5, '*')  |
+------------------------+------------------------+
| NULL                   | NULL                   |
+------------------------+------------------------+
```
