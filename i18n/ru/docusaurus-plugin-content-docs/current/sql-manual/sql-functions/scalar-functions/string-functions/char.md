# CHAR {#char}

## Описание {#description}

Функция CHAR интерпретирует каждый аргумент как целое число и возвращает строку из символов, соответствующих этим целочисленным кодам.

## Синтаксис {#syntax}

```sql
CHAR(<expr>[, <expr> ...] [USING <charset_name>])
```

## Параметры {#parameters}

| Параметр | Описание |
| ------------------ | ----------------------------------------- |
| `<expr>` | Целочисленный код, преобразуемый в символ. Тип: INT |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR: строку из символов, соответствующих целочисленным кодам, переданным в аргументах.

Особые случаи:
- Если какой-либо аргумент равен NULL, возвращает пустую строку
- Если результирующая строка недопустима для заданного набора символов, возвращает NULL
- Аргументы со значением больше 255 преобразуются в многобайтовые символы. Например, `CHAR(15049882)` эквивалентно `CHAR(229, 164, 154)`

## Примеры {#examples}

1. Базовое использование: формирование символов ASCII
```sql
SELECT CHAR(68, 111, 114, 105, 115);
```
```text
+--------------------------------------+
| CHAR(68, 111, 114, 105, 115)         |
+--------------------------------------+
| Doris                                |
+--------------------------------------+
```

2. Многобайтовые символы UTF-8 (китайские)
```sql
SELECT CHAR(15049882, 15179199, 14989469);
```
```text
+--------------------------------------------+
| CHAR(15049882, 15179199, 14989469)        |
+--------------------------------------------+
| 多睿丝                                     |
+--------------------------------------------+
```

3. Недопустимый символ приводит к возврату NULL
```sql
SELECT CHAR(255);
```
```text
+-------------------+
| CHAR(255)             |
+-------------------+
| NULL              |
+-------------------+
```

4. Обработка значения NULL
```sql
SELECT CHAR(NULL);
```
```text
+------------+
| CHAR(NULL) |
+------------+
|            |
+------------+
```
