## Описание {#description}

Функция LTRIM удаляет подряд идущие пробелы или символы из заданного набора с левой стороны (из начала) строки. Функция просматривает строку слева и удаляет все подряд идущие целевые символы, пока не встретит символ, не входящий в целевой набор.

## Синтаксис {#syntax}

```sql
LTRIM(<str> [, <trim_chars>])
```

## Параметры {#parameters}

| Параметр      | Описание                                                                                                                                                                                                                                                                           |
|----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<str>`        | Исходная строка, из начала которой удаляются символы. Тип: VARCHAR                                                                                                                                                                                                                                  |
| `<trim_chars>` | Необязательный параметр, задающий набор удаляемых символов. Если не указан, по умолчанию удаляются пробельные символы. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR — строку после удаления заданных символов с левой стороны.

Правила удаления:
- Символы удаляются только с левой стороны (из начала) строки
- Удаляются все подряд идущие символы, входящие в trim_chars
- Удаление прекращается при обнаружении символа, не входящего в trim_chars
- Если trim_chars не указан, по умолчанию удаляются пробельные символы (включая пробелы, символы табуляции, перевода строки и т. д.)

Особые случаи:
- Если любой из параметров равен NULL, возвращается NULL
- Если str — пустая строка, возвращается пустая строка
- Если trim_chars — пустая строка, возвращается исходная строка
- Если вся строка состоит из символов, входящих в trim_chars, возвращается пустая строка

## Примеры {#examples}

1. Удаление пробелов в начале строки
```sql
SELECT LTRIM('   ab d');
```
```text
+-------------------+
| LTRIM('   ab d')  |
+-------------------+
| ab d              |
+-------------------+
```

2. Удаление заданных символов
```sql
SELECT LTRIM('ababccaab', 'ab');
```
```text
+----------------------------+
| LTRIM('ababccaab', 'ab')   |
+----------------------------+
| ccaab                      |
+----------------------------+
```

3. Обработка значений NULL
```sql
SELECT LTRIM(NULL), LTRIM('test', NULL);
```
```text
+-------------+---------------------+
| LTRIM(NULL) | LTRIM('test', NULL) |
+-------------+---------------------+
| NULL        | NULL                |
+-------------+---------------------+
```
