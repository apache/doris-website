## Описание {#description}

Выполняет URL-кодирование переданного текста с использованием кодировки UTF-8. Обычно используется для кодирования параметров, передаваемых в составе URL

## Синтаксис {#syntax}

```sql
URL_ENCODE(  <str>  ) 
```

## Обязательные параметры {#required-parameters}
| Параметры | Описание |
|------|------|
| `<str>` | Строка для кодирования |

##  Возвращаемое значение {#return-value}


Результат URL-кодирования переданного текста с использованием кодировки UTF-8

##  Пример {#example}

```sql
select  URL_ENCODE('Doris Q&A');
```

```text
+-------------------------+
| url_encode('Doris Q&A') |
+-------------------------+
| Doris+Q%26A             |
+-------------------------+

```
