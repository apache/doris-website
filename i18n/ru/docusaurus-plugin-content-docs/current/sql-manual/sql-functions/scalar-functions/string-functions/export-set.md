## Описание {#description}

`EXPORT_SET` преобразует каждый бит целого числа в заданную строку и объединяет их в результирующую строку. Для каждого бита в `bits`, равного 1, в соответствующей позиции результата отображается строка `on`; для каждого бита, равного 0, отображается строка `off`. Биты проверяются справа налево (то есть от младшего к старшему), а в результирующую строку объединяются слева направо. Биты разделяются строкой `separator` (по умолчанию — запятой `,`).

Количество отображаемых битов определяется параметром `number_of_bits` и по умолчанию составляет 64. Если параметр не указан или выходит за пределы допустимого диапазона (превышает 64), используется значение 64.

Эта функция работает аналогично [функции EXPORT_SET в MySQL](https://dev.mysql.com/doc/refman/8.4/en/string-functions.html#function_export-set).

## Синтаксис {#syntax}

```sql
EXPORT_SET(bits, on, off[, separator[, number_of_bits]])
```

## Параметры {#parameters}

| Параметр         | Описание |
|-------------------|-------------|
| `bits`            | Целое число типа LARGEINT, используемое для преобразования. Если значение меньше -2^63, оно обрабатывается как -2^63. Если значение больше 2^64 - 1, оно обрабатывается как 2^63 - 1. |
| `on`              | Строка, отображаемая для бита, равного 1. |
| `off`             | Строка, отображаемая для бита, равного 0. |
| `separator`       | Необязательный параметр: строка для разделения битов. По умолчанию — ','. |
| `number_of_bits`  | Необязательный параметр: количество битов, отображаемых в результате. Поддерживается целочисленный тип INT. По умолчанию — 64; если значение выходит за пределы диапазона [0, 64], используется значение по умолчанию. |

## Возвращаемое значение {#return-value}

Возвращает строку. Для каждого бита в `bits`, начиная с младшего и заканчивая старшим, 1 заменяется на `on`, а 0 — на `off`. Полученные строки объединяются по порядку. Биты разделяются строкой `separator`; итоговый результат содержит `number_of_bits` битов.

Если `number_of_bits` выходит за пределы диапазона [-2^31, 2^31 - 1] или любой параметр функции равен NULL, возвращается NULL.
