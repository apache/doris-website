## Описание {#description}

Функция STRCMP сравнивает две строки лексикографически. Она возвращает целое число, указывающее результат сравнения.

## Синтаксис {#syntax}

```sql
STRCMP(<str0>, <str1>)
```

## Параметры {#parameters}
| Параметр | Описание |
| --------- | ----------------------------------------- |
| `<str0>` | Первая строка для сравнения. Тип: VARCHAR |
| `<str1>` | Вторая строка для сравнения. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа TINYINT, указывающее результат сравнения:
- Возвращает 0: если str0 равна str1
- Возвращает 1: если str0 лексикографически больше str1
- Возвращает -1: если str0 лексикографически меньше str1

Особые случаи:
- Возвращает NULL, если какой-либо аргумент равен NULL

## Примеры {#examples}

1. Сравнение одинаковых строк
```sql
SELECT strcmp('test', 'test');
```
```text
+------------------------+
| strcmp('test', 'test') |
+------------------------+
|                      0 |
+------------------------+
```

2. Первая строка больше
```sql
SELECT strcmp('test1', 'test');
```
```text
+-------------------------+
| strcmp('test1', 'test') |
+-------------------------+
|                       1 |
+-------------------------+
```

3. Первая строка меньше
```sql
SELECT strcmp('test', 'test1');
```
```text
+-------------------------+
| strcmp('test', 'test1') |
+-------------------------+
|                      -1 |
+-------------------------+
```
