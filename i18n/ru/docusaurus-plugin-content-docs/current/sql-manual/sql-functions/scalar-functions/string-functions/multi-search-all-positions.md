## Описание {#description}

Функция MULTI_SEARCH_ALL_POSITIONS выполняет пакетный поиск нескольких подстрок в строке. Возвращает массив с позицией первого вхождения каждой подстроки. Поиск выполняется с учётом регистра.

## Синтаксис {#syntax}

```sql
MULTI_SEARCH_ALL_POSITIONS(<haystack>, <needles>)
```

## Параметры {#parameters}

| Параметр | Описание |
| ------------ | ----------------------------------------- |
| `<haystack>` | Строка, в которой выполняется поиск. Тип: VARCHAR |
| `<needles>` | Массив подстрок для поиска. Тип: ARRAY<VARCHAR> |

## Возвращаемое значение {#return-value}

Возвращает значение типа ARRAY<INT>, где i-й элемент массива представляет позицию первого вхождения i-й подстроки из `<needles>` в `<haystack>`.

Особые случаи:
- Отсчёт позиций начинается с 1
- Если подстрока не найдена, для соответствующей позиции возвращается 0
- Поиск выполняется с учётом регистра
- Если `<haystack>` имеет значение NULL, возвращается массив нулей той же длины, что и `<needles>`
- Если `<needles>` имеет значение NULL, возвращается пустой массив `[]`, в том числе когда оба параметра имеют значение NULL
- Возвращается позиция в байтах, а не позиция n-го символа

## Примеры {#examples}

1. Базовое использование: поиск нескольких подстрок
```sql
SELECT multi_search_all_positions('Hello, World!', ['Hello', 'World']);
```
```text
+----------------------------------------------------------+
| multi_search_all_positions('Hello, World!', ['Hello', 'World']) |
+----------------------------------------------------------+
| [1, 8]                                                   |
+----------------------------------------------------------+
```

2. Поиск с учётом регистра: подстроки в нижнем регистре не найдены
```sql
SELECT multi_search_all_positions('Hello, World!', ['hello', '!', 'world']);
```
```text
+----------------------------------------------------------------------+
| multi_search_all_positions('Hello, World!', ['hello', '!', 'world']) |
+----------------------------------------------------------------------+
| [0, 13, 0]                                                           |
+----------------------------------------------------------------------+
```

3. Смешанный поиск: найдена часть подстрок
```sql
SELECT multi_search_all_positions('Hello, World!', ['Hello', '!', 'xyz']);
```
```text
+--------------------------------------------------------------------+
| multi_search_all_positions('Hello, World!', ['Hello', '!', 'xyz']) |
+--------------------------------------------------------------------+
| [1, 13, 0]                                                         |
+--------------------------------------------------------------------+
```

4. Пустой массив
```sql
SELECT multi_search_all_positions('Hello', []);
```
```text
+------------------------------------------+
| multi_search_all_positions('Hello', [])  |
+------------------------------------------+
| []                                       |
+------------------------------------------+
```

5. Поддержка специальных символов UTF-8
```sql
SELECT multi_search_all_positions('ṭṛì ḍḍumai Hello', ['ṭṛì', 'Hello', 'test']);
```
```text
+----------------------------------------------------------------------------------------+
| multi_search_all_positions('ṭṛì ḍḍumai Hello', ['ṭṛì', 'Hello', 'test'])               |
+----------------------------------------------------------------------------------------+
| [1, 21, 0]                                                                             |
+----------------------------------------------------------------------------------------+
```

Входные значения NULL:

```sql
SELECT multi_search_all_positions(NULL, ['a', 'b']) AS null_haystack,
       multi_search_all_positions('a', NULL) AS null_needles,
       multi_search_all_positions(NULL, NULL) AS both_null;
```
```text
+---------------+--------------+-----------+
| null_haystack | null_needles | both_null |
+---------------+--------------+-----------+
| [0, 0]        | []           | []        |
+---------------+--------------+-----------+
```
