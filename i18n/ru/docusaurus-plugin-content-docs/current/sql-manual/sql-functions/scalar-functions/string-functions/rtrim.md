## Описание {#description}

Функция RTRIM используется для удаления подряд идущих пробелов или указанных строк с конца строки. Если второй параметр не указан, удаляются завершающие пробелы; если указан, функция удаляет указанную строку целиком с правого края.

## Синтаксис {#syntax}

```sql
RTRIM(<str>[, <rhs>])
```

## Параметры {#parameters}

| Параметр | Описание |
| --------- | ----------- |
| `<str>` | Обрабатываемая строка. Тип: VARCHAR |
| `<rhs>` | Необязательный параметр: символы, которые нужно удалить с конца строки. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR.

Особые случаи:
- Если какой-либо параметр равен NULL, возвращается NULL
- Если rhs не указан, удаляются завершающие пробелы
- Если rhs указан, строка rhs удаляется целиком (а не посимвольно)

## Примеры {#examples}

1. Удаление завершающих пробелов
```sql
SELECT rtrim('ab d   ') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. Удаление указанной строки с конца
```sql
SELECT rtrim('ababccaab', 'ab') str;
```
```text
+---------+
| str     |
+---------+
| ababcca |
+---------+
```

3. По умолчанию удаляются только пробелы ASCII: `RTRIM` **не** удаляет символы табуляции (`\t`) или перевода строки (`\n`) без второго аргумента. Сравните `LENGTH` до и после: удаляется только один завершающий пробел ASCII; `\t\n` сохраняются.
```sql
SELECT LENGTH('hello world  \t\n '), LENGTH(RTRIM('hello world  \t\n '));
```
```text
+------------------------------+-------------------------------------+
| LENGTH('hello world  \t\n ') | LENGTH(RTRIM('hello world  \t\n ')) |
+------------------------------+-------------------------------------+
|                           16 |                                  15 |
+------------------------------+-------------------------------------+
```

4. Поддержка символов UTF-8
```sql
SELECT rtrim('ṭṛì ḍḍumai   ');
```
```text
+---------------------------+
| rtrim('ṭṛì ḍḍumai   ')    |
+---------------------------+
| ṭṛì ḍḍumai                |
+---------------------------+
```

5. Если совпадающего суффикса нет, возвращается исходная строка
```sql
SELECT rtrim('Hello World', 'xyz');
```
```text
+---------------------------------+
| rtrim('Hello World', 'xyz')     |
+---------------------------------+
| Hello World                     |
+---------------------------------+
```

6. Обработка значений NULL
```sql
SELECT rtrim(NULL), rtrim('Hello', NULL);
```
```text
+-------------+------------------------+
| rtrim(NULL) | rtrim('Hello', NULL)   |
+-------------+------------------------+
| NULL        | NULL                   |
+-------------+------------------------+
```

7. Обработка пустой строки
```sql
SELECT rtrim(''), rtrim('abc', '');
```
```text
+-----------+-------------------+
| rtrim('') | rtrim('abc', '')  |
+-----------+-------------------+
|           | abc               |
+-----------+-------------------+
```

8. Удаление повторяющегося шаблона с конца строки
```sql
SELECT rtrim('abcabcabc', 'abc');
```
```text
+-------------------------------+
| rtrim('abcabcabc', 'abc')     |
+-------------------------------+
|                               |
+-------------------------------+
```

9. Несколько вхождений: удаляется только совпадение в конце строки
```sql
SELECT rtrim('HelloHelloWorld', 'Hello');
```
```text
+---------------------------------------+
| rtrim('HelloHelloWorld', 'Hello')     |
+---------------------------------------+
| HelloHelloWorld                       |
+---------------------------------------+
```
