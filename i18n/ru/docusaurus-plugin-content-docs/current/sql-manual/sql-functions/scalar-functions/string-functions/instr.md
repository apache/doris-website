## Описание {#description}

Функция INSTR возвращает позицию первого вхождения подстроки в основной строке; отсчёт позиций начинается с 1. Это часто используемая функция поиска в строках, которая поддерживает точное сопоставление и учитывает регистр. Функция широко применяется при обработке текста, очистке данных и анализе строк.

## Синтаксис {#syntax}

```sql
INSTR(<str>, <substr>)
```

## Параметры {#parameters}

| Параметр | Описание |
|--------|-----------|
| `<str>` | Основная строка, в которой выполняется поиск. Тип: VARCHAR |
| `<substr>` | Искомая подстрока. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа INT, обозначающее позицию первого вхождения подстроки в основной строке.

Правила поиска:
- Возвращает индекс позиции, отсчитываемый с 1 (а не с 0)
- Если подстрока не найдена, возвращает 0
- Поиск учитывает регистр
- Поддерживает корректное определение позиций для многобайтовых символов UTF-8
- Предусмотрена особая обработка пустых строк

Особые случаи:
- Если любой из параметров равен NULL, возвращает NULL
- Если подстрока является пустой строкой, возвращает 1 (пустая строка «присутствует» в любой позиции)
- Если основная строка пуста, а подстрока нет, возвращает 0
- Поддерживает поиск подстрок, содержащих специальные знаки и символы

## Примеры {#examples}

1. Простой поиск символа
```sql
SELECT INSTR('abc', 'b'), INSTR('abc', 'd');
```
```text
+-------------------+-------------------+
| INSTR('abc', 'b') | INSTR('abc', 'd') |
+-------------------+-------------------+
|                 2 |                 0 |
+-------------------+-------------------+
```

2. Поиск подстроки
```sql
SELECT INSTR('hello world', 'world'), INSTR('hello world', 'WORLD');
```
```text
+------------------------------+------------------------------+
| INSTR('hello world', 'world') | INSTR('hello world', 'WORLD') |
+------------------------------+------------------------------+
|                            7 |                            0 |
+------------------------------+------------------------------+
```

3. Обработка значений NULL
```sql
SELECT INSTR(NULL, 'test'), INSTR('test', NULL);
```
```text
+---------------------+---------------------+
| INSTR(NULL, 'test') | INSTR('test', NULL) |
+---------------------+---------------------+
| NULL                | NULL                |
+---------------------+---------------------+
```

4. Обработка пустых строк
```sql
SELECT INSTR('hello', ''), INSTR('', 'world');
```
```text
+--------------------+---------------------+
| INSTR('hello', '') | INSTR('', 'world') |
+--------------------+---------------------+
|                  1 |                   0 |
+--------------------+---------------------+
```

5. Повторные вхождения (возвращается первое совпадение)
```sql
SELECT INSTR('abcabc', 'abc'), INSTR('banana', 'a');
```
```text
+------------------------+----------------------+
| INSTR('abcabc', 'abc') | INSTR('banana', 'a') |
+------------------------+----------------------+
|                      1 |                    2 |
+------------------------+----------------------+
```

6. Специальные знаки и символы
```sql
SELECT INSTR('user@example.com', '@'), INSTR('price: $99.99', '$');
```
```text
+--------------------------------+-----------------------------+
| INSTR('user@example.com', '@') | INSTR('price: $99.99', '$') |
+--------------------------------+-----------------------------+
|                              5 |                           8 |
+--------------------------------+-----------------------------+
```

7. Многобайтовые символы UTF-8
```sql
SELECT INSTR('ṭṛì ḍḍumai hello', 'ḍḍumai'), INSTR('ṭṛì ḍḍumai hello', 'hello');
```
```text
+--------------------------------------------------+---------------------------------------------+
| INSTR('ṭṛì ḍḍumai hello', 'ḍḍumai')              | INSTR('ṭṛì ḍḍumai hello', 'hello')          |
+--------------------------------------------------+---------------------------------------------+
|                                                5 |                                          12 |
+--------------------------------------------------+---------------------------------------------+
```

8. Строки с числами
```sql
SELECT INSTR('123456789', '456'), INSTR('123-456-789', '-');
```
```text
+---------------------------+---------------------------+
| INSTR('123456789', '456') | INSTR('123-456-789', '-') |
+---------------------------+---------------------------+
|                         4 |                         4 |
+---------------------------+---------------------------+
```

9. Поиск подстроки в тексте из нескольких слов
```sql
SELECT INSTR('The quick brown fox', 'quick'), INSTR('The quick brown fox', 'slow');
```
```text
+---------------------------------------+--------------------------------------+
| INSTR('The quick brown fox', 'quick') | INSTR('The quick brown fox', 'slow') |
+---------------------------------------+--------------------------------------+
|                                     5 |                                    0 |
+---------------------------------------+--------------------------------------+
```

10. Поиск в путях и URL
```sql
SELECT INSTR('/home/user/file.txt', '/'), INSTR('https://www.example.com', '://');
```
```text
+-----------------------------------+-----------------------------------------+
| INSTR('/home/user/file.txt', '/') | INSTR('https://www.example.com', '://') |
+-----------------------------------+-----------------------------------------+
|                                 1 |                                       6 |
+-----------------------------------+-----------------------------------------+
```
