## Описание {#description}

Функция SPLIT_BY_STRING разбивает входную строку на массив строк по заданной строке-разделителю. Эта функция поддерживает разделители из нескольких символов и может отличаться от аналогичных функций в других базах данных способом обработки пустых строк.

## Синтаксис {#syntax}

```sql
SPLIT_BY_STRING(<str>, <separator>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|-------------|
| `<str>` | Исходная строка для разбиения. Тип: VARCHAR |
| `<separator>` | Строка-разделитель, используемая для разбиения. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа ARRAY<VARCHAR>, содержащее массив строк, полученных при разбиении по разделителю.

Правила разбиения:
- Разбиение выполняется по каждому вхождению separator в str
- Последовательные разделители создают элементы с пустыми строками
- Разделители в начале или в конце строки создают элементы с пустыми строками

Особые случаи:
- Если любой из параметров равен NULL, возвращается NULL
- Если str является пустой строкой, возвращается пустой массив `[]`
- Если separator является пустой строкой, str разбивается на символы (каждый символ становится элементом массива)
- Если separator отсутствует в str, возвращается массив, содержащий исходную строку
- Если str содержит только разделители, возвращается соответствующее количество пустых строк в зависимости от числа разделителей

## Примеры {#examples}

1. Простое разбиение строки
```sql
SELECT SPLIT_BY_STRING('hello', 'l');
```
```text
+-------------------------------+
| SPLIT_BY_STRING('hello', 'l') |
+-------------------------------+
| ["he", "", "o"]               |
+-------------------------------+
```

2. Пустой разделитель (разбиение на символы)
```sql
SELECT SPLIT_BY_STRING('hello', '');
```
```text
+------------------------------+
| SPLIT_BY_STRING('hello', '') |
+------------------------------+
| ["h", "e", "l", "l", "o"]    |
+------------------------------+
```

3. Разделитель из нескольких символов
```sql
SELECT SPLIT_BY_STRING('apple::banana::cherry', '::');
```
```text
+------------------------------------------------+
| SPLIT_BY_STRING('apple::banana::cherry', '::') |
+------------------------------------------------+
| ["apple", "banana", "cherry"]                  |
+------------------------------------------------+
```

4. Обработка значений NULL
```sql
SELECT SPLIT_BY_STRING(NULL, ','), SPLIT_BY_STRING('hello', NULL);
```
```text
+-----------------------------+----------------------------------+
| SPLIT_BY_STRING(NULL, ',')  | SPLIT_BY_STRING('hello', NULL)   |
+-----------------------------+----------------------------------+
| NULL                        | NULL                             |
+-----------------------------+----------------------------------+
```

5. Обработка пустых строк
```sql
SELECT SPLIT_BY_STRING('', ','), SPLIT_BY_STRING('hello', 'xyz');
```
```text
+---------------------------+----------------------------------+
| SPLIT_BY_STRING('', ',')  | SPLIT_BY_STRING('hello', 'xyz')  |
+---------------------------+----------------------------------+
| []                        | ["hello"]                       |
+---------------------------+----------------------------------+
```

6. Последовательные разделители
```sql
SELECT SPLIT_BY_STRING('a,,b,c', ',');
```
```text
+-------------------------------+
| SPLIT_BY_STRING('a,,b,c', ',') |
+-------------------------------+
| ["a", "", "b", "c"]           |
+-------------------------------+
```

7. Разделители в начале и в конце строки
```sql
SELECT SPLIT_BY_STRING(',a,b,', ',');
```
```text
+------------------------------+
| SPLIT_BY_STRING(',a,b,', ',') |
+------------------------------+
| ["", "a", "b", ""]           |
+------------------------------+
```

8. Строка содержит только разделители
```sql
SELECT SPLIT_BY_STRING('|||', '|');
```
```text
+----------------------------+
| SPLIT_BY_STRING('|||', '|') |
+----------------------------+
| ["", "", "", ""]           |
+----------------------------+
```

9. Разбиение строки с символами UTF-8
```sql
SELECT SPLIT_BY_STRING('ṭṛì ḍḍumai ṭṛì', ' ');
```
```text
+--------------------------------------+
| SPLIT_BY_STRING('ṭṛì ḍḍumai ṭṛì', ' ') |
+--------------------------------------+
| ["ṭṛì", "ḍḍumai", "ṭṛì"]              |
+--------------------------------------+
```

10. Отсутствующий разделитель
```sql
SELECT SPLIT_BY_STRING('hello world', 'xyz');
```
```text
+--------------------------------------+
| SPLIT_BY_STRING('hello world', 'xyz') |
+--------------------------------------+
| ["hello world"]                      |
+--------------------------------------+
```

### Ключевые слова {#keywords}

    SPLIT_BY_STRING, SPLIT
