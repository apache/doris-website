## Описание {#description}

Функция TRIM_IN используется для удаления указанных символов в начале и конце строки. Если набор символов не указан, по умолчанию удаляются пробелы в начале и конце строки. Если набор символов указан, функция удаляет с обоих концов строки все символы из этого набора (независимо от их порядка в наборе).

Главная особенность TRIM_IN заключается в том, что она удаляет любые комбинации символов из указанного набора, тогда как функция TRIM удаляет символы на основе точного совпадения строк.

## Синтаксис {#syntax}

```sql
TRIM_IN(<str>[, <rhs>])
```

## Параметры {#parameters}

| Параметр | Описание |
| --------- | ------------------------------------------------------------------------ |
| `<str>` | Обрабатываемая строка. Тип: VARCHAR |
| `<rhs>` | Необязательный параметр — набор удаляемых символов. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает обработанную строку типа VARCHAR.

Особые случаи:
- Если str имеет значение NULL, возвращает NULL
- Если rhs не указан, удаляет все пробелы в начале и конце строки
- Если rhs указан, удаляет с обоих концов строки все символы, входящие в rhs, пока не встретит символы, не входящие в rhs

## Примеры {#examples}

1. Удаление пробелов в начале и конце строки
```sql
SELECT trim_in('   ab d   ') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. Удаление символов из указанного набора
```sql
SELECT trim_in('ababccaab', 'ab') str;
```
```text
+------+
| str  |
+------+
| cc   |
+------+
```

3. Сравнение с функцией TRIM
```sql
SELECT trim_in('ababccaab', 'ab'), trim('ababccaab', 'ab');
```
```text
+----------------------------+-------------------------+
| trim_in('ababccaab', 'ab') | trim('ababccaab', 'ab') |
+----------------------------+-------------------------+
| cc                         | cca                     |
+----------------------------+-------------------------+
```

4. Порядок символов в наборе не имеет значения
```sql
SELECT trim_in('abcHelloabc', 'cba');
```
```text
+--------------------------------+
| trim_in('abcHelloabc', 'cba')  |
+--------------------------------+
| Hello                          |
+--------------------------------+
```

5. Поддержка символов UTF-8
```sql
SELECT trim_in('+++ṭṛì ḍḍumai+++', '+');
```
```text
+--------------------------------------+
| trim_in('+++ṭṛì ḍḍumai+++', '+')    |
+--------------------------------------+
| ṭṛì ḍḍumai                           |
+--------------------------------------+
```

6. Обработка значения NULL
```sql
SELECT trim_in(NULL, 'abc');
```
```text
+-----------------------+
| trim_in(NULL, 'abc')  |
+-----------------------+
| NULL                  |
+-----------------------+
```

7. Обработка пустых строк
```sql
SELECT trim_in('', 'abc'), trim_in('abc', '');
```
```text
+--------------------+--------------------+
| trim_in('', 'abc') | trim_in('abc', '') |
+--------------------+--------------------+
|                    | abc                |
+--------------------+--------------------+
```

### Ключевые слова {#keywords}
