## Описание {#description}

Функция TRANSLATE выполняет посимвольную замену в строке, преобразуя символы исходной строки в соответствии с правилами сопоставления. Эта функция заменяет каждый символ исходной строки, присутствующий в строке 'from', соответствующим символом на той же позиции в строке 'to'.

## Синтаксис {#syntax}

```sql
TRANSLATE(<source>, <from>, <to>)
```

## Параметры {#parameters}
| Параметр | Описание                                         |
| --------- | --------------------------------------------------- |
| `<source>` | Исходная строка для преобразования. Тип: VARCHAR    |
| `<from>` | Набор символов, подлежащих замене. Тип: VARCHAR |
| `<to>` | Набор символов для замены. Тип: VARCHAR    |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее строку, преобразованную в соответствии с правилами сопоставления символов.

Правила сопоставления символов:
- Символы сопоставляются один к одному на основе их позиций в строках 'from' и 'to'
- 1-й символ в 'from' соответствует 1-му символу в 'to', 2-й соответствует 2-му и так далее
- Если 'from' содержит повторяющиеся символы, используется сопоставление для первого вхождения, а последующие повторения игнорируются
- Символы исходной строки, отсутствующие в строке 'from', остаются без изменений

Особые случаи:
- Возвращает NULL, если любой из параметров равен NULL
- Возвращает пустую строку, если исходная строка пуста
- Возвращает исходную строку без изменений, если строка 'from' пуста
- Удаляет из исходной строки все символы, присутствующие в 'from', если строка 'to' пуста
- Если строка 'to' короче строки 'from', из исходной строки удаляются символы, соответствующие лишним символам в 'from'

## Примеры {#examples}

1. Простая замена символа
```sql
SELECT translate('abcd', 'a', 'z');
```
```text
+---------------------------+
| translate('abcd', 'a', 'z') |
+---------------------------+
| zbcd                      |
+---------------------------+
```

2. Многократная замена одного и того же символа
```sql
SELECT translate('abcda', 'a', 'z');
```
```text
+----------------------------+
| translate('abcda', 'a', 'z') |
+----------------------------+
| zbcdz                      |
+----------------------------+
```

3. Замена специального символа
```sql
SELECT translate('Palhoça', 'ç', 'c');
```
```text
+--------------------------------+
| translate('Palhoça', 'ç', 'c') |
+--------------------------------+
| Palhoca                        |
+--------------------------------+
```

4. Удаление символа (пустая строка 'to')
```sql
SELECT translate('abcd', 'a', '');
```
```text
+----------------------------+
| translate('abcd', 'a', '') |
+----------------------------+
| bcd                        |
+----------------------------+
```

5. Повторяющиеся символы в строке 'from' (используется только первое сопоставление)
```sql
SELECT TRANSLATE('abacad', 'aac', 'zxy');
```
```text
+-----------------------------------+
| TRANSLATE('abacad', 'aac', 'zxy') |
+-----------------------------------+
| zbzyzd                            |
+-----------------------------------+
```

6. Строка 'to' короче строки 'from' (лишние символы удаляются)
```sql
SELECT TRANSLATE('abcde', 'ace', 'xy');
```
```text
+-------------------------------+
| TRANSLATE('abcde', 'ace', 'xy') |
+-------------------------------+
| xbyd                          |
+-------------------------------+
```

7. Замена символов UTF-8
```sql
SELECT TRANSLATE('ṭṛì ḍḍumai', 'ṭṛ', 'ab');
```
```text
+-----------------------------------+
| TRANSLATE('ṭṛì ḍḍumai', 'ṭṛ', 'ab') |
+-----------------------------------+
| abì ḍḍumai                        |
+-----------------------------------+
```

8. Замена цифр
```sql
SELECT TRANSLATE('a1b2c3', '123', 'xyz');
```
```text
+----------------------------------+
| TRANSLATE('a1b2c3', '123', 'xyz') |
+----------------------------------+
| axbycz                           |
+----------------------------------+
```

9. Замена специальных знаков
```sql
SELECT TRANSLATE('hello@world.com', '@.', '-_');
```
```text
+--------------------------------------------+
| TRANSLATE('hello@world.com', '@.', '-_')   |
+--------------------------------------------+
| hello-world_com                            |
+--------------------------------------------+
```
