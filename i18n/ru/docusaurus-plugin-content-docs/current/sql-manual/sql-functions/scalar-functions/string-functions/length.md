## Описание {#description}

Функция LENGTH возвращает длину строки в байтах. Эта функция вычисляет количество байтов, которое занимает строка в кодировке UTF-8, а не количество символов.

**Обратите внимание на отличие от CHAR_LENGTH:**
- `LENGTH()` возвращает количество байтов
- `CHAR_LENGTH()` и `CHARACTER_LENGTH()` возвращают количество символов
- Для символов ASCII количество байтов равно количеству символов
- Для многобайтовых символов (например, китайских иероглифов и эмодзи) количество байтов обычно превышает количество символов

## Псевдоним {#alias}
- `OCTET_LENGTH()`

## Синтаксис {#syntax}

```sql
LENGTH(<str>)
```

## Параметры {#parameters}

| Параметр | Описание |
|---------|---------------|
| `<str>` | Строка, длину которой в байтах требуется вычислить. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа INT, представляющее длину строки в байтах.

Особые случаи:
- Если параметр равен NULL, возвращает NULL
- Для пустой строки возвращает 0
- Результат представляет собой количество байтов в кодировке UTF-8

## Примеры {#examples}

1. Символы ASCII (количество байтов = количество символов)
```sql
SELECT LENGTH('abc'), CHAR_LENGTH('abc');
```
```text
+---------------+--------------------+
| LENGTH('abc') | CHAR_LENGTH('abc') |
+---------------+--------------------+
|             3 |                  3 |
+---------------+--------------------+
```

2. Китайские иероглифы (количество байтов > количество символов)
```sql
SELECT LENGTH('中国'), CHAR_LENGTH('中国');
```
```text
+------------------+---------------------+
| LENGTH('中国')   | CHAR_LENGTH('中国') |
+------------------+---------------------+
|                6 |                   2 |
+------------------+---------------------+
```

3. Обработка значения NULL
```sql
SELECT LENGTH(NULL);
```
```text
+--------------+
| LENGTH(NULL) |
+--------------+
|         NULL |
+--------------+
```

4. Пустая строка
```sql
SELECT LENGTH('');
```
```text
+------------+
| LENGTH('') |
+------------+
|          0 |
+------------+
```

5. Сочетание символов разных типов
```sql
SELECT LENGTH('Hello世界'), CHAR_LENGTH('Hello世界');
```
```text
+-----------------------+----------------------------+
| LENGTH('Hello世界')   | CHAR_LENGTH('Hello世界')   |
+-----------------------+----------------------------+
|                    11 |                          7 |
+-----------------------+----------------------------+
```

6. Экранированные символы и пробелы ASCII
```sql
SELECT LENGTH('\t\n\r'), LENGTH('  ');
```
```text
+------------------+--------------+
| LENGTH('\t\n\r') | LENGTH('  ') |
+------------------+--------------+
|                3 |            2 |
+------------------+--------------+
```

7. Многобайтовые символы UTF-8: сравнение длины в байтах и количества символов
```sql
SELECT LENGTH('ṭṛì'), CHAR_LENGTH('ṭṛì');
```
```text
+--------------------+-------------------------+
| LENGTH('ṭṛì')      | CHAR_LENGTH('ṭṛì')      |
+--------------------+-------------------------+
|                  8 |                       3 |
+--------------------+-------------------------+
```

8. Эмодзи (обычно 4 байта на глиф)
```sql
SELECT LENGTH('😀😁'), CHAR_LENGTH('😀😁');
```
```text
+--------------------+-------------------------+
| LENGTH('😀😁')         | CHAR_LENGTH('😀😁')         |
+--------------------+-------------------------+
|                  8 |                       2 |
+--------------------+-------------------------+
```

9. Строки из цифр
```sql
SELECT LENGTH('12345'), CHAR_LENGTH('12345');
```
```text
+-----------------+----------------------+
| LENGTH('12345') | CHAR_LENGTH('12345') |
+-----------------+----------------------+
|               5 |                    5 |
+-----------------+----------------------+
```
