## Описание {#description}

Функция SOUNDEX вычисляет [код Soundex](https://en.wikipedia.org/wiki/Soundex) для строки. Soundex представляет собой фонетический алгоритм, который преобразует английские слова в коды, отражающие их произношение, поэтому слова с похожим произношением получают одинаковый код.

Правило кодирования: возвращается код из 4 символов, состоящий из одной прописной буквы и трёх цифр (например, S530).

## Синтаксис {#syntax}

```sql
SOUNDEX(<expr>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -------- | ----------------------------------------- |
| `<expr>` | Строка, для которой вычисляется код Soundex (поддерживаются только символы ASCII). Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR(4), представляющее код Soundex для строки.

Особые случаи:
- Если аргумент равен NULL, возвращается NULL
- Если строка пуста или не содержит букв, возвращается пустая строка
- Обрабатываются только буквы ASCII, остальные символы игнорируются
- Символы вне ASCII вызывают ошибку функции

## Примеры {#examples}

1. Базовое использование: кодирование слова
```sql
SELECT soundex('Doris');
```
```text
+------------------+
| soundex('Doris') |
+------------------+
| D620             |
+------------------+
```

2. Слова с похожим произношением получают одинаковый код
```sql
SELECT soundex('Smith'), soundex('Smyth');
```
```text
+------------------+------------------+
| soundex('Smith') | soundex('Smyth') |
+------------------+------------------+
| S530             | S530             |
+------------------+------------------+
```

3. Обработка пустой строки
```sql
SELECT soundex('');
```
```text
+-------------+
| soundex('') |
+-------------+
|             |
+-------------+
```

4. Обработка значения NULL

```sql
SELECT soundex(NULL);
```

```text
+---------------+
| soundex(NULL) |
+---------------+
| NULL          |
+---------------+
```

5. Для пустой строки возвращается пустая строка

```sql
SELECT soundex('');
```

```text
+-------------+
| soundex('') |
+-------------+
|             |
+-------------+
```

6. Для строки, содержащей только небуквенные символы, возвращается пустая строка

```sql
SELECT soundex('123@*%');
```

```text
+-------------------+
| soundex('123@*%') |
+-------------------+
|                   |
+-------------------+
```

7. Игнорирование небуквенных символов

```sql
SELECT soundex('R@b-e123rt'), soundex('Robert');
```

```text
+-----------------------+-------------------+
| soundex('R@b-e123rt') | soundex('Robert') |
+-----------------------+-------------------+
| R163                  | R163              |
+-----------------------+-------------------+
```

9. Пример ошибки для строки, содержащей только символы вне ASCII

```sql
SELECT soundex('你好');  
```
```text
ERROR 1105 (HY000): errCode = 2, detailMessage = Not Supported: Not Supported: soundex only supports ASCII, but got: 你
```

```sql
SELECT soundex('Apache Doris 你好');
```

```text
+--------------------------------+
| soundex('Apache Doris 你好')   |
+--------------------------------+
| A123                           |
+--------------------------------+
```
