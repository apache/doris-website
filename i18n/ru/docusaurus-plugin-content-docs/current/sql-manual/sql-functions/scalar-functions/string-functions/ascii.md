## Описание {#description}

Возвращает значение ASCII-кода первого символа строки. Функция обрабатывает только первый символ строки, поэтому для строк из нескольких символов возвращает только ASCII-код первого символа.

## Синтаксис {#syntax}

```sql
ASCII(<str>)
```

## Параметры {#parameters}

| Параметр | Описание                      |
|---------|-----------------------------|
| `<str>` | Строка, для первого символа которой нужно получить ASCII-код. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа INT, представляющее ASCII-код первого символа строки.

Особые случаи:
- Если параметр равен NULL, возвращает NULL
- Если строка пустая, возвращает 0
- Если первый символ не является символом ASCII (значение кода больше 127), возвращает соответствующее значение байта
- Для многобайтовых символов UTF-8 возвращает значение первого байта

## Примеры {#examples}

1. Базовые примеры с цифрами
```sql
SELECT ASCII('1'), ASCII('234');
```
```text
+------------+--------------+
| ASCII('1') | ASCII('234') |
+------------+--------------+
|         49 |           50 |
+------------+--------------+
```

2. Буквы
```sql
SELECT ASCII('A'), ASCII('a'), ASCII('Z');
```
```text
+------------+------------+------------+
| ASCII('A') | ASCII('a') | ASCII('Z') |
+------------+------------+------------+
|         65 |         97 |         90 |
+------------+------------+------------+
```

3. Обработка пустой строки
```sql
SELECT ASCII('');
```
```text
+-----------+
| ASCII('') |
+-----------+
|         0 |
+-----------+
```

4. Обработка значения NULL
```sql
SELECT ASCII(NULL);
```
```text
+-------------+
| ASCII(NULL) |
+-------------+
|        NULL |
+-------------+
```

5. Специальные символы
```sql
SELECT ASCII(' '), ASCII('!'), ASCII('@');
```
```text
+------------+------------+------------+
| ASCII(' ') | ASCII('!') | ASCII('@') |
+------------+------------+------------+
|         32 |         33 |         64 |
+------------+------------+------------+
```

6. Управляющие символы
```sql
SELECT ASCII('\t'), ASCII('\n'), ASCII('\r');
```
```text
+-------------+-------------+-------------+
| ASCII('\t') | ASCII('\n') | ASCII('\r') |
+-------------+-------------+-------------+
|           9 |          10 |          13 |
+-------------+-------------+-------------+
```

7. Строки из нескольких символов (возвращается только первый символ)
```sql
SELECT ASCII('Hello'), ASCII('World123');
```
```text
+----------------+------------------+
| ASCII('Hello') | ASCII('World123') |
+----------------+------------------+
|             72 |               87 |
+----------------+------------------+
```

8. Многобайтовые символы UTF-8
```sql
SELECT ASCII('ṭṛì'), ASCII('ḍḍumai');
```
```text
+---------------+------------------+
| ASCII('ṭṛì')  | ASCII('ḍḍumai') |
+---------------+------------------+
|           225 |              225 |
+---------------+------------------+
```

9. Сочетание цифр и символов
```sql
SELECT ASCII('9abc'), ASCII('0xyz');
```
```text
+---------------+---------------+
| ASCII('9abc') | ASCII('0xyz') |
+---------------+---------------+
|            57 |            48 |
+---------------+---------------+
```
