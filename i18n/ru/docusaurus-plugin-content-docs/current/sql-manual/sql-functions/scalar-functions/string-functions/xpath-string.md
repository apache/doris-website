## Описание {#description}

Функция XPATH_STRING разбирает строку XML и возвращает первый узел XML, соответствующий выражению [XPath](https://www.w3.org/TR/xpath-10/).

:::tip
Эта функция поддерживается начиная с версии 3.0.6.
:::

## Синтаксис {#syntax}

```sql
XPATH_STRING(<xml_string>, <xpath_expression>)
```

## Параметры {#parameters}
| Параметр | Описание                                   |
| --------- | ----------------------------------------------|
| `<xml_string>` | Исходная строка. Тип: VARCHAR             |
| `<xpath_expression>` | Выражение [XPath](https://www.w3.org/TR/xpath-10/). Тип: VARCHAR    |

## Возвращаемое значение {#return-value}

Возвращает содержимое первого узла XML, соответствующего выражению XPath, в виде значения типа VARCHAR.

Особые случаи:
- Функция выдаёт ошибку, если xml или xpath имеют некорректный формат.

## Примеры {#examples}

1. Простое извлечение значения узла
```sql
SELECT xpath_string('<a>123</a>', '/a');
```
```text
+-----------------------------------+
| xpath_string('<a>123</a>', '/a')  |
+-----------------------------------+
| 123                               |
+-----------------------------------+
```

2. Извлечение вложенного элемента
```sql
SELECT xpath_string('<a><b>123</b></a>', '/a/b');
```
```text
+--------------------------------------------+
| xpath_string('<a><b>123</b></a>', '/a/b')  |
+--------------------------------------------+
| 123                                        |
+--------------------------------------------+
```

3. Использование атрибутов
```sql
SELECT xpath_string('<a><b id="1">123</b></a>', '//b[@id="1"]');
```
```text
+----------------------------------------------------------+
| xpath_string('<a><b id="1">123</b></a>', '//b[@id="1"]') |
+----------------------------------------------------------+
| 123                                                      |
+----------------------------------------------------------+
```

4. Использование позиционных предикатов
```sql
SELECT xpath_string('<a><b>1</b><b>2</b></a>', '/a/b[2]');
```
```text
+----------------------------------------------------+
| xpath_string('<a><b>1</b><b>2</b></a>', '/a/b[2]') |
+----------------------------------------------------+
| 2                                                  |
+----------------------------------------------------+
```

5. Обработка CDATA и комментариев
```sql
SELECT xpath_string(NULL, '/a');
```
```text
+--------------------------+
| xpath_string(NULL, '/a') |
+--------------------------+
| NULL                     |
+--------------------------+
```
