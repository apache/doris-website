## Описание {#description}

Функция UUID генерирует случайный универсальный уникальный идентификатор (UUID). Сгенерированный UUID соответствует стандарту RFC 4122 и имеет формат 8-4-4-4-12 (36 символов, включая дефисы).

Существующая функция `UUID()` по-прежнему возвращает `VARCHAR`. Функции [UUID_V4](../uuid-functions/uuid-v4.md) и [UUID_V7](../uuid-functions/uuid-v7.md) возвращают значение нативного [типа UUID](../../../basic-element/sql-data-types/uuid.md).

## Синтаксис {#syntax}

```sql
UUID()
```

## Параметры {#parameters}

Нет параметров.

## Возвращаемое значение {#return-value}

Возвращает случайно сгенерированную строку UUID типа VARCHAR.

Особенности:
- Каждый вызов генерирует новый UUID
- Формат UUID: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
- Сгенерированный UUID глобально уникален

## Примеры {#examples}

1. Базовое использование: генерация одного UUID
```sql
SELECT UUID();
```
```text
+--------------------------------------+
| UUID()                               |
+--------------------------------------+
| 29077778-fc5e-4603-8368-6b5f8fd55c24 |
+--------------------------------------+
```

2. Повторные вызовы генерируют разные UUID
```sql
SELECT UUID(), UUID();
```
```text
+--------------------------------------+--------------------------------------+
| UUID()                               | UUID()                               |
+--------------------------------------+--------------------------------------+
| a1b2c3d4-e5f6-47a8-b9c0-d1e2f3a4b5c6 | f7e8d9c0-b1a2-4938-8756-c4d3e2f1a0b9 |
+--------------------------------------+--------------------------------------+
```
