## Описание {#description}

Функция LTRIM_IN удаляет указанные символы из начала строки. Если набор символов не указан, по умолчанию удаляются начальные пробелы. Если набор символов указан, из начала строки удаляются все символы, входящие в этот набор (независимо от их порядка в наборе).
Главная особенность LTRIM_IN заключается в том, что она удаляет любые сочетания символов из указанного набора, тогда как функция LTRIM удаляет символы на основе точного совпадения строк.

## Синтаксис {#syntax}

```sql
LTRIM_IN(<str> [, <rhs>])
```

## Параметры {#parameters}
| Параметр | Описание                                                            |
| --------- | ---------------------------------------------------------------------- |
| `<str>` | Строка для обработки. Тип: VARCHAR                              |
| `<rhs>` | Необязательный параметр, набор символов для удаления. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает обработанную строку типа VARCHAR.

Особые случаи:
- Если str имеет значение NULL, возвращает NULL
- Если rhs не указан, удаляет все начальные пробелы
- Если rhs указан, удаляет из начала строки все символы, входящие в rhs, до первого символа, не входящего в rhs

## Примеры {#examples}

1. Удаление начальных пробелов
```sql
SELECT ltrim_in('   ab d') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. Удаление символов из указанного набора
```sql
SELECT ltrim_in('ababccaab', 'ab') str;
```
```text
+-------+
| str   |
+-------+
| ccaab |
+-------+
```

3. Сравнение с функцией LTRIM
```sql
SELECT ltrim_in('abcd', 'ae'),ltrim('abcd', 'abe');
```
```text
+------------------------+----------------------+
| ltrim_in('abcd', 'ae') | ltrim('abcd', 'abe') |
+------------------------+----------------------+
| bcd                    | abcd                 |
+------------------------+----------------------+
```
