## Описание {#description}

Функция OVERLAY используется для замены подстроки заданной длины в указанной позиции строки. Начиная с указанной позиции, она заменяет заданное количество символов новой строкой. Эта функция корректно работает с многобайтовыми символами.

Поведение этой функции соответствует поведению [функции INSERT](https://dev.mysql.com/doc/refman/8.4/en/string-functions.html#function_insert) в MySQL.

## Псевдоним {#alias}

- INSERT

## Синтаксис {#syntax}

```sql
OVERLAY(<str>, <pos>, <len>, <newstr>)
```

## Параметры {#parameters}

| Параметр | Описание |
| ---------- | ----------------------------------------- |
| `<str>` | Исходная строка, которую нужно изменить. Тип: VARCHAR |
| `<pos>` | Начальная позиция замены (нумерация с 1). Тип: INT |
| `<len>` | Количество символов для замены. Тип: INT |
| `<newstr>` | Новая строка для замены. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает новую строку типа VARCHAR после замены.

Особые случаи:
- Если любой из параметров равен NULL, возвращает NULL
- Если `<pos>` меньше 1 или превышает длину строки, замена не выполняется и возвращается исходная строка
- Если `<len>` меньше 0 или превышает оставшуюся длину, замена выполняется от `<pos>` до конца строки

## Примеры {#examples}

1. Базовое использование: замена средней части строки
```sql
SELECT overlay('Quadratic', 3, 4, 'What');
```
```text
+------------------------------------+
| overlay('Quadratic', 3, 4, 'What') |
+------------------------------------+
| QuWhattic                          |
+------------------------------------+
```

2. Отрицательная длина: замена до конца строки
```sql
SELECT overlay('Quadratic', 2, -1, 'Hi');
```
```text
+-----------------------------------+
| overlay('Quadratic', 2, -1, 'Hi') |
+-----------------------------------+
| QHi                               |
+-----------------------------------+
```

3. Позиция за пределами строки: замена не выполняется
```sql
SELECT overlay('Hello', 10, 2, 'X');
```
```text
+-------------------------------+
| overlay('Hello', 10, 2, 'X')  |
+-------------------------------+
| Hello                         |
+-------------------------------+
```

4. Обработка значения NULL
```sql
SELECT overlay('Hello', NULL, 2, 'X');
```
```text
+--------------------------------+
| overlay('Hello', NULL, 2, 'X') |
+--------------------------------+
| NULL                           |
+--------------------------------+
```

```sql
SELECT INSERT('🎉🎊🎈', 2, 1, '🎁');
```
```text

| INSERT('🎉🎊🎈', 2, 1, '🎁')                 |
+--------------------------------------+
| 🎉🎁🎈                                     |
+--------------------------------------+
```
