## Описание {#description}

Функция `JSON_SEARCH` ищет указанные значения в документе JSON. Если значение найдено, функция возвращает путь к нему. Если значение не найдено, возвращается NULL. Функция поддерживает рекурсивный поиск в структурах данных JSON.

## Синтаксис {#syntax}

```sql
JSON_SEARCH( <json_object>, <one_or_all>, <search_value> )
```
## Параметры {#parameters}
- `<json_object>`: тип JSON; документ JSON, в котором выполняется поиск.
- `<one_or_all>`: строковый тип; определяет, нужно ли искать все совпадающие значения. Допустимые значения: 'one' и 'all'.
- `<search_value>`: строковый тип; искомое значение.
    Поддерживаются подстановочные символы '%' (соответствует любому количеству любых символов) и '_' (соответствует любому одному символу).

## Возвращаемое значение {#return-value}
Nullable(JSON): в зависимости от параметра `<one_or_all>` возможны два случая:

    1. 'one': If a matching value is found, returns a JSON path pointing to the matching value. If no matching value is found, returns NULL.
    2. 'all': Returns paths to all matching values. If there are multiple values, returns them as a JSON array. If no matches are found, returns NULL.

## Примечания {#notes}
- Параметр `one_or_all` определяет, нужно ли искать все совпадающие значения. Значение 'one' возвращает первый найденный путь, а 'all' возвращает все найденные пути. При любом другом значении возникает ошибка.
- Если совпадающее значение не найдено, функция возвращает NULL.
- Если хотя бы один из параметров `<json_object>`, `<one_or_all>`, `<search_value>` равен NULL, возвращается NULL.

## Примеры {#examples}

1. Поиск одного значения (one)
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30}', 'one', 'John');
    ```
    ```text
    +-----------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30}', 'one', 'John') |
    +-----------------------------------------------------------+
    | "$.name"                                                  |
    +-----------------------------------------------------------+

    ```
2. Поиск одного значения (one): даже при нескольких совпадениях возвращается только один путь
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30, "alias": "John"}', 'one', 'John');
    ```
    ```text
    +----------------------------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30, "alias": "John"}', 'one', 'John') |
    +----------------------------------------------------------------------------+
    | "$.name"                                                                   |
    +----------------------------------------------------------------------------+
    ```
3. Поиск всех совпадающих значений (all)
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30, "alias": "John"}', 'all', 'John');
    ```
    ```text
    +----------------------------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30, "alias": "John"}', 'all', 'John') |
    +----------------------------------------------------------------------------+
    | ["$.alias","$.name"]                                                       |
    +----------------------------------------------------------------------------+
    ```
4. '%' в качестве подстановочного символа
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30, "alias": "John"}', 'all', '%');
    ```
    ```text
    +-------------------------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30, "alias": "John"}', 'all', '%') |
    +-------------------------------------------------------------------------+
    | ["$.alias","$.name"]                                                    |
    +-------------------------------------------------------------------------+
    ```
5. '_' в качестве подстановочного символа
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30, "alias": "Jihn"}', 'all', 'J_hn');
    ```
    ```text
    +----------------------------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30, "alias": "Jihn"}', 'all', 'J_hn') |
    +----------------------------------------------------------------------------+
    | ["$.alias","$.name"]                                                       |
    +----------------------------------------------------------------------------+
    ```
6. Экранирование подстановочного символа
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30, "alias": "J_hn"}', 'all', 'J\_hn');
    ```
    ```text
    +-----------------------------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30, "alias": "J_hn"}', 'all', 'J\_hn') |
    +-----------------------------------------------------------------------------+
    | "$.alias"                                                                   |
    +-----------------------------------------------------------------------------+
    ```
    > 'J\_hn' соответствует только "J_hn" и не соответствует "John".
7. Совпадающее значение не найдено

    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30}', 'one', 'Alice');
    ```
    ```text
    +------------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30}', 'one', 'Alice') |
    +------------------------------------------------------------+
    | NULL                                                       |
    +------------------------------------------------------------+
    ```
8. Параметры со значением NULL
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30}', NULL, 'Alice');
    ```
    ```text
    +-----------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30}', NULL, 'Alice') |
    +-----------------------------------------------------------+
    | NULL                                                      |
    +-----------------------------------------------------------+
    ```
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30}', 'one', NULL);
    ```
    ```text
    +---------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30}', 'one', NULL) |
    +---------------------------------------------------------+
    | NULL                                                    |
    +---------------------------------------------------------+
    ```
    ```sql
    SELECT JSON_SEARCH(NULL, 'one', 'Alice');
    ```
    ```
    +-----------------------------------+
    | JSON_SEARCH(NULL, 'one', 'Alice') |
    +-----------------------------------+
    | NULL                              |
    +-----------------------------------+
    ```
9. Недопустимое значение параметра `<one_or_all>`
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30}', 'three', 'Alice');
    ```
    ```text
    ERROR 1105 (HY000): errCode = 2, detailMessage = [INVALID_ARGUMENT]the one_or_all argument three is not 'one' not 'all'
    ```
