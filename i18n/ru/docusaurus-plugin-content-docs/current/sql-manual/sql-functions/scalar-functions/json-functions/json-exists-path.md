## Описание {#description}

Определяет, существует ли в данных JSON поле, заданное параметром `<path>`. Возвращает TRUE, если поле существует, и FALSE, если не существует.

## Синтаксис {#syntax}

```sql
JSON_EXISTS_PATH (<json_object>, <path>)
```

## Параметры {#parameters}
- `<json_object>` — значение типа JSON, в котором проверяется наличие пути, заданного параметром `<path>`.
- `<path>` — значение строкового типа, задающее путь.

## Возвращаемое значение {#return-value}
- Тип BOOL: возвращает TRUE, если поле существует, и FALSE, если не существует.
- NULL: если хотя бы один из параметров `<json_object>` или `<path>` равен NULL, возвращает NULL.

## Примеры {#examples}
1. Пример 1
    ```sql
    SELECT JSON_EXISTS_PATH('{"id": 123, "name": "doris"}', '$.name');
    ```
    ```text
    +------------------------------------------------------------+
    | JSON_EXISTS_PATH('{"id": 123, "name": "doris"}', '$.name') |
    +------------------------------------------------------------+
    |                                                          1 |
    +------------------------------------------------------------+
    ```
2. Пример 2
    ```sql
    SELECT JSON_EXISTS_PATH('{"id": 123, "name": "doris"}', '$.age');
    ```
    ```text
    +-----------------------------------------------------------+
    | JSON_EXISTS_PATH('{"id": 123, "name": "doris"}', '$.age') |
    +-----------------------------------------------------------+
    |                                                         0 |
    +-----------------------------------------------------------+
    ```
3. Параметры со значением NULL
    ```sql
    SELECT JSON_EXISTS_PATH('{"id": 123, "name": "doris"}', NULL);
    ```
    ```text
    +--------------------------------------------------------+
    | JSON_EXISTS_PATH('{"id": 123, "name": "doris"}', NULL) |
    +--------------------------------------------------------+
    |                                                   NULL |
    +--------------------------------------------------------+
    ```
    ```sql
    SELECT JSON_EXISTS_PATH(NULL, '$.age');
    ```
    ```text
    +---------------------------------+
    | JSON_EXISTS_PATH(NULL, '$.age') |
    +---------------------------------+
    |                            NULL |
    +---------------------------------+
    ```
