## Описание {#description}
Функция `JSON_SET` вставляет или заменяет данные в JSON и возвращает результат.

## Синтаксис {#syntax}
```sql
JSON_SET (<json_object>, <path>,  <value>[, <path>,  <value>, ...])
```

## Параметры {#parameters}
- `<json_object>`: выражение типа JSON, задающее объект для изменения.
- `<path>`: выражение строкового типа, задающее путь для вставки значения
- `<value>`: значение для вставки типа JSON или другого типа, поддерживаемого функцией [`TO_JSON`](./to-json.md).

## Возвращаемое значение {#return-value}
- Nullable(JSON) Возвращает изменённый объект JSON

## Примечания по использованию {#usage-notes}
1. Если объект, на который указывает `<path>`, существует, функция ведёт себя так же, как [`JSON_REPLACE`](./json-replace.md), иначе — как [`JSON_INSERT`](./json-insert.md)

## Примеры {#examples}
1. Путь не существует
    ```sql
    select json_set('{}', '$.k', json_parse('{}'), '$.k.k2', 123);
    ```
    ```text
    +--------------------------------------------------------+
    | json_set('{}', '$.k', json_parse('{}'), '$.k.k2', 123) |
    +--------------------------------------------------------+
    | {"k":{"k2":123}}                                       |
    +--------------------------------------------------------+
    ```
2. Значение, на которое указывает `<path>`, уже существует в объекте JSON
    ```sql
    select json_set('{"k": 1}', "$.k", 2);
    ```
    ```text
    +--------------------------------+
    | json_set('{"k": 1}', "$.k", 2) |
    +--------------------------------+
    | {"k":2}                        |
    +--------------------------------+
    ```
3. Параметры со значением NULL
    ```sql
    select json_set(NULL, '$[1]', 123);
    ```
    ```text
    +-----------------------------+
    | json_set(NULL, '$[1]', 123) |
    +-----------------------------+
    | NULL                        |
    +-----------------------------+
    ```
    ```sql
    select json_set('{"k": "v"}', NULL, 123);
    ```
    ```text
    +-----------------------------------+
    | json_set('{"k": "v"}', NULL, 123) |
    +-----------------------------------+
    | NULL                              |
    +-----------------------------------+
    ```
    ```sql
    select json_set('{"k": "v"}', '$.k[1]', NULL);
    ```
    ```text
    +----------------------------------------+
    | json_set('{"k": "v"}', '$.k[1]', NULL) |
    +----------------------------------------+
    | {"k":["v",null]}                       |
    +----------------------------------------+
    ```
