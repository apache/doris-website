## Описание {#description}

`JSON_OBJECT_FLATTEN` преобразует вложенный объект JSON в одноуровневый объект JSON, ключи которого представляют собой пути к каждому конечному значению с точками в качестве разделителей. Функция следует семантике NiFi FlattenJson "keep-arrays": рекурсивно обходятся только объекты, а массивы, скалярные значения, значения null и пустые объекты сохраняются как неделимые конечные значения.

Если входное значение верхнего уровня не является объектом (например, это скалярное значение, массив или `null`), оно возвращается без изменений.

## Синтаксис {#syntax}

```sql
JSON_OBJECT_FLATTEN(<json_value>)
```

## Параметры {#parameters}

**`<json_value>`** - Значение JSON, которое нужно преобразовать в одноуровневую структуру. Должно иметь тип JSON.

## Возвращаемое значение {#return-value}

Возвращает значение JSON:

- Если входное значение является вложенным объектом JSON, возвращает одноуровневый объект JSON, ключи которого представляют собой пути к каждому конечному значению с точками в качестве разделителей.
- Если входное значение не является объектом (скалярное значение, массив или null), возвращает его без изменений.
- Если входное значение равно `NULL`, возвращает `NULL`.

## Примеры {#examples}

### Преобразование простого вложенного объекта в одноуровневый объект {#basic-nested-object-flattening}

```sql
SELECT json_object_flatten('{"a":{"b":2}}');
```

```text
+--------------------------------------+
| json_object_flatten('{"a":{"b":2}}') |
+--------------------------------------+
| {"a.b":2}                            |
+--------------------------------------+
```

### Глубоко вложенный объект {#deeply-nested-object}

```sql
SELECT json_object_flatten('{"a":{"b":{"c":3}}}');
```

```text
+--------------------------------------------+
| json_object_flatten('{"a":{"b":{"c":3}}}') |
+--------------------------------------------+
| {"a.b.c":3}                                |
+--------------------------------------------+
```

### Уже одноуровневый объект {#already-flat-object}

```sql
SELECT json_object_flatten('{"a":1,"b":"hi"}');
```

```text
+-----------------------------------------+
| json_object_flatten('{"a":1,"b":"hi"}') |
+-----------------------------------------+
| {"a":1,"b":"hi"}                        |
+-----------------------------------------+
```

### Массивы сохраняются как неделимые конечные значения {#arrays-preserved-as-opaque-leaves}

```sql
SELECT json_object_flatten('{"a":[{"b":1},{"b":2}]}');
```

```text
+------------------------------------------------+
| json_object_flatten('{"a":[{"b":1},{"b":2}]}') |
+------------------------------------------------+
| {"a":[{"b":1},{"b":2}]}                        |
+------------------------------------------------+
```

```sql
SELECT json_object_flatten('{"a":{"b":[1,2,3]}}');
```

```text
+--------------------------------------------+
| json_object_flatten('{"a":{"b":[1,2,3]}}') |
+--------------------------------------------+
| {"a.b":[1,2,3]}                            |
+--------------------------------------------+
```

### Значения верхнего уровня, не являющиеся объектами, возвращаются без изменений {#top-level-non-object-values-pass-through-unchanged}

```sql
SELECT json_object_flatten('42');
```

```text
+---------------------------+
| json_object_flatten('42') |
+---------------------------+
| 42                        |
+---------------------------+
```

```sql
SELECT json_object_flatten('[1,2,{"x":3}]');
```

```text
+--------------------------------------+
| json_object_flatten('[1,2,{"x":3}]') |
+--------------------------------------+
| [1,2,{"x":3}]                        |
+--------------------------------------+
```

### Входное значение NULL {#null-input}

```sql
SELECT json_object_flatten(NULL);
```

```text
+---------------------------+
| json_object_flatten(NULL) |
+---------------------------+
| NULL                      |
+---------------------------+
```

### Вложенный объект, содержащий скалярные значения, массивы и подобъекты {#mixed-nested-object-with-scalars-arrays-and-sub-objects}

```sql
SELECT json_object_flatten('{"x":{"s":1,"a":[1,2],"o":{"k":"v"}}}');
```

```text
+--------------------------------------------------------------+
| json_object_flatten('{"x":{"s":1,"a":[1,2],"o":{"k":"v"}}}') |
+--------------------------------------------------------------+
| {"x.s":1,"x.a":[1,2],"x.o.k":"v"}                            |
+--------------------------------------------------------------+
```
