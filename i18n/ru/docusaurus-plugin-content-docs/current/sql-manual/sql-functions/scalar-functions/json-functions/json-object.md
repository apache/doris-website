## Описание {#description}

Формирует один объект JSON, содержащий указанные пары «ключ-значение». Возвращает ошибку, если ключ имеет значение NULL или передано нечётное число параметров.

## Синтаксис {#syntax}

```sql
JSON_OBJECT (<key>, <value>[, <key>, <value>, ...])
```

```sql
JSON_OBJECT(*)
```

## Параметры {#parameters}
### Переменное число параметров: {#variable-parameters}
- `<key>`: тип String.
- `<value>`: различные типы; Doris автоматически преобразует параметры типов, отличных от JSON, в тип JSON с помощью функции [`TO_JSON`](./to-json.md).
- `*`: при вызове со звёздочкой (подстановочным символом) значение OBJECT формируется из указанных данных: имена атрибутов используются в качестве ключей, а соответствующие значения используются в качестве значений объекта.

    При передаче подстановочного символа в функцию можно указать перед ним имя или псевдоним таблицы. Например, чтобы передать все столбцы таблицы с именем mytable, укажите следующее:

    ```sql
    (mytable.*)
    ```

## Примечания {#notes}
- Число параметров должно быть чётным; допускается 0 параметров (возвращается пустой объект JSON).
- По соглашению список параметров состоит из чередующихся ключей и значений.
- Ключи принудительно преобразуются в текст в соответствии с определением JSON.
- Если переданный ключ имеет значение NULL, возникает ошибка исключения.
- Параметры значений преобразуются в JSON и должны иметь типы, поддерживаемые [`TO_JSON`](./to-json.md).
- Если переданное значение равно NULL, значением соответствующей пары «ключ-значение» в возвращаемом объекте JSON будет значение JSON null.
- Чтобы использовать в качестве значений другие типы, можно преобразовать их в JSON/String с помощью CAST.
- В настоящее время Doris не выполняет дедупликацию объектов JSON, поэтому повторяющиеся ключи допускаются. Однако повторяющиеся ключи могут приводить к неожиданным результатам:
    1. Другие системы могут отбрасывать значения, соответствующие повторяющимся ключам, или сообщать об ошибках.
    2. Результат, возвращаемый [`JSON_EXTRACT`](./json-extract.md), не определён.

## Возвращаемое значение {#return-value}

[`JSON`](../../../basic-element/sql-data-types/semi-structured/JSON.md): возвращает объект JSON, сформированный из списка параметров.

## Примеры {#examples}
1. Пример без параметров
    ```sql
    select json_object();
    ```
    ```text
    +---------------+
    | json_object() |
    +---------------+
    | {}            |
    +---------------+
    ```
2. Неподдерживаемые типы значений 
    ```sql
    select json_object('time',curtime());
    ```
    ```text
    ERROR 1105 (HY000): errCode = 2, detailMessage = Can not find the compatibility function signature: to_json(TIMEV2(0))
    ```
    Значение можно преобразовать в String с помощью cast
    ```sql
    select json_object('time', cast(curtime() as string));
    ```
    ```text
    +------------------------------------------------+
    | json_object('time', cast(curtime() as string)) |
    +------------------------------------------------+
    | {"time":"17:09:42"}                            |
    +------------------------------------------------+
    ```
3. Ключи типов, отличных от String, преобразуются в String
    ```sql
    SELECT json_object(123, 456);
    ```
    ```text
    +-----------------------+
    | json_object(123, 456) |
    +-----------------------+
    | {"123":456}           |
    +-----------------------+
    ```
4. NULL нельзя использовать в качестве ключа
    ```sql
    select json_object(null, 456);
    ```
    ```text
    ERROR 1105 (HY000): errCode = 2, detailMessage = json_object key can't be NULL: json_object(NULL, 456)
    ```
    NULL можно использовать в качестве значения
    ```sql
    select json_object('key', null);
    ```
    ```text
    +--------------------------+
    | json_object('key', null) |
    +--------------------------+
    | {"key":null}             |
    +--------------------------+
    ```

5. Строки JSON можно разобрать в объекты JSON с помощью [`JSON_PARSE`](./json-parse.md) перед передачей в `JSON_OBJECT`
    ```sql
    select json_object(123, json_parse('{"key": "value"}'));
    ```
    ```text
    +--------------------------------------------------+
    | json_object(123, json_parse('{"key": "value"}')) |
    +--------------------------------------------------+
    | {"123":{"key":"value"}}                          |
    +--------------------------------------------------+
    ```
    В противном случае значение будет обрабатываться как строка
    ```sql
    select json_object(123,'{"key": "value"}');
    ```
    ```text
    +-------------------------------------+
    | json_object(123,'{"key": "value"}') |
    +-------------------------------------+
    | {"123":"{\"key\": \"value\"}"}      |
    +-------------------------------------+
    ```
6. Типы, не поддерживаемые [`TO_JSON`](./to-json.md)
    ```sql
    select json_object('key', map('abc', 'efg'));
    ```
    ```text
    ERROR 1105 (HY000): errCode = 2, detailMessage = Can not find the compatibility function signature: to_json(MAP<VARCHAR(3),VARCHAR(3)>)
    ```

    Перед передачей значение можно преобразовать в JSON с помощью CAST:
    ```sql
    select json_object('key', cast(map('abc', 'efg') as json));
    ```
    ```text
    +-----------------------------------------------------+
    | json_object('key', cast(map('abc', 'efg') as json)) |
    +-----------------------------------------------------+
    | {"key":{"abc":"efg"}}                               |
    +-----------------------------------------------------+
    ```
7. Пример с повторяющимися ключами
    ```sql
    select
        json_object('key', 123, 'key', 4556) v1
        , jsonb_extract(json_object('key', 123, 'key', 4556), '$.key') v2
        , jsonb_extract(json_object('key', 123, 'key', 4556), '$.*') v3;
    ```
    ```text
    +------------------------+------+------------+
    | v1                     | v2   | v3         |
    +------------------------+------+------------+
    | {"key":123,"key":4556} | 123  | [123,4556] |
    +------------------------+------+------------+
    ```
