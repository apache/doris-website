## Описание {#description}

Определяет тип поля, указанного с помощью `json_path`, в данных JSONB. Если поле не существует, возвращает NULL. Если поле существует, возвращает один из следующих типов:

- object
- array
- null
- bool
- int
- bigint
- largeint
- double
- string

## Синтаксис {#syntax}

```sql
JSON_TYPE( <json>, <json_path> )
```

## Параметры {#parameters}

- `<json>` Строка JSON, тип которой требуется определить.
- `<json_path>` Значение строкового типа, задающее расположение поля в JSON. Путь обычно начинается с символа $, а для обозначения иерархической структуры используется точка.

## Возвращаемое значение {#return-value}

`Nullable<String>`: возвращает тип соответствующего поля.

## Примечания по использованию {#usage-notes}
- Если `<json_object>` или `<json_path>` имеет значение NULL, возвращает NULL.
- Если `<json_path>` не является корректным путём, функция выдаёт ошибку.
- Если поле, указанное с помощью `<json_path>`, не существует, возвращает NULL.

## Примеры {#examples}
1. Значение JSON имеет строковый тип:
    ```sql
    SELECT JSON_TYPE('{"name": "John", "age": 30}', '$.name');
    ```
    ```text
    +-------------------------------------------------------------------+
    | jsonb_type(cast('{"name": "John", "age": 30}' as JSON), '$.name') |
    +-------------------------------------------------------------------+
    | string                                                            |
    +-------------------------------------------------------------------+
    ```

2. Значение JSON имеет числовой тип:
    ```sql
    SELECT JSON_TYPE('{"name": "John", "age": 30}', '$.age');
    ```
    ```text
    +------------------------------------------------------------------+
    | jsonb_type(cast('{"name": "John", "age": 30}' as JSON), '$.age') |
    +------------------------------------------------------------------+
    | int                                                              |
    +------------------------------------------------------------------+
    ```
3. Параметры со значением NULL
    ```sql
    select json_type(NULL, '$.key1');
    ```
    ```text
    +---------------------------+
    | json_type(NULL, '$.key1') |
    +---------------------------+
    | NULL                      |
    +---------------------------+
    ```
4. Параметры со значением NULL 2
    ```sql
    select json_type('{"key1": true}', NULL);
    ```
    ```text
    +-----------------------------------+
    | json_type('{"key1": true}', NULL) |
    +-----------------------------------+
    | NULL                              |
    +-----------------------------------+
    ```
5. Поле, указанное параметром `json_path`, не существует
    ```sql
    select json_type('{"key1": true}', '$.key2');
    ```
    ```text
    +---------------------------------------+
    | json_type('{"key1": true}', '$.key2') |
    +---------------------------------------+
    | NULL                                  |
    +---------------------------------------+
    ```
6. Некорректный параметр `json_path`
    ```sql
    select json_type('{"key1": true}', '$.');
    ```
    ```text
    ERROR 1105 (HY000): errCode = 2, detailMessage = [INVALID_ARGUMENT]Json path error: Invalid Json Path for value: $.
    ```
