## Описание {#description}
`JSON_EXTRACT_BOOL` извлекает поле, указанное в `<json_path>`, из объекта JSON и преобразует его в тип [`BOOLEAN`](../../../basic-element/sql-data-types/numeric/BOOLEAN.md).

## Синтаксис {#syntax}
```sql
JSON_EXTRACT_BOOL(<json_object>, <json_path>)
```

## Параметры {#parameters}
- `<json_object>`: значение типа JSON, из которого извлекаются данные.
- `<json_path>`: значение типа String, задающее путь JSON для извлечения нужного элемента из целевого объекта JSON.

## Возвращаемое значение {#return-value}
`Nullable(BOOLEAN)`: извлечённое значение BOOLEAN; в некоторых случаях возвращается NULL.

## Примечания по использованию {#usage-notes}
1. Если `<json_object>` или `<json_path>` имеет значение NULL, возвращается NULL.
2. Если элемент, указанный в `<json_path>`, не существует, возвращается NULL.
3. Если элемент, указанный в `<json_path>`, невозможно преобразовать в BOOLEAN, возвращается NULL.
4. Поведение соответствует сочетанию "cast + json_extract", что эквивалентно:
    ```sql
    CAST(JSON_EXTRACT(<json_object>, <json_path>) as BOOLEAN)
    ```

## Примеры {#examples}
1. Обычные параметры
    ```sql
    SELECT json_extract_bool('{"id": true, "name": "doris"}', '$.id');
    ```
    ```text
    +------------------------------------------------------------+
    | json_extract_bool('{"id": true, "name": "doris"}', '$.id') |
    +------------------------------------------------------------+
    |                                                          1 |
    +------------------------------------------------------------+
    ```
2. Указанный путь не существует
    ```sql
    SELECT json_extract_bool('{"id": true, "name": "doris"}', '$.id2');
    ```
    ```text
    +-------------------------------------------------------------+
    | json_extract_bool('{"id": true, "name": "doris"}', '$.id2') |
    +-------------------------------------------------------------+
    |                                                        NULL |
    +-------------------------------------------------------------+
    ```
3. Параметры со значением NULL
    ```sql
    SELECT json_extract_bool('{"id": true, "name": "doris"}', NULl);
    ```
    ```text
    +----------------------------------------------------------+
    | json_extract_bool('{"id": true, "name": "doris"}', NULl) |
    +----------------------------------------------------------+
    |                                                     NULL |
    +----------------------------------------------------------+
    ```
    ```sql
    SELECT json_extract_bool(NULL, '$.id2');
    ```
    ```text
    +----------------------------------+
    | json_extract_bool(NULL, '$.id2') |
    +----------------------------------+
    |                             NULL |
    +----------------------------------+
    ```
4. Преобразование в BOOLEAN невозможно
    ```sql
    SELECT json_extract_bool('{"id": 123, "name": "doris"}','$.name');
    ```
    ```text
    +------------------------------------------------------------+
    | json_extract_bool('{"id": 123, "name": "doris"}','$.name') |
    +------------------------------------------------------------+
    |                                                       NULL |
    +------------------------------------------------------------+
    ```
