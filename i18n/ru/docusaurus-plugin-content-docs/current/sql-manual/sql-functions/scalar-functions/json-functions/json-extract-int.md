## Описание {#description}
`JSON_EXTRACT_INT` извлекает из объекта JSON поле, указанное в `<json_path>`, и преобразует его в тип [`INT`](../../../basic-element/sql-data-types/numeric/INT.md).

## Синтаксис {#syntax}
```sql
JSON_EXTRACT_INT(<json_object>, <json_path>)
```

## Параметры {#parameters}
- `<json_object>`: значение типа JSON, из которого извлекается элемент.
- `<json_path>`: значение типа String, задающее путь JSON к элементу, который нужно извлечь из исходного JSON.

## Возвращаемое значение {#return-value}
`Nullable(INT)` Возвращает извлечённое значение INT; в некоторых случаях возвращает NULL.

## Примечания по использованию {#usage-notes}
1. Если `<json_object>` или `<json_path>` имеет значение NULL, возвращает NULL.
2. Если элемент, указанный в `<json_path>`, не существует, возвращает NULL.
3. Если элемент, указанный в `<json_path>`, невозможно преобразовать в INT, возвращает NULL.
4. Поведение соответствует сочетанию "cast + json_extract", что эквивалентно:
    ```sql
    CAST(JSON_EXTRACT(<json_object>, <json_path>) as INT)
    ```

## Примеры {#examples}
1. Обычные параметры
    ```sql
    SELECT json_extract_int('{"id": 123, "name": "doris"}', '$.id');
    ```
    ```text
    +----------------------------------------------------------+
    | json_extract_int('{"id": 123, "name": "doris"}', '$.id') |
    +----------------------------------------------------------+
    |                                                      123 |
    +----------------------------------------------------------+
    ```
2. Несуществующий путь
    ```sql
    SELECT json_extract_int('{"id": 123, "name": "doris"}', '$.id2');
    ```
    ```text
    +-----------------------------------------------------------+
    | json_extract_int('{"id": 123, "name": "doris"}', '$.id2') |
    +-----------------------------------------------------------+
    |                                                      NULL |
    +-----------------------------------------------------------+
    ```
3. Параметры со значением NULL
    ```sql
    SELECT json_extract_int('{"id": 123, "name": "doris"}', NULl);
    ```
    ```text
    +--------------------------------------------------------+
    | json_extract_int('{"id": 123, "name": "doris"}', NULl) |
    +--------------------------------------------------------+
    |                                                   NULL |
    +--------------------------------------------------------+
    ```
    ```sql
    SELECT json_extract_int(NULL, '$.id2');
    ```
    ```text
    +---------------------------------+
    | json_extract_int(NULL, '$.id2') |
    +---------------------------------+
    |                            NULL |
    +---------------------------------+
    ```
4. Преобразование в INT невозможно
    ```sql
    SELECT json_extract_int('{"id": 123, "name": "doris"}','$.name');
    ```
    ```text
    +-----------------------------------------------------------+
    | json_extract_int('{"id": 123, "name": "doris"}','$.name') |
    +-----------------------------------------------------------+
    |                                                      NULL |
    +-----------------------------------------------------------+
    ```
