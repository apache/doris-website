## Описание {#description}
Преобразует значение `<x>` в двоичное представление и возвращает значение для указанных позиций `<bits>`, где нумерация `<bits>` начинается с 0 (крайний правый бит).

Если `<bits>` содержит несколько значений, значения битов в этих позициях объединяются с помощью оператора AND, и возвращается итоговый результат.

Если какое-либо значение в `<bits>` отрицательно или превышает общее число битов в `<x>`, результат равен 0.

Поддерживаемые целочисленные типы для `<x>`: TINYINT, SMALLINT, INT, BIGINT, LARGEINT.

## Псевдоним {#alias}
- BIT_TEST_ALL

## Синтаксис {#syntax}
```sql
BIT_TEST(<x>, <bits>[, <bits> ... ])
```

## Параметры {#parameters}
- `<x>`
- `<bits>`

## Возвращаемое значение {#return-value}

Возвращает значение для указанных позиций.

## Примеры {#examples}
1. Пример 1
    ```sql
    select BIT_TEST(43, 1), BIT_TEST(43, -1), BIT_TEST(43, 2), BIT_TEST(43, 0, 1, 3, 5), BIT_TEST(43, 0, 1, 3, 5, 2);
    ```
    ```text
    +-----------------+------------------+-----------------+--------------------------+-----------------------------+
    | BIT_TEST(43, 1) | BIT_TEST(43, -1) | BIT_TEST(43, 2) | BIT_TEST(43, 0, 1, 3, 5) | BIT_TEST(43, 0, 1, 3, 5, 2) |
    +-----------------+------------------+-----------------+--------------------------+-----------------------------+
    |               1 |                0 |               0 |                        1 |                           0 |
    +-----------------+------------------+-----------------+--------------------------+-----------------------------+
    ```
    > Двоичное представление числа 43 — "101011", поэтому `BIT_TEST(43, 1)` возвращает 1, `BIT_TEST(43, 2)` возвращает 0, а `BIT_TEST(43, 0, 1, 3, 5)` возвращает 1.
    > `BIT_TEST(43, 0, 1, 3, 5, 2)` возвращает 0.
2. Аргумент NULL
    ```sql
    select BIT_TEST(NULL, 1), BIT_TEST(43, NULL), BIT_TEST(NULL, NULL);
    ```
    ```text
    +-------------------+--------------------+----------------------+
    | BIT_TEST(NULL, 1) | BIT_TEST(43, NULL) | BIT_TEST(NULL, NULL) |
    +-------------------+--------------------+----------------------+
    |              NULL |               NULL |                 NULL |
    +-------------------+--------------------+----------------------+
    ```
