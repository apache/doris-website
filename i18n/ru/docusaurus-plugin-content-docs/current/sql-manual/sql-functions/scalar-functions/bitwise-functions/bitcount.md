## Описание {#description}

Возвращает количество битов со значением 1 в двоичном представлении целого числа. Эта функция позволяет быстро подсчитать «активные» биты в двоичном представлении целого числа, что часто полезно при анализе распределения данных или выполнении определённых побитовых операций.

## Синтаксис {#syntax}
```sql
BIT_COUNT(<x>)
```

## Параметры {#parameters}
- `<x>`: Целое число, в двоичном представлении которого подсчитываются биты со значением 1. Поддерживаемые типы: TINYINT, SMALLINT, INT, BIGINT, LARGEINT.

## Возвращаемое значение {#return-value}

Возвращает количество битов со значением 1 в двоичном представлении `<x>`.

## Примеры {#examples}
1. Пример 1
    ```sql
    select BIT_COUNT(0), BIT_COUNT(8), BIT_COUNT(-1);
    ```
    ```text
    +--------------+--------------+---------------+
    | BIT_COUNT(0) | BIT_COUNT(8) | BIT_COUNT(-1) |
    +--------------+--------------+---------------+
    |            0 |            1 |             8 |
    +--------------+--------------+---------------+
    ```
2. Аргумент NULL
    ```sql
    select BIT_COUNT(NULL);
    ```
    ```text
    +-----------------+
    | BIT_COUNT(NULL) |
    +-----------------+
    |            NULL |
    +-----------------+
    ```
