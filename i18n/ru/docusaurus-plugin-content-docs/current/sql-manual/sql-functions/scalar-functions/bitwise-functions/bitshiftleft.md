## Описание {#description}
Выполняет операцию сдвига влево, при которой все биты двоичного числа сдвигаются влево на указанное число позиций. Это побитовая операция, которая часто используется для обработки двоичных данных или эффективного выполнения математических вычислений.

Для максимального значения типа BIGINT (9223372036854775807) сдвиг влево на одну позицию даёт -2.
## Синтаксис {#syntax}
```sql
BIT_SHIFT_LEFT(<x>, <bits>)
```

## Параметры {#parameters}
- `<x>`: Число, к которому применяется сдвиг.
- `<bits>`: Количество позиций для сдвига влево. Это целое число, определяющее, на сколько позиций будет сдвинуто число `<x>`.

## Возвращаемое значение {#return-value}
Возвращает целое число, представляющее результат операции сдвига влево.

## Примеры {#examples}
1. Пример 1
    ```sql
    select BIT_SHIFT_LEFT(5, 2), BIT_SHIFT_LEFT(-5, 2), BIT_SHIFT_LEFT(9223372036854775807, 1);
    ```

    ```text
    +----------------------+-----------------------+----------------------------------------+
    | BIT_SHIFT_LEFT(5, 2) | BIT_SHIFT_LEFT(-5, 2) | BIT_SHIFT_LEFT(9223372036854775807, 1) |
    +----------------------+-----------------------+----------------------------------------+
    |                   20 |                   -20 |                                     -2 |
    +----------------------+-----------------------+----------------------------------------+
    ```
2. Аргумент NULL
    ```sql
    select BIT_SHIFT_LEFT(5, NULL), BIT_SHIFT_LEFT(NULL, 2), BIT_SHIFT_LEFT(NULL, NULL);
    ```
    ```text
    +-------------------------+-------------------------+----------------------------+
    | BIT_SHIFT_LEFT(5, NULL) | BIT_SHIFT_LEFT(NULL, 2) | BIT_SHIFT_LEFT(NULL, NULL) |
    +-------------------------+-------------------------+----------------------------+
    |                    NULL |                    NULL |                       NULL |
    +-------------------------+-------------------------+----------------------------+
    ```
