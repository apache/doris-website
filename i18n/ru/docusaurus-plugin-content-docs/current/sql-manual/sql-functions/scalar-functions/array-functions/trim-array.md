## trim_array {#trim_array}

<version since="dev">

</version>

## Описание {#description}

Удаляет `<size>` элементов с конца массива `<arr>`, сохраняя порядок оставшихся элементов.

## Синтаксис {#syntax}

```sql
TRIM_ARRAY(<arr>, <size>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<arr>` | Входной массив `ARRAY<T>`. `T` может быть числовым, логическим, строковым типом, типом даты/времени, типом IP-адреса или сложным типом. |
| `<size>` | Неотрицательное значение `BIGINT`, задающее количество элементов, которые нужно удалить с конца массива. Оно не может превышать количество элементов в `<arr>`. |

## Возвращаемое значение {#return-value}

Возвращает массив `ARRAY<T>`, содержащий первые `cardinality(<arr>) - <size>` элементов массива `<arr>`.

- Если `<size>` равен `0`, возвращает исходный массив без изменений.
- Если `<size>` равен количеству элементов в массиве, возвращает пустой массив.
- Если любой из аргументов равен `NULL`, возвращает `NULL`.
- Элементы `NULL` внутри массива сохраняются.
- Если `<size>` отрицателен или превышает количество элементов в массиве, возвращает ошибку.

## Примеры {#examples}

Удаление двух элементов с конца массива:

```sql
SELECT trim_array([1, 2, 3, 4], 2);
```

```text
[1, 2]
```

При нулевом размере массив остаётся без изменений:

```sql
SELECT trim_array(['a', 'b', 'c'], 0);
```

```text
["a", "b", "c"]
```

Удаление всех элементов:

```sql
SELECT trim_array([1, 2, 3], 3);
```

```text
[]
```

Поддерживаются элементы `NULL` и вложенные массивы:

```sql
SELECT trim_array([[1, NULL], [2, 3], [4, 5]], 1);
```

```text
[[1, null], [2, 3]]
```

Если аргумент равен `NULL`, возвращается `NULL`:

```sql
SELECT trim_array(CAST(NULL AS ARRAY<INT>), 0);
```

```text
NULL
```

Если размер превышает количество элементов в массиве, возникает ошибка:

```sql
SELECT trim_array([1, 2, 3], 4);
```

```text
ERROR 1105 (HY000): size must not exceed array cardinality 3: 4
```
