## array_intersect {#array_intersect}

<version since="2.0.0">

</version>

### Описание {#description}

Возвращает пересечение нескольких массивов, то есть элементы, присутствующие во всех массивах. Функция находит элементы, присутствующие во всех входных массивах, и формирует из них новый массив без дубликатов.

### Синтаксис {#syntax}

```sql
array_intersect(ARRAY<T> arr1, ARRAY<T> arr2, [ARRAY<T> arr3, ...])
```

### Параметры {#parameters}

- `arr1, arr2, arr3, ...`: массивы типа ARRAY<T>, для которых вычисляется пересечение. Поддерживаются два и более параметра-массива.

**Поддерживаемые типы T:**
- Числовые типы: TINYINT, SMALLINT, INT, BIGINT, LARGEINT, FLOAT, DOUBLE, DECIMAL
- Строковые типы: CHAR, VARCHAR, STRING
- Типы даты и времени: DATE, DATETIME, DATEV2, DATETIMEV2, TIMESTAMP_NS
- Логический тип: BOOLEAN
- Типы IP: IPV4, IPV6
- UUID: [UUID](../../../basic-element/sql-data-types/uuid.md)

### Возвращаемое значение {#return-value}

Тип возвращаемого значения: ARRAY<T>

Описание возвращаемого значения:
- Возвращается новый массив, содержащий уникальные элементы, присутствующие во всех входных массивах
- Пустой массив: если во всех входных массивах нет общих элементов

Примечания по использованию:
- Функция находит элементы, присутствующие во всех входных массивах, и удаляет дубликаты из результирующего массива
- Пересечение пустого массива с любым массивом, отличным от NULL, даёт пустой массив. Если общих элементов нет, функция возвращает пустой массив.
- Функция не поддерживает массивы NULL
- Сравнение элементов выполняется по правилам совместимости типов. Если типы несовместимы, предпринимается попытка преобразования; при неудаче результатом становится null
- Значения null в элементах массива: при выполнении операции элементы null обрабатываются как обычные элементы, при этом null считается равным null

**Примеры запросов:**

Пересечение двух массивов:
```sql
SELECT array_intersect([1, 2, 3, 4, 5], [2, 4, 6, 8]);
+------------------------------------------------+
| array_intersect([1, 2, 3, 4, 5], [2, 4, 6, 8]) |
+------------------------------------------------+
| [4, 2]                                         |
+------------------------------------------------+
```

Пересечение нескольких массивов:
```sql
SELECT array_intersect([1, 2, 3, 4, 5], [2, 4, 6, 8], [2, 4, 10, 12]);
+----------------------------------------------------------------+
| array_intersect([1, 2, 3, 4, 5], [2, 4, 6, 8], [2, 4, 10, 12]) |
+----------------------------------------------------------------+
| [2, 4]                                                         |
+----------------------------------------------------------------+
```

Пересечение строковых массивов:
```sql
SELECT array_intersect(['a', 'b', 'c'], ['b', 'c', 'd']);
+--------------------------------------------+
| array_intersect(['a','b','c'], ['b','c','d']) |
+--------------------------------------------+
| ["b", "c"]                                 |
+--------------------------------------------+
```

Массив со значениями null: null рассматривается как значение, которое можно сравнивать на равенство:
```sql
SELECT array_intersect([1, null, 2, null, 3], [null, 2, 3, 4]);
+---------------------------------------------------------+
| array_intersect([1, null, 2, null, 3], [null, 2, 3, 4]) |
+---------------------------------------------------------+
| [null, 2, 3]                                            |
+---------------------------------------------------------+
```

Пересечение строкового массива и массива целых чисел:
Строку '2' можно преобразовать в целое число 2; преобразование 'b' завершается неудачей, и значение становится null:
```sql
SELECT array_intersect([1, 2, null, 3], ['2', 'b']);
+----------------------------------------------+
| array_intersect([1, 2, null, 3], ['2', 'b']) |
+----------------------------------------------+
| [null, 2]                                    |
+----------------------------------------------+
```

Пересечение пустого массива с любым массивом:
```sql
SELECT array_intersect([], [1, 2, 3]);
+-----------------------------+
| array_intersect([], [1,2,3]) |
+-----------------------------+
| []                          |
+-----------------------------+
```

Передача NULL вместо входных массивов приводит к ошибке:
```sql
SELECT array_intersect(NULL, NULL);
ERROR 1105 (HY000): errCode = 2, detailMessage = class org.apache.doris.nereids.types.NullType cannot be cast to class org.apache.doris.nereids.types.ArrayType (org.apache.doris.nereids.types.NullType and org.apache.doris.nereids.types.ArrayType are in unnamed module of loader 'app')
```

Сложные типы не поддерживаются и приводят к ошибке:
Вложенные массивы не поддерживаются и приводят к ошибке:
```sql
SELECT array_intersect([[1,2],[3,4],[5,6]]);
ERROR 1105 (HY000): errCode = 2, detailMessage = array_intersect does not support type ARRAY<ARRAY<TINYINT>>, expression is array_intersect([[1, 2], [3, 4], [5, 6]])
```

Типы Map не поддерживаются и приводят к ошибке:
```sql
SELECT array_intersect([{'k':1},{'k':2},{'k':3}]);
ERROR 1105 (HY000): errCode = 2, detailMessage = array_intersect does not support type ARRAY<MAP<VARCHAR(1),TINYINT>>, expression is array_intersect([map('k', 1), map('k', 2), map('k', 3)])
```

Ошибка при неверном количестве параметров:
```sql
SELECT array_intersect([1, 2, 3]);
ERROR 1105 (HY000): errCode = 2, detailMessage = Can not found function 'array_intersect' which has 1 arity. Candidate functions are: [array_intersect(Expression, Expression, ...)]
```

Ошибка при передаче значения, не являющегося массивом:
```sql
SELECT array_intersect('not_an_array', [1, 2, 3]);
ERROR 1105 (HY000): errCode = 2, detailMessage = Can not find the compatibility function signature: array_intersect(VARCHAR(12), ARRAY<INT>)
```

### Ключевые слова {#keywords}

ARRAY, INTERSECT, ARRAY_INTERSECT
