## Описание {#description}

Вычисляет векторное произведение двух трёхмерных числовых массивов.

Для `lhs = [x1, x2, x3]` и `rhs = [y1, y2, y3]` результат имеет вид:

`lhs x rhs = [x2 * y3 - x3 * y2, x3 * y1 - x1 * y3, x1 * y2 - x2 * y1]`

## Псевдоним {#alias}

- `cross_product`

## Синтаксис {#syntax}

```sql
array_cross_product(ARRAY<T> lhs, ARRAY<T> rhs)
```

## Параметры {#parameters}

| Параметр | Описание |
|---|---|
| `lhs` | Первый трёхмерный числовой массив |
| `rhs` | Второй трёхмерный числовой массив |

Для `T` поддерживаются `FLOAT` и целочисленные типы элементов массива, такие как `TINYINT`, `SMALLINT`, `INT`, `BIGINT` и `LARGEINT`.

## Возвращаемое значение {#return-value}

Возвращает `ARRAY<FLOAT>`.

- Возвращает `NULL`, если хотя бы один из входных массивов равен `NULL`.
- Возвращает ошибку, если хотя бы один из входных массивов содержит элементы `NULL`.
- Возвращает ошибку, если количество элементов хотя бы в одном из входных массивов не равно трём.

## Примеры {#examples}

```sql
SELECT array_cross_product([2.5, -3.0, 4.25], [-7.5, 0.5, 1.25]);
```

```text
+--------------------------------------------------------------+
| array_cross_product([2.5, -3.0, 4.25], [-7.5, 0.5, 1.25])    |
+--------------------------------------------------------------+
| [-5.875, -35, -21.25]                                        |
+--------------------------------------------------------------+
```

```sql
SELECT array_cross_product(CAST([-128, 0, 127] AS ARRAY<TINYINT>),
                           CAST([3, -5, 7] AS ARRAY<TINYINT>));
```

```text
+---------------------------------------------------------------------------------------------------+
| array_cross_product(CAST([-128, 0, 127] AS ARRAY<TINYINT>), CAST([3, -5, 7] AS ARRAY<TINYINT>)) |
+---------------------------------------------------------------------------------------------------+
| [635, 1277, 640]                                                                                  |
+---------------------------------------------------------------------------------------------------+
```

```sql
SELECT array_cross_product(CAST(NULL AS ARRAY<FLOAT>), [4.0, 5.0, 6.0]);
```

```text
+--------------------------------------------------------------------------+
| array_cross_product(CAST(NULL AS ARRAY<FLOAT>), [4.0, 5.0, 6.0])         |
+--------------------------------------------------------------------------+
| NULL                                                                     |
+--------------------------------------------------------------------------+
```

```sql
SELECT array_cross_product([-11, NULL, 13], [17, -19, 23]);
```

```text
ERROR 1105 (HY000): errCode = 2, detailMessage = function array_cross_product cannot have null
```
