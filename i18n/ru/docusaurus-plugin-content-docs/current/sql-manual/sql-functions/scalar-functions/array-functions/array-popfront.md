## array_popfront {#array_popfront}

<version since="2.0.0">

</version>

## Описание {#description}

Удаляет первый элемент массива. Функция возвращает новый массив, содержащий все элементы исходного массива, кроме первого.

## Синтаксис {#syntax}

```sql
array_popfront(ARRAY<T> arr)
```

### Параметры {#parameters}

- `arr`：тип ARRAY<T>, массив, из которого нужно удалить первый элемент

**Поддерживаемые типы T:**
- Числовые типы: TINYINT, SMALLINT, INT, BIGINT, LARGEINT, FLOAT, DOUBLE, DECIMAL
- Строковые типы: CHAR, VARCHAR, STRING
- Типы даты и времени: DATE, DATETIME, DATEV2, DATETIMEV2, TIMESTAMP_NS
- Логический тип: BOOLEAN
- Типы IP-адресов: IPV4, IPV6
- UUID: [UUID](../../../basic-element/sql-data-types/uuid.md)
- Сложные типы: ARRAY, MAP, STRUCT

### Возвращаемое значение {#return-value}

Тип возвращаемого значения: ARRAY<T>

Описание возвращаемого значения:
- Возвращает новый массив, содержащий все элементы исходного массива, кроме первого
- NULL: если входной массив равен NULL

Примечания по использованию:
- Функция удаляет первый элемент массива и возвращает оставшиеся элементы
- Для пустых массивов возвращаются пустые массивы; для массивов с единственным элементом также возвращаются пустые массивы
- Значения null в элементах массива: элементы null обрабатываются обычным образом

**Примеры запросов:**

Удаление первого элемента массива строк:
```sql
SELECT array_popfront(['apple', 'banana', 'cherry', 'date']);
+----------------------------------------------------+
| array_popfront(['apple', 'banana', 'cherry', 'date']) |
+----------------------------------------------------+
| ["banana", "cherry", "date"]                       |
+----------------------------------------------------+
```

Удаление первого элемента массива, содержащего значения null:
```sql
SELECT array_popfront([1, null, 3, null, 5]);
+------------------------------------------+
| array_popfront([1, null, 3, null, 5])   |
+------------------------------------------+
| [null, 3, null, 5]                      |
+------------------------------------------+
```

Для массивов с единственным элементом возвращаются пустые массивы:
```sql
SELECT array_popfront([42]);
+------------------------+
| array_popfront([42])   |
+------------------------+
| []                     |
+------------------------+
```

Для пустых массивов возвращаются пустые массивы:
```sql
SELECT array_popfront([]);
+------------------------+
| array_popfront([])     |
+------------------------+
| []                     |
+------------------------+
```

Для массивов со значением NULL возвращается NULL:
```sql
SELECT array_popfront(NULL);
+------------------------+
| array_popfront(NULL)   |
+------------------------+
| NULL                   |
+------------------------+
```

Удаление первого элемента массива IP-адресов:
```sql
SELECT array_popfront(CAST(['192.168.1.1', '192.168.1.2', '192.168.1.3'] AS ARRAY<IPV4>));
+----------------------------------------------------------------------------------+
| array_popfront(CAST(['192.168.1.1', '192.168.1.2', '192.168.1.3'] AS ARRAY<IPV4>)) |
+----------------------------------------------------------------------------------+
| ["192.168.1.2", "192.168.1.3"]                                                   |
+----------------------------------------------------------------------------------+
```

Удаление первого элемента вложенного массива:
```sql
SELECT array_popfront([[1, 2], [3, 4], [5, 6]]);
+------------------------------------------+
| array_popfront([[1, 2], [3, 4], [5, 6]]) |
+------------------------------------------+
| [[3, 4], [5, 6]]                         |
+------------------------------------------+
```

Удаление первого элемента массива MAP:
```sql
SELECT array_popfront([{'name':'Alice','age':20}, {'name':'Bob','age':30}, {'name':'Charlie','age':40}]);
+---------------------------------------------------------------------------------------------------+
| array_popfront([{'name':'Alice','age':20}, {'name':'Bob','age':30}, {'name':'Charlie','age':40}]) |
+---------------------------------------------------------------------------------------------------+
| [{"name":"Bob", "age":"30"}, {"name":"Charlie", "age":"40"}]                                      |
+---------------------------------------------------------------------------------------------------+
```

Удаление первого элемента массива STRUCT:
```sql
SELECT array_popfront(array(named_struct('name','Alice','age',20), named_struct('name','Bob','age',30), named_struct('name','Charlie','age',40)));
+-------------------------------------------------------------------------------------------------------------------------------------------+
| array_popfront(array(named_struct('name','Alice','age',20), named_struct('name','Bob','age',30), named_struct('name','Charlie','age',40))) |
+-------------------------------------------------------------------------------------------------------------------------------------------+
| [{"name":"Bob", "age":30}, {"name":"Charlie", "age":40}]                                                                                  |
+-------------------------------------------------------------------------------------------------------------------------------------------+
```

### Ключевые слова {#keywords}

ARRAY, POPFRONT, ARRAY_POPFRONT
