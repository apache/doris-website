## array_enumerate_uniq {#array_enumerate_uniq}

<version since="2.0.0">

</version>

## Описание {#description}

Возвращает порядковый номер вхождения каждого элемента массива. Функция формирует для каждого элемента массива номер, показывающий, сколько раз этот элемент уже встретился в массиве.

## Синтаксис {#syntax}

```sql
array_enumerate_uniq(ARRAY<T> arr1, [ARRAY<T> arr2, ...])
```

### Параметры {#parameters}

- `arr1, arr2, ...`：массивы типа ARRAY<T>, для которых требуется сгенерировать уникальные номера. Поддерживается передача одного или нескольких массивов.

**Поддерживаемые типы T:**
- Числовые типы: TINYINT, SMALLINT, INT, BIGINT, LARGEINT, FLOAT, DOUBLE, DECIMAL
- Строковые типы: CHAR, VARCHAR, STRING
- Типы даты и времени: DATE, DATETIME, DATEV2, DATETIMEV2, TIMESTAMP_NS
- Логический тип: BOOLEAN
- Типы IP: IPV4, IPV6
- UUID: [UUID](../../../basic-element/sql-data-types/uuid.md)

### Возвращаемое значение {#return-value}

Тип возвращаемого значения: ARRAY<BIGINT>

Смысл возвращаемого значения:
- Возвращается новый массив той же длины, что и входной массив. В каждой позиции содержится порядковый номер вхождения соответствующего элемента массива
- NULL: если входной массив равен NULL

Примечания по использованию:
- Функция формирует уникальные номера для каждого элемента массива, начиная с 1 и далее увеличивая их
- Если элемент встречается несколько раз, при каждом его вхождении номер увеличивается
- При передаче нескольких массивов все они должны иметь одинаковую длину, иначе возникает ошибка. Элементы на соответствующих позициях нескольких массивов объединяются в пары, на основе которых формируются номера
- Для пустых массивов возвращаются пустые массивы, для массивов NULL возвращается NULL
- Обработка значений null в элементах массива: элементам null также присваиваются соответствующие номера

**Примеры запросов:**

Генерация уникальных номеров для элементов массива. Если элемент встречается несколько раз, при каждом его вхождении номер увеличивается:
```sql
SELECT array_enumerate_uniq([1, 2, 1, 3, 2, 1]);
+------------------------------------------+
| array_enumerate_uniq([1, 2, 1, 3, 2, 1]) |
+------------------------------------------+
| [1, 1, 2, 1, 2, 3]                       |
+------------------------------------------+
```

Для пустого массива возвращается пустой массив:
```sql
SELECT array_enumerate_uniq([]);
+----------------------+
| array_enumerate_uniq([]) |
+----------------------+
| []                   |
+----------------------+
```

Для массива NULL возвращается NULL:
```sql
SELECT array_enumerate_uniq(NULL), array_enumerate_uniq(NULL, NULL);
+----------------------------+----------------------------------+
| array_enumerate_uniq(NULL) | array_enumerate_uniq(NULL, NULL) |
+----------------------------+----------------------------------+
| NULL                       | NULL                             |
+----------------------------+----------------------------------+
```

Массив со значениями null: элементам null также присваиваются номера:
```sql
SELECT array_enumerate_uniq([1, null, 1, null, 1]);
+--------------------------------------------+
| array_enumerate_uniq([1, null, 1, null, 1]) |
+--------------------------------------------+
| [1, 1, 2, 2, 3]                            |
+--------------------------------------------+
```

Пример с несколькими массивами: номера формируются на основе комбинаций элементов нескольких массивов:
```sql
SELECT array_enumerate_uniq([1, 2, 1], [10, 20, 10]);
+----------------------------------------------+
| array_enumerate_uniq([1, 2, 1], [10, 20, 10]) |
+----------------------------------------------+
| [1, 1, 2]                                    |
+----------------------------------------------+
```

Ошибка при несовпадении длин массивов:
```sql
SELECT array_enumerate_uniq([1,2,3], [4,5]);
ERROR 1105 (HY000): errCode = 2, detailMessage = lengths of all arrays of function array_enumerate_uniq must be equal.
```

Примеры использования типов IP:
```sql
SELECT array_enumerate_uniq(CAST(['192.168.1.1', '192.168.1.2', '192.168.1.1'] AS ARRAY<IPV4>));
+------------------------------------------------------------------------------------------+
| array_enumerate_uniq(CAST(['192.168.1.1', '192.168.1.2', '192.168.1.1'] AS ARRAY<IPV4>)) |
+------------------------------------------------------------------------------------------+
| [1, 1, 2]                                                                                |
+------------------------------------------------------------------------------------------+

mysql> SELECT array_enumerate_uniq(CAST(['2001:db8::1', '2001:db8::2', '2001:db8::1'] AS ARRAY<IPV6>));
+------------------------------------------------------------------------------------------+
| array_enumerate_uniq(CAST(['2001:db8::1', '2001:db8::2', '2001:db8::1'] AS ARRAY<IPV6>)) |
+------------------------------------------------------------------------------------------+
| [1, 1, 2]                                                                                |
+------------------------------------------------------------------------------------------+
```

Примеры со сложными типами:

Вложенные массивы не поддерживаются; вызов приводит к ошибке:
```sql
SELECT array_enumerate_uniq([[1,2],[3,4],[5,6]]);
ERROR 1105 (HY000): errCode = 2, detailMessage = array_enumerate_uniq does not support type ARRAY<ARRAY<TINYINT>>, expression is array_enumerate_uniq([[1, 2], [3, 4], [5, 6]])
```

Типы Map не поддерживаются; вызов приводит к ошибке:
```sql
SELECT array_enumerate_uniq([{'k':1},{'k':2},{'k':3}]);
ERROR 1105 (HY000): errCode = 2, detailMessage = array_enumerate_uniq does not support type ARRAY<MAP<VARCHAR(1),TINYINT>>, expression is array_enumerate_uniq([map('k', 1), map('k', 2), map('k', 3)])
```

Ошибка при неверном количестве параметров:
```sql
SELECT array_enumerate_uniq();
ERROR 1105 (HY000): errCode = 2, detailMessage = Can not found function 'array_enumerate_uniq' which has 0 arity. Candidate functions are: [array_enumerate_uniq(Expression, Expression...)]
```

Ошибка при передаче значения, не являющегося массивом:
```sql
SELECT array_enumerate_uniq('not_an_array');
ERROR 1105 (HY000): errCode = 2, detailMessage = Can not find the compatibility function signature: array_enumerate_uniq(VARCHAR(12))
```

### Ключевые слова {#keywords}

ARRAY, ENUMERATE, UNIQ, ARRAY_ENUMERATE_UNIQ
