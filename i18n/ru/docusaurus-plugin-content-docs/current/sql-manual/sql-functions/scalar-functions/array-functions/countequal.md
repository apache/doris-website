## Функция {#function}

Подсчитывает количество элементов массива, равных заданному целевому значению.

## Синтаксис {#syntax}

- `COUNTEQUAL(arr, target)`

## Параметры {#parameters}

- `arr`: `ARRAY<T>`, поддерживаются числовые, логические и строковые типы элементов, а также datetime, IP и UUID.
- `target`: имеет тот же тип, что и элементы `arr`.

## Возвращаемое значение {#return-value}

- Возвращает `BIGINT`, представляющий количество равных элементов.

## Примечания по использованию {#usage-notes}

- В этой функции `NULL` равен `NULL` и учитывается при подсчёте.

## Примеры {#examples}

- Базовые примеры
  - `COUNTEQUAL([1,2,3,2], 2)` -> `2`
  - `COUNTEQUAL(['a','b','a'], 'a')` -> `2`
  - `COUNTEQUAL([true,false,false], false)` -> `2`

- `NULL` считается равным самому себе и учитывается при подсчёте
  - `COUNTEQUAL([1,NULL,2,NULL], NULL)` -> `2`
  - `COUNTEQUAL([1,NULL,1], 1)` -> `2`
  - `COUNTEQUAL([1, 2], NULL)` -> `0`

- Если массив равен `NULL`, возвращается `NULL`
  - `COUNTEQUAL(NULL, 1)` -> `NULL`
