## array_popback {#array_popback}

<version since="2.0.0">

</version>

## Описание {#description}

Удаляет последний элемент массива. Функция возвращает новый массив, содержащий все элементы исходного массива, кроме последнего.

## Синтаксис {#syntax}

```sql
array_popback(ARRAY<T> arr)
```

### Параметры {#parameters}

- `arr`：тип ARRAY<T>, массив, из которого нужно удалить последний элемент

**Поддерживаемые типы T:**
- Числовые типы: TINYINT, SMALLINT, INT, BIGINT, LARGEINT, FLOAT, DOUBLE, DECIMAL
- Строковые типы: CHAR, VARCHAR, STRING
- Типы даты и времени: DATE, DATETIME, DATEV2, DATETIMEV2, TIMESTAMP_NS
- Логический тип: BOOLEAN
- Типы IP: IPV4, IPV6
- UUID: [UUID](../../../basic-element/sql-data-types/uuid.md)
- Сложные типы: ARRAY, MAP, STRUCT

### Возвращаемое значение {#return-value}

Тип возвращаемого значения: ARRAY<T>

Описание возвращаемого значения:
- Возвращает новый массив, содержащий все элементы исходного массива, кроме последнего
- NULL: если входной массив равен NULL

Примечания по использованию:
- Функция удаляет последний элемент массива и возвращает оставшиеся элементы
- Для пустых массивов и массивов, содержащих только один элемент, возвращаются пустые массивы
- Элементы массива со значением null обрабатываются обычным образом

**Примеры запросов:**

Удаление последнего элемента строкового массива:
```sql
SELECT array_popback(['apple', 'banana', 'cherry', 'date']);
+--------------------------------------------------+
| array_popback(['apple', 'banana', 'cherry', 'date']) |
+--------------------------------------------------+
| ["apple", "banana", "cherry"]                    |
+--------------------------------------------------+
```

Удаление последнего элемента массива, содержащего значения null:
```sql
SELECT array_popback([1, null, 3, null, 5]);
+--------------------------------------------+
| array_popback([1, null, 3, null, 5])      |
+--------------------------------------------+
| [1, null, 3, null]                        |
+--------------------------------------------+
```

Для массивов, содержащих только один элемент, возвращаются пустые массивы:
```sql
SELECT array_popback([42]);
+----------------------+
| array_popback([42])  |
+----------------------+
| []                   |
+----------------------+
```

Для пустых массивов возвращаются пустые массивы:
```sql
SELECT array_popback([]);
+----------------------+
| array_popback([])    |
+----------------------+
| []                   |
+----------------------+
```

Для массивов со значением NULL возвращается NULL:
```sql
SELECT array_popback(NULL);
+----------------------+
| array_popback(NULL)  |
+----------------------+
| NULL                 |
+----------------------+
```

Удаление последнего элемента массива IP-адресов:
```sql
SELECT array_popback(CAST(['192.168.1.1', '192.168.1.2', '192.168.1.3'] AS ARRAY<IPV4>));
+----------------------------------------------------------------------------------+
| array_popback(CAST(['192.168.1.1', '192.168.1.2', '192.168.1.3'] AS ARRAY<IPV4>)) |
+----------------------------------------------------------------------------------+
| ["192.168.1.1", "192.168.1.2"]                                                   |
+----------------------------------------------------------------------------------+
```

Удаление последнего элемента вложенного массива:
```sql
SELECT array_popback([[1, 2], [3, 4], [5, 6]]);
+------------------------------------------+
| array_popback([[1, 2], [3, 4], [5, 6]]) |
+------------------------------------------+
| [[1, 2], [3, 4]]                         |
+------------------------------------------+
```

Удаление последнего элемента массива MAP:
```sql
SELECT array_popback([{'name':'Alice','age':20}, {'name':'Bob','age':30}, {'name':'Charlie','age':40}]);
+--------------------------------------------------------------------------------------------------+
| array_popback([{'name':'Alice','age':20}, {'name':'Bob','age':30}, {'name':'Charlie','age':40}]) |
+--------------------------------------------------------------------------------------------------+
| [{"name":"Alice", "age":"20"}, {"name":"Bob", "age":"30"}]                                       |
+--------------------------------------------------------------------------------------------------+
```

Удаление последнего элемента массива STRUCT:
```sql
SELECT array_popback(array(named_struct('name','Alice','age',20), named_struct('name','Bob','age',30), named_struct('name','Charlie','age',40)));
+-------------------------------------------------------------------------------------------------------------------------------------------+
| array_popback(array(named_struct('name','Alice','age',20), named_struct('name','Bob','age',30), named_struct('name','Charlie','age',40))) |
+-------------------------------------------------------------------------------------------------------------------------------------------+
| [{"name":"Alice", "age":20}, {"name":"Bob", "age":30}]                                                                                    |
+-------------------------------------------------------------------------------------------------------------------------------------------+
```

### Ключевые слова {#keywords}

ARRAY, POPBACK, ARRAY_POPBACK
