## Описание {#description}

Вычисляет площадь замкнутой области на поверхности Земли в квадратных километрах. Входной параметр представляет собой геометрический объект (например, GeoPolygon, GeoCircle, GeoMultiPolygon), задающий область на поверхности Земли.



## Синтаксис {#syntax}

```sql
ST_AREA_SQUARE_KM( <geo>)
```
## Параметры {#parameters}

| Параметры | Описание     |
| -- |--------|
| `<geo>` | Геометрический объект на поверхности Земли типа GeoPolygon, GeoCircle или GeoMultiPolygon, который должен образовывать замкнутую область.|

## Возвращаемое значение {#return-value}

Возвращает площадь области в квадратных километрах в виде значения типа DOUBLE.

Особые случаи для ST_AREA_SQUARE_KM:

- Возвращает NULL, если входной параметр равен NULL.
- Возвращает NULL, если входной геометрический объект некорректен (например, имеет самопересечения или нулевую площадь).
- Если входной геометрический объект не замкнут (например, точка GeoPoint или отрезок GeoLineString), возвращает 0.
- Возвращает NULL, если какая-либо координата выходит за допустимый диапазон долготы или широты (долгота [-180, 180], широта [-90, 90]).

## Пример {#example}

Небольшая квадратная область (небольшой диапазон долготы и широты) со сторонами примерно по 1° и площадью примерно 12,364 квадратных километров.

```sql
SELECT ST_Area_Square_Km(ST_Polygon("POLYGON ((0 0, 1 0, 1 1, 0 1, 0 0))"));
```

```text
+----------------------------------------------------------------------+
| st_area_square_km(st_polygon('POLYGON ((0 0, 1 0, 1 1, 0 1, 0 0))')) |
+----------------------------------------------------------------------+
|                                                   12364.036567076409 |
+----------------------------------------------------------------------+
```

Прямоугольная область большего размера

```sql
mysql> SELECT ST_Area_Square_Km(ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"));
+--------------------------------------------------------------------------+
| ST_Area_Square_Km(ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))")) |
+--------------------------------------------------------------------------+
|                                                       1233204.7035253085 |
+--------------------------------------------------------------------------+

```

Сложный многоугольник с криволинейными рёбрами
