## Описание {#description}

Определяет, пересекаются ли две геометрические фигуры, то есть имеют ли они хотя бы одну общую точку (включая касание границ или перекрытие внутренних областей).

:::info Примечание
Поддерживается начиная с Apache Doris 3.0.6.
:::

## Синтаксис {#syntax}

```sql
ST_INTERSECTS( <shape1>, <shape2>)
```

## Параметры {#parameters}

| Параметр       | Описание                     |
|----------|------------------------|
| `<shape1>` | Первая геометрическая фигура, для которой проверяется пересечение с другой фигурой. Поддерживаются такие типы, как Point, Line, Polygon, Circle. |
| `<shape2>` | 	Вторая геометрическая фигура, для которой проверяется пересечение с другой фигурой. Поддерживаются такие типы, как Point, Line, Polygon, Circle. |

## Возвращаемое значение {#return-value}

Возвращает 1: shape1 пересекается с shape2

Возвращает 0: shape1 не пересекается с shape2

Для ST_INTERSECTS предусмотрены следующие особые случаи:

- Если хотя бы один входной параметр равен NULL, возвращает NULL.
- Если входная геометрическая фигура некорректна, возвращает NULL.
- Если входная геометрическая фигура пуста, возвращает NULL.
- Если две фигуры лишь касаются друг друга на границе (имеют единственную общую точку), возвращает 1 (касание границ считается пересечением)

## Пример {#example}


Точка внутри многоугольника (есть пересечение, возвращает 1)

```sql
SELECT ST_Intersects(ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"), ST_Point(5, 5));
```

```text
+--------------------------------------------------------------------------------------+
| ST_Intersects(ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"), ST_Point(5, 5)) |
+--------------------------------------------------------------------------------------+
|                                                                                    1 |
+--------------------------------------------------------------------------------------+
```

Точка на границе многоугольника (есть пересечение, возвращает 1)

```sql

mysql> SELECT ST_INTERSECTS(  ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"),  ST_Point(0, 5));
+-----------------------------------------------------------------------------------------+
| ST_INTERSECTS(  ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"),  ST_Point(0, 5)) |
+-----------------------------------------------------------------------------------------+
|                                                                                       1 |
+-----------------------------------------------------------------------------------------+
```

Точка вне многоугольника (нет пересечения, возвращает 0)

```sql
mysql> SELECT ST_INTERSECTS(  ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"),  ST_Point(50, 50));
+-------------------------------------------------------------------------------------------+
| ST_INTERSECTS(  ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"),  ST_Point(50, 50)) |
+-------------------------------------------------------------------------------------------+
|                                                                                         0 |
+-------------------------------------------------------------------------------------------+
```

Линии пересекаются (есть пересечение, возвращает 1)

```sql
mysql> SELECT ST_INTERSECTS(  ST_Linefromtext("LINESTRING (0 0, 10 10)"),  ST_Linefromtext("LINESTRING (0 10, 10 0)"));
+----------------------------------------------------------------------------------------------------------+
| ST_INTERSECTS(  ST_Linefromtext("LINESTRING (0 0, 10 10)"),  ST_Linefromtext("LINESTRING (0 10, 10 0)")) |
+----------------------------------------------------------------------------------------------------------+
|                                                                                                        1 |
+----------------------------------------------------------------------------------------------------------+
```

Линии имеют одну общую точку


Линии параллельны и расположены на расстоянии друг от друга (нет пересечения, возвращает 0)
