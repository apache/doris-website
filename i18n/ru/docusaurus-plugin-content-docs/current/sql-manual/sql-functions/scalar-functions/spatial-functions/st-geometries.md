## Описание {#description}

Разбивает геометрический объект на массив составляющих его геометрических объектов. Для типов коллекций (MultiPolygon) каждый составляющий полигон возвращается как отдельный элемент массива. Для типов, не являющихся коллекциями (Point, LineString, Polygon, Circle), возвращается массив из одного элемента, содержащий сам геометрический объект.

## Синтаксис {#syntax}

```sql
ST_GEOMETRIES( <shape> )
```

## Параметры {#parameters}

| Параметр | Описание |
| :--- | :--- |
| `<shape>` | Входной геометрический объект типа GEOMETRY или VARCHAR (в формате WKT), который можно преобразовать в GEOMETRY. |

## Возвращаемое значение {#return-value}

Возвращает `ARRAY<STRING>`, каждый элемент которого представляет собой закодированный геометрический объект, пригодный для использования с другими пространственными функциями, такими как `ST_AsText` или `ST_GeometryType`.

Особые случаи для `ST_GEOMETRIES`:
-   Если входной параметр равен `NULL`, возвращается `NULL`.
-   Если входной параметр не удаётся разобрать как корректный геометрический объект, возвращается `NULL`.
-   Для типов, не являющихся коллекциями (`POINT`, `LINESTRING`, `POLYGON`, `CIRCLE`), возвращается массив из одного элемента, содержащий входной геометрический объект.
-   Для `MULTIPOLYGON` возвращается массив, каждый элемент которого представляет собой один из составляющих полигонов.
-   Элементы массива можно передавать другим пространственным функциям для дальнейшей обработки.

## Пример {#example}

**Составляющие объекта Point (массив из одного элемента)**
```sql
SELECT ST_AsText(ST_GEOMETRIES(ST_Point(1, 2))[1]);
```
```text
+------------------------------------------------+
| ST_AsText(ST_GEOMETRIES(ST_Point(1, 2))[1])    |
+------------------------------------------------+
| POINT (1 2)                                    |
+------------------------------------------------+
```

**Составляющие объекта Polygon (массив из одного элемента)**
```sql
SELECT ST_GeometryType(ST_GEOMETRIES(ST_GeometryFromText('POLYGON((0 0, 1 0, 1 1, 0 1, 0 0))'))[1]);
```
```text
+----------------------------------------------------------------------------------------------------+
| ST_GeometryType(ST_GEOMETRIES(ST_GeometryFromText('POLYGON((0 0, 1 0, 1 1, 0 1, 0 0))'))[1])    |
+----------------------------------------------------------------------------------------------------+
| ST_POLYGON                                                                                         |
+----------------------------------------------------------------------------------------------------+
```

**Составляющие объекта MultiPolygon (несколько элементов)**
```sql
SELECT SIZE(ST_GEOMETRIES(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))')));
```
```text
+----------------------------------------------------------------------------------------------------------------------+
| SIZE(ST_GEOMETRIES(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))))') |
+----------------------------------------------------------------------------------------------------------------------+
|                                                                                                                    2 |
+----------------------------------------------------------------------------------------------------------------------+
```

**Доступ к отдельным элементам MultiPolygon**
```sql
SELECT ST_AsText(ST_GEOMETRIES(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))'))[1]);
```
```text
+----------------------------------------------------------------------------------------------------------------------------------+
| ST_AsText(ST_GEOMETRIES(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))'))[1])    |
+----------------------------------------------------------------------------------------------------------------------------------+
| POLYGON ((1 0, 1 1, 0 1, 0 0, 1 0))                                                                                             |
+----------------------------------------------------------------------------------------------------------------------------------+
```

```sql
SELECT ST_AsText(ST_GEOMETRIES(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))'))[2]);
```
```text
+----------------------------------------------------------------------------------------------------------------------------------+
| ST_AsText(ST_GEOMETRIES(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))'))[2])    |
+----------------------------------------------------------------------------------------------------------------------------------+
| POLYGON ((3 2, 3 3, 2 3, 2 2, 3 2))                                                                                             |
+----------------------------------------------------------------------------------------------------------------------------------+
```

**Индекс за пределами массива (возвращает NULL)**
```sql
SELECT ST_GEOMETRIES(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))'))[3];
```
```text
+----------------------------------------------------------------------------------------------------------------------------+
| ST_GEOMETRIES(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))'))[3]          |
+----------------------------------------------------------------------------------------------------------------------------+
| NULL                                                                                                                       |
+----------------------------------------------------------------------------------------------------------------------------+
```

**Параметр NULL**
```sql
SELECT ST_GEOMETRIES(NULL);
```
```text
+----------------------+
| ST_GEOMETRIES(NULL)  |
+----------------------+
| NULL                 |
+----------------------+
```

**Недопустимый параметр (возвращает NULL)**
```sql
SELECT ST_GEOMETRIES(ST_GeometryFromText('INVALID'));
```
```text
+----------------------------------------------------+
| ST_GEOMETRIES(ST_GeometryFromText('INVALID'))      |
+----------------------------------------------------+
| NULL                                               |
+----------------------------------------------------+
```
