## Описание {#description}

Преобразует заданное значение в тип HLL (HyperLogLog). Эта функция обычно используется при загрузке данных для создания HLL на основе исходных данных.

## Синтаксис {#syntax}

```sql
HLL_HASH(<value>)
```

## Параметры {#parameters}

| Параметр | Описание                                                   |
|-----------|---------------------------------------------------------------|
| `<value>` | Значение для преобразования в тип HLL. Это может быть строка, число или значение любого типа данных. |

## Примеры {#examples}

```sql
SELECT HLL_CARDINALITY(HLL_HASH('abc'));
```

```text
+----------------------------------+
| hll_cardinality(HLL_HASH('abc')) |
+----------------------------------+
|                                1 |
+----------------------------------+
```
