## Описание {#description}

Вычисляет и возвращает максимальное значение в Bitmap.

## Синтаксис {#syntax}

```sql
BITMAP_MAX(<bitmap>)
```

## Параметры {#parameters}

| Параметр   | Описание                        |
|------------|---------------------------------|
| `<bitmap>` | Столбец или выражение типа Bitmap |

## Возвращаемое значение {#return-value}

Максимальное значение в Bitmap.  
Возвращает `NULL`, если Bitmap пуст или имеет значение NULL.

## Примеры {#examples}

Чтобы вычислить максимальное значение в пустом Bitmap:

```sql
select bitmap_max(bitmap_from_string('')) value;
```

Результат будет следующим:

```text
+-------+
| value |
+-------+
|  NULL |
+-------+
```

Чтобы вычислить максимальное значение в Bitmap с несколькими элементами:

```sql
select bitmap_max(bitmap_from_string('1,9999999999')) value;
```

Результат будет следующим:

```text
+------------+
| value      |
+------------+
| 9999999999 |
+------------+
```

```sql
select bitmap_max(bitmap_empty()) res1, bitmap_max(NULL) res2;
```

Результат будет следующим:

```text
+------+------+
| res1 | res2 |
+------+------+
| NULL | NULL |
+------+------+
```
