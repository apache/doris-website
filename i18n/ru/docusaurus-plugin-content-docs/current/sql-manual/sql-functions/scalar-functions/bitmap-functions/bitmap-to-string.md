## Описание {#description}

Преобразует Bitmap в строку, содержащую позиции всех установленных битов через запятую.

## Синтаксис {#syntax}

```sql
BITMAP_TO_STRING(<bitmap>)
```

## Параметры {#parameters}

| Параметр   | Описание                        |
|------------|---------------------------------|
| `<bitmap>` | Столбец типа Bitmap или выражение |

## Возвращаемое значение {#return-value}

Строка, содержащая позиции всех установленных битов в Bitmap, разделённые запятыми.  
Возвращает `NULL`, если Bitmap имеет значение `NULL`.

## Примеры {#examples}

Преобразование Bitmap со значением `NULL` в строку:

```sql
select bitmap_to_string(null);
```

Результат:

```text
+------------------------+
| bitmap_to_string(NULL) |
+------------------------+
| NULL                   |
+------------------------+
```

Преобразование пустого Bitmap в строку:

```sql
select bitmap_to_string(bitmap_empty());
```

Результат:

```text
+----------------------------------+
| bitmap_to_string(bitmap_empty()) |
+----------------------------------+
|                                  |
+----------------------------------+
```

Преобразование Bitmap с одним элементом в строку:

```sql
select bitmap_to_string(to_bitmap(1));
```

Результат:

```text
+--------------------------------+
| bitmap_to_string(to_bitmap(1)) |
+--------------------------------+
| 1                              |
+--------------------------------+
```

Преобразование Bitmap с несколькими элементами в строку:

```sql
select bitmap_to_string(bitmap_or(to_bitmap(1), to_bitmap(2)));
```

Результат:

```text
+---------------------------------------------------------+
| bitmap_to_string(bitmap_or(to_bitmap(1), to_bitmap(2))) |
+---------------------------------------------------------+
| 1,2                                                     |
+---------------------------------------------------------+
```
