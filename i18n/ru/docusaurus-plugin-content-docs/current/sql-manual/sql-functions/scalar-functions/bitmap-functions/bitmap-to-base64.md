## Описание {#description}

Преобразует Bitmap в строку в кодировке Base64.

## Синтаксис {#syntax}

```sql
BITMAP_TO_BASE64(<bitmap>)
```

## Параметры {#parameters}

| Параметр   | Описание                        |
|------------|---------------------------------|
| `<bitmap>` | Столбец или выражение типа Bitmap |

## Возвращаемое значение {#return-value}

Строка в кодировке Base64, представляющая Bitmap.  
Возвращает `NULL`, если Bitmap имеет значение `NULL`.

::: note

Параметр конфигурации BE `enable_set_in_bitmap_value` изменяет формат представления значений bitmap в памяти, что влияет на результат этой функции.  
Порядок элементов в bitmap не гарантирован, поэтому для одного и того же содержимого могут генерироваться разные строки Base64. Однако после декодирования с помощью `bitmap_from_base64` результатом будет один и тот же bitmap.

:::

## Примеры {#examples}

Чтобы преобразовать Bitmap со значением `NULL` в строку Base64:

```sql
select bitmap_to_base64(null);
```

Результат:

```text
+------------------------+
| bitmap_to_base64(NULL) |
+------------------------+
| NULL                   |
+------------------------+
```

Чтобы преобразовать пустой Bitmap в строку Base64:

```sql
select bitmap_to_base64(bitmap_empty());
```

Результат:

```text
+----------------------------------+
| bitmap_to_base64(bitmap_empty()) |
+----------------------------------+
| AA==                             |
+----------------------------------+
```

Чтобы преобразовать Bitmap с одним элементом в строку Base64:

```sql
select bitmap_to_base64(to_bitmap(1));
```

Результат:

```text
+--------------------------------+
| bitmap_to_base64(to_bitmap(1)) |
+--------------------------------+
| BQEBAAAAAAAAAA==               |
+--------------------------------+
```

Чтобы преобразовать Bitmap с несколькими элементами в строку Base64:

```sql
select bitmap_to_base64(bitmap_from_string("1,9999999"));
```

Результат:

```text
+---------------------------------------------------------+
| bitmap_to_base64(bitmap_from_string("1,9999999"))       |
+---------------------------------------------------------+
| BQIBAAAAAAAAAH+WmAAAAAAA                          |
+---------------------------------------------------------+
```
