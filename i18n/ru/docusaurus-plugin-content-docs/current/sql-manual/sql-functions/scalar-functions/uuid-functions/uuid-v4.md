## Описание {#description}

Генерирует UUID версии 4 встроенного типа UUID. В версии 4 используются случайные значения.

## Псевдонимы {#alias}

`GENERATE_UUID_V4`, `GENERATEUUIDV4`.

## Примечания по использованию {#usage-notes}

Генерирует значение независимо для каждой строки. Не принимает аргументов, поэтому передавать `NULL` нельзя. Может использоваться как динамическое значение по умолчанию для столбца UUID в `CREATE TABLE`; `ALTER TABLE ADD COLUMN` не поддерживает такое динамическое значение по умолчанию. См. [тип UUID](../../../basic-element/sql-data-types/uuid.md).

## Синтаксис {#syntax}

```sql
UUID_V4()
```

## Параметры {#parameters}

| Параметр | Описание |
| --- | --- |
| Нет | Не принимает аргументов. |

## Возвращаемое значение {#return-value}

Возвращает значение типа `UUID`, которое никогда не бывает `NULL`. Значения отображаются в каноническом формате длиной 36 символов с буквами в нижнем регистре.

## Пример {#example}

```sql
SELECT UUID_VERSION(UUID_V4()) AS version,
       LENGTH(CAST(UUID_V4() AS STRING)) AS text_length;
```

```text
+---------+-------------+
| version | text_length |
+---------+-------------+
| 4       | 36          |
+---------+-------------+
```

```sql
SELECT UUID_VERSION(GENERATE_UUID_V4()) AS alias_version,
       UUID_VERSION(GENERATEUUIDV4()) AS compact_alias_version;
```

```text
+---------------+-----------------------+
| alias_version | compact_alias_version |
+---------------+-----------------------+
| 4             | 4                     |
+---------------+-----------------------+
```
