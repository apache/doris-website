## Описание {#description}

Функция TOPN_WEIGHTED возвращает N наиболее часто встречающихся значений в указанном столбце с учётом весов. В отличие от обычной функции TOPN, TOPN_WEIGHTED позволяет регулировать значимость значений с помощью весов.

## Синтаксис {#syntax}

```sql
TOPN_WEIGHTED(<expr>, <weight>, <top_num> [, <space_expand_rate>])
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<expr>` | Столбец или выражение, для значений которого выполняется подсчёт. Поддерживаемые типы: Boolean (в линейке Doris 4.1 начиная с 4.1.5), TinyInt, SmallInt, Integer, BigInt, LargeInt, Float, Double, Decimal, Date, Datetime, TimestampNs, IPV4, IPV6, UUID, String. |
| `<weight>` | Столбец или выражение, используемое для задания веса. Тип: BIGINT.|
| `<top_num>` | Количество наиболее часто встречающихся значений, которые нужно вернуть. Должно быть положительной константой типа INT. |
| `<space_expand_rate>` | Необязательная константа типа INT, значение по умолчанию: 50. При положительном значении во время сериализации промежуточного состояния сохраняется не более `top_num * space_expand_rate` кандидатов; более высокие значения обычно повышают точность. Этот параметр не задаёт жёсткого ограничения на объём памяти для локальной агрегации. В линейке Doris 4.1 начиная с 4.1.5 при значении 0 или меньше сохраняются все промежуточные кандидаты, при этом итоговый результат по-прежнему содержит не более `top_num` значений. Этот режим может потреблять больше памяти, и на него по-прежнему распространяются ограничения на использование памяти запросом. |

## Возвращаемое значение {#return-value}

Возвращает массив, содержащий N значений с наибольшими взвешенными частотами.
Если в группе нет допустимых данных, возвращает NULL.

## Пример {#example}
```sql
-- setup
CREATE TABLE product_sales (
    product_id INT,
    sale_amount DECIMAL(10,2),
    sale_date DATE
) DISTRIBUTED BY HASH(product_id)
PROPERTIES (
    "replication_num" = "1"
);
INSERT INTO product_sales VALUES
(1, 100.00, '2024-01-01'),
(2, 50.00, '2024-01-01'),
(1, 150.00, '2024-01-01'),
(3, 75.00, '2024-01-01'),
(1, 200.00, '2024-01-01'),
(2, 80.00, '2024-01-01'),
(1, 120.00, '2024-01-01'),
(4, 90.00, '2024-01-01');
```

```sql
SELECT TOPN_WEIGHTED(product_id, sale_amount, 3) as top_products
FROM product_sales;
```

Найдите 3 товара с наибольшей суммой продаж (с учётом весов).

```text
+--------------+
| top_products |
+--------------+
| [1, 2, 4]    |
+--------------+
```

```sql
SELECT TOPN_WEIGHTED(product_id, sale_amount, 3) as top_products
FROM product_sales where product_id is null;
```

Найдите 3 товара с наибольшей суммой продаж (с учётом весов).

```text
+--------------+
| top_products |
+--------------+
| NULL         |
+--------------+
```

Входные данные типа BOOLEAN (в линейке Doris 4.1 начиная с 4.1.5):

```sql
SELECT TOPN_WEIGHTED(TRUE, 1, 2), TOPN_WEIGHTED(CAST(NULL AS BOOLEAN), 1, 2);
```

```text
[1]    NULL
```
