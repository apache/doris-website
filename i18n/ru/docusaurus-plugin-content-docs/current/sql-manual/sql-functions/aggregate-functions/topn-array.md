## Описание {#description}

TOPN_ARRAY возвращает массив из N наиболее часто встречающихся значений в указанном столбце. Это функция приближённого вычисления, которая возвращает результаты в порядке убывания числа вхождений.

## Синтаксис {#syntax}

```sql
TOPN_ARRAY(<expr>, <top_num> [, <space_expand_rate>])
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<expr>` | Столбец или выражение, для которого подсчитывается число вхождений значений. Поддерживаемые типы: Boolean (в серии Doris 4.1 начиная с версии 4.1.5), TinyInt, SmallInt, Integer, BigInt, LargeInt, Float, Double, Decimal, Date, Datetime, TimestampNs, Timestamptz, IPV4, IPV6, UUID, String. |
| `<top_num>` | Количество наиболее часто встречающихся значений, которые нужно вернуть. Должно быть положительной константой типа INT. |
| `<space_expand_rate>` | Необязательная константа типа INT, по умолчанию 50. При положительном значении во время сериализации промежуточного состояния сохраняется не более `top_num * space_expand_rate` кандидатов; более высокие значения обычно повышают точность. Этот параметр не задаёт жёсткий предел использования памяти при локальной агрегации. В серии Doris 4.1 начиная с версии 4.1.5 при значении 0 или меньше сохраняются все промежуточные кандидаты, при этом итоговый результат по-прежнему содержит не более `top_num` значений. В этом режиме может потребоваться больше памяти, а ограничения на использование памяти запросом продолжают действовать. |

## Возвращаемое значение {#return-value}

Возвращает массив, содержащий N наиболее часто встречающихся значений.
Если в группе нет допустимых данных, возвращает NULL.

## Пример {#example}
```sql
-- setup
CREATE TABLE page_visits (
    page_id INT,
    user_id INT,
    visit_date DATE
) DISTRIBUTED BY HASH(page_id)
PROPERTIES (
    "replication_num" = "1"
);
INSERT INTO page_visits VALUES
(1, 101, '2024-01-01'),
(2, 102, '2024-01-01'),
(1, 103, '2024-01-01'),
(3, 101, '2024-01-01'),
(1, 104, '2024-01-01'),
(2, 105, '2024-01-01'),
(1, 106, '2024-01-01'),
(4, 107, '2024-01-01');
```

```sql
SELECT TOPN_ARRAY(page_id, 3) as top_pages
FROM page_visits;
```

Найти 3 наиболее посещаемые страницы.

```text
+-----------+
| top_pages |
+-----------+
| [1, 2, 4] |
+-----------+
```

```sql
SELECT TOPN_ARRAY(page_id, 3) as top_pages FROM page_visits where page_id is null;
```

```text
+-----------+
| top_pages |
+-----------+
| NULL      |
+-----------+
```

Входные данные типа BOOLEAN (в серии Doris 4.1 начиная с версии 4.1.5):

```sql
SELECT TOPN_ARRAY(TRUE, 2), TOPN_ARRAY(CAST(NULL AS BOOLEAN), 2);
```

```text
[1]    NULL
```
