## Описание {#description}

Табличная функция, создающая временную таблицу с единственным столбцом с именем `number`. Все значения в столбце равны `const_value`, если задан параметр `const_value`; в противном случае они последовательно возрастают в диапазоне [0,`number`).

## Синтаксис {#syntax}
```sql
NUMBERS(
    "number" = "<number>"
    [, "const_value" = "<const_value>" ]
  );
```

## Обязательные параметры {#required-parameters}

| Поле          | Описание                  |
|---------------|---------------------------|
| **number**    | Количество строк          |

## Необязательные параметры {#optional-parameters}

| Поле              | Описание                                 |
|-------------------|------------------------------------------|
| **const_value**   | Задаёт генерируемое константное значение  |



## Возвращаемое значение {#return-value}
| Поле       | Тип     | Описание                        |
|----------------|---------|---------------------------------|
| **number**     | BIGINT  | Значение, возвращаемое для каждой строки |


## Примеры {#examples}
```sql
select * from numbers("number" = "5");
```
```text
+--------+
| number |
+--------+
|      0 |
|      1 |
|      2 |
|      3 |
|      4 |
+--------+
```

```sql
select * from numbers("number" = "5", "const_value" = "-123");
```
```text
+--------+
| number |
+--------+
|   -123 |
|   -123 |
|   -123 |
|   -123 |
|   -123 |
+--------+
```
