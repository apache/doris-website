## Описание {#description}

Табличная функция создаёт временную таблицу разделов, которая позволяет просматривать список разделов указанной таблицы.

## Синтаксис {#syntax}

```sql
PARTITIONS(
    "catalog"="<catalog>",
    "database"="<database>",
    "table"="<table>"
)
```

## Обязательные параметры {#required-parameters}
| Поле             | Описание                                         |
|------------------|--------------------------------------------------|
| **`<catalog>`**  | Укажите имя каталога кластера, для которого выполняется запрос. |
| **`<database>`** | Укажите имя базы данных кластера, для которой выполняется запрос. |
| **`<table>`**    | Укажите имя таблицы кластера, для которой выполняется запрос. |


## Возвращаемое значение {#return-value}
| Поле                      | Описание                                                                    |
|---------------------------|-----------------------------------------------------------------------------|
| PartitionId               | ID раздела                                                                  |
| PartitionName             | Имя раздела                                                                 |
| VisibleVersion            | Версия раздела                                                              |
| VisibleVersionTime        | Время фиксации версии раздела                                                |
| State                     | Состояние раздела                                                           |
| PartitionKey              | Ключ раздела                                                                |
| Range                     | Диапазон раздела                                                            |
| DistributionKey           | Ключ распределения при разбиении на разделы                                  |
| Buckets                   | Количество бакетов в разделе                                                 |
| ReplicationNum            | Количество реплик в разделе                                                  |
| StorageMedium             | Носитель данных, используемый для раздела                                    |
| CooldownTime              | Время охлаждения раздела                                                     |
| RemoteStoragePolicy       | Политика удалённого хранения для раздела                                     |
| LastConsistencyCheckTime  | Время последней проверки согласованности раздела                             |
| DataSize                  | Размер данных в разделе                                                     |
| IsInMemory                | Хранится ли раздел в памяти                                                  |
| ReplicaAllocation         | Стратегия репликации раздела                                                 |
| IsMutable                 | Можно ли изменять раздел                                                     |
| SyncWithBaseTables        | Синхронизирован ли раздел с базовой таблицей (для асинхронных материализованных представлений) |
| UnsyncTables              | Какая базовая таблица не синхронизирована (для разделов асинхронных материализованных представлений) |
