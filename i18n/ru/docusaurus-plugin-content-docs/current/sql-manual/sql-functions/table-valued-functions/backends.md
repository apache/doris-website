## Описание {#description}

Табличная функция создаёт временную таблицу backends, в которой можно просмотреть информацию об узлах BE в текущем кластере Doris.

## Синтаксис {#syntax}
```sql
BACKENDS()
```

## Требования к правам доступа {#access-control-requirements}

| Привилегия | Объект | Примечания |
| :--------- |:-------|:------|
| SELECT_PRIV | internal.information_schema | По умолчанию все пользователи имеют права доступа к этой базе данных |

## Возвращаемое значение {#return-value}
| Поле                        | Описание |
|-----------------------------|------------------------------------------------------------------------------------------------------------------------|
| **BackendId**               | Уникальный идентификатор каждого узла BE. |
| **Host**                    | IP-адрес или имя хоста узла BE. |
| **HeartbeatPort**           | Порт для проверки работоспособности (heartbeat). |
| **BePort**                  | Порт для связи узла BE с кластером при выполнении запросов. |
| **HttpPort**                | HTTP-порт узла BE. |
| **BrpcPort**                | Порт для обмена данными по BRPC. |
| **ArrowFlightSqlPort**      | Порт Arrow Flight SQL (используется для интеграции с Apache Arrow для высокопроизводительной передачи данных). |
| **LastStartTime**           | Временная метка последнего запуска узла BE. |
| **LastHeartbeat**           | Временная метка последнего heartbeat, полученного от узла BE. |
| **Alive**                   | Работает ли узел BE (true/false). |
| **SystemDecommissioned**    | Выведен ли узел BE из эксплуатации. |
| **TabletNum**               | Количество tablets под управлением узла BE. |
| **DataUsedCapacity**        | Объём дискового пространства, используемого узлом BE (в MB). |
| **TrashUsedCapacity**       | Объём дискового пространства, занятого корзиной (в MB). |
| **AvailCapacity**           | Доступное дисковое пространство на узле BE. |
| **TotalCapacity**           | Общая ёмкость дисков узла BE. |
| **UsedPct**                 | Процент дискового пространства, используемого узлом BE. |
| **MaxDiskUsedPct**          | Максимальный процент использования диска среди всех tablets. |
| **RemoteUsedCapacity**      | Дисковое пространство, используемое удалённым хранилищем (если применимо). |
| **Tag**                     | Теги узла BE, обычно используемые для классификации (например, по расположению). |
| **ErrMsg**                  | Сообщения об ошибках, переданные узлом BE. |
| **Version**                 | Версия узла BE. |
| **Status**                  | Текущее состояние узла BE, включая отчёты об успешных и неудачных операциях с tablets, время загрузки и состояния запросов. |
| **HeartbeatFailureCounter** | Количество сбоев heartbeat, если они были. |
| **NodeRole**                | Роль узла BE, например `mix`: в этом случае узел отвечает и за хранение данных, и за обработку запросов. |
| **CpuCores**                | Количество ядер CPU на узле BE. |
| **Memory**                  | Объём памяти на узле BE. |
