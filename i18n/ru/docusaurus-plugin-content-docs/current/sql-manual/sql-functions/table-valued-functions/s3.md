# S3 {#s3}

## Описание {#description}

Табличная функция S3 (TVF) позволяет читать файлы из объектного хранилища, совместимого с S3, и обращаться к ним как к данным реляционной таблицы. В настоящее время поддерживаются форматы файлов `csv/csv_with_names/csv_with_names_and_types/json/parquet/orc`.

## Синтаксис {#syntax}

```sql
S3(
    "uri" = "<uri>",
    "s3.access_key" = "<s3_access_key>",
    "s3.secret_key" = "<s3_secret_key>",
    "s3.region" = "<s3_region>",
    "s3.endpoint" = "<s3_endpoint>",
    "format" = "<format>"
    [, "<optional_property_key>" = "<optional_property_value>" [, ...] ]
  )
```

## Обязательные параметры {#required-parameters}

| Параметр       | Описание                                                                                                                           |
|-----------------|---------------------------------------------------------------------------------------------------------------------------------------|
| `uri`           | URI для доступа к S3. Поддерживает подстановочные знаки и шаблоны диапазонов. Подробнее см. в разделе [Шаблон пути к файлу](../../basic-element/file-path-pattern). Функция использует Path Style или Virtual-hosted Style в зависимости от параметра `use_path_style`        |
| `s3.access_key` | Ключ доступа к S3                                                                                                                     |
| `s3.secret_key` | Секретный ключ для S3                                                                                                                     |
| `s3.region`     | Регион S3                                                                                                                             |
| `s3.endpoint`   | Адрес конечной точки S3                                                                                                                   |
| `format`        | Формат файла; поддерживаются `csv/csv_with_names/csv_with_names_and_types/json/parquet/orc`                                                 |

## Примечания {#notes}

1. Для AWS S3 стандартные стили URI включают:

   - Стиль клиента AWS (стиль Hadoop S3)
   
      ```
      s3://my-bucket/path/to/file?versionId=abc123&partNumber=77&partNumber=88
      ```

   - Стиль Virtual Host
   
      ```
      https://my-bucket.s3.us-west-1.amazonaws.com/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   - Стиль Path
   
      ```
      https://s3.us-west-1.amazonaws.com/my-bucket/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   Помимо этих трёх стандартных стилей URI, поддерживаются и другие, менее распространённые:

   - Смешанный стиль Virtual Host и клиента AWS (Hadoop S3)
      
      ```
      s3://my-bucket.s3.us-west-1.amazonaws.com/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   - Смешанный стиль Path и клиента AWS (Hadoop S3)

      ```
      s3://s3.us-west-1.amazonaws.com/my-bucket/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   Подробные примеры использования приведены ниже.

2. Для прямого выполнения запросов к TVF или создания представления на основе этой TVF требуется право USAGE на Resource. Для запроса к представлению, созданному на основе TVF, достаточно права SELECT на это представление.

- **Формат CSV**

  Поскольку табличная функция S3 заранее не знает схему таблицы, она читает файл один раз, чтобы определить эту схему.

  Формат `csv`: табличная функция S3 читает файлы из S3 и обрабатывает их как файлы CSV, определяя схему таблицы по первой строке. Количество столбцов `n` в первой строке используется как количество столбцов в схеме таблицы; столбцам автоматически присваиваются имена `c1, c2, ..., cn`, а для всех столбцов задаётся тип `String`. Пример:

  Содержимое файла `student1.csv`:

  ```
  1,ftw,12
  2,zs,18
  3,ww,20
  ```

  Использование S3 TVF:

    ```sql
    select * from s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                     "s3.access_key"= "minioadmin",
                     "s3.secret_key" = "minioadmin",
                     "s3.endpoint" = "http://127.0.0.1:9312",
                     "s3.region" = "us-east-1",
                     "format" = "csv",
                     "use_path_style" = "true") order by c1;

    +------+------+------+
    | c1   | c2   | c3   |
    +------+------+------+
    | 1    | ftw  | 12   |
    | 2    | zs   | 18   |
    | 3    | ww   | 20   |
    +------+------+------+
    ```

  Для просмотра схемы таблицы можно использовать `desc function S3()`:

    ```sql
    Desc function s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                     "s3.access_key"= "minioadmin",
                     "s3.secret_key" = "minioadmin",
                     "s3.endpoint" = "http://127.0.0.1:9312",
                     "s3.region" = "us-east-1",
                     "format" = "csv",
                     "use_path_style" = "true");

    +-------+------+------+-------+---------+-------+
    | Field | Type | Null | Key   | Default | Extra |
    +-------+------+------+-------+---------+-------+
    | c1    | TEXT | Yes  | false | NULL    | NONE  |
    | c2    | TEXT | Yes  | false | NULL    | NONE  |
    | c3    | TEXT | Yes  | false | NULL    | NONE  |
    +-------+------+------+-------+---------+-------+
    ```

  Содержимое файла `student_with_names.csv`:

  ```
  id,name,age
  1,ftw,12
  2,zs,18
  3,ww,20
  ```

  Использование S3 TVF:

  ```sql
  select * from s3("uri" = "http://127.0.0.1:9312/test2/student_with_names.csv",

                    "s3.secret_key" = "minioadmin",
                    "s3.endpoint" = "http://127.0.0.1:9312",
  ```

- **Формат JSON**

  Формат `json`: для формата JSON предусмотрено множество необязательных параметров. О назначении каждого параметра см. в разделе [Загрузка JSON](../../../data-operate/import/file-format/json). При запросе файлов формата JSON с помощью S3 TVF функция находит объект JSON на основе параметров `json_root` и `jsonpaths`, использует `key` объекта как имена столбцов в схеме таблицы и задаёт всем столбцам тип String. Пример:

  Содержимое файла `data.json`:

  ```
  [{"id":1, "name":"ftw", "age":18}]
  [{"id":2, "name":"xxx", "age":17}]
  [{"id":3, "name":"yyy", "age":19}]
  ```

  Выполнение запроса с помощью S3 TVF:

  ```sql
  select * from s3(
      "uri" = "http://127.0.0.1:9312/test2/data.json",
      "s3.access_key"= "minioadmin",
      "s3.secret_key" = "minioadmin",
      "s3.endpoint" = "http://127.0.0.1:9312",
      "s3.region" = "us-east-1",
      "format" = "json",
      "strip_outer_array" = "true",
      "read_json_by_line" = "true",
      "use_path_style"="true");
  +------+------+------+
  | id   | name | age  |
  +------+------+------+
  | 1    | ftw  | 18   |
  | 2    | xxx  | 17   |
  | 3    | yyy  | 19   |
  +------+------+------+
  
  select * from s3(
      "uri" = "http://127.0.0.1:9312/test2/data.json",
      "s3.access_key"= "minioadmin",
      "s3.secret_key" = "minioadmin",
      "s3.endpoint" = "http://127.0.0.1:9312",
      "s3.region" = "us-east-1",
      "format" = "json",
      "strip_outer_array" = "true",
      "jsonpaths" = "[\"$.id\", \"$.age\"]",
      "use_path_style"="true");
  ```

- **URI с подстановочными знаками**

  URI может содержать подстановочные знаки и шаблоны диапазонов для чтения нескольких файлов. Подробный синтаксис, включая `*`, `?`, `[...]` и раскрытие диапазонов `{1..10}`, описан в разделе [Шаблон пути к файлу](../../basic-element/file-path-pattern). Примечание: при использовании подстановочных знаков убедитесь, что все файлы имеют одинаковый формат (в частности, `csv`, `csv_with_names`, `csv_with_names_and_types` считаются разными форматами). S3 TVF использует первый файл для определения схемы таблицы.
  
  Для следующих двух файлов CSV:

  ```
  // file1.csv
  1,aaa,18
  2,qqq,20
  3,qwe,19
  
  // file2.csv
  5,cyx,19
  6,ftw,21
  ```

  Можно выполнить запрос с подстановочными знаками в URI:

  ```sql
  select * from s3(
          "uri" = "http://127.0.0.1:9312/test2/file*.csv",
          "s3.access_key"= "minioadmin",
          "s3.secret_key" = "minioadmin",
          "s3.endpoint" = "http://127.0.0.1:9312",
          "s3.region" = "us-east-1",
          "format" = "csv",
          "use_path_style"="true");

  +------+------+------+
  | c1   | c2   | c3   |
  +------+------+------+
  | 1    | aaa  | 18   |
  | 2    | qqq  | 20   |
  | 3    | qwe  | 19   |
  | 5    | cyx  | 19   |
  | 6    | ftw  | 21   |
  +------+------+------+
  ```

- **Использование S3 TVF с `insert into` и `cast`**

  ```sql
  -- Create Doris internal table
  CREATE TABLE IF NOT EXISTS ${testTable}
      (
          id int,
          name varchar(50),
          age int
      )
      COMMENT "my first table"
      DISTRIBUTED BY HASH(id) BUCKETS 32
      PROPERTIES("replication_num" = "1");
  
  -- Insert data using S3
  insert into ${testTable} (id,name,age)
  select cast (id as INT) as id, name, cast (age as INT) as age
  from s3(
      "uri" = "${uri}",
      "s3.access_key"= "${ak}",
      "s3.secret_key" = "${sk}",
      "s3.endpoint" = "http://127.0.0.1:9312",
      "s3.region" = "us-east-1",
      "format" = "${format}",
      "strip_outer_array" = "true",
      "read_json_by_line" = "true",
      "use_path_style" = "true");
  ```
