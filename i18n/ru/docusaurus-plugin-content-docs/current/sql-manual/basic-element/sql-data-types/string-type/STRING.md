## STRING {#string}
### Описание {#description}
Строка переменной длины с мягким ограничением длины по умолчанию 10485760 байт (10 MiB). Чтобы увеличить этот предел до 2147483643 байт (приблизительно 2 GiB), настройте параметр `string_type_length_soft_limit_bytes` на BE. Тип STRING можно использовать только в столбцах значений, но не в ключевых столбцах, столбцах секционирования или бакетизации.

Примечание: строки переменной длины хранятся в кодировке UTF-8, поэтому английские символы обычно занимают 1 байт, а китайские — 3 байта.

### Ключевые слова {#keywords}
STRING

### Псевдонимы типа и отображение метаданных {#type-aliases-and-metadata-display}

`STRING` и `TEXT` обозначают один и тот же тип Doris. Разные интерфейсы отображают этот тип по-разному:

| Интерфейс | Отображение столбца типа `STRING` |
| --- | --- |
| `SHOW CREATE TABLE` и `DESC` | `text` |
| `information_schema.columns.DATA_TYPE` | `varchar`, для совместимости с MySQL |
| `information_schema.columns.COLUMN_TYPE` | `string` |

Эти названия не меняют хранимый тип или ограничение его длины. Чтобы отличить в метаданных столбец Doris типа `STRING` от столбца типа `VARCHAR` с ограничением длины, проверьте `COLUMN_TYPE`.
