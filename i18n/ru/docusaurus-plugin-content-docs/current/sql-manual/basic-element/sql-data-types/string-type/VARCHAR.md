## VARCHAR {#varchar}
### Описание {#description}
VARCHAR(M)
Строка переменной длины. M обозначает длину строки переменной длины в байтах. Диапазон значений M: 1-65533.

Примечание: строки переменной длины хранятся в кодировке UTF-8, поэтому символы английского алфавита обычно занимают 1 байт, а китайские иероглифы занимают 3 байта.

### Ключевые слова {#keywords}
