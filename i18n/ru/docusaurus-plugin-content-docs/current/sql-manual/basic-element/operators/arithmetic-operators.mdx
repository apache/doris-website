## Описание {#description}

Арифметические операторы с одним или двумя параметрами позволяют выполнять смену знака, сложение, вычитание, умножение и деление чисел. Некоторые из этих операторов также используются для арифметических операций с интервалами дат и времени. Параметры операторов должны иметь числовые типы данных либо любой тип данных, который можно неявно преобразовать в числовой.

Унарные арифметические операторы возвращают значение того же типа данных, что и числовой параметр. Для бинарных арифметических операторов Doris преобразует параметры в подходящий для вычислений тип в соответствии с правилами неявного преобразования типов и возвращает результат соответствующего типа. Подробные правила преобразования приведены в разделе «Преобразование типов».

## Примечания по использованию {#usage-notes}

В арифметических выражениях:
1. Не используйте два знака минус подряд `--` для обозначения двойного отрицания (это символ комментария в SQL)
2. При необходимости разделяйте их пробелами или скобками: `-(-5)` или `- -5`
3. Подробнее о правилах оформления комментариев см. в разделе «Комментарии»
