## Описание {#description}

Приоритет операторов определяет порядок их вычисления в выражении. Если выражение содержит несколько операторов, Doris выполняет вычисления в порядке убывания приоритета операторов.

## Приоритет операторов {#operator-precedence}

Приоритет убывает сверху вниз: операторы с наивысшим приоритетом находятся вверху.

| Приоритет | Оператор |
|------------|----------|
| 1          | !        |
| 2          | + (унарный плюс), - (унарный минус), ~ (унарный побитовый NOT), ^ |
| 3          | *, /, %, DIV |
| 4          | -, +     |
| 5          | &        |
| 6          | \|       |
| 7          | =(сравнение), <=>, >=, >, <=, <, <>, !=, IS, LIKE, REGEXP, MATCH, IN |
| 8          | NOT      |
| 9          | AND, &&  |
| 10         | XOR      |
| 11         | OR       |
| 12         | \|\|     |
