## Описание {#description}

Побитовые операторы выполняют заданные операции над одним или двумя выражениями на уровне битов. Эти операторы принимают только аргументы типа `BIGINT`. Поэтому все выражения, обрабатываемые побитовыми операторами, преобразуются к типу `BIGINT`.  

## Обзор операторов {#operator-overview}

| Оператор | Действие                                                                                     | Пример          |  
|----------|----------------------------------------------------------------------------------------------|-----------------|  
| `&`      | Выполняет побитовую операцию AND. Если оба соответствующих бита равны `1`, результирующий бит равен `1`; иначе он равен `0`. | `SELECT 1 & 2` |  
| `\|`     | Выполняет побитовую операцию OR. Если хотя бы один из соответствующих битов равен `1`, результирующий бит равен `1`; иначе он равен `0`.  | `SELECT 1 &#124; 2` |  
| `^`      | Выполняет побитовую операцию XOR. Если соответствующие биты различаются, результирующий бит равен `1`; иначе он равен `0`.   | `SELECT 1 ^ 2` |  
| `~`      | Выполняет побитовую операцию NOT. Инвертирует каждый бит: `1` становится `0`, а `0` становится `1`.                          | `SELECT ~1`    |
