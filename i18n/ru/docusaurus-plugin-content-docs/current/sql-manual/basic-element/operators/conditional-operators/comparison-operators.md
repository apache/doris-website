## Описание {#description}

Условия сравнения сравнивают одно выражение с другим. Результатом сравнения может быть TRUE, FALSE или UNKNOWN.

## Обзор операторов {#operator-introduction}

| Оператор | Действие | Пример |
| ------------------- | ----------------------------------------------------------- | ------------------- |
| `=` | Сравнение на равенство. Если хотя бы одна из сторон сравнения имеет значение UNKNOWN, результат — UNKNOWN. | `SELECT 1 = 1` |
| `<=>` | Сравнение на равенство с учётом NULL. В отличие от обычного сравнения на равенство, рассматривает NULL как значение, которое можно сравнивать. Возвращает TRUE, если обе стороны равны NULL. Возвращает FALSE, если только одна сторона равна NULL. Этот оператор никогда не возвращает UNKNOWN. | `SELECT NULL <=> NULL` |
| `!=` `<>` | Сравнение на неравенство | `SELECT 1 != 1` |
| `<` `>` | Сравнение «больше» и «меньше» | `SELECT 1 > 1` |
| `<=` `>=` | Сравнение «больше или равно» и «меньше или равно» | `SELECT 1 >= 1` |
| `<x> BETWEEN <y> AND <z>` | Эквивалентно `<x> >= <y> and <x> <= <z>`. Больше или равно `<y>` и меньше или равно `<z>` | `SELECT 1 BETWEEN 0 AND 2` |
