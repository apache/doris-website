Дедупликация относится к наиболее ресурсоёмким операциям в аналитических нагрузках. Apache Doris предоставляет два специализированных типа данных в качестве альтернативы `COUNT DISTINCT`, позволяющих выполнять дедупликацию с меньшим потреблением памяти и меньшей задержкой: выбирайте **BITMAP**, когда нужны точные результаты, и **HLL**, если допустима погрешность 1%–2% в обмен на меньший объём хранимых данных.
