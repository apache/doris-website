Настройка выполнения запросов помогает устранить узкие места производительности, проявляющиеся во время выполнения: неподходящий уровень параллелизма, слишком позднее срабатывание RuntimeFilters, перекос данных при Shuffle, а также ситуации, когда выбор оптимизатора требует ручного вмешательства. Сначала найдите признаки проблемы в Profile, затем выберите соответствующий способ настройки.
