Материализованное представление представляет собой объект, содержащий логику вычислений и данные. Его можно использовать для ускорения запросов, облегчённого ETL-моделирования и ускорения федеративных запросов к lakehouse. Сначала ознакомьтесь с основными понятиями, а затем выберите синхронные или асинхронные материализованные представления в зависимости от требований к актуальности данных.

Ознакомьтесь с документацией по [материализованным представлениям](./intro).
