Материализованное представление — это объект, содержащий как логику вычислений, так и данные. Его можно использовать для ускорения запросов, упрощённого ETL-моделирования и ускорения федеративных запросов в lakehouse. Сначала изучите основные понятия, затем выберите синхронные или асинхронные материализованные представления в зависимости от требований к актуальности данных.
