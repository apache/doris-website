Apache Doris обеспечивает высокую производительность без дополнительной настройки в большинстве сценариев запросов с Join. Однако при строгих требованиях к производительности можно дополнительно оптимизировать запросы, организовав совместное размещение таблиц и направляя работу оптимизатора с помощью подсказок. Рекомендуется сначала использовать Colocation Join, чтобы исключить сетевое перераспределение данных при соединениях по равенству между бакетированными таблицами, а затем, если оптимизатор делает неоптимальный выбор, настроить способ перераспределения данных и порядок Join с помощью Distribute Hint и Leading Hint.
