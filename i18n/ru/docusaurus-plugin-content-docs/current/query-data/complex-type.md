В таких сценариях, как работа с журналами, отслеживание событий, хранение профилей пользователей и сведений о заказах, бизнес-данные редко имеют плоскую реляционную структуру. Обычно такие данные вложенные или полуструктурированные. Apache Doris поддерживает сложные типы, такие как Array, Map, Struct и JSON, что позволяет хранить такие данные в исходной структуре, выполнять к ним запросы и обрабатывать их с помощью специализированных функций.

## Сценарии использования {#applicable-scenarios}

Сложные типы подходят для следующих сценариев запросов:

- Поля в виде списков, например теги, категории или многозначные атрибуты товаров, которые нужно представлять с помощью **Array**.
- Поля в виде словарей, например конфигурации или пары ключей и значений атрибутов, которые нужно представлять с помощью **Map**.
- Структурированные записи, например вложенные объекты или составные поля, которые нужно представлять с помощью **Struct**.
- Полуструктурированные данные **JSON** из систем-источников без фиксированной схемы.
