# Запросы к данным {#data-querying}

Apache Doris поддерживает стандартный SQL с высокой степенью совместимости с MySQL, а также предоставляет высокопроизводительные запросы с соединениями, богатый набор аналитических функций, доступ к полуструктурированным данным и пользовательские функции. Выберите ниже документацию для своего сценария.
