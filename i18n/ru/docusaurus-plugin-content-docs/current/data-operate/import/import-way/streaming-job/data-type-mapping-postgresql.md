:::caution Экспериментальная функция

Непрерывная загрузка в Doris является экспериментальной функцией и поддерживается начиная с Doris 4.1.5.

:::

<!-- Knowledge type: Reference / data type mapping -->

В таблице ниже показано, как каждый тип столбца PostgreSQL сопоставляется с типом столбца Doris. Используется одно сопоставление, общее для обоих методов синхронизации; различается только то, кто создает целевую таблицу:

- **Синхронизация с автоматическим созданием таблицы**: Doris считывает схему исходной системы и автоматически создает целевую таблицу с этими типами столбцов Doris.
- **Синхронизация с сопоставлением SQL**: вы самостоятельно создаете целевую таблицу, используя совместимый тип Doris для каждого столбца.

В обоих случаях значения записываются в соответствии с одним и тем же сопоставлением. Информацию о неподдерживаемых типах см. в разделе [Ограничения](./continuous-load-overview.md#limitations).

## PostgreSQL в Doris {#postgresql-to-doris}

| Тип PostgreSQL | Тип Doris | Примечания |
| --- | --- | --- |
| `bool` | `BOOLEAN` | |
| `bit(1)` | `BOOLEAN` | |
| `bit(n>1)` / `varbit` | `STRING` | |
| `int2` / `smallserial` | `SMALLINT` | |
| `int4` / `serial` | `INT` | |
| `int8` / `bigserial` | `BIGINT` | |
| `float4` | `FLOAT` | |
| `float8` | `DOUBLE` | |
| `numeric(p,s)` | `DECIMAL(min(p,38), s)` | Точность ограничена значением 38; если scale не указан, по умолчанию используется 9 |
| `bpchar(n)` (то есть `CHAR(n)`) | `CHAR` / `VARCHAR` | Длина умножается на 3 для UTF-8; при значении `> 255` используется `VARCHAR` |
| `varchar` / `text` | `STRING` | PostgreSQL `varchar` сопоставляется с `STRING` (без длины) |
| `date` | `DATE` | |
| `timestamp` / `timestamptz` | `DATETIME(s)` | Значение scale — от 0 до 6; `timestamptz` нормализуется к часовому поясу сервера |
| `time` / `timetz` / `interval` | `STRING` | `timetz` сохраняет смещение, нормализованное по UTC |
| `uuid` / `inet` / `cidr` / `macaddr` / `macaddr8` | `STRING` | |
| `bytea` | `STRING` | Строка в кодировке Base64 |
| `xml` / `hstore` | `STRING` | |
| `json` / `jsonb` | `JSON` | |
| Геометрические типы (`point`, `line`, `polygon`, …) | `STRING` | Сериализуются в строку GeoJSON (`type` / `coordinates` / `srid`) |
| Типы массивов (например, `int4[]`, `text[]`) | `ARRAY<T>` | Поддерживаются только одномерные массивы |
| Другие / пользовательские типы | `STRING` | |
