Doris использует **Streaming Job + S3 TVF** для пакетной загрузки файлов из S3 в существующую таблицу Doris. Выберите упорядоченную загрузку, загрузку по уведомлениям или однократную загрузку в зависимости от того, как поступают файлы и должно ли задание продолжать работу.

## Выбор режима загрузки {#choose-an-ingestion-mode}

| Руководство | Режим | Когда использовать | Завершение |
| --- | --- | --- | --- |
| [Упорядоченная загрузка](./continuous-load-s3-ordered.md) | `ORDERED_LIST` (по умолчанию) | Ключи возрастают в лексикографическом порядке, например временные метки или значения счётчиков с ведущими нулями | Работает непрерывно и ожидает новые файлы |
| [Загрузка по уведомлениям](./continuous-load-s3-notification.md) | `NOTIFICATION` | Используются ключи UUID или файлы поступают в произвольном порядке; файлы обнаруживаются с помощью событий AWS S3 и выделенной очереди SQS | Работает непрерывно и ожидает сообщения |
| [Однократная загрузка](./continuous-load-s3-one-time.md) | `ONE_TIME` | Подготовленный статический набор файлов или отдельная загрузка исторических данных | Переходит в состояние `FINISHED` после фиксации последнего пакета |

Загрузка по уведомлениям не загружает ранее созданные объекты, а повторные уведомления могут приводить к повторной загрузке данных. Во всех режимах исходные объекты должны оставаться доступными для чтения и неизменными во время загрузки. Каждое из приведённых выше руководств содержит инструкции по настройке, примеры SQL, параметры и ограничения.
