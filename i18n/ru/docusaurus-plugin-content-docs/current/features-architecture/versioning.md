## Что такое номер версии? {#what-is-a-version-number}

Apache Doris использует номер версии из трёх частей (X.Y.Z), где каждая цифра соответствует определённому типу выпуска:

| Позиция в номере версии | Название | Описание |
|------------------|------|-------------|
| X | Мажорная версия | Крупные обновления функциональности или архитектуры с циклом выпуска около 1 года |
| Y | Минорная версия | Важные новые функции и улучшения производительности с циклом выпуска примерно раз в квартал |
| Z | Патч-версия | Исправления ошибок и улучшения производительности с циклом выпуска в 2-4 недели |

**Пример**: Версия `2.1.0` означает мажорную версию 2, минорную версию 1 и патч-версию 0.

## Что нужно знать перед обновлением {#what-you-must-know-before-upgrading}

### Различия в совместимости при изменении разных частей номера версии {#compatibility-differences-across-version-positions}

| Тип версии | Изменения метаданных / формата данных | Примечания о совместимости |
|--------------|--------------------------------|---------------------|
| Мажорная версия (X) | Возможны | Прямая совместимость обеспечивается, но обратная совместимость не гарантируется |
| Минорная версия (Y) | Без изменений | Прямая и обратная совместимость гарантируются при условии, что новые функции не используются |
| Патч-версия (Z) | Без изменений | Полная прямая и обратная совместимость, можно свободно обновляться или возвращаться к предыдущим версиям |

:::warning Важно
При обновлении до новой мажорной версии **возможность возврата к предыдущей версии не гарантируется**. Перед обновлением создайте резервную копию данных.
:::

### Контрольный список перед обновлением {#pre-upgrade-checklist}

-  Определите, к какому типу относится целевая версия: мажорная, минорная или патч-версия
-  Создайте резервные копии важных данных и метаданных
-  Проверьте процедуру обновления в тестовой среде
-  Изучите примечания о совместимости версий, если они есть

## Как выбрать версию {#how-to-choose-a-version}

Apache Doris поддерживает две актуальные ветки версий:

| Тип версии | Сценарии использования | Описание |
|--------------|-----------|-------------|
| **Latest** | POC, тестирование производительности, знакомство с новыми функциями | Содержит новейшие функции, может работать нестабильно |
| **Stable** | Промышленные среды | Продолжает получать исправления ошибок, отличается высокой стабильностью |

**Рекомендации по выбору**:
- Для промышленных сред выбирайте **Stable**
- Для изучения возможностей и тестирования выбирайте **Latest**

## Модель CPU и выбор бинарной сборки {#cpu-model-and-binary-selection}

Doris предоставляет три варианта бинарных сборок для разных наборов инструкций CPU:

| Вариант | Подходящие CPU | Описание |
|---------|----------------|-------------|
| x64 (avx2) | CPU x86_64 с поддержкой набора инструкций avx2 | Наилучшая производительность |
| x64 (no avx2) | CPU x86_64 без поддержки avx2 | Приоритет совместимости |
| ARM64 | CPU с архитектурой ARM | Apple M-series, Kunpeng и другие |

### Как определить, поддерживает ли ваш CPU avx2 {#how-to-determine-whether-your-cpu-supports-avx2}

```bash
cat /proc/cpuinfo | grep avx2
```

Если команда выводит результат, CPU поддерживает набор инструкций avx2. В этом случае можно выбрать сборку x64 (avx2) для более высокой производительности.

## Часто задаваемые вопросы {#frequently-asked-questions}

### Вопрос: Можно ли обновиться с 2.0 до 3.1? {#q-can-i-upgrade-from-20-to-31}

Да. Однако обновление до новой мажорной версии может сопровождаться изменениями формата данных. Перед обновлением:

1. Создайте резервную копию данных
2. Проверьте обновление в тестовой среде
3. Подготовьте план отката

### Вопрос: Можно ли устанавливать патч-версии в любое время? {#q-can-patch-versions-be-upgraded-at-any-time}

Да. Для патч-версий (например, при переходе с 2.1.0 на 2.1.1) гарантируются прямая и обратная совместимость, поэтому обновляться или возвращаться к предыдущей версии можно в любое время.

### Вопрос: Как проверить текущую версию Doris? {#q-how-do-i-check-the-current-doris-version}

Выполните запрос `SELECT VERSION();`, чтобы узнать текущую версию.

### Вопрос: Где можно скачать версии Latest и Stable? {#q-where-can-i-download-the-latest-and-stable-versions}

Ссылки для скачивания всех версий доступны на [странице загрузки Apache Doris](https://doris.apache.org/download).
