## Описание {#description}

- `client_ip`: Если используется прокси-сервис и передача исходного IP-адреса не включена, здесь может быть записан IP-адрес прокси-сервиса вместо реального IP-адреса клиента.
- `state`: `EOF` означает, что запрос выполнен успешно. `OK` означает, что операторы DDL и DML выполнены успешно. `ERR` означает, что выполнение оператора завершилось ошибкой.
- `scan_bytes`: Указывает объём данных, обрабатываемых BE. Это объём считанных с диска данных в несжатом виде, включая данные, считанные из внутреннего кэша страниц Doris. Он отражает фактический объём данных, который требуется обработать запросу. Это значение не равно `scan_bytes_from_local_storage` + `scan_bytes_from_remote_storage`.
- `scan_rows`: Указывает количество строк, просканированных при выполнении запроса. Поскольку Doris является базой данных с колоночным хранением, сначала сканируются столбцы с предикатами фильтрации, а затем на основе результатов фильтрации сканируются остальные столбцы. Поэтому количество просканированных строк у разных столбцов различается. Для столбцов с предикатами сканируется больше строк, чем для столбцов без предикатов, и это значение отражает количество строк, просканированных в столбцах с предикатами при выполнении запроса.
- `scan_bytes_from_local_storage`: Указывает объём данных, считанных с локального диска, до сжатия. Данные, считанные из кэша страниц Doris, не учитываются, а данные из кэша страниц операционной системы включаются в эту статистику.
- `scan_bytes_from_remote_storage`: Указывает объём данных, считанных из удалённого хранилища, до сжатия.
