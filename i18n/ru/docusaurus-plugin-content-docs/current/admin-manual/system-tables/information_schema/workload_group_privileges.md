## Обзор {#overview}

Хранит информацию о правах доступа к группам рабочей нагрузки.

## База данных {#database}


`information_schema`


## Информация о таблице {#table-information}

| Имя столбца         | Тип          | Описание                                 |
| ------------------- | ------------ | ---------------------------------------- |
| GRANTEE             | varchar(64)  | Пользователь, которому предоставлены права доступа |
| WORKLOAD_GROUP_NAME | varchar(256) | Имя группы рабочей нагрузки              |
| PRIVILEGE_TYPE      | varchar(64)  | Тип права доступа                        |
| IS_GRANTABLE        | varchar(3)   | Можно ли предоставлять это право другим пользователям |
