## Обзор {#overview}

Содержит смещение потребления, величину отставания и время последнего потребления каждого Table Stream для каждой партиции его базовой таблицы. Каждая строка соответствует одной единице потребления (партиции базовой таблицы) одного Stream. Подробнее об использовании см. в разделе [Расширенные возможности Table Stream](../../../data-operate/incremental/table-stream-advanced#partition-level-consumption-offsets).

## База данных {#database}

`information_schema`

## Информация о таблице {#table-information}

| Столбец | Тип | Описание |
| :--- | :--- | :--- |
| DB_NAME | varchar(64) | База данных, к которой относится Stream |
| STREAM_NAME | varchar(64) | Имя Stream |
| STREAM_ID | bigint | Идентификатор Stream |
| UNIT | varchar(64) | Единица потребления, то есть имя партиции базовой таблицы. Таблица без явно заданных партиций содержит единственную партицию с именем таблицы |
| CONSUMPTION_STATUS | varchar(64) | Метка времени фиксации (TSO), до которой были потреблены данные партиции; `N/A` означает, что данные партиции ещё ни разу не потреблялись |
| LAG | varchar(64) | Разность между последним зафиксированным TSO партиции и TSO, до которого были потреблены данные; `0` означает отсутствие отставания, `N/A` означает, что в партиции есть данные, но они ещё ни разу не потреблялись. Младшие 18 бит TSO представляют собой логический счётчик, поэтому значение `LAG`, делённое на 262144, приблизительно соответствует отставанию в миллисекундах |
| LAST_CONSUMPTION_TIME | bigint | Время последнего потребления данных партиции (метка времени в миллисекундах); `-1` означает, что данные ещё ни разу не потреблялись |

## Примеры {#examples}

```sql
SELECT UNIT, CONSUMPTION_STATUS, LAG, LAST_CONSUMPTION_TIME
FROM information_schema.table_stream_consumption
WHERE DB_NAME = 'demo' AND STREAM_NAME = 'orders_stream'
ORDER BY UNIT;
```

