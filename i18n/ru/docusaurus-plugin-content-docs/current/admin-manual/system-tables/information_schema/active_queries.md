## Обзор {#overview}

Используется для просмотра выполняющихся в данный момент запросов

## База данных {#database}


`information_schema`


## Информация о таблице {#table-information}

| Имя столбца       | Тип          | Описание                                                     |
| ----------------- | ------------ | ------------------------------------------------------------ |
| QUERY_ID          | varchar(256) | Идентификатор запроса                                        |
| QUERY_START_TIME  | varchar(256) | Время начала выполнения запроса                              |
| QUERY_TIME_MS     | bigint       | Время выполнения запроса                                     |
| WORKLOAD_GROUP_ID | bigint       | Идентификатор Workload Group, к которой относится запрос      |
| DATABASE          | varchar(256) | База данных, в которой выполнялся запрос                      |
| FRONTEND_INSTANCE | varchar(256) | IP-адрес экземпляра Frontend, получившего запрос на выполнение |
| QUEUE_START_TIME  | varchar(256) | Время начала ожидания в очереди; пусто, если запрос не находился в очереди |
| QUEUE_END_TIME    | varchar(256) | Время окончания ожидания в очереди; пусто, если запрос не находился в очереди |
| QUERY_STATUS      | varchar(256) | Состояние запроса                                            |
| SQL               | text         | Текст SQL-запроса                                            |
