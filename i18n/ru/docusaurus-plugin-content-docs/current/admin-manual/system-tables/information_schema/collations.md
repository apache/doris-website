## Обзор {#overview}

Просмотр всех правил сортировки для наборов символов. Эта таблица используется только для совместимости с поведением MySQL и не имеет практического значения. Она не отражает фактические правила сортировки символов, используемые в Doris.

## База данных {#database}


`information_schema`


## Информация о таблице {#table-information}

| Имя столбца        | Тип          | Описание                                                 |
| ------------------ | ------------ | -------------------------------------------------------- |
| COLLATION_NAME     | varchar(512) | Название правила сортировки набора символов              |
| CHARACTER_SET_NAME | varchar(64)  | Название связанного набора символов                      |
| ID                 | bigint       | Идентификатор правила сортировки                         |
| IS_DEFAULT         | varchar(64)  | Указывает, используется ли это правило сортировки по умолчанию. |
| IS_COMPILED        | varchar(64)  | Указывает, встроено ли правило сортировки в сервис        |
| SORTLEN            | bigint       | Связан с объёмом памяти, используемой этим алгоритмом сортировки |
