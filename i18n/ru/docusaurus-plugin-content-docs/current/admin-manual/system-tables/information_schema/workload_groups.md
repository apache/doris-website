## Обзор {#overview}

Содержит сведения о конфигурации групп рабочей нагрузки.

## База данных {#database}


`information_schema`


## Информация о таблице {#table-information}

| Имя столбца                    | Тип          | Описание                                                     |
| ------------------------------ | ------------ | ------------------------------------------------------------ |
| ID                             | bigint       | ID группы рабочей нагрузки                                   |
| NAME                           | varchar(256) | Имя группы рабочей нагрузки                                  |
| CPU_SHARE                      | bigint       | Вес группы рабочей нагрузки для мягкого ограничения CPU       |
| MEMORY_LIMIT                   | varchar(256) | Ограничение памяти для группы рабочей нагрузки                |
| ENABLE_MEMORY_OVERCOMMIT       | varchar(256) | Включено ли мягкое ограничение памяти для группы рабочей нагрузки |
| MAX_CONCURRENCY                | bigint       | Максимальное количество одновременных запросов в группе рабочей нагрузки |
| MAX_QUEUE_SIZE                 | bigint       | Максимальный размер очереди для группы рабочей нагрузки       |
| QUEUE_TIMEOUT                  | bigint       | Время ожидания в очереди для группы рабочей нагрузки          |
| CPU_HARD_LIMIT                 | varchar(256) | Величина жёсткого ограничения CPU для группы рабочей нагрузки  |
| SCAN_THREAD_NUM                | bigint       | Количество потоков локального сканирования                    |
| MAX_REMOTE_SCAN_THREAD_NUM     | bigint       | Максимальное количество потоков в пуле потоков удалённого сканирования |
| MIN_REMOTE_SCAN_THREAD_NUM     | bigint       | Минимальное количество потоков в пуле потоков удалённого сканирования |
| SPILL_THRESHOLD_LOW_WATERMARK  | varchar(256) | Нижний порог сброса на диск для группы рабочей нагрузки       |
| SPILL_THRESHOLD_HIGH_WATERMARK | varchar(256) | Верхний порог сброса на диск для группы рабочей нагрузки      |
| TAG                            | varchar(256) | Тег группы рабочей нагрузки                                  |
| READ_BYTES_PER_SECOND          | bigint       | Количество байтов, сканируемых в секунду при локальном чтении |
| REMOTE_READ_BYTES_PER_SECOND   | bigint       | Количество байтов, сканируемых в секунду при удалённом чтении |
