## База данных {#database}

## Информация о таблице {#table-information}

| Имя столбца    | Тип           | Описание                                                 |
| -------------- | ------------- | -------------------------------------------------------- |
| VARIABLE_NAME  | varchar(64)   | Имя переменной                                           |
| VARIABLE_VALUE | varchar(1024) | Текущее значение                                         |
| DEFAULT_VALUE  | varchar(1024) | Значение по умолчанию                                    |
| CHANGED        | varchar(4)    | Отличается ли текущее значение от значения по умолчанию   |
