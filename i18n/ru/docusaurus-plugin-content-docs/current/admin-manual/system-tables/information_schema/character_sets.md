## Обзор {#overview}

Просмотр поддерживаемых наборов символов. Эта таблица используется только для совместимости с поведением MySQL и не отражает наборы символов, фактически используемые Doris.

## База данных {#database}


`information_schema`


## Информация о таблице {#table-information}

| Имя столбца          | Тип          | Описание                                                     |
| -------------------- | ------------ | ------------------------------------------------------------ |
| CHARACTER_SET_NAME   | varchar(512) | Имя набора символов                                          |
| DEFAULT_COLLATE_NAME | varchar(64)  | Имя сопоставления по умолчанию                                |
| DESCRIPTION          | varchar(64)  | Подробное описание набора символов                           |
| MAXLEN               | bigint       | Максимальное количество байтов, занимаемых одним символом в наборе символов |
