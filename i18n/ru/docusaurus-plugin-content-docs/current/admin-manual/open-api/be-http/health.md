# Проверка доступности {#check-alive}

## Запрос {#request}

`GET /api/health`

## Описание {#description}

Позволяет службе мониторинга проверить доступность BE. Если BE доступен, он отправляет ответ.

## Параметры запроса {#query-parameters}

Нет

## Тело запроса {#request-body}

Нет

## Ответ {#response}

    ```
    {"status": "OK","msg": ""}
    ```

## Примеры {#examples}


    ```
    curl http://127.0.0.1:8040/api/health
    ```
