## Область применения {#applicable-scenario}

DataGrip — мощный кроссплатформенный инструмент для работы с базами данных от JetBrains, который поддерживает как реляционные базы данных, так и NoSQL. Apache Doris обеспечивает высокую совместимость с протоколом MySQL, поэтому источник данных MySQL в DataGrip позволяет подключаться к Apache Doris и выполнять запросы к данным во внутреннем и внешнем Catalog.

После прочтения этой статьи вы сможете:

- Создать подключение к Doris с помощью источника данных MySQL.
- Настроить параметры подключения к внутреннему или внешнему Catalog.
- Проверить соединение, просматривать базы данных и управлять ими в DataGrip.

## Предварительные требования {#prerequisites}

- Установлен DataGrip. Если он ещё не установлен, скачайте и установите его с [официального сайта DataGrip](https://www.jetbrains.com/datagrip/).
- Подготовлены данные для подключения к кластеру Doris: IP-адрес хоста FE, порт запросов FE, целевая база данных, имя пользователя и пароль.

:::info Примечание о версии
Описанные в этой статье действия проверены в DataGrip 2023.3.4.
:::

## Подключение к Doris {#connect-to-doris}

### 1. Добавление источника данных MySQL {#1-add-a-mysql-data-source}

Запустите DataGrip, нажмите значок плюса (**+**) в левом верхнем углу окна DataGrip и выберите источник данных MySQL.

![Добавление источника данных](/images/datagrip1.png)

### 2. Настройка подключения к Doris {#2-configure-the-doris-connection}

На вкладке «Общие» в окне «Источники данных и драйверы» укажите параметры подключения к Doris.

| Параметр | Описание |
| --- | --- |
| Хост | IP-адрес хоста FE кластера Doris. |
| Порт | Порт запросов FE кластера Doris, например `9030`. |
| База данных | Целевая база данных в кластере Doris. Для указания Catalog также можно использовать формат `catalog.db`. |
| Пользователь | Имя пользователя для входа в кластер Doris, например `admin`. |
| Пароль | Пароль для входа в кластер Doris. |

Поле «База данных» позволяет выбрать внутренний или внешний Catalog. С помощью источника данных MySQL в DataGrip можно создать несколько источников данных Doris, чтобы отдельно управлять разными Catalog в Doris.

| Как заполнить поле «База данных» | Подключение по умолчанию |
| --- | --- |
| Указать только имя базы данных | По умолчанию выполняется подключение к внутреннему Catalog. |
| Указать `catalog.db` | По умолчанию выполняется подключение к Catalog, указанному в поле «База данных». В DataGrip также отображаются базы данных и таблицы из этого Catalog. |

:::info Примечание о версии
Для управления внешним Catalog Doris с помощью формата `catalog.db` в поле «База данных» требуется Doris версии 2.1.0 или более поздней.
:::

### 3. Проверка подключения к источнику данных {#3-test-the-data-source-connection}

После заполнения параметров подключения нажмите «Проверить соединение» в левом нижнем углу, чтобы проверить правильность данных для подключения к базе данных. Если DataGrip отображает приведённое ниже диалоговое окно, проверка соединения прошла успешно. Затем нажмите «ОК» в правом нижнем углу, чтобы завершить настройку подключения.

![Проверка соединения](/images/datagrip4.png)

### 4. Подключение к базе данных и управление ею {#4-connect-to-and-manage-the-database}

После установления соединения с базой данных созданное подключение к источнику данных появится на панели навигации по подключениям слева. Теперь вы можете подключаться к базе данных и управлять ею через DataGrip.

![Установление соединения](/images/datagrip5.png)

## Поддерживаемые возможности {#feature-support-scope}

| Статус поддержки | Описание |
| --- | --- |
| В основном поддерживается | Большинство операций просмотра через графический интерфейс, а также работа с Doris с помощью SQL в консоли SQL. |
| Не поддерживается или не проверено | Такие операции, как создание баз данных и таблиц, изменение схемы, вставка, обновление и удаление данных. |
