# Flink Doris Connector {#flink-doris-connector}

[Flink Doris Connector](https://github.com/apache/doris-flink-connector) читает данные из кластера Doris и записывает их в него через Flink, а благодаря интеграции с [Flink CDC](https://nightlies.apache.org/flink/flink-cdc-docs-release-3.2/docs/connectors/flink-sources/overview/) позволяет удобно синхронизировать целые базы данных из исходных систем, таких как MySQL.

## Возможности {#capabilities}

| Возможность | Описание | Типичные сценарии |
| --- | --- | --- |
| [Чтение данных из Doris](./read.md) | Параллельно читает данные с узлов BE, не передавая их через FE; поддерживает протоколы Thrift и Arrow Flight SQL | Использование таблицы Doris в качестве источника данных для задания Flink, массовый экспорт |
| [Инкрементальное чтение с Doris Changelog](./incremental-read.md) | Непрерывно считывает изменения строк таблицы (вставки, обновления, удаления), при необходимости начиная со снимка; требуется Connector 26.4.0+ и Doris 5.0.0+ | Синхронизация изменений таблицы Doris с целевыми системами в реальном времени |
| [Запись данных в Doris](./write.md) | Объединяет данные в пакеты во Flink и записывает их через Stream Load; поддерживает потоковую запись (на основе Checkpoint, с гарантией Exactly-Once), пакетную запись и запись через S3 TVF | Загрузка данных в реальном времени, применение изменений CDC, частичное обновление столбцов |
| [Lookup Join](./lookup-join.md) | Объединяет записи из источника в пакеты и асинхронно запрашивает таблицу измерений Doris | Обогащение потоков данными измерений |
| [Синхронизация всей базы данных](./cdc-sync.md) | Благодаря интеграции с Flink CDC синхронизирует целую базу данных MySQL, Oracle, PostgreSQL, SQLServer, DB2 или MongoDB одной командой, автоматически создавая таблицы и синхронизируя DDL | Синхронизация баз данных бизнес-приложений с Doris в реальном времени |

Все возможности доступны через FlinkSQL; чтение и запись также доступны через [DataStream API](./datastream-api.md). Настройки подключения описаны в разделе [Параметры подключения и TLS](./connection.md), а соответствие типов Doris и Flink приведено в разделе [Сопоставление типов данных](./data-type-mapping.md).

## Принцип работы {#how-it-works}

![Принципы работы Flink Connector с JDBC и Doris](/images/next/connection-integration/data-integration/flink-doris-connector.jpg)

- **Чтение**: Connector получает от FE сведения о Tablet из плана запроса, а затем читает данные напрямую с узлов BE параллельно. Данные не проходят через FE, что устраняет узкое место, возникающее при последовательном чтении и записи через JDBC на одном узле FE. См. [Принцип чтения](./read.md#how-it-works).
- **Запись**: Данные объединяются в пакеты в памяти Flink, а затем массово загружаются в Doris через Stream Load. По умолчанию запись выполняется в соответствии с Flink Checkpoints и использует двухфазную фиксацию для обеспечения гарантии Exactly-Once; также доступен режим пакетной записи, который не зависит от Checkpoints. См. [Режимы записи](./write.md#write-modes).
- **Lookup Join**: Записи из источника объединяются в пакеты, а запросы к таблице измерений Doris выполняются асинхронно, вместо отдельного точечного запроса для каждой записи.
- **Синхронизация всей базы данных**: Изменения считываются из исходной базы данных с помощью Flink CDC и записываются через Doris Sink, который автоматически создает целевые таблицы и синхронизирует изменения схемы (Schema Changes).

## Установка {#installation}

Поддерживается установка как с помощью Jar-пакета, так и через зависимость Maven.

### Установка с помощью Jar-пакета {#jar-package-method}

Скачайте Jar-пакет Flink Doris Connector нужной версии со [страницы загрузок Doris](https://doris.apache.org/download#doris-ecosystem) и скопируйте его в `classpath` Flink:

- **Режим Standalone**: Поместите Jar-файл в каталог `lib/`.
- **Кластерный режим Yarn**: Поместите Jar-файл в пакет, подготавливаемый перед развертыванием.

### Установка через зависимость Maven {#maven-dependency-method}

Добавьте следующую зависимость в `pom.xml` проекта:

```xml
<dependency>
    <groupId>org.apache.doris</groupId>
    <artifactId>flink-doris-connector-${flink.version}</artifactId>
    <version>${connector.version}</version>
</dependency>
```

Например:

```xml
<dependency>
    <groupId>org.apache.doris</groupId>
    <artifactId>flink-doris-connector-1.16</artifactId>
    <version>26.3.0</version>
</dependency>
```
