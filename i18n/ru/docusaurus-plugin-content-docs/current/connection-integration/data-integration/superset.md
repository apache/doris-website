[Apache Superset](https://superset.apache.org/) — платформа с открытым исходным кодом для исследования данных, которая поддерживает подключение к широкому спектру источников данных, различные виды визуализации и детальное управление правами пользователей. Основные возможности включают самостоятельный анализ данных, создание собственных дашбордов, экспорт результатов анализа в виде визуализаций, управление правами пользователей и ролей, а также встроенный редактор SQL.

**Цель статьи**: настроить источник данных Apache Doris в Apache Superset 3.1 для выполнения запросов и визуализации данных.

<!-- Knowledge type: Version requirements -->
| Компонент | Рекомендуемая версия | Примечания |
|------|----------|------|
| Apache Superset | 3.1 или новее | Официально поддерживает подключения к Apache Doris |
| Apache Doris | 2.0.4 или новее | Рекомендуется |
| Python | 3.9 / 3.10 / 3.11 | Используйте стабильную версию |
| pydoris | 1.1.0 | Клиент Doris для Python |

## Предварительные требования {#prerequisites}

Перед началом настройки выполните следующие действия:

1. Установите Apache Superset 3.1 или новее.

    См. [официальное руководство по установке Superset](https://superset.apache.org/docs/installation/installing-superset-from-pypi).

2. Установите клиент Apache Doris для Python:

    ```bash
    pip install pydoris
    ```

3. Проверьте установку:

    ```bash
    pip list | grep pydoris
    # Expected output:
    # pydoris                       1.1.0
    ```

## Шаг 1: Настройка источника данных Doris {#step-1-configure-the-doris-data-source}

После подготовки среды выполните следующие действия, чтобы добавить источник данных Doris в Superset.

### 1. Получите строку подключения SQLAlchemy {#1-get-the-sqlalchemy-connection-string}

Doris использует следующий формат URI SQLAlchemy:

```
doris://<username>:<password>@<host>:<port>/<Catalog>.<database>
```

**Описание параметров:**

| Параметр | Значение | Пример |
|------|------|------|
| username | Имя пользователя для подключения к Doris | testuser |
| password | Пароль пользователя | xxxxxx |
| host | Хост базы данных | 127.0.1.28 |
| port | Порт для запросов | 9030 |
| Catalog | Catalog в Doris. Для внутренних таблиц используйте `internal`, а при выполнении запросов к озеру данных через внешние таблицы укажите соответствующий Catalog. | internal |
| database | Имя базы данных | tpch |

### 2. Добавьте источник данных в Superset {#2-add-a-data-source-in-superset}

1. Откройте веб-интерфейс Superset, нажмите **Настройки** в правом верхнем углу, затем **Коннекторы баз данных**.

    ![Откройте коннекторы баз данных](/images/next/connection-integration/superset/02-superset-connect.png)

2. Нажмите **+ Добавить базу данных** и в диалоговом окне **Подключение базы данных** выберите **Apache Doris**.

    ![Выберите Apache Doris](/images/next/connection-integration/superset/03-superset-choose-db.png)

3. Введите URI SQLAlchemy в параметрах подключения. После успешной проверки подключения нажмите **Подключить**.

    ![Заполните параметры подключения](/images/next/connection-integration/superset/04-superset-choose-test-connect.png)

4. После успешного добавления источник данных появится в интерфейсе.

    ![Источник данных успешно добавлен](/images/next/connection-integration/superset/05-superset-after-connect.png)

## Шаг 2: Создание графика {#step-2-build-a-visualization-chart}

После настройки источника данных можно приступать к созданию визуализаций.

В этой статье на примере набора данных TPC-H показано, как анализировать изменение сумм заказов с течением времени для разных способов доставки.

> **Предварительное требование**: набор данных TPC-H должен быть загружен в Apache Doris. См. [руководство по подготовке данных TPC-H](../../lakehouse/best-practices/tpch.md).

### 1. Создайте набор данных {#1-create-a-dataset}

1. На левой панели навигации нажмите **Наборы данных**, затем **+ Добавить набор данных**.

    ![Добавьте набор данных](/images/next/connection-integration/superset/06-superset-add-dataset.png)

2. Задайте следующие параметры, затем нажмите **Создать набор данных и график** в правом нижнем углу:

    - **База данных**: Doris
    - **Схема**: tpch
    - **Таблица**: lineitem

    ![Выберите таблицу данных](/images/next/connection-integration/superset/07-superset-add-db.png)

### 2. Добавьте пользовательскую метрику {#2-add-a-custom-metric}

1. На странице редактирования набора данных нажмите **Метрики**, затем **Добавить элемент** и добавьте вычисляемую метрику:

    - **Ключ метрики**: Revenue
    - **Выражение SQL**: `SUM(l_extendedprice * (1 - l_discount))`

    ![Добавьте метрику](/images/next/connection-integration/superset/09-superset-metrics.png)

### 3. Создайте график {#3-create-a-chart}

1. Перейдите на страницу **График**, нажмите **+ Добавить график**, выберите **lineitem** в качестве набора данных и **Линейный график** в качестве типа графика.

    ![Выберите тип графика](/images/next/connection-integration/superset/10-superset-add-chart.png)

2. Настройте параметры графика:

    - Перетащите **l_shipdate** на ось X и задайте временную детализацию.
    - Перетащите метрику **Revenue** в область **Метрики**.
    - Перетащите столбец **l_shipmode** в область **Измерения**.

    ![Настройте график](/images/next/connection-integration/superset/11-superset-edit-chart.png)

3. Нажмите **Обновить график** для предварительного просмотра. После проверки нажмите **Сохранить**, чтобы сохранить дашборд.

    ![Сохраните дашборд](/images/next/connection-integration/superset/12-superset-edit-save-chart.png)

## Частые вопросы и рекомендации {#faq-and-tips}

<!-- Knowledge type: Troubleshooting / Best practices -->

### Предварительные требования {#prerequisites-1}

- Пакет `pydoris` необходимо заранее установить в среде Superset. Иначе при создании базы данных вариант Apache Doris будет недоступен.

### Настройка производительности {#performance-tuning}

| Оптимизация | Описание |
|--------|------|
| Проектирование схемы таблиц | Проектируйте базы данных и таблицы Doris с учётом реальных требований, используйте партиционирование и бакетирование по времени. |
| Проталкивание предикатов | Эффективно сокращает затраты на фильтрацию по предикатам и объём передаваемых данных. |
| Сетевая безопасность | Используйте частные подключения VPC, чтобы избежать рисков безопасности, связанных с доступом через общедоступную сеть. |
| Управление правами доступа | Детально настраивайте роли и права доступа учётных записей Doris, избегайте предоставления избыточных привилегий. |

### Устранение неполадок {#troubleshooting}

**Вопрос: Apache Doris не отображается среди вариантов при добавлении базы данных.**

Ответ: проверьте, установлен ли `pydoris` в новой среде. Superset отображает этот вариант, только если обнаруживает драйвер Doris во время работы. После установки может потребоваться перезапустить службу Superset.

**Вопрос: Проверка подключения завершается ошибкой.**

Ответ: проверьте правильность формата URI SQLAlchemy, доступность хоста и порта, а также корректность имени пользователя и пароля. Для предварительной проверки подключения можно использовать Doris BE или MySQL Client.
