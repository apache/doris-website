## Обзор {#overview}

[DBine](https://dbine.com) — бесплатный настольный менеджер баз данных с открытым исходным кодом (лицензия Apache 2.0) для Windows, macOS и Linux. Он позволяет работать с более чем 130 базами данных и облачными сервисами в одном окне. В DBine предусмотрен тип подключения Apache Doris, который соединяется с FE по протоколу MySQL.

Прочитав эту статью, вы сможете:

- Установить DBine и создать подключение к Doris.
- Просматривать базы данных внутреннего Catalog, таблицы, представления и столбцы, а также выполнять SQL-запросы к Doris.
- Узнать, чем Doris отличается от сервера MySQL при отображении сведений о подключении.

## Предварительные требования {#prerequisites}

<!-- Knowledge type: Prerequisites -->
<!-- Applicable scenario: Check the DBine and Doris connection requirements before connecting -->

- Установлен DBine. Загрузить его можно со [страницы выпусков](https://github.com/addlayer-io/dbine/releases).
- FE доступен с компьютера, на котором запущен DBine. Пользователю Doris предоставлены права, необходимые для работы с нужной базой данных и таблицами.
- Подготовлены параметры подключения к кластеру Doris: адрес хоста FE, порт протокола MySQL на FE (по умолчанию `9030`), целевая база данных, имя пользователя и пароль.

## Подключение к Doris {#connect-to-doris}

<!-- Knowledge type: Procedure -->
<!-- Applicable scenario: Create a Doris connection in DBine -->

### 1. Добавьте подключение {#1-add-a-connection}

В DBine нажмите **Новое подключение** и выберите **Apache Doris** в списке СУБД.

### 2. Настройте подключение к Doris {#2-configure-the-doris-connection}

Заполните форму подключения:

| Поле | Описание |
| --- | --- |
| Сервер | Адрес хоста FE кластера Doris. |
| Порт | Порт протокола MySQL на FE, по умолчанию `9030`. |
| База данных | Целевая база данных во внутреннем Catalog кластера Doris. Необязательное поле. |
| Пользователь | Имя пользователя кластера Doris. |
| Пароль | Пароль пользователя кластера Doris. |

Если в кластере используется TLS, откройте вкладку **SSL/TLS** и выберите **Шифровать подключение (TLS)**.

### 3. Проверьте и сохраните подключение {#3-test-and-save-the-connection}

Нажмите **Проверить подключение**, затем — **Сохранить и подключиться**. При успешной проверке появится сообщение `Connection successful`, а подключение отобразится в **Обозревателе**.

![Настройка подключения](/images/next/connection-integration/data-integration/dbine/dbine-connection-form.png)

### 4. Просматривайте данные и выполняйте запросы {#4-browse-and-query}

Разверните подключение в **Обозревателе**, чтобы увидеть базы данных Doris. Разверните базу данных, чтобы увидеть её таблицы, представления и столбцы. Нажмите правой кнопкой мыши на базе данных и выберите **Новый запрос**, чтобы открыть редактор SQL, затем нажмите **Выполнить**. Например:

```sql
SELECT @@version_comment AS doris_version;
```

```text
+--------------------------------------------+
| doris_version                              |
+--------------------------------------------+
| doris version doris-4.1.3-rc02-7126cf65d96 |
+--------------------------------------------+
```

![Просмотр данных и выполнение запросов в Doris](/images/next/connection-integration/data-integration/dbine/dbine-editor.png)

## Известные ограничения {#known-limitations}

Приведённые ниже результаты проверены с Doris 4.1.3 (`apache/doris:all-in-one-4.1.3`).

| Область | Состояние | Подробности |
| --- | --- | --- |
| Просмотр данных и запросы | Работает корректно | Отображаются базы данных, таблицы, представления и столбцы. Запросы к внутреннему Catalog выполняются с правами самого пользователя: пользователь с правом `SELECT_PRIV` для одной базы данных видит эту базу данных наряду с `information_schema` и `mysql`. |
| EXPLAIN | Работает корректно | `EXPLAIN` возвращает план Nereids, сформированный Doris, в текстовом виде. |
| Версия сервера | Версия MySQL | При проверке подключения и в строке состояния отображается `5.7.99` — версия MySQL, которую Doris сообщает через `version()`. Чтобы узнать версию сборки Doris, выполните `SELECT @@version_comment`. |

Дополнительную информацию об использовании DBine см. в [репозитории DBine](https://github.com/addlayer-io/dbine).
