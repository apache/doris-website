Apache Doris полностью совместима с **сетевым протоколом MySQL**. Поэтому к Doris могут напрямую подключаться все клиентские инструменты, средства визуализации, а также драйверы и библиотеки MySQL для популярных языков программирования, которые поддерживают этот протокол. **Устанавливать отдельный драйвер для Doris не требуется**.

> По умолчанию Doris FE предоставляет доступ по протоколу MySQL через порт `9030`. Ему соответствует параметр `query_port` в файле `fe.conf`.

## Типичные сценарии использования {#typical-use-cases}

Подключения по протоколу MySQL можно разделить на два типичных сценария:

| Сценарий | Типичное применение | Рекомендуемый способ |
| --- | --- | --- |
| Доступ из командной строки или скриптов | Поиск и устранение неполадок, разовые запросы, скрипты автоматизации | MySQL CLI |
| Интеграция с приложениями | Серверные службы, программы обработки данных, задачи ETL | Драйверы MySQL для соответствующего языка (Java / Go / Rust / Python / C++ и т. д.) |

## Подготовка к подключению {#preparation-before-connecting}

Перед подключением уточните следующие данные:

| Параметр | Описание | Пример |
| --- | --- | --- |
| `FE_IP` | IP-адрес или имя хоста узла Doris FE | `172.20.63.118` |
| `FE_QUERY_PORT` | Порт службы протокола MySQL на FE, соответствующий параметру `query_port` в `fe.conf` | `9030` |
| `USER` | Учётная запись для входа | `root` |
| `PASSWORD` | Пароль для входа (у учётной записи `root` по умолчанию пустой пароль) | - |

> Чтобы изменить порт, задайте нужное значение параметра `query_port` в файле `fe.conf` на узле FE и перезапустите FE.

Подходит для работы из командной строки, выполнения разовых запросов и вызовов из скриптов.

### 1. Скачайте и распакуйте клиент MySQL {#1-download-and-extract-the-mysql-client}

Скачайте клиент MySQL с [официального сайта MySQL](https://dev.mysql.com/downloads/mysql/). Doris совместима с клиентами **MySQL версии 5.7 и новее**.

После распаковки инструмент командной строки `mysql` будет находиться в каталоге `bin/`.

### 2. Подключитесь к Doris {#2-connect-to-doris}

Для подключения к Doris выполните команду:

```shell
mysql -h FE_IP -P FE_QUERY_PORT -u USER -p
```

После нажатия Enter введите пароль. У учётной записи `root` по умолчанию нет пароля, поэтому достаточно нажать Enter ещё раз.

### 3. Проверьте вход {#3-verify-login}

После успешного входа появится следующее сообщение:

```text
Welcome to the MySQL monitor.  Commands end with ; or \g.
Your MySQL connection id is 236
Server version: 5.7.99 Doris version doris-2.0.3-rc06-37d31a5

Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

mysql>
```

Подходит для интеграции приложений Java с Doris. Для подключения Doris рекомендует использовать **MySQL JDBC Connector**.

### 1. Добавьте драйвер JDBC {#1-add-the-jdbc-driver}

Добавьте в проект зависимость MySQL JDBC Connector (рекомендуется версия MySQL 5.1.49 или новее).

### 2. Напишите код подключения {#2-write-the-connection-code}

```java
String user = "user_name";
String password = "user_password";
String url = "jdbc:mysql://FE_IP:FE_QUERY_PORT/demo"
        + "?useUnicode=true"
        + "&characterEncoding=utf8"
        + "&useTimezone=true"
        + "&serverTimezone=Asia/Shanghai"
        + "&useSSL=false"
        + "&allowPublicKeyRetrieval=true";

try (Connection conn = DriverManager.getConnection(url, user, password);
     Statement stmt = conn.createStatement();
     ResultSet rs = stmt.executeQuery("show databases")) {

    ResultSetMetaData metaData = rs.getMetaData();
    int columnCount = metaData.getColumnCount();
    while (rs.next()) {
        for (int i = 1; i <= columnCount; i++) {
            System.out.println(rs.getObject(i));
        }
    }
} catch (SQLException e) {
    log.error("get JDBC connection exception.", e);
}
```

### 3. Распространённые параметры URL JDBC {#3-common-jdbc-url-parameters}

| Параметр | Значение | Рекомендуемое значение / пример | Обязателен |
| --- | --- | --- | --- |
| `useUnicode` | Использовать ли набор символов Unicode | `true` | Нет |
| `characterEncoding` | Кодировка символов | `utf8` | Нет |
| `useTimezone` | Включать ли преобразование часовых поясов | `true` | Нет |
| `serverTimezone` | Часовой пояс сервера | `Asia/Shanghai` | Нет |
| `useSSL` | Использовать ли SSL для подключения | `false` | Нет |
| `allowPublicKeyRetrieval` | Разрешать ли получение открытого ключа с сервера (обычно требуется драйверу MySQL 8) | `true` | Нет |
| `sessionVariables` | Переменные сеанса, инициализируемые при установлении подключения | `key1=val1,key2=val2` | Нет |

### 4. Инициализируйте переменные сеанса (необязательно) {#4-initialize-session-variables-optional}

Если при установлении подключения нужно инициализировать переменные сеанса, используйте URL следующего формата:

```text
jdbc:mysql://FE_IP:FE_QUERY_PORT/demo?sessionVariables=key1=val1,key2=val2
```
