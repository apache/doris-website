В следующей таблице описано, как Doris 4.2 (`branch-4.2`) сопоставляет типы данных в схемах внешних таблиц Iceberg при чтении. Запись также зависит от целевой схемы и поддерживаемых операций записи; правила сопоставления для чтения нельзя автоматически применять в обратном направлении при записи.

| Тип Iceberg                           | Тип Doris           | Примечание                                 |
| -------------------------------------- | -------------------- | --------------------------------------- |
| boolean                                | boolean              |                                         |
| integer                                | int                  |                                         |
| long                                   | bigint               |                                         |
| float                                  | float                |                                         |
| double                                 | double               |                                         |
| decimal(P, S)                          | decimal(P, S)        |                                         |
| date                                   | date                 |                                         |
| timestamp (отметка времени без часового пояса) | datetime(6)          | Сопоставляется с datetime с точностью 6     |
| timestamptz (отметка времени с часовым поясом) | TIMESTAMPTZ(6) | Начиная с 4.1.5, этот тип всегда сопоставляется с `TIMESTAMPTZ(6)`. Точность ограничена значением 6, поэтому более высокая точность теряется. |
| fixed(N) | VARBINARY(N) | Начиная с 4.1.5, фиксированная длина двоичных данных сохраняется. |
| string                                 | string               |                                         |
| binary | VARBINARY | Начиная с 4.1.5, этот тип всегда сопоставляется с `VARBINARY`. |
| uuid | UUID | Нативный тип `UUID` в 4.2; Doris 4.1.5 сопоставляет его с `VARBINARY(16)`. |
| struct                                 | struct (поддерживается начиная с версии 2.1.3) |                                         |
| map                                    | map (поддерживается начиная с версии 2.1.3)    |                                         |
| list                                   | array                |                                         |
| timestamp_ns (без часового пояса) | TIMESTAMP_NS | Сохраняет наносекундную точность без преобразования часового пояса сессии. |
| timestamptz_ns (с часовым поясом) | UNSUPPORTED | Отметки времени с часовым поясом и наносекундной точностью не поддерживаются. |
| time | UNSUPPORTED | Не сопоставляется с типом Doris `TIME`. |
| variant | VARIANT | Iceberg V3 Variant; задействованные узлы BE должны поддерживать чтение Variant. |
| прочие                                  | UNSUPPORTED          |                                         |

## Примечания по использованию {#usage-notes}

Для вложенных полей сложных типов рекурсивно применяются те же правила сопоставления. `TIMESTAMPTZ` представляет момент времени, отображаемый в часовом поясе сессии `time_zone`.

`timestamp` и `timestamptz` используют микросекундную точность. Только `timestamp_ns` без часового пояса сопоставляется с `TIMESTAMP_NS`. Его диапазон: от `1677-09-21 00:12:43.145224192` до `2262-04-11 23:47:16.854775807`; значения за пределами этого диапазона не могут быть представлены.

В выводе `DESCRIBE table_name` значение `WITH_TIMEZONE` в столбце Extra указывает на исходное поле с часовым поясом.

При записи в формате Parquet в поля UUID таблиц Iceberg сохраняется логическая аннотация UUID, в том числе для вложенных полей.

Реализация: [IcebergUtils.java](https://github.com/apache/doris/blob/bcaaa5f293674f1adba0dfa52c8f8f57fb5e9549/fe/fe-core/src/main/java/org/apache/doris/datasource/iceberg/IcebergUtils.java) (`branch-4.2`).
