В этом документе описаны поддерживаемые параметры подключения к Google Dataproc Metastore и доступа к нему с помощью оператора `CREATE CATALOG`.

| Имя свойства        | Описание                                                                                                     | Значение по умолчанию | Обязательное |
| -------------------- | --------------------------------------------------------------------------------------------------------------- | ------------- | -------- |
| `hive.metastore.uri` | URI-адрес Metastore. Его можно получить на странице [Сервисы Dataproc Metastore](https://console.cloud.google.com/dataproc/metastore) | Отсутствует          | Да |
