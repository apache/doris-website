# Статистика {#statistics}

Doris поддерживает автоматический или ручной сбор статистики для таблиц из внешних источников данных, таких как Hive, Iceberg и Paimon. Точность статистики напрямую определяет точность оценки стоимости, что крайне важно для выбора оптимального плана запроса. Это позволяет значительно повысить эффективность выполнения запросов, особенно сложных.

Подробнее см. в разделе «Сбор статистики для внешних таблиц» документа [Статистика](../query-acceleration/optimization-technology-principle/statistics#external-table-collection).
