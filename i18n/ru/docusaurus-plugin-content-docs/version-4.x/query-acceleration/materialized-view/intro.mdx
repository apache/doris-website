Материализованное представление — это объект, содержащий как вычислительную логику, так и данные. Его можно использовать для ускорения запросов, построения простых ETL-моделей и ускорения федеративных запросов к lakehouse. Сначала изучите основные понятия, затем выберите синхронные или асинхронные материализованные представления в зависимости от требований к актуальности данных.
