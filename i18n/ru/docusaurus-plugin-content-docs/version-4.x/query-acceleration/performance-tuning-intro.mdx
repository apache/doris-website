Адаптивный оптимизатор и движок выполнения Pipeline в Apache Doris позволяют выполнять большинство рабочих нагрузок без дополнительной настройки, однако в промышленных средах обычно всё же требуется систематическая настройка производительности. Начните с методики настройки, чтобы выявить узкие места, а затем переходите к оптимизации конкретных сценариев выполнения запросов или загрузки данных. Если вам встретится план выполнения, который сложно объяснить, обратитесь к принципам работы технологий оптимизации, чтобы разобраться в лежащих в его основе механизмах.
