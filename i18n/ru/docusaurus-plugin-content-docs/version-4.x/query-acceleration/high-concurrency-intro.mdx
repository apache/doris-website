В дополнение к столбцовому хранению, ориентированному на аналитику, Doris предоставляет специальный путь оптимизации для точечных запросов и поиска значений по ключу в онлайн-сценариях, требующих высокой конкурентности и низкой задержки. Механизмы row store и short path обеспечивают высокий QPS и низкую задержку для точечных запросов по первичному ключу в таблицах Unique. Словари преобразуют соединения с таблицами измерений в поиск значений по ключу в памяти.
