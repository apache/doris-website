Quick BI — это инструмент бизнес-аналитики на основе хранилищ данных, который помогает компаниям быстро создавать панели для визуального анализа. Quick BI поддерживает различные источники данных, включая базы данных MySQL, Oracle, SQL Server и Apache Doris, а также файловые форматы Excel, CSV и JSON. Он предоставляет компоненты визуализации, такие как таблицы, диаграммы и карты, позволяя пользователям выполнять визуальный анализ данных с помощью перетаскивания элементов.

В этом документе описано, как подключить источник данных Apache Doris в Quick BI и создать на его основе набор данных для последующего анализа в отчетах.

## Сценарии использования {#applicable-scenarios}

| Сценарий | Цель пользователя | Результат |
| --- | --- | --- |
| Подключение источника данных Doris | Создать источник данных Apache Doris в рабочей области Quick BI | Quick BI получает доступ к данным в Doris |
| Создание набора данных для анализа | Выбрать таблицу Doris в созданном источнике данных | Создается набор данных, который можно использовать для настройки отчетов |
| Построение визуальных отчетов | Использовать компоненты визуализации Quick BI для анализа данных Doris | Результаты анализа отображаются с помощью таблиц, диаграмм и карт |

## Обзор возможностей Quick BI {#quick-bi-capability-overview}

| Возможность | Описание |
| --- | --- |
| Источники данных на основе баз данных | Поддерживаются базы данных MySQL, Oracle, SQL Server и Apache Doris |
| Файловые источники данных | Поддерживаются файловые форматы Excel, CSV и JSON |
| Компоненты визуализации | Доступны таблицы, диаграммы и карты |
| Способ анализа | Поддерживается визуальный анализ данных с помощью перетаскивания элементов |

## Предварительные требования {#prerequisites}

Перед началом работы убедитесь, что выполнены следующие условия:

- Вы вошли в Quick BI и можете создать рабочую область.
- Данные для подключения к Apache Doris подготовлены.
- В Doris есть таблица данных, которую можно использовать для создания набора данных. В этом документе в качестве примера используется набор данных TPC-H.

## Порядок действий {#procedure}

| Шаг | Цель | Описание |
| --- | --- | --- |
| Шаг 1 | Создать рабочую область | Войдите в Quick BI и создайте рабочую область для управления источниками и наборами данных |
| Шаг 2 | Создать источник данных Doris | Выберите Apache Doris в рабочей области и укажите данные для подключения к Doris |
| Шаг 3 | Проверить результат подключения | После успешного подключения найдите созданный источник данных в списке источников данных |
| Шаг 4 | Создать набор данных | Создайте набор данных на основе источника данных Doris и используйте его для последующей настройки отчетов |

### Шаг 1: Создание рабочей области Quick BI {#step-1-create-a-quick-bi-workspace}

1. Войдите в Quick BI и создайте рабочую область.

2. В текущей рабочей области нажмите «Создать источник данных».

    ![Создание источника данных](/images/next/connection-integration/data-integration/quickbi/bi-quickbi-en-1.png)

### Шаг 2: Создание источника данных Doris {#step-2-create-a-doris-data-source}

На странице «Создать источник данных» выберите **Apache Doris** и укажите соответствующие данные для подключения к Doris.

![Ввод данных для подключения к Doris](/images/next/connection-integration/data-integration/quickbi/bi-quickbi-en-2.png)

### Шаг 3: Проверка результата подключения к источнику данных {#step-3-verify-the-data-source-connection-result}

После успешного подключения созданный источник данных Doris появится в списке источников данных.

![Просмотр источника данных](/images/next/connection-integration/data-integration/quickbi/bi-quickbi-en-3.png)

### Шаг 4: Создание набора данных и настройка отчета {#step-4-create-a-dataset-and-configure-a-report}

Создайте набор данных в созданном источнике данных. В этом документе в качестве примера используется набор данных TPC-H. После создания набора данных можно настроить соответствующий отчет.

![Создание набора данных Doris](/images/next/connection-integration/data-integration/quickbi/bi-quickbi-en-4.png)

## Результат {#result}

После выполнения описанной выше настройки Quick BI сможет получать доступ к данным Doris через созданный источник данных Doris и настраивать отчеты для визуального анализа на основе набора данных.
