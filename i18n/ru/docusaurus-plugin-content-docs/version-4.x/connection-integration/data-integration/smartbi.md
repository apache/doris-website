[Smartbi](https://www.smartbi.com.cn/) представляет собой набор программных сервисов и коннекторов приложений для подключения к различным источникам данных, таким как Oracle, SQL Server, MySQL и Apache Doris, а также для объединения и очистки данных.

В этом документе описано, как подключиться к источнику данных Apache Doris в Smartbi и выполнять моделирование, анализ и визуализацию данных Doris.

## Сценарии использования {#applicable-scenarios}

| Сценарий | Цель пользователя | Результат |
| --- | --- | --- |
| Подключение к источнику данных Doris | Создать подключение к данным Doris в Smartbi | Smartbi получает доступ к данным в Doris |
| Создание аналитической модели | Создать реляционную модель на основе данных Doris, написать выражения для анализа данных и установить связи между данными | Основа для расширенного анализа и визуализации данных |
| Создание отчётов с визуализацией | Использовать диаграммы Smartbi, географические карты, интерактивные панели мониторинга и настраиваемые инструменты визуализации для представления данных | Более наглядное и полное понимание и представление данных |

## Обзор возможностей Smartbi {#smartbi-capabilities-overview}

| Возможность | Описание |
| --- | --- |
| Подключение к источникам данных | Поддерживает подключение к различным источникам данных, таким как Oracle, SQL Server, MySQL и Apache Doris |
| Моделирование данных | Поддерживает создание сложных реляционных моделей, написание выражений для анализа данных и установление связей между данными |
| Визуальный анализ | Предоставляет диаграммы, географические карты, интерактивные панели мониторинга и настраиваемые инструменты визуализации |
| Представление данных | Помогает лучше понимать данные и представлять их более наглядно и полно, повышая результативность и эффективность анализа данных |

## Предварительные требования {#prerequisites}

Перед началом работы убедитесь, что выполнены следующие условия:

- У вас есть доступ для входа в Smartbi.
- У вас есть сведения для подключения к базе данных Apache Doris.
- Вы определили, какие сведения об отчёте необходимо настроить на панели e-service.

## Порядок действий {#procedure}

| Шаг | Цель | Описание |
| --- | --- | --- |
| Шаг 1 | Открыть страницу подключения к данным | Войдите в Smartbi и откройте раздел подключения к данным |
| Шаг 2 | Выбрать базу данных Doris | Выберите Doris из списка баз данных, доступных для подключения |
| Шаг 3 | Указать сведения для подключения | Введите сведения для подключения к базе данных Doris |
| Шаг 4 | Проверить подключение | Убедитесь, что сведения для подключения верны, и выполните проверку подключения |
| Шаг 5 | Настроить отчёт | Перейдите в модуль анализа данных и настройте сведения об отчёте на панели e-service |

### Шаг 1: Откройте страницу подключения к данным {#step-1-open-the-data-connection-page}

После входа в Smartbi нажмите «Подключение к данным».

![Открытие страницы подключения к данным](/images/next/connection-integration/data-integration/smartbi/bi-smartbi-en-1.png)

### Шаг 2: Выберите базу данных Doris {#step-2-select-the-doris-database}

На странице подключения к данным просмотрите список баз данных, доступных для подключения, и выберите базу данных Doris.

![Выбор базы данных Doris](/images/next/connection-integration/data-integration/smartbi/bi-smartbi-en-2.png)

### Шаг 3: Укажите сведения для подключения к Doris {#step-3-fill-in-the-doris-connection-information}

После выбора базы данных Doris укажите сведения для подключения к ней.

![Ввод сведений для подключения к Doris](/images/next/connection-integration/data-integration/smartbi/bi-smartbi-en-3.png)

### Шаг 4: Проверьте подключение {#step-4-test-the-connection}

Если сведения для подключения верны и подключение установлено, на странице отображается сообщение об успешном прохождении проверки.

![Проверка подключения пройдена](/images/next/connection-integration/data-integration/smartbi/bi-smartbi-en-4.png)

### Шаг 5: Настройте аналитический отчёт {#step-5-configure-the-data-analysis-report}

После успешного подключения перейдите на панель e-service в модуле анализа данных и настройте сведения об отчёте в соответствии со своими потребностями.

![Настройка аналитического отчёта](/images/next/connection-integration/data-integration/smartbi/bi-smartbi-en-5.png)

## Результат {#result}

После завершения описанной выше настройки Smartbi получает доступ к данным Doris через созданное подключение к данным Doris и позволяет настраивать необходимые отчёты с помощью модуля анализа данных.
