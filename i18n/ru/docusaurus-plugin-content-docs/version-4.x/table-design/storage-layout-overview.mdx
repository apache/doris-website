Apache Doris позволяет пользователям настраивать организацию хранения данных на диске с помощью параметров. Правильная настройка позволяет снизить затраты на хранение, ускорить точечные запросы к широким таблицам и сократить накладные расходы на хранение исторических и холодных данных без изменения модели таблицы или запросов.
