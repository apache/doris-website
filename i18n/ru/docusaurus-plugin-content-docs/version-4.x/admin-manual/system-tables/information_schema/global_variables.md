## Обзор {#overview}

Просмотр глобальных переменных

## База данных {#database}


`information_schema`


## Сведения о таблице {#table-information}

| Имя столбца    | Тип           | Описание                                                   |
| -------------- | ------------- | ---------------------------------------------------------- |
| VARIABLE_NAME  | varchar(64)   | Имя переменной                                             |
| VARIABLE_VALUE | varchar(1024) | Текущее значение переменной                                |
| DEFAULT_VALUE  | varchar(1024) | Значение переменной по умолчанию                            |
| CHANGED        | varchar(4)    | Указывает, отличается ли значение от значения по умолчанию |
