## Обзор {#overview}

Позволяет просматривать сведения об атрибутах таблиц (включая внутренние и внешние таблицы).

## База данных {#database}


`information_schema`


## Информация о таблице {#table-information}

| Имя столбца    | Тип         | Описание                                |
| -------------- | ----------- | --------------------------------------- |
| TABLE_CATALOG  | varchar(64) | Catalog, которому принадлежит таблица   |
| TABLE_SCHEMA   | varchar(64) | База данных, которой принадлежит таблица |
| TABLE_NAME     | varchar(64) | Имя таблицы                             |
| PROPERTY_NAME  | string      | Имя свойства                            |
| PROPERTY_VALUE | string      | Значение свойства                       |
