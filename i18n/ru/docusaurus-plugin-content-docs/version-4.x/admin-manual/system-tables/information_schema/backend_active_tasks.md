## Обзор {#overview}

Просмотр использования ресурсов задачами запросов или загрузки, выполняющимися в данный момент на узлах Backend.

## База данных {#database}


`information_schema`


## Информация о таблице {#table-information}

| Имя столбца               | Тип          | Описание                                         |
| ------------------------- | ------------ | ------------------------------------------------ |
| BE_ID                     | bigint       | Идентификатор узла Backend, выполняющего задачу   |
| FE_HOST                   | varchar(256) | Адрес узла Frontend, отправившего задачу          |
| QUERY_ID                  | varchar(256) | Идентификатор запроса                            |
| TASK_TIME_MS              | bigint       | Время выполнения задачи                          |
| TASK_CPU_TIME_MS          | bigint       | Время CPU, затраченное на выполнение задачи       |
| SCAN_ROWS                 | bigint       | Количество просканированных строк                |
| SCAN_BYTES                | bigint       | Количество просканированных байтов               |
| BE_PEAK_MEMORY_BYTES      | bigint       | Пиковый объём используемой памяти                |
| CURRENT_USED_MEMORY_BYTES | bigint       | Текущий объём используемой памяти                |
| SHUFFLE_SEND_BYTES        | bigint       | Количество перераспределённых и отправленных байтов |
| SHUFFLE_SEND_ROWS         | bigint       | Количество перераспределённых и отправленных строк |
| QUERY_TYPE                | varchar(256) | Тип запроса                                      |
