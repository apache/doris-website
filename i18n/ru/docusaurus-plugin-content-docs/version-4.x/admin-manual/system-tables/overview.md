# Обзор {#overview}

В кластере Apache Doris есть несколько встроенных системных баз данных, в которых хранятся метаданные о самой системе Doris.

### information_schema {#information_schema}

Все таблицы в базе данных `information_schema` являются виртуальными и не имеют физического представления. Эти системные таблицы содержат метаданные о кластере Doris и всех объектах его баз данных, включая базы данных, таблицы, столбцы, права доступа и т. д. Они также содержат сведения о состоянии таких функциональных компонентов, как Workload Group, Task и т. д.

В каждом Catalog есть база данных `information_schema`, содержащая метаданные только о базах данных и таблицах соответствующего Catalog.

Все таблицы в базе данных `information_schema` доступны только для чтения. Пользователи не могут изменять, удалять или создавать таблицы в этой базе данных.

По умолчанию все пользователи имеют права на чтение всех таблиц в этой базе данных, однако результаты запросов зависят от фактических прав пользователя. Например, если пользователь A имеет права только на `db1.table1`, запрос к таблице `information_schema.tables` вернёт только сведения, относящиеся к `db1.table1`.

### mysql {#mysql}

Все таблицы в базе данных `mysql` являются виртуальными и не имеют физического представления. Эти системные таблицы содержат такие сведения, как права доступа, и используются главным образом для обеспечения совместимости с экосистемой MySQL.

В каждом Catalog есть база данных `mysql`, но содержимое её таблиц везде одинаково.

Все таблицы в базе данных `mysql` доступны только для чтения. Пользователи не могут изменять, удалять или создавать таблицы в этой базе данных.

### __internal_schema {#__internal_schema}

Все таблицы в базе данных `__internal_schema` являются реальными таблицами Doris и хранятся так же, как таблицы с данными, созданные пользователями. При создании кластера Doris все системные таблицы в этой базе данных создаются автоматически.

По умолчанию обычные пользователи имеют права только на чтение таблиц в этой базе данных. Однако после предоставления соответствующих прав они могут изменять, удалять или создавать таблицы в этой базе данных.
