# Обзор {#overview}

OPEN API дополняет средства эксплуатации и обслуживания Apache Doris и в основном используется администраторами баз данных для выполнения операций управления.

:::note
В настоящее время OPEN API нестабилен и рекомендуется только для тестирования и использования разработчиками. В последующих версиях мы можем изменить поведение интерфейса.
В производственной среде для выполнения операций рекомендуется использовать команды SQL.
:::

## Аутентификация {#security-certification}

Аутентификацию для API FE и BE можно включить с помощью следующих параметров конфигурации:

| Параметр | Файл конфигурации | Значение по умолчанию | Описание |
| --- | ---| --- | --- |
| `enable_all_http_auth` | `be.conf` | `false` | Включает аутентификацию для HTTP-порта BE (по умолчанию 8040). После включения для доступа к HTTP API BE необходимо войти под учетной записью пользователя с правами ADMIN. |
| `enable_brpc_builtin_services` | `be.conf` | true | Определяет, доступен ли встроенный сервис brpc извне (порт по умолчанию 8060). Если параметр отключен, HTTP-порт 8060 будет недоступен. (Поддерживается начиная с версии 2.1.7) |
| `enable_all_http_auth` | `fe.conf` | `false` | Включает аутентификацию для HTTP-порта FE (по умолчанию 8030). После включения для доступа к HTTP API FE необходимы соответствующие права пользователя. |

:::info ПРИМЕЧАНИЕ
Требования к правам доступа для HTTP API FE и BE различаются в зависимости от версии. Подробности см. в документации соответствующего API.
:::
