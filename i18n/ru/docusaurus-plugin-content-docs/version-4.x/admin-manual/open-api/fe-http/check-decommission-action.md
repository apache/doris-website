# Проверка возможности вывода из эксплуатации {#check-decommission-action}

## Запрос {#request}

`GET /api/check_decommission`

## Описание {#description}

Позволяет определить, можно ли вывести указанный BE из эксплуатации. Например, будут ли оставшиеся узлы после вывода этого узла из эксплуатации удовлетворять требованиям к объёму дискового пространства и количеству реплик.

## Параметры пути {#path-parameters}

Нет

## Параметры запроса {#query-parameters}

* `host_ports`

    Укажите один или несколько BE через запятую. Например: `ip1:port1,ip2:port2,...`.

    Здесь port обозначает порт heartbeat узла BE.

## Тело запроса {#request-body}

Нет

## Ответ {#response}

Возвращает список узлов, которые можно вывести из эксплуатации.

```
{
	"msg": "OK",
	"code": 0,
	"data": ["192.168.10.11:9050", "192.168.10.12:9050"],
	"count": 0
}
```

## Примеры {#examples}

1. Проверка возможности вывода указанного узла BE из эксплуатации

    ```
    GET /api/check_decommission?host_ports=192.168.10.11:9050,192.168.10.12:9050
    
    Response:
    {
    	"msg": "OK",
    	"code": 0,
    	"data": ["192.168.10.11:9050", "192.168.10.12:9050"],
    	"count": 0
    }
    ```
