# Получение состояния загрузки {#get-load-state}

## Запрос {#request}

`GET /api/<db>/get_load_state`

## Описание {#description}

Возвращает состояние транзакции загрузки с указанной меткой.
Состояние указанной транзакции возвращается в виде строки в формате JSON:
	Метка: указанная метка.
	Статус: успешно ли выполнен этот запрос.
	Сообщение: сообщения об ошибках.
	Состояние:
		UNKNOWN/PREPARE/COMMITTED/VISIBLE/ABORTED

## Параметры пути {#path-parameters}

* `<db>`

    Укажите базу данных

## Параметры запроса {#query-parameters}

* `label`

    Укажите метку

## Тело запроса {#request-body}

Отсутствует

## Ответ {#response}

```
{
	"msg": "success",
	"code": 0,
	"data": "VISIBLE",
	"count": 0
}
```

Если метка не существует, возвращается:

```
{
	"msg": "success",
	"code": 0,
	"data": "UNKNOWN",
	"count": 0
}
```

## Примеры {#examples}

1. Получение состояния транзакции загрузки с указанной меткой.

    ```
    GET /api/example_db/get_load_state?label=my_label
    
    {
    	"msg": "success",
    	"code": 0,
    	"data": "VISIBLE",
    	"count": 0
    }
    ```
