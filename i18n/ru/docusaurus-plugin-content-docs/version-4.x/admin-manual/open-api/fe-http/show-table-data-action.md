# Получение объёма данных таблиц {#show-table-data-action}

## Запрос {#request}

`GET /api/show_table_data`

## Описание {#description}

Позволяет получить объём данных всех таблиц во всех базах данных во всех внутренних Catalog либо объём данных указанной базы данных или таблицы. Единица измерения: байт.

## Параметры пути {#path-parameters}

NULL

## Параметры запроса {#query-parameters}

* `db`

    Необязательный параметр. Если указан, возвращается объём данных таблиц в указанной базе данных.

* `table`

    Необязательный параметр. Если указан, возвращается объём данных указанной таблицы.

* `single_replica`

    Необязательный параметр. Если указан, возвращается объём данных одной реплики таблицы.

## Тело запроса {#request-body}

NULL

## Ответ {#response}

1. Объём данных всех таблиц в указанной базе данных.

    ```
    {
        "msg":"success",
        "code":0,
        "data":{
            "tpch":{
                "partsupp":9024548244,
                "revenue0":0,
                "customer":1906421482
            }
        },
        "count":0
    }
    ```
    
2. Объём данных указанной таблицы в указанной базе данных.

    ```
    {
        "msg":"success",
        "code":0,
        "data":{
            "tpch":{
                "partsupp":9024548244
            }
        },
        "count":0
    }
    ```

3. Объём данных одной реплики указанной таблицы в указанной базе данных.

    ```
    {
        "msg":"success",
        "code":0,
        "data":{
            "tpch":{
                "partsupp":3008182748
            }
        },
        "count":0
    }
    ```

    ```
    }
    ```
