# Отмена загрузки {#cancel-load-action}

## Запрос {#request}

`POST /api/<db>/_cancel`

## Описание {#description}

Используется для отмены транзакции загрузки с указанной меткой.
ВОЗВРАЩАЕМЫЕ ЗНАЧЕНИЯ
    Возвращается строка в формате JSON:
    Статус:
        Успех: отмена выполнена успешно
        Другие значения: отмена не удалась
    Сообщение: сообщение об ошибке, если отмена не удалась

## Параметры пути {#path-parameters}

* `<db>`

    Укажите имя базы данных

## Параметры запроса {#query-parameters}

* `<label>`

    Укажите метку загрузки

## Тело запроса {#request-body}

Отсутствует

## Ответ {#response}

* Отмена выполнена успешно

    ```
    {
    	"msg": "OK",
    	"code": 0,
    	"data": null,
    	"count": 0
    }
    ```

* Отмена не удалась

    ```
    {
    	"msg": "Error msg...",
    	"code": 1,
    	"data": null,
    	"count": 0
    }
    ```
    
## Примеры {#examples}

1. Отмена транзакции загрузки с указанной меткой

    ```
    POST /api/example_db/_cancel?label=my_label1

    Response:
    {
    	"msg": "OK",
    	"code": 0,
    	"data": null,
    	"count": 0
    }
    ```
