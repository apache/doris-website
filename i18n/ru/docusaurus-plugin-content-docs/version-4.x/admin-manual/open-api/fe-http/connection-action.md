# Операция с соединением {#connection-action}

## Запрос {#request}

`GET /api/connection`

## Описание {#description}

Возвращает по идентификатору соединения идентификатор запроса, который сейчас выполняется в этом соединении, или последнего завершённого запроса.

Идентификатор соединения можно посмотреть в столбце id в выводе команды MySQL `show processlist;`.

## Параметры пути {#path-parameters}

Нет

## Параметры запроса {#query-parameters}

* `connection_id`

    Идентификатор нужного соединения

## Тело запроса {#request-body}

Отсутствует

## Ответ {#response}

```
{
	"msg": "OK",
	"code": 0,
	"data": {
		"query_id": "b52513ce3f0841ca-9cb4a96a268f2dba"
	},
	"count": 0
}
```

## Примеры {#examples}

1. Получение идентификатора запроса по указанному идентификатору соединения

    ```
    GET /api/connection?connection_id=101
    
    Response:
    {
    	"msg": "OK",
    	"code": 0,
    	"data": {
    		"query_id": "b52513ce3f0841ca-9cb4a96a268f2dba"
    	},
    	"count": 0
    }
    ```
