# Получение объёма данных {#show-data-action}

## Запрос {#request}

`GET /api/show_data`

## Описание {#description}

Используется для получения общего объёма данных кластера или объёма данных указанной базы данных. Объём указывается в байтах.

## Параметры пути {#path-parameters}

Нет

## Параметры запроса {#query-parameters}

* `db`

    Необязательный параметр. Если задан, возвращается объём данных указанной базы данных.

## Тело запроса {#request-body}

Нет

## Ответ {#response}

1. Объём данных указанной базы данных.

    ```
    {
    	"msg": "success",
    	"code": 0,
    	"data": {
    		"default_cluster:db1": 381
    	},
    	"count": 0
    }
    ```
    
2. Общий объём данных

    ```
    {
    	"msg": "success",
    	"code": 0,
    	"data": {
    		"__total_size": 381
    	},
    	"count": 0
    }
    ```
    
## Примеры {#examples}

1. Получение объёма данных указанной базы данных

    ```
    GET /api/show_data?db=db1
    
    Response:
    {
    	"msg": "success",
    	"code": 0,
    	"data": {
    		"default_cluster:db1": 381
    	},
    	"count": 0
    }
    ```

2. Получение общего объёма данных кластера

    ```
    GET /api/show_data
        
    Response:
    {
    	"msg": "success",
    	"code": 0,
    	"data": {
    		"__total_size": 381
    	},
    	"count": 0
    }
    ```
