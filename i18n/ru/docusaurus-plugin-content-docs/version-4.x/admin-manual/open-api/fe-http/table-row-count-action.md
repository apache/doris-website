# Операция получения количества строк в таблице {#table-row-count-action}

## Запрос {#request}

`GET /api/<db>/<table>/_count`

## Описание {#description}

Используется для получения статистики о количестве строк в указанной таблице. Этот интерфейс в настоящее время используется в Spark-Doris-Connector. Spark получает статистику таблицы Doris.

## Параметры пути {#path-parameters}

* `<db>`

    Укажите базу данных

* `<table>`

    Укажите таблицу

## Параметры запроса {#query-parameters}

Нет

## Тело запроса {#request-body}

Нет

## Ответ {#response}

```
{
	"msg": "success",
	"code": 0,
	"data": {
		"size": 1,
		"status": 200
	},
	"count": 0
}
```

Поле `data.size` указывает количество строк в указанной таблице.

## Примеры {#examples}

1. Получение количества строк в указанной таблице.

    ```
    GET /api/db1/tbl1/_count
    
    Response:
    {
    	"msg": "success",
    	"code": 0,
    	"data": {
    		"size": 1,
    		"status": 200
    	},
    	"count": 0
    }
    ```
