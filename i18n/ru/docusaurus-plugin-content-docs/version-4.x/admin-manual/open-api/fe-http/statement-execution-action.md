# Выполнение оператора {#statement-execution-action}


## Запрос {#request}

```
POST /api/query/<ns_name>/<db_name>
```

## Описание {#description}

Эта операция позволяет выполнить оператор и получить результат.

## Параметры пути {#path-parameters}

* `<ns_name>`

    Укажите пространство имён. В настоящее время поддерживается только `default_cluster`.

* `<db_name>`

    Укажите имя базы данных. Эта база данных будет использоваться по умолчанию в текущем сеансе. Если в SQL перед именем таблицы не указано имя базы данных, будет использоваться эта база данных.

## Параметры запроса {#query-parameters}

Нет

## Тело запроса {#request-body}

```
{
    "stmt" : "select * from tbl1"
}
```

* Поле `stmt` содержит конкретный SQL-оператор, который требуется выполнить.

### Ответ {#response}

* Возврат набора результатов

    ```
    {
        "msg": "success",
        "code": 0,
        "data": {
            "type": "result_set",
            "data": [
                [1],
                [2]
            ],
            "meta": [{
                "name": "k1",
                "type": "INT"
            }],
            "status": {},
            "time": 10
        },
        "count": 0
    }
    ```

    * Поле type имеет значение `result_set`, которое означает, что возвращается набор результатов. Результаты необходимо получать и отображать на основе полей meta и data. Поле meta содержит сведения о возвращаемых столбцах. Поле data возвращает строку результата. Типы столбцов в каждой строке следует определять по содержимому поля meta. Поле status возвращает сведения MySQL, например количество строк с предупреждениями, код состояния и т. д. Поле time возвращает время выполнения в миллисекундах.

* Возврат результата выполнения

    ```
    {
        "msg": "success",
        "code": 0,
        "data": {
            "type": "exec_status",
            "status": {}
        },
        "count": 0,
        "time": 10
    }
    ```

    * Поле type имеет значение `exec_status`, которое означает, что возвращается результат выполнения. В настоящее время получение такого результата означает, что оператор выполнен успешно.
