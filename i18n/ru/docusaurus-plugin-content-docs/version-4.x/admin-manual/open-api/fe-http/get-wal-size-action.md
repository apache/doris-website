## Запрос {#request}

`GET fe_host:fe_http_port/api/get_wal_size?host_ports=host1:port1,host2:port2...`

## Описание {#description}

Этот HTTP-интерфейс позволяет получить количество файлов WAL на указанном BE. Если BE не указан, по умолчанию возвращается количество файлов WAL на всех BE.

## Параметры пути {#path-parameters}

Нет

## Параметры запроса {#query-parameters}

* `host_ports`

    IP-адрес и HTTP-порт BE.

## Тело запроса {#request-body}

Нет

## Ответ {#response}

```
{
"msg": "OK",
"code": 0,
"data": ["192.168.10.11:9050:1", "192.168.10.11:9050:0"],
"count": 0
}
```

## Примеры {#examples}

1. Получение количества файлов WAL на всех BE.

    ```
    curl -u root: "127.0.0.1:8038/api/get_wal_size"
    
    Response:
    {
    "msg": "OK",
    "code": 0,
    "data": ["192.168.10.11:9050:1", "192.168.10.11:9050:0"],
    "count": 0
    }
    ```
    
    В возвращаемом результате число после каждого BE обозначает количество файлов WAL на этом BE.

2. Получение количества файлов WAL на указанном BE.

    ```
    curl -u root: "127.0.0.1:8038/api/get_wal_size?host_ports=192.168.10.11:9050"
    
    Response:
    {
    "msg": "OK",
    "code": 0,
    "data": ["192.168.10.11:9050:1"],
    "count": 0
    }
    ```
    
    В возвращаемом результате число после каждого BE обозначает количество файлов WAL на этом BE.
