# Обновление статистики количества строк {#row-count-action}

## Запрос {#request}

`GET /api/rowcount`

## Описание {#description}

Используется для ручного обновления статистики количества строк в указанной таблице. При обновлении статистики количества строк в формате JSON также возвращаются данные о количестве строк в таблице и соответствующем rollup

## Параметры пути {#path-parameters}

Нет

## Параметры запроса {#query-parameters}

* `db`

    Укажите базу данных

* `table`

    Укажите таблицу

## Тело запроса {#request-body}

Нет

## Ответ {#response}

```
{
	"msg": "success",
	"code": 0,
	"data": {
		"tbl1": 10000
	},
	"count": 0
}
```

## Примеры {#examples}

1. Обновление и получение количества строк в указанной таблице

    ```
    GET /api/rowcount?db=example_db&table=tbl1
    
    Response:
    {
    	"msg": "success",
    	"code": 0,
    	"data": {
    		"tbl1": 10000
    	},
    	"count": 0
    }
    ```
