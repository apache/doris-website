# Операция проверки типа хранения {#check-storage-type-action}

## Запрос {#request}

`GET /api/_check_storagetype`

## Описание {#description}

Позволяет проверить, используется ли для таблицы в указанной базе данных строчный формат хранения. (Строчный формат устарел.)

## Параметры пути {#path-parameters}

Нет

## Параметры запроса {#query-parameters}

* `db`

    Укажите базу данных

## Тело запроса {#request-body}

Нет

## Ответ {#response}

```
{
	"msg": "success",
	"code": 0,
	"data": {
		"tbl2": {},
		"tbl1": {}
	},
	"count": 0
}
```

Если после имени таблицы есть содержимое, в нём будет указана базовая таблица или таблица rollup со строчным форматом хранения.

## Примеры {#examples}

1. Проверьте, используется ли для следующей таблицы в указанной базе данных строчный формат хранения

    ```
    GET /api/_check_storagetype
    
    Response:
    {
    	"msg": "success",
    	"code": 0,
    	"data": {
    		"tbl2": {},
    		"tbl1": {}
    	},
    	"count": 0
    }
    ```
