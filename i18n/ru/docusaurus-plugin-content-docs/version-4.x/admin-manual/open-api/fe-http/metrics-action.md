# Получение метрик {#metrics-action}

## Запрос {#request}

`GET /api/metrics`

## Описание {#description}

Используется для получения метрик Doris.

## Параметры пути {#path-parameters}

Нет

## Параметры запроса {#query-parameters}

* `type`

    Необязательный параметр. По умолчанию отображаются все метрики. Возможные значения:
    - `core` Вывод основных метрик
    - `json` Вывод метрик в формате JSON

## Тело запроса {#request-body}

Нет
