На этой странице перечислены параметры Meta Service, добавленные в версии 4.1.5. Пока она не охватывает все параметры. Meta Service использует `doris_cloud.conf`; эти параметры не следует добавлять в файл `fe.conf` для FE или в файл `be.conf` для BE.

## Управление транзакциями {#transaction-management}

### `enable_get_prepare_txn_by_coordinator_by_running_key` {#enable_get_prepare_txn_by_coordinator_by_running_key}

| Характеристика | Значение |
| --- | --- |
| Тип | Boolean |
| По умолчанию | `true` |
| Изменение во время работы | Да |
| Версия | Добавлено в 4.1.5 |

Определяет, как Meta Service ищет подготовленные транзакции, принадлежащие координатору. По умолчанию сервис сначала сканирует индекс выполняющихся транзакций, затем получает сведения о соответствующих транзакциях, что позволяет избежать сканирования всех записей о транзакциях. Установите значение `false`, чтобы сканировать записи со сведениями о транзакциях напрямую. Оба способа используют одинаковые критерии отбора транзакций и возвращают одинаковые результаты. Оставьте значение по умолчанию, если вам не требуется изменить стратегию сканирования.

Чтобы явно задать этот параметр, добавьте следующую строку в файл `doris_cloud.conf` Meta Service:

```properties
enable_get_prepare_txn_by_coordinator_by_running_key = true
```
