# Каталог конфигурации {#config-dir}

Файлы конфигурации FE и BE находятся в каталоге `conf/`. Помимо стандартных fe.conf, be.conf и других файлов, этот каталог также используется для хранения общих файлов конфигурации.

Пользователи могут размещать в нём файлы конфигурации, и система будет автоматически их считывать.

В режиме с разделением вычислений и хранения Meta Service использует отдельный файл `doris_cloud.conf`. См. [Конфигурация Meta Service](./ms-config.md).

## hdfs-site.xml и hive-site.xml {#hdfs-sitexml-and-hive-sitexml}

Для работы некоторых функций Doris требуется доступ к данным в HDFS или к Hive metastore.

При использовании этих функций различные параметры HDFS/Hive можно указать вручную в соответствующем операторе.

Однако таких параметров очень много, и указывать их все вручную неудобно.

Поэтому пользователи могут разместить файл конфигурации HDFS или Hive hdfs-site.xml/hive-site.xml непосредственно в каталоге `conf/`. Doris автоматически считает эти файлы конфигурации.

Параметры, заданные пользователем в команде, переопределяют соответствующие параметры из файла конфигурации.

Таким образом, для доступа к HDFS/Hive пользователям достаточно указать лишь небольшое число параметров.
