Doris предоставляет два взаимодополняющих уровня изоляции ресурсов: физическую изоляцию на уровне узлов и логическую изоляцию внутри одного процесса. Выбирайте подходящий механизм в зависимости от архитектуры развёртывания и требований к изоляции.
