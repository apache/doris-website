<!-- Knowledge type: How-to guide -->
<!-- Applicable scenarios: Data update / Real-time write / Unique model Upsert -->

При работе с хранилищами данных в реальном времени и синхронизации операционных баз данных пользователи часто сталкиваются со следующими проблемами:

- Данные в таблицах бизнес-приложений необходимо постоянно обновлять по первичному ключу (например, при изменении статуса заказа или обновлении профиля пользователя), при этом операция записи должна автоматически определять, нужно ли выполнить «вставку» или «обновление».
- Изменяются лишь некоторые поля (например, обновляется только поле `status` заказа), и каждый раз собирать полную запись нежелательно.

Для этих сценариев модель Unique (с первичным ключом) в Doris поддерживает два способа обновления данных с помощью загрузки: **обновление всей строки** и **частичное обновление столбцов**. В этом документе описано, как использовать оба способа.

## Обновление всей строки {#full-row-update}

<!-- Knowledge type: Capability definition -->

При загрузке данных в модель Unique в Doris используется режим **Upsert**: при записи новых данных Doris автоматически определяет по первичному ключу, нужно ли выполнить «вставку» или «обновление».

| Сценарий | Поведение |
| --- | --- |
| Первичный ключ не существует | Вставка новой строки данных |
| Первичный ключ уже существует | Перезапись существующей строки новыми данными |

Поддерживаются следующие методы загрузки:

- Stream Load
- Broker Load
- Routine Load
- Insert Into

> Обновление всей строки выполняется так же, как загрузка новой записи. Подробные инструкции см. в документации [Загрузка данных](../import/import-way/stream-load-manual.md).

## Частичное обновление столбцов {#partial-column-update}

<!-- Knowledge type: Capability definition -->

Если нужно обновить только некоторые поля, можно воспользоваться частичным обновлением столбцов в модели Unique, чтобы не собирать полную запись. Подробную информацию (включая примеры использования, гибкое частичное обновление столбцов и обработку новых строк) см. в документе [Обновление столбцов](./partial-column-update.md#column-update-on-the-unique-key-model).
