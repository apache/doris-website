Синхронизация изменений схемы OceanBase автоматически переносит изменения столбцов из исходной системы в целевые таблицы Doris во время непрерывной загрузки. Эта возможность доступна только для [OceanBase CDC с автоматическим созданием таблиц](./continuous-load-oceanbase-database.md).

:::caution Экспериментальная функция

Синхронизация изменений схемы OceanBase доступна как экспериментальная функция начиная с Doris 4.1.4 и поддерживает только режим совместимости с MySQL.

:::

OceanBase использует механизм обработки изменений схемы MySQL CDC, поэтому набор поддерживаемых изменений и поведение такие же, как у MySQL.

## Поддерживаемые изменения схемы {#supported-schema-changes}

| Операция OceanBase | Поведение Doris |
| --- | --- |
| `ADD COLUMN` | Добавляет столбец с тем же именем и типом, определяемым по правилам [сопоставления типов данных OceanBase](./data-type-mapping-oceanbase.md), и копирует комментарий к столбцу. Ограничения DEFAULT и `NOT NULL` не копируются, а существующие строки не заполняются значениями нового столбца. Для последующих строк используются фактические значения, которые OceanBase записывает в binlog. |
| `DROP COLUMN` | Удаляет столбец с тем же именем. |

## Что следует учитывать {#considerations}

- Если добавляемый столбец уже существует или удаляемый столбец отсутствует, Doris пропускает операцию, чтобы повторные попытки не приводили к сбою задания.
- Позиции столбцов, заданные с помощью `FIRST` и `AFTER`, не синхронизируются с Doris. Новые столбцы добавляются после существующих столбцов Doris.
- Операции `CHANGE COLUMN`, `MODIFY COLUMN`, `RENAME COLUMN`, изменения DEFAULT и изменения ограничений `NULL` / `NOT NULL` не синхронизируются автоматически.
- Изменения первичного ключа, индексов, секций, имени таблицы и другие изменения схемы на уровне таблицы не синхронизируются автоматически.
- Перед неподдерживаемым изменением схемы приостановите задание непрерывной загрузки, вручную измените целевую таблицу Doris, убедитесь в совместимости обеих схем, а затем возобновите выполнение задания.
- При синхронизации с автоматическим созданием таблиц синхронизация изменений схемы включена по умолчанию. В настоящее время Doris не предоставляет свойства SQL для её отключения.

## Пример {#example}

Добавьте столбец в исходную таблицу OceanBase:

```sql
ALTER TABLE source_db.users ADD COLUMN city VARCHAR(50);
INSERT INTO source_db.users VALUES (2, 'Alice', 'Hangzhou');
```

После обработки заданием инкрементальных данных в целевой таблице Doris появится столбец `city`:

```sql
DESC target_db.users;
```

```text
+-------+--------------+------+-------+---------+-------+
| Field | Type         | Null | Key   | Default | Extra |
+-------+--------------+------+-------+---------+-------+
| id    | int          | No   | true  | NULL    |       |
| name  | varchar(100) | Yes  | false | NULL    | NONE  |
| city  | varchar(50)  | Yes  | false | NULL    | NONE  |
+-------+--------------+------+-------+---------+-------+
```
