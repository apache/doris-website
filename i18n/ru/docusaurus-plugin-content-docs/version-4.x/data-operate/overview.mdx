Apache Doris предоставляет полный набор операций с данными, охватывающий весь путь от загрузки до экспорта. Можно загружать данные из различных источников, обновлять и удалять их с транзакционными гарантиями, а также экспортировать результаты запросов или данные таблиц во внешние системы хранения.

Кроме того, Apache Doris поддерживает непосредственное управление данными таблиц Apache Iceberg, включая ускорение запросов, запись, обновление и удаление. Подробнее см. раздел управления данными в документации Iceberg Catalog.
