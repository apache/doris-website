## Описание {#description}

Этот оператор используется исключительно для проверки на TRUE, FALSE или NULL. Введение в понятие NULL приведено в разделе «Значения NULL».

## Обзор операторов {#operator-introduction}

| Оператор | Назначение | Пример |
| -------------------- | ------------------------------------------------------------ | ------------------------ |
| `x IS [NOT] TRUE` | Проверяет, имеет ли x значение TRUE. Возвращает TRUE, если x имеет значение TRUE, иначе возвращает FALSE. | `SELECT 1 IS NOT TRUE` |
| `x IS [NOT] FALSE` | Проверяет, имеет ли x значение FALSE. Возвращает TRUE, если x имеет значение FALSE, иначе возвращает FALSE. | `SELECT 1 IS NOT FALSE` |
| `x IS [NOT] NULL` | Проверяет, имеет ли x значение NULL. Возвращает TRUE, если x имеет значение NULL, иначе возвращает FALSE. | `SELECT 1 IS NOT NULL` |
