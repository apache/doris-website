## Описание {#description}

Оператор присваивания присваивает выражению слева от оператора значение выражения справа от него. В Doris оператор присваивания можно использовать только в части SET оператора UPDATE и в операторе SET. Подробнее см. описание оператора [UPDATE](../../sql-statements/data-modification/DML/UPDATE.md) и оператора [SET](../../sql-statements/session/variable/SET-VARIABLE.md).

## Операторы {#operators}

| Оператор | Назначение | Пример |
|----------|---------|---------|
| <x> = <y> | Присваивает результат <y> выражению <x>. | `SET enable_profile = true` |
