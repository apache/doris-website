## Описание {#description}

Комментарии упрощают чтение и сопровождение приложения. Например, можно добавить комментарий в оператор, чтобы описать его назначение в приложении. Комментарии в операторах SQL (за исключением HINT) не влияют на выполнение оператора. Подробнее об использовании этой особой формы комментариев с HINT см. в разделе [HINT](../../query-acceleration/tuning/tuning-plan/adjusting-join-shuffle).

В операторах SQL комментарии могут находиться между любыми ключевыми словами, параметрами или знаками препинания. Добавить комментарии в операторы можно двумя способами:

- Многострочные комментарии: начните комментарий с косой черты и звёздочки (`/*`), затем добавьте текст комментария. Этот текст может занимать несколько строк. Завершите комментарий звёздочкой и косой чертой (`*/`). Между символами начала и конца комментария и его текстом не требуются пробелы или переносы строк.
- Однострочные комментарии: начните комментарий с двух дефисов (`--`), затем добавьте текст комментария. Этот текст не может переходить на новую строку. Комментарий заканчивается символом перевода строки.

## Примеры {#examples}

### Многострочный комментарий {#multi-line-comment}

```sql
SELECT /* This is a multi-line comment
          that can span multiple lines */
       column_name
FROM   table_name;
```

### Однострочный комментарий {#single-line-comment}

```sql
SELECT column_name -- This is a single-line comment
FROM   table_name;
```
