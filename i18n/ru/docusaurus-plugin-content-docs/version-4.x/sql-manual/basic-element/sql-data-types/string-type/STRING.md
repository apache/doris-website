## STRING {#string}
### Описание {#description}
Строка переменной длины с мягким ограничением длины по умолчанию в 10485760 байт (10 MiB). Настройте `string_type_length_soft_limit_bytes` на BE, чтобы увеличить этот предел вплоть до 2147483643 байт (приблизительно 2 GiB). STRING можно использовать только в столбцах значений, но не в ключевых столбцах или столбцах партиционирования и бакетирования.

Примечание: строки переменной длины хранятся в кодировке UTF-8, поэтому английские символы обычно занимают 1 байт, а китайские символы занимают 3 байта.
