# TIME {#time}

## Описание {#description}

Тип TIME(p) хранит время, где p — точность в диапазоне `[0, 6]`, а значение по умолчанию — 0. То есть TIME эквивалентен TIME(0).

Диапазон значений — `[-838:59:59.999..., 838:59:59.999...]`, а формат вывода по умолчанию — 'HH:mm:ss.SSS...' После десятичной точки располагается p цифр. Например, диапазон значений TIME(6) — `[-838:59:59.999999, 838:59:59.999999]`.

Тип TIME используется только для промежуточных результатов вычислений. Значения этого типа можно вводить и выводить, но их хранение в столбцах таблиц OLAP **не поддерживается**.

О преобразовании других типов в TIME и допустимых входных значениях см. в разделе [Преобразование в TIME](../conversion/time-conversion.md).

Типы даты и времени не поддерживают прямое применение математических операторов для арифметических операций. При выполнении математических операций типы даты и времени сначала неявно преобразуются в числовые типы, после чего выполняется операция.

## Примеры {#examples}

```sql
select cast('-123:00:02.9' as time);
```

```text
+------------------------------+
| cast('-123:00:02.9' as time) |
+------------------------------+
| -123:00:03                   |
+------------------------------+
```

```sql
select cast('838:59:59.999999' as time(6));
```

```text
+-------------------------------------+
| cast('838:59:59.999999' as time(6)) |
+-------------------------------------+
| 838:59:59.999999                    |
+-------------------------------------+
```
