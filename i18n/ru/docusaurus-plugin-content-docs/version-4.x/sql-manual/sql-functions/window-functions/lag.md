## Описание {#description}

LAG() — оконная функция, которая позволяет получать данные из предыдущих строк без самообъединения. Она извлекает значения из строки, расположенной на N строк раньше текущей строки в пределах раздела.

## Синтаксис {#syntax}

```sql
LAG ( <expr> [, <offset> [, <default> ] ] )
```

## Параметры {#parameters}
| Параметр            | Описание                                                                                           |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| expr                | Выражение, значение которого нужно получить. Поддерживаемые типы: tinyint/smallint/int/bigint/float/double/decimal/string/date/datetime/                                                      |
| offset              | Необязательный параметр типа Bigint. Количество строк для просмотра вперёд. Значение по умолчанию: 1. |
| default             | Необязательный параметр того же типа, что и первый параметр. Значение, возвращаемое, когда смещение выходит за границы окна. Значение по умолчанию: NULL               |

## Возвращаемое значение {#return-value}

Возвращает значение того же типа данных, что и входное выражение.

Вычислите разницу между текущей суммой продаж каждого продавца и его суммой продаж за предыдущий день:

```sql
select stock_symbol, closing_date, closing_price,    
lag(closing_price,1, 0) over (partition by stock_symbol order by closing_date) as "yesterday closing"   
from stock_ticker   
order by closing_date;
```
