## Описание {#description}

ROW_NUMBER() является оконной функцией, которая присваивает каждой строке в пределах раздела уникальный порядковый номер. Нумерация начинается с 1 и продолжается без пропусков. В отличие от RANK() и DENSE_RANK(), ROW_NUMBER() присваивает разные номера даже строкам с одинаковыми значениями, обеспечивая уникальный номер для каждой строки.

## Синтаксис {#syntax}

```sql
ROW_NUMBER()
```

## Возвращаемое значение {#return-value}

Возвращает порядковый номер типа BIGINT. Нумерация начинается с 1 и продолжается без пропусков. Номера уникальны в пределах каждого раздела.

## Примеры {#examples}

<!-- setup-sql
CREATE TABLE int_t (x INT, y INT) DISTRIBUTED BY HASH(x) BUCKETS 1 PROPERTIES("replication_num"="1");
INSERT INTO int_t VALUES (1,1),(1,2),(1,2),(2,1),(2,2),(2,3),(3,1),(3,1),(3,2);
-->

```sql
select x, y, row_number() over(partition by x order by y) as rank from int_t;
```

```text
| --- | --- | ---- |

| 2   | 1   | 1    |
| 2   | 2   | 2    |
| 2   | 3   | 3    |
| 3   | 1   | 1    |
| 3   | 1   | 2    |
| 3   | 2   | 3    |
+-----+-----+------+
```
