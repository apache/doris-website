## Описание {#description}

Функция MAX возвращает максимальное значение выражения, отличное от NULL.

Различия между версиями: в линейке Doris 4.1 начиная с 4.1.5, а также в Doris 4.2 и более поздних версиях элемент `NULL` внутри массива при сравнении считается больше элемента, отличного от `NULL`. В Doris 4.0 и Doris 4.1 до 4.1.5 элемент массива со значением `NULL` считается меньше. Массив, значение которого равно `NULL`, игнорируется во всех этих версиях.

## Синтаксис {#syntax}

```sql
MAX(<expr>)
```

## Параметры {#parameters}

| Параметр | Описание |
| --- | --- |
| `<expr>` | Выражение, значение которого требуется получить. Поддерживаемые типы: String, Time, Date, DateTime, Timestamptz, IPv4, IPv6, TinyInt, SmallInt, Integer, BigInt, LargeInt, Float, Double, Decimal, Array. |

## Возвращаемое значение {#return-value}

Возвращает значение того же типа данных, что и входное выражение.
Если все записи в группе имеют значение NULL, функция возвращает NULL.


:::caution Изменение поведения (4.1.5)

В линейке Doris 4.1 начиная с 4.1.5 элементы NULL внутри сложных значений, таких как массивы, при сравнении считаются больше элементов, отличных от NULL, на той же позиции. Например, `[10, 20, NULL]` больше, чем `[10, 20, 40]`. Это отличается от случая, когда всё выражение равно NULL: такие строки по-прежнему игнорируются. До 4.1.5 при сравнении в агрегатных функциях элементы NULL внутри сложных значений считались меньшими.

:::

## Пример {#example}

```sql
-- setup
create table t1(
        k1 int,
        k_string varchar(100),
        k_decimal decimal(10, 2),
        k_array array<int>
) distributed by hash (k1) buckets 1
properties ("replication_num"="1");
insert into t1 values 
    (1, 'apple', 10.01, [10, 20, 30]),
    (1, 'banana', 20.02, [10, 20]),
    (2, 'orange', 30.03, [10, 20, 40]),
    (2, null, null, [10, 20, null]),
    (3, null, null, null);
```

```text
Table created and data inserted successfully.
```

```sql
select k1, max(k_string) from t1 group by k1 order by k1;
```

Для типа String: возвращает максимальное строковое значение для каждой группы.

```text
+------+---------------+
| k1   | max(k_string) |
+------+---------------+
|    1 | banana        |
|    2 | orange        |
|    3 | NULL          |
+------+---------------+
```

```sql
select k1, max(k_decimal) from t1 group by k1 order by k1;
```

Для типа Decimal: возвращает максимальное десятичное значение высокой точности.

```text
+------+----------------+
| k1   | max(k_decimal) |
+------+----------------+
|    1 |          20.02 |
|    2 |          30.03 |
|    3 |           NULL |
+------+----------------+
```

```sql
select k1, max(k_array) from t1 group by k1 order by k1;
```

Для типа Array: последовательно сравнивает элементы и возвращает максимальное значение массива для каждой группы. Элементы NULL при сравнении считаются больше элементов, отличных от NULL, на той же позиции.

```text
+------+----------------+
| k1   | max(k_array)   |
+------+----------------+
|    1 | [10, 20, 30]   |
|    2 | [10, 20, null] |
|    3 | NULL           |
+------+----------------+
```

```sql
select max(k_string) from t1 where k1 = 3;
```

Если все значения в группе равны NULL, возвращает NULL.

```text
+---------------+
| max(k_string) |
+---------------+
| NULL          |
+---------------+
```

```sql
select max(k_string) from t1;
```

Возвращает максимальное значение среди всех данных.

```text
+---------------+
| max(k_string) |
+---------------+
| orange        |
+---------------+
```
