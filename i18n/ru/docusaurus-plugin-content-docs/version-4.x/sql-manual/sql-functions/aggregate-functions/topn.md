## Описание {#description}

Функция TOPN возвращает N наиболее часто встречающихся значений в указанном столбце. Это функция приближённых вычислений, которая возвращает результаты в порядке убывания количества вхождений.

## Синтаксис {#syntax}

```sql
TOPN(<expr>, <top_num> [, <space_expand_rate>])
```

## Параметры {#parameters}
| Параметр | Описание |
| -- | -- |
| `<expr>` | Столбец или выражение, для которого подсчитывается количество вхождений значений. Поддерживаемые типы: TinyInt, SmallInt, Integer, BigInt, LargeInt, Float, Double, Decimal, Date, Datetime, IPV4, IPV6, String. |
| `<top_num>` | Количество наиболее часто встречающихся значений, которые нужно вернуть. Должно быть положительной константой INT. |
| `<space_expand_rate>` | Необязательная константа INT, по умолчанию 50. При положительном значении во время сериализации промежуточного состояния сохраняется не более `top_num * space_expand_rate` кандидатов; более высокие значения обычно повышают точность. Этот параметр не задаёт жёсткого ограничения на объём памяти для локальной агрегации. В серии Doris 4.1 начиная с версии 4.1.5 при значении 0 или меньше сохраняются все промежуточные кандидаты, при этом итоговый результат по-прежнему содержит не более `top_num` значений. Этот режим может потреблять больше памяти, и на него по-прежнему распространяются ограничения памяти для запроса. |

## Возвращаемое значение {#return-value}

Возвращает строку JSON, содержащую значения и количество их вхождений.
Если в группе нет допустимых данных, возвращает NULL.

## Пример {#example}
```sql
-- setup
CREATE TABLE page_visits (
    page_id INT,
    user_id INT,
    visit_date DATE
) DISTRIBUTED BY HASH(page_id)
PROPERTIES (
    "replication_num" = "1"
);
INSERT INTO page_visits VALUES
(1, 101, '2024-01-01'),
(2, 102, '2024-01-01'),
(1, 103, '2024-01-01'),
(3, 101, '2024-01-01'),
(1, 104, '2024-01-01'),
(2, 105, '2024-01-01'),
(1, 106, '2024-01-01'),
(4, 107, '2024-01-01');
```

```sql
SELECT TOPN(page_id, 3) as top_pages
FROM page_visits;
```

Найти 3 наиболее посещаемые страницы.

```text
+---------------------+
| top_pages           |
+---------------------+
| {"1":4,"2":2,"4":1} |
+---------------------+
```

```sql
SELECT TOPN(page_id, 3) as top_pages
FROM page_visits where page_id is null;
```

```text
+-----------+
| top_pages |
+-----------+
| NULL      |
+-----------+
```

Сохранить все промежуточные кандидаты, но вернуть только наиболее часто встречающееся значение:

```sql
SELECT TOPN(s, 1, 0)
FROM (SELECT 'a' AS s UNION ALL SELECT 'b' UNION ALL SELECT 'a') t;
```

```text
{"a":2}
```
