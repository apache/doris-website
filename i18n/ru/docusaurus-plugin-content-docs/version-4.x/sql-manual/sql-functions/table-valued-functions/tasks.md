## Описание {#description}

Табличная функция, создающая временную таблицу задач, которая позволяет просматривать сведения о задачах, созданных заданиями в текущем кластере Doris.

## Синтаксис {#syntax}
```sql
TASKS(
    "type"="<type>"
)
```

## Параметры {#parameters}
| Параметр     | Описание                                                                                       |
|---------------|---------------------------------------------------------------------------------------------------|
| **`<type>`**  | Тип задачи: <br/> `insert`: задача типа insert into. <br/> `mv`: задача материализованного представления. |


## Возвращаемое значение {#return-value}

Эта табличная функция возвращает ноль или более строк. Сама функция не возвращает NULL. Отдельные поля могут быть пустыми или содержать `NULL` либо `\N`, если соответствующие метаданные задачи недоступны.

-  **`tasks("type"="insert")`**: возвращаемые значения для задач типа insert

   | Имя поля   | Описание                        |
   |--------------|------------------------------------|
   | **TaskId**   | Идентификатор задачи                            |
   | **JobId**    | Идентификатор задания                             |
   | **JobName**  | Имя задания                           |
   | **Label**    | Метка                              |
   | **Status**   | Состояние задачи                        |
   | **ErrorMsg** | Сведения об ошибке задачи          |
   | **CreateTime**| Время создания задачи                |
   | **FinishTime**| Время завершения задачи              |
   | **TrackingUrl**| URL для отслеживания                     |
   | **LoadStatistic**| Статистика загрузки                |
   | **User**     | Пользователь                               |

-  **`tasks("type"="mv")`**: возвращаемые значения для задач типа MV

   | Имя поля | Описание |
   |------------|-------------|
   | **TaskId** | Уникальный идентификатор задачи обновления. При каждом обновлении материализованного представления создаётся новая запись задачи. |
   | **JobId** | Идентификатор задания, создавшего эту задачу. Соответствует `jobs("type"="mv").Id`. |
   | **JobName** | Имя задания, создавшего эту задачу. Соответствует `mv_infos("database"="...").JobName` и `jobs("type"="mv").Name`. |
   | **MvId** | Идентификатор материализованного представления, обновляемого этой задачей. |
   | **MvName** | Имя материализованного представления, обновляемого этой задачей. |
   | **MvDatabaseId** | Идентификатор базы данных, содержащей материализованное представление. |
   | **MvDatabaseName** | Имя базы данных, содержащей материализованное представление. |
   | **Status** | Состояние задачи. Возможные значения: `PENDING` означает, что задача ожидает выполнения; `RUNNING` означает, что задача выполняется; `SUCCESS` означает, что задача успешно завершена; `FAILED` означает, что задача завершилась с ошибкой; `CANCELED` означает, что задача отменена. |
   | **ErrorMsg** | Сообщение об ошибке, если `Status` имеет значение `FAILED` или `CANCELED`. Пустое при успешном завершении задачи. |
   | **CreateTime** | Время создания записи задачи. |
   | **StartTime** | Время начала выполнения задачи. Может содержать `\N`, если задача ещё не запущена. |
   | **FinishTime** | Время завершения задачи. Может содержать `\N`, если задача ещё ожидает выполнения или выполняется. |
   | **DurationMs** | Время выполнения в миллисекундах, вычисляемое как `FinishTime - StartTime`. Может содержать `\N`, если задача ещё не завершена. |
   | **TaskContext** | Строка JSON, описывающая причину запуска задачи и запрос пользователя. Часто используемые поля: `triggerMode`, `partitions` и `isComplete`. Значения `triggerMode`: `MANUAL`, `COMMIT` и `SYSTEM`. |
   | **RefreshMode** | Фактический охват обновления, определённый этой задачей. Возможные значения: `COMPLETE` означает, что обновлены все партиции материализованного представления; `PARTIAL` означает, что обновлены лишь некоторые партиции; `NOT_REFRESH` означает, что ни одна партиция не требовала обновления. |
   | **NeedRefreshPartitions** | Массив JSON с партициями материализованного представления, которые требовали обновления в этой задаче. Пустой массив означает, что ни одна партиция не требовала обновления. |
   | **CompletedPartitions** | Массив JSON с партициями, которые были успешно обновлены. Сравните его с `NeedRefreshPartitions`, чтобы проверить, завершено ли обновление всех требуемых партиций. |
   | **Progress** | Ход обновления в формате `percentage (completed/total)`, например `100.00% (1/1)`. Может содержать `\N`, если нет партиций для обновления. |
   | **LastQueryId** | Идентификатор запроса SQL, выполненного задачей обновления. Используйте этот идентификатор для поиска в журналах FE или BE при диагностике сбоев задач. Может быть пустым, если SQL для обновления не выполнялся. Это поле поддерживается начиная с Doris 3.0.0. |

### Поля задач MV с перечисляемыми значениями {#mv-task-enum-fields}

Следующие поля с перечисляемыми значениями часто используются при проверке задач обновления материализованных представлений:

- `Status`: состояние задачи в её жизненном цикле.
  - `PENDING`: задача создана, но ещё не запущена. Она ожидает планирования или выделения ресурсов.
  - `RUNNING`: задача выполняется.
  - `SUCCESS`: задача успешно завершена.
  - `FAILED`: задача завершилась с ошибкой. Сначала проверьте `ErrorMsg`, затем используйте `LastQueryId` для поиска в журналах, если это поле не пустое.
  - `CANCELED`: задача отменена до завершения.
- `TaskContext.triggerMode`: причина создания задачи.
  - `MANUAL`: создана командой ручного обновления, например `REFRESH MATERIALIZED VIEW`.
  - `COMMIT`: создана из-за изменений данных в связанных базовых таблицах, которые вызвали обновление.
  - `SYSTEM`: создана внутренним действием системы, например при первоначальном построении материализованного представления, созданного с немедленным построением.
- `TaskContext.isComplete`: запрошено ли полное обновление.
  - `true`: запрос предписывает Doris обновить все партиции материализованного представления.
  - `false`: запрос не требует принудительного полного обновления. Doris может определить фактический охват обновления на основе актуальности партиций.
- `RefreshMode`: фактический охват обновления, выбранный задачей после проверки партиций.
  - `COMPLETE`: для обновления выбраны все партиции материализованного представления, принадлежащие MV.
  - `PARTIAL`: для обновления выбраны лишь некоторые партиции материализованного представления.
  - `NOT_REFRESH`: ни одна партиция не требовала обновления. В этом случае `NeedRefreshPartitions` обычно пуст, а `Progress` может содержать `\N`.

:::info Версия

`LastQueryId` поддерживается начиная с Doris 3.0.0. В Doris 2.1.x это поле недоступно.

:::


## Примеры {#examples}

Просмотр последней задачи обновления материализованного представления.

```sql
select *
from tasks("type"="mv")
where MvDatabaseName = "test" and MvName = "mv1"
order by CreateTime desc
limit 1\G
```
```text
*************************** 1. row ***************************
               TaskId: 437156301250803
                JobId: 19508
              JobName: inner_mtmv_19494
                 MvId: 19494
               MvName: mv1
         MvDatabaseId: 16016
       MvDatabaseName: test
               Status: SUCCESS
             ErrorMsg:
           CreateTime: 2025-01-07 22:13:48
            StartTime: 2025-01-07 22:13:48
           FinishTime: 2025-01-07 22:17:45
           DurationMs: 236985
          TaskContext: {"triggerMode":"MANUAL","partitions":[],"isComplete":false}
          RefreshMode: COMPLETE
NeedRefreshPartitions: ["p_20210101_MAXVALUE","p_20200101_20210101"]
  CompletedPartitions: ["p_20210101_MAXVALUE","p_20200101_20210101"]
             Progress: 100.00% (2/2)
          LastQueryId: 7965b4ddce8a4480-8884e9701679c1c4
```

В этом результате:

- `TaskId` идентифицирует это выполнение обновления. При каждом обновлении он отличается.
- `JobId` и `JobName` идентифицируют задание обновления MV. Сведения о задании можно получить запросом `select * from jobs("type"="mv") where Name = "inner_mtmv_19494";`.
- `MvId`, `MvName`, `MvDatabaseId` и `MvDatabaseName` идентифицируют материализованное представление, обновляемое задачей.
- `Status` имеет значение `SUCCESS`, поэтому задача успешно завершена. Если значение равно `FAILED`, сначала проверьте `ErrorMsg`.
- `CreateTime`, `StartTime`, `FinishTime` и `DurationMs` показывают время создания, начала и завершения задачи, а также продолжительность её выполнения.
- `TaskContext` показывает, что задача запущена вручную. `partitions: []` означает, что пользователь не указал список партиций в команде обновления.
- `RefreshMode` имеет значение `COMPLETE`, поэтому эта задача обновила все партиции материализованного представления, требовавшие обновления.
- `NeedRefreshPartitions` содержит две партиции, требовавшие обновления, а `CompletedPartitions` содержит те же две партиции, поэтому обновление всех требуемых партиций завершено.
- `Progress` имеет значение `100.00% (2/2)`, что также означает завершение обновления двух из двух требуемых партиций.
- `LastQueryId` содержит идентификатор запроса SQL для обновления. Используйте его для поиска в журналах Doris, если задача завершается с ошибкой или выполняется медленно.

:::info Примечание

Количество сохраняемых и отображаемых записей задач определяется параметром конфигурации FE `max_persistence_task_count`. Значение по умолчанию — 100. Когда количество записей задач превышает этот предел, старые записи удаляются. Если значение меньше 1, записи задач не сохраняются. После изменения этого параметра перезапустите FE.

:::
