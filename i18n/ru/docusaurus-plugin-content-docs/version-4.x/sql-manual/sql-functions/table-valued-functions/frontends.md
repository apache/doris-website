## Описание {#description}

Табличная функция создаёт временную таблицу frontends, которая позволяет просматривать информацию об узлах FE в текущем кластере Doris.

## Синтаксис {#syntax}
```sql
FRONTENDS()
```

## Требования к правам доступа {#access-control-requirements}

| Привилегия  | Объект | Примечания |
| :--------- |:-------|:------|
| SELECT_PRIV | internal.information_schema | По умолчанию все пользователи имеют права доступа к этой базе данных |

## Возвращаемое значение {#return-value}
| Поле                     | Описание                                                                                                |
|--------------------------|---------------------------------------------------------------------------------------------------------|
| **Name**                 | Уникальное имя узла FE.                                                                                 |
| **Host**                 | IP-адрес или имя хоста узла FE.                                                                          |
| **EditLogPort**          | Порт, используемый для передачи журнала изменений.                                                       |
| **HttpPort**             | HTTP-порт узла FE.                                                                                      |
| **QueryPort**            | Порт, используемый для выполнения запросов на узле FE.                                                   |
| **RpcPort**              | Порт, используемый для обмена данными по RPC.                                                            |
| **ArrowFlightSqlPort**   | Порт Arrow Flight SQL (используется для интеграции с Apache Arrow для высокопроизводительной передачи данных). |
| **Role**                 | Роль узла FE (например, `FOLLOWER`).                                                                     |
| **IsMaster**             | Указывает, является ли узел ведущим (true/false).                                                        |
| **ClusterId**            | Идентификатор кластера, к которому принадлежит узел FE.                                                  |
| **Join**                 | Указывает, входит ли узел FE в состав кластера (true/false).                                             |
| **Alive**                | Указывает, работает ли узел FE (true/false).                                                             |
| **ReplayedJournalId**    | ID последней записи журнала, воспроизведённой узлом FE.                                                  |
| **LastStartTime**        | Временная метка последнего запуска узла FE.                                                             |
| **LastHeartbeat**        | Временная метка последнего сигнала heartbeat, полученного от узла FE.                                    |
| **IsHelper**             | Указывает, является ли узел FE вспомогательным узлом (true/false).                                       |
| **ErrMsg**               | Сообщения об ошибках, полученные от узла FE.                                                             |
| **Version**              | Версия узла FE.                                                                                        |
| **CurrentConnected**     | Указывает, подключён ли узел FE к кластеру в данный момент (Yes/No).                                     |
