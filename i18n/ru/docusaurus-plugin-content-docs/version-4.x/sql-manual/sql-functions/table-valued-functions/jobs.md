## Описание {#description}

Табличная функция, которая создаёт временную таблицу задач для просмотра сведений о заданиях определённого типа.

## Синтаксис {#syntax}

```sql
JOBS(
    "type"="<type>"
)
```

## Параметры {#parameters}
| Параметр     | Описание                                                                                   |
|---------------|-----------------------------------------------------------------------------------------------|
| **`<type>`**  | Тип задания: <br/> `insert`: задание типа Insert into. <br/> `mv`: задание материализованного представления. |



## Возвращаемое значение {#return-value}

Эта табличная функция возвращает ноль или более строк. Сама функция не возвращает NULL. Отдельные поля могут быть пустыми или содержать `NULL`, если соответствующие метаданные недоступны.

-  **`jobs("type"="insert")`** Возвращаемые значения для заданий типа insert

    | Параметр     | Описание                |
    |--------------------|----------------------------|
    | Id                 | Идентификатор задания                     |
    | Name               | Имя задания                   |
    | Definer            | Пользователь, определивший задание                |
    | ExecuteType        | Тип выполнения             |
    | RecurringStrategy  | Правило периодического запуска         |
    | Status             | Статус задания                 |
    | ExecuteSql         | Выполняемый SQL              |
    | CreateTime         | Время создания задания          |
    | SucceedTaskCount   | Количество успешно выполненных задач |
    | FailedTaskCount    | Количество задач, завершившихся с ошибкой     |
    | CanceledTaskCount  | Количество отменённых задач   |
    | Comment            | Комментарий к заданию                |
    | Properties         | Свойства задания. Значение есть только у заданий с `ExecuteType = STREAMING` |
    | CurrentOffset      | Смещение, до которого задание завершило обработку. Значение есть только у заданий с `ExecuteType = STREAMING` |
    | EndOffset          | Наибольшее смещение, полученное заданием из источника данных. Значение есть только у заданий с `ExecuteType = STREAMING` |
    | LoadStatistic      | Статистика загрузки данных для задания |
    | ErrorMsg           | Сообщение об ошибке выполнения задания |
    | JobRuntimeMsg      | Сообщение, формируемое во время выполнения задания |
    | LagBytes           | Объём отставания по журналу на стороне источника в байтах (например, MySQL binlog или PostgreSQL WAL). `-1` означает, что значение в данный момент недоступно, например для источника данных S3 или на этапе создания полного снимка.<br/>**Начиная с 4.1.4**, этот столбец переименован из `Lag` (в секундах) в `LagBytes` (в байтах) |
    | LastSourceEventTimestamp | Метка времени (в секундах Unix) последнего события на стороне источника, соответствующего смещению, зафиксированному заданием. Пустое значение означает, что информация недоступна. **Добавлено в 4.1.4** |
    | LastTaskSuccessTime | Время последнего успешного завершения задачи |


- **`jobs("type"="mv")`** Возвращаемые значения для заданий типа MV

    | Параметр     | Описание                                                 |
    |----------------------|-------------------------------------------------------------|
    | Id                   | Идентификатор задания. Для заданий MV соответствует `tasks("type"="mv").JobId`. |
    | Name                 | Имя задания. Для заданий MV соответствует `mv_infos("database"="...").JobName` и `tasks("type"="mv").JobName`. |
    | MvId                 | Идентификатор материализованного представления, обслуживаемого этим заданием. |
    | MvName               | Имя материализованного представления, обслуживаемого этим заданием. |
    | MvDatabaseId         | Идентификатор базы данных, содержащей материализованное представление. |
    | MvDatabaseName       | Имя базы данных, содержащей материализованное представление. |
    | ExecuteType          | Тип выполнения задания. Для заданий MV возможны значения `MANUAL` и `RECURRING`. `MANUAL` означает, что задачи обновления запускаются вручную, при фиксации транзакции или по внутренним событиям. `RECURRING` означает, что задачи обновления запускаются периодически по расписанию. |
    | RecurringStrategy    | Описание расписания, сформированное на основе `ExecuteType`. `MANUAL TRIGGER` означает, что задание не запускается по таймеру. `EVERY ... STARTS ... [ENDS ...]` означает, что задание запускается периодически. |
    | Status               | Статус задания. Возможные значения: `PENDING` означает, что задание ожидает запуска по расписанию; `RUNNING` означает, что задание может создавать задачи; `PAUSED` означает, что задание приостановлено и его можно возобновить; `STOPPED` означает, что задание остановлено и его нельзя возобновить; `FINISHED` означает, что задание завершено. |
    | CreateTime           | Время создания задания. |

### Поля заданий MV с перечисляемыми значениями {#mv-job-enum-fields}

При проверке заданий обновления материализованных представлений часто используются следующие поля с перечисляемыми значениями:

- `ExecuteType`: способ создания задач обновления заданием.
  - `MANUAL`: задание не запускается по собственному таймеру. Задача создаётся только при запуске обновления вручную, при фиксации транзакции или по инициативе системы.
  - `RECURRING`: задание запускается по расписанию и периодически создаёт задачи обновления.
- `RecurringStrategy`: правило запуска в удобочитаемом виде, сформированное на основе `ExecuteType`.
  - `MANUAL TRIGGER`: задание не запускается периодически по расписанию. Обычно это значение используется, когда `ExecuteType` имеет значение `MANUAL`.
  - `EVERY <interval> <unit> STARTS <time> [ENDS <time>]`: задание запускается периодически по расписанию. Например, `EVERY 10 MINUTE STARTS 2025-01-17 14:42:53`.
- `Status`: текущее состояние самого задания.
  - `PENDING`: задание ожидает запуска по расписанию.
  - `RUNNING`: задание активно и может создавать задачи обновления.
  - `PAUSED`: задание приостановлено. Оно не будет создавать новые задачи обновления до возобновления.
  - `STOPPED`: задание остановлено, и его нельзя возобновить.
  - `FINISHED`: задание завершено. Этот статус редко встречается у долгоживущих заданий обновления MV, но может появляться в общем механизме выполнения заданий.

Каждому материализованному представлению соответствует одно задание обновления, а одно задание обновления может создавать множество задач обновления. Используйте `jobs("type"="mv").Name`, чтобы связать задание с `mv_infos("database"="...").JobName` и `tasks("type"="mv").JobName`.


## Примеры {#examples}

Просмотр задания обновления материализованного представления.

```sql
select *
from jobs("type"="mv")
where MvDatabaseName = "test" and MvName = "mv1"\G
```
```text
*************************** 1. row ***************************
               Id: 19508
             Name: inner_mtmv_19494
             MvId: 19494
           MvName: mv1
     MvDatabaseId: 16016
   MvDatabaseName: test
      ExecuteType: MANUAL
RecurringStrategy: MANUAL TRIGGER
           Status: RUNNING
       CreateTime: 2025-01-07 22:13:31
```

В этом результате:

- `Id` содержит идентификатор задания обновления MV. Это то же значение, что и `JobId` в `tasks("type"="mv")`.
- `Name` содержит имя задания обновления MV. Это то же значение, что и `JobName` в `mv_infos("database"="test")` и `tasks("type"="mv")`.
- `MvId` и `MvName` определяют материализованное представление, обслуживаемое этим заданием.
- `MvDatabaseId` и `MvDatabaseName` определяют базу данных, содержащую материализованное представление.
- `ExecuteType` имеет значение `MANUAL`, поэтому это задание не запускается по собственному таймеру. Задача обновления создаётся при ручном обновлении материализованного представления, обновлении при фиксации транзакции или запуске обновления системой.
- `RecurringStrategy` имеет значение `MANUAL TRIGGER`, что соответствует `ExecuteType = MANUAL`. Для материализованного представления с обновлением по расписанию это поле отображается как `EVERY ... STARTS ...`.
- `Status` имеет значение `RUNNING`, поэтому задание может создавать задачи обновления. Если значение равно `PAUSED`, возобновите задание материализованного представления, прежде чем ожидать появления новых задач.
- `CreateTime` содержит время создания этого задания обновления MV.

Чтобы просмотреть задачи, созданные этим заданием, используйте имя задания:

```sql
select TaskId, JobName, MvName, Status, CreateTime, FinishTime
from tasks("type"="mv")
where JobName = "inner_mtmv_19494"
order by CreateTime desc;
```
```text
+-----------------+------------------+--------+---------+---------------------+---------------------+
| TaskId          | JobName          | MvName | Status  | CreateTime          | FinishTime          |
+-----------------+------------------+--------+---------+---------------------+---------------------+
| 437156301250803 | inner_mtmv_19494 | mv1    | SUCCESS | 2025-01-07 22:13:48 | 2025-01-07 22:17:45 |
+-----------------+------------------+--------+---------+---------------------+---------------------+
```
