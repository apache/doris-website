## Описание {#description}

Вычисление 256-битного хеша SM3 для нескольких строк

## Синтаксис {#syntax}

```sql
SM3SUM( <str> [ , <str> ... ] )
```

## Параметры {#parameters}

| параметр | описание |
|-----------|-------------|
| `<str>`   | Значение, для которого необходимо вычислить sm3   |

## Возвращаемое значение {#return-value}

Возвращает значение sm3 для нескольких входных строк

## Примеры {#examples}

```sql
select sm3sum("ab","cd");
```

```text
+------------------------------------------------------------------+
| sm3sum('ab', 'cd')                                               |
+------------------------------------------------------------------+
| 82ec580fe6d36ae4f81cae3c73f4a5b3b5a09c943172dc9053c69fd8e18dca1e |
+------------------------------------------------------------------+
```
