## Описание {#description}

Вычисление 64-битного хеш-значения murmur3

Отличие от `MURMUR_HASH3_64_V2`: эта версия специально оптимизирована для 64-битного результата и работает немного быстрее версии v2, однако её результаты не совпадают с результатами реализации из [стандартной библиотеки](https://mmh3.readthedocs.io/en/latest/api.html#mmh3.hash64).

- Примечание: тестирование показало, что производительность `xxhash_64` примерно вдвое выше, чем у `murmur_hash3_64`, поэтому для вычисления хеш-значений рекомендуется использовать `xxhash_64` вместо `murmur_hash3_64`.


## Синтаксис {#syntax}

```sql
MURMUR_HASH3_64( <str> [ , <str> ... ] )
```

## Параметры {#parameters}

| параметр      | описание                                             |
|---------|------------------------------------------------|
| `<str>` | 64-битное хеш-значение murmur3, которое требуется вычислить |

## Возвращаемое значение {#return-value}

Возвращает 64-битное хеш-значение murmur3 для входной строки.

Возвращает NULL, если хотя бы один входной параметр равен NULL.

## Примеры {#examples}

```sql
select murmur_hash3_64(null), murmur_hash3_64("hello"), murmur_hash3_64("hello", "world");
```

```text
+-----------------------+--------------------------+-----------------------------------+
| murmur_hash3_64(NULL) | murmur_hash3_64('hello') | murmur_hash3_64('hello', 'world') |
+-----------------------+--------------------------+-----------------------------------+
|                  NULL |     -3215607508166160593 |               3583109472027628045 |
+-----------------------+--------------------------+-----------------------------------+
```
