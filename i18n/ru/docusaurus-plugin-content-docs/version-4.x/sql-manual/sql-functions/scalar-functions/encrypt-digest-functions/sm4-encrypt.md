## Описание {#description}

SM4 представляет собой алгоритм шифрования с симметричным ключом, принятый в качестве национального стандарта и широко используемый в финансах, связи, электронной коммерции и других областях. Функция SM4_ENCRYPT используется для шифрования данных с помощью SM4. По умолчанию используется алгоритм `SM4_128_ECB`.

## Синтаксис {#syntax}

```sql
SM4_ENCRYPT( <str>, <key_str>[, <init_vector>][, <encryption_mode>])
```

## Параметры {#parameters}

| параметр            | описание                                                                                                                                                                                            |
|---------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<str>`             | Текст для шифрования                                                                                                                                                                                              |
| `<key_str>`         | Ключ. Обратите внимание, что ключ задаётся не в шестнадцатеричной кодировке, а в виде закодированной строки. Например, для шифрования с 128-битным ключом длина `key_str` должна составлять 16. Если длина ключа недостаточна, используйте **дополнение нулями** до нужной длины. Если длина превышает требуемую, используйте циклический XOR для получения итогового ключа. Например, если алгоритм использует 128-битный ключ `key`, то `key[i] = key_str[i] ^ key_str[i+128] ^ key_str[i+256] ^ ...` |
| `<init_vector>`     | Вектор инициализации, используемый в алгоритме. Применяется только в определённых алгоритмах. Если он не указан, Doris использует встроенный вектор                                                                                                                                                          |
| `<encryption_mode>` | Алгоритм шифрования. Допустимые значения указаны в переменных                                                                                                                                                                                       |


## Возвращаемое значение {#return-value}

Возвращает зашифрованные двоичные данные

## Примеры {#examples}

Использование алгоритма по умолчанию
```sql
set block_encryption_mode='';
select TO_BASE64(SM4_ENCRYPT('text','F3229A0B371ED2D9441B830D21A390C3'));
```

```text
+----------------------------------------------------------+
| to_base64(sm4_encrypt('text', '***', '', 'SM4_128_ECB')) |
+----------------------------------------------------------+
| aDjwRflBrDjhBZIOFNw3Tg==                                 |
+----------------------------------------------------------+
```

Использование алгоритма SM4_128_CBC
```sql
set block_encryption_mode="SM4_128_CBC";
select TO_BASE64(SM4_ENCRYPT('text','F3229A0B371ED2D9441B830D21A390C3'));
```

```text
+----------------------------------------------------------+
| to_base64(sm4_encrypt('text', '***', '', 'SM4_128_CBC')) |
+----------------------------------------------------------+
| FSYstvOmH2cXy7B/072Mug==                                 |
+----------------------------------------------------------+
```

Использование алгоритма SM4_128_CBC с заданным вектором инициализации
```sql
set block_encryption_mode="SM4_128_CBC";
select to_base64(SM4_ENCRYPT('text','F3229A0B371ED2D9441B830D21A390C3', '0123456789'));
```
```text
+--------------------------------------------------------------------+
| to_base64(sm4_encrypt('text', '***', '0123456789', 'SM4_128_CBC')) |
+--------------------------------------------------------------------+
| 1Y4NGIukSbv9OrkZnRD1bQ==                                           |
+--------------------------------------------------------------------+
```
