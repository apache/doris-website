## Описание {#description}

Используйте CRC32 для вычисления результата.

## Синтаксис {#syntax}
```sql
CRC32( <str> )
```
## Параметры {#parameters}

| параметр | описание |
| -- | -- |
| `<str>` | Значение, используемое для вычисления CRC |

## Возвращаемое значение {#return-value}

Возвращает значение циклического избыточного кода для этой строки.

## Примеры {#examples}

```sql
select crc32("abc"),crc32("中国");
```
```text
+--------------+-----------------+
| crc32('abc') | crc32('中国')   |
+--------------+-----------------+
|    891568578 |       737014929 |
+--------------+-----------------+
```
