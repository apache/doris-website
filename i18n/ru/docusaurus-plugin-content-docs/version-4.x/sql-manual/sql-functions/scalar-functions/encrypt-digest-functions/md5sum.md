## Описание {#description}

Вычисляет 128-битную контрольную сумму MD5 для строк

## Синтаксис {#syntax}

```sql
MD5SUM( <str> [ , <str> ... ] )
```

## Параметры {#parameters}

|  параметр | описание |
|---------| -- |
| `<str>` | Значение, для которого вычисляется MD5 |

## Возвращаемое значение {#return-value}

Возвращает значение MD5 для нескольких строк

## Примеры {#examples}

```sql
select md5("abcd"),md5sum("ab","cd");
```

```text
+----------------------------------+----------------------------------+
| md5('abcd')                      | md5sum('ab', 'cd')               |
+----------------------------------+----------------------------------+
| e2fc714c4727ee9395f324cd2e7f331f | e2fc714c4727ee9395f324cd2e7f331f |
+----------------------------------+----------------------------------+
```
