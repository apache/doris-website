## Описание {#description}
Принимает строковое представление адреса IPv4 и возвращает значение типа IPv4. Если входное значение некорректно или равно NULL, возвращает значение по умолчанию `0.0.0.0`.

## Синтаксис {#syntax}
```sql
TO_IPV4_OR_DEFAULT(<ipv4_str>)
```

### Параметры {#parameters}
- `<ipv4_str>`: адрес IPv4 в виде строки

### Возвращаемое значение {#return-value}
Тип возвращаемого значения: IPv4

Описание возвращаемого значения:
- Возвращает значение типа IPv4, двоичное представление которого эквивалентно возвращаемому значению `ipv4_string_to_num`
- Возвращает `0.0.0.0`, если входное значение равно NULL или содержит некорректный адрес IPv4

### Примечания по использованию {#usage-notes}
- Эквивалентно `to_ipv4_or_default` → тип `IPv4`; подходит для сценариев, в которых таблицы создаются со столбцами типа `IPv4`
- При некорректных входных данных не вызывает исключений, а возвращает значение по умолчанию `0.0.0.0`

## Примеры {#examples}

Преобразование строкового представления адреса IPv4 `255.255.255.255` в тип `IPv4`.
```sql
SELECT to_ipv4_or_default('255.255.255.255') as v4;
+-----------------+
| v4              |
+-----------------+
| 255.255.255.255 |
+-----------------+
```

При входном значении NULL возвращается значение по умолчанию `0.0.0.0`.
```sql
SELECT to_ipv4_or_default(NULL) as v4;
+---------+
| v4      |
+---------+
| 0.0.0.0 |
+---------+
```

При некорректном строковом представлении адреса IPv4 возвращается значение по умолчанию `0.0.0.0`.
```sql
SELECT to_ipv4_or_default('256.1.1.1') as v4;
+---------+
| v4      |
+---------+
| 0.0.0.0 |
+---------+
```
