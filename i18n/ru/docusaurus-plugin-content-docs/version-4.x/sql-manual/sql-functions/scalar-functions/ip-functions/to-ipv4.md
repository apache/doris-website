## Описание {#description}
Принимает IPv4-адрес в строковом представлении и возвращает значение типа IPv4.

## Синтаксис {#syntax}
```sql
TO_IPV4(<ipv4_str>)
```

### Параметры {#parameters}
- `<ipv4_str>`: IPv4-адрес типа String

### Возвращаемое значение {#return-value}
Тип возвращаемого значения: IPv4

Описание возвращаемого значения:
- Возвращает значение типа IPv4, двоичное представление которого эквивалентно результату `ipv4_string_to_num`
- Вызывает исключение, если входное значение равно NULL
- Вызывает исключение при недопустимом IPv4-адресе или входном значении `NULL`

### Примечания по использованию {#usage-notes}
- Эквивалентно преобразованию `to_ipv4` → `IPv4`; подходит для случаев, когда таблицы создаются со столбцами типа `IPv4`

## Примеры {#examples}

Преобразование IPv4-адреса в текстовом представлении `255.255.255.255` в тип `IPv4`.
```sql
SELECT to_ipv4('255.255.255.255') as v4;
+-----------------+
| v4              |
+-----------------+
| 255.255.255.255 |
+-----------------+
```

Входное значение NULL вызывает исключение
```sql
SELECT to_ipv4(NULL);
ERROR 1105 (HY000): errCode = 2, detailMessage = (...)[INVALID_ARGUMENT]The arguments of function to_ipv4 must be String, not NULL
```

Недопустимый IPv4-адрес в текстовом представлении вызывает исключение.
```sql
SELECT to_ipv4('256.1.1.1');
ERROR 1105 (HY000): errCode = 2, detailMessage = (...)[INVALID_ARGUMENT]Invalid IPv4 value '256.1.1.1'
```
