## Описание {#description}
Проверяет, соответствует ли входная строка формату корректного IPv4-адреса. Возвращает 1, если это корректный IPv4-адрес, и 0 в противном случае.

## Псевдоним {#alias}
- IS_IPV4

## Синтаксис {#syntax}
```sql
IS_IPV4_STRING(<ipv4_str>)
```

### Параметры {#parameters}
- `<ipv4_str>`: Строка для проверки

### Возвращаемое значение {#return-value}
Тип возвращаемого значения: BOOLEAN

Значение результата:
- Возвращает 1: входная строка соответствует формату корректного IPv4-адреса
- Возвращает 0: входная строка не соответствует формату корректного IPv4-адреса
- Возвращает NULL, если входное значение равно NULL

### Примечания по использованию {#usage-notes}
- Проверяет только соответствие формата строки спецификации IPv4-адресов (формат A.B.C.D)
- Не выполняет фактическое преобразование IP-адреса, а только проверяет формат
- Поддерживает входное значение NULL и возвращает NULL

## Примеры {#examples}

Проверка корректного формата IPv4-адреса.
```sql
SELECT is_ipv4_string('192.168.1.1') as is_valid;
+----------+
| is_valid |
+----------+
| 1        |
+----------+
```

Проверка IPv4-адресов с граничными значениями.
```sql
SELECT 
  is_ipv4_string('0.0.0.0') as min_ip,
  is_ipv4_string('255.255.255.255') as max_ip;
+--------+--------+
| min_ip | max_ip |
+--------+--------+
| 1      | 1      |
+--------+--------+
```

Проверка некорректных форматов IPv4-адресов.
```sql
SELECT 
  is_ipv4_string('256.1.1.1') as invalid_range,
  is_ipv4_string('192.168.1') as missing_octet,
  is_ipv4_string('192.168.1.1.1') as extra_octet,
  is_ipv4_string('not-an-ip') as not_ip;
+---------------+----------------+--------------+--------+
| invalid_range | missing_octet | extra_octet | not_ip |
+---------------+----------------+--------------+--------+
| 0             | 0              | 0            | 0      |
+---------------+----------------+--------------+--------+
```

Проверка входного значения NULL.
```sql
SELECT is_ipv4_string(NULL) as null_check;
+------------+
| null_check |
+------------+
| NULL       |
+------------+
```
