# Обзор условных функций {#conditional-functions-overview}

Условные функции — это встроенные функции для реализации условной логики и ветвления в SQL-запросах. Они позволяют выполнять различные операции в зависимости от заданных условий, например выбирать значения, обрабатывать значения NULL и реализовывать логику выбора по нескольким условиям.

## Векторизованное выполнение и условные функции {#vectorized-execution-and-conditional-functions}

Doris — это движок с векторизованным выполнением. Однако поведение условных функций может показаться неожиданным.

Рассмотрим следующий пример:

```sql
mysql> set enable_strict_cast = true;
Query OK, 0 rows affected (0.00 sec)

mysql> select count(
    ->     if(number < 128 , 
    ->       cast(number as tinyint), 
    ->       cast(number as String))
    ->   ) from numbers("number" = "300");
ERROR 1105 (HY000): errCode = 2, detailMessage = (127.0.0.1)[INVALID_ARGUMENT]Value 128 out of range for type tinyint
```

В этом примере ошибка возникает, хотя приведение к `tinyint` в функции `number < 128` выполняется только при выполнении условия `if`.

Это связано с тем, как традиционно выполнялись условные функции, такие как `if(cond, colA, colB)`:

1. Сначала полностью вычисляются оба выражения: `colA` и `colB`
2. Затем на основе значения `cond` выбирается и возвращается соответствующий результат

Поэтому, даже если значение `colA` на практике не используется, полное вычисление `colA` всё равно приведёт к ошибке.

Функции `if`, `ifnull`, `case` и `coalesce` ведут себя аналогичным образом.

Обратите внимание, что у таких функций, как `LEAST`, этой проблемы нет, поскольку для сравнения значений им в любом случае необходимо вычислить все параметры.

## Вычисление по короткой схеме {#short-circuit-evaluation}

В Doris 4.0.4 мы улучшили логику выполнения условных функций, добавив поддержку вычисления по короткой схеме.

```sql
mysql> set short_circuit_evaluation = true;
Query OK, 0 rows affected (0.00 sec)

mysql> select count(
    ->     if(number < 128 , 
    ->       cast(number as tinyint), 
    ->       cast(number as String))
    ->   ) from numbers("number" = "300");
+--------------------------------------------------------------------------+
| count(if(number < 128, cast(number as tinyint), cast(number as String))) |
+--------------------------------------------------------------------------+
|                                                                      300 |
+--------------------------------------------------------------------------+
```

При включённом вычислении по короткой схеме такие функции, как `if`, `ifnull`, `case` и `coalesce`, во многих случаях позволяют избежать ненужных вычислений, предотвращая ошибки и повышая производительность.

### Включение вычисления по короткой схеме {#enabling-short-circuit-evaluation}

Чтобы включить вычисление по короткой схеме, задайте переменную сеанса:

```sql
SET short_circuit_evaluation = true;
```

### Преимущества вычисления по короткой схеме {#benefits-of-short-circuit-evaluation}

1. **Предотвращение ошибок**: ветви, которые могли бы вызвать ошибки, не выполняются, если условия исключают их выполнение
2. **Повышение производительности**: вычисляются только действительно необходимые ветви, что сокращает объём ненужных вычислений
3. **Более интуитивное поведение**: поведение условных функций становится ближе к поведению условных конструкций в традиционных языках программирования

## Распространённые условные функции {#common-conditional-functions}

К распространённым условным функциям, для которых полезно вычисление по короткой схеме, относятся:

- `IF`: возвращает одно из двух значений в зависимости от условия
- `IFNULL`: возвращает первый аргумент, если он не равен NULL, иначе возвращает второй аргумент
- `CASE`: предоставляет несколько условных ветвей, аналогично конструкциям switch-case
- `COALESCE`: возвращает первое значение из списка аргументов, отличное от NULL
- `NULLIF`: возвращает NULL, если два аргумента равны, иначе возвращает первый аргумент

Подробные сведения о каждой функции приведены на соответствующих страницах документации.
