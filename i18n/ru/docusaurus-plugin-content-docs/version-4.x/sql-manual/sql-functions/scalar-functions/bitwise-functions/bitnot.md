## Описание {#description}
Выполняет побитовую операцию NOT над целым числом.

Поддерживаемые целочисленные типы: TINYINT, SMALLINT, INT, BIGINT, LARGEINT.

## Синтаксис {#syntax}
```sql
BITNOT(<x>)
```

## Параметры {#parameters}
- `<x>`: Целое число, над которым выполняется операция.

## Возвращаемое значение {#return-value}
Возвращает результат побитовой операции NOT над целым числом.

## Примеры {#examples}
1. Пример 1
    ```sql
    select BITNOT(7), BITNOT(-127);
    ```
    ```text
    +-----------+--------------+
    | BITNOT(7) | BITNOT(-127) |
    +-----------+--------------+
    |        -8 |          126 |
    +-----------+--------------+
    ```
2. Аргумент со значением NULL
    ```sql
    select BITNOT(NULL);
    ```
    ```text
    +--------------+
    | BITNOT(NULL) |
    +--------------+
    |         NULL |
    +--------------+
    ```
