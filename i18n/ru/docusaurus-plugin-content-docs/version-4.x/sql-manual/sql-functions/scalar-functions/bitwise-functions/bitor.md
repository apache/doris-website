## Описание {#description}
Выполняет побитовую операцию OR над двумя целыми числами.

Поддерживаемые целочисленные типы: TINYINT, SMALLINT, INT, BIGINT, LARGEINT

## Синтаксис {#syntax}
```sql
BITOR(<lhs>, <rhs>)
```

## Параметры {#parameters}
- `<lhs>`: Первое целое число для операции.
- `<rhs>`: Второе целое число для операции.

## Возвращаемое значение {#return-value}

Возвращает результат побитовой операции OR над двумя целыми числами.

## Примеры {#examples}
1. Пример 1
    ```sql
    select BITOR(3,5), BITOR(4,7);
    ```
    ```text
    +------------+------------+
    | BITOR(3,5) | BITOR(4,7) |
    +------------+------------+
    |          7 |          7 |
    +------------+------------+
    ```
2. Аргумент NULL
    ```sql
    select BITOR(3, NULL), BITOR(NULL, 5), BITOR(NULL, NULL);
    ```
    ```text
    +----------------+----------------+-------------------+
    | BITOR(3, NULL) | BITOR(NULL, 5) | BITOR(NULL, NULL) |
    +----------------+----------------+-------------------+
    |           NULL |           NULL |              NULL |
    +----------------+----------------+-------------------+
    ```
