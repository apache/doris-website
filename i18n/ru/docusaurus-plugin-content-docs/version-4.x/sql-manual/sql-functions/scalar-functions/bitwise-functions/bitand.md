## Описание {#description}
Выполняет побитовую операцию AND. При побитовой операции AND сравниваются соответствующие биты двух целых чисел; результат равен 1, только если оба соответствующих бита равны 1, иначе результат равен 0.

Поддерживаемые целочисленные типы: TINYINT, SMALLINT, INT, BIGINT, LARGEINT

## Синтаксис {#syntax}
```sql
BITAND(<lhs>, <rhs>)
```

## Параметры {#parameters}
- `<lhs>`: Первое целое число для побитовой операции AND.
- `<rhs>`: Второе целое число для побитовой операции AND.

## Возвращаемое значение {#return-value}
Возвращает результат побитовой операции AND над двумя целыми числами.


## Примеры {#examples}
1. Пример 1
    ```sql
    select BITAND(3,5), BITAND(5, 10), BITAND(7, 10);
    ```
    ```text
    +-------------+---------------+---------------+
    | BITAND(3,5) | BITAND(5, 10) | BITAND(7, 10) |
    +-------------+---------------+---------------+
    |           1 |             0 |             2 |
    +-------------+---------------+---------------+
    ```
2. Аргумент NULL
    ```sql
    select BITAND(1, null), BITAND(null, 1), BITAND(null, null);
    ```
    ```text
    +-----------------+-----------------+--------------------+
    | BITAND(1, null) | BITAND(null, 1) | BITAND(null, null) |
    +-----------------+-----------------+--------------------+
    |            NULL |            NULL |               NULL |
    +-----------------+-----------------+--------------------+
    ```
