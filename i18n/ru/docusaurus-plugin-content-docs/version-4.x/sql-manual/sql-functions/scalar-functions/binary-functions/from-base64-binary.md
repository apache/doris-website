## Описание {#description}

Функция FROM_BASE64_BINARY декодирует строку в кодировке Base64 и возвращает результат в виде значения VARBINARY.

Особые случаи:

- Если входная строка не является допустимой строкой в кодировке Base64, функция возвращает NULL.

## Синтаксис {#syntax}

```sql
FROM_BASE64_BINARY ( <str> )
```

## Параметры {#parameters}

| Параметр  | Описание                                               |
| --------- | ------------------------------------------------------ |
| `<str>`   | Строка в кодировке Base64, которую нужно декодировать.   |

## Возвращаемое значение {#return-value}

Значение параметра `<str>`, декодированное из Base64, в виде результата типа VARBINARY.

Особые случаи:

- Если входная строка недопустима (содержит символы, не входящие в алфавит Base64), функция возвращает NULL.

## Пример {#example}

```sql
SELECT FROM_BASE64_BINARY('MQ==');
```

```text
+--------------------------------------------------------+
| FROM_BASE64_BINARY('MQ==')                             |
+--------------------------------------------------------+
| 0x31                                                   |
+--------------------------------------------------------+
```

```sql
SELECT FROM_BASE64_BINARY('MjM0');
```

```text
+--------------------------------------------------------+
| FROM_BASE64_BINARY('MjM0')                             |
+--------------------------------------------------------+
| 0x323334                                               |
+--------------------------------------------------------+
```

```sql
SELECT FROM_BASE64_BINARY(NULL);
```

```text
+----------------------------------------------------+
| FROM_BASE64_BINARY(NULL)                           |
+----------------------------------------------------+
| NULL                                               |
+----------------------------------------------------+
```
