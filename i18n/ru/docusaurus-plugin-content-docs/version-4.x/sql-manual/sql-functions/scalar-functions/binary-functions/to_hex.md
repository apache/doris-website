## Описание {#description}

Преобразует входную строку в соответствующую последовательность байтов в шестнадцатеричном представлении.

## Псевдоним {#alias}

TO_BINARY

## Синтаксис {#syntax}

```sql
TO_HEX(<str>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<str>` | Строковые данные для преобразования |

## Возвращаемое значение {#return-value}

Возвращает декодированное значение VARBINARY (отображается в шестнадцатеричном формате с префиксом 0x).
Возвращает NULL, если выполняется любое из следующих условий:
Входное значение равно NULL;
Длина входного значения равна 0;
Длина входного значения нечётная;
Входное значение содержит символы, не входящие в набор [0-9a-fA-F];
Длина декодированного результата равна 0 (ошибка декодирования).

## Примеры {#examples}

```sql
select to_hex(NULL),to_hex('a');
```

```text
+----------------------------+--------------------------+
| to_hex(NULL)               | to_hex('a')              |
+----------------------------+--------------------------+
| NULL                       | NULL                     |
+----------------------------+--------------------------+
```

```sql
select to_hex('ab');
```

```text
+----------------------------+
| to_hex('ab')               |
+----------------------------+
| 0xAB                       |
+----------------------------+
```

```sql
select to_hex('000A');
```

```text
+--------------------------------+
| to_hex('000A')                 |
+--------------------------------+
| 0x000A                         |
+--------------------------------+
```
