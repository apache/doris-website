## Описание {#description}

Функция CONCAT_WS (конкатенация с разделителем) объединяет несколько строк или массивов с помощью указанного разделителя. В отличие от функции CONCAT, CONCAT_WS автоматически пропускает значения NULL (но не пустые строки) и вставляет разделитель между значениями, отличными от NULL. Функция поддерживает режимы со строковыми аргументами и с аргументами в виде массивов и удобна для формирования данных в формате CSV, объединения частей пути и создания списков тегов.

## Синтаксис {#syntax}

```sql
-- String mode
CONCAT_WS(<sep>, <str> [, <str> ...])

-- Array mode  
CONCAT_WS(<sep>, <array> [, <array> ...])
```

## Параметры {#parameters}

| Параметр    | Описание              |
|-------|-----------------|
| `<sep>` | Строка-разделитель для объединения частей. Тип: VARCHAR |
| `<str>` | Строковые аргументы для объединения. Тип: VARCHAR |
| `<array>` | Аргументы в виде массивов для объединения; элементы массивов должны быть строкового типа. Тип: ARRAY&lt;VARCHAR&gt; |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее собой строку, объединённую с помощью разделителей.

Правила объединения:
- Первый аргумент используется как разделитель при объединении последующих аргументов
- Значения NULL автоматически пропускаются, а пустые строки сохраняются
- Поддерживаются строковые аргументы или аргументы в виде массивов, но смешивать их нельзя
- Поддерживаются многобайтовые символы UTF-8 в разделителях и содержимом

Особые случаи:
- Если разделитель равен NULL, возвращается NULL
- Если все объединяемые аргументы равны NULL, возвращается пустая строка
- В режиме массивов элементы NULL пропускаются, а элементы с пустыми строками сохраняются
- Если среди нескольких переданных массивов есть массивы со значением NULL, возвращается пустая строка
- Смешивать строковые аргументы и аргументы в виде массивов не допускается

## Примеры {#examples}

1. Простое объединение строк
```sql
SELECT CONCAT_WS(',', 'apple', 'banana', 'orange'), CONCAT_WS('-', 'hello', 'world');
```
```text
+-------------------------------------------+----------------------------------+
| CONCAT_WS(',', 'apple', 'banana', 'orange') | CONCAT_WS('-', 'hello', 'world') |
+-------------------------------------------+----------------------------------+
| apple,banana,orange                       | hello-world                      |
+-------------------------------------------+----------------------------------+
```

2. Обработка разделителя NULL
```sql
SELECT CONCAT_WS(NULL, 'd', 'is'), CONCAT_WS('or', 'd', NULL, 'is');
```
```text
+----------------------------+----------------------------------+
| CONCAT_WS(NULL, 'd', 'is') | CONCAT_WS('or', 'd', NULL, 'is') |
+----------------------------+----------------------------------+
| NULL                       | doris                            |
+----------------------------+----------------------------------+
```

3. Обработка пустых строк (пустые строки сохраняются)
```sql
SELECT CONCAT_WS('|', 'hello', '', 'world', NULL), CONCAT_WS(',', '', 'test', '');
```
```text
+--------------------------------------------+-------------------------------+
| CONCAT_WS('|', 'hello', '', 'world', NULL) | CONCAT_WS(',', '', 'test', '') |
+--------------------------------------------+-------------------------------+
| hello||world                               | ,test,                        |
+--------------------------------------------+-------------------------------+
```

4. Все значения равны NULL
```sql
SELECT CONCAT_WS('x', NULL, NULL), CONCAT_WS('-', NULL, NULL, NULL);
```
```text
+----------------------------+---------------------------------+
| CONCAT_WS('x', NULL, NULL) | CONCAT_WS('-', NULL, NULL, NULL) |
+----------------------------+---------------------------------+
|                            |                                 |
+----------------------------+---------------------------------+
```

5. Основы использования режима массивов
```sql
SELECT CONCAT_WS('or', ['d', 'is']), CONCAT_WS('-', ['apple', 'banana', 'cherry']);
```
```text
+------------------------------+--------------------------------------------+
| CONCAT_WS('or', ['d', 'is']) | CONCAT_WS('-', ['apple', 'banana', 'cherry']) |
+------------------------------+--------------------------------------------+
| doris                        | apple-banana-cherry                        |
+------------------------------+--------------------------------------------+
```

6. Значения NULL в массивах
```sql
SELECT CONCAT_WS('or', ['d', NULL, 'is']), CONCAT_WS(',', [NULL, 'a', 'b', NULL, 'c']);
```
```text
+------------------------------------+------------------------------------------+
| CONCAT_WS('or', ['d', NULL, 'is']) | CONCAT_WS(',', [NULL, 'a', 'b', NULL, 'c']) |
+------------------------------------+------------------------------------------+
| doris                              | a,b,c                                    |
+------------------------------------+------------------------------------------+
```

7. Объединение нескольких массивов
```sql
SELECT CONCAT_WS('-', ['a', 'b'], ['c', NULL], ['d']), CONCAT_WS('|', ['x'], ['y', 'z']);
```
```text
+------------------------------------------------+----------------------------------+
| CONCAT_WS('-', ['a', 'b'], ['c', NULL], ['d']) | CONCAT_WS('|', ['x'], ['y', 'z']) |
+------------------------------------------------+----------------------------------+
| a-b-c-d                                        | x|y|z                            |
+------------------------------------------------+----------------------------------+
```

8. Массив NULL среди нескольких массивов
```sql
SELECT CONCAT_WS('-', ['a', 'b'], NULL, ['c', NULL], ['d']);
```
```text
+-----------------------------------------------------+
| CONCAT_WS('-', ['a', 'b'], NULL, ['c', NULL], ['d']) |
+-----------------------------------------------------+
|                                                     |
+-----------------------------------------------------+
```

9. Обработка многобайтовых символов UTF-8
```sql
SELECT CONCAT_WS('x', 'ṭṛì', 'ḍḍumai'), CONCAT_WS('→', ['ṭṛì', 'ḍḍumai', 'hello']);
```
```text
+-------------------------------+----------------------------------------------+
| CONCAT_WS('x', 'ṭṛì', 'ḍḍumai') | CONCAT_WS('→', ['ṭṛì', 'ḍḍumai', 'hello']) |
+-------------------------------+----------------------------------------------+
| ṭṛìxḍḍumai                    | ṭṛì→ḍḍumai→hello                          |
+-------------------------------+----------------------------------------------+
```

10. Формирование данных в формате CSV и объединение частей пути
```sql
SELECT CONCAT_WS(',', 'Name', 'Age', 'City'), CONCAT_WS('/', 'home', 'user', 'documents', 'file.txt');
```
```text
+------------------------------------+--------------------------------------------------------+
| CONCAT_WS(',', 'Name', 'Age', 'City') | CONCAT_WS('/', 'home', 'user', 'documents', 'file.txt') |
+------------------------------------+--------------------------------------------------------+
| Name,Age,City                      | home/user/documents/file.txt                          |
+------------------------------------+--------------------------------------------------------+
```
