## Описание {#description}

Функция RTRIM_IN удаляет заданные символы с правого края строки. Если набор символов не указан, по умолчанию удаляются пробелы в конце строки. Если набор символов указан, с правого края удаляются все символы, входящие в этот набор (независимо от их порядка в наборе).

Ключевая особенность RTRIM_IN заключается в том, что она удаляет любое сочетание символов из заданного набора, тогда как функция RTRIM удаляет символы на основе точного совпадения строк.

## Синтаксис {#syntax}

```sql
RTRIM_IN(<str>[, <rhs>])
```

## Параметры {#parameters}
| Параметр | Описание |
| --------- | ---------------------------------------------------------------------- |
| `<str>` | Обрабатываемая строка. Тип: VARCHAR |
| `<rhs>` | Необязательный параметр: набор символов для удаления. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее обработанную строку.

Особые случаи:
- Если str имеет значение NULL, возвращает NULL
- Если rhs не указан, удаляет все пробелы в конце строки
- Если rhs указан, удаляет с правого края все символы, входящие в rhs, до первого символа, не входящего в rhs

## Примеры {#examples}

1. Удаление пробелов в конце строки
```sql
SELECT rtrim_in('ab d   ') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. Удаление символов из заданного набора
```sql
SELECT rtrim_in('ababccaab', 'ab') str;
```
```text
+---------+
| str     |
+---------+
| ababcc  |
+---------+
```

3. Сравнение с функцией RTRIM
```sql
SELECT rtrim_in('ababccaab', 'ab'), rtrim('ababccaab', 'ab');
```
```text
+-----------------------------+--------------------------+
| rtrim_in('ababccaab', 'ab') | rtrim('ababccaab', 'ab') |
+-----------------------------+--------------------------+
| ababcc                      | ababcca                  |
+-----------------------------+--------------------------+
```

4. Порядок символов в наборе не имеет значения
```sql
SELECT rtrim_in('Helloabc', 'cba');
```
```text
+-----------------------------+
| rtrim_in('Helloabc', 'cba') |
+-----------------------------+
| Hello                       |
+-----------------------------+
```

5. Поддержка символов UTF-8
```sql
SELECT rtrim_in('ṭṛì ḍḍumai+++', '+');
```
```text
+------------------------------------+
| rtrim_in('ṭṛì ḍḍumai+++', '+')    |
+------------------------------------+
| ṭṛì ḍḍumai                         |
+------------------------------------+
```

6. Обработка значения NULL
```sql
SELECT rtrim_in(NULL, 'abc');
```
```text
+------------------------+
| rtrim_in(NULL, 'abc')  |
+------------------------+
| NULL                   |
+------------------------+
```

7. Обработка пустых строк
```sql
SELECT rtrim_in('', 'abc'), rtrim_in('abc', '');
```
```text
+---------------------+---------------------+
| rtrim_in('', 'abc') | rtrim_in('abc', '') |
+---------------------+---------------------+
|                     | abc                 |
+---------------------+---------------------+
```

### Ключевые слова {#keywords}

    RTRIM_IN, RTRIM
