## Описание {#description}
Функция UNCOMPRESS распаковывает двоичные данные в строки или значения. Необходимо убедиться, что двоичные данные получены в результате вызова функции `COMPRESS`.

## Синтаксис {#syntax}

```sql
UNCOMPRESS(<compressed_str>)
```

## Параметры {#parameters}

| Параметр          | Описание            |
|--------------------|------------------------|
| `<compressed_str>` | Сжатые двоичные данные; тип параметра — varchar или string |

## Возвращаемое значение {#return-value}

Тип возвращаемого значения совпадает с типом входного параметра `compressed_str`.

Особые случаи:
- Возвращает NULL, если `compressed_str` не является двоичными данными, полученными с помощью `COMPRESS`.


## Примеры {#examples}

``` sql
select uncompress(compress('abc'));
```
```text 
+-----------------------------+
| uncompress(compress('abc')) |
+-----------------------------+
| abc                         |
+-----------------------------+
```
```sql
select uncompress(compress(''));
```
```text 
+--------------------------+
| uncompress(compress('')) |
+--------------------------+
|                          |
+--------------------------+
```
```sql
select uncompress('abc');
```
```text 
+-------------------+
| uncompress('abc') |
+-------------------+
| NULL              |
+-------------------+
```

### Ключевые слова {#keywords}

    UNCOMPRESS, COMPRESS
