## Описание {#description}

Функция `sub_replace` используется для замены подстрок в строке. Можно указать подстроку для замены и строку, которая её заменит. Функция возвращает новую строку, в которой подстрока, начинающаяся с позиции `start` и имеющая длину `len` в строке `str`, заменена на `new_str`. Если `start` или `len` является отрицательным целым числом, возвращается NULL. По умолчанию значение `len` равно длине `new_str`.

## Синтаксис {#syntax}

```sql
sub_replace(<str>, <new_str>, [ ,<start> [ , <len> ] ])
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<str>` | Строка, в которой выполняется замена |
| `<new_str>` | Строка, которая заменит указанную подстроку |
| `<start>` | `start` задаёт начальную позицию операции замены, то есть позицию в строке, с которой начинается замена |
| `<len>` | `len` — необязательный параметр, который задаёт длину заменяемой подстроки |

## Возвращаемое значение {#return-value}

Возвращает строку после замены.

## Примеры {#examples}

1. Основное использование: замена с указанием позиции и длины
```sql
SELECT sub_replace('doris', '***', 1, 2);
```
```text
+-----------------------------------+
| sub_replace('doris', '***', 1, 2) |
+-----------------------------------+
| d***is                            |
+-----------------------------------+
```

2. Замена с длиной по умолчанию
```sql
SELECT sub_replace('hello', 'Hi', 0);
```
```text
+--------------------------------+
| sub_replace('hello', 'Hi', 0)  |
+--------------------------------+
| Hillo                          |
+--------------------------------+
```

3. При отрицательном значении параметра возвращается NULL
```sql
SELECT sub_replace('hello', 'Hi', -1, 2);
```
```text
+------------------------------------+
| sub_replace('hello', 'Hi', -1, 2)  |
+------------------------------------+
| NULL                               |
+------------------------------------+
```

4. Обработка значения NULL
```sql
SELECT sub_replace(NULL, 'new', 0, 3);
```
```text
+-------------------------------------+
| sub_replace(NULL, 'new', 0, 3)      |
+-------------------------------------+
| NULL                                |
+-------------------------------------+
```

5. Строка UTF-8
```sql
SELECT sub_replace('doris', 'ṛìḍḍ', 1, 2);
```
```text
+-------------------------------------------+
| sub_replace('doris', 'ṛìḍḍ', 1, 2)        |
+-------------------------------------------+
| dṛìḍḍis                                   |
+-------------------------------------------+
```

6. Начальная позиция превышает длину строки
```sql
SELECT sub_replace('hello', 'Hi', 9, 2);
```
```text
+----------------------------------+
| sub_replace('hello', 'Hi', 9, 2) |
+----------------------------------+
| NULL                             |
+----------------------------------+
```

7. Указанная длина замены превышает длину оставшейся части строки
```sql
SELECT sub_replace('hello', 'Hi', 1, 9);
```
```text
+----------------------------------+
| sub_replace('hello', 'Hi', 1, 9) |
+----------------------------------+
| hHi                              |
+----------------------------------+
```

### Ключевые слова {#keywords}
