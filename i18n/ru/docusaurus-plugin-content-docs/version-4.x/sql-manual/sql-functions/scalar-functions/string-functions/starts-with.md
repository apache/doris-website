## Описание {#description}

Функция STARTS_WITH проверяет, начинается ли строка с указанного префикса. Эта логическая функция выполняет точное сопоставление префикса с учётом регистра.

## Синтаксис {#syntax}

```sql
STARTS_WITH(<str>, <prefix>)
```

## Параметры {#parameters}
| Параметр | Описание |
| --------- | ----------------------------------------- |
| `<str>` | Основная строка для проверки. Тип: VARCHAR |
| `<prefix>` | Строка префикса для сопоставления. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа BOOLEAN (в Doris отображается как TINYINT: 1 для true, 0 для false).

Правила сопоставления:
- Точное совпадение префикса с учётом регистра
- Пустой префикс соответствует любой строке (возвращается true)
- Поддерживается корректное сопоставление многобайтовых символов UTF-8
- Длина префикса не может превышать длину основной строки (кроме случая, когда префикс пуст)

Особые случаи:
- Возвращает NULL, если любой из аргументов равен NULL
- Возвращает true, если префикс является пустой строкой (любая строка начинается с пустой строки)
- Возвращает false, если основная строка пуста, а префикс нет
- Возвращает true, если обе строки пусты

## Примеры {#examples}

1. Простое сопоставление префикса
```sql
SELECT STARTS_WITH('hello world', 'hello'), STARTS_WITH('hello world', 'world');
```
```text
+-------------------------------------+-------------------------------------+
| STARTS_WITH('hello world', 'hello') | STARTS_WITH('hello world', 'world') |
+-------------------------------------+-------------------------------------+
|                                   1 |                                   0 |
+-------------------------------------+-------------------------------------+
```

2. Чувствительность к регистру
```sql
SELECT STARTS_WITH('Hello World', 'hello'), STARTS_WITH('Hello World', 'Hello');
```
```text
+-------------------------------------+-------------------------------------+
| STARTS_WITH('Hello World', 'hello') | STARTS_WITH('Hello World', 'Hello') |
+-------------------------------------+-------------------------------------+
|                                   0 |                                   1 |
+-------------------------------------+-------------------------------------+
```

3. Обработка значений NULL
```sql
SELECT STARTS_WITH(NULL, 'test'), STARTS_WITH('test', NULL);
```
```text
+----------------------------+----------------------------+
| STARTS_WITH(NULL, 'test')  | STARTS_WITH('test', NULL)  |
+----------------------------+----------------------------+
| NULL                       | NULL                       |
+----------------------------+----------------------------+
```

4. Обработка пустых строк
```sql
SELECT STARTS_WITH('hello', ''), STARTS_WITH('', 'world');
```
```text
+---------------------------+----------------------------+
| STARTS_WITH('hello', '')  | STARTS_WITH('', 'world')   |
+---------------------------+----------------------------+
|                         1 |                          0 |
+---------------------------+----------------------------+
```

5. Совпадение всей строки
```sql
SELECT STARTS_WITH('test', 'test'), STARTS_WITH('test', 'testing');
```
```text
+-----------------------------+--------------------------------+
| STARTS_WITH('test', 'test') | STARTS_WITH('test', 'testing') |
+-----------------------------+--------------------------------+
|                           1 |                              0 |
+-----------------------------+--------------------------------+
```

6. Проверка путей к файлам
```sql
SELECT STARTS_WITH('/home/user/file.txt', '/home'), STARTS_WITH('C:\\Windows\\file.txt', 'C:\\');
```
```text
+--------------------------------------------+------------------------------------------------+
| STARTS_WITH('/home/user/file.txt', '/home') | STARTS_WITH('C:\\Windows\\file.txt', 'C:\\')   |
+--------------------------------------------+------------------------------------------------+
|                                          1 |                                              1 |
+--------------------------------------------+------------------------------------------------+
```

7. Многобайтовые символы UTF-8
```sql
SELECT STARTS_WITH('ṭṛì ḍḍumai hello', 'ṭṛì'), STARTS_WITH('ṭṛì ḍḍumai hello', 'ḍḍumai');
```
```text
+------------------------------------------+---------------------------------------------+
| STARTS_WITH('ṭṛì ḍḍumai hello', 'ṭṛì')   | STARTS_WITH('ṭṛì ḍḍumai hello', 'ḍḍumai')  |
+------------------------------------------+---------------------------------------------+
|                                        1 |                                           0 |
+------------------------------------------+---------------------------------------------+
```

8. Проверка URL и протоколов
```sql
SELECT STARTS_WITH('https://example.com', 'https://'), STARTS_WITH('ftp://server.com', 'http://');
```
```text
+----------------------------------------------+---------------------------------------------+
| STARTS_WITH('https://example.com', 'https://') | STARTS_WITH('ftp://server.com', 'http://') |
+----------------------------------------------+---------------------------------------------+
|                                            1 |                                           0 |
+----------------------------------------------+---------------------------------------------+
```

9. Префикс строки из цифр
```sql
SELECT STARTS_WITH('123456789', '123'), STARTS_WITH('987654321', '123');
```
```text
+----------------------------------+----------------------------------+
| STARTS_WITH('123456789', '123')  | STARTS_WITH('987654321', '123')  |
+----------------------------------+----------------------------------+
|                                1 |                                0 |
+----------------------------------+----------------------------------+
```

10. Специальные символы и знаки
```sql
SELECT STARTS_WITH('@username', '@'), STARTS_WITH('#hashtag', '#');
```
```text
+-------------------------------+--------------------------------+
| STARTS_WITH('@username', '@') | STARTS_WITH('#hashtag', '#')   |
+-------------------------------+--------------------------------+
|                             1 |                              1 |
+-------------------------------+--------------------------------+
```
