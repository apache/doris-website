## Описание {#description}

Функция MASK используется для маскирования данных с целью защиты конфиденциальной информации. По умолчанию она заменяет прописные буквы на `X`, строчные буквы на `x`, а цифры на `n`.

## Синтаксис {#syntax}

```sql
MASK(<str>[, <upper>[, <lower>[, <number>]]])
```

## Параметры {#parameters}

| Параметр | Описание |
| ---------- | ----------------------------------------- |
| `<str>` | Строка для маскирования. Тип: VARCHAR |
| `<upper>` | Символ для замены прописных букв, по умолчанию `X` (необязательный параметр). Тип: VARCHAR |
| `<lower>` | Символ для замены строчных букв, по умолчанию `x` (необязательный параметр). Тип: VARCHAR |
| `<number>` | Символ для замены цифр, по умолчанию `n` (необязательный параметр). Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает строку типа VARCHAR, в которой буквы и цифры заменены.

Особые случаи:
- Если какой-либо параметр равен NULL, возвращает NULL
- Символы, не являющиеся буквами или цифрами, остаются без изменений
- Если параметры, задающие символы замены, содержат несколько символов, используется только первый символ

## Примеры {#examples}

1. Базовое использование: правила замены по умолчанию
```sql
SELECT mask('abc123XYZ');
```
```text
+-------------------+
| mask('abc123XYZ') |
+-------------------+
| xxxnnnXXX         |
+-------------------+
```

2. Пользовательские символы замены
```sql
SELECT mask('abc123XYZ', '*', '#', '$');
```
```text
+----------------------------------+
| mask('abc123XYZ', '*', '#', '$') |
+----------------------------------+
| ###$$$***                        |
+----------------------------------+
```

3. Специальные символы остаются без изменений
```sql
SELECT mask('Hello-123!');
```
```text
+--------------------+
| mask('Hello-123!') |
+--------------------+
| Xxxxx-nnn!         |
+--------------------+
```

4. Обработка значения NULL
```sql
SELECT mask(NULL);
```
```text
+------------+
| mask(NULL) |
+------------+
| NULL       |
+------------+
```

5. Строка, состоящая только из цифр
```sql
SELECT mask('1234567890');
```
```text
+--------------------+
| mask('1234567890') |
+--------------------+
| nnnnnnnnnn         |
+--------------------+
```

6. Строка, состоящая только из букв
```sql
SELECT mask('AbCdEfGh');
```
```text
+------------------+
| mask('AbCdEfGh') |
+------------------+
| XxXxXxXx         |
+------------------+
```

7. Обработка пустой строки
```sql
SELECT mask('');
```
```text
+----------+
| mask('') |
+----------+
|          |
+----------+
```

8. Замена одним символом (при указании нескольких используется первый)
```sql
SELECT mask('Test123', 'ABC', 'xyz', '999');
```
```text
+--------------------------------------+
| mask('Test123', 'ABC', 'xyz', '999') |
+--------------------------------------+
| Axxx999                              |
+--------------------------------------+
```

9. Маскирование номера кредитной карты
```sql
SELECT mask('1234-5678-9012-3456');
```
```text
+-----------------------------+
| mask('1234-5678-9012-3456') |
+-----------------------------+
| nnnn-nnnn-nnnn-nnnn         |
+-----------------------------+
```

10. Маскирование адреса электронной почты
```sql
SELECT mask('user@example.com');
```
```text
+--------------------------+
| mask('user@example.com') |
+--------------------------+
| xxxx@xxxxxxx.xxx         |
+--------------------------+
```

```sql
SELECT mask('eeeéèêëìí1234');
```
```text
+-----------------------------+
| mask('eeeéèêëìí1234')       |
+-----------------------------+
| xxxéèêëìínnnn               |
+-----------------------------+
```
