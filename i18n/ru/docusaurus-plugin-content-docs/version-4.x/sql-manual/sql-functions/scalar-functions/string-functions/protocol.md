## Описание {#description}

Функция PROTOCOL используется главным образом для извлечения протокола из строки URL.

## Синтаксис {#syntax}

```sql
PROTOCOL( <url> )
```

## Параметры {#parameters}

| Параметр      | Описание         |
|---------|------------|
| `<url>` | URL для разбора |

## Возвращаемое значение {#return-value}

Возвращает протокол из <url>. Особые случаи:

- Если хотя бы один из параметров равен NULL, возвращается NULL.

## Примеры {#examples}

```sql
SELECT protocol('https://doris.apache.org/');
```

```text
+---------------------------------------+
| protocol('https://doris.apache.org/') |
+---------------------------------------+
| https                                 |
+---------------------------------------+
```

```sql
SELECT protocol(null);
```

```text
+----------------+
| protocol(NULL) |
+----------------+
| NULL           |
+----------------+
```
