## Описание {#description}

Функция SUBSTRING извлекает подстроку из строки. Можно указать начальную позицию и длину; поддерживается извлечение в прямом и обратном направлении. Позиция первого символа в строке — 1.

## Псевдонимы {#alias}

SUBSTR

MID

## Синтаксис {#syntax}

```sql
SUBSTRING(<str>, <pos> [, <len>])

SUBSTRING(<str> FROM <pos> [FOR <len>])
```

## Параметры {#parameters}
| Параметр | Описание                                      |
| --------- | ------------------------------------------------ |
| `<str>` | Исходная строка. Тип: VARCHAR                     |
| `<pos>` | Начальная позиция, может быть отрицательной. Тип: INT    |
| `<len>` | Необязательный параметр: длина извлекаемой подстроки. Тип: INT |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее извлечённую подстроку.

Особые случаи:
- Если любой из параметров равен NULL, возвращает NULL
- Если pos равен 0, возвращает пустую строку
- Если pos отрицателен, отсчёт ведётся от конца строки к началу
- Если pos превышает длину строки, возвращает пустую строку
- Если len не указан, возвращает все символы от позиции pos до конца строки

## Примеры {#examples}

1. Базовое использование (указание начальной позиции)
```sql
SELECT substring('abc1', 2);
```
```text
+-----------------------------+
| substring('abc1', 2)        |
+-----------------------------+
| bc1                         |
+-----------------------------+
```

2. Использование отрицательной позиции
```sql
SELECT substring('abc1', -2);
```
```text
+-----------------------------+
| substring('abc1', -2)       |
+-----------------------------+
| c1                          |
+-----------------------------+
```

3. Случай, когда позиция равна 0
```sql
SELECT substring('abc1', 0);
```
```text
+----------------------+
| substring('abc1', 0) |
+----------------------+
|                      |
+----------------------+
```

4. Позиция превышает длину строки
```sql
SELECT substring('abc1', 5);
```
```text
+-----------------------------+
| substring('abc1', 5)        |
+-----------------------------+
|                             |
+-----------------------------+
```

5. Указание параметра длины
```sql
SELECT substring('abc1def', 2, 2);
```
```text
+-----------------------------+
| substring('abc1def', 2, 2)  |
+-----------------------------+
| bc                          |
+-----------------------------+
```

6. Использование from и for
```sql
SELECT substring('foobarbar' FROM 4 FOR 3);
```
```text
+-------------------------------------+
| substring('foobarbar' FROM 4 FOR 3) |
+-------------------------------------+
| bar                                 |
+-------------------------------------+
```

7. Использование from
```sql
SELECT substring('foobarbar' FROM 4);
```
```text
+-------------------------------+
| substring('foobarbar' FROM 4) |
+-------------------------------+
| barbar                        |
+-------------------------------+
```

8. Пример с NULL и псевдонимом MID
```sql
SELECT MID(NULL, 2);
```
```text
+--------------+
| MID(NULL, 2) |
+--------------+
| NULL         |
+--------------+
```

9. Использование псевдонима SUBSTR
```sql
SELECT SUBSTR('Hello World', 7, 5);
```
```text
+------------------------------+
| SUBSTR('Hello World', 7, 5)  |
+------------------------------+
| World                        |
+------------------------------+
```

10. Многобайтовые символы UTF-8
```sql
SELECT SUBSTRING('ṭṛì ḍḍumai hello', 5, 6);
```
```text
+--------------------------------------+
| SUBSTRING('ṭṛì ḍḍumai hello', 5, 6)  |
+--------------------------------------+
| ḍḍumai                               |
+--------------------------------------+
```

11. Пустая исходная строка
```sql
SELECT substring('', 1, 3);
```
```text
+---------------------+
| substring('', 1, 3) |
+---------------------+
|                     |
+---------------------+
```

12. Передача NULL непосредственно в `substring` (случай с псевдонимом `MID` приведён в примере 8)
```sql
SELECT substring(NULL, 1, 3);
```
```text
+-----------------------+
| substring(NULL, 1, 3) |
+-----------------------+
| NULL                  |
+-----------------------+
```

### Ключевые слова {#keywords}

    SUBSTRING, SUBSTR, MID
