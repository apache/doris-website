## Описание {#description}

Функция CHAR_LENGTH вычисляет количество символов (не байтов) в строке. Для многобайтовых символов (например, китайских иероглифов) она возвращает количество символов.

В настоящее время поддерживается только кодировка UTF-8.

## Псевдоним {#alias}

- CHARACTER_LENGTH

## Синтаксис {#syntax}

```sql 
CHAR_LENGTH(<str>)
```

## Параметры {#parameters}

| Параметр | Описание |
| ------- | ----------------------------------------- |
| `<str>` | Строка, для которой требуется вычислить количество символов. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа INT, представляющее количество символов в строке.

Особые случаи:
- Если параметр равен NULL, возвращает NULL
- Для пустой строки возвращает 0
- Каждый многобайтовый символ UTF-8 считается за 1 символ

## Примеры {#examples}

1. Английские символы
```sql
SELECT CHAR_LENGTH('hello');
```
```text
+----------------------+
| char_length('hello') |
+----------------------+
|                    5 |
+----------------------+
```

2. Китайские иероглифы (каждый китайский иероглиф считается одним символом)
```sql
SELECT CHAR_LENGTH('中国');
```
```text
+----------------------+
| char_length('中国')  |
+----------------------+
|                    2 |
+----------------------+
```

3. Обработка значения NULL
```sql
SELECT CHAR_LENGTH(NULL);
```
```text
+--------------------+
| char_length(NULL)  |
+--------------------+
|               NULL |
+--------------------+
```

4. Сравнение с функцией LENGTH (LENGTH возвращает количество байтов)
```sql
SELECT CHAR_LENGTH('中国') AS char_len, LENGTH('中国') AS byte_len;
```
```text
+----------+----------+
| char_len | byte_len |
+----------+----------+
|        2 |        6 |
+----------+----------+
```
