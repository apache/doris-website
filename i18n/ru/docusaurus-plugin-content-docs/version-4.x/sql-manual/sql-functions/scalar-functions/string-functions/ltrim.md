## Описание {#description}

Функция LTRIM удаляет идущие подряд пробелы или символы из заданного набора с левого края (из начала) строки. Функция просматривает строку слева и удаляет все идущие подряд целевые символы, пока не встретит символ, не входящий в заданный набор.

## Синтаксис {#syntax}

```sql
LTRIM(<str> [, <trim_chars>])
```

## Параметры {#parameters}

| Параметр      | Описание                                                                                                                                                                                                                                                                           |
|----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<str>`        | Исходная строка, из начала которой нужно удалить символы. Тип: VARCHAR                                                                                                                                                                                                                                  |
| `<trim_chars>` | Необязательный параметр, задающий набор удаляемых символов. Если не указан, по умолчанию удаляются пробельные символы. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее собой строку после удаления указанных символов с левого края.

Правила удаления:
- Удаляются только символы в левой части (в начале) строки
- Удаляются все идущие подряд символы, входящие в trim_chars
- Удаление прекращается при встрече символа, не входящего в trim_chars
- Если trim_chars не указан, по умолчанию удаляются пробельные символы (включая пробелы, табуляции, переводы строк и т. д.)

Особые случаи:
- Если любой из параметров равен NULL, возвращается NULL
- Если str является пустой строкой, возвращается пустая строка
- Если trim_chars является пустой строкой, возвращается исходная строка
- Если строка целиком состоит из символов, входящих в trim_chars, возвращается пустая строка

## Примеры {#examples}

1. Удаление пробелов слева
```sql
SELECT LTRIM('   ab d');
```
```text
+-------------------+
| LTRIM('   ab d')  |
+-------------------+
| ab d              |
+-------------------+
```

2. Удаление указанных символов
```sql
SELECT LTRIM('ababccaab', 'ab');
```
```text
+----------------------------+
| LTRIM('ababccaab', 'ab')   |
+----------------------------+
| ccaab                      |
+----------------------------+
```

3. Обработка значений NULL
```sql
SELECT LTRIM(NULL), LTRIM('test', NULL);
```
```text
+-------------+---------------------+
| LTRIM(NULL) | LTRIM('test', NULL) |
+-------------+---------------------+
| NULL        | NULL                |
+-------------+---------------------+
```

4. Пустые входные значения
```sql
SELECT LTRIM(''), LTRIM('test', '');
```
```text
+-----------+-------------------+
| LTRIM('') | LTRIM('test', '') |
+-----------+-------------------+
|           | test              |
+-----------+-------------------+
```

5. Удаление префикса из нескольких символов
```sql
SELECT LTRIM('abcdefg', 'abc'), LTRIM('123456', '12');
```
```text
+-------------------------+-----------------------+
| LTRIM('abcdefg', 'abc') | LTRIM('123456', '12') |
+-------------------------+-----------------------+
| defg                    | 3456                  |
+-------------------------+-----------------------+
```

6. Вся строка состоит из удаляемых символов
```sql
SELECT LTRIM('aaaaa', 'a'), LTRIM('   ', ' ');
```
```text
+---------------------+-------------------+
| LTRIM('aaaaa', 'a') | LTRIM('   ', ' ') |
+---------------------+-------------------+
|                     |                   |
+---------------------+-------------------+
```

7. Удаление подстроки UTF-8 (второй аргумент сопоставляется как буквальная подстрока, а не как набор символов)
```sql
SELECT LTRIM('ṭṛìṭṛì test', 'ṭṛì'), LTRIM('ḍḍuḍḍu hello', 'ḍu');
```
```text
+--------------------------------------------+---------------------------------------+
| LTRIM('ṭṛìṭṛì test', 'ṭṛì')                | LTRIM('ḍḍuḍḍu hello', 'ḍu')           |
+--------------------------------------------+---------------------------------------+
|  test                                      | ḍḍuḍḍu hello                          |
+--------------------------------------------+---------------------------------------+
```

8. Удаление числового префикса
```sql
SELECT LTRIM('000123', '0'), LTRIM('123abc123', '123');
```
```text
+----------------------+---------------------------+
| LTRIM('000123', '0') | LTRIM('123abc123', '123') |
+----------------------+---------------------------+
| 123                  | abc123                    |
+----------------------+---------------------------+
```

9. Удаление префикса из знаков пунктуации
```sql
SELECT LTRIM('---text---', '-'), LTRIM('@@hello@@', '@');
```
```text
+--------------------------+-------------------------+
| LTRIM('---text---', '-') | LTRIM('@@hello@@', '@') |
+--------------------------+-------------------------+
| text---                  | hello@@                 |
+--------------------------+-------------------------+
```
