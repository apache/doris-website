## Описание {#description}

Функция SPLIT_BY_REGEXP разбивает строку на массив строк по заданному шаблону регулярного выражения. В отличие от SPLIT_BY_STRING, эта функция поддерживает сопоставление со сложными регулярными выражениями, позволяя гибко задавать правила разбиения. При необходимости можно ограничить максимальное количество разбиений, что полезно при обработке структурированного текста, очистке данных и сопоставлении с шаблоном.

## Синтаксис {#syntax}

```sql
SPLIT_BY_REGEXP(<str>, <pattern> [, <max_limit>])
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|-------------|
| `<str>` | Исходная строка для разбиения. Тип: VARCHAR |
| `<pattern>` | Шаблон регулярного выражения, используемый в качестве разделителя. Тип: VARCHAR |
| `<max_limit>` | Необязательный параметр, ограничивающий максимальное количество элементов в возвращаемом массиве. Тип: INT |

## Возвращаемое значение {#return-value}

Возвращает значение типа ARRAY<VARCHAR>, представляющее собой массив строк, полученный разбиением по регулярному выражению.

Правила разбиения:

- Точки разбиения определяются по совпадениям с шаблоном регулярного выражения
- Поддерживается стандартный синтаксис регулярных выражений
- Если шаблон представляет собой пустую строку, строка разбивается на отдельные символы
- Если совпадений с шаблоном нет, возвращается массив из одного элемента, содержащего исходную строку
- max_limit ограничивает максимальную длину результирующего массива

Особые случаи:

- Если любой из параметров равен NULL, возвращается NULL
- Если строка пуста, возвращается массив из одного элемента, содержащего пустую строку
- Если регулярное выражение представляет собой пустую строку, выполняется разбиение по символам
- Если max_limit равен 0 или отрицателен, ограничение не применяется
- Последовательные совпадения создают элементы с пустыми строками

## Примеры {#examples}

1. Разбиение по символам с пустым шаблоном
```sql
SELECT SPLIT_BY_REGEXP('abcde', '');
```
```text
+------------------------------+
| SPLIT_BY_REGEXP('abcde', '') |
+------------------------------+
| ["a", "b", "c", "d", "e"]    |
+------------------------------+
```

2. Разбиение по шаблону из цифр
```sql
SELECT SPLIT_BY_REGEXP('a12bc23de345f', '\\d+');
```
```text
+-----------------------------------------+
| SPLIT_BY_REGEXP('a12bc23de345f', '\d+') |
+-----------------------------------------+
| ["a", "bc", "de", "f"]                  |
+-----------------------------------------+
```

3. Обработка значений NULL
```sql
SELECT SPLIT_BY_REGEXP(NULL, '\\d+'), SPLIT_BY_REGEXP('test', NULL);
```
```text
+--------------------------------+--------------------------------+
| SPLIT_BY_REGEXP(NULL, '\d+')   | SPLIT_BY_REGEXP('test', NULL)  |
+--------------------------------+--------------------------------+
| NULL                           | NULL                           |
+--------------------------------+--------------------------------+
```

4. Обработка пустой строки
```sql
SELECT SPLIT_BY_REGEXP('', ','), SPLIT_BY_REGEXP('hello', 'xyz');
```
```text
+---------------------------+-------------------------------+
| SPLIT_BY_REGEXP('', ',')  | SPLIT_BY_REGEXP('hello', 'xyz') |
+---------------------------+-------------------------------+
| [""]                      | ["hello"]                     |
+---------------------------+-------------------------------+
```

5. Использование параметра максимального количества элементов
```sql
SELECT SPLIT_BY_REGEXP('a,b,c,d,e', ',', 3), SPLIT_BY_REGEXP('1-2-3-4-5', '-', 2);
```
```text
+--------------------------------------+--------------------------------------+
| SPLIT_BY_REGEXP('a,b,c,d,e', ',', 3) | SPLIT_BY_REGEXP('1-2-3-4-5', '-', 2) |
+--------------------------------------+--------------------------------------+
| ["a", "b", "c,d,e"]                  | ["1", "2-3-4-5"]                    |
+--------------------------------------+--------------------------------------+
```

6. Шаблон для пробельных символов
```sql
SELECT SPLIT_BY_REGEXP('hello world  test', '\\s+'), SPLIT_BY_REGEXP('a\tb\nc\rd', '\\s');
```
```text
+------------------------------------------+------------------------------------+
| SPLIT_BY_REGEXP('hello world  test', '\s+') | SPLIT_BY_REGEXP('a\tb\nc\rd', '\s') |
+------------------------------------------+------------------------------------+
| ["hello", "world", "test"]               | ["a", "b", "c", "d"]               |
+------------------------------------------+------------------------------------+
```

7. Специальные символы и экранирование
```sql
SELECT SPLIT_BY_REGEXP('a.b.c.d', '\\.'), SPLIT_BY_REGEXP('x(y)z[w]', '[\\(\\)\\[\\]]');
```
```text
+----------------------------------+--------------------------------------------+
| SPLIT_BY_REGEXP('a.b.c.d', '\.') | SPLIT_BY_REGEXP('x(y)z[w]', '[\(\)\[\]]') |
+----------------------------------+--------------------------------------------+
| ["a", "b", "c", "d"]             | ["x", "y", "z", "w"]                   |
+----------------------------------+--------------------------------------------+
```

8. Границы слов и сложные шаблоны
```sql
SELECT SPLIT_BY_REGEXP('TheQuickBrownFox', '[A-Z]'), SPLIT_BY_REGEXP('user@example.com', '@|\\.');
```
```text
+------------------------------------------+-------------------------------------------+
| SPLIT_BY_REGEXP('TheQuickBrownFox', '[A-Z]') | SPLIT_BY_REGEXP('user@example.com', '@|\.') |
+------------------------------------------+-------------------------------------------+
| ["", "he", "uick", "rown", "ox"]         | ["user", "example", "com"]                |
+------------------------------------------+-------------------------------------------+
```

9. Многобайтовые символы UTF-8
```sql
SELECT SPLIT_BY_REGEXP('ṭṛì→ḍḍumai→hello', '→'), SPLIT_BY_REGEXP('αβγδε', '[βδ]');
```
```text
+------------------------------------------+----------------------------------+
| SPLIT_BY_REGEXP('ṭṛì→ḍḍumai→hello', '→') | SPLIT_BY_REGEXP('αβγδε', '[βδ]') |
+------------------------------------------+----------------------------------+
| ["ṭṛì", "ḍḍumai", "hello"]               | ["α", "γ", "ε"]                  |
+------------------------------------------+----------------------------------+
```

10. Последовательные совпадения и пустые элементы
```sql
SELECT SPLIT_BY_REGEXP('a,,b,c', ','), SPLIT_BY_REGEXP('123abc456def', '[a-z]+');
```
```text
+-------------------------------+---------------------------------------+
| SPLIT_BY_REGEXP('a,,b,c', ',') | SPLIT_BY_REGEXP('123abc456def', '[a-z]+') |
+-------------------------------+---------------------------------------+
| ["a", "", "b", "c"]           | ["123", "456", ""]                    |
+-------------------------------+---------------------------------------+
```

### Ключевые слова {#keywords}

    SPLIT_BY_REGEXP, SPLIT, REGEXP, REGEXP_SPLIT_TO_ARRAY
