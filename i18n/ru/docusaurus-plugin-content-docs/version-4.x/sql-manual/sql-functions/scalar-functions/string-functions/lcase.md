## Описание {#description}

Функция LCASE (псевдоним LOWER) преобразует все прописные буквы в строке в строчные.

## Синтаксис {#syntax}

```sql
LCASE(<str>)
LOWER(<str>)
```

## Параметры {#parameters}

| Параметр | Описание |
|---------|--------------|
| `<str>` | Строка для преобразования в нижний регистр. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает строку типа VARCHAR, преобразованную в нижний регистр.

Правила преобразования:
- Все прописные буквы в строке преобразуются в соответствующие строчные буквы
- Символы, не являющиеся буквами (цифры, специальные символы, пробелы и т. д.), остаются без изменений
- Буквы, которые уже являются строчными, остаются без изменений

Особые случаи:
- Если параметр равен NULL, возвращает NULL
- Если строка пустая, возвращает пустую строку
- Если строка не содержит прописных букв, возвращает исходную строку

## Примеры {#examples}

1. Простое преобразование английских букв
```sql
SELECT LOWER('AbC123'), LCASE('AbC123');
```
```text
+-----------------+-----------------+
| LOWER('AbC123') | LCASE('AbC123') |
+-----------------+-----------------+
| abc123          | abc123          |
+-----------------+-----------------+
```

2. Обработка строки с различными символами
```sql
SELECT LOWER('Hello World!'), LCASE('TEST@123');
```
```text
+----------------------+------------------+
| LOWER('Hello World!') | LCASE('TEST@123') |
+----------------------+------------------+
| hello world!         | test@123         |
+----------------------+------------------+
```

3. Обработка значения NULL
```sql
SELECT LOWER(NULL), LCASE(NULL);
```
```text
+-------------+-------------+
| LOWER(NULL) | LCASE(NULL) |
+-------------+-------------+
| NULL        | NULL        |
+-------------+-------------+
```

4. Пустая строка
```sql
SELECT LOWER(''), LCASE('');
```
```text
+-----------+-----------+
| LOWER('') | LCASE('') |
+-----------+-----------+
|           |           |
+-----------+-----------+
```

5. Строка уже в нижнем регистре или содержит только цифры
```sql
SELECT LOWER('already lowercase'), LCASE('abc123');
```
```text
+----------------------------+-----------------+
| LOWER('already lowercase') | LCASE('abc123') |
+----------------------------+-----------------+
| already lowercase          | abc123          |
+----------------------------+-----------------+
```

6. Символы, не являющиеся буквами, остаются без изменений
```sql
SELECT LOWER('123!@#$%'), LCASE('PRICE: $99.99');
```
```text
+-------------------+------------------------+
| LOWER('123!@#$%') | LCASE('PRICE: $99.99') |
+-------------------+------------------------+
| 123!@#$%          | price: $99.99          |
+-------------------+------------------------+
```

7. Преобразование регистра многобайтовых символов UTF-8
```sql
SELECT LOWER('ṬṚÌ TEST'), LCASE('ḌḌUMAI HELLO');
```
```text
+------------------------+---------------------------+
| LOWER('ṬṚÌ TEST')      | LCASE('ḌḌUMAI HELLO')     |
+------------------------+---------------------------+
| ṭṛì test               | ḍḍumai hello              |
+------------------------+---------------------------+
```
