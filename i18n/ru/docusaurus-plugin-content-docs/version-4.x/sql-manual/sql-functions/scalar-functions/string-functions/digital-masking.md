## Описание {#description}

Функция DIGITAL_MASKING маскирует числовые строки, заменяя среднюю часть на `****` по фиксированному шаблону и сохраняя первые 3 и последние 4 цифры. Эквивалентна `CONCAT(LEFT(id, 3), '****', RIGHT(id, 4))`.

## Синтаксис {#syntax}

```sql
DIGITAL_MASKING(<digital_number>)
```

## Параметры {#parameters}

| Параметр | Описание |
| ------------------ | ----------------------------------------- |
| `<digital_number>` | Числовая строка, которую необходимо замаскировать. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее замаскированную числовую строку.

Особые случаи:
- Если параметр равен NULL, возвращает NULL
- Формат маскирования: первые 3 цифры + `****` + последние 4 цифры
- Если длина строки меньше 7 цифр, начальная и конечная части в результате могут перекрываться

## Примеры {#examples}

1. Основное использование: маскирование телефонного номера из 11 цифр
```sql
SELECT digital_masking('13812345678');
```
```text
+--------------------------------+
| digital_masking('13812345678') |
+--------------------------------+
| 138****5678                    |
+--------------------------------+
```

2. Числа разной длины
```sql
SELECT digital_masking('1234567890');
```
```text
+-------------------------------+
| digital_masking('1234567890') |
+-------------------------------+
| 123****7890                   |
+-------------------------------+
```

3. Короткое число (менее 7 цифр)
```sql
SELECT digital_masking('123');
```
```text
+------------------------+
| digital_masking('123') |
+------------------------+
| 123****123             |
+------------------------+
```

4. Обработка значения NULL
```sql
SELECT digital_masking(NULL);
```
```text
+-----------------------+
| digital_masking(NULL) |
+-----------------------+
| NULL                  |
+-----------------------+
```

5. Строка с символами UTF-8
```sql
SELECT digital_masking('13812ṭṛ34678');
```
```text
+-------------------------------------+
| digital_masking('13812ṭṛ34678')     |
+-------------------------------------+
| 138****4678                         |
+-------------------------------------+
```
