## Описание {#description}

Функция SUBSTRING_INDEX используется для извлечения части строки по заданному разделителю. Указав количество вхождений разделителя, можно выполнять извлечение с левой или правой стороны.

## Синтаксис {#syntax}

```sql
SUBSTRING_INDEX(<content>, <delimiter>, <field>)
```

## Параметры {#parameters}
| Параметр | Описание |
| --------- | --------------------------------------------------------------------------------------------------------------- |
| `<content>` | Исходная строка, из которой извлекается подстрока. Тип: VARCHAR |
| `<delimiter>` | Строка-разделитель. Учитывается регистр, поддерживаются многобайтовые символы. Тип: VARCHAR |
| `<field>` | Количество вхождений разделителя. При положительном значении отсчёт ведётся слева, при отрицательном справа, при значении 0 возвращается пустая строка. Тип: INT |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее извлечённую подстроку.

Правила извлечения:
- При field > 0: возвращается часть content до field-го вхождения разделителя слева
- При field < 0: возвращается часть content после |field|-го вхождения разделителя справа
- При field = 0: возвращается пустая строка (если content равен NULL, возвращается NULL)
- Разделитель должен совпадать точно, с учётом регистра

Особые случаи:
- Если любой из параметров равен NULL, возвращается NULL
- Если разделитель отсутствует в строке, возвращается исходная строка
- Если указанное количество превышает фактическое число вхождений разделителя, возвращается максимально возможная для извлечения часть строки
- Если разделитель является пустой строкой, возвращается пустая строка
- Если исходная строка пустая, возвращается пустая строка

## Примеры {#examples}

1. Базовый пример извлечения слева
```sql
SELECT SUBSTRING_INDEX('hello world', ' ', 1), SUBSTRING_INDEX('one,two,three', ',', 2);
```
```text
+----------------------------------------+------------------------------------------+
| SUBSTRING_INDEX('hello world', ' ', 1) | SUBSTRING_INDEX('one,two,three', ',', 2) |
+----------------------------------------+------------------------------------------+
| hello                                  | one,two                                  |
+----------------------------------------+------------------------------------------+
```

2. Извлечение справа (отрицательное количество)
```sql
SELECT SUBSTRING_INDEX('hello world', ' ', -1), SUBSTRING_INDEX('one,two,three', ',', -1);
```
```text
+-----------------------------------------+-------------------------------------------+
| SUBSTRING_INDEX('hello world', ' ', -1) | SUBSTRING_INDEX('one,two,three', ',', -1) |
+-----------------------------------------+-------------------------------------------+
| world                                   | three                                     |
+-----------------------------------------+-------------------------------------------+
```

3. Обработка значений NULL
```sql
SELECT SUBSTRING_INDEX(NULL, ',', 1), SUBSTRING_INDEX('test', NULL, 1);
```
```text
+--------------------------------+------------------------------------+
| SUBSTRING_INDEX(NULL, ',', 1)  | SUBSTRING_INDEX('test', NULL, 1)   |
+--------------------------------+------------------------------------+
| NULL                           | NULL                               |
+--------------------------------+------------------------------------+
```

4. Обработка нулевого количества
```sql
SELECT SUBSTRING_INDEX('hello world', ' ', 0), SUBSTRING_INDEX('a,b,c', ',', 0);
```
```text
+----------------------------------------+----------------------------------+
| SUBSTRING_INDEX('hello world', ' ', 0) | SUBSTRING_INDEX('a,b,c', ',', 0) |
+----------------------------------------+----------------------------------+
|                                        |                                  |
+----------------------------------------+----------------------------------+
```

5. Разделитель отсутствует
```sql
SELECT SUBSTRING_INDEX('hello world', ',', 1), SUBSTRING_INDEX('no-delimiter', '|', -1);
```
```text
+----------------------------------------+------------------------------------------+
| SUBSTRING_INDEX('hello world', ',', 1) | SUBSTRING_INDEX('no-delimiter', '|', -1) |
+----------------------------------------+------------------------------------------+
| hello world                            | no-delimiter                             |
+----------------------------------------+------------------------------------------+
```

6. Указанное количество превышает число вхождений разделителя
```sql
SELECT SUBSTRING_INDEX('a,b,c', ',', 5), SUBSTRING_INDEX('a,b,c', ',', -5);
```
```text
+----------------------------------+-----------------------------------+
| SUBSTRING_INDEX('a,b,c', ',', 5) | SUBSTRING_INDEX('a,b,c', ',', -5) |
+----------------------------------+-----------------------------------+
| a,b,c                            | a,b,c                             |
+----------------------------------+-----------------------------------+
```

7. Многобайтовый символ UTF-8 в качестве разделителя
```sql
SELECT SUBSTRING_INDEX('ṭṛì→ḍḍumai→hello', '→', 1), SUBSTRING_INDEX('ṭṛì→ḍḍumai→hello', '→', -1);
```
```text
+-----------------------------------------------+------------------------------------------------+
| SUBSTRING_INDEX('ṭṛì→ḍḍumai→hello', '→', 1)   | SUBSTRING_INDEX('ṭṛì→ḍḍumai→hello', '→', -1)  |
+-----------------------------------------------+------------------------------------------------+
| ṭṛì                                           | hello                                          |
+-----------------------------------------------+------------------------------------------------+
```

8. Разделитель из нескольких символов
```sql
SELECT SUBSTRING_INDEX('data::field::value', '::', 2), SUBSTRING_INDEX('data::field::value', '::', -1);
```
```text
+---------------------------------------------+----------------------------------------------+
| SUBSTRING_INDEX('data::field::value', '::', 2) | SUBSTRING_INDEX('data::field::value', '::', -1) |
+---------------------------------------------+----------------------------------------------+
| data::field                                 | value                                        |
+---------------------------------------------+----------------------------------------------+
```

9. Пустая исходная строка
```sql
SELECT SUBSTRING_INDEX('', ' ', 1);
```
```text
+-----------------------------+
| SUBSTRING_INDEX('', ' ', 1) |
+-----------------------------+
|                             |
+-----------------------------+
```

### Ключевые слова {#keywords}

    SUBSTRING_INDEX, SUBSTRING
