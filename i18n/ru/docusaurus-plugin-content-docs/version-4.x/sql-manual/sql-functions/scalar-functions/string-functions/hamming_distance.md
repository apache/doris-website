## Описание {#description}

Функция `HAMMING_DISTANCE` возвращает количество позиций, в которых различаются две строки.

Эта функция сравнивает строки по символам UTF-8, а не по байтам. Обе входные строки должны содержать одинаковое количество символов UTF-8. При сравнении учитывается регистр.

## Синтаксис {#syntax}

```sql
HAMMING_DISTANCE(<str1>, <str2>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<str1>` | Первая строка для сравнения. |
| `<str2>` | Вторая строка для сравнения. |

## Возвращаемое значение {#return-value}

Возвращает значение типа BIGINT, представляющее количество позиций с различающимися символами.

Особые случаи:

- Если хотя бы один из аргументов равен NULL, возвращается NULL.
- Если оба аргумента — пустые строки, возвращается 0.
- Если строки содержат разное количество символов UTF-8, возвращается ошибка.

## Примеры {#examples}

1. Сравнение двух строк ASCII одинаковой длины.

```sql
SELECT hamming_distance('karolin', 'kathrin') AS distance;
```

```text
+----------+
| distance |
+----------+
|        3 |
+----------+
```

2. Сравнение двух строк UTF-8. Строки содержат одинаковое количество символов и различаются только одним символом.

```sql
SELECT hamming_distance('数据库', '数据仓') AS distance;
```

```text
+----------+
| distance |
+----------+
|        1 |
+----------+
```

3. Сравнение строк, различающихся только регистром букв.

```sql
SELECT hamming_distance('Doris', 'doris') AS distance;
```

```text
+----------+
| distance |
+----------+
|        1 |
+----------+
```

4. Если входное значение равно NULL, возвращается NULL.

```sql
SELECT hamming_distance(NULL, 'abc') AS distance;
```

```text
+----------+
| distance |
+----------+
|     NULL |
+----------+
```
