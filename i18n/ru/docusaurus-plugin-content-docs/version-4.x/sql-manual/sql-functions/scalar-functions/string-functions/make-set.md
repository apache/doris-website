## Описание {#description}

Функция MAKE_SET выбирает и объединяет строки из нескольких строковых параметров на основе битовой маски (bit). Возвращает набор строк, разделённых запятыми, в который входят все строки, для которых соответствующий бит равен 1.

Поведение соответствует функции [MAKE_SET](https://dev.mysql.com/doc/refman/8.4/en/string-functions.html#function-make-set) в MySQL.

## Синтаксис {#syntax}

```sql
MAKE_SET(<bit>, <str1>[, <str2>, ...])
```

## Параметры {#parameters}

| Параметр | Описание |
| -------- | ----------------------------------------- |
| `<bit>` | Значение битовой маски: двоичные биты определяют, какие строки выбрать. Тип: BIGINT |
| `<str1>`, `<str2>`, ... | Строковые параметры для объединения (переменное число аргументов). Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR: набор строк, разделённых запятыми.

Особые случаи:
- Если `<bit>` равен NULL, возвращается NULL
- Если строка, соответствующая биту со значением 1, равна NULL, эта строка пропускается
- Если соответствующий бит выходит за пределы списка параметров, он игнорируется
- Биты нумеруются справа налево; бит 0 соответствует первому строковому параметру
- Если `<bit>` равен 0, возвращается пустая строка

## Примеры {#examples}

1. Базовое использование: bit = 3 (двоичное представление 011, выбираются биты 0 и 1)
```sql
SELECT make_set(3, 'dog', 'cat', 'bird');
```
```text
+-----------------------------------+
| make_set(3, 'dog', 'cat', 'bird') |
+-----------------------------------+
| dog,cat                           |
+-----------------------------------+
```

2. Пропуск значений NULL: bit = 5 (двоичное представление 101, выбираются биты 0 и 2)
```sql
SELECT make_set(5, NULL, 'warm', 'hot');
```
```text
+---------------------------------+
| make_set(5, NULL, 'warm', 'hot') |
+---------------------------------+
| hot                             |
+---------------------------------+
```

3. bit равен 0: строки не выбираются
```sql
SELECT make_set(0, 'hello', 'world');
```
```text
+--------------------------------+
| make_set(0, 'hello', 'world')  |
+--------------------------------+
|                                |
+--------------------------------+
```

4. Обработка значения NULL
```sql
SELECT make_set(NULL, 'a', 'b', 'c');
```
```text
+-------------------------------+
| make_set(NULL, 'a', 'b', 'c') |
+-------------------------------+
| NULL                          |
+-------------------------------+
```

5. Бит выходит за пределы списка параметров: bit = 15 (двоичное представление 1111, выбираются 4 бита, но переданы только 2 параметра)
```sql
SELECT make_set(15, 'first', 'second');
```
```text
+-------------------------------------+
| make_set(15, 'first', 'second')     |
+-------------------------------------+
| first,second                        |
+-------------------------------------+
```

6. Поддержка специальных символов UTF-8
```sql
SELECT make_set(7, 'ṭṛì', 'ḍḍumai', 'test');
```
```text
+------------------------------------------+
| make_set(7, 'ṭṛì', 'ḍḍumai', 'test')    |
+------------------------------------------+
| ṭṛì,ḍḍumai,test                          |
+------------------------------------------+
```
