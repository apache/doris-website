## Описание {#description}

Функция AUTO_PARTITION_NAME используется для формирования имён партиций при автоматическом партиционировании. Она поддерживает два режима: в режиме RANGE имена партиций формируются на основе единиц времени, а в режиме LIST имена партиций формируются на основе строковых значений.

Поддерживается начиная с Apache Doris 2.1.6.

## Синтаксис {#syntax}

```sql
AUTO_PARTITION_NAME('RANGE', <unit>, <datetime>)
AUTO_PARTITION_NAME('LIST', <value>[, <value> ...])
```

## Параметры {#parameters}

| Параметр | Описание |
| ----------- | ----------------------------------------- |
| `'RANGE'` | Режим партиционирования RANGE, в котором имена партиций формируются на основе времени |
| `'LIST'` | Режим партиционирования LIST, в котором имена партиций формируются на основе строковых значений |
| `<unit>` | Единица времени для режима RANGE: `year`, `month`, `day`, `hour`, `minute`, `second`. Тип: VARCHAR |
| `<datetime>` | Значение даты и времени для режима RANGE. Тип: DATETIME |
| `<value>` | Значение партиции для режима LIST (можно указать несколько значений). Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее сформированное имя партиции.

Особые случаи:
- Режим RANGE: имя партиции имеет формат `pYYYYMMDDHHMMSS` и усекается до точности, соответствующей указанной единице времени
- Режим LIST: имя партиции имеет формат `p<value><length>`, несколько значений разделяются указанием длины
- Если параметры недопустимы, возвращается ошибка

## Примеры {#examples}

1. Базовое использование: RANGE по дням
```sql
SELECT auto_partition_name('range', 'day', '2022-12-12 19:20:30');
```
```text
+------------------------------------------------------------+
| auto_partition_name('range', 'day', '2022-12-12 19:20:30') |
+------------------------------------------------------------+
| p20221212000000                                            |
+------------------------------------------------------------+
```

2. RANGE по месяцам
```sql
SELECT auto_partition_name('range', 'month', '2022-12-12 19:20:30');
```
```text
+--------------------------------------------------------------+
| auto_partition_name('range', 'month', '2022-12-12 19:20:30') |
+--------------------------------------------------------------+
| p20221201000000                                              |
+--------------------------------------------------------------+
```

3. LIST с одним значением
```sql
SELECT auto_partition_name('list', 'helloworld');
```
```text
+-------------------------------------------+
| auto_partition_name('list', 'helloworld') |
+-------------------------------------------+
| phelloworld10                             |
+-------------------------------------------+
```

4. LIST с несколькими значениями
```sql
SELECT auto_partition_name('list', 'hello', 'world');
```
```text
+-----------------------------------------------+
| auto_partition_name('list', 'hello', 'world') |
+-----------------------------------------------+
| phello5world5                                 |
+-----------------------------------------------+
```

5. Поддержка специальных символов UTF-8: режим LIST
```sql
SELECT auto_partition_name('list', 'ṭṛì', 'ḍḍumai');
```
```text
+-------------------------------------------------------+
| auto_partition_name('list', 'ṭṛì', 'ḍḍumai')          |
+-------------------------------------------------------+
| p1e6d1e5bec31e0d1e0dumai6                             |
+-------------------------------------------------------+
```

6. Недопустимое значение параметра единицы времени
```sql
SELECT auto_partition_name('range', 'years', '2022-12-12');
```
```text
ERROR 1105 (HY000): errCode = 2, detailMessage = range auto_partition_name must accept year|month|day|hour|minute|second for 2nd argument
```
