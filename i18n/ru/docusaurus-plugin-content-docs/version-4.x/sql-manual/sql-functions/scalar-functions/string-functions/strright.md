## Описание {#description}

Функция STRRIGHT возвращает указанное количество символов с правого края строки. Длина измеряется в символах UTF8.

## Псевдоним {#alias}

RIGHT

## Синтаксис {#syntax}

```sql
STRRIGHT(<str>, <len>)
```

## Параметры {#parameters}
| Параметр | Описание                                   |
| --------- | --------------------------------------------- |
| `<str>` | Строка, из которой извлекаются символы. Тип: VARCHAR     |
| `<len>` | Количество возвращаемых символов. Тип: INT |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее извлечённую подстроку.

Особые случаи:
- Возвращает NULL, если хотя бы один аргумент равен NULL
- Если len отрицательно, возвращает подстроку, начинающуюся с символа на позиции abs(len) при отсчёте справа
- Возвращает всю строку, если len превышает длину строки

## Примеры {#examples}

1. Простое извлечение символов с правого края
```sql
SELECT STRRIGHT('Hello doris', 5), RIGHT('Hello doris', 5);
```
```text
+----------------------------+------------------------+
| STRRIGHT('Hello doris', 5) | RIGHT('Hello doris', 5) |
+----------------------------+------------------------+
| doris                      | doris                  |
+----------------------------+------------------------+
```

2. Извлечение подстрок разной длины
```sql
SELECT STRRIGHT('Hello World', 3), STRRIGHT('Hello World', 8);
```
```text
+-----------------------------+-----------------------------+
| STRRIGHT('Hello World', 3)  | STRRIGHT('Hello World', 8)  |
+-----------------------------+-----------------------------+
| rld                         | lo World                    |
+-----------------------------+-----------------------------+
```

3. Обработка значений NULL
```sql
SELECT STRRIGHT(NULL, 5), STRRIGHT('Hello doris', NULL);
```
```text
+-------------------+-------------------------------+
| STRRIGHT(NULL, 5) | STRRIGHT('Hello doris', NULL) |
+-------------------+-------------------------------+
| NULL              | NULL                          |
+-------------------+-------------------------------+
```

4. Пустая строка и нулевая длина
```sql
SELECT STRRIGHT('', 5), STRRIGHT('Hello World', 0);
```
```text
+-------------------+-----------------------------+
| STRRIGHT('', 5)   | STRRIGHT('Hello World', 0)  |
+-------------------+-----------------------------+
|                   |                             |
+-------------------+-----------------------------+
```

5. Обработка отрицательной длины
```sql
SELECT STRRIGHT('Hello doris', -7), STRRIGHT('Hello doris', -5);
```
```text
+-----------------------------+-----------------------------+
| STRRIGHT('Hello doris', -7) | STRRIGHT('Hello doris', -5) |
+-----------------------------+-----------------------------+
| doris                       | o doris                     |
+-----------------------------+-----------------------------+
```

6. Длина превышает длину строки
```sql
SELECT STRRIGHT('ABC', 10), STRRIGHT('short', 20);
```
```text
+---------------------+-----------------------+
| STRRIGHT('ABC', 10) | STRRIGHT('short', 20) |
+---------------------+-----------------------+
| ABC                 | short                 |
+---------------------+-----------------------+
```

7. Многобайтовые символы UTF-8
```sql
SELECT STRRIGHT('ṭṛì ḍḍumai hello', 5), STRRIGHT('ṭṛì ḍḍumai hello', 11);
```
```text
+----------------------------------+-----------------------------------+
| STRRIGHT('ṭṛì ḍḍumai hello', 5)  | STRRIGHT('ṭṛì ḍḍumai hello', 11) |
+----------------------------------+-----------------------------------+
| hello                            | ḍumai hello                       |
+----------------------------------+-----------------------------------+
```

8. Обработка строк с цифрами
```sql
SELECT STRRIGHT('123456789', 3), STRRIGHT('ID_987654321', 6);
```
```text
+----------------------------+-------------------------------+
| STRRIGHT('123456789', 3)   | STRRIGHT('ID_987654321', 6)   |
+----------------------------+-------------------------------+
| 789                        | 654321                        |
+----------------------------+-------------------------------+
```

9. Извлечение домена из адреса электронной почты
```sql
SELECT STRRIGHT('user@example.com', 11), STRRIGHT('admin@company.org.cn', 14);
```
```text
+----------------------------------+--------------------------------------+
| STRRIGHT('user@example.com', 11) | STRRIGHT('admin@company.org.cn', 14) |
+----------------------------------+--------------------------------------+
| example.com                      | company.org.cn                      |
+----------------------------------+--------------------------------------+
```

### Ключевые слова {#keywords}

    STRRIGHT, RIGHT
