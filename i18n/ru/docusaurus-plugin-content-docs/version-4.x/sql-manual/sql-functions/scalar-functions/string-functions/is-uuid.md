## Описание {#description}

Если параметр представляет собой корректный UUID, возвращает 1. Если UUID некорректен, возвращает 0. Если параметр равен NULL, возвращает NULL.

UUID считается корректным, если он имеет правильную длину и содержит только допустимые символы (шестнадцатеричные цифры и буквы в любом регистре, а также необязательные дефисы и фигурные скобки). Он может быть представлен в одном из следующих трёх форматов:
```text
aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
aaaaaaaabbbbccccddddeeeeeeeeeeee
{aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee}
```

## Синтаксис {#syntax}

```sql
IS_UUID ( <str> )
```

## Параметры {#parameters}
| Параметр  | Описание |
|------------|-----------------|
| `<str>` | строка |


## Возвращаемое значение {#return-value}

Если `<str>` является корректным UUID, возвращает 1; в противном случае возвращает 0.

Особые случаи:
- Если параметр равен NULL, возвращает NULL.
