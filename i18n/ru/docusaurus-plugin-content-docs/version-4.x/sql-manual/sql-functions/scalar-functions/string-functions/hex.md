## Описание {#description}

Функция HEX преобразует входные параметры в строковое шестнадцатеричное представление. Функция совместима с MySQL и поддерживает как числовые, так и строковые входные данные, применяя к ним разные правила преобразования.

Если входной параметр является числом (типа BIGINT), функция возвращает строковое шестнадцатеричное представление этого числа.

Если входной параметр является строкой, функция преобразует каждый символ (побайтово) в два шестнадцатеричных символа, а затем объединяет все преобразованные символы в результирующую строку.

## Синтаксис {#syntax}

```sql
HEX(<expr>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-------|--------------|
| `<expr>` | Входной параметр: число типа BIGINT или строка типа VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, содержащее шестнадцатеричное представление входного параметра.

Правила преобразования:
- Числовые входные данные: преобразуются в соответствующее шестнадцатеричное значение (в пределах диапазона BIGINT)
- Строковые входные данные: каждый байт преобразуется в два шестнадцатеричных символа в верхнем регистре
- Отрицательные числа преобразуются с использованием двоичного представления в дополнительном коде

Особые случаи:
- Если параметр равен NULL, возвращается NULL
- Число 0 преобразуется в '0'
- Пустая строка преобразуется в пустую строку
- Отрицательные числа преобразуются в шестнадцатеричное представление 64-битного дополнительного кода

## Примеры {#examples}

1. Базовое преобразование чисел
```sql
SELECT HEX(12), HEX(-1);
```
```text
+---------+------------------+
| HEX(12) | HEX(-1)          |
+---------+------------------+
| C       | FFFFFFFFFFFFFFFF |
+---------+------------------+
```

2. Преобразование строк
```sql
SELECT HEX('1'), HEX('@'), HEX('12');
```
```text
+----------+----------+-----------+
| HEX('1') | HEX('@') | HEX('12') |
+----------+----------+-----------+
| 31       | 40       | 3132      |
+----------+----------+-----------+
```

3. Преобразование больших целых чисел
```sql
SELECT HEX(255), HEX(65535), HEX(16777215);
```
```text
+----------+------------+----------------+
| HEX(255) | HEX(65535) | HEX(16777215)  |
+----------+------------+----------------+
| FF       | FFFF       | FFFFFF         |
+----------+------------+----------------+
```

4. Обработка значения NULL
```sql
SELECT HEX(NULL);
```
```text
+-----------+
| HEX(NULL) |
+-----------+
| NULL      |
+-----------+
```

5. Ноль и пустая строка
```sql
SELECT HEX(0), HEX('');
```
```text
+--------+--------+
| HEX(0) | HEX('') |
+--------+--------+
| 0      |        |
+--------+--------+
```

6. Пробельные символы (каждый байт → две шестнадцатеричные цифры)
```sql
SELECT HEX(' '), HEX('\t'), HEX('\n');
```
```text
+----------+-----------+-----------+
| HEX(' ') | HEX('\t') | HEX('\n') |
+----------+-----------+-----------+
| 20       | 09        | 0A        |
+----------+-----------+-----------+
```

7. Многобайтовые строки UTF-8
```sql
SELECT HEX('ṭṛì'), HEX('ḍḍumai');
```
```text
+------------------+----------------------+
| HEX('ṭṛì')       | HEX('ḍḍumai')        |
+------------------+----------------------+
| E1B9ADE1B99BC3AC | E1B88DE1B88D756D6169 |
+------------------+----------------------+
```

8. Отрицательные целые числа (64-битный дополнительный код)
```sql
SELECT HEX(-128), HEX(-32768);
```
```text
+------------------+------------------+
| HEX(-128)        | HEX(-32768)      |
+------------------+------------------+
| FFFFFFFFFFFFFF80 | FFFFFFFFFFFF8000 |
+------------------+------------------+
```

9. Строки с буквами и цифрами
```sql
SELECT HEX('A1'), HEX('Hello!');
```
```text
+-----------+---------------+
| HEX('A1') | HEX('Hello!') |
+-----------+---------------+
| 4131      | 48656C6C6F21  |
+-----------+---------------+
```
