## Описание {#description}

Функция POSITION находит позицию подстроки в основной строке. Отсчёт позиций начинается с 1.

## Синтаксис {#syntax}

```sql
POSITION(<substr> IN <str>)

POSITION(<substr>, <str> [, <pos>])
```

## Параметры {#parameters}

| Параметр | Описание |
| -------- | ----------------------------------------------- |
| `substr` | Подстрока для поиска. Тип: VARCHAR |
| `str`    | Основная строка, в которой выполняется поиск. Тип: VARCHAR |
| `pos`    | Необязательный параметр, задающий начальную позицию (отсчёт с 1). Если указан, поиск начинается с этой позиции |

## Возвращаемое значение {#return-value}

Возвращает значение типа INT, обозначающее позицию первого вхождения подстроки в основную строку.

Правила поиска:
- Возвращает индекс позиции, отсчёт которого начинается с 1
- Если подстрока не найдена, возвращает 0
- Если указана начальная позиция, поиск начинается с этой позиции
- Поиск выполняется с учётом регистра

Особые случаи:
- Если любой из параметров равен NULL, возвращает NULL
- Если подстрока является пустой строкой, возвращает 1 (или начальную позицию)
- Если начальная позиция превышает длину строки, возвращает 0
- Если начальная позиция отрицательная, поиск выполняется с начала строки

## Примеры {#examples}

1. Базовый поиск (две формы синтаксиса)
```sql
SELECT POSITION('bar' IN 'foobarbar'), POSITION('bar', 'foobarbar');
```
```text
+----------------------------------+--------------------------------+
| POSITION('bar' IN 'foobarbar')   | POSITION('bar', 'foobarbar')   |
+----------------------------------+--------------------------------+
|                                4 |                              4 |
+----------------------------------+--------------------------------+
```

2. Поиск с указанием начальной позиции
```sql
SELECT POSITION('bar', 'foobarbar', 5), POSITION('xbar', 'foobar');
```
```text
+-----------------------------------+----------------------------------+
| POSITION('bar', 'foobarbar', 5)   | POSITION('xbar', 'foobar')       |
+-----------------------------------+----------------------------------+
|                                 7 |                                0 |
+-----------------------------------+----------------------------------+
```

3. Обработка значений NULL
```sql
SELECT POSITION('test' IN NULL), POSITION(NULL, 'test');
```
```text
+--------------------------+------------------------+
| POSITION('test' IN NULL) | POSITION(NULL, 'test') |
+--------------------------+------------------------+
| NULL                     | NULL                   |
+--------------------------+------------------------+
```

4. Обработка пустых строк
```sql
SELECT POSITION('' IN 'hello'), POSITION('world' IN '');
```
```text
+------------------------+------------------------+
| POSITION('' IN 'hello') | POSITION('world' IN '') |
+------------------------+------------------------+
|                      1 |                      0 |
+------------------------+------------------------+
```

5. Поиск с учётом регистра
```sql
SELECT POSITION('World' IN 'Hello World'), POSITION('world' IN 'Hello World');
```
```text
+----------------------------------+----------------------------------+
| POSITION('World' IN 'Hello World') | POSITION('world' IN 'Hello World') |
+----------------------------------+----------------------------------+
|                                7 |                                0 |
+----------------------------------+----------------------------------+
```

6. Поиск с разных позиций
```sql
SELECT POSITION('a', 'banana', 1), POSITION('a', 'banana', 3);
```
```text
+-----------------------------+-----------------------------+
| POSITION('a', 'banana', 1)  | POSITION('a', 'banana', 3)  |
+-----------------------------+-----------------------------+
|                           2 |                           4 |
+-----------------------------+-----------------------------+
```

7. Многобайтовые символы UTF-8
```sql
SELECT POSITION('ḍḍumai' IN 'ṭṛì ḍḍumai hello'), POSITION('hello', 'ṭṛì ḍḍumai hello', 8);
```
```text
+-------------------------------------------------------+---------------------------------------------------+
| POSITION('ḍḍumai' IN 'ṭṛì ḍḍumai hello')              | POSITION('hello', 'ṭṛì ḍḍumai hello', 8)          |
+-------------------------------------------------------+---------------------------------------------------+
|                                                     5 |                                                12 |
+-------------------------------------------------------+---------------------------------------------------+
```

8. Поиск специальных символов
```sql
SELECT POSITION('@' IN 'user@domain.com'), POSITION('.', 'user@domain.com', 10);
```
```text
+----------------------------------+--------------------------------------+
| POSITION('@' IN 'user@domain.com') | POSITION('.', 'user@domain.com', 10) |
+----------------------------------+--------------------------------------+
|                                5 |                                   12 |
+----------------------------------+--------------------------------------+
```

9. Начальная позиция за пределами строки
```sql
SELECT POSITION('test', 'hello world', 20), POSITION('test', 'hello world', 0);
```
```text
+--------------------------------------+-------------------------------------+
| POSITION('test', 'hello world', 20)  | POSITION('test', 'hello world', 0)  |
+--------------------------------------+-------------------------------------+
|                                   0 |                                   0 |
+--------------------------------------+-------------------------------------+
```

10. Поиск в строках с числами и символами
```sql
SELECT POSITION('123' IN '456123789'), POSITION('-', 'phone: 123-456-7890', 11);
```
```text
+------------------------------+-------------------------------------------+
| POSITION('123' IN '456123789') | POSITION('-', 'phone: 123-456-7890', 11) |
+------------------------------+-------------------------------------------+
|                            4 |                                        11 |
+------------------------------+-------------------------------------------+
```
