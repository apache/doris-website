## Описание {#description}

Функция APPEND_TRAILING_CHAR_IF_ABSENT гарантирует, что строка заканчивается указанным символом. Если этот символ отсутствует в конце строки, он добавляется; если уже присутствует, строка остаётся без изменений.

## Синтаксис {#syntax}

```sql
APPEND_TRAILING_CHAR_IF_ABSENT(<str>, <trailing_char>)
```

## Параметры {#parameters}

| Параметр | Описание |
| ------------------ | ----------------------------------------- |
| `<str>` | Строка для обработки. Тип: VARCHAR |
| `<trailing_char>` | Символ, который должен находиться в конце строки. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR:
- Если `<trailing_char>` отсутствует в конце `<str>`, возвращает результат конкатенации `<str>` и `<trailing_char>`
- Если `<trailing_char>` уже присутствует в конце `<str>`, возвращает исходную строку `<str>`

Особые случаи:
- Если какой-либо аргумент равен NULL, возвращает NULL
- Если `<str>` — пустая строка, возвращает `<trailing_char>`

## Примеры {#examples}

1. Базовое использование: добавление отсутствующего символа
```sql
SELECT APPEND_TRAILING_CHAR_IF_ABSENT('a', 'c');
```
```text
+------------------------------------------+
| append_trailing_char_if_absent('a', 'c') |
+------------------------------------------+
| ac                                       |
+------------------------------------------+
```

2. Символ уже присутствует и не добавляется
```sql
SELECT APPEND_TRAILING_CHAR_IF_ABSENT('ac', 'c');
```
```text
+-------------------------------------------+
| append_trailing_char_if_absent('ac', 'c') |
+-------------------------------------------+
| ac                                        |
+-------------------------------------------+
```

3. Обработка пустой строки
```sql
SELECT APPEND_TRAILING_CHAR_IF_ABSENT('', '/');
```
```text
+------------------------------------------+
| append_trailing_char_if_absent('', '/')  |
+------------------------------------------+
| /                                        |
+------------------------------------------+
```

4. Обработка значения NULL
```sql
SELECT APPEND_TRAILING_CHAR_IF_ABSENT(NULL, 'c');
```
```text
+-------------------------------------------+
| append_trailing_char_if_absent(NULL, 'c') |
+-------------------------------------------+
| NULL                                      |
+-------------------------------------------+
```

5. Символ UTF-8
```sql
SELECT APPEND_TRAILING_CHAR_IF_ABSENT('acf', 'ṛ');
```
```text
+----------------------------------------------+
| APPEND_TRAILING_CHAR_IF_ABSENT('acf', 'ṛ')   |
+----------------------------------------------+
| acfṛ                                         |
+----------------------------------------------+
```
