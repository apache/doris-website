## Описание {#description}

Функция RANDOM_BYTES генерирует случайную последовательность байтов заданной длины. Возвращаемая последовательность байтов представлена в виде шестнадцатеричной строки.

## Синтаксис {#syntax}

```sql
RANDOM_BYTES(<len>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -------- | ----------------------------------------- |
| `<len>` | Количество случайных байтов для генерации. Тип: INT |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR: случайную последовательность байтов, закодированную в шестнадцатеричном формате (с префиксом `0x`).

Особые случаи:
- `<len>` должен быть больше 0, иначе возвращается ошибка
- Если параметр равен NULL, возвращается NULL
- Каждый вызов генерирует случайный результат

## Примеры {#examples}

1. Базовое использование: генерация случайной последовательности длиной 8 байт
```sql
SELECT random_bytes(8);
```
```text
+--------------------+
| random_bytes(8)    |
+--------------------+
| 0x1a2b3c4d5e6f7089 |
+--------------------+
```

2. Генерация короткой последовательности
```sql
SELECT random_bytes(4);
```
```text
+----------------+
| random_bytes(4) |
+----------------+
| 0xab12cd34     |
+----------------+
```

3. Недопустимый параметр: отрицательное число
```sql
SELECT random_bytes(-1);
```
```text
ERROR 1105 (HY000): errCode = 2, detailMessage = (10.16.10.3)[INVALID_ARGUMENT]argument -1 of function random_bytes at row 0 was invalid.
```

4. Обработка значения NULL
```sql
SELECT random_bytes(NULL);
```
```text
+--------------------+
| random_bytes(NULL) |
+--------------------+
| NULL               |
+--------------------+
```

5. Генерация более длинной последовательности (16 байт)
```sql
SELECT random_bytes(16);
```
```text
+------------------------------------+
| random_bytes(16)                   |
+------------------------------------+
| 0x1a2b3c4d5e6f708192a3b4c5d6e7f809 |
+------------------------------------+
```
