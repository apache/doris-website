## Описание {#description}

Функция `LEVENSHTEIN` вычисляет [расстояние Левенштейна](https://en.wikipedia.org/wiki/Edit_distance) между двумя строками.

Расстояние Левенштейна равно минимальному количеству операций редактирования отдельных символов, необходимых для преобразования одной строки в другую. Поддерживаются следующие операции:

- Вставка символа
- Удаление символа
- Замена символа

Функция вычисляет расстояние по символам UTF-8, а не по байтам. Поэтому каждый многобайтовый символ, например китайский иероглиф, учитывается как один символ.

:::note
Начиная с 4.2.0
:::

## Псевдонимы {#alias}

- `LEVENSHTEIN_DISTANCE`
- `EDIT_DISTANCE`

## Синтаксис {#syntax}

```sql
LEVENSHTEIN(<str1>, <str2>)
LEVENSHTEIN_DISTANCE(<str1>, <str2>)
EDIT_DISTANCE(<str1>, <str2>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<str1>` | Первая строка. Тип: VARCHAR |
| `<str2>` | Вторая строка. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа INT, представляющее расстояние Левенштейна между двумя строками.

Особые случаи:

- Если хотя бы один аргумент равен NULL, возвращает NULL.
- Если строки одинаковы, возвращает 0.
- Если одна строка пуста, возвращает количество символов в другой строке.
- Функция коммутативна: `LEVENSHTEIN(a, b)` и `LEVENSHTEIN(b, a)` возвращают одинаковый результат.

## Примеры {#examples}

1. Базовое использование

```sql
SELECT levenshtein('kitten', 'sitting');
```

```text
+----------------------------------+
| levenshtein('kitten', 'sitting') |
+----------------------------------+
|                                3 |
+----------------------------------+
```

Строку `kitten` можно преобразовать в `sitting` с помощью 3 операций: заменить `k` на `s`, заменить `e` на `i` и вставить `g` в конец.

2. Одинаковые строки

```sql
SELECT levenshtein('abc', 'abc');
```

```text
+---------------------------+
| levenshtein('abc', 'abc') |
+---------------------------+
|                         0 |
+---------------------------+
```

3. Пустая строка

```sql
SELECT levenshtein('', 'abc'), levenshtein('数据库', '');
```

```text
+------------------------+------------------------------+
| levenshtein('', 'abc') | levenshtein('数据库', '')    |
+------------------------+------------------------------+
|                      3 |                            3 |
+------------------------+------------------------------+
```

4. Символы UTF-8

```sql
SELECT levenshtein('你好世界', '你好世间');
```

```text
+---------------------------------------------+
| levenshtein('你好世界', '你好世间')         |
+---------------------------------------------+
|                                           1 |
+---------------------------------------------+
```

Замена `界` на `间` требует 1 операции редактирования.

5. Перестановка соседних символов считается двумя операциями редактирования

```sql
SELECT levenshtein('abcd', 'abdc');
```

```text
+-----------------------------+
| levenshtein('abcd', 'abdc') |
+-----------------------------+
|                           2 |
+-----------------------------+
```

При вычислении расстояния Левенштейна перестановка соседних символов не считается одной операцией, поэтому расстояние между `abcd` и `abdc` равно 2.

6. Использование псевдонимов

```sql
SELECT levenshtein_distance('abcd', 'abdc'), edit_distance('kitten', 'sitting');
```

```text
+--------------------------------------+------------------------------------+
| levenshtein_distance('abcd', 'abdc') | edit_distance('kitten', 'sitting') |
+--------------------------------------+------------------------------------+
|                                    2 |                                  3 |
+--------------------------------------+------------------------------------+
```

7. Аргументы со значением NULL

```sql
SELECT levenshtein(NULL, 'abc'), levenshtein('abc', NULL);
```

```text
+--------------------------+--------------------------+
| levenshtein(NULL, 'abc') | levenshtein('abc', NULL) |
+--------------------------+--------------------------+
|                     NULL |                     NULL |
+--------------------------+--------------------------+
```
