## Описание {#description}

Функция XPATH_STRING разбирает строку XML и возвращает первый узел XML, соответствующий выражению [XPath](https://www.w3.org/TR/xpath-10/).

:::tip
Эта функция поддерживается начиная с версии 3.0.6.
:::

## Синтаксис {#syntax}

```sql
XPATH_STRING(<xml_string>, <xpath_expression>)
```

## Параметры {#parameters}
| Параметр | Описание                                   |
| --------- | ----------------------------------------------|
| `<xml_string>` | Исходная строка. Тип: VARCHAR             |
| `<xpath_expression>` | Выражение [XPath](https://www.w3.org/TR/xpath-10/). Тип: VARCHAR    |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, содержащее содержимое первого узла XML, соответствующего выражению XPath.

Особые случаи:
- Функция вызывает ошибку, если xml или xpath имеют неверный формат.

## Примеры {#examples}

1. Простое извлечение значения узла
```sql
SELECT xpath_string('<a>123</a>', '/a');
```
```text
+-----------------------------------+
| xpath_string('<a>123</a>', '/a')  |
+-----------------------------------+
| 123                               |
+-----------------------------------+
```

2. Извлечение вложенного элемента
```sql
SELECT xpath_string('<a><b>123</b></a>', '/a/b');
```
```text
+--------------------------------------------+
| xpath_string('<a><b>123</b></a>', '/a/b')  |
+--------------------------------------------+
| 123                                        |
+--------------------------------------------+
```

3. Использование атрибутов
```sql
SELECT xpath_string('<a><b id="1">123</b></a>', '//b[@id="1"]');
```
```text
+----------------------------------------------------------+
| xpath_string('<a><b id="1">123</b></a>', '//b[@id="1"]') |
+----------------------------------------------------------+
| 123                                                      |
+----------------------------------------------------------+
```

4. Использование позиционных предикатов
```sql
SELECT xpath_string('<a><b>1</b><b>2</b></a>', '/a/b[2]');
```
```text
+----------------------------------------------------+
| xpath_string('<a><b>1</b><b>2</b></a>', '/a/b[2]') |
+----------------------------------------------------+
| 2                                                  |
+----------------------------------------------------+
```

5. Входное значение NULL
```sql
SELECT xpath_string(NULL, '/a');
```
```text
+--------------------------+
| xpath_string(NULL, '/a') |
+--------------------------+
| NULL                     |
+--------------------------+
```

6. Разделы CDATA: содержимое CDATA возвращается как обычный текст
```sql
SELECT xpath_string('<a><![CDATA[123]]></a>', '/a');
```
```text
+----------------------------------------------+
| xpath_string('<a><![CDATA[123]]></a>', '/a') |
+----------------------------------------------+
| 123                                          |
+----------------------------------------------+
```

7. Комментарии XML пропускаются
```sql
SELECT xpath_string('<a><!-- comment -->123</a>', '/a');
```
```text
+--------------------------------------------------+
| xpath_string('<a><!-- comment -->123</a>', '/a') |
+--------------------------------------------------+
| 123                                              |
+--------------------------------------------------+
```

8. Путь не соответствует ни одному узлу: возвращается пустая строка
```sql
SELECT xpath_string('<a>123</a>', '/b');
```
```text
+----------------------------------+
| xpath_string('<a>123</a>', '/b') |
+----------------------------------+
|                                  |
+----------------------------------+
```

9. Некорректный XML: функция вызывает ошибку
```sql
SELECT xpath_string('<a><!-- comment -->123/a>', '/a');
ERROR 1105 (HY000): errCode = 2, detailMessage = [INVALID_ARGUMENT]Function xpath_string failed to parse XML string: Start-end tags mismatch
```

### Ключевые слова {#keywords}
