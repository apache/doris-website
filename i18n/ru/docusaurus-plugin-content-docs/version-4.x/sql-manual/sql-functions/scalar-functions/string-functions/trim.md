## Описание {#description}

Функция TRIM используется для удаления подряд идущих пробелов или указанных строк с обоих концов строки. Если второй параметр не указан, удаляются начальные и конечные пробелы; если указан, функция удаляет указанную строку целиком с обоих концов.

## Синтаксис {#syntax}

```sql
TRIM(<str>[, <rhs>])
```

## Параметры {#parameters}

| Параметр | Описание |
| --------- | ----------- |
| `<str>` | Строка для обработки. Тип: VARCHAR |
| `<rhs>` | Необязательный параметр, символы для удаления с обоих концов строки. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR.

Особые случаи:
- Если какой-либо параметр равен NULL, возвращается NULL
- Если rhs не указан, удаляются начальные и конечные пробелы
- Если rhs указан, строка rhs удаляется целиком с обоих концов (а не посимвольно)

## Примеры {#examples}

1. Удаление начальных и конечных пробелов
```sql
SELECT trim('   ab d   ') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. Удаление указанных строк с обоих концов: `trim(str, rhs)` многократно удаляет `<rhs>` с начала и конца строки `<str>`, пока ни один из концов не будет содержать `<rhs>`.
```sql
SELECT trim('ababccaab', 'ab') str;
```
```text
+------+
| str  |
+------+
| cca  |
+------+
```

3. Поддержка символов UTF-8
```sql
SELECT trim('   ṭṛì ḍḍumai   ');
```
```text
+------------------------------+
| trim('   ṭṛì ḍḍumai   ')     |
+------------------------------+
| ṭṛì ḍḍumai                   |
+------------------------------+
```

4. Если совпадающего префикса или суффикса нет, возвращается исходная строка
```sql
SELECT trim('Hello World', 'xyz');
```
```text
+--------------------------------+
| trim('Hello World', 'xyz')     |
+--------------------------------+
| Hello World                    |
+--------------------------------+
```

5. Обработка значений NULL
```sql
SELECT trim(NULL), trim('Hello', NULL);
```
```text
+------------+-----------------------+
| trim(NULL) | trim('Hello', NULL)   |
+------------+-----------------------+
| NULL       | NULL                  |
+------------+-----------------------+
```

6. Обработка пустой строки
```sql
SELECT trim(''), trim('abc', '');
```
```text
+----------+------------------+
| trim('') | trim('abc', '')  |
+----------+------------------+
|          | abc              |
+----------+------------------+
```

7. Удаление повторяющегося шаблона с обоих концов
```sql
SELECT trim('abcabcabc', 'abc');
```
```text
+------------------------------+
| trim('abcabcabc', 'abc')     |
+------------------------------+
|                              |
+------------------------------+
```

8. Асимметричное удаление
```sql
SELECT trim('abcHelloabc', 'abc');
```
```text
+--------------------------------+
| trim('abcHelloabc', 'abc')     |
+--------------------------------+
| Hello                          |
+--------------------------------+
```

9. Строка UTF-8 с шаблоном удаления в UTF-8: удаляется только начальная подстрока `ṭṛì`, поскольку конец строки не совпадает с шаблоном (`+++`), поэтому trim прекращает удаление с этого конца.
```sql
SELECT trim('ṭṛì ḍḍumai+++', 'ṭṛì');
```
```text
+--------------------------------------------+
| trim('ṭṛì ḍḍumai+++', 'ṭṛì')               |
+--------------------------------------------+
|  ḍḍumai+++                                 |
+--------------------------------------------+
```
