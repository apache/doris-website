## Описание {#description}

Функция MASK_FIRST_N используется для маскирования первых N байт строки. В первых N байтах она заменяет прописные буквы на `X`, строчные буквы на `x`, а цифры на `n`.

## Синтаксис {#syntax}

```sql
MASK_FIRST_N(<str>[, <n>])
```

## Параметры {#parameters}

| Параметр | Описание |
| ------- | ----------------------------------------- |
| `<str>` | Строка для маскирования. Тип: VARCHAR |
| `<n>` | Количество первых N байт для маскирования (необязательный параметр; по умолчанию маскируется вся строка). Тип: INT |

## Возвращаемое значение {#return-value}

Возвращает строку типа VARCHAR с замаскированными первыми N байтами.

Особые случаи:
- Если любой из параметров равен NULL, возвращает NULL
- Символы, не являющиеся буквами или цифрами, остаются без изменений
- Если `<n>` превышает длину строки, маскирует всю строку

## Примеры {#examples}

1. Базовое использование: маскирование первых 4 байт
```sql
SELECT mask_first_n('1234-5678', 4);
```
```text
+------------------------------+
| mask_first_n('1234-5678', 4) |
+------------------------------+
| nnnn-5678                    |
+------------------------------+
```

2. Без указания n (маскируется вся строка)
```sql
SELECT mask_first_n('abc123');
```
```text
+-----------------------+
| mask_first_n('abc123') |
+-----------------------+
| xxxnnn                |
+-----------------------+
```

3. n превышает длину строки
```sql
SELECT mask_first_n('Hello', 100);
```
```text
+----------------------------+
| mask_first_n('Hello', 100) |
+----------------------------+
| Xxxxx                      |
+----------------------------+
```

4. Обработка значения NULL
```sql
SELECT mask_first_n(NULL, 5);
```
```text
+-----------------------+
| mask_first_n(NULL, 5) |
+-----------------------+
| NULL                  |
+-----------------------+
```

5. n равен 0 (символы не маскируются)
```sql
SELECT mask_first_n('Hello123', 0);
```
```text
+-----------------------------+
| mask_first_n('Hello123', 0) |
+-----------------------------+
| Hello123                    |
+-----------------------------+
```

6. n превышает длину строки (маскируется вся строка)
```sql
SELECT mask_first_n('Test', 100);
```
```text
+---------------------------+
| mask_first_n('Test', 100) |
+---------------------------+
| Xxxx                      |
+---------------------------+
```

7. Маскирование начальной части адреса электронной почты
```sql
SELECT mask_first_n('user@example.com', 6);
```
```text
+-------------------------------------+
| mask_first_n('user@example.com', 6) |
+-------------------------------------+
| xxxx@xxample.com                    |
+-------------------------------------+
```

8. Маскирование первых 3 цифр номера телефона
```sql
SELECT mask_first_n('13812345678', 3);
```
```text
+--------------------------------+
| mask_first_n('13812345678', 3) |
+--------------------------------+
| nnn12345678                    |
+--------------------------------+
```

9. Сочетание букв, цифр и специальных символов
```sql
SELECT mask_first_n('Abc-123-XYZ', 7);
```
```text
+---------------------------------+
| mask_first_n('Abc-123-XYZ', 7)  |
+---------------------------------+
| Xxx-nnn-XYZ                     |
+---------------------------------+
```

10. Обработка символов UTF-8 (побайтовое маскирование)
```sql
SELECT mask_first_n('ṭṛWorld123', 7);
```
```text
+-----------------------------------+
| mask_first_n('ṭṛWorld123', 7)     |
+-----------------------------------+
| ṭṛXorld123                        |
+-----------------------------------+
```

```sql
SELECT mask_first_n('eeeéèêëìí1234');
```
```text
+-------------------------------------+
| mask_first_n('eeeéèêëìí1234')       |
+-------------------------------------+
| xxxéèêëìínnnn                       |
+-------------------------------------+
```
