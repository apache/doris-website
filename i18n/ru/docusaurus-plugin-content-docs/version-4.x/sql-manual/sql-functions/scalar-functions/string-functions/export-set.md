## Описание {#description}

Функция `EXPORT_SET` преобразует каждый бит целого числа в заданную строку и объединяет эти строки в результирующую строку. Для каждого бита в `bits`, равного 1, в соответствующей позиции результата выводится строка `on`; для каждого бита, равного 0, выводится строка `off`. Биты проверяются справа налево (то есть от младшего бита к старшему), но объединяются в результирующую строку слева направо. Биты разделяются строкой `separator` (по умолчанию запятой `,`).

Количество отображаемых битов определяется параметром `number_of_bits` и по умолчанию составляет 64 бита. Если параметр не указан или выходит за допустимый диапазон (больше 64), автоматически используется 64 бита.

Эта функция работает аналогично [функции EXPORT_SET](https://dev.mysql.com/doc/refman/8.4/en/string-functions.html#function_export-set) в MySQL.

## Синтаксис {#syntax}

```sql
EXPORT_SET(bits, on, off[, separator[, number_of_bits]])
```

## Параметры {#parameters}

| Параметр          | Описание |
|-------------------|-------------|
| `bits`            | Целое число типа LARGEINT, используемое для преобразования. Если значение меньше -2^63, оно обрабатывается как -2^63. Если оно больше 2^64 - 1, оно обрабатывается как 2^63 - 1. |
| `on`              | Строка, отображаемая, когда бит равен 1 |
| `off`             | Строка, отображаемая, когда бит равен 0 |
| `separator`       | Необязательный параметр: строка для разделения битов, по умолчанию ',' |
| `number_of_bits`  | Необязательный параметр: количество битов, отображаемых в результате; поддерживается целочисленный тип INT. Значение по умолчанию: 64. Если значение выходит за пределы диапазона [0, 64], автоматически используется значение по умолчанию. |

## Возвращаемое значение {#return-value}

Возвращает строку. Каждый бит в `bits` обрабатывается в порядке от младшего к старшему: если он равен 1, он заменяется на `on`; если равен 0, на `off`. Полученные строки объединяются в том же порядке. Биты разделяются строкой `separator`, а итоговый результат содержит `number_of_bits` битов.

Если `number_of_bits` выходит за пределы диапазона [-2^31, 2^31 - 1] или любой параметр функции равен NULL, возвращается NULL.
