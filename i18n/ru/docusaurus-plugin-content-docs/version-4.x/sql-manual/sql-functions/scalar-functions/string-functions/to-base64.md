## Описание {#description}

Функция TO_BASE64 преобразует входную строку в формат Base64. Base64 представляет собой способ кодирования на основе 64 печатных символов, который обычно используется для передачи данных в протоколах, не поддерживающих двоичные данные, например в электронной почте, параметрах URL, JSON и т. д. Эта функция соответствует стандарту RFC 4648 и использует стандартный набор символов Base64 (A-Z, a-z, 0-9, +, /) и символ заполнения (=).

## Синтаксис {#syntax}

```sql
TO_BASE64(<str>)
```

## Параметры {#parameters}
| Параметр | Описание |
| --------- | ---------------------------------------------- |
| `<str>` | Строка для кодирования в Base64. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, содержащее строку в кодировке Base64.

Правила кодирования:
- Использует стандартный набор символов Base64: A-Z, a-z, 0-9, +, /
- Использует = в качестве символа заполнения, чтобы длина результата была кратна 4
- Поддерживает корректное кодирование многобайтовых символов UTF-8
- Результирующая строка содержит только печатные символы ASCII

Особые случаи:
- Если входное значение равно NULL, возвращает NULL
- Если входное значение является пустой строкой, возвращает пустую строку
- Автоматически обрабатывает кодировку символов UTF-8
- Длина результата всегда равна числу байтов входной строки, умноженному на 4/3 (с округлением вверх до значения, кратного 4)

## Примеры {#examples}

1. Базовое кодирование символов
```sql
SELECT TO_BASE64('1'), TO_BASE64('A');
```
```text
+----------------+----------------+
| TO_BASE64('1') | TO_BASE64('A') |
+----------------+----------------+
| MQ==           | QQ==           |
+----------------+----------------+
```

2. Кодирование строки из нескольких символов
```sql
SELECT TO_BASE64('234'), TO_BASE64('Hello');
```
```text
+------------------+--------------------+
| TO_BASE64('234') | TO_BASE64('Hello') |
+------------------+--------------------+
| MjM0             | SGVsbG8=           |
+------------------+--------------------+
```

3. Обработка NULL и пустой строки
```sql
SELECT TO_BASE64(NULL), TO_BASE64('');
```
```text
+-----------------+---------------+
| TO_BASE64(NULL) | TO_BASE64('') |
+-----------------+---------------+
| NULL            |               |
+-----------------+---------------+
```

4. Кодирование длинной строки
```sql
SELECT TO_BASE64('Hello World'), TO_BASE64('The quick brown fox');
```
```text
+-------------------------+-------------------------------+
| TO_BASE64('Hello World') | TO_BASE64('The quick brown fox') |
+-------------------------+-------------------------------+
| SGVsbG8gV29ybGQ=        | VGhlIHF1aWNrIGJyb3duIGZveA==  |
+-------------------------+-------------------------------+
```

5. Числа и специальные символы
```sql
SELECT TO_BASE64('123456'), TO_BASE64('!@#$%^&*()');
```
```text
+---------------------+------------------------+
| TO_BASE64('123456') | TO_BASE64('!@#$%^&*()') |
+---------------------+------------------------+
| MTIzNDU2            | IUAjJCVeJiooKQ==       |
+---------------------+------------------------+
```

6. Многобайтовые символы UTF-8
```sql
SELECT TO_BASE64('ṭṛì'), TO_BASE64('ḍḍumai hello');
```
```text
+-------------------+---------------------------+
| TO_BASE64('ṭṛì')  | TO_BASE64('ḍḍumai hello') |
+-------------------+---------------------------+
| 4bmt4bmbw6w=      | 4bmN4bmNdW1haSBoZWxsbw==  |
+-------------------+---------------------------+
```

7. Кодирование адресов электронной почты
```sql
SELECT TO_BASE64('user@example.com'), TO_BASE64('admin.test@company.org');
```
```text
+------------------------------+-----------------------------------+
| TO_BASE64('user@example.com') | TO_BASE64('admin.test@company.org') |
+------------------------------+-----------------------------------+
| dXNlckBleGFtcGxlLmNvbQ==     | YWRtaW4udGVzdEBjb21wYW55Lm9yZw== |
+------------------------------+-----------------------------------+
```

8. Кодирование данных JSON
```sql
SELECT TO_BASE64('{"name":"John","age":30}'), TO_BASE64('[1,2,3,4,5]');
```
```text
+--------------------------------------+----------------------+
| TO_BASE64('{"name":"John","age":30}') | TO_BASE64('[1,2,3,4,5]') |
+--------------------------------------+----------------------+
| eyJuYW1lIjoiSm9obiIsImFnZSI6MzB9     | WzEsMiwzLDQsNV0=     |
+--------------------------------------+----------------------+
```

9. Строки разной длины и заполнение
```sql
SELECT TO_BASE64('a'), TO_BASE64('ab'), TO_BASE64('abc');
```
```text
+----------------+-----------------+------------------+
| TO_BASE64('a') | TO_BASE64('ab') | TO_BASE64('abc') |
+----------------+-----------------+------------------+
| YQ==           | YWI=            | YWJj             |
+----------------+-----------------+------------------+
```

### Ключевые слова {#keywords}

    TO_BASE64, BASE64
