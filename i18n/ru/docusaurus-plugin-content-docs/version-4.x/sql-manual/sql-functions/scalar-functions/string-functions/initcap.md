## Описание {#description}

Функция INITCAP делает первую букву каждого слова в строке заглавной, а остальные буквы строчными. Словом считается последовательность букв и цифр, отделённая от других слов символами, не являющимися буквами или цифрами. Эта функция подходит для оформления имён, заголовков и других случаев, когда требуется стандартное оформление регистра.

## Синтаксис {#syntax}

```sql
INITCAP(<str>)
```

## Параметры {#parameters}

| Параметр | Описание |
|---------|-----------|
| `<str>` | Строка, в которой нужно изменить регистр символов. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, содержащее преобразованную строку.

Правила преобразования:
- Первая буква каждого слова переводится в верхний регистр
- Остальные буквы в слове переводятся в нижний регистр
- Слова разделяются символами, не являющимися буквами или цифрами (пробелами, знаками препинания, символами и т. д.)
- Регистр цифр не изменяется
- Поддерживается преобразование регистра символов Unicode

Особые случаи:
- Если параметр равен NULL, возвращается NULL
- Если строка пустая, возвращается пустая строка
- Последовательность символов, не являющихся буквами или цифрами, считается одним разделителем
- Буква в начале строки становится заглавной

## Примеры {#examples}

1. Простое преобразование первых букв слов в заглавные
```sql
SELECT INITCAP('hello world');
```
```text
+------------------------+
| INITCAP('hello world') |
+------------------------+
| Hello World            |
+------------------------+
```

2. Преобразование смешанного регистра
```sql
SELECT INITCAP('hELLo WoRLD');
```
```text
+------------------------+
| INITCAP('hELLo WoRLD') |
+------------------------+
| Hello World            |
+------------------------+
```

3. Обработка значения NULL
```sql
SELECT INITCAP(NULL);
```
```text
+---------------+
| INITCAP(NULL) |
+---------------+
| NULL          |
+---------------+
```

4. Строка с цифрами и символами
```sql
SELECT INITCAP('hello hello.,HELLO123HELlo');
```
```text
+---------------------------------------+
| INITCAP('hello hello.,HELLO123HELlo') |
+---------------------------------------+
| Hello Hello.,Hello123hello            |
+---------------------------------------+
```

5. Пустая строка
```sql
SELECT INITCAP('');
```
```text
+-------------+
| INITCAP('') |
+-------------+
|             |
+-------------+
```

6. Несколько разделителей, не являющихся буквами или цифрами
```sql
SELECT INITCAP('word1@word2#word3$word4');
```
```text
+------------------------------------+
| INITCAP('word1@word2#word3$word4') |
+------------------------------------+
| Word1@Word2#Word3$Word4            |
+------------------------------------+
```

7. Слова с многобайтовыми символами UTF-8
```sql
SELECT INITCAP('ṭṛì ḍḍumai hello');
```
```text
+--------------------------------------+
| INITCAP('ṭṛì ḍḍumai hello')          |
+--------------------------------------+
| Ṭṛì Ḍḍumai Hello                     |
+--------------------------------------+
```

8. Обычное написание имён с заглавной буквы
```sql
SELECT INITCAP('john doe'), INITCAP('MARY JANE');
```
```text
+---------------------+----------------------+
| INITCAP('john doe') | INITCAP('MARY JANE') |
+---------------------+----------------------+
| John Doe            | Mary Jane            |
+---------------------+----------------------+
```

9. Предложения со смешанным регистром
```sql
SELECT INITCAP('the quick brown fox'), INITCAP('DATABASE management SYSTEM');
```
```text
+--------------------------------+---------------------------------------+
| INITCAP('the quick brown fox') | INITCAP('DATABASE management SYSTEM') |
+--------------------------------+---------------------------------------+
| The Quick Brown Fox            | Database Management System            |
+--------------------------------+---------------------------------------+
```

10. Несколько пробелов и соседние знаки препинания
```sql
SELECT INITCAP('word1   word2--word3'), INITCAP('hello, world! how are you?');
```
```text
+---------------------------------+---------------------------------------+
| INITCAP('word1   word2--word3') | INITCAP('hello, world! how are you?') |
+---------------------------------+---------------------------------------+
| Word1   Word2--Word3            | Hello, World! How Are You?            |
+---------------------------------+---------------------------------------+
```
