## Описание {#description}

Функция PARSE_DATA_SIZE разбирает строку с единицами измерения объёма данных (например, "1.5GB") и преобразует её в числовое значение в байтах.

## Синтаксис {#syntax}

```sql
PARSE_DATA_SIZE(<str>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -------- | ----------------------------------------- |
| `<str>` | Строка с размером данных и единицей измерения (например, "100MB", "2.5GB"). Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа LARGEINT, представляющее размер в байтах после преобразования.

Особые случаи:
- Поддерживаемые единицы измерения (регистр учитывается; используйте именно эти обозначения): B, kB, MB, GB, TB, PB, EB, ZB, YB
- Для единиц измерения используется основание 1024 (например, 1kB = 1024B)
- Поддерживаются десятичные дроби (например, "2.5MB")
- Если формат параметра некорректен, возвращается ошибка
- Если параметр равен NULL, возвращается NULL. В ветке Doris 4.1 начиная с версии 4.1.5 строки со значением NULL в столбцах, допускающих такие значения, пропускаются до разбора строкового содержимого

**Таблица поддерживаемых единиц измерения:**

| Единица измерения | Название | Байты |
|------|------|-------|
| B    | Байты      | 1          |
| kB   | Килобайты  | 1024       |
| MB   | Мегабайты  | 1024²      |
| GB   | Гигабайты  | 1024³      |
| TB   | Терабайты  | 1024⁴      |
| PB   | Петабайты  | 1024⁵      |
| EB   | Эксабайты  | 1024⁶      |

## Примеры {#example}

1. Базовое использование: разбор значения в байтах
```sql
SELECT parse_data_size('1024B');
```
```text
+--------------------------+
| parse_data_size('1024B') |
+--------------------------+
| 1024                     |
+--------------------------+
```

2. Разбор значения в килобайтах
```sql
SELECT parse_data_size('1kB');
```
```text
+------------------------+
| parse_data_size('1kB') |
+------------------------+
| 1024                   |
+------------------------+
```

3. Разбор дробного значения в мегабайтах
```sql
SELECT parse_data_size('2.5MB');
```
```text
+--------------------------+
| parse_data_size('2.5MB') |
+--------------------------+
| 2621440                  |
+--------------------------+
```

4. Разбор значения в гигабайтах
```sql
SELECT parse_data_size('1GB');
```
```text
+------------------------+
| parse_data_size('1GB') |
+------------------------+
| 1073741824             |
+------------------------+
```

5. Разбор значения в терабайтах
```sql
SELECT parse_data_size('1TB');
```
```text
+------------------------+
| parse_data_size('1TB') |
+------------------------+
| 1099511627776          |
+------------------------+
```

6. Неподдерживаемая единица измерения: ошибка
```sql
SELECT parse_data_size('1iB');
```
```text
ERROR 1105 (HY000): errCode = 2, detailMessage = (10.16.10.3)[INVALID_ARGUMENT]Invalid Input argument "1iB" of function parse_data_size
```

7. Входное значение NULL
```sql
SELECT parse_data_size(NULL);
```
```text
+-----------------------+
| parse_data_size(NULL) |
+-----------------------+
| NULL                  |
+-----------------------+
```
