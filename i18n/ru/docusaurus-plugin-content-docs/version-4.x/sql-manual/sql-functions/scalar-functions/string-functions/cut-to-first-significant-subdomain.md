## Описание {#description}

Функция CUT_TO_FIRST_SIGNIFICANT_SUBDOMAIN извлекает значимую часть доменного имени из URL, включая домен верхнего уровня и поддомены вплоть до «первого значимого поддомена». Если входной URL некорректен, функция возвращает пустую строку.

## Синтаксис {#syntax}

```sql
CUT_TO_FIRST_SIGNIFICANT_SUBDOMAIN(<url>)
```

## Параметры {#parameters}
| Параметр | Описание                                   |
| --------- | --------------------------------------------- |
| `<url>` | Строка URL для обработки. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, содержащее извлечённую часть доменного имени.

Особые случаи:
- Если url равен NULL, возвращает NULL
- Если url не соответствует допустимому формату доменного имени, возвращает пустую строку

## Примеры {#examples}

1. Обработка обычного доменного имени
```sql
SELECT cut_to_first_significant_subdomain('www.baidu.com');
```
```text
+-----------------------------------------------------+
| cut_to_first_significant_subdomain('www.baidu.com') |
+-----------------------------------------------------+
| baidu.com                                           |
+-----------------------------------------------------+
```

2. Обработка многоуровневого доменного имени
```sql
SELECT cut_to_first_significant_subdomain('www.google.com.cn');
```
```text
+---------------------------------------------------------+
| cut_to_first_significant_subdomain('www.google.com.cn') |
+---------------------------------------------------------+
| google.com.cn                                           |
+---------------------------------------------------------+
```

3. Обработка некорректного доменного имени
```sql
SELECT cut_to_first_significant_subdomain('wwwwwwww');
```
```text
+------------------------------------------------+
| cut_to_first_significant_subdomain('wwwwwwww') |
+------------------------------------------------+
|                                                |
+------------------------------------------------+
```
