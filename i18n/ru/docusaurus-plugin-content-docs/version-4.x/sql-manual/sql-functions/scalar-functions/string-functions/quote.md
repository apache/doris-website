## Описание {#description}

Функция QUOTE заключает строку в одинарные кавычки и экранирует специальные символы внутри неё, обеспечивая её безопасное использование в операторах SQL.

## Синтаксис {#syntax}

```sql
QUOTE(<str>)
```

## Параметры {#parameters}

| Параметр | Описание |
| ------- | ----------------------------------------- |
| `<str>` | Входная строка, которую нужно заключить в кавычки. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает строку типа VARCHAR, заключённую в одинарные кавычки, с экранированными специальными символами.

Особые случаи:
- Если входное значение равно NULL, возвращается строка 'NULL' (без кавычек)
- Одинарные кавычки `'` экранируются как `\'`
- Обратные косые черты `\` экранируются как `\\`
- Для пустой строки возвращается `''`

## Примеры {#examples}

1. Заключение обычной строки в кавычки
```sql
SELECT quote('hello');
```
```text
+----------------+
| quote('hello') |
+----------------+
| 'hello'        |
+----------------+
```

2. Строка с одинарными кавычками (будут экранированы)
```sql
SELECT quote("It's a test");
```
```text
+----------------------+
| quote("It's a test") |
+----------------------+
| 'It's a test'        |
+----------------------+
```

3. Обработка значения NULL
```sql
SELECT quote(NULL);
```
```text
+-------------+
| quote(NULL) |
+-------------+
| NULL        |
+-------------+
```

4. Обработка пустой строки
```sql
SELECT quote('');
```
```text
+-----------+
| quote('') |
+-----------+
| ''        |
+-----------+
```

5. Символ обратной косой черты
```sql
SELECT quote('aaa\\');
```
```text
+----------------+
| quote('aaa\\') |
+----------------+
| 'aaa\'         |
+----------------+
```

```sql
SELECT quote('aaa\cccb');
```
```text
+-------------------+
| quote('aaa\cccb') |
+-------------------+
| 'aaacccb'         |
+-------------------+
```
