## Описание {#description}

Преобразует входное закодированное значение LARGEINT в исходную строку UUID.

## Синтаксис {#syntax}

```sql
INT_TO_UUID(<int128>)
```

## Параметры {#parameters}

| Параметр | Описание |
|------------|-----------------|
| `<int128>` | Закодированное значение LARGEINT |

## Возвращаемое значение {#return-value}

Возвращает исходную строку UUID, соответствующую параметру `<int128>`.

- Если входное значение равно NULL, возвращает NULL

## Примеры {#examples}

```sql
SELECT INT_TO_UUID(95721955514869408091759290071393952876)
```

```text
+-----------------------------------------------------+
| int_to_uuid(95721955514869408091759290071393952876) |
+-----------------------------------------------------+
| 6ce4766f-6783-4b30-b357-bba1c7600348                |
+-----------------------------------------------------+
```

```sql
SELECT INT_TO_UUID(NULL);
```

```text
+-------------------+
| INT_TO_UUID(NULL) |
+-------------------+
| NULL              |
+-------------------+
```
