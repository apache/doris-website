## Описание {#description}

Возвращает значение параметра `name` в URL, если такой параметр есть, или пустую строку в противном случае.

Если параметров с таким именем несколько, возвращается значение первого из них.

Функция предполагает, что имя параметра закодировано в URL точно так же, как и в переданном аргументе.

Чтобы получить другие части URL, можно использовать [parse_url](parse-url.md)

## Синтаксис {#syntax}

```sql
EXTRACT_URL_PARAMETER ( <url> , <name> )
```

## Параметры {#parameters}

| Параметры | Описание |
|------------|---------------|
| `<url>`    | Строка URL, из которой нужно получить значение параметра |
| `<name>`   | Имя параметра, значение которого нужно получить |

## Возвращаемое значение {#return-value}

Значение параметра `<name>` в `<url>`

## Пример {#example}

```sql
SELECT EXTRACT_URL_PARAMETER("http://doris.apache.org?k1=aa&k2=bb&test=cc#999", "k2")
```
