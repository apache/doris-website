## Описание {#description}

Функция LOCATE возвращает позицию первого вхождения подстроки substr в строке str (отсчёт начинается с 1). Если указан необязательный третий параметр pos, поиск начинается с указанной позиции в строке str. Эта функция совместима с MySQL и часто используется для поиска совпадений в строках и определения их позиций.

## Синтаксис {#syntax}

```sql
LOCATE(<substr>, <str> [, <pos>])
```

## Параметры {#parameters}

| Параметр | Описание |
|----------|-----------------|
| `<substr>` | Искомая подстрока. Тип: VARCHAR |
| `<str>`    | Исходная строка, в которой выполняется поиск. Тип: VARCHAR |
| `<pos>`    | Необязательный параметр, задающий начальную позицию поиска (отсчёт с 1). Тип: INT |

## Возвращаемое значение {#return-value}

Возвращает значение типа INT, представляющее позицию первого вхождения substr в str (отсчёт с 1).

Правила поиска:
- Отсчёт позиций начинается с 1 (а не с 0)
- Возвращается позиция первого совпадения
- Если указан pos, поиск начинается с этой позиции, но возвращаемая позиция по-прежнему отсчитывается от начала строки
- Поиск выполняется с учётом регистра

Особые случаи:
- Если совпадение не найдено, возвращается 0
- Если любой из параметров равен NULL, возвращается NULL
- Если substr является пустой строкой, возвращается 1 (или значение pos, если pos указан и pos > 1)
- Если str является пустой строкой, а substr нет, возвращается 0
- Если pos меньше 1, возвращается 0
- Если pos больше длины str, возвращается 0

## Примеры {#examples}

1. Базовый поиск
```sql
SELECT LOCATE('bar', 'foobarbar'), LOCATE('xbar', 'foobar'), LOCATE('bar', 'foobarbar', 5);
```
```text
+----------------------------+--------------------------+-------------------------------+
| LOCATE('bar', 'foobarbar') | LOCATE('xbar', 'foobar') | LOCATE('bar', 'foobarbar', 5) |
+----------------------------+--------------------------+-------------------------------+
|                          4 |                        0 |                             7 |
+----------------------------+--------------------------+-------------------------------+
```

2. Поиск первого символа
```sql
SELECT LOCATE('f', 'foobar'), LOCATE('r', 'foobar');
```
```text
+-----------------------+-----------------------+
| LOCATE('f', 'foobar') | LOCATE('r', 'foobar') |
+-----------------------+-----------------------+
|                     1 |                     6 |
+-----------------------+-----------------------+
```

3. Совпадение не найдено
```sql
SELECT LOCATE('xyz', 'foobar'), LOCATE('FOO', 'foobar');
```
```text
+-------------------------+-------------------------+
| LOCATE('xyz', 'foobar') | LOCATE('FOO', 'foobar') |
+-------------------------+-------------------------+
|                       0 |                       0 |
+-------------------------+-------------------------+
```

4. Обработка NULL
```sql
SELECT LOCATE(NULL, 'foobar'), LOCATE('foo', NULL), LOCATE(NULL, NULL);
```
```text
+------------------------+---------------------+--------------------+
| LOCATE(NULL, 'foobar') | LOCATE('foo', NULL) | LOCATE(NULL, NULL) |
+------------------------+---------------------+--------------------+
|                   NULL |                NULL |               NULL |
+------------------------+---------------------+--------------------+
```

5. Обработка пустых строк
```sql
SELECT LOCATE('', 'foobar'), LOCATE('foo', ''), LOCATE('', '');
```
```text
+----------------------+-------------------+----------------+
| LOCATE('', 'foobar') | LOCATE('foo', '') | LOCATE('', '') |
+----------------------+-------------------+----------------+
|                    1 |                 0 |              1 |
+----------------------+-------------------+----------------+
```

6. Указание начальной позиции
```sql
SELECT LOCATE('o', 'foobar', 1), LOCATE('o', 'foobar', 2), LOCATE('o', 'foobar', 4);
```
```text
+--------------------------+--------------------------+--------------------------+
| LOCATE('o', 'foobar', 1) | LOCATE('o', 'foobar', 2) | LOCATE('o', 'foobar', 4) |
+--------------------------+--------------------------+--------------------------+
|                        2 |                        2 |                        0 |
+--------------------------+--------------------------+--------------------------+
```

7. Граничные значения аргумента позиции
```sql
SELECT LOCATE('foo', 'foobar', 0), LOCATE('foo', 'foobar', -1), LOCATE('foo', 'foobar', 10);
```
```text
+----------------------------+-----------------------------+-----------------------------+
| LOCATE('foo', 'foobar', 0) | LOCATE('foo', 'foobar', -1) | LOCATE('foo', 'foobar', 10) |
+----------------------------+-----------------------------+-----------------------------+
|                          0 |                           0 |                           0 |
+----------------------------+-----------------------------+-----------------------------+
```

8. Поиск подстроки в UTF-8
```sql
SELECT LOCATE('ṛì', 'ṭṛì ḍḍumai'), LOCATE('ḍḍu', 'ṭṛì ḍḍumai');
```
```text
+----------------------------------------+------------------------------------------+
| LOCATE('ṛì', 'ṭṛì ḍḍumai')             | LOCATE('ḍḍu', 'ṭṛì ḍḍumai')              |
+----------------------------------------+------------------------------------------+
|                                      2 |                                        5 |
+----------------------------------------+------------------------------------------+
```

9. Учёт регистра
```sql
SELECT LOCATE('BAR', 'foobar'), LOCATE('Bar', 'foobar'), LOCATE('bar', 'fooBAR');
```
```text
+-------------------------+-------------------------+-------------------------+
| LOCATE('BAR', 'foobar') | LOCATE('Bar', 'foobar') | LOCATE('bar', 'fooBAR') |
+-------------------------+-------------------------+-------------------------+
|                       0 |                       0 |                       0 |
+-------------------------+-------------------------+-------------------------+
```

10. Пустая подстрока с аргументом позиции
```sql
SELECT LOCATE('', 'foobar', 3), LOCATE('', 'foobar', 7), LOCATE('', '', 1);
```
```text
+-------------------------+-------------------------+-------------------+
| LOCATE('', 'foobar', 3) | LOCATE('', 'foobar', 7) | LOCATE('', '', 1) |
+-------------------------+-------------------------+-------------------+
|                       3 |                       0 |                 1 |
+-------------------------+-------------------------+-------------------+
```
