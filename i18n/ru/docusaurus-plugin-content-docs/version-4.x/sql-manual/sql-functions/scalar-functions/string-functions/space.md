## Описание {#description}

Создаёт строку, состоящую из заданного количества пробелов.

## Синтаксис {#syntax}

```sql
SPACE ( <len> )
```

## Параметры {#parameters}

| Параметр | Описание                      |
|-----------|----------------------------------|
| `<len>`   | Количество пробелов для создания |

## Возвращаемое значение {#return-value}

Возвращает строку, состоящую из заданного количества пробелов. Особые случаи:

- Если какой-либо параметр равен NULL, возвращается NULL.
- Если `<len>` меньше 0, возвращается пустая строка.

## Примеры {#examples}

1. Создание заданного количества пробелов
```sql
SELECT space(5);
```
```text
+----------+
| space(5) |
+----------+
|          |
+----------+
```

2. Обработка нулевого или отрицательного количества пробелов
```sql
SELECT space(0), space(-5);
```
```text
+----------+-----------+
| space(0) | space(-5) |
+----------+-----------+
|          |           |
+----------+-----------+
```

3. Обработка значения NULL
```sql
SELECT space(NULL);
```
```text
+-------------+
| space(NULL) |
+-------------+
| NULL        |
+-------------+
```

4. Использование с другими функциями
```sql
SELECT CONCAT('Hello', space(3), 'World');
```
```text
+------------------------------------+
| concat('Hello', space(3), 'World') |
+------------------------------------+
| Hello   World                      |
+------------------------------------+
```
