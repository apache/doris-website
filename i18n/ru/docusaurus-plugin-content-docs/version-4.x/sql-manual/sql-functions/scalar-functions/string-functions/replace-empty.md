## Описание {#description}

Функция REPLACE_EMPTY используется для замены части символов в строке другими символами. В отличие от функции [REPLACE](./replace.md), если `old` является пустой строкой, строка `new` вставляется перед каждым символом строки `str` и в конце строки `str`.

Эта функция предназначена прежде всего для обеспечения совместимости с Presto и Trino. Её поведение полностью совпадает с поведением функции `REPLACE()` в Presto и Trino. Поддерживается начиная с версии 2.1.5.

## Синтаксис {#syntax}

```sql
REPLACE_EMPTY ( <str>, <old>, <new> )
```

## Параметры {#parameters}

| Параметр      | Описание                                                                                                                                                                                                         |
|---------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<str>` | Строка, в которой нужно выполнить замену.                                                                                                                                                                               |
| `<old>` | Подстрока, которую нужно заменить. Если `<old>` отсутствует в `<str>`, замена не выполняется. Если `<old>` является пустой строкой, строка `<new>` вставляется перед каждым символом строки str. |
| `<new>` | Новая подстрока для замены `<old>`.                                                                                                                                                                           |

## Возвращаемое значение {#return-value}

Возвращает VARCHAR: новую строку после замены подстроки. Особые случаи:

- Если хотя бы один параметр равен NULL, возвращает NULL.
- Если `<old>` является пустой строкой, возвращает строку, в которой `<new>` вставлена перед каждым символом `<str>` и в конце.
- Если `<old>` не найдена в `<str>`, возвращает `<str>` без изменений.

## Примеры {#examples}

Для сравнения: `REPLACE` заменяет каждое вхождение `<old>`, оставляя остальную часть строки без изменений:

```sql
SELECT replace('hello world', 'world', 'universe');
```

```text
+---------------------------------------------+
| replace('hello world', 'world', 'universe') |
+---------------------------------------------+
| hello universe                              |
+---------------------------------------------+
```

Функция `REPLACE_EMPTY` работает так же в обычном случае (см. пример 2 ниже), но ведёт себя иначе, когда `<old>` является пустой строкой: тогда она вставляет `<new>` перед каждым символом `<str>` и в конце (пример 1). Остальные примеры показывают граничные случаи.

1. Базовое использование: вставка, когда `<old>` является пустой строкой.

```sql
SELECT replace_empty('abc', '', 'x');
```

```text
+-------------------------------+
| replace_empty('abc', '', 'x') |
+-------------------------------+
| xaxbxcx                       |
+-------------------------------+
```

2. Обычная замена подстроки (поведение совпадает с `REPLACE`).

```sql
SELECT replace_empty('hello', 'l', 'L');
```

```text
+----------------------------------+
| replace_empty('hello', 'l', 'L') |
+----------------------------------+
| heLLo                            |
+----------------------------------+
```

3. Пустая строка `<str>` вместе с пустой строкой `<old>`.

```sql
SELECT replace_empty('', '', 'x');
```

```text
+----------------------------+
| replace_empty('', '', 'x') |
+----------------------------+
| x                          |
+----------------------------+
```

4. Распространение NULL.

```sql
SELECT replace_empty(NULL, 'old', 'new');
```

```text
+-----------------------------------+
| replace_empty(NULL, 'old', 'new') |
+-----------------------------------+
| NULL                              |
+-----------------------------------+
```

5. Многобайтовая (UTF-8) строка `<new>`.

```sql
SELECT replace_empty('hello', 'l', 'ṭṛìṭ');
```

```text
+--------------------------------------------+
| replace_empty('hello', 'l', 'ṭṛìṭ')        |
+--------------------------------------------+
| heṭṛìṭṭṛìṭo                                |
+--------------------------------------------+
```
