## Описание {#description}

Функция REPEAT повторяет указанную строку заданное число раз, создавая новую строку. Эта функция обычно используется для генерации символов заполнения, создания разделителей или генерации тестовых данных.

## Синтаксис {#syntax}

```sql
REPEAT(<str>, <count>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<str>` | Исходная строка для повторения. Тип: VARCHAR |
| `<count>` | Число повторений. Должно быть неотрицательным целым числом. Тип: INT |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, содержащее строку, повторённую указанное число раз.

Правила повторения:
- Если count больше 0, возвращается результат повторения строки str count раз
- Если count равен 0, возвращается пустая строка
- Если count меньше 0, возвращается пустая строка
- Если результирующая строка слишком длинная, на неё могут распространяться ограничения длины строки

Особые случаи:
- Если любой из параметров равен NULL, возвращается NULL
- Если str является пустой строкой, возвращается пустая строка независимо от count
- Если count равен 0, возвращается пустая строка
- Если count отрицательный, возвращается пустая строка

## Примеры {#examples}

1. Простое повторение символа
```sql
SELECT REPEAT('a', 3);
```
```text
+----------------+
| REPEAT('a', 3) |
+----------------+
| aaa            |
+----------------+
```

2. Повторение строки из нескольких символов
```sql
SELECT REPEAT('hello', 2);
```
```text
+--------------------+
| REPEAT('hello', 2) |
+--------------------+
| hellohello         |
+--------------------+
```

3. Нулевое число повторений
```sql
SELECT REPEAT('test', 0);
```
```text
+-------------------+
| REPEAT('test', 0) |
+-------------------+
|                   |
+-------------------+
```

4. Отрицательное число повторений
```sql
SELECT REPEAT('a', -1);
```
```text
+-----------------+
| REPEAT('a', -1) |
+-----------------+
|                 |
+-----------------+
```

5. Обработка значений NULL
```sql
SELECT REPEAT(NULL, 3), REPEAT('a', NULL);
```
```text
+------------------+-------------------+
| REPEAT(NULL, 3)  | REPEAT('a', NULL) |
+------------------+-------------------+
| NULL             | NULL              |
+------------------+-------------------+
```

6. Повторение пустой строки
```sql
SELECT REPEAT('', 5);
```
```text
+----------------+
| REPEAT('', 5)  |
+----------------+
|                |
+----------------+
```

7. Повторение специальных символов
```sql
SELECT REPEAT('-', 10), REPEAT('*', 5);
```
```text
+------------------+-----------------+
| REPEAT('-', 10)  | REPEAT('*', 5)  |
+------------------+-----------------+
| ----------       | *****           |
+------------------+-----------------+
```

8. Повторение символов UTF-8
```sql
SELECT REPEAT('ṭṛì', 3), REPEAT('ḍḍu', 2);
```
```text
+-------------------+-------------------+
| REPEAT('ṭṛì', 3)  | REPEAT('ḍḍu', 2)  |
+-------------------+-------------------+
| ṭṛìṭṛìṭṛì          | ḍḍuḍḍu            |
+-------------------+-------------------+
```

9. Сочетание цифр и символов
```sql
SELECT REPEAT('123', 3), REPEAT('@#', 4);
```
```text
+-------------------+------------------+
| REPEAT('123', 3)  | REPEAT('@#', 4)  |
+-------------------+------------------+
| 123123123         | @#@#@#@#         |
+-------------------+------------------+
```

10. Повторение символов UTF-8
```sql
SELECT REPEAT('ṭṛìṭṛì', 3);
```
```text
+--------------------------------------------------+
| REPEAT('ṭṛìṭṛì', 3)                              |
+--------------------------------------------------+
| ṭṛìṭṛìṭṛìṭṛìṭṛìṭṛì                               |
+--------------------------------------------------+
```
