## Описание {#description}

Функция TOP_LEVEL_DOMAIN извлекает домен верхнего уровня из URL. Если входной URL некорректен, функция возвращает пустую строку.

## Синтаксис {#syntax}

```sql
TOP_LEVEL_DOMAIN(<url>)
```

## Параметры {#parameters}
| Параметр | Описание                                                              |
| --------- | ------------------------------------------------------------------------ |
| `<url>` | Строка URL, из которой извлекается домен верхнего уровня. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее извлечённый домен верхнего уровня.

Особые случаи:
- Возвращает NULL, если url равен NULL
- Возвращает пустую строку, если url не соответствует допустимому формату URL
- Для многоуровневых доменов (например, .com.cn) возвращает последний уровень домена

## Примеры {#examples}

1. Обработка обычного домена
```sql
SELECT top_level_domain('www.baidu.com');
```
```text
+-----------------------------------+
| top_level_domain('www.baidu.com') |
+-----------------------------------+
| com                               |
+-----------------------------------+
```

2. Обработка многоуровневого домена
```sql
SELECT top_level_domain('www.google.com.cn');
```
```text
+---------------------------------------+
| top_level_domain('www.google.com.cn') |
+---------------------------------------+
| cn                                    |
+---------------------------------------+
```

3. Обработка некорректного URL
```sql
SELECT top_level_domain('wwwwwwww');
```
```text
+------------------------------+
| top_level_domain('wwwwwwww') |
+------------------------------+
|                              |
+------------------------------+
```
