## Описание {#description}

Функция TRIM_IN используется для удаления заданных символов в начале и конце строки. Если набор символов не указан, по умолчанию удаляются начальные и конечные пробелы. Если набор символов указан, с обоих концов строки удаляются все входящие в него символы (независимо от их порядка в наборе).

Главная особенность TRIM_IN заключается в том, что она удаляет любые сочетания символов из заданного набора, тогда как функция TRIM удаляет символы на основе точного совпадения строк.

## Синтаксис {#syntax}

```sql
TRIM_IN(<str>[, <rhs>])
```

## Параметры {#parameters}

| Параметр | Описание |
| --------- | ------------------------------------------------------------------------ |
| `<str>` | Строка для обработки. Тип: VARCHAR |
| `<rhs>` | Необязательный параметр: набор символов для удаления. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает обработанную строку типа VARCHAR.

Особые случаи:
- Если str имеет значение NULL, возвращает NULL
- Если rhs не указан, удаляет все начальные и конечные пробелы
- Если rhs указан, удаляет с обоих концов строки все символы, входящие в rhs, пока не встретит символы, не входящие в rhs

## Примеры {#examples}

1. Удаление начальных и конечных пробелов
```sql
SELECT trim_in('   ab d   ') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. Удаление символов из заданного набора
```sql
SELECT trim_in('ababccaab', 'ab') str;
```
```text
+------+
| str  |
+------+
| cc   |
+------+
```

3. Сравнение с функцией TRIM: `trim_in` рассматривает второй аргумент как *набор символов* и удаляет любые из этих символов с обоих концов строки, а `trim` рассматривает его как буквальную *подстроку* и удаляет точные совпадения с обоих концов. Обе функции повторяют удаление, пока ни на одном конце не останется совпадений.
```sql
SELECT trim_in('ababccaab', 'ab'), trim('ababccaab', 'ab');
```
```text
+----------------------------+-------------------------+
| trim_in('ababccaab', 'ab') | trim('ababccaab', 'ab') |
+----------------------------+-------------------------+
| cc                         | cca                     |
+----------------------------+-------------------------+
```

4. Порядок символов в наборе не имеет значения
```sql
SELECT trim_in('abcHelloabc', 'cba');
```
```text
+--------------------------------+
| trim_in('abcHelloabc', 'cba')  |
+--------------------------------+
| Hello                          |
+--------------------------------+
```

5. Поддержка символов UTF-8
```sql
SELECT trim_in('+++ṭṛì ḍḍumai+++', '+');
```
```text
+--------------------------------------+
| trim_in('+++ṭṛì ḍḍumai+++', '+')    |
+--------------------------------------+
| ṭṛì ḍḍumai                           |
+--------------------------------------+
```

6. Обработка значений NULL
```sql
SELECT trim_in(NULL, 'abc');
```
```text
+-----------------------+
| trim_in(NULL, 'abc')  |
+-----------------------+
| NULL                  |
+-----------------------+
```

7. Обработка пустых строк
```sql
SELECT trim_in('', 'abc'), trim_in('abc', '');
```
```text
+--------------------+--------------------+
| trim_in('', 'abc') | trim_in('abc', '') |
+--------------------+--------------------+
|                    | abc                |
+--------------------+--------------------+
```

### Ключевые слова {#keywords}

    TRIM_IN, TRIM
