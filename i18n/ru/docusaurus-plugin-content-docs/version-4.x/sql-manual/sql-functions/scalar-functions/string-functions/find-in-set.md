## Описание {#description}

Возвращает позицию первого вхождения строки str в списке строк strlist, разделённых запятыми (отсчёт начинается с 1). Эта функция реализована в режиме совместимости с MySQL и используется для поиска определённых строк в списках значений, разделённых запятыми.

## Синтаксис {#syntax}

```sql
FIND_IN_SET(<str>, <strlist>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-------------|----------|
| `<str>`     | Искомая строка. Тип: VARCHAR |
| `<strlist>` | Список строк, разделённых запятыми, в котором выполняется поиск str. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа INT, обозначающее позицию str в strlist (отсчёт начинается с 1).

Правила поиска:
- Точное совпадение: позиция возвращается только в том случае, если str в точности совпадает с подстрокой в strlist
- Отсчёт позиций начинается с 1
- Возвращается позиция первого совпадения

Особые случаи:
- Если str является пустой строкой, возвращается 0
- Если strlist является пустой строкой, возвращается 0
- Если совпадение не найдено, возвращается 0
- Если любой из параметров равен NULL, возвращается NULL
- Если str содержит запятую, корректное сопоставление невозможно (поскольку запятая служит разделителем)
- При сопоставлении учитывается регистр

## Примеры {#examples}

1. Базовый поиск
```sql
SELECT FIND_IN_SET('b', 'a,b,c');
```
```text
+---------------------------+
| FIND_IN_SET('b', 'a,b,c') |
+---------------------------+
|                         2 |
+---------------------------+
```

2. Поиск первого элемента
```sql
SELECT FIND_IN_SET('apple', 'apple,banana,cherry');
```
```text
+------------------------------------------+
| FIND_IN_SET('apple', 'apple,banana,cherry') |
+------------------------------------------+
|                                        1 |
+------------------------------------------+
```

3. Поиск последнего элемента
```sql
SELECT FIND_IN_SET('cherry', 'apple,banana,cherry');
```
```text
+-------------------------------------------+
| FIND_IN_SET('cherry', 'apple,banana,cherry') |
+-------------------------------------------+
|                                         3 |
+-------------------------------------------+
```

4. Совпадение не найдено
```sql
SELECT FIND_IN_SET('orange', 'apple,banana,cherry');
```
```text
+--------------------------------------------+
| FIND_IN_SET('orange', 'apple,banana,cherry') |
+--------------------------------------------+
|                                          0 |
+--------------------------------------------+
```

5. Обработка значений NULL
```sql
SELECT FIND_IN_SET(NULL, 'a,b,c'), FIND_IN_SET('b', NULL);
```
```text
+---------------------------+-------------------------+
| FIND_IN_SET(NULL, 'a,b,c') | FIND_IN_SET('b', NULL) |
+---------------------------+-------------------------+
|                      NULL |                    NULL |
+---------------------------+-------------------------+
```

6. Обработка пустых строк
```sql
SELECT FIND_IN_SET('', 'a,b,c'), FIND_IN_SET('a', '');
```
```text
+-------------------------+-----------------------+
| FIND_IN_SET('', 'a,b,c') | FIND_IN_SET('a', '') |
+-------------------------+-----------------------+
|                       0 |                     0 |
+-------------------------+-----------------------+
```

7. Строка, содержащая запятую (корректное сопоставление невозможно)
```sql
SELECT FIND_IN_SET('a,b', 'a,b,c,d');
```
```text
+------------------------------+
| FIND_IN_SET('a,b', 'a,b,c,d') |
+------------------------------+
|                            0 |
+------------------------------+
```

8. Сопоставление с учётом регистра
```sql
SELECT FIND_IN_SET('B', 'a,b,c'), FIND_IN_SET('b', 'A,B,C');
```
```text
+---------------------------+---------------------------+
| FIND_IN_SET('B', 'a,b,c') | FIND_IN_SET('b', 'A,B,C') |
+---------------------------+---------------------------+
|                         0 |                         0 |
+---------------------------+---------------------------+
```

9. Частичное совпадение не считается успешным
```sql
SELECT FIND_IN_SET('ap', 'apple,banana,cherry');
```
```text
+---------------------------------------+
| FIND_IN_SET('ap', 'apple,banana,cherry') |
+---------------------------------------+
|                                     0 |
+---------------------------------------+
```

10. Поиск числовой строки
```sql
SELECT FIND_IN_SET('2', '1,2,3,10,20');
```
```text
+--------------------------------+
| FIND_IN_SET('2', '1,2,3,10,20') |
+--------------------------------+
|                              2 |
+--------------------------------+
```
