## Описание {#description}

Функция REVERSE изменяет порядок входной последовательности на обратный. Для строковых аргументов она возвращает строку с обратным порядком символов; для аргументов в виде массивов она возвращает массив с обратным порядком элементов. Функция выполняет обращение посимвольно и корректно обрабатывает многобайтовые символы UTF-8.

## Синтаксис {#syntax}

```sql
REVERSE(<seq>)
```

## Параметры {#parameters}

| Параметр | Описание |
|---------|----------------|
| `<seq>` | Строка или массив, порядок которых нужно изменить на обратный. Тип: VARCHAR или ARRAY |

## Возвращаемое значение {#return-value}

Возвращает последовательность в обратном порядке, сохраняя тип входного значения:
- Строка на входе: возвращает строку типа VARCHAR с обратным порядком символов
- Массив на входе: возвращает массив типа ARRAY с обратным порядком элементов

Особые случаи:
- Если параметр равен NULL, возвращает NULL
- Если строка пустая, возвращает пустую строку
- Если массив пустой, возвращает пустой массив
- Строка из одного символа остаётся неизменной после обращения

## Примеры {#examples}

1. Простое обращение строки
```sql
SELECT REVERSE('hello');
```
```text
+------------------+
| REVERSE('hello') |
+------------------+
| olleh            |
+------------------+
```

2. Обращение порядка элементов массива
```sql
SELECT REVERSE(['hello', 'world']);
```
```text
+-----------------------------+
| REVERSE(['hello', 'world']) |
+-----------------------------+
| ["world", "hello"]          |
+-----------------------------+
```

3. Обработка значения NULL
```sql
SELECT REVERSE(NULL);
```
```text
+---------------+
| REVERSE(NULL) |
+---------------+
| NULL          |
+---------------+
```

4. Пустая строка и пустой массив
```sql
SELECT REVERSE(''), REVERSE([]);
```
```text
+-------------+-------------+
| REVERSE('') | REVERSE([]) |
+-------------+-------------+
|             | []          |
+-------------+-------------+
```

5. Строка из одного символа и массив из одного элемента
```sql
SELECT REVERSE('A'), REVERSE(['single']);
```
```text
+--------------+--------------------+
| REVERSE('A') | REVERSE(['single']) |
+--------------+--------------------+
| A            | ["single"]         |
+--------------+--------------------+
```

6. Числа и специальные символы
```sql
SELECT REVERSE('12345'), REVERSE('!@#$%');
```
```text
+------------------+------------------+
| REVERSE('12345') | REVERSE('!@#$%') |
+------------------+------------------+
| 54321            | %$#@!            |
+------------------+------------------+
```

7. Многобайтовые символы UTF-8
```sql
SELECT REVERSE('ṭṛì ḍḍumai'), REVERSE('ḍḍumannàri');
```
```text
+--------------------------------+----------------------------+
| REVERSE('ṭṛì ḍḍumai')          | REVERSE('ḍḍumannàri')      |
+--------------------------------+----------------------------+
| iamuḍḍ ìṛṭ                     | irànnamuḍḍ                 |
+--------------------------------+----------------------------+
```

8. Сочетание разных типов символов
```sql
SELECT REVERSE('Hello123'), REVERSE('test@email.com');
```
```text
+---------------------+--------------------------+
| REVERSE('Hello123') | REVERSE('test@email.com') |
+---------------------+--------------------------+
| 321olleH            | moc.liame@tset           |
+---------------------+--------------------------+
```

9. Массив из нескольких элементов
```sql
SELECT REVERSE([1, 2, 3, 4, 5]), REVERSE(['a', 'b', 'c']);
```
```text
+---------------------------+------------------------+
| REVERSE([1, 2, 3, 4, 5])  | REVERSE(['a', 'b', 'c']) |
+---------------------------+------------------------+
| [5, 4, 3, 2, 1]           | ["c", "b", "a"]        |
+---------------------------+------------------------+
```

10. Проверка палиндрома
```sql
SELECT REVERSE('level'), REVERSE('12321');
```
```text
+------------------+-------------------+
| REVERSE('level') | REVERSE('12321')  |
+------------------+-------------------+
| level            | 12321             |
+------------------+-------------------+
```
