## Описание {#description}

Функция UCASE (псевдоним UPPER) преобразует все строчные буквы в строке в прописные. Эта функция поддерживает преобразование символов Unicode и корректно обрабатывает правила изменения регистра для различных языков.

## Синтаксис {#syntax}

```sql
UCASE(<str>)
UPPER(<str>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|-------------|
| `<str>` | Строка для преобразования в верхний регистр. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее строку, преобразованную в верхний регистр.

Правила преобразования:
- Все строчные буквы в строке преобразуются в соответствующие прописные буквы
- Символы, не являющиеся буквами (цифры, специальные символы, пробелы и т. д.), остаются без изменений
- Буквы, уже находящиеся в верхнем регистре, остаются без изменений

Особые случаи:
- Возвращает NULL, если параметр равен NULL
- Возвращает пустую строку, если входная строка пуста
- Возвращает исходную строку, если в ней нет строчных букв

## Примеры {#examples}

1. Простое преобразование английских букв
```sql
SELECT UCASE('aBc123'), UPPER('aBc123');
```
```text
+-----------------+-----------------+
| UCASE('aBc123') | UPPER('aBc123') |
+-----------------+-----------------+
| ABC123          | ABC123          |
+-----------------+-----------------+
```

2. Обработка строки с разными символами
```sql
SELECT UCASE('Hello World!'), UPPER('test@123');
```
```text
+----------------------+------------------+
| UCASE('Hello World!') | UPPER('test@123') |
+----------------------+------------------+
| HELLO WORLD!         | TEST@123         |
+----------------------+------------------+
```

3. Обработка значений NULL
```sql
SELECT UCASE(NULL), UPPER(NULL);
```
```text
+-------------+-------------+
| UCASE(NULL) | UPPER(NULL) |
+-------------+-------------+
| NULL        | NULL        |
+-------------+-------------+
```

4. Обработка пустой строки
```sql
SELECT UCASE(''), UPPER('');
```
```text
+-----------+-----------+
| UCASE('') | UPPER('') |
+-----------+-----------+
|           |           |
+-----------+-----------+
```

5. Строка, уже записанная в верхнем регистре
```sql
SELECT UCASE('ALREADY UPPERCASE'), UPPER('ABC123');
```
```text
+---------------------------+----------------+
| UCASE('ALREADY UPPERCASE') | UPPER('ABC123') |
+---------------------------+----------------+
| ALREADY UPPERCASE         | ABC123         |
+---------------------------+----------------+
```

6. Цифры и символы
```sql
SELECT UCASE('123!@#$%'), UPPER('price: $99.99');
```
```text
+-------------------+----------------------+
| UCASE('123!@#$%') | UPPER('price: $99.99') |
+-------------------+----------------------+
| 123!@#$%          | PRICE: $99.99        |
+-------------------+----------------------+
```

7. Многобайтовые символы UTF-8
```sql
SELECT UCASE('ṭṛì test'), UPPER('ḍḍumai hello');
```
```text
+--------------------+-----------------------+
| UCASE('ṭṛì test')  | UPPER('ḍḍumai hello') |
+--------------------+-----------------------+
| ṬṚÌ TEST           | ḌḌUMAI HELLO          |
+--------------------+-----------------------+
```

8. Кириллические буквы
```sql
SELECT UCASE('Кириллица'), UPPER('Бәйтерек');
```
```text
+---------------------+-------------------+
| UCASE('Кириллица')  | UPPER('Бәйтерек') |
+---------------------+-------------------+
| КИРИЛЛИЦА           | БӘЙТЕРЕК          |
+---------------------+-------------------+
```

### Ключевые слова {#keywords}

    UCASE, UPPER
