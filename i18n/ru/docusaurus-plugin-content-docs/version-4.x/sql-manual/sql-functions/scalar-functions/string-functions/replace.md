## Описание {#description}

Функция REPLACE используется для замены всех вхождений указанной подстроки в строке новой подстрокой. Эта функция заменяет все совпадающие вхождения подстроки в строке, выполняя глобальную замену.

**Отличие от функции REPLACE_EMPTY:**
- `REPLACE()` заменяет указанную подстроку, включая пустые строки
- `REPLACE_EMPTY()` предназначена для замены пустых значений или пустых строк указанным значением

## Синтаксис {#syntax}

```sql
REPLACE(<str>, <old>, <new>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|-------------|
| `<str>` | Исходная строка, в которой выполняется замена. Тип: VARCHAR |
| `<old>` | Подстрока, которую необходимо заменить. Если она не найдена в str, замена не выполняется. Тип: VARCHAR |
| `<new>` | Новая подстрока, заменяющая old. Тип: VARCHAR |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR, представляющее новую строку после замены.

Правила замены:
- Заменяются все вхождения подстроки old в строке
- Замена учитывает регистр
- Если old является пустой строкой, возвращается исходная строка (операция не выполняется)
- Если new является пустой строкой, все вхождения подстроки old удаляются

Особые случаи:
- Если любой параметр равен NULL, возвращается NULL
- Если str является пустой строкой, возвращается пустая строка
- Если old является пустой строкой, возвращается исходная строка str (без замены)
- Если old не найдена в str, возвращается исходная строка str

## Примеры {#examples}

1. Базовая операция замены
```sql
SELECT REPLACE('hello world', 'world', 'universe');
```
```text
+---------------------------------------------+
| REPLACE('hello world', 'world', 'universe') |
+---------------------------------------------+
| hello universe                              |
+---------------------------------------------+
```

2. Замена нескольких совпадений
```sql
SELECT REPLACE('apple apple apple', 'apple', 'orange');
```
```text
+------------------------------------------------+
| REPLACE('apple apple apple', 'apple', 'orange') |
+------------------------------------------------+
| orange orange orange                           |
+------------------------------------------------+
```

3. Удаление подстроки (замена пустой строкой)
```sql
SELECT REPLACE('banana', 'a', '');
```
```text
+---------------------------+
| REPLACE('banana', 'a', '') |
+---------------------------+
| bnn                       |
+---------------------------+
```

4. Обработка значений NULL
```sql
SELECT REPLACE(NULL, 'old', 'new'), REPLACE('test', NULL, 'new'), REPLACE('test', 'old', NULL);
```
```text
+------------------------------+------------------------------+------------------------------+
| REPLACE(NULL, 'old', 'new')  | REPLACE('test', NULL, 'new') | REPLACE('test', 'old', NULL) |
+------------------------------+------------------------------+------------------------------+
| NULL                         | NULL                         | NULL                         |
+------------------------------+------------------------------+------------------------------+
```

5. Замена символов UTF-8
```sql
SELECT REPLACE('ṭṛì ḍḍumai test ṭṛì ḍḍumannàri', 'ṭṛì', 'replaced');
```
```text
+-----------------------------------------------------------+
| REPLACE('ṭṛì ḍḍumai test ṭṛì ḍḍumannàri', 'ṭṛì', 'replaced') |
+-----------------------------------------------------------+
| replaced ḍḍumai test replaced ḍḍumannàri                  |
+-----------------------------------------------------------+
```

6. Граничные случаи с пустыми строками: если `str` пуста, возвращается пустая строка; если `old` пуста, `str` возвращается без изменений; если `new` пуста, удаляются все совпадения
```sql
SELECT REPLACE('', 'old', 'new'), REPLACE('test', '', 'new'), REPLACE('test', 'old', '');
```
```text
+---------------------------+----------------------------+----------------------------+
| REPLACE('', 'old', 'new') | REPLACE('test', '', 'new') | REPLACE('test', 'old', '') |
+---------------------------+----------------------------+----------------------------+
|                           | test                       | test                       |
+---------------------------+----------------------------+----------------------------+
```

7. Замена учитывает регистр (совпадает только `hello` в нижнем регистре)
```sql
SELECT REPLACE('Hello HELLO hello', 'hello', 'hi');
```
```text
+---------------------------------------------+
| REPLACE('Hello HELLO hello', 'hello', 'hi') |
+---------------------------------------------+
| Hello HELLO hi                              |
+---------------------------------------------+
```

8. `old` отсутствует: `str` возвращается без изменений
```sql
SELECT REPLACE('hello world', 'xyz', 'abc');
```
```text
+--------------------------------------+
| REPLACE('hello world', 'xyz', 'abc') |
+--------------------------------------+
| hello world                          |
+--------------------------------------+
```

9. Повторяющиеся неперекрывающиеся совпадения
```sql
SELECT REPLACE('123123123', '123', 'ABC');
```
```text
+------------------------------------+
| REPLACE('123123123', '123', 'ABC') |
+------------------------------------+
| ABCABCABC                          |
+------------------------------------+
```
