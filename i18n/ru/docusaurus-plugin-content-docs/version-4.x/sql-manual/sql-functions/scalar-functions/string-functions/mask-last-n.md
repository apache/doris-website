## Описание {#description}

Функция MASK_LAST_N используется для маскирования последних N байтов строки. В последних N байтах она заменяет прописные буквы на `X`, строчные буквы на `x`, а цифры на `n`.

## Синтаксис {#syntax}

```sql
MASK_LAST_N(<str>[, <n>])
```

## Параметры {#parameters}

| Параметр | Описание |
| ------- | ----------------------------------------- |
| `<str>` | Строка для маскирования. Тип: VARCHAR |
| `<n>` | Количество последних N байтов для маскирования (необязательный параметр; по умолчанию маскируется вся строка). Тип: INT |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR: строку с замаскированными последними N байтами.

Особые случаи:
- Если любой из параметров равен NULL, возвращается NULL
- Символы, не являющиеся буквами или цифрами, остаются без изменений
- Если `<n>` превышает длину строки, маскируется вся строка

## Примеры {#examples}

1. Базовое использование: маскирование последних 4 байтов
```sql
SELECT mask_last_n('1234-5678', 4);
```
```text
+-----------------------------+
| mask_last_n('1234-5678', 4) |
+-----------------------------+
| 1234-nnnn                   |
+-----------------------------+
```

2. Без указания n (маскируется вся строка)
```sql
SELECT mask_last_n('abc123');
```
```text
+----------------------+
| mask_last_n('abc123') |
+----------------------+
| xxxnnn               |
+----------------------+
```

3. n превышает длину строки
```sql
SELECT mask_last_n('Hello', 100);
```
```text
+---------------------------+
| mask_last_n('Hello', 100) |
+---------------------------+
| Xxxxx                     |
+---------------------------+
```

4. Обработка значения NULL
```sql
SELECT mask_last_n(NULL, 5);
```
```text
+----------------------+
| mask_last_n(NULL, 5) |
+----------------------+
| NULL                 |
+----------------------+
```

5. n равно 0 (ни один символ не маскируется)
```sql
SELECT mask_last_n('Hello123', 0);
```
```text
+----------------------------+
| mask_last_n('Hello123', 0) |
+----------------------------+
| Hello123                   |
+----------------------------+
```

6. n превышает длину строки (маскируется вся строка)
```sql
SELECT mask_last_n('Test', 100);
```
```text
+--------------------------+
| mask_last_n('Test', 100) |
+--------------------------+
| Xxxx                     |
+--------------------------+
```

7. Маскирование доменной части адреса электронной почты
```sql
SELECT mask_last_n('user@example.com', 11);
```
```text
+-------------------------------------+
| mask_last_n('user@example.com', 11) |
+-------------------------------------+
| user@xxxxxxx.xxx                    |
+-------------------------------------+
```

8. Маскирование последних 4 цифр номера телефона
```sql
SELECT mask_last_n('13812345678', 4);
```
```text
+-------------------------------+
| mask_last_n('13812345678', 4) |
+-------------------------------+
| 1381234nnnn                   |
+-------------------------------+
```

9. Сочетание букв, цифр и специальных символов
```sql
SELECT mask_last_n('ABC-123-xyz', 7);
```
```text
+--------------------------------+
| mask_last_n('ABC-123-xyz', 7)  |
+--------------------------------+
| ABC-nnn-xxx                    |
+--------------------------------+
```

10. Обработка символов UTF-8 (маскирование по байтам)
```sql
SELECT mask_last_n('Hello你好123', 9);
```
```text
+--------------------------------+
| mask_last_n('Hello你好123', 9) |
+--------------------------------+
| Hello你好nnn                   |
+--------------------------------+
```

```sql
SELECT mask_last_n('eeeéèêëìí1234');
```
```text
+------------------------------------+
| mask_last_n('eeeéèêëìí1234')       |
+------------------------------------+
| xxxéèêëìínnnn                      |
+------------------------------------+
```
