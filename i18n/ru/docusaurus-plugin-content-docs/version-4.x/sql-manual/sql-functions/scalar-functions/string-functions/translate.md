## Описание {#description}

Функция TRANSLATE выполняет посимвольную замену в строке, преобразуя символы исходной строки в соответствии с правилами сопоставления. Эта функция заменяет каждый символ исходной строки, который встречается в строке 'from', на символ, находящийся на той же позиции в строке 'to'.

## Синтаксис {#syntax}

```sql
TRANSLATE(<source>, <from>, <to>)
```

## Параметры {#parameters}
| Параметр | Описание                                         |
| --------- | --------------------------------------------------- |
| `<source>` | Исходная строка для преобразования. Тип: VARCHAR    |
| `<from>` | Набор символов, которые нужно заменить. Тип: VARCHAR |
| `<to>` | Набор символов для замены. Тип: VARCHAR    |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR: строку, преобразованную в соответствии с правилами сопоставления символов.

Правила сопоставления символов:
- Сопоставляет символы один к одному по их позициям в строках 'from' и 'to'
- 1-й символ в 'from' соответствует 1-му символу в 'to', 2-й соответствует 2-му и так далее
- Если в 'from' есть повторяющиеся символы, используется сопоставление для первого вхождения, а последующие повторения игнорируются
- Символы исходной строки, которых нет в строке 'from', остаются без изменений

Особые случаи:
- Если хотя бы один параметр равен NULL, возвращается NULL
- Если исходная строка пустая, возвращается пустая строка
- Если 'from' является пустой строкой, исходная строка возвращается без изменений
- Если 'to' является пустой строкой, из исходной строки удаляются все символы, встречающиеся в 'from'
- Если строка 'to' короче 'from', символы исходной строки, соответствующие лишним символам в 'from', удаляются

## Примеры {#examples}

1. Простая замена символа
```sql
SELECT TRANSLATE('abcd', 'a', 'z');
```
```text
+-----------------------------+
| TRANSLATE('abcd', 'a', 'z') |
+-----------------------------+
| zbcd                        |
+-----------------------------+
```

2. Замена каждого вхождения символа в исходной строке
```sql
SELECT TRANSLATE('abcda', 'a', 'z');
```
```text
+------------------------------+
| TRANSLATE('abcda', 'a', 'z') |
+------------------------------+
| zbcdz                        |
+------------------------------+
```

3. Сопоставление нескольких символов по позициям
```sql
SELECT TRANSLATE('abcd', 'ac', 'zx');
```
```text
+-------------------------------+
| TRANSLATE('abcd', 'ac', 'zx') |
+-------------------------------+
| zbxd                          |
+-------------------------------+
```

4. Повторяющиеся символы в `<from>` (используется только первое сопоставление)
```sql
SELECT TRANSLATE('abacad', 'aac', 'zxy');
```
```text
+-----------------------------------+
| TRANSLATE('abacad', 'aac', 'zxy') |
+-----------------------------------+
| zbzyzd                            |
+-----------------------------------+
```

5. Строка `<to>` короче `<from>` (лишние символы удаляются)
```sql
SELECT TRANSLATE('abcde', 'ace', 'xy');
```
```text
+---------------------------------+
| TRANSLATE('abcde', 'ace', 'xy') |
+---------------------------------+
| xbyd                            |
+---------------------------------+
```

6. Обработка NULL: если хотя бы один аргумент равен NULL, возвращается NULL
```sql
SELECT TRANSLATE(NULL, 'a', 'z'), TRANSLATE('abc', NULL, 'z'), TRANSLATE('abc', 'a', NULL);
```
```text
+---------------------------+-----------------------------+-----------------------------+
| TRANSLATE(NULL, 'a', 'z') | TRANSLATE('abc', NULL, 'z') | TRANSLATE('abc', 'a', NULL) |
+---------------------------+-----------------------------+-----------------------------+
| NULL                      | NULL                        | NULL                        |
+---------------------------+-----------------------------+-----------------------------+
```

7. Граничные случаи с пустыми строками: при пустой исходной строке возвращается пустая строка, при пустой строке `<from>` исходная строка остаётся без изменений, а при пустой строке `<to>` совпадающие символы удаляются
```sql
SELECT TRANSLATE('', 'a', 'z'), TRANSLATE('abc', '', 'z'), TRANSLATE('abc', 'a', '');
```
```text
+-------------------------+---------------------------+---------------------------+
| TRANSLATE('', 'a', 'z') | TRANSLATE('abc', '', 'z') | TRANSLATE('abc', 'a', '') |
+-------------------------+---------------------------+---------------------------+
|                         | abc                       | bc                        |
+-------------------------+---------------------------+---------------------------+
```

8. Многобайтовые символы UTF-8
```sql
SELECT TRANSLATE('ṭṛì ḍḍumai', 'ṭṛ', 'ab');
```
```text
+--------------------------------------------------+
| TRANSLATE('ṭṛì ḍḍumai', 'ṭṛ', 'ab')              |
+--------------------------------------------------+
| abì ḍḍumai                                       |
+--------------------------------------------------+
```

9. Замена цифровых символов
```sql
SELECT TRANSLATE('a1b2c3', '123', 'xyz');
```
```text
+-----------------------------------+
| TRANSLATE('a1b2c3', '123', 'xyz') |
+-----------------------------------+
| axbycz                            |
+-----------------------------------+
```

10. Повторное сопоставление при наличии повторяющихся символов с обеих сторон
```sql
SELECT TRANSLATE('aabbccaa', 'abab', 'xyuv');
```
```text
+---------------------------------------+
| TRANSLATE('aabbccaa', 'abab', 'xyuv') |
+---------------------------------------+
| xxyyccxx                              |
+---------------------------------------+
```

11. Замена специальных символов
```sql
SELECT TRANSLATE('hello@world.com', '@.', '-_');
```
```text
+------------------------------------------+
| TRANSLATE('hello@world.com', '@.', '-_') |
+------------------------------------------+
| hello-world_com                          |
+------------------------------------------+
```

### Ключевые слова {#keywords}
