## Описание {#description}

Функция FORMAT_NUMBER форматирует числовые значения в виде строк с обозначениями единиц. Поддерживаются следующие единицы: K (тысяча), M (миллион), B (миллиард), T (триллион), Q (квадриллион).

## Синтаксис {#syntax}

```sql
FORMAT_NUMBER(<val>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -------- | ----------------------------------------- |
| `<val>` | Числовое значение для форматирования. Тип: DOUBLE |

## Возвращаемое значение {#return-value}

Возвращает значение типа VARCHAR — отформатированную строку с обозначением единицы.

Особые случаи:
- Если параметр равен NULL, возвращает NULL
- Числа меньше 1000 возвращаются без изменений и без обозначения единицы
- Правила преобразования единиц:
  - K: тысяча (1,000)
  - M: миллион (1,000,000)
  - B: миллиард (1,000,000,000)
  - T: триллион (1,000,000,000,000)
  - Q: квадриллион (1,000,000,000,000,000)

## Примеры {#examples}

1. Базовое использование: тысячи (K)
```sql
SELECT format_number(1500);
```
```text
+---------------------+
| format_number(1500) |
+---------------------+
| 1.50K               |
+---------------------+
```

2. Миллионы (M)
```sql
SELECT format_number(5000000);
```
```text
+------------------------+
| format_number(5000000) |
+------------------------+
| 5.00M                  |
+------------------------+
```

3. Числа меньше тысячи
```sql
SELECT format_number(999);
```
```text
+----------------------------------+
| format_number(cast(999 as DOUBLE))|
+----------------------------------+
| 999                              |
+----------------------------------+
```

4. Обработка значения NULL
```sql
SELECT format_number(NULL);
```
```text
+---------------------+
| format_number(NULL) |
+---------------------+
| NULL                |
+---------------------+
```
