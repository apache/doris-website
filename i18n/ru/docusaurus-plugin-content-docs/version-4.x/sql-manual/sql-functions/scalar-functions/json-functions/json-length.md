## Описание {#description}
Функция `JSON_LENGTH` возвращает длину или количество элементов в заданном документе JSON. Если документ JSON представляет собой массив, функция возвращает количество элементов массива; если документ JSON представляет собой объект, она возвращает количество пар «ключ-значение» в объекте. Если документ JSON некорректен, функция возвращает `NULL`.

## Синтаксис {#syntax}

```sql
JSON_LENGTH(<json_object> [, <path>])
```

## Параметры {#parameters}
### Обязательные параметры {#required-parameters}
- `<json_object>`: документ типа JSON, длину которого требуется вернуть.

### Необязательные параметры {#optional-parameters}
- `<path>`: параметр строкового типа, позволяющий получить длину конкретного объекта в документе.

## Примечания {#notes}
Эта функция вычисляет длину документа JSON по следующим правилам:
- Длина скалярного значения равна 1. Например: '1', '"x"', 'true', 'false', 'null' имеют длину 1.
- Длина массива равна количеству его элементов. Например: '[1, 2]' имеет длину 2.
- Длина объекта равна количеству его членов. Например: '{"x": 1, "y": [1, 2, 3]}' имеет длину 2.

## Возвращаемое значение {#return-value}
- Для массивов JSON возвращает количество элементов массива.
- Для объектов JSON возвращает количество пар «ключ-значение» в объекте.
- Для скалярных типов JSON (таких как строки, числа, логические значения, null и т. д.) возвращает 1.
- Для некорректных строк JSON возвращает NULL.

## Примеры {#examples}
1. Пример 1
    ```sql
    SELECT json_length('{"k1":"v31","k2":300}');
    ```
    ```text
    +--------------------------------------+
    | json_length('{"k1":"v31","k2":300}') |
    +--------------------------------------+
    |                                    2 |
    +--------------------------------------+
    ```
    ```sql
    SELECT json_length('[1, 2, 3, 4, 5, 6]');
    ```
    ```text
    +-----------------------------------+
    | json_length('[1, 2, 3, 4, 5, 6]') |
    +-----------------------------------+
    |                                 6 |
    +-----------------------------------+
    ```
2. Длина значений скалярных типов
    ```sql
    SELECT json_length('"abc"');
    ```
    ```text
    +----------------------+
    | json_length('"abc"') |
    +----------------------+
    |                    1 |
    +----------------------+
    ```
    ```sql
    SELECT json_length('123');
    ```
    ```text
    +--------------------+
    | json_length('123') |
    +--------------------+
    |                  1 |
    +--------------------+
    ```
    ```sql
    SELECT json_length('{"k": null}');
    ```
    ```text
    +----------------------------+
    | json_length('{"k": null}') |
    +----------------------------+
    |                          1 |
    +----------------------------+
    ```
3. Указание пути
    ```sql
    SELECT json_length('{"x": 1, "y": [1, 2]}', '$.y');
    ```
    ```text
    +---------------------------------------------+
    | json_length('{"x": 1, "y": [1, 2]}', '$.y') |
    +---------------------------------------------+
    |                                           2 |
    +---------------------------------------------+
    ```
4. Параметры NULL
    ```sql
    SELECT json_length('{"x": 1, "y": [1, 2]}', NULL);
    ```
    ```text
    +--------------------------------------------+
    | json_length('{"x": 1, "y": [1, 2]}', NULL) |
    +--------------------------------------------+
    |                                       NULL |
    +--------------------------------------------+
    ```
    ```sql
    SELECT json_length(NULL, '$.y');
    ```
    ```text
    +--------------------------+
    | json_length(NULL, '$.y') |
    +--------------------------+
    |                     NULL |
    +--------------------------+
    ```
