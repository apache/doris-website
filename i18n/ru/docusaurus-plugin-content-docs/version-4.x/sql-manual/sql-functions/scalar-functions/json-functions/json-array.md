## Описание {#description}
Создаёт массив JSON, содержащий указанные элементы. Возвращает пустой массив, если параметры не переданы.

## Синтаксис {#syntax}
```sql
JSON_ARRAY([<expression>, ...]) 
```
## Параметры {#parameters}
### Переменное число параметров: {#variable-parameters}
- `<expression>`: Элементы, которые нужно включить в массив JSON. Можно указать одно или несколько значений разных типов, включая NULL.

## Возвращаемое значение {#return-value}
[`JSON`](../../../basic-element/sql-data-types/semi-structured/JSON.md): Возвращает массив JSON, составленный из списка параметров.

## Примечания по использованию {#usage-notes}
- Реализация JSON_ARRAY преобразует параметры разных типов в значения JSON, неявно вызывая функцию [`TO_JSON`](./to-json.md), поэтому типы параметров должны поддерживаться функцией [`TO_JSON`](./to-json.md)
- NULL преобразуется в JSON null. Если вы не хотите сохранять значения null в массиве, можно использовать функцию [`JSON_ARRAY_IGNORE_NULL`](./json-array-ignore-null.md).
- Если тип параметра не поддерживается функцией [`TO_JSON`](./to-json.md), возникнет ошибка. Сначала можно преобразовать этот параметр в тип String, например:
    ```sql
    select JSON_ARRAY(CAST(NOW() as String));
    ```
    > Функция NOW() возвращает значение типа DateTime, которое необходимо преобразовать в тип String с помощью функции CAST
- Если параметр представляет собой строку JSON и вы хотите добавить её в массив как объект JSON, следует явно вызвать функцию [`JSON_PARSE`](./json-parse.md), чтобы разобрать строку в объект JSON:
  ```sql
  select JSON_ARRAY(JSON_PARSE('{"key": "value"}'));
  ```

## Примеры {#examples}
1. Обычные параметры
    ```sql
    select json_array() as empty_array, json_array(1) v1, json_array(1, 'abc') v2;
    ```
    ```
    +-------------+------+-----------+
    | empty_array | v1   | v2        |
    +-------------+------+-----------+
    | []          | [1]  | [1,"abc"] |
    +-------------+------+-----------+
    ```
2. Параметры NULL
    ```sql
    select json_array(null) v1, json_array(1, null, 'I am a string') v2;
    ```
    ```
    +--------+--------------------------+
    | v1     | v2                       |
    +--------+--------------------------+
    | [null] | [1,null,"I am a string"] |
    +--------+--------------------------+
    ```
3. Неподдерживаемые типы параметров
    ```sql
    select json_array('item1', map(123, 'abc'));
    ```
    ```
    ERROR 1105 (HY000): errCode = 2, detailMessage = Can not find the compatibility function signature: to_json(MAP<TINYINT,VARCHAR(3)>)
    ```
4. Параметры типа Map можно явно преобразовать в JSON
    ```sql
    select json_array(1, cast(map('key', 'value') as json));
    ```
    ```
    +--------------------------------------------------+
    | json_array(1, cast(map('key', 'value') as json)) |
    +--------------------------------------------------+
    | [1,{"key":"value"}]                              |
    +--------------------------------------------------+
    ```
5. Строка JSON будет добавлена в массив в виде строки
    ```sql
    select json_array('{"key1": "value", "key2": [1, "I am a string", 3]}');
    ```
    ```
    +------------------------------------------------------------------+
    | json_array('{"key1": "value", "key2": [1, "I am a string", 3]}') |
    +------------------------------------------------------------------+
    | ["{\"key1\": \"value\", \"key2\": [1, \"I am a string\", 3]}"]   |
    +------------------------------------------------------------------+
    ```
6. Строку JSON можно разобрать с помощью `json_parse`, а затем передать в `json_array`
    ```sql
    select json_array(json_parse('{"key1": "value", "key2": [1, "I am a string", 3]}'));
    ```
    ```
    +------------------------------------------------------------------------------+
    | json_array(json_parse('{"key1": "value", "key2": [1, "I am a string", 3]}')) |
    +------------------------------------------------------------------------------+
    | [{"key1":"value","key2":[1,"I am a string",3]}]                              |
    +------------------------------------------------------------------------------+
    ```
