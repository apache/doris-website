## Описание {#description}

Функция JSON_VALID проверяет, соответствуют ли входные данные формату JSON. Она принимает входные данные типа String или JSON и проверяет корректность формата JSON.

## Синтаксис {#syntax}

```sql
JSON_VALID(<str>)
JSON_VALID(<json>)
```

## Параметры {#parameters}

- `<str>`: тип String, строка в формате JSON для проверки
- `<json>`: тип JSON, значение JSON для проверки

## Возвращаемые значения {#return-values}

- `1`: если входные данные представляют собой корректный JSON
- `0`: если входные данные не соответствуют формату JSON
- `NULL`: если входной параметр равен NULL

## Примечания {#notes}

Поддержка параметров типа JSON позволяет избежать возможных проблем с неявным преобразованием типов (из JSON в String) при передаче столбца типа JSON. Как правило, в столбцах типа JSON хранятся корректные данные JSON, поэтому вызов JSON_VALID с параметром типа JSON обычно возвращает 1.

## Псевдоним {#alias}

- JSONB_VALID

## Примеры {#examples}

1. Проверка корректной строки JSON
    ```sql
    SELECT json_valid('{"k1":"v31","k2":300}');
    ```
    ```text
    +-------------------------------------+
    | json_valid('{"k1":"v31","k2":300}') |
    +-------------------------------------+
    |                                   1 |
    +-------------------------------------+
    ```

2. Проверка некорректной строки JSON
    ```sql
    SELECT json_valid('invalid json');
    ```
    ```text
    +----------------------------+
    | json_valid('invalid json') |
    +----------------------------+
    |                          0 |
    +----------------------------+
    ```

3. Проверка параметра NULL
    ```sql
    SELECT json_valid(NULL);
    ```
    ```text
    +------------------+
    | json_valid(NULL) |
    +------------------+
    |             NULL |
    +------------------+
    ```

4. Проверка параметра типа JSON
    ```sql
    SELECT json_valid(cast('{"k1":"v31","k2":300}' as json));
    ```
    ```text
    +----------------------------------------------------+
    | json_valid(cast('{"k1":"v31","k2":300}' as json)) |
    +----------------------------------------------------+
    |                                                  1 |
    +----------------------------------------------------+
    ```
