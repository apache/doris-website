## Описание {#description}
Функция `JSON_INSERT` вставляет данные в JSON и возвращает результат.

## Синтаксис {#syntax}
```sql
JSON_INSERT (<json_object>, <path>,  <value>[, <path>,  <value>, ...])
```

## Параметры {#parameters}
- `<json_object>`: выражение типа JSON, задающее изменяемый объект.
- `<path>`: выражение строкового типа, задающее путь для вставки значения
- `<value>`: значение типа JSON или другого типа, поддерживаемого [`TO_JSON`](./to-json.md), которое требуется вставить.

## Возвращаемое значение {#return-value}
- `Nullable(JSON)` Возвращает изменённый объект JSON

## Примечания по использованию {#usage-notes}
1. Обратите внимание, что пары «путь — значение» обрабатываются слева направо.
2. Если значение, на которое указывает `<path>`, уже существует в объекте JSON, вставка не выполняется.
3. `<path>` не может содержать подстановочные знаки. При их наличии возникает ошибка.
4. Если `<path>` содержит несколько уровней пути, все уровни, кроме последнего, должны существовать в объекте JSON.
5. Если `<path>` указывает на элемент массива, но объект фактически не является массивом, этот объект становится первым элементом массива, после чего обработка продолжается как для обычного массива.
6. Если `<json_object>` или `<path>` равен NULL, возвращается NULL. Если `<value>` равен NULL, вставляется значение JSON null.

## Примеры {#examples}
1. Пары «путь — значение» обрабатываются слева направо
    ```sql
    select json_insert('{}', '$.k', json_parse('{}'), '$.k.k2', 123);
    ```
    ```text
    +-----------------------------------------------------------+
    | json_insert('{}', '$.k', json_parse('{}'), '$.k.k2', 123) |
    +-----------------------------------------------------------+
    | {"k":{"k2":123}}                                          |
    +-----------------------------------------------------------+
    ```
2. Значение, на которое указывает `<path>`, уже существует в объекте JSON
    ```sql
    select json_insert('{"k": 1}', "$.k", 2);
    ```
    ```text
    +-----------------------------------+
    | json_insert('{"k": 1}', "$.k", 2) |
    +-----------------------------------+
    | {"k":1}                           |
    +-----------------------------------+
    ```
3. `<path>` не может содержать подстановочные знаки
    ```sql
    select json_insert('{"k": 1}', "$.*", 2);
    ```
    ```text
    ERROR 1105 (HY000): errCode = 2, detailMessage = [INVALID_ARGUMENT] In this situation, path expressions may not contain the * and ** tokens or an array range, argument index: 1, row index: 0
    ```
4. Создание многоуровневых путей невозможно
    ```sql
    select json_insert('{}', '$.k1.k2.k3', 123);
    ```
    ```text
    +--------------------------------------+
    | json_insert('{}', '$.k1.k2.k3', 123) |
    +--------------------------------------+
    | {}                                   |
    +--------------------------------------+
    ```
5. Автоматическое преобразование в массив
    ```sql
    select json_insert('{"k": "v"}', '$[1]', 123);
    ```
    ```text
    +----------------------------------------+
    | json_insert('{"k": "v"}', '$[1]', 123) |
    +----------------------------------------+
    | [{"k": "v"}, 123]                      |
    +----------------------------------------+
    ```
    ```sql
    select json_insert('{"k": "v"}', '$.k[1]', 123);
    ```
    ```text
    +------------------------------------------+
    | json_insert('{"k": "v"}', '$.k[1]', 123) |
    +------------------------------------------+
    | {"k": ["v", 123]}                        |
    +------------------------------------------+
    ```
6. Параметры со значением NULL
    ```sql
    select json_insert(NULL, '$[1]', 123);
    ```
    ```text
    +--------------------------------+
    | json_insert(NULL, '$[1]', 123) |
    +--------------------------------+
    | NULL                           |
    +--------------------------------+
    ```
    ```sql
    select json_insert('{"k": "v"}', NULL, 123);
    ```
    ```text
    +--------------------------------------+
    | json_insert('{"k": "v"}', NULL, 123) |
    +--------------------------------------+
    | NULL                                 |
    +--------------------------------------+
    ```
    ```sql
    select json_insert('{"k": "v"}', '$.k[1]', NULL);
    ```
    ```text
    +-------------------------------------------+
    | json_insert('{"k": "v"}', '$.k[1]', NULL) |
    +-------------------------------------------+
    | {"k": ["v", null]}                        |
    +-------------------------------------------+
    ```
