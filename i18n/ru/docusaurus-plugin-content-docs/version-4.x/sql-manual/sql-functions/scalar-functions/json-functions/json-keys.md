## Описание {#description}
Возвращает все ключи объекта JSON в виде массива. По умолчанию возвращает ключи корневого объекта, но с помощью параметров можно также указать путь к объекту, ключи которого нужно вернуть.

## Синтаксис {#syntax}

```sql
JSON_KEYS(<json_object>[, <path>])
```

## Параметры {#parameters}
### Обязательные параметры {#required-parameters}
- `<json_object>`: объект типа JSON, из которого необходимо извлечь ключи.


### Необязательные параметры {#optional-parameters}
- `<path>`: тип String; необязательный путь JSON, указывающий поддокумент JSON для проверки. Если не указан, по умолчанию используется корневой документ.

## Возвращаемое значение {#return-value}
- Array<String> Возвращает массив строк, содержащий все ключи объекта JSON.

## Примечания {#notes}
- Возвращает NULL, если `<json_object>` или `<path>` имеет значение NULL.
- Возвращает NULL, если значение не является объектом JSON (например, если это массив JSON).
- Возвращает NULL, если объект, на который указывает `<path>`, не существует.

## Примеры {#examples}
1. Пример 1
    ```sql
    SELECT JSON_KEYS('{"a": 1, "b": {"c": 30}}');
    ```
    ```text
    +---------------------------------------+
    | JSON_KEYS('{"a": 1, "b": {"c": 30}}') |
    +---------------------------------------+
    | ["a", "b"]                            |
    +---------------------------------------+
    ```
    ```sql
    SELECT JSON_KEYS('{}');
    ```
    ```text
    +-----------------+
    | JSON_KEYS('{}') |
    +-----------------+
    | []              |
    +-----------------+
    ```

2. Указание пути
    ```sql
    SELECT JSON_KEYS('{"a": 1, "b": {"c": 30}}', '$.b');
    ```
    ```text
    +----------------------------------------------+
    | JSON_KEYS('{"a": 1, "b": {"c": 30}}', '$.b') |
    +----------------------------------------------+
    | ["c"]                                        |
    +----------------------------------------------+
    ```
3. Параметры со значением NULL
    ```sql
    SELECT JSON_KEYS('{"a": 1, "b": {"c": 30}}', NULL);
    ```
    ```text
    +---------------------------------------------+
    | JSON_KEYS('{"a": 1, "b": {"c": 30}}', NULL) |
    +---------------------------------------------+
    | NULL                                        |
    +---------------------------------------------+
    ```
    ```sql
    SELECT JSON_KEYS(NULL);
    ```
    ```text
    +-----------------+
    | JSON_KEYS(NULL) |
    +-----------------+
    | NULL            |
    +-----------------+
    ```
4. Значение не является объектом JSON
    ```sql
    SELECT JSON_KEYS('[1,2]');
    ```
    ```text
    +--------------------+
    | JSON_KEYS('[1,2]') |
    +--------------------+
    | NULL               |
    +--------------------+
    ```
    ```sql
    SELECT JSON_KEYS('{"k": [1, 2, 3]}', '$.k');
    ```
    ```text
    +--------------------------------------+
    | JSON_KEYS('{"k": [1, 2, 3]}', '$.k') |
    +--------------------------------------+
    | NULL                                 |
    +--------------------------------------+
    ```
5. Объект, указанный в пути, не существует
    ```sql
    SELECT JSON_KEYS('{"a": 1, "b": {"c": 30}}', '$.c');
    ```
    ```text
    +----------------------------------------------+
    | JSON_KEYS('{"a": 1, "b": {"c": 30}}', '$.c') |
    +----------------------------------------------+
    | NULL                                         |
    +----------------------------------------------+
    ```
