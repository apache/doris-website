## Описание {#description}

Функция `JSON_SEARCH` используется для поиска указанных значений в документе JSON. Если значение найдено, она возвращает путь к нему. Если значение не найдено, она возвращает NULL. Функция поддерживает рекурсивный поиск в структурах данных JSON.

## Синтаксис {#syntax}

```sql
JSON_SEARCH( <json_object>, <one_or_all>, <search_value> )
```
## Параметры {#parameters}
- `<json_object>`: тип JSON, документ JSON, в котором выполняется поиск.
- `<one_or_all>`: тип String, определяет, нужно ли искать все совпадающие значения. Допустимые значения: 'one' или 'all'.
- `<search_value>`: тип String, значение, которое нужно найти.
    Поддерживает символы подстановки '%' (соответствует любому количеству произвольных символов) и '_' (соответствует любому одному символу).

## Возвращаемое значение {#return-value}
Nullable(JSON): в зависимости от параметра `<one_or_all>` возможны два варианта:

1. 'one': если найдено совпадающее значение, возвращает путь в JSON, указывающий на это значение. Если совпадающее значение не найдено, возвращает NULL.
2. 'all': возвращает пути ко всем совпадающим значениям. Если значений несколько, возвращает пути в виде массива JSON. Если совпадения не найдены, возвращает NULL.

## Примечания {#notes}
- Параметр `one_or_all` определяет, нужно ли искать все совпадающие значения. 'one' возвращает первый путь к совпадающему значению, 'all' возвращает все такие пути. При любом другом значении возникает ошибка.
- Если совпадающее значение не найдено, функция возвращает NULL.
- Если любой из параметров `<json_object>`, `<one_or_all>`, `<search_value>` имеет значение NULL, возвращает NULL.

## Примеры {#examples}

1. Поиск одного значения (one)
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30}', 'one', 'John');
    ```
    ```text
    +-----------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30}', 'one', 'John') |
    +-----------------------------------------------------------+
    | "$.name"                                                  |
    +-----------------------------------------------------------+

    ```
2. Поиск одного значения (one): возвращается только один путь, даже если найдено несколько совпадений
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30, "alias": "John"}', 'one', 'John');
    ```
    ```text
    +----------------------------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30, "alias": "John"}', 'one', 'John') |
    +----------------------------------------------------------------------------+
    | "$.name"                                                                   |
    +----------------------------------------------------------------------------+
    ```
3. Поиск всех совпадающих значений (all)
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30, "alias": "John"}', 'all', 'John');
    ```
    ```text
    +----------------------------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30, "alias": "John"}', 'all', 'John') |
    +----------------------------------------------------------------------------+
    | ["$.alias","$.name"]                                                       |
    +----------------------------------------------------------------------------+
    ```
4. '%' в качестве символа подстановки
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30, "alias": "John"}', 'all', '%');
    ```
    ```text
    +-------------------------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30, "alias": "John"}', 'all', '%') |
    +-------------------------------------------------------------------------+
    | ["$.alias","$.name"]                                                    |
    +-------------------------------------------------------------------------+
    ```
5. '_' в качестве символа подстановки
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30, "alias": "Jihn"}', 'all', 'J_hn');
    ```
    ```text
    +----------------------------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30, "alias": "Jihn"}', 'all', 'J_hn') |
    +----------------------------------------------------------------------------+
    | ["$.alias","$.name"]                                                       |
    +----------------------------------------------------------------------------+
    ```
6. Экранирование символа подстановки
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30, "alias": "J_hn"}', 'all', 'J\_hn');
    ```
    ```text
    +-----------------------------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30, "alias": "J_hn"}', 'all', 'J\_hn') |
    +-----------------------------------------------------------------------------+
    | "$.alias"                                                                   |
    +-----------------------------------------------------------------------------+
    ```
    > 'J\_hn' соответствует только "J_hn" и не соответствует "John".
7. Совпадающее значение не найдено

    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30}', 'one', 'Alice');
    ```
    ```text
    +------------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30}', 'one', 'Alice') |
    +------------------------------------------------------------+
    | NULL                                                       |
    +------------------------------------------------------------+
    ```
8. Параметры со значением NULL
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30}', NULL, 'Alice');
    ```
    ```text
    +-----------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30}', NULL, 'Alice') |
    +-----------------------------------------------------------+
    | NULL                                                      |
    +-----------------------------------------------------------+
    ```
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30}', 'one', NULL);
    ```
    ```text
    +---------------------------------------------------------+
    | JSON_SEARCH('{"name": "John", "age": 30}', 'one', NULL) |
    +---------------------------------------------------------+
    | NULL                                                    |
    +---------------------------------------------------------+
    ```
    ```sql
    SELECT JSON_SEARCH(NULL, 'one', 'Alice');
    ```
    ```
    +-----------------------------------+
    | JSON_SEARCH(NULL, 'one', 'Alice') |
    +-----------------------------------+
    | NULL                              |
    +-----------------------------------+
    ```
9. Недопустимое значение параметра `<one_or_all>`
    ```sql
    SELECT JSON_SEARCH('{"name": "John", "age": 30}', 'three', 'Alice');
    ```
    ```text
    ERROR 1105 (HY000): errCode = 2, detailMessage = [INVALID_ARGUMENT]the one_or_all argument three is not 'one' not 'all'
    ```
