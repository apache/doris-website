## Описание {#description}
`JSON_EXTRACT_LARGEINT` извлекает из объекта JSON поле, указанное в `<json_path>`, и преобразует его в тип [`LARGEINT`](../../../basic-element/sql-data-types/numeric/LARGEINT.md).

## Синтаксис {#syntax}
```sql
JSON_EXTRACT_LARGEINT(<json_object>, <json_path>)
```

## Параметры {#parameters}
- `<json_object>`: объект типа JSON, из которого извлекается элемент.
- `<json_path>`: значение типа String, задающее путь JSON для извлечения целевого элемента из исходного объекта JSON.

## Возвращаемое значение {#return-value}
`Nullable(LARGEINT)`: извлечённое значение LARGEINT; в некоторых случаях возвращается NULL.

## Примечания по использованию {#usage-notes}
1. Если `<json_object>` или `<json_path>` имеет значение NULL, возвращается NULL.
2. Если элемент, указанный в `<json_path>`, не существует, возвращается NULL.
3. Если элемент, указанный в `<json_path>`, невозможно преобразовать в LARGEINT, возвращается NULL.
4. Поведение соответствует "cast + json_extract", что эквивалентно следующему выражению:
    ```sql
    CAST(JSON_EXTRACT(<json_object>, <json_path>) as LARGEINT)
    ```

## Примеры {#examples}
1. Корректные параметры
    ```sql
    SELECT json_extract_largeint('{"id": 11529215046068469760, "name": "doris"}', '$.id');
    ```
    ```text
    +--------------------------------------------------------------------------------+
    | json_extract_largeint('{"id": 11529215046068469760, "name": "doris"}', '$.id') |
    +--------------------------------------------------------------------------------+
    | 11529215046068469760                                                           |
    +--------------------------------------------------------------------------------+
    ```
2. Несуществующий путь
    ```sql
    SELECT json_extract_largeint('{"id": 11529215046068469760, "name": "doris"}', '$.id2');
    ```
    ```text
    +---------------------------------------------------------------------------------+
    | json_extract_largeint('{"id": 11529215046068469760, "name": "doris"}', '$.id2') |
    +---------------------------------------------------------------------------------+
    | NULL                                                                            |
    +---------------------------------------------------------------------------------+
    ```
3. Параметры со значением NULL
    ```sql
    SELECT json_extract_largeint('{"id": 11529215046068469760, "name": "doris"}', NULl);
    ```
    ```text
    +------------------------------------------------------------------------------+
    | json_extract_largeint('{"id": 11529215046068469760, "name": "doris"}', NULl) |
    +------------------------------------------------------------------------------+
    | NULL                                                                         |
    +------------------------------------------------------------------------------+
    ```
    ```sql
    SELECT json_extract_largeint(NULL, '$.id2');
    ```
    ```text
    +--------------------------------------+
    | json_extract_largeint(NULL, '$.id2') |
    +--------------------------------------+
    | NULL                                 |
    +--------------------------------------+
    ```
4. Невозможность преобразования в LARGEINT
    ```sql
    SELECT json_extract_largeint('{"id": 123, "name": "doris"}','$.name');
    ```
    ```text
    +----------------------------------------------------------------+
    | json_extract_largeint('{"id": 123, "name": "doris"}','$.name') |
    +----------------------------------------------------------------+
    | NULL                                                           |
    +----------------------------------------------------------------+
    ```
