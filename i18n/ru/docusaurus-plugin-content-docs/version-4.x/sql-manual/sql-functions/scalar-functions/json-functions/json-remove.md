## Описание {#description}
Функция `JSON_REMOVE` используется для удаления данных из документа JSON и возврата результата.

## Синтаксис {#syntax}
```sql
JSON_REMOVE (<json_object>, path[, path] ...)
```

## Параметры {#parameters}
- `<json_object>` — выражение типа JSON, из которого необходимо удалить данные.
- `<path>` — выражение строкового типа. Параметры пути обрабатываются слева направо. Документ JSON, полученный после обработки одного пути, становится новым значением для обработки следующего пути.

## Возвращаемое значение {#return-value}
- `Nullable(JSON)` возвращает объект JSON после удаления данных.

## Примеры {#examples}
1. Путь не существует
```sql
SELECT JSON_REMOVE('{"a": 1, "b": 2, "c": 3}', '$.d');
```
```text
+------------------------------------------------+
| JSON_REMOVE('{"a": 1, "b": 2, "c": 3}', '$.d') |
+------------------------------------------------+
| {"a":1,"b":2,"c":3}                            |
+------------------------------------------------+
```

2. Удаление из объекта JSON значения, на которое указывает `<path>`
```sql
SELECT JSON_REMOVE('{"Name": "Jack", "Gender": "Male", "Age": 20}', '$.Age');
```
```text
+-----------------------------------------------------------------------+
| JSON_REMOVE('{"Name": "Jack", "Gender": "Male", "Age": 20}', '$.Age') |
+-----------------------------------------------------------------------+
| {"Name":"Jack","Gender":"Male"}                                       |
+-----------------------------------------------------------------------+
```

3. Указание нескольких путей для удаления данных из нескольких мест в объекте JSON
```sql
SELECT JSON_REMOVE('[1, 2, 3, 4, 5]', '$[3]'), JSON_REMOVE('[1, 2, 3, 4, 5]', '$[1]', '$[3]');
```
```text
+----------------------------------------+------------------------------------------------+
| JSON_REMOVE('[1, 2, 3, 4, 5]', '$[3]') | JSON_REMOVE('[1, 2, 3, 4, 5]', '$[1]', '$[3]') |
+----------------------------------------+------------------------------------------------+
| [1,2,3,5]                              | [1,3,4]                                        |
+----------------------------------------+------------------------------------------------+
```

4. Объект JSON большего размера
```sql
SELECT JSON_REMOVE('{"Person": {"Name": "Jack","Age": 20,"Hobbies": ["Eating", "Sleeping", "Base Jumping"]}}', '$.Person.Age', '$.Person.Hobbies[2]');
```
```text
+------------------------------------------------------------------------------------------------------------------------------------------------+
| JSON_REMOVE('{"Person": {"Name": "Jack","Age": 20,"Hobbies": ["Eating", "Sleeping", "Base Jumping"]}}', '$.Person.Age', '$.Person.Hobbies[2]') |
+------------------------------------------------------------------------------------------------------------------------------------------------+
| {"Person":{"Name":"Jack","Hobbies":["Eating","Sleeping"]}}                                                                                     |
+------------------------------------------------------------------------------------------------------------------------------------------------+
```
