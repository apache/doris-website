## Описание {#description}

Возвращает базу данных текущего подключения SQL-клиента.

## Псевдоним {#alias}

- SCHEMA

## Синтаксис {#syntax}

```sql
DATABASE()
```
или

```sql
SCHEMA()
```

## Возвращаемое значение {#return-value}

Имя базы данных, к которой подключён текущий SQL-клиент.

## Примеры {#examples}

```sql
select database(),schema();
```
