## Описание {#description}

Возвращает имя текущего пользователя и его белый список правил для IP-адресов.

## Синтаксис {#syntax}

```sql
CURRENT_USER()
```

## Возвращаемое значение {#return-value}

Возвращает имя текущего пользователя и его белый список IP-адресов.

Формат:`<user_name>@<ip_white_list>`

## Примеры {#examples}

- Пользователь root, без ограничений по IP
```sql
select current_user();
```

```text
+----------------+
| current_user() |
+----------------+
| 'root'@'%'     |
+----------------+
```

- Пользователь doris, белый список IP-адресов: 192.168.*
```sql
select current_user();
```

```text
+---------------------+
| current_user()      |
+---------------------+
| 'doris'@'192.168.%' |
+---------------------+
```
