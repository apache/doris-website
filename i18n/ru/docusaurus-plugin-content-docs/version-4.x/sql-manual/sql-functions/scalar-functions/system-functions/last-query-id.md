## Описание {#description}

Получение идентификатора последнего запроса текущего пользователя.

## Синтаксис {#syntax}

```sql
LAST_QUERY_ID()
```

## Возвращаемое значение {#return-value}

Возвращает идентификатор последнего запроса текущего пользователя;

## Примеры {#examples}

```sql
select last_query_id();
```

```text
+-----------------------------------+
| last_query_id()                   |
+-----------------------------------+
| 128f913c3ec84a1e-b834bd0262cc090a |
+-----------------------------------+
```
