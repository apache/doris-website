## Описание {#description}

Удаляет повторяющиеся ключи из Map.
По умолчанию Doris удаляет повторяющиеся ключи из создаваемых Map (например, при импорте данных).
Однако в Map, полученных в некоторых особых случаях, например при чтении данных из внешних таблиц или преобразовании строк в Map, повторяющиеся ключи могут сохраняться.
Эта функция позволяет удалять повторяющиеся ключи из значений типа Map.

## Синтаксис {#syntax}

```sql
DEDUPLICATE_MAP(<map>)
```

## Параметры {#parameters}

- `<map>`: Содержимое входного Map.

## Возвращаемое значение {#return-value}

`Map`: Возвращает Map без повторяющихся ключей (тип совпадает с типом входного параметра).

## Примеры {#examples}
    ```sql
    select m, deduplicate_map(m) from (select cast('{"a": 123, "a": 345}' as map<string, int>) m ) t;
    ```

    ```text
    +--------------------+--------------------+
    | m                  | deduplicate_map(m) |
    +--------------------+--------------------+
    | {"a":123, "a":345} | {"a":345}          |
    +--------------------+--------------------+
    ```
> В Map, полученных путём преобразования строк, повторяющиеся ключи не удаляются.
