## Описание {#description}

Определяет, содержит ли заданный `map` указанную запись `(key, value)`

## Синтаксис {#syntax}

```sql
MAP_CONTAINS_ENTRY(<map>, <key>, <value>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<map>` | Содержимое входного map |
| `<key>` | Ключ для поиска |
| `<value>` | Значение для поиска |

## Возвращаемое значение {#return-value}

Определяет, содержит ли заданный `map` указанную пару `(key, value)`. Возвращает 1, если пара существует, иначе возвращает 0. Если `<map>` имеет значение `NULL`, возвращает `NULL`.

При сравнении ключей и значений применяется правило «null-safe equal» (два значения `NULL` считаются равными), что отличается от стандартного определения SQL.

## Пример {#example}

```sql
select map_contains_entry(map(null, 1, 2, null), null, 1);
```

```text
+----------------------------------------------------+
| map_contains_entry(map(null, 1, 2, null), null, 1) |
+----------------------------------------------------+
|                                                  1 |
+----------------------------------------------------+
```

```sql
select map_contains_entry(map(1, '100', 0.1, '2'), 1, '100');
```

```text
+-------------------------------------------------------+
| map_contains_entry(map(1, '100', 0.1, '2'), 1, '100') |
+-------------------------------------------------------+
|                                                     1 |
+-------------------------------------------------------+
```

```sql
select map_contains_entry(map(1, '100', 0.1, '2'), 0.11, '2');
```

```text
+--------------------------------------------------------+
| map_contains_entry(map(1, '100', 0.1, '2'), 0.11, '2') |
+--------------------------------------------------------+
|                                                      0 |
+--------------------------------------------------------+
```
