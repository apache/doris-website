## Описание {#description}

Преобразует заданное отображение `map` в `ARRAY<STRUCT<key, value>>`.

Каждый элемент возвращаемого массива представляет собой структуру с двумя именованными полями: `key` и `value`. Оба поля допускают значение NULL.
Типы полей `key` и `value` совпадают с типами ключей и значений отображения соответственно.

## Синтаксис {#syntax}

```sql
MAP_ENTRIES(<map>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<map>` | Содержимое входного отображения |

## Возвращаемое значение {#return-value}

Возвращает массив структур, представляющих элементы отображения. Если `<map>` имеет значение `NULL`, возвращает `NULL`.

## Пример {#example}

```sql
select 
  map_entries(map()),
  map_entries(map(1, '100', 0.1, '2'));
```

```text
+--------------------+--------------------------------------------------------+
| map_entries(map()) | map_entries(map(1, '100', 0.1, '2'))                   |
+--------------------+--------------------------------------------------------+
| []                 | [{"key":1.0, "value":"100"}, {"key":0.1, "value":"2"}] |
+--------------------+--------------------------------------------------------+
```
