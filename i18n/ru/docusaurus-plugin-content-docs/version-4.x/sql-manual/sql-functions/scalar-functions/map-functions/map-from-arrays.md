## Описание {#description}

Создаёт `MAP<K, V>` из массива ключей и массива значений. Элементы на одинаковых позициях образуют пару «ключ-значение».

:::note
Эта функция поддерживается начиная с Apache Doris 4.2.
:::

## Синтаксис {#syntax}

```sql
MAP_FROM_ARRAYS(<keys>, <values>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<keys>` | Массив типа `ARRAY<K>`. `K` должен быть типом, поддерживаемым для ключей MAP. Массив и его элементы могут иметь значение `NULL`. |
| `<values>` | Массив типа `ARRAY<V>`. Массив и его элементы могут иметь значение `NULL`. Если оба массива отличны от `NULL`, количество элементов в этом массиве должно совпадать с количеством элементов в `<keys>`. |

## Возвращаемое значение {#return-value}

Возвращает `MAP<K, V>`.

- Если любой из входных массивов имеет значение `NULL`, возвращает `NULL`.
- Элементы `NULL` сохраняются в результате как ключи или значения со значением `NULL`.
- Если оба массива отличны от `NULL`, но имеют разную длину, возникает ошибка. Длина другого массива не проверяется, если любой из массивов имеет значение `NULL`.
- Если ключ встречается несколько раз, сохраняется значение из последнего вхождения.
- Если аргумент не является массивом или `K` не относится к типам, поддерживаемым для ключей MAP, возникает ошибка анализа.

## Примеры {#examples}

```sql
SELECT map_from_arrays([1, 2], [10, 20]) AS result;
```

```text
+--------------+
| result       |
+--------------+
| {1:10, 2:20} |
+--------------+
```

```sql
SELECT map_from_arrays([1, 1], [10, 20]) AS result;
```

```text
+--------+
| result |
+--------+
| {1:20} |
+--------+
```

```sql
SELECT map_from_arrays(CAST(NULL AS ARRAY<INT>), [10]);
```

```text
+-------------------------------------------------+
| map_from_arrays(CAST(NULL AS ARRAY<INT>), [10]) |
+-------------------------------------------------+
| NULL                                            |
+-------------------------------------------------+
```

```sql
SELECT map_from_arrays(
    array(CAST(NULL AS INT), 2),
    array(10, CAST(NULL AS INT))) AS result;
```

```text
+-------------------+
| result            |
+-------------------+
| {null:10, 2:null} |
+-------------------+
```

```sql
SELECT map_from_arrays([1, 2], [10]);
```

```text
ERROR 1105 (HY000): The key and value array offsets of function map_from_arrays must be identical
```
