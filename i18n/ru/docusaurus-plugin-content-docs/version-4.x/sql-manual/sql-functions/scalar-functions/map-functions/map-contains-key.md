## Описание {#description}

Определяет, содержит ли заданный `map` указанный ключ `key`

## Синтаксис {#syntax}

```sql
MAP_CONTAINS_KEY(<map>, <key>)
```

## Параметры {#parameters}
- `<map>` — содержимое входного map типа [`MAP`](../../../basic-element/sql-data-types/semi-structured/MAP.md).
- `<key>` — ключ для поиска с типом, поддерживаемым [`MAP`](../../../basic-element/sql-data-types/semi-structured/MAP.md).

## Возвращаемое значение {#return-value}
Определяет, содержит ли заданный `map` указанный ключ `key`: возвращает 1, если ключ существует, и 0, если его нет.

## Примеры {#examples}

```sql
select map_contains_key(map(null, 1, 2, null), null),map_contains_key(map(1, "100", 0.1, 2), 0.11);
```

```text
+-----------------------------------------------+-----------------------------------------------+
| map_contains_key(map(null, 1, 2, null), null) | map_contains_key(map(1, "100", 0.1, 2), 0.11) |
+-----------------------------------------------+-----------------------------------------------+
|                                             1 |                                             0 |
+-----------------------------------------------+-----------------------------------------------+
```
> При сравнении ключей в Map используется «null-safe equal» (null и null считаются равными), что отличается от 

```sql
select map_contains_key(map(null,1), null);
```
```text
+-------------------------------------+
| map_contains_key(map(null,1), null) |
+-------------------------------------+
|                                   1 |
+-------------------------------------+
