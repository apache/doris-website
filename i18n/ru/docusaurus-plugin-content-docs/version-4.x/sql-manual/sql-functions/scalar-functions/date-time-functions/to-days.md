## Описание {#description}
Функция для вычислений с датами, которая преобразует дату в числовое значение, вычисляя общее количество дней от начальной даты (`0000-00-00`) до указанной даты.

Поведение этой функции соответствует поведению [функции to_days](https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_to-days) в MySQL.

## Синтаксис {#syntax}

```sql
TO_DAYS(`<date_or_date_expr>`)
```

## Параметры {#parameters}
| Параметр | Описание |
|-----------|-------------|
| `<date_or_time_expr>` | Входное значение даты и времени; поддерживаются типы date/datetime. Подробнее о форматах datetime и date см. в разделах [преобразование даты и времени](../../../../sql-manual/basic-element/sql-data-types/conversion/datetime-conversion) и [преобразование даты](../../../../sql-manual/basic-element/sql-data-types/conversion/date-conversion) |

## Возвращаемое значение {#return-value}

Возвращает значение типа BIGINT, представляющее количество дней.

## Примеры {#examples}

```sql
-- Based on the date `0000-00-00`
select to_days('0000-01-01');
+-----------------------+
| to_days('0000-01-01') |
+-----------------------+
|                     1 |
+-----------------------+

--input date type
select to_days('2007-10-07');
+-----------------------+
| to_days('2007-10-07') |
+-----------------------+
|                733321 |
+-----------------------+

--input datetime type
select to_days('2007-10-07 10:03:09');
+--------------------------------+
| to_days('2007-10-07 10:03:09') |
+--------------------------------+
|                         733321 |
+--------------------------------+
```
