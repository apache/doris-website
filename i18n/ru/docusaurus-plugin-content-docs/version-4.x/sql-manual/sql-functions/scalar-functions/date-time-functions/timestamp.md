# TIMESTAMP {#timestamp}

## Описание {#description}

Функция TIMESTAMP преобразует строку в формате даты и времени в значение типа DATETIME.
Если указан второй параметр, задающий время, функция вычисляет сумму двух параметров и возвращает результат в формате DATETIME.

Подробнее о форматах даты и времени см. в разделе [Преобразование даты и времени](../../../../sql-manual/basic-element/sql-data-types/conversion/datetime-conversion).

Эта функция работает так же, как [функция timestamp](https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_timestamp) в MySQL.

## Синтаксис {#syntax}

```sql
TIMESTAMP(<date_or_datetime_string>[, <time_string>])
```

## Параметры {#parameters}

| Параметр | Описание                                           |
|-----------|-------------------------------------------------------|
| `date_or_datetime_string` | Строка с датой или датой и временем |
| `time_string` | Строка со временем |

## Возвращаемое значение {#return-value}

Возвращает значение типа DATETIME.

Если передан один параметр, возвращает результат преобразования первого параметра в тип DATETIME.
Если переданы два параметра, возвращает их сумму.

- Если первый параметр представляет собой строку с датой, время устанавливается в 00:00:00
- Если какой-либо параметр равен NULL или тип параметра не соответствует ожидаемому, возвращает NULL

## Примеры {#examples}

```sql
-- Convert a string to DATETIME
SELECT TIMESTAMP('2019-01-01 12:00:00');

+------------------------------------+
| timestamp('2019-01-01 12:00:00')   |
+------------------------------------+
| 2019-01-01 12:00:00                |
+------------------------------------+

-- Input date string
SELECT TIMESTAMP('2019-01-01');
+-------------------------+
| TIMESTAMP('2019-01-01') |
+-------------------------+
| 2019-01-01 00:00:00     |
+-------------------------+

-- Input NULL, returns NULL
SELECT TIMESTAMP(NULL);
+-----------------+
| TIMESTAMP(NULL) |
+-----------------+
| NULL            |
+-----------------+

-- Two parameters, returns the sum of the two parameters (Date/DateTime + Time)
SELECT TIMESTAMP('2025-11-30 23:45:12', '12:34:56');
+----------------------------------------------+
| TIMESTAMP('2025-11-30 23:45:12', '12:34:56') |
+----------------------------------------------+
| 2025-12-01 12:20:08                          |
+----------------------------------------------+

-- The first parameter only accepts Date/Datetime type, the second parameter only accepts Time type
SELECT TIMESTAMP('12:34:56', '12:34:56');
+-----------------------------------+
| TIMESTAMP('12:34:56', '12:34:56') |
+-----------------------------------+
| NULL                              |
+-----------------------------------+

-- If any parameter is NULL, returns NULL
SELECT TIMESTAMP('2025-12-01', NULL);
+-------------------------------+
| TIMESTAMP('2025-12-01', NULL) |
+-------------------------------+
| NULL                          |
+-------------------------------+
```
