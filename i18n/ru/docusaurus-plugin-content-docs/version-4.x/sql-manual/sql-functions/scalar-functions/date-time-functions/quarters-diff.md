## Описание {#description}

Функция `QUARTERS_DIFF` вычисляет количество кварталов между двумя датами. Она принимает два параметра даты и возвращает разность в кварталах, полученную при вычитании второй даты из первой. Разность в кварталах равна разности в месяцах, делённой на 3 (с округлением к нулю).

## Синтаксис {#syntax}

```sql
QUARTERS_DIFF(<enddate>, <startdate>)
```

## Параметры {#parameters}

| Параметр     | Описание                                                                           |
|---------------|--------------------------------------------------------------------------------------|
| `<enddate>`   | Конечная дата, обозначающая более позднюю дату при вычислении разности. Поддерживаются типы `DATE` и `DATETIME` |
| `<startdate>` | Начальная дата, обозначающая более раннюю дату при вычислении разности. Поддерживаются типы `DATE` и `DATETIME` |

## Возвращаемое значение {#return-value}

Возвращает количество кварталов, полученное при вычитании `<startdate>` из `<enddate>`
- Если хотя бы один из параметров `<enddate>` или `<startdate>` равен NULL, возвращает NULL

## Примеры {#examples}

```sql
select QUARTERS_DIFF('2021-03-25', '2020-10-25'), QUARTERS_DIFF('2020-10-25 10:00:00', '2022-12-25 11:00:00');
```

```text
+------------------------------------------+------------------------------------------------------------+
| QUARTERS_DIFF('2021-03-25','2020-10-25') | QUARTERS_DIFF('2020-10-25 10:00:00','2022-12-25 11:00:00') |
+------------------------------------------+------------------------------------------------------------+
|                                        1 |                                                         -8 |
+------------------------------------------+------------------------------------------------------------+
```
