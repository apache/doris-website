## Описание {#description}
Функция UTC_TIME возвращает текущее время в часовом поясе UTC. Эта функция не зависит от локального часового пояса и всегда возвращает текущее время в часовом поясе UTC, обеспечивая согласованность времени при работе с разными часовыми поясами.

Поведение этой функции соответствует поведению [функции utc_time](https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_utc-time) в MySQL.

## Синтаксис {#syntax}

```sql
UTC_TIME([<`precision`>])
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|-------------|
| `<precision>` | Точность возвращаемого значения времени задаётся целым числом в диапазоне [0, 6]. Допускаются только константы целочисленного типа. |

## Возвращаемое значение {#return-value}
Возвращает текущее время UTC.

Возвращает значение типа Time (формат: HH:mm:ss). При использовании результата в числовых операциях он преобразуется в [целочисленный формат](../../../../sql-manual/basic-element/sql-data-types/conversion/int-conversion#from-time) (время, прошедшее с 00:00:00, в микросекундах).

Если входное значение равно NULL или точность выходит за допустимый диапазон, возникает ошибка.

## Примеры {#examples}

```sql
-- Assume the current local time is UTC+8 2025-10-27 14:39:01
SELECT UTC_TIME(), UTC_TIME() + 1, UTC_TIME(6), UTC_TIME(6) + 1;
```
```text
+------------+----------------+-----------------+-----------------+
| UTC_TIME() | UTC_TIME() + 1 | UTC_TIME(6)     | UTC_TIME(6) + 1 |
+------------+----------------+-----------------+-----------------+
| 06:39:01   |    23941000001 | 06:39:01.934119 |     23941934120 |
+------------+----------------+-----------------+-----------------+
```

```sql
SELECT UTC_TIME(7);
-- ERROR 1105 (HY000): errCode = 2, detailMessage = scale must be between 0 and 6

SELECT UTC_TIME(NULL);
-- ERROR 1105 (HY000): errCode = 2, detailMessage = UTC_TIME argument cannot be NULL.
```
