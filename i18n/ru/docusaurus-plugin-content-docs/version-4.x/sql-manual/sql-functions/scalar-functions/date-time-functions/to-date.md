## Описание {#description}

Эта функция эквивалентна `CAST(<STRING> TO DATE)`.

Функция TO_DATE преобразует значения даты и времени в тип DATE (содержащий только год, месяц и день в формате YYYY-MM-DD). Функция автоматически игнорирует временную часть входного значения (часы, минуты, секунды, микросекунды) и извлекает для преобразования только дату.

## Синтаксис {#syntax}
```sql
TO_DATE(`<datetime_value>`)
```

## Параметры {#parameters}
| Параметр | Описание |
|-----------|-------------|
| `<datetime_value>` | Значение даты и времени типа DATETIME; поддерживается формат DATETIME. Подробнее о формате даты и времени см. в разделе [Преобразование даты и времени](../../../../sql-manual/basic-element/sql-data-types/conversion/datetime-conversion) |

## Возвращаемое значение {#return-value}

Возвращает значение типа DATE.

## Примеры {#examples}

```sql
-- Extract the date part from datetime
select to_date("2020-02-02 00:00:00");

+--------------------------------+
| to_date('2020-02-02 00:00:00') |
+--------------------------------+
| 2020-02-02                     |
+--------------------------------+

-- Input date, returns itself
select to_date("2020-02-02");
+-----------------------+
| to_date("2020-02-02") |
+-----------------------+
| 2020-02-02            |
+-----------------------+

-- Input NULL, returns NULL
SELECT TO_DATE(NULL) AS result;
+--------+
| result |
+--------+
| NULL   |
+--------+
```
