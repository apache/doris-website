## Описание {#description}

Функция DATEDIFF вычисляет разницу между двумя значениями даты или даты и времени с точностью до дня. Она возвращает количество дней, полученное при вычитании `expr2` из `expr1`. Функция учитывает только дату и игнорирует часы, минуты и секунды во временной части.

Поведение этой функции соответствует [функции datediff](https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_datediff) в MySQL.

## Синтаксис {#syntax}

```sql
DATEDIFF(<expr1>, <expr2>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<expr1>` | Уменьшаемая дата; поддерживаются типы datetime и date. Подробные сведения о форматах datetime и date см. в разделах [преобразование datetime](../../../../sql-manual/basic-element/sql-data-types/conversion/datetime-conversion) и [преобразование date](../../../../sql-manual/basic-element/sql-data-types/conversion/date-conversion) |
| `<expr2>` | Вычитаемая дата; поддерживаются типы date и datetime |

## Возвращаемое значение {#return-value}

Возвращает значение expr1 - expr2 с точностью до дня. Тип результата: INT.

Особые случаи:
- Если expr1 больше expr2, возвращается положительное число, в противном случае возвращается отрицательное число.
- Если любой из параметров равен NULL, возвращается NULL.
- Временная часть игнорируется.

## Примеры {#examples}

```sql
-- The two dates differ by 1 day (ignoring the time part)
select datediff(CAST('2007-12-31 23:59:59' AS DATETIME), CAST('2007-12-30' AS DATETIME));
+-----------------------------------------------------------------------------------+
| datediff(CAST('2007-12-31 23:59:59' AS DATETIME), CAST('2007-12-30' AS DATETIME)) |
+-----------------------------------------------------------------------------------+
|                                                                                 1 |
+-----------------------------------------------------------------------------------+

-- The first date is earlier than the second date, returning a negative number
select datediff(CAST('2010-11-30 23:59:59' AS DATETIME), CAST('2010-12-31' AS DATETIME));
+-----------------------------------------------------------------------------------+
| datediff(CAST('2010-11-30 23:59:59' AS DATETIME), CAST('2010-12-31' AS DATETIME)) |
+-----------------------------------------------------------------------------------+
|                                                                               -31 |
+-----------------------------------------------------------------------------------+

-- Any parameter is NULL
mysql> select datediff('2023-01-01', NULL);
+------------------------------+
| datediff('2023-01-01', NULL) |
+------------------------------+
|                         NULL |
+------------------------------+

-- If input datetime type, will ignore time part
select datediff('2023-01-02 13:00:00', '2023-01-01 12:00:00');
+--------------------------------------------------------+
| datediff('2023-01-02 13:00:00', '2023-01-01 12:00:00') |
+--------------------------------------------------------+
|                                                      1 |
+--------------------------------------------------------+

select datediff('2023-01-02 12:00:00', '2023-01-01 13:00:00');
+--------------------------------------------------------+
| datediff('2023-01-02 12:00:00', '2023-01-01 13:00:00') |
+--------------------------------------------------------+
|                                                      1 |
+--------------------------------------------------------+
1 row in set (0.01 sec)
```
