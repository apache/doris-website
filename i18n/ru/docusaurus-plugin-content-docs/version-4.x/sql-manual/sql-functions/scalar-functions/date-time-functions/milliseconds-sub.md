## Описание {#description}

Функция `MILLISECONDS_SUB` вычитает заданное количество миллисекунд из входного значения даты и времени и возвращает полученное новое значение даты и времени. Эта функция поддерживает обработку значений типа `DATETIME`.

## Синтаксис {#syntax}

```sql
MILLISECONDS_SUB(`<datetime>`, `<delta>`)
```

## Параметры {#parameters}

| Параметр     | Описание                                                                                      |
|--------------|-----------------------------------------------------------------------------------------------|
| `<datetime>` | Входное значение даты и времени типа `DATETIME`. Подробнее о форматах даты и времени см. в разделе [Преобразование даты и времени](../../../../sql-manual/basic-element/sql-data-types/conversion/datetime-conversion). |
| `<delta>`    | Количество миллисекунд, которое необходимо вычесть, типа `BIGINT`. 1 секунда = 1,000 миллисекунд = 1,000,000 микросекунд. |

## Возвращаемое значение {#return-value}

Возвращает значение типа `DATETIME`, представляющее результат вычитания заданного количества миллисекунд из исходного времени.

- Если `<delta>` отрицательно, функция работает так же, как при добавлении соответствующего количества миллисекунд к исходному времени.
- Если входное значение имеет тип `DATE` (содержит только год, месяц и день), время по умолчанию устанавливается в `00:00:00.000`.
- Если результат вычисления выходит за допустимый диапазон типа `DATETIME` (от `0000-01-01 00:00:00` до `9999-12-31 23:59:59.999999`), возникает исключение.
- Если какой-либо параметр равен `NULL`, функция возвращает `NULL`.

## Примеры {#examples}

```sql
-- Subtract 1 millisecond
SELECT MILLISECONDS_SUB('2023-09-08 16:02:08.435123', 1);
+---------------------------------------------------+
| MILLISECONDS_SUB('2023-09-08 16:02:08.435123', 1) |
+---------------------------------------------------+
| 2023-09-08 16:02:08.434123                        |
+---------------------------------------------------+

-- Negative delta (equivalent to addition)
SELECT MILLISECONDS_SUB('2023-05-01 10:00:00.200', -300);
+---------------------------------------------------+
| MILLISECONDS_SUB('2023-05-01 10:00:00.200', -300) |
+---------------------------------------------------+
| 2023-05-01 10:00:00.500000                        |
+---------------------------------------------------+

-- Input is of DATE type (default time is 00:00:00.000)
SELECT MILLISECONDS_SUB('2023-01-01', 1500);
+--------------------------------------+
| MILLISECONDS_SUB('2023-01-01', 1500) |
+--------------------------------------+
| 2022-12-31 23:59:58.500000           |
+--------------------------------------+

-- Calculation result exceeds the datetime range, throws an exception
SELECT MILLISECONDS_SUB('0000-01-01', 1500);
ERROR 1105 (HY000): errCode = 2, detailMessage = (10.16.10.3)[E-218]Operation millisecond_add of 0000-01-01 00:00:00, -1500 out of range

-- Any parameter is NULL, returns NULL
SELECT MILLISECONDS_SUB(NULL, 100), MILLISECONDS_SUB('2023-01-01', NULL) AS after_sub;
+------------------------------+----------------------------+
| milliseconds_sub(NULL, 100)  | after_sub                  |
+------------------------------+----------------------------+
| NULL                         | NULL                       |
+------------------------------+----------------------------+

```
