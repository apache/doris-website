# TIME {#time}

## Описание {#description}
Функция `TIME` извлекает компонент `time` из значения Datetime.

## Синтаксис {#syntax}

```sql
TIME(<datetime>)
```

## Параметры {#parameters}

| Параметр       | Описание              |
|----------------|-----------------------|
| `<datetime>`   | Значение даты и времени. |

## Возвращаемое значение {#return-value}
Возвращает значение типа `TIME`

## Пример {#example}

```sql
SELECT TIME('2025-1-1 12:12:12');
```

```text
mysql> 
+---------------------------+
| time('2025-1-1 12:12:12') |
+---------------------------+
| 12:12:12                  |
+---------------------------+
```
