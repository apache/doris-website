## Описание {#description}

Функция `MILLISECONDS_ADD` добавляет указанное количество миллисекунд к входному значению даты и времени и возвращает полученное новое значение даты и времени. Функция поддерживает обработку значений типа `DATETIME` с точностью до миллисекунд.

## Синтаксис {#syntax}

```sql
MILLISECONDS_ADD(`<datetime>`, `<delta>`)
```

## Параметры {#parameters}

| Параметр     | Описание                                                                                      |
|--------------|-----------------------------------------------------------------------------------------------|
| `<datetime>` | Входное значение даты и времени. Поддерживается тип `DATETIME`. Подробнее о форматах даты и времени см. в разделе [Преобразование даты и времени](../../../../sql-manual/basic-element/sql-data-types/conversion/datetime-conversion). |
| `<delta>`    | Количество добавляемых миллисекунд, тип — `BIGINT`. 1 секунда = 1,000 миллисекунд = 1,000,000 микросекунд. |

## Возвращаемое значение {#return-value}

Возвращает значение типа `DATETIME`, представляющее результат добавления указанного количества миллисекунд к исходному значению даты и времени.

- Если `<delta>` имеет отрицательное значение, функция вычитает соответствующее количество миллисекунд из исходного значения даты и времени (то есть `MILLISECONDS_ADD(basetime, -n)` эквивалентно `MILLISECONDS_SUB(basetime, n)`).
- Если входное значение имеет тип `DATE` (содержит только год, месяц и день), временная часть по умолчанию устанавливается в `00:00:00.000`.
- Если результат вычисления выходит за допустимый диапазон типа `DATETIME` (от `0000-01-01 00:00:00` до `9999-12-31 23:59:59.999999`), возникает исключение.
- Если любой из параметров равен `NULL`, функция возвращает `NULL`.

## Примеры {#examples}

```sql
-- Add one millisecond
SELECT MILLISECONDS_ADD('2023-09-08 16:02:08.435123', 1);

+---------------------------------------------------+
| MILLISECONDS_ADD('2023-09-08 16:02:08.435123', 1) |
+---------------------------------------------------+
| 2023-09-08 16:02:08.436123                        |
+---------------------------------------------------+

-- Negative milliseconds, subtracts the corresponding milliseconds from the datetime
SELECT MILLISECONDS_ADD('2023-05-01 10:00:00.800', -300);
+---------------------------------------------------+
| MILLISECONDS_ADD('2023-05-01 10:00:00.800', -300) |
+---------------------------------------------------+
| 2023-05-01 10:00:00.500000                        |
+---------------------------------------------------+

-- Input is of DATE type (default time is 00:00:00.000)
SELECT MILLISECONDS_ADD('2023-01-01', 1500);
+--------------------------------------+
| MILLISECONDS_ADD('2023-01-01', 1500) |
+--------------------------------------+
| 2023-01-01 00:00:01.500000           |
+--------------------------------------+

-- Calculation result exceeds the datetime range, throws an exception
SELECT MILLISECONDS_ADD('9999-12-31 23:59:59.999', 2000) AS after_add;
ERROR 1105 (HY000): errCode = 2, detailMessage = (10.16.10.3)[E-218]Operation milliseconds_add of 9999-12-31 23:59:59.999000, 2000 out of range

-- Any parameter is NULL, returns NULL
SELECT MILLISECONDS_ADD('2023-10-01 12:00:00.500', NULL) AS after_add;
+-----------+
| after_add |
+-----------+
| NULL      |
+-----------+

-- delta supports the full BIGINT range; values beyond INT max (2^31 - 1) still compute correctly
SELECT MILLISECONDS_ADD('2023-09-08 16:02:08.435', 2147483648) AS after_add;
+----------------------------+
| after_add                  |
+----------------------------+
| 2023-10-03 12:33:32.083000 |
+----------------------------+

```
