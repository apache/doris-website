## Описание {#description}
Функция UTC_DATE возвращает текущую дату в часовом поясе UTC. Локальный часовой пояс не влияет на эту функцию: она всегда возвращает текущую дату по UTC, обеспечивая согласованность дат при работе с разными часовыми поясами.

Поведение этой функции соответствует поведению [функции utc_date](https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_utc-date) в MySQL.

## Синтаксис {#syntax}

```sql
UTC_DATE()
```

## Возвращаемое значение {#return-value}
Возвращает текущую дату по UTC в виде значения типа DATE.

Возвращаемое значение имеет тип Date (формат: YYYY-MM-DD). При выполнении числовых операций над возвращаемым результатом выполняется преобразование типа, и значение возвращается в [целочисленном формате](../../../../sql-manual/basic-element/sql-data-types/conversion/int-conversion#from-date) (формат: YYYYMMDD).

## Примеры {#examples}

```sql
-- Assume the current local time is UTC+8 2025-10-27 10:55:35
SELECT UTC_DATE(), UTC_DATE() + 0;
```
```text
+------------+----------------+
| UTC_DATE() | UTC_DATE() + 0 |
+------------+----------------+
| 2025-10-27 |       20251027 |
+------------+----------------+
```
