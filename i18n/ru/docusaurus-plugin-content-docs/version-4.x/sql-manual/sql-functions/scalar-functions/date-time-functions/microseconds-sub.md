## Описание {#description}

Функция `MICROSECONDS_SUB` вычитает указанное количество микросекунд из входного значения даты и времени и возвращает полученное значение даты и времени. Функция поддерживает обработку значений типов `DATETIME` и `TIMESTAMPTZ` с точностью до микросекунд.

Поведение этой функции совпадает с поведением [функции date_sub](https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_date-sub) в MySQL при использовании MICROSECOND в качестве единицы измерения.

## Синтаксис {#syntax}

```sql
MICROSECONDS_SUB(`<datetime_like_type>`, `<delta>`)
```

## Параметры {#parameters}

| Параметр    | Описание                                                                                     |
|--------------|-------------------------------------------------------------------------------------------------|
| `<datetime_like_type>` | Входное значение даты и времени типа `DATETIME` или `TIMESTAMPTZ`. Подробнее о форматах см. в разделах [Преобразование timestamptz](../../../../sql-manual/basic-element/sql-data-types/conversion/timestamptz-conversion) и [Преобразование datetime](../../../../sql-manual/basic-element/sql-data-types/conversion/datetime-conversion). |
| `<delta>`    | Количество микросекунд для вычитания, тип `BIGINT`. 1 секунда = 1,000,000 микросекунд.       |

## Возвращаемое значение {#return-value}

Возвращает результат вычитания указанного количества микросекунд `<delta>` из исходного времени `<datetime_like_type>`. Тип возвращаемого значения совпадает с типом первого параметра.

- Если `<delta>` отрицательно, функция прибавляет соответствующее количество микросекунд к исходному времени (то есть `MICROSECONDS_SUB(basetime, -n)` эквивалентно `MICROSECONDS_ADD(basetime, n)`).
- Если результат вычисления выходит за допустимый диапазон типа `DATETIME` (от `0000-01-01 00:00:00` до `9999-12-31 23:59:59.999999`), возникает исключение.
- Если любой из параметров равен `NULL`, функция возвращает `NULL`.

## Примеры {#examples}

```sql
-- Subtract microseconds
SELECT NOW(3) AS current_time, MICROSECONDS_SUB(NOW(3), 100000) AS after_sub;

+-------------------------+----------------------------+
| current_time            | after_sub                  |
+-------------------------+----------------------------+
| 2025-01-16 11:52:22.296 | 2025-01-16 11:52:22.196000 |
+-------------------------+----------------------------+

-- Negative delta (equivalent to addition)
mysql> SELECT MICROSECONDS_SUB('2023-10-01 12:00:00.200000', -300000) AS after_sub;
+----------------------------+
| after_sub                  |
+----------------------------+
| 2023-10-01 12:00:00.500000 |
+----------------------------+

-- Any parameter is NULL, returns NULL
SELECT MICROSECONDS_SUB(NULL, 1000), MICROSECONDS_SUB('2023-01-01', NULL) AS after_sub;
+------------------------------+----------------------------+
| microseconds_sub(NULL, 1000) | after_sub                  |
+------------------------------+----------------------------+
| NULL                         | NULL                       |
+------------------------------+----------------------------+

-- Input type is DATE, time part is automatically set to 00:00:00.000000
SELECT MICROSECONDS_SUB('2023-10-01', -300000);
+-----------------------------------------+
| MICROSECONDS_SUB('2023-10-01', -300000) |
+-----------------------------------------+
| 2023-10-01 00:00:00.300000              |
+-----------------------------------------+

-- Example of TimeStampTz type, SET time_zone = '+08:00'
SELECT MICROSECONDS_SUB('2024-12-25 12:34:56.123+04:00', '765800');
+-------------------------------------------------------------+
| MICROSECONDS_SUB('2024-12-25 12:34:56.123+04:00', '765800') |
+-------------------------------------------------------------+
| 2024-12-25 16:34:55.357200+08:00                            |
+-------------------------------------------------------------+

-- Exceeds datetime range, throws an error
mysql> SELECT MICROSECONDS_SUB('0000-01-01 00:00:00.000000', 1000000) AS after_sub;
ERROR 1105 (HY000): errCode = 2, detailMessage = (10.16.10.3)[E-218]Operation microseconds_add of 0000-01-01 00:00:00, -1000000 
out of range

```
