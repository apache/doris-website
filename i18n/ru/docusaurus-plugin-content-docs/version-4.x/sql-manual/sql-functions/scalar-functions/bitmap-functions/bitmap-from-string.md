## Описание {#description}

Преобразует строку в BITMAP. Строка состоит из набора беззнаковых чисел типа bigint, разделённых запятыми. (Значения чисел находятся в диапазоне: 0 ~ 18446744073709551615)
Например, строка "0, 1, 2" будет преобразована в Bitmap, в котором установлены биты с номерами 0, 1 и 2. Если входное поле содержит недопустимое значение, возвращается NULL.

## Синтаксис {#syntax}

```sql
 BITMAP_FROM_STRING(<str>)
```

## Параметры {#parameters}

| Параметр | Описание                                                                                    |
|-----------|------------------------------------------------------------------------------------------------|
| `<str>`   | Строковое представление массива. Например, строка "0, 1, 2" будет преобразована в Bitmap с установленными битами 0, 1, 2 |  

## Возвращаемое значение {#return-value}

Возвращает BITMAP.
- Если входное поле содержит недопустимое значение, результатом будет NULL.

## Примеры {#examples}

```sql
select bitmap_to_string(bitmap_from_string("0, 1, 2")) bts;
```

```text
+-------+
| bts   |
+-------+
| 0,1,2 |
+-------+
```

```sql
select bitmap_to_string(bitmap_from_string("-1, 0, 1, 2")) bfs;
```

```text
+------+
| bfs  |
+------+
| NULL |
+------+
```

```sql
select bitmap_to_string(bitmap_from_string(NULL)) bfs;
```

```text
+------+
| bfs  |
+------+
| NULL |
+------+
```

```sql
select bitmap_to_string(bitmap_from_string("18446744073709551616, 1")) bfs;
```

```text
+------+
| bfs  |
+------+
| NULL |
+------+
```

```sql
select bitmap_to_string(bitmap_from_string("0, 1, 18446744073709551615")) bts;
```

```text
+--------------------------+
| bts                      |
+--------------------------+
| 0,1,18446744073709551615 |
+--------------------------+
```
