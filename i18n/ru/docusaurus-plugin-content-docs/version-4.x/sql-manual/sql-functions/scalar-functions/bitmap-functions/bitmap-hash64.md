## Описание {#description}

Вычисляет 64-битное хеш-значение входного значения любого типа и возвращает Bitmap, содержащий это хеш-значение.

## Синтаксис {#syntax}

```sql
BITMAP_HASH64(<expr>)
```

## Параметры {#parameters}

| Параметр | Описание           |
|-----------|-----------------------|
| `<expr>`  | Любое значение или выражение поля |

## Возвращаемое значение {#return-value}

Возвращает Bitmap, содержащий 64-битное хеш-значение параметра `<expr>`.
- Если значение параметра равно NULL, возвращает пустой Bitmap

## Примеры {#examples}

Чтобы вычислить 64-битное хеш-значение, можно использовать:

```sql
select bitmap_to_string(bitmap_hash64('hello'));
```

Результат:

```text
+------------------------------------------+
| bitmap_to_string(bitmap_hash64('hello')) |
+------------------------------------------+
| 15231136565543391023                     |
+------------------------------------------+
```

```sql
select bitmap_to_string(bitmap_hash64(NULL));
```

Результат:

```text
+---------------------------------------+
| bitmap_to_string(bitmap_hash64(NULL)) |
+---------------------------------------+
|                                       |
+---------------------------------------+
```
