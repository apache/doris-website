# Обзор функций для работы с URL {#url-functions-overview}

Функции для работы с URL извлекают такие компоненты, как домены, протоколы и параметры запроса, а также кодируют и декодируют URL-строки. Синтаксис, требования к входным данным и примеры приведены на страницах функций, ссылки на которые указаны ниже.

| Функция | Назначение |
| --- | --- |
| [DOMAIN](../string-functions/domain.md) | Извлекает домен из URL. |
| [DOMAIN_WITHOUT_WWW](../string-functions/domain-without-www.md) | Извлекает домен и удаляет начальное `www.`. |
| [TOP_LEVEL_DOMAIN](../string-functions/top-level-domain.md) | Извлекает домен верхнего уровня. |
| [FIRST_SIGNIFICANT_SUBDOMAIN](../string-functions/first-significant-subdomain.md) | Извлекает первый значимый поддомен. |
| [CUT_TO_FIRST_SIGNIFICANT_SUBDOMAIN](../string-functions/cut-to-first-significant-subdomain.md) | Сохраняет часть домена до первого значимого поддомена включительно. |
| [PROTOCOL](../string-functions/protocol.md) | Извлекает протокол из URL. |
| [PARSE_URL](../string-functions/parse-url.md) | Извлекает указанный компонент URL. |
| [EXTRACT_URL_PARAMETER](../string-functions/extract-url-parameter.md) | Извлекает параметр запроса URL с указанным именем. |
| [URL_ENCODE](../string-functions/url-encode.md) | Кодирует строку для использования в URL. |
| [URL_DECODE](../string-functions/url-decode.md) | Декодирует строку, закодированную для URL. |
