## Назначение {#function}

`ARRAY_UNION` возвращает объединение нескольких массивов, то есть объединяет все элементы массивов, удаляет дубликаты и возвращает новый массив.

## Синтаксис {#syntax}

```SQL
ARRAY_UNION(arr1, arr2, ..., arrN)
```

## Параметры {#parameters}

- `arr1, arr2, ..., arrN`: произвольное количество входных массивов типа `ARRAY<T>`.
    - Тип элементов `T` должен быть одинаковым для всех массивов либо допускать неявное приведение к общему типу.
    - Тип элементов `T` может быть числовым, строковым, типом даты/времени или IP.
  
## Возвращаемое значение {#return-value}

- Возвращает новый массив типа `ARRAY<T>`, содержащий все уникальные элементы входных массивов (без дубликатов).
    - Если хотя бы один входной параметр равен `NULL`, возвращает `NULL` (см. пример).

## Примечания по использованию {#usage-notes}

1. Удаление дубликатов выполняется на основе сравнения на равенство (оператор `=`).
2. В результирующем массиве сохраняется только одно значение `NULL` (см. пример).
3. Если сам входной массив содержит несколько одинаковых элементов, сохраняется только один из них (см. пример).
4. Порядок элементов в результирующем массиве не гарантируется.

## Примеры {#examples}

1. Простой пример

    ```SQL
    SELECT ARRAY_UNION(ARRAY('hello', 'world'), ARRAY('hello', 'world')); 
    +---------------------------------------------------------------+
    | ARRAY_UNION(ARRAY('hello', 'world'), ARRAY('hello', 'world')) |
    +---------------------------------------------------------------+
    | ["world", "hello"]                                            |
    +---------------------------------------------------------------+

    SELECT ARRAY_UNION(ARRAY(1, 2, 3), ARRAY(3, 5, 6));
    +---------------------------------------------+
    | ARRAY_UNION(ARRAY(1, 2, 3), ARRAY(3, 5, 6)) |
    +---------------------------------------------+
    | [1, 5, 2, 6, 3]                             |
    +---------------------------------------------+
    ```

2. Если хотя бы один входной массив равен `NULL`, возвращается `NULL`
   
    ```SQL
    SELECT ARRAY_UNION(ARRAY('hello', 'world'), ARRAY('hello', 'world'), NULL); 
    +---------------------------------------------------------------------+
    | ARRAY_UNION(ARRAY('hello', 'world'), ARRAY('hello', 'world'), NULL) |
    +---------------------------------------------------------------------+
    | NULL                                                                |
    +---------------------------------------------------------------------+
    ```

3. Если входные массивы содержат `NULL`, результирующий массив будет содержать только одно значение `NULL`

    ```SQL
    SELECT ARRAY_UNION(ARRAY('hello', 'world'), ARRAY('hello', NULL)); 
    +---------------------------------------------------------------------+
    | ARRAY_UNION(ARRAY('hello', 'world', 'hello'), ARRAY('hello', NULL)) |
    +---------------------------------------------------------------------+
    | [null, "world", "hello"]                                            |
    +---------------------------------------------------------------------+

    SELECT ARRAY_UNION(ARRAY(NULL, 'world'), ARRAY('hello', NULL)); 
    +---------------------------------------------------------+
    | ARRAY_UNION(ARRAY(NULL, 'world'), ARRAY('hello', NULL)) |
    +---------------------------------------------------------+
    | [null, "world", "hello"]                                |
    +---------------------------------------------------------+
    ```

4. Если массив содержит повторяющиеся элементы, возвращается только один из них

    ```SQL
    SELECT ARRAY_UNION(ARRAY('hello', 'world', 'hello'), ARRAY('hello', NULL)); 
    +------------------------------------------------------------+
    | ARRAY_UNION(ARRAY('hello', 'world'), ARRAY('hello', NULL)) |
    +------------------------------------------------------------+
    | [null, "world", "hello"]                                   |
    +------------------------------------------------------------+
    ```
