## array_pushback {#array_pushback}

<version since="2.0.0">

</version>

## Описание {#description}

Добавляет элемент в конец массива. Функция возвращает новый массив, содержащий все элементы исходного массива и добавленный элемент.

## Псевдоним {#alias}

- array_append

## Синтаксис {#syntax}

```sql
array_pushback(ARRAY<T> arr, T element)
```

### Параметры {#parameters}

- `arr`：тип ARRAY<T>, массив, в который нужно добавить элемент
- `element`：тип T, элемент, который нужно добавить в конец массива

**Поддерживаемые типы T:**
- Числовые типы: TINYINT, SMALLINT, INT, BIGINT, LARGEINT, FLOAT, DOUBLE, DECIMAL
- Строковые типы: CHAR, VARCHAR, STRING
- Типы даты и времени: DATE, DATETIME, DATEV2, DATETIMEV2
- Логический тип: BOOLEAN
- Типы IP: IPV4, IPV6
- Сложные типы: ARRAY, MAP, STRUCT

### Возвращаемое значение {#return-value}

Тип результата: ARRAY<T>

Описание возвращаемого значения:
- Возвращает новый массив, содержащий все элементы исходного массива и добавленный элемент
- NULL: если входной массив равен NULL

Примечания по использованию:
- Функция добавляет указанный элемент в конец массива
- В пустые массивы также можно добавлять элементы; тип нового элемента должен быть совместим с типом элементов массива
- Элементы массива со значением null обрабатываются обычным образом

**Примеры запросов:**

Добавление элемента в конец массива строк:
```sql
SELECT array_pushback(['apple', 'banana', 'cherry'], 'date');
+----------------------------------------------------+
| array_pushback(['apple', 'banana', 'cherry'], 'date') |
+----------------------------------------------------+
| ["apple", "banana", "cherry", "date"]              |
+----------------------------------------------------+
```

Добавление элемента null в конец массива, содержащего значения null:
```sql
SELECT array_pushback([1, null, 3], null);
+------------------------------------+
| array_pushback([1, null, 3], null) |
+------------------------------------+
| [1, null, 3, null]                 |
+------------------------------------+
```

Добавление элемента в конец пустого массива:
```sql
SELECT array_pushback([], 42);
+--------------------------+
| array_pushback([], 42)   |
+--------------------------+
| [42]                     |
+--------------------------+
```

Добавление элемента в конец массива чисел с плавающей точкой:
```sql
SELECT array_pushback([1.1, 2.2, 3.3], 4.4);
+------------------------------------------+
| array_pushback([1.1, 2.2, 3.3], 4.4)    |
+------------------------------------------+
| [1.1, 2.2, 3.3, 4.4]                    |
+------------------------------------------+
```

Для массивов со значением NULL возвращается NULL:
```sql
SELECT array_pushback(NULL, 1);
+--------------------------+
| array_pushback(NULL, 1)  |
+--------------------------+
| NULL                     |
+--------------------------+
```

Добавление элемента в конец массива IP-адресов:
```sql
SELECT array_pushback(CAST(['192.168.1.1', '192.168.1.2'] AS ARRAY<IPV4>), CAST('192.168.1.3' AS IPV4));
+----------------------------------------------------------------------------------+
| array_pushback(CAST(['192.168.1.1', '192.168.1.2'] AS ARRAY<IPV4>), CAST('192.168.1.3' AS IPV4)) |
+----------------------------------------------------------------------------------+
| ["192.168.1.1", "192.168.1.2", "192.168.1.3"]                                   |
+----------------------------------------------------------------------------------+
```

Добавление элемента в конец вложенного массива:
```sql
SELECT array_pushback([[1,2], [3,4]], [5,6]);
+------------------------------------------+
| array_pushback([[1,2], [3,4]], [5,6])   |
+------------------------------------------+
| [[1, 2], [3, 4], [5, 6]]                |
+------------------------------------------+
```

Добавление элемента в конец массива элементов MAP:
```sql
SELECT array_pushback([{'a':1}, {'b':2}], {'c':3});
+----------------------------------------------+
| array_pushback([{'a':1}, {'b':2}], {'c':3}) |
+----------------------------------------------+
| [{"a":1}, {"b":2}, {"c":3}]                 |
+----------------------------------------------+
```

Добавление элемента в конец массива элементов STRUCT:
```sql
SELECT array_pushback(array(named_struct('name','Alice','age',20), named_struct('name','Bob','age',30)), named_struct('name','Charlie','age',40));
+-------------------------------------------------------------------------------------------------------------------------------------------+
| array_pushback(array(named_struct('name','Alice','age',20), named_struct('name','Bob','age',30)), named_struct('name','Charlie','age',40)) |
+-------------------------------------------------------------------------------------------------------------------------------------------+
| [{"name":"Alice", "age":20}, {"name":"Bob", "age":30}, {"name":"Charlie", "age":40}]                                                    |
+-------------------------------------------------------------------------------------------------------------------------------------------+
```

Ошибка при неверном количестве параметров:
```sql
SELECT array_pushback([1,2,3]);
ERROR 1105 (HY000): errCode = 2, detailMessage: Can not found function 'array_pushback' which has 1 arity. Candidate functions are: [array_pushback(Expression, Expression)]
```

Ошибка при передаче значения, не являющегося массивом:
```sql
SELECT array_pushback('not_an_array', 1);
ERROR 1105 (HY000): errCode = 2, detailMessage: Can not find the compatibility function signature: array_pushback(VARCHAR(12), TINYINT)
```

### Ключевые слова {#keywords}

ARRAY, PUSHBACK, ARRAY_PUSHBACK
