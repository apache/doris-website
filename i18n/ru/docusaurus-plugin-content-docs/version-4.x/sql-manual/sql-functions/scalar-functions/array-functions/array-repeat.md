## Функция {#function}

`ARRAY_REPEAT` используется для создания массива заданной длины, все элементы которого имеют указанное значение.

## Синтаксис {#syntax}

```SQL
ARRAY_REPEAT(element, count)
```

## Параметры {#parameters}

- `element`: Любой тип данных, поддерживаемый в `ARRAY`.

- `count`: Целочисленный тип, задаёт длину возвращаемого массива.


## Возвращаемое значение {#return-value}

- Возвращает массив типа `ARRAY<T>`, где `T` обозначает тип `element`.
    - Массив содержит `count` копий одного и того же `element`.

## Примечания по использованию {#usage-notes}

- При `count = 0` или `NULL` возвращается пустой массив.
- Если `element` имеет значение `NULL`, все элементы массива равны `NULL`.
- Эта функция выполняет ту же задачу, что и `ARRAY_WITH_CONSTANT`, но порядок параметров обратный.

## Примеры {#examples}

1. Простой пример

    ```SQL
    SELECT ARRAY_REPEAT('hello', 3);
    +---------------------------------+
    | ARRAY_REPEAT('hello', 3) |
    +---------------------------------+
    | ["hello", "hello", "hello"]     |
    +---------------------------------+
    ```

2. Особые случаи
   
    ```SQL
    SELECT ARRAY_REPEAT('hello', 0);
    +---------------------------------+
    | ARRAY_REPEAT('hello', 0) |
    +---------------------------------+
    | []                              |
    +---------------------------------+

    SELECT ARRAY_REPEAT('hello', NULL);
    +------------------------------------+
    | ARRAY_REPEAT('hello', NULL) |
    +------------------------------------+
    | []                                 |
    +------------------------------------+

    SELECT ARRAY_REPEAT(NULL, 2);
    +------------------------------+
    | ARRAY_REPEAT(NULL, 2) |
    +------------------------------+
    | [null, null]                 |
    +------------------------------+

    SELECT ARRAY_REPEAT(NULL, NULL);
    +---------------------------------+
    | ARRAY_REPEAT(NULL, NULL) |
    +---------------------------------+
    | []                              |
    +---------------------------------+

    -- Returns error: INVALID_ARGUMENT
    SELECT ARRAY_REPEAT('hello', -1);
    ```
