## array_pushfront {#array_pushfront}

<version since="2.0.0">

</version>

## Описание {#description}

Добавляет элемент в начало массива. Функция возвращает новый массив, содержащий добавленный элемент и все элементы исходного массива.

## Синтаксис {#syntax}

```sql
array_pushfront(ARRAY<T> arr, T element)
```

### Параметры {#parameters}

- `arr`：тип ARRAY<T>, массив, в который добавляется элемент
- `element`：тип T, элемент, добавляемый в начало массива

**Поддерживаемые типы T:**
- Числовые типы: TINYINT, SMALLINT, INT, BIGINT, LARGEINT, FLOAT, DOUBLE, DECIMAL
- Строковые типы: CHAR, VARCHAR, STRING
- Типы даты и времени: DATE, DATETIME, DATEV2, DATETIMEV2
- Логический тип: BOOLEAN
- Типы IP: IPV4, IPV6
- Сложные типы: ARRAY, MAP, STRUCT

### Возвращаемое значение {#return-value}

Тип возвращаемого значения: ARRAY<T>

Описание возвращаемого значения:
- Возвращает новый массив, содержащий добавленный элемент и все элементы исходного массива
- NULL: если входной массив имеет значение NULL

Примечания по использованию:
- Функция добавляет указанный элемент в начало массива
- В пустые массивы также можно добавлять элементы; тип нового элемента должен быть совместим с типом элементов массива
- Значения null в элементах массива: элементы со значением null обрабатываются обычным образом

**Примеры запросов:**

Добавление элемента в начало массива строк:
```sql
SELECT array_pushfront(['banana', 'cherry', 'date'], 'apple');
+--------------------------------------------------------+
| array_pushfront(['banana', 'cherry', 'date'], 'apple') |
+--------------------------------------------------------+
| ["apple", "banana", "cherry", "date"]                  |
+--------------------------------------------------------+
```

Добавление элемента null в начало массива, содержащего значения null:
```sql
SELECT array_pushfront([1, null, 3], null);
+-------------------------------------+
| array_pushfront([1, null, 3], null) |
+-------------------------------------+
| [null, 1, null, 3]                  |
+-------------------------------------+
```

Добавление элемента в начало пустого массива:
```sql
SELECT array_pushfront([], 42);
+--------------------------+
| array_pushfront([], 42)  |
+--------------------------+
| [42]                     |
+--------------------------+
```

Для массивов со значением NULL возвращается NULL:
```sql
SELECT array_pushfront(NULL, 1);
+---------------------------+
| array_pushfront(NULL, 1)  |
+---------------------------+
| NULL                      |
+---------------------------+
```

Добавление элемента в начало массива чисел с плавающей точкой:
```sql
SELECT array_pushfront([2.2, 3.3, 4.4], 1.1);
+------------------------------------------+
| array_pushfront([2.2, 3.3, 4.4], 1.1)   |
+------------------------------------------+
| [1.1, 2.2, 3.3, 4.4]                    |
+------------------------------------------+
```

Добавление элемента в начало массива IP-адресов:
```sql
SELECT array_pushfront(CAST(['192.168.1.2', '192.168.1.3'] AS ARRAY<IPV4>), CAST('192.168.1.1' AS IPV4));
+----------------------------------------------------------------------------------+
| array_pushfront(CAST(['192.168.1.2', '192.168.1.3'] AS ARRAY<IPV4>), CAST('192.168.1.1' AS IPV4)) |
+----------------------------------------------------------------------------------+
| ["192.168.1.1", "192.168.1.2", "192.168.1.3"]                                   |
+----------------------------------------------------------------------------------+
```

Добавление элемента в начало вложенного массива:
```sql
SELECT array_pushfront([[3,4], [5,6]], [1,2]);
+------------------------------------------+
| array_pushfront([[3,4], [5,6]], [1,2])  |
+------------------------------------------+
| [[1, 2], [3, 4], [5, 6]]                |
+------------------------------------------+
```

Добавление элемента в начало массива MAP:
```sql
SELECT array_pushfront([{'b':2}, {'c':3}], {'a':1});
+----------------------------------------------+
| array_pushfront([{'b':2}, {'c':3}], {'a':1}) |
+----------------------------------------------+
| [{"a":1}, {"b":2}, {"c":3}]                 |
+----------------------------------------------+
```

Добавление элемента в начало массива STRUCT:
```sql
SELECT array_pushfront(array(named_struct('name','Bob','age',30), named_struct('name','Charlie','age',40)), named_struct('name','Alice','age',20));
+-------------------------------------------------------------------------------------------------------------------------------------------+
| array_pushfront(array(named_struct('name','Bob','age',30), named_struct('name','Charlie','age',40)), named_struct('name','Alice','age',20)) |
+-------------------------------------------------------------------------------------------------------------------------------------------+
| [{"name":"Alice", "age":20}, {"name":"Bob", "age":30}, {"name":"Charlie", "age":40}]                                                    |
+-------------------------------------------------------------------------------------------------------------------------------------------+
```

Ошибка при неверном количестве параметров:
```sql
SELECT array_pushfront([1,2,3]);
ERROR 1105 (HY000): errCode = 2, detailMessage: Can not found function 'array_pushfront' which has 1 arity. Candidate functions are: [array_pushfront(Expression, Expression)]
```

Ошибка при передаче значения, не являющегося массивом:
```sql
SELECT array_pushfront('not_an_array', 1);
ERROR 1105 (HY000): errCode = 2, detailMessage: Can not find the compatibility function signature: array_pushfront(VARCHAR(12), TINYINT)
```

### Ключевые слова {#keywords}

ARRAY, PUSHFRONT, ARRAY_PUSHFRONT
