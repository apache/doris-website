## Назначение {#function}

Сортирует элементы массива по убыванию.

## Синтаксис {#syntax}

- `ARRAY_REVERSE_SORT(arr)`

## Параметры {#parameters}

- `arr`: `ARRAY<T>`, где `T` может быть числовым, логическим, строковым типом, типом даты и времени, IP и т. д. Поддерживаются многомерные массивы, однако все элементы массива (независимо от глубины вложенности) должны иметь один из поддерживаемых типов.

## Возвращаемое значение {#return-value}

- Возвращает `ARRAY<T>` того же типа, что и входной массив.
- Элементы `NULL` помещаются в конец возвращаемого массива.

## Примечания по использованию {#usage-notes}

- Если на вход подан `NULL`, возвращает `NULL`; если на вход подан пустой массив `[]`, возвращает пустой массив.
- `ARRAY_REVERSE_SORT` сортирует по убыванию, а `ARRAY_SORT` сортирует по возрастанию.

## Примеры {#examples}

- Базовый пример: элементы `NULL` помещаются в конец возвращаемого массива
  - `ARRAY_REVERSE_SORT([1,2,3,null])` -> `[3,2,1,null]`

- Если на вход подан `NULL`, возвращает `NULL`; если на вход подан пустой массив `[]`, возвращает пустой массив.
  - `ARRAY_REVERSE_SORT(NULL)` -> `NULL`
  - `ARRAY_REVERSE_SORT([])` -> `[]`

- Сортировка многомерного массива
  - `ARRAY_REVERSE_SORT([[3, 4], [5, 6]])` -> `[[5, 6], [3, 4]]`
