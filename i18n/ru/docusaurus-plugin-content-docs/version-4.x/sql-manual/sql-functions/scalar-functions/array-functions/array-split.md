## Назначение {#function}

Разбивает входной массив на несколько подмассивов в соответствии с заданными логическими флагами.

- Правило разбиения (слева направо): для `arr=[a1,a2,...,an]` и `flags=[f1,f2,...,fn]` в каждой позиции, где `fi==true`, выполняется разбиение между `ai` и `a(i-1)`.
  - Например, для `arr=[3, 4, 5]` и `flags=[false, true, false]` второй флаг имеет значение true, поэтому разбиение выполняется между первым и вторым элементами. В результате получаются два подмассива: `[3]` и `[4,5]`.

## Синтаксис {#syntax}

- `ARRAY_SPLIT(arr, flags)`
- `ARRAY_SPLIT(lambda, arr0, ...)`
- `ARRAY_SPLIT(lambda, arr0, ...)` эквивалентно `ARRAY_SPLIT(arr0, ARRAY_MAP(lambda, arr0, ...))`

## Параметры {#parameters}

- `arr`: `ARRAY<T>`.
- `flags`: `ARRAY<BOOLEAN>`, длина которого должна совпадать с длиной `arr` в каждой строке. `true` означает разбиение между текущей позицией и следующим элементом.
- `arr0, ...`: один или несколько массивов `ARRAY<T>`.
- `lambda`: выражение `lambda`, применяемое к `arr0, ...` для получения `flags`, которые затем используются для разбиения.

## Возвращаемое значение {#return-value}

- Возвращает `ARRAY<ARRAY<T>>`. Внутренние массивы содержат те же элементы, что и `arr`.
- Если количество элементов в `arr` и `flags` не совпадает, возникает ошибка.

## Примечания по использованию {#usage-notes}

- Если в какой-либо позиции `flags` находится `NULL`, разбиение в этой позиции не выполняется (эквивалентно `false`).
- Правило разбиения для `ARRAY_SPLIT`: в каждой позиции, где `fi==true`, выполняется разбиение между `ai` и `a(i-1)`.
- Правило разбиения для `ARRAY_REVERSE_SPLIT`: в каждой позиции, где `fi==true`, выполняется разбиение между `ai` и `a(i+1)`.

## Примеры {#examples}

- Базовое разбиение: в каждой позиции со значением `true` разбиение выполняется между текущим элементом и его левым соседом.
  - `ARRAY_SPLIT([1,2,3,4,5], [false,true,false,true,false])` -> `[[1], [2, 3], [4, 5]]`
  - `ARRAY_SPLIT(['a','b','c'], [false,false,false])` -> `[['a','b','c']]`

- При наличии `NULL` в `flags`: `NULL` обрабатывается так же, как `false` (без разбиения).
  - `ARRAY_SPLIT([1,NULL,3], [false,null,false])` -> `[[1, NULL, 3]]`

- `lambda= x -> x-1` при применении к `arr0=[1, 2, 3]` формирует `flags=[0,1,2]`, что эквивалентно `flags=[false,true,true]`
  - `ARRAY_SPLIT(x->x-1, [1, 2, 3])` эквивалентно `ARRAY_SPLIT([1, 2, 3], [false,true,true])` -> `[[1], [2], [3]]`

- `lambda= (x,y) -> x-y` при применении к `arr0=[1, 2, 3]` и `arr1=[0,1,2]` формирует `flags=[true,true,true]`
  - `ARRAY_SPLIT((x,y) -> x-y, [1, 2, 3], [0, 1, 2])` эквивалентно `ARRAY_SPLIT([1, 2, 3], [true,true,true])` -> `[[1], [2], [3]]`
