### Функция {#function}

Функция `ARRAY_SUM` вычисляет сумму всех числовых элементов массива.

## Синтаксис {#syntax}

```SQL
ARRAY_SUM(ARRAY<T>)
```

## Параметры {#parameters}

`ARRAY<T>`: массив, содержащий элементы **числового типа**.

## Возвращаемое значение {#return-value}

- Возвращает сумму всех элементов массива, отличных от `NULL`.

    - Если все элементы равны `NULL`, возвращает `NULL`.

## Примечания по использованию {#usage-notes}

1. Для суммирования элементов используется оператор `+`.

2. Элементы со значением `NULL` автоматически игнорируются.

3. Если массив содержит элементы нечислового типа (например, строки), возникает ошибка во время выполнения.

## Примеры {#examples}

1. Простой пример

    ```SQL
    SELECT ARRAY_SUM([1, 2, 3, 4]);
    +-------------------------+
    | ARRAY_SUM([1, 2, 3, 4]) |
    +-------------------------+
    |                      10 |
    +-------------------------+
    ```

2. Обработка значений `NULL` в массивах

    ```SQL
    SELECT ARRAY_SUM([1, NULL, 3]); 
    +-------------------------+
    | ARRAY_SUM([1, NULL, 3]) |
    +-------------------------+
    |                       4 |
    +-------------------------+

    SELECT ARRAY_SUM(NULL);
    +-----------------+
    | ARRAY_SUM(NULL) |
    +-----------------+
    |            NULL |
    +-----------------+

    SELECT ARRAY_SUM([NULL, NULL]); 
    +-------------------------+
    | ARRAY_SUM([NULL, NULL]) |
    +-------------------------+
    |                    NULL |
    +-------------------------+
    ```
