## array_enumerate {#array_enumerate}

<version since="2.0.0">

</version>

## Описание {#description}

Возвращает порядковый номер (начиная с 1) каждого элемента массива. Функция формирует соответствующий порядковый номер для каждого элемента массива.

## Синтаксис {#syntax}

```sql
array_enumerate(ARRAY<T> arr)
```

### Параметры {#parameters}

- `arr`：массив типа ARRAY<T>, для элементов которого нужно сформировать порядковые номера. Поддерживаются имена столбцов и константные значения.

**Поддерживаемые типы T:**
- Числовые типы: TINYINT, SMALLINT, INT, BIGINT, LARGEINT, FLOAT, DOUBLE, DECIMAL
- Строковые типы: CHAR, VARCHAR, STRING
- Типы даты и времени: DATE, DATETIME, DATEV2, DATETIMEV2
- Логический тип: BOOLEAN
- Типы IP: IPV4, IPV6
- Сложные типы: ARRAY, MAP, STRUCT

### Возвращаемое значение {#return-value}

Тип возвращаемого значения: ARRAY<BIGINT>

Описание возвращаемого значения:
- Возвращает новый массив той же длины, что и входной массив, где на каждой позиции находится порядковый номер (начиная с 1) соответствующего элемента исходного массива
- NULL: если входной массив равен NULL

Примечания по использованию:
- Функция формирует порядковые номера для каждого элемента массива, начиная с 1 и последовательно увеличивая их
- Для пустых массивов возвращаются пустые массивы, для массивов со значением NULL возвращается NULL
- Элементы массива со значением null также получают соответствующие порядковые номера

### Примеры {#examples}

**Примеры запросов:**

Формирование порядковых номеров для элементов массива:
```sql
SELECT array_enumerate([1, 2, 1, 4, 5]);
+----------------------------------+
| array_enumerate([1, 2, 1, 4, 5]) |
+----------------------------------+
| [1, 2, 3, 4, 5]                  |
+----------------------------------+
```

Для пустого массива возвращается пустой массив:
```sql
SELECT array_enumerate([]);
+----------------------+
| array_enumerate([])  |
+----------------------+
| []                   |
+----------------------+
```

Массив со значениями null: элементы со значением null также получают порядковые номера:
```sql
SELECT array_enumerate([1, null, 3, null, 5]);
+--------------------------------------------+
| array_enumerate([1, null, 3, null, 5])     |
+--------------------------------------------+
| [1, 2, 3, 4, 5]                            |
+--------------------------------------------+
```

Примеры со сложными типами:

Типы вложенных массивов:
```sql
SELECT array_enumerate([[1,2],[3,4],[5,6]]);
+----------------------------------------+
| array_enumerate([[1,2],[3,4],[5,6]])   |
+----------------------------------------+
| [1, 2, 3]                              |
+----------------------------------------+
```

Типы Map:
```sql
SELECT array_enumerate([{'k':1},{'k':2},{'k':3}]);
+----------------------------------------------+
| array_enumerate([{'k':1},{'k':2},{'k':3}])   |
+----------------------------------------------+
| [1, 2, 3]                                    |
+----------------------------------------------+
```

Типы Struct:
```sql
SELECT array_enumerate(array(named_struct('name','Alice','age',20),named_struct('name','Bob','age',30)));
+----------------------------------------------------------------------------------------+
| array_enumerate(array(named_struct('name','Alice','age',20),named_struct('name','Bob','age',30))) |
+----------------------------------------------------------------------------------------+
| [1, 2]                                                                                  |
+----------------------------------------------------------------------------------------+
```

Ошибка при неверном количестве параметров:
```sql
SELECT array_enumerate([1,2,3], [4,5,6]);
ERROR 1105 (HY000): errCode = 2, detailMessage = Can not found function 'array_enumerate' which has 2 arity. Candidate functions are: [array_enumerate(Expression)]
```

Ошибка при передаче значения, не являющегося массивом:
```sql
SELECT array_enumerate('not_an_array');
ERROR 1105 (HY000): errCode = 2, detailMessage = Can not find the compatibility function signature: array_enumerate(VARCHAR(12))
```
