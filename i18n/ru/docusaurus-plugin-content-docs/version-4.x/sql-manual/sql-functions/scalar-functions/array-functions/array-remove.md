## Назначение {#function}

Удаляет из массива все элементы, равные заданному значению, сохраняя относительный порядок оставшихся элементов.

## Синтаксис {#syntax}

- `ARRAY_REMOVE(arr, target)`

## Параметры {#parameters}

- `arr`: `ARRAY<T>`, поддерживает числа, типы boolean, string, datetime, IP и т. д.
- `target`: значение того же типа, что и элементы массива, используемое для поиска элементов, которые нужно удалить.

## Возвращаемое значение {#return-value}

- Возвращает `ARRAY<T>` того же типа, что и входной массив.
- Если `arr` равен `NULL`, возвращается `NULL`.

## Примечания по использованию {#usage-notes}

- Правило сопоставления: удаляются только элементы, значение которых равно `target`. `NULL` считается равным `NULL`.

## Примеры {#examples}

- Базовый пример: после удаления оставшиеся элементы сохраняют исходный относительный порядок.
  - `ARRAY_REMOVE([1,2,3], 1)` -> `[2,3]`
  - `ARRAY_REMOVE([1,2,3,null], 1)` -> `[2,3,null]`

- Если `target` равен `NULL`, удаляются значения `NULL` из `arr`.
  - `ARRAY_REMOVE(['a','b','c',NULL], NULL)` -> `NULL`

- Если `arr` равен `NULL`, возвращается `NULL`
  - `ARRAY_REMOVE(NULL, 2)` -> `NULL`

- Совпадений нет
  - `ARRAY_REMOVE([1,2,3], 258)` -> `[1,2,3]`
