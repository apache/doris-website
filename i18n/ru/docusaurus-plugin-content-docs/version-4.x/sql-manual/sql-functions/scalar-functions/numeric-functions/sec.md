## Описание {#description}

Возвращает секанс x, где x задан в радианах. Поддерживаются только входные и выходные значения типа double. Для входного значения null возвращается null.

## Синтаксис {#syntax}

```sql
SEC(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<x>` | Значение, для которого вычисляется секанс |

## Возвращаемое значение {#return-value}

Возвращает значение типа Double, представляющее секанс x.

## Особые случаи {#special-cases}
- Если `x` имеет значение NaN, возвращается NaN
- Если `x` равен положительной или отрицательной бесконечности, возвращается NaN
- Если `x` имеет значение NULL, возвращается NULL

## Пример {#example}

```sql
select sec(1),sec(2),sec(1000);
```

```text
+--------------------+--------------------+--------------------+
| sec(1)             | sec(2)             | sec(1000)          |
+--------------------+--------------------+--------------------+
| 1.8508157176809255 | -2.402997961722381 | 1.7781600385912715 |
+--------------------+--------------------+--------------------+
```

Входное значение null.

```sql
select sec(null);
```

```text
+--------------------+
| sec(null)          |
+--------------------+
|      NULL          |
+--------------------+
```

```sql
select sec(cast('nan' as double));
```

```text
+---------------------------+
| sec(cast('nan' AS DOUBLE))|
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select sec(cast('inf' as double));
```

```text
+---------------------------+
| sec(cast('inf' AS DOUBLE))|
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select sec(cast('-inf' as double));
```

```text
+----------------------------+
| sec(cast('-inf' AS DOUBLE))|
+----------------------------+
| NaN                        |
+----------------------------+
```
