## Описание {#description}

Возвращает арктангенс отношения 'y' / 'x'.

## Синтаксис {#syntax}

```sql
ATAN2(<y>, <x>)
```

## Параметры {#parameters}

| Параметр | Описание |  
| -- | -- |  
| `<x>` | Значение, представляющее горизонтальное расстояние (координату) от начала координат (0,0) вдоль оси x. |  
| `<y>` | Значение, представляющее вертикальное расстояние (координату) от начала координат (0,0) вдоль оси y. |  

## Возвращаемое значение {#return-value}

Значение atan2 для отношения параметров `y` / `x`. 

## Особые случаи {#special-cases}
- Если `y` или `x` имеет значение NaN, возвращается NaN
- Если `x > 0` и `y = ±0.0`, возвращается ±0 (знак совпадает со знаком `y`)
- Если `x = 0.0` (+0.0 или -0.0) и `y > 0`, возвращается π/2 (приблизительно 1.570796326794897)
- Если `x = 0.0` (+0.0 или -0.0) и `y < 0`, возвращается -π/2 (приблизительно -1.570796326794897)
- Если `x < 0` и `y = +0.0`, возвращается π (приблизительно 3.141592653589793); если `x < 0` и `y = -0.0`, возвращается -π
- Если `y = +Infinity` и `x` имеет конечное значение, возвращается π/2; если `y = -Infinity` и `x` имеет конечное значение, возвращается -π/2
- Если `y = +Infinity` и `x = +Infinity`, возвращается π/4 (приблизительно 0.7853981633974483)
- Если `y = -Infinity` и `x = +Infinity`, возвращается -π/4 (приблизительно -0.7853981633974483)
- Если `y = +Infinity` и `x = -Infinity`, возвращается 3π/4 (приблизительно 2.356194490192345)
- Если `y = -Infinity` и `x = -Infinity`, возвращается -3π/4 (приблизительно -2.356194490192345)
- Если `x = +Infinity` и конечное значение `y` > 0, возвращается 0; если конечное значение `y` < 0, возвращается -0
- Если `x = -Infinity` и конечное значение `y` > 0, возвращается π; если конечное значение `y` < 0, возвращается -π
- Если `y` или `x` имеет значение NULL, возвращается NULL
