## Описание {#description}

Возвращает квадратный корень из значения, при этом входное значение должно быть больше или равно 0.

## Синтаксис {#syntax}

```sql
SQRT(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<x>` | Значение, квадратный корень из которого требуется вычислить |

## Возвращаемое значение {#return-value}

Квадратный корень из значения параметра `x`.

## Особые случаи {#special-cases}

- Если `x` равен 0, возвращает 0
- Если `x` равен -0, возвращает -0
- Если `x` меньше 0, возвращает `NULL`
- Если `x` имеет значение NaN, возвращает NaN
- Если `x` равен положительной бесконечности, возвращает Infinity
- Если `x` равен отрицательной бесконечности, возвращает `NULL`
- Если `x` имеет значение NULL, возвращает NULL

## Примеры {#examples}

```sql
select sqrt(9), sqrt(2);
```

```text
+-------------------------+-------------------------+
| sqrt(cast(9 as DOUBLE)) | sqrt(cast(2 as DOUBLE)) |
+-------------------------+-------------------------+
|                     3.0 |      1.4142135623730951 |
+-------------------------+-------------------------+
```

```sql

```

```text

+------------+
```

```text

+------------+
```
