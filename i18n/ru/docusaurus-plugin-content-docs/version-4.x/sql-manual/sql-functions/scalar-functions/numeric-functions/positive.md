## Описание {#description}

Возвращает само значение.

## Синтаксис {#syntax}

```sql
POSITIVE(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<x>`   | Значение, которое нужно вернуть. |

## Возвращаемое значение {#return-value}

Возвращает целое число или число с плавающей точкой. Особые случаи:

- Если параметр равен NULL, возвращается NULL.

## Пример {#example}

```sql
SELECT positive(-10);
```

```text
+---------------+
| positive(-10) |
+---------------+
|           -10 |
+---------------+
```

```sql
SELECT positive(10.111);
```

```text
+------------------+
| positive(10.111) |
+------------------+
|           10.111 |
+------------------+
```

```sql
SELECT positive(12);
```

```text
+--------------+
| positive(12) |
+--------------+
|           12 |
+--------------+
```

```sql
SELECT positive(null);
```

```text
+----------------+
| positive(NULL) |
+----------------+
|           NULL |
+----------------+
```
