## Описание {#description}

Возвращает гиперболический тангенс x.

## Синтаксис {#syntax}

```sql
TANH(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<x>` | Значение, для которого вычисляется гиперболический тангенс |

## Возвращаемое значение {#return-value}

Гиперболический тангенс параметра x.

## Особые случаи {#special-cases}
- Если `x` равен NaN, возвращает NaN
- Если `x` равен положительной бесконечности, возвращает 1
- Если `x` равен отрицательной бесконечности, возвращает -1
- Если `x` равен NULL, возвращает NULL

## Пример {#example}

```sql
select tanh(0),tanh(1);
```

```text
+-------------------------+-------------------------+
| tanh(cast(0 as DOUBLE)) | tanh(cast(1 as DOUBLE)) |
+-------------------------+-------------------------+
|                       0 |      0.7615941559557649 |
+-------------------------+-------------------------+
```

```sql
select tanh(cast('nan' as double));
```
```text
+-----------------------------+
| tanh(cast('nan' AS DOUBLE)) |
+-----------------------------+
| NaN                         |
+-----------------------------+
```

```sql
select tanh(cast('inf' as double));
```
```text
+-----------------------------+
| tanh(cast('inf' AS DOUBLE)) |
+-----------------------------+
| 1                           |
+-----------------------------+
```

```sql
select tanh(cast('-inf' as double));
```
```text
+------------------------------+
| tanh(cast('-inf' AS DOUBLE)) |
+------------------------------+
| -1                           |
+------------------------------+
```
