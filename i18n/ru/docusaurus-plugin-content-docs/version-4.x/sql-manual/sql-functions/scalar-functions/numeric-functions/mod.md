## Описание {#description}

Вычисляет остаток от деления a на b для целочисленного типа. Для типа с плавающей точкой используйте функцию fmod.

## Синтаксис {#syntax}

```sql
MOD(<col_a> , <col_b>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<col_a>`   | Делимое |
| `<col_b>`   | Делитель не должен быть равен 0 |

## Возвращаемое значение {#return-value}

Возвращает значение целочисленного типа. Особые случаи:

Если col_a IS NULL или col_b IS NULL, возвращает NULL.

## Пример {#example}

```sql
select mod(10, 3);
```

```text
+----------+
| (10 % 3) |
+----------+
|        1 |
+----------+
```

```sql
select mod(10, 0);
```

```text
+----------+
| (10 % 0) |
+----------+
|     NULL |
+----------+
```
