## Описание {#description}

Вычисляет остаток от деления чисел с плавающей точкой a / b. Для целочисленных типов используйте функцию mod.

## Синтаксис {#syntax}

```sql
FMOD(<col_a> , <col_b>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<col_a>` | Делимое |
| `<col_b>` | Делитель (не может быть 0) |

## Возвращаемое значение {#return-value}

Возвращает число с плавающей точкой. Особые случаи:

- Если любой из входных параметров равен NULL, возвращает NULL.

## Примеры {#examples}

```sql
select fmod(10.1, 3.2);
```

```text
+--------------------+
| fmod(10.1, 3.2)    |
+--------------------+
| 0.4999999999999991 |
+--------------------+
```

```sql
select fmod(10.1, 0);
```

```text
+---------------+
| fmod(10.1, 0) |
+---------------+
|          NULL |
+---------------+
```

```sql
select fmod(10.1, NULL);
```

```text
+------------------+
| fmod(10.1, NULL) |
+------------------+
|             NULL |
+------------------+
```
