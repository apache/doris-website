## Описание {#description}

Возвращает арксинус `x` или `NULL`, если `x` находится вне диапазона от `-1` до `1`.

## Синтаксис {#syntax}

```sql
ASIN(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |  
| -- | -- |  
| `<x>` | Значение, для которого вычисляется арксинус |  

## Возвращаемое значение {#return-value}

Арксинус значения параметра `x`, выраженный в радианах.

## Особые случаи {#special-cases}

- Если `x` равен 0, возвращается 0
- Если `x` равен 1, возвращается π/2
- Если `x` равен -1, возвращается -π/2
- Если `x` находится вне диапазона [-1, 1], возвращается `NULL`
- Если `x` равен NaN, возвращается NaN
- Если `x` равен положительной или отрицательной бесконечности, возвращается `NULL`
- Если `x` равен NULL, возвращается NULL

## Примеры {#examples}

```sql
select asin(0.5);
```

```text
+---------------------+
| asin(0.5)           |
+---------------------+
| 0.52359877559829893 |
+---------------------+
```

```sql
select asin(0.0);
```

```text
+------------+
| asin(0.0)  |
+------------+
|          0 |
+------------+
```

```sql
select asin(1.0);
```

```text
+--------------------+
| asin(1.0)          |
+--------------------+
| 1.570796326794897  |
+--------------------+
```

```sql
select asin(-1.0);
```

```text
+---------------------+
| asin(-1.0)          |
+---------------------+
| -1.570796326794897  |
+---------------------+
```

```sql
select asin(2);
```

```text
+------------+
| asin(2.0)  |
+------------+
|       NULL |
+------------+
```

```sql
select asin(cast('nan' as double));
```

```text
+---------------------------+
| asin(cast('nan' AS DOUBLE)) |
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select asin(cast('inf' as double));
```

```text
+---------------------------+
| asin(cast('inf' AS DOUBLE)) |
+---------------------------+
| NULL                      |
+---------------------------+
```
