## Описание {#description}

Возвращает логарифм `x` по основанию `2`.

## Синтаксис {#syntax}

```sql
LOG2(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<x>`   | Аргумент логарифма должен быть больше 0 |

## Возвращаемое значение {#return-value}

Возвращает число с плавающей точкой. Особые случаи:

- Если x имеет значение NULL, возвращается `NULL`
- Если x имеет значение NaN, возвращается NaN

## Пример {#example}

```sql
select log2(1);
```

```text
+-------------------------+
| log2(cast(1 as DOUBLE)) |
+-------------------------+
|                     0.0 |
+-------------------------+
```

```sql
select log2(2);
```

```text
+-------------------------+
| log2(cast(2 as DOUBLE)) |
+-------------------------+
|                     1.0 |
+-------------------------+
```

```sql
select log2(10);
```

```text
+--------------------------+
| log2(cast(10 as DOUBLE)) |
+--------------------------+
|       3.3219280948873626 |
+--------------------------+
```

```sql
select log2(NULL);
```

```text
+------------+
| log2(NULL) |
+------------+
|       NULL |
+------------+
```

```sql
select log2(cast('Nan' as double));
```

```text
+-----------------------------+
| log2(cast('Nan' as double)) |
+-----------------------------+
|                         NaN |
+-----------------------------+
```
