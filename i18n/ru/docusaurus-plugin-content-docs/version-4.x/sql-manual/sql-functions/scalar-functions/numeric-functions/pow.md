## Описание {#description}

Возвращает значение первого аргумента, возведённое в степень, заданную вторым аргументом.

## Псевдонимы {#alias}

- POWER
- FPOW
- DPOW

## Синтаксис {#syntax}

```sql
POW(<a>, <b>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<a>`   | Основание   |
| `<b>`   | Показатель степени  |

## Возвращаемое значение {#return-value}

Возвращает значение целочисленного типа или типа с плавающей точкой.

Особые случаи:

- Если для a выполняется `IS NULL` или для b выполняется `IS NULL`, возвращается `NULL`.
- Если `b = 0`, а для a выполняется `IS NOT NULL`, всегда возвращается `1`.

## Примеры {#examples}

```sql
select pow(2, 0);
```
```text
+-------------------------------------------+
| pow(cast(2 as DOUBLE), cast(0 as DOUBLE)) |
+-------------------------------------------+
|                                         1 |
+-------------------------------------------+
```

```sql
select pow(2, 10);
```
```text
+--------------------------------------------+
| pow(cast(2 as DOUBLE), cast(10 as DOUBLE)) |
+--------------------------------------------+
|                                       1024 |
+--------------------------------------------+
```

```sql
select pow(1.2, 2);
```
```text
+---------------------------------------------+
| pow(cast(1.2 as DOUBLE), cast(2 as DOUBLE)) |
+---------------------------------------------+
|                                        1.44 |
+---------------------------------------------+
```

```sql
select pow(1.2, 2.1);
```
```text
+-----------------------------------------------+
| pow(cast(1.2 as DOUBLE), cast(2.1 as DOUBLE)) |
+-----------------------------------------------+
|                            1.4664951016517147 |
+-----------------------------------------------+
```

```sql
select pow(2, null);
```
```text
+------------------------------+
| pow(cast(2 as DOUBLE), NULL) |
+------------------------------+
|                         NULL |
+------------------------------+
```

```sql
select pow(null, 2);
```
```text
+------------------------------+
| pow(NULL, cast(2 as DOUBLE)) |
+------------------------------+
|                         NULL |
+------------------------------+
```
