## Описание {#description}

Округляет x методом банковского округления, сохраняя d знаков после десятичной точки. Значение d по умолчанию равно 0.

Если d отрицательно, |d| цифр слева от десятичной точки заменяются на 0.

Если x или d равны null, возвращает null.

Если d задан столбцом, а первый параметр имеет тип Decimal, то результат типа Decimal будет содержать столько же знаков после десятичной точки, сколько входное значение Decimal.

Согласно правилам алгоритма банковского округления, при округлении до заданного десятичного разряда:

- Если отбрасываемая цифра равна 5 и после неё нет других ненулевых цифр, проверяется непосредственно предшествующая ей цифра:
   - Если предшествующая цифра чётная, 5 просто отбрасывается.
   - Если предшествующая цифра нечётная, число округляется вверх.

- Если отбрасываемая цифра больше 5 или после неё есть ненулевые цифры, применяются обычные правила округления: если цифра больше или равна 5, число округляется вверх, в противном случае округляется вниз.

Например:

- Для значения 2.5 цифра 2 перед 5 чётная, поэтому результат округления равен 2.

- Для значения 3.5 цифра 3 перед 5 нечётная, поэтому результат округления равен 4.

- Для значения 2.51 цифра после 5 не равна 0, поэтому число сразу округляется вверх, и результат равен 3.

## Синтаксис {#syntax}

```sql
ROUND_BANKERS(<x> [ , <d>])
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<x>` | Число для округления |
| `<d>` | Необязательный параметр, задающий количество знаков после десятичной точки, до которого выполняется округление. Значение по умолчанию равно 0. |

## Возвращаемое значение {#return-value}

Возвращает целое число или число с плавающей точкой:

- По умолчанию, когда параметр d = 0, возвращает целое число, полученное округлением x по алгоритму банковского округления.

- Если d отрицательно, возвращает целое число, у которого первая цифра слева от десятичной точки равна 0.

- Если и x, и d равны NULL, возвращает NULL.

- Если d задан столбцом, а x имеет тип Decimal, возвращает число с плавающей точкой с той же точностью.
