## Описание {#description}

Вычисляет синус параметра

## Синтаксис {#syntax}

```sql
SIN(<a>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<a>` | число с плавающей точкой, значение параметра в радианах, для которого вычисляется синус |

## Возвращаемое значение {#return-value}

Синус параметра `<a>`, выраженного в радианах.

## Особые случаи {#special-cases}
- Если `a` имеет значение NaN, возвращает NaN
- Если `a` равен положительной или отрицательной бесконечности, возвращает NaN
- Если `a` имеет значение NULL, возвращает NULL

## Примеры {#examples}

```sql
select sin(1);
```

```text
+------------------------+
| sin(cast(1 as DOUBLE)) |
+------------------------+
|     0.8414709848078965 |
+------------------------+
```

```sql
select sin(0);
```

```text
+------------------------+
| sin(cast(0 as DOUBLE)) |
+------------------------+
|                    0.0 |
+------------------------+
```

```sql
select sin(Pi());
```

```text
+------------------------------------+
| sin(pi())                          |
+------------------------------------+
| 0.00000000000000012246467991473532 |
+------------------------------------+
```

```sql
select sin(cast('nan' as double));
```

```text
+----------------------------+
| sin(cast('nan' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```


```text

+----------------------------+
```

```sql

```

```text

| sin(cast('-inf' AS DOUBLE)) |

+-----------------------------+
```
