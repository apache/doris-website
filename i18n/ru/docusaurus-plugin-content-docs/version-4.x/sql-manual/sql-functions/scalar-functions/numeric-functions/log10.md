## Описание {#description}

Возвращает логарифм `x` по основанию `10`.

## Псевдоним {#alias}

- DLOG10

## Синтаксис {#syntax}

```sql
LOG10(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<x>`   | Аргумент логарифма должен быть больше 0 |

## Возвращаемое значение {#return-value}

Возвращает число с плавающей точкой. Особые случаи:

- Если x имеет значение NULL, возвращает `NULL`
- Если x имеет значение NaN, равен нулю или отрицателен, возвращает `NULL`

## Пример {#example}

```sql
select log10(1);
```

```text
+--------------------------+
| log10(cast(1 as DOUBLE)) |
+--------------------------+
|                      0.0 |
+--------------------------+
```

```sql
select log10(10);
```

```text
+---------------------------+
| log10(cast(10 as DOUBLE)) |
+---------------------------+
|                       1.0 |
+---------------------------+
```

```sql
select log10(16);
```

```text
+---------------------------+
| log10(cast(16 as DOUBLE)) |
+---------------------------+
|        1.2041199826559248 |
+---------------------------+
```

```sql
select log10(NULL);
```

```text
+-------------+
| log10(NULL) |
+-------------+
|        NULL |
+-------------+
```

```sql
select log10(cast('nan' as double));
```

```text
+------------------------------+
| log10(cast('nan' as double)) |
+------------------------------+
|                         NULL |
+------------------------------+
```
