## Описание {#description}

Возвращает гиперболический арксинус `x`.

## Синтаксис {#syntax}

```sql
ASINH(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |  
| -- | -- |  
| `<x>` | Значение, для которого требуется вычислить гиперболический арксинус |  

## Возвращаемое значение {#return-value}

Значение asinh для параметра `x`. 

## Особые случаи {#special-cases}
- Если `x` имеет значение NaN, возвращает NaN
- Если `x` имеет значение положительной бесконечности, возвращает Infinity
- Если `x` имеет значение отрицательной бесконечности, возвращает -Infinity
- Если `x` имеет значение +0.0, возвращает 0
- Если `x` имеет значение -0.0, возвращает -0
- При очень больших значениях по модулю возможно переполнение с результатом Infinity/-Infinity (например, ±1e308)
- Если `x` имеет значение NULL, возвращает NULL

## Пример {#example}

```sql
select asinh(0.0);
```

```text
+------------+
| asinh(0.0) |
+------------+
|          0 |
+------------+
```

```sql
select asinh(1.0);
```

```text
+-------------------+
| asinh(1.0)        |
+-------------------+
| 0.881373587019543 |
+-------------------+
```

```sql
select asinh(-1.0);
```

```text
+--------------------+
| asinh(-1.0)        |
+--------------------+
| -0.881373587019543 |
+--------------------+
```

```sql
select asinh(cast('nan' as double));
```

```text
+------------------------------+
| asinh(cast('nan' AS DOUBLE)) |
+------------------------------+
| NaN                          |
+------------------------------+
```

```sql
select asinh(cast('inf' as double));
```

```text
+------------------------------+
| asinh(cast('inf' AS DOUBLE)) |
+------------------------------+
| Infinity                     |
+------------------------------+
```

```sql
select asinh(cast('-inf' as double));
```

```text
+-------------------------------+
| asinh(cast('-inf' AS DOUBLE)) |
+-------------------------------+
| -Infinity                     |
+-------------------------------+
```
