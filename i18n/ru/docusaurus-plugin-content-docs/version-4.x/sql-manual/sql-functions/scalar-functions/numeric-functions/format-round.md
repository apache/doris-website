## Описание {#description}

Форматирует число по шаблону вида "#,###,###.##", округляет его до указанного количества знаков после запятой и возвращает результат в виде строки.

:::tip
Эта функция поддерживается начиная с версии 3.0.6.
:::

## Синтаксис {#syntax}

```sql
FORMAT_ROUND(<number>, <D>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<number>` | Число для форматирования |
| `<D>` | Количество знаков после запятой, диапазон [0, 1024] |

## Возвращаемое значение {#return-value}

Возвращает отформатированную строку типа STRING. Особые случаи:

- Возвращает NULL, если параметр равен NULL
- Если D равен 0, результат не содержит десятичной точки и дробной части. В линейке Doris 4.1 начиная с версии 4.1.5 входные значения DECIMAL также округляются, когда D равен 0; в более ранних версиях дробная часть могла отбрасываться без округления.
- Если D не входит в диапазон [0, 1024], возвращается ошибка с указанием, что аргумент должен находиться в этом диапазоне.

## Пример {#example}

```sql
select format_round(17014116, 2);
```

```text
+---------------------------+
| format_round(17014116, 2) |
+---------------------------+
| 17,014,116.00             |
+---------------------------+
```

```sql
select format_round(1123.456, 2);
```

```text
+---------------------------+
| format_round(1123.456, 2) |
+---------------------------+
| 1,123.46                  |
+---------------------------+
```

```sql
select format_round(1123.4, 2);
```

```text
+-------------------------+
| format_round(1123.4, 2) |
+-------------------------+
| 1,123.40                |
+-------------------------+
```

```sql
select format_round(123456, 0);
```

```text
+-------------------------+
| format_round(123456, 0) |
+-------------------------+
| 123,456                 |
+-------------------------+
```

```sql
select format_round(123456, 3);
```

```text
+-------------------------+
| format_round(123456, 3) |
+-------------------------+
| 123,456.000             |
+-------------------------+
```

```sql
select format_round(123456.123456, 0);
```

```text
+--------------------------------+
| format_round(123456.123456, 0) |
+--------------------------------+
| 123,456                        |
+--------------------------------+
```

```sql
select format_round(123456.123456, 3);
```

```text
+--------------------------------+
| format_round(123456.123456, 3) |
+--------------------------------+
| 123,456.123                    |
+--------------------------------+
```

```sql
select format_round(123456.123456, 6);
```

```text
+--------------------------------+
| format_round(123456.123456, 6) |
+--------------------------------+
| 123,456.123456                 |
+--------------------------------+
```

```sql
SELECT format_round(-0.01, -1);
```

```text
ERROR 1105 (HY000): errCode = 2, detailMessage = (127.0.0.1)[INVALID_ARGUMENT]The second argument is -1, it should be in range [0, 1024].
```

```sql
SELECT format_round(-0.01, -1500);
```

```text
ERROR 1105 (HY000): errCode = 2, detailMessage = (127.0.0.1)[INVALID_ARGUMENT]The second argument is -1500, it should be in range [0, 1024].
```

Округление входных значений DECIMAL до целых:

```sql
SELECT FORMAT_ROUND(CAST(1.9 AS DECIMAL(9, 1)), 0),
       FORMAT_ROUND(CAST(-1.9 AS DECIMAL(9, 1)), 0),
       FORMAT_ROUND(CAST(1.4 AS DECIMAL(9, 1)), 0),
       FORMAT_ROUND(CAST(-1.4 AS DECIMAL(9, 1)), 0);
```

```text
2    -2    1    -1
```

Входное значение NULL:

```sql
SELECT FORMAT_ROUND(NULL, 2);
```

```text
NULL
```
