## Описание {#description}

Выполняет равномерную выборку и генерирует случайные числа в указанном диапазоне с использованием заданного начального значения генератора.

## Синтаксис {#syntax}

```sql
UNIFORM( <min> , <max> , <gen> )
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<min>` | Нижняя граница диапазона случайных чисел; принимает числовое значение, которое должно быть литералом |
| `<max>` | Верхняя граница диапазона случайных чисел; принимает числовое значение, которое должно быть литералом |
| `<gen>` | Целое число, начальное значение генератора, обычно получаемое случайным образом с помощью функции [RANDOM](./random.md). |

## Возвращаемое значение {#return-value}

Возвращает случайное число в диапазоне `[<min>, <max>]`. Если `<min>` и `<max>` являются целыми числами, возвращаемое значение имеет тип `BIGINT`, иначе `DOUBLE`.

Обратите внимание: в отличие от [типичного использования](https://docs.snowflake.com/en/sql-reference/functions/uniform) в Snowflake, функция RANDOM в Doris по умолчанию возвращает число с плавающей точкой от 0 до 1, поэтому при использовании `RANDOM()` в качестве начального значения генератора следует добавить множитель, чтобы результат распределялся в целочисленном диапазоне. Подробности приведены в примерах.

## Пример {#example}

<!-- setup-sql
CREATE TABLE it (k0 INT) DISTRIBUTED BY HASH(k0) BUCKETS 1 PROPERTIES("replication_num"="1");
INSERT INTO it VALUES (NULL),(1),(2),(3),(4),(5);
CREATE TABLE fn_test (ksint INT) DISTRIBUTED BY HASH(ksint) BUCKETS 1 PROPERTIES("replication_num"="1");
INSERT INTO fn_test VALUES (1);
-->

Если все входные параметры являются целыми числами, возвращается целое число:

```sql
select uniform(-100, 100, random() * 10000) as result from numbers("number" = "10");
```

```text
+--------+
| result |
+--------+
|    -82 |
|    -79 |
|     21 |
|     19 |
|     50 |
|     53 |
|   -100 |
|    -67 |
|     46 |
|     40 |
+--------+
```

Если не все входные параметры являются целыми числами, возвращается значение типа double:

```sql
select uniform(1, 100., random() * 10000) as result from numbers("number" = "10");
```

```text
+-------------------+
| result            |
+-------------------+
| 84.25057360297031 |
| 63.34296160793329 |
|  81.8770598286311 |
| 26.53334147605743 |
| 17.42787914185705 |
| 2.532901549399078 |
| 63.72223367924216 |
| 78.42165786093118 |
|   18.913688179943 |
| 41.73057334477316 |
+-------------------+
```

Параметры должны быть литералами:

```sql
select uniform(1, unix_timestamp(), random() * 10000) as result from numbers("number" = "10");
```

```text
ERROR 1105 (HY000): errCode = 2, detailMessage = The second parameter (max) of uniform function must be literal
```

Параметры должны быть литералами:

```sql
select uniform(1, ksint, random()) from fn_test;
```

```text
ERROR 1105 (HY000): errCode = 2, detailMessage = The second parameter (max) of uniform function must be literal
```

Одинаковые начальные значения генератора дают одинаковые результаты (результат `random()` находится в диапазоне от 0 до 1, и при его непосредственном использовании параметр начального значения генератора функции `uniform` всегда равен `0`):

```sql
select uniform(-100, 100, random()) as result from numbers("number" = "10");
```

```text
+--------+
| result |
+--------+
|    -68 |
|    -68 |
|    -68 |
|    -68 |
|    -68 |
|    -68 |
|    -68 |
|    -68 |
|    -68 |
|    -68 |
+--------+
```

Если любой входной параметр равен NULL, результат также равен NULL:

```sql
select uniform(-100, NULL, random() * 10000) as result from numbers("number" = "10");
```

```text
+--------+
| result |
+--------+
|   NULL |
|   NULL |
|   NULL |
|   NULL |
|   NULL |
|   NULL |
|   NULL |
|   NULL |
|   NULL |
|   NULL |
+--------+
```

```sql
select k0, uniform(0, 1000, k0) from it order by k0;
```

```text
+------+----------------------+
| k0   | uniform(0, 1000, k0) |
+------+----------------------+
| NULL |                 NULL |
|    1 |                  134 |
|    2 |                  904 |
|    3 |                  559 |
|    4 |                  786 |
|    5 |                  673 |
+------+----------------------+
```
