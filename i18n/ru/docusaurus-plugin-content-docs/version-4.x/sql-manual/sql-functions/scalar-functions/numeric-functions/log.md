## Описание {#description}

Возвращает логарифм `x` по основанию `b`.

## Синтаксис {#syntax}

```sql
LOG([<b>, ]<x>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<b>`     | Необязательный параметр. Основание должно быть больше 0 и не равно 1.0. Если не указано, вычисляется натуральный логарифм (по основанию e). |
| `<x>`     | Логарифмируемое число должно быть больше 0 |

## Возвращаемое значение {#return-value}

Возвращает число с плавающей точкой. Особые случаи:

- Если b IS NULL или x IS NULL, возвращается NULL
- Если любой из параметров равен NaN, возвращается NaN
- Если параметры не соответствуют ограничениям на входные значения, возвращается NULL

## Пример {#example}

```sql
select log(5,1);
```

```text
+---------------+
| log(5.0, 1.0) |
+---------------+
|             0 |
+---------------+
```

```sql
select log(3),ln(3);
```

```text
+--------------------+--------------------+
| log(3)             | ln(3)              |
+--------------------+--------------------+
| 1.0986122886681098 | 1.0986122886681098 |
+--------------------+--------------------+
```

```sql
select log(3,20);
```

```text
+--------------------+
| log(3.0, 20.0)     |
+--------------------+
| 2.7268330278608417 |
+--------------------+
```

```sql
select log(2,65536);
```

```text
+-------------------+
| log(2.0, 65536.0) |
+-------------------+
|                16 |
+-------------------+
```

```sql
select log(5,NULL);
```

```text
+------------------------------+
| log(cast(5 as DOUBLE), NULL) |
+------------------------------+
|                         NULL |
+------------------------------+
```

```sql
select log(NULL,3);
```

```text
+------------------------------+
| log(NULL, cast(3 as DOUBLE)) |
+------------------------------+
|                         NULL |
+------------------------------+
```

```sql
select log(2 ,cast('nan' as double));
```

```text
+-------------------------------+
| log(2 ,cast('nan' as double)) |
+-------------------------------+
|                           NaN |
+-------------------------------+
```

```sql
select log(2 ,-1);
```

```text
+------------+
| log(2 ,-1) |
+------------+
|       NULL |
+------------+
```
