## Описание {#description}

Возвращает котангенс x, где x задан в радианах. Для входного и выходного значений поддерживается только тип double. Если входное значение равно null, возвращается null.

## Синтаксис {#syntax}

```sql
COT(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<x>` | Значение, для которого вычисляется котангенс |

## Возвращаемое значение {#return-value}

Возвращает значение типа Double, равное котангенсу x.

## Особые случаи {#special-cases}
- Если `x` равен NaN, возвращается NaN
- Если `x` равен положительной или отрицательной бесконечности, возвращается NaN
- Если `x` равен NULL, возвращается NULL

## Пример {#example}

```sql
select cot(1),cot(2),cot(1000);
```

```text
+--------------------+----------------------+--------------------+
| cot(1)             | cot(2)               | cot(1000)          |
+--------------------+----------------------+--------------------+
| 0.6420926159343306 | -0.45765755436028577 | 0.6801221323348698 |
+--------------------+----------------------+--------------------+
```

Входное значение null.

```sql
select cot(null);
```

```text
+--------------------+
| cot(null)          |
+--------------------+
|      NULL          |
+--------------------+
```

```sql
select cot(cast('nan' as double));
```

```text
+----------------------------+
| cot(cast('nan' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select cot(cast('inf' as double));
```

```text
+----------------------------+
| cot(cast('inf' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select cot(cast('-inf' as double));
```

```text
+-----------------------------+
| cot(cast('-inf' AS DOUBLE)) |
+-----------------------------+
| NaN                         |
+-----------------------------+
```
