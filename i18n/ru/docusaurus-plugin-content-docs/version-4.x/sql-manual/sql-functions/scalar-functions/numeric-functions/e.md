## Описание {#description}

Возвращает значение константы `e`.

## Синтаксис {#syntax}

`E()`

## Пример {#example}

```
mysql> select e();
+--------------------+
| e()                |
+--------------------+
| 2.718281828459045  |
+--------------------+
```
