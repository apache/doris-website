## Описание {#description}

Число выводится в денежном формате: целая часть разделяется запятыми на группы по три разряда, а дробная часть содержит два знака.

## Синтаксис {#syntax}

```sql
MONEY_FORMAT(<number>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<number>`   | Числа для форматирования |

## Возвращаемое значение {#return-value}

Возвращает строку в денежном формате. Особые случаи:

- Если параметр равен NULL, возвращается NULL

## Пример {#example}

```sql
select money_format(17014116);
```

```text
+------------------------+
| money_format(17014116) |
+------------------------+
| 17,014,116.00          |
+------------------------+
```

```sql
select money_format(1123.456);
```

```text
+------------------------+
| money_format(1123.456) |
+------------------------+
| 1,123.46               |
+------------------------+
```

```sql
select money_format(1123.4);
```

```text
+----------------------+
| money_format(1123.4) |
+----------------------+
| 1,123.40             |
+----------------------+
```
