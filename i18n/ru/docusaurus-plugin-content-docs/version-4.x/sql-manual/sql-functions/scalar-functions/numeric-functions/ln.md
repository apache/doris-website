## Описание {#description}

Возвращает натуральный логарифм `x` по основанию `e`.

## Псевдоним {#alias}

- DLOG1

## Синтаксис {#syntax}

```sql
LN(<x>)
```

## Параметры {#parameters}

| Параметр | Описание |
|-----------|------------|
| `<x>`   | Аргумент логарифма должен быть больше 0 |

## Возвращаемое значение {#return-value}

Возвращает число с плавающей запятой. Особые случаи:

- Если x имеет значение NULL, возвращается NULL
- Если x имеет значение NaN, возвращается NaN
- Если x равен положительной бесконечности, возвращается Infinity

## Пример {#example}

```sql
select ln(1);
```

```text
+-----------------------+
| ln(cast(1 as DOUBLE)) |
+-----------------------+
|                   0.0 |
+-----------------------+
```

```sql
select ln(e());
```

```text
+---------+
| ln(e()) |
+---------+
|     1.0 |
+---------+
```

```sql
select ln(10);
```

```text
+------------------------+
| ln(cast(10 as DOUBLE)) |
+------------------------+
|      2.302585092994046 |
+------------------------+
```

```sql
select ln(cast('inf' as double));
```

```text
+---------------------------+
| ln(cast('inf' as double)) |
+---------------------------+
|                  Infinity |
+---------------------------+
```

```sql
select ln(cast('nan' as double));
```

```text
+---------------------------+
| ln(cast('nan' as double)) |
+---------------------------+
|                       NaN |
+---------------------------+
```
