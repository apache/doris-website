## Описание {#description}

Преобразует десятичные числа в двоичные строки.

## Синтаксис {#syntax}

```sql
BIN(<a>)
```

## Параметры {#parameters}

| Параметр | Описание |
| -- | -- |
| `<a>` | Десятичное значение для преобразования (тип: BigInt) |

## Возвращаемое значение {#return-value}

Двоичное представление параметра `<a>`. Если `<a>` имеет отрицательное значение, результатом будет его 64-битное представление в дополнительном коде.
Если `a` равен NULL, функция возвращает NULL.

## Примеры {#examples}

```sql
select bin(0);
```

```text
+--------+
| bin(0) |
+--------+
| 0      |
+--------+
```

```sql
select bin(-1);
```

```text
+------------------------------------------------------------------+
| bin(-1)                                                          |
+------------------------------------------------------------------+
| 1111111111111111111111111111111111111111111111111111111111111111 |
+------------------------------------------------------------------+
```

```sql
select bin(123);
```

```text
+----------+
| bin(123) |
+----------+
| 1111011  |
+----------+
```

```sql
select bin(NULL);
```

```text
+-----------+
| bin(NULL) |
+-----------+
| NULL      |
+-----------+
```
