## Описание {#description}

Создаёт геометрический объект Point по заданным координатам X и Y.
В геопространственном контексте X/Y обычно обозначают долготу и широту соответственно,

## Синтаксис {#syntax}

```sql
ST_POINT( <x>, <y>)
```
## Параметры {#parameters}

| Параметр  | Описание  |
|-----|-----|
| `<x>` | Координата X (долгота) точки, диапазон: от -180.0 до 180.0 (в градусах) |
| `<y>` | Координата Y (широта) точки, диапазон: от -90.0 до 90.0 (в градусах) |

## Возвращаемое значение {#return-value}

Возвращает геометрический объект Point, представляющий 2D-координату.

- Возвращает NULL, если <x> или <y> выходит за допустимые пределы долготы/широты.
- Возвращает NULL, если любой из параметров равен NULL.

## Пример {#example}

Допустимые координаты

```sql
SELECT ST_AsText(ST_Point(24.7, 56.7));
```

```text
+---------------------------------+
| st_astext(st_point(24.7, 56.7)) |
+---------------------------------+
| POINT (24.7 56.7)               |
+---------------------------------+
```

Недопустимая долгота (за пределами диапазона)

```sql
mysql> SELECT ST_Point(200, 50);
+-------------------+
| ST_Point(200, 50) |
+-------------------+
| NULL              |
+-------------------+
```

Недопустимая широта (за пределами диапазона)

```sql
mysql> SELECT ST_Point(116, -100);
+---------------------+
| ST_Point(116, -100) |
+---------------------+
| NULL                |
+---------------------+
```

Любой из параметров равен NULL

```sql
mysql> SELECT ST_Point(NULL, 50);
+--------------------+
| ST_Point(NULL, 50) |
+--------------------+
| NULL               |
+--------------------+
```

```sql
mysql> SELECT ST_Point(50, NULL);
+--------------------+
| ST_Point(50, NULL) |
+--------------------+
| NULL               |
+--------------------+

```
