## Описание {#description}

Преобразует WKB (Well-known binary) стандартной геометрической фигуры в соответствующий геометрический объект в памяти

## Псевдоним {#alias}

- ST_GEOMFROMWKB

## Синтаксис {#syntax}

```sql
ST_GEOMETRYFROMWKB( <wkb>)
```
## Параметры {#parameters}

| Параметры | Описание |
| -- |---------|
| `<wkb>` | Двоичное представление геометрического объекта, обычно создаваемое функцией ST_AsBinary или другими функциями, возвращающими WKB. Поддерживаются все стандартные типы геометрических объектов: POINT, LINESTRING,LINE, POLYGON |

## Возвращаемое значение {#return-value}

Возвращает геометрический объект, соответствующий входному WKB. Возвращает NULL, если входное значение равно NULL или формат WKB некорректен.

## Примеры {#examples}

Аргумент типа POINT

```sql
select ST_AsText(ST_GeometryFromWKB(ST_AsBinary(ST_Point(24.7, 56.7))));
```

```text
+------------------------------------------------------------------+
| st_astext(st_geometryfromwkb(st_asbinary(st_point(24.7, 56.7)))) |
+------------------------------------------------------------------+
| POINT (24.7 56.7)                                                |
+------------------------------------------------------------------+
```

```sql
select ST_AsText(ST_GeomFromWKB(ST_AsBinary(ST_Point(24.7, 56.7))));
```

```text
+--------------------------------------------------------------+
| st_astext(st_geomfromwkb(st_asbinary(st_point(24.7, 56.7)))) |
+--------------------------------------------------------------+
| POINT (24.7 56.7)                                            |
+--------------------------------------------------------------+
```

Аргумент типа LINESTRING

```sql
select ST_AsText(ST_GeometryFromWKB(ST_AsBinary(ST_GeometryFromText("LINESTRING (1 1, 2 2)"))));
```

```text
+------------------------------------------------------------------------------------------+
| st_astext(st_geometryfromwkb(st_asbinary(st_geometryfromtext('LINESTRING (1 1, 2 2)')))) |
+------------------------------------------------------------------------------------------+
| LINESTRING (1 1, 2 2)                                                                    |
+------------------------------------------------------------------------------------------+
```

```sql
+-------------------------------------+
| NULL                                |
+-------------------------------------+
```
