## Описание {#description}

Возвращает общее количество вершин (точек) в геометрическом объекте. Для разных типов геометрии действуют следующие правила подсчёта: для Point возвращается 1, для LineString — количество вершин, для Polygon — общее количество вершин во всех кольцах (включая замыкающую точку), а для MultiPolygon — сумма количества точек во всех составляющих его полигонах.

:::note
Начиная с версии 4.1.2
:::

## Синтаксис {#syntax}

```sql
ST_NUMPOINTS( <shape> )
```

## Параметры {#parameters}

| Параметр | Описание |
| :--- | :--- |
| `<shape>` | Входная геометрия типа GEOMETRY или VARCHAR (в формате WKT), которую можно преобразовать в GEOMETRY. |

## Возвращаемое значение {#return-value}

Возвращает значение типа BIGINT, представляющее общее количество точек в геометрическом объекте.

Особые случаи для `ST_NUMPOINTS`:
- Если входной параметр равен `NULL`, возвращается `NULL`.
- Если входной параметр не удаётся разобрать как корректный геометрический объект, возвращается `NULL`.
- Для `POINT` возвращается `1`.
- Для `LINESTRING` возвращается количество вершин линии.
- Для `POLYGON` возвращается общее количество вершин во всех кольцах (внешнее кольцо + внутренние кольца). Каждое кольцо включает замыкающую точку.
- Для `MULTIPOLYGON` возвращается сумма количества точек во всех составляющих его полигонах.
- Для `CIRCLE` возвращается `-1` (у окружностей нет дискретных вершин).

## Пример {#example}

**Количество точек в объекте Point**
```sql
SELECT ST_NUMPOINTS(ST_Point(1, 2));
```
```text
+------------------------------+
| ST_NUMPOINTS(ST_Point(1, 2)) |
+------------------------------+
|                            1 |
+------------------------------+
```

**Количество точек в объекте LineString**
```sql
SELECT ST_NUMPOINTS(ST_GeometryFromText('LINESTRING(0 0, 1 1, 2 2)'));
```
```text
+-------------------------------------------------------------------+
| ST_NUMPOINTS(ST_GeometryFromText('LINESTRING(0 0, 1 1, 2 2)'))   |
+-------------------------------------------------------------------+
|                                                                 3 |
+-------------------------------------------------------------------+
```

**Количество точек в объекте Polygon (квадрат)**
```sql
SELECT ST_NUMPOINTS(ST_GeometryFromText('POLYGON((0 0, 1 0, 1 1, 0 1, 0 0))'));
```
```text
+----------------------------------------------------------------------------+
| ST_NUMPOINTS(ST_GeometryFromText('POLYGON((0 0, 1 0, 1 1, 0 1, 0 0))'))  |
+----------------------------------------------------------------------------+
|                                                                          5 |
+----------------------------------------------------------------------------+
```

**Количество точек в объекте Polygon с отверстием**
```sql
SELECT ST_NUMPOINTS(ST_GeometryFromText('POLYGON((0 0, 10 0, 10 10, 0 10, 0 0),(1 1, 2 1, 2 2, 1 2, 1 1))'));
```
```text
+-----------------------------------------------------------------------------------------------------------+
| ST_NUMPOINTS(ST_GeometryFromText('POLYGON((0 0, 10 0, 10 10, 0 10, 0 0),(1 1, 2 1, 2 2, 1 2, 1 1))'))   |
+-----------------------------------------------------------------------------------------------------------+
|                                                                                                        10 |
+-----------------------------------------------------------------------------------------------------------+
```

**Количество точек в объекте MultiPolygon**
```sql
SELECT ST_NUMPOINTS(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))'));
```
```text
+--------------------------------------------------------------------------------------------------------------+
| ST_NUMPOINTS(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))')) |
+--------------------------------------------------------------------------------------------------------------+
|                                                                                                           10 |
+--------------------------------------------------------------------------------------------------------------+
```

**Количество точек в объекте Circle (возвращает -1)**
```sql
SELECT ST_NUMPOINTS(ST_Circle(0, 0, 100));
```
```text
+--------------------------------------+
| ST_NUMPOINTS(ST_Circle(0, 0, 100))  |
+--------------------------------------+
|                                   -1 |
+--------------------------------------+
```

**Параметр NULL**
```sql
SELECT ST_NUMPOINTS(NULL);
```
```text
+---------------------+
| ST_NUMPOINTS(NULL)  |
+---------------------+
|                NULL |
+---------------------+
```

**Некорректный параметр (возвращает NULL)**
```sql
SELECT ST_NUMPOINTS(ST_GeometryFromText('INVALID'));
```
```text
+------------------------------------------------+
| ST_NUMPOINTS(ST_GeometryFromText('INVALID'))   |
+------------------------------------------------+
|                                           NULL |
+------------------------------------------------+
```
