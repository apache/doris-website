## Описание {#description}

Возвращает координату Y корректной геометрии POINT. В геопространственном контексте координата Y обычно соответствует широте в диапазоне [-90.0, 90.0] (в градусах).

## Синтаксис {#syntax}

```sql
ST_Y( <point>)
```

## Параметры {#parameters}

| Параметры   | Описание      |
|------|----------|
| `<point>` | Корректная геометрия 2D POINT, из которой извлекается координата Y. Значение Y (широта) должно находиться в диапазоне [-90.0, 90.0], а значение X (долгота) — в диапазоне [-180.0, 180.0]. |

## Возвращаемое значение {#return-value}

Координата Y входного объекта POINT, возвращаемая в формате DOUBLE PRECISION FLOAT.

Возвращает координату Y (широту) для корректных входных объектов POINT.
Возвращает NULL для входных значений NULL, пустых точек (POINT EMPTY), точек 3D или некорректных точек (например, с широтой за пределами диапазона [-90.0, 90.0]).

## Примеры {#examples}

Корректная точка

```sql
SELECT ST_Y(ST_Point(24.7, 56.7));
```

```text
+----------------------------+
| ST_Y(ST_Point(24.7, 56.7)) |
+----------------------------+
| 56.7                       |
+----------------------------+
```

Пустая точка (POINT EMPTY)

```sql
mysql> SELECT ST_Y(ST_GeometryFromText("POINT EMPTY"));
+------------------------------------------+
| ST_Y(ST_GeometryFromText("POINT EMPTY")) |
+------------------------------------------+
|                                     NULL |
+------------------------------------------+
```
Точка 3D (не поддерживается)

```sql
mysql> SELECT ST_Y(ST_GeometryFromText("POINT (10 20 30)"));
+-----------------------------------------------+
| ST_Y(ST_GeometryFromText("POINT (10 20 30)")) |
+-----------------------------------------------+
|                                          NULL |
+-----------------------------------------------+
```


Входное значение NULL

```sql
mysql> SELECT ST_Y(NULL);
+------------+
| ST_Y(NULL) |
+------------+
|       NULL |
+------------+
```

Некорректная широта (вне допустимого диапазона)

```sql
mysql> SELECT ST_Y(ST_Point(116.4, 91));
+---------------------------+
| ST_Y(ST_Point(116.4, 91)) |
+---------------------------+
|                      NULL |
+---------------------------+
```

Некорректная долгота (вне допустимого диапазона)

```sql
mysql> SELECT ST_Y(ST_Point(190, 39.9));
+---------------------------+
| ST_Y(ST_Point(190, 39.9)) |
+---------------------------+
|                      NULL |
+---------------------------+
```
