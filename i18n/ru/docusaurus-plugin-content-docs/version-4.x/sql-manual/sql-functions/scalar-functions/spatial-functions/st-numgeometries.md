## Описание {#description}

Возвращает количество геометрических компонентов в геометрическом объекте. Для типов, не являющихся коллекциями (Point, LineString, Polygon, Circle), всегда возвращает 1. Для типов коллекций (MultiPolygon) возвращает количество геометрических компонентов в коллекции.

:::note
Начиная с версии 4.1.2
:::

## Синтаксис {#syntax}

```sql
ST_NUMGEOMETRIES( <shape> )
```

## Параметры {#parameters}

| Параметр | Описание |
| :--- | :--- |
| `<shape>` | Входной геометрический объект типа GEOMETRY или VARCHAR (в формате WKT), который можно преобразовать в GEOMETRY. |

## Возвращаемое значение {#return-value}

Возвращает значение типа BIGINT, представляющее количество геометрических компонентов в геометрическом объекте.

Для `ST_NUMGEOMETRIES` предусмотрены следующие особые случаи:
- Если входной параметр равен `NULL`, возвращает `NULL`.
- Если входной параметр не удаётся распознать как корректный геометрический объект, возвращает `NULL`.
- Для типов, не являющихся коллекциями (`POINT`, `LINESTRING`, `POLYGON`, `CIRCLE`), всегда возвращает `1`.
- Для `MULTIPOLYGON` возвращает количество полигонов в коллекции.

## Пример {#example}

**Количество геометрий в Point**
```sql
SELECT ST_NUMGEOMETRIES(ST_Point(1, 2));
```
```text
+----------------------------------+
| ST_NUMGEOMETRIES(ST_Point(1, 2)) |
+----------------------------------+
|                                1 |
+----------------------------------+
```

**Количество геометрий в Polygon**
```sql
SELECT ST_NUMGEOMETRIES(ST_GeometryFromText('POLYGON((0 0, 1 0, 1 1, 0 1, 0 0))'));
```
```text
+------------------------------------------------------------------------------+
| ST_NUMGEOMETRIES(ST_GeometryFromText('POLYGON((0 0, 1 0, 1 1, 0 1, 0 0))')) |
+------------------------------------------------------------------------------+
|                                                                            1 |
+------------------------------------------------------------------------------+
```

**Количество геометрий в MultiPolygon с двумя полигонами**
```sql
SELECT ST_NUMGEOMETRIES(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))'));
```
```text
+------------------------------------------------------------------------------------------------------------------+
| ST_NUMGEOMETRIES(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))')) |
+------------------------------------------------------------------------------------------------------------------+
|                                                                                                                2 |
+------------------------------------------------------------------------------------------------------------------+
```

**Количество геометрий в Circle**
```sql
SELECT ST_NUMGEOMETRIES(ST_Circle(0, 0, 100));
```
```text
+----------------------------------------+
| ST_NUMGEOMETRIES(ST_Circle(0, 0, 100)) |
+----------------------------------------+
|                                      1 |
+----------------------------------------+
```

**Параметр NULL**
```sql
SELECT ST_NUMGEOMETRIES(NULL);
```
```text
+------------------------+
| ST_NUMGEOMETRIES(NULL) |
+------------------------+
|                   NULL |
+------------------------+
```

**Некорректный параметр (возвращает NULL)**
```sql
SELECT ST_NUMGEOMETRIES(ST_GeometryFromText('INVALID'));
```
```text
+--------------------------------------------------+
| ST_NUMGEOMETRIES(ST_GeometryFromText('INVALID')) |
+--------------------------------------------------+
|                                             NULL |
+--------------------------------------------------+
```
