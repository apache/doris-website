## Описание {#description}

Оператор `CREATE ROLE` используется для создания роли без привилегий, которую впоследствии можно назначить с помощью команды GRANT.

## Синтаксис {#syntax}

```sql
 CREATE ROLE <role_name> [<comment>];
```

## Обязательные параметры {#required-parameters}

**1. `<role_name>`**

> Имя роли. 

## Необязательные параметры {#optional-parameters}

**1. `<comment>`**

> Комментарий к роли.

## Требования к управлению доступом {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать как минимум следующими привилегиями:

| Привилегия    | Объект    | Примечания |
|:--------------|:----------|:------|
| ADMIN_PRIV    | USER или ROLE    | Эту операцию могут выполнять только пользователи или роли с привилегией ADMIN_PRIV  |

## Пример {#example}

- Создание роли

```sql
CREATE ROLE role1;
```

- Создание роли с комментарием

```sql
CREATE ROLE role2 COMMENT "this is my first role";
```
