## Описание {#description}

 Этот оператор используется для просмотра прав пользователей.

## Синтаксис {#syntax}

```sql
SHOW [ALL] GRANTS [FOR <user_identity>];
```

## Необязательные параметры {#optional-parameters}

**1. `[ALL]`**

Следует ли просматривать права всех пользователей.

**2. `<user_identity>`**

  Укажите пользователя, права которого требуется просмотреть. `user_identity` должен быть создан командой `CREATE USER`.

## Возвращаемое значение {#return-value}

  | Столбец | Описание |
  | -- | -- |
  | UserIdentity | Идентификатор пользователя |
  | Comment | Комментарий |
  | Password | `No`, если локальный пароль недоступен; `Yes`, если указан только основной пароль; `Yes (dual)`, если дополнительно сохранён вторичный пароль (начиная с версии 4.2.1). |
  | Roles | Роли |
  | GlobalPrivs | Глобальные привилегии |
  | CatalogPrivs | Привилегии Catalog |
  | DatabasePrivs | Привилегии базы данных |
  | TablePrivs | Привилегии таблиц |
  | ColPrivs | Привилегии столбцов |
  | ResourcePrivs | Привилегии ресурсов |
  | WorkloadGroupPrivs | Привилегии WorkloadGroup |

## Требования к управлению доступом {#access-control-requirements}

Пользователи, выполняющие эту SQL-команду, должны иметь как минимум следующие привилегии:

| Привилегия | Объект | Примечания                |
| :---------------- | :------------- | :---------------------------- |
| GRANT_PRIV        | Пользователь или роль    | Пользователь или роль должны иметь привилегию `GRANT_PRIV`, чтобы просматривать права всех пользователей; в противном случае можно просматривать только права текущего пользователя |

## Примечания по использованию {#usage-notes}
  - `SHOW ALL GRANTS` позволяет просматривать права всех пользователей, но для этого требуется привилегия `GRANT_PRIV`.
  - Если указан `user_identity`, просматриваются права указанного пользователя. `user_identity` должен быть создан командой `CREATE USER`.
  - Если `user_identity` не указан, просматриваются права текущего пользователя.
  - Doris реализует управление правами на основе модели RBAC (Role-Based Access Control). Поэтому отображаемые здесь права фактически представляют собой совокупность прав всех ролей, назначенных пользователю. Чтобы определить, какая именно роль предоставляет право, используйте команду [SHOW ROLES](./SHOW-ROLES.md).

1. Просмотр информации о правах всех пользователей.

   ```sql
   SHOW ALL GRANTS;
   ```

   ```text
   +--------------+---------+----------+----------+----------------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
   | UserIdentity | Comment | Password | Roles    | GlobalPrivs          | CatalogPrivs | DatabasePrivs                                                         | TablePrivs | ColPrivs | ResourcePrivs | WorkloadGroupPrivs |
   +--------------+---------+----------+----------+----------------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
   | 'root'@'%'   | ROOT    | No       | operator | Node_priv,Admin_priv | NULL         | internal.information_schema: Select_priv; internal.mysql: Select_priv | NULL       | NULL     | NULL          | normal: Usage_priv |
   | 'admin'@'%'  | ADMIN   | No       | admin    | Admin_priv           | NULL         | internal.information_schema: Select_priv; internal.mysql: Select_priv | NULL       | NULL     | NULL          | normal: Usage_priv |
   | 'jack'@'%'   |         | No       |          | NULL                 | NULL         | internal.information_schema: Select_priv; internal.mysql: Select_priv | NULL       | NULL     | NULL          | normal: Usage_priv |
   +--------------+---------+----------+----------+----------------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
   ```

2. Просмотр прав указанного пользователя

    ```sql
    SHOW GRANTS FOR jack@'%';
    ```

    ```text
    +--------------+---------+----------+-------+-------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
    | UserIdentity | Comment | Password | Roles | GlobalPrivs | CatalogPrivs | DatabasePrivs                                                         | TablePrivs | ColPrivs | ResourcePrivs | WorkloadGroupPrivs |
    +--------------+---------+----------+-------+-------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
    | 'jack'@'%'   |         | No       |       | NULL        | NULL         | internal.information_schema: Select_priv; internal.mysql: Select_priv | NULL       | NULL     | NULL          | normal: Usage_priv |
    +--------------+---------+----------+-------+-------------+--------------+-----------------------------------------------------------------------+------------+----------+---------------+--------------------+
    ```

3. Просмотр прав текущего пользователя

   ```sql
   SHOW GRANTS;
   ```
