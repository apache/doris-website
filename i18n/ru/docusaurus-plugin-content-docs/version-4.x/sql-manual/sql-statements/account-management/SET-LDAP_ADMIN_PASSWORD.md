## Описание {#description}

 Команда `SET LDAP_ADMIN_PASSWORD` используется для установки пароля администратора LDAP. При использовании аутентификации LDAP Doris требуется учётная запись и пароль администратора для отправки в службу LDAP запроса на получение сведений о пользователе, выполняющем вход.

## Синтаксис {#syntax}

```sql
 SET LDAP_ADMIN_PASSWORD = PASSWORD('<plain_password>')
```

## Обязательные параметры {#required-parameters}

**1. `<plain_password>`**

Пароль администратора LDAP

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Привилегия | Объект | Примечания                  |
| :--------------------- | :-------------- | :--------------------- |
| ADMIN_PRIV        | USER или ROLE    | Эту операцию могут выполнять только пользователи или роли с привилегией `ADMIN_PRIV` |

## Примеры {#examples}

- Установка пароля администратора LDAP
  ```sql
  SET LDAP_ADMIN_PASSWORD = PASSWORD('123456')
  ```
