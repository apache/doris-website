## Описание {#description}

Оператор `SHOW CREATE USER` используется для отображения оператора создания пользователя в системе управления базами данных. Он помогает администраторам эффективнее управлять учётными записями.

## Синтаксис {#syntax}

```sql
SHOW CREATE USER '<user_identity>'
```

## Возвращаемое значение {#return-value}

| Столбец         | Описание         |
|:------------|:------------|
| Идентификатор пользователя  | Указанный идентификатор пользователя |
| Оператор создания  | Оператор создания указанного пользователя |

## Требования к управлению доступом {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны обладать как минимум следующими правами:

| Право | Объект | Примечания                |
| :---------------- | :------------- | :---------------------------- |
| ADMIN_PRIV        | Пользователь или роль    | Операцию `SHOW CREATE USER` могут выполнять только пользователи или роли с правом `ADMIN_PRIV`. |
