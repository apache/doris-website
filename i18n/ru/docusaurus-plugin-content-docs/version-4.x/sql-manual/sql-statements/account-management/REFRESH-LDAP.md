## Описание {#description}

Этот оператор используется для обновления кэша данных LDAP в Doris. При изменении данных пользователей в службе LDAP или прав ролей, соответствующих группам пользователей LDAP в Doris, изменения могут вступать в силу не сразу из-за кэширования. Этот оператор позволяет обновить кэш.

## Синтаксис {#syntax}

```sql
REFRESH LDAP [ALL | FOR <user_name>];
```

## Необязательные параметры {#optional-parameters}

**1. `[ALL]`**

Указывает, нужно ли обновить кэш данных LDAP для всех пользователей.

**2. `<user_name>`**

Пользователь, для которого необходимо обновить кэш данных LDAP

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие привилегии:


| Привилегия | Объект | Примечания                 |
| :---------------- | :------------- | :---------------------------- |
| ADMIN_PRIV        | Пользователь или роль | Только пользователи или роли с правом `ADMIN_PRIV` могут обновлять кэш данных LDAP для всех пользователей. В противном случае можно обновить кэш данных LDAP только для текущего пользователя |

## Примечания по использованию {#usage-notes}

- По умолчанию срок действия кэша данных LDAP в Doris составляет 12 часов. Его можно посмотреть с помощью `SHOW FRONTEND CONFIG LIKE 'ldap_user_cache_timeout_s';`.
- `REFRESH LDAP ALL` обновляет кэш данных LDAP для всех пользователей, но требует права `ADMIN_PRIV`.
- Если указан `user_name`, обновляется кэш данных LDAP для указанного пользователя.
- Если `user_name` не указан, обновляется кэш данных LDAP для текущего пользователя.

## Примеры {#examples}

1. Обновление кэша данных всех пользователей LDAP.

    ```sql
    REFRESH LDAP ALL;
    ```

2. Обновление кэша данных текущего пользователя LDAP.

    ```sql
    REFRESH LDAP;
    ```

3. Обновление кэша данных указанного пользователя LDAP jack.

    ```sql
    REFRESH LDAP FOR jack;
    ```
