## Описание {#description}

Эта инструкция используется для просмотра свойств пользователя.

## Синтаксис {#syntax}

```sql
SHOW {ALL PROPERTIES | PROPERTY [FOR <user_name>]} [LIKE <key>]
```

## Необязательные параметры {#optional-parameters}
**1. `[ALL PROPERTIES]`**

   Определяет, следует ли отображать свойства всех пользователей.

**2. `<user_name>`**

   Просмотр свойств указанного пользователя. Если пользователь не указан, отображаются свойства текущего пользователя.

**3. `<key>`**

   Поддерживается нечёткий поиск по имени свойства.

## Возвращаемое значение {#return-value}
- Если в инструкции используется `PROPERTY`

   | Столбец | Описание |
   | -- | -- |
   | Key | Имя свойства |
   | Value | Значение свойства |

- Если в инструкции используется `PROPERTIES`

   | Столбец | Описание |
   | -- | -- |
   | User | Имя пользователя |
   | Properties | Каждое свойство `property` соответствующего пользователя в формате `key:value` |

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие права:

| Привилегия | Объект | Примечания                 |
| :---------------- | :------------- | :---------------------------- |
| GRANT_PRIV        | Пользователь или роль    | Для просмотра свойств всех пользователей пользователь или роль должны иметь разрешение `GRANT_PRIV`. Для просмотра свойств текущего пользователя с помощью `SHOW PROPERTY` разрешение `GRANT_PRIV` не требуется |

## Примечания по использованию {#usage-notes}
-  `SHOW ALL PROPERTIES` позволяет просмотреть свойства всех пользователей.
- Если указан параметр `user_name`, отображаются свойства указанного пользователя.
- Если параметр `user_name` не указан, отображаются свойства текущего пользователя.
- Для просмотра свойств текущего пользователя с помощью `SHOW PROPERTY` разрешение `GRANT_PRIV` не требуется.

## Примеры {#examples}

- Просмотр свойств пользователя jack

   ```sql
   SHOW PROPERTY FOR 'jack';
   ```
   ```text
   +-------------------------------------+--------+
   | Key                                 | Value  |
   +-------------------------------------+--------+
   | cpu_resource_limit                  | -1     |
   | default_load_cluster                |        |
   | default_workload_group              | normal |
   | exec_mem_limit                      | -1     |
   | insert_timeout                      | -1     |
   | max_query_instances                 | 3000   |
   | max_user_connections                | 1000   |
   | parallel_fragment_exec_instance_num | -1     |
   | query_timeout                       | -1     |
   | resource_tags                       |        |
   | sql_block_rules                     |        |
   +-------------------------------------+--------+
   ```

- Просмотр свойств пользователя jack, связанных с ограничениями

   ```sql
   SHOW PROPERTY FOR 'jack' LIKE '%limit%';
   ```

   ```text
   +--------------------+-------+
   | Key                | Value |
   +--------------------+-------+
   | cpu_resource_limit | -1    |
   | exec_mem_limit     | -1    |
   +--------------------+-------+
   ```

- Просмотр свойств всех пользователей, связанных с ограничениями

   ```sql
   SHOW ALL PROPERTIES LIKE '%limit%';
   ```

   ```text
   +-------+------------------------------------------------------------+
   | User  | Properties                                                 |
   +-------+------------------------------------------------------------+
   | root  | {
     "cpu_resource_limit": "-1",
     "exec_mem_limit": "-1"
   } |
   | admin | {
     "cpu_resource_limit": "-1",
     "exec_mem_limit": "-1"
   } |
   | jack  | {
     "cpu_resource_limit": "-1",
     "exec_mem_limit": "-1"
   } |
   +-------+------------------------------------------------------------+
   ```
