## Описание {#description}
Отображает настроенные правила блокировки SQL. Если имя правила не указано, отображаются все правила.

## Синтаксис {#syntax}
```sql
SHOW SQL_BLOCK_RULE [FOR <rule_name>];
```

## Необязательные параметры {#optional-parameters}

`<rule_name>`

Имя правила блокировки SQL, которое нужно отобразить. Если не указано, отображаются все правила.

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду, должны иметь следующие привилегии:

| Привилегия | Объект        | Примечания  |
|-----------|--------------|--------|
| `ADMIN`   | Пользователь или роль | Требуется для выполнения этой операции. |

## Примеры {#examples}

1. Отобразить все правила блокировки SQL  
```sql
SHOW SQL_BLOCK_RULE;
```

```text
+------------+------------------------------+---------+-------------+-----------+-------------+--------+--------+------------------------+
| Name       | Sql                          | SqlHash | PartitionNum | TabletNum | Cardinality | Global | Enable | RequirePartitionFilter |
+------------+------------------------------+---------+-------------+-----------+-------------+--------+--------+------------------------+
| test_rule  | select * from order_analysis | NULL    | 0           | 0         | 0           | true   | true   | false                  |
| test_rule2 | NULL                         | NULL    | 30          | 0         | 10000000000 | false  | true   | false                  |
+------------+------------------------------+---------+-------------+-----------+-------------+--------+--------+------------------------+
```

2. Отобразить конкретное правило блокировки SQL  
```sql
SHOW SQL_BLOCK_RULE FOR test_rule2;
```

```text
+------------+------+---------+-------------+-----------+-------------+--------+--------+------------------------+
| Name       | Sql  | SqlHash | PartitionNum | TabletNum | Cardinality | Global | Enable | RequirePartitionFilter |
+------------+------+---------+-------------+-----------+-------------+--------+--------+------------------------+
| test_rule2 | NULL | NULL    | 30          | 0         | 10000000000 | false  | true   | false                  |
+------------+------+---------+-------------+-----------+-------------+--------+--------+------------------------+
```
