## Описание {#description}

Удаляет одно или несколько правил блокировки SQL. Можно удалить несколько правил одновременно, перечислив их через запятую.

## Синтаксис {#syntax}

```sql
DROP SQL_BLOCK_RULE <rule_name>[, ...]
```

## Обязательные параметры {#required-parameters}

<rule_name>
Имя правила блокировки SQL, которое нужно удалить. Можно указать несколько имён правил через запятую. 

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту SQL-команду, должны обладать как минимум следующими привилегиями:
| Привилегия | Объект | Примечания                |
| :---------------- | :------------- | :---------------------------- |
| ADMIN        | Пользователь или роль   | Операцию DROP могут выполнять только пользователи или роли с привилегией ADMIN. |


## Пример {#example}

Удаление правил блокировки `test_rule1` и `test_rule2`

```sql
DROP SQL_BLOCK_RULE test_rule1, test_rule2;
```
