## Описание {#description}

Просмотр политик безопасности на уровне строк. Подробнее о политиках безопасности на уровне строк см. в главе «Политики безопасности»

## Синтаксис {#syntax}

```sql
SHOW ROW POLICY [ FOR { <user_name> | ROLE <role_name> } ];
```
## Необязательные параметры {#optional-parameters}

**<user_name>**

> Имя пользователя

**<role_name>**

> Имя роли

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие привилегии:

| Привилегия | Объект | Примечания |
| :--------- | :----- | :---- |
| ADMIN_PRIV | Глобальный уровень |       |

## Примеры {#examples}

1. Просмотр всех политик безопасности


  ```sql
  SHOW ROW POLICY;
  ```

1. Запрос с указанием имени пользователя

  ```sql
  SHOW ROW POLICY FOR user1;
  ```

1. Запрос с указанием имени роли

  ```sql
  SHOW ROW POLICY for role role1;
  ```
