## Описание {#description}

Этот оператор используется для приостановки запуска заданий материализованных представлений по расписанию

## Синтаксис {#syntax}

```sql
PAUSE MATERIALIZED VIEW JOB ON <mv_name>
```

## Обязательные параметры {#required-parameters}
**1. `<mv_name>`**
> Задаёт имя материализованного представления.
>
> Имя материализованного представления должно начинаться с буквы (или символа любого языка, если включена поддержка имён unicode) и не может содержать пробелы или специальные символы, если только вся строка имени материализованного представления не заключена в обратные кавычки (например, `My Object`).
>
> В качестве имени материализованного представления нельзя использовать зарезервированные ключевые слова.
>
> Подробности см. в разделе «Зарезервированные ключевые слова».


## Требования к правам доступа {#access-control-requirements}
Пользователи, выполняющие эту команду SQL, должны обладать как минимум следующими привилегиями:

| Привилегия | Объект | Примечания |
| :--------- | :----- | :------------------------------------------- |
| ALTER_PRIV | Материализованное представление | PAUSE выполняет операцию ALTER над материализованным представлением |


## Примечания по использованию {#usage-notes}

- После выполнения этого оператора можно возобновить запуск заданий с помощью оператора RESUME для материализованного представления.


## Пример {#example}

- Приостановка запуска заданий материализованного представления mv1 по расписанию

    ```sql
    PAUSE MATERIALIZED VIEW JOB ON mv1;
    ```
