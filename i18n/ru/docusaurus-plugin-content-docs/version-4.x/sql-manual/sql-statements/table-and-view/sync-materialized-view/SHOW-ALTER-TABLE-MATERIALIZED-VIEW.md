## Описание {#description}

Проверка состояния задачи построения синхронного материализованного представления.

Поскольку создание синхронного материализованного представления является асинхронной операцией, после отправки задачи на создание материализованного представления пользователям необходимо асинхронно проверять состояние построения синхронного материализованного представления с помощью команды.

## Синтаксис {#syntax}


```sql
SHOW ALTER TABLE MATERIALIZED VIEW FROM <database>
```

## Обязательные параметры {#required-parameters}

**1. `<database>`**

> База данных, к которой принадлежит базовая таблица синхронного материализованного представления.

## Права доступа {#permissions}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права доступа:

| Право доступа | Объект | Примечания                                                   |
| ---------- | ------ | ------------------------------------------------------------ |
| ALTER_PRIV | Таблица | Требуется право ALTER_PRIV для таблицы, к которой относится текущее материализованное представление |

## Пример {#example}

```sql
SHOW ALTER TABLE MATERIALIZED VIEW FROM doc_db;
```
