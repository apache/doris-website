## Описание {#description}

Просмотр оператора создания материализованного представления.

## Синтаксис {#syntax}

```sql
SHOW CREATE MATERIALIZED VIEW <materialized_view_name> ON <table_name>
```

## Обязательные параметры {#required-parameters}

**1. `<materialized_view_name>`**

> Имя материализованного представления.

**2. `<table_name>`**

> Таблица, которой принадлежит материализованное представление.

## Возвращаемые значения {#return-values}

|Имя столбца | Описание   |
| -- |------|
| TableName | Имя таблицы   |
| ViewName | Имя материализованного представления |
| CreateStmt | Оператор создания материализованного представления |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право | Объект | Примечания                                                        |
| --------- | ------ | ------------------------------------------------------------ |
| SELECT_PRIV/LOAD_PRIV/ALTER_PRIV/CREATE_PRIV/DROP_PRIV | Таблица  | Необходимо иметь права на таблицу, которой принадлежит текущее материализованное представление |

## Примеры {#examples}

1. Просмотр оператора создания синхронного материализованного представления

   ```sql
   SHOW CREATE MATERIALIZED VIEW sync_agg_mv on lineitem;
   ```
