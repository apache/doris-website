## Описание {#description}

Удаление синхронного материализованного представления.

## Синтаксис {#syntax}


```sql
DROP MATERIALIZED VIEW 
[ IF EXISTS ] <materialized_view_name>
ON <table_name>
```

## Обязательные параметры {#required-parameters}

**1. `<materialized_view_name>`**

> Имя удаляемого материализованного представления.

**2. `<table_name>`**

> Таблица, которой принадлежит материализованное представление.

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать как минимум следующими правами:

| Привилегия | Объект | Примечания                                                   |
| ---------- | ------ | ------------------------------------------------------------ |
| ALTER_PRIV | Таблица | Требуется право ALTER_PRIV на таблицу, которой принадлежит удаляемое материализованное представление |

## Пример {#example}

Удаление синхронного материализованного представления `sync_agg_mv` для таблицы `lineitem`


```sql
DROP MATERIALIZED VIEW sync_agg_mv on lineitem;
```
