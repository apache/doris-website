## Описание {#description}

Этот оператор используется для изменения определения логического представления.

## Синтаксис {#syntax}

```sql
ALTER VIEW [<db_name>.]<view_name> 
 [(<column_definition>)]
AS <query_stmt>
```

Где:
```sql
column_definition:
    <column_name> [COMMENT '<comment>'] [,...]
```

## Обязательные параметры {#required-parameters}

**1. `<view_name>`**
> Идентификатор (то есть имя) изменяемого представления.

**2. `<query_stmt>`**
> Запрос SELECT, определяющий представление.

## Необязательные параметры {#optional-parameters}

**1. `<db_name>`**
> Имя базы данных, в которой находится представление. Если не указано, по умолчанию используется текущая база данных.

**2. `<column_definition>`**
> Определения столбцов представления.  
> Где:  
> **1. `<column_name>`**  
> Имя столбца.  
> **2. `<comment>`**  
> Комментарий к столбцу.

## Требования к правам доступа {#access-control-requirements}

| Право доступа | Объект   | Примечания                                                            |
|---------------|----------|-----------------------------------------------------------------------|
| ALTER_PRIV   | Представление | Для изменяемого представления требуется право доступа ALTER_PRIV. |
| SELECT_PRIV  | Таблица, представление | Для таблиц, представлений или материализованных представлений, к которым выполняется запрос, требуется право доступа SELECT_PRIV. |

## Пример {#example}

1. Изменение представления `example_view` в базе данных `example_db`

  ```sql
  ALTER VIEW example_db.example_view
  (
    c1 COMMENT "column 1",
    c2 COMMENT "column 2",
    c3 COMMENT "column 3"
  )
  AS SELECT k1, k2, SUM(v1) FROM example_table 
  GROUP BY k1, k2
  ```
