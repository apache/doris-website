## Описание {#description}

Удаляет представление в текущей или указанной базе данных.

## Синтаксис {#syntax}

```sql
DROP VIEW [ IF EXISTS ] <name>
```
## Обязательные параметры {#required-parameters}

Имя представления, которое нужно удалить.

## Необязательные параметры {#optional-parameters}

**[ IF EXISTS ]**

Если указан этот параметр, при отсутствии представления ошибка не возникает, а операция удаления пропускается.

## Примечания по использованию {#usage-notes}

Удалённые представления нельзя восстановить, их необходимо создать заново.

## Примеры {#examples}

```sql
CREATE VIEW vtest AS SELECT 1, 'test';
DROP VIEW IF EXISTS vtest;
```
