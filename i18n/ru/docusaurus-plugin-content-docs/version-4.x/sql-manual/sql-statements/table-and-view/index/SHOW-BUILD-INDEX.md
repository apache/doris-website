## Описание {#description}

Просмотр состояния задач построения индексов.

## Синтаксис {#syntax}

```sql
SHOW BUILD INDEX [ (FROM | IN) <database_name>
[ where_clause ] [ sort_clause ] [ limit_clause ] ] 
```

Где:

```sql
where_clause
  : WHERE <output_column_name = value>
```

Где:

```sql
sort_clause
  :
   ORDER BY <output_column_name>
```

Где:

```sql
limit_clause
  :
   LIMIT <n>
```
## Необязательные параметры {#optional-parameters}

**`<database_name>`**

> Задаёт идентификатор (имя) базы данных, который должен быть уникальным в пределах её кластера.
>
> Идентификатор должен начинаться с буквы (или символа любого языка, если включена поддержка имён Unicode) и не может содержать пробелы или специальные символы, если вся строка идентификатора не заключена в обратные кавычки (например, `My Object`).
>
> В качестве идентификаторов нельзя использовать зарезервированные ключевые слова.
>
> Подробнее см. разделы «Требования к идентификаторам» и «Зарезервированные ключевые слова».


**`<WHERE output_column_name = value>`**

> Задаёт условие фильтрации результатов, при этом output_column_name должен входить в список выходных полей.

**`<ORDER BY output_column_name>`**

> Задаёт столбец для сортировки результатов, при этом output_column_name должен входить в список выходных полей.

**`LIMIT <n>`**

> Задаёт ограничение на количество выводимых строк, при этом n должно быть числом.

## Примечания по использованию {#usage-notes}

- В настоящее время команда применима только к инвертированным индексам и не применима к другим индексам, например к индексу bloomfilter.
- В настоящее время команда применима только в режиме с совмещённым хранением и вычислениями и не применима в режиме с разделением хранения и вычислений.

## Примеры {#examples}

- Просмотр всех задач построения индексов

  ```sql
  SHOW BUILD INDEX
  ```

- Просмотр задач построения индексов для базы данных database1

  ```sql
  SHOW BUILD INDEX FROM database1
  ```

- Просмотр задач построения индексов для таблицы table1

  ```sql
  SHOW BUILD INDEX WHERE TableName = 'table1'
  ```

- Просмотр задач построения индексов для таблицы table1 с сортировкой по JobId и выводом первых 10 строк

  ```sql
  SHOW BUILD INDEX WHERE TableName = 'table1' ORDER BY JobId LIMIT 10
  ```
