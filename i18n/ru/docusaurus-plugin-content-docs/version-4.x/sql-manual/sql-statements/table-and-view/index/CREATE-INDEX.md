## Описание {#description}

Создаёт новый индекс для таблицы. Необходимо указать имя таблицы и имя индекса. При необходимости можно указать тип индекса, свойства и комментарий.

## Синтаксис {#syntax}


```sql
CREATE INDEX [IF NOT EXISTS] <index_name>
             ON <table_name> (<column_name> [, ...])
             [USING {INVERTED | NGRAM_BF | ANN}]
             [PROPERTIES ("<key>" = "<value>"[ , ...])]
             [COMMENT '<index_comment>']
```

## Обязательные параметры {#required-parameters}

**1. `<index_name>`**

> Указывает идентификатор (то есть имя) индекса, который должен быть уникальным в пределах таблицы.
>
> Идентификатор должен начинаться с буквы (если включена поддержка имён Unicode, он может начинаться с любого символа любого языка) и не может содержать пробелы или специальные символы, если вся строка идентификатора не заключена в обратные кавычки (например, `My Object`).
>
> Идентификатор не может быть зарезервированным ключевым словом.
>
> Подробнее см. требования к идентификаторам и зарезервированным ключевым словам.

**2. `<table_name>`**

> Указывает идентификатор (то есть имя) таблицы, который должен быть уникальным в пределах базы данных.
>
> Идентификатор должен начинаться с буквы (если включена поддержка имён Unicode, он может начинаться с любого символа любого языка) и не может содержать пробелы или специальные символы, если вся строка идентификатора не заключена в обратные кавычки (например, `My Object`).
>
> Идентификатор не может быть зарезервированным ключевым словом.
>
> Подробнее см. требования к идентификаторам и зарезервированным ключевым словам.

**3. `<column_name> [, ...]`**

> Указывает столбцы, для которых создаётся индекс (в настоящее время поддерживается только один столбец); столбец должен быть уникальным в пределах таблицы.
>
> Идентификатор должен начинаться с буквы (если включена поддержка имён Unicode, он может начинаться с любого символа любого языка) и не может содержать пробелы или специальные символы, если вся строка идентификатора не заключена в обратные кавычки (например, `My Object`).
>
> Идентификатор не может быть зарезервированным ключевым словом.
>
> Подробнее см. требования к идентификаторам и зарезервированным ключевым словам.

## Необязательные параметры {#optional-parameters}

**1. `USING {INVERTED | NGRAM_BF}`**

> Задаёт тип индекса. В настоящее время поддерживаются два типа: **INVERTED** (инвертированный индекс) и **NGRAM_BF** (индекс ngram bloomfilter).

**2. `PROPERTIES ("<key>" = "<value>"[ ,  ...])`**

> Задаёт параметры индекса в общем формате PROPERTIES. Параметры и семантику, поддерживаемые каждым индексом, см. в документации для конкретного типа индекса.

**3. `COMMENT '<index_comment>'`**

> Задаёт комментарий к индексу для упрощения обслуживания.

## Примечания по использованию {#usage-notes}

- Для обычного индекса **INVERTED** сведения об индексации исторических данных см. в разделе [Управление инвертированными индексами](../../../../table-design/index/inverted-index/overview.md#managing-inverted-indexes).
- Начиная с Doris 4.2, используйте `variant_index_scope = "values"`, чтобы [добавить индекс значений VARIANT в существующую таблицу](../../../../table-design/index/inverted-index/variant-values-index.md#add-to-existing-table). Пока индекс отсутствует, запросы могут сканировать исторические данные.
- После создания индекс **NGRAM_BF** NGram BloomFilter в фоновом режиме выполняет schema change для всех данных, чтобы завершить построение индекса. Проверить ход выполнения можно с помощью SHOW ALTER TABLE COLUMN.

## Примеры {#examples}

- Создайте инвертированный индекс `index1` в `table1`



  ```sql
  CREATE INDEX index1 ON table1(col1) USING INVERTED;
  ```

- Создайте индекс NGram BloomFilter `index2` в `table1`



  ```sql
  CREATE INDEX index2 ON table1(col1) USING NGRAM_BF PROPERTIES("gram_size"="3", "bf_size"="1024");
  ```


- Создайте индекс ANN `index3` в `table1` для векторного столбца (`embedding`).


  ```sql
  CREATE INDEX index3 ON table1 (`embedding`) USING ANN PROPERTIES(
    "index_type"="hnsw",
    "metric_type"="l2_distance",
    "dim"="128"
  );
    ```
