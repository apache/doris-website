## Описание {#description}

Этот оператор выводит сведения о tablet и таблицах, которым они принадлежат.

## Синтаксис {#syntax}

```sql
SHOW TABLETS BELONG <tablet_id> [, <tablet_id>]...;
```

## Обязательные параметры {#required-parameters}

**1. `<tablet_id>`**

> Один или несколько идентификаторов tablet, разделённых запятыми. Повторяющиеся идентификаторы в результате удаляются.

## Возвращаемое значение {#return-value}

При использовании `SHOW TABLETS BELONG <tablet_id> [, <tablet_id>]...` возвращаются следующие столбцы:

| Столбец       | Тип данных | Описание                                                               |
|---------------|------------|------------------------------------------------------------------------|
| DbName        | String     | Имя базы данных, содержащей tablet.                                     |
| TableName     | String     | Имя таблицы, содержащей tablet.                                         |
| TableSize     | String     | Размер таблицы (например, "8.649 KB").                                   |
| PartitionNum  | Int        | Количество разделов в таблице.                                          |
| BucketNum     | Int        | Количество бакетов в таблице.                                          |
| ReplicaCount  | Int        | Количество реплик в таблице.                                            |
| TabletIds     | Array      | Список идентификаторов tablet, принадлежащих таблице.                    |

## Требования к управлению доступом {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие привилегии:

| Привилегия | Объект      | Примечания                                                                                                                        |
|:-----------|:------------|:----------------------------------------------------------------------------------------------------------------------------------|
| Admin_priv | База данных | Требуется для выполнения административных операций с базой данных, включая управление таблицами, разделами и команды системного уровня. |

## Примеры {#examples}

Вывести сведения об определённом tablet:

```sql
SHOW TABLETS BELONG 10145;
```

```text
+--------+-----------+-----------+--------------+-----------+--------------+-----------+
| DbName | TableName | TableSize | PartitionNum | BucketNum | ReplicaCount | TabletIds |
+--------+-----------+-----------+--------------+-----------+--------------+-----------+
| test   | sell_user | 8.649 KB  | 1            | 4         | 4            | [10145]   |
+--------+-----------+-----------+--------------+-----------+--------------+-----------+
```

Вывести сведения о нескольких tablet:

```sql
SHOW TABLETS BELONG 27028,78880,78382,27028;
```

```text
+---------------------+-----------+-----------+--------------+-----------+--------------+----------------+
| DbName              | TableName | TableSize | PartitionNum | BucketNum | ReplicaCount | TabletIds      |
+---------------------+-----------+-----------+--------------+-----------+--------------+----------------+
| default_cluster:db1 | kec       | 613.000 B | 379          | 604       | 604          | [78880, 78382] |
| default_cluster:db1 | test      | 1.874 KB  | 1            | 1         | 1            | [27028]        |
+---------------------+-----------+-----------+--------------+-----------+--------------+----------------+
```
