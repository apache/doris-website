## Описание {#description}

Оператор `SHOW DATA SKEW` используется для просмотра неравномерности распределения данных в таблице или партиции. Этот оператор предоставляет следующие возможности:

- Позволяет просматривать распределение данных во всей таблице.
- Позволяет просматривать распределение данных в указанных партициях.
- Показывает количество строк, объём данных и процентную долю для каждого бакета.
- Поддерживает таблицы с партициями и без них.

## Синтаксис {#syntax}

```sql
SHOW DATA SKEW FROM [<db_name>.]<table_name> [ PARTITION (<partition_name> [, ...]) ];
```

## Обязательные параметры {#required-parameters}

**1. `FROM [<db_name>.]<table_name>`**

> Задаёт имя таблицы для просмотра. Можно указать имя базы данных.
>
> Имя таблицы должно быть уникальным в пределах её базы данных.

## Необязательные параметры {#optional-parameters}

**1. `PARTITION (<partition_name> [, ...])`**

> Задаёт список имён партиций для просмотра.
>
> Если этот параметр не указан, отображается распределение данных для всех партиций таблицы.
>
> Для таблиц без партиционирования имя партиции совпадает с именем таблицы.

## Возвращаемые значения {#return-values}

| Имя столбца      | Описание                          |
|------------------|--------------------------------------|
| PartitionName    | Имя партиции                       |
| BucketIdx        | Индекс бакета                  |
| AvgRowCount      | Среднее количество строк                    |
| AvgDataSize      | Средний размер данных (в байтах)        |
| Graph            | Диаграмма распределения данных |
| Percent          | Доля объёма данных этого бакета в общем объёме данных, в процентах |

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие права:

| Право       | Объект      | Примечания                                         |
| :-------------- | :---------- | :-------------------------------------------- |
| SELECT          | Таблица       | Для просмотра таблицы требуется право SELECT. |

## Примечания по использованию {#usage-notes}

- Распределение данных отображается по двум измерениям: партициям и бакетам.
- В столбце Graph символ `>` используется для наглядного представления доли данных.
- Процентные значения указываются с точностью до двух знаков после запятой.
- Для таблиц без партиционирования имя партиции в результате запроса совпадает с именем таблицы.

## Примеры {#examples}

- Создание таблицы с партициями и просмотр распределения её данных:

    ```sql
    CREATE TABLE test_show_data_skew
    (
        id int,
        name string,
        pdate date
    )
    PARTITION BY RANGE(pdate)
    (
        FROM ("2023-04-16") TO ("2023-04-20") INTERVAL 1 DAY
    )
    DISTRIBUTED BY HASH(id) BUCKETS 5
    PROPERTIES (
        "replication_num" = "1"
    );
    ```
