## Описание {#description}

Эта инструкция позволяет просмотреть объём пространства, занимаемого мусорными данными на узлах BE.

## Синтаксис {#syntax}

```sql
SHOW TRASH [ON ("<be_host>:<be_heartbeat_port>" [, ...])];
```

## Необязательные параметры {#optional-parameters}

**1. `[ON ("<be_host>:<be_heartbeat_port>" [, ...])]`**

Укажите узел BE, информацию о котором нужно просмотреть. Если ON не указан, по умолчанию отображаются все узлы BE.


## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие права:


| Право доступа | Объект | Примечания |
| :--------- | :----- | :------------------------------------------- |
| ADMIN_PRIV или NODE_PRIV | Пользователь или роль | Только пользователи или роли с правом ADMIN_PRIV или NODE_PRIV могут выполнять операцию SHOW TRASH. |


## Примеры {#examples}

1. Просмотр объёма пространства, занимаемого мусорными данными на всех узлах BE.


```sql
SHOW TRASH;
```

2. Просмотр объёма пространства, занимаемого мусорными данными на узле '192.168.0.1:9050' (отображается информация о диске).


```sql
SHOW TRASH ON "192.168.0.1:9050";
```
