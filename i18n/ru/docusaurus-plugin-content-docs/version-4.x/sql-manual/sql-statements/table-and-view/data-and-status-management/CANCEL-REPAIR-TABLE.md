## Описание {#description}

Оператор `CANCEL REPAIR TABLE` используется для отмены восстановления с высоким приоритетом для указанной таблицы или раздела. Этот оператор обладает следующими возможностями:

- Позволяет отменить восстановление с высоким приоритетом для всей таблицы.
- Позволяет отменить восстановление с высоким приоритетом для указанных разделов.
- Не влияет на стандартный механизм восстановления реплик в системе.

## Синтаксис {#syntax}

```sql
ADMIN CANCEL REPAIR TABLE <table_name> [ PARTITION (<partition_name> [, ...]) ];
```

## Обязательные параметры {#required-parameters}

**1. `<table_name>`**

> Указывает имя таблицы, для которой требуется отменить восстановление.
>
> Имя таблицы должно быть уникальным в пределах её базы данных.

## Необязательные параметры {#optional-parameters}

**1. `PARTITION (<partition_name> [, ...])`**

> Указывает список имён разделов, для которых требуется отменить восстановление.
>
> Если этот параметр не указан, восстановление с высоким приоритетом будет отменено для всей таблицы.

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту SQL-команду, должны иметь как минимум следующие права:

| Привилегия      | Объект      | Примечания                                    |
| :-------------- | :---------- | :-------------------------------------------- |
| ADMIN           | Система     | Для выполнения этой команды пользователь должен обладать привилегиями ADMIN. |

## Примечания по использованию {#usage-notes}

- Этот оператор отменяет только восстановление с высоким приоритетом и не останавливает стандартный механизм восстановления реплик в системе.
- После отмены система продолжит восстанавливать реплики, используя стандартный способ планирования.
- Если необходимо снова назначить восстановлению высокий приоритет, можно использовать команду `ADMIN REPAIR TABLE`.
- Команда вступает в силу сразу после выполнения.

## Примеры {#examples}

- Отмена восстановления с высоким приоритетом для всей таблицы:

    ```sql
    ADMIN CANCEL REPAIR TABLE tbl;
    ```

- Отмена восстановления с высоким приоритетом для указанных разделов:

    ```sql
    ADMIN CANCEL REPAIR TABLE tbl PARTITION(p1, p2);
    ```
