## Описание {#description}

Эта инструкция используется для выполнения указанной операции проверки над набором tablet.

## Синтаксис {#syntax}

```sql
ADMIN CHECK TABLET ( <tablet_id> [,...] ) PROPERTIES("type" = "<type_value>")
```

## Обязательные параметры {#required-parameters}

**1. `<tablet_id>`**

Идентификатор tablet, для которого будет выполнена указанная операция проверки.


## Необязательные параметры {#optional-parameters}

**1. `<type_value>`**

В настоящее время поддерживается только consistency.

- consistency:

  Проверяет согласованность данных реплик tablet. Эта команда выполняется асинхронно: после её отправки Doris запускает задачу проверки согласованности для соответствующего tablet.

## Возвращаемое значение {#return-value}

Итоговый результат выполнения инструкции отображается в столбце InconsistentNum результата команды `SHOW PROC "/cluster_health/tablet_health";`.

| Столбец         | Тип данных | Примечание                           |
|-----------------|----------|--------------------------------------|
| InconsistentNum | Int      | Количество tablet с несогласованными данными |


## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие привилегии:

| Привилегия | Объект   | Примечания                                                                                                                       |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------|
| Admin_priv | База данных | Требуется для выполнения административных операций с базой данных, включая управление таблицами и разделами, а также выполнение команд системного уровня. |

## Примеры {#examples}
- Проверка согласованности данных реплик для указанного набора tablet

  ```sql
  admin check tablet (10000, 10001) PROPERTIES("type" = "consistency");
  ```
