## Описание {#description}

Оператор `REBALANCE DISK` используется для оптимизации распределения данных на узлах Backend (BE). Он предоставляет следующие возможности:

- Балансировка данных на указанных узлах BE.
- Балансировка данных на всех узлах BE кластера.
- Приоритетная балансировка данных указанных узлов независимо от того, насколько сбалансирован кластер в целом.

## Синтаксис {#syntax}

```sql
ADMIN REBALANCE DISK [ ON ( "<host>:<port>" [, ... ] ) ];
```

## Необязательные параметры {#optional-parameters}

**1. `"<host>:<port>"`**

> Задаёт список узлов BE, на которых необходимо выполнить балансировку.
>
> Каждый узел задаётся именем хоста (или IP-адресом) и портом heartbeat.
>
> Если этот параметр не указан, балансировка выполняется на всех узлах BE.

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие права:

| Привилегия      | Объект      | Примечания                                    |
| :-------------- | :---------- | :-------------------------------------------- |
| ADMIN           | Система     | Для выполнения этой команды пользователь должен иметь привилегию ADMIN. |

## Примечания по использованию {#usage-notes}

- По умолчанию срок действия этой команды составляет 24 часа. По истечении этого времени система перестанет отдавать приоритет балансировке данных на дисках указанных узлов BE. Чтобы продолжить балансировку, необходимо выполнить команду повторно.
- После завершения балансировки данных на дисках указанного узла BE настройка высокого приоритета для этого узла автоматически перестаёт действовать.
- Эту команду можно выполнять, даже если кластер находится в несбалансированном состоянии.

## Примеры {#examples}

- Сбалансировать данные на всех узлах BE кластера:

```sql
ADMIN REBALANCE DISK;
```

- Сбалансировать данные на двух указанных узлах BE:

```sql
ADMIN REBALANCE DISK ON ("192.168.1.1:1234", "192.168.1.2:1234");
```
