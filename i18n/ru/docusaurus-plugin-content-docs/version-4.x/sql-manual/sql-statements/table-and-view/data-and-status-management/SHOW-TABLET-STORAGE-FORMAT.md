## Описание {#description}

Эта инструкция используется для вывода информации о формате хранения на Backend.

## Синтаксис {#syntax}

```sql
SHOW TABLET STORAGE FORMAT [VERBOSE]
```


## Необязательные параметры {#optional-parameters}

** 1. `VERBOSE` **

  Выводит более подробную информацию.

## Возвращаемое значение {#return-value}

**Вывод по умолчанию** (без `VERBOSE`):

| Столбец   | Тип данных | Примечание                                                           |
|-----------|----------|----------------------------------------------------------------------|
| BackendId | Int      | ID узла BE (Backend), на котором расположена реплика таблета. |
| V1Count   | Int      | Количество таблетов версии V1.                                        |
| V2Count   | Int      | Количество таблетов версии V2.                                        |

**С `VERBOSE`**:

| Столбец       | Тип данных | Примечание                                                           |
|---------------|----------|----------------------------------------------------------------------|
| BackendId     | Int      | ID узла BE (Backend), на котором расположена реплика таблета. |
| TabletId      | Int      | Уникальный идентификатор таблета.                                     |
| StorageFormat | String   | Версия таблета: V1 или V2.                                            |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право      | Объект   | Примечания                                                                                                                       |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------|
| Admin_priv | База данных | Необходимо для выполнения административных операций с базой данных, включая управление таблицами, разделами и выполнение команд системного уровня. |

## Примеры {#examples}

- Выполните инструкцию без параметра verbose

  ```sql
  show tablet storage format;
  ```

  ```text
  +-----------+---------+---------+
  | BackendId | V1Count | V2Count |
  +-----------+---------+---------+
  | 10002     | 0       | 2867    |
  +-----------+---------+---------+
  ```

- Выполните инструкцию с параметром verbose

  ```sql
  show tablet storage format verbose;
  ```

  ```text
  +-----------+----------+---------------+
  | BackendId | TabletId | StorageFormat |
  +-----------+----------+---------------+
  | 10002     | 39227    | V2            |
  | 10002     | 39221    | V2            |
  | 10002     | 39215    | V2            |
  | 10002     | 39199    | V2            |
  +-----------+----------+---------------+
  ```
