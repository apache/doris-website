## Описание {#description}

Инструкция `SHOW DATA` используется для отображения информации об объёме данных, количестве реплик и статистике по строкам. Эта инструкция предоставляет следующие возможности:

- Отображение объёма данных и количества реплик для всех таблиц в текущей базе данных.
- Отображение объёма данных, количества реплик и статистики по строкам для материализованных представлений указанной таблицы.
- Отображение использования квоты базы данных.
- Сортировка по объёму данных, количеству реплик и другим столбцам.

## Синтаксис {#syntax}

```sql
SHOW DATA [ FROM [<db_name>.]<table_name> ] [ ORDER BY <order_by_clause> ];
```

Где:

```sql
order_by_clause:
    <column_name> [ ASC | DESC ] [ , <column_name> [ ASC | DESC ] ... ]
```

## Необязательные параметры {#optional-parameters}

**1. `FROM [<db_name>.]<table_name>`**

> Указывает имя таблицы для просмотра. Можно также указать имя базы данных.
>
> Если этот параметр не указан, отображается информация о данных всех таблиц в текущей базе данных.

**2. `ORDER BY <order_by_clause>`**

> Указывает способ сортировки результирующего набора.
>
> Можно выполнить сортировку по любому столбцу в порядке возрастания (ASC) или убывания (DESC).
>
> Поддерживается сортировка по нескольким столбцам.

## Возвращаемые значения {#return-values}

В зависимости от сценария запроса возвращаются следующие результирующие наборы:

- Если предложение `FROM` не указано (отображается информация на уровне базы данных):

| Имя столбца      | Описание                          |
|------------------|--------------------------------------|
| DbId             | Идентификатор базы данных                          |
| DbName           | Имя базы данных                        |
| Size             | Общий объём данных базы данных    |
| RemoteSize       | Объём данных в удалённом хранилище           |
| RecycleSize      | Объём данных в корзине              |
| RecycleRemoteSize| Объём данных корзины в удалённом хранилище    |

- Если предложение `FROM` указано (отображается информация на уровне таблицы):

| Имя столбца      | Описание                          |
|------------------|--------------------------------------|
| TableName        | Имя таблицы                           |
| IndexName        | Имя индекса (материализованного представления)      |
| Size             | Размер данных                            |
| ReplicaCount     | Количество реплик                        |
| RowCount         | Статистика по строкам (отображается только при просмотре конкретной таблицы) |

## Требования к управлению доступом {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие права:

| Привилегия       | Объект      | Примечания                                         |
| :-------------- | :---------- | :-------------------------------------------- |
| SELECT          | Таблица       | Для просмотра таблицы требуется привилегия SELECT. |

## Примечания по использованию {#usage-notes}

- Статистика объёма данных включает общий объём данных всех реплик.
- При подсчёте реплик учитываются все партиции и реплики всех материализованных представлений таблицы.
- При подсчёте строк учитывается максимальное количество строк среди нескольких реплик.
- Строка `Total` в результирующем наборе содержит агрегированные данные.
- Строка `Quota` в результирующем наборе показывает текущую квоту, установленную для базы данных.
- Строка `Left` в результирующем наборе показывает оставшуюся квоту.
- Для просмотра размера каждой партиции используйте команду `SHOW PARTITIONS`.

## Примеры {#examples}

- Отобразить информацию об объёме данных для всех баз данных:

    ```sql
    SHOW DATA;
    ```

    ```
    +-------+-----------------------------------+--------+------------+-------------+-------------------+
    | DbId  | DbName                            | Size   | RemoteSize | RecycleSize | RecycleRemoteSize |
    +-------+-----------------------------------+--------+------------+-------------+-------------------+
    | 21009 | db1                               | 0      | 0          | 0           | 0                 |
    | 22011 | regression_test_inverted_index_p0 | 72764  | 0          | 0           | 0                 |
    | Total | NULL                              | 118946 | 0          | 0           | 0                 |
    +-------+-----------------------------------+--------+------------+-------------+-------------------+
    ```

- Отобразить информацию об объёме данных для всех таблиц в текущей базе данных:

    ```sql
    USE db1;
    SHOW DATA;
    ```

    ```text
    +-----------+-------------+--------------+
    | TableName | Size        | ReplicaCount |
    +-----------+-------------+--------------+
    | tbl1      | 900.000 B   | 6            |
    | tbl2      | 500.000 B   | 3            |
    | Total     | 1.400 KB    | 9            |
    | Quota     | 1024.000 GB | 1073741824   |
    | Left      | 1021.921 GB | 1073741815   |
    +-----------+-------------+--------------+
    ```

- Отобразить подробную информацию об объёме данных для указанной таблицы:

    ```sql
    SHOW DATA FROM example_db.test;
    ```

    ```text
    +-----------+-----------+-----------+--------------+----------+
    | TableName | IndexName | Size      | ReplicaCount | RowCount |
    +-----------+-----------+-----------+--------------+----------+
    | test      | r1        | 10.000MB  | 30           | 10000    |
    |           | r2        | 20.000MB  | 30           | 20000    |
    |           | test2     | 50.000MB  | 30           | 50000    |
    |           | Total     | 80.000MB  | 90           |          |
    +-----------+-----------+-----------+--------------+----------+
    ```

- Отсортировать по количеству реплик в порядке убывания и по объёму данных в порядке возрастания:

    ```sql
    SHOW DATA ORDER BY ReplicaCount DESC, Size ASC;
    ```

    ```text
    +-----------+-------------+--------------+
    | TableName | Size        | ReplicaCount |
    +-----------+-------------+--------------+
    | table_c   | 3.102 KB    | 40           |
    | table_d   | .000        | 20           |
    | table_b   | 324.000 B   | 20           |
    | table_a   | 1.266 KB    | 10           |
    | Total     | 4.684 KB    | 90           |
    | Quota     | 1024.000 GB | 1073741824   |
    | Left      | 1024.000 GB | 1073741734   |
    +-----------+-------------+--------------+
   ```
