## Описание {#description}

Эта команда выводит инструкцию создания таблицы данных.

## Синтаксис {#syntax}

```sql
SHOW [BRIEF] CREATE TABLE [<db_name>.]<table_name>
```

## Обязательные параметры {#required-parameters}
**1.`<table_name>`**
> Задаёт идентификатор (имя) таблицы, который должен быть уникальным в пределах базы данных, содержащей эту таблицу.
>
> Идентификаторы должны начинаться с буквы (или любого символа языка, если включена поддержка имён Unicode) и не могут содержать пробелы или специальные символы, если только вся строка идентификатора не заключена в обратные кавычки (например, `My Object`).
>
> Зарезервированные ключевые слова нельзя использовать в качестве идентификаторов.
>
> Подробнее см. в разделах «Требования к идентификаторам» и «Зарезервированные ключевые слова».

## Необязательные параметры {#optional-parameters}
**1.`BRIEF`**
> Выводит только основные сведения о таблице, без определений столбцов.

**2.`<db_name>`**
> Задаёт идентификатор (то есть имя) базы данных.
>
> Идентификаторы должны начинаться с буквы (или любого символа соответствующего языка, если включена поддержка имён Unicode) и не могут содержать пробелы или специальные символы, если только вся строка идентификатора не заключена в обратные кавычки (например, `My Database`).
>
> Зарезервированные ключевые слова нельзя использовать в качестве идентификаторов.
>
> Подробнее см. в разделах «Требования к идентификаторам» и «Зарезервированные ключевые слова».

## Возвращаемое значение {#return-value}
| Имя столбца | Описание |
| -- |-------------|
| Table | Имя таблицы          |
| Create Table | Инструкция создания таблицы        |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право доступа     | Объект    | Примечания                      |
|:------------------|:----------|:--------------------------------|
| Select_priv       | Таблица   | SHOW CREATE TABLE относится к операции SELECT для таблицы |


## Примеры {#examples}

1. Просмотр инструкции создания таблицы

   ```sql
   SHOW CREATE TABLE demo.test_table;
   ```
2. Просмотр упрощённой инструкции создания таблицы

   ```sql
   SHOW BRIEF CREATE TABLE demo.test_table;
   ```
