## Описание {#descriptions}

Эта инструкция используется для отображения информации о партициях. Поддерживаются Internal catalog и Hive Catalog.

Для `Hive Catalog`:

Поддерживается получение всех партиций, включая многоуровневые.
## Синтаксис {#syntax}

```sql
SHOW [ TEMPORARY ] PARTITIONS
    FROM [ <db_name>. ] <table_name>
    [ <where_clause> ]
    [ ORDER BY <order_by_key> ]
    [ LIMIT <limit_rows> ];
```

## Обязательные параметры {#required-parameters}
**1. `<table_name>`**

Необходимо указать имя таблицы, для которой требуется просмотреть информацию о партициях.


## Необязательные параметры {#optional-parameters}
**1. `TEMPORARY`**

Определяет, нужно ли запрашивать информацию о временных партициях.

**2. `<db_name>`**

Необходимо указать имя базы данных, для которой требуется просмотреть информацию о партициях.

**3. `<where_clause>`**

Условия фильтрации. Поддерживается фильтрация по таким столбцам, как PartitionId, PartitionName, State, Buckets, ReplicationNum, LastConsistencyCheckTime и др.

Обратите внимание:
1. В настоящее время условие WHERE поддерживает только операторы `=`, `!=`, `like` для строковых столбцов PartitionName и State. Для остальных столбцов поддерживаются только такие операторы, как `=`, `!=`, `>`, `<`, `>=`, `<=`.
2. При использовании указанных операторов в условии WHERE имя столбца должно находиться слева.
3. Условие WHERE может содержать `AND`.

**4. `<order_by_key>`**

Условия сортировки. Поддерживается сортировка по таким столбцам, как PartitionId, PartitionName, State, Buckets, ReplicationNum, LastConsistencyCheckTime и др.

**5. `<limit_rows>`**

Максимальное количество возвращаемых строк.

## Возвращаемое значение {#return-value}
| Столбец                  | Тип данных | Описание                                                                                                                                                      |
|--------------------------|----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PartitionId              | bigint   | Идентификатор партиции                                                                                                                                         |
| PartitionName            | varchar  | Имя партиции                                                                                                                                                  |
| VisibleVersion           | int      | Максимальное значение VisibleVersion для tablets в этой партиции.                                                                                              |
| VisibleVersionTime       | datetime | Время последней VisibleVersion в этой партиции.                                                                                                                |
| State                    | varchar  | Состояние партиции                                                                                                                                            |
| PartitionKey             | datetime | Ключ партиционирования этой партиции                                                                                                                           |
| Range                    | datetime | Диапазон партиции                                                                                                                                             |
| DistributionKey          | varchar  | Ключ распределения этой партиции                                                                                                                               |
| Buckets                  | int      | Количество бакетов в партиции                                                                                                                                  |
| ReplicationNum           | int      | Количество реплик партиции                                                                                                                                    |
| StorageMedium            | varchar  | Носитель хранения партиции                                                                                                                                    |
| CooldownTime             | datetime | Время переноса партиции в холодное хранилище. Если разделение на горячие и холодные данные не используется, значение этого поля равно [9999-12-31 23:59:59], что означает, что данные всегда остаются горячими. |
| RemoteStoragePolicy      | varchar  | Политика удалённого хранения для этой партиции.                                                                                                                 |
| LastConsistencyCheckTime | datetime | Время последней проверки согласованности этой партиции.                                                                                                        |
| DataSize                 | int      | Размер данных в партиции.                                                                                                                                      |
| IsInMemory               | boolean  | Хранится ли партиция в памяти. Значение по умолчанию: false.                                                                                                    |
| ReplicaAllocation        | varchar  | Стратегия распределения реплик этой партиции.                                                                                                                   |
| IsMutable                | boolean  | Допускает ли партиция изменения. Значение по умолчанию: true.                                                                                                   |
| SyncWithBaseTables       | boolean  | Синхронизирована ли партиция с данными базовой таблицы.                                                                                                         |
| UnsyncTables             | varchar  | Принадлежит ли партиция несинхронизированной таблице.                                                                                                           |


## Требования к правам доступа {#access-control-requirements}
Для просмотра требуется право SHOW на соответствующую таблицу.
