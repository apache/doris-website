## Описание {#description}

Эта инструкция используется для отмены (отзыва) выполняемой операции ALTER TABLE. С помощью этой команды можно прекратить выполнение операции ALTER TABLE.

## Синтаксис {#syntax}

```sql
CANCEL ALTER TABLE { COLUMN | MATERIALIZED VIEW | ROLLUP } FROM <db_name>.<table_name> [ <job_id1> [ , <job_id2> ... ]]
```

## Обязательные параметры {#required-parameters}
**1. `{ COLUMN | MATERIALIZED VIEW | ROLLUP }`**
>Укажите тип изменения, которое нужно отменить. Необходимо выбрать один из вариантов.
>- `COLUMN`: отмена операции изменения столбца таблицы
>- `ROLLUP`: отмена операции изменения представления
>- `MATERIALIZED VIEW`: отмена операции изменения материализованного представления

**2.`<db_name>`**
> Указывает идентификатор (то есть имя) базы данных.
>
> Идентификатор должен начинаться с буквы (если включена поддержка имен Unicode, допускаются символы любого языка) и не должен содержать пробелы или специальные символы, за исключением случаев, когда вся строка идентификатора заключена в кавычки (например, `My Database`).
>
> В качестве идентификатора нельзя использовать зарезервированные ключевые слова.
>
> Подробнее см. в разделах «Требования к идентификаторам» и «Зарезервированные ключевые слова».

**3.`<table_name>`**
> Указывает идентификатор (то есть имя) таблицы в ее базе данных (Database).
>
> Идентификатор должен начинаться с буквы (если включена поддержка имен Unicode, допускаются символы любого языка) и не должен содержать пробелы или специальные символы, за исключением случаев, когда вся строка идентификатора заключена в кавычки (например, `My Object`).
>
> В качестве идентификатора нельзя использовать зарезервированные ключевые слова.
>
> Подробнее см. в разделах «Требования к идентификаторам» и «Зарезервированные ключевые слова».

## Необязательные параметры {#optional-parameters}
**1. `<job_id>`**
> ID конкретного задания, которое нужно отменить.
>
> Если указан ID задания, отменяется только это задание; если ID не указан, отменяются все выполняемые изменения указанного типа (COLUMN или ROLLUP) для таблицы.
>
> Можно указать несколько ID заданий, разделив их запятыми.
>
> ID заданий можно получить с помощью команды `SHOW ALTER TABLE COLUMN` или `SHOW ALTER TABLE ROLLUP`.


## Управление правами доступа {#permission-control}
Пользователи, выполняющие эту SQL-команду, должны иметь как минимум следующие права:


| Привилегия | Объект | Примечания                    |
| :---------------- | :------------- | :---------------------------- |
| ALTER_PRIV        | Таблица   | CANCEL ALTER TABLE относится к операциям ALTER над таблицей |


## Примечания {#notes}
- Эта команда выполняется асинхронно. Фактический результат выполнения необходимо подтвердить, проверив состояние задания с помощью `SHOW ALTER TABLE COLUMN` или `SHOW ALTER TABLE ROLLUP`.

## Пример {#example}

1. Отмена операции ALTER TABLE COLUMN

```sql
CANCEL ALTER TABLE COLUMN
FROM db_name.table_name
```

2. Отмена операции ALTER TABLE ROLLUP  


```sql
CANCEL ALTER TABLE ROLLUP
FROM db_name.table_name
```

3. Пакетная отмена операций ALTER TABLE ROLLUP по ID заданий


```sql
CANCEL ALTER TABLE ROLLUP
FROM db_name.table_name (jobid,...)
```
