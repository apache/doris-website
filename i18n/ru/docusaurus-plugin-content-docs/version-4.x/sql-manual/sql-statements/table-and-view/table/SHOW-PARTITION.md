## Описание {#description}

SHOW PARTITION используется для отображения подробной информации об указанной партиции. Эта информация включает имя и ID связанной базы данных, имя и ID связанной таблицы, а также имя партиции.

## Синтаксис {#syntax}

```sql
SHOW PARTITION <partition_id>
```

## Обязательные параметры {#required-parameters}

**<partition_id>**

> ID партиции. ID партиции можно получить, например, с помощью SHOW PARTITIONS. Подробнее см. в разделе "SHOW PARTITIONS".

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум права `ADMIN_PRIV`.

## Примеры {#examples}

Запрос информации о партиции с ID 13004:

```sql
SHOW PARTITION 13004;
```

Если партиция с таким ID существует, результат выглядит следующим образом. Приведённые ID служат примером; замените `13004` фактическим ID своей партиции (см. `SHOW PARTITIONS`). Если подходящая партиция не найдена, `SHOW PARTITION` возвращает пустой набор результатов.

```sql
+--------+-----------+---------------+-------+---------+
| DbName | TableName | PartitionName | DbId  | TableId |
+--------+-----------+---------------+-------+---------+
| ods    | sales     | sales         | 13003 | 13005   |
+--------+-----------+---------------+-------+---------+
```
