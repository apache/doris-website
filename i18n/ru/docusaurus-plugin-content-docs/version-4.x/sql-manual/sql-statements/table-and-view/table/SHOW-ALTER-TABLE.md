## Описание {#description}

Этот оператор отображает состояние выполнения различных текущих задач изменения.

```sql
SHOW ALTER [TABLE [COLUMN | ROLLUP] [FROM db_name]];
```

Примечания:

1. TABLE COLUMN: отображает задачи ALTER по изменению столбцов.
2. Поддерживаемый синтаксис: [WHERE TableName|CreateTime|FinishTime|State] [ORDER BY] [LIMIT].
3. TABLE ROLLUP: отображает задачи создания или удаления ROLLUP.
4. Если db_name не указан, используется текущая база данных по умолчанию.

## Результат {#result}

*SHOW ALTER TABLE COLUMN*

| Имя поля              | Описание                                                         |
|-----------------------|------------------------------------------------------------------|
| JobId                 | Уникальный ID каждой задачи Schema Change.                          |
| TableName             | Имя базовой таблицы, к которой относится Schema Change. |
| CreateTime            | Время создания задачи.                                              |
| FinishedTime          | Время завершения задачи. Если задача не завершена, отображается "N/A".      |
| IndexName             | Имя базовой таблицы или синхронного материализованного представления, участвующих в этом изменении.        |
| IndexId               | ID новой базовой таблицы или синхронного материализованного представления.                                      |
| OriginIndexId         | ID базовой таблицы или синхронного материализованного представления, участвующих в этом изменении.                                      |
| SchemaVersion         | Отображается в формате M:N. M обозначает версию Schema Change, а N обозначает соответствующее значение хеша. При каждом Schema Change версия увеличивается. |
| TransactionId         | ID транзакции для преобразования исторических данных.                  |
| State                 | Этап выполнения задачи.                                               |
|                       | - PENDING: задача ожидает планирования в очереди.        |
|                       | - WAITING_TXN: ожидание завершения задач загрузки с ID транзакций меньше граничного ID. |
|                       | - RUNNING: выполняется преобразование исторических данных.                |
|                       | - FINISHED: задача успешно завершена.                            |
|                       | - CANCELLED: задача завершилась с ошибкой.                                          |
| Msg                   | Если задача завершилась с ошибкой, отображается сообщение об ошибке.                        |
| Progress              | Ход выполнения задачи. Отображается только в состоянии RUNNING. Прогресс отображается в формате M/N. N обозначает общее количество реплик, участвующих в Schema Change. M обозначает количество реплик, для которых завершено преобразование исторических данных. |
| Timeout                | Время ожидания выполнения задачи в секундах.                                       |


## Примеры {#examples}

1. Отобразить состояние выполнения всех задач изменения столбцов для базы данных по умолчанию.

   ```sql
   SHOW ALTER TABLE COLUMN;
   ```

2. Отобразить состояние выполнения последней задачи изменения столбцов для определённой таблицы.

   ```sql
   SHOW ALTER TABLE COLUMN WHERE TableName = "table1" ORDER BY CreateTime DESC LIMIT 1;
   ```

3. Отобразить состояние выполнения задач создания или удаления ROLLUP для указанной базы данных.

   ```sql
   SHOW ALTER TABLE ROLLUP FROM example_db;
   ```
