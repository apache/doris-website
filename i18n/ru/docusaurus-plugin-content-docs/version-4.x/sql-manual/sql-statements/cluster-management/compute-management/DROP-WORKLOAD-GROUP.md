## Описание {#description}

Эта инструкция используется для удаления группы рабочей нагрузки.

## Синтаксис {#syntax}

```sql
DROP WORKLOAD GROUP [IF EXISTS] '<rg_name>' [FOR <compute_group>]
```

## Параметры {#parameters}

1. `<compute_group>`

    Указывает вычислительную группу, содержащую группу рабочей нагрузки, которую нужно удалить.

    - **Облачный режим (с разделением хранения и вычислений)**: Предложение `FOR <compute_group>` **необходимо указывать явно**. Если его опустить, возникает ошибка: `Must specify compute group via 'FOR <compute_group>' in cloud mode.`
    - **Необлачный режим (с объединением хранения и вычислений)**: Предложение `FOR <compute_group>` необязательно. Здесь значение фактически обозначает группу ресурсов (Tag); общий с облачным режимом синтаксис используется исключительно для единообразия. Если предложение опущено, удаляется одноимённая группа рабочей нагрузки из группы ресурсов по умолчанию (`default`).

## Примеры {#examples}

1. Удаление группы рабочей нагрузки с именем g1 (в необлачном режиме удаляет g1 из группы ресурсов по умолчанию):
    
    ```sql
    drop workload group if exists g1;
    ```

2. Удаление группы рабочей нагрузки с именем g1 из `compute_group_a` (в облачном режиме это предложение обязательно):

    ```sql
    drop workload group if exists g1 for compute_group_a;
    ```
