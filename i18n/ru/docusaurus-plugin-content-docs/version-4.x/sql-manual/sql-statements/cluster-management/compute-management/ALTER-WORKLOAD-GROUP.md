## Описание {#description}

Этот оператор используется для изменения группы рабочей нагрузки.

## Синтаксис {#syntax}

```sql
ALTER WORKLOAD GROUP  "<rg_name>"
[FOR <compute_group>]
PROPERTIES (
  `<property>`
  [ , ... ]
);
```

:::note
Оператор `ALTER` изменяет только свойства группы рабочей нагрузки; он **не может изменить привязку группы рабочей нагрузки к вычислительной группе**. Предложение `FOR <compute_group>` определяет, в какой вычислительной группе находится изменяемая группа рабочей нагрузки.
:::

## Параметры {#parameters}

1. `<compute_group>`

    Указывает вычислительную группу, содержащую группу рабочей нагрузки, которую нужно изменить.

    - **Облачный режим (с разделением хранения и вычислений)**: предложение `FOR <compute_group>` **необходимо указывать явно**. Если его опустить, возникает ошибка: `Must specify compute group via 'FOR <compute_group>' in cloud mode.`
    - **Необлачный режим (с совмещением хранения и вычислений)**: предложение `FOR <compute_group>` необязательно. Указанное здесь значение фактически обозначает группу ресурсов (Tag); общий с облачным режимом синтаксис используется исключительно для единообразия. Если предложение опущено, выбирается группа рабочей нагрузки с тем же именем в группе ресурсов по умолчанию (`default`).

2. `<property>`

    Формат `<property>`: `<key>` = `<value>`. Допустимые значения `<key>` приведены в разделе [Группа рабочей нагрузки](../../../../admin-manual/workload-management/workload-group.md).

## Примеры {#examples}

1. Изменение группы рабочей нагрузки с именем g1 (в необлачном режиме изменяется g1 в группе ресурсов по умолчанию):

    ```sql
    alter workload group g1
    properties (
        "max_cpu_percent"="20%",
        "max_memory_percent"="40%"
    );
    ```

2. Изменение группы рабочей нагрузки с именем g1 в вычислительной группе `compute_group_a` (в облачном режиме это предложение обязательно):

    ```sql
    alter workload group g1 for compute_group_a
    properties (
        "max_cpu_percent"="20%",
        "max_memory_percent"="40%"
    );
    ```
