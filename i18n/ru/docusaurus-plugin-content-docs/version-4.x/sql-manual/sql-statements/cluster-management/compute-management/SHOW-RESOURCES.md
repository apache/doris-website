## Описание {#description}

Этот оператор используется для отображения ресурсов, к которым у пользователя есть доступ. Обычные пользователи могут просматривать только ресурсы, к которым у них есть доступ, а пользователи root или admin могут просматривать все ресурсы.

## Синтаксис {#syntax}

```sql
SHOW RESOURCES
[
  WHERE
  [NAME [ = "<your_resource_name>" | LIKE "<name_matcher>"]]
  [RESOURCETYPE = "<type>"]
] | [LIKE "<pattern>"]
[ORDER BY ...]
[LIMIT <limit>][OFFSET <offset>];
```

## Примечания по использованию {#usage-notes}

1. При использовании NAME LIKE в RESOURCES будут найдены ресурсы, у которых Name содержит name_matcher.
2. При использовании NAME = выполняется точное сопоставление с указанным значением Name.
3. Если указан RESOURCETYPE, выбираются ресурсы соответствующего типа. Поддерживаемые значения RESOURCETYPE приведены в [CREATE-RESOURCE](./CREATE-RESOURCE.md).
4. С помощью ORDER BY можно выполнить сортировку по любой комбинации столбцов.
5. Если указан LIMIT, отображается не более limit подходящих записей. В противном случае отображаются все подходящие записи.
6. Если указан OFFSET, результаты запроса отображаются начиная со смещения offset. По умолчанию смещение равно 0.
7. При использовании LIKE условие WHERE игнорируется.

## Пример {#example}

1. Отображение всех ресурсов, к которым у текущего пользователя есть доступ

   ```sql
   SHOW RESOURCES;
   ```

2. Отображение указанного ресурса, имя которого содержит строку "20140102", с выводом 10 атрибутов

   ```sql
   SHOW RESOURCES WHERE NAME LIKE "2014_01_02" LIMIT 10;
   ```

3. Отображение указанного ресурса с именем "20140102" и сортировкой по KEY в порядке убывания

   ```sql
   SHOW RESOURCES WHERE NAME = "20140102" ORDER BY `KEY` DESC;
   ```

3. Использование LIKE для поиска ресурса по шаблону

   ```sql
   SHOW RESOURCES LIKE "jdbc%";
   ```
