## Описание {#description}

Этот оператор используется для задания хранилища по умолчанию в Doris. Хранилище по умолчанию используется для хранения данных внутренних или системных таблиц. Если хранилище по умолчанию не задано, Doris не сможет работать корректно. После задания хранилища по умолчанию удалить его нельзя.


## Синтаксис {#syntax}

```sql
SET <vault_name> AS DEFAULT STORAGE VAULT
```

## Обязательные параметры {#required-parameters}

| Имя параметра          | Описание                                                         |
|-------------------|--------------------------------------------------------------|
| `<vault_name>`    | Имя хранилища. Это уникальный идентификатор хранилища, которое вы хотите назначить хранилищем по умолчанию.           |

## Примечания по использованию: {#usage-notes}
> 1. Только пользователи ADMIN могут задавать хранилище по умолчанию.

## Примеры {#examples}

1. Назначьте хранилище с именем s3_vault хранилищем по умолчанию.

   ```sql
   SET s3_vault AS DEFAULT STORAGE VAULT;
   ```
