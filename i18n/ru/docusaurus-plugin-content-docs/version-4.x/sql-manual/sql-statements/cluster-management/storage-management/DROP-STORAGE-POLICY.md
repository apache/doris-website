## Описание {#description}

Удаляет политику хранения. Подробное описание политик хранения см. в разделе «Политика хранения».

## Синтаксис {#syntax}

```sql
DROP STORAGE POLICY <policy_name>
```
## Обязательные параметры {#required-parameters}

**<policy_name>**

> Имя политики хранения

## Управление доступом {#permission-control}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право      | Объект | Примечания |
| :--------- | :----- | :---- |
| ADMIN_PRIV | Глобальный уровень |       |

## Пример {#example}

1. Удаление политики хранения с именем policy1

    ```sql
    DROP STORAGE POLICY policy1
    ```
