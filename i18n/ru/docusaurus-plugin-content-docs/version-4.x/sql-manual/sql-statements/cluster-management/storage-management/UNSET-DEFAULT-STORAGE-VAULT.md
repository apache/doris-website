## Описание {#description}
Отменяет назначение указанного Storage Vault хранилищем по умолчанию

## Синтаксис {#syntax}

```sql
UNSET DEFAULT STORAGE VAULT
```

## Управление правами доступа {#permission-control}

| Привилегия | Объект        | Примечания                                                 |
| :--------- | :------------ | :--------------------------------------------------------- |
| ADMIN_PRIV | Storage Vault | Только пользователи с правами администратора могут выполнять этот оператор |

## Пример {#example}

```sql
UNSET DEFAULT STORAGE VAULT
```
