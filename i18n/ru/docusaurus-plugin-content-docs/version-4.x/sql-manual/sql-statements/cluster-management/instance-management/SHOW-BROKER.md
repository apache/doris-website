## Описание {#description}

Эта инструкция используется для просмотра состояния существующих процессов Broker.

## Синтаксис {#syntax}

```sql
SHOW BROKER;
```


## Результат {#output}
| Столбец        | Тип данных | Описание                                                       |
|----------------|------------|----------------------------------------------------------------|
| Name           | varchar    | Имя процесса Broker                                            |
| Host           | varchar    | IP-адрес узла процесса Broker                                   |
| Port           | varchar    | Порт узла процесса Broker                                       |
| Alive          | varchar    | Состояние узла процесса Broker                                  |
| LastStartTime  | varchar    | Время последнего запуска процесса Broker                        |
| LastUpdateTime | varchar    | Время последнего обновления процесса Broker                     |
| ErrMsg         | varchar    | Сообщение об ошибке при последнем неудачном запуске процесса Broker |


## Требования к правам доступа {#access-control-requirements}
Пользователь, выполняющий эту инструкцию, должен иметь разрешение `ADMIN/OPERATOR`.
