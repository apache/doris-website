## Описание {#description}

Этот оператор используется для просмотра основных сведений о состоянии узлов BE.

## Синтаксис {#syntax}

```sql
 SHOW BACKENDS
```

## Возвращаемое значение {#return-value}

| Столбец | Описание |
|-------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BackendId | Идентификатор текущего BE. |
| Host | IP-адрес или имя хоста текущего BE. |
| HeartbeatPort | Порт связи службы heartbeat текущего BE. |
| BePort | Порт связи thrift RPC текущего BE. |
| HttpPort | Порт связи HTTP текущего BE. |
| BrpcPort | Порт связи bRPC текущего BE. |
| ArrowFlightSqlPort | Порт связи по протоколу ArrowFlight текущего BE. |
| LastStartTime | Временная метка запуска текущего BE. |
| LastHeartbeat | Временная метка последнего heartbeat, успешно отправленного текущим BE. |
| Alive | Показывает, работает ли текущий BE. |
| SystemDecommissioned | Если это значение равно true, текущий узел BE находится в процессе безопасного вывода из эксплуатации. |
| TabletNum | Количество объектов tablet, хранящихся на текущем BE. |
| DataUsedCapacity | Дисковое пространство, занимаемое данными текущего BE. |
| TrashUsedCapacity | Дисковое пространство, занимаемое данными в корзине текущего BE. |
| AvailCapacity | Доступное дисковое пространство текущего BE. |
| TotalCapacity | Общий объём дискового пространства текущего BE. TotalCapacity = AvailCapacity + TrashUsedCapacity + DataUsedCapacity + дисковое пространство, занимаемое другими файлами, не содержащими пользовательские данные. |
| UsedPct | Доля занятого места в общем объёме дискового пространства текущего BE, выраженная в процентах. |
| MaxDiskUsedPct | Наибольший процент занятого пространства среди всех дисков текущего BE. |
| RemoteUsedCapacity | Дисковое пространство, занимаемое данными, выгруженными в удалённое хранилище при использовании на текущем BE функции многоуровневого хранения горячих и холодных данных. |
| Tag | Информация о тегах текущего BE в формате JSON. Состав сохраняемой информации о тегах зависит от режима развёртывания. В режиме с совмещёнными хранением и вычислениями сохраняется имя группы ресурсов текущего BE. В режиме с разделёнными хранением и вычислениями сохраняется дополнительная информация. |
| ErrMsg | Сообщение об ошибке при сбое heartbeat текущего BE. |
| Version | Информация о версии текущего BE. |
| Status | Сведения о состоянии текущего BE в формате JSON, включая lastSuccessReportTabletsTime, lastStreamLoadTime, isQueryDisabled, isLoadDisabled и т. д. Следует учитывать, что состав сохраняемой информации может немного различаться в разных версиях. |
| HeartbeatFailureCounter | Количество последовательных сбоев heartbeat текущего BE. Если это количество превышает значение параметра `max_backend_heartbeat_failure_tolerance_count`, заданного в FE Master (значение по умолчанию 1), поле `Alive` устанавливается в false. |
| NodeRole | Роль текущего BE. Возможны два варианта: `mix` является ролью по умолчанию, а `computation` означает, что текущий узел используется только для федеративных аналитических запросов. |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий этот SQL-оператор, должен иметь как минимум следующие права:

| Право | Объект | Примечания |
|------------|----|----|
| SELECT_PRIV | internal.information_schema | По умолчанию все пользователи имеют права доступа к этой базе данных |

## Примечания по использованию {#usage-notes}

Если требуется дополнительная фильтрация результатов запроса, можно использовать табличную функцию [backends()](../../../sql-functions/table-valued-functions/backends.md). SHOW BACKENDS эквивалентен следующему оператору:
```sql
SELECT * FROM BACKENDS();
```
