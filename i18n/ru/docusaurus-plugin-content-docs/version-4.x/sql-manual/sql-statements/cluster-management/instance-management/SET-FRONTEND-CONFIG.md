## Описание {#description}

Эта инструкция задаёт параметры конфигурации кластера (в настоящее время поддерживается только настройка параметров FE).

## Синтаксис: {#syntax}

```sql
ADMIN SET {ALL FRONTENDS | FRONTEND} CONFIG ("<fe_config_key>" = "<fe_config_value>")
```

## Обязательные параметры {#required-parameters}
**`{ALL FRONTENDS | FRONTEND}`**
> **`ALL FRONTENDS`**: Обозначает все узлы FE в кластере Doris
>
> **`FRONTEND`**: Обозначает узел FE, к которому установлено текущее подключение, то есть узел FE, с которым взаимодействует пользователь

## Необязательные параметры {#optional-parameters}
Параметры `<fe_config_key>` и `<fe_config_value>`, которые требуется изменить, можно просмотреть с помощью команды [SHOW FRONTEND CONFIG](./SHOW-FRONTEND-CONFIG)

:::tip Пояснение

- Начиная с версий 2.0.11 и 2.1.5 поддерживается ключевое слово `ALL`. При использовании ключевого слова `ALL` параметры конфигурации применяются ко всем узлам FE (за исключением параметра `master_only`).
- Этот синтаксис не сохраняет изменения конфигурации на постоянной основе. После перезапуска FE изменённые настройки перестают действовать. Чтобы сохранить изменения, необходимо одновременно добавить параметры конфигурации в fe.conf.
:::

## Пример {#example}

1. Установить для параметра `disable_balance` значение `true`

    ```sql
    ADMIN SET FRONTEND CONFIG ("disable_balance" = "true");
    ```

2. Установить для параметра `disable_balance` на всех узлах FE значение `true`
   ```sql
   ADMIN SET ALL FRONTENDS CONFIG ("disable_balance" = "true");
   ```
