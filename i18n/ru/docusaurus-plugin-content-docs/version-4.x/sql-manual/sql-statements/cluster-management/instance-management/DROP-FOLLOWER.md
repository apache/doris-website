## Описание {#description}

Этот оператор удаляет узел FRONTEND с ролью FOLLOWER. (Только для администраторов!)

## Синтаксис {#syntax}

```sql
ALTER SYSTEM DROP FOLLOWER "<follower_host>:<edit_log_port>"
```

## Обязательные параметры {#required-parameters}

**1. `<follower_host>`**

> Имя хоста или IP-адрес узла FE

**2. `<edit_log_port>`**

> Порт узла FE для обмена данными bdbje, по умолчанию 9010

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Привилегия | Объект | Примечания |
|-----------|----|-------|
| NODE_PRIV |    |       |

## Примечания по использованию {#usage-notes}

1. Перед удалением узла FOLLOWER убедитесь, что узел, который требуется вывести из эксплуатации, не является узлом Master.
2. Перед удалением узла FOLLOWER убедитесь, что после вывода удаляемых узлов из эксплуатации количество узлов FOLLOWER в кластере останется нечётным.
3. После удаления узла FOLLOWER используйте команду [`SHOW FRONTENDS`](./SHOW-FRONTENDS.md), чтобы убедиться в успешном удалении.

## Примеры {#examples}

1. Удаление узла FOLLOWER

   ```sql
   ALTER SYSTEM DROP FOLLOWER "host_ip:9010"
   ```
   Эта команда удаляет узел FOLLOWER из кластера (IP-адрес host_ip, порт 9010)
