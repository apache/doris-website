## Описание {#description}

Этот оператор используется для отображения системных переменных Doris с возможностью отбора по условиям

## Синтаксис {#syntax}

```sql
SHOW [<effective_scope>] VARIABLES [<like_pattern> | <where clause>]
```

## Необязательные параметры {#optional-parameters}
**1. `<effective_scope>`**
> Область действия может принимать одно из значений: `GLOBAL`, `SESSION` или `LOCAL`. Если область действия не указана, по умолчанию используется `SESSION`. `LOCAL` является псевдонимом `SESSION`.

**2. `<like_pattern>`**
> Используется оператор like для сопоставления и фильтрации результатов

**3. `<where>`**
> Используется условие where для сопоставления и фильтрации результатов

## Требования к управлению доступом {#access-control-requirements}
Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие привилегии:

| Привилегия  | Объект | Примечания                                        |
| :--------- | :----- | :------------------------------------------- |
| N/A      | Session  | Для просмотра переменных специальные привилегии не требуются |


## Возвращаемое значение {#return-value}
| Variable_name | Value   | Default_Value                    | Changed |
|:--------------|:--------|:---------------------------------|:--------|
| имя переменной1      | значение1 | значение по умолчанию1 |   0/1      |
| имя переменной2      | значение2 | значение по умолчанию2 |   0/1      |


## Примечания по использованию {#usage-notes}

- Команда Show variables в основном используется для просмотра значений системных переменных.
- Для выполнения команды SHOW VARIABLES не требуются никакие привилегии: достаточно иметь возможность подключиться к серверу.
- В столбце `Changed` из раздела `Return Value` значение 0 означает отсутствие изменений, а 1 означает наличие изменений.
- При использовании оператора `SHOW` действуют следующие ограничения:
  - В условии where нельзя использовать `or`
  - Имена столбцов должны находиться слева
  - В условии where поддерживаются только сравнения на равенство
  - Для сопоставления с variable_name используется оператор like.
  - Подстановочный символ процента % можно использовать в любом месте шаблона сопоставления


## Пример {#example}


- По умолчанию сопоставление выполняется по Variable_name; в этом примере используется точное совпадение

    ```sql
    show variables like 'max_connections';
    ```


- С помощью подстановочного символа процента (%) можно найти несколько совпадений

    ```sql
    show variables like '%connec%';
    ```


- Использование условия Where для запросов с сопоставлением

    ```sql
    show variables where variable_name = 'version';
    ```
