## Описание {#description}

Завершает соединение с указанным идентификатором. При этом также завершается запрос, связанный с этим соединением.

## Синтаксис {#syntax}

```sql
KILL [ CONNECTION ] <connection_id>
```

## Обязательные параметры {#required-parameters}

**<connection_id>**

> Идентификатор соединения. Его можно узнать с помощью оператора SHOW PROCESSLIST.

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен быть владельцем соединения или иметь как минимум право `ADMIN_PRIV`.

## Примеры {#examples}

Получите `connection_id`:

```sql
show processlist;
```

Результат:

```sql
+------------------+----+------+-----------------+---------------------+----------+------+---------+------+-------+-----------------------------------+------------------+--------------+--------------+
| CurrentConnected | Id | User | Host            | LoginTime           | Catalog  | Db   | Command | Time | State | QueryId                           | Info             | FE           | CloudCluster |
+------------------+----+------+-----------------+---------------------+----------+------+---------+------+-------+-----------------------------------+------------------+--------------+--------------+
| Yes              | 16 | root | 127.0.0.1:63746 | 2024-11-04 20:18:07 | internal | test | Query   | 0    | OK    | e4d69a1cce81468d-91c9ae32b17540e9 | show processlist | 172.16.123.1 | NULL         |
+------------------+----+------+-----------------+---------------------+----------+------+---------+------+-------+-----------------------------------+------------------+--------------+--------------+
```

Отправьте команду KILL:

```sql
KILL CONNECTION 16;
```
