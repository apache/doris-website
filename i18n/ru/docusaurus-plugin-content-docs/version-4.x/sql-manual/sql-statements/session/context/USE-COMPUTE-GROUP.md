## Описание {#description}

В версии с разделением хранения и вычислений укажите вычислительный кластер, который следует использовать.

## Синтаксис {#syntax}


```sql
USE { [ <catalog_name>. ]<database_name>[ @<compute_group_name> ] | @<compute_group_name> }
```

## Обязательные параметры {#required-parameters}

`<compute_group_name>`： Имя вычислительного кластера.

## Возвращаемое значение {#return-value}

При успешном переключении вычислительного кластера возвращается сообщение "Database changed"; при неудачном переключении возвращается соответствующее сообщение об ошибке.

## Примеры {#examples}

1. Укажите вычислительный кластер `compute_cluster`, который следует использовать:

    ```sql
    use @compute_cluster;
    Database changed
    ```

2. Укажите одновременно базу данных `mysql` и вычислительный кластер `compute_cluster`, которые следует использовать:

    ```sql
    use mysql@compute_cluster
    Database changed
    ```

## Управление правами доступа {#permission-control}

Для успешного выполнения этой команды SQL необходимо иметь право USAGE_PRIV на группу вычислений. См. документацию по правам доступа.

| Право      | Объект            | Примечания                                       |
| :--------- | :------------ | :------------------------------------ |
| USAGE_PRIV | Группа вычислений | Право на использование вычислительного кластера |

Если пользователь не имеет права доступа к группе вычислений и пытается указать группу вычислений, будет выдана ошибка. Например, `test` — обычный пользователь без права доступа к группе вычислений:

```sql
mysql -utest -h175.40.1.1 -P9030

use @compute_cluster;
ERROR 5042 (42000): errCode = 2, detailMessage = USAGE denied to user test'@'127.0.0.1' for compute group 'compute_cluster'
```


## Примечания {#notes}

1. Если имя базы данных или группы вычислений является зарезервированным ключевым словом, его необходимо заключить в обратные кавычки, например:

    ```sql
    use @`create`
    ```

2. Если группа вычислений не существует, будет возвращено сообщение об ошибке:

    ```sql
    mysql> use @compute_group_not_exist;
    ERROR 5098 (42000): errCode = 2, detailMessage = Compute Group compute_group_not_exist not exist
    ```
