## Описание {#description}

Каждое соединение Doris выполняется в отдельном потоке. Используйте эту инструкцию для завершения потока.

## Синтаксис {#syntax}

```SQL
KILL [CONNECTION] <processlist_id>
```

## Альтернативный синтаксис {#varaint-syntax}

```SQL
KILL QUERY [ { <processlist_id> | <query_id> } ]
```

## Обязательные параметры {#required-parameters}

**1. `<processlist_id>`**

> Указывает ID потока соединения, который требуется завершить

**2. `<query_id>`**

> Указывает ID запроса, который требуется завершить

## Необязательные параметры {#optional-parameters}

**1. `CONNECTION`**

> Указывает, подключён ли поток в данный момент

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Привилегия    | Объект    | Примечания                      |
|:--------------|:-----------|:-----------------------|
| ADMIN_PRIV | Глобальный уровень | Для завершения запросов или соединений других пользователей требуется привилегия ADMIN; для завершения собственных запросов привилегии не требуются |

## Примечания по использованию {#usage-notes}

- Идентификатор потока в списке процессов можно узнать из столбца Id в выводе SHOW PROCESSLIST

- Идентификатор соединения можно узнать с помощью SELECT CONNECTION_ID()
