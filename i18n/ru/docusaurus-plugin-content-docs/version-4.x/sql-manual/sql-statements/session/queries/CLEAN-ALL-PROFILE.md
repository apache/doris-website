## Описание {#description}

Эта команда позволяет вручную удалить все профили ранее выполненных запросов или загрузок.

## Синтаксис {#syntax}

```sql
CLEAN ALL PROFILE
```

## Требования к управлению доступом {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Привилегия   | Объект    | Примечания                                           |
|:--------------|:-----------|:-----------------------------------------------------|
| ADMIN_PRIV   | Глобальный уровень | Для удаления всех профилей требуется привилегия ADMIN |

## Примеры {#examples}

```sql
CLEAN ALL PROFILE
```
