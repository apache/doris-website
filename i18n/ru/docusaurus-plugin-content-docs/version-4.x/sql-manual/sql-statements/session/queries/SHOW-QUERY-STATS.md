## Описание {#description}

Этот оператор отображает столбцы таблиц базы данных, к которым обращались ранее выполненные запросы

## Синтаксис {#syntax}

```sql
SHOW QUERY STATS [ { [FOR <db_name>] | [FROM <table_name>] } ] [ALL] [VERBOSE]];
```

## Необязательные параметры {#optional-parameters}

**1. `<db_name>`**

> Если этот параметр задан, отображается статистика обращений к базе данных

**2. `<table_name>`**

> Если этот параметр задан, запрашивается статистика обращений к таблице

**3. `ALL`**

> ALL указывает, следует ли отображать статистику обращений ко всем индексам

**4. `VERBOSE`**

> VERBOSE отображает подробную статистику обращений

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать как минимум следующими правами:

| Привилегия         | Объект    | Примечания         |
|:-------------------|:----------|:-------------------|
| SELECT_PRIV        | DATABASE  | Необходимо иметь право SELECT на базу данных, к которой выполняется запрос |

## Примечания по использованию {#usage-notes}

- Позволяет просматривать статистику обращений к базам данных и таблицам в ранее выполненных запросах. Данные сбрасываются после перезапуска fe, а статистика собирается отдельно для каждого fe.

- С помощью FOR DATABASE и FROM TABLE можно указать базу данных или таблицу, статистику обращений к которой нужно получить. После этих конструкций указывается имя базы данных или таблицы.

- Параметры ALL и VERBOSE можно использовать по отдельности или вместе, но они должны стоять в конце команды и применимы только к запросам статистики таблиц.

- Если ни одна база данных не выбрана, выполнение 'SHOW QUERY STATS' покажет статистику обращений ко всем базам данных.

- Результат может содержать два столбца: QueryCount указывает, сколько раз столбец использовался в запросах, а FilterCount указывает, сколько раз столбец использовался в условии where.
