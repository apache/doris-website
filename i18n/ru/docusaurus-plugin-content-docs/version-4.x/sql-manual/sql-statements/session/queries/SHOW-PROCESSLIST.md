## Описание {#description}

Отображает поток, выполняемый пользователем.
Эта команда отображает сведения о подключениях только текущего FE.
Чтобы просмотреть сведения о подключениях всего кластера, необходимо задать переменную сеанса:
```
SET SHOW_ALL_FE_CONNECTION = TRUE;
```

## Синтаксис {#syntax}

```sql
SHOW [FULL] PROCESSLIST
```

## Необязательные параметры {#optional-parameters}

**1. `FULL`**

> Указывает, следует ли отображать сведения о подключениях других пользователей

## Возвращаемое значение {#return-value}

| Столбец           | Описание                                   |
|------------------|--------------------------------------|
| CurrentConnected | Является ли подключение текущим                              |
| Id               | Уникальный идентификатор этого потока                            |
| User             | Пользователь, запустивший этот поток                            |
| Host             | IP-адрес и номер порта клиента, отправляющего запрос                |
| LoginTime        | Время установления подключения                              |
| Catalog          | Каталог данных, в котором сейчас выполняется команда                    |
| Db               | База данных, в которой выполняется команда. Если база данных не указана, значение равно NULL |
| Command          | Команда, которую поток выполняет в данный момент                         |
| Time             | Время с момента отправки предыдущей команды до текущего состояния, в секундах                 |
| State            | Состояние потока                                |
| QueryId          | Идентификатор текущего запроса                           |
| Info             | Обычно содержит инструкцию, выполняемую потоком; по умолчанию отображаются только первые 100 символов         |

Распространённые значения Command:

| Столбец | Описание |
| -- | -- |
| Query | Поток выполняет инструкцию |
| Sleep | Ожидание инструкции для выполнения от клиента |
| Quit | Поток завершает работу |
| Kill | Выполняется инструкция kill |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Привилегия    | Объект    | Примечания                      |
|:-------------|:----------|:---------------------------|
| ADMIN_PRIV        | DATABASE  | Для просмотра сведений о подключениях других пользователей требуется право ADMIN |
