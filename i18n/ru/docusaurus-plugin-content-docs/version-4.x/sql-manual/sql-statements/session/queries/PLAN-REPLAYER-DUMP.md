## Описание {#description}

PLAN REPLAYER DUMP позволяет пользователям Doris создавать диагностические файлы планов выполнения. Он сохраняет состояние и входные данные оптимизатора запросов, упрощая отладку и анализ проблем оптимизации запросов. В результате возвращается http-адрес соответствующего диагностического файла.


## Синтаксис {#syntax}

```sql
PLAN REPLAYER DUMP <query>
```


## Обязательные параметры {#required-parameters}

`<query>`


- Обозначает оператор запроса в соответствующей инструкции DML.
- Если указан не оператор запроса, будет выдана ошибка синтаксического анализа.
- Дополнительные сведения см. в описании синтаксиса [SELECT](https://doris.apache.org/docs/dev/sql-manual/sql-statements/data-query/SELECT).


## Управление правами доступа {#permission-control}


Для выполнения этой команды SQL пользователям необходимы как минимум следующие права доступа:


| Право доступа | Объект | Примечания |
| :--: | :--: | :--: |
| SELECT_PRIV | Таблица, представление | Для выполнения <query_sql_statement> требуется право SELECT_PRIV на таблицу, представление или материализованное представление, к которым обращается запрос. |


## Примеры {#examples}


### Базовый пример {#basic-example}

```sql
create database test_replayer;
use database test_replayer;
create table t1 (c1 int, c11 int) distributed by hash(c1) buckets 3 properties('replication_num' = '1');
plan replayer dump select * from t1;
```


Пример результата выполнения:

```sql
+-------------------------------------------------------------------------------+
| Plan Replayer dump url                                                        |
+-------------------------------------------------------------------------------+
| http://127.0.0.1:8030/api/minidump?query_id=6e7441f741e94afd-ad3ba69429ad18ec |
+-------------------------------------------------------------------------------+
```


Для получения соответствующего файла можно использовать curl или wget, например:

```sql
wget http://127.0.0.1:8030/api/minidump?query_id=6e7441f741e94afd-ad3ba69429ad18ec
```


Если требуются права доступа, имя пользователя и пароль можно указать следующим образом:

```sql
wget --header="Authorization: Basic $(echo -n 'root:' | base64)" http://127.0.0.1:8030/api/minidump?query_id=6e7441f741e94afd-ad3ba69429ad18ec
```
