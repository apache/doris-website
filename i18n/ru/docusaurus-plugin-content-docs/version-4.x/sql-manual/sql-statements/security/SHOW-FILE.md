## Описание {#description}

Эта инструкция отображает файл, созданный в базе данных.

## Синтаксис {#syntax}

```sql
SHOW FILE { [ FROM | IN ] <database_name>}
```

## Необязательные параметры {#optional-parameters}

**1. `<database_name>`**

> Указывает базу данных, которой принадлежит файл. Если параметр не указан, используется база данных текущего сеанса.

## Возвращаемое значение {#return-value}

| Столбец     | Описание                        |
|:------------|:--------------------------------|
| `Id`        | Глобально уникальный идентификатор файла |
| `DbName`    | Имя базы данных, которой принадлежит файл |
| `Catalog`   | Классификация, заданная пользователем |
| `FileName`  | Имя файла                       |
| `FileSize`  | Размер файла в байтах           |
| `IsContent` | Признак наличия содержимого     |
| `MD5`       | Контрольная сумма MD5 файла     |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать следующими минимальными правами:

| Право        | Объект      | Примечания                                                                                                  |
|:-------------|:------------|:------------------------------------------------------------------------------------------------------------|
| `ADMIN_PRIV` | Пользователь / Роль | Для выполнения этой команды пользователь или роль должны иметь права доступа к базе данных, в которой находится файл |

## Пример {#example}

- Просмотр загруженных файлов в базе данных текущего сеанса

   ```sql
   SHOW FILE;
   ```
   ```text
   +-------+--------+----------+--------------------------+----------+-----------+----------------------------------+
   | Id    | DbName | Catalog  | FileName                 | FileSize | IsContent | MD5                              |
   +-------+--------+----------+--------------------------+----------+-----------+----------------------------------+
   | 12006 | testdb | doris_be | doris_be_metadata_layout | 89349    | true      | 9a3f68160b4106b0e923a0aa2fc05599 |
   +-------+--------+----------+--------------------------+----------+-----------+----------------------------------+
   ```

- Просмотр загруженных файлов в указанной базе данных

   ```sql
   SHOW FILE FROM example_db;
   ```
   ```text
   +-------+------------+----------+--------------------------+----------+-----------+----------------------------------+
   | Id    | DbName     | Catalog  | FileName                 | FileSize | IsContent | MD5                              |
   +-------+------------+----------+--------------------------+----------+-----------+----------------------------------+
   | 12007 | example_db | doris_fe | doris_fe_metadata_layout | 569373   | true      | 10385505d3c0d03f085fea6f8d51adfa |
   | 12008 | example_db | doris_be | doris_be_metadata_layout | 89349    | true      | 9a3f68160b4106b0e923a0aa2fc05599 |
   +-------+------------+----------+--------------------------+----------+-----------+----------------------------------+
   ```
