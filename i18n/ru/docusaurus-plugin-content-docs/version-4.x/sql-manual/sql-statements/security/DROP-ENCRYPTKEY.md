## Описание {#description}

Удаляет пользовательский ключ. Указанное имя должно в точности совпадать с именем удаляемого ключа.

## Синтаксис {#syntax}

```sql
DROP ENCRYPTKEY [IF EXISTS] <key_name>
```

## Обязательные параметры {#required-parameters}

**1. `<key_name>`**

> Задаёт имя удаляемого ключа, которое может включать идентификатор базы данных.
> Пример: `db1.my_key`

## Необязательные параметры {#optional-parameters}

**1. `[IF EXISTS]`**

> Если этот параметр указан, попытка удалить несуществующий ключ не вызовет ошибку.

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать следующими минимальными привилегиями:

| Привилегия   | Объект              | Примечания                                                                                   |
|:-------------|:------------|:----------------------------------------------------------------------------------------|
| `ADMIN_PRIV` | Пользователь / Роль | Для удаления ключей пользователь или роль должны обладать привилегией `ADMIN_PRIV` |

## Пример {#example}

- Удаление ключа

  ```sql
  DROP ENCRYPTKEY my_key;
  ```
- Удаление ключа без ошибки, если он не существует

  ```sql
  DROP ENCRYPTKEY IF EXISTS testdb.my_key;
  ```
