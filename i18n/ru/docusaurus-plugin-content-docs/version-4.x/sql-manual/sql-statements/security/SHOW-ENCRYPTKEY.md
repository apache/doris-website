## Описание {#description}

Отображает все пользовательские ключи в базе данных. Если пользователь указывает базу данных, запрос выполняется в указанной базе данных, в противном случае
запрос выполняется непосредственно в базе данных текущего сеанса.

## Синтаксис {#syntax}

```sql
SHOW ENCRYPTKEYS [ { IN | FROM } <db> ] [ LIKE '<key_pattern>']
```

## Необязательные параметры {#optional-parameters}

**1. `<db>`**

> Имя целевой базы данных.  
> Пример: `db1` (в именах ключей вида `db1.my_key`).

**2. `<key_pattern>`**

> Шаблон для фильтрации имен ключей (поддерживаются подстановочные символы).

## Возвращаемое значение {#return-value}

| Столбец             | Описание         |
|:--------------------|:-----------------|
| `EncryptKey Name`   | Имя ключа        |
| `EncryptKey String` | Значение ключа   |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен обладать следующими минимально необходимыми привилегиями:

| Привилегия   | Объект              | Примечания                                                                           |
|:-------------|:--------------------|:-------------------------------------------------------------------------------------|
| `ADMIN_PRIV` | Пользователь / Роль | Для просмотра ключей шифрования необходимо иметь привилегию `ADMIN_PRIV` для целевого пользователя или роли |

## Примечания по использованию {#usage-notes}

Если база данных указана явно, система выполняет запрос ключей шифрования в указанной базе данных. В противном случае
запрос ключей автоматически выполняется в базе данных текущего сеанса.

## Пример {#example}

- Вывести все пользовательские ключи в базе данных текущего сеанса.

    ```sql
    SHOW ENCRYPTKEYS;
    ```
    ```text
    +-----------------+-------------------+
    | EncryptKey Name | EncryptKey String |
    +-----------------+-------------------+
    | testdb.test_key | ABCD123456789     |
    +-----------------+-------------------+
    ```
- Вывести все пользовательские ключи в указанной базе данных.

    ```sql
    SHOW ENCRYPTKEYS FROM example_db ;
    ```
    ```text
    +---------------------+-------------------+
    | EncryptKey Name     | EncryptKey String |
    +---------------------+-------------------+
    | example_db.my_key   | ABCD123456789     |
    | example_db.test_key | ABCD123456789     |
    +---------------------+-------------------+
    ```

- Отфильтровать ключи по шаблону имени в указанной базе данных.

    ```sql
    SHOW ENCRYPTKEYS FROM example_db LIKE "%my%";
    ```
    ```text
    +-------------------+-------------------+
    | EncryptKey Name   | EncryptKey String |
    +-------------------+-------------------+
    | example_db.my_key | ABCD123456789     |
    +-------------------+-------------------+
    ```
