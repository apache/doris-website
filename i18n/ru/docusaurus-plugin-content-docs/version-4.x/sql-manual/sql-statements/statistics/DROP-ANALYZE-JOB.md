## Описание {#description}

Удаляет историю указанного задания по сбору статистики.

## Синтаксис {#syntax}

```sql
DROP ANALYZE JOB <job_id>
```

# Обязательные параметры {#required-parameters}

**<job_id>**

> Указывает идентификатор задания. Получить job_id можно, выполнив SHOW ANALYZE. Подробные сведения об использовании см. в разделе "SHOW ANALYZE".

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право | Объект | Примечания |
| ----------- | ------ | ----- |
| SELECT_PRIV | таблица |       |

## Примеры {#examples}

Удаление записи о задании по сбору статистики с идентификатором 10036

```sql
DROP ANALYZE JOB 10036
```
