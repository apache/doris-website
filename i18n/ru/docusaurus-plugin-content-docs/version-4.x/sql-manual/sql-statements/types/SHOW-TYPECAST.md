## Описание {#description}

Отображает все преобразования типов в базе данных. Если пользователь указывает базу данных, отображаются преобразования в указанной базе данных; в противном случае
запрос выполняется непосредственно к базе данных, связанной с текущим сеансом

## Синтаксис {#syntax}

```sql
SHOW TYPE_CAST [ { IN | FROM } <db>]
```

## Обязательные параметры {#required-parameters}

**1. `<db>`**

Имя базы данных, к которой выполняется запрос.

## Возвращаемое значение {#return-value}

| Имя столбца | Описание     |
|-------------|-----------------|
| Исходный тип | Исходный тип   |
| Целевой тип   | Тип после преобразования |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право   | Объект        | Примечания                                                                                            |
|-------------|---------------|--------------------------------------------------------------------------------------------------|
| `Select_priv` | База данных (DB) | Для просмотра всех преобразований типов в базе данных пользователь или роль должны иметь право `Select_priv` на эту базу данных |

## Примечания по использованию {#usage-notes}

Если пользователь указывает базу данных, система выполняет запрос к указанной базе данных; в противном случае по умолчанию запрос выполняется
к базе данных, связанной с текущим сеансом.
