## Описание {#description}

Эта инструкция позволяет просмотреть историю успешно выполненных задач удаления

## Синтаксис {#syntax}

```sql
SHOW DELETE [FROM <db_name>]
```

## Необязательные параметры {#optional-parameters}
**<db_name>** : Имя базы данных, для которой нужно отобразить историю задач удаления

## Возвращаемое значение {#return-value}
| Столбец            | Описание                                                                      |
|-------------------|----------------------------------------------------------------------------------|
| `TableName`       | Имя таблицы, в которой выполнялась операция удаления.                   |
| `PartitionName`   | Имя раздела, затронутого операцией удаления.                      |
| `CreateTime`      | Временная метка отправки операции удаления.                              |
| `DeleteCondition` | Условие операции удаления, определяющее, какие строки были удалены. |
| `State`           | Состояние операции удаления                                               |


## Пример {#example}

1. Перейдите в тестовую базу данных, чтобы просмотреть историю всех задач удаления
     ```sql
    show delete;
    ```
    ```text
    +---------------+---------------+---------------------+-----------------+----------+
    | TableName     | PartitionName | CreateTime          | DeleteCondition | State    |
    +---------------+---------------+---------------------+-----------------+----------+
    | iceberg_table | *             | 2025-03-14 15:53:32 | id EQ "1"       | FINISHED |
    +---------------+---------------+---------------------+-----------------+----------+
    ```

2. Отобразите историю всех задач удаления в базе данных

     ```sql
     show delete from tpch;
     ```
     ```
     +-----------+---------------+---------------------+-------------------+----------+
     | TableName | PartitionName | CreateTime          | DeleteCondition   | State    |
     +-----------+---------------+---------------------+-------------------+----------+
     | customer  | *             | 2025-03-14 15:45:19 | c_custkey EQ "18" | FINISHED |
     +-----------+---------------+---------------------+-------------------+----------+
     ```
