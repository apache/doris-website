## Описание {#description}

Используется для ручной очистки меток ранее выполненных задач импорта. После очистки метки можно использовать повторно.
Обычно применяется в автоматических задачах импорта, запускаемых программами. При повторном выполнении в качестве метки импорта задаётся фиксированная строка.
Перед запуском каждой задачи импорта выполните эту инструкцию для очистки метки.

## Синтаксис {#syntax}

```sql
CLEAN LABEL [ <label> ] FROM <db_name>;
```

## Обязательные параметры {#required-parameters}

**1. `<db_name>`**  
  label Имя базы данных.

## Необязательные параметры {#optional-parameters}

**1. `<label>`**    
  Метка для очистки. Если параметр не указан, по умолчанию очищаются все метки в текущей базе данных.

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право                 | Объект     | Примечания                                    |
|:----------------------|:-----------|:----------------------------------------------|
| ALTER_PRIV            | База данных | Требуется право на изменение базы данных.    |


## Примеры {#examples}

- Очистка метки label1 в базе данных db1

   ```sql
   CLEAN LABEL label1 FROM db1;
   ```

- Очистка всех меток в базе данных db1

   ```sql
   CLEAN LABEL FROM db1;
   ```
