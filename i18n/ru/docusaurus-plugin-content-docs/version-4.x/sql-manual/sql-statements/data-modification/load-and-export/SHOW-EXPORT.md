## Описание {#description}

Эта инструкция используется для просмотра состояния выполнения указанного задания экспорта.

## Синтаксис {#syntax}

```sql
SHOW EXPORT
[ FROM <db_name> ]
  [
    WHERE
      [ ID = <job_id> ]
      [ STATE = { "PENDING" | "EXPORTING" | "FINISHED" | "CANCELLED" } ]
      [ LABEL = <label> ]
   ]
[ ORDER BY <column_name> [ ASC | DESC ] [, column_name [ ASC | DESC ] ... ] ]
[ LIMIT <limit> ];
```

## Необязательные параметры {#optional-parameters}

**1. `<db_name>`**: Необязательный параметр. Если не указан, используется текущая база данных по умолчанию.

**2. `<job_id>`**: Необязательный параметр. Задаёт идентификатор задания экспорта, которое нужно отобразить.

**3. `<label>`**: Необязательный параметр. Задаёт метку задания экспорта, которое нужно отобразить.

**4. `<column_name>`**: Необязательный параметр. Задаёт имя столбца для сортировки.

**5. `<limit>`**: Необязательный параметр. Если указан, отображается только заданное количество подходящих записей; если не указан, отображаются все записи.


## Возвращаемое значение {#return-value}

| Столбец | Тип данных | Описание |
|-------------|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| JobId | string | Уникальный идентификатор задания |
| Label | string | Метка задания экспорта. Если не указана, система генерирует её по умолчанию. |
| State | string | Состояние задания: <br> - `PENDING`: Задание ожидает запуска планировщиком <br> - `EXPORTING`: Выполняется экспорт данных <br> - `FINISHED`: Задание успешно выполнено <br> - `CANCELLED`: Задание завершилось с ошибкой |
| Progress | string | Прогресс задания, измеряемый по числу выполненных планов запросов. Например, если из 10 потоков завершены 3, прогресс составляет 30%. |
| TaskInfo | json | Информация о задании в формате JSON: <br> - db: Имя базы данных <br> - tbl: Имя таблицы <br> - partitions: Разделы, указанные для экспорта; пустой (`empty`) список означает все разделы <br> - column_separator: Разделитель столбцов в экспортируемом файле <br> - line_delimiter: Разделитель строк в экспортируемом файле <br> - tablet num: Общее количество задействованных tablet <br> - broker: Имя используемого брокера <br> - coord num: Количество планов запросов <br> - max_file_size: Максимальный размер экспортируемого файла <br> - delete_existing_files: Нужно ли удалять существующие файлы и каталоги в каталоге экспорта <br> - columns: Столбцы для экспорта; пустое значение означает экспорт всех столбцов <br> - format: Формат экспортируемого файла |
| Path | string | Путь экспорта в удалённом хранилище |
| CreateTime | string | Время создания задания |
| StartTime | string | Время начала выполнения задания |
| FinishTime | string | Время завершения задания |
| Timeout | int | Время ожидания выполнения задания (в секундах). Отсчитывается от CreateTime. |
| ErrorMsg | string | Если при выполнении задания возникает ошибка, здесь отображается её причина. |
| OutfileInfo | string | Если задание экспорта выполнено успешно, здесь отображается подробная информация о результате `SELECT INTO OUTFILE`. |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право | Объект | Примечания |
|:-------------|:--------------------|:------------------------------------------------|
| SELECT_PRIV | База данных (база данных) | Требуется доступ на чтение к базе данных и таблице. |


## Примеры {#examples}

- Показать все задания экспорта для базы данных по умолчанию

    ```sql
    SHOW EXPORT;
    ```

- Показать задания экспорта для указанной базы данных, отсортированные по StartTime в порядке убывания

    ```sql
     SHOW EXPORT FROM example_db ORDER BY StartTime DESC;
    ```

- Показать задания экспорта для указанной базы данных в состоянии "exporting", отсортированные по StartTime в порядке убывания

    ```sql
    SHOW EXPORT FROM example_db WHERE STATE = "exporting" ORDER BY StartTime DESC;
    ```

- Показать задание экспорта для указанной базы данных с указанным job_id

    ```sql
      SHOW EXPORT FROM example_db WHERE ID = job_id;
    ```

- Показать задание экспорта для указанной базы данных с указанной меткой

    ```sql
     SHOW EXPORT FROM example_db WHERE LABEL = "mylabel";
    ```
