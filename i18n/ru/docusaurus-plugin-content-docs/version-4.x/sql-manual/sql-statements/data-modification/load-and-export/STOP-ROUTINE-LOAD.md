## Описание {#description}

Этот синтаксис используется для остановки задания Routine Load. В отличие от команды PAUSE, остановленные задания нельзя запустить повторно. Если необходимо снова загрузить данные, потребуется создать новое задание загрузки.

## Синтаксис {#syntax}

```sql
STOP ROUTINE LOAD FOR <job_name>;
```

## Обязательные параметры {#required-parameters}

**1. `<job_name>`**

> Задаёт имя задания, которое нужно остановить. Допустимы следующие форматы:
>
> - `<job_name>`: остановить задание с указанным именем в текущей базе данных
> - `<db_name>.<job_name>`: остановить задание с указанным именем в указанной базе данных

## Требования к управлению доступом {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующее разрешение:

| Привилегия | Объект | Примечания |
| :--------- | :----- | :------------------------------------------------------- |
| LOAD_PRIV  | Таблица | Для выполнения STOP ROUTINE LOAD требуется разрешение LOAD на таблицу |

## Примечания {#notes}

- Операция остановки необратима; остановленные задания нельзя запустить повторно с помощью команды RESUME
- Операция остановки вступает в силу немедленно, а выполняющиеся задачи прерываются
- Перед остановкой задания рекомендуется проверить его состояние с помощью команды SHOW ROUTINE LOAD
- Если нужно лишь временно приостановить задание, используйте команду PAUSE

## Примеры {#examples}

- Остановить задание Routine Load с именем test1

   ```sql
   STOP ROUTINE LOAD FOR test1;
   ```

- Остановить задание Routine Load в указанной базе данных

   ```sql
   STOP ROUTINE LOAD FOR example_db.test1;
   ```
