## Описание {#description}

Этот синтаксис используется для просмотра выполняющихся в данный момент подзадач указанного задания Routine Load.

## Синтаксис {#syntax}

```sql
SHOW ROUTINE LOAD TASK WHERE JobName = <job_name>;
```

## Обязательные параметры {#required-parameters}

**1. `<job_name>`**

> Имя задания Routine Load, подзадачи которого нужно просмотреть.

## Возвращаемые результаты {#return-results}

Возвращаемые результаты содержат следующие поля:

| Имя поля             | Описание                                                     |
| :------------------- | :---------------------------------------------------------- |
| TaskId               | Уникальный идентификатор подзадачи                           |
| TxnId                | Идентификатор транзакции загрузки, соответствующей подзадаче  |
| TxnStatus            | Статус транзакции загрузки для подзадачи. Null означает, что подзадача ещё не была запланирована к выполнению |
| JobId                | Идентификатор задания, которому принадлежит подзадача        |
| CreateTime           | Время создания подзадачи                                     |
| ExecuteStartTime     | Время, когда подзадача была запланирована к выполнению, обычно позже времени её создания |
| Timeout              | Время ожидания подзадачи, обычно вдвое превышающее значение `max_batch_interval`, заданное для задания |
| BeId                 | Идентификатор узла BE, выполняющего эту подзадачу             |
| DataSourceProperties | Начальное смещение раздела Kafka, данные из которого подзадача готовится читать. Это строка в формате JSON. Ключ — идентификатор раздела, значение — начальное смещение для чтения |

## Требования к управлению доступом {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие привилегии:

| Привилегия | Объект | Примечания |
| :-------- | :----- | :---- |
| LOAD_PRIV | Таблица | Для SHOW ROUTINE LOAD TASK требуется привилегия LOAD для таблицы |

## Примечания {#notes}

- Значение null в TxnStatus не указывает на ошибку задачи: оно может означать, что задача ещё не была запланирована к выполнению
- Сведения о смещении в DataSourceProperties можно использовать для отслеживания хода чтения данных
- По истечении Timeout задача автоматически завершается независимо от того, завершено ли чтение данных

## Примеры {#examples}

- Показать сведения о подзадачах задания Routine Load с именем test1.

    ```sql
    SHOW ROUTINE LOAD TASK WHERE JobName = "test1";
    ```
