## Описание {#description}

Этот синтаксис используется для приостановки одного или всех заданий Routine Load. Приостановленные задания можно возобновить с помощью команды RESUME.

## Синтаксис {#syntax}

```sql
PAUSE [ALL] ROUTINE LOAD FOR <job_name>
```

## Обязательные параметры {#required-parameters}

**1. `<job_name>`**

> Указывает имя задания, которое нужно приостановить. Если указан ALL, параметр job_name не требуется.

## Необязательные параметры {#optional-parameters}

**1. `[ALL]`**

> Необязательный параметр. Если указан ALL, приостанавливаются все задания Routine Load.

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующие привилегии:

| Привилегия | Объект | Примечания |
| :-------- | :----- | :---- |
| LOAD_PRIV | Таблица | Для PAUSE ROUTINE LOAD требуется привилегия LOAD для таблицы |

## Примечания {#notes}

- После приостановки задание можно возобновить с помощью команды RESUME
- Операция приостановки не влияет на задачи, уже отправленные на BE: эти задачи продолжат выполняться до завершения

## Примеры {#examples}

- Приостановить задание Routine Load с именем test1.

   ```sql
   PAUSE ROUTINE LOAD FOR test1;
   ```

- Приостановить все задания Routine Load.

   ```sql
   PAUSE ALL ROUTINE LOAD;
   ```
