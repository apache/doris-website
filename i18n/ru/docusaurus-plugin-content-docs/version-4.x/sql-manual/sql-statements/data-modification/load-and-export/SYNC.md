## Описание {#description}

Этот оператор используется для синхронизации метаданных на узлах Frontend (FE), не являющихся главными. В Apache Doris только главный узел FE может записывать метаданные, а остальные узлы FE перенаправляют операции записи метаданных главному узлу. После того как главный узел завершит запись метаданных, на остальных узлах возможна небольшая задержка при применении этих изменений. Этот оператор позволяет принудительно синхронизировать метаданные.

## Синтаксис {#syntax}

```sql
SYNC;
```

## Требования к правам доступа {#access-control-requirements}

Эту операцию может выполнять любой пользователь или любая роль.


## Примеры {#examples}

Синхронизация метаданных:

    ```sql
    SYNC;
    ```
