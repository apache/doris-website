## Описание {#description}

Этот оператор используется для отображения команды создания задания Routine Load.

Результат показывает разделы Kafka, из которых в данный момент считываются данные, и соответствующие смещения для дальнейшего чтения. Результат может не отражать текущую позицию чтения данных, поэтому следует ориентироваться на результат [show routine load](./SHOW-ROUTINE-LOAD.md).

## Синтаксис {#syntax}

```sql
SHOW [ALL] CREATE ROUTINE LOAD for <load_name>;
```

## Обязательные параметры {#required-parameters}

**1. `<load_name>`**

> Имя задания Routine Load

## Необязательные параметры {#optional-parameters}

**1. `[ALL]`**

> Необязательный параметр для получения всех заданий, включая исторические

## Требования к правам доступа {#access-control-requirements}

Пользователи, выполняющие эту команду SQL, должны иметь как минимум следующее право доступа:

| Право доступа | Объект | Примечания |
| :--------- | :----- | :------------------------------------------------------- |
| LOAD_PRIV | Таблица | Для SHOW CREATE ROUTINE LOAD требуется право LOAD на таблицу |

## Примеры {#examples}

- Отображение команды создания указанного задания Routine Load в базе данных по умолчанию

   ```sql
   SHOW CREATE ROUTINE LOAD for test_load
   ```
