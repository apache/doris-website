## Описание {#description}

Эта инструкция используется для удаления созданного репозитория.

## Синтаксис {#syntax}

```sql
DROP REPOSITORY <repo_name>;
```

## Обязательные параметры {#required-parameters}
**<repo_name>**
> Уникальное имя репозитория.

## Требования к правам доступа {#access-control-requirements}

| Привилегия               | Объект                         | Примечания                                               |
|:-------------------|:-----------------------------|:----------------------------------------------------|
| ADMIN_PRIV         | Права на управление всем кластером | Создавать репозитории может только root или суперпользователь  |


## Примечания по использованию {#usage-notes}
- При удалении репозитория удаляется только его привязка в Doris, а сами данные репозитория сохраняются. После удаления репозиторий можно привязать повторно, указав то же значение LOCATION.

## Примеры {#examples}

Удаление репозитория с именем example_repo:

```sql
DROP REPOSITORY `example_repo`;
```
