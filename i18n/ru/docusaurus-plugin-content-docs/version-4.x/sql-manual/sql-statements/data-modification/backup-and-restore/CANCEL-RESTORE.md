## Описание {#description}

Этот оператор используется для отмены выполняющейся задачи RESTORE.

## Синтаксис {#syntax}

```sql
CANCEL RESTORE FROM <db_name>;
```

## Параметры {#parameters}

**1.`<db_name>`**

Имя базы данных, к которой относится задача восстановления.

## Примечания по использованию {#usage-notes}

- При отмене задачи восстановления на этапе COMMIT или на более позднем этапе восстанавливаемая таблица может стать недоступной. В этом случае восстановить данные можно только повторным выполнением задачи восстановления.

## Пример {#example}

1. Отмените задачу RESTORE для example_db.

```sql
CANCEL RESTORE FROM example_db;
```
