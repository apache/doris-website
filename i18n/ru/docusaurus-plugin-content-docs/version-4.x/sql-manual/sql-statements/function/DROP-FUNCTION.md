## Описание {#description}

Удаляет пользовательскую функцию.

## Синтаксис {#syntax}

```sql
DROP [ GLOBAL ] FUNCTION <function_name> ( <arg_type> )
```

## Обязательные параметры {#required-parameters}

**1. `<function_name>`**

> Указывает имя функции, которую нужно удалить.
>
> Имя функции должно точно совпадать с именем, указанным при её создании.

**2. `<arg_type>`**

> Указывает список аргументов удаляемой функции.
>
> В списке параметров необходимо указать тип данных параметра для каждой позиции.

## Необязательные параметры {#optional-parameters}

**1.`GLOBAL`**

> GLOBAL является необязательным параметром.
>
> Если задан GLOBAL, функция ищется в глобальной области и удаляется.
>
> Если GLOABL не указан, функция ищется в текущей базе данных и удаляется.

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право      | Объект         | Примечания  |
|:-----------|:---------------|:------------|
| ADMIN_PRIV | Пользовательская функция| DROP является административной операцией |


## Примечания по использованию {#usage-notes}

- Функцию можно удалить только при точном совпадении имени и типов параметров

## Примеры {#examples}

```sql
DROP FUNCTION my_add(INT, INT)
```

```sql
DROP GLOBAL FUNCTION my_add(INT, INT)
```
