## Описание {#description}

Этот оператор используется для просмотра оператора создания пользовательской функции

## Синтаксис {#syntax}

```sql
SHOW CREATE [ GLOBAL ] FUNCTION <function_name>( <arg_type> ) [ FROM <db_name> ];
```

## Обязательные параметры {#required-parameters}

**1. `<function_name>`**

> Имя пользовательской функции, для которой запрашивается оператор создания.

**2. `<arg_type>`**

> Список параметров пользовательской функции, для которой запрашивается оператор создания.
>
> На каждой позиции в списке параметров необходимо указать тип данных соответствующего параметра

## Необязательные параметры {#optional-parameters}

**1.`GLOBAL`**

> GLOBAL — необязательный параметр.
>
> Если указан GLOBAL, функция ищется в глобальной области и удаляется.
>
> Если GLOABL не указан, функция ищется в текущей базе данных и удаляется.

**2.`<db_name>`**

> FROM db_name указывает, что запрос пользовательской функции выполняется в указанной базе данных

## Возвращаемое значение {#return-value}

| Столбец          | Описание          |
|-----------------|-------------|
| SYMBOL          | Имя пакета функции        |
| FILE            | Путь к jar-пакету     |
| ALWAYS_NULLABLE | Может ли результат быть NULL |
| TYPE            | Тип функции        |

## Требования к правам доступа {#access-control-requirements}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие права:

| Право | Объект   | Примечания       |
|:----------|:---------|:--------------|
| SHOW_PRIV | Функция | Необходимо иметь право на просмотр этой функции |

## Примеры {#examples}

```sql
SHOW CREATE FUNCTION add_one(INT)
```

```text
| Function Signature | Create Function
+--------------------+-------------------------------------------------------
| add_one(INT)       | CREATE FUNCTION add_one(INT) RETURNS INT PROPERTIES (
  "SYMBOL"="org.apache.doris.udf.AddOne",
  "FILE"="file:///xxx.jar",
  "ALWAYS_NULLABLE"="true",
  "TYPE"="JAVA_UDF"
  ); |
+--------------------+-------------------------------------------------------
```
