## Описание {#description}

Эта инструкция используется для поиска имени базы данных по её идентификатору (доступна только администраторам)

## Синтаксис {#syntax}

```sql
SHOW DATABASE <database_id>
```

## Обязательные параметры {#required-parameters}

** 1. `<database_id>`**
>  Идентификатор базы данных

## Возвращаемое значение {#return-value}

| Столбец | Описание |
|:---------|:-----------|
| DbName |  Имя базы данных|

## Управление доступом {#permission-control}

Пользователь, выполняющий эту команду SQL, должен иметь как минимум следующие привилегии:

| Привилегии         | Объект   | Примечания            |
|:-----------|:-----|:--------------|
| ADMIN_PRIV | Весь кластер | Требуются административные привилегии на весь кластер |

## Пример {#example}

- Найти имя базы данных по её идентификатору

    ```sql
    SHOW DATABASE 10396;
    ```

    ```text
    +------------+
    | DbName     |
    +------------+
    | example_db |
    +------------+
    ```
