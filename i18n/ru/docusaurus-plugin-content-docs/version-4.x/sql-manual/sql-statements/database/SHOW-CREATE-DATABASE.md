## Описание {#description}

Эта инструкция позволяет просмотреть сведения о создании встроенной базы данных doris или базы данных в Catalog.

## Синтаксис {#syntax}

```sql
SHOW CREATE DATABASE [<catalog>.]<db_name>;
```

## Обязательные параметры {#required-parameters}

** 1. `<db_name>`**
>  Имя базы данных

## Необязательные параметры {#optional-parameters}

** 1. `<catalog>`**
>  Указывает, является ли таблица внутренней или внешней

## Возвращаемое значение {#return-value}

| Столбец | Описание |
|:---------|:-----------|
| Database | Имя базы данных |
| Create Database | Соответствующая инструкция создания базы данных |

## Управление доступом {#permission-control}

Пользователь, выполняющий эту команду SQL, должен обладать как минимум следующими правами:

| Права         | Объект    | Примечания             |
|:-----------|:------|:---------------|
| SELECT_PRIV | Соответствующая база данных | Требуется право на чтение соответствующей базы данных |

## Пример {#example}

- Просмотр инструкции создания базы данных test в doris

   ```sql
   SHOW CREATE DATABASE test;
   ```

   ```text
   +----------+------------------------+
   | Database | Create Database        |
   +----------+------------------------+
   | test     | CREATE DATABASE `test` |
   +----------+------------------------+
   ```

- Просмотр сведений о создании базы данных hdfs_text в Catalog hive

   ```sql
   SHOW CREATE DATABASE hdfs_text;
   ```

   ```text
   +-----------+------------------------------------------------------------------------------------+                         
   | Database  | Create Database                                                                    |                         
   +-----------+------------------------------------------------------------------------------------+                         
   | hdfs_text | CREATE DATABASE `hdfs_text` LOCATION 'hdfs://HDFS1009138/hive/warehouse/hdfs_text' |                         
   +-----------+------------------------------------------------------------------------------------+  
   ```
