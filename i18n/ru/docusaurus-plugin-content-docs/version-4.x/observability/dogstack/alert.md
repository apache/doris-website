Благодаря интеграции DOG Stack с Grafana вы можете создавать оповещения и управлять ими непосредственно в Grafana. В этой статье описаны основные операции с оповещениями. Подробнее о расширенных возможностях см. в [документации Grafana Alerting](https://grafana.com/docs/grafana/latest/alerting/).

На рисунке показан основной принцип работы оповещений Grafana:

1. Пользователь задаёт правила оповещения, включая базовый запрос и условие срабатывания.
2. Система периодически выполняет запрос из правила и проверяет условие срабатывания.
3. Если условие выполнено, создаётся экземпляр оповещения.
4. Затем оповещение отправляется напрямую в точку контакта или маршрутизируется с помощью гибко настраиваемых политик уведомлений.

![Обзор оповещений](https://cdnd.selectdb.com/images/upload/dogstack/alert_overview.png)



Типичный процесс создания правил оповещения и управления ими выглядит так:

**1. Откройте Grafana Alerting → Правила оповещения и нажмите «Создать оповещение»**

![Создание оповещения](https://cdnd.selectdb.com/images/upload/dogstack/alert_create.png)



**2. Задайте запрос и условие срабатывания**

Сначала выберите источник данных, например Doris. В режиме **Конструктор** можно составить простой запрос с помощью визуального интерфейса, а в режиме **Код** — написать SQL для более сложных запросов. В этом примере используется режим **Код**, чтобы получить количество строк в `otel.otel_logs` за последние 10 минут, в поле `body` которых встречается ключевое слово `error`.

Затем в разделе **Выражение** выберите способ дополнительной агрегации результата запроса (необязательно) и задайте порог срабатывания оповещения. В этом примере порог задан как «result > 10», а дополнительная агрегация не применяется.

Наконец, нажмите **Предпросмотр**, чтобы просмотреть результат запроса и проверить, сработает ли оповещение. Здесь запрос возвращает 882, что превышает порог 10, поэтому отображается статус **1 сработавшее оповещение**.

Подробнее см. в [документации Grafana](https://grafana.com/docs/grafana/latest/alerting/alerting-rules/create-grafana-managed-rule/).

![Условие срабатывания оповещения](https://cdnd.selectdb.com/images/upload/dogstack/alert_condition.png)



**3. Настройте интервал проверки и группировку оповещений**

Сначала выберите папку для группировки оповещений, затем задайте интервал проверки оповещения и, наконец, длительность ожидания. В примере создаётся группа проверки, которая запускается каждую минуту, и выбирается «Ожидание = Нет». Это означает, что оповещение переходит в состояние **Сработало** сразу при выполнении условия, без ожидания, в течение которого условие должно оставаться выполненным (например, 1 минуту).

Подробнее см. в [документации Grafana](https://grafana.com/docs/grafana/latest/alerting/fundamentals/alert-rule-evaluation/).

![Проверка оповещений](https://cdnd.selectdb.com/images/upload/dogstack/alert_evaluation.png)



**4. Настройте канал уведомлений**

Grafana поддерживает множество каналов уведомлений: электронную почту, Slack, Discord, PagerDuty, Webhook и другие. Вы можете выбрать существующую точку контакта или создать свою, а также настроить гибкие политики уведомлений для маршрутизации оповещений на основе меток.

Подробнее см. в [документации Grafana](https://grafana.com/docs/grafana/latest/alerting/fundamentals/notifications/).

![Метки оповещения](https://cdnd.selectdb.com/images/upload/dogstack/alert_lable.png)

![Точка контакта для оповещений](https://cdnd.selectdb.com/images/upload/dogstack/alert_contact.png)



**5. Настройте текст уведомления**

Вы можете настроить содержимое уведомления, включая краткое описание, подробное описание и URL инструкции по реагированию, чтобы получатели быстрее понимали, что произошло.

![Текст уведомления](https://cdnd.selectdb.com/images/upload/dogstack/alert_message.png)



**6. Управление оповещениями**

После создания правил оповещения вы можете управлять ими: приостанавливать оповещения, временно отключать уведомления, изменять правила, менять канал уведомлений и выполнять другие действия.

Подробнее см. в [документации Grafana](https://grafana.com/docs/grafana/latest/alerting/monitor-status/).

![Управление оповещениями](https://cdnd.selectdb.com/images/upload/dogstack/alert_management.png)
