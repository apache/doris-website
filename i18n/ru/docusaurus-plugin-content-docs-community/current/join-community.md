# Присоединяйтесь к сообществу Apache Doris {#join-the-apache-doris-community}

<!-- Knowledge type: Procedure -->
<!-- Applicable scenario: New user onboarding / Joining the community -->

[Apache Doris](https://github.com/apache/doris) представляет собой проект хранилища данных реального времени с открытым исходным кодом, который поддерживают пользователи и разработчики со всего мира. В июне 2022 года проект вышел из Apache Incubator и получил статус Apache Top-Level Project (TLP). На этой странице перечислены официальные каналы общения сообщества. Выберите наиболее удобный для вас канал, чтобы участвовать в обсуждениях и следить за новостями.

:::tip Хотите внести вклад в развитие сообщества?

Если вы хотите внести вклад в Apache Doris, занимаясь разработкой кода, созданием материалов или популяризацией проекта, начните с [руководства по участию в проекте](how-to-contribute/contribute-to-doris.mdx).

:::

## Обзор официальных каналов сообщества {#overview-of-official-community-channels}

Назначение каждого канала и варианты его использования приведены ниже:

| Канал | Назначение | Ссылка |
|------|------|------|
| Slack | Обсуждения, вопросы и ответы в реальном времени (рекомендуется новым пользователям) | [https://doris.apache.org/slack](https://doris.apache.org/slack?utm_source=website&utm_medium=docs&utm_content=community_join_page) |
| GitHub | Исходный код, задачи, PRs, примечания к выпускам | <https://github.com/apache/doris> |
| Список рассылки | Официальный канал Apache для асинхронных обсуждений и принятия решений | См. [Подписка на список рассылки](subscribe-mail-list) |
| Twitter | Примеры использования со всего мира, новости о выпусках, анонсы мероприятий | <https://twitter.com/doris_apache> |
| LinkedIn | Расширение круга профессиональных знакомств, вакансии и новости отрасли | <https://www.linkedin.com/company/doris-apache/> |
| YouTube | Видеозаписи зарубежных Meetup и технических докладов | <https://www.youtube.com/hashtag/apachedoris> |
| Bilibili | Видеозаписи Meetup и технических докладов в Китае | <https://space.bilibili.com/362350065> |

## Выбор канала в зависимости от задачи {#choose-a-channel-by-scenario}

<!-- Knowledge type: Scenario routing -->

- **Чтобы быстро задать вопрос или участвовать в ежедневных обсуждениях**: присоединяйтесь к [Slack](https://doris.apache.org/slack?utm_source=website&utm_medium=docs&utm_content=community_join_page).
- **Чтобы сообщить об ошибках или предложить изменения в коде**: посетите [GitHub](https://github.com/apache/doris) и ознакомьтесь с разделом [Обратная связь](feedback) и [руководством по участию в проекте](how-to-contribute/contribute-to-doris.mdx).
- **Чтобы следить за решениями сообщества и объявлениями о выпусках**: [подпишитесь на список рассылки](subscribe-mail-list).
- **Чтобы знакомиться с примерами использования и техническими материалами**: следите за публикациями в [Twitter](https://twitter.com/doris_apache) и [LinkedIn](https://www.linkedin.com/company/doris-apache/).
- **Чтобы смотреть записи Meetup и технических докладов**: посетите [YouTube](https://www.youtube.com/hashtag/apachedoris) или [Bilibili](https://space.bilibili.com/362350065).
