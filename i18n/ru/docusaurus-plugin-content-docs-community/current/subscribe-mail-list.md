# Подписка на список рассылки Apache Doris {#subscribe-to-the-apache-doris-mailing-list}

<!-- Knowledge type: Procedural steps -->
<!-- Applicable scenarios: New user onboarding / Joining the community / Following community decisions -->

Список рассылки считается наиболее общепринятым способом общения в сообществе Apache. В нём задают повседневные вопросы, обсуждают технические темы и принимают решения. Асинхронный обмен сообщениями с рассылкой всем подписчикам хорошо подходит для сообществ открытого ПО, участники которых находятся по всему миру. В этой статье описано, как подписаться на список рассылки Apache Doris `dev` за 5 шагов.

## Адреса списка рассылки {#mailing-list-address-reference}

Для подписки, обсуждений и отписки используются разные адреса электронной почты. Ниже указано назначение каждого из них:

| Назначение | Адрес электронной почты | Примечания |
|---------|---------------|-------|
| Подписка | `dev-subscribe@doris.apache.org` | Любые тема и текст письма |
| Подтверждение | `dev-help@doris.apache.org` | Автоматический ответ; для подтверждения подписки нужно ответить на это письмо |
| Повседневные обсуждения | `dev@doris.apache.org` | Используется для вопросов и обсуждений после подписки |
| Отписка | `dev-unsubscribe@doris.apache.org` | Любые тема и текст письма |

## Порядок подписки {#subscription-steps}

### 1. Отправьте запрос на подписку {#1-send-a-subscription-email}

Откройте почтовый клиент, создайте новое письмо и отправьте его на адрес `dev-subscribe@doris.apache.org`. Тема и текст письма могут быть любыми.

![Шаг 1](/images/subscribe-mail-list-step1.png)

### 2. Получите письмо для подтверждения подписки от dev-help {#2-receive-the-confirmation-email-from-dev-help}

После выполнения шага 1 вы получите письмо для подтверждения подписки с адреса `dev-help@doris.apache.org`.

> Если письмо долго не приходит, проверьте, не было ли оно заблокировано или автоматически перемещено в папки «Подписки», «Спам» или «Промоакции».

![Шаг 2](/images/subscribe-mail-list-step2.png)

### 3. Ответьте на письмо для подтверждения подписки {#3-reply-to-the-confirmation-email}

Получив письмо на предыдущем шаге, выберите один из следующих двух способов:

- **Способ A**: ответьте непосредственно на это письмо.
- **Способ B**: создайте новое письмо и укажите в качестве получателя адрес из поля «Reply-To» предыдущего письма.

В обоих случаях тема и текст письма могут быть любыми.

![Шаг 3](/images/subscribe-mail-list-step3.png)

### 4. Получите приветственное письмо {#4-receive-the-welcome-email}

После выполнения шага 3 вы получите приветственное письмо с темой **ДОБРО ПОЖАЛОВАТЬ в dev@doris.apache.org**. Подписка завершена, и теперь вы будете получать новости сообщества через этот список рассылки.

![Шаг 4](/images/subscribe-mail-list-step4.png)

### 5. Начните обсуждение по почте (необязательно) {#5-start-a-mail-discussion-optional}

После подписки отправьте письмо на адрес `dev@doris.apache.org`, чтобы начать обсуждение. Его получат все подписчики.

## Отписка от списка рассылки {#unsubscribe-from-the-mailing-list}

Чтобы отписаться, отправьте письмо на адрес `dev-unsubscribe@doris.apache.org` с любыми темой и текстом, а затем подтвердите отписку, следуя инструкциям в ответном письме.
