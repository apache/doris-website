В этом документе представлены примечания к выпускам Apache Doris Core в обратном хронологическом порядке.

## Примечания к выпускам Doris Core {#doris-core-release-notes}

:::tip Последний выпуск
🎉 Вышла версия 4.1.5. Подробнее — в 🔗[примечаниях к выпуску](./v4.1/release-4.1.5.md). В Apache Doris 4.1.5 добавлены перезапись статических разделов таблиц Hive, токенизаторы IK для пользовательских анализаторов инвертированного индекса, отдельные свойства эмбеддингов для ресурсов AI и привязка заданий Routine Load и асинхронных материализованных представлений к вычислительным группам. Также улучшены выполнение запросов, загрузка данных, совместимость с Lakehouse, работа File Cache и стабильность.

<br />

🎉 Вышла версия 4.0.8. Подробнее — в 🔗[примечаниях к выпуску](./v4.0/release-4.0.8.md). Apache Doris 4.0.8 — выпуск с исправлениями, направленными на улучшение развёртываний с раздельными вычислениями и хранением, стабильности загрузки данных и транзакций, работы File Cache, защиты внутренних конечных точек и совместимости с Lakehouse. Всем пользователям версий 4.0.x рекомендуется обновиться.

<br />

🎉 Вышла версия 3.1.4. Подробнее — в 🔗[примечаниях к выпуску](./v3.1/release-3.1.4.md). В Doris 3.1 для типа данных VARIANT появились разреженный столбец и шаблон схемы. Это повышает эффективность хранения и обработки запросов к большим наборам данных с динамическими полями, например к журналам и данным JSON. Для работы с Lakehouse улучшены асинхронные материализованные представления и расширена поддержка Iceberg и Paimon, что укрепляет связь между озёрами данных и хранилищами данных.

<br />

🎉 Вышла версия 3.0.8. Подробнее — в 🔗[примечаниях к выпуску](./v3.0/release-3.0.8.md). Начиная с версии 3.X Apache Doris поддерживает развёртывание кластеров с раздельными вычислениями и хранением наряду с режимом, в котором они объединены. Благодаря облачной архитектуре с разделёнными уровнями вычислений и хранения пользователи могут физически изолировать нагрузку от запросов между несколькими вычислительными кластерами, а также нагрузку от чтения и записи.

<br />

🎉 Вышла версия 2.1.11. Подробнее — в 🔗[примечаниях к выпуску](./v2.1/release-2.1.11.md). Версия 2.1 обеспечивает исключительную производительность: тесты TPC-DS на 1 ТБ подтвердили повышение скорости выполнения запросов при настройках по умолчанию на 100%. Аналитика данных в озёрах работает в 4–6 раз быстрее, чем в Trino и Spark. Также добавлены надёжные средства анализа полуструктурированных данных на основе нового типа Variant и набора аналитических функций, асинхронные материализованные представления для ускорения запросов, оптимизированная запись данных в реальном времени при больших нагрузках и улучшенное управление нагрузкой со стабильной работой и отслеживанием ресурсов, потребляемых SQL-запросами во время выполнения.

:::
