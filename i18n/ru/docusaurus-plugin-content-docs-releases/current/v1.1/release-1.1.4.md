В этом релизе команда Doris внесла около 60 исправлений и улучшений производительности по сравнению с версией 1.1.3. Это релиз с исправлениями ошибок для ветки 1.1, и всем пользователям рекомендуется обновиться до него.


# Возможности {#features}

- Добавлена поддержка загрузки через obs broker load в Huawei Cloud. [#13523](https://github.com/apache/doris/pull/13523)

- SparkLoad теперь поддерживает файлы parquet и orc.[#13438](https://github.com/apache/doris/pull/13438)

# Улучшения {#improvements}

- Устранён захват мьютекса в обработчике метрик, поскольку при высокой нагрузке он снижал производительность запросов.[#10941](https://github.com/apache/doris/pull/10941)


# Исправления ошибок {#bugfix}

- Условие WHERE не применялось при загрузке файла через SparkLoad. [#13804](https://github.com/apache/doris/pull/13804)

- В векторизованном режиме функция IF возвращала ошибочный результат при наличии столбца, допускающего NULL. [#13779](https://github.com/apache/doris/pull/13779)

- Исправлен неверный результат при использовании anti join с другими предикатами соединения. [#13743](https://github.com/apache/doris/pull/13743)

- Исправлен сбой BE при вызове функции concat(ifnull). [#13693](https://github.com/apache/doris/pull/13693)

- Исправлена ошибка планировщика при наличии функции в предложении GROUP BY. [#13613](https://github.com/apache/doris/pull/13613)

- Исправлено распознавание имён таблиц и столбцов в предложении LATERAL VIEW. [#13600](https://github.com/apache/doris/pull/13600)

- Исправлена ошибка «неизвестный столбец» при использовании MV и псевдонима таблицы. [#13605](https://github.com/apache/doris/pull/13605)

- JSONReader теперь освобождает память, выделенную для значения и аллокатора разбора. [#13513](https://github.com/apache/doris/pull/13513)

- Исправлена ошибка, позволявшая создавать MV с использованием to_bitmap() для столбцов с отрицательными значениями, когда enable_vectorized_alter_table имеет значение true. [#13448](https://github.com/apache/doris/pull/13448)

- Исправлена потеря микросекунд в функции from_date_format_str. [#13446](https://github.com/apache/doris/pull/13446)

- После подстановки с использованием данных smap дочернего узла признак допустимости NULL у выражений сортировки мог определяться неверно. [#13328](https://github.com/apache/doris/pull/13328)

- Исправлен сбой с созданием дампа памяти при использовании CASE с 1000 условиями. [#13315](https://github.com/apache/doris/pull/13315)

- Исправлена ошибка, из-за которой при загрузке через Stream Load терялась последняя строка данных. [#13066](https://github.com/apache/doris/pull/13066)

- При восстановлении таблицы или раздела сохраняется число реплик, которое было до резервного копирования. [#11942](https://github.com/apache/doris/pull/11942)
