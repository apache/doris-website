# Apache Doris 커뮤니티 참여 {#join-the-apache-doris-community}

<!-- Knowledge type: Procedure -->
<!-- Applicable scenario: New user onboarding / Joining the community -->

[Apache Doris](https://github.com/apache/doris)는 전 세계 사용자와 개발자가 함께 유지 관리하는 오픈 소스 실시간 데이터 웨어하우스 프로젝트입니다. 2022년 유월 Apache Incubator를 졸업하여 Apache 최상위 프로젝트 (TLP)가 되었습니다. 이 페이지에서는 커뮤니티의 공식 소통 채널을 안내합니다. 자신에게 맞는 채널을 선택하여 토론에 참여하고 소식을 받아보세요.

:::tip 커뮤니티에 기여하고 싶으신가요?

코드 개발, 콘텐츠 제작, 커뮤니티 홍보를 통해 Apache Doris에 기여하고 싶다면 [커뮤니티 기여 가이드](how-to-contribute/contribute-to-doris.mdx)부터 확인하세요.

:::

## 공식 커뮤니티 채널 개요 {#overview-of-official-community-channels}

각 채널의 목적과 활용 방법은 다음과 같습니다.

| 채널 | 목적 | 참여 링크 |
|------|------|------|
| Slack | 실시간 토론과 질의응답 (신규 사용자에게 권장) | [https://doris.apache.org/slack](https://doris.apache.org/slack?utm_source=website&utm_medium=docs&utm_content=community_join_page) |
| GitHub | 소스 코드, 이슈, PR, 릴리스 노트 | <https://github.com/apache/doris> |
| 메일링 리스트 | Apache의 공식 비동기 토론 및 의사 결정 채널 | [메일링 리스트 구독](subscribe-mail-list) 참고 |
| Twitter | 전 세계 사용자 사례, 릴리스 소식, 행사 안내 | <https://twitter.com/doris_apache> |
| LinkedIn | 기술 인맥 확장, 채용 및 업계 소식 | <https://www.linkedin.com/company/doris-apache/> |
| YouTube | 해외 Meetup 및 기술 발표 녹화 영상 | <https://www.youtube.com/hashtag/apachedoris> |
| Bilibili | 중국 내 Meetup 및 기술 발표 녹화 영상 | <https://space.bilibili.com/362350065> |

## 상황에 맞는 채널 선택 {#choose-a-channel-by-scenario}

<!-- Knowledge type: Scenario routing -->

- **간단한 질문이나 일상적인 토론에 참여하려면**: [Slack](https://doris.apache.org/slack?utm_source=website&utm_medium=docs&utm_content=community_join_page)에 참여하세요.
- **버그를 보고하거나 코드를 제출하려면**: [GitHub](https://github.com/apache/doris)를 방문하고 [피드백](feedback)과 [커뮤니티 기여 가이드](how-to-contribute/contribute-to-doris.mdx)를 참고하세요.
- **커뮤니티 의사 결정과 릴리스 공지를 확인하려면**: [메일링 리스트를 구독](subscribe-mail-list)하세요.
- **사용자 사례와 기술 인사이트를 보려면**: [Twitter](https://twitter.com/doris_apache)와 [LinkedIn](https://www.linkedin.com/company/doris-apache/)을 팔로우하세요.
- **Meetup 및 기술 발표 녹화 영상을 보려면**: [YouTube](https://www.youtube.com/hashtag/apachedoris) 또는 [Bilibili](https://space.bilibili.com/362350065)를 방문하세요.
