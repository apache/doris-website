# Apache Doris 메일링 리스트 구독하기 {#subscribe-to-the-apache-doris-mailing-list}

<!-- Knowledge type: Procedural steps -->
<!-- Applicable scenarios: New user onboarding / Joining the community / Following community decisions -->

메일링 리스트는 Apache 커뮤니티에서 가장 널리 쓰이는 소통 수단입니다. 일상적인 질문과 기술 토론, 의사 결정이 메일링 리스트에서 이루어집니다. 비동기적으로 메시지를 모든 구독자에게 전달하는 방식은 전 세계에 분산된 오픈 소스 커뮤니티에 잘 맞습니다. 이 문서에서는 Apache Doris `dev` 메일링 리스트를 구독하는 방법을 5단계로 설명합니다.

## 메일링 리스트 주소 안내 {#mailing-list-address-reference}

구독 신청, 토론, 구독 취소에는 각각 다른 이메일 주소를 사용합니다. 용도별 주소는 다음과 같습니다.

| 용도 | 이메일 주소 | 참고 사항 |
|---------|---------------|-------|
| 구독 신청 | `dev-subscribe@doris.apache.org` | 제목과 본문은 자유롭게 작성 |
| 구독 확인 | `dev-help@doris.apache.org` | 자동 응답 메일이며, 구독을 확정하려면 답장해야 함 |
| 일상적인 토론 | `dev@doris.apache.org` | 구독 후 질문과 토론에 사용 |
| 구독 취소 | `dev-unsubscribe@doris.apache.org` | 제목과 본문은 자유롭게 작성 |

## 구독 절차 {#subscription-steps}

### 1. 구독 신청 이메일 보내기 {#1-send-a-subscription-email}

이메일 클라이언트에서 새 메시지를 작성해 `dev-subscribe@doris.apache.org`로 보내세요. 제목과 본문은 자유롭게 작성해도 됩니다.

![1단계](/images/subscribe-mail-list-step1.png)

### 2. dev-help에서 보낸 확인 이메일 받기 {#2-receive-the-confirmation-email-from-dev-help}

1단계를 완료하면 `dev-help@doris.apache.org`에서 확인 이메일이 도착합니다.

> 오래 기다려도 이메일이 오지 않으면 차단되었는지, 또는 '구독', '스팸', '프로모션' 등의 폴더로 자동 분류되었는지 확인하세요.

![2단계](/images/subscribe-mail-list-step2.png)

### 3. 확인 이메일에 답장하기 {#3-reply-to-the-confirmation-email}

앞 단계에서 받은 이메일에 다음 두 방법 중 하나로 답장하세요.

- **방법 A**: 받은 이메일에 바로 답장합니다.
- **방법 B**: 새 이메일을 작성하고, 앞서 받은 이메일에 표시된 'Reply-To' 주소를 받는 사람으로 지정합니다.

어느 방법이든 제목과 본문은 자유롭게 작성해도 됩니다.

![3단계](/images/subscribe-mail-list-step3.png)

### 4. 환영 이메일 받기 {#4-receive-the-welcome-email}

3단계를 완료하면 제목이 **WELCOME to dev@doris.apache.org**인 환영 이메일이 도착합니다. 이제 구독이 완료되었으며, 이 메일링 리스트를 통해 커뮤니티 소식을 받아볼 수 있습니다.

![4단계](/images/subscribe-mail-list-step4.png)

### 5. 이메일 토론 시작하기(선택 사항) {#5-start-a-mail-discussion-optional}

구독한 후 `dev@doris.apache.org`로 이메일을 보내면 토론을 시작할 수 있습니다. 모든 구독자가 해당 이메일을 받습니다.

## 메일링 리스트 구독 취소하기 {#unsubscribe-from-the-mailing-list}

구독을 취소하려면 `dev-unsubscribe@doris.apache.org`로 이메일을 보내세요. 제목과 본문은 자유롭게 작성해도 됩니다. 그런 다음 회신 이메일의 안내에 따라 구독 취소를 확인하세요.
