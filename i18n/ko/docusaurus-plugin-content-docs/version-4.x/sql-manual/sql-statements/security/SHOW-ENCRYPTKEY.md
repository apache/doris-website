## 설명 {#description}

데이터베이스의 모든 사용자 정의 키를 조회합니다. 사용자가 데이터베이스를 지정하면 해당 데이터베이스를 확인하고, 지정하지 않으면
현재 세션의 데이터베이스를 직접 쿼리합니다.

## 구문 {#syntax}

```sql
SHOW ENCRYPTKEYS [ { IN | FROM } <db> ] [ LIKE '<key_pattern>']
```

## 선택적 매개변수 {#optional-parameters}

**1. `<db>`**

> 대상 데이터베이스의 이름입니다.  
> 예: `db1` (`db1.my_key`와 같은 키 이름에서 사용).

**2. `<key_pattern>`**

> 키 이름을 필터링하는 패턴 매개변수입니다(와일드카드 일치 지원).

## 반환 값 {#return-value}

| 열                  | 설명             |
|:--------------------|:-----------------|
| `EncryptKey Name`   | 키 이름          |
| `EncryptKey String` | 키 값            |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한을 보유해야 합니다.

| 권한         | 객체          | 참고 사항                                                                            |
|:-------------|:--------------|:-------------------------------------------------------------------------------------|
| `ADMIN_PRIV` | 사용자 / 역할 | 암호화 키를 보려면 대상 사용자/역할에 대한 `ADMIN_PRIV` 권한이 있어야 합니다 |

## 사용 시 참고 사항 {#usage-notes}

데이터베이스를 명시적으로 지정하면 시스템은 지정된 데이터베이스의 암호화 키를 쿼리합니다. 지정하지 않으면
현재 세션의 데이터베이스에 있는 키를 자동으로 쿼리합니다.

## 예제 {#example}

- 현재 세션의 데이터베이스에 있는 모든 사용자 정의 키를 나열합니다.

    ```sql
    SHOW ENCRYPTKEYS;
    ```
    ```text
    +-----------------+-------------------+
    | EncryptKey Name | EncryptKey String |
    +-----------------+-------------------+
    | testdb.test_key | ABCD123456789     |
    +-----------------+-------------------+
    ```
- 지정된 데이터베이스의 모든 사용자 정의 키를 나열합니다.

    ```sql
    SHOW ENCRYPTKEYS FROM example_db ;
    ```
    ```text
    +---------------------+-------------------+
    | EncryptKey Name     | EncryptKey String |
    +---------------------+-------------------+
    | example_db.my_key   | ABCD123456789     |
    | example_db.test_key | ABCD123456789     |
    +---------------------+-------------------+
    ```

- 지정된 데이터베이스에서 이름 패턴으로 키를 필터링합니다.

    ```sql
    SHOW ENCRYPTKEYS FROM example_db LIKE "%my%";
    ```
    ```text
    +-------------------+-------------------+
    | EncryptKey Name   | EncryptKey String |
    +-------------------+-------------------+
    | example_db.my_key | ABCD123456789     |
    +-------------------+-------------------+
    ```
