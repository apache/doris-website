## 설명 {#description}
설정된 SQL 차단 규칙을 표시합니다. 규칙 이름을 지정하지 않으면 모든 규칙을 표시합니다.

## 구문 {#syntax}
```sql
SHOW SQL_BLOCK_RULE [FOR <rule_name>];
```

## 선택적 매개변수 {#optional-parameters}

`<rule_name>`

표시할 SQL 차단 규칙의 이름입니다. 생략하면 모든 규칙을 표시합니다.

## 접근 제어 요구 사항 {#access-control-requirements}

이 명령을 실행하는 사용자에게는 다음 권한이 있어야 합니다.

| 권한 | 객체        | 비고  |
|-----------|--------------|--------|
| `ADMIN`   | 사용자 또는 역할 | 이 작업을 수행하는 데 필요합니다. |

## 예제 {#examples}

1. 모든 SQL 차단 규칙 표시  
```sql
SHOW SQL_BLOCK_RULE;
```

```text
+------------+------------------------------+---------+-------------+-----------+-------------+--------+--------+------------------------+
| Name       | Sql                          | SqlHash | PartitionNum | TabletNum | Cardinality | Global | Enable | RequirePartitionFilter |
+------------+------------------------------+---------+-------------+-----------+-------------+--------+--------+------------------------+
| test_rule  | select * from order_analysis | NULL    | 0           | 0         | 0           | true   | true   | false                  |
| test_rule2 | NULL                         | NULL    | 30          | 0         | 10000000000 | false  | true   | false                  |
+------------+------------------------------+---------+-------------+-----------+-------------+--------+--------+------------------------+
```

2. 특정 SQL 차단 규칙 표시  
```sql
SHOW SQL_BLOCK_RULE FOR test_rule2;
```

```text
+------------+------+---------+-------------+-----------+-------------+--------+--------+------------------------+
| Name       | Sql  | SqlHash | PartitionNum | TabletNum | Cardinality | Global | Enable | RequirePartitionFilter |
+------------+------+---------+-------------+-----------+-------------+--------+--------+------------------------+
| test_rule2 | NULL | NULL    | 30          | 0         | 10000000000 | false  | true   | false                  |
+------------+------+---------+-------------+-----------+-------------+--------+--------+------------------------+
```
