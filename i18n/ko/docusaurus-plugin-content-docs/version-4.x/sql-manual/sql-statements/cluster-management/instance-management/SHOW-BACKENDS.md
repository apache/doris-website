## 설명 {#description}

이 문은 BE 노드의 기본 상태 정보를 조회하는 데 사용됩니다.

## 구문 {#syntax}

```sql
 SHOW BACKENDS
```

## 반환 값 {#return-value}

| 열 | 설명 |
|-------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BackendId | 현재 BE의 ID입니다. |
| Host | 현재 BE의 IP 주소 또는 호스트 이름입니다. |
| HeartbeatPort | 현재 BE의 heartbeat 서비스 통신 포트입니다. |
| BePort | 현재 BE의 thrift RPC 통신 포트입니다. |
| HttpPort | 현재 BE의 HTTP 통신 포트입니다. |
| BrpcPort | 현재 BE의 bRPC 통신 포트입니다. |
| ArrowFlightSqlPort | 현재 BE의 ArrowFlight 프로토콜 통신 포트입니다. |
| LastStartTime | 현재 BE가 시작된 시점의 타임스탬프입니다. |
| LastHeartbeat | 현재 BE가 마지막으로 성공적으로 전송한 heartbeat의 타임스탬프입니다. |
| Alive | 현재 BE의 활성 여부입니다. |
| SystemDecommissioned | 이 값이 true이면 현재 BE 노드의 안전한 해제 절차가 진행 중임을 의미합니다. |
| TabletNum | 현재 BE에 저장된 tablet 수입니다. |
| DataUsedCapacity | 현재 BE의 데이터가 차지하는 디스크 공간입니다. |
| TrashUsedCapacity | 현재 BE의 휴지통에 있는 데이터가 차지하는 디스크 공간입니다. |
| AvailCapacity | 현재 BE의 사용 가능한 디스크 공간입니다. |
| TotalCapacity | 현재 BE의 전체 디스크 공간입니다. TotalCapacity = AvailCapacity + TrashUsedCapacity + DataUsedCapacity + 기타 비사용자 데이터 파일이 차지하는 디스크 공간입니다. |
| UsedPct | 현재 BE의 전체 디스크 공간 중 사용 중인 공간의 비율입니다. |
| MaxDiskUsedPct | 현재 BE의 모든 디스크 중 가장 높은 디스크 사용률입니다. |
| RemoteUsedCapacity | 현재 BE에서 핫/콜드 계층화 기능을 사용한 후 원격 스토리지에 업로드한 데이터가 차지하는 디스크 공간입니다. |
| Tag | 현재 BE의 태그 정보로, JSON 형식으로 표시됩니다. 저장되는 태그 정보는 배포 모드에 따라 다릅니다. 스토리지와 컴퓨팅이 통합된 모드에서는 현재 BE 리소스 그룹의 이름이 저장됩니다. 스토리지와 컴퓨팅이 분리된 모드에서는 추가 정보가 저장됩니다. |
| ErrMsg | 현재 BE의 heartbeat가 실패했을 때의 오류 메시지입니다. |
| Version | 현재 BE의 버전 정보입니다. |
| Status | 현재 BE의 일부 상태 정보로, JSON 형식으로 표시됩니다. lastSuccessReportTabletsTime, lastStreamLoadTime, isQueryDisabled, isLoadDisabled 등이 포함됩니다. 저장되는 정보는 버전에 따라 약간 다를 수 있습니다. |
| HeartbeatFailureCounter | 현재 BE의 연속 heartbeat 실패 횟수입니다. 이 횟수가 FE Master에 설정된 `max_backend_heartbeat_failure_tolerance_count`(기본값은 1)를 초과하면 `Alive` 필드가 false로 설정됩니다. |
| NodeRole | 현재 BE의 역할입니다. 두 가지 유형이 있으며, `mix`는 기본 역할이고 `computation`은 현재 노드가 연합 분석 쿼리에만 사용됨을 의미합니다. |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL을 실행하는 사용자는 최소한 다음 권한이 있어야 합니다.

| 권한 | 객체 | 설명 |
|------------|----|----|
| SELECT_PRIV | internal.information_schema | 모든 사용자는 기본적으로 이 데이터베이스에 대한 권한이 있습니다 |

## 사용 시 참고 사항 {#usage-notes}

쿼리 결과를 추가로 필터링해야 하는 경우 테이블 반환 함수 [backends()](../../../sql-functions/table-valued-functions/backends.md)를 사용할 수 있습니다. SHOW BACKENDS는 다음 문과 동일합니다.
```sql
SELECT * FROM BACKENDS();
```
