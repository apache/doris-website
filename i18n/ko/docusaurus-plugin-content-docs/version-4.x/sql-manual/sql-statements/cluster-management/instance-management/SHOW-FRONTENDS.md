## 설명 {#description}

이 문은 FE 노드의 기본 상태 정보를 조회하는 데 사용됩니다.

## 구문 {#syntax}

```sql
SHOW FRONTENDS
```

## 반환 값 {#return-value}

| 열                      | 설명                                                                                          |
|--------------------|-----------------------------------------------------------------------------------------------|
| Name               | Doris에서 현재 FE의 이름입니다. 일반적으로 `fe` 접두사가 붙은 임의의 문자열입니다. |
| Host               | 현재 FE의 IP 주소 또는 호스트 이름입니다.                                                |
| EditLogPort        | 현재 FE의 bdbje 통신 포트입니다.                                               |
| HttpPort           | 현재 FE의 http 통신 포트입니다.                                                                             |
| QueryPort          | 현재 FE의 MySQL 프로토콜 통신 포트입니다.                                                                          |
| RpcPort            | 현재 FE의 thrift RPC 통신 포트입니다.                                                                       |
| ArrowFlightSqlPort | 현재 FE의 ArrowFlight 프로토콜 통신 포트입니다.                                                                    |
| Role               | 현재 FE의 역할입니다. 가능한 값은 FOLLOWER와 OBSERVER입니다.                                                           |
| IsMaster           | 현재 FE가 Master로 선출되었는지 여부입니다.                                                                           |
| ClusterId          | 현재 Doris 클러스터의 ID입니다. 일반적으로 무작위로 생성된 숫자입니다.                                                                  |
| Join               | 현재 FE 노드가 현재 Doris 클러스터에 성공적으로 참여했는지 여부를 나타냅니다.                                                                 |
| Alive              | 현재 FE가 활성 상태인지 여부입니다.                                                                                    |
| ReplayedJournalId  | 현재 FE가 재생한 메타데이터 로그 중 가장 큰 ID입니다.                                                                         |
| LastStartTime      | 현재 FE가 시작된 시점의 타임스탬프입니다.                                                                                  |
| LastHeartbeat      | 현재 FE가 마지막으로 성공적으로 전송한 하트비트의 타임스탬프입니다.                                                                           |
| IsHelper           | 현재 FE가 bdbje의 도우미 노드인지 여부입니다.                                                                  |
| ErrMsg             | 현재 FE의 하트비트가 실패했을 때의 오류 메시지입니다.                                                                              |
| Version            | 현재 FE의 버전 정보입니다.                                                                                   |
| CurrentConnected   | 현재 클라이언트 연결이 현재 FE 노드에 연결되어 있는지 여부입니다.                                                                          |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL을 실행하는 사용자는 최소한 다음 권한을 가지고 있어야 합니다.

| 권한  | 객체 | 설명 |
|------------|----|----|
| SELECT_PRIV | internal.information_schema | 모든 사용자는 기본적으로 이 데이터베이스에 대한 권한을 가지고 있습니다 |

## 사용 시 참고 사항 {#usage-notes}

쿼리 결과를 추가로 필터링하려면 테이블 반환 함수 [frontends()](../../../sql-functions/table-valued-functions/frontends.md)를 사용할 수 있습니다. SHOW FRONTENDS는 다음 문과 동일합니다.

```sql
SELECT * FROM FRONTENDS();
```
