## 설명 {#description}

현재 사용자에게 사용 권한이 있는 컴퓨트 그룹 목록을 표시합니다.

- **컴퓨트-스토리지 분리 모드**: 현재 사용자에게 사용 권한이 있는 컴퓨트 그룹 목록을 반환합니다.
- **컴퓨트-스토리지 결합 모드**: 4.1.4 버전부터 지원됩니다. 이 모드에서는 BE의 리소스 그룹(`location` 태그)이 컴퓨트 그룹에 매핑됩니다. 4.1.4 이전 버전에서는 이 모드에서 해당 문을 실행하면 `ERR_NOT_CLOUD_MODE` 오류가 발생합니다.

## 구문 {#syntax}

```sql
SHOW COMPUTE GROUPS
```

## 반환 값 {#return-value}

현재 사용자에게 권한이 있는 컴퓨트 그룹 목록을 반환합니다. 반환되는 열은 두 모드에서 서로 다릅니다.

**컴퓨트-스토리지 분리 모드:**

- Name - 컴퓨트 그룹의 이름
- IsCurrent - 현재 사용자가 이 컴퓨트 그룹을 사용 중인지 여부
- Users - 이 컴퓨트 그룹을 기본 컴퓨트 그룹으로 설정한 사용자 이름
- BackendNum - 이 컴퓨트 그룹에 속한 백엔드 수
- SubComputeGroups / Policy / Properties - 가상 컴퓨트 그룹에 관한 정보

**컴퓨트-스토리지 결합 모드(4.1.4+):**

- Name - 컴퓨트 그룹의 이름, 즉 BE의 리소스 그룹(`location` 태그)
- BackendNum - 이 컴퓨트 그룹에 속한 백엔드 수

결과는 컴퓨트 그룹 이름순으로 정렬됩니다.

## 예시 {#example}

이름이 `compute_cluster`인 컴퓨트 그룹을 사용하도록 지정합니다.

```sql
SHOW COMPUTE GROUPS;
```

결과는 다음과 같습니다.

```sql
+-----------------+-----------+-------+------------+
| Name            | IsCurrent | Users | BackendNum |
+-----------------+-----------+-------+------------+
| compute_cluster | TRUE      |       | 3          |
+-----------------+-----------+-------+------------+
```

## 액세스 제어 요구 사항 {#access-control-requirements}

4.1.4 버전부터 컴퓨트-스토리지 결합 모드에서 이 문을 실행할 때 **전역 `ADMIN_PRIV` 또는 `NODE_PRIV` 권한이 더 이상 필요하지 않습니다**. 컴퓨트-스토리지 분리 모드와 마찬가지로, 현재 사용자는 자신의 컴퓨트 그룹에서 사용이 허용된 리소스 그룹만 볼 수 있습니다.

## 사용 시 참고 사항 {#usage-note}

- 현재 사용자에게 사용 권한이 있는 컴퓨트 그룹이 없으면 `SHOW COMPUTE GROUPS`는 빈 목록을 반환합니다.
- 컴퓨트-스토리지 결합 모드에서는 현재 세션의 컴퓨트 그룹이 `INVALID_COMPUTE_GROUP`인 경우에도 빈 결과 집합을 반환합니다.
- `SHOW CLUSTERS`는 동일한 기능을 수행하는 문입니다. 컴퓨트-스토리지 결합 모드에서는 열 이름이 `cluster`와 `backend_num`입니다.
