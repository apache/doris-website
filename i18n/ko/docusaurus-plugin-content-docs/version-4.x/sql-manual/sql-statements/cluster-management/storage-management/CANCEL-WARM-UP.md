## 설명 {#description}

Doris에서 지정한 워밍업 작업을 종료합니다.

## 구문 {#syntax}

```sql
CANCEL WARM UP JOB WHERE id = <id>;
```
## 필수 매개변수 {#required-parameters}

> 종료하려는 워밍업 작업의 id로, `SHOW WARM UP JOB` 명령으로 조회할 수 있습니다.

## 권한 제어 {#permission-control}

이 SQL 명령을 실행하는 사용자는 최소한 ADMIN_PRIV 권한이 있어야 합니다.

## 예시 {#example}

시스템에서 현재 실행 중인 워밍업 작업을 `SHOW WARM UP JOB`으로 조회합니다:

```sql
SHOW WARM UP JOB
```

결과는 다음과 같습니다:

```C++
+----------------+---------------+---------+-------+-------------------------+-------------+----------+------------+--------+
| JobId          | ClusterName   | Status  | Type  | CreateTime              | FinishBatch | AllBatch | FinishTime | ErrMsg |
+----------------+---------------+---------+-------+-------------------------+-------------+----------+------------+--------+
| 90290165739458 | CloudCluster1 | RUNNING | TABLE | 2024-11-11 11:11:42.700 | 1           | 3        | NULL       |        |
+----------------+---------------+---------+-------+-------------------------+-------------+----------+------------+--------+
```

그런 다음 `CANCEL WARM UP`으로 해당 작업을 종료합니다:

```C++
CANCEL WARM UP JOB WHERE id = 90290165739458;
```

다음 내용이 반환되면 지정한 id에 해당하는 워밍업 작업이 존재하지 않는다는 뜻입니다:

```C++
ERROR 1105 (HY000): errCode = 2, detailMessage = job id: 110 does not exist.
```

명령이 성공적으로 실행된 후 `SHOW WARM UP JOB`을 다시 사용하면 작업 상태가 RUNNING에서 CANCELLED로 변경된 것을 확인할 수 있습니다:

```C++
+----------------+---------------+-----------+-------+-------------------------+-------------+----------+-------------------------+-------------+
| JobId          | ClusterName   | Status    | Type  | CreateTime              | FinishBatch | AllBatch | FinishTime              | ErrMsg      |
+----------------+---------------+-----------+-------+-------------------------+-------------+----------+-------------------------+-------------+
| 90290165739458 | CloudCluster1 | CANCELLED | TABLE | 2024-11-11 11:11:42.700 | 1           | 3        | 2024-11-11 11:11:43.700 | user cancel |
+----------------+---------------+-----------+-------+-------------------------+-------------+----------+-------------------------+-------------+
```
