## 설명 {#description}
지정된 기본 Storage Vault 설정을 해제합니다.

## 구문 {#syntax}

```sql
UNSET DEFAULT STORAGE VAULT
```

## 권한 제어 {#permission-control}

| 권한       | 객체          | 설명                                                       |
| :--------- | :------------ | :--------------------------------------------------------- |
| ADMIN_PRIV | Storage Vault | 관리자 사용자만 이 문을 실행할 권한이 있습니다. |

## 예시 {#example}

```sql
UNSET DEFAULT STORAGE VAULT
```
