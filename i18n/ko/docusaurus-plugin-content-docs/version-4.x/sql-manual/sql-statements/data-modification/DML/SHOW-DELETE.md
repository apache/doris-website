## 설명 {#description}

성공적으로 실행된 과거 삭제 작업을 표시하는 문입니다

## 구문 {#syntax}

```sql
SHOW DELETE [FROM <db_name>]
```

## 선택적 매개변수 {#optional-parameters}
**<db_name>** : 조회할 데이터베이스의 이름

## 반환 값 {#return-value}
| 열                | 설명                                                                             |
|-------------------|----------------------------------------------------------------------------------|
| `TableName`       | 삭제 작업이 실행된 테이블의 이름입니다.                                           |
| `PartitionName`   | 삭제 작업의 영향을 받은 파티션의 이름입니다.                                      |
| `CreateTime`      | 삭제 작업이 요청된 시점의 타임스탬프입니다.                                        |
| `DeleteCondition` | 삭제 작업에 사용된 조건으로, 어떤 행이 삭제되었는지 나타냅니다.                    |
| `State`           | 삭제 작업의 상태입니다                                                           |


## 예제 {#example}

1. test 데이터베이스로 이동하여 모든 과거 삭제 작업을 확인합니다
     ```sql
    show delete;
    ```
    ```text
    +---------------+---------------+---------------------+-----------------+----------+
    | TableName     | PartitionName | CreateTime          | DeleteCondition | State    |
    +---------------+---------------+---------------------+-----------------+----------+
    | iceberg_table | *             | 2025-03-14 15:53:32 | id EQ "1"       | FINISHED |
    +---------------+---------------+---------------------+-----------------+----------+
    ```

2. 데이터베이스의 모든 과거 삭제 작업을 표시합니다

     ```sql
     show delete from tpch;
     ```
     ```
     +-----------+---------------+---------------------+-------------------+----------+
     | TableName | PartitionName | CreateTime          | DeleteCondition   | State    |
     +-----------+---------------+---------------------+-------------------+----------+
     | customer  | *             | 2025-03-14 15:45:19 | c_custkey EQ "18" | FINISHED |
     +-----------+---------------+---------------------+-------------------+----------+
     ```
