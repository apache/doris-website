## 설명 {#description}

이 문은 과거 쿼리에서 참조한 데이터베이스, 테이블, 열을 표시하는 데 사용됩니다.

## 구문 {#syntax}

```sql
SHOW QUERY STATS [ { [FOR <db_name>] | [FROM <table_name>] } ] [ALL] [VERBOSE]];
```

## 선택적 매개변수 {#optional-parameters}

**1. `<db_name>`**

> 이 매개변수를 설정하면 해당 데이터베이스의 참조 통계를 표시합니다.

**2. `<table_name>`**

> 이 매개변수를 설정하면 해당 테이블의 참조 통계를 조회합니다.

**3. `ALL`**

> ALL은 모든 인덱스의 참조 통계를 표시할지 지정합니다.

**4. `VERBOSE`**

> VERBOSE는 상세한 참조 통계를 표시합니다.

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한을 보유해야 합니다.

| 권한               | 대상      | 설명               |
|:-------------------|:----------|:-------------------|
| SELECT_PRIV        | DATABASE  | 조회할 데이터베이스에 대한 SELECT 권한이 있어야 합니다. |

## 사용 시 주의 사항 {#usage-notes}

- 데이터베이스와 테이블에 대한 과거 쿼리의 참조 통계를 조회합니다. fe를 다시 시작하면 데이터가 초기화되며, 통계는 각 fe별로 수집됩니다.

- FOR DATABASE와 FROM TABLE을 사용하여 참조 통계를 조회할 데이터베이스나 테이블을 지정할 수 있습니다. 각 구문 뒤에 데이터베이스 이름이나 테이블 이름을 입력합니다.

- ALL과 VERBOSE 매개변수는 단독으로 사용하거나 함께 사용할 수 있지만, 반드시 마지막에 지정해야 하며 테이블을 조회할 때만 사용할 수 있습니다.

- 사용 중인 데이터베이스가 없으면 'SHOW QUERY STATS'만 실행하여 모든 데이터베이스의 참조 횟수를 확인할 수 있습니다.

- 참조 통계 결과에는 두 개의 열이 포함될 수 있습니다. QueryCount는 해당 열이 쿼리에서 참조된 횟수를 나타내고, FilterCount는 해당 열이 where 조건으로 참조된 횟수를 나타냅니다.
