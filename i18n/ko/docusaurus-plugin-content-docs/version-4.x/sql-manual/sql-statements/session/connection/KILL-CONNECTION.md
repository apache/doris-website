## 설명 {#description}

지정한 연결 ID에 해당하는 연결을 종료합니다. 해당 연결의 쿼리도 함께 종료됩니다.

## 구문 {#syntax}

```sql
KILL [ CONNECTION ] <connection_id>
```

## 필수 매개변수 {#required-parameters}

**<connection_id>**

> 연결의 ID입니다. SHOW PROCESSLIST 문으로 조회할 수 있습니다.

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 해당 연결의 소유자이거나 최소한 `ADMIN_PRIV` 권한이 있어야 합니다.

## 예제 {#examples}

`connection_id` 조회:

```sql
show processlist;
```

```sql

| Yes              | 16 | root | 127.0.0.1:63746 | 2024-11-04 20:18:07 | internal | test | Query   | 0    | OK    | e4d69a1cce81468d-91c9ae32b17540e9 | show processlist | 172.16.123.1 | NULL         |
```

```sql
KILL CONNECTION 16;
```
