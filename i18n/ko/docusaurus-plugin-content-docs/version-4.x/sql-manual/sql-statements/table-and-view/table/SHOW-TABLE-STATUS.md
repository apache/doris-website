## 설명 {#description}

이 문은 테이블이나 뷰의 일부 정보를 표시하는 데 사용됩니다.

## 구문 {#syntax}

```sql
SHOW TABLE STATUS [ FROM [ <catalog_name>.]<db_name> ] [ LIKE <like_condition> ]
```
## 선택적 매개변수 {#optional-parameters}

**1. ` FROM [ <catalog_name>.]<db_name>`**
> 조회할 Catalog 이름과 데이터베이스 이름은 FROM 절에서 지정할 수 있습니다.

**2. `LIKE <like_condition>`**
> LIKE 절을 사용하면 테이블 이름을 기준으로 유사 일치 쿼리를 수행할 수 있습니다.

## 반환 값 {#return-value}

| 열                  | 데이터 타입 | 설명 |
|:--------------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Name                | String   | 테이블 이름 |
| Engine              | String   | 테이블의 스토리지 엔진 |
| Version             | String   | 버전 |
| Row_format          | String   | 행 형식입니다. MyISAM 엔진에서는 Dynamic, Fixed 또는 Compressed일 수 있습니다. Dynamic 행은 Varchar나 Blob 타입 필드처럼 길이가 가변적입니다. Fixed 행은 Char나 Integer 타입 필드처럼 길이가 고정되어 있습니다. |
| Rows                | String   | 테이블의 행 수입니다. 비트랜잭션 테이블에서는 정확한 값이며, 트랜잭션 엔진에서는 일반적으로 추정값입니다. |
| Avg_row_length      | Integer  | 행당 평균 바이트 수 |
| Data_length         | Integer  | 전체 테이블의 데이터 크기(바이트 단위) |
| Max_data_length     | Integer  | 테이블에 저장할 수 있는 최대 데이터 크기 |
| Index_length        | Integer  | 인덱스가 차지하는 디스크 공간 |
| Data_free           | Integer  | MyISAM 엔진에서 할당되었지만 현재 사용하지 않는 공간을 나타내며, 삭제된 행의 공간도 포함합니다. |
| Auto_increment      | Integer  | 다음 Auto_increment 값 |
| Create_time         | Datetime | 테이블 생성 시간 |
| Update_time         | Datetime | 테이블의 마지막 업데이트 시간 |
| Check_time          | Datetime | check table 또는 myisamchk 도구로 테이블을 마지막으로 검사한 시간 |
| Collation           | String   | 테이블의 기본 문자 집합이며, 현재는 utf-8만 지원합니다. |
| Checksum            | String   | 활성화된 경우, 전체 테이블 내용에 대해 계산된 체크섬 |
| Create_options      | String   | 테이블 생성 시 지정한 기타 모든 옵션 |
| Comment             | String   | 테이블 주석 |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한을 보유해야 합니다:

| 권한 | 객체 | 설명 |
|:--------------|:-----------|:------------------------|
| ADMIN_PRIV | 테이블, 뷰 | 현재는 **ADMIN** 권한이 있어야 이 작업을 수행할 수 있습니다. |

## 사용 시 참고 사항 {#usage-notes}

- 이 문은 주로 MySQL 구문과의 호환성을 위해 사용됩니다. 현재는 Comment 등의 일부 정보만 표시됩니다.
