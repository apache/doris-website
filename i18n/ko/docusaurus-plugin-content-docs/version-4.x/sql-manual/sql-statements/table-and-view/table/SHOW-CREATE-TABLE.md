## 설명 {#description}

이 문은 데이터 테이블의 생성문을 표시하는 데 사용됩니다.

## 구문 {#syntax}

```sql
SHOW [BRIEF] CREATE TABLE [<db_name>.]<table_name>
```

## 필수 매개변수 {#required-parameters}
**1.`<table_name>`**
> 테이블 식별자(이름)를 지정합니다. 이 식별자는 해당 테이블이 속한 데이터베이스 내에서 고유해야 합니다.
>
> 식별자는 영문자로 시작해야 합니다(유니코드 이름 지원이 활성화된 경우 해당 언어의 모든 문자로 시작할 수 있습니다). 식별자 문자열 전체를 백틱으로 묶지 않으면 공백이나 특수 문자를 포함할 수 없습니다(예: `My Object`).
>
> 식별자에는 예약 키워드를 사용할 수 없습니다.
>
> 자세한 내용은 식별자 요구 사항 및 예약 키워드를 참조하세요.

## 선택적 매개변수 {#optional-parameters}
**1.`BRIEF`**
> 열 정의를 제외하고 테이블의 기본 정보만 표시합니다.

**2.`<db_name>`**
> 데이터베이스의 식별자(이름)를 지정합니다.
>
> 식별자는 영문자로 시작해야 합니다(유니코드 이름 지원이 활성화된 경우 해당 언어의 모든 문자로 시작할 수 있습니다). 식별자 문자열 전체를 백틱으로 묶지 않으면 공백이나 특수 문자를 포함할 수 없습니다(예: `My Database`).
>
> 식별자에는 예약 키워드를 사용할 수 없습니다.
>
> 자세한 내용은 식별자 요구 사항 및 예약 키워드를 참조하세요.

## 반환 값 {#return-value}
| 열 이름 | 설명 |
| -- |-------------|
| Table | 테이블 이름          |
| Create Table | 테이블 생성문        |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한을 보유해야 합니다.

| 권한         | 객체    | 참고                           |
|:------------------|:----------|:--------------------------------|
| Select_priv       | 테이블     | SHOW CREATE TABLE은 테이블 SELECT 작업에 해당합니다 |


## 예제 {#examples}

1. 테이블의 생성문 조회

   ```sql
   SHOW CREATE TABLE demo.test_table;
   ```
2. 테이블의 간략한 생성문 조회

   ```sql
   SHOW BRIEF CREATE TABLE demo.test_table;
   ```
