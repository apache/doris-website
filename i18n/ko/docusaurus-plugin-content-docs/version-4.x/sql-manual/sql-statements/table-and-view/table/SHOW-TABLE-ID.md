## 설명 {#description}

테이블 ID를 기준으로 해당 데이터베이스 이름과 테이블 이름을 조회하는 문입니다.

## 구문 {#syntax}

```sql
SHOW TABLE <table_id>
```

## 필수 매개변수 {#required-parameters}

**1. `<table_id>`**
> 데이터베이스 이름과 테이블 이름을 조회할 테이블의 `<table_id>`입니다.

## 반환값 {#return-value}

| 열 이름 (열) | 유형 (데이터 유형) | 비고 (비고) |
|:--------------------|:-------------|:----------|
| DbName | String | 데이터베이스 이름 |
| TableName | String | 테이블 이름 |
| DbId | String | 데이터베이스 ID |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한이 있어야 합니다:

| 권한 (권한) | 객체 (객체) | 비고 (비고) |
|:--------------|:-----------|:------------------------|
| ADMIN_PRIV | 테이블 (테이블) | 현재 이 작업은 **ADMIN** 권한이 있는 경우에만 수행할 수 있습니다 |

## 예제 {#examples}

- 테이블 ID를 기준으로 해당 데이터베이스 이름과 테이블 이름 조회

   ```sql
   SHOW TABLE 2261121
   ```

   ```text
   +--------+------------+---------+
   | DbName | TableName  | DbId    |
   +--------+------------+---------+
   | demo   | test_table | 2261034 |
   +--------+------------+---------+
   ```
