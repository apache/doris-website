## 설명 {#description}

이 문은 테이블을 삭제하는 데 사용됩니다.
## 구문 {#syntax}

```sql
DROP [TEMPORARY] TABLE [IF EXISTS] [<db_name>.]<table_name> [FORCE];
```

## 필수 매개변수 {#required-parameters}
**1.`<table_name>`**
> 테이블의 식별자(이름)를 지정합니다. 이 식별자는 해당 테이블이 속한 데이터베이스 내에서 고유해야 합니다.
>
> 식별자는 알파벳 문자(또는 unicode 이름 지원이 활성화된 경우 해당 언어의 임의의 문자)로 시작해야 하며, 식별자 문자열 전체를 백틱으로 감싸지 않는 한 공백이나 특수 문자를 포함할 수 없습니다(예: `My Object`).
>
> 식별자에는 예약 키워드를 사용할 수 없습니다.
>
> 자세한 내용은 식별자 요구 사항 및 예약 키워드를 참조하세요.

## 선택적 매개변수 {#optional-parameters}

**1. `TEMPORARY` **
> 지정하면 TEMPORARY 테이블만 삭제합니다.

**2. `IF EXISTS`**
> 지정하면 테이블이 존재하지 않아도 오류가 발생하지 않습니다.

**3.`<db_name>`**
> 데이터베이스의 식별자(이름)를 지정합니다.
>
> 식별자는 알파벳 문자(또는 unicode 이름 지원이 활성화된 경우 해당 언어의 임의의 문자)로 시작해야 하며, 식별자 문자열 전체를 백틱으로 감싸지 않는 한 공백이나 특수 문자를 포함할 수 없습니다(예: `My Database`).
>
> 식별자에는 예약 키워드를 사용할 수 없습니다.
>
> 자세한 내용은 식별자 요구 사항 및 예약 키워드를 참조하세요.

**4.`FORCE`**
> 지정하면 시스템은 테이블에 완료되지 않은 트랜잭션이 있는지 확인하지 않습니다. 테이블은 즉시 삭제되며 복구할 수 없습니다. 일반적으로 이 작업은 권장하지 않습니다.

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한이 있어야 합니다.


| 권한            | 객체      | 설명                       |
|:----------------|:----------|:---------------------------|
| Drop_priv       | 테이블    | DROP TABLE은 테이블 DROP 작업에 해당합니다 |

## 사용 시 참고 사항 {#usage-notes}

- `DROP TABLE` 실행 후 일정 기간 동안은 RECOVER 문을 사용하여 삭제된 테이블을 복구할 수 있습니다. 자세한 내용은 [RECOVER](../../recycle/RECOVER) 문을 참조하세요.
- `DROP TABLE FORCE`를 실행하면 시스템은 테이블에 완료되지 않은 트랜잭션이 있는지 확인하지 않습니다. 테이블은 즉시 삭제되며 복구할 수 없습니다. 일반적으로 이 작업은 권장하지 않습니다.

## 예제 {#examples}

1. 테이블 삭제

    ```sql
    DROP TABLE my_table;
    ```

2. 지정한 데이터베이스에 테이블이 존재하면 삭제합니다.

    ```sql
    DROP TABLE IF EXISTS example_db.my_table;
    ```

3. 지정한 데이터베이스에 테이블이 존재하면 강제로 삭제합니다.

    ```sql
    DROP TABLE IF EXISTS example_db.my_table FORCE;
    ```
