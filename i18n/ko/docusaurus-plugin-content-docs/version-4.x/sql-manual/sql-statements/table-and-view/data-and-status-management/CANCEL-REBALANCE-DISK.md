## 설명 {#description}

`CANCEL REBALANCE DISK` 문은 Backend (BE) 노드에서 우선순위가 높은 디스크 데이터 균형 조정을 취소하는 데 사용됩니다. 이 문은 다음 기능을 제공합니다.

- 지정된 BE 노드에서 우선순위가 높은 디스크 균형 조정을 취소할 수 있습니다.
- 클러스터 전체의 모든 BE 노드에서 우선순위가 높은 디스크 균형 조정을 취소할 수 있습니다.
- 취소 후에도 시스템은 기본 스케줄링 방식으로 BE 노드의 디스크 데이터 균형 조정을 계속 수행합니다.

## 구문 {#syntax}

```sql
ADMIN CANCEL REBALANCE DISK [ ON ( "<host>:<port>" [, ... ] ) ];
```

## 선택적 매개변수 {#optional-parameters}

**1. `"<host>:<port>"`**

> 우선순위가 높은 디스크 균형 조정을 취소할 BE 노드 목록을 지정합니다.
>
> 각 노드는 호스트 이름(또는 IP 주소)과 하트비트 포트로 구성됩니다.
>
> 이 매개변수를 지정하지 않으면 모든 BE 노드에서 우선순위가 높은 디스크 균형 조정을 취소합니다.

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한을 보유해야 합니다.

| 권한            | 객체        | 비고                                          |
| :-------------- | :---------- | :-------------------------------------------- |
| ADMIN           | 시스템      | 이 명령을 실행하려면 사용자에게 ADMIN 권한이 있어야 합니다. |

## 사용 시 참고 사항 {#usage-notes}

- 이 문은 지정된 BE의 디스크 데이터 균형 조정에 더 이상 우선순위를 부여하지 않도록 할 뿐이며, 시스템은 기본 스케줄링 방식으로 BE의 디스크 데이터 균형 조정을 계속 수행합니다.
- 이 명령을 실행하면 이전에 설정한 우선순위가 높은 균형 조정 전략은 즉시 무효화됩니다.

## 예제 {#examples}

- 클러스터의 모든 BE에서 우선순위가 높은 디스크 균형 조정 취소:

    ```sql
    ADMIN CANCEL REBALANCE DISK;
    ```

- 지정된 BE에서 우선순위가 높은 디스크 균형 조정 취소:

```sql
ADMIN CANCEL REBALANCE DISK ON ("192.168.1.1:1234", "192.168.1.2:1234");
```
