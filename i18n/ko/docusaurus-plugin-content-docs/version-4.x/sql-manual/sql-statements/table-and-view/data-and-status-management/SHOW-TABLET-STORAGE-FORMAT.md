## 설명 {#description}

이 문은 Backend의 스토리지 형식 정보를 표시하는 데 사용됩니다.

## 구문 {#syntax}

```sql
SHOW TABLET STORAGE FORMAT [VERBOSE]
```


## 선택적 매개변수 {#optional-parameters}

** 1. `VERBOSE` **

  더 자세한 정보를 표시합니다.

## 반환 값 {#return-value}

**기본 출력** (`VERBOSE` 미사용):

| 열        | 데이터 타입 | 설명                                                                 |
|-----------|----------|----------------------------------------------------------------------|
| BackendId | Int      | tablet 복제본이 위치한 BE (Backend) 노드의 ID입니다. |
| V1Count   | Int      | V1 버전 tablet의 수입니다.                                        |
| V2Count   | Int      | V2 버전 tablet의 수입니다.                                        |

**`VERBOSE` 사용 시**:

| 열            | 데이터 타입 | 설명                                                                 |
|---------------|----------|----------------------------------------------------------------------|
| BackendId     | Int      | tablet 복제본이 위치한 BE (Backend) 노드의 ID입니다. |
| TabletId      | Int      | tablet의 고유 식별자입니다.                                 |
| StorageFormat | String   | tablet의 버전으로, V1 또는 V2입니다.                          |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한이 있어야 합니다:

| 권한       | 객체     | 설명                                                                                                                            |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------|
| Admin_priv | 데이터베이스 | 테이블 및 파티션 관리와 시스템 수준 명령 실행을 포함하여 데이터베이스에서 관리 작업을 수행하는 데 필요합니다. |

## 예시 {#examples}

- verbose 매개변수 없이 문을 실행합니다

  ```sql
  show tablet storage format;
  ```

  ```text
  +-----------+---------+---------+
  | BackendId | V1Count | V2Count |
  +-----------+---------+---------+
  | 10002     | 0       | 2867    |
  +-----------+---------+---------+
  ```

- verbose 매개변수를 사용하여 문을 실행합니다

  ```sql
  show tablet storage format verbose;
  ```

  ```text
  +-----------+----------+---------------+
  | BackendId | TabletId | StorageFormat |
  +-----------+----------+---------------+
  | 10002     | 39227    | V2            |
  | 10002     | 39221    | V2            |
  | 10002     | 39215    | V2            |
  | 10002     | 39199    | V2            |
  +-----------+----------+---------------+
  ```
