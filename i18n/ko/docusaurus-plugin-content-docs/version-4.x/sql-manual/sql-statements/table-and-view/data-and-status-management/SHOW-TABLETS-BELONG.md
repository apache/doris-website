## 설명 {#description}

이 문은 tablet과 해당 tablet이 속한 테이블의 정보를 표시하는 데 사용됩니다.

## 구문 {#syntax}

```sql
SHOW TABLETS BELONG <tablet_id> [, <tablet_id>]...;
```

## 필수 매개변수 {#required-parameters}

**1. `<tablet_id>`**

> 하나 이상의 tablet ID를 쉼표로 구분하여 지정합니다. 결과에서는 중복된 ID가 제거됩니다.

## 반환 값 {#return-value}

`SHOW TABLETS BELONG <tablet_id> [, <tablet_id>]...`을 사용하면 다음 열이 반환됩니다.

| 열            | 데이터 타입 | 설명                                                                   |
|---------------|----------|------------------------------------------------------------------------|
| DbName        | String   | tablet이 속한 데이터베이스의 이름입니다.                                |
| TableName     | String   | tablet이 속한 테이블의 이름입니다.                                      |
| TableSize     | String   | 테이블의 크기입니다(예: "8.649 KB").                                    |
| PartitionNum  | Int      | 테이블의 파티션 수입니다.                                               |
| BucketNum     | Int      | 테이블의 버킷 수입니다.                                                 |
| ReplicaCount  | Int      | 테이블의 복제본 수입니다.                                               |
| TabletIds     | Array    | 테이블에 속한 tablet ID 목록입니다.                                     |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한을 보유해야 합니다.

| 권한       | 객체     | 설명                                                                                                                             |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------|
| Admin_priv | 데이터베이스 | 테이블 및 파티션 관리와 시스템 수준 명령 실행을 비롯한 데이터베이스 관리 작업을 수행하는 데 필요합니다. |

## 예시 {#examples}

특정 tablet의 정보를 표시합니다.

```sql
SHOW TABLETS BELONG 10145;
```

```text
+--------+-----------+-----------+--------------+-----------+--------------+-----------+
| DbName | TableName | TableSize | PartitionNum | BucketNum | ReplicaCount | TabletIds |
+--------+-----------+-----------+--------------+-----------+--------------+-----------+
| test   | sell_user | 8.649 KB  | 1            | 4         | 4            | [10145]   |
+--------+-----------+-----------+--------------+-----------+--------------+-----------+
```

여러 tablet의 정보를 표시합니다.

```sql
SHOW TABLETS BELONG 27028,78880,78382,27028;
```

```text
+---------------------+-----------+-----------+--------------+-----------+--------------+----------------+
| DbName              | TableName | TableSize | PartitionNum | BucketNum | ReplicaCount | TabletIds      |
+---------------------+-----------+-----------+--------------+-----------+--------------+----------------+
| default_cluster:db1 | kec       | 613.000 B | 379          | 604       | 604          | [78880, 78382] |
| default_cluster:db1 | test      | 1.874 KB  | 1            | 1         | 1            | [27028]        |
+---------------------+-----------+-----------+--------------+-----------+--------------+----------------+
```
