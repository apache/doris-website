## 설명 {#description}

이 문은 테이블의 요약 통계를 조회하는 데 사용됩니다.

## 구문 {#syntax}

```SQL
SHOW TABLE STATS <table_name>;
```

## 필수 매개변수 {#required-parameters}

**1. `<table_name>`**

> 테이블 이름

## 선택적 매개변수 {#optional-parameters}

**없음**

## 반환 값 {#return-value}

| 열 | 설명           |
| -- |--------------|
| updated_rows | 테이블에서 업데이트된 행 수           |
| query_times |   테이블 쿼리 횟수           |
| row_count | 테이블의 행 수           |
| updated_time | 테이블의 마지막 수정 시간        |
| columns | 분석된 열 목록           |
| trigger |   마지막 분석의 트리거 방식           |
| new_partition |  새 파티션의 최초 데이터 적재 여부           |
| user_inject | 사용자의 통계 주입 여부         |
| enable_auto_analyze | 자동 분석 활성화 여부         |
| last_analyze_time |   마지막 분석 시간          |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL을 실행하는 사용자는 최소한 다음 권한이 있어야 합니다.

| 권한 | 객체 | 설명                                    |
|:--------------| :------------- |:------------------------------------------------|
| SELECT_PRIV   | 테이블    | SHOW를 실행하려면 조회할 테이블에 대한 SELECT_PRIV 권한이 필요합니다. |

## 예제 {#examples}

1. test1 테이블의 요약 통계를 조회합니다.

```sql
SHOW TABLE STATS test1;
```
