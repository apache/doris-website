## 설명 {#description}

이 문은 테이블의 열 통계를 표시하는 데 사용됩니다.

## 구문 {#syntax}

```SQL
SHOW COLUMN [CACHED] STATS <table_name> [ (<column_name> [, ...]) ];
```

## 필수 매개변수 {#required-parameters}

**1. `<table_name>`**

> 열 통계를 표시할 테이블의 이름입니다.

## 선택 매개변수 {#optional-parameters}

**1. `CACHED`**

> FE 캐시에 있는 열 통계를 표시합니다. 지정하지 않으면 기본적으로 통계 테이블에 영구 저장된 정보를 표시합니다.

**2. `<column_name>`**

> 정보를 표시할 열 이름을 지정합니다. 열 이름은 테이블에 존재해야 하며, 여러 열 이름은 쉼표로 구분합니다. 지정하지 않으면 기본적으로 모든 열의 정보를 표시합니다.

## 반환 값 {#return-value}

| 열 | 설명           |
| -- |--------------|
| column_name | 열 이름           |
| index_name |   인덱스 이름           |
| count | 열의 행 수           |
| ndv | 열의 고유 값 수         |
| num_null | 열의 NULL 값 수           |
| data_size |   열의 전체 데이터 크기           |
| avg_size_byte |  열의 평균 크기           |
| min | 최솟값         |
| max | 최댓값           |
| method |   수집 방법          |
| type | 수집 유형           |
| trigger | 작업 트리거 방식         |
| query_times | 쿼리 횟수          |
| updated_time |   업데이트 시간           |
| update_rows | 마지막 분석 시점의 업데이트된 행 수           |
| last_analyze_row_count | 마지막 분석 시점의 테이블 행 수         |
| last_analyze_version | 마지막 분석 시점의 테이블 버전         |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL을 실행하는 사용자는 최소한 다음 권한이 있어야 합니다:

| 권한 | 객체 | 설명                                    |
|:--------------| :------------- |:------------------------------------------------|
| SELECT_PRIV   | 테이블    | SHOW를 실행하려면 조회 대상 테이블에 대한 SELECT_PRIV 권한이 필요합니다. |
