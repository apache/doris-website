## 설명 {#description}

문자열은 작은따옴표(') 또는 큰따옴표(")로 둘러싼 바이트 또는 문자의 시퀀스입니다. 예:

```sql
'a string'
"another string"
```

## 이스케이프 문자 {#escape-characters}

문자열에서 특정 시퀀스는 NO_BACKSLASH_ESCAPES SQL 모드가 활성화되어 있지 않으면 특별한 의미를 갖습니다. 이러한 시퀀스는 이스케이프 문자라고 하는 백슬래시(\)로 시작합니다. Doris에서 인식하는 이스케이프 문자는 아래 테이블에 나와 있습니다.

| 이스케이프 문자 | 의미                                      |
| -------------- | ------------------------------------------- |
| `\0`         | ASCII 문자 NUL (0x00)              |
| `\'`         | 작은따옴표(')                             |
| `\"`         | 큰따옴표(")                            |
| `\b`         | 백스페이스                                   |
| `\n`        | 줄바꿈                                     |
| `\r`        | 캐리지 리턴                                |
| `\t`        | 탭                                         |
| `\Z`        | ASCII 26 (Control+Z)                         |
| `\\`        | 백슬래시(`\`)                              |
| `\%`        | 백분율 기호 `%`. 자세한 내용은 아래 참고 사항 참조 |
| `\_`        | 밑줄 `_`. 자세한 내용은 아래 참고 사항 참조 |

**참고 사항**

> 1. 패턴 매칭에서 `%`와 `_`는 일반적으로 와일드카드로 해석되지만, 시퀀스 `\%`와 `\_`를 사용하면 `%`와 `_` 문자 자체를 검색할 수 있습니다. 자세한 내용은 "패턴 매칭 연산자" 절의 LIKE 연산자 설명을 참조하세요. 패턴 이외의 문맥에서 `\%` 또는 `\_`를 사용하면 문자열 `\%`와 `\_`로 처리되며, `%`와 `_`로 처리되지 않습니다.
> 2. 테이블에 나열되지 않은 이스케이프 문자의 백슬래시는 무시됩니다. 예를 들어, `'\y'`와 `'y'`는 동일합니다.

## 문자열 리터럴에서 따옴표 사용 {#using-quotes-in-string-literals}

문자열에 따옴표 문자를 포함하는 방법은 여러 가지가 있습니다.

- 작은따옴표(')로 둘러싼 문자열에서는 작은따옴표를 작은따옴표 두 개('')로 표기할 수 있습니다.
- 큰따옴표(")로 둘러싼 문자열에서는 큰따옴표를 큰따옴표 두 개(")로 표기할 수 있습니다.
- 따옴표 문자 앞에 이스케이프 문자(`\`)를 추가합니다.
- 큰따옴표로 둘러싼 문자열에 작은따옴표를 포함할 때는 특별한 처리가 필요하지 않으며, 작은따옴표를 두 번 쓰거나 이스케이프할 필요도 없습니다. 마찬가지로 작은따옴표로 둘러싼 문자열에 큰따옴표를 포함할 때도 특별한 처리가 필요하지 않습니다.
