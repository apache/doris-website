## 설명 {#description}

하나 또는 두 개의 매개변수를 사용하는 산술 연산자로 숫자의 부호 반전, 덧셈, 뺄셈, 곱셈, 나눗셈을 수행할 수 있습니다. 일부 연산자는 날짜 및 시간 간격의 산술 연산에도 사용됩니다. 연산자의 매개변수는 숫자 데이터 타입 또는 숫자 데이터 타입으로 암시적으로 변환할 수 있는 데이터 타입으로 해석되어야 합니다.

단항 산술 연산자는 매개변수의 숫자 데이터 타입과 같은 데이터 타입을 반환합니다. 이항 산술 연산자의 경우 Doris는 암시적 타입 변환 규칙에 따라 매개변수를 연산에 적합한 타입으로 변환하고 적절한 타입의 결과를 반환합니다. 구체적인 변환 규칙은 "타입 변환" 섹션을 참조하세요.

## 사용 시 주의 사항 {#usage-notes}

산술 표현식에서는 다음 사항에 유의하세요:
1. 부호를 두 번 반전할 때 연속된 빼기 기호 `--`를 사용하지 마세요(이는 SQL 주석 기호입니다).
2. 필요에 따라 공백이나 괄호로 구분하세요: `-(-5)` 또는 `- -5`
3. 자세한 주석 작성 규칙은 "주석" 섹션을 참조하세요
