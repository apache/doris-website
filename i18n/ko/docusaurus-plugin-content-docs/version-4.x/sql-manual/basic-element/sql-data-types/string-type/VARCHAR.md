## VARCHAR {#varchar}
### 설명 {#description}
VARCHAR(M)
가변 길이 문자열로, M은 문자열의 바이트 길이를 나타냅니다. M의 범위는 1-65533입니다.

참고: 가변 길이 문자열은 UTF-8 인코딩으로 저장되므로, 일반적으로 영문자는 1바이트, 중국어 문자는 3바이트를 차지합니다.

### 키워드 {#keywords}
