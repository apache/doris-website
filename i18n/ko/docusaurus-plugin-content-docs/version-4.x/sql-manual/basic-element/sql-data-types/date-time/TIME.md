# TIME {#time}

## 설명 {#description}

TIME(p) 타입은 시간을 저장합니다. 여기서 p는 정밀도를 나타내며, 값의 범위는 `[0, 6]`이고 기본값은 0입니다. 즉, TIME은 TIME(0)과 동일합니다.

값의 범위는 `[-838:59:59.999..., 838:59:59.999...]`이며, 기본 출력 형식은 'HH:mm:ss.SSS...'입니다. 소수점 아래 자릿수는 총 p자리입니다. 예를 들어 TIME(6)의 범위는 `[-838:59:59.999999, 838:59:59.999999]`입니다.

TIME 타입은 중간 계산값으로만 사용되며 입력과 출력이 가능하지만, OLAP 테이블의 컬럼으로 저장하는 것은 **지원하지 않습니다**.

다른 타입을 TIME으로 변환하는 방법과 변환 시 허용되는 입력은 [TIME으로 형 변환](../conversion/time-conversion.md)을 참조하세요.

날짜 및 시간 타입은 수학 연산자를 직접 사용한 산술 연산을 지원하지 않습니다. 수학 연산을 수행하면 실제로는 먼저 날짜 및 시간 타입을 숫자 타입으로 암시적으로 변환한 후 연산을 수행합니다.

## 예제 {#examples}

```sql
select cast('-123:00:02.9' as time);
```

```text
+------------------------------+
| cast('-123:00:02.9' as time) |
+------------------------------+
| -123:00:03                   |
+------------------------------+
```

```sql
select cast('838:59:59.999999' as time(6));
```

```text
+-------------------------------------+
| cast('838:59:59.999999' as time(6)) |
+-------------------------------------+
| 838:59:59.999999                    |
+-------------------------------------+
```
