# S3 {#s3}

## 설명 {#description}

S3 테이블 반환 함수(TVF)를 사용하면 S3 호환 객체 스토리지에 저장된 파일을 관계형 테이블 형식의 데이터처럼 읽고 접근할 수 있습니다. 현재 `csv/csv_with_names/csv_with_names_and_types/json/parquet/orc` 파일 형식을 지원합니다.

## 구문 {#syntax}

```sql
S3(
    "uri" = "<uri>",
    "s3.access_key" = "<s3_access_key>",
    "s3.secret_key" = "<s3_secret_key>",
    "s3.region" = "<s3_region>",
    "s3.endpoint" = "<s3_endpoint>",
    "format" = "<format>"
    [, "<optional_property_key>" = "<optional_property_value>" [, ...] ]
  )
```

## 필수 매개변수 {#required-parameters}

| 매개변수       | 설명                                                                                                                           |
|-----------------|---------------------------------------------------------------------------------------------------------------------------------------|
| `uri`           | S3에 접근하기 위한 URI입니다. 와일드카드와 범위 패턴을 지원합니다. 자세한 내용은 [파일 경로 패턴](../../basic-element/file-path-pattern)을 참조하세요. 이 함수는 `use_path_style` 매개변수에 따라 Path Style 또는 Virtual-hosted Style을 사용합니다.        |
| `s3.access_key` | S3 액세스 키                                                                                                                     |
| `s3.secret_key` | S3 비밀 키                                                                                                                     |
| `s3.region`     | S3 리전                                                                                                                             |
| `s3.endpoint`   | S3 엔드포인트 주소                                                                                                                   |
| `format`        | 파일 형식입니다. `csv/csv_with_names/csv_with_names_and_types/json/parquet/orc`를 지원합니다.                                                 |

## 참고 사항 {#notes}

1. AWS S3의 표준 URI 형식은 다음과 같습니다.

   - AWS Client Style(Hadoop S3 Style)
   
      ```
      s3://my-bucket/path/to/file?versionId=abc123&partNumber=77&partNumber=88
      ```

   - Virtual Host Style
   
      ```
      https://my-bucket.s3.us-west-1.amazonaws.com/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   - Path Style
   
      ```
      https://s3.us-west-1.amazonaws.com/my-bucket/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   이 세 가지 표준 URI 형식 외에도 다른 URI 형식을 지원합니다(다만 사용 빈도는 낮습니다).

   - Virtual Host와 AWS Client(Hadoop S3)의 혼합 형식
      
      ```
      s3://my-bucket.s3.us-west-1.amazonaws.com/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   - Path와 AWS Client(Hadoop S3)의 혼합 형식

      ```
      s3://s3.us-west-1.amazonaws.com/my-bucket/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   자세한 사용 예는 아래 예제를 참조하세요.

2. TVF를 직접 쿼리하거나 이 TVF를 기반으로 뷰를 생성하려면 Resource에 대한 USAGE 권한이 필요합니다. TVF를 기반으로 생성된 뷰를 쿼리하려면 해당 뷰에 대한 SELECT 권한만 있으면 됩니다.

## 예제 {#examples}

- S3 호환 객체 스토리지에 있는 CSV 형식 파일 읽기 및 접근

  ```sql
  select * from s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                  "s3.access_key"= "minioadmin",
                  "s3.secret_key" = "minioadmin",
                  "s3.endpoint" = "http://127.0.0.1:9312",
                  "s3.region" = "us-east-1",
                  "format" = "csv",
                  "use_path_style" = "true") order by c1;
  ```


- `desc function`과 함께 사용 가능

  ```sql
  desc function s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                   "s3.access_key"= "minioadmin",
                   "s3.secret_key" = "minioadmin",
                   "s3.endpoint" = "http://127.0.0.1:9312",
                   "s3.region" = "us-east-1",
                   "format" = "csv",
                   "use_path_style" = "true");
  ```

- **CSV 형식**

  S3 테이블 반환 함수는 테이블 스키마를 미리 알 수 없으므로, 파일을 한 번 읽어 테이블 스키마를 파싱합니다.

  `csv` 형식: S3 테이블 반환 함수는 S3의 파일을 읽어 CSV 파일로 처리하며, 첫 번째 줄을 사용하여 테이블 스키마를 파싱합니다. 첫 번째 줄의 컬럼 수 `n`이 테이블 스키마의 컬럼 수가 되며, 컬럼 이름은 자동으로 `c1, c2, ..., cn`으로 지정되고 모든 컬럼 타입은 `String`으로 설정됩니다. 예:

  `student1.csv` 파일 내용:

  ```
  1,ftw,12
  2,zs,18
  3,ww,20
  ```

  S3 TVF 사용:

    ```sql
    select * from s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                     "s3.access_key"= "minioadmin",
                     "s3.secret_key" = "minioadmin",
                     "s3.endpoint" = "http://127.0.0.1:9312",
                     "s3.region" = "us-east-1",
                     "format" = "csv",
                     "use_path_style" = "true") order by c1;

    +------+------+------+
    | c1   | c2   | c3   |
    +------+------+------+
    | 1    | ftw  | 12   |
    | 2    | zs   | 18   |
    | 3    | ww   | 20   |
    +------+------+------+
    ```

  `desc function S3()`로 테이블 스키마를 확인할 수 있습니다:

    ```sql
    Desc function s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                     "s3.access_key"= "minioadmin",
                     "s3.secret_key" = "minioadmin",
                     "s3.endpoint" = "http://127.0.0.1:9312",
                     "s3.region" = "us-east-1",
                     "format" = "csv",
                     "use_path_style" = "true");

    +-------+------+------+-------+---------+-------+
    | Field | Type | Null | Key   | Default | Extra |
    +-------+------+------+-------+---------+-------+
    | c1    | TEXT | Yes  | false | NULL    | NONE  |
    | c2    | TEXT | Yes  | false | NULL    | NONE  |
    | c3    | TEXT | Yes  | false | NULL    | NONE  |
    +-------+------+------+-------+---------+-------+
    ```

- **`csv_with_names` 형식**

  `csv_with_names` 형식: 파일의 첫 번째 줄에서 테이블 스키마의 컬럼 수와 이름을 파싱하며, 모든 컬럼 타입을 `String`으로 설정합니다. 예:

  `student_with_names.csv` 파일 내용:

  ```
  id,name,age
  1,ftw,12
  2,zs,18
  3,ww,20
  ```

  S3 TVF 사용:

  ```sql
  select * from s3("uri" = "http://127.0.0.1:9312/test2/student_with_names.csv",
                    "s3.access_key"= "minioadmin",
                    "s3.secret_key" = "minioadmin",
                    "s3.endpoint" = "http://127.0.0.1:9312",
                    "s3.region" = "us-east-1",
                    "format" = "csv_with_names",
                    "use_path_style" = "true") order by id;

  +------+------+------+
  | id   | name | age  |
  +------+------+------+
  | 1    | ftw  | 12   |
  | 2    | zs   | 18   |
  | 3    | ww   | 20   |
  +------+------+------+
  ```

- 마찬가지로 `desc function S3()`로 테이블 스키마를 확인할 수 있습니다.

  ```sql
  desc function s3("uri" = "http://127.0.0.1:9312/test2/student_with_names.csv",
                    "s3.access_key"= "minioadmin",
                    "s3.secret_key" = "minioadmin",
                    "s3.endpoint" = "http://127.0.0.1:9312",
                    "s3.region" = "us-east-1",
                    "format" = "csv_with_names",
                    "use_path_style" = "true");

    +-------+------+------+-------+---------+-------+
    | Field | Type | Null | Key   | Default | Extra |
    +-------+------+------+-------+---------+-------+
    | id    | TEXT | Yes  | false | NULL    | NONE  |
    | name  | TEXT | Yes  | false | NULL    | NONE  |
    | age   | TEXT | Yes  | false | NULL    | NONE  |
    +-------+------+------+-------+---------+-------+
  ```

- **`csv_with_names_and_types` 형식**

  `csv_with_names_and_types` 형식: 현재 CSV 파일에서 컬럼 타입을 파싱하는 기능은 지원하지 않습니다. 이 형식을 사용하면 S3 TVF는 첫 번째 줄에서 테이블 스키마의 컬럼 수와 이름을 파싱하고, 모든 컬럼 타입을 String으로 설정하며 파일의 두 번째 줄은 무시합니다.

  `student_with_names_and_types.csv` 파일 내용:

  ```
  id,name,age
  INT,STRING,INT
  1,ftw,12
  2,zs,18
  3,ww,20
  ```

  S3 TVF 사용:

  ```sql
  select * from s3("uri" = "http://127.0.0.1:9312/test2/student_with_names_and_types.csv",
                   "s3.access_key"= "minioadmin",
                   "s3.secret_key" = "minioadmin",
                   "s3.endpoint" = "http://127.0.0.1:9312",
                   "s3.region" = "us-east-1",
                   "format" = "csv_with_names_and_types",
                   "use_path_style" = "true") order by id;

  +------+------+------+
  | id   | name | age  |
  +------+------+------+
  | 1    | ftw  | 12   |
  | 2    | zs   | 18   |
  | 3    | ww   | 20   |
  +------+------+------+
  ```

  마찬가지로 `desc function S3()`로 테이블 스키마를 확인할 수 있습니다:

  ```sql
  Desc function s3("uri" = "http://127.0.0.1:9312/test2/student_with_names_and_types.csv",
                    "s3.access_key"= "minioadmin",
                    "s3.secret_key" = "minioadmin",
  ```

- **JSON 형식**

  `json` 형식: JSON 형식에는 여러 선택적 매개변수가 있습니다. 각 매개변수의 의미는 [JSON 데이터 적재](../../../data-operate/import/file-format/json)를 참조하세요. S3 TVF로 JSON 형식 파일을 쿼리할 때는 `json_root`와 `jsonpaths` 매개변수를 기준으로 JSON 객체를 찾고, 객체의 `key`를 테이블 스키마의 컬럼 이름으로 사용하며, 모든 컬럼 타입을 String으로 설정합니다. 예:

  `data.json` 파일 내용:

  ```
  [{"id":1, "name":"ftw", "age":18}]
  [{"id":2, "name":"xxx", "age":17}]
  [{"id":3, "name":"yyy", "age":19}]
  ```

  S3 TVF를 사용한 쿼리:

  ```sql
  select * from s3(
      "uri" = "http://127.0.0.1:9312/test2/data.json",
      "s3.access_key"= "minioadmin",
      "s3.secret_key" = "minioadmin",
      "s3.endpoint" = "http://127.0.0.1:9312",
      "s3.region" = "us-east-1",
      "format" = "json",
      "strip_outer_array" = "true",
      "read_json_by_line" = "true",
      "use_path_style"="true");
  +------+------+------+
  | id   | name | age  |
  +------+------+------+
  | 1    | ftw  | 18   |
  | 2    | xxx  | 17   |
  | 3    | yyy  | 19   |
  +------+------+------+
  
  select * from s3(
      "uri" = "http://127.0.0.1:9312/test2/data.json",
      "s3.access_key"= "minioadmin",
      "s3.secret_key" = "minioadmin",
      "s3.endpoint" = "http://127.0.0.1:9312",
      "s3.region" = "us-east-1",
      "format" = "json",
      "strip_outer_array" = "true",
      "jsonpaths" = "[\"$.id\", \"$.age\"]",
      "use_path_style"="true");

  +------+------+
  ```

- **와일드카드를 포함한 URI**

  URI에서는 와일드카드와 범위 패턴을 사용하여 여러 파일을 읽을 수 있습니다. `*`, `?`, `[...]` 및 `{1..10}` 범위 확장을 포함한 자세한 구문은 [파일 경로 패턴](../../basic-element/file-path-pattern)을 참조하세요. 참고: 와일드카드를 사용할 때는 모든 파일의 형식이 동일한지 확인해야 합니다(특히 `csv`, `csv_with_names`, `csv_with_names_and_types`는 서로 다른 형식입니다). S3 TVF는 첫 번째 파일을 사용하여 테이블 스키마를 파싱합니다.
  
  다음 두 CSV 파일이 있는 경우:

  ```
  // file1.csv
  1,aaa,18
  2,qqq,20
  3,qwe,19
  
  // file2.csv
  5,cyx,19
  6,ftw,21
  ```

  URI에 와일드카드를 사용하여 쿼리할 수 있습니다:

  ```sql
  select * from s3(
          "uri" = "http://127.0.0.1:9312/test2/file*.csv",
          "s3.access_key"= "minioadmin",
          "s3.secret_key" = "minioadmin",
          "s3.endpoint" = "http://127.0.0.1:9312",
          "s3.region" = "us-east-1",
          "format" = "csv",
          "use_path_style"="true");

  +------+------+------+
  | c1   | c2   | c3   |
  +------+------+------+
  | 1    | aaa  | 18   |
  | 2    | qqq  | 20   |
  | 3    | qwe  | 19   |
  | 5    | cyx  | 19   |
  | 6    | ftw  | 21   |
  +------+------+------+
  ```

- **S3 TVF와 `insert into` 및 `cast` 함께 사용**

  ```sql
  -- Create Doris internal table
  CREATE TABLE IF NOT EXISTS ${testTable}
      (
          id int,
          name varchar(50),
          age int
      )
      COMMENT "my first table"
      DISTRIBUTED BY HASH(id) BUCKETS 32
      PROPERTIES("replication_num" = "1");
  
  -- Insert data using S3
  insert into ${testTable} (id,name,age)
  select cast (id as INT) as id, name, cast (age as INT) as age
  from s3(
      "uri" = "${uri}",
      "s3.access_key"= "${ak}",
      "s3.secret_key" = "${sk}",
      "s3.endpoint" = "http://127.0.0.1:9312",
      "s3.region" = "us-east-1",
      "format" = "${format}",
      "strip_outer_array" = "true",
      "read_json_by_line" = "true",
      "use_path_style" = "true");
  ```
