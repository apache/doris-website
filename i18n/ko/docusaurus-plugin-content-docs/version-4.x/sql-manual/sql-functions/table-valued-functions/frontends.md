## 설명 {#description}

이 테이블 함수는 frontends 임시 테이블을 생성하며, 이 테이블을 통해 현재 Doris 클러스터의 FE 노드 정보를 확인할 수 있습니다.

## 구문 {#syntax}
```sql
FRONTENDS()
```

## 접근 제어 요구 사항 {#access-control-requirements}

| 권한  | 객체 | 비고 |
| :--------- |:-------|:------|
| SELECT_PRIV | internal.information_schema | 모든 사용자는 기본적으로 이 데이터베이스에 대한 권한이 있습니다 |

## 반환 값 {#return-value}
| 필드                     | 설명 |
|--------------------------|---------------------------------------------------------------------------------------------------------|
| **Name**                 | 프런트엔드 노드의 고유한 이름입니다. |
| **Host**                 | 프런트엔드 노드의 IP 주소 또는 호스트 이름입니다. |
| **EditLogPort**          | 편집 로그 통신에 사용되는 포트입니다. |
| **HttpPort**             | 프런트엔드 노드의 HTTP 포트입니다. |
| **QueryPort**            | 프런트엔드 노드에서 쿼리 실행에 사용되는 포트입니다. |
| **RpcPort**              | RPC 통신에 사용되는 포트입니다. |
| **ArrowFlightSqlPort**   | Arrow Flight SQL 포트입니다(고성능 데이터 전송을 위한 Apache Arrow 연동에 사용). |
| **Role**                 | 프런트엔드 노드의 역할입니다(예: `FOLLOWER`). |
| **IsMaster**             | 해당 노드가 마스터 노드인지 여부를 나타냅니다(true/false). |
| **ClusterId**            | 프런트엔드 노드가 속한 클러스터의 식별자입니다. |
| **Join**                 | 프런트엔드 노드가 클러스터에 참여하고 있는지 여부를 나타냅니다(true/false). |
| **Alive**                | 프런트엔드 노드가 살아 있는지 여부를 나타냅니다(true/false). |
| **ReplayedJournalId**    | 프런트엔드 노드가 마지막으로 재생한 저널 ID입니다. |
| **LastStartTime**        | 프런트엔드 노드가 마지막으로 시작된 시각의 타임스탬프입니다. |
| **LastHeartbeat**        | 프런트엔드 노드에서 마지막으로 수신한 하트비트의 타임스탬프입니다. |
| **IsHelper**             | 프런트엔드 노드가 헬퍼 노드인지 여부를 나타냅니다(true/false). |
| **ErrMsg**               | 프런트엔드 노드가 보고한 오류 메시지입니다. |
| **Version**              | 프런트엔드 노드의 버전입니다. |
| **CurrentConnected**     | 프런트엔드 노드가 현재 클러스터에 연결되어 있는지 여부를 나타냅니다(Yes/No). |
