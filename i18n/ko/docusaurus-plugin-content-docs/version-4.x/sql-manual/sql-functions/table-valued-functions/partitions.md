## 설명 {#description}

이 테이블 함수는 임시 파티션 테이블을 생성하여 특정 테이블의 파티션 목록을 조회할 수 있게 합니다.

## 구문 {#syntax}

```sql
PARTITIONS(
    "catalog"="<catalog>",
    "database"="<database>",
    "table"="<table>"
)
```

## 필수 매개변수 {#required-parameters}
| 필드             | 설명                                             |
|------------------|--------------------------------------------------|
| **`<catalog>`**  | 쿼리할 클러스터의 Catalog 이름을 지정합니다.     |
| **`<database>`** | 쿼리할 클러스터의 데이터베이스 이름을 지정합니다. |
| **`<table>`**    | 쿼리할 클러스터의 테이블 이름을 지정합니다.       |


## 반환 값 {#return-value}
| 필드                      | 설명                                                                         |
|---------------------------|-----------------------------------------------------------------------------|
| PartitionId               | 파티션 ID                                                                    |
| PartitionName             | 파티션 이름                                                                  |
| VisibleVersion            | 파티션 버전                                                                  |
| VisibleVersionTime        | 파티션 버전이 커밋된 시간                                                      |
| State                     | 파티션 상태                                                                  |
| PartitionKey              | 파티션 키                                                                    |
| Range                     | 파티션 범위                                                                  |
| DistributionKey           | 파티셔닝에 사용하는 분산 키                                                   |
| Buckets                   | 파티션의 버킷 수                                                              |
| ReplicationNum            | 파티션의 복제본 수                                                            |
| StorageMedium             | 파티션에 사용하는 저장 매체                                                   |
| CooldownTime              | 파티션의 쿨다운 시간                                                          |
| RemoteStoragePolicy       | 파티션의 원격 스토리지 정책                                                   |
| LastConsistencyCheckTime  | 파티션의 마지막 일관성 검사 시간                                              |
| DataSize                  | 파티션 내 데이터 크기                                                         |
| IsInMemory                | 파티션이 메모리에 저장되는지 여부                                             |
| ReplicaAllocation         | 파티션의 복제 전략                                                            |
| IsMutable                 | 파티션의 변경 가능 여부                                                       |
| SyncWithBaseTables        | 파티션이 기본 테이블과 동기화되어 있는지 여부(비동기 구체화된 뷰의 경우)       |
| UnsyncTables              | 동기화되지 않은 기본 테이블(비동기 구체화된 뷰 파티션의 경우)                 |
