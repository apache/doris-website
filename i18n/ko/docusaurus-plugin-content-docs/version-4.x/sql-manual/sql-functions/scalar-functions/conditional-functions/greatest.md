## 설명 {#description}

여러 표현식을 비교하여 그중 가장 큰 값을 반환합니다. 인수 중 하나라도 `NULL`이면 `NULL`을 반환합니다.

## 구문 {#syntax}

```sql
GREATEST(<expr> [, ...])
```

## 매개변수 {#parameters}
### 필수 매개변수 {#required-parameter}
- `<expr>`: `TINYINT`, `SMALLINT`, `INT`, `BIGINT`, `LARGEINT`, `FLOAT`, `DOUBLE`, `STRING`, `DATETIME`, `DECIMAL` 타입을 지원합니다.
### 선택적 매개변수 {#optional-parameters}
- 여러 인수를 지원합니다.

## 반환 값 {#return-value}
- 주어진 표현식 중 가장 큰 값을 반환합니다.
- 인수 중 하나라도 `NULL`이면 `NULL`을 반환합니다.

## 사용 시 참고 사항 {#usage-notes}
1. 같은 타입의 인수를 전달하는 것이 좋습니다. 인수의 타입이 서로 다르면 함수는 같은 타입으로 변환을 시도합니다. 변환 규칙은 [타입 변환](../../../basic-element/sql-data-types/conversion/overview.md)을 참고하세요.
2. 인수 중 하나라도 NULL이면 결과는 NULL입니다.

## 예제 {#examples}
1. 예제 1
    ```sql
    SELECT GREATEST(-1, 0, 5, 8);
    ```
    ```text
    +-----------------------+
    | GREATEST(-1, 0, 5, 8) |
    +-----------------------+
    |                     8 |
    +-----------------------+
    ```
2. NULL 인수
    ```sql
    SELECT GREATEST(-1, 0, 5, NULL);
    ```
    ```text
    +--------------------------+
    | GREATEST(-1, 0, 5, NULL) |
    +--------------------------+
    | NULL                     |
    +--------------------------+
    ```
3. 타입 변환
    ```sql
    SELECT GREATEST(6, 4.29, 7);
    ```
    ```text
    +----------------------+
    | GREATEST(6, 4.29, 7) |
    +----------------------+
    |                 7.00 |
    +----------------------+
    ```
    > 세 번째 인수 "7"은 Decimal 타입으로 변환됩니다.
4. 날짜 타입
    ```sql
    SELECT GREATEST('2022-02-26 20:02:11', '2020-01-23 20:02:11', '2020-06-22 20:02:11');
    ```
    ```text
    +-------------------------------------------------------------------------------+
    | GREATEST('2022-02-26 20:02:11', '2020-01-23 20:02:11', '2020-06-22 20:02:11') |
    +-------------------------------------------------------------------------------+
    | 2022-02-26 20:02:11                                                           |
    +-------------------------------------------------------------------------------+
    ```
