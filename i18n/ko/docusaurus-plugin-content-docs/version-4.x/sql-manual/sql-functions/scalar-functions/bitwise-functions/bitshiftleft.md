## 설명 {#description}
이진수의 모든 비트를 지정된 자릿수만큼 왼쪽으로 이동하는 왼쪽 시프트 연산을 수행합니다. 비트 연산의 한 형태로, 일반적으로 이진 데이터를 처리하거나 수학 계산을 효율적으로 수행하는 데 사용됩니다.

BIGINT 타입의 최댓값(9223372036854775807)을 왼쪽으로 한 자리 시프트하면 결과는 -2입니다.
## 구문 {#syntax}
```sql
BIT_SHIFT_LEFT(<x>, <bits>)
```

## 매개변수 {#parameters}
- `<x>`: 시프트할 숫자입니다.
- `<bits>`: 왼쪽으로 시프트할 자릿수입니다. `<x>`를 몇 자리 시프트할지 결정하는 정수입니다.

## 반환 값 {#return-value}
왼쪽 시프트 연산의 결과를 나타내는 정수를 반환합니다.

## 예제 {#examples}
1. 예제 1
    ```sql
    select BIT_SHIFT_LEFT(5, 2), BIT_SHIFT_LEFT(-5, 2), BIT_SHIFT_LEFT(9223372036854775807, 1);
    ```

    ```text
    +----------------------+-----------------------+----------------------------------------+
    | BIT_SHIFT_LEFT(5, 2) | BIT_SHIFT_LEFT(-5, 2) | BIT_SHIFT_LEFT(9223372036854775807, 1) |
    +----------------------+-----------------------+----------------------------------------+
    |                   20 |                   -20 |                                     -2 |
    +----------------------+-----------------------+----------------------------------------+
    ```
2. NULL 인수
    ```sql
    select BIT_SHIFT_LEFT(5, NULL), BIT_SHIFT_LEFT(NULL, 2), BIT_SHIFT_LEFT(NULL, NULL);
    ```
    ```text
    +-------------------------+-------------------------+----------------------------+
    | BIT_SHIFT_LEFT(5, NULL) | BIT_SHIFT_LEFT(NULL, 2) | BIT_SHIFT_LEFT(NULL, NULL) |
    +-------------------------+-------------------------+----------------------------+
    |                    NULL |                    NULL |                       NULL |
    +-------------------------+-------------------------+----------------------------+
    ```
