## 설명 {#description}

TIME_FORMAT 함수는 지정된 형식 문자열에 따라 시간 값을 문자열로 변환합니다. TIME 및 DATETIME 타입의 형식 지정을 지원하며, 지정된 형식에 맞는 문자열을 출력합니다.

이 함수는 MySQL의 [time_format 함수](https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_time-format)와 동일하게 동작합니다.

## 구문 {#syntax}

```sql
TIME_FORMAT(<time_or_datetime_expr>, <format>)
```

## 매개변수 {#parameters}

| 매개변수                 | 설명                                                                                                                                                |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<time_or_datetime_expr>` | 유효한 시간 값으로, TIME 또는 DATETIME 타입을 지원합니다.                                                                                                     |
| `<format>`                | 시간의 출력 형식을 `varchar` 타입으로 지정합니다. 형식 문자열에 날짜 형식 지정자나 허용되지 않는 형식 지정자가 포함되어 있으면 NULL을 반환합니다. |

지원되는 형식 지정자:

| 지정자 | 설명                                   |
| --------- | --------------------------------------------- |
| %f        | 마이크로초 (000000-999999)                  |
| %H        | 시 (00-23)                                  |
| %h        | 시 (01-12)                                  |
| %I        | 시 (01-12)                                  |
| %i        | 분, 숫자 (00-59)                      |
| %k        | 시 (0-23)                                   |
| %l        | 시 (1-12)                                   |
| %p        | AM 또는 PM                                      |
| %r        | 시간, 12시간제 (hh:mm:ss 뒤에 AM 또는 PM) |
| %S        | 초 (00-59)                               |
| %s        | 초 (00-59)                               |
| %T        | 시간, 24시간제 (hh:mm:ss)                      |
| %%        | 리터럴 % 문자를 나타냄              |

## 반환 값 {#return-value}

형식이 지정된 시간 문자열을 Varchar 타입으로 반환합니다.

특수한 경우:
- `time_or_datetime_expr` 또는 `format`이 NULL이면 NULL을 반환합니다.
- `format` 문자열에 날짜 형식 지정자가 포함되어 있는 경우:
    - `%Y`: `0000`을 반환합니다.
    - `%y`, `%m`, `%d`: `00`을 반환합니다.
    - `%c`, `%e`: `0`을 반환합니다.
    - 그 밖의 날짜 형식 지정자 (`%a`, `%b`, `%D`, `%j`, `%M`, `%u`, `%U`, `%v`, `%V`, `%w`, `%W`, `%x`, `%X`): NULL을 반환합니다.
- 시간 값의 시 부분이 23보다 크면 `%H` 및 `%k` 형식 지정자는 23보다 큰 값을 반환합니다. 다른 시 형식 지정자는 시 값을 12로 나눈 나머지를 반환합니다.

SELECT
    id,
    tm,
    TIME_FORMAT(tm, '%H') AS '%H',
    TIME_FORMAT(tm, '%k') AS '%k',
    TIME_FORMAT(tm, '%h') AS '%h',
    TIME_FORMAT(tm, '%I') AS '%I',
    TIME_FORMAT(tm, '%l') AS '%l',
    TIME_FORMAT(tm, '%i') AS '%i',
    TIME_FORMAT(tm, '%s') AS '%s',
    TIME_FORMAT(tm, '%S') AS '%S',
    TIME_FORMAT(tm, '%f') AS '%f',
    TIME_FORMAT(tm, '%p') AS '%p',
    TIME_FORMAT(tm, '%r') AS '%r',
    TIME_FORMAT(tm, '%T') AS '%T',
    TIME_FORMAT(tm, '%H:%i:%s.%f') AS '%H:%i:%s.%f',
    TIME_FORMAT(tm, '%k %H %l %I %h') AS '%k %H %l %I %h',
    TIME_FORMAT(tm, '%T %r %h:%I') AS '%T %r %h:%I',
    TIME_FORMAT(tm, '%l %k %I %H %h %p') AS '%l %k %I %H %h %p',
    TIME_FORMAT(tm, '%f %s %i %T %r') AS '%f %s %i %T %r'
FROM test_time_format
