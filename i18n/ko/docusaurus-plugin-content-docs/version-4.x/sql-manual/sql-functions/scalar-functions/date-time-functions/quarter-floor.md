## 설명 {#description}

날짜 및 시간 값을 지정된 분기 주기의 가장 가까운 경계로 내림합니다. 기준 시간을 지정하면 해당 시간을 기준으로 주기를 계산합니다.

## 구문 {#syntax}

```sql
QUARTER_FLOOR(<datetime>)
QUARTER_FLOOR(<datetime>, <origin>)
QUARTER_FLOOR(<datetime>, <period>)
QUARTER_FLOOR(<datetime>, <period>, <origin>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| ---- | ---- |
| `<datetime>` | 내림할 날짜 및 시간 값으로, 타입은 DATE 또는 DATETIME입니다 |
| `<period>` | 분기 단위의 주기 값으로, 타입은 INT이며 각 주기에 포함되는 분기 수를 나타냅니다 |
| `<origin>` | 주기의 시작점으로, 타입은 DATE 또는 DATETIME이며 기본값은 0001-01-01 00:00:00입니다 |

참고:
- period를 지정하지 않으면 1분기를 주기로 사용하는 것과 같습니다
- period가 양의 정수가 아니면 함수의 결과는 NULL입니다
- 결과는 항상 과거 시점으로 내림됩니다
- 반환 값의 시간 부분은 항상 00:00:00입니다

## 반환 값 {#return-value}

`<datetime>`이 DATE 타입이면 반환 타입은 DATE입니다.
`<datetime>`이 DATETIME 타입이면 반환 타입은 DATETIME입니다.
결과의 시간 부분은 00:00:00으로 설정됩니다.

## 예제 {#examples}

시작점을 '0001-01-01 00:00:00'으로 하고 주기를 각각 5 / 4분기로 설정하면, 입력 날짜에 가장 가까운 주기 시작점을 반환합니다.
```sql
SELECT QUARTER_FLOOR("2023-07-13 22:28:18", 5), QUARTER_FLOOR("2023-07-13 22:28:18", 4);
```

```text
+-----------------------------------------+-----------------------------------------+
| QUARTER_FLOOR("2023-07-13 22:28:18", 5) | QUARTER_FLOOR("2023-07-13 22:28:18", 4) |
+-----------------------------------------+-----------------------------------------+
| 2021-01-01 00:00:00                     | 2022-01-01 00:00:00                     |
+-----------------------------------------+-----------------------------------------+
```

주기의 시작점을 '2022-01-01 00:00:00'으로 하고 주기를 각각 2 / 4분기로 설정하면, 입력 날짜에 가장 가까운 주기 시작점을 반환합니다.
```sql
SELECT QUARTER_FLOOR("2023-03-13 22:28:18", 2, "2022-01-01 00:00:00"), QUARTER_FLOOR("2023-07-13 22:28:18", 4, "2022-01-01 00:00:00");
```

```text
+----------------------------------------------------------------+----------------------------------------------------------------+
| QUARTER_FLOOR("2023-03-13 22:28:18", 2, "2022-01-01 00:00:00") | QUARTER_FLOOR("2023-07-13 22:28:18", 4, "2022-01-01 00:00:00") |
+----------------------------------------------------------------+----------------------------------------------------------------+
| 2023-01-01 00:00:00                                            | 2022-01-01 00:00:00                                            |
+----------------------------------------------------------------+----------------------------------------------------------------+
```
