## 설명 {#description}

SM3 256비트 계산

## 구문 {#syntax}

```sql
SM3( <input> )
```

## 매개변수 {#parameters}


| 매개변수 | 설명 |
|-----------|-------------|
| `<input>`   | sm3 값을 계산할 입력값으로, 문자열 및 바이너리 타입을 지원합니다.  |

## 반환값 {#return-value}
입력 문자열의 sm3 값을 반환합니다.

## 예제 {#examples}

```sql
-- vb (VarBinary) and vc (VarChar) used the same string during insertion.
SELECT * FROM mysql_catalog.binary_test.binary_test;
```

```text
|    3 | NULL       | NULL |
+------+------------+------+
```
