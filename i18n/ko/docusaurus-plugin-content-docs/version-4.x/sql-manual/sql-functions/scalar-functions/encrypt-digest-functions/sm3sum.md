## 설명 {#description}

여러 문자열의 SM3 256비트 해시 값을 계산합니다.

## 구문 {#syntax}

```sql
SM3SUM( <str> [ , <str> ... ] )
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|-----------|-------------|
| `<str>`   | sm3 값을 계산할 문자열   |

## 반환 값 {#return-value}

입력된 여러 문자열의 sm3 값을 반환합니다.

## 예제 {#examples}

```sql
select sm3sum("ab","cd");
```

```text
+------------------------------------------------------------------+
| sm3sum('ab', 'cd')                                               |
+------------------------------------------------------------------+
| 82ec580fe6d36ae4f81cae3c73f4a5b3b5a09c943172dc9053c69fd8e18dca1e |
+------------------------------------------------------------------+
```
