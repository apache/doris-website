## 설명 {#description}

64비트 murmur3 해시 값을 계산합니다.

`MURMUR_HASH3_64_V2`와의 차이점은 다음과 같습니다. 이 버전은 64비트 출력에 맞게 최적화되어 있어 v2 버전보다 성능이 약간 더 좋지만, [표준 라이브러리](https://mmh3.readthedocs.io/en/latest/api.html#mmh3.hash64) 구현과는 일치하지 않습니다.

- 참고: 테스트 결과, `xxhash_64`의 성능은 `murmur_hash3_64`의 약 두 배이므로 해시 값을 계산할 때는 `xxhash_64`를 `murmur_hash3_64` 대신 사용하는 것이 좋습니다.


## 구문 {#syntax}

```sql
MURMUR_HASH3_64( <str> [ , <str> ... ] )
```

## 매개변수 {#parameters}

| 매개변수      | 설명                                             |
|---------|------------------------------------------------|
| `<str>` | 계산할 64비트 murmur3 해시 값 |

## 반환 값 {#return-value}

입력 문자열의 64비트 murmur3 해시를 반환합니다.

입력 매개변수 중 하나라도 NULL이면 NULL을 반환합니다.

## 예제 {#examples}

```sql
select murmur_hash3_64(null), murmur_hash3_64("hello"), murmur_hash3_64("hello", "world");
```

```text
+-----------------------+--------------------------+-----------------------------------+
| murmur_hash3_64(NULL) | murmur_hash3_64('hello') | murmur_hash3_64('hello', 'world') |
+-----------------------+--------------------------+-----------------------------------+
|                  NULL |     -3215607508166160593 |               3583109472027628045 |
+-----------------------+--------------------------+-----------------------------------+
```
