## 기능 {#function}

시작 오프셋과 길이를 지정하여 하위 배열을 반환합니다.

## 구문 {#syntax}

- `ARRAY_SLICE(arr, offset)`
- `ARRAY_SLICE(arr, offset, length)`

## 매개변수 {#parameters}

- `arr`: `ARRAY<T>`.
- `offset`: 시작 위치입니다. 양수이면 배열의 처음부터 셉니다(`1`은 첫 번째 요소). 음수이면 배열의 끝부터 셉니다(`-1`은 마지막 요소).
- `length`: 가져올 길이입니다. 양수이면 `length`개의 요소를 가져오고, 음수이면 길이를 0으로 처리합니다.

## 반환 값 {#return-value}

- 입력과 동일한 타입의 `ARRAY<T>`를 반환합니다.

## 사용 시 참고 사항 {#usage-notes}

- 범위를 벗어나도 안전하게 처리됩니다. 시작 위치와 끝 위치는 배열 경계에 맞게 제한됩니다. 겹치는 범위가 없으면 빈 배열을 반환합니다.

## 예제 {#examples}

- 시작 오프셋이 양수인 경우: 오프셋부터 오른쪽 끝까지
  - `ARRAY_SLICE([1,2,3,4,5,6], 2)` -> `[2,3,4,5,6]`

- 시작 오프셋이 음수인 경우: 오프셋부터 오른쪽 끝까지
  - `ARRAY_SLICE([1,2,3,4,5,6], -3)` -> `[4,5,6]`

- 길이가 양수인 경우: 오프셋부터 오른쪽으로 요소 가져오기
  - `ARRAY_SLICE([1,2,3,4,5,6], 2, 3)` -> `[2,3,4]`
  - `ARRAY_SLICE([1,2,3,4,5,6], -4, 2)` -> `[3,4]`

- 길이가 음수인 경우: 길이를 0으로 처리
  - `ARRAY_SLICE([1,2,3,4,5,6], 2, -2)` -> `[]`

- 인수가 범위를 벗어난 경우: 빈 배열 반환
  - `ARRAY_SLICE([1,2,3,4,5,6], 10, 3)` -> `[]`

- 인수가 하나라도 `NULL`인 경우: `NULL` 반환
  - `ARRAY_SLICE([1,2,3], NULL, 2)` -> `NULL`
  - `ARRAY_SLICE([1,2,3], 2, NULL)` -> `NULL`
  - `ARRAY_SLICE(NULL, 2, 3)` -> `NULL`
