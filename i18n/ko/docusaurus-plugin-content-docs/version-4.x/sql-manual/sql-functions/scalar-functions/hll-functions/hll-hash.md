## 설명 {#description}

주어진 값을 HLL (HyperLogLog) 타입으로 변환합니다. 이 함수는 일반적으로 데이터 적재 시 원시 데이터로부터 HLL을 생성하는 데 사용됩니다.

## 구문 {#syntax}

```sql
HLL_HASH(<value>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명                                                   |
|-----------|---------------------------------------------------------------|
| `<value>` | HLL 타입으로 변환할 값입니다. 문자열, 숫자 등 어떤 데이터 타입의 값이든 사용할 수 있습니다. |

## 예제 {#examples}

```sql
SELECT HLL_CARDINALITY(HLL_HASH('abc'));
```

```text
+----------------------------------+
| hll_cardinality(HLL_HASH('abc')) |
+----------------------------------+
|                                1 |
+----------------------------------+
```
