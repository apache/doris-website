## 설명 {#description}

JSON 데이터에 `<path>`로 지정한 필드가 존재하는지 확인합니다. 존재하면 TRUE를, 존재하지 않으면 FALSE를 반환합니다.

## 구문 {#syntax}

```sql
JSON_EXISTS_PATH (<json_object>, <path>)
```

## 매개변수 {#parameters}
- `<json_object>` JSON 타입입니다. 이 값에 `<path>`로 지정한 경로가 존재하는지 확인합니다.
- `<path>` String 타입으로, 경로를 지정합니다.

## 반환값 {#return-value}
- BOOL 타입으로, 존재하면 TRUE를, 존재하지 않으면 FALSE를 반환합니다.
- NULL: `<json_object>` 또는 `<path>` 중 하나라도 NULL이면 NULL을 반환합니다.

## 예제 {#examples}
1. 예제 1
    ```sql
    SELECT JSON_EXISTS_PATH('{"id": 123, "name": "doris"}', '$.name');
    ```
    ```text
    +------------------------------------------------------------+
    | JSON_EXISTS_PATH('{"id": 123, "name": "doris"}', '$.name') |
    +------------------------------------------------------------+
    |                                                          1 |
    +------------------------------------------------------------+
    ```
2. 예제 2
    ```sql
    SELECT JSON_EXISTS_PATH('{"id": 123, "name": "doris"}', '$.age');
    ```
    ```text
    +-----------------------------------------------------------+
    | JSON_EXISTS_PATH('{"id": 123, "name": "doris"}', '$.age') |
    +-----------------------------------------------------------+
    |                                                         0 |
    +-----------------------------------------------------------+
    ```
3. NULL 매개변수
    ```sql
    SELECT JSON_EXISTS_PATH('{"id": 123, "name": "doris"}', NULL);
    ```
    ```text
    +--------------------------------------------------------+
    | JSON_EXISTS_PATH('{"id": 123, "name": "doris"}', NULL) |
    +--------------------------------------------------------+
    |                                                   NULL |
    +--------------------------------------------------------+
    ```
    ```sql
    SELECT JSON_EXISTS_PATH(NULL, '$.age');
    ```
    ```text
    +---------------------------------+
    | JSON_EXISTS_PATH(NULL, '$.age') |
    +---------------------------------+
    |                            NULL |
    +---------------------------------+
    ```
