## 설명 {#description}

x의 쌍곡탄젠트를 반환합니다.

## 구문 {#syntax}

```sql
TANH(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<x>` | 쌍곡탄젠트를 계산할 값 |

## 반환 값 {#return-value}

매개변수 x의 쌍곡탄젠트입니다.

## 특수한 경우 {#special-cases}
- `x`가 NaN이면 NaN을 반환합니다
- `x`가 양의 무한대이면 1을 반환합니다
- `x`가 음의 무한대이면 -1을 반환합니다
- `x`가 NULL이면 NULL을 반환합니다

## 예제 {#example}

```sql
select tanh(0),tanh(1);
```

```text
+-------------------------+-------------------------+
| tanh(cast(0 as DOUBLE)) | tanh(cast(1 as DOUBLE)) |
+-------------------------+-------------------------+
|                       0 |      0.7615941559557649 |
+-------------------------+-------------------------+
```

```sql
select tanh(cast('nan' as double));
```
```text
+-----------------------------+
| tanh(cast('nan' AS DOUBLE)) |
+-----------------------------+
| NaN                         |
+-----------------------------+
```

```sql
select tanh(cast('inf' as double));
```
```text
+-----------------------------+
| tanh(cast('inf' AS DOUBLE)) |
+-----------------------------+
| 1                           |
+-----------------------------+
```

```sql
select tanh(cast('-inf' as double));
```
```text
+------------------------------+
| tanh(cast('-inf' AS DOUBLE)) |
+------------------------------+
| -1                           |
+------------------------------+
```
