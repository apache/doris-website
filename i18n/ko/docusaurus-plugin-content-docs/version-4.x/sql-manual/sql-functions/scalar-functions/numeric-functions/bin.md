## 설명 {#description}

십진수를 이진수 텍스트로 변환합니다.

## 구문 {#syntax}

```sql
BIN(<a>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<a>` | 변환할 십진수 값(유형: BigInt) |

## 반환 값 {#return-value}

매개변수 `<a>`의 이진수 표현을 반환합니다. `<a>`가 음수이면 결과는 해당 값의 64비트 보수입니다.
`a`가 NULL이면 NULL을 반환합니다.

## 예제 {#examples}

```sql
select bin(0);
```

```text
+--------+
| bin(0) |
+--------+
| 0      |
+--------+
```

```sql
select bin(-1);
```

```text
+------------------------------------------------------------------+
| bin(-1)                                                          |
+------------------------------------------------------------------+
| 1111111111111111111111111111111111111111111111111111111111111111 |
+------------------------------------------------------------------+
```

```sql
select bin(123);
```

```text
+----------+
| bin(123) |
+----------+
| 1111011  |
+----------+
```

```sql
select bin(NULL);
```

```text
+-----------+
| bin(NULL) |
+-----------+
| NULL      |
+-----------+
```
