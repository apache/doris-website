## 설명 {#description}

숫자를 통화 형식으로 출력합니다. 정수 부분은 세 자리마다 쉼표로 구분하고, 소수 부분은 두 자리로 표시합니다.

## 구문 {#syntax}

```sql
MONEY_FORMAT(<number>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|-----------|------------|
| `<number>`   | 통화 형식으로 변환할 숫자 |

## 반환값 {#return-value}

통화 형식의 문자열을 반환합니다. 특수한 경우는 다음과 같습니다:

- 매개변수가 NULL이면 NULL을 반환합니다.

## 예제 {#example}

```sql
select money_format(17014116);
```

```text
+------------------------+
| money_format(17014116) |
+------------------------+
| 17,014,116.00          |
+------------------------+
```

```sql
select money_format(1123.456);
```

```text
+------------------------+
| money_format(1123.456) |
+------------------------+
| 1,123.46               |
+------------------------+
```

```sql
select money_format(1123.4);
```

```text
+----------------------+
| money_format(1123.4) |
+----------------------+
| 1,123.40             |
+----------------------+
```
