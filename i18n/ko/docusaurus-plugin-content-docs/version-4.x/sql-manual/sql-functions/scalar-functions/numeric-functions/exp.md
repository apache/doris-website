## 설명 {#description}

`x`를 지수로 하고 `e`를 밑으로 하는 값을 반환합니다.

## 별칭 {#alias}

- DEXP

## 구문 {#syntax}

```sql
EXP(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<x>` | 독립 변수 |

## 반환값 {#return-value}

 double 타입의 값을 반환합니다. 특수한 경우는 다음과 같습니다:
- 매개변수가 NULL이면 NULL을 반환합니다.
- 매개변수가 매우 크면 Infinity를 반환합니다.

## 예제 {#example}

```sql
select exp(2);
```

```text
+------------------+
| exp(2.0)         |
+------------------+
| 7.38905609893065 |
+------------------+
```

```sql
select exp(3.4);
```

```text
+--------------------+
| exp(3.4)           |
+--------------------+
| 29.964100047397011 |
+--------------------+
```

```sql
select exp(1000000);
```

```text
+--------------+
| EXP(1000000) |
+--------------+
|     Infinity |
+--------------+
```
