## 설명 {#description}

`x`의 아크코사인을 반환하며, 반환값은 `NULL`입니다(단, `x`가 `-1`에서 `1` 사이의 범위에 없는 경우).

## 구문 {#syntax}

```sql
ACOS(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |  
| -- | -- |  
| `<x>` | 아크코사인을 계산할 값 |  

## 반환 값 {#return-value}

매개변수 `x`의 아크코사인 값으로, 라디안 단위로 표현됩니다.

## 특수 사례 {#special-cases}

- `x`가 1이면 0을 반환합니다
- `x`가 0이면 π/2를 반환합니다
- `x`가 -1이면 π를 반환합니다
- `x`가 [-1, 1] 범위에 없으면 `NULL`을 반환합니다
- `x`가 NaN이면 NaN을 반환합니다
- `x`가 양의 무한대 또는 음의 무한대이면 `NULL`을 반환합니다
- `x`가 NULL이면 NULL을 반환합니다

## 예제 {#examples}

```sql
select acos(1);
```

```text
+-----------+
| acos(1.0) |
+-----------+
|         0 |
+-----------+
```

```sql
select acos(0);
```

```text
+--------------------+
| acos(0.0)          |
+--------------------+
| 1.5707963267948966 |
+--------------------+
```

```sql
select acos(-1);
```

```text
+--------------------+
| acos(-1.0)         |
+--------------------+
| 3.141592653589793  |
+--------------------+
```

```sql
select acos(-2);
```

```text
+------------+
| acos(-2.0) |
+------------+
|       NULL |
+------------+
```

```sql
select acos(1.0000001);
```

```text
+-----------------+
| acos(1.0000001) |
+-----------------+
|            NULL |
+-----------------+
```

```sql
select acos(cast('nan' as double));
```

```text
+---------------------------+
| acos(cast('nan' AS DOUBLE)) |
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select acos(cast('inf' as double));
```

```text
+---------------------------+
| acos(cast('inf' AS DOUBLE)) |
+---------------------------+
| NULL                      |
+---------------------------+
```
