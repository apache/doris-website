## 설명 {#description}

라디안 단위의 값 x의 코탄젠트를 반환합니다. 입력과 출력은 double 타입만 지원합니다. null 값을 입력하면 null 값을 반환합니다.

## 구문 {#syntax}

```sql
COT(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<x>` | 코탄젠트를 계산할 값 |

## 반환값 {#return-value}

x의 코탄젠트를 나타내는 Double 타입 값을 반환합니다.

## 특수한 경우 {#special-cases}
- `x`가 NaN이면 NaN을 반환합니다
- `x`가 양의 무한대 또는 음의 무한대이면 NaN을 반환합니다
- `x`가 NULL이면 NULL을 반환합니다

## 예제 {#example}

```sql
select cot(1),cot(2),cot(1000);
```

```text
+--------------------+----------------------+--------------------+
| cot(1)             | cot(2)               | cot(1000)          |
+--------------------+----------------------+--------------------+
| 0.6420926159343306 | -0.45765755436028577 | 0.6801221323348698 |
+--------------------+----------------------+--------------------+
```

null 값을 입력하는 경우입니다.

```sql
select cot(null);
```

```text
+--------------------+
| cot(null)          |
+--------------------+
|      NULL          |
+--------------------+
```

```sql
select cot(cast('nan' as double));
```

```text
+----------------------------+
| cot(cast('nan' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select cot(cast('inf' as double));
```

```text
+----------------------------+
| cot(cast('inf' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select cot(cast('-inf' as double));
```

```text
+-----------------------------+
| cot(cast('-inf' AS DOUBLE)) |
+-----------------------------+
| NaN                         |
+-----------------------------+
```
