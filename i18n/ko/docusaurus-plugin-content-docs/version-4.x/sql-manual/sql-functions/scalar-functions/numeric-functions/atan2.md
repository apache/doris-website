## 설명 {#description}

'y' / 'x'의 아크탄젠트를 반환합니다.

## 구문 {#syntax}

```sql
ATAN2(<y>, <x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |  
| -- | -- |  
| `<x>` | 원점 (0,0)에서 x축을 따라 잰 수평 거리(좌표)를 나타내는 값입니다. |  
| `<y>` | 원점 (0,0)에서 y축을 따라 잰 수직 거리(좌표)를 나타내는 값입니다. |  

## 반환값 {#return-value}

매개변수 `y` / `x`의 atan2 값입니다. 

## 특수한 경우 {#special-cases}
- `y` 또는 `x`가 NaN이면 NaN을 반환합니다
- `x > 0`이고 `y = ±0.0`이면 ±0을 반환합니다(부호는 `y`를 따릅니다)
- `x = 0.0`(+0.0 또는 -0.0)이고 `y > 0`이면 π/2(약 1.570796326794897)를 반환합니다
- `x = 0.0`(+0.0 또는 -0.0)이고 `y < 0`이면 -π/2(약 -1.570796326794897)를 반환합니다
- `x < 0`이고 `y = +0.0`이면 π(약 3.141592653589793)를 반환하며, `x < 0`이고 `y = -0.0`이면 -π를 반환합니다
- `y = +Infinity`이고 `x`가 유한하면 π/2를 반환하며, `y = -Infinity`이고 `x`가 유한하면 -π/2를 반환합니다
- `y = +Infinity`이고 `x = +Infinity`이면 π/4(약 0.7853981633974483)를 반환합니다
- `y = -Infinity`이고 `x = +Infinity`이면 -π/4(약 -0.7853981633974483)를 반환합니다
- `y = +Infinity`이고 `x = -Infinity`이면 3π/4(약 2.356194490192345)를 반환합니다
- `y = -Infinity`이고 `x = -Infinity`이면 -3π/4(약 -2.356194490192345)를 반환합니다
- `x = +Infinity`이고 유한한 `y` > 0이면 0을 반환하며, 유한한 `y` < 0이면 -0을 반환합니다
- `x = -Infinity`이고 유한한 `y` > 0이면 π를 반환하며, 유한한 `y` < 0이면 -π를 반환합니다
- `y` 또는 `x`가 NULL이면 NULL을 반환합니다

+---------------------+
