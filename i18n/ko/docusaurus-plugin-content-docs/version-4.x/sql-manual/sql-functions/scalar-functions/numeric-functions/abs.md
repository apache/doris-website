## 설명 {#description}

`x`의 절댓값을 반환합니다.

## 구문 {#syntax}

```sql
ABS(<x>) 
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |  
| -- | -- |  
| `<x>` | 절댓값을 계산할 값 |  

## 반환 값 {#return-value}

매개변수 `x`의 절댓값을 반환합니다. 
`x`가 NULL이면 NULL을 반환합니다.

## 예제 {#example}

```sql
select abs(-2);
```

```text
+---------+
| abs(-2) |
+---------+
|       2 |
+---------+
```

```sql
select abs(3.254655654);
```

```text
+------------------+
| abs(3.254655654) |
+------------------+
|      3.254655654 |
+------------------+
```

```sql
select abs(-3254654236547654354654767);
```

```text
+---------------------------------+
| abs(-3254654236547654354654767) |
+---------------------------------+
| 3254654236547654354654767       |
+---------------------------------+
```

```sql
select abs(NULL);
```

```text
+-----------+
| abs(NULL) |
+-----------+
|      NULL |
+-----------+
```
