## 설명 {#description}

`x`의 자연로그를 밑 `e`로 계산하여 반환합니다.

## 별칭 {#alias}

- DLOG1

## 구문 {#syntax}

```sql
LN(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|-----------|------------|
| `<x>`   | 진수는 0보다 커야 합니다 |

## 반환 값 {#return-value}

부동소수점 수를 반환합니다. 특수한 경우는 다음과 같습니다.

- x가 NULL이면 NULL을 반환합니다
- x가 NaN이면 NaN을 반환합니다
- x가 양의 무한대이면 Infinity를 반환합니다

## 예제 {#example}

```sql
select ln(1);
```

```text
+-----------------------+
| ln(cast(1 as DOUBLE)) |
+-----------------------+
|                   0.0 |
+-----------------------+
```

```sql
select ln(e());
```

```text
+---------+
| ln(e()) |
+---------+
|     1.0 |
+---------+
```

```sql
select ln(10);
```

```text
+------------------------+
| ln(cast(10 as DOUBLE)) |
+------------------------+
|      2.302585092994046 |
+------------------------+
```

```sql
select ln(cast('inf' as double));
```

```text
+---------------------------+
| ln(cast('inf' as double)) |
+---------------------------+
|                  Infinity |
+---------------------------+
```

```sql
select ln(cast('nan' as double));
```

```text
+---------------------------+
| ln(cast('nan' as double)) |
+---------------------------+
|                       NaN |
+---------------------------+
```
