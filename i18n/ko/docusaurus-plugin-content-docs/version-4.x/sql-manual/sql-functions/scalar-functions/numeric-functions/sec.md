## 설명 {#description}

라디안 단위의 값 x에 대한 시컨트 값을 반환합니다. 입력과 출력은 double 타입만 지원합니다. null 값을 입력하면 null 값을 반환합니다.

## 구문 {#syntax}

```sql
SEC(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<x>` | 시컨트를 계산할 값 |

## 반환 값 {#return-value}

x의 시컨트 값을 Double 타입으로 반환합니다.

## 특수한 경우 {#special-cases}
- `x`가 NaN이면 NaN을 반환합니다.
- `x`가 양의 무한대 또는 음의 무한대이면 NaN을 반환합니다.
- `x`가 NULL이면 NULL을 반환합니다.

## 예제 {#example}

```sql
select sec(1),sec(2),sec(1000);
```

```text
+--------------------+--------------------+--------------------+
| sec(1)             | sec(2)             | sec(1000)          |
+--------------------+--------------------+--------------------+
| 1.8508157176809255 | -2.402997961722381 | 1.7781600385912715 |
+--------------------+--------------------+--------------------+
```

null 값을 입력하는 경우입니다.

```sql
select sec(null);
```

```text
+--------------------+
| sec(null)          |
+--------------------+
|      NULL          |
+--------------------+
```

```sql
select sec(cast('nan' as double));
```

```text
+---------------------------+
| sec(cast('nan' AS DOUBLE))|
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select sec(cast('inf' as double));
```

```text
+---------------------------+
| sec(cast('inf' AS DOUBLE))|
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select sec(cast('-inf' as double));
```

```text
+----------------------------+
| sec(cast('-inf' AS DOUBLE))|
+----------------------------+
| NaN                        |
+----------------------------+
```
