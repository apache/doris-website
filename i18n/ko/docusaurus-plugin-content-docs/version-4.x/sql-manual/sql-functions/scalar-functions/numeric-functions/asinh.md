## 설명 {#description}

`x`의 역쌍곡사인 값을 반환합니다.

## 구문 {#syntax}

```sql
ASINH(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |  
| -- | -- |  
| `<x>` | 역쌍곡사인 값을 계산할 대상 값 |  

## 반환 값 {#return-value}

매개변수 `x`의 asinh 값입니다. 

## 특수한 경우 {#special-cases}
- `x`가 NaN이면 NaN을 반환합니다
- `x`가 양의 무한대이면 Infinity를 반환합니다
- `x`가 음의 무한대이면 -Infinity를 반환합니다
- `x`가 +0.0이면 0을 반환합니다
- `x`가 -0.0이면 -0을 반환합니다
- 절댓값이 매우 크면 Infinity/-Infinity로 오버플로할 수 있습니다(예: ±1e308)
- `x`가 NULL이면 NULL을 반환합니다

## 예제 {#example}

```sql
select asinh(0.0);
```

```text
+------------+
| asinh(0.0) |
+------------+
|          0 |
+------------+
```

```sql
select asinh(1.0);
```

```text
+-------------------+
| asinh(1.0)        |
+-------------------+
| 0.881373587019543 |
+-------------------+
```

```sql
select asinh(-1.0);
```

```text
+--------------------+
| asinh(-1.0)        |
+--------------------+
| -0.881373587019543 |
+--------------------+
```

```sql
select asinh(cast('nan' as double));
```

```text
+------------------------------+
| asinh(cast('nan' AS DOUBLE)) |
+------------------------------+
| NaN                          |
+------------------------------+
```

```sql
select asinh(cast('inf' as double));
```

```text
+------------------------------+
| asinh(cast('inf' AS DOUBLE)) |
+------------------------------+
| Infinity                     |
+------------------------------+
```

```sql
select asinh(cast('-inf' as double));
```

```text
+-------------------------------+
| asinh(cast('-inf' AS DOUBLE)) |
+-------------------------------+
| -Infinity                     |
+-------------------------------+
```
