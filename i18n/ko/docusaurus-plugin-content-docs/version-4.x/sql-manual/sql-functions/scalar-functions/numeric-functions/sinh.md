## 설명 {#description}

`x`의 쌍곡사인 값을 반환합니다.

## 구문 {#syntax}

```sql
SINH(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |  
| -- | -- |  
| `<x>` | 쌍곡사인 값을 계산할 값 |  

## 반환 값 {#return-value}

매개변수 `x`의 sinh 값입니다.

## 특수한 경우 {#special-cases}
- `x`가 NaN이면 NaN을 반환합니다
- `x`가 양의 무한대이면 Infinity를 반환합니다
- `x`가 음의 무한대이면 -Infinity를 반환합니다
- `x`가 NULL이면 NULL을 반환합니다

## 예제 {#example}

```sql
select sinh(0.0);
```

```
+-----------+
| sinh(0.0) |
+-----------+
|         0 |
+-----------+
```

```sql
select sinh(1.0);
```

```
+--------------------+
| sinh(1.0)          |
+--------------------+
| 1.1752011936438014 |
+--------------------+
```

```sql
select sinh(-1.0);
```

```
+---------------------+
| sinh(-1.0)          |
+---------------------+
| -1.1752011936438014 |
+---------------------+
```

```sql
select sinh(cast('nan' as double));
```
```
+------------------------------+
| sinh(cast('nan' AS DOUBLE))  |
+------------------------------+
| NaN                          |
+------------------------------+
```

```sql
select sinh(cast('inf' as double));
```
```
+------------------------------+
| sinh(cast('inf' AS DOUBLE))  |
+------------------------------+
| Infinity                     |
+------------------------------+
```

```sql
select sinh(cast('-inf' as double));
```
```
+-------------------------------+
| sinh(cast('-inf' AS DOUBLE))  |
+-------------------------------+
| -Infinity                     |
+-------------------------------+
```
