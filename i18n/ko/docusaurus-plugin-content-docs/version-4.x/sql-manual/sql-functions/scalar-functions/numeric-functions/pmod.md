## 설명 {#description}

모듈러 체계에서 나머지 연산 x mod y의 가장 작은 양의 해를 반환합니다. 이 값은 (x % y + y) % y를 계산하여 구합니다.

## 구문 {#syntax}

```sql
PMOD(<x> , <y>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|-----------|------------|
| `<x>` | 피제수 |
| `<y>` | 제수이며 0이 아니어야 합니다 |

## 반환 값 {#return-value}

정수 또는 부동 소수점 수를 반환합니다. 특수한 경우는 다음과 같습니다.

- x = 0이면 0을 반환합니다.
- x가 NULL이거나 y가 NULL이면 NULL을 반환합니다.

## 예제 {#example}

```sql
SELECT PMOD(13,5);
```

```text
+-------------+
| pmod(13, 5) |
+-------------+
|           3 |
+-------------+
```

```sql
SELECT PMOD(-13,5);
```

```text
+--------------+
| pmod(-13, 5) |
+--------------+
|            2 |
+--------------+
```

```sql
SELECT PMOD(0,-12);
```

```text
+--------------+
| pmod(0, -12) |
+--------------+
|            0 |
+--------------+
```

```sql
SELECT PMOD(0,null);
```

```text
+-------------------------------+
| pmod(cast(0 as DOUBLE), NULL) |
+-------------------------------+
|                          NULL |
+-------------------------------+
```
