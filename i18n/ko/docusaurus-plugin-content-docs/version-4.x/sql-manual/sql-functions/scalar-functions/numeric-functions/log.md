## 설명 {#description}

`x`에 대해 밑이 `b`인 로그를 반환합니다.

## 구문 {#syntax}

```sql
LOG([<b>, ]<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|-----------|------------|
| `<b>`     | 선택 사항입니다. 밑은 0보다 크고 1.0이 아니어야 합니다. 생략하면 자연로그(밑이 e)를 계산합니다. |
| `<x>`     | 진수는 0보다 커야 합니다. |

## 반환 값 {#return-value}

부동 소수점 수를 반환합니다. 특수한 경우는 다음과 같습니다:

- b IS NULL 또는 x IS NULL인 경우 NULL을 반환합니다.
- 매개변수 중 하나라도 NaN이면 NaN을 반환합니다.
- 매개변수가 입력 제약 조건을 충족하지 않으면 NULL을 반환합니다.

## 예제 {#example}

```sql
select log(5,1);
```

```text
+---------------+
| log(5.0, 1.0) |
+---------------+
|             0 |
+---------------+
```

```sql
select log(3),ln(3);
```

```text
+--------------------+--------------------+
| log(3)             | ln(3)              |
+--------------------+--------------------+
| 1.0986122886681098 | 1.0986122886681098 |
+--------------------+--------------------+
```

```sql
select log(3,20);
```

```text
+--------------------+
| log(3.0, 20.0)     |
+--------------------+
| 2.7268330278608417 |
+--------------------+
```

```sql
select log(2,65536);
```

```text
+-------------------+
| log(2.0, 65536.0) |
+-------------------+
|                16 |
+-------------------+
```

```sql
select log(5,NULL);
```

```text
+------------------------------+
| log(cast(5 as DOUBLE), NULL) |
+------------------------------+
|                         NULL |
+------------------------------+
```

```sql
select log(NULL,3);
```

```text
+------------------------------+
| log(NULL, cast(3 as DOUBLE)) |
+------------------------------+
|                         NULL |
+------------------------------+
```

```sql
select log(2 ,cast('nan' as double));
```

```text
+-------------------------------+
| log(2 ,cast('nan' as double)) |
+-------------------------------+
|                           NaN |
+-------------------------------+
```

```sql
select log(2 ,-1);
```

```text
+------------+
| log(2 ,-1) |
+------------+
|       NULL |
+------------+
```
