## 설명 {#description}

숫자 `x`를 지정된 자릿수로 반올림합니다.
- `d`를 지정하지 않으면 `x`를 가장 가까운 정수로 반올림합니다.
- `d`가 음수이면 소수점 왼쪽에서 `d`로 지정한 자릿수로 반올림합니다.
- `x` 또는 `d`가 `null`이면 `null`을 반환합니다.
- `d`가 열이고 첫 번째 인수의 타입이 `Decimal`이면 결과 `Decimal`의 소수 자릿수는 입력 `Decimal`과 같습니다.


## 별칭 {#alias}

- `DROUND`

## 구문 {#syntax}

```sql
ROUND(<x> [ , <d> ])
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<x>` | 반올림할 숫자 |
| `<d>` | 선택 사항. 반올림하여 남길 소수 자릿수 |
