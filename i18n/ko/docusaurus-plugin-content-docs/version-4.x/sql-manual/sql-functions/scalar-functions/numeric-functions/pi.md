## 설명 {#description}

상수 `Pi` 값을 반환합니다.

## 구문 {#syntax}

```sql
PI()
```

## 반환 값 {#return-value}

부동 소수점 타입의 상수 Pi를 반환합니다.

## 예제 {#example}

```sql
select Pi();
```

```text
+-------------------+
| pi()              |
+-------------------+
| 3.141592653589793 |
+-------------------+
```
