## 설명 {#description}

매개변수의 코사인 값을 계산합니다

## 구문 {#syntax}

```sql
COS(<a>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<a>` | 부동 소수점 수로, 코사인을 계산할 매개변수의 라디안 값 |

## 반환값 {#return-value}

매개변수 `<a>`의 코사인 값이며, 라디안으로 표현됩니다.

## 특수 사례 {#special-cases}
- `a`가 NaN이면 NaN을 반환합니다
- `a`가 양의 무한대 또는 음의 무한대이면 NaN을 반환합니다
- `a`가 NULL이면 NULL을 반환합니다

## 예제 {#examples}

```sql
select cos(1);
```

```text
+---------------------+
| cos(1.0)            |
+---------------------+
| 0.54030230586813977 |
+---------------------+
```

```sql
select cos(0);
```

```text
+------------------------+
| cos(cast(0 as DOUBLE)) |
+------------------------+
|                    1.0 |
+------------------------+
```

```sql
select cos(Pi());
```

```text
+-----------+
| cos(pi()) |
+-----------+
|        -1 |
+-----------+
```

```sql
select cos(cast('nan' as double));
```

```text
+----------------------------+
| cos(cast('nan' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select cos(cast('inf' as double));
```

```text
+----------------------------+
| cos(cast('inf' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select cos(cast('-inf' as double));
```

```text
+-----------------------------+
| cos(cast('-inf' AS DOUBLE)) |
+-----------------------------+
| NaN                         |
+-----------------------------+
```
