## 설명 {#description}

`x`의 부호를 반환합니다. 음수, 영, 양수는 각각 -1, 0, 1에 해당합니다.

## 구문 {#syntax}

```sql
SIGN(x)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|-----------|------------|
| `<x>`   | 독립 변수 |

## 반환값 {#return-value}

정수를 반환합니다:

- x > 0이면 양수를 나타내는 1을 반환합니다.

- x = 0이면 영을 나타내는 0을 반환합니다.

- x < 0이면 음수를 나타내는 -1을 반환합니다.

- x가 NULL이면 NULL을 반환합니다.

부동 소수점의 양의 영과 음의 영에 대해서는 모두 0을 반환한다는 점에 유의하세요. 부동 소수점 수의 양의 영과 음의 영을 구분하려면 `<signbit>` 함수를 사용할 수 있습니다.

## 예제 {#example}

```sql
select sign(3);
```

```text
+-------------------------+
| sign(cast(3 as DOUBLE)) |
+-------------------------+
|                       1 |
+-------------------------+
```

```sql
select sign(0);
```

```text
+-------------------------+
| sign(cast(0 as DOUBLE)) |
+-------------------------+
|                       0 |
+-------------------------+
```

```sql
select sign(-10.0);
```

```text
+-----------------------------+
| sign(cast(-10.0 as DOUBLE)) |
+-----------------------------+
|                          -1 |
+-----------------------------+
```

```sql
select sign(null);
```

```text
+------------+
| sign(NULL) |
+------------+
|       NULL |
+------------+
```

```sql
select sign(cast('+0.0' as double)) , sign(cast('-0.0' as double));
```

```text
+------------------------------+------------------------------+
| sign(cast('+0.0' as double)) | sign(cast('-0.0' as double)) |
+------------------------------+------------------------------+
|                            0 |                            0 |
+------------------------------+------------------------------+
```
