## 설명 {#description}

`x`의 역쌍곡 코사인 값을 반환하며, `NULL`은 `x`가 `1`보다 작을 때 반환됩니다.

## 구문 {#syntax}

```sql
ACOSH(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |  
| -- | -- |  
| `<x>` | 역쌍곡 코사인을 계산할 값 |  

## 반환 값 {#return-value}

매개변수 `x`의 역쌍곡 코사인 값입니다.

## 특수한 경우 {#special-cases}

- `x`가 1이면 0을 반환합니다.
- `x`가 1보다 작으면 `NULL`을 반환합니다.
- `x`가 NaN이면 NaN을 반환합니다.
- `x`가 양의 무한대이면 Infinity를 반환합니다.
- `x`가 음의 무한대이면 `NULL`을 반환합니다.
- `x`가 NULL이면 NULL을 반환합니다.

## 예제 {#examples}

```sql
select acosh(0.0);
```

```text
+------------+
| acosh(0.0) |
+------------+
|       NULL |
+------------+
```

```sql

```

```text

| acosh(-1.0) |
+-------------+
|        NULL |
+-------------+
```
