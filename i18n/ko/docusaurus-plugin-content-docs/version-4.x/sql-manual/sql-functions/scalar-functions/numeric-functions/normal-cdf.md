## 설명 {#description}

값 `x`에서 정규 분포의 누적 분포 함수(CDF)를 계산합니다.

- 반환값이 `NULL`이 되는 경우는 정규 분포의 표준편차가 `0` 이하일 때입니다.

## 구문 {#syntax}

```sql
NORMAL_CDF(<mean>, <sd>, <x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<mean>` | 정규 분포의 평균 |
| `<sd>` | 정규 분포의 표준편차 |
| `<x>` | 평가할 값 |

## 반환값 {#return-value}

값 `x`에서 정규 확률 변수의 누적 분포 함수(CDF) 값을 반환합니다.

- 반환값이 `NULL`이 되는 경우는 정규 분포의 표준편차가 `0` 이하일 때입니다.
- 입력값 중 하나라도 NULL이면 NULL을 반환합니다.

## 예제 {#examples}

```sql
select normal_cdf(10, 9, 10);
```

```text
+-----------------------------------------------------------------------+
| normal_cdf(cast(10 as DOUBLE), cast(9 as DOUBLE), cast(10 as DOUBLE)) |
+-----------------------------------------------------------------------+
|                                                                   0.5 |
+-----------------------------------------------------------------------+
```

```sql
select NORMAL_CDF(10, 0, 10);
```

```text
+-----------------------------------------------------------------------+
| normal_cdf(cast(10 as DOUBLE), cast(0 as DOUBLE), cast(10 as DOUBLE)) |
+-----------------------------------------------------------------------+
|                                                                  NULL |
+-----------------------------------------------------------------------+
```

```sql
select normal_cdf(10, 9, NULL);
```

```text
+-------------------------+
| normal_cdf(10, 9, NULL) |
+-------------------------+
|                    NULL |
+-------------------------+
```
