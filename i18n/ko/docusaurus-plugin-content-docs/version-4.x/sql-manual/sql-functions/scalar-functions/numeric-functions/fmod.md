## 설명 {#description}

부동 소수점 수의 나머지(a / b)를 계산합니다. 정수형에는 mod 함수를 사용하세요.

## 구문 {#syntax}

```sql
FMOD(<col_a> , <col_b>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<col_a>` | 피제수 |
| `<col_b>` | 제수(0일 수 없음) |

## 반환 값 {#return-value}

부동 소수점 수를 반환합니다. 특수한 경우의 동작은 다음과 같습니다.

- 입력 매개변수 중 하나라도 NULL이면 NULL을 반환합니다.

## 예제 {#examples}

```sql
select fmod(10.1, 3.2);
```

```text
+--------------------+
| fmod(10.1, 3.2)    |
+--------------------+
| 0.4999999999999991 |
+--------------------+
```

```sql
select fmod(10.1, 0);
```

```text
+---------------+
| fmod(10.1, 0) |
+---------------+
|          NULL |
+---------------+
```

```sql
select fmod(10.1, NULL);
```

```text
+------------------+
| fmod(10.1, NULL) |
+------------------+
|             NULL |
+------------------+
```
