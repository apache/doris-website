## 설명 {#description}

주어진 X 및 Y 좌표로 Point 지오메트리 객체를 생성합니다.
지리 공간에서 X/Y는 일반적으로 각각 경도와 위도를 나타냅니다.

## 구문 {#syntax}

```sql
ST_POINT( <x>, <y>)
```
## 매개변수 {#parameters}

| 매개변수  | 설명  |
|-----|-----|
| `<x>` | 점의 X 좌표(경도), 범위: -180.0 ~ 180.0(도) |
| `<y>` | 점의 Y 좌표(위도), 범위: -90.0 ~ 90.0(도) |

## 반환값 {#return-value}

2D 좌표를 나타내는 Point 지오메트리 객체를 반환합니다.

- <x> 또는 <y>가 유효한 경도/위도 범위를 벗어나면 NULL을 반환합니다.
- 매개변수 중 하나라도 NULL이면 NULL을 반환합니다.

## 예제 {#example}

유효한 좌표

```sql
SELECT ST_AsText(ST_Point(24.7, 56.7));
```

```text
+---------------------------------+
| st_astext(st_point(24.7, 56.7)) |
+---------------------------------+
| POINT (24.7 56.7)               |
+---------------------------------+
```

유효하지 않은 경도(범위 초과)

```sql
mysql> SELECT ST_Point(200, 50);
+-------------------+
| ST_Point(200, 50) |
+-------------------+
| NULL              |
+-------------------+
```

유효하지 않은 위도(범위 초과)

```sql
mysql> SELECT ST_Point(116, -100);
+---------------------+
| ST_Point(116, -100) |
+---------------------+
| NULL                |
+---------------------+
```

매개변수 중 하나가 NULL인 경우

```sql
mysql> SELECT ST_Point(NULL, 50);
+--------------------+
| ST_Point(NULL, 50) |
+--------------------+
| NULL               |
+--------------------+
```

```sql
mysql> SELECT ST_Point(50, NULL);
+--------------------+
| ST_Point(50, NULL) |
+--------------------+
| NULL               |
+--------------------+

```
