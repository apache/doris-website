## 설명 {#description}

기하 객체에 포함된 하위 기하 객체의 수를 반환합니다. 컬렉션이 아닌 유형(Point, LineString, Polygon, Circle)의 경우 항상 1을 반환합니다. 컬렉션 유형(MultiPolygon)의 경우 컬렉션에 포함된 하위 기하 객체의 수를 반환합니다.

:::note
4.1.2부터 지원됩니다.
:::

## 구문 {#syntax}

```sql
ST_NUMGEOMETRIES( <shape> )
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| :--- | :--- |
| `<shape>` | 입력 기하 객체입니다. GEOMETRY 유형이거나 GEOMETRY로 변환할 수 있는 VARCHAR 유형(WKT 형식)이어야 합니다. |

## 반환 값 {#return-value}

기하 객체에 포함된 하위 기하 객체의 수를 나타내는 BIGINT 값을 반환합니다.

`ST_NUMGEOMETRIES`는 다음과 같은 특수한 경우를 처리합니다.
- 입력 매개변수가 `NULL`이면 `NULL`을 반환합니다.
- 입력 매개변수를 유효한 기하 객체로 파싱할 수 없으면 `NULL`을 반환합니다.
- 컬렉션이 아닌 유형(`POINT`, `LINESTRING`, `POLYGON`, `CIRCLE`)의 경우 항상 `1`을 반환합니다.
- `MULTIPOLYGON`의 경우 컬렉션에 포함된 다각형의 수를 반환합니다.

## 예제 {#example}

**Point에 포함된 기하 객체의 수**
```sql
SELECT ST_NUMGEOMETRIES(ST_Point(1, 2));
```
```text
+----------------------------------+
| ST_NUMGEOMETRIES(ST_Point(1, 2)) |
+----------------------------------+
|                                1 |
+----------------------------------+
```

**Polygon에 포함된 기하 객체의 수**
```sql
SELECT ST_NUMGEOMETRIES(ST_GeometryFromText('POLYGON((0 0, 1 0, 1 1, 0 1, 0 0))'));
```
```text
+------------------------------------------------------------------------------+
| ST_NUMGEOMETRIES(ST_GeometryFromText('POLYGON((0 0, 1 0, 1 1, 0 1, 0 0))')) |
+------------------------------------------------------------------------------+
|                                                                            1 |
+------------------------------------------------------------------------------+
```

**다각형 두 개로 구성된 MultiPolygon에 포함된 기하 객체의 수**
```sql
SELECT ST_NUMGEOMETRIES(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))'));
```
```text
+------------------------------------------------------------------------------------------------------------------+
| ST_NUMGEOMETRIES(ST_GeometryFromText('MULTIPOLYGON(((0 0, 1 0, 1 1, 0 1, 0 0)),((2 2, 3 2, 3 3, 2 3, 2 2)))')) |
+------------------------------------------------------------------------------------------------------------------+
|                                                                                                                2 |
+------------------------------------------------------------------------------------------------------------------+
```

**Circle에 포함된 기하 객체의 수**
```sql
SELECT ST_NUMGEOMETRIES(ST_Circle(0, 0, 100));
```
```text
+----------------------------------------+
| ST_NUMGEOMETRIES(ST_Circle(0, 0, 100)) |
+----------------------------------------+
|                                      1 |
+----------------------------------------+
```

**NULL 매개변수**
```sql
SELECT ST_NUMGEOMETRIES(NULL);
```
```text
+------------------------+
| ST_NUMGEOMETRIES(NULL) |
+------------------------+
|                   NULL |
+------------------------+
```

**유효하지 않은 매개변수(NULL 반환)**
```sql
SELECT ST_NUMGEOMETRIES(ST_GeometryFromText('INVALID'));
```
```text
+--------------------------------------------------+
| ST_NUMGEOMETRIES(ST_GeometryFromText('INVALID')) |
+--------------------------------------------------+
|                                             NULL |
+--------------------------------------------------+
```
