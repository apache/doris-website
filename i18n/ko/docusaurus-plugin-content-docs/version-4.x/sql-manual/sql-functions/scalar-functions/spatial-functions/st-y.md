## 설명 {#description}

유효한 POINT 지오메트리의 Y 좌표를 반환합니다. 지리 공간에서 Y 좌표는 일반적으로 위도에 해당하며, 범위는 [-90.0, 90.0]입니다(단위: 도).

## 구문 {#syntax}

```sql
ST_Y( <point>)
```

## 매개변수 {#parameters}

| 매개변수   | 설명      |
|------|----------|
| `<point>` | Y 좌표를 추출할 유효한 2D POINT 지오메트리입니다. Y 값(위도)은 [-90.0, 90.0] 범위에 있어야 하며, X 값(경도)은 [-180.0, 180.0] 범위에 있어야 합니다. |

## 반환 값 {#return-value}

입력 POINT의 Y 좌표를 DOUBLE PRECISION FLOAT로 반환합니다.

유효한 POINT 입력에 대해 Y 좌표(위도)를 반환합니다.
NULL 입력, 빈 포인트(POINT EMPTY), 3D 포인트 또는 유효하지 않은 포인트(예: 위도가 [-90.0, 90.0] 범위를 벗어나는 경우)에 대해서는 NULL을 반환합니다.

## 예제 {#examples}

유효한 포인트

```sql
SELECT ST_Y(ST_Point(24.7, 56.7));
```

```text
+----------------------------+
| ST_Y(ST_Point(24.7, 56.7)) |
+----------------------------+
| 56.7                       |
+----------------------------+
```

빈 포인트(POINT EMPTY)

```sql
mysql> SELECT ST_Y(ST_GeometryFromText("POINT EMPTY"));
+------------------------------------------+
| ST_Y(ST_GeometryFromText("POINT EMPTY")) |
+------------------------------------------+
|                                     NULL |
+------------------------------------------+
```
3D 포인트(지원되지 않음)

```sql
mysql> SELECT ST_Y(ST_GeometryFromText("POINT (10 20 30)"));
+-----------------------------------------------+
| ST_Y(ST_GeometryFromText("POINT (10 20 30)")) |
+-----------------------------------------------+
|                                          NULL |
+-----------------------------------------------+
```


NULL 입력

```sql
mysql> SELECT ST_Y(NULL);
+------------+
| ST_Y(NULL) |
+------------+
|       NULL |
+------------+
```

유효하지 않은 위도(범위 초과)

```sql
mysql> SELECT ST_Y(ST_Point(116.4, 91));
+---------------------------+
| ST_Y(ST_Point(116.4, 91)) |
+---------------------------+
|                      NULL |
+---------------------------+
```

유효하지 않은 경도(범위 초과)

```sql
mysql> SELECT ST_Y(ST_Point(190, 39.9));
+---------------------------+
| ST_Y(ST_Point(190, 39.9)) |
+---------------------------+
|                      NULL |
+---------------------------+
```
