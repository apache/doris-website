## 설명 {#description}

WKT(Well Known Text)를 이에 대응하는 메모리 내 지오메트리로 변환합니다


## 별칭 {#alias}

- ST_GEOMFROMTEXT

## 구문 {#syntax}

```sql
ST_GEOMETRYFROMTEXT( <wkt>)
```
## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- |---------|
| `<wkt>` | 도형의 메모리 표현 |

## 지원하는 WKT 형식 {#support-wkt-formats}

- `POINT` - 공간상의 단일 점
- `LINESTRING` - 서로 연결된 선분의 연속
- `POLYGON` - 하나 이상의 링으로 정의된 닫힌 영역으로, 서로 다른 점이 최소 세 개 있어야 하며 시작점과 끝점이 일치해야 합니다.
- `MULTIPOLYGON` - 다각형의 집합으로, 구성 다각형끼리는 개별 점만 공유할 수 있습니다.

:::info 참고
Apache Doris 3.0.6부터 MULTIPOLYGON 형식의 파싱을 지원합니다
:::

## 반환 값 {#return-value}

WKB에 대응하는 지오메트리 저장 형식

입력 WKT 형식이 규격에 맞지 않거나 입력이 NULL이면 NULL을 반환합니다.

## 예제 {#examples}

```sql
-- POINT example
SELECT ST_AsText(ST_GeometryFromText("POINT (1 1)"));
```

```text
+-----------------------------------------------+
| ST_AsText(ST_GeometryFromText("POINT (1 1)")) |
+-----------------------------------------------+
| POINT (1 1)                                   |
+-----------------------------------------------+
```

```sql
-- POINT illegal example(too many points)
SELECT ST_AsText(ST_GeometryFromText("POINT (1 1, 2 2)"));
```

```text
+----------------------------------------------------+
| ST_AsText(ST_GeometryFromText("POINT (1 1, 2 2)")) |
+----------------------------------------------------+
| NULL                                               |
+----------------------------------------------------+
```

```sql
-- LINESTRING example
```

```text
+---------------------------------------------------------+
| st_astext(st_geometryfromtext('LINESTRING (1 1, 2 2)')) |

| LINESTRING (1 1, 2 2)                                   |
```

```sql

```

```text
+----------------------------------------------------+

+----------------------------------------------------+
| NULL                                               |
+----------------------------------------------------+
```
