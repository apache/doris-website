## 설명 {#description}

입력 타입에 관계없이 64비트 해시 값을 계산하고 해당 해시 값이 포함된 Bitmap을 반환합니다.

## 구문 {#syntax}

```sql
BITMAP_HASH64(<expr>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명           |
|-----------|-----------------------|
| `<expr>`  | 임의의 값 또는 필드 표현식 |

## 반환 값 {#return-value}

매개변수 `<expr>`의 64비트 해시 값이 포함된 Bitmap을 반환합니다.
- 매개변수 값이 NULL이면 Empty Bitmap을 반환합니다.

## 예제 {#examples}

값의 64비트 해시를 계산하려면 다음과 같이 사용할 수 있습니다.

```sql
select bitmap_to_string(bitmap_hash64('hello'));
```

결과는 다음과 같습니다.

```text
+------------------------------------------+
| bitmap_to_string(bitmap_hash64('hello')) |
+------------------------------------------+
| 15231136565543391023                     |
+------------------------------------------+
```

```sql
select bitmap_to_string(bitmap_hash64(NULL));
```

결과는 다음과 같습니다.

```text
+---------------------------------------+
| bitmap_to_string(bitmap_hash64(NULL)) |
+---------------------------------------+
|                                       |
+---------------------------------------+
```
