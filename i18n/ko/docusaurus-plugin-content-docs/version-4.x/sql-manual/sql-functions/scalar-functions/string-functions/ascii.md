## 설명 {#description}

문자열 첫 번째 문자의 ASCII 코드 값을 반환합니다. 이 함수는 문자열의 첫 번째 문자만 처리하므로, 여러 문자로 구성된 문자열에서도 첫 번째 문자의 ASCII 값만 반환합니다.

## 구문 {#syntax}

```sql
ASCII(<str>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명                      |
|---------|-----------------------------|
| `<str>` | 첫 번째 문자의 ASCII 코드 값을 구할 문자열입니다. 타입: VARCHAR |

## 반환 값 {#return-value}

문자열 첫 번째 문자의 ASCII 코드 값을 나타내는 INT 타입의 값을 반환합니다.

특수한 경우:
- 매개변수가 NULL이면 NULL을 반환합니다
- 문자열이 비어 있으면 0을 반환합니다
- 첫 번째 문자가 ASCII 문자가 아니면(코드 값이 127보다 크면) 해당 바이트 값을 반환합니다
- 멀티바이트 UTF-8 문자의 경우 첫 번째 바이트 값을 반환합니다

## 예제 {#examples}

1. 기본 숫자 문자
```sql
SELECT ASCII('1'), ASCII('234');
```
```text
+------------+--------------+
| ASCII('1') | ASCII('234') |
+------------+--------------+
|         49 |           50 |
+------------+--------------+
```

2. 알파벳 문자
```sql
SELECT ASCII('A'), ASCII('a'), ASCII('Z');
```
```text
+------------+------------+------------+
| ASCII('A') | ASCII('a') | ASCII('Z') |
+------------+------------+------------+
|         65 |         97 |         90 |
+------------+------------+------------+
```

3. 빈 문자열 처리
```sql
SELECT ASCII('');
```
```text
+-----------+
| ASCII('') |
+-----------+
|         0 |
+-----------+
```

4. NULL 값 처리
```sql
SELECT ASCII(NULL);
```
```text
+-------------+
| ASCII(NULL) |
+-------------+
|        NULL |
+-------------+
```

5. 특수 기호
```sql
SELECT ASCII(' '), ASCII('!'), ASCII('@');
```
```text
+------------+------------+------------+
| ASCII(' ') | ASCII('!') | ASCII('@') |
+------------+------------+------------+
|         32 |         33 |         64 |
+------------+------------+------------+
```

6. 제어 문자
```sql
SELECT ASCII('\t'), ASCII('\n'), ASCII('\r');
```
```text
+-------------+-------------+-------------+
| ASCII('\t') | ASCII('\n') | ASCII('\r') |
+-------------+-------------+-------------+
|           9 |          10 |          13 |
+-------------+-------------+-------------+
```

7. 여러 문자로 구성된 문자열(첫 번째 문자만 반환)
```sql
SELECT ASCII('Hello'), ASCII('World123');
```
```text
+----------------+------------------+
| ASCII('Hello') | ASCII('World123') |
+----------------+------------------+
|             72 |               87 |
+----------------+------------------+
```

8. UTF-8 멀티바이트 문자
```sql
SELECT ASCII('ṭṛì'), ASCII('ḍḍumai');
```
```text
+---------------+------------------+
| ASCII('ṭṛì')  | ASCII('ḍḍumai') |
+---------------+------------------+
|           225 |              225 |
+---------------+------------------+
```

9. 숫자와 문자가 섞인 문자열
```sql
SELECT ASCII('9abc'), ASCII('0xyz');
```
```text
+---------------+---------------+
| ASCII('9abc') | ASCII('0xyz') |
+---------------+---------------+
|            57 |            48 |
+---------------+---------------+
```
