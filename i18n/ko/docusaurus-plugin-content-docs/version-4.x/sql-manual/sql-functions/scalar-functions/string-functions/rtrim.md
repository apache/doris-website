## 설명 {#description}

RTRIM 함수는 문자열의 오른쪽 끝에 연속으로 있는 공백이나 지정된 문자열을 제거하는 데 사용됩니다. 두 번째 매개변수를 지정하지 않으면 문자열 끝의 공백을 제거하고, 지정하면 오른쪽 끝에서 지정된 문자열 전체를 제거합니다.

## 문법 {#syntax}

```sql
RTRIM(<str>[, <rhs>])
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| --------- | ----------- |
| `<str>` | 처리할 문자열입니다. 타입: VARCHAR |
| `<rhs>` | 선택적 매개변수로, 문자열 끝에서 제거할 문자를 지정합니다. 타입: VARCHAR |

## 반환 값 {#return-value}

VARCHAR 타입의 값을 반환합니다.

특수한 경우:
- 매개변수 중 하나라도 NULL이면 NULL을 반환합니다
- rhs를 지정하지 않으면 문자열 끝의 공백을 제거합니다
- rhs를 지정하면 rhs 문자열 전체를 제거합니다(문자 단위로 제거하지 않음)

## 예제 {#examples}

1. 문자열 끝의 공백 제거
```sql
SELECT rtrim('ab d   ') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. 문자열 끝에서 지정된 문자열 제거
```sql
SELECT rtrim('ababccaab', 'ab') str;
```
```text
+---------+
| str     |
+---------+
| ababcca |
+---------+
```

3. 기본적으로 ASCII 공백만 제거합니다. `RTRIM`은 두 번째 인수 없이는 탭(`\t`)이나 줄 바꿈(`\n`)을 **제거하지 않습니다**. 제거 전후의 `LENGTH`를 비교하면 맨 끝의 ASCII 공백 하나만 제거되고 `\t\n`은 그대로 남습니다.
```sql
SELECT LENGTH('hello world  \t\n '), LENGTH(RTRIM('hello world  \t\n '));
```
```text
+------------------------------+-------------------------------------+
| LENGTH('hello world  \t\n ') | LENGTH(RTRIM('hello world  \t\n ')) |
+------------------------------+-------------------------------------+
|                           16 |                                  15 |
+------------------------------+-------------------------------------+
```

4. UTF-8 문자 지원
```sql
SELECT rtrim('ṭṛì ḍḍumai   ');
```
```text
+---------------------------+
| rtrim('ṭṛì ḍḍumai   ')    |
+---------------------------+
| ṭṛì ḍḍumai                |
+---------------------------+
```

5. 일치하는 접미사가 없으면 원래 문자열 반환
```sql
SELECT rtrim('Hello World', 'xyz');
```
```text
+---------------------------------+
| rtrim('Hello World', 'xyz')     |
+---------------------------------+
| Hello World                     |
+---------------------------------+
```

6. NULL 값 처리
```sql
SELECT rtrim(NULL), rtrim('Hello', NULL);
```
```text
+-------------+------------------------+
| rtrim(NULL) | rtrim('Hello', NULL)   |
+-------------+------------------------+
| NULL        | NULL                   |
+-------------+------------------------+
```

7. 빈 문자열 처리
```sql
SELECT rtrim(''), rtrim('abc', '');
```
```text
+-----------+-------------------+
| rtrim('') | rtrim('abc', '')  |
+-----------+-------------------+
|           | abc               |
+-----------+-------------------+
```

8. 문자열 끝에서 반복되는 패턴 제거
```sql
SELECT rtrim('abcabcabc', 'abc');
```
```text
+-------------------------------+
| rtrim('abcabcabc', 'abc')     |
+-------------------------------+
|                               |
+-------------------------------+
```

9. 같은 문자열이 여러 번 나타나는 경우, 끝에서 일치하는 부분만 제거
```sql
SELECT rtrim('HelloHelloWorld', 'Hello');
```
```text
+---------------------------------------+
| rtrim('HelloHelloWorld', 'Hello')     |
+---------------------------------------+
| HelloHelloWorld                       |
+---------------------------------------+
```
