## 설명 {#description}

지정한 개수의 공백으로 구성된 문자열을 생성합니다.

## 구문 {#syntax}

```sql
SPACE ( <len> )
```

## 매개변수 {#parameters}

| 매개변수 | 설명                      |
|-----------|----------------------------------|
| `<len>`   | 생성할 공백의 개수 |

## 반환값 {#return-value}

지정한 개수의 공백으로 구성된 문자열을 반환합니다. 특수한 경우는 다음과 같습니다.

- 매개변수 중 하나라도 NULL이면 NULL을 반환합니다.
- `<len>`이 0보다 작으면 빈 문자열을 반환합니다.

## 예제 {#examples}

1. 지정한 개수의 공백 생성
```sql
SELECT space(5);
```
```text
+----------+
| space(5) |
+----------+
|          |
+----------+
```

2. 영 또는 음수 처리
```sql
SELECT space(0), space(-5);
```
```text
+----------+-----------+
| space(0) | space(-5) |
+----------+-----------+
|          |           |
+----------+-----------+
```

3. NULL 값 처리
```sql
SELECT space(NULL);
```
```text
+-------------+
| space(NULL) |
+-------------+
| NULL        |
+-------------+
```

4. 다른 함수와 함께 사용
```sql
SELECT CONCAT('Hello', space(3), 'World');
```
```text
+------------------------------------+
| concat('Hello', space(3), 'World') |
+------------------------------------+
| Hello   World                      |
+------------------------------------+
```
