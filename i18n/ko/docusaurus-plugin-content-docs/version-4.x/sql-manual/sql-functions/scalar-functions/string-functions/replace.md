## 설명 {#description}

REPLACE 함수는 문자열에서 지정된 부분 문자열이 나타나는 모든 위치를 새 부분 문자열로 치환하는 데 사용됩니다. 이 함수는 문자열에서 일치하는 부분 문자열을 모두 치환하여 전체 치환 작업을 수행합니다.

**REPLACE_EMPTY 함수와의 차이점:**
- `REPLACE()`는 빈 문자열을 포함하여 지정된 부분 문자열을 치환합니다.
- `REPLACE_EMPTY()`는 빈 값이나 빈 문자열을 지정된 값으로 치환하는 데 특화된 함수입니다.

## 구문 {#syntax}

```sql
REPLACE(<str>, <old>, <new>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|-----------|-------------|
| `<str>` | 치환할 원본 문자열입니다. 타입: VARCHAR |
| `<old>` | 치환 대상 부분 문자열입니다. str에서 찾을 수 없으면 치환하지 않습니다. 타입: VARCHAR |
| `<new>` | old를 치환할 새 부분 문자열입니다. 타입: VARCHAR |

## 반환값 {#return-value}

치환 후의 새 문자열을 나타내는 VARCHAR 타입의 값을 반환합니다.

치환 규칙:
- 문자열에서 old와 일치하는 모든 부분 문자열을 치환합니다.
- 치환 시 대소문자를 구분합니다.
- old가 빈 문자열이면 원본 문자열을 반환합니다(작업을 수행하지 않음).
- new가 빈 문자열이면 old와 일치하는 모든 부분 문자열을 삭제합니다.

특수한 경우:
- 매개변수 중 하나라도 NULL이면 NULL을 반환합니다.
- str이 빈 문자열이면 빈 문자열을 반환합니다.
- old가 빈 문자열이면 원본 str을 반환합니다(치환하지 않음).
- str에서 old를 찾을 수 없으면 원본 str을 반환합니다.

## 예제 {#examples}

1. 기본 치환 작업
```sql
SELECT REPLACE('hello world', 'world', 'universe');
```
```text
+---------------------------------------------+
| REPLACE('hello world', 'world', 'universe') |
+---------------------------------------------+
| hello universe                              |
+---------------------------------------------+
```

2. 일치하는 여러 항목 치환
```sql
SELECT REPLACE('apple apple apple', 'apple', 'orange');
```
```text
+------------------------------------------------+
| REPLACE('apple apple apple', 'apple', 'orange') |
+------------------------------------------------+
| orange orange orange                           |
+------------------------------------------------+
```

3. 부분 문자열 삭제(빈 문자열로 치환)
```sql
SELECT REPLACE('banana', 'a', '');
```
```text
+---------------------------+
| REPLACE('banana', 'a', '') |
+---------------------------+
| bnn                       |
+---------------------------+
```

4. NULL 값 처리
```sql
SELECT REPLACE(NULL, 'old', 'new'), REPLACE('test', NULL, 'new'), REPLACE('test', 'old', NULL);
```
```text
+------------------------------+------------------------------+------------------------------+
| REPLACE(NULL, 'old', 'new')  | REPLACE('test', NULL, 'new') | REPLACE('test', 'old', NULL) |
+------------------------------+------------------------------+------------------------------+
| NULL                         | NULL                         | NULL                         |
+------------------------------+------------------------------+------------------------------+
```

5. UTF-8 문자 치환
```sql
SELECT REPLACE('ṭṛì ḍḍumai test ṭṛì ḍḍumannàri', 'ṭṛì', 'replaced');
```
```text
+-----------------------------------------------------------+
| REPLACE('ṭṛì ḍḍumai test ṭṛì ḍḍumannàri', 'ṭṛì', 'replaced') |
+-----------------------------------------------------------+
| replaced ḍḍumai test replaced ḍḍumannàri                  |
+-----------------------------------------------------------+
```

6. 빈 문자열 경계 사례: `str`이 비어 있으면 빈 문자열을 반환하고, `old`가 비어 있으면 `str`을 그대로 반환하며, `new`가 비어 있으면 일치하는 모든 항목을 삭제합니다.
```sql
SELECT REPLACE('', 'old', 'new'), REPLACE('test', '', 'new'), REPLACE('test', 'old', '');
```
```text
+---------------------------+----------------------------+----------------------------+
| REPLACE('', 'old', 'new') | REPLACE('test', '', 'new') | REPLACE('test', 'old', '') |
+---------------------------+----------------------------+----------------------------+
|                           | test                       | test                       |
+---------------------------+----------------------------+----------------------------+
```

7. 대소문자를 구분하는 치환(소문자 `hello`만 일치)
```sql
SELECT REPLACE('Hello HELLO hello', 'hello', 'hi');
```
```text
+---------------------------------------------+
| REPLACE('Hello HELLO hello', 'hello', 'hi') |
+---------------------------------------------+
| Hello HELLO hi                              |
+---------------------------------------------+
```

8. `old`가 없는 경우: `str`을 그대로 반환
```sql
SELECT REPLACE('hello world', 'xyz', 'abc');
```
```text
+--------------------------------------+
| REPLACE('hello world', 'xyz', 'abc') |
+--------------------------------------+
| hello world                          |
+--------------------------------------+
```

9. 겹치지 않고 반복되는 일치 항목 치환
```sql
SELECT REPLACE('123123123', '123', 'ABC');
```
```text
+------------------------------------+
| REPLACE('123123123', '123', 'ABC') |
+------------------------------------+
| ABCABCABC                          |
+------------------------------------+
```
