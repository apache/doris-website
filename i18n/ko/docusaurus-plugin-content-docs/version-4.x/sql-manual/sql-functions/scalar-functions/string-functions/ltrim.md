## 설명 {#description}

LTRIM 함수는 문자열의 왼쪽(시작 부분)에서 연속으로 나타나는 공백이나 지정된 문자 집합에 속하는 문자를 제거합니다. 이 함수는 문자열의 왼쪽 끝부터 검사하며, 대상 문자 집합에 속하지 않는 문자를 만날 때까지 연속으로 나타나는 대상 문자를 모두 제거합니다.

## 구문 {#syntax}

```sql
LTRIM(<str> [, <trim_chars>])
```

## 매개변수 {#parameters}

| 매개변수      | 설명                                                                                                                                                                                                                                                                           |
|----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<str>`        | 왼쪽에서 문자를 제거할 원본 문자열입니다. 타입: VARCHAR                                                                                                                                                                                                                                  |
| `<trim_chars>` | 제거할 문자 집합을 지정하는 선택적 매개변수입니다. 지정하지 않으면 기본적으로 공백 문자를 제거합니다. 타입: VARCHAR |

## 반환값 {#return-value}

왼쪽에서 지정된 문자를 제거한 문자열을 VARCHAR 타입으로 반환합니다.

문자 제거 규칙:
- 문자열의 왼쪽(시작 부분)에서만 문자를 제거합니다.
- trim_chars에 포함된 문자가 연속으로 나타나면 모두 제거합니다.
- trim_chars에 포함되지 않은 문자를 만나면 제거를 중단합니다.
- trim_chars를 지정하지 않으면 기본적으로 공백 문자(공백, 탭, 줄 바꿈 등)를 제거합니다.

특수한 경우:
- 매개변수 중 하나라도 NULL이면 NULL을 반환합니다.
- str이 빈 문자열이면 빈 문자열을 반환합니다.
- trim_chars가 빈 문자열이면 원본 문자열을 반환합니다.
- 문자열 전체가 trim_chars에 포함된 문자로 구성되어 있으면 빈 문자열을 반환합니다.

## 예제 {#examples}

1. 왼쪽 공백 제거
```sql
SELECT LTRIM('   ab d');
```
```text
+-------------------+
| LTRIM('   ab d')  |
+-------------------+
| ab d              |
+-------------------+
```

2. 지정된 문자 제거
```sql
SELECT LTRIM('ababccaab', 'ab');
```
```text
+----------------------------+
| LTRIM('ababccaab', 'ab')   |
+----------------------------+
| ccaab                      |
+----------------------------+
```

3. NULL 값 처리
```sql
SELECT LTRIM(NULL), LTRIM('test', NULL);
```
```text
+-------------+---------------------+
| LTRIM(NULL) | LTRIM('test', NULL) |
+-------------+---------------------+
| NULL        | NULL                |
+-------------+---------------------+
```

4. 빈 입력값
```sql
SELECT LTRIM(''), LTRIM('test', '');
```
```text
+-----------+-------------------+
| LTRIM('') | LTRIM('test', '') |
+-----------+-------------------+
|           | test              |
+-----------+-------------------+
```

5. 여러 문자로 된 접두사 제거
```sql
SELECT LTRIM('abcdefg', 'abc'), LTRIM('123456', '12');
```
```text
+-------------------------+-----------------------+
| LTRIM('abcdefg', 'abc') | LTRIM('123456', '12') |
+-------------------------+-----------------------+
| defg                    | 3456                  |
+-------------------------+-----------------------+
```

6. 문자열 전체가 제거할 문자와 일치하는 경우
```sql
SELECT LTRIM('aaaaa', 'a'), LTRIM('   ', ' ');
```
```text
+---------------------+-------------------+
| LTRIM('aaaaa', 'a') | LTRIM('   ', ' ') |
+---------------------+-------------------+
|                     |                   |
+---------------------+-------------------+
```

7. UTF-8 부분 문자열 제거(두 번째 인수는 문자 집합이 아니라 리터럴 부분 문자열로 일치 여부를 확인합니다)
```sql
SELECT LTRIM('ṭṛìṭṛì test', 'ṭṛì'), LTRIM('ḍḍuḍḍu hello', 'ḍu');
```
```text
+--------------------------------------------+---------------------------------------+
| LTRIM('ṭṛìṭṛì test', 'ṭṛì')                | LTRIM('ḍḍuḍḍu hello', 'ḍu')           |
+--------------------------------------------+---------------------------------------+
|  test                                      | ḍḍuḍḍu hello                          |
+--------------------------------------------+---------------------------------------+
```

8. 숫자 접두사 제거
```sql
SELECT LTRIM('000123', '0'), LTRIM('123abc123', '123');
```
```text
+----------------------+---------------------------+
| LTRIM('000123', '0') | LTRIM('123abc123', '123') |
+----------------------+---------------------------+
| 123                  | abc123                    |
+----------------------+---------------------------+
```

9. 문장 부호 접두사 제거
```sql
SELECT LTRIM('---text---', '-'), LTRIM('@@hello@@', '@');
```
```text
+--------------------------+-------------------------+
| LTRIM('---text---', '-') | LTRIM('@@hello@@', '@') |
+--------------------------+-------------------------+
| text---                  | hello@@                 |
+--------------------------+-------------------------+
```
