## 설명 {#description}

MASK 함수는 민감한 정보를 보호하기 위해 데이터를 마스킹하는 데 사용됩니다. 기본적으로 대문자는 `X`로, 소문자는 `x`로, 숫자는 `n`으로 변환합니다.

## 구문 {#syntax}

```sql
MASK(<str>[, <upper>[, <lower>[, <number>]]])
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| ---------- | ----------------------------------------- |
| `<str>` | 마스킹할 문자열. 타입: VARCHAR |
| `<upper>` | 대문자를 대체할 문자. 기본값은 `X`입니다(선택 사항). 타입: VARCHAR |
| `<lower>` | 소문자를 대체할 문자. 기본값은 `x`입니다(선택 사항). 타입: VARCHAR |
| `<number>` | 숫자를 대체할 문자. 기본값은 `n`입니다(선택 사항). 타입: VARCHAR |

## 반환 값 {#return-value}

문자와 숫자를 대체한 문자열을 VARCHAR 타입으로 반환합니다.

특수한 경우:
- 매개변수 중 하나라도 NULL이면 NULL을 반환합니다
- 영문자나 숫자가 아닌 문자는 변경되지 않습니다
- 대체 문자 매개변수에 여러 문자가 포함되어 있으면 첫 번째 문자만 사용합니다

## 예제 {#examples}

1. 기본 사용법: 기본 대체 규칙
```sql
SELECT mask('abc123XYZ');
```
```text
+-------------------+
| mask('abc123XYZ') |
+-------------------+
| xxxnnnXXX         |
+-------------------+
```

2. 사용자 지정 대체 문자
```sql
SELECT mask('abc123XYZ', '*', '#', '$');
```
```text
+----------------------------------+
| mask('abc123XYZ', '*', '#', '$') |
+----------------------------------+
| ###$$$***                        |
+----------------------------------+
```

3. 특수 문자는 변경되지 않음
```sql
SELECT mask('Hello-123!');
```
```text
+--------------------+
| mask('Hello-123!') |
+--------------------+
| Xxxxx-nnn!         |
+--------------------+
```

4. NULL 값 처리
```sql
SELECT mask(NULL);
```
```text
+------------+
| mask(NULL) |
+------------+
| NULL       |
+------------+
```

5. 숫자로만 구성된 문자열
```sql
SELECT mask('1234567890');
```
```text
+--------------------+
| mask('1234567890') |
+--------------------+
| nnnnnnnnnn         |
+--------------------+
```

6. 문자로만 구성된 문자열
```sql
SELECT mask('AbCdEfGh');
```
```text
+------------------+
| mask('AbCdEfGh') |
+------------------+
| XxXxXxXx         |
+------------------+
```

7. 빈 문자열 처리
```sql
SELECT mask('');
```
```text
+----------+
| mask('') |
+----------+
|          |
+----------+
```

8. 단일 문자로 대체(여러 문자 중 첫 번째 문자 사용)
```sql
SELECT mask('Test123', 'ABC', 'xyz', '999');
```
```text
+--------------------------------------+
| mask('Test123', 'ABC', 'xyz', '999') |
+--------------------------------------+
| Axxx999                              |
+--------------------------------------+
```

9. 신용카드 번호 마스킹
```sql
SELECT mask('1234-5678-9012-3456');
```
```text
+-----------------------------+
| mask('1234-5678-9012-3456') |
+-----------------------------+
| nnnn-nnnn-nnnn-nnnn         |
+-----------------------------+
```

10. 이메일 주소 마스킹
```sql
SELECT mask('user@example.com');
```
```text
+--------------------------+
| mask('user@example.com') |
+--------------------------+
| xxxx@xxxxxxx.xxx         |
+--------------------------+
```

```sql
SELECT mask('eeeéèêëìí1234');
```
```text
+-----------------------------+
| mask('eeeéèêëìí1234')       |
+-----------------------------+
| xxxéèêëìínnnn               |
+-----------------------------+
```
