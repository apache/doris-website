## 설명 {#description}

LCASE 함수(별칭 LOWER)는 문자열의 모든 대문자를 소문자로 변환합니다.

## 구문 {#syntax}

```sql
LCASE(<str>)
LOWER(<str>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|---------|--------------|
| `<str>` | 소문자로 변환할 문자열입니다. 타입: VARCHAR |

## 반환값 {#return-value}

소문자로 변환된 문자열을 VARCHAR 타입으로 반환합니다.

변환 규칙:
- 문자열의 모든 대문자를 해당 소문자로 변환합니다.
- 문자가 아닌 문자(숫자, 기호, 공백 등)는 그대로 유지됩니다.
- 이미 소문자인 문자는 그대로 유지됩니다.

특수한 경우:
- 매개변수가 NULL이면 NULL을 반환합니다.
- 문자열이 비어 있으면 빈 문자열을 반환합니다.
- 문자열에 대문자가 없으면 원래 문자열을 반환합니다.

## 예제 {#examples}

1. 기본적인 영문자 변환
```sql
SELECT LOWER('AbC123'), LCASE('AbC123');
```
```text
+-----------------+-----------------+
| LOWER('AbC123') | LCASE('AbC123') |
+-----------------+-----------------+
| abc123          | abc123          |
+-----------------+-----------------+
```

2. 여러 종류의 문자가 섞인 문자열 처리
```sql
SELECT LOWER('Hello World!'), LCASE('TEST@123');
```
```text
+----------------------+------------------+
| LOWER('Hello World!') | LCASE('TEST@123') |
+----------------------+------------------+
| hello world!         | test@123         |
+----------------------+------------------+
```

3. NULL 값 처리
```sql
SELECT LOWER(NULL), LCASE(NULL);
```
```text
+-------------+-------------+
| LOWER(NULL) | LCASE(NULL) |
+-------------+-------------+
| NULL        | NULL        |
+-------------+-------------+
```

4. 빈 문자열
```sql
SELECT LOWER(''), LCASE('');
```
```text
+-----------+-----------+
| LOWER('') | LCASE('') |
+-----------+-----------+
|           |           |
+-----------+-----------+
```

5. 이미 소문자이거나 숫자로만 이루어진 문자열
```sql
SELECT LOWER('already lowercase'), LCASE('abc123');
```
```text
+----------------------------+-----------------+
| LOWER('already lowercase') | LCASE('abc123') |
+----------------------------+-----------------+
| already lowercase          | abc123          |
+----------------------------+-----------------+
```

6. 알파벳이 아닌 문자는 변경 없이 그대로 반환
```sql
SELECT LOWER('123!@#$%'), LCASE('PRICE: $99.99');
```
```text
+-------------------+------------------------+
| LOWER('123!@#$%') | LCASE('PRICE: $99.99') |
+-------------------+------------------------+
| 123!@#$%          | price: $99.99          |
+-------------------+------------------------+
```

7. UTF-8 멀티바이트 case folding
```sql
SELECT LOWER('ṬṚÌ TEST'), LCASE('ḌḌUMAI HELLO');
```
```text
+------------------------+---------------------------+
| LOWER('ṬṚÌ TEST')      | LCASE('ḌḌUMAI HELLO')     |
+------------------------+---------------------------+
| ṭṛì test               | ḍḍumai hello              |
+------------------------+---------------------------+
```
