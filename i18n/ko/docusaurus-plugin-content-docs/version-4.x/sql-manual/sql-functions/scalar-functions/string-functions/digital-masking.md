## 설명 {#description}

DIGITAL_MASKING 함수는 숫자 문자열의 중간 부분을 고정된 형식의 `****`로 대체하여 마스킹하며, 처음 3자리와 마지막 4자리는 유지합니다. `CONCAT(LEFT(id, 3), '****', RIGHT(id, 4))`와 동일합니다.

## 구문 {#syntax}

```sql
DIGITAL_MASKING(<digital_number>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| ------------------ | ----------------------------------------- |
| `<digital_number>` | 마스킹할 숫자 문자열입니다. 유형: VARCHAR |

## 반환값 {#return-value}

마스킹된 숫자 문자열을 나타내는 VARCHAR 유형의 값을 반환합니다.

특수한 경우:
- 매개변수가 NULL이면 NULL을 반환합니다.
- 마스킹 형식: 처음 3자리 + `****` + 마지막 4자리
- 문자열 길이가 7자리보다 짧으면 결과에서 앞부분과 뒷부분이 겹칠 수 있습니다.

## 예제 {#examples}

1. 기본 사용법: 11자리 전화번호 마스킹
```sql
SELECT digital_masking('13812345678');
```
```text
+--------------------------------+
| digital_masking('13812345678') |
+--------------------------------+
| 138****5678                    |
+--------------------------------+
```

2. 길이가 다른 숫자 문자열
```sql
SELECT digital_masking('1234567890');
```
```text
+-------------------------------+
| digital_masking('1234567890') |
+-------------------------------+
| 123****7890                   |
+-------------------------------+
```

3. 짧은 숫자 문자열(7자리 미만)
```sql
SELECT digital_masking('123');
```
```text
+------------------------+
| digital_masking('123') |
+------------------------+
| 123****123             |
+------------------------+
```

4. NULL 값 처리
```sql
SELECT digital_masking(NULL);
```
```text
+-----------------------+
| digital_masking(NULL) |
+-----------------------+
| NULL                  |
+-----------------------+
```

5. UTF-8 문자가 포함된 문자열
```sql
SELECT digital_masking('13812ṭṛ34678');
```
```text
+-------------------------------------+
| digital_masking('13812ṭṛ34678')     |
+-------------------------------------+
| 138****4678                         |
+-------------------------------------+
```
