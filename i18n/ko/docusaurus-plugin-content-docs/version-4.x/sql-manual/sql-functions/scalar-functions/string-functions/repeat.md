## 설명 {#description}

REPEAT 함수는 지정된 문자열을 지정된 횟수만큼 반복하여 새 문자열을 생성합니다. 이 함수는 주로 패딩 문자, 구분자 또는 테스트 데이터를 생성할 때 사용합니다.

## 구문 {#syntax}

```sql
REPEAT(<str>, <count>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<str>` | 반복할 원본 문자열입니다. 타입: VARCHAR |
| `<count>` | 반복 횟수이며, 음이 아닌 정수여야 합니다. 타입: INT |

## 반환 값 {#return-value}

지정된 횟수만큼 반복된 문자열을 VARCHAR 타입으로 반환합니다.

반복 규칙:
- count가 0보다 크면 str을 count번 반복한 결과를 반환합니다.
- count가 0이면 빈 문자열을 반환합니다.
- count가 0보다 작으면 빈 문자열을 반환합니다.
- 결과 문자열이 너무 길면 문자열 길이 제한이 적용될 수 있습니다.

특수한 경우:
- 매개변수 중 하나라도 NULL이면 NULL을 반환합니다.
- str이 빈 문자열이면 count에 관계없이 빈 문자열을 반환합니다.
- count가 0이면 빈 문자열을 반환합니다.
- count가 음수이면 빈 문자열을 반환합니다.

## 예제 {#examples}

1. 기본 문자 반복
```sql
SELECT REPEAT('a', 3);
```
```text
+----------------+
| REPEAT('a', 3) |
+----------------+
| aaa            |
+----------------+
```

2. 여러 문자로 구성된 문자열 반복
```sql
SELECT REPEAT('hello', 2);
```
```text
+--------------------+
| REPEAT('hello', 2) |
+--------------------+
| hellohello         |
+--------------------+
```

3. 반복 횟수가 영인 경우
```sql
SELECT REPEAT('test', 0);
```
```text
+-------------------+
| REPEAT('test', 0) |
+-------------------+
|                   |
+-------------------+
```

4. 반복 횟수가 음수인 경우
```sql
SELECT REPEAT('a', -1);
```
```text
+-----------------+
| REPEAT('a', -1) |
+-----------------+
|                 |
+-----------------+
```

5. NULL 값 처리
```sql
SELECT REPEAT(NULL, 3), REPEAT('a', NULL);
```
```text
+------------------+-------------------+
| REPEAT(NULL, 3)  | REPEAT('a', NULL) |
+------------------+-------------------+
| NULL             | NULL              |
+------------------+-------------------+
```

6. 빈 문자열 반복
```sql
SELECT REPEAT('', 5);
```
```text
+----------------+
| REPEAT('', 5)  |
+----------------+
|                |
+----------------+
```

7. 특수 문자 반복
```sql
SELECT REPEAT('-', 10), REPEAT('*', 5);
```
```text
+------------------+-----------------+
| REPEAT('-', 10)  | REPEAT('*', 5)  |
+------------------+-----------------+
| ----------       | *****           |
+------------------+-----------------+
```

8. UTF-8 문자 반복
```sql
SELECT REPEAT('ṭṛì', 3), REPEAT('ḍḍu', 2);
```
```text
+-------------------+-------------------+
| REPEAT('ṭṛì', 3)  | REPEAT('ḍḍu', 2)  |
+-------------------+-------------------+
| ṭṛìṭṛìṭṛì          | ḍḍuḍḍu            |
+-------------------+-------------------+
```

9. 숫자와 기호 혼합
```sql
SELECT REPEAT('123', 3), REPEAT('@#', 4);
```
```text
+-------------------+------------------+
| REPEAT('123', 3)  | REPEAT('@#', 4)  |
+-------------------+------------------+
| 123123123         | @#@#@#@#         |
+-------------------+------------------+
```

10. UTF-8 문자 반복
```sql
SELECT REPEAT('ṭṛìṭṛì', 3);
```
```text
+--------------------------------------------------+
| REPEAT('ṭṛìṭṛì', 3)                              |
+--------------------------------------------------+
| ṭṛìṭṛìṭṛìṭṛìṭṛìṭṛì                               |
+--------------------------------------------------+
```
