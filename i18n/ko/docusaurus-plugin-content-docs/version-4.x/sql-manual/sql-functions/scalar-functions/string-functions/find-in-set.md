## 설명 {#description}

쉼표로 구분된 문자열 목록 strlist에서 문자열 str이 처음 나타나는 위치를 반환합니다(위치는 1부터 셉니다). 이 함수는 MySQL 호환 모드로 구현되었으며, 쉼표로 구분된 값 목록에서 특정 문자열을 찾는 데 사용됩니다.

## 구문 {#syntax}

```sql
FIND_IN_SET(<str>, <strlist>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|-------------|----------|
| `<str>`     | 검색할 대상 문자열입니다. 타입: VARCHAR |
| `<strlist>` | str을 검색할 쉼표로 구분된 문자열 목록입니다. 타입: VARCHAR |

## 반환 값 {#return-value}

strlist에서 str의 위치를 나타내는 INT 타입 값을 반환합니다(위치는 1부터 셉니다).

검색 규칙:
- 정확히 일치: str이 strlist의 부분 문자열과 정확히 일치하는 경우에만 위치를 반환합니다
- 위치는 1부터 셉니다
- 처음 일치하는 항목의 위치를 반환합니다

특수한 경우:
- str이 빈 문자열이면 0을 반환합니다
- strlist가 빈 문자열이면 0을 반환합니다
- 일치하는 항목이 없으면 0을 반환합니다
- 매개변수 중 하나라도 NULL이면 NULL을 반환합니다
- str에 쉼표가 포함되어 있으면 올바르게 검색할 수 없습니다(쉼표가 구분자이기 때문입니다)
- 일치 여부를 확인할 때 대소문자를 구분합니다

## 예제 {#examples}

1. 기본 검색
```sql
SELECT FIND_IN_SET('b', 'a,b,c');
```
```text
+---------------------------+
| FIND_IN_SET('b', 'a,b,c') |
+---------------------------+
|                         2 |
+---------------------------+
```

2. 첫 번째 요소 찾기
```sql
SELECT FIND_IN_SET('apple', 'apple,banana,cherry');
```
```text
+------------------------------------------+
| FIND_IN_SET('apple', 'apple,banana,cherry') |
+------------------------------------------+
|                                        1 |
+------------------------------------------+
```

3. 마지막 요소 찾기
```sql
SELECT FIND_IN_SET('cherry', 'apple,banana,cherry');
```
```text
+-------------------------------------------+
| FIND_IN_SET('cherry', 'apple,banana,cherry') |
+-------------------------------------------+
|                                         3 |
+-------------------------------------------+
```

4. 일치하는 항목이 없는 경우
```sql
SELECT FIND_IN_SET('orange', 'apple,banana,cherry');
```
```text
+--------------------------------------------+
| FIND_IN_SET('orange', 'apple,banana,cherry') |
+--------------------------------------------+
|                                          0 |
+--------------------------------------------+
```

5. NULL 값 처리
```sql
SELECT FIND_IN_SET(NULL, 'a,b,c'), FIND_IN_SET('b', NULL);
```
```text
+---------------------------+-------------------------+
| FIND_IN_SET(NULL, 'a,b,c') | FIND_IN_SET('b', NULL) |
+---------------------------+-------------------------+
|                      NULL |                    NULL |
+---------------------------+-------------------------+
```

6. 빈 문자열 처리
```sql
SELECT FIND_IN_SET('', 'a,b,c'), FIND_IN_SET('a', '');
```
```text
+-------------------------+-----------------------+
| FIND_IN_SET('', 'a,b,c') | FIND_IN_SET('a', '') |
+-------------------------+-----------------------+
|                       0 |                     0 |
+-------------------------+-----------------------+
```

7. 쉼표가 포함된 문자열(올바르게 검색할 수 없음)
```sql
SELECT FIND_IN_SET('a,b', 'a,b,c,d');
```
```text
+------------------------------+
| FIND_IN_SET('a,b', 'a,b,c,d') |
+------------------------------+
|                            0 |
+------------------------------+
```

8. 대소문자를 구분하는 일치 검색
```sql
SELECT FIND_IN_SET('B', 'a,b,c'), FIND_IN_SET('b', 'A,B,C');
```
```text
+---------------------------+---------------------------+
| FIND_IN_SET('B', 'a,b,c') | FIND_IN_SET('b', 'A,B,C') |
+---------------------------+---------------------------+
|                         0 |                         0 |
+---------------------------+---------------------------+
```

9. 부분 일치는 검색되지 않음
```sql
SELECT FIND_IN_SET('ap', 'apple,banana,cherry');
```
```text
+---------------------------------------+
| FIND_IN_SET('ap', 'apple,banana,cherry') |
+---------------------------------------+
|                                     0 |
+---------------------------------------+
```

10. 숫자 문자열 검색
```sql
SELECT FIND_IN_SET('2', '1,2,3,10,20');
```
```text
+--------------------------------+
| FIND_IN_SET('2', '1,2,3,10,20') |
+--------------------------------+
|                              2 |
+--------------------------------+
```
