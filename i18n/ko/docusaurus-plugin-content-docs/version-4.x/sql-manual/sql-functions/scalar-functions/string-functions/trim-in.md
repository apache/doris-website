## 설명 {#description}

TRIM_IN 함수는 문자열의 앞뒤에서 지정된 문자를 제거하는 데 사용됩니다. 문자 집합을 지정하지 않으면 기본적으로 문자열 앞뒤의 공백을 제거합니다. 문자 집합을 지정하면 집합 내 문자 순서에 관계없이 양 끝에서 지정된 문자를 모두 제거합니다.

TRIM_IN의 주요 특징은 지정된 집합에 속하는 문자라면 조합에 관계없이 제거한다는 점입니다. 반면 TRIM 함수는 문자열이 정확히 일치하는 경우에만 제거합니다.

## 구문 {#syntax}

```sql
TRIM_IN(<str>[, <rhs>])
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| --------- | ------------------------------------------------------------------------ |
| `<str>` | 처리할 문자열입니다. 유형: VARCHAR |
| `<rhs>` | 제거할 문자 집합을 지정하는 선택적 매개변수입니다. 유형: VARCHAR |

## 반환값 {#return-value}

처리된 문자열을 나타내는 VARCHAR 유형의 값을 반환합니다.

특수한 경우:
- str이 NULL이면 NULL을 반환합니다.
- rhs를 지정하지 않으면 문자열 앞뒤의 모든 공백을 제거합니다.
- rhs를 지정하면 문자열의 양 끝에서 rhs에 포함된 문자를 모두 제거하며, rhs에 없는 문자를 만나면 해당 끝에서의 제거를 중단합니다.

## 예제 {#examples}

1. 문자열 앞뒤의 공백 제거
```sql
SELECT trim_in('   ab d   ') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. 지정된 문자 집합 제거
```sql
SELECT trim_in('ababccaab', 'ab') str;
```
```text
+------+
| str  |
+------+
| cc   |
+------+
```

3. TRIM 함수와 비교: `trim_in`은 두 번째 인수를 *문자 집합*으로 취급하여 양 끝에서 해당 집합에 속하는 문자를 제거하고, `trim`은 두 번째 인수를 리터럴 *부분 문자열*로 취급하여 양 끝에서 정확히 일치하는 부분을 제거합니다. 두 함수 모두 양 끝에 더 이상 제거할 대상이 없을 때까지 반복해서 제거합니다.
```sql
SELECT trim_in('ababccaab', 'ab'), trim('ababccaab', 'ab');
```
```text
+----------------------------+-------------------------+
| trim_in('ababccaab', 'ab') | trim('ababccaab', 'ab') |
+----------------------------+-------------------------+
| cc                         | cca                     |
+----------------------------+-------------------------+
```

4. 문자 집합 내 순서는 결과에 영향을 주지 않음
```sql
SELECT trim_in('abcHelloabc', 'cba');
```
```text
+--------------------------------+
| trim_in('abcHelloabc', 'cba')  |
+--------------------------------+
| Hello                          |
+--------------------------------+
```

5. UTF-8 문자 지원
```sql
SELECT trim_in('+++ṭṛì ḍḍumai+++', '+');
```
```text
+--------------------------------------+
| trim_in('+++ṭṛì ḍḍumai+++', '+')    |
+--------------------------------------+
| ṭṛì ḍḍumai                           |
+--------------------------------------+
```

6. NULL 값 처리
```sql
SELECT trim_in(NULL, 'abc');
```
```text
+-----------------------+
| trim_in(NULL, 'abc')  |
+-----------------------+
| NULL                  |
+-----------------------+
```

7. 빈 문자열 처리
```sql
SELECT trim_in('', 'abc'), trim_in('abc', '');
```
```text
+--------------------+--------------------+
| trim_in('', 'abc') | trim_in('abc', '') |
+--------------------+--------------------+
|                    | abc                |
+--------------------+--------------------+
```

### 키워드 {#keywords}

    TRIM_IN, TRIM
