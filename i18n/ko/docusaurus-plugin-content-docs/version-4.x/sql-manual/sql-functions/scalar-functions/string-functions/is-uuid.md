## 설명 {#description}

매개변수가 유효한 UUID이면 1을 반환합니다. 유효하지 않은 UUID이면 0을 반환합니다. 매개변수가 NULL이면 NULL을 반환합니다.

UUID는 길이가 올바르고 허용된 문자(대소문자를 구분하지 않는 십육진수 숫자와 선택적으로 포함할 수 있는 하이픈 및 중괄호)만 포함하면 유효한 것으로 간주됩니다. 다음 세 가지 형식 중 하나로 나타낼 수 있습니다:
```text
aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
aaaaaaaabbbbccccddddeeeeeeeeeeee
{aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee}
```

## 구문 {#syntax}

```sql
IS_UUID ( <str> )
```

## 매개변수 {#parameters}
| 매개변수  | 설명 |
|------------|-----------------|
| `<str>` | 문자열 |


## 반환값 {#return-value}

`<str>`이 유효한 UUID이면 1을 반환하고, 그렇지 않으면 0을 반환합니다.

특수한 경우:
- 매개변수가 NULL이면 NULL을 반환합니다.
