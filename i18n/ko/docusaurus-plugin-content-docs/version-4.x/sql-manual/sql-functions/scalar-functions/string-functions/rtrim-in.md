## 설명 {#description}

RTRIM_IN 함수는 문자열 오른쪽에서 지정된 문자를 제거합니다. 문자 집합을 지정하지 않으면 기본적으로 후행 공백을 제거합니다. 문자 집합을 지정하면 집합 내 문자 순서에 관계없이 문자열 오른쪽에서 지정된 문자를 모두 제거합니다.

RTRIM_IN의 주요 특징은 지정된 집합에 속한 문자라면 어떤 조합이든 제거한다는 점입니다. 반면 RTRIM 함수는 문자열이 정확히 일치하는 경우에만 해당 문자열을 제거합니다.

## 구문 {#syntax}

```sql
RTRIM_IN(<str>[, <rhs>])
```

## 매개변수 {#parameters}
| 매개변수 | 설명 |
| --------- | ---------------------------------------------------------------------- |
| `<str>` | 처리할 문자열입니다. 타입: VARCHAR |
| `<rhs>` | 제거할 문자 집합을 지정하는 선택적 매개변수입니다. 타입: VARCHAR |

## 반환 값 {#return-value}

처리된 문자열을 VARCHAR 타입으로 반환합니다.

특수한 경우:
- str이 NULL이면 NULL을 반환합니다.
- rhs를 지정하지 않으면 모든 후행 공백을 제거합니다.
- rhs를 지정하면 문자열 오른쪽에서 rhs에 포함된 문자를 모두 제거하며, rhs에 포함되지 않은 문자를 처음 만나면 중단합니다.

## 예제 {#examples}

1. 후행 공백 제거
```sql
SELECT rtrim_in('ab d   ') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. 지정된 문자 집합의 문자 제거
```sql
SELECT rtrim_in('ababccaab', 'ab') str;
```
```text
+---------+
| str     |
+---------+
| ababcc  |
+---------+
```

3. RTRIM 함수와 비교
```sql
SELECT rtrim_in('ababccaab', 'ab'), rtrim('ababccaab', 'ab');
```
```text
+-----------------------------+--------------------------+
| rtrim_in('ababccaab', 'ab') | rtrim('ababccaab', 'ab') |
+-----------------------------+--------------------------+
| ababcc                      | ababcca                  |
+-----------------------------+--------------------------+
```

4. 문자 집합 내 순서와 무관한 동작
```sql
SELECT rtrim_in('Helloabc', 'cba');
```
```text
+-----------------------------+
| rtrim_in('Helloabc', 'cba') |
+-----------------------------+
| Hello                       |
+-----------------------------+
```

5. UTF-8 문자 지원
```sql
SELECT rtrim_in('ṭṛì ḍḍumai+++', '+');
```
```text
+------------------------------------+
| rtrim_in('ṭṛì ḍḍumai+++', '+')    |
+------------------------------------+
| ṭṛì ḍḍumai                         |
+------------------------------------+
```

6. NULL 값 처리
```sql
SELECT rtrim_in(NULL, 'abc');
```
```text
+------------------------+
| rtrim_in(NULL, 'abc')  |
+------------------------+
| NULL                   |
+------------------------+
```

7. 빈 문자열 처리
```sql
SELECT rtrim_in('', 'abc'), rtrim_in('abc', '');
```
```text
+---------------------+---------------------+
| rtrim_in('', 'abc') | rtrim_in('abc', '') |
+---------------------+---------------------+
|                     | abc                 |
+---------------------+---------------------+
```

### 키워드 {#keywords}
