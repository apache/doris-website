## 설명 {#description}

TRANSLATE 함수는 매핑 규칙에 따라 원본 문자열의 문자를 하나씩 치환합니다. 원본 문자열에서 'from' 문자열에 포함된 각 문자를 'to' 문자열의 같은 위치에 있는 문자로 치환합니다.

## 구문 {#syntax}

```sql
TRANSLATE(<source>, <from>, <to>)
```

## 매개변수 {#parameters}
| 매개변수 | 설명                                         |
| --------- | --------------------------------------------------- |
| `<source>` | 변환할 원본 문자열입니다. 타입: VARCHAR    |
| `<from>` | 치환할 문자 집합입니다. 타입: VARCHAR |
| `<to>` | 치환에 사용할 문자 집합입니다. 타입: VARCHAR    |

## 반환값 {#return-value}

문자 매핑 규칙에 따라 변환된 문자열을 VARCHAR 타입으로 반환합니다.

문자 매핑 규칙:
- 'from' 문자열과 'to' 문자열의 위치를 기준으로 문자를 일대일로 매핑합니다
- 'from'의 1번째 문자는 'to'의 1번째 문자에, 2번째 문자는 2번째 문자에 매핑되며, 이후에도 같은 방식으로 매핑됩니다
- 'from'에 중복 문자가 있으면 처음 등장한 위치의 매핑을 사용하고 이후의 중복 문자는 무시합니다
- 원본 문자열에서 'from' 문자열에 포함되지 않은 문자는 그대로 유지됩니다

특수한 경우:
- 매개변수 중 하나라도 NULL이면 NULL을 반환합니다
- 원본이 빈 문자열이면 빈 문자열을 반환합니다
- 'from'이 빈 문자열이면 원본 문자열을 그대로 반환합니다
- 'to'가 빈 문자열이면 원본에서 'from'에 포함된 모든 문자를 삭제합니다
- 'to' 문자열이 'from'보다 짧으면 원본에서 'from'의 남는 문자에 해당하는 문자를 삭제합니다

## 예제 {#examples}

1. 기본 문자 치환
```sql
SELECT TRANSLATE('abcd', 'a', 'z');
```
```text
+-----------------------------+
| TRANSLATE('abcd', 'a', 'z') |
+-----------------------------+
| zbcd                        |
+-----------------------------+
```

2. 원본 문자가 등장하는 모든 위치에서 치환
```sql
SELECT TRANSLATE('abcda', 'a', 'z');
```
```text
+------------------------------+
| TRANSLATE('abcda', 'a', 'z') |
+------------------------------+
| zbcdz                        |
+------------------------------+
```

3. 여러 문자 매핑(위치 기준)
```sql
SELECT TRANSLATE('abcd', 'ac', 'zx');
```
```text
+-------------------------------+
| TRANSLATE('abcd', 'ac', 'zx') |
+-------------------------------+
| zbxd                          |
+-------------------------------+
```

4. `<from>`에 중복 문자가 있는 경우(첫 번째 매핑만 사용)
```sql
SELECT TRANSLATE('abacad', 'aac', 'zxy');
```
```text
+-----------------------------------+
| TRANSLATE('abacad', 'aac', 'zxy') |
+-----------------------------------+
| zbzyzd                            |
+-----------------------------------+
```

5. `<to>`가 `<from>`보다 짧은 경우(남는 문자 삭제)
```sql
SELECT TRANSLATE('abcde', 'ace', 'xy');
```
```text
+---------------------------------+
| TRANSLATE('abcde', 'ace', 'xy') |
+---------------------------------+
| xbyd                            |
+---------------------------------+
```

6. NULL 처리: 인수 중 하나라도 NULL이면 NULL 반환
```sql
SELECT TRANSLATE(NULL, 'a', 'z'), TRANSLATE('abc', NULL, 'z'), TRANSLATE('abc', 'a', NULL);
```
```text
+---------------------------+-----------------------------+-----------------------------+
| TRANSLATE(NULL, 'a', 'z') | TRANSLATE('abc', NULL, 'z') | TRANSLATE('abc', 'a', NULL) |
+---------------------------+-----------------------------+-----------------------------+
| NULL                      | NULL                        | NULL                        |
+---------------------------+-----------------------------+-----------------------------+
```

7. 빈 문자열의 경계 사례: 원본이 비어 있으면 빈 문자열 반환, `<from>`이 비어 있으면 원본을 그대로 반환, `<to>`가 비어 있으면 일치하는 문자 삭제
```sql
SELECT TRANSLATE('', 'a', 'z'), TRANSLATE('abc', '', 'z'), TRANSLATE('abc', 'a', '');
```
```text
+-------------------------+---------------------------+---------------------------+
| TRANSLATE('', 'a', 'z') | TRANSLATE('abc', '', 'z') | TRANSLATE('abc', 'a', '') |
+-------------------------+---------------------------+---------------------------+
|                         | abc                       | bc                        |
+-------------------------+---------------------------+---------------------------+
```

8. UTF-8 멀티바이트 문자
```sql
SELECT TRANSLATE('ṭṛì ḍḍumai', 'ṭṛ', 'ab');
```
```text
+--------------------------------------------------+
| TRANSLATE('ṭṛì ḍḍumai', 'ṭṛ', 'ab')              |
+--------------------------------------------------+
| abì ḍḍumai                                       |
+--------------------------------------------------+
```

9. 숫자 문자 치환
```sql
SELECT TRANSLATE('a1b2c3', '123', 'xyz');
```
```text
+-----------------------------------+
| TRANSLATE('a1b2c3', '123', 'xyz') |
+-----------------------------------+
| axbycz                            |
+-----------------------------------+
```

10. 양쪽 문자열에 중복 문자가 있는 경우의 반복 매핑
```sql
SELECT TRANSLATE('aabbccaa', 'abab', 'xyuv');
```
```text
+---------------------------------------+
| TRANSLATE('aabbccaa', 'abab', 'xyuv') |
+---------------------------------------+
| xxyyccxx                              |
+---------------------------------------+
```

11. 특수 기호 치환
```sql
SELECT TRANSLATE('hello@world.com', '@.', '-_');
```
```text
+------------------------------------------+
| TRANSLATE('hello@world.com', '@.', '-_') |
+------------------------------------------+
| hello-world_com                          |
+------------------------------------------+
```
