## 설명 {#description}

REPLACE_EMPTY 함수는 문자열의 일부 문자를 다른 문자로 치환하는 데 사용됩니다. [REPLACE](./replace.md) 함수와 달리, `old`가 빈 문자열이면 `new` 문자열을 `str` 문자열의 각 문자 앞과 `str` 문자열의 끝에 삽입합니다.

이 함수는 주로 Presto 및 Trino와의 호환성을 위해 사용되며, Presto 및 Trino의 `REPLACE()` 함수와 동작이 완전히 같습니다. 버전 2.1.5부터 지원됩니다.

## 구문 {#syntax}

```sql
REPLACE_EMPTY ( <str>, <old>, <new> )
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|---------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `<str>` | 치환 대상 문자열입니다. |
| `<old>` | 치환할 부분 문자열입니다. `<old>`가 `<str>`에 없으면 치환하지 않습니다. `<old>`가 빈 문자열이면 `<new>` 문자열을 str 문자열의 각 문자 앞에 삽입합니다. |
| `<new>` | `<old>`를 대체할 새 부분 문자열입니다. |

## 반환 값 {#return-value}

부분 문자열을 치환한 새 문자열을 VARCHAR로 반환합니다. 특수한 경우는 다음과 같습니다:

- 매개변수 중 하나라도 NULL이면 NULL을 반환합니다.
- `<old>`가 빈 문자열이면 `<new>`를 `<str>`의 각 문자 앞과 끝에 삽입한 문자열을 반환합니다.
- `<old>`를 `<str>`에서 찾을 수 없으면 `<str>`를 그대로 반환합니다.

## 예제 {#examples}

참고로, `REPLACE`는 `<old>`가 나타나는 모든 부분을 치환하고 문자열의 나머지 부분은 그대로 유지합니다:

```sql
SELECT replace('hello world', 'world', 'universe');
```

```text
+---------------------------------------------+
| replace('hello world', 'world', 'universe') |
+---------------------------------------------+
| hello universe                              |
+---------------------------------------------+
```

`REPLACE_EMPTY`는 일반적인 경우에는 동일하게 동작하지만(아래 예제 2 참조), `<old>`가 빈 문자열일 때는 동작이 다릅니다. 이때는 `<new>`를 `<str>`의 각 문자 앞과 끝에 삽입합니다(예제 1). 나머지 예제는 경계 사례를 다룹니다.

1. 기본 사용법: `<old>`가 빈 문자열일 때의 삽입 동작.

```sql
SELECT replace_empty('abc', '', 'x');
```

```text
+-------------------------------+
| replace_empty('abc', '', 'x') |
+-------------------------------+
| xaxbxcx                       |
+-------------------------------+
```

2. 일반적인 부분 문자열 치환(`REPLACE`와 동일한 동작).

```sql
SELECT replace_empty('hello', 'l', 'L');
```

```text
+----------------------------------+
| replace_empty('hello', 'l', 'L') |
+----------------------------------+
| heLLo                            |
+----------------------------------+
```

3. `<str>`와 `<old>`가 모두 빈 문자열인 경우.

```sql
SELECT replace_empty('', '', 'x');
```

```text
+----------------------------+
| replace_empty('', '', 'x') |
+----------------------------+
| x                          |
+----------------------------+
```

4. NULL 전파.

```sql
SELECT replace_empty(NULL, 'old', 'new');
```

```text
+-----------------------------------+
| replace_empty(NULL, 'old', 'new') |
+-----------------------------------+
| NULL                              |
+-----------------------------------+
```

5. 멀티바이트(UTF-8) `<new>`.

```sql
SELECT replace_empty('hello', 'l', 'ṭṛìṭ');
```

```text
+--------------------------------------------+
| replace_empty('hello', 'l', 'ṭṛìṭ')        |
+--------------------------------------------+
| heṭṛìṭṭṛìṭo                                |
+--------------------------------------------+
```
