## 설명 {#description}

LTRIM_IN 함수는 문자열의 왼쪽에서 지정된 문자를 제거합니다. 문자 집합을 지정하지 않으면 기본적으로 선행 공백을 제거합니다. 문자 집합을 지정하면 집합 내 순서와 관계없이 왼쪽에서 지정된 문자를 모두 제거합니다.
LTRIM_IN의 주요 특징은 지정된 집합에 속한 문자가 어떤 조합으로 나타나든 제거한다는 점이며, LTRIM 함수는 정확히 일치하는 문자열을 기준으로 문자를 제거합니다.

## 구문 {#syntax}

```sql
LTRIM_IN(<str> [, <rhs>])
```

## 매개변수 {#parameters}
| 매개변수 | 설명                                                            |
| --------- | ---------------------------------------------------------------------- |
| `<str>` | 처리할 문자열입니다. 타입: VARCHAR                              |
| `<rhs>` | 선택적 매개변수로, 제거할 문자 집합입니다. 타입: VARCHAR |

## 반환값 {#return-value}

처리된 문자열을 나타내는 VARCHAR 타입을 반환합니다.

특수한 경우:
- str이 NULL이면 NULL을 반환합니다
- rhs를 지정하지 않으면 선행 공백을 모두 제거합니다
- rhs를 지정하면 rhs에 포함되지 않은 첫 번째 문자가 나올 때까지 왼쪽에서 rhs에 포함된 문자를 모두 제거합니다

## 예제 {#examples}

1. 선행 공백 제거
```sql
SELECT ltrim_in('   ab d') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. 지정된 문자 집합 제거
```sql
SELECT ltrim_in('ababccaab', 'ab') str;
```
```text
+-------+
| str   |
+-------+
| ccaab |
+-------+
```

3. LTRIM 함수와 비교
```sql
SELECT ltrim_in('abcd', 'ae'),ltrim('abcd', 'abe');
```
```text
+------------------------+----------------------+
| ltrim_in('abcd', 'ae') | ltrim('abcd', 'abe') |
+------------------------+----------------------+
| bcd                    | abcd                 |
+------------------------+----------------------+
```
