# 데이터 통합 {#data-integration}

Apache Doris는 다양한 데이터 생태계 도구와의 통합을 지원합니다. 사용 사례에 맞는 도구를 선택하여 Doris를 데이터 시각화, 데이터 마이그레이션 및 동기화, 실시간 데이터 수집, 로그 및 관측성 분석, 데이터베이스 개발 및 관리, 데이터 모델링 및 변환에 활용할 수 있습니다.
