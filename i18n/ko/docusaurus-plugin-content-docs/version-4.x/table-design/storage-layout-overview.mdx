Apache Doris는 사용자가 디스크의 스토리지 레이아웃을 조정할 수 있도록 매개변수를 제공합니다. 스토리지 레이아웃을 적절히 구성하면 테이블 모델이나 쿼리를 변경하지 않고도 스토리지 비용을 절감하고, 컬럼 수가 많은 테이블의 포인트 쿼리를 가속하며, 과거 데이터와 콜드 데이터의 저장 오버헤드를 줄일 수 있습니다.
