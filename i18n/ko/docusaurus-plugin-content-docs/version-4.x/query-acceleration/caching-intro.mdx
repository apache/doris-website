Apache Doris는 여러 계층의 캐싱으로 쿼리를 가속화합니다. 결과 수준 캐싱은 동일한 SQL의 쿼리 결과를 재사용하고, 세그먼트 수준 캐싱은 필터 조건의 연산 결과를 재사용합니다. 파일 수준 캐싱은 원격 레이크하우스 데이터와 컴퓨팅-스토리지 분리 모드의 내부 테이블 데이터를 로컬 디스크에 캐싱합니다. 워크로드 특성에 맞는 캐싱 전략을 선택하세요.
