Apache Doris의 적응형 옵티마이저와 Pipeline 실행 엔진 덕분에 대부분의 워크로드는 별도 설정 없이도 원활하게 실행되지만, 운영 환경에서는 대개 체계적인 성능 튜닝이 필요합니다. 먼저 튜닝 방법론에 따라 병목 지점을 찾은 다음, 쿼리 또는 데이터 적재 측면에서 구체적인 시나리오에 맞춰 최적화하세요. 이해하기 어려운 실행 계획을 만나면 최적화 기술 원리를 참고하여 그 이면의 동작 방식을 파악하세요.
