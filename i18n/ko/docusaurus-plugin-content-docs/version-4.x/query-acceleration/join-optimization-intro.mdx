Apache Doris는 대부분의 Join 쿼리 시나리오에서 별도 설정 없이도 우수한 성능을 제공합니다. 하지만 성능 요구 사항이 엄격한 시나리오에서는 테이블의 Colocation을 구성하고 Hint로 옵티마이저를 유도하여 성능을 더 최적화할 수 있습니다. 먼저 Colocation Join을 사용해 버킷 기반 equi-join의 네트워크 shuffle을 제거하고, 이후 옵티마이저가 최적이 아닌 선택을 하는 경우 Distribute Hint와 Leading Hint로 shuffle 방식과 Join 순서를 세밀하게 조정하는 것이 좋습니다.
