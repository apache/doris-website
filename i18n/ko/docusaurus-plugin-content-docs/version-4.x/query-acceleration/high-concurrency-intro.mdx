Doris는 분석에 최적화된 컬럼 기반 스토리지에 더해, 높은 동시성과 낮은 지연 시간이 필요한 온라인 포인트 쿼리와 키-값 조회를 위한 전용 최적화 경로를 제공합니다. row store와 short path는 Unique 테이블의 기본 키 포인트 쿼리에 높은 QPS와 낮은 지연 시간을 제공합니다. 딕셔너리는 디멘션 조인을 인메모리 키-값 조회로 변환합니다.
