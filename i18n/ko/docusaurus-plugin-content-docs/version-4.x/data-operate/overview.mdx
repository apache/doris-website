Apache Doris는 데이터 수집부터 데이터 내보내기까지 전체 파이프라인을 아우르는 포괄적인 데이터 작업 기능을 제공합니다. 다양한 데이터 소스에서 데이터를 적재하고, 트랜잭션을 보장하면서 데이터를 업데이트하거나 삭제하며, 쿼리 결과나 테이블 데이터를 외부 스토리지 시스템으로 내보낼 수 있습니다.

또한 Apache Doris는 Apache Iceberg 테이블 데이터를 직접 관리하는 기능도 지원합니다. 여기에는 Iceberg 테이블에 대한 직접 쿼리 가속, 쓰기, 업데이트 및 삭제 작업이 포함됩니다. 자세한 내용은 Iceberg Catalog의 데이터 관리 섹션을 참조하세요.
