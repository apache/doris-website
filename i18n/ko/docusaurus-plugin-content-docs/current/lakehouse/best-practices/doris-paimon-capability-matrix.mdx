다음 매트릭스는 현재 Doris에서 사용할 수 있는 Paimon Catalog 기능을 요약합니다. 행은 기능 영역별로 묶여 있으며, 백엔드 열은 Doris가 해당 메타데이터 서비스를 사용할 때 각 작업을 수행할 수 있는지를 나타냅니다. ✅는 Doris에서 해당 작업을 지원함을, ❌는 현재 해당 작업을 지원하지 않음을 나타냅니다.

DLF 열은 `paimon.catalog.type=dlf`를 가리킵니다. 이 설정은 Hive와 호환되는 메타스토어 클라이언트를 사용하며, OSS 또는 OSS-HDFS 스토리지 구성이 필요합니다. `paimon.catalog.type=rest`를 통해 접근하는 DLF는 REST 열에 포함됩니다.
