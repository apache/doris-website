## 버전 번호란 무엇인가요? {#what-is-a-version-number}

Apache Doris는 세 부분으로 구성된 버전 번호(X.Y.Z)를 사용하며, 각 자리는 서로 다른 릴리스 유형을 나타냅니다.

| 버전 번호 위치 | 이름 | 설명 |
|------------------|------|-------------|
| X | 메이저 버전 | 주요 기능 릴리스 또는 아키텍처 업그레이드, 약 1년 주기 |
| Y | 마이너 버전 | 중요한 기능 추가 및 성능 개선, 약 분기별 주기 |
| Z | 패치 버전 | 버그 수정 및 성능 개선, 2-4주 주기 |

**예시**: 버전 `2.1.0`은 메이저 버전 2, 마이너 버전 1, 패치 버전 0을 나타냅니다.

---

## 업그레이드 전에 반드시 알아야 할 사항 {#what-you-must-know-before-upgrading}

### 버전 번호 위치에 따른 호환성 차이 {#compatibility-differences-across-version-positions}

| 버전 유형 | 메타데이터 / 데이터 형식 변경 | 호환성 안내 |
|--------------|--------------------------------|---------------------|
| 메이저 버전 (X) | 변경될 수 있음 | 순방향 호환성은 제공하지만 역방향 호환성은 보장하지 않음 |
| 마이너 버전 (Y) | 변경 없음 | 새 기능을 사용하지 않는 한 순방향 및 역방향 호환성을 모두 보장함 |
| 패치 버전 (Z) | 변경 없음 | 순방향 및 역방향 호환성을 완전히 보장하므로 자유롭게 업그레이드 또는 다운그레이드 가능 |

:::warning 중요
메이저 버전을 업그레이드할 때는 **이전 버전으로의 다운그레이드가 보장되지 않습니다**. 업그레이드 전에 데이터를 백업하세요.
:::

### 업그레이드 전 확인 사항 {#pre-upgrade-checklist}

-  대상 버전이 메이저, 마이너, 패치 릴리스 중 어디에 해당하는지 확인하세요
-  중요한 데이터와 메타데이터를 백업하세요
-  테스트 환경에서 업그레이드 절차를 검증하세요
-  버전 호환성 안내가 있다면 검토하세요

## 버전 선택 방법 {#how-to-choose-a-version}

Apache Doris는 두 가지 최신 버전 브랜치를 유지 관리합니다.

| 버전 유형 | 사용 사례 | 설명 |
|--------------|-----------|-------------|
| **Latest** | POC, 성능 테스트, 새 기능 체험 | 최신 기능이 포함되어 있으며 불안정할 수 있음 |
| **Stable** | 프로덕션 환경 | 버그 수정이 지속적으로 반영되며 안정성이 높음 |

**선택 가이드**:
- 프로덕션 환경: **Stable** 선택
- 기능 탐색 및 테스트: **Latest** 선택

## CPU 모델 및 바이너리 선택 {#cpu-model-and-binary-selection}

Doris는 CPU 명령어 세트에 따라 세 가지 바이너리 버전을 제공합니다.

| 버전 | 지원 CPU | 설명 |
|---------|----------------|-------------|
| x64 (avx2) | avx2 명령어 세트를 지원하는 x86_64 CPU | 최고의 성능 |
| x64 (no avx2) | avx2를 지원하지 않는 x86_64 CPU | 호환성 우선 |
| ARM64 | ARM 아키텍처 CPU | Apple M-series, Kunpeng 등 |

### CPU의 avx2 지원 여부 확인 방법 {#how-to-determine-whether-your-cpu-supports-avx2}

```bash
cat /proc/cpuinfo | grep avx2
```

명령어 실행 결과가 출력되면 해당 CPU는 avx2 명령어 세트를 지원하므로, 더 나은 성능을 위해 x64 (avx2) 빌드를 선택할 수 있습니다.

## 자주 묻는 질문 {#frequently-asked-questions}

### 질문: 2.0에서 3.1로 업그레이드할 수 있나요? {#q-can-i-upgrade-from-20-to-31}

네. 다만 메이저 버전 업그레이드에는 데이터 형식 변경이 수반될 수 있습니다. 업그레이드 전에 다음을 준비하세요.

1. 데이터를 백업하세요
2. 테스트 환경에서 검증하세요
3. 롤백 계획을 준비하세요

### 질문: 패치 버전은 언제든지 업그레이드할 수 있나요? {#q-can-patch-versions-be-upgraded-at-any-time}

네. 패치 버전(예: 2.1.0에서 2.1.1로 업그레이드)은 순방향 및 역방향 호환성이 모두 보장되므로 언제든지 업그레이드하거나 다운그레이드할 수 있습니다.

### 질문: 현재 Doris 버전은 어떻게 확인하나요? {#q-how-do-i-check-the-current-doris-version}

`SELECT VERSION();`를 실행하여 현재 버전을 쿼리하세요.

### 질문: Latest 및 Stable 버전은 어디에서 다운로드할 수 있나요? {#q-where-can-i-download-the-latest-and-stable-versions}

[Apache Doris 다운로드 페이지](https://doris.apache.org/download)에서 모든 버전의 다운로드 링크를 확인할 수 있습니다.
