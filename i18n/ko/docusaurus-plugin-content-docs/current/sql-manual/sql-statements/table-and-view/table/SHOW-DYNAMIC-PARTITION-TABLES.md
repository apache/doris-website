## 설명 {#descriptions}

이 문은 현재 데이터베이스에 있는 모든 동적 파티션 테이블의 상태를 표시하는 데 사용됩니다.

## 구문 {#syntax}

```sql
SHOW DYNAMIC PARTITION TABLES [FROM <db_name>];
```

## 필수 매개변수 {#required-parameters}
**1. `<db_name>`**

동적 파티션 테이블의 상태를 표시할 `DB` 이름을 지정합니다. 지정하지 않으면 기본적으로 현재 `DB`에 있는 모든 동적 파티션 테이블의 상태가 표시됩니다.
## 반환 값 {#return-value}

| 열                     | 데이터 타입 | 설명 |
|------------------------|----------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TableName              | varchar  | 현재 DB 또는 지정한 DB에 있는 테이블의 이름입니다. |
| Enable                 | varchar  | 테이블의 동적 파티션 속성 활성화 여부입니다. |
| TimeUnit               | varchar  | 동적 파티션 테이블의 파티션 단위로, `HOUR`, `DAY`, `WEEK`, `MONTH`, `YEAR`가 있습니다. |
| Start                  | varchar  | 동적 파티션의 시작 오프셋으로, 음수입니다. 기본값은 -2147483648이며, 이는 과거 파티션을 삭제하지 않음을 의미합니다. time_unit 속성에 따라 현재 날짜(주/월)를 기준으로 이 오프셋 이전 범위의 파티션을 삭제합니다. |
| End                    | varchar  | 동적 파티션의 종료 오프셋으로, 양수입니다. time_unit 속성에 따라 현재 날짜(주/월)를 기준으로 해당 범위 내의 파티션을 미리 생성합니다. |
| Prefix                 | varchar  | 동적으로 생성되는 파티션 이름의 접두사입니다. |
| Buckets                | varchar  | 동적으로 생성되는 파티션의 버킷 수입니다. |
| ReplicationNum         | varchar  | 동적으로 생성되는 파티션의 복제본 수입니다. 지정하지 않으면 테이블 생성 시 지정한 복제본 수를 기본값으로 사용합니다. |
| ReplicaAllocation      | varchar  | 동적으로 생성되는 파티션의 복제본 배치 전략입니다. 지정하지 않으면 테이블 생성 시 지정한 복제본 배치 전략을 기본값으로 사용합니다. |
| StartOf                | varchar  | 동적 파티셔닝에서 각 파티션 단위의 시작점입니다. time_unit이 WEEK인 경우 이 필드는 각 주의 시작 요일을 나타내며, 값의 범위는 MONDAY부터 SUNDAY까지입니다. time_unit이 MONTH인 경우 각 월의 시작일을 나타내며, 값의 범위는 1일부터 28일까지입니다. time_unit이 MONTH인 경우 이 값의 기본값은 NULL입니다. |
| LastUpdateTime         | datetime | 동적 파티션의 마지막 갱신 시간으로, 기본값은 NULL입니다. |
| LastSchedulerTime      | datetime | 동적 파티션의 마지막 스케줄링 시간입니다. |
| State                  | varchar  | 동적 파티션의 상태입니다. |
| LastCreatePartitionMsg | varchar  | 동적 파티션 추가 스케줄링을 마지막으로 실행했을 때의 오류 메시지입니다. |
| LastDropPartitionMsg   | varchar  | 동적 파티션 삭제 스케줄링을 마지막으로 실행했을 때의 오류 메시지입니다. |
| ReservedHistoryPeriods | varchar  | 동적 파티션에서 보존하는 과거 파티션의 범위로, 동적 파티션 테이블에서 자동으로 삭제하지 않고 보존해야 할 과거 파티션을 나타냅니다. |

## 접근 제어 요구 사항 {#access-control-requirements}
1. 매개변수 db_name을 지정하지 않으면 현재 DB에 있는 모든 동적 파티션 테이블의 상태가 표시되며, 기본적으로 사용자가 현재 DB에 대한 `SHOW_PRIV` 권한을 가진 것으로 간주합니다.
2. 매개변수 db_name을 지정하면 지정한 DB에 있는 모든 동적 파티션 테이블의 상태가 표시되며, 사용자는 해당 DB에 대한 `SHOW_PRIV` 권한이 있어야 합니다.
