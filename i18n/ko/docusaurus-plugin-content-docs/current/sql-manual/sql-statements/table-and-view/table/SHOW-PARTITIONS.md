## 설명 {#descriptions}

이 문은 파티션 정보를 표시하는 데 사용됩니다. Internal catalog와 Hive Catalog를 모두 지원합니다.

`Hive Catalog`의 경우:

다단계 파티션을 포함한 모든 파티션을 반환할 수 있습니다.
## 구문 {#syntax}

```sql
SHOW [ TEMPORARY ] PARTITIONS
    FROM [ <db_name>. ] <table_name>
    [ <where_clause> ]
    [ ORDER BY <order_by_key> ]
    [ LIMIT <limit_rows> ];
```

## 필수 매개변수 {#required-parameters}
**1. `<table_name>`**

파티션 정보를 조회할 테이블의 이름을 지정해야 합니다.


## 선택적 매개변수 {#optional-parameters}
**1. `TEMPORARY`**

임시 파티션 정보를 쿼리할지 여부입니다.

**2. `<db_name>`**

파티션 정보를 조회할 데이터베이스의 이름을 지정해야 합니다.

**3. `<where_clause>`**

필터 조건입니다. PartitionId, PartitionName, State, Buckets, ReplicationNum, LastConsistencyCheckTime 등의 열을 기준으로 필터링할 수 있습니다.

다음 사항에 유의하세요.
1. 현재 WHERE 절은 문자열 타입인 PartitionName과 State에 대해 `=`, `!=`, `like` 연산자만 지원합니다. 다른 열에는 `=`, `!=`, `>`, `<`, `>=`, `<=` 등의 연산자만 지원합니다.
2. WHERE 절에서 위 연산자를 사용할 때는 열 이름을 왼쪽에 배치해야 합니다.
3. WHERE 절에는 `AND`를 사용할 수 있습니다.

**4. `<order_by_key>`**

정렬 조건입니다. PartitionId, PartitionName, State, Buckets, ReplicationNum, LastConsistencyCheckTime 등의 열을 기준으로 정렬할 수 있습니다.

**5. `<limit_rows>`**

반환할 최대 행 수입니다.

## 반환 값 {#return-value}
| 열                       | 데이터 타입 | 설명                                                                                                                                                          |
|--------------------------|----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PartitionId              | bigint   | 파티션 ID                                                                                                                                                     |
| PartitionName            | varchar  | 파티션 이름                                                                                                                                                   |
| VisibleVersion           | int      | 이 파티션에 속한 태블릿의 최대 VisibleVersion.                                                                                                                  |
| VisibleVersionTime       | datetime | 이 파티션의 가장 최근 VisibleVersion 시간.                                                                                                                     |
| State                    | varchar  | 이 파티션의 상태                                                                                                                                              |
| PartitionKey             | datetime | 이 파티션의 파티션 키                                                                                                                                         |
| Range                    | datetime | 이 파티션의 범위                                                                                                                                              |
| DistributionKey          | varchar  | 이 파티션의 분산 키                                                                                                                                           |
| Buckets                  | int      | 이 파티션의 버킷 수                                                                                                                                           |
| ReplicationNum           | int      | 이 파티션의 복제본 수                                                                                                                                         |
| StorageMedium            | varchar  | 이 파티션의 스토리지 매체                                                                                                                                      |
| CooldownTime             | datetime | 이 파티션의 쿨다운 시간. 핫/콜드 분리를 사용하지 않는 경우 이 필드의 값은 [9999-12-31 23:59:59]이며, 항상 핫 데이터임을 의미합니다.                              |
| RemoteStoragePolicy      | varchar  | 이 파티션의 원격 스토리지 정책.                                                                                                                                |
| LastConsistencyCheckTime | datetime | 이 파티션의 마지막 파티션 일관성 검사 시간.                                                                                                                     |
| DataSize                 | int      | 이 파티션의 데이터 크기.                                                                                                                                      |
| IsInMemory               | boolean  | 인메모리 파티션인지 여부. 기본값은 false입니다.                                                                                                                 |
| ReplicaAllocation        | varchar  | 이 파티션의 복제본 배치 전략.                                                                                                                                  |
| IsMutable                | boolean  | 파티션의 변경 가능 여부. 기본값은 true입니다.                                                                                                                   |
| SyncWithBaseTables       | boolean  | 파티션이 기본 테이블의 데이터와 동기화되어 있는지 여부.                                                                                                          |
| UnsyncTables             | varchar  | 해당 파티션이 동기화되지 않은 테이블의 파티션인지 여부.                                                                                                          |


## 접근 제어 요구 사항 {#access-control-requirements}
조회할 테이블에 대한 SHOW 권한이 필요합니다.
