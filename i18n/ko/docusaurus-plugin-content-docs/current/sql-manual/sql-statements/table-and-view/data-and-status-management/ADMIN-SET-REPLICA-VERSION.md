## 설명 {#description}

이 문은 지정된 복제본의 버전, 마지막 성공 버전 및 마지막 실패 버전을 수동으로 설정하는 데 사용됩니다. 주로 시스템에 문제가 발생했을 때 비정상 상태의 복제본을 복구하는 데 사용됩니다.

## 구문 {#syntax}

```sql
ADMIN SET REPLICA VERSION PROPERTIES ("<key>"="<value>" [,...])
```

## 필수 매개변수 {#required-parameters}

** 1. `"<key>"="<value>"`**

| 키           | 값 유형    | 설명                                                             |
|--------------|------------|------------------------------------------------------------------|
| `tablet_id`  | Int        | 복제본 버전을 수정할 tablet의 ID입니다. |
| `backend_id` | Int        | 복제본이 있는 BE 노드의 ID입니다.              |


## 선택적 매개변수 {#optional-parameters}

** 1. `"<key>"="<value>"`**

| 키                     | 값 유형    | 설명                                             |
|------------------------|------------|--------------------------------------------------|
| `version`              | Int        | 복제본의 버전을 설정합니다.                 |
| `last_success_version` | Int        | 복제본의 마지막 성공 버전을 설정합니다. |
| `last_failed_version`  | Int        | 복제본의 마지막 실패 버전을 설정합니다.     |


**주의 사항**

- 지정된 복제본이 존재하지 않으면 작업은 무시됩니다.
-
- 이 값을 수정하면 이후 데이터 읽기 및 쓰기 작업이 실패하여 데이터 불일치가 발생할 수 있습니다. 신중하게 진행하세요!

- 수정하기 전에 원래 값을 기록해 두세요. 변경 후에는 테이블 읽기 및 쓰기 작업이 정상적으로 수행되는지 확인하세요. 실패하면 원래 값으로 되돌리세요. 단, 원래 값으로 되돌리는 작업도 실패할 수 있습니다.

- 현재 데이터를 쓰고 있는 tablet에는 이 작업을 수행하지 마세요!


## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한을 보유해야 합니다.

| 권한       | 객체     | 설명                                                                                                                             |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------|
| Admin_priv | 데이터베이스 | 테이블 및 파티션 관리, 시스템 수준 명령 실행 등 데이터베이스 관리 작업을 수행하는 데 필요합니다. |

## 예제 {#examples}

- BE 10001에 있는 tablet 10003의 복제본에서 실패 상태 플래그 지우기

  ```sql
  ADMIN SET REPLICA VERSION PROPERTIES("tablet_id" = "10003", "backend_id" = "10001", "last_failed_version" = "-1");
  ```

- BE 10001에 있는 tablet 10003의 복제본 버전을 1004로 설정하기

  ```sql
  ADMIN SET REPLICA VERSION PROPERTIES("tablet_id" = "10003", "backend_id" = "10001", "version" = "1004");
  ```
