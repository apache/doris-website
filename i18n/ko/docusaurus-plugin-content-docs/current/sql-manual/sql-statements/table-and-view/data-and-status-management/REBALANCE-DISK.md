## 설명 {#description}

`REBALANCE DISK` 문은 Backend (BE) 노드의 데이터 분포를 최적화하는 데 사용됩니다. 이 문은 다음 기능을 제공합니다:

- 지정된 BE 노드의 데이터 균형을 조정할 수 있습니다.
- 클러스터 전체의 모든 BE 노드에 걸쳐 데이터 균형을 조정할 수 있습니다.
- 클러스터의 전반적인 균형 상태와 관계없이 지정된 노드의 데이터 균형 조정을 우선 처리합니다.

## 구문 {#syntax}

```sql
ADMIN REBALANCE DISK [ ON ( "<host>:<port>" [, ... ] ) ];
```

## 선택적 매개변수 {#optional-parameters}

**1. `"<host>:<port>"`**

> 균형 조정이 필요한 BE 노드 목록을 지정합니다.
>
> 각 노드는 호스트 이름(또는 IP 주소)과 하트비트 포트로 구성됩니다.
>
> 이 매개변수를 지정하지 않으면 모든 BE 노드의 균형을 조정합니다.

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한을 보유해야 합니다:

| 권한            | 대상        | 비고                                          |
| :-------------- | :---------- | :-------------------------------------------- |
| ADMIN           | 시스템      | 이 명령을 실행하려면 사용자에게 ADMIN 권한이 있어야 합니다. |

## 사용 시 참고 사항 {#usage-notes}

- 이 명령의 기본 제한 시간은 24시간입니다. 이 시간이 지나면 시스템은 더 이상 지정된 BE의 디스크 데이터 균형 조정을 우선 처리하지 않습니다. 균형 조정을 계속하려면 명령을 다시 실행해야 합니다.
- 지정된 BE 노드의 디스크 데이터 균형 조정이 완료되면 해당 노드의 높은 우선순위 설정이 자동으로 해제됩니다.
- 클러스터가 불균형 상태인 경우에도 이 명령을 실행할 수 있습니다.

## 예제 {#examples}

- 클러스터의 모든 BE 노드에 걸쳐 데이터 균형 조정:

```sql
ADMIN REBALANCE DISK;
```

- 지정된 두 BE 노드의 데이터 균형 조정:

```sql
ADMIN REBALANCE DISK ON ("192.168.1.1:1234", "192.168.1.2:1234");
```
