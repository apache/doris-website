## 설명 {#description}

`REPAIR TABLE` 문은 지정된 테이블 또는 파티션의 복제본 복구 우선순위를 높이는 데 사용됩니다. 이 문은 다음 기능을 제공합니다.

- 테이블 전체의 모든 복제본을 복구할 수 있습니다.
- 지정된 파티션의 복제본을 복구할 수 있습니다.
- 높은 우선순위로 복제본 복구를 수행합니다.
- 복구 타임아웃 설정을 지원합니다.

## 구문 {#syntax}

```sql
ADMIN REPAIR TABLE <table_name> [ PARTITION (<partition_name> [, ...]) ];
```

## 필수 매개변수 {#required-parameters}

**1. `<table_name>`**

> 복구할 테이블의 이름을 지정합니다.
>
> 테이블 이름은 해당 데이터베이스 내에서 고유해야 합니다.

## 선택적 매개변수 {#optional-parameters}

**1. `PARTITION (<partition_name> [, ...])`**

> 복구할 파티션 이름 목록을 지정합니다.
>
> 이 매개변수를 지정하지 않으면 테이블 전체의 모든 파티션을 복구합니다.

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한을 보유해야 합니다.

| 권한            | 객체        | 참고 사항                                     |
| :-------------- | :---------- | :-------------------------------------------- |
| ADMIN           | 시스템      | 이 명령을 실행하려면 사용자에게 ADMIN 권한이 있어야 합니다. |

## 사용 시 참고 사항 {#usage-notes}

- 이 문은 시스템이 지정된 복제본의 복구를 높은 우선순위로 시도하도록 하지만, 복구 성공을 보장하지는 않습니다.
- 기본 타임아웃은 14,400초(4시간)로 설정되어 있습니다.
- 타임아웃이 지나면 시스템은 지정된 복제본의 복구를 더 이상 우선적으로 처리하지 않습니다.
- 복구 시간이 타임아웃을 초과하면 복구 프로세스를 계속하려면 명령을 다시 실행해야 합니다.
- 복구 진행 상황은 `SHOW REPLICA STATUS` 명령으로 모니터링할 수 있습니다.
- 이 명령은 시스템의 일반적인 복제본 복구 메커니즘에 영향을 주지 않으며, 지정된 테이블 또는 파티션의 복구 우선순위만 높입니다.

## 예제 {#examples}

- 테이블 전체의 모든 복제본 복구:

    ```sql
    ADMIN REPAIR TABLE tbl1;
    ```

- 지정된 파티션의 복제본 복구:

    ```sql
    ADMIN REPAIR TABLE tbl1 PARTITION (p1, p2);
    ```

- 복구 진행 상황 확인:

    ```sql
    SHOW REPLICA STATUS FROM tbl1;
    ```
