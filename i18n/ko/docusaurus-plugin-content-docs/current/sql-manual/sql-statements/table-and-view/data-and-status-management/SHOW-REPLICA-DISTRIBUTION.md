## 설명 {#description}

이 문은 테이블 또는 파티션의 복제본 상태 정보를 표시하는 데 사용됩니다.

## 구문 {#syntax}

```sql
SHOW REPLICA DISTRIBUTION FROM [ <database_name>.]<table_name> [<partition_list>] 
[where_clause]
```
각 항목의 구문은 다음과 같습니다.

```sql
partition_list
  : PARTITION (<partition_name>[ , ... ])
```

각 항목의 구문은 다음과 같습니다.

```sql
where_clause
: WHERE <output_column_name> = <value>
```

## 필수 매개변수 {#required-parameters}

**1. `<table_name>`**

> 테이블의 식별자(즉, 이름)로, 데이터베이스(Database) 내에서 고유해야 합니다.
>
> 식별자는 문자로 시작해야 하며(Unicode 이름 지원이 활성화된 경우 지원되는 언어의 모든 문자로 시작할 수 있음), 식별자 문자열 전체를 백틱으로 감싸지 않는 한 공백이나 특수 문자를 포함할 수 없습니다(예: My Object).
>
> 식별자에는 예약 키워드를 사용할 수 없습니다.
>
> 자세한 내용은 식별자 요구 사항 및 예약 키워드를 참조하세요.


## 선택적 매개변수 {#optional-parameters}

**1. `<db_name>`**

> 데이터베이스의 식별자(즉, 이름)로, 클러스터(Cluster) 내에서 고유해야 합니다.
>
> 식별자는 문자로 시작해야 하며(Unicode 이름 지원이 활성화된 경우 지원되는 언어의 모든 문자로 시작할 수 있음), 식별자 문자열 전체를 백틱으로 감싸지 않는 한 공백이나 특수 문자를 포함할 수 없습니다(예: My Object).
>
> 식별자에는 예약 키워드를 사용할 수 없습니다.
>
> 자세한 내용은 식별자 요구 사항 및 예약 키워드를 참조하세요.

**2. `<partition_list>`**

> 쉼표로 구분된 파티션 식별자(즉, 이름) 목록으로, 각 식별자는 테이블(Table) 내에서 고유해야 합니다.
>
> 식별자는 문자로 시작해야 하며(Unicode 이름 지원이 활성화된 경우 지원되는 언어의 모든 문자로 시작할 수 있음), 식별자 문자열 전체를 백틱으로 감싸지 않는 한 공백이나 특수 문자를 포함할 수 없습니다(예: My Object).
>
> 식별자에는 예약 키워드를 사용할 수 없습니다.
>
> 자세한 내용은 식별자 요구 사항 및 예약 키워드를 참조하세요.


## 반환 값 {#return-value}

| 열          | 데이터 유형 | 설명                                                                              |
|-------------|----------|-----------------------------------------------------------------------------------|
| BackendId   | Int      | 복제본이 위치한 BE(Backend) 노드의 ID입니다.                                       |
| ReplicaNum  | Int      | 이 BE 노드에 있는 복제본 수입니다.                                                 |
| ReplicaSize | Int      | 이 BE 노드의 모든 복제본이 차지하는 총 저장 공간 크기입니다(바이트 단위).           |
| NumGraph    | String   | 복제본 수의 비율을 > 기호로 시각화한 것입니다.                                     |
| NumPercent  | String   | 복제본 수의 비율을 백분율로 표시한 것입니다(예: 100.00%).                          |
| SizeGraph   | String   | 복제본 저장 공간 크기의 비율을 > 기호로 시각화한 것입니다.                         |
| SizePercent | String   | 복제본 저장 공간 크기의 비율을 백분율로 표시한 것입니다(예: 100.00%).              |
