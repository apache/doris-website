## 설명 {#description}

통계 수집 작업의 상태를 확인하는 데 사용하는 문입니다.

## 구문 {#syntax}

```SQL
SHOW [AUTO] ANALYZE [ <table_name> | <job_id> ]
    [ WHERE STATE = {"PENDING" | "RUNNING" | "FINISHED" | "FAILED"} ];
```

## 필수 매개변수 {#required-parameters}

**없음**

## 선택적 매개변수 {#optional-parameters}

**1. `AUTO`**

> 자동 작업의 정보를 표시합니다. 지정하지 않으면 기본적으로 수동 작업의 정보를 표시합니다.

**2. `<table_name>`**

> 테이블 이름입니다. 지정하면 해당 테이블의 작업 정보를 확인할 수 있습니다. 지정하지 않으면 기본적으로 모든 테이블의 작업 정보를 반환합니다.

**3. `<job_id>`**

> 통계 수집 작업 ID입니다. ANALYZE로 비동기 수집을 수행할 때 얻을 수 있습니다. ID를 지정하지 않으면 이 명령은 모든 작업의 정보를 반환합니다.

**4. `WHERE STATE = {"PENDING" | "RUNNING" | "FINISHED" | "FAILED"}`**

> 작업 상태를 필터링하는 조건입니다. 지정하지 않으면 기본적으로 모든 상태의 작업 정보를 표시합니다.

## 반환 값 {#return-value}

| 열 | 설명           |
| -- |--------------|
| job_id | 고유한 통계 수집 작업 ID           |
| catalog_name |   Catalog 이름         |
| db_name | 데이터베이스 이름           |
| tbl_name | 테이블 이름         |
| col_name | 열 이름 목록           |
| job_type |   작업 유형           |
| analysis_type |  분석 유형           |
| message | 오류 메시지         |
| last_exec_time_in_ms | 마지막 통계 수집 시간           |
| state |   작업 상태          |
| progress | 작업 진행 상황           |
| schedule_type | 스케줄 유형         |
| start_time | 작업 시작 시간          |
| end_time |   작업 종료 시간           |
| priority | 작업 우선순위           |
| enable_partition | 파티션 수집 활성화 플래그         |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL을 실행하는 사용자는 최소한 다음 권한이 있어야 합니다.

| 권한 | 객체 | 설명                                    |
|:--------------| :------------- |:------------------------------------------------|
| SELECT_PRIV   | 테이블    | SHOW 실행 시 조회 대상 테이블에 대한 SELECT_PRIV 권한이 필요합니다. |
