## 설명 {#description}

지정한 Catalog의 속성을 표시합니다.

## 속성 마스킹 {#property-masking}

공통 마스킹 정책은 Doris 4.2.0과 5.0 이상 버전에 도입될 예정입니다. 민감한 속성은 `*XXX`로 표시되며, 일부 내부 속성은 생략됩니다. 명시적인 JDBC 연결 문자열은 전체가 숨겨지고, 일반 URI는 값에 따라 민감한 부분이 제거됩니다. [Catalog 속성 마스킹 규칙](../../../lakehouse/catalog-property-masking.md)을 참조하세요. 아래 예시는 이 정책을 적용한 것으로, 4.0, 4.1 또는 3.x의 동작을 설명하지 않습니다.

## 구문 {#syntax}

```sql
SHOW CATALOG <catalog_name>
```


## 필수 매개변수 {#required-parameters}

**1. `<catalog_name>`**

표시할 Catalog의 이름입니다.

## 반환값 {#return-value}

| 열 이름 | 설명                   |
|-------------|-------------------------------|
| Key         | 설정 속성의 이름입니다.  |
| Value       | 설정 속성의 값입니다. |

## 접근 권한 요구 사항 {#access-control-requirements}

| 권한                                                                                    | 객체  | 설명                                     |
|:---------------------------------------------------------------------------------------------|:--------|:------------------------------------------|
| ADMIN_PRIV / SELECT_PRIV / LOAD_PRIV / ALTER_PRIV / CREATE_PRIV / SHOW_VIEW_PRIV / DROP_PRIV | Catalog | 위 권한 중 하나가 필요합니다. |
