## 설명 {#description}

이 문은 데이터베이스에 생성된 파일을 표시하는 데 사용됩니다.

## 구문 {#syntax}

```sql
SHOW FILE { [ FROM | IN ] <database_name>}
```

## 선택적 매개변수 {#optional-parameters}

**1. `<database_name>`**

> 파일이 속한 데이터베이스를 지정합니다. 지정하지 않으면 현재 세션의 데이터베이스를 사용합니다.

## 반환 값 {#return-value}

| 열          | 설명                            |
|:------------|:--------------------------------|
| `Id`        | 전역적으로 고유한 파일 식별자    |
| `DbName`    | 파일이 속한 데이터베이스 이름   |
| `Catalog`   | 사용자 정의 분류                |
| `FileName`  | 파일 이름                       |
| `FileSize`  | 파일 크기(바이트)               |
| `IsContent` | 콘텐츠 존재 여부 플래그         |
| `MD5`       | 파일의 MD5 체크섬               |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한을 보유해야 합니다.

| 권한         | 대상          | 비고                                                                                                       |
|:-------------|:------------|:------------------------------------------------------------------------------------------------------------|
| `ADMIN_PRIV` | 사용자 / 역할 | 이 명령을 실행하려면 사용자 또는 역할에 파일이 저장된 데이터베이스에 대한 접근 권한이 있어야 합니다        |

## 예시 {#example}

- 현재 세션의 데이터베이스에 업로드된 파일 조회

   ```sql
   SHOW FILE;
   ```
   ```text
   +-------+--------+----------+--------------------------+----------+-----------+----------------------------------+
   | Id    | DbName | Catalog  | FileName                 | FileSize | IsContent | MD5                              |
   +-------+--------+----------+--------------------------+----------+-----------+----------------------------------+
   | 12006 | testdb | doris_be | doris_be_metadata_layout | 89349    | true      | 9a3f68160b4106b0e923a0aa2fc05599 |
   +-------+--------+----------+--------------------------+----------+-----------+----------------------------------+
   ```

- 지정된 데이터베이스에 업로드된 파일 조회

   ```sql
   SHOW FILE FROM example_db;
   ```
   ```text
   +-------+------------+----------+--------------------------+----------+-----------+----------------------------------+
   | Id    | DbName     | Catalog  | FileName                 | FileSize | IsContent | MD5                              |
   +-------+------------+----------+--------------------------+----------+-----------+----------------------------------+
   | 12007 | example_db | doris_fe | doris_fe_metadata_layout | 569373   | true      | 10385505d3c0d03f085fea6f8d51adfa |
   | 12008 | example_db | doris_be | doris_be_metadata_layout | 89349    | true      | 9a3f68160b4106b0e923a0aa2fc05599 |
   +-------+------------+----------+--------------------------+----------+-----------+----------------------------------+
   ```
