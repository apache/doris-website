## 설명 {#description}

`SHOW CREATE USER` 문은 데이터베이스 시스템에서 사용자 생성 구문을 표시하는 데 사용됩니다. 이를 통해 관리자는 계정을 더 효율적으로 관리할 수 있습니다.

## 구문 {#syntax}

```sql
SHOW CREATE USER '<user_identity>'
```

## 반환 값 {#return-value}

| 열         | 설명         |
|:------------|:------------|
| 사용자 식별자  | 지정한 사용자의 식별자 |
| 생성 구문  | 지정한 사용자의 생성 구문 |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한을 보유해야 합니다.

| 권한 | 객체 | 참고 사항                |
| :---------------- | :------------- | :---------------------------- |
| ADMIN_PRIV        | 사용자 또는 역할    | 이 `SHOW CREATE USER` 작업은 `ADMIN_PRIV` 권한이 있는 사용자 또는 역할만 수행할 수 있습니다. |


## 예제 {#examples}

지정한 사용자의 생성 구문을 확인합니다.


```sql
SHOW CREATE USER '<user_identity>'
```

```text
+---------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| User Identity | Create Stmt                                                                                                                                                                     |

| xxxxxxx       | CREATE USER 'xxxxxxx'@'%' IDENTIFIED BY ***  PASSWORD_HISTORY DEFAULT PASSWORD_EXPIRE INTERVAL 864000 SECOND FAILED_LOGIN_ATTEMPTS 3 PASSWORD_LOCK_TIME 86400 SECOND COMMENT "" |
+---------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
```
