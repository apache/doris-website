## 설명 {#description}

사용자가 실행 중인 스레드를 표시합니다.
이 명령은 현재 FE의 연결 정보만 표시할 수 있습니다.
전체 클러스터의 연결 정보를 보려면 다음 세션 변수를 설정해야 합니다:
```
SET SHOW_ALL_FE_CONNECTION = TRUE;
```

## 구문 {#syntax}

```sql
SHOW [FULL] PROCESSLIST
```

## 선택적 매개변수 {#optional-parameters}

**1. `FULL`**

> 다른 사용자의 연결 정보를 표시할지 여부를 지정합니다.

## 반환 값 {#return-value}

| 열               | 설명                                   |
|------------------|--------------------------------------|
| CurrentConnected | 현재 사용 중인 연결인지 여부                              |
| Id               | 이 스레드의 고유 식별자                            |
| User             | 이 스레드를 시작한 사용자                            |
| Host             | 요청을 보내는 클라이언트의 IP 주소와 포트 번호                |
| LoginTime        | 연결이 설정된 시간                              |
| Catalog          | 명령이 현재 실행되는 데이터 디렉터리                    |
| Db               | 명령이 실행되는 데이터베이스. 데이터베이스를 지정하지 않으면 값은 NULL입니다. |
| Command          | 스레드가 현재 실행 중인 명령                         |
| Time             | 이전 명령이 제출된 시점부터 현재 상태까지 경과한 시간(초)                 |
| State            | 스레드의 상태                                |
| QueryId          | 현재 쿼리 문의 ID                           |
| Info             | 일반적으로 스레드가 실행하는 문이 기록되며, 기본적으로 처음 100자만 표시됩니다.         |

주요 Command 유형은 다음과 같습니다:

| 열 | 설명 |
| -- | -- |
| Query | 스레드가 문을 실행 중입니다. |
| Sleep | 클라이언트가 실행할 문을 보내기를 기다리고 있습니다. |
| Quit | 스레드가 종료 중입니다. |
| Kill | kill 문을 실행 중입니다. |

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한을 보유해야 합니다:

| 권한         | 객체      | 참고 사항                  |
|:-------------|:----------|:---------------------------|
| ADMIN_PRIV        | DATABASE  | 다른 사용자의 연결 정보를 보려면 ADMIN 권한이 필요합니다. |
