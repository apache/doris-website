## 설명 {#description}

이 문은 현재 생성된 웨어하우스를 조회하는 데 사용됩니다

## 구문 {#syntax}

```sql
SHOW REPOSITORIES;
```

## 반환 값 {#return-value}

| 필드           | 설명                              |
|-----------------|------------------------------------------|
| **RepoId**      | 저장소의 고유 식별자(ID) |
| **RepoName**    | 저장소 이름               |
| **CreateTime**  | 저장소 생성 시간      |
| **IsReadOnly**  | 저장소의 읽기 전용 여부. `false`는 읽기 전용이 아님을, `true`는 읽기 전용임을 의미합니다 |
| **Location**    | 저장소에서 데이터 백업에 사용하는 루트 디렉터리 |
| **Broker**      | -                                        |
| **Type**        | 저장소 유형. 현재 S3 및 HDFS를 지원합니다 |
| **ErrMsg**      | 저장소의 오류 메시지. 오류가 발생하지 않으면 일반적으로 `NULL`입니다 |


## 예제 {#examples}

생성된 저장소 조회:

```sql
SHOW REPOSITORIES;
```
```text
+--------+--------------+---------------------+------------+----------+--------+------+--------+
| RepoId | RepoName     | CreateTime          | IsReadOnly | Location | Broker | Type | ErrMsg |
+--------+--------------+---------------------+------------+----------+--------+------+--------+
| 43411  | example_repo | 2025-01-17 18:50:47 | false      | s3://rep1  | -      | S3   | NULL   |
+--------+--------------+---------------------+------------+----------+--------+------+--------+
```
