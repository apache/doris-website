## 설명 {#description}

과거 데이터 적재 작업의 레이블을 수동으로 정리하는 데 사용합니다. 정리한 레이블은 다시 사용할 수 있습니다.
프로그램에서 설정한 자동 데이터 적재 작업에 주로 사용합니다. 작업을 반복 실행할 때는 적재 작업의 레이블을 고정된 문자열로 설정합니다.
각 적재 작업을 시작하기 전에 이 문을 실행하여 레이블을 정리합니다.

## 구문 {#syntax}

```sql
CLEAN LABEL [ <label> ] FROM <db_name>;
```

## 필수 매개변수 {#required-parameters}

**1. `<db_name>`**  
  레이블이 속한 데이터베이스의 이름입니다.

## 선택적 매개변수 {#optional-parameters}

**1. `<label>`**    
  정리할 레이블입니다. 생략하면 기본적으로 현재 데이터베이스의 모든 레이블을 정리합니다.

## 접근 제어 요구 사항 {#access-control-requirements}

이 SQL 명령을 실행하는 사용자는 최소한 다음 권한을 보유해야 합니다.

| 권한                  | 객체       | 설명                                          |
|:----------------------|:-----------|:----------------------------------------------|
| ALTER_PRIV            | 데이터베이스 | 데이터베이스에 대한 수정 권한이 필요합니다. |


## 예제 {#examples}

- 데이터베이스 db1에서 label1 레이블 정리

   ```sql
   CLEAN LABEL label1 FROM db1;
   ```

- 데이터베이스 db1에서 모든 레이블 정리

   ```sql
   CLEAN LABEL FROM db1;
   ```
