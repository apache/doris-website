## 설명 {#description}

이 테이블 함수는 backends 임시 테이블을 생성하며, 현재 doris 클러스터의 BE 노드 정보를 확인할 수 있습니다.

## 구문 {#syntax}
```sql
BACKENDS()
```

## 접근 제어 요구 사항 {#access-control-requirements}

| 권한  | 대상 | 참고 |
| :--------- |:-------|:------|
| SELECT_PRIV | internal.information_schema | 모든 사용자는 기본적으로 이 데이터베이스에 대한 권한이 있습니다. |

## 반환 값 {#return-value}
| 필드                       | 설명 |
|-----------------------------|------------------------------------------------------------------------------------------------------------------------|
| **BackendId**               | 각 백엔드 노드의 고유 식별자입니다. |
| **Host**                    | 백엔드 노드의 IP 주소 또는 호스트 이름입니다. |
| **HeartbeatPort**           | 상태 확인(하트비트)에 사용하는 포트입니다. |
| **BePort**                  | 쿼리 실행을 위해 백엔드 노드와 클러스터 간 통신에 사용하는 포트입니다. |
| **HttpPort**                | 백엔드 노드의 HTTP 포트입니다. |
| **BrpcPort**                | BRPC 통신에 사용하는 포트입니다. |
| **ArrowFlightSqlPort**      | Arrow Flight SQL 포트입니다(고성능 데이터 전송을 위해 Apache Arrow와 연동할 때 사용). |
| **LastStartTime**           | 백엔드 노드가 마지막으로 시작된 시각의 타임스탬프입니다. |
| **LastHeartbeat**           | 백엔드 노드에서 마지막으로 수신한 하트비트의 타임스탬프입니다. |
| **Alive**                   | 백엔드 노드의 활성 여부입니다(true/false). |
| **SystemDecommissioned**    | 백엔드 노드의 서비스 해제 여부입니다. |
| **TabletNum**               | 백엔드 노드가 관리하는 태블릿 수입니다. |
| **DataUsedCapacity**        | 백엔드 노드가 사용하는 디스크 공간입니다(MB 단위). |
| **TrashUsedCapacity**       | 휴지통이 사용하는 디스크 공간입니다(MB 단위). |
| **AvailCapacity**           | 백엔드 노드에서 사용 가능한 디스크 공간입니다. |
| **TotalCapacity**           | 백엔드 노드의 전체 디스크 용량입니다. |
| **UsedPct**                 | 백엔드 노드의 디스크 용량 사용률입니다. |
| **MaxDiskUsedPct**          | 모든 태블릿 중 최대 디스크 사용률입니다. |
| **RemoteUsedCapacity**      | 원격 스토리지가 사용하는 디스크 공간입니다(해당하는 경우). |
| **Tag**                     | 백엔드 노드와 연결된 태그로, 일반적으로 위치 등의 분류에 사용합니다. |
| **ErrMsg**                  | 백엔드 노드가 보고한 오류 메시지입니다. |
| **Version**                 | 백엔드 노드의 버전입니다. |
| **Status**                  | 태블릿의 성공/실패 보고, 데이터 적재 시간, 쿼리 상태를 포함한 백엔드 노드의 현재 상태입니다. |
| **HeartbeatFailureCounter** | 하트비트 실패가 발생한 경우 그 횟수입니다. |
| **NodeRole**                | 백엔드 노드의 역할입니다. 예를 들어 `mix`는 노드가 스토리지와 쿼리 처리를 모두 담당함을 의미합니다. |
| **CpuCores**                | 백엔드 노드의 CPU 코어 수입니다. |
| **Memory**                  | 백엔드 노드의 메모리 용량입니다. |
