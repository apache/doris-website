### 기능 {#function}

`ARRAY_SUM` 함수는 배열에 있는 모든 숫자형 요소의 합을 계산합니다.

## 구문 {#syntax}

```SQL
ARRAY_SUM(ARRAY<T>)
```

## 매개변수 {#parameters}

`ARRAY<T>`: **숫자형** 요소가 포함된 배열입니다.

## 반환값 {#return-value}

- 배열에서 `NULL`이 아닌 모든 요소의 합을 반환합니다.

    - 모든 요소가 `NULL`이면 `NULL`을 반환합니다.

## 사용 시 참고 사항 {#usage-notes}

1. 요소의 합을 계산할 때는 `+` 연산자를 사용합니다.

2. `NULL`인 요소는 자동으로 무시됩니다.

3. 배열에 문자열과 같이 숫자형이 아닌 요소가 포함되어 있으면 런타임 오류가 발생합니다.

## 예제 {#examples}

1. 간단한 예제

    ```SQL
    SELECT ARRAY_SUM([1, 2, 3, 4]);
    +-------------------------+
    | ARRAY_SUM([1, 2, 3, 4]) |
    +-------------------------+
    |                      10 |
    +-------------------------+
    ```

2. 배열의 `NULL` 값 처리

    ```SQL
    SELECT ARRAY_SUM([1, NULL, 3]); 
    +-------------------------+
    | ARRAY_SUM([1, NULL, 3]) |
    +-------------------------+
    |                       4 |
    +-------------------------+

    SELECT ARRAY_SUM(NULL);
    +-----------------+
    | ARRAY_SUM(NULL) |
    +-----------------+
    |            NULL |
    +-----------------+

    SELECT ARRAY_SUM([NULL, NULL]); 
    +-------------------------+
    | ARRAY_SUM([NULL, NULL]) |
    +-------------------------+
    |                    NULL |
    +-------------------------+
    ```
