## array_popfront {#array_popfront}

<version since="2.0.0">

</version>

## 설명 {#description}

배열에서 첫 번째 요소를 제거합니다. 첫 번째 요소를 제외한 원래 배열의 모든 요소를 포함하는 새 배열을 반환합니다.

## 구문 {#syntax}

```sql
array_popfront(ARRAY<T> arr)
```

### 매개변수 {#parameters}

- `arr`：ARRAY<T> 타입, 첫 번째 요소를 제거할 배열

**지원되는 T의 타입:**
- 숫자 타입: TINYINT, SMALLINT, INT, BIGINT, LARGEINT, FLOAT, DOUBLE, DECIMAL
- 문자열 타입: CHAR, VARCHAR, STRING
- 날짜 및 시간 타입: DATE, DATETIME, DATEV2, DATETIMEV2, TIMESTAMP_NS
- 불리언 타입: BOOLEAN
- IP 타입: IPV4, IPV6
- UUID: [UUID](../../../basic-element/sql-data-types/uuid.md)
- 복합 타입: ARRAY, MAP, STRUCT

### 반환 값 {#return-value}

반환 타입: ARRAY<T>

반환 값의 의미:
- 첫 번째 요소를 제외한 원래 배열의 모든 요소를 포함하는 새 배열을 반환합니다
- NULL: 입력 배열이 NULL인 경우

사용 시 참고 사항:
- 배열에서 첫 번째 요소를 제거하고 나머지 요소를 반환합니다
- 빈 배열은 빈 배열을 반환하며, 요소가 하나뿐인 배열도 빈 배열을 반환합니다
- 배열 요소에 null 값이 있는 경우: null 요소도 정상적으로 처리됩니다

**쿼리 예제:**

문자열 배열에서 첫 번째 요소 제거:
```sql
SELECT array_popfront(['apple', 'banana', 'cherry', 'date']);
+----------------------------------------------------+
| array_popfront(['apple', 'banana', 'cherry', 'date']) |
+----------------------------------------------------+
| ["banana", "cherry", "date"]                       |
+----------------------------------------------------+
```

null 값이 포함된 배열에서 첫 번째 요소 제거:
```sql
SELECT array_popfront([1, null, 3, null, 5]);
+------------------------------------------+
| array_popfront([1, null, 3, null, 5])   |
+------------------------------------------+
| [null, 3, null, 5]                      |
+------------------------------------------+
```

요소가 하나뿐인 배열은 빈 배열을 반환합니다:
```sql
SELECT array_popfront([42]);
+------------------------+
| array_popfront([42])   |
+------------------------+
| []                     |
+------------------------+
```

빈 배열은 빈 배열을 반환합니다:
```sql
SELECT array_popfront([]);
+------------------------+
| array_popfront([])     |
+------------------------+
| []                     |
+------------------------+
```

NULL 배열은 NULL을 반환합니다:
```sql
SELECT array_popfront(NULL);
+------------------------+
| array_popfront(NULL)   |
+------------------------+
| NULL                   |
+------------------------+
```

IP 주소 배열에서 첫 번째 요소 제거:
```sql
SELECT array_popfront(CAST(['192.168.1.1', '192.168.1.2', '192.168.1.3'] AS ARRAY<IPV4>));
+----------------------------------------------------------------------------------+
| array_popfront(CAST(['192.168.1.1', '192.168.1.2', '192.168.1.3'] AS ARRAY<IPV4>)) |
+----------------------------------------------------------------------------------+
| ["192.168.1.2", "192.168.1.3"]                                                   |
+----------------------------------------------------------------------------------+
```

중첩 배열에서 첫 번째 요소 제거:
```sql
SELECT array_popfront([[1, 2], [3, 4], [5, 6]]);
+------------------------------------------+
| array_popfront([[1, 2], [3, 4], [5, 6]]) |
+------------------------------------------+
| [[3, 4], [5, 6]]                         |
+------------------------------------------+
```

MAP 배열에서 첫 번째 요소 제거:
```sql
SELECT array_popfront([{'name':'Alice','age':20}, {'name':'Bob','age':30}, {'name':'Charlie','age':40}]);
+---------------------------------------------------------------------------------------------------+
| array_popfront([{'name':'Alice','age':20}, {'name':'Bob','age':30}, {'name':'Charlie','age':40}]) |
+---------------------------------------------------------------------------------------------------+
| [{"name":"Bob", "age":"30"}, {"name":"Charlie", "age":"40"}]                                      |
+---------------------------------------------------------------------------------------------------+
```

STRUCT 배열에서 첫 번째 요소 제거:
```sql
SELECT array_popfront(array(named_struct('name','Alice','age',20), named_struct('name','Bob','age',30), named_struct('name','Charlie','age',40)));
+-------------------------------------------------------------------------------------------------------------------------------------------+
| array_popfront(array(named_struct('name','Alice','age',20), named_struct('name','Bob','age',30), named_struct('name','Charlie','age',40))) |
+-------------------------------------------------------------------------------------------------------------------------------------------+
| [{"name":"Bob", "age":30}, {"name":"Charlie", "age":40}]                                                                                  |
+-------------------------------------------------------------------------------------------------------------------------------------------+
```

### 키워드 {#keywords}

ARRAY, POPFRONT, ARRAY_POPFRONT
