## 설명 {#description}

`JSON_OBJECT_FLATTEN`은 중첩된 JSON 객체를 각 리프 값의 경로를 점으로 연결한 키를 갖는 단일 수준의 JSON 객체로 평탄화합니다. NiFi FlattenJson의 "keep-arrays" 동작 방식을 따릅니다. 객체만 재귀적으로 탐색하며, 배열, 스칼라, null, 빈 객체는 더 이상 탐색하지 않고 리프 값으로 유지합니다.

최상위 입력이 객체가 아닌 경우(예: 스칼라, 배열 또는 `null`)에는 입력을 그대로 반환합니다.

## 구문 {#syntax}

```sql
JSON_OBJECT_FLATTEN(<json_value>)
```

## 매개변수 {#parameters}

**`<json_value>`** - 평탄화할 JSON 값입니다. JSON 타입이어야 합니다.

## 반환 값 {#return-value}

JSON 값을 반환합니다:

- 입력이 중첩된 JSON 객체이면 각 리프 값의 경로를 점으로 연결한 키를 갖는 단일 수준의 JSON 객체를 반환합니다.
- 입력이 객체가 아니면(스칼라, 배열 또는 null) 입력을 그대로 반환합니다.
- 입력이 `NULL`이면 `NULL`을 반환합니다.

## 예제 {#examples}

### 기본적인 중첩 객체 평탄화 {#basic-nested-object-flattening}

```sql
SELECT json_object_flatten('{"a":{"b":2}}');
```

```text
+--------------------------------------+
| json_object_flatten('{"a":{"b":2}}') |
+--------------------------------------+
| {"a.b":2}                            |
+--------------------------------------+
```

### 깊게 중첩된 객체 {#deeply-nested-object}

```sql
SELECT json_object_flatten('{"a":{"b":{"c":3}}}');
```

```text
+--------------------------------------------+
| json_object_flatten('{"a":{"b":{"c":3}}}') |
+--------------------------------------------+
| {"a.b.c":3}                                |
+--------------------------------------------+
```

### 이미 평탄화된 객체 {#already-flat-object}

```sql
SELECT json_object_flatten('{"a":1,"b":"hi"}');
```

```text
+-----------------------------------------+
| json_object_flatten('{"a":1,"b":"hi"}') |
+-----------------------------------------+
| {"a":1,"b":"hi"}                        |
+-----------------------------------------+
```

### 배열을 분해하지 않고 리프 값으로 유지 {#arrays-preserved-as-opaque-leaves}

```sql
SELECT json_object_flatten('{"a":[{"b":1},{"b":2}]}');
```

```text
+------------------------------------------------+
| json_object_flatten('{"a":[{"b":1},{"b":2}]}') |
+------------------------------------------------+
| {"a":[{"b":1},{"b":2}]}                        |
+------------------------------------------------+
```

```sql
SELECT json_object_flatten('{"a":{"b":[1,2,3]}}');
```

```text
+--------------------------------------------+
| json_object_flatten('{"a":{"b":[1,2,3]}}') |
+--------------------------------------------+
| {"a.b":[1,2,3]}                            |
+--------------------------------------------+
```

### 객체가 아닌 최상위 값은 그대로 반환 {#top-level-non-object-values-pass-through-unchanged}

```sql
SELECT json_object_flatten('42');
```

```text
+---------------------------+
| json_object_flatten('42') |
+---------------------------+
| 42                        |
+---------------------------+
```

```sql
SELECT json_object_flatten('[1,2,{"x":3}]');
```

```text
+--------------------------------------+
| json_object_flatten('[1,2,{"x":3}]') |
+--------------------------------------+
| [1,2,{"x":3}]                        |
+--------------------------------------+
```

### NULL 입력 {#null-input}

```sql
SELECT json_object_flatten(NULL);
```

```text
+---------------------------+
| json_object_flatten(NULL) |
+---------------------------+
| NULL                      |
+---------------------------+
```

### 스칼라, 배열, 하위 객체가 혼합된 중첩 객체 {#mixed-nested-object-with-scalars-arrays-and-sub-objects}

```sql
SELECT json_object_flatten('{"x":{"s":1,"a":[1,2],"o":{"k":"v"}}}');
```

```text
+--------------------------------------------------------------+
| json_object_flatten('{"x":{"s":1,"a":[1,2],"o":{"k":"v"}}}') |
+--------------------------------------------------------------+
| {"x.s":1,"x.a":[1,2],"x.o.k":"v"}                            |
+--------------------------------------------------------------+
```
