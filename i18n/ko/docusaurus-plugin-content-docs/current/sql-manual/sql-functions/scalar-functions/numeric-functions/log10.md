## 설명 {#description}

`x`의 밑이 `10`인 로그를 반환합니다.

## 별칭 {#alias}

- DLOG10

## 구문 {#syntax}

```sql
LOG10(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|-----------|------------|
| `<x>`   | 진수는 0보다 커야 합니다 |

## 반환값 {#return-value}

부동 소수점 수를 반환합니다. 특수한 경우는 다음과 같습니다:

- x가 NULL이면 `NULL`을 반환합니다
- x가 NaN이면 NaN을 반환합니다

## 예제 {#example}

```sql
select log10(1);
```

```text
+--------------------------+
| log10(cast(1 as DOUBLE)) |
+--------------------------+
|                      0.0 |
+--------------------------+
```

```sql
select log10(10);
```

```text
+---------------------------+
| log10(cast(10 as DOUBLE)) |
+---------------------------+
|                       1.0 |
+---------------------------+
```

```sql
select log10(16);
```

```text
+---------------------------+
| log10(cast(16 as DOUBLE)) |
+---------------------------+
|        1.2041199826559248 |
+---------------------------+
```

```sql
select log10(NULL);
```

```text
+-------------+
| log10(NULL) |
+-------------+
|        NULL |
+-------------+
```

```sql
select log10(cast('nan' as double));
```

```text
+------------------------------+
| log10(cast('nan' as double)) |
+------------------------------+
|                          NaN |
+------------------------------+
```
