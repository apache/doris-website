## 설명 {#description}

부동 소수점 및 고정 소수점 형식의 소수를 지정된 자릿수로 내림하고, 내림한 부동 소수점 또는 고정 소수점 수를 반환합니다.

## 구문 {#syntax}

```sql
FLOOR(<a>[, <d>])
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<a>` | 내림할 값을 나타내는 부동 소수점(Double) 또는 고정 소수점(Decimal) 매개변수 |
| `<d>` | 내림할 대상 자릿수를 나타내는 선택적 정수 매개변수입니다. 양수는 다음 소수 자릿수로, 음수는 다음 소수 자릿수로 내림함을 의미하며, `0`은 정수로 내림함을 나타냅니다. 지정하지 않으면 `<d> = 0`과 같습니다. |

## 반환 값 {#return-value}

다음 규칙에 따라 `<a>` 이하인 수 중 내림하여 얻을 수 있는 가장 큰 수를 반환합니다.

`1/(10^d)` 단위로 내림합니다. 즉, 결과가 `1/(10^d)`로 나누어떨어지도록 합니다. `1/(10^d)`를 정확하게 표현할 수 없으면 해당 데이터 타입에서 표현할 수 있는 가장 가까운 수를 내림 단위로 사용합니다.

Decimal 타입의 입력값 `<a>`가 `Decimal(p, s)` 타입이라고 가정하면 반환 값은 다음과 같습니다.

- `Decimal(p, 0)`: `<d> <= 0`인 경우
- `Decimal(p, <d>)`: `0 < <d> <= s`인 경우
- `Decimal(p, s)`: `<d> > s`인 경우

입력 매개변수 중 하나라도 NULL이면 NULL을 반환합니다.

## 별칭 {#alias}

- DFLOOR

## 예제 {#examples}

```sql
select floor(123.456);
```

```text
+----------------+
| floor(123.456) |
+----------------+
|            123 |
+----------------+
```

```sql
select floor(123.456, 2);
```

```text
+-------------------+
| floor(123.456, 2) |
+-------------------+
|            123.45 |
+-------------------+
```

```sql
select floor(123.456, -2);
```

```text
+--------------------+
| floor(123.456, -2) |
+--------------------+
|                100 |
+--------------------+
```

```sql
select floor(123.45, 1), floor(123.45), floor(123.45, 0), floor(123.45, -1);
```

```text
+------------------+---------------+------------------+-------------------+
| floor(123.45, 1) | floor(123.45) | floor(123.45, 0) | floor(123.45, -1) |
+------------------+---------------+------------------+-------------------+
|            123.4 |           123 |              123 |               120 |
+------------------+---------------+------------------+-------------------+
```

```sql
select floor(x, 2) from ( select cast(123.456 as decimal(6,3)) as x from numbers("number"="5") )t;
```

```text
+-------------+
| floor(x, 2) |
+-------------+
|      123.45 |
|      123.45 |
|      123.45 |
|      123.45 |
|      123.45 |
+-------------+
```

```sql
select floor(NULL, 2);
```

```text
+----------------+
| floor(NULL, 2) |
+----------------+
|           NULL |
+----------------+
```
