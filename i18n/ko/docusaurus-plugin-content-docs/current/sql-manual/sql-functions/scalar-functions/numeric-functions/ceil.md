## 설명 {#description}

부동소수점 및 고정소수점 소수를 지정한 자릿수로 올림하고, 올림한 부동소수점 또는 고정소수점 수를 반환합니다.

## 구문 {#syntax}

```sql
CEIL(<a>[, <d>])
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<a>` | 올림할 값을 나타내는 부동소수점(Double) 또는 고정소수점(Decimal) 매개변수 |
| `<d>` | 선택 사항인 정수로, 올림할 자릿수를 나타냅니다. 양수이면 소수점 아래 자릿수로, 음수이면 소수점 위 자릿수로 올림하며, `0`이면 정수로 올림합니다. 지정하지 않으면 `<d> = 0`과 같습니다. |

## 반환값 {#return-value}

다음 규칙에 따라 `<a>`보다 크거나 같은 수 중 가장 작은 올림값을 반환합니다.

`1/(10^d)` 단위로 올림합니다. 즉, 결과가 `1/(10^d)`로 나누어떨어지도록 합니다. `1/(10^d)`를 정확히 표현할 수 없으면 해당 데이터 타입에서 가장 가까운 수를 올림 단위로 사용합니다.

Decimal 타입의 입력값 `<a>`가 `Decimal(p, s)` 타입이라고 가정하면 반환값은 다음과 같습니다.

- `Decimal(p, 0)`: `<d> <= 0`인 경우
- `Decimal(p, <d>)`: `0 < <d> <= s`인 경우
- `Decimal(p, s)`: `<d> > s`인 경우

입력 매개변수 중 하나라도 NULL이면 NULL을 반환합니다.

## 별칭 {#alias}

- DCEIL
- CEILING

## 예제 {#examples}

```sql
select ceil(123.456);
```

```text
+---------------+
| ceil(123.456) |
+---------------+
|           124 |
+---------------+
```

```sql
select ceil(123.456, 2);
```

```text
+------------------+
| ceil(123.456, 2) |
+------------------+
|           123.46 |
+------------------+
```

```sql
select ceil(123.456, -2);
```

```text
+-------------------+
| ceil(123.456, -2) |
+-------------------+
|               200 |
+-------------------+
```

```sql
select ceil(123.45, 1), ceil(123.45), ceil(123.45, 0), ceil(123.45, -1);
```

```text
+-----------------+--------------+-----------------+------------------+
| ceil(123.45, 1) | ceil(123.45) | ceil(123.45, 0) | ceil(123.45, -1) |
+-----------------+--------------+-----------------+------------------+
|           123.5 |          124 |             124 |              130 |
+-----------------+--------------+-----------------+------------------+
```

```sql
select ceil(x, 2) from ( select cast(123.456 as decimal(6,3)) as x from numbers("number"="5") )t;
```

```text
+------------+
| ceil(x, 2) |
+------------+
|     123.46 |
|     123.46 |
|     123.46 |
|     123.46 |
|     123.46 |
+------------+
```

```sql
select ceil(NULL);
```

```text
+------------+
| ceil(NULL) |
+------------+
|       NULL |
+------------+
```
