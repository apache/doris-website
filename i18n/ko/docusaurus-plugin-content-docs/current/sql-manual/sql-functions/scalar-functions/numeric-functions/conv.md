## 설명 {#description}

입력 매개변수의 진법을 변환합니다.

## 구문 {#syntax}

```sql
CONV(<input>, <from_base>, <to_base>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<input>` | 변환할 매개변수로, 문자열 또는 정수입니다. |
| `<from_base>` | 변환 전 진법을 나타내는 숫자이며, 범위는 `[2,36]`입니다. |
| `<to_base>` | 변환할 대상 진법을 나타내는 숫자이며, 범위는 `[2,36]`입니다. |

## 반환 값 {#return-value}

대상 진법 `<to_base>`로 변환한 숫자를 문자열로 반환합니다.
입력 매개변수 중 하나라도 NULL이면 NULL을 반환합니다.
`<from_base>` 또는 `<to_base>`가 허용 범위를 벗어나면 NULL을 반환합니다.

## 예제 {#examples}

```sql
SELECT CONV(15,10,2);
```

```text
+-----------------+
| conv(15, 10, 2) |
+-----------------+
| 1111            |
+-----------------+
```

```sql
SELECT CONV('ff',16,10);
```

```text
+--------------------+
| conv('ff', 16, 10) |
+--------------------+
| 255                |
+--------------------+
```

```sql
SELECT CONV(230,10,16);
```

```text
+-------------------+
| conv(230, 10, 16) |
+-------------------+
| E6                |
+-------------------+
```

```sql
SELECT CONV(230,10,NULL);
```

```text
+-------------------+
| CONV(230,10,NULL) |
+-------------------+
| NULL              |
+-------------------+
```

```sql
SELECT CONV(230,10,56);
```

```text
+-----------------+
| CONV(230,10,56) |
+-----------------+
| NULL            |
+-----------------+
```
