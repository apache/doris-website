## 설명 {#description}

x의 코시컨트 값을 반환합니다. x는 라디안 단위의 값이며, 입력과 출력은 double 타입만 지원합니다. null 값을 입력하면 null 값을 반환합니다.

## 구문 {#syntax}

```sql
CSC(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<x>` | 코시컨트를 계산할 값 |

## 반환 값 {#return-value}

x의 코시컨트를 나타내는 Double 타입의 값을 반환합니다.

## 특수 사례 {#special-cases}
- `x`가 NaN이면 NaN을 반환합니다.
- `x`가 양의 무한대 또는 음의 무한대이면 NaN을 반환합니다.
- `x`가 NULL이면 NULL을 반환합니다.

## 예제 {#example}

```sql
select csc(1),csc(2),csc(1000);
```

```text
+--------------------+--------------------+------------------+
| csc(1)             | csc(2)             | csc(1000)        |
+--------------------+--------------------+------------------+
| 1.1883951057781212 | 1.0997501702946164 | 1.20936599707935 |
+--------------------+--------------------+------------------+
```

null 값을 입력한 경우입니다.

```sql
select csc(null);
```

```text
+--------------------+
| csc(null)          |
+--------------------+
|      NULL          |
+--------------------+
```

```sql
select csc(cast('nan' as double));
```

```text
+---------------------------+
| csc(cast('nan' AS DOUBLE))|
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select csc(cast('inf' as double));
```

```text
+---------------------------+
| csc(cast('inf' AS DOUBLE))|
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select csc(cast('-inf' as double));
```

```text
+----------------------------+
| csc(cast('-inf' AS DOUBLE))|
+----------------------------+
| NaN                        |
+----------------------------+
```
