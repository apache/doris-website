## 설명 {#description}

아크탄젠트 값을 반환합니다.

- 매개변수가 하나일 때: `x`의 아크탄젠트를 반환하며, 결과 범위는 [-π/2, π/2]입니다.

- 매개변수가 두 개일 때: `y/x`의 아크탄젠트를 반환하며, [ATAN2(y, x)](https://doris.apache.org/docs/dev/sql-manual/sql-functions/scalar-functions/numeric-functions/atan2)와 동일하게 동작합니다. 결과 범위는 [-π, π]입니다.

## 구문 {#syntax}

```sql
ATAN([<y>, ]<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |  
| -- | -- |  
| `<x>` | 매개변수가 하나일 때는 아크탄젠트를 계산할 값을 나타냅니다. 매개변수가 두 개일 때는 수평 좌표(또는 x 값), 즉 원점 (0,0)에서 x축을 따라 떨어진 거리를 나타냅니다. |  
| `<y>` | 선택 사항으로, 수직 좌표(또는 y 값), 즉 원점 (0,0)에서 y축을 따라 떨어진 거리를 나타냅니다.|

## 반환 값 {#return-value}

매개변수 `x`의 atan 값입니다. 

## 특수 사례 {#special-cases}

### 단일 매개변수 버전 {#single-parameter-version}
- `x`가 NaN이면 NaN을 반환합니다.
- `x`가 양의 무한대이면 π/2(약 1.570796326794897)를 반환합니다.
- `x`가 음의 무한대이면 -π/2(약 -1.570796326794897)를 반환합니다.
- `x`가 NULL이면 NULL을 반환합니다.

### 두 매개변수 버전 {#two-parameter-version}
- `y` 또는 `x`가 NaN이면 NaN을 반환합니다.
- `x > 0`이고 `y = ±0.0`이면 ±0을 반환합니다(부호는 `y`를 따릅니다).
- `x = 0.0`(+0.0 또는 -0.0)이고 `y > 0`이면 π/2(약 1.570796326794897)를 반환합니다.
- `x = 0.0`(+0.0 또는 -0.0)이고 `y < 0`이면 -π/2(약 -1.570796326794897)를 반환합니다.
- `x < 0`이고 `y = +0.0`이면 π(약 3.141592653589793)를 반환하고, `x < 0`이고 `y = -0.0`이면 -π를 반환합니다.
- `y = +Infinity`이고 `x`가 유한하면 π/2를 반환하고, `y = -Infinity`이고 `x`가 유한하면 -π/2를 반환합니다.
- `y = +Infinity`이고 `x = +Infinity`이면 π/4(약 0.7853981633974483)를 반환합니다.
- `y = -Infinity`이고 `x = +Infinity`이면 -π/4(약 -0.7853981633974483)를 반환합니다.
- `y = +Infinity`이고 `x = -Infinity`이면 3π/4(약 2.356194490192345)를 반환합니다.
- `y = -Infinity`이고 `x = -Infinity`이면 -3π/4(약 -2.356194490192345)를 반환합니다.
- `x = +Infinity`이고 유한한 `y` > 0이면 0을 반환하고, 유한한 `y` < 0이면 -0을 반환합니다.
- `x = -Infinity`이고 유한한 `y` > 0이면 π를 반환하고, 유한한 `y` < 0이면 -π를 반환합니다.
- `y` 또는 `x`가 NULL이면 NULL을 반환합니다.

## 예제 {#examples}

```sql
select atan(0);
```

```text
+-----------+
| atan(0.0) |
+-----------+
|         0 |
+-----------+
```

```sql
select atan(2);
```

```text
+--------------------+
| atan(2.0)          |
+--------------------+
| 1.1071487177940904 |
+--------------------+
```

```sql
select atan(cast('nan' as double));
```

```text
+-----------------------------+
| atan(cast('nan' AS DOUBLE)) |
+-----------------------------+
| NaN                         |
+-----------------------------+
```

```sql
select atan(cast('inf' as double));
```

```text
+-----------------------------+
| atan(cast('inf' AS DOUBLE)) |
+-----------------------------+
| 1.570796326794897           |
+-----------------------------+
```

```sql
select atan(cast('-inf' as double));
```

```text
+------------------------------+
| atan(cast('-inf' AS DOUBLE)) |
+------------------------------+
| -1.570796326794897           |
+------------------------------+
```
