## 설명 {#description}

매개변수의 사인 값을 계산합니다

## 구문 {#syntax}

```sql
SIN(<a>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<a>` | 부동 소수점 수로, 계산할 매개변수의 라디안 값 |

## 반환 값 {#return-value}

라디안으로 표현된 매개변수 `<a>`의 사인 값입니다.

## 특수한 경우 {#special-cases}
- `a`가 NaN이면 NaN을 반환합니다
- `a`가 양의 무한대 또는 음의 무한대이면 NaN을 반환합니다
- `a`가 NULL이면 NULL을 반환합니다

## 예제 {#examples}

```sql
select sin(1);
```

```text
+------------------------+
| sin(cast(1 as DOUBLE)) |
+------------------------+
|     0.8414709848078965 |
+------------------------+
```

```sql
select sin(0);
```

```text
+------------------------+
| sin(cast(0 as DOUBLE)) |
+------------------------+
|                    0.0 |
+------------------------+
```

```sql
select sin(Pi());
```

```text
+------------------------------------+
| sin(pi())                          |
+------------------------------------+
| 0.00000000000000012246467991473532 |
+------------------------------------+
```

```sql
select sin(cast('nan' as double));
```

```text
+----------------------------+
| sin(cast('nan' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select sin(cast('inf' as double));
```

```text
+----------------------------+
| sin(cast('inf' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select sin(cast('-inf' as double));
```

```text
+-----------------------------+
| sin(cast('-inf' AS DOUBLE)) |
+-----------------------------+
| NaN                         |
+-----------------------------+
```
