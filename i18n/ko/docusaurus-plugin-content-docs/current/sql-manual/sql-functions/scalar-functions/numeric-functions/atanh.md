## 설명 {#description}

`x`의 쌍곡선 역탄젠트를 반환합니다. 반환값이 `NULL`이 되는 경우는 `x`가 `-1`에서 `1` 사이의 범위(`-1`과 `1` 제외)에 속하지 않을 때입니다.

## 구문 {#syntax}

```sql
ATANH(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |  
| -- | -- |  
| `<x>` | 쌍곡선 역탄젠트를 계산할 값 |  

## 반환 값 {#return-value}

매개변수 `x`의 쌍곡선 역탄젠트 값입니다.

## 특수 사례 {#special-cases}

- `x`가 0이면 0을 반환합니다
- `x`가 1 또는 -1이면 `NULL`을 반환합니다
- `x`가 범위 (-1, 1)을 벗어나면 `NULL`을 반환합니다
- `x`가 NaN이면 NaN을 반환합니다
- `x`가 양의 무한대 또는 음의 무한대이면 `NULL`을 반환합니다
- `x`가 NULL이면 NULL을 반환합니다
