## 설명 {#description}

`x`에 대해 밑이 `2`인 로그를 반환합니다.

## 구문 {#syntax}

```sql
LOG2(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|-----------|------------|
| `<x>`   | 진수는 0보다 커야 합니다 |

## 반환 값 {#return-value}

부동 소수점 수를 반환합니다. 특수한 경우는 다음과 같습니다.

- x가 NULL이면 `NULL`을 반환합니다.
- x가 NaN이면 NaN을 반환합니다.

## 예제 {#example}

```sql
select log2(1);
```

```text
+-------------------------+
| log2(cast(1 as DOUBLE)) |
+-------------------------+
|                     0.0 |
+-------------------------+
```

```sql
select log2(2);
```

```text
+-------------------------+
| log2(cast(2 as DOUBLE)) |
+-------------------------+
|                     1.0 |
+-------------------------+
```

```sql
select log2(10);
```

```text
+--------------------------+
| log2(cast(10 as DOUBLE)) |
+--------------------------+
|       3.3219280948873626 |
+--------------------------+
```

```sql
select log2(NULL);
```

```text
+------------+
| log2(NULL) |
+------------+
|       NULL |
+------------+
```

```sql
select log2(cast('Nan' as double));
```

```text
+-----------------------------+
| log2(cast('Nan' as double)) |
+-----------------------------+
|                         NaN |
+-----------------------------+
```
