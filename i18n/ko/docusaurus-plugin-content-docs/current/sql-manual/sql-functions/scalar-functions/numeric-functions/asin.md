## 설명 {#description}

`x`의 아크사인 값을 반환합니다. `NULL`이 반환되는 경우는 `x`가 `-1`에서 `1` 사이의 범위를 벗어날 때입니다.

## 구문 {#syntax}

```sql
ASIN(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |  
| -- | -- |  
| `<x>` | 아크사인을 계산할 값 |  

## 반환값 {#return-value}

매개변수 `x`의 아크사인 값이며, 라디안 단위로 표시됩니다.

## 특수한 경우 {#special-cases}

- `x`가 0이면 0을 반환합니다
- `x`가 1이면 π/2를 반환합니다
- `x`가 -1이면 -π/2를 반환합니다
- `x`가 [-1, 1] 범위를 벗어나면 `NULL`을 반환합니다
- `x`가 NaN이면 NaN을 반환합니다
- `x`가 양의 무한대 또는 음의 무한대이면 `NULL`을 반환합니다
- `x`가 NULL이면 NULL을 반환합니다

## 예제 {#examples}

```sql
select asin(0.5);
```

```text
+---------------------+
| asin(0.5)           |
+---------------------+
| 0.52359877559829893 |
+---------------------+
```

```sql
select asin(0.0);
```

```text
+------------+
| asin(0.0)  |
+------------+
|          0 |
+------------+
```

```sql
select asin(1.0);
```

```text
+--------------------+
| asin(1.0)          |
+--------------------+
| 1.570796326794897  |
+--------------------+
```

```sql
select asin(-1.0);
```

```text
+---------------------+
| asin(-1.0)          |
+---------------------+
| -1.570796326794897  |
+---------------------+
```

```sql
select asin(2);
```

```text
+------------+
| asin(2.0)  |
+------------+
|       NULL |
+------------+
```

```sql
select asin(cast('nan' as double));
```

```text
+---------------------------+
| asin(cast('nan' AS DOUBLE)) |
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select asin(cast('inf' as double));
```

```text
+---------------------------+
| asin(cast('inf' AS DOUBLE)) |
+---------------------------+
| NULL                      |
+---------------------------+
```
