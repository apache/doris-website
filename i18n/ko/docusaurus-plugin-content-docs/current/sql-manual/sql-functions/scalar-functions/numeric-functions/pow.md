## 설명 {#description}

첫 번째 인수를 밑으로 하고 두 번째 인수를 지수로 하는 거듭제곱 값을 반환합니다.

## 별칭 {#alias}

- POWER
- FPOW
- DPOW

## 구문 {#syntax}

```sql
POW(<a>, <b>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|-----------|------------|
| `<a>`   | 밑   |
| `<b>`   | 지수  |

## 반환 값 {#return-value}

정수형 또는 부동소수점형을 반환합니다.

특수한 경우:

- a가 `IS NULL`이거나 b가 `IS NULL`이면 `NULL`을 반환합니다.
- `b = 0`이고 a가 `IS NOT NULL`이면 항상 `1`을 반환합니다.

## 예제 {#examples}

```sql
select pow(2, 0);
```
```text
+-------------------------------------------+
| pow(cast(2 as DOUBLE), cast(0 as DOUBLE)) |
+-------------------------------------------+
|                                         1 |
+-------------------------------------------+
```

```sql
select pow(2, 10);
```
```text
+--------------------------------------------+
| pow(cast(2 as DOUBLE), cast(10 as DOUBLE)) |
+--------------------------------------------+
|                                       1024 |
+--------------------------------------------+
```

```sql
select pow(1.2, 2);
```
```text
+---------------------------------------------+
| pow(cast(1.2 as DOUBLE), cast(2 as DOUBLE)) |
+---------------------------------------------+
|                                        1.44 |
+---------------------------------------------+
```

```sql
select pow(1.2, 2.1);
```
```text
+-----------------------------------------------+
| pow(cast(1.2 as DOUBLE), cast(2.1 as DOUBLE)) |
+-----------------------------------------------+
|                            1.4664951016517147 |
+-----------------------------------------------+
```

```sql
select pow(2, null);
```
```text
+------------------------------+
| pow(cast(2 as DOUBLE), NULL) |
+------------------------------+
|                         NULL |
+------------------------------+
```

```sql
select pow(null, 2);
```
```text
+------------------------------+
| pow(NULL, cast(2 as DOUBLE)) |
+------------------------------+
|                         NULL |
+------------------------------+
```
