## 설명 {#description}

`x`의 쌍곡코사인을 반환합니다.

## 구문 {#syntax}

`COSH(<x>)`

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<x>` | 쌍곡코사인을 계산할 값  |

## 반환 값 {#return-value}

매개변수 `x`의 쌍곡코사인을 반환합니다.

## 특수한 경우 {#special-cases}
- `x`가 NaN이면 NaN을 반환합니다.
- `x`가 양의 무한대이면 Infinity를 반환합니다.
- `x`가 음의 무한대이면 Infinity를 반환합니다.
- `x`가 NULL이면 NULL을 반환합니다.

## 예제 {#examples}

```sql
select cosh(0);
```
```text
+-------------------------+
| cosh(cast(0 as DOUBLE)) |
+-------------------------+
|                     1.0 |
+-------------------------+
```

```sql
select cosh(1);
```
```text
+-------------------------+
| cosh(cast(1 as DOUBLE)) |
+-------------------------+
|       1.543080634815244 |
+-------------------------+
```

```sql
select cosh(-1);
```
```text
+--------------------------+
| cosh(cast(-1 as DOUBLE)) |
+--------------------------+
|        1.543080634815244 |
+--------------------------+
```

```sql
select cosh(cast('nan' as double));
```
```text
+-----------------------------+
| cosh(cast('nan' AS DOUBLE)) |
+-----------------------------+
| NaN                         |
+-----------------------------+
```

```sql
select cosh(cast('inf' as double));
```
```text
+-----------------------------+
| cosh(cast('inf' AS DOUBLE)) |
+-----------------------------+
| Infinity                    |
+-----------------------------+
```

```sql
select cosh(cast('-inf' as double));
```
```text
+------------------------------+
| cosh(cast('-inf' AS DOUBLE)) |
+------------------------------+
| Infinity                     |
+------------------------------+
```
