## 설명 {#description}

값의 제곱근을 반환합니다. 입력값은 0 이상이어야 합니다.

## 구문 {#syntax}

```sql
SQRT(<x>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<x>` | 제곱근을 계산할 값 |

## 반환 값 {#return-value}

매개변수 `x`의 제곱근입니다.

## 특수한 경우 {#special-cases}

- `x`가 0이면 0을 반환합니다
- `x`가 -0이면 -0을 반환합니다
- `x`가 0보다 작으면 `NULL`을 반환합니다
- `x`가 NaN이면 NaN을 반환합니다
- `x`가 양의 무한대이면 Infinity를 반환합니다
- `x`가 음의 무한대이면 `NULL`을 반환합니다
- `x`가 NULL이면 NULL을 반환합니다

## 예제 {#examples}

```sql
select sqrt(9), sqrt(2);
```

```text
+-------------------------+-------------------------+
| sqrt(cast(9 as DOUBLE)) | sqrt(cast(2 as DOUBLE)) |
+-------------------------+-------------------------+
|                     3.0 |      1.4142135623730951 |
+-------------------------+-------------------------+
```
