# URL 함수 개요 {#url-functions-overview}

URL 함수는 도메인, 프로토콜, 쿼리 매개변수 등의 구성 요소를 추출하거나 URL 문자열을 인코딩하고 디코딩합니다. 각 함수의 구문, 입력 요구 사항, 예시는 아래 함수 참조 페이지에서 확인하세요.

| 함수 | 용도 |
| --- | --- |
| [DOMAIN](../string-functions/domain.md) | URL에서 도메인을 추출합니다. |
| [DOMAIN_WITHOUT_WWW](../string-functions/domain-without-www.md) | 도메인을 추출하고 앞에 있는 `www.`를 제거합니다. |
| [TOP_LEVEL_DOMAIN](../string-functions/top-level-domain.md) | 최상위 도메인을 추출합니다. |
| [FIRST_SIGNIFICANT_SUBDOMAIN](../string-functions/first-significant-subdomain.md) | 첫 번째 주요 하위 도메인을 추출합니다. |
| [CUT_TO_FIRST_SIGNIFICANT_SUBDOMAIN](../string-functions/cut-to-first-significant-subdomain.md) | 도메인을 첫 번째 주요 하위 도메인까지 유지합니다. |
| [PROTOCOL](../string-functions/protocol.md) | URL에서 프로토콜을 추출합니다. |
| [PARSE_URL](../string-functions/parse-url.md) | 지정한 URL 구성 요소를 추출합니다. |
| [EXTRACT_URL_PARAMETER](../string-functions/extract-url-parameter.md) | 이름으로 지정한 URL 쿼리 매개변수를 추출합니다. |
| [URL_ENCODE](../string-functions/url-encode.md) | URL에서 사용할 수 있도록 문자열을 인코딩합니다. |
| [URL_DECODE](../string-functions/url-decode.md) | URL 인코딩된 문자열을 디코딩합니다. |
