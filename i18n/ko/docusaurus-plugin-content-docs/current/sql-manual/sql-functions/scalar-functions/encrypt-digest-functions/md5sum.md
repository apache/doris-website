## 설명 {#description}

문자열의 MD5 128비트 체크섬을 계산합니다

## 구문 {#syntax}

```sql
MD5SUM( <str> [ , <str> ... ] )
```

## 매개변수 {#parameters}

|  매개변수 | 설명 |
|---------| -- |
| `<str>` | 계산할 MD5 값 |

## 반환 값 {#return-value}

여러 문자열의 MD5 값을 반환합니다

## 예제 {#examples}

```sql
select md5("abcd"),md5sum("ab","cd");
```

```text
+----------------------------------+----------------------------------+
| md5('abcd')                      | md5sum('ab', 'cd')               |
+----------------------------------+----------------------------------+
| e2fc714c4727ee9395f324cd2e7f331f | e2fc714c4727ee9395f324cd2e7f331f |
+----------------------------------+----------------------------------+
```
