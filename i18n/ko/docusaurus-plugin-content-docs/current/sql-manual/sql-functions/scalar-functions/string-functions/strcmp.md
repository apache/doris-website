## 설명 {#description}

STRCMP 함수는 두 문자열을 사전순으로 비교합니다. 비교 결과를 나타내는 정숫값을 반환합니다.

## 구문 {#syntax}

```sql
STRCMP(<str0>, <str1>)
```

## 매개변수 {#parameters}
| 매개변수 | 설명 |
| --------- | ----------------------------------------- |
| `<str0>` | 비교할 첫 번째 문자열입니다. 타입: VARCHAR |
| `<str1>` | 비교할 두 번째 문자열입니다. 타입: VARCHAR |

## 반환 값 {#return-value}

비교 결과를 TINYINT 타입으로 반환합니다:
- 0 반환: str0이 str1과 같은 경우
- 1 반환: str0이 사전순으로 str1보다 큰 경우
- -1 반환: str0이 사전순으로 str1보다 작은 경우

특수한 경우:
- 인수 중 하나라도 NULL이면 NULL을 반환합니다

## 예제 {#examples}

1. 동일한 문자열 비교
```sql
SELECT strcmp('test', 'test');
```
```text
+------------------------+
| strcmp('test', 'test') |
+------------------------+
|                      0 |
+------------------------+
```

2. 첫 번째 문자열이 더 큰 경우
```sql
SELECT strcmp('test1', 'test');
```
```text
+-------------------------+
| strcmp('test1', 'test') |
+-------------------------+
|                       1 |
+-------------------------+
```

3. 첫 번째 문자열이 더 작은 경우
```sql
SELECT strcmp('test', 'test1');
```
```text
+-------------------------+
| strcmp('test', 'test1') |
+-------------------------+
|                      -1 |
+-------------------------+
```
