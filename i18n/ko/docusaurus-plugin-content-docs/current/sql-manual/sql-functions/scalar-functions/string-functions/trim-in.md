## 설명 {#description}

TRIM_IN 함수는 문자열의 앞뒤에서 지정된 문자를 제거하는 데 사용됩니다. 문자 집합을 지정하지 않으면 기본적으로 앞뒤의 공백을 제거합니다. 문자 집합을 지정하면 집합 내 순서와 관계없이 양 끝에서 지정된 문자를 모두 제거합니다.

TRIM_IN의 주요 특징은 지정된 집합에 속한 문자의 모든 조합을 제거한다는 점입니다. TRIM 함수는 문자열이 정확히 일치하는 경우에 해당 문자열을 제거합니다.

## 구문 {#syntax}

```sql
TRIM_IN(<str>[, <rhs>])
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| --------- | ------------------------------------------------------------------------ |
| `<str>` | 처리할 문자열입니다. 타입: VARCHAR |
| `<rhs>` | 제거할 문자 집합을 지정하는 선택적 매개변수입니다. 타입: VARCHAR |

## 반환 값 {#return-value}

처리된 문자열을 VARCHAR 타입으로 반환합니다.

특수한 경우:
- str이 NULL이면 NULL을 반환합니다.
- rhs를 지정하지 않으면 앞뒤의 공백을 모두 제거합니다.
- rhs를 지정하면 양 끝에서 rhs에 포함되지 않은 문자를 만날 때까지 rhs에 포함된 문자를 모두 제거합니다.

## 예제 {#examples}

1. 앞뒤 공백 제거
```sql
SELECT trim_in('   ab d   ') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. 지정된 문자 집합의 문자 제거
```sql
SELECT trim_in('ababccaab', 'ab') str;
```
```text
+------+
| str  |
+------+
| cc   |
+------+
```

3. TRIM 함수와 비교
```sql
SELECT trim_in('ababccaab', 'ab'), trim('ababccaab', 'ab');
```
```text
+----------------------------+-------------------------+
| trim_in('ababccaab', 'ab') | trim('ababccaab', 'ab') |
+----------------------------+-------------------------+
| cc                         | cca                     |
+----------------------------+-------------------------+
```

4. 문자 집합의 순서는 무관
```sql
SELECT trim_in('abcHelloabc', 'cba');
```
```text
+--------------------------------+
| trim_in('abcHelloabc', 'cba')  |
+--------------------------------+
| Hello                          |
+--------------------------------+
```

5. UTF-8 문자 지원
```sql
SELECT trim_in('+++ṭṛì ḍḍumai+++', '+');
```
```text
+--------------------------------------+
| trim_in('+++ṭṛì ḍḍumai+++', '+')    |
+--------------------------------------+
| ṭṛì ḍḍumai                           |
+--------------------------------------+
```

6. NULL 값 처리
```sql
SELECT trim_in(NULL, 'abc');
```
```text
+-----------------------+
| trim_in(NULL, 'abc')  |
+-----------------------+
| NULL                  |
+-----------------------+
```

7. 빈 문자열 처리
```sql
SELECT trim_in('', 'abc'), trim_in('abc', '');
```
```text
+--------------------+--------------------+
| trim_in('', 'abc') | trim_in('abc', '') |
+--------------------+--------------------+
|                    | abc                |
+--------------------+--------------------+
```

### 키워드 {#keywords}
