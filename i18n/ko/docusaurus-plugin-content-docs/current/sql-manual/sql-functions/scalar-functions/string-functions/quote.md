## 설명 {#description}

QUOTE 함수는 문자열을 작은따옴표로 감싸고 문자열 안의 특수 문자를 이스케이프 처리하여 SQL 문에서 안전하게 사용할 수 있도록 합니다.

## 구문 {#syntax}

```sql
QUOTE(<str>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| ------- | ----------------------------------------- |
| `<str>` | 따옴표로 감쌀 입력 문자열입니다. 타입: VARCHAR |

## 반환 값 {#return-value}

VARCHAR 타입을 반환하며, 작은따옴표로 감싸고 특수 문자를 이스케이프 처리한 문자열입니다.

특수한 경우:
- 입력이 NULL이면 문자열 'NULL'을 반환합니다(따옴표 제외).
- 작은따옴표 `'`는 `\'`로 이스케이프 처리됩니다.
- 백슬래시 `\`는 `\\`로 이스케이프 처리됩니다.
- 빈 문자열을 입력하면 `''`를 반환합니다.

## 예제 {#examples}

1. 기본 문자열에 따옴표 추가
```sql
SELECT quote('hello');
```
```text
+----------------+
| quote('hello') |
+----------------+
| 'hello'        |
+----------------+
```

2. 작은따옴표가 포함된 문자열(이스케이프 처리됨)
```sql
SELECT quote("It's a test");
```
```text
+----------------------+
| quote("It's a test") |
+----------------------+
| 'It\'s a test'       |
+----------------------+
```

3. NULL 값 처리
```sql
SELECT quote(NULL);
```
```text
+-------------+
| quote(NULL) |
+-------------+
| NULL        |
+-------------+
```

4. 빈 문자열 처리
```sql
SELECT quote('');
```
```text
+-----------+
| quote('') |
+-----------+
| ''        |
+-----------+
```

5. 백슬래시 문자
```sql
SELECT quote('aaa\\');
```
```text
+----------------+
| quote('aaa\\') |
+----------------+
| 'aaa\'         |
+----------------+
```

```sql
SELECT quote('aaa\cccb');
```
```text
+-------------------+
| quote('aaa\cccb') |
+-------------------+
| 'aaacccb'         |
+-------------------+
```
