## 설명 {#description}

MAKE_SET 함수는 비트마스크(bit)를 기준으로 여러 문자열 매개변수에서 문자열을 선택하여 결합합니다. 대응하는 비트가 1인 모든 문자열을 포함하는 쉼표로 구분된 문자열 집합을 반환합니다.

동작은 MySQL의 [MAKE_SET](https://dev.mysql.com/doc/refman/8.4/en/string-functions.html#function-make-set)과 동일합니다.

## 구문 {#syntax}

```sql
MAKE_SET(<bit>, <str1>[, <str2>, ...])
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -------- | ----------------------------------------- |
| `<bit>` | 비트마스크 값으로, 이진수의 각 비트는 선택할 문자열을 나타냅니다. 타입: BIGINT |
| `<str1>`, `<str2>`, ... | 결합할 문자열 매개변수(가변 인자). 타입: VARCHAR |

## 반환 값 {#return-value}

VARCHAR 타입의 쉼표로 구분된 문자열 집합을 반환합니다.

특수한 경우:
- `<bit>`가 NULL이면 NULL을 반환합니다.
- 값이 1인 비트에 대응하는 문자열이 NULL이면 해당 문자열을 건너뜁니다.
- 대응하는 비트가 매개변수 범위를 벗어나면 해당 비트를 무시합니다.
- 이진수의 비트는 오른쪽에서 왼쪽으로 세며, 비트 0은 첫 번째 문자열 매개변수에 대응합니다.
- `<bit>`가 0이면 빈 문자열을 반환합니다.

## 예제 {#examples}

1. 기본 사용법: bit = 3(이진수 011, 비트 0과 비트 1 선택)
```sql
SELECT make_set(3, 'dog', 'cat', 'bird');
```
```text
+-----------------------------------+
| make_set(3, 'dog', 'cat', 'bird') |
+-----------------------------------+
| dog,cat                           |
+-----------------------------------+
```

2. NULL 값 건너뛰기: bit = 5(이진수 101, 비트 0과 비트 2 선택)
```sql
SELECT make_set(5, NULL, 'warm', 'hot');
```
```text
+---------------------------------+
| make_set(5, NULL, 'warm', 'hot') |
+---------------------------------+
| hot                             |
+---------------------------------+
```

3. bit가 0인 경우: 문자열을 선택하지 않음
```sql
SELECT make_set(0, 'hello', 'world');
```
```text
+--------------------------------+
| make_set(0, 'hello', 'world')  |
+--------------------------------+
|                                |
+--------------------------------+
```

4. NULL 값 처리
```sql
SELECT make_set(NULL, 'a', 'b', 'c');
```
```text
+-------------------------------+
| make_set(NULL, 'a', 'b', 'c') |
+-------------------------------+
| NULL                          |
+-------------------------------+
```

5. 비트가 매개변수 범위를 벗어나는 경우: bit = 15(이진수 1111, 비트 4개를 선택하지만 매개변수는 2개뿐임)
```sql
SELECT make_set(15, 'first', 'second');
```
```text
+-------------------------------------+
| make_set(15, 'first', 'second')     |
+-------------------------------------+
| first,second                        |
+-------------------------------------+
```

6. UTF-8 특수 문자 지원
```sql
SELECT make_set(7, 'ṭṛì', 'ḍḍumai', 'test');
```
```text
+------------------------------------------+
| make_set(7, 'ṭṛì', 'ḍḍumai', 'test')    |
+------------------------------------------+
| ṭṛì,ḍḍumai,test                          |
+------------------------------------------+
```
