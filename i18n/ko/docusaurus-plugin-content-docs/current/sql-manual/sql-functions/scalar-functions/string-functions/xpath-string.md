## 설명 {#description}

XPATH_STRING 함수는 XML 문자열을 파싱하고 [XPath](https://www.w3.org/TR/xpath-10/) 표현식과 일치하는 첫 번째 XML 노드를 반환하는 데 사용됩니다.

:::tip
이 함수는 버전 3.0.6부터 지원됩니다.
:::

## 구문 {#syntax}

```sql
XPATH_STRING(<xml_string>, <xpath_expression>)
```

## 매개변수 {#parameters}
| 매개변수 | 설명                                   |
| --------- | ----------------------------------------------|
| `<xml_string>` | 원본 문자열. 타입: VARCHAR             |
| `<xpath_expression>` | [XPath](https://www.w3.org/TR/xpath-10/) 표현식. 타입: VARCHAR    |

## 반환 값 {#return-value}

XPath 표현식과 일치하는 첫 번째 XML 노드의 내용을 VARCHAR 타입으로 반환합니다.

특수한 경우:
- xml 또는 xpath의 형식이 올바르지 않으면 함수에서 오류가 발생합니다.

## 예제 {#examples}

1. 기본 노드 값 추출
```sql
SELECT xpath_string('<a>123</a>', '/a');
```
```text
+-----------------------------------+
| xpath_string('<a>123</a>', '/a')  |
+-----------------------------------+
| 123                               |
+-----------------------------------+
```

2. 중첩된 요소 추출
```sql
SELECT xpath_string('<a><b>123</b></a>', '/a/b');
```
```text
+--------------------------------------------+
| xpath_string('<a><b>123</b></a>', '/a/b')  |
+--------------------------------------------+
| 123                                        |
+--------------------------------------------+
```

3. 속성 사용
```sql
SELECT xpath_string('<a><b id="1">123</b></a>', '//b[@id="1"]');
```
```text
+----------------------------------------------------------+
| xpath_string('<a><b id="1">123</b></a>', '//b[@id="1"]') |
+----------------------------------------------------------+
| 123                                                      |
+----------------------------------------------------------+
```

4. 위치 조건식 사용
```sql
SELECT xpath_string('<a><b>1</b><b>2</b></a>', '/a/b[2]');
```
```text
+----------------------------------------------------+
| xpath_string('<a><b>1</b><b>2</b></a>', '/a/b[2]') |
+----------------------------------------------------+
| 2                                                  |
+----------------------------------------------------+
```

5. CDATA 및 주석 처리
```sql
SELECT xpath_string(NULL, '/a');
```
```text
+--------------------------+
| xpath_string(NULL, '/a') |
+--------------------------+
| NULL                     |
+--------------------------+
```
