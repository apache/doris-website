## 설명 {#description}

UCASE 함수(별칭: UPPER)는 문자열의 모든 소문자를 대문자로 변환합니다. 이 함수는 Unicode 문자 변환을 지원하며 다양한 언어의 대소문자 변환 규칙을 올바르게 처리할 수 있습니다.

## 구문 {#syntax}

```sql
UCASE(<str>)
UPPER(<str>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
|-----------|-------------|
| `<str>` | 대문자로 변환할 문자열입니다. 타입: VARCHAR |

## 반환 값 {#return-value}

대문자로 변환된 문자열을 나타내는 VARCHAR 타입을 반환합니다.

변환 규칙:
- 문자열의 모든 소문자를 해당 대문자로 변환합니다.
- 문자가 아닌 요소(숫자, 기호, 공백 등)는 변경되지 않습니다.
- 이미 대문자인 문자는 변경되지 않습니다.

특수한 경우:
- 매개변수가 NULL이면 NULL을 반환합니다.
- 문자열이 비어 있으면 빈 문자열을 반환합니다.
- 소문자가 없으면 원래 문자열을 반환합니다.

## 예제 {#examples}

1. 기본 영어 문자 변환
```sql
SELECT UCASE('aBc123'), UPPER('aBc123');
```
```text
+-----------------+-----------------+
| UCASE('aBc123') | UPPER('aBc123') |
+-----------------+-----------------+
| ABC123          | ABC123          |
+-----------------+-----------------+
```

2. 여러 종류의 문자가 섞인 문자열 처리
```sql
SELECT UCASE('Hello World!'), UPPER('test@123');
```
```text
+----------------------+------------------+
| UCASE('Hello World!') | UPPER('test@123') |
+----------------------+------------------+
| HELLO WORLD!         | TEST@123         |
+----------------------+------------------+
```

3. NULL 값 처리
```sql
SELECT UCASE(NULL), UPPER(NULL);
```
```text
+-------------+-------------+
| UCASE(NULL) | UPPER(NULL) |
+-------------+-------------+
| NULL        | NULL        |
+-------------+-------------+
```

4. 빈 문자열 처리
```sql
SELECT UCASE(''), UPPER('');
```
```text
+-----------+-----------+
| UCASE('') | UPPER('') |
+-----------+-----------+
|           |           |
+-----------+-----------+
```

5. 이미 대문자인 문자열
```sql
SELECT UCASE('ALREADY UPPERCASE'), UPPER('ABC123');
```
```text
+---------------------------+----------------+
| UCASE('ALREADY UPPERCASE') | UPPER('ABC123') |
+---------------------------+----------------+
| ALREADY UPPERCASE         | ABC123         |
+---------------------------+----------------+
```

6. 숫자와 기호
```sql
SELECT UCASE('123!@#$%'), UPPER('price: $99.99');
```
```text
+-------------------+----------------------+
| UCASE('123!@#$%') | UPPER('price: $99.99') |
+-------------------+----------------------+
| 123!@#$%          | PRICE: $99.99        |
+-------------------+----------------------+
```

7. UTF-8 멀티바이트 문자
```sql
SELECT UCASE('ṭṛì test'), UPPER('ḍḍumai hello');
```
```text
+--------------------+-----------------------+
| UCASE('ṭṛì test')  | UPPER('ḍḍumai hello') |
+--------------------+-----------------------+
| ṬṚÌ TEST           | ḌḌUMAI HELLO          |
+--------------------+-----------------------+
```

8. 키릴 문자
```sql
SELECT UCASE('Кириллица'), UPPER('Бәйтерек');
```
```text
+---------------------+-------------------+
| UCASE('Кириллица')  | UPPER('Бәйтерек') |
+---------------------+-------------------+
| КИРИЛЛИЦА           | БӘЙТЕРЕК          |
+---------------------+-------------------+
```

### 키워드 {#keywords}

    UCASE, UPPER
