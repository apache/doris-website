## 설명 {#description}

매개변수가 유효한 UUID이면 1을 반환합니다. 유효하지 않은 UUID이면 0을 반환합니다. 매개변수가 NULL이면 NULL을 반환합니다.

UUID는 길이가 올바르고 허용된 문자(대소문자를 구분하지 않는 십육진수 문자와 선택적으로 사용할 수 있는 하이픈 및 중괄호)만 포함하면 유효한 것으로 간주됩니다. 다음 세 가지 형식 중 하나로 나타낼 수 있습니다:
```text
aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
aaaaaaaabbbbccccddddeeeeeeeeeeee
{aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee}
```

이 함수는 네이티브 [UUID 타입](../../../basic-element/sql-data-types/uuid.md)과 다른 텍스트 검증 규칙을 사용합니다. 중괄호로 둘러싼 표준 형식의 UUID를 허용하지만, 네이티브 파서는 이를 허용하지 않습니다. 네이티브 UUID 컬럼에 사용할 텍스트를 검증하려면 [TO_UUID_OR_NULL](../uuid-functions/to-uuid-or-null.md) 또는 `TRY_CAST(<str> AS UUID)`를 사용하세요.

## 구문 {#syntax}

```sql
IS_UUID ( <str> )
```

## 매개변수 {#parameters}
| 매개변수  | 설명 |
|------------|-----------------|
| `<str>` | 문자열 |


## 반환 값 {#return-value}

`<str>`이 유효한 UUID이면 1을 반환하고, 그렇지 않으면 0을 반환합니다.

특수한 경우:
- 매개변수가 NULL이면 NULL을 반환합니다.
