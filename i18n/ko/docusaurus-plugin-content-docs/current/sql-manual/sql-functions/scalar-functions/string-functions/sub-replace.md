## 설명 {#description}

`sub_replace` 함수는 문자열 내의 부분 문자열을 치환하는 데 사용됩니다. 치환할 부분 문자열과 치환에 사용할 문자열을 지정할 수 있습니다. 이 함수는 `start` 위치에서 시작하고 길이가 `len`인 `str`의 부분 문자열을 `new_str`로 치환한 새 문자열을 반환합니다. `start` 또는 `len`이 음의 정수이면 NULL을 반환합니다. `len`의 기본값은 `new_str`의 길이입니다.

## 구문 {#syntax}

```sql
sub_replace(<str>, <new_str>, [ ,<start> [ , <len> ] ])
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<str>` | 치환이 이루어질 대상 문자열 |
| `<new_str>` | 지정된 부분 문자열을 대체할 문자열 |
| `<start>` | `start`는 치환 연산이 시작되는 위치로, 문자열의 어느 위치에서 치환을 시작할지 나타냅니다 |
| `<len>` | `len`은 치환할 부분 문자열의 길이를 지정하는 선택적 매개변수입니다 |

## 반환 값 {#return-value}

치환 후의 문자열을 반환합니다.

## 예제 {#examples}

1. 기본 사용법: 위치와 길이를 지정하여 치환
```sql
SELECT sub_replace('doris', '***', 1, 2);
```
```text
+-----------------------------------+
| sub_replace('doris', '***', 1, 2) |
+-----------------------------------+
| d***is                            |
+-----------------------------------+
```

2. 기본 길이를 사용하여 치환
```sql
SELECT sub_replace('hello', 'Hi', 0);
```
```text
+--------------------------------+
| sub_replace('hello', 'Hi', 0)  |
+--------------------------------+
| Hillo                          |
+--------------------------------+
```

3. 매개변수가 음수이면 NULL 반환
```sql
SELECT sub_replace('hello', 'Hi', -1, 2);
```
```text
+------------------------------------+
| sub_replace('hello', 'Hi', -1, 2)  |
+------------------------------------+
| NULL                               |
+------------------------------------+
```

4. NULL 값 처리
```sql
SELECT sub_replace(NULL, 'new', 0, 3);
```
```text
+-------------------------------------+
| sub_replace(NULL, 'new', 0, 3)      |
+-------------------------------------+
| NULL                                |
+-------------------------------------+
```

5. UTF-8 문자열
```sql
SELECT sub_replace('doris', 'ṛìḍḍ', 1, 2);
```
```text
+-------------------------------------------+
| sub_replace('doris', 'ṛìḍḍ', 1, 2)        |
+-------------------------------------------+
| dṛìḍḍis                                   |
+-------------------------------------------+
```

6. 시작 위치가 문자열 길이를 초과하는 경우
```sql
SELECT sub_replace('hello', 'Hi', 9, 2);
```
```text
+----------------------------------+
| sub_replace('hello', 'Hi', 9, 2) |
+----------------------------------+
| NULL                             |
+----------------------------------+
```

7. 지정된 치환 길이가 남은 문자열 길이를 초과하는 경우
```sql
SELECT sub_replace('hello', 'Hi', 1, 9);
```
```text
+----------------------------------+
| sub_replace('hello', 'Hi', 1, 9) |
+----------------------------------+
| hHi                              |
+----------------------------------+
```
