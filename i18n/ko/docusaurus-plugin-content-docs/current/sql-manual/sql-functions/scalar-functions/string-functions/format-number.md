## 설명 {#description}

FORMAT_NUMBER 함수는 숫자 값을 단위 기호가 포함된 문자열로 변환합니다. 지원하는 단위는 K(천), M(백만), B(십억), T(조), Q(천조)입니다.

## 구문 {#syntax}

```sql
FORMAT_NUMBER(<val>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -------- | ----------------------------------------- |
| `<val>` | 형식을 지정할 숫자 값입니다. 타입: DOUBLE |

## 반환값 {#return-value}

단위 기호가 포함된 형식화된 문자열을 VARCHAR 타입으로 반환합니다.

특수한 경우:
- 매개변수가 NULL이면 NULL을 반환합니다.
- 1000 미만의 숫자는 단위 없이 그대로 반환합니다.
- 단위 변환 규칙:
  - K: 천 (1,000)
  - M: 백만 (1,000,000)
  - B: 십억 (1,000,000,000)
  - T: 조 (1,000,000,000,000)
  - Q: 천조 (1,000,000,000,000,000)

## 예제 {#examples}

1. 기본 사용법: 천(K)
```sql
SELECT format_number(1500);
```
```text
+---------------------+
| format_number(1500) |
+---------------------+
| 1.50K               |
+---------------------+
```

2. 백만(M)
```sql
SELECT format_number(5000000);
```
```text
+------------------------+
| format_number(5000000) |
+------------------------+
| 5.00M                  |
+------------------------+
```

3. 천 미만의 숫자
```sql
SELECT format_number(999);
```
```text
+----------------------------------+
| format_number(cast(999 as DOUBLE))|
+----------------------------------+
| 999                              |
+----------------------------------+
```

4. NULL 값 처리
```sql
SELECT format_number(NULL);
```
```text
+---------------------+
| format_number(NULL) |
+---------------------+
| NULL                |
+---------------------+
```
