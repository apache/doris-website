## 설명 {#description}

FORMAT 함수는 지정된 형식 문자열과 매개변수에 따라 서식이 적용된 문자열을 반환합니다. 서식 규칙은 [fmt 형식 명세](https://fmt.dev/11.1/syntax/#format-specification-mini-language)를 따릅니다.

## 구문 {#syntax}

```sql
FORMAT(<format>, <args>[, ...])
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| ---------- | ----------------------------------------- |
| `<format>` | 서식 자리 표시자가 포함된 형식 문자열. 타입: VARCHAR |
| `<args>` | 서식을 적용할 매개변수(여러 개 지정 가능). 타입: ANY |

## 반환값 {#return-value}

형식 문자열에 따라 서식이 적용된 결과를 VARCHAR 타입으로 반환합니다.

특수한 경우:
- 매개변수 중 하나라도 NULL이면 NULL을 반환합니다
- 형식 문자열은 `{}`를 자리 표시자로 사용합니다
- 위치 매개변수(예: `{0}`, `{1}`)와 이름이 지정된 매개변수를 지원합니다
- 다양한 서식 옵션(정렬, 정밀도, 패딩 등)을 지원합니다

## 예제 {#examples}

1. 기본 사용법: 숫자의 정밀도 지정
```sql
SELECT format('{:.2}', pi());
```
```text
+-----------------------+
| format('{:.2}', pi()) |
+-----------------------+
| 3.1                   |
+-----------------------+
```

2. 여러 매개변수의 서식 지정
```sql
SELECT format('{0}-{1}', 'hello', 'world');
```
```text
+-------------------------------------+
| format('{0}-{1}', 'hello', 'world') |
+-------------------------------------+
| hello-world                         |
+-------------------------------------+
```

3. 정렬 및 패딩
```sql
SELECT format('{:>10}', 123);
```
```text
+-----------------------+
| format('{:>10}', 123) |
+-----------------------+
|        123            |
+-----------------------+
```

4. NULL 값 처리
```sql
SELECT format('{:.2}', NULL);
```
```text
+-----------------------+
| format('{:.2}', NULL) |
+-----------------------+
| NULL                  |
+-----------------------+
```

5. UTF-8 문자열 처리
```sql
SELECT format('{0}-{1}', 'ṭṛṭṛ', 'ṭṛ');
```
```text
+---------------------------------------------+
| format('{0}-{1}', 'ṭṛṭṛ', 'ṭṛ')             |
+---------------------------------------------+
| ṭṛṭṛ-ṭṛ                                     |
+---------------------------------------------+
```
