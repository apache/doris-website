## 설명 {#description}

ELT 함수는 지정한 인덱스 위치의 문자열을 반환합니다. 인덱스는 1부터 시작합니다.

## 구문 {#syntax}

```sql
ELT(<pos>, <str>[, <str> ...])
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -------- | ----------------------------------------- |
| `<pos>` | 인덱스 위치(1부터 시작). 타입: INT |
| `<str>` | 문자열 목록. 타입: VARCHAR |

## 반환값 {#return-value}

지정한 인덱스 위치의 문자열을 VARCHAR 타입으로 반환합니다.

특수한 경우:
- `<pos>`가 1보다 작거나 문자열 개수보다 크면 NULL을 반환합니다.
- `<pos>`가 NULL이면 NULL을 반환합니다.
- 인덱스는 1부터 시작하며, 첫 번째 문자열의 인덱스는 1입니다.

## 예제 {#examples}

1. 기본 사용법: 1번째 문자열 조회
```sql
SELECT ELT(1, 'aaa', 'bbb', 'ccc');
```
```text
+-----------------------------+
| elt(1, 'aaa', 'bbb', 'ccc') |
+-----------------------------+
| aaa                         |
+-----------------------------+
```

2. 2번째 문자열 조회
```sql
SELECT ELT(2, 'aaa', 'bbb', 'ccc');
```
```text
+-----------------------------+
| elt(2, 'aaa', 'bbb', 'ccc') |
+-----------------------------+
| bbb                         |
+-----------------------------+
```

3. 인덱스가 범위를 벗어나면 NULL 반환
```sql
SELECT ELT(0, 'aaa', 'bbb'), ELT(5, 'aaa', 'bbb');
```
```text
+----------------------+----------------------+
| elt(0, 'aaa', 'bbb') | elt(5, 'aaa', 'bbb') |
+----------------------+----------------------+
| NULL                 | NULL                 |
+----------------------+----------------------+
```

4. NULL 값 처리
```sql
SELECT ELT(NULL, 'aaa', 'bbb');
```
```text
+-------------------------+
| elt(NULL, 'aaa', 'bbb') |
+-------------------------+
| NULL                    |
+-------------------------+
```

5. 인덱스가 범위를 초과하면 NULL 반환

```sql
SELECT ELT(5, 'aaa', 'bbb', 'ccc');
```

```text
+-----------------------------+
| elt(5, 'aaa', 'bbb', 'ccc') |
+-----------------------------+
| NULL                        |
+-----------------------------+
```

6. 인덱스가 음수이면 NULL 반환

```sql
SELECT ELT(-1, 'first', 'second');
```

```text
+----------------------------+
| elt(-1, 'first', 'second') |
+----------------------------+
| NULL                       |
+----------------------------+
```

7. UTF-8 문자열

```sql
SELECT 
    ELT(2, 'Hello', 'ṭṛ', 'Hola');
```

```text
+-----------------------------------+
| ELT(2, 'Hello', 'ṭṛ', 'Hola')     |
+-----------------------------------+
| ṭṛ                                |
+-----------------------------------+
```

8. 빈 문자열 처리

```sql
SELECT ELT(2, 'first', '', 'third');
```

```text
+------------------------------+
| elt(2, 'first', '', 'third') |
+------------------------------+
|                              |
+------------------------------+
```
