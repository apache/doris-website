## 설명 {#description}

TRIM 함수는 문자열 양쪽 끝에서 연속된 공백이나 지정된 문자열을 제거하는 데 사용됩니다. 두 번째 매개변수를 지정하지 않으면 앞뒤 공백을 제거하고, 지정하면 양쪽 끝에서 지정된 문자열 전체를 제거합니다.

## 구문 {#syntax}

```sql
TRIM(<str>[, <rhs>])
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| --------- | ----------- |
| `<str>` | 처리할 문자열입니다. 타입: VARCHAR |
| `<rhs>` | 양쪽 끝에서 제거할 문자를 지정하는 선택적 매개변수입니다. 타입: VARCHAR |

## 반환값 {#return-value}

VARCHAR 타입의 값을 반환합니다.

특수한 경우:
- 매개변수 중 하나라도 NULL이면 NULL을 반환합니다
- rhs를 지정하지 않으면 앞뒤 공백을 제거합니다
- rhs를 지정하면 양쪽 끝에서 rhs 문자열 전체를 제거합니다(문자 단위로 제거하지 않음)

## 예제 {#examples}

1. 앞뒤 공백 제거
```sql
SELECT trim('   ab d   ') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. 양쪽 끝에서 지정된 문자열 제거: `trim(str, rhs)`는 `<rhs>`를 `<str>`의 양쪽 끝에서 반복적으로 제거하며, 어느 쪽 끝도 더 이상 `<rhs>`로 시작하거나 끝나지 않을 때까지 수행합니다.
```sql
SELECT trim('ababccaab', 'ab') str;
```
```text
+------+
| str  |
+------+
| cca  |
+------+
```

3. UTF-8 문자 지원
```sql
SELECT trim('   ṭṛì ḍḍumai   ');
```
```text
+------------------------------+
| trim('   ṭṛì ḍḍumai   ')     |
+------------------------------+
| ṭṛì ḍḍumai                   |
+------------------------------+
```

4. 일치하는 접두사/접미사가 없으면 원본 문자열 반환
```sql
SELECT trim('Hello World', 'xyz');
```
```text
+--------------------------------+
| trim('Hello World', 'xyz')     |
+--------------------------------+
| Hello World                    |
+--------------------------------+
```

5. NULL 값 처리
```sql
SELECT trim(NULL), trim('Hello', NULL);
```
```text
+------------+-----------------------+
| trim(NULL) | trim('Hello', NULL)   |
+------------+-----------------------+
| NULL       | NULL                  |
+------------+-----------------------+
```

6. 빈 문자열 처리
```sql
SELECT trim(''), trim('abc', '');
```
```text
+----------+------------------+
| trim('') | trim('abc', '')  |
+----------+------------------+
|          | abc              |
+----------+------------------+
```

7. 양쪽 끝에서 반복되는 패턴 제거
```sql
SELECT trim('abcabcabc', 'abc');
```
```text
+------------------------------+
| trim('abcabcabc', 'abc')     |
+------------------------------+
|                              |
+------------------------------+
```

8. 비대칭 제거
```sql
SELECT trim('abcHelloabc', 'abc');
```
```text
+--------------------------------+
| trim('abcHelloabc', 'abc')     |
+--------------------------------+
| Hello                          |
+--------------------------------+
```

9. UTF-8 문자열에 UTF-8 제거 패턴 적용: 앞부분의 `ṭṛì`만 제거됩니다. 뒷부분은 패턴과 일치하지 않으므로(`+++`), 해당 끝에서는 제거가 중단됩니다.
```sql
SELECT trim('ṭṛì ḍḍumai+++', 'ṭṛì');
```
```text
+--------------------------------------------+
| trim('ṭṛì ḍḍumai+++', 'ṭṛì')               |
+--------------------------------------------+
|  ḍḍumai+++                                 |
+--------------------------------------------+
```
