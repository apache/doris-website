# CHAR {#char}

## 설명 {#description}

CHAR 함수는 각 인수를 정수로 해석하고 해당 정수 코드 값이 나타내는 문자로 구성된 문자열을 반환합니다.

## 구문 {#syntax}

```sql
CHAR(<expr>[, <expr> ...] [USING <charset_name>])
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| ------------------ | ----------------------------------------- |
| `<expr>` | 문자로 변환할 정수 코드 값. 타입: INT |

## 반환 값 {#return-value}

인수의 정수 코드 값에 해당하는 문자로 구성된 문자열을 VARCHAR 타입으로 반환합니다.

특수한 경우:
- 인수 중 하나라도 NULL이면 빈 문자열을 반환합니다
- 결과 문자열이 지정된 문자 집합에서 유효하지 않으면 NULL을 반환합니다
- 255보다 큰 인수는 멀티바이트 문자로 변환됩니다. 예를 들어, `CHAR(15049882)`는 `CHAR(229, 164, 154)`와 동일합니다

## 예제 {#examples}

1. 기본 사용법: ASCII 문자 생성
```sql
SELECT CHAR(68, 111, 114, 105, 115);
```
```text
+--------------------------------------+
| CHAR(68, 111, 114, 105, 115)         |
+--------------------------------------+
| Doris                                |
+--------------------------------------+
```

2. 멀티바이트 UTF-8 문자(중국어)
```sql
SELECT CHAR(15049882, 15179199, 14989469);
```
```text
+--------------------------------------------+
| CHAR(15049882, 15179199, 14989469)        |
+--------------------------------------------+
| 多睿丝                                     |
+--------------------------------------------+
```

3. 유효하지 않은 문자의 경우 NULL 반환
```sql
SELECT CHAR(255);
```
```text
+-------------------+
| CHAR(255)             |
+-------------------+
| NULL              |
+-------------------+
```

4. NULL 값 처리
```sql
SELECT CHAR(NULL);
```
```text
+------------+
| CHAR(NULL) |
+------------+
|            |
+------------+
```
