## 설명 {#description}
비트 단위 AND 연산을 수행합니다. 비트 단위 AND 연산은 두 정수의 각 비트를 비교하며, 대응하는 두 비트가 모두 1일 때만 결과가 1이고, 그렇지 않으면 0입니다.

지원하는 정수 타입: TINYINT, SMALLINT, INT, BIGINT, LARGEINT

## 구문 {#syntax}
```sql
BITAND(<lhs>, <rhs>)
```

## 매개변수 {#parameters}
- `<lhs>`: 비트 단위 AND 연산에 사용할 첫 번째 정수입니다.
- `<rhs>`: 비트 단위 AND 연산에 사용할 두 번째 정수입니다.

## 반환값 {#return-value}
두 정수 간의 비트 단위 AND 연산 결과를 반환합니다.


## 예제 {#examples}
1. 예제 1
    ```sql
    select BITAND(3,5), BITAND(5, 10), BITAND(7, 10);
    ```
    ```text
    +-------------+---------------+---------------+
    | BITAND(3,5) | BITAND(5, 10) | BITAND(7, 10) |
    +-------------+---------------+---------------+
    |           1 |             0 |             2 |
    +-------------+---------------+---------------+
    ```
2. NULL 인수
    ```sql
    select BITAND(1, null), BITAND(null, 1), BITAND(null, null);
    ```
    ```text
    +-----------------+-----------------+--------------------+
    | BITAND(1, null) | BITAND(null, 1) | BITAND(null, null) |
    +-----------------+-----------------+--------------------+
    |            NULL |            NULL |               NULL |
    +-----------------+-----------------+--------------------+
    ```
