## 설명 {#description}

문자열 또는 바이너리 값의 비트 길이(즉, 바이트 길이 × 8)를 반환합니다.

## 구문 {#syntax}
```sql
BIT_LENGTH(<str>)
```

## 매개변수 {#parameters}
- `<str>` 비트 길이를 반환할 문자열 값입니다.

## 반환 값 {#return-value}

`<str>`의 이진 표현에서 모든 `0`과 `1` 비트를 세어 해당 값이 차지하는 비트 수를 반환합니다.

## 예제 {#examples}
1. 예제 1
    ```sql
    select BIT_LENGTH("abc"), BIT_LENGTH("中国"), BIT_LENGTH(123);
    ```

    ```text
    +-------------------+----------------------+-----------------+
    | BIT_LENGTH("abc") | BIT_LENGTH("中国")   | BIT_LENGTH(123) |
    +-------------------+----------------------+-----------------+
    |                24 |                   48 |              24 |
    +-------------------+----------------------+-----------------+
    ```
2. NULL 인수
    ```sql
    select BIT_LENGTH(NULL);
    ```
    ```text
    +------------------+
    | BIT_LENGTH(NULL) |
    +------------------+
    |             NULL |
    +------------------+
    ```
