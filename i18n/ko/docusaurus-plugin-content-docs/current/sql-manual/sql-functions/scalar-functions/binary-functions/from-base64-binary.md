## 설명 {#description}

FROM_BASE64_BINARY 함수는 Base64로 인코딩된 문자열을 디코딩하여 결과를 VARBINARY 값으로 반환합니다.

특수한 경우:

- 입력 문자열이 유효한 Base64 인코딩 문자열이 아니면 함수는 NULL을 반환합니다.

## 구문 {#syntax}

```sql
FROM_BASE64_BINARY ( <str> )
```

## 매개변수 {#parameters}

| 매개변수 | 설명                                            |
| --------- | ------------------------------------------------------ |
| `<str>`   | 디코딩할 Base64 인코딩 문자열입니다.               |

## 반환값 {#return-value}

매개변수 `<str>`를 Base64로 디코딩한 결과를 VARBINARY 값으로 반환합니다.

특수한 경우:

- 입력 문자열이 유효하지 않으면(Base64 인코딩에 사용할 수 없는 문자가 포함된 경우) NULL을 반환합니다.

## 예제 {#example}

```sql
SELECT FROM_BASE64_BINARY('MQ==');
```

```text
+--------------------------------------------------------+
| FROM_BASE64_BINARY('MQ==')                             |
+--------------------------------------------------------+
| 0x31                                                   |
+--------------------------------------------------------+
```

```sql
SELECT FROM_BASE64_BINARY('MjM0');
```

```text
+--------------------------------------------------------+
| FROM_BASE64_BINARY('MjM0')                             |
+--------------------------------------------------------+
| 0x323334                                               |
+--------------------------------------------------------+
```

```sql
SELECT FROM_BASE64_BINARY(NULL);
```

```text
+----------------------------------------------------+
| FROM_BASE64_BINARY(NULL)                           |
+----------------------------------------------------+
| NULL                                               |
+----------------------------------------------------+
```
