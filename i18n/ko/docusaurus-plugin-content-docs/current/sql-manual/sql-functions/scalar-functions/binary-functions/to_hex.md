## 설명 {#description}

입력 문자열을 십육진수로 표현된 해당 바이트 시퀀스로 변환합니다.

## 별칭 {#alias}

TO_BINARY

## 구문 {#syntax}

```sql
TO_HEX(<str>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<str>` | 변환할 문자열 데이터 |

## 반환 값 {#return-value}

디코딩된 VARBINARY를 반환합니다(0x 접두사가 붙은 십육진수 형식으로 표시됨).
다음 조건 중 하나라도 충족되면 NULL을 반환합니다:
입력이 NULL인 경우;
입력 길이가 0인 경우;
입력 길이가 홀수인 경우;
입력에 [0-9a-fA-F] 이외의 문자가 포함된 경우;
디코딩된 결과의 길이가 0인 경우(디코딩 실패).

## 예제 {#examples}

```sql
select to_hex(NULL),to_hex('a');
```

```text
+----------------------------+--------------------------+
| to_hex(NULL)               | to_hex('a')              |
+----------------------------+--------------------------+
| NULL                       | NULL                     |
+----------------------------+--------------------------+
```

```sql
select to_hex('ab');
```

```text
+----------------------------+
| to_hex('ab')               |
+----------------------------+
| 0xAB                       |
+----------------------------+
```

```sql
select to_hex('000A');
```

```text
+--------------------------------+
| to_hex('000A')                 |
+--------------------------------+
| 0x000A                         |
+--------------------------------+
```
