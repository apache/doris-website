## 설명 {#description}

`QUARTERS_DIFF` 함수는 두 날짜 사이의 분기 수를 계산합니다. 이 함수는 두 날짜를 매개변수로 받아 첫 번째 날짜에서 두 번째 날짜를 뺀 분기 차이를 반환합니다. 분기 차이는 개월 수 차이를 3으로 나눈 후 소수점 이하를 버린 값과 같습니다.

## 구문 {#syntax}

```sql
QUARTERS_DIFF(<enddate>, <startdate>)
```

## 매개변수 {#parameters}

| 매개변수     | 설명                                                                           |
|---------------|--------------------------------------------------------------------------------------|
| `<enddate>`   | 종료 날짜입니다. `DATE`, `DATETIME` 또는 `TIMESTAMP_NS`를 지원합니다. |
| `<startdate>` | 시작 날짜입니다. `DATE`, `DATETIME` 또는 `TIMESTAMP_NS`를 지원합니다. |

## 반환 값 {#return-value}

`<startdate>`를 `<enddate>`에서 뺀 결과를 분기 수로 반환합니다.
- `<enddate>` 또는 `<startdate>` 중 하나라도 NULL이면 NULL을 반환합니다.

## 예제 {#examples}

```sql
select QUARTERS_DIFF('2021-03-25', '2020-10-25'), QUARTERS_DIFF('2020-10-25 10:00:00', '2022-12-25 11:00:00');
```

```text
+------------------------------------------+------------------------------------------------------------+
| QUARTERS_DIFF('2021-03-25','2020-10-25') | QUARTERS_DIFF('2020-10-25 10:00:00','2022-12-25 11:00:00') |
+------------------------------------------+------------------------------------------------------------+
|                                        1 |                                                         -8 |
+------------------------------------------+------------------------------------------------------------+
```
