## 설명 {#description}

두 기하 도형이 교차하는지, 즉 하나 이상의 공통점이 있는지(경계에서의 접촉 또는 내부 영역의 겹침 포함) 판별합니다.

:::info 참고
Apache Doris 3.0.6부터 지원됩니다.
:::

## 구문 {#syntax}

```sql
ST_INTERSECTS( <shape1>, <shape2>)
```

## 매개변수 {#parameters}

| 매개변수       | 설명                     |
|----------|------------------------|
| `<shape1>` | 다른 도형과 교차하는지 판별할 첫 번째 기하 도형입니다. Point, Line, Polygon, Circle 등의 타입을 지원합니다. |
| `<shape2>` | 	다른 도형과 교차하는지 판별할 두 번째 기하 도형입니다. Point, Line, Polygon, Circle 등의 타입을 지원합니다. |

## 반환값 {#return-value}

1 반환: shape1이 shape2와 교차합니다.

0 반환: shape1이 shape2와 교차하지 않습니다.

ST_INTERSECTS는 다음과 같은 특수한 경우를 처리합니다:

- 입력 매개변수 중 하나라도 NULL이면 NULL을 반환합니다.
- 입력 기하 도형이 유효하지 않으면 NULL을 반환합니다.
- 입력이 빈 기하 도형이면 NULL을 반환합니다.
- 두 도형이 경계에서만 접하는 경우(공통점이 하나뿐인 경우) 1을 반환합니다(경계에서의 접촉도 교차로 간주합니다).

## 예제 {#example}


다각형 내부의 점(교차, 1 반환)

```sql
SELECT ST_Intersects(ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"), ST_Point(5, 5));
```

```text
+--------------------------------------------------------------------------------------+
| ST_Intersects(ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"), ST_Point(5, 5)) |
+--------------------------------------------------------------------------------------+
|                                                                                    1 |
+--------------------------------------------------------------------------------------+
```

다각형 경계 위의 점(교차, 1 반환)

```sql

mysql> SELECT ST_INTERSECTS(  ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"),  ST_Point(0, 5));
+-----------------------------------------------------------------------------------------+
| ST_INTERSECTS(  ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"),  ST_Point(0, 5)) |
+-----------------------------------------------------------------------------------------+
|                                                                                       1 |
+-----------------------------------------------------------------------------------------+
```

다각형 외부의 점(교차하지 않음, 0 반환)

```sql
mysql> SELECT ST_INTERSECTS(  ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"),  ST_Point(50, 50));

```
