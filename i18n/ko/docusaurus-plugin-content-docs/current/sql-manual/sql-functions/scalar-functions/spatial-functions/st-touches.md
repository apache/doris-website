## 설명 {#description}

두 기하 도형이 경계에서만 접하는지(즉, 경계에 공통점이 있지만 내부는 교차하지 않는지) 판별합니다. 구체적인 동작은 다음과 같습니다.

두 도형의 경계에 하나 이상의 공통점이 있고 내부가 전혀 교차하지 않으면(겹치는 영역이 없으면) 1을 반환합니다.
경계에 공통점이 없거나 내부가 교차하면(경계가 접하더라도) 0을 반환합니다.

이 함수는 인접한 다각형의 공유 변(경계에서만 접함)이나 선과 다각형 사이의 접점(경계에서만 접함) 등에서 "경계에서만 접하는 경우"와 "내부가 교차하는 경우"를 구분하는 데 사용합니다.

## 구문 {#syntax}

```sql
ST_TOUCHES( <shape1>, <shape2>)
```

## 매개변수 {#parameter}

| 매개변수| 설명                     |
|----------|------------------------|
| `<shape1>` | 접촉 여부를 판별할 첫 번째 기하 도형입니다. Point, LineString, Polygon, Circle 등의 타입을 지원합니다. |
| `<shape2>` | 접촉 여부를 판별할 두 번째 기하 도형입니다. Point, LineString, Polygon, Circle 등의 타입을 지원합니다. |

## 반환값 {#return-value}

shape1이 shape2와 접하면 1을 반환합니다.
shape1이 shape2와 접하지 않으면 0을 반환합니다.

ST_TOUCHES는 다음과 같은 특수한 경우를 처리합니다.

- 입력 매개변수 중 하나라도 NULL이면 NULL을 반환합니다.
- 입력 기하 도형이 유효하지 않으면 NULL을 반환합니다.
- 입력이 빈 기하 객체(예: POINT EMPTY)이면 NULL을 반환합니다.
- 한 도형이 다른 도형 내부에 완전히 포함되어 있으면(내부가 교차하면), 두 도형의 경계가 접하더라도 0을 반환합니다.
- 점이 도형의 경계와 접하면(점에는 내부가 없음) 1을 반환합니다(점의 "경계"는 점 자체이며, 내부 교차 없이 도형의 경계와 일치합니다).

## 예제 {#example}

다각형 경계 위의 점

```sql
mysql> SELECT ST_TOUCHES(  ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"),  ST_Point(0, 5));
+--------------------------------------------------------------------------------------+
| ST_TOUCHES(  ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"),  ST_Point(0, 5)) |
+--------------------------------------------------------------------------------------+
|                                                                                    1 |
+--------------------------------------------------------------------------------------+
```

다각형 경계 위에 있지 않은 점(기하 도형 내부에 있음)

```sql
mysql> SELECT ST_TOUCHES(  ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"),  ST_Point(5, 5));
+--------------------------------------------------------------------------------------+
| ST_TOUCHES(  ST_Polygon("POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))"),  ST_Point(5, 5)) |
+--------------------------------------------------------------------------------------+
|                                                                                    0 |
+--------------------------------------------------------------------------------------+
```


끝점에서 접하는 선

```sql
mysql> SELECT ST_TOUCHES(  ST_Linefromtext("LINESTRING (0 0, 2 2)"),  ST_Linefromtext("LINESTRING (2 2, 4 0)"));
+---------------------------------------------------------------------------------------------------+
| ST_TOUCHES(  ST_Linefromtext("LINESTRING (0 0, 2 2)"),  ST_Linefromtext("LINESTRING (2 2, 4 0)")) |
+---------------------------------------------------------------------------------------------------+
|                                                                                                 1 |
+---------------------------------------------------------------------------------------------------+
```

내부에서 교차하는 선(경계 접촉이 아니므로 0 반환)

```sql
mysql> SELECT ST_TOUCHES(  ST_Linefromtext("LINESTRING (0 0, 10 10)"),  ST_Linefromtext("LINESTRING (0 10, 10 0)"));
+-------------------------------------------------------------------------------------------------------+
| ST_TOUCHES(  ST_Linefromtext("LINESTRING (0 0, 10 10)"),  ST_Linefromtext("LINESTRING (0 10, 10 0)")) |
+-------------------------------------------------------------------------------------------------------+
|                                                                                                     0 |
+-------------------------------------------------------------------------------------------------------+
```
