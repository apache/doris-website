## 설명 {#description}

표준 도형의 WKB(Well-known binary)를 해당하는 메모리 내 기하 객체로 변환합니다

## 별칭 {#alias}

- ST_GEOMFROMWKB

## 구문 {#syntax}

```sql
ST_GEOMETRYFROMWKB( <wkb>)
```
## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- |---------|
| `<wkb>` | 기하 도형의 바이너리 표현으로, 일반적으로 ST_AsBinary 또는 WKB를 생성하는 다른 함수로 생성합니다. 지원되는 기하 타입에는 POINT, LINESTRING,LINE, POLYGON 등 모든 표준 타입이 포함됩니다. |

## 반환값 {#return-value}

입력 WKB에 해당하는 기하 객체를 반환합니다. 입력이 NULL이거나 WKB 형식이 유효하지 않으면 NULL을 반환합니다.

## 예제 {#examples}

POINT 타입 인수

```sql
select ST_AsText(ST_GeometryFromWKB(ST_AsBinary(ST_Point(24.7, 56.7))));
```

```text
+------------------------------------------------------------------+
| st_astext(st_geometryfromwkb(st_asbinary(st_point(24.7, 56.7)))) |
+------------------------------------------------------------------+
| POINT (24.7 56.7)                                                |
+------------------------------------------------------------------+
```

```sql
select ST_AsText(ST_GeomFromWKB(ST_AsBinary(ST_Point(24.7, 56.7))));
```

```text
+--------------------------------------------------------------+
| st_astext(st_geomfromwkb(st_asbinary(st_point(24.7, 56.7)))) |
+--------------------------------------------------------------+
| POINT (24.7 56.7)                                            |
+--------------------------------------------------------------+
```

LINESTRING 타입 인수

```sql
select ST_AsText(ST_GeometryFromWKB(ST_AsBinary(ST_GeometryFromText("LINESTRING (1 1, 2 2)"))));
```

```text
+------------------------------------------------------------------------------------------+
| st_astext(st_geometryfromwkb(st_asbinary(st_geometryfromtext('LINESTRING (1 1, 2 2)')))) |
+------------------------------------------------------------------------------------------+
| LINESTRING (1 1, 2 2)                                                                    |
+------------------------------------------------------------------------------------------+
```
