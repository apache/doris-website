## 설명 {#description}

지구 표면의 닫힌 영역의 면적을 제곱미터 단위로 계산합니다. 입력 매개변수는 지구 표면의 영역을 나타내는 기하 객체(다각형, 원, 다면체 등)입니다.

닫히지 않은 기하 객체(점, 선분 등)의 면적은 0입니다. 유효하지 않은 기하 객체(자기 교차 다각형 등)의 경우 NULL을 반환합니다.


## 구문 {#syntax}

```sql
ST_AREA_SQUARE_METERS( <geo>)
```
## 매개변수 {#parameters}

| 매개변수 | 설명     |
| -- |--------|
| `<geo>` | 지구 표면의 기하 객체입니다. GeoPolygon, GeoCircle, GeoMultiPolygon과 같은 닫힌 영역 유형을 지원합니다. |

## 반환 값 {#return-value}

영역의 면적을 제곱미터 단위로 반환하며, 반환 타입은 DOUBLE입니다.

ST_AREA_SQUARE_METERS는 다음과 같은 경계 조건을 처리합니다.

- 입력 매개변수가 NULL이면 NULL을 반환합니다.
- 입력이 닫히지 않은 기하 객체(점 GeoPoint, 선분 GeoLineString 등)이면 0을 반환합니다.
- 입력 기하 객체가 유효하지 않으면(자기 교차 다각형, 닫히지 않은 다각형 등) NULL을 반환합니다.
- 입력 좌표가 경도/위도 범위(경도 [-180, 180], 위도 [-90, 90])를 벗어나면 NULL을 반환합니다.

## 예제 {#example}

원형 영역(반지름이 1도인 원)

```sql
SELECT ST_Area_Square_Meters(ST_Circle(0, 0, 1));
```

```text
+-------------------------------------------------+
| st_area_square_meters(st_circle(0.0, 0.0, 1.0)) |
+-------------------------------------------------+
|                              3.1415926535897869 |
+-------------------------------------------------+
```

점 객체(면적 없음)

```sql
SELECT ST_Area_Square_Meters(ST_Point(0, 1));
```

```text
+-------------------------------------------+
| st_area_square_meters(st_point(0.0, 1.0)) |
+-------------------------------------------+
|                                         0 |
+-------------------------------------------+
```

선분 객체(면적 없음)

```sql
SELECT ST_Area_Square_Meters(ST_LineFromText("LINESTRING (1 1, 2 2)"));
```

```text
+-----------------------------------------------------------------+
| st_area_square_meters(st_linefromtext('LINESTRING (1 1, 2 2)')) |
+-----------------------------------------------------------------+
|                                                               0 |
+-----------------------------------------------------------------+
```
