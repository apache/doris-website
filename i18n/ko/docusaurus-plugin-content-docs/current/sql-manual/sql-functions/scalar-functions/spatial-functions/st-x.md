## 설명 {#description}

점이 유효한 POINT 타입이면 해당 X 좌표 값을 반환합니다.

## 구문 {#syntax}

```sql
ST_X( <point>)
```

## 매개변수 {#parameters}

| 매개변수   | 설명       |
|------|----------|
| `<point>` | X 좌표를 추출할 기하 객체입니다. 유효한 POINT 타입(2D 점)이어야 하며, X(경도)의 범위는 [-180, 180]이고 Y(위도)의 범위는 [-90, 90]입니다.|

## 반환 값 {#return-value}

기하 좌표의 X 값이며, 타입은 배정밀도 부동소수점 수(Double)입니다.

- 입력이 유효한 POINT 객체이면 점의 X 좌표(배정밀도 부동소수점 수, Double)를 반환합니다.
- 입력이 NULL, POINT 타입이 아닌 객체, 빈 점(POINT EMPTY) 또는 유효하지 않은 점(예: 3D 점)이면 NULL을 반환합니다.

## 예제 {#example}


유효한 점의 X 좌표 추출

```sql
SELECT ST_X(ST_Point(24.7, 56.7));
```

```text
+----------------------------+
| st_x(st_point(24.7, 56.7)) |
+----------------------------+
|                       24.7 |
+----------------------------+
```

입력이 빈 점(POINT EMPTY)인 경우

```sql
mysql> SELECT ST_X(ST_GeometryFromText("POINT EMPTY"));
+------------------------------------------+
| ST_X(ST_GeometryFromText("POINT EMPTY")) |
+------------------------------------------+
|                                     NULL |
+------------------------------------------+
```

입력이 3D 점인 경우(지원되지 않음)

```sql

mysql> SELECT ST_X(ST_GeometryFromText("POINT (10 20 30)"));
+-----------------------------------------------+
| ST_X(ST_GeometryFromText("POINT (10 20 30)")) |
+-----------------------------------------------+
|                                          NULL |
+-----------------------------------------------+
```

입력이 NULL인 경우

```sql
mysql> SELECT ST_X(NULL);
+------------+
| ST_X(NULL) |
+------------+
|       NULL |
+------------+
```


경도가 범위를 벗어난 경우

```sql
mysql> SELECT ST_X(ST_Point(244.7, 56.7));
+-----------------------------+
| ST_X(ST_Point(244.7, 56.7)) |
+-----------------------------+
|                        NULL |
+-----------------------------+
```

위도가 범위를 벗어난 경우

```sql
mysql> SELECT ST_X(ST_Point(44.7, 156.7));
+-----------------------------+
| ST_X(ST_Point(44.7, 156.7)) |
+-----------------------------+
|                        NULL |
+-----------------------------+
```
