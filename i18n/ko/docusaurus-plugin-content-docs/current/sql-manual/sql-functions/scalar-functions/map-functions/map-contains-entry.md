## 설명 {#description}

주어진 `map`에 특정 항목 `(key, value)`가 포함되어 있는지 확인합니다.

## 구문 {#syntax}

```sql
MAP_CONTAINS_ENTRY(<map>, <key>, <value>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<map>` | 입력 map의 내용 |
| `<key>` | 검색할 키 |
| `<value>` | 검색할 값 |

## 반환 값 {#return-value}

주어진 `map`에 특정 `(key, value)` 쌍이 포함되어 있는지 확인합니다. 존재하면 1을 반환하고, 그렇지 않으면 0을 반환합니다. `<map>`이 `NULL`이면 `NULL`을 반환합니다.

키와 값 비교에는 "null-safe equal"을 사용합니다(두 `NULL`을 같은 것으로 간주). 이는 표준 SQL의 정의와 다릅니다.

## 예제 {#example}

```sql
select map_contains_entry(map(null, 1, 2, null), null, 1);
```

```text
+----------------------------------------------------+
| map_contains_entry(map(null, 1, 2, null), null, 1) |
+----------------------------------------------------+
|                                                  1 |
+----------------------------------------------------+
```

```sql
select map_contains_entry(map(1, '100', 0.1, '2'), 1, '100');
```

```text
+-------------------------------------------------------+
| map_contains_entry(map(1, '100', 0.1, '2'), 1, '100') |
+-------------------------------------------------------+
|                                                     1 |
+-------------------------------------------------------+
```

```sql
select map_contains_entry(map(1, '100', 0.1, '2'), 0.11, '2');
```

```text
+--------------------------------------------------------+
| map_contains_entry(map(1, '100', 0.1, '2'), 0.11, '2') |
+--------------------------------------------------------+
|                                                      0 |
+--------------------------------------------------------+
```
