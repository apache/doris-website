## 설명 {#description}

주어진 `map`을 `ARRAY<STRUCT<key, value>>`로 변환합니다.

반환된 배열의 각 요소는 이름이 `key`와 `value`인 두 필드를 갖는 구조체입니다. 두 필드 모두 NULL을 허용합니다.
`key`와 `value` 필드의 타입은 각각 맵의 키 타입 및 값 타입과 같습니다.

## 구문 {#syntax}

```sql
MAP_ENTRIES(<map>)
```

## 매개변수 {#parameters}

| 매개변수 | 설명 |
| -- | -- |
| `<map>` | 입력 맵의 내용 |

## 반환 값 {#return-value}

맵의 항목을 나타내는 구조체 배열을 반환합니다. `<map>`이 `NULL`이면 `NULL`을 반환합니다.

## 예제 {#example}

```sql
select 
  map_entries(map()),
  map_entries(map(1, '100', 0.1, '2'));
```

```text
+--------------------+--------------------------------------------------------+
| map_entries(map()) | map_entries(map(1, '100', 0.1, '2'))                   |
+--------------------+--------------------------------------------------------+
| []                 | [{"key":1.0, "value":"100"}, {"key":0.1, "value":"2"}] |
+--------------------+--------------------------------------------------------+
```
