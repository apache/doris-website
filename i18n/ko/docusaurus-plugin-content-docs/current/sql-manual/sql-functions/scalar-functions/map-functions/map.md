# MAP {#map}

## 설명 {#description}

여러 그룹의 키-값 쌍을 사용하여 특정 타입의 [`MAP<K, V>`](../../../basic-element/sql-data-types/semi-structured/MAP.md)를 생성합니다

## 구문 {#syntax}

```sql
MAP( <key1> , <value1> [, <key2>, <value2> ... ])
```

## 매개변수 {#parameters}
### 선택적 매개변수 {#optional-parameters}
- `<key1>`은 여러 타입을 지원하며([`MAP<K, V>`](../../../basic-element/sql-data-types/semi-structured/MAP.md) 참조), 맵의 키를 구성합니다
- `<value1>`은 맵의 값을 구성합니다
### 가변 매개변수 {#variable-parameters}
여러 그룹의 키-값 매개변수를 지원합니다

## 반환값 {#return-value}

여러 그룹의 키-값 쌍으로 생성한 특정 타입의 `MAP<K, V>`를 반환합니다

## 참고 사항 {#notes}
1. 매개변수의 개수는 짝수여야 하며(0도 가능), 그렇지 않으면 오류가 발생합니다.
2. 키 매개변수는 중복될 수 있지만, Doris는 중복 키를 제거합니다.
3. 키는 NULL일 수 있으며, NULL 키가 여러 개 있으면 중복을 제거합니다.

## 예제 {#examples}
1. 일반 매개변수
    ```sql
    select map(1, "100", 0.1, 2),map(1, "100", 0.1, 2)[1];
    ```

    ```text
    +-----------------------+--------------------------+
    | map(1, "100", 0.1, 2) | map(1, "100", 0.1, 2)[1] |
    +-----------------------+--------------------------+
    | {1.0:"100", 0.1:"2"}  | 100                      |
    +-----------------------+--------------------------+
    ```
2. 매개변수가 없는 경우
    ```sql
    select map();
    ```
    ```text
    +-------+
    | map() |
    +-------+
    | {}    |
    +-------+
    ```
3. NULL 매개변수
    ```sql
    select map(null, 2, 3, null);
    ```
    ```text
    +-----------------------+
    | map(null, 2, 3, null) |
    +-----------------------+
    | {null:2, 3:null}      |
    +-----------------------+
    ```
4. 중복 키가 있으면 중복을 제거합니다
    ```sql
    select map(1, 2, 2, 11, 1, 3, null, "null 1", null, "null 2");
    ```
    ```text
    +--------------------------------------------------------+
    | map(1, 2, 2, 11, 1, 3, null, "null 1", null, "null 2") |
    +--------------------------------------------------------+
    | {2:"11", 1:"3", null:"null 2"}                         |
    +--------------------------------------------------------+
    ```
