## 설명 {#description}

비트 연산자는 하나 또는 두 개의 표현식에 대해 비트 수준에서 지정된 연산을 수행합니다. 이 연산자는 `BIGINT` 타입의 인수만 허용합니다. 따라서 비트 연산자로 처리되는 모든 표현식은 `BIGINT` 타입으로 변환됩니다.  

## 연산자 개요 {#operator-overview}

| 연산자 | 기능                                                                                     | 예제         |  
|----------|----------------------------------------------------------------------------------------------|-----------------|  
| `&`      | 비트 AND 연산을 수행합니다. 대응하는 두 비트가 모두 `1`이면 결과 비트는 `1`이고, 그렇지 않으면 `0`입니다. | `SELECT 1 & 2` |  
| `\|`     | 비트 OR 연산을 수행합니다. 대응하는 비트 중 하나라도 `1`이면 결과 비트는 `1`이고, 그렇지 않으면 `0`입니다.  | `SELECT 1 &#124; 2` |  
| `^`      | 비트 XOR 연산을 수행합니다. 대응하는 비트가 서로 다르면 결과 비트는 `1`이고, 그렇지 않으면 `0`입니다.   | `SELECT 1 ^ 2` |  
| `~`      | 비트 NOT 연산을 수행합니다. 각 비트를 반전하여 `1`은 `0`으로, `0`은 `1`로 바꿉니다.                          | `SELECT ~1`    |
