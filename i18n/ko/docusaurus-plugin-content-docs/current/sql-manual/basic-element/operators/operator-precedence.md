## 설명 {#description}

연산자 우선순위는 표현식에서 연산자가 평가되는 순서를 결정합니다. 표현식에 여러 연산자가 포함된 경우, Doris는 연산자 우선순위가 높은 순서대로 계산을 수행합니다.

## 연산자 우선순위 {#operator-precedence}

우선순위는 위에서 아래로 갈수록 낮아지며, 맨 위가 가장 높습니다.

| 우선순위 | 연산자 |
|------------|----------|
| 1          | !        |
| 2          | + (단항 플러스), - (단항 마이너스), ~ (단항 비트 NOT), ^ |
| 3          | *, /, %, DIV |
| 4          | -, +     |
| 5          | &        |
| 6          | \|       |
| 7          | =(비교), <=>, >=, >, <=, <, <>, !=, IS, LIKE, REGEXP, MATCH, IN |
| 8          | NOT      |
| 9          | AND, &&  |
| 10         | XOR      |
| 11         | OR       |
| 12         | \|\|     |
