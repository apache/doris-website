## 설명 {#description}

예약어는 SQL에서 특별한 의미를 갖는 단어입니다. 예약어는 키워드의 특수한 범주에 속하며, 객체 식별자로 사용하려면 백틱 (`)으로 감싸야 합니다. 예를 들어 ```FROM```과 같이 사용합니다. 객체 식별자에 대한 자세한 내용은 [객체 식별자](./object-identifiers) 섹션을 참조하세요.
