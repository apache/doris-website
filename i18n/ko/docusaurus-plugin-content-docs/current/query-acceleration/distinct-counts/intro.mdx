중복 제거는 분석 워크로드에서 리소스를 가장 많이 사용하는 작업 중 하나입니다. Apache Doris는 `COUNT DISTINCT`를 대체하는 두 가지 전용 데이터 타입을 제공하여 메모리 사용량과 지연 시간을 줄이면서 중복을 제거합니다. 정확한 결과가 필요하면 **BITMAP**을, 저장 공간을 줄이는 대신 1%–2%의 오차를 허용할 수 있으면 **HLL**을 선택하세요.
