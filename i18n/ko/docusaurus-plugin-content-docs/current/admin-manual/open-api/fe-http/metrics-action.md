# 메트릭 액션 {#metrics-action}

## 요청 {#request}

`GET /api/metrics`

## 설명 {#description}

Doris 메트릭 정보를 가져오는 데 사용합니다.

## 경로 매개변수 {#path-parameters}

없음

## 쿼리 매개변수 {#query-parameters}

* `type`

    선택적 매개변수입니다. 기본적으로 모든 메트릭을 표시하며, 다음 값을 사용할 수 있습니다:
    - `core` 핵심 메트릭 출력
    - `json` JSON 형식으로 메트릭 출력
