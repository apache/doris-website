# 개요 {#overview}

Apache Doris 클러스터에는 Doris 시스템 자체의 메타데이터 정보를 저장하기 위한 여러 내장 시스템 데이터베이스가 있습니다.

### information_schema {#information_schema}

`information_schema` 데이터베이스의 모든 테이블은 물리적 실체가 없는 가상 테이블입니다. 이러한 시스템 테이블에는 Doris 클러스터와 데이터베이스, 테이블, 컬럼, 권한 등을 포함한 모든 데이터베이스 객체의 메타데이터가 들어 있습니다. Workload Group, Task 등의 기능 상태 정보도 포함되어 있습니다.

각 Catalog에는 `information_schema` 데이터베이스가 있으며, 해당 Catalog의 데이터베이스와 테이블에 대한 메타데이터만 포함합니다.

`information_schema` 데이터베이스의 모든 테이블은 읽기 전용이며, 사용자는 이 데이터베이스에서 테이블을 수정하거나 삭제하거나 생성할 수 없습니다.

기본적으로 모든 사용자는 이 데이터베이스의 모든 테이블에 대한 읽기 권한을 갖지만, 쿼리 결과는 사용자가 실제로 보유한 권한에 따라 달라집니다. 예를 들어, 사용자 A에게 `db1.table1`에 대한 권한만 있다면 `information_schema.tables` 테이블을 쿼리할 때 `db1.table1`과 관련된 정보만 반환됩니다.

### mysql {#mysql}

`mysql` 데이터베이스의 모든 테이블은 물리적 실체가 없는 가상 테이블입니다. 이러한 시스템 테이블에는 권한 등의 정보가 들어 있으며, 주로 MySQL 생태계와의 호환성을 위해 사용됩니다.

각 Catalog에는 `mysql` 데이터베이스가 있지만, 테이블의 내용은 모두 동일합니다.

`mysql` 데이터베이스의 모든 테이블은 읽기 전용이며, 사용자는 이 데이터베이스에서 테이블을 수정하거나 삭제하거나 생성할 수 없습니다.

### __internal_schema {#__internal_schema}

`__internal_schema` 데이터베이스의 모든 테이블은 Doris의 실제 테이블이며, 사용자가 생성한 데이터 테이블과 같은 방식으로 저장됩니다. Doris 클러스터를 생성하면 이 데이터베이스의 모든 시스템 테이블이 자동으로 생성됩니다.

기본적으로 일반 사용자는 이 데이터베이스의 테이블에 대해 읽기 전용 권한을 갖습니다. 다만, 권한을 부여받으면 이 데이터베이스에서 테이블을 수정하거나 삭제하거나 생성할 수 있습니다.
