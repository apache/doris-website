## 説明

このステートメントは、過去のクエリで参照されたデータベース、テーブル、カラムのヒット情報を表示します。

## 構文

```sql
SHOW QUERY STATS [ { [FOR <db_name>] | [FROM <table_name>] } ] [ALL] [VERBOSE]];
```

## オプションパラメータ

**1. `<db_name>`**

> 指定すると、対象データベースのヒット情報を表示します。

**2. `<table_name>`**

> 指定すると、対象テーブルのヒット状況を照会します。

**3. `ALL`**

> ALL は、すべてのインデックスのヒット情報を表示するかどうかを指定します。

**4. `VERBOSE`**

> VERBOSE は、詳細なヒット情報を表示します。

## アクセス制御要件

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限               | オブジェクト | 備考               |
|:-------------------|:----------|:-------------------|
| SELECT_PRIV        | DATABASE  | 照会対象のデータベースに対する SELECT 権限が必要です |

## 使用上の注意

- データベースとテーブルについて、過去のクエリでのヒット状況を照会します。fe を再起動するとデータはリセットされ、統計は fe ごとに収集されます。

- FOR DATABASE と FROM TABLE にそれぞれデータベース名またはテーブル名を続けることで、照会対象のデータベースまたはテーブルのヒット情報を指定できます。

- ALL と VERBOSE は単独でも併用でも使用できますが、テーブルの照会でのみ使用でき、末尾に指定する必要があります。

- データベースを選択していない場合、'SHOW QUERY STATS' を実行するだけで、すべてのデータベースのヒット状況を表示できます。

- ヒット結果には、QueryCount と FilterCount の二つのカラムが表示される場合があります。QueryCount はそのカラムがクエリで参照された回数、FilterCount は where 条件で使用された回数を示します。
