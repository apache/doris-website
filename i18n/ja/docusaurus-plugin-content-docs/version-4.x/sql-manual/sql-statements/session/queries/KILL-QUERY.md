## 説明

Doris の各接続は個別のスレッドで実行されます。このステートメントを使用して、そのスレッドを終了します。

## 構文

```SQL
KILL [CONNECTION] <processlist_id>
```

## 別の構文

```SQL
KILL QUERY [ { <processlist_id> | <query_id> } ]
```

## 必須パラメータ

**1. `<processlist_id>`**

> 終了する接続スレッドの ID を指定します。

**2. `<query_id>`**

> 終了するクエリの ID を指定します。

## オプションパラメータ

**1. `CONNECTION`**

> スレッドが現在接続されているかどうかを示します。

## 権限要件

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限    | オブジェクト    | 備考                      |
|:--------------|:-----------|:-----------------------|
| ADMIN_PRIV | グローバル | 他のユーザーのクエリや接続を終了するには ADMIN 権限が必要です。自分のクエリを終了する場合は権限が不要です。 |

## 使用上の注意

- スレッドのプロセスリスト ID は、SHOW PROCESSLIST の出力にある Id 列で確認できます。

- 接続 ID は、SELECT CONNECTION_ID() で確認できます。
