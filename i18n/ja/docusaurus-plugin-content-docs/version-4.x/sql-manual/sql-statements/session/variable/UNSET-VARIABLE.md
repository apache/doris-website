## 説明

このステートメントは、Doris のシステム変数を元に戻すために使用します。これらのシステム変数は、グローバルまたはセッションのスコープで変更できます。

## 構文

```sql
UNSET [<effective_scope>] VARIABLE (<variable_name>)
```

## 必須パラメータ
**1. `<variable_name>`**
> 変数名を指定します。すべての変数を元に戻す場合は、キーワード `ALL` を指定できます。

## オプションパラメータ
**1. `<effective_scope>`**
> 適用スコープには `GLOBAL`、`SESSION`、`LOCAL` のいずれかを指定します。省略した場合の既定値は `SESSION` です。`LOCAL` は `SESSION` の別名です。

## アクセス制御要件
この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限  | 対象 | 備考                                        |
| :--------- | :----- | :------------------------------------------- |
| ADMIN_PRIV | セッション  | グローバル変数を元に戻すには管理者権限が必要です。 |

## 使用上の注意

- 変数をグローバルに元に戻せるのは、ADMIN ユーザーのみです。
- `GLOBAL` を指定して変数を元に戻すと、現在使用中のセッションと、新しく開始するセッションにのみ影響します。すでに開いている他のセッションには影響しません。



## 例

- タイムゾーンの値を元に戻す

   ```
   UNSET VARIABLE time_zone;
   ```


- グローバルな実行メモリのサイズを元に戻す

   ```
   UNSET GLOBAL VARIABLE exec_mem_limit;
   ```


- すべての変数をグローバルに元に戻す

   ```
   UNSET GLOBAL VARIABLE ALL;
   ```
