## 説明

"SHOW CHARSET" コマンドは、現在のデータベース管理システムで使用可能な文字セットと、各文字セットに関連する属性を表示します。

属性には、文字セット名、デフォルトの照合順序、最大バイト長などが含まれます。"SHOW CHARSET" コマンドを実行すると、システムでサポートされている文字セットとその詳細を確認できます。

## 構文
```sql
SHOW CHARSET
```

## 戻り値
| 列名 | 説明 |
| -- |-------------|
| Charset | 文字セット |
| Description | 説明 |
| Default Collation | デフォルトの照合順序名 |
| Maxlen | 最大バイト長 |

## 使用例

```sql
SHOW CHARSET;
```

```text
+---------+---------------+-------------------+--------+
| Charset | Description   | Default collation | Maxlen |
+---------+---------------+-------------------+--------+
| utf8mb4 | UTF-8 Unicode | utf8mb4_0900_bin  | 4      |
+---------+---------------+-------------------+--------+
```
