## 説明

このステートメントは、Doris の組み込みデータベースまたはカタログ内のデータベースの作成情報を確認します。

## 構文

```sql
SHOW CREATE DATABASE [<catalog>.]<db_name>;
```

## 必須パラメータ

** 1. `<db_name>`**
>  データベース名

## 省略可能なパラメータ

** 1. `<catalog>`**
>  テーブルが内部か外部かを示します

## 戻り値

| 列 | 説明 |
|:---------|:-----------|
| Database | データベース名 |
| Create Database | 対応するデータベースの作成ステートメント |

## 権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限         | オブジェクト    | 備考             |
|:-----------|:------|:---------------|
| SELECT_PRIV | 対応するデータベース | 対応するデータベースの読み取り権限が必要です |

## 例

- Doris の test データベースの作成情報を表示する

   ```sql
   SHOW CREATE DATABASE test;
   ```

   ```text
   +----------+------------------------+
   | Database | Create Database        |
   +----------+------------------------+
   | test     | CREATE DATABASE `test` |
   +----------+------------------------+
   ```

- Hive カタログ内の hdfs_text データベースの作成情報を表示する

   ```sql
   SHOW CREATE DATABASE hdfs_text;
   ```

   ```text
   +-----------+------------------------------------------------------------------------------------+                         
   | Database  | Create Database                                                                    |                         
   +-----------+------------------------------------------------------------------------------------+                         
   | hdfs_text | CREATE DATABASE `hdfs_text` LOCATION 'hdfs://HDFS1009138/hive/warehouse/hdfs_text' |                         
   +-----------+------------------------------------------------------------------------------------+  
   ```
