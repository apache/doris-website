## 説明

この文はデータベース ID に対応するデータベース名の検索に使用します（管理者のみ使用可能）。

## 構文

```sql
SHOW DATABASE <database_id>
```

## 必須パラメータ

** 1. `<database_id>`**
>  対応するデータベースの ID 番号

## 戻り値

| 列 | 説明 |
|:---------|:-----------|
| DbName | データベース名 |

## 権限

この SQL コマンドを実行するユーザーには、少なくとも以下の権限が必要です。

| 権限         | 対象   | 備考            |
|:-----------|:-----|:--------------|
| ADMIN_PRIV | クラスター全体 | クラスター全体に対する管理者権限が必要です |

## 例

- データベース ID に対応するデータベース名を検索します。

    ```sql
    SHOW DATABASE 10396;
    ```

    ```text
    +------------+
    | DbName     |
    +------------+
    | example_db |
    +------------+
    ```
