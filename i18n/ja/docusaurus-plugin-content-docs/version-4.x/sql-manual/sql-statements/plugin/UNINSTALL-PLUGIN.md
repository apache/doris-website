## 説明

プラグインをアンインストールするためのステートメントです。

## 構文

```sql
UNINSTALL PLUGIN <plugin_name>;
```

## 必須パラメータ

**1. `<plugin_name>`**
> アンインストールするプラグインの名前

## 権限管理

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限 | 対象 | 備考 |
|:-----------|:-----|:--------------|
| ADMIN_PRIV | クラスター全体 | クラスター全体に対する管理者権限が必要です |

## 注意事項

アンインストールできるのは組み込みではないプラグインのみです。

## 例

- プラグインをアンインストールする場合：

    ```sql
    UNINSTALL PLUGIN auditdemo;
    ```
