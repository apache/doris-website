## 説明

このステートメントは、master 以外の Frontend（FE）ノードのメタデータを同期するために使用します。Apache Doris では、master FE ノードのみがメタデータを書き込めるため、その他の FE ノードはメタデータの書き込み操作を master に転送します。master がメタデータの書き込み操作を完了した後、master 以外のノードではメタデータのリプレイに短い遅延が生じる場合があります。このステートメントを使用すると、メタデータを強制的に同期できます。

## 構文

```sql
SYNC;
```

## アクセス制御要件  

すべてのユーザーまたはロールがこの操作を実行できます。


## 例

メタデータを同期します。

    ```sql
    SYNC;
    ```
