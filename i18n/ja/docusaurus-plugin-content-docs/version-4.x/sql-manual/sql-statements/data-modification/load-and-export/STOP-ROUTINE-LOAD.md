## 説明

この構文は Routine Load ジョブを停止するために使用します。PAUSE コマンドとは異なり、停止したジョブは再開できません。再度データを取り込むには、新しいロードジョブを作成する必要があります。

## 構文

```sql
STOP ROUTINE LOAD FOR <job_name>;
```

## 必須パラメータ

**1. `<job_name>`**

> 停止するジョブの名前を指定します。次の形式を使用できます。
>
> - `<job_name>`: 現在のデータベースにある、指定した名前のジョブを停止します
> - `<db_name>.<job_name>`: 指定したデータベースにある、指定した名前のジョブを停止します

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限       | オブジェクト | 説明                                                  |
| :--------- | :----------- | :---------------------------------------------------- |
| LOAD_PRIV  | テーブル     | STOP ROUTINE LOAD には、テーブルに対する LOAD 権限が必要です |

## 注意事項

- 停止操作は取り消せません。停止したジョブは RESUME コマンドで再開できません
- 停止操作は直ちに反映され、実行中のタスクは中断されます
- ジョブを停止する前に、SHOW ROUTINE LOAD コマンドでジョブの状態を確認することを推奨します
- ジョブを一時停止するだけの場合は、代わりに PAUSE コマンドを使用します

## 例

- test1 という名前の Routine Load ジョブを停止する

   ```sql
   STOP ROUTINE LOAD FOR test1;
   ```

- 指定したデータベースにある Routine Load ジョブを停止する

   ```sql
   STOP ROUTINE LOAD FOR example_db.test1;
   ```
