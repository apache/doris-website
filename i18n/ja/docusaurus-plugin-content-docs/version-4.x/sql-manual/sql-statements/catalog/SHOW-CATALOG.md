## 説明

指定したカタログのプロパティを表示します。

## 構文

```sql
SHOW CATALOG <catalog_name>
```


## 必須パラメータ

**1. `<catalog_name>`**

表示するカタログの名前。

## 戻り値

| 列名  | 説明                             |
|-------|----------------------------------|
| Key   | 設定プロパティの名前。           |
| Value | 設定プロパティの値。             |

## 必要な権限

| 権限                                                                                          | 対象       | 説明                                             |
|:----------------------------------------------------------------------------------------------|:-----------|:-------------------------------------------------|
| ADMIN_PRIV / SELECT_PRIV / LOAD_PRIV / ALTER_PRIV / CREATE_PRIV / SHOW_VIEW_PRIV / DROP_PRIV | カタログ   | 上記のいずれかの権限が必要です。                 |

1. 指定したカタログの設定の詳細を表示する

   ```sql
   show catalog test_mysql;
   ```
