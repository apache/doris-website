## 説明

作成済みのカタログを表示します。

## 構文

```sql
SHOW CATALOGS [LIKE <catalog_name>]
```

補足:

1. LIKE: カタログ名に基づくあいまい検索を行います。


## 任意パラメータ

**1. `<catalog_name>`**

表示するカタログの名前です。

## 戻り値

| 列名    | 説明 |
|---|---|
| CatalogId      | データカタログの一意の ID |
| CatalogName    | データカタログの名前。デフォルトの組み込みカタログは「internal」という名前で、変更できません。 |
| Type           | データカタログの種類 |
| IsCurrent      | 現在アクティブなデータカタログかどうかを示します。 |
| CreateTime     | 作成日時 |
| LastUpdateTime | 最終更新日時 |
| Comment        | カタログに関するコメント |

## 必要な権限
| 権限                                                                                    | 対象  | 説明                                     |
|:---------------------------------------------------------------------------------------------|:--------|:------------------------------------------|
| ADMIN_PRIV / SELECT_PRIV / LOAD_PRIV / ALTER_PRIV / CREATE_PRIV / SHOW_VIEW_PRIV / DROP_PRIV | カタログ | 上記のいずれかの権限が必要です。 |


## 例

1. 現在作成されているデータカタログを表示します。

   ```sql
   SHOW CATALOGS;
   ```
   ```sql
    +-----------+-------------+----------+-----------+-------------------------+---------------------+------------------------+
    | CatalogId | CatalogName | Type     | IsCurrent | CreateTime              | LastUpdateTime      | Comment                |
    +-----------+-------------+----------+-----------+-------------------------+---------------------+------------------------+
    |    130100 | hive        | hms      |           | 2023-12-25 16:11:41.687 | 2023-12-25 20:43:18 | NULL                   |
    |         0 | internal    | internal | yes       | UNRECORDED              | NULL                | Doris internal catalog |
    +-----------+-------------+----------+-----------+-------------------------+---------------------+------------------------+
    ```

2. カタログ名であいまい検索を行います。

   ```sql
   SHOW CATALOGS LIKE 'hi%';
   ```
    ```sql
    +-----------+-------------+----------+-----------+-------------------------+---------------------+------------------------+
    | CatalogId | CatalogName | Type     | IsCurrent | CreateTime              | LastUpdateTime      | Comment                |
    +-----------+-------------+----------+-----------+-------------------------+---------------------+------------------------+
    |    130100 | hive        | hms      |           | 2023-12-25 16:11:41.687 | 2023-12-25 20:43:18 | NULL                   |
    +-----------+-------------+----------+-----------+-------------------------+---------------------+------------------------+
   ```
