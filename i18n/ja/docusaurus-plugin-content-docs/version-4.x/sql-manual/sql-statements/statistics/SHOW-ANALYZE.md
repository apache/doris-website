## 説明

統計情報収集ジョブの状態を表示します。

## 構文

```SQL
SHOW [AUTO] ANALYZE [ <table_name> | <job_id> ]
    [ WHERE STATE = {"PENDING" | "RUNNING" | "FINISHED" | "FAILED"} ];
```

## 必須パラメータ

**なし**

## 任意パラメータ

**1. `AUTO`**

> 自動ジョブの情報を表示します。指定しない場合は、デフォルトで手動ジョブの情報を表示します。

**2. `<table_name>`**

> テーブル名。指定すると、そのテーブルに対応するジョブの情報を表示します。指定しない場合は、デフォルトですべてのテーブルのジョブ情報を返します。

**3. `<job_id>`**

> 統計情報収集ジョブの ID。ANALYZE による非同期収集を実行したときに取得します。指定しない場合は、すべてのジョブの情報を返します。

**4. `WHERE STATE = {"PENDING" | "RUNNING" | "FINISHED" | "FAILED"}`**

> ジョブの状態によるフィルター条件。指定しない場合は、デフォルトですべての状態のジョブ情報を表示します。

## 戻り値

| 列 | 説明 |
| -- | -- |
| job_id | 統計情報収集ジョブの一意な ID |
| catalog_name | カタログ名 |
| db_name | データベース名 |
| tbl_name | テーブル名 |
| col_name | 列名のリスト |
| job_type | ジョブの種類 |
| analysis_type | 分析の種類 |
| message | エラーメッセージ |
| last_exec_time_in_ms | 最後に分析を実行した時刻 |
| state | ジョブの状態 |
| progress | ジョブの進捗 |
| schedule_type | スケジュールの種類 |
| start_time | ジョブの開始時刻 |
| end_time | ジョブの終了時刻 |
| priority | ジョブの優先度 |
| enable_partition | パーティション単位の収集を有効にするかを示すフラグ |

## アクセス制御要件

この SQL を実行するユーザーには、少なくとも次の権限が必要です。

| 権限 | オブジェクト | 備考 |
| :-- | :-- | :-- |
| SELECT_PRIV | テーブル | SHOW を実行するには、照会対象のテーブルに対する SELECT_PRIV 権限が必要です。 |
