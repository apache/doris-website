## 説明

バックグラウンドで実行中の統計情報収集ジョブを停止します。

## 構文

```sql
KILL ANALYZE <job_id>
```
## 必須パラメータ

**<job_id>**

> ジョブの ID を指定します。ジョブの job_id は SHOW ANALYZE を使用して取得できます。詳しい使用方法については、「SHOW ANALYZE」の章を参照してください。

## オプションパラメータ

なし

## アクセス制御要件

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限 | オブジェクト | 備考 |
| --------------------- | --------------- | ------------- |
| SELECT_PRIV           | テーブル           |               |

## 使用上の注意

すでに実行が完了したジョブは停止できません。

## 例

ID が 10036 の統計情報収集ジョブを停止します。

```sql
kill analyze 10036
```
