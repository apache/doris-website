## 説明

データベース内に作成されたファイルを表示します。

## 構文

```sql
SHOW FILE { [ FROM | IN ] <database_name>}
```

## 任意パラメータ

**1. `<database_name>`**

> ファイルが属するデータベースを指定します。省略した場合は、現在のセッションのデータベースを使用します。

## 戻り値

| 列          | 説明                                  |
|:------------|:--------------------------------------|
| `Id`        | ファイルをグローバルに一意に識別する ID |
| `DbName`    | ファイルが属するデータベース名          |
| `Catalog`   | ユーザー定義の分類                      |
| `FileName`  | ファイル名                            |
| `FileSize`  | ファイルサイズ（バイト単位）            |
| `IsContent` | コンテンツの有無を示すフラグ             |
| `MD5`       | ファイルの MD5 チェックサム             |

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限         | 対象                | 備考                                                                    |
|:-------------|:--------------------|:------------------------------------------------------------------------|
| `ADMIN_PRIV` | ユーザー / ロール    | このコマンドを実行するには、ユーザーまたはロールに、ファイルが存在するデータベースへのアクセス権限が必要です。 |

## 例

- 現在のセッションのデータベースにアップロードされたファイルを表示します。

   ```sql
   SHOW FILE;
   ```
   ```text
   +-------+--------+----------+--------------------------+----------+-----------+----------------------------------+
   | Id    | DbName | Catalog  | FileName                 | FileSize | IsContent | MD5                              |
   +-------+--------+----------+--------------------------+----------+-----------+----------------------------------+
   | 12006 | testdb | doris_be | doris_be_metadata_layout | 89349    | true      | 9a3f68160b4106b0e923a0aa2fc05599 |
   +-------+--------+----------+--------------------------+----------+-----------+----------------------------------+
   ```

- 指定したデータベースにアップロードされたファイルを表示します。

   ```sql
   SHOW FILE FROM example_db;
   ```
   ```text
   +-------+------------+----------+--------------------------+----------+-----------+----------------------------------+
   | Id    | DbName     | Catalog  | FileName                 | FileSize | IsContent | MD5                              |
   +-------+------------+----------+--------------------------+----------+-----------+----------------------------------+
   | 12007 | example_db | doris_fe | doris_fe_metadata_layout | 569373   | true      | 10385505d3c0d03f085fea6f8d51adfa |
   | 12008 | example_db | doris_be | doris_be_metadata_layout | 89349    | true      | 9a3f68160b4106b0e923a0aa2fc05599 |
   +-------+------------+----------+--------------------------+----------+-----------+----------------------------------+
   ```
