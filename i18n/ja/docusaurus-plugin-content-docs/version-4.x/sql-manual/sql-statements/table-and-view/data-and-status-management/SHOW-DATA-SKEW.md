## 説明

`SHOW DATA SKEW` 文は、テーブルまたはパーティションのデータの偏りを確認するために使用します。この文には次の機能があります。

- テーブル全体のデータ分布を表示できます。
- 指定したパーティションのデータ分布を表示できます。
- バケットごとの行数、データ量、割合を表示します。
- パーティション化されたテーブルとパーティション化されていないテーブルの両方に対応します。

## 構文

```sql
SHOW DATA SKEW FROM [<db_name>.]<table_name> [ PARTITION (<partition_name> [, ...]) ];
```

## 必須パラメータ

**1. `FROM [<db_name>.]<table_name>`**

> 表示するテーブルの名前を指定します。データベース名も指定できます。
>
> テーブル名は、そのデータベース内で一意である必要があります。

## オプションパラメータ

**1. `PARTITION (<partition_name> [, ...])`**

> 表示するパーティション名の一覧を指定します。
>
> このパラメータを指定しない場合、テーブル内のすべてのパーティションのデータ分布を表示します。
>
> パーティション化されていないテーブルでは、パーティション名はテーブル名と同じです。

## 戻り値

| 列名             | 説明                                 |
|------------------|--------------------------------------|
| PartitionName    | パーティション名                     |
| BucketIdx        | バケットのインデックス番号           |
| AvgRowCount      | 平均行数                             |
| AvgDataSize      | 平均データサイズ（バイト単位）       |
| Graph            | データ分布を視覚的に示すグラフ       |
| Percent          | データ量の合計に対する、このバケットのデータ量の割合 |

## アクセス制御要件

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限            | オブジェクト | 備考                                          |
| :-------------- | :---------- | :-------------------------------------------- |
| SELECT          | テーブル   | テーブルを表示するには SELECT 権限が必要です。 |

## 使用上の注意

- データ分布は、パーティションとバケットの二つの軸で表示されます。
- Graph 列では、文字 `>` を使ってデータ分布の割合を視覚的に表します。
- 割合は小数点以下二桁まで表示されます。
- パーティション化されていないテーブルでは、クエリ結果のパーティション名はテーブル名と同じです。

## 例

- パーティション化されたテーブルを作成し、データ分布を確認します。

    ```sql
    CREATE TABLE test_show_data_skew
    (
        id int,
        name string,
        pdate date
    )
    PARTITION BY RANGE(pdate)
    (
        FROM ("2023-04-16") TO ("2023-04-20") INTERVAL 1 DAY
    )
    DISTRIBUTED BY HASH(id) BUCKETS 5
    PROPERTIES (
        "replication_num" = "1"
    );
    ```
