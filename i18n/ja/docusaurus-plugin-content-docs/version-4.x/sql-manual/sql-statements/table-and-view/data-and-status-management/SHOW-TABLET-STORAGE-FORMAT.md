## 説明

このステートメントは、BE（Backend）上のストレージ形式に関する情報を表示します。

## 構文

```sql
SHOW TABLET STORAGE FORMAT [VERBOSE]
```


## オプションパラメータ

** 1. `VERBOSE` **

  より詳細な情報を表示します。

## 戻り値

**デフォルトの出力**（`VERBOSE` を指定しない場合）:

| 列        | データ型 | 説明                                                   |
|-----------|----------|--------------------------------------------------------|
| BackendId | Int      | タブレットのレプリカが配置されている BE（Backend）ノードの ID。 |
| V1Count   | Int      | V1 バージョンのタブレット数。                           |
| V2Count   | Int      | V2 バージョンのタブレット数。                           |

**`VERBOSE` を指定した場合**:

| 列            | データ型 | 説明                                                   |
|---------------|----------|--------------------------------------------------------|
| BackendId     | Int      | タブレットのレプリカが配置されている BE（Backend）ノードの ID。 |
| TabletId      | Int      | タブレットの一意の識別子。                             |
| StorageFormat | String   | タブレットのバージョン。V1 または V2。                  |

## アクセス制御要件

この SQL コマンドを実行するには、少なくとも次の権限が必要です。

| 権限       | 対象           | 備考                                                                           |
|:-----------|:---------------|:-------------------------------------------------------------------------------|
| Admin_priv | データベース   | テーブルやパーティションの管理、システムレベルのコマンドなど、データベースに対する管理操作を実行するために必要です。 |

## 例

- verbose パラメータを指定せずにステートメントを実行します。

  ```sql
  show tablet storage format;
  ```

  ```text
  +-----------+---------+---------+
  | BackendId | V1Count | V2Count |
  +-----------+---------+---------+
  | 10002     | 0       | 2867    |
  +-----------+---------+---------+
  ```

- verbose パラメータを指定してステートメントを実行します。

  ```sql
  show tablet storage format verbose;
  ```

  ```text
  +-----------+----------+---------------+
  | BackendId | TabletId | StorageFormat |
  +-----------+----------+---------------+
  | 10002     | 39227    | V2            |
  | 10002     | 39221    | V2            |
  | 10002     | 39215    | V2            |
  | 10002     | 39199    | V2            |
  +-----------+----------+---------------+
  ```
