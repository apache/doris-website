## 説明

`CANCEL REPAIR TABLE` 文は、指定したテーブルまたはパーティションの高優先度の修復をキャンセルするために使用します。この文には次の機能があります。

- テーブル全体の高優先度の修復をキャンセルできます。
- 指定したパーティションの高優先度の修復をキャンセルできます。
- システムのデフォルトのレプリカ修復メカニズムには影響しません。

## 構文

```sql
ADMIN CANCEL REPAIR TABLE <table_name> [ PARTITION (<partition_name> [, ...]) ];
```

## 必須パラメータ

**1. `<table_name>`**

> 修復をキャンセルするテーブルの名前を指定します。
>
> テーブル名は、データベース内で一意である必要があります。

## 任意パラメータ

**1. `PARTITION (<partition_name> [, ...])`**

> 修復をキャンセルするパーティション名のリストを指定します。
>
> このパラメータを指定しない場合、テーブル全体の高優先度の修復をキャンセルします。

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限  | 対象       | 説明                                      |
| :---- | :--------- | :---------------------------------------- |
| ADMIN | システム   | このコマンドの実行には ADMIN 権限が必要です。 |

## 使用上の注意

- この文は高優先度の修復のみをキャンセルし、システムのデフォルトのレプリカ修復メカニズムは停止しません。
- キャンセル後も、システムはデフォルトのスケジューリング方式でレプリカを修復します。
- 高優先度の修復を再設定する場合は、`ADMIN REPAIR TABLE` コマンドを使用できます。
- このコマンドの効果は、実行後すぐに反映されます。

## 例

- テーブル全体の高優先度の修復をキャンセルします。

    ```sql
    ADMIN CANCEL REPAIR TABLE tbl;
    ```

- 指定したパーティションの高優先度の修復をキャンセルします。

    ```sql
    ADMIN CANCEL REPAIR TABLE tbl PARTITION(p1, p2);
    ```
