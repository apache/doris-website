## 説明 {#description}

`SHOW DATA` ステートメントは、データ量、レプリカ数、行数統計に関する情報を表示します。このステートメントには、次の機能があります。

- 現在のデータベースにあるすべてのテーブルのデータ量とレプリカ数を表示できます。
- 指定したテーブルのマテリアライズドビューについて、データ量、レプリカ数、行数統計を表示できます。
- データベースのクォータ使用状況を表示できます。
- データ量やレプリカ数などで結果を並べ替えられます。

## 構文 {#syntax}

```sql
SHOW DATA [ FROM [<db_name>.]<table_name> ] [ ORDER BY <order_by_clause> ];
```

ここで：

```sql
order_by_clause:
    <column_name> [ ASC | DESC ] [ , <column_name> [ ASC | DESC ] ... ]
```

## オプションのパラメータ {#optional-parameters}

**1. `FROM [<db_name>.]<table_name>`**

> 情報を表示するテーブル名を指定します。データベース名も含めることができます。
>
> このパラメータを指定しない場合は、現在のデータベースにあるすべてのテーブルのデータ情報を表示します。

**2. `ORDER BY <order_by_clause>`**

> 結果セットの並べ替え方法を指定します。
>
> 任意の列を昇順（ASC）または降順（DESC）で並べ替えられます。
>
> 複数の列を組み合わせた並べ替えに対応しています。

## 戻り値 {#return-values}

クエリの条件に応じて、次の結果セットが返されます。

- `FROM` 句を指定しない場合（データベースレベルの情報を表示）：

| 列名             | 説明                                 |
|------------------|--------------------------------------|
| DbId             | データベース ID                      |
| DbName           | データベース名                       |
| Size             | データベースの総データ量             |
| RemoteSize       | リモートストレージのデータ量         |
| RecycleSize      | ごみ箱のデータ量                     |
| RecycleRemoteSize| ごみ箱のリモートストレージのデータ量 |

- `FROM` 句を指定した場合（テーブルレベルの情報を表示）：

| 列名             | 説明                                                 |
|------------------|------------------------------------------------------|
| TableName        | テーブル名                                           |
| IndexName        | インデックス（マテリアライズドビュー）名             |
| Size             | データサイズ                                         |
| ReplicaCount     | レプリカ数                                           |
| RowCount         | 行数統計（特定のテーブルを表示する場合のみ表示）     |

## アクセス制御要件 {#access-control-requirements}

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限             | オブジェクト | 備考                                       |
| :-------------- | :----------- | :----------------------------------------- |
| SELECT          | テーブル     | テーブルを表示するには SELECT 権限が必要です。 |

## 使用上の注意 {#usage-notes}

- データ量の統計には、すべてのレプリカのデータ量の合計が含まれます。
- レプリカ数には、そのテーブルのすべてのマテリアライズドビューに属する、すべてのパーティションとレプリカが含まれます。
- 行数を集計する際は、複数のレプリカの中で最大の行数を使用します。
- 結果セットの `Total` 行は、集計値を示します。
- 結果セットの `Quota` 行は、データベースに現在設定されているクォータを示します。
- 結果セットの `Left` 行は、残りのクォータを示します。
- 各パーティションのサイズを確認するには、`SHOW PARTITIONS` コマンドを使用します。

## 例 {#examples}

- すべてのデータベースのデータ量に関する情報を表示します。

    ```sql
    SHOW DATA;
    ```

    ```
    +-------+-----------------------------------+--------+------------+-------------+-------------------+
    | DbId  | DbName                            | Size   | RemoteSize | RecycleSize | RecycleRemoteSize |
    +-------+-----------------------------------+--------+------------+-------------+-------------------+
    | 21009 | db1                               | 0      | 0          | 0           | 0                 |
    | 22011 | regression_test_inverted_index_p0 | 72764  | 0          | 0           | 0                 |
    | Total | NULL                              | 118946 | 0          | 0           | 0                 |
    +-------+-----------------------------------+--------+------------+-------------+-------------------+
    ```

- 現在のデータベースにあるすべてのテーブルのデータ量に関する情報を表示します。

    ```sql
    USE db1;
    SHOW DATA;
    ```

    ```text
    +-----------+-------------+--------------+
    | TableName | Size        | ReplicaCount |
    +-----------+-------------+--------------+
    | tbl1      | 900.000 B   | 6            |
    | tbl2      | 500.000 B   | 3            |
    | Total     | 1.400 KB    | 9            |
    | Quota     | 1024.000 GB | 1073741824   |
    | Left      | 1021.921 GB | 1073741815   |
    +-----------+-------------+--------------+
    ```

- 指定したテーブルのデータ量に関する詳細情報を表示します。

    ```sql
    SHOW DATA FROM example_db.test;
    ```

    ```text
    +-----------+-----------+-----------+--------------+----------+
    | TableName | IndexName | Size      | ReplicaCount | RowCount |
    +-----------+-----------+-----------+--------------+----------+
    | test      | r1        | 10.000MB  | 30           | 10000    |
    |           | r2        | 20.000MB  | 30           | 20000    |
    |           | test2     | 50.000MB  | 30           | 50000    |
    |           | Total     | 80.000MB  | 90           |          |
    +-----------+-----------+-----------+--------------+----------+
    ```

- レプリカ数の降順、続いてデータ量の昇順で並べ替えます。

    ```sql
    SHOW DATA ORDER BY ReplicaCount DESC, Size ASC;
    ```

    ```text
    +-----------+-------------+--------------+
    | TableName | Size        | ReplicaCount |
    +-----------+-------------+--------------+
    | table_c   | 3.102 KB    | 40           |
    | table_d   | .000        | 20           |
    | table_b   | 324.000 B   | 20           |
    | table_a   | 1.266 KB    | 10           |
    | Total     | 4.684 KB    | 90           |
    | Quota     | 1024.000 GB | 1073741824   |
    | Left      | 1024.000 GB | 1073741734   |
    +-----------+-------------+--------------+
   ```
