## 説明

`CANCEL REBALANCE DISK` 文は、Backend（BE）ノードのディスクデータの高優先度バランシングをキャンセルするために使用します。この文には次の機能があります。

- 指定した BE ノードの高優先度ディスクバランシングをキャンセルできます。
- クラスター全体のすべての BE ノードの高優先度ディスクバランシングをキャンセルできます。
- キャンセル後も、システムはデフォルトのスケジューリング方式で BE ノードのディスクデータをバランシングします。

## 構文

```sql
ADMIN CANCEL REBALANCE DISK [ ON ( "<host>:<port>" [, ... ] ) ];
```

## 任意パラメータ

**1. `"<host>:<port>"`**

> 高優先度ディスクバランシングをキャンセルする BE ノードのリストを指定します。
>
> 各ノードは、ホスト名（または IP アドレス）とハートビートポートで構成されます。
>
> このパラメータを省略すると、すべての BE ノードの高優先度ディスクバランシングがキャンセルされます。

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限  | 対象   | 説明                                      |
| :---- | :----- | :---------------------------------------- |
| ADMIN | System | このコマンドの実行には ADMIN 権限が必要です。 |

## 使用上の注意

- この文は、システムが指定した BE のディスクデータのバランシングを優先しなくなることを示します。ただし、システムはデフォルトのスケジューリング方式で BE のディスクデータのバランシングを続けます。
- このコマンドの実行後、以前に設定された高優先度のバランシング戦略は直ちに無効になります。

## 例

- クラスター内のすべての BE の高優先度ディスクバランシングをキャンセルします。

    ```sql
    ADMIN CANCEL REBALANCE DISK;
    ```

- 指定した BE の高優先度ディスクバランシングをキャンセルします。

```sql
ADMIN CANCEL REBALANCE DISK ON ("192.168.1.1:1234", "192.168.1.2:1234");
```
