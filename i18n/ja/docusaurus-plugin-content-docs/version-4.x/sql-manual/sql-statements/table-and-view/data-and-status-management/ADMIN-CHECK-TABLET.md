## 説明

この文は、指定したタブレット群に対して指定のチェック処理を実行するために使用します。

## 構文

```sql
ADMIN CHECK TABLET ( <tablet_id> [,...] ) PROPERTIES("type" = "<type_value>")
```

## 必須パラメータ

**1. `<tablet_id>`**

指定のチェック処理を実行するタブレットの ID。


## 任意パラメータ

**1. `<type_value>`**

現在サポートされているのは consistency のみです。

- consistency:

  タブレットのレプリカデータの整合性をチェックします。このコマンドは非同期で実行されます。コマンドを送信すると、Doris は対応するタブレットの整合性チェックジョブの実行を開始します。

## 戻り値

この文の最終結果は、`SHOW PROC "/cluster_health/tablet_health";` の結果にある InconsistentNum 列に反映されます。

| 列              | データ型 | 説明                                 |
|-----------------|----------|--------------------------------------|
| InconsistentNum | Int      | データに不整合があるタブレットの数   |


## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限       | 対象         | 説明                                                                                  |
|:-----------|:-------------|:--------------------------------------------------------------------------------------|
| Admin_priv | Database     | テーブル、パーティション、システムレベルのコマンドの管理を含む、データベースの管理操作を実行するために必要です。 |

## 例
- 指定したタブレット群のレプリカデータの整合性をチェックします。

  ```sql
  admin check tablet (10000, 10001) PROPERTIES("type" = "consistency");
  ```
