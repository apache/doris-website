## 説明

この文は、マテリアライズドビューの定期ジョブのスケジューリングを一時停止するために使用します。

## 構文

```sql
PAUSE MATERIALIZED VIEW JOB ON <mv_name>
```

## 必須パラメータ
**1. `<mv_name>`**
> マテリアライズドビューの名前を指定します。
>
> マテリアライズドビュー名は文字で始める必要があります（Unicode 名のサポートが有効な場合は、任意の言語の文字で始めることができます）。名前全体をバッククォートで囲まない限り、空白や特殊文字を含めることはできません（例：`My Object`）。
>
> マテリアライズドビュー名に予約キーワードは使用できません。
>
> 詳細は「予約キーワード」を参照してください。


## アクセス制御要件
この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限  | オブジェクト | 備考                                        |
| :--------- | :----- | :------------------------------------------- |
| ALTER_PRIV | マテリアライズドビュー | PAUSE はマテリアライズドビューに対する ALTER 操作です |


## 使用上の注意

- この文を使用した後は、マテリアライズドビューの RESUME 文を使用して再開できます。


## 例

- マテリアライズドビュー mv1 の定期ジョブのスケジューリングを一時停止します。

    ```sql
    PAUSE MATERIALIZED VIEW JOB ON mv1;
    ```
