## 説明

同期マテリアライズドビューの構築タスクのステータスを確認します。

同期マテリアライズドビューの作成は非同期で行われます。そのため、マテリアライズドビューの作成タスクを送信した後、このコマンドで同期マテリアライズドビューの構築ステータスを確認する必要があります。

## 構文


```sql
SHOW ALTER TABLE MATERIALIZED VIEW FROM <database>
```

## 必須パラメータ

**1. `<database>`**

> 同期マテリアライズドビューのベーステーブルが属するデータベース。

## 権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限       | オブジェクト | 備考                                                         |
| ---------- | ------------ | ------------------------------------------------------------ |
| ALTER_PRIV | テーブル     | 現在のマテリアライズドビューが属するテーブルに対する ALTER_PRIV 権限が必要です。 |

## 例

```sql
SHOW ALTER TABLE MATERIALIZED VIEW FROM doc_db;
```
