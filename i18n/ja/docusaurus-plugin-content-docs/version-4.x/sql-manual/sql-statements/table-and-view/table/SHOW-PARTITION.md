## 説明

SHOW PARTITION は指定したパーティションの詳細情報を表示します。関連するデータベースとテーブルの名前および ID、パーティション名が含まれます。

## 構文

```sql
SHOW PARTITION <partition_id>
```

## 必須パラメータ

**<partition_id>**

> パーティションの ID。パーティション ID は SHOW PARTITIONS などで取得できます。詳細は「SHOW PARTITIONS」のセクションを参照してください。

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも `ADMIN_PRIV` 権限が必要です。

## 例

パーティション ID 13004 の情報を照会します。

```sql
SHOW PARTITION 13004;
```

指定した ID のパーティションが存在する場合、出力は次のようになります。表示されている ID は例です。`13004` を実際のパーティション ID に置き換えてください（`SHOW PARTITIONS` を参照）。該当するパーティションがない場合、`SHOW PARTITION` は空の結果セットを返します。

```sql
+--------+-----------+---------------+-------+---------+
| DbName | TableName | PartitionName | DbId  | TableId |
+--------+-----------+---------------+-------+---------+
| ods    | sales     | sales         | 13003 | 13005   |
+--------+-----------+---------------+-------+---------+
```
