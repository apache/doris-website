## 説明

パーティション ID に対応するデータベース名、テーブル名、パーティション名を検索します。

## 構文

```sql
SHOW PARTITION <partition_id>
```

## 必須パラメータ

**1. `<partition_id>`**

> パーティション ID

## 必要な権限

この SQL を実行するユーザーには、少なくとも次の権限が必要です。

| 権限                  | 対象 | 説明 |
|---------------------|----|----|
| ADMIN_PRIV |    |    |

## 例

1. パーティション ID に対応するデータベース名、テーブル名、パーティション名を検索します。

    ```sql
    SHOW PARTITION 10002;
    ```
