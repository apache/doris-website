## 説明

データテーブルの作成文を表示します。

## 構文

```sql
SHOW [BRIEF] CREATE TABLE [<db_name>.]<table_name>
```

## 必須パラメータ
**1.`<table_name>`**
> テーブルの識別子（名前）を指定します。所属するデータベース内で一意である必要があります。
>
> 識別子は英字で始める必要があります（Unicode 名が有効な場合は任意の言語の文字でも可）。全体をバッククォートで囲まない限り、空白や特殊文字は使用できません（例: `My Object`）。
>
> 識別子には予約語を使用できません。
>
> 詳細は「識別子の要件と予約語」を参照してください。

## 任意パラメータ
**1.`BRIEF`**
> 列定義を除いたテーブルの基本情報のみを表示します。

**2.`<db_name>`**
> データベースの識別子（名前）を指定します。
>
> 識別子は英字で始める必要があります（Unicode 名が有効な場合は任意の言語の文字でも可）。全体をバッククォートで囲まない限り、空白や特殊文字は使用できません（例: `My Database`）。
>
> 識別子には予約語を使用できません。
>
> 詳細は「識別子の要件と予約語」を参照してください。

## 戻り値
| 列名 | 説明 |
| -- |-------------|
| Table | テーブル名          |
| Create Table | テーブル作成文        |

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限         | 対象    | 説明                           |
|:------------------|:----------|:--------------------------------|
| Select_priv       | Table     | SHOW CREATE TABLE はテーブルに対する SELECT 操作に該当します |


## 例

1. テーブルの作成文を表示します

   ```sql
   SHOW CREATE TABLE demo.test_table;
   ```
2. テーブルの簡略化された作成文を表示します

   ```sql
   SHOW BRIEF CREATE TABLE demo.test_table;
   ```
