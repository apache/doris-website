## 説明

パーティション情報を表示します。Internal Catalog と Hive Catalog の両方に対応します。

`Hive Catalog` の場合:

多階層のパーティションを含め、すべてのパーティションを返せます。
## 構文

```sql
SHOW [ TEMPORARY ] PARTITIONS
    FROM [ <db_name>. ] <table_name>
    [ <where_clause> ]
    [ ORDER BY <order_by_key> ]
    [ LIMIT <limit_rows> ];
```

## 必須パラメータ
**1. `<table_name>`**

パーティション情報を表示するテーブル名を指定する必要があります。


## 任意パラメータ
**1. `TEMPORARY`**

一時パーティションの情報を照会するかどうかを指定します。

**2. `<db_name>`**

パーティション情報を表示するデータベース名を指定します。

**3. `<where_clause>`**

フィルター条件。PartitionId、PartitionName、State、Buckets、ReplicationNum、LastConsistencyCheckTime などの列で絞り込めます。

次の点に注意してください。
1. 現在、文字列型の PartitionName と State に対しては、WHERE 句で `=`、`!=`、`like` のみを使用できます。その他の列では `=`、`!=`、`>`、`<`、`>=`、`<=` などを使用できます。
2. WHERE 句で上記の演算子を使用する場合、列名を左辺に置く必要があります。
3. WHERE 句では `AND` を使用できます。

**4. `<order_by_key>`**

並べ替え条件。PartitionId、PartitionName、State、Buckets、ReplicationNum、LastConsistencyCheckTime などの列で並べ替えられます。

**5. `<limit_rows>`**

返される行数の上限。

## 戻り値
| 列                  | データ型 | 説明                                                                                                                                                          |
|--------------------------|----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PartitionId              | bigint   | パーティション ID                                                                                                                                                  |
| PartitionName            | varchar  | パーティション名                                                                                                                                                |
| Visibleバージョン           | int      | このパーティション内のタブレットの Visibleバージョン の最大値。                                                                                                  |
| VisibleバージョンTime       | datetime | このパーティションの最新の Visibleバージョン の時刻。                                                                                                 |
| State                    | varchar  | このパーティションの状態                                                                                                                                   |
| PartitionKey             | datetime | このパーティションのパーティションキー                                                                                                                          |
| Range                    | datetime | このパーティションの範囲                                                                                                                                   |
| DistributionKey          | varchar  | このパーティションの分散キー                                                                                                                       |
| Buckets                  | int      | このパーティションのバケット数                                                                                                                              |
| ReplicationNum           | int      | このパーティションのレプリカ数                                                                                                                             |
| StorageMedium            | varchar  | このパーティションのストレージメディア                                                                                                                          |
| CooldownTime             | datetime | このパーティションのクールダウン時刻。ホット・コールド分離がない場合は [9999-12-31 23:59:59] となり、常にホットデータであることを示します。 |
| RemoteStoragePolicy      | varchar  | このパーティションのリモートストレージポリシー。                                                                                                                  |
| LastConsistencyCheckTime | datetime | このパーティションに対する最後の整合性チェックの時刻。                                                                                          |
| DataSize                 | int      | このパーティションのデータサイズ。                                                                                                                           |
| IsInMemory               | boolean  | メモリ内パーティションかどうか。デフォルトは false です。                                                                                                   |
| ReplicaAllocation        | varchar  | このパーティションのレプリカ配置戦略。                                                                                                          |
| IsMutable                | boolean  | パーティションが変更可能かどうか。デフォルトは true です。                                                                                                        |
| SyncWithBaseTables       | boolean  | パーティションがベーステーブルのデータと同期しているかどうか。                                                                                        |
| UnsyncTables             | varchar  | パーティションが未同期テーブルのパーティションかどうか。                                                                                              |


## 必要な権限
表示するテーブルに対する SHOW 権限が必要です。
