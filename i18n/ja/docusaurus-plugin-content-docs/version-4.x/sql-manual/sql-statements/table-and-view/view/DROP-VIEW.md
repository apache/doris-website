## 説明

現在または指定したデータベースのビューを削除します。

## 構文

```sql
DROP VIEW [ IF EXISTS ] <name>
```
## 必須パラメータ

削除するビューの名前。

## 任意パラメータ

**[ IF EXISTS ]**

このパラメータを指定すると、ビューが存在しない場合もエラーにならず、削除操作をスキップします。

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限 | 対象 | 説明 |
| :-------- | :----- | :---- |
| DROP_PRIV | Table  |       |

## 使用上の注意

削除したビューは復元できません。必要な場合は再作成してください。

## 例

```sql
CREATE VIEW vtest AS SELECT 1, 'test';
DROP VIEW IF EXISTS vtest;
```
