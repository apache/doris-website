## 説明

テーブルから指定名のインデックスを削除します。現在は転置インデックスと ANN インデックスのみをサポートします。

## 構文

```sql
DROP INDEX [ IF EXISTS ] <index_name> ON [ <db_name> . ] <table_name>;
```

## 必須パラメータ

**1. `<index_name>`**: インデックス名。  

**2. `<table_name>`**：インデックスが属するテーブル名。  

## 任意パラメータ

**1. `<db_name>`**：データベース名。省略可能で、指定しない場合は現在のデータベースを使用します。  

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限            | 対象             | 説明                                         |
|:---------------------|:-------------------|:----------------------------------------------|
| ALTER_PRIV           | Table              | DROP INDEX はテーブルに対する ALTER 操作です |

## 例

- インデックスを削除します

   ```sql
   DROP INDEX IF EXISTS index_name ON table1 ;
   ```
