## 説明

テーブル全体または指定したパーティションのインデックスを構築します。テーブル名とインデックス名は必須で、パーティション一覧は任意です。

## 構文

```sql
BUILD INDEX <index_name> ON <table_name> [partition_list]
```

各要素は次のとおりです。

```sql
partition_list
  : PARTITION (<partition_name1>[ , parition_name2 ][ ... ])
```
## 必須パラメータ

**<index_name>**

> インデックスの識別子（名前）を指定します。所属するテーブル内で一意である必要があります。
>
> 識別子は英字で始める必要があります（Unicode 名が有効な場合は任意の言語の文字でも可）。全体をバッククォートで囲まない限り、空白や特殊文字は使用できません（例: `My Object`）。
>
> 識別子には予約語を使用できません。
>
> 詳細は「識別子の要件と予約語」を参照してください。

**<table_name>**

> テーブルの識別子（名前）を指定します。所属するデータベース内で一意である必要があります。
>
> 識別子は英字で始める必要があります（Unicode 名が有効な場合は任意の言語の文字でも可）。全体をバッククォートで囲まない限り、空白や特殊文字は使用できません（例: `My Object`）。
>
> 識別子には予約語を使用できません。
>
> 詳細は「識別子の要件と予約語」を参照してください。

## 任意パラメータ

**<partition_list>**

> カンマ区切りのパーティション識別子（名前）の一覧を指定します。各名前は所属するテーブル内で一意である必要があります。
>
> 識別子は英字で始める必要があります（Unicode 名が有効な場合は任意の言語の文字でも可）。全体をバッククォートで囲まない限り、空白や特殊文字は使用できません（例: `My Object`）。
>
> 識別子には予約語を使用できません。
>
> 詳細は「識別子の要件と予約語」を参照してください。

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限  | 対象 | 説明                                        |
| :--------- | :----- | :------------------------------------------- |
| ALTER_PRIV | Table  | BUILD INDEX はテーブルに対する ALTER 操作です |

## 使用上の注意

- 現在は転置インデックスのみで有効です。BloomFilter インデックスなど、他のインデックスには適用できません。
- 現在はコンピュートとストレージの一体型モードでのみ有効で、分離型モードでは使用できません。
- BUILD INDEX の進捗は SHOW BUILD INDEX で確認できます。

## 例

- table1 全体にインデックス index1 を構築します。

  ```sql
  BUILD INDEX index1 ON table1
  ```

- table1 のパーティション p1 と p2 にインデックス index1 を構築します。

  ```sql
  BUILD INDEX index1 ON table1 PARTITION(p1, p2)
  ```
