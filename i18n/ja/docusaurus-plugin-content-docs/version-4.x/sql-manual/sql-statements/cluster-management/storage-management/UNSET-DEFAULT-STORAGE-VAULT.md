## 説明
デフォルトとして指定されている Storage Vault の設定を解除します。

## 構文

```sql
UNSET DEFAULT STORAGE VAULT
```

## 権限

| 権限       | オブジェクト  | 備考                                             |
| :--------- | :------------ | :----------------------------------------------- |
| ADMIN_PRIV | Storage Vault | この文を実行できるのは管理者ユーザーのみです。   |

## 例

```sql
UNSET DEFAULT STORAGE VAULT
```
