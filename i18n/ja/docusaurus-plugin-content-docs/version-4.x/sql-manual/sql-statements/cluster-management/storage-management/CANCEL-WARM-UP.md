## 説明

Doris で指定したウォームアップジョブをキャンセルします。

## 構文

```sql
CANCEL WARM UP JOB WHERE id = <id>;
```
## 必須パラメータ

> キャンセルするウォームアップジョブの ID。`SHOW WARM UP JOB` コマンドで確認できます。

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも ADMIN_PRIV 権限が必要です。

## 例

`SHOW WARM UP JOB` で、システム内で実行中のウォームアップジョブを確認します。

```sql
SHOW WARM UP JOB
```

実行結果は次のとおりです。

```C++
+----------------+---------------+---------+-------+-------------------------+-------------+----------+------------+--------+
| JobId          | ClusterName   | Status  | Type  | CreateTime              | FinishBatch | AllBatch | FinishTime | ErrMsg |
+----------------+---------------+---------+-------+-------------------------+-------------+----------+------------+--------+
| 90290165739458 | CloudCluster1 | RUNNING | TABLE | 2024-11-11 11:11:42.700 | 1           | 3        | NULL       |        |
+----------------+---------------+---------+-------+-------------------------+-------------+----------+------------+--------+
```

次に、`CANCEL WARM UP` でこのジョブをキャンセルします。

```C++
CANCEL WARM UP JOB WHERE id = 90290165739458;
```

次のエラーが返された場合、指定した ID に対応するウォームアップジョブは存在しません。

```C++
ERROR 1105 (HY000): errCode = 2, detailMessage = job id: 110 does not exist.
```

コマンドが正常に実行された後、`SHOW WARM UP JOB` を再度実行すると、ジョブのステータスが RUNNING から CANCELLED に変わったことを確認できます。

```C++
+----------------+---------------+-----------+-------+-------------------------+-------------+----------+-------------------------+-------------+
| JobId          | ClusterName   | Status    | Type  | CreateTime              | FinishBatch | AllBatch | FinishTime              | ErrMsg      |
+----------------+---------------+-----------+-------+-------------------------+-------------+----------+-------------------------+-------------+
| 90290165739458 | CloudCluster1 | CANCELLED | TABLE | 2024-11-11 11:11:42.700 | 1           | 3        | 2024-11-11 11:11:43.700 | user cancel |
+----------------+---------------+-----------+-------+-------------------------+-------------+----------+-------------------------+-------------+
```
