## 説明

このステートメントは、現在存在する Broker プロセスの状態を表示するために使用します。

## 構文

```sql
SHOW BROKER;
```


## 出力
| カラム         | データ型 | 説明                                                           |
|----------------|----------|----------------------------------------------------------------|
| Name           | varchar  | Broker プロセスの名前                                            |
| Host           | varchar  | Broker プロセスが動作するノードの IP アドレス                     |
| Port           | varchar  | Broker プロセスが動作するノードのポート                           |
| Alive          | varchar  | Broker プロセスが動作するノードの状態                             |
| LastStartTime  | varchar  | Broker プロセスの最終起動時刻                                    |
| LastUpdateTime | varchar  | Broker プロセスの最終更新時刻                                    |
| ErrMsg         | varchar  | Broker プロセスの直近の起動失敗時のエラーメッセージ               |


## アクセス制御要件
このステートメントを実行するユーザーには、`ADMIN/OPERATOR` 権限が必要です。

## 例

1. 現在存在する Broker プロセスの状態を表示する
    ```sql
    show broker;
    ```
    ```text
    +-------------+------------+------+-------+---------------------+---------------------+--------+
    | Name        | Host       | Port | Alive | LastStartTime       | LastUpdateTime      | ErrMsg |
    +-------------+------------+------+-------+---------------------+---------------------+--------+
    | broker_test | 10.10.10.1 | 8196 | true  | 2025-01-21 11:30:10 | 2025-01-21 11:31:40 |        |
    +-------------+------------+------+-------+---------------------+---------------------+--------+
    ```
