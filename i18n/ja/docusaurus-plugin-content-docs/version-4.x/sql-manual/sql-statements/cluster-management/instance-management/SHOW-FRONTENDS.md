## 説明

このステートメントは、FE ノードの基本的なステータス情報を表示します。

## 構文

```sql
SHOW FRONTENDS
```

## 戻り値

| カラム                      | 説明                                                                                          |
|--------------------|-----------------------------------------------------------------------------------------------|
| Name               | Doris における現在の FE の名前です。通常は `fe` で始まるランダムな文字列です。 |
| Host               | 現在の FE の IP アドレスまたはホスト名です。                                                |
| EditLogPort        | 現在の FE の bdbje 通信ポートです。                                               |
| HttpPort           | 現在の FE の http 通信ポートです。                                                                             |
| QueryPort          | 現在の FE の MySQL プロトコル通信ポートです。                                                                          |
| RpcPort            | 現在の FE の thrift RPC 通信ポートです。                                                                       |
| ArrowFlightSqlPort | 現在の FE の ArrowFlight プロトコル通信ポートです。                                                                    |
| Role               | 現在の FE のロールです。取り得る値は FOLLOWER と OBSERVER です。                                                           |
| IsMaster           | 現在の FE がマスターとして選出されているかどうかを示します。                                                                           |
| ClusterId          | 現在の Doris クラスターの ID です。通常はランダムに生成された数値です。                                                                  |
| Join               | 現在の FE ノードが現在の Doris クラスターに正常に参加したかどうかを示します。                                                                 |
| Alive              | 現在の FE が稼働しているかどうかを示します。                                                                                    |
| ReplayedJournalId  | 現在の FE が再生したメタデータログの最大 ID です。                                                                         |
| LastStartTime      | 現在の FE が起動した時刻を示すタイムスタンプです。                                                                                  |
| LastHeartbeat      | 現在の FE が最後に正常に送信したハートビートのタイムスタンプです。                                                                           |
| IsHelper           | 現在の FE が bdbje のヘルパーノードかどうかを示します。                                                                  |
| ErrMsg             | 現在の FE のハートビートが失敗したときのエラーメッセージです。                                                                              |
| Version            | 現在の FE のバージョン情報です。                                                                                   |
| CurrentConnected   | 現在のクライアント接続が、現在の FE ノードに接続されているかどうかを示します。                                                                          |

## アクセス制御要件

この SQL を実行するユーザーには、少なくとも以下の権限が必要です。

| 権限  | オブジェクト | 備考 |
|------------|----|----|
| SELECT_PRIV | internal.information_schema | すべてのユーザーは、デフォルトでこのデータベースに対する権限を持っています。 |

## 使用上の注意

クエリ結果をさらに絞り込む必要がある場合は、テーブル値関数 [frontends()](../../../sql-functions/table-valued-functions/frontends.md) を使用できます。SHOW FRONTENDS は次のステートメントと同等です。

```sql
SELECT * FROM FRONTENDS();
```
