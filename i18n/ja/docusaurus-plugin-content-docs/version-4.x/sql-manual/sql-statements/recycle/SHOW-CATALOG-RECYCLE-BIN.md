## 説明

このステートメントは、ごみ箱にあるデータベース、テーブル、またはパーティションの復元可能なメタデータを表示します。

## 構文

```sql
SHOW CATALOG RECYCLE BIN [ WHERE NAME [ = "<name>" | LIKE "<name_matcher>"] ]
```

## オプションパラメータ

名前による絞り込み

**1. `<name>`**
> データベース、テーブル、またはパーティションの名前。

パターンマッチングによる絞り込み

**1. `<name_matcher>`**
> データベース、テーブル、またはパーティションの名前に一致させるパターン。

## 戻り値

| 列             | 型       | 説明                                                                                                                                                                   |
|----------------|----------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Type           | String   | メタデータの種類：Database、Table、Partition                                                                                                                            |
| Name           | String   | メタデータの名前                                                                                                                                                       |
| DbId           | Bigint   | データベースの ID                                                                                                                                                       |
| TableId        | Bigint   | テーブルの ID                                                                                                                                                           |
| PartitionId    | Bigint   | パーティションの ID                                                                                                                                                     |
| DropTime       | DateTime | メタデータがごみ箱に移動された日時                                                                                                                                     |
| DataSize       | Bigint   | データサイズ。メタデータの種類がデータベースの場合、ごみ箱にあるすべてのテーブルとパーティションのデータサイズを含みます                                               |
| RemoteDataSize | Decimal  | リモートストレージ（HDFS またはオブジェクトストレージ）上のデータサイズ。メタデータの種類がデータベースの場合、ごみ箱にあるすべてのテーブルとパーティションのリモートデータサイズを含みます |

## アクセス制御要件

| 権限        | 対象 | 備考 |
|-------------|------|------|
| ADMIN_PRIV  |      |      |

## 例

1. ごみ箱にあるすべてのメタデータを表示する

    ```sql
    SHOW CATALOG RECYCLE BIN;
    ```

2. ごみ箱にある名前が 'test' のメタデータを表示する

    ```sql
    SHOW CATALOG RECYCLE BIN WHERE NAME = 'test';
    ```

3. ごみ箱にある名前が 'test' で始まるメタデータを表示する

    ```sql
    SHOW CATALOG RECYCLE BIN WHERE NAME LIKE 'test%';
    ```
