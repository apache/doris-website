## 説明

`SHOW CREATE USER` 文は、データベースシステム内のユーザーの作成文を表示します。管理者のアカウント管理に役立ちます。

## 構文

```sql
SHOW CREATE USER '<user_identity>'
```

## 戻り値

| 列         | 説明         |
|:------------|:------------|
| User Identity  | 指定したユーザー識別子 |
| Create Stmt  | 指定したユーザーの作成文 |

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限 | 対象 | 説明                |
| :---------------- | :------------- | :---------------------------- |
| ADMIN_PRIV        | User or Role    | この `SHOW CREATE USER` 操作を実行できるのは、`ADMIN_PRIV` 権限を持つユーザーまたはロールのみです。 |


## 例

指定したユーザーの作成文を表示します。


```sql
SHOW CREATE USER '<user_identity>'
```
