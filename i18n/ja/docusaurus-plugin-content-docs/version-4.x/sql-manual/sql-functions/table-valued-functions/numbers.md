## 説明

`number` という名前の列を一つだけ持つ一時テーブルを生成するテーブル関数です。`const_value` を指定した場合、すべての行の値は `const_value` になります。指定しない場合、値は [0,`number`) の範囲で順に増加します。

## 構文
```sql
NUMBERS(
    "number" = "<number>"
    [, "const_value" = "<const_value>" ]
  );
```

## 必須パラメータ

| フィールド         | 説明               |
|---------------|---------------------------|
| **number**    | 行数        |

## オプションパラメータ

| フィールド             | 説明                              |
|-------------------|------------------------------------------|
| **const_value**   | 生成する一定の値を指定します   |



## 戻り値
| フィールド      | 型    | 説明                     |
|----------------|---------|---------------------------------|
| **number**     | BIGINT  | 各行に返される値 |


## 例
```sql
select * from numbers("number" = "5");
```
```text
+--------+
| number |
+--------+
|      0 |
|      1 |
|      2 |
|      3 |
|      4 |
+--------+
```

```sql
select * from numbers("number" = "5", "const_value" = "-123");
```
```text
+--------+
| number |
+--------+
|   -123 |
|   -123 |
|   -123 |
|   -123 |
|   -123 |
+--------+
```
