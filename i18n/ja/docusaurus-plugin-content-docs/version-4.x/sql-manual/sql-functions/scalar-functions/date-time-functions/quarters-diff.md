## 説明

`QUARTERS_DIFF` 関数は、二つの日付の間の四半期数を計算します。この関数は二つの日付パラメータを受け取り、先に指定した日付から後に指定した日付を引いた四半期単位の差を返します。四半期単位の差は、月単位の差を 3 で割り、ゼロ方向に丸めた値です。

## 構文

```sql
QUARTERS_DIFF(<enddate>, <startdate>)
```

## パラメータ

| パラメータ | 説明 |
|-----------|------|
| `<enddate>` | 終了日。差を計算する際の後の日付を表します。`DATE` 型または `DATETIME` 型をサポートします |
| `<startdate>` | 開始日。差を計算する際の前の日付を表します。`DATE` 型または `DATETIME` 型をサポートします |

## 戻り値

`<startdate>` を `<enddate>` から引いて得られる四半期数を返します。
- `<enddate>` または `<startdate>` が NULL の場合、NULL を返します。

## 例

```sql
select QUARTERS_DIFF('2021-03-25', '2020-10-25'), QUARTERS_DIFF('2020-10-25 10:00:00', '2022-12-25 11:00:00');
```

```text
+------------------------------------------+------------------------------------------------------------+
| QUARTERS_DIFF('2021-03-25','2020-10-25') | QUARTERS_DIFF('2020-10-25 10:00:00','2022-12-25 11:00:00') |
+------------------------------------------+------------------------------------------------------------+
|                                        1 |                                                         -8 |
+------------------------------------------+------------------------------------------------------------+
```
