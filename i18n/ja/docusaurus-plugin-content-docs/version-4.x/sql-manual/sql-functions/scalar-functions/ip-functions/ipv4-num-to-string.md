# IPV4_NUM_TO_STRING

## 説明
Int16、Int32、Int64 の数値を受け取り、ビッグエンディアンの IPv4 アドレスとして解釈します。対応する IPv4 アドレスを A.B.C.D 形式 (ドット区切りの十進数) の文字列として返します。

## 別名
- INET_NTOA

## 構文

```sql
IPV4_NUM_TO_STRING(<ipv4_num>)
```

## パラメータ
| パラメータ | 説明                                      |
|-----------|--------------------------------------------------|
| `<ipv4_num>`      | IPv4 から変換された整数型の値 |


## 戻り値
対応する IPv4 アドレスを A.B.C.D 形式 (ドット区切りの十進数) の文字列として返します。特殊な場合は次のとおりです。
- `NULL` を返す場合: 入力が負の値、または `4294967295` (`'255.255.255.255'` に相当) より大きい場合。

## 例
```sql
select ipv4_num_to_string(3232235521);
```
```text
+--------------------------------+
| ipv4_num_to_string(3232235521) |
+--------------------------------+
| 192.168.0.1                    |
+--------------------------------+
```
