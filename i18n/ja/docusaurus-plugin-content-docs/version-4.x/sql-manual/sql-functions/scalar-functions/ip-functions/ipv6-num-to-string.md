# IPV6_NUM_TO_STRING

## 説明
String 型のバイナリ形式の IPv6 アドレスを受け取り、そのアドレスをテキスト形式の文字列で返します。
- IPv4 マップド IPv6 アドレスは ::ffff:111.222.33.44 のように表されます。

## 別名
- INET6_NTOA

## 構文
```sql
IPV6_NUM_TO_STRING(<ipv6_num>)
```

## パラメータ
| パラメータ | 説明 |
|-----------|--------------------------------------------------|
| `<ipv6_num>` | String 型のバイナリ形式の IPv6 アドレス |

## 戻り値
IPv6 アドレスをテキスト形式の文字列で返します。
- 入力文字列が有効な IPv6 アドレスのバイナリ表現でない場合は `NULL` を返します。


## 例
```sql
select ipv6_num_to_string(unhex('2A0206B8000000000000000000000011')) as addr, ipv6_num_to_string("-23vno12i34nlfwlsj");
```
```text
+--------------+------------------------------------------+
| addr         | ipv6_num_to_string('-23vno12i34nlfwlsj') |
+--------------+------------------------------------------+
| 2a02:6b8::11 | NULL                                     |
+--------------+------------------------------------------+
```
