## 説明

TOP_LEVEL_DOMAIN 関数は URL からトップレベルドメインを抽出します。入力 URL が無効な場合は空文字列を返します。

## 構文

```sql
TOP_LEVEL_DOMAIN(<url>)
```

## 引数
| 引数 | 説明                                                              |
| --------- | ------------------------------------------------------------------------ |
| `<url>` | トップレベルドメインを抽出する対象の URL 文字列。型: VARCHAR |

## 戻り値

VARCHAR 型の値を返します。抽出したトップレベルドメインを表します。

特殊なケース:
- url が NULL の場合、NULL を返します
- url が有効な URL 形式でない場合、空文字列を返します
- 複数階層のドメイン（例: .com.cn）の場合、最後の階層のドメインを返します

## 使用例

1. 基本的なドメインの処理
```sql
SELECT top_level_domain('www.baidu.com');
```
```text
+-----------------------------------+
| top_level_domain('www.baidu.com') |
+-----------------------------------+
| com                               |
+-----------------------------------+
```

2. 複数階層のドメインの処理
```sql
SELECT top_level_domain('www.google.com.cn');
```
```text
+---------------------------------------+
| top_level_domain('www.google.com.cn') |
+---------------------------------------+
| cn                                    |
+---------------------------------------+
```

3. 無効な URL の処理
```sql
SELECT top_level_domain('wwwwwwww');
```
```text
+------------------------------+
| top_level_domain('wwwwwwww') |
+------------------------------+
|                              |
+------------------------------+
```
