## 説明

NGRAM_SEARCH 関数は、二つの文字列間の N-gram 類似度を計算します。類似度は 0 から 1 の範囲で、値が大きいほど文字列が類似しています。

N-gram は、文字列を連続する N 文字からなる集合に分解します。類似度の計算式は `2 * |intersection| / (|set1| + |set2|)` です。

ASCII 文字のみをサポートします。

## 構文

```sql
NGRAM_SEARCH(<text>, <pattern>, <gram_num>)
```

## パラメータ

| パラメータ | 説明 |
| ------------ | ----------------------------------------- |
| `<text>` | 比較するテキスト文字列。型: VARCHAR |
| `<pattern>` | パターン文字列（定数である必要があります）。型: VARCHAR |
| `<gram_num>` | N-gram の N の値（定数である必要があります）。型: INT |

## 戻り値

二つの文字列間の N-gram 類似度を DOUBLE 型で返します（0 から 1 の範囲）。

特殊なケース:
- いずれかのパラメータが NULL の場合、NULL を返します。
- 文字列の長さが `<gram_num>` より短い場合、0 を返します。
- `<pattern>` と `<gram_num>` は定数である必要があります。
- 類似度が 1 でも、文字列が完全に同一とは限りません。

## 例

1. 基本的な使用例: 類似度を計算する
```sql
SELECT ngram_search('123456789', '12345', 3);
```
```text
+---------------------------------------+
| ngram_search('123456789', '12345', 3) |
+---------------------------------------+
|                                   0.6 |
+---------------------------------------+
```

2. 類似度が高い例
```sql
SELECT ngram_search('abababab', 'babababa', 2);
```
```text
+-----------------------------------------+
| ngram_search('abababab', 'babababa', 2) |
+-----------------------------------------+
|                                       1 |
+-----------------------------------------+
```

3. 文字列が短すぎる場合は 0 を返す
```sql
SELECT ngram_search('ab', 'abc', 3);
```
```text
+----------------------------------+
| ngram_search('ab', 'abc', 3)     |
+----------------------------------+
|                                0 |
+----------------------------------+
```

4. NULL 値の扱い
```sql
SELECT ngram_search(NULL, 'test', 2);
```
```text
+--------------------------------+
| ngram_search(NULL, 'test', 2)  |
+--------------------------------+
| NULL                           |
+--------------------------------+
```
