## 説明

LTRIM_IN 関数は文字列の左端から指定した文字を削除します。削除対象の文字を指定しない場合は、デフォルトで先頭の空白を削除します。文字の集合を指定した場合は、その集合内の文字を順序に関係なく左端からすべて削除します。
LTRIM_IN の主な特徴は、指定した集合内の文字を任意の組み合わせで削除することです。一方、LTRIM 関数は文字列の完全一致に基づいて文字を削除します。

## 構文

```sql
LTRIM_IN(<str> [, <rhs>])
```

## パラメータ
| パラメータ | 説明 |
| --------- | ---- |
| `<str>` | 処理対象の文字列。型: VARCHAR |
| `<rhs>` | 省略可能。削除する文字の集合。型: VARCHAR |

## 戻り値

処理後の文字列を VARCHAR 型で返します。

特別な場合:
- str が NULL の場合、NULL を返します
- rhs を指定しない場合、先頭の空白をすべて削除します
- rhs を指定した場合、rhs に含まれない文字に達するまで、左端から rhs に含まれる文字をすべて削除します

## 例

1. 先頭の空白を削除する
```sql
SELECT ltrim_in('   ab d') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. 指定した文字の集合を削除する
```sql
SELECT ltrim_in('ababccaab', 'ab') str;
```
```text
+-------+
| str   |
+-------+
| ccaab |
+-------+
```

3. LTRIM 関数と比較する
```sql
SELECT ltrim_in('abcd', 'ae'),ltrim('abcd', 'abe');
```
```text
+------------------------+----------------------+
| ltrim_in('abcd', 'ae') | ltrim('abcd', 'abe') |
+------------------------+----------------------+
| bcd                    | abcd                 |
+------------------------+----------------------+
```
