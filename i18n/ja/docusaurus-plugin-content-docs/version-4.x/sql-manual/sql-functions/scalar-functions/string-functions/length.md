## 説明

LENGTH 関数は文字列のバイト長を返します。この関数は文字数ではなく、文字列が UTF-8 エンコーディングで占めるバイト数を計算します。

**CHAR_LENGTH との違い:**
- `LENGTH()` はバイト数を返します
- `CHAR_LENGTH()` と `CHARACTER_LENGTH()` は文字数を返します
- ASCII 文字では、バイト数と文字数は同じです
- 中国語の文字や絵文字など、複数バイトの文字では、通常、バイト数が文字数より大きくなります

## 別名
- `OCTET_LENGTH()`

## 構文

```sql
LENGTH(<str>)
```

## パラメータ

| パラメータ | 説明 |
|---------|---------------|
| `<str>` | バイト長を計算する文字列。型: VARCHAR |

## 戻り値

文字列のバイト長を表す INT 型の値を返します。

特殊なケース:
- 引数が NULL の場合は NULL を返します
- 空文字列の場合は 0 を返します
- 結果は UTF-8 エンコーディングでのバイト数です

## 例

1. ASCII 文字（バイト数 = 文字数）
```sql
SELECT LENGTH('abc'), CHAR_LENGTH('abc');
```
```text
+---------------+--------------------+
| LENGTH('abc') | CHAR_LENGTH('abc') |
+---------------+--------------------+
|             3 |                  3 |
+---------------+--------------------+
```

2. 中国語の文字（バイト数 > 文字数）
```sql
SELECT LENGTH('中国'), CHAR_LENGTH('中国');
```
```text
+------------------+---------------------+
| LENGTH('中国')   | CHAR_LENGTH('中国') |
+------------------+---------------------+
|                6 |                   2 |
+------------------+---------------------+
```

3. NULL 値の処理
```sql
SELECT LENGTH(NULL);
```
```text
+--------------+
| LENGTH(NULL) |
+--------------+
|         NULL |
+--------------+
```

4. 空文字列
```sql
SELECT LENGTH('');
```
```text
+------------+
| LENGTH('') |
+------------+
|          0 |
+------------+
```

5. 異なる種類の文字が混在する文字列
```sql
SELECT LENGTH('Hello世界'), CHAR_LENGTH('Hello世界');
```
```text
+-----------------------+----------------------------+
| LENGTH('Hello世界')   | CHAR_LENGTH('Hello世界')   |
+-----------------------+----------------------------+
|                    11 |                          7 |
+-----------------------+----------------------------+
```

6. エスケープ文字と ASCII スペース
```sql
SELECT LENGTH('\t\n\r'), LENGTH('  ');
```
```text
+------------------+--------------+
| LENGTH('\t\n\r') | LENGTH('  ') |
+------------------+--------------+
|                3 |            2 |
+------------------+--------------+
```

7. UTF-8 の複数バイト文字と文字数の比較
```sql
SELECT LENGTH('ṭṛì'), CHAR_LENGTH('ṭṛì');
```
```text
+--------------------+-------------------------+
| LENGTH('ṭṛì')      | CHAR_LENGTH('ṭṛì')      |
+--------------------+-------------------------+
|                  8 |                       3 |
+--------------------+-------------------------+
```

8. 絵文字（通常、各グリフは 4 バイト）
```sql
SELECT LENGTH('😀😁'), CHAR_LENGTH('😀😁');
```
```text
+--------------------+-------------------------+
| LENGTH('😀😁')         | CHAR_LENGTH('😀😁')         |
+--------------------+-------------------------+
|                  8 |                       2 |
+--------------------+-------------------------+
```

9. 数字の文字列
```sql
SELECT LENGTH('12345'), CHAR_LENGTH('12345');
```
```text
+-----------------+----------------------+
| LENGTH('12345') | CHAR_LENGTH('12345') |
+-----------------+----------------------+
|               5 |                    5 |
+-----------------+----------------------+
```
