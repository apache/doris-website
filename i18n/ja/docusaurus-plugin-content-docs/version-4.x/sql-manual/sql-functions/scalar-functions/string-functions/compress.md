## 説明

COMPRESS 関数は、zlib 圧縮アルゴリズムを使用して文字列をバイナリデータに圧縮します。圧縮されたデータは、UNCOMPRESS 関数を使用して元の文字列に展開できます。

## 構文

```sql
COMPRESS(<str>)
```

## パラメータ

| パラメータ | 説明 |
| -------- | ----------------------------------------- |
| `<str>` | 圧縮する文字列。型: VARCHAR |

## 戻り値

VARCHAR 型の値を返します。この値は圧縮されたバイナリデータであり、人が読める形式ではありません。

特殊なケース:
- パラメータが NULL の場合、NULL を返します
- 入力が空文字列 `''` の場合、空文字列 `''` を返します

## 例

1. 基本的な使い方: 圧縮と展開
```sql
SELECT uncompress(compress('hello'));
```
```text 
+-------------------------------+
| uncompress(compress('hello')) |
+-------------------------------+
| hello                         |
+-------------------------------+
```

2. 空文字列の処理
```sql
SELECT compress('');
```
```text 
+--------------+
| compress('') |
+--------------+
|              |
+--------------+
```

3. NULL 値の処理
```sql
SELECT compress(NULL);
```
```text 
+----------------+
| compress(NULL) |
+----------------+
| NULL           |
+----------------+
```

4. UTF-8 文字のテスト
```sql
SELECT uncompress(compress('ṭṛì'));
```
```text
+----------------------------------+
| uncompress(compress('ṭṛì'))      |
+----------------------------------+
| ṭṛì                              |
+----------------------------------+
```
