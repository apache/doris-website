## 説明

UNHEX 関数は十六進数の文字列を元の文字列に戻す、HEX 関数の逆の処理を行います。この関数は十六進数の文字（0-9、A-F、a-f）を二文字ずつ一バイトに変換します。UNHEX_NULL 関数も同様に動作しますが、無効な入力に対しては NULL を返します。これらの関数は、バイナリデータ、暗号化されたデータ、または十六進数で表す必要のあるデータを扱う際に役立ちます。

:::tip
この関数はバージョン 3.0.6 以降でサポートされています。
:::

## 構文

```sql
UNHEX(<str>)
```

## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<str>` | 十六進数の文字列 |

## 戻り値

十六進数から復号した元の文字列を表す VARCHAR 型の値を返します。

復号規則:
- 使用できる文字の範囲: 0-9、a-f、A-F
- 十六進数の文字二文字を一バイトに変換します
- 結果に表示できない文字が含まれる場合があります

特殊なケース（UNHEX）:
- 入力が NULL の場合、NULL を返します
- 文字列の長さが 0 または奇数の場合、空文字列を返します
- 十六進数以外の文字が含まれる場合、空文字列を返します

特殊なケース（UNHEX_NULL）:
- 入力が NULL の場合、NULL を返します
- 文字列の長さが 0 または奇数の場合、NULL を返します
- 十六進数以外の文字が含まれる場合、NULL を返します

## 例

```sql
select unhex('@');
```

```text
+------------+
| unhex('@') |
+------------+
|            |
+------------+
```

```sql
select unhex_null('@');
```

```text
+-----------------+
| unhex_null('@') |
+-----------------+
| NULL            |
+-----------------+
```

```sql
select unhex('41');
```

```text
+-------------+
| unhex('41') |
+-------------+
| A           |
+-------------+
```

```sql
select unhex('4142'), unhex('48656C6C6F');
```

```text
+---------------+----------------------+
| unhex('4142') | unhex('48656C6C6F')  |
+---------------+----------------------+
| AB            | Hello                |
+---------------+----------------------+
```

5. NULL 値の扱いの比較
```sql
SELECT UNHEX(NULL), UNHEX_NULL(NULL);
```
```text
+-------------+-----------------+
| UNHEX(NULL) | UNHEX_NULL(NULL) |
+-------------+-----------------+
| NULL        | NULL            |
+-------------+-----------------+
```

6. UTF-8 文字の復号
```sql
SELECT UNHEX('E4B8AD'), UNHEX('E69687');
```
```text
+-----------------+-----------------+
| UNHEX('E4B8AD') | UNHEX('E69687') |
+-----------------+-----------------+
| 中              | 文              |
+-----------------+-----------------+
```

7. 十六進数への符号化と復号の往復確認
```sql
SELECT UNHEX(HEX('Hello')), UNHEX(HEX('Test123'));
```
```text
+---------------------+------------------------+
| UNHEX(HEX('Hello')) | UNHEX(HEX('Test123'))  |
+---------------------+------------------------+
| Hello               | Test123                |
+---------------------+------------------------+
```

### キーワード

    UNHEX, UNHEX_NULL, HEX
