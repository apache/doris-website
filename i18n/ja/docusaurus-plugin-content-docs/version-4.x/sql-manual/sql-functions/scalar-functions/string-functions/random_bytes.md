## 説明

RANDOM_BYTES 関数は、指定した長さのランダムなバイト列を生成します。返されるバイト列は、十六進数の文字列で表されます。

## 構文

```sql
RANDOM_BYTES(<len>)
```

## パラメータ

| パラメータ | 説明 |
| -------- | ----------------------------------------- |
| `<len>` | 生成するランダムなバイト数。型: INT |

## 戻り値

`0x` を先頭に付けた、ランダムなバイト列を十六進数で表す VARCHAR 型の値を返します。

特殊なケース:
- `<len>` は 0 より大きい必要があります。そうでない場合はエラーを返します。
- 引数が NULL の場合は、NULL を返します。
- 呼び出すたびにランダムな結果を生成します。

## 例

1. 基本的な使い方: 8 バイトのランダムなバイト列を生成する
```sql
SELECT random_bytes(8);
```
```text
+--------------------+
| random_bytes(8)    |
+--------------------+
| 0x1a2b3c4d5e6f7089 |
+--------------------+
```

2. 短いバイト列を生成する
```sql
SELECT random_bytes(4);
```
```text
+----------------+
| random_bytes(4) |
+----------------+
| 0xab12cd34     |
+----------------+
```

3. 無効な引数: 負の数
```sql
SELECT random_bytes(-1);
```
```text
ERROR 1105 (HY000): errCode = 2, detailMessage = (10.16.10.3)[INVALID_ARGUMENT]argument -1 of function random_bytes at row 0 was invalid.
```

4. NULL 値の処理
```sql
SELECT random_bytes(NULL);
```
```text
+--------------------+
| random_bytes(NULL) |
+--------------------+
| NULL               |
+--------------------+
```

5. 長いバイト列を生成する（16 バイト）
```sql
SELECT random_bytes(16);
```
```text
+------------------------------------+
| random_bytes(16)                   |
+------------------------------------+
| 0x1a2b3c4d5e6f708192a3b4c5d6e7f809 |
+------------------------------------+
```

### キーワード
