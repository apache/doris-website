## 説明 {#description}

PARSE_DATA_SIZE 関数は、ストレージ単位を含む文字列（「1.5GB」など）を解析し、バイト単位の数値に変換します。

## 構文 {#syntax}

```sql
PARSE_DATA_SIZE(<str>)
```

## パラメータ {#parameters}

| パラメータ | 説明 |
| -------- | ----------------------------------------- |
| `<str>` | 単位を含むデータサイズの文字列（例: "100MB"、"2.5GB"）。型: VARCHAR |

## 戻り値 {#return-value}

バイト単位に変換した数値を LARGEINT 型で返します。

特記事項:
- 使用できる単位（大文字と小文字を区別します。表記は次のとおりにしてください）: B, kB, MB, GB, TB, PB, EB, ZB, YB
- 単位は 1024 を基数とします（例: 1kB = 1024B）
- 小数に対応しています（例: "2.5MB"）
- パラメータの形式が無効な場合はエラーを返します
- パラメータが NULL の場合は NULL を返します。Doris 4.1 系列では、4.1.5 以降、NULL を許容する列の NULL 行は文字列の解析前にスキップされます

**使用できる単位の一覧:**

| 単位 | 名称 | バイト数 |
|------|------|-------|
| B    | バイト      | 1          |
| kB   | キロバイト  | 1024       |
| MB   | メガバイト  | 1024²      |
| GB   | ギガバイト  | 1024³      |
| TB   | テラバイト  | 1024⁴      |
| PB   | ペタバイト  | 1024⁵      |
| EB   | エクサバイト   | 1024⁶      |

## 例 {#example}

1. 基本的な使い方: バイトを解析する
```sql
SELECT parse_data_size('1024B');
```
```text
+--------------------------+
| parse_data_size('1024B') |
+--------------------------+
| 1024                     |
+--------------------------+
```

2. キロバイトを解析する
```sql
SELECT parse_data_size('1kB');
```
```text
+------------------------+
| parse_data_size('1kB') |
+------------------------+
| 1024                   |
+------------------------+
```

3. 小数を含むメガバイトを解析する
```sql
SELECT parse_data_size('2.5MB');
```
```text
+--------------------------+
| parse_data_size('2.5MB') |
+--------------------------+
| 2621440                  |
+--------------------------+
```

4. ギガバイトを解析する
```sql
SELECT parse_data_size('1GB');
```
```text
+------------------------+
| parse_data_size('1GB') |
+------------------------+
| 1073741824             |
+------------------------+
```

5. テラバイトを解析する
```sql
SELECT parse_data_size('1TB');
```
```text
+------------------------+
| parse_data_size('1TB') |
+------------------------+
| 1099511627776          |
+------------------------+
```

6. サポートされていない単位: エラーになる
```sql
SELECT parse_data_size('1iB');
```
```text
ERROR 1105 (HY000): errCode = 2, detailMessage = (10.16.10.3)[INVALID_ARGUMENT]Invalid Input argument "1iB" of function parse_data_size
```

7. NULL を入力する
```sql
SELECT parse_data_size(NULL);
```
```text
+-----------------------+
| parse_data_size(NULL) |
+-----------------------+
| NULL                  |
+-----------------------+
```
