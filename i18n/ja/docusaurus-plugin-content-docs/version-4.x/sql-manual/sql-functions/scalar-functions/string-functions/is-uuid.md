## 説明

引数が有効な UUID の場合は 1、無効な UUID の場合は 0、NULL の場合は NULL を返します。

長さが正しく、使用可能な文字（大文字または小文字の十六進数字と、省略可能なハイフンおよび波括弧）のみを含む場合、有効な UUID と見なされます。次の三つの形式のいずれかです。
```text
aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
aaaaaaaabbbbccccddddeeeeeeeeeeee
{aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee}
```

## 構文

```sql
IS_UUID ( <str> )
```

## パラメータ
| パラメータ  | 説明 |
|------------|-----------------|
| `<str>` | 文字列 |


## 戻り値

`<str>` が有効な UUID の場合は 1、それ以外の場合は 0 を返します。

特殊なケース:
- 引数が NULL の場合は、NULL を返します。
