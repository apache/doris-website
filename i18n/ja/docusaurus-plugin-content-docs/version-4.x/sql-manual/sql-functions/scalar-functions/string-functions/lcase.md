## 説明

LCASE 関数（別名 LOWER）は、文字列内のすべての大文字を小文字に変換します。

## 構文

```sql
LCASE(<str>)
LOWER(<str>)
```

## パラメータ

| パラメータ | 説明 |
|---------|--------------|
| `<str>` | 小文字に変換する文字列。型: VARCHAR |

## 戻り値

小文字に変換した文字列を表す VARCHAR 型の値を返します。

変換規則:
- 文字列内のすべての大文字を対応する小文字に変換します。
- 数字、記号、空白など、アルファベット以外の要素は変更しません。
- すでに小文字の文字は変更しません。

特殊なケース:
- 引数が NULL の場合は、NULL を返します。
- 文字列が空の場合は、空文字列を返します。
- 文字列に大文字が含まれない場合は、元の文字列を返します。

## 例

1. 基本的な英字の変換
```sql
SELECT LOWER('AbC123'), LCASE('AbC123');
```
```text
+-----------------+-----------------+
| LOWER('AbC123') | LCASE('AbC123') |
+-----------------+-----------------+
| abc123          | abc123          |
+-----------------+-----------------+
```

2. 異なる種類の文字を含む文字列の処理
```sql
SELECT LOWER('Hello World!'), LCASE('TEST@123');
```
```text
+----------------------+------------------+
| LOWER('Hello World!') | LCASE('TEST@123') |
+----------------------+------------------+
| hello world!         | test@123         |
+----------------------+------------------+
```

3. NULL 値の処理
```sql
SELECT LOWER(NULL), LCASE(NULL);
```
```text
+-------------+-------------+
| LOWER(NULL) | LCASE(NULL) |
+-------------+-------------+
| NULL        | NULL        |
+-------------+-------------+
```

4. 空文字列
```sql
SELECT LOWER(''), LCASE('');
```
```text
+-----------+-----------+
| LOWER('') | LCASE('') |
+-----------+-----------+
|           |           |
+-----------+-----------+
```

5. すでに小文字の文字列、または数字のみを含む文字列
```sql
SELECT LOWER('already lowercase'), LCASE('abc123');
```
```text
+----------------------------+-----------------+
| LOWER('already lowercase') | LCASE('abc123') |
+----------------------------+-----------------+
| already lowercase          | abc123          |
+----------------------------+-----------------+
```

6. 英字以外の文字は変更されずにそのまま返される
```sql
SELECT LOWER('123!@#$%'), LCASE('PRICE: $99.99');
```
```text
+-------------------+------------------------+
| LOWER('123!@#$%') | LCASE('PRICE: $99.99') |
+-------------------+------------------------+
| 123!@#$%          | price: $99.99          |
+-------------------+------------------------+
```

7. UTF-8 マルチバイト文字の小文字への変換
```sql
SELECT LOWER('ṬṚÌ TEST'), LCASE('ḌḌUMAI HELLO');
```
```text
+------------------------+---------------------------+
| LOWER('ṬṚÌ TEST')      | LCASE('ḌḌUMAI HELLO')     |
+------------------------+---------------------------+
| ṭṛì test               | ḍḍumai hello              |
+------------------------+---------------------------+
```
