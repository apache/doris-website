## 説明

QUOTE 関数は、文字列をシングルクォートで囲み、文字列内の特殊文字をエスケープして、SQL 文で安全に使用できるようにします。

## 構文

```sql
QUOTE(<str>)
```

## パラメータ

| パラメータ | 説明 |
| ------- | ----------------------------------------- |
| `<str>` | クォートする入力文字列。型: VARCHAR |

## 戻り値

VARCHAR 型を返します。戻り値は、シングルクォートで囲まれ、特殊文字がエスケープされた文字列です。

特殊なケース:
- 入力が NULL の場合、引用符を付けずに文字列 'NULL' を返します
- シングルクォート `'` は `\'` にエスケープされます
- バックスラッシュ `\` は `\\` にエスケープされます
- 空文字列の場合は `''` を返します

## 使用例

1. 基本的な文字列のクォート
```sql
SELECT quote('hello');
```
```text
+----------------+
| quote('hello') |
+----------------+
| 'hello'        |
+----------------+
```

2. シングルクォートを含む文字列（エスケープされます）
```sql
SELECT quote("It's a test");
```
```text
+----------------------+
| quote("It's a test") |
+----------------------+
| 'It's a test'        |
+----------------------+
```

3. NULL 値の処理
```sql
SELECT quote(NULL);
```
```text
+-------------+
| quote(NULL) |
+-------------+
| NULL        |
+-------------+
```

4. 空文字列の処理
```sql
SELECT quote('');
```
```text
+-----------+
| quote('') |
+-----------+
| ''        |
+-----------+
```

5. バックスラッシュ文字
```sql
SELECT quote('aaa\\');
```
```text
+----------------+
| quote('aaa\\') |
+----------------+
| 'aaa\'         |
+----------------+
```

```sql
SELECT quote('aaa\cccb');
```
```text
+-------------------+
| quote('aaa\cccb') |
+-------------------+
| 'aaacccb'         |
+-------------------+
```
