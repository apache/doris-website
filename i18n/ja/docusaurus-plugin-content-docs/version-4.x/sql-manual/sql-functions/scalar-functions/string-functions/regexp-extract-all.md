## 説明

`REGEXP_EXTRACT_ALL` 関数は、指定した文字列 `str` に正規表現を適用し、指定した `pattern` の最初の部分パターンに一致するすべての部分を抽出します。一致した部分を文字列の配列として返すには、パターンが入力文字列 `str` の一部に正確に一致する必要があります。一致する部分がない場合、またはパターンに部分パターンがない場合は、空文字列を返します。

文字集合のマッチングには UTF-8 標準の文字クラスを使用してください。これにより、さまざまな言語の文字を正しく識別して処理できます。

pattern が無効な正規表現の場合は、エラーが発生します。

デフォルトでサポートされる文字マッチングのクラス: https://github.com/google/re2/wiki/Syntax

Doris では、セッション変数 `enable_extended_regex`（デフォルトは `false`）を使用すると、前後読みなどの高度なゼロ幅アサーションを有効にできます。

セッション変数 `enable_extended_regex` を `true` に設定した場合にサポートされる文字マッチングの種類: https://www.boost.org/doc/libs/latest/libs/regex/doc/html/boost_regex/syntax/perl_syntax.html

## 構文

```sql
REGEXP_EXTRACT_ALL(<str>, <pattern>)
```

## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<str>` | String 型。正規表現のマッチング対象となる入力文字列です。文字列リテラル、または文字列データを含むテーブルのカラムへの参照を指定できます。|
| `<pattern>` | String 型。入力文字列 <str> に適用する正規表現パターンです。文字クラス、量指定子、部分パターンなどを含めることができます。|

## 戻り値

指定した正規表現の最初の部分パターンに一致する入力文字列の部分を、文字列の配列として返します。戻り値の型は String 値の配列です。一致する部分がない場合、またはパターンに部分パターンがない場合は、空の配列を返します。いずれかの引数が NULL の場合は NULL を返します。

**デフォルトの動作**:

| デフォルトの設定                      | 動作                                                                                  |
| ------------------------------------ | ----------------------------------------------------------------------------------------- |
| `.` は改行に一致                  | デフォルトでは `.` が `\n`（改行）に一致します。                                                  |
| 大文字と小文字を区別                       | マッチングでは大文字と小文字を区別します。                                                               |
| `^`/`$` は文字列全体の境界に一致 | `^` は文字列の先頭、`$` は末尾にのみ一致し、各行の先頭や末尾には一致しません。 |
| 最長一致の量指定子                   | デフォルトでは `*` や `+` などが可能な限り長く一致します。                                      |
| UTF-8                                | 文字列は UTF-8 として処理されます。                                                           |

**パターン修飾子**:

`pattern` の先頭に `(?flags)` を付けると、デフォルトの動作を変更できます。複数の修飾子は `(?im)` のように組み合わせられます。`-` を付けた `(?-s)` のような指定では、対応するオプションが無効になります。

パターン修飾子が有効になるのは、デフォルトの正規表現エンジンを使用する場合だけです。`enable_extended_regex=true` を有効にしてゼロ幅アサーション（`(?<=...)`、`(?=...)` など）を使用すると、クエリは Boost.Regex エンジンで処理され、修飾子が期待どおりに機能しない場合があります。両者を併用しないことを推奨します。

| フラグ    | 意味                                                                      |
| ------- | ---------------------------------------------------------------------------- |
| `(?i)`  | 大文字と小文字を区別しないマッチング                                                    |
| `(?-i)` | 大文字と小文字を区別する（デフォルト）                                                     |
| `(?s)`  | `.` が改行に一致する（デフォルトで有効）                                     |
| `(?-s)` | `.` が改行に一致**しない**                                               |
| `(?m)`  | 複数行モード: `^` は各行の先頭、`$` は各行の末尾に一致する |
| `(?-m)` | 単一行モード: `^`/`$` は文字列全体の境界に一致する（デフォルト）             |
| `(?U)`  | 最短一致の量指定子: `*` や `+` などが可能な限り短く一致する           |
| `(?-U)` | 最長一致の量指定子（デフォルト）: `*` や `+` などが可能な限り長く一致する       |

## 例

C の前後にある小文字の基本的なマッチング。この例では、パターン ([[:lower:]]+)C([[:lower:]]+) が、一文字以上の小文字、C、一文字以上の小文字という並びに一致します。C の前にある最初の部分パターン ([[:lower:]]+) は b に一致するため、結果は ['b'] です。

```sql
mysql> SELECT regexp_extract_all('AbCdE', '([[:lower:]]+)C([[:lower:]]+)');
+--------------------------------------------------------------+
| regexp_extract_all('AbCdE', '([[:lower:]]+)C([[:lower:]]+)') |
+--------------------------------------------------------------+
| ['b']                                                        |
+--------------------------------------------------------------+
```

文字列内の複数箇所のマッチング。この例では、パターンが文字列内の二箇所に一致します。最初の一致では最初の部分パターンが b に、二番目の一致では f に一致するため、結果は ['b', 'f'] です。

```sql
mysql> SELECT regexp_extract_all('AbCdEfCg', '([[:lower:]]+)C([[:lower:]]+)');
+-----------------------------------------------------------------+
| regexp_extract_all('AbCdEfCg', '([[:lower:]]+)C([[:lower:]]+)') |
+-----------------------------------------------------------------+
| ['b','f']                                                       |
+-----------------------------------------------------------------+
```

キーと値のペアからキーを抽出する例です。パターンは文字列内のキーと値のペアに一致し、最初の部分パターンがキーをキャプチャするため、結果はキーの配列 ['abc', 'def', 'ghi'] です。

```sql
mysql> SELECT regexp_extract_all('abc=111, def=222, ghi=333','("[^"]+"|\\w+)=("[^"]+"|\\w+)');
+--------------------------------------------------------------------------------+
| regexp_extract_all('abc=111, def=222, ghi=333', '("[^"]+"|\w+)=("[^"]+"|\w+)') |
+--------------------------------------------------------------------------------+
| ['abc','def','ghi']                                                            |
+--------------------------------------------------------------------------------+
```
中国語の文字のマッチング。パターン (\p{Han}+)(.+) では、最初の部分パターン (\p{Han}+) が一文字以上の漢字に一致するため、結果は ['这是一段中文'] です。

```sql
mysql> select regexp_extract_all('这是一段中文 This is a passage in English 1234567', '(\\p{Han}+)(.+)');
+------------------------------------------------------------------------------------------------+
| regexp_extract_all('这是一段中文 This is a passage in English 1234567', '(\p{Han}+)(.+)')       |
+------------------------------------------------------------------------------------------------+
| ['这是一段中文']                                                                               |
+------------------------------------------------------------------------------------------------+
```

データを挿入して REGEXP_EXTRACT_ALL を使用する例

```sql

CREATE TABLE test_regexp_extract_all (
    id INT,
    text_content VARCHAR(255),
    pattern VARCHAR(255)
) PROPERTIES ("replication_num"="1");


INSERT INTO test_regexp_extract_all VALUES
(1, 'apple1, banana2, cherry3', '([a-zA-Z]+)\\d'),
(2, 'red#123, blue#456, green#789', '([a-zA-Z]+)#\\d+'),
(3, 'hello@example.com, world@test.net', '([a-zA-Z]+)@');


SELECT id, regexp_extract_all(text_content, pattern) AS extracted_data
FROM test_regexp_extract_all;
```
```text
+------+----------------------+
| id   | extracted_data       |
+------+----------------------+
|    1 | ['apple', 'banana', 'cherry'] |
|    2 | ['red', 'blue', 'green']     |
|    3 | ['hello', 'world']           |
+------+----------------------+
```

絵文字のマッチング
```sql
mysql> SELECT REGEXP_EXTRACT_ALL('👩‍💻,👨‍🚀', '(💻|🚀)');
+--------------------------------------------------------------+
| REGEXP_EXTRACT_ALL('👩‍💻,👨‍🚀', '(💻|🚀)')                      |
+--------------------------------------------------------------+
| ['💻','🚀']                                                 |
+--------------------------------------------------------------+
```

`pattern` が無効な正規表現の場合はエラーが発生する

```sql
SELECT regexp_extract_all('hello (world) 123', '([[:alpha:]+');
```

```text
Error: missing ]: [[:alpha:]+
```

高度な正規表現
```sql
SELECT REGEXP_EXTRACT_ALL('ID:AA-1,ID:BB-2,ID:CC-3', '(?<=ID:)([A-Z]{2}-\\d)');
-- ERROR 1105 (HY000): errCode = 2, detailMessage = (127.0.0.1)[INVALID_ARGUMENT]Invalid regex pattern: (?<=ID:)([A-Z]{2}-\d). Error: invalid perl operator: (?<
```

```sql
SET enable_extended_regex = true;
SELECT REGEXP_EXTRACT_ALL('ID:AA-1,ID:BB-2,ID:CC-3', '(?<=ID:)([A-Z]{2}-\\d)');
```
```text
+-------------------------------------------------------------------------+
| REGEXP_EXTRACT_ALL('ID:AA-1,ID:BB-2,ID:CC-3', '(?<=ID:)([A-Z]{2}-\\d)') |
+-------------------------------------------------------------------------+
| ['AA-1','BB-2','CC-3']                                                  |
+-------------------------------------------------------------------------+
```

パターン修飾子

大文字と小文字を区別しないマッチング: `(?i)` を付けると大文字と小文字の違いを無視します。

```sql
SELECT REGEXP_EXTRACT_ALL('Hello hello HELLO', '(hello)') AS case_sensitive,
       REGEXP_EXTRACT_ALL('Hello hello HELLO', '(?i)(hello)') AS case_insensitive;
```

```text
+----------------+---------------------------+
| case_sensitive | case_insensitive          |
+----------------+---------------------------+
| ['hello']      | ['Hello','hello','HELLO'] |
+----------------+---------------------------+
```

複数行モード: `(?m)` を付けると、`^` と `$` は各行の先頭と末尾に一致します。

```sql
SELECT REGEXP_EXTRACT_ALL('foo\nbar\nbaz', '^([a-z]+)') AS single_line,
       REGEXP_EXTRACT_ALL('foo\nbar\nbaz', '(?m)^([a-z]+)') AS multi_line;
```

```text
+-------------+---------------------+
| single_line | multi_line          |
+-------------+---------------------+
| ['foo']     | ['foo','bar','baz'] |
+-------------+---------------------+
```

最長一致と最短一致: `(?U)` を付けると、量指定子は可能な限り短く一致します。

```sql
SELECT REGEXP_EXTRACT_ALL('aXbXcXd', '(a.*X)') AS greedy,
       REGEXP_EXTRACT_ALL('aXbXcXd', '(?U)(a.*X)') AS non_greedy;
```

```text
+----------+------------+
| greedy   | non_greedy |
+----------+------------+
| ['aXbXcX'] | ['aX']   |
+----------+------------+
```
