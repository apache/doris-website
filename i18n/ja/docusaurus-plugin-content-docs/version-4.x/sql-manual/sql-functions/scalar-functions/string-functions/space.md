## 説明

指定した数の空白文字で構成される文字列を生成します。

## 構文

```sql
SPACE ( <len> )
```

## パラメータ

| パラメータ | 説明                     |
|------------|--------------------------|
| `<len>`    | 生成する空白文字の数     |

## 戻り値

指定した数の空白文字で構成される文字列を返します。特別な場合:

- 引数が NULL の場合、NULL を返します。
- `<len>` が 0 未満の場合、空文字列を返します。

## 例

1. 指定した数の空白文字を生成
```sql
SELECT space(5);
```
```text
+----------+
| space(5) |
+----------+
|          |
+----------+
```

2. ゼロまたは負の数の扱い
```sql
SELECT space(0), space(-5);
```
```text
+----------+-----------+
| space(0) | space(-5) |
+----------+-----------+
|          |           |
+----------+-----------+
```

3. NULL 値の扱い
```sql
SELECT space(NULL);
```
```text
+-------------+
| space(NULL) |
+-------------+
| NULL        |
+-------------+
```

4. 他の関数と組み合わせて使用
```sql
SELECT CONCAT('Hello', space(3), 'World');
```
```text
+------------------------------------+
| concat('Hello', space(3), 'World') |
+------------------------------------+
| Hello   World                      |
+------------------------------------+
```
