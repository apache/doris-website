## 説明

任意の入力型の値から 64 ビットのハッシュ値を計算し、そのハッシュ値を含む Bitmap を返します。

## 構文

```sql
BITMAP_HASH64(<expr>)
```

## パラメータ

| パラメータ | 説明 |
|-----------|------|
| `<expr>`  | 任意の値またはフィールド式 |

## 戻り値

パラメータ `<expr>` の 64 ビットのハッシュ値を含む Bitmap を返します。
- パラメータが NULL の場合、空の Bitmap を返します。

## 例

値の 64 ビットのハッシュ値を計算するには、次のようにします。

```sql
select bitmap_to_string(bitmap_hash64('hello'));
```

結果は次のとおりです。

```text
+------------------------------------------+
| bitmap_to_string(bitmap_hash64('hello')) |
+------------------------------------------+
| 15231136565543391023                     |
+------------------------------------------+
```

```sql
select bitmap_to_string(bitmap_hash64(NULL));
```

結果は次のとおりです。

```text
+---------------------------------------+
| bitmap_to_string(bitmap_hash64(NULL)) |
+---------------------------------------+
|                                       |
+---------------------------------------+
```
