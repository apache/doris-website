## 説明

Bitmap に設定されているすべてのビット位置をカンマ区切りの文字列に変換します。

## 構文

```sql
BITMAP_TO_STRING(<bitmap>)
```

## 引数

| 引数       | 説明                            |
|------------|---------------------------------|
| `<bitmap>` | Bitmap 型のカラムまたは式       |

## 戻り値

Bitmap に設定されているすべてのビット位置をカンマで区切った文字列を返します。  
Bitmap が `NULL` の場合は `NULL` を返します。

## 例

`NULL` の Bitmap を文字列に変換する場合:

```sql
select bitmap_to_string(null);
```

実行結果:

```text
+------------------------+
| bitmap_to_string(NULL) |
+------------------------+
| NULL                   |
+------------------------+
```

空の Bitmap を文字列に変換する場合:

```sql
select bitmap_to_string(bitmap_empty());
```

実行結果:

```text
+----------------------------------+
| bitmap_to_string(bitmap_empty()) |
+----------------------------------+
|                                  |
+----------------------------------+
```

要素を一つだけ含む Bitmap を文字列に変換する場合:

```sql
select bitmap_to_string(to_bitmap(1));
```

実行結果:

```text
+--------------------------------+
| bitmap_to_string(to_bitmap(1)) |
+--------------------------------+
| 1                              |
+--------------------------------+
```

複数の要素を含む Bitmap を文字列に変換する場合:

```sql
select bitmap_to_string(bitmap_or(to_bitmap(1), to_bitmap(2)));
```

実行結果:

```text
+---------------------------------------------------------+
| bitmap_to_string(bitmap_or(to_bitmap(1), to_bitmap(2))) |
+---------------------------------------------------------+
| 1,2                                                     |
+---------------------------------------------------------+
```
