## 説明

指定した値を HLL（HyperLogLog）型に変換します。通常、データのロード時に元データから HLL を作成するために使用します。

## 構文

```sql
HLL_HASH(<value>)
```

## 引数

| 引数 | 説明                                                   |
|-----------|---------------------------------------------------------------|
| `<value>` | HLL 型に変換する値。文字列、数値など、任意のデータ型を指定できます。 |

## 例

```sql
SELECT HLL_CARDINALITY(HLL_HASH('abc'));
```

```text
+----------------------------------+
| hll_cardinality(HLL_HASH('abc')) |
+----------------------------------+
|                                1 |
+----------------------------------+
```
