## 説明 {#description}
JSON 型データから json_path で指定されたフィールドを抽出します。

## 構文 {#syntax}
```sql
JSON_EXTRACT (<json_object>, <path>[, <path2>, ...])
```
## パラメータ {#parameters}

| パラメータ | 説明 |
| --- | --- |
| `<json_object>` | 必須。JSON 値、または JSON に変換可能な有効な JSON テキスト。 |
| `<path>` | 必須。STRING 型の JSON パス。配列を走査するには明示的なワイルドカードを使用します。 |
| `<path2>, ...` | オプション。追加の STRING パス。マッチした結果は JSON 配列にまとめられます。 |

<a id="required-parameters"></a>
<a id="optionalvariable-parameters"></a>

## 戻り値 {#return-value}

いずれかの引数が `NULL` またはパスに一致するものがない場合、SQL `NULL` を返します。
- `Nullable(JSON)`: `<path>` が指す JSON 要素を返します。複数の結果がマッチした場合は、JSON 配列として返されます。

## 使用上の注意 {#usage-notes}
- `<json_object>` または `<path>` が NULL の場合、NULL を返します。
- `<path>` パラメータが 1 つの場合、`<path>` が存在しなければ NULL を返します。
- `<path>` パラメータが複数ある場合、存在しないパスは無視され、マッチした要素が JSON 配列として返されます。マッチするものがない場合は NULL を返します。
- `<path>` が有効なパスでない場合は、エラーが報告されます。
- `<path>` に対応する値が文字列の場合、返される文字列は二重引用符（`"`）で囲まれます。二重引用符なしの結果を取得するには、関数 [`JSON_UNQUOTE`](./json-unquote.md) を使用してください。
- `<path>` の構文は次のとおりです。
    * `$` は JSON ルートを表します
    * `.k1` は JSON オブジェクト内でキー `k1` を持つ要素を表します
        * キーの値に「.」が含まれる場合、`<path>` では二重引用符を使用する必要があります。例: `SELECT json_extract('{"k1.a":"abc","k2":300}', '$."k1.a"')`;
    * `[i]` は JSON 配列のインデックス i にある要素を表します
        * json_array の最後の要素を取得するには `$[last]`、最後から 2 番目の要素を取得するには `$[last-1]` などを使用できます。
    * `*` はワイルドカードを表します。`$.*` はルートオブジェクトのすべてのメンバー、`$[*]` は配列のすべての要素を表します。
    * `**` は '$' と組み合わせて使用します。'$**' はすべてのパス（複数レベルのサブパスを含む）を表します。
- `<path>` にワイルドカード（`*`）が含まれる場合、マッチした結果は配列形式で返されます。
- `<path>` は配列に対して自動的にブロードキャストされません。`<json_object>` が JSON 配列で `<path>` が `$.k` の場合、結果は NULL です。`$.k` はオブジェクトメンバーのみを走査します。インデックスで要素を指定するには `$[i].k` を使用します。配列の各要素からフィールドを抽出するには、Doris 4.0 以降でサポートされるワイルドカード構文 `$[*].k` を使用します。

## 例 {#examples}
1. 一般的なパラメータ
  ```sql
  SELECT JSON_EXTRACT('{"k1":"v31","k2":300}', '$.k1');
  ```
  ```text
```

```text
+-----------------------------------------------+
  | JSON_EXTRACT('{"k1":"v31","k2":300}', '$.k1') |
  +-----------------------------------------------+
  | "v31"                                         |
  +-----------------------------------------------+
  ```
> 注: 返される結果は `"v31"` であり、`v31` ではありません。
2. NULL パラメータ
    ```sql
    select JSON_EXTRACT(null, '$.k1');
    ```
    ```text
    +----------------------------+
    | JSON_EXTRACT(null, '$.k1') |
    +----------------------------+
    | NULL                       |
    +----------------------------+
    ```
3. `<path>` が NULL
    ```sql
    SELECT JSON_EXTRACT('{"k1":"v31","k2":300}', NULL);
    ```
    ```text
    +---------------------------------------------+
    | JSON_EXTRACT('{"k1":"v31","k2":300}', NULL) |
    +---------------------------------------------+
    | NULL                                        |
    +---------------------------------------------+
    ```
4. 多階層パス
    ```sql
    SELECT JSON_EXTRACT('{"k1":"v31","k2":{"sub_key": 1234.56}}', '$.k2.sub_key');
    ```
    ```text
    +------------------------------------------------------------------------+
    | JSON_EXTRACT('{"k1":"v31","k2":{"sub_key": 1234.56}}', '$.k2.sub_key') |
    +------------------------------------------------------------------------+
    | 1234.56                                                                |
    +------------------------------------------------------------------------+
    ```
5. 配列パス
    ```sql
    SELECT JSON_EXTRACT(json_array("abc", 123, cast(now() as string)), '$[2]');
    ```
    ```text
    +----------------------------------------------------------------------+
    | JSON_EXTRACT(json_array("abc", 123, cast(now() as string)), '$[2]') |
    +----------------------------------------------------------------------+
    | "2025-07-16 18:35:25"                                                |
    +----------------------------------------------------------------------+
    ```
6. 存在しないパス
    ```sql
    SELECT JSON_EXTRACT('{"k1":"v31","k2":300}', '$.k3');
    ```
    ```text
    +-----------------------------------------------+
    | JSON_EXTRACT('{"k1":"v31","k2":300}', '$.k3') |
    +-----------------------------------------------+
    | NULL                                          |
    +-----------------------------------------------+
    ```
7. 複数のパスパラメータ
    ```sql
    select JSON_EXTRACT('{"id": 123, "name": "doris"}', '$.name', '$.id', '$.not_exists');
    ```
    ```text
    +--------------------------------------------------------------------------------+
    | JSON_EXTRACT('{"id": 123, "name": "doris"}', '$.name', '$.id', '$.not_exists') |
    +--------------------------------------------------------------------------------+
    | ["doris",123]                                                                  |
    +--------------------------------------------------------------------------------+
    ```
    > マッチが 1 つだけの場合でも、配列形式で返されます
    ```sql
    SELECT json_extract('{"id": 123, "name": "doris"}', '$.aaa', '$.name');
    ```
    ```text
    +-----------------------------------------------------------------+
    | json_extract('{"id": 123, "name": "doris"}', '$.aaa', '$.name') |
    +-----------------------------------------------------------------+
    | ["doris"]                                                       |
    +-----------------------------------------------------------------+
    ```
    > すべてのパスにマッチするものがない場合は NULL を返します
    ```sql
    select JSON_EXTRACT('{"id": 123, "name": "doris"}', '$.k1', '$.k2', '$.not_exists');
    ```
    ```text
    +------------------------------------------------------------------------------+
    | JSON_EXTRACT('{"id": 123, "name": "doris"}', '$.k1', '$.k2', '$.not_exists') |
    +------------------------------------------------------------------------------+
    | NULL                                                                         |
    +------------------------------------------------------------------------------+
    ```

8. ワイルドカードパス
    ```sql
    select json_extract('{"k": [1,2,3,4,5]}', '$.k[*]');
    ```
    ```text
    +----------------------------------------------+
    | json_extract('{"k": [1,2,3,4,5]}', '$.k[*]') |
    +----------------------------------------------+
    | [1,2,3,4,5]                                  |
    +----------------------------------------------+
    ```
    ```sql
    select json_extract('{"k": [1,2,3,4,5], "k2": "abc", "k3": {"k4": "v4"}}', '$.*', '$.k3.k4');
    ```
    ```text
    +---------------------------------------------------------------------------------------+
    | json_extract('{"k": [1,2,3,4,5], "k2": "abc", "k3": {"k4": "v4"}}', '$.*', '$.k3.k4') |
    +---------------------------------------------------------------------------------------+
    | [[1,2,3,4,5],"abc",{"k4":"v4"},"v4"]                                                  |
    +---------------------------------------------------------------------------------------+
    ```
9. パス内の '**'
    ```sql
    select json_extract('{"k": 123, "b": {"k": ["ab", "cd"]}}', '$**.k');
    ```
    ```text
    +---------------------------------------------------------------+
    | json_extract('{"k": 123, "b": {"k": ["ab", "cd"]}}', '$**.k') |
    +---------------------------------------------------------------+
    | [123,["ab","cd"]]                                             |
    +---------------------------------------------------------------+
    ```

10. 値が NULL の場合
    ```sql
    select JSON_EXTRACT('{"id": 123, "name": null}', '$.name') v, JSON_EXTRACT('{"id": 123, "name": null}', '$.name') is null v2;
    ```
    ```text
    +------+------+
    | v    | v2   |
    +------+------+
    | null |    0 |
    +------+------+
    ```

11. JSON 配列の各要素からフィールドを抽出（Doris 4.0 以降）
    ```sql
    select json_extract('[{"k":1},{"k":2},{"k":3}]', '$.k');
    ```
    ```text
    +--------------------------------------------------+
    | json_extract('[{"k":1},{"k":2},{"k":3}]', '$.k') |
    +--------------------------------------------------+
    | NULL                                             |
    +--------------------------------------------------+
    ```
    > `$.k` は配列を走査せず、オブジェクトのメンバーのみをたどります。
    ```sql
    select json_extract('[{"k":1},{"k":2},{"k":3}]', '$[*].k');
    ```
    ```text
    +-----------------------------------------------------+
    | json_extract('[{"k":1},{"k":2},{"k":3}]', '$[*].k') |
    +-----------------------------------------------------+
    | [1,2,3]                                             |
    +-----------------------------------------------------+
    ```
    > 配列の各要素からフィールドを抽出するには `$[*].k` を使用します。

### 配列要素から同じフィールドを抽出（Doris 4.0 以降） {#extracting-the-same-field-from-array-elements-doris-40-and-later}

`$[*].k1` を使用して配列要素を明示的に走査します。`$.k1` はオブジェクトメンバーにのみアクセスし、配列を暗黙的に走査しないため、以下の直接パスは SQL `NULL` を返します。`k1` を持たない配列要素はマッチ結果から除外されます。
```sql
SELECT json_extract('[{"k1":"v1"},{"k2":"v2"},{"k1":"v3"},{"k1":"v4"}]', '$.k1') AS direct_path,
       json_extract('[{"k1":"v1"},{"k2":"v2"},{"k1":"v3"},{"k1":"v4"}]', '$[*].k1') AS all_values;
```

```text
+-------------+------------------+
| direct_path | all_values       |
+-------------+------------------+
| NULL        | ["v1","v3","v4"] |
+-------------+------------------+
```
