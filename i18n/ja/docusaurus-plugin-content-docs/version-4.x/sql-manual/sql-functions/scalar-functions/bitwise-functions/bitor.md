## 説明
両方の整数に対してビット単位の OR 演算を実行します。

サポートされる整数型: TINYINT、SMALLINT、INT、BIGINT、LARGEINT

## 構文
```sql
BITOR(<lhs>, <rhs>)
```

## パラメータ
- `<lhs>`: 演算対象の最初の整数。
- `<rhs>`: 演算対象の次の整数。

## 戻り値

両方の整数に対するビット単位の OR 演算の結果を返します。

## 使用例
1. 使用例 1
    ```sql
    select BITOR(3,5), BITOR(4,7);
    ```
    ```text
    +------------+------------+
    | BITOR(3,5) | BITOR(4,7) |
    +------------+------------+
    |          7 |          7 |
    +------------+------------+
    ```
2. NULL 引数
    ```sql
    select BITOR(3, NULL), BITOR(NULL, 5), BITOR(NULL, NULL);
    ```
    ```text
    +----------------+----------------+-------------------+
    | BITOR(3, NULL) | BITOR(NULL, 5) | BITOR(NULL, NULL) |
    +----------------+----------------+-------------------+
    |           NULL |           NULL |              NULL |
    +----------------+----------------+-------------------+
    ```
