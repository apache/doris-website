## 説明
ビット単位の AND 演算を実行します。両方の整数の対応するビットを比較し、両方が 1 の場合のみ結果が 1 になり、それ以外は 0 になります。

サポートされる整数型: TINYINT、SMALLINT、INT、BIGINT、LARGEINT

## 構文
```sql
BITAND(<lhs>, <rhs>)
```

## パラメータ
- `<lhs>`: ビット単位の AND 演算の最初の整数。
- `<rhs>`: ビット単位の AND 演算の次の整数。

## 戻り値
両方の整数に対するビット単位の AND 演算の結果を返します。


## 使用例
1. 使用例 1
    ```sql
    select BITAND(3,5), BITAND(5, 10), BITAND(7, 10);
    ```
    ```text
    +-------------+---------------+---------------+
    | BITAND(3,5) | BITAND(5, 10) | BITAND(7, 10) |
    +-------------+---------------+---------------+
    |           1 |             0 |             2 |
    +-------------+---------------+---------------+
    ```
2. NULL 引数
    ```sql
    select BITAND(1, null), BITAND(null, 1), BITAND(null, null);
    ```
    ```text
    +-----------------+-----------------+--------------------+
    | BITAND(1, null) | BITAND(null, 1) | BITAND(null, null) |
    +-----------------+-----------------+--------------------+
    |            NULL |            NULL |               NULL |
    +-----------------+-----------------+--------------------+
    ```
