## 説明

整数値のバイナリ表現に含まれる 1 のビット数を返します。 この関数を使うと、整数のバイナリ表現に含まれるセットされたビットをすばやく数えられます。データ分布の分析やビット演算に利用できます。

## 構文
```sql
BIT_COUNT(<x>)
```

## パラメータ
- `<x>`: バイナリ表現に含まれる 1 のビットを数える対象の整数。サポートされる型: TINYINT、SMALLINT、INT、BIGINT、LARGEINT。

## 戻り値

`<x>` のバイナリ表現に含まれる 1 のビット数を返します。

## 使用例
1. 使用例 1
    ```sql
    select BIT_COUNT(0), BIT_COUNT(8), BIT_COUNT(-1);
    ```
    ```text
    +--------------+--------------+---------------+
    | BIT_COUNT(0) | BIT_COUNT(8) | BIT_COUNT(-1) |
    +--------------+--------------+---------------+
    |            0 |            1 |             8 |
    +--------------+--------------+---------------+
    ```
2. NULL 引数
    ```sql
    select BIT_COUNT(NULL);
    ```
    ```text
    +-----------------+
    | BIT_COUNT(NULL) |
    +-----------------+
    |            NULL |
    +-----------------+
    ```
