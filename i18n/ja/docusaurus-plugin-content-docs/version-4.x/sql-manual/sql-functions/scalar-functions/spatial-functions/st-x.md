## 説明

点が有効な POINT 型の場合、対応する X 座標の値を返します。

## 構文

```sql
ST_X( <point>)
```

## パラメータ

| パラメータ | 説明 |
|------|----------|
| `<point>` | X 座標を抽出する幾何オブジェクト。有効な POINT 型（2 次元の点）である必要があります。X（経度）の範囲は [-180, 180]、Y（緯度）の範囲は [-90, 90] です。|

## 戻り値

幾何座標の X 値を倍精度浮動小数点数（Double）で返します。

- 入力が有効な POINT オブジェクトの場合、点の X 座標を倍精度浮動小数点数（Double）で返します。
- 入力が NULL、POINT 型以外のオブジェクト、空の点（POINT EMPTY）、または無効な点（例：3 次元の点）の場合、NULL を返します。

## 例


有効な点の X 座標を抽出する

```sql
SELECT ST_X(ST_Point(24.7, 56.7));
```

```text
+----------------------------+
| st_x(st_point(24.7, 56.7)) |
+----------------------------+
|                       24.7 |
+----------------------------+
```

入力が空の点（POINT EMPTY）の場合

```sql
mysql> SELECT ST_X(ST_GeometryFromText("POINT EMPTY"));
+------------------------------------------+
| ST_X(ST_GeometryFromText("POINT EMPTY")) |
+------------------------------------------+
|                                     NULL |
+------------------------------------------+
```

入力が 3 次元の点（サポート対象外）の場合

```sql

mysql> SELECT ST_X(ST_GeometryFromText("POINT (10 20 30)"));
+-----------------------------------------------+
| ST_X(ST_GeometryFromText("POINT (10 20 30)")) |
+-----------------------------------------------+
|                                          NULL |
+-----------------------------------------------+
```

入力が NULL の場合

```sql
mysql> SELECT ST_X(NULL);
+------------+
| ST_X(NULL) |
+------------+
|       NULL |
+------------+
```


経度が範囲外の場合

```sql
mysql> SELECT ST_X(ST_Point(244.7, 56.7));
+-----------------------------+
| ST_X(ST_Point(244.7, 56.7)) |
+-----------------------------+
|                        NULL |
+-----------------------------+
```

緯度が範囲外の場合

```sql
mysql> SELECT ST_X(ST_Point(44.7, 156.7));
+-----------------------------+
| ST_X(ST_Point(44.7, 156.7)) |
+-----------------------------+
|                        NULL |
+-----------------------------+
```
