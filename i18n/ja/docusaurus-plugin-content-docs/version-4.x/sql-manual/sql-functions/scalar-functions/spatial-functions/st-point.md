## 説明

指定された X 座標と Y 座標から Point ジオメトリオブジェクトを作成します。
地理空間の文脈では、X/Y は通常、それぞれ経度と緯度を表します。

## 構文

```sql
ST_POINT( <x>, <y>)
```
## パラメータ

| パラメータ  | 説明  |
|-----|-----|
| `<x>` | 点の X 座標（経度）。範囲: -180.0 ～ 180.0（度） |
| `<y>` | 点の Y 座標（緯度）。範囲: -90.0 ～ 90.0（度） |

## 戻り値

2 次元座標を表す Point ジオメトリオブジェクトを返します。

- <x> または <y> が有効な経度・緯度の範囲を超える場合、NULL を返します。
- いずれかのパラメータが NULL の場合、NULL を返します。

## 例

有効な座標

```sql
SELECT ST_AsText(ST_Point(24.7, 56.7));
```

```text
+---------------------------------+
| st_astext(st_point(24.7, 56.7)) |
+---------------------------------+
| POINT (24.7 56.7)               |
+---------------------------------+
```

無効な経度（範囲外）

```sql
mysql> SELECT ST_Point(200, 50);
+-------------------+
| ST_Point(200, 50) |
+-------------------+
| NULL              |
+-------------------+
```

無効な緯度（範囲外）

```sql
mysql> SELECT ST_Point(116, -100);
+---------------------+
| ST_Point(116, -100) |
+---------------------+
| NULL                |
+---------------------+
```

いずれかのパラメータが NULL

```sql
mysql> SELECT ST_Point(NULL, 50);
+--------------------+
| ST_Point(NULL, 50) |
+--------------------+
| NULL               |
+--------------------+
```

```sql
mysql> SELECT ST_Point(50, NULL);
+--------------------+
| ST_Point(50, NULL) |
+--------------------+
| NULL               |
+--------------------+

```
