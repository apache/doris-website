## 説明

64 ビットの MurmurHash3 ハッシュ値を計算します

`MURMUR_HASH3_64_V2` との違いは、このバージョンが 64 ビット出力向けに最適化されている点です。v2 よりわずかに高速ですが、[標準ライブラリ](https://mmh3.readthedocs.io/en/latest/api.html#mmh3.hash64)の実装とは結果が一致しません。

- 注: テストでは `xxhash_64` は `murmur_hash3_64` の約二倍の性能を示しました。ハッシュ値の計算には `xxhash_64` を `murmur_hash3_64` の代わりに使用することを推奨します。


## 構文

```sql
MURMUR_HASH3_64( <str> [ , <str> ... ] )
```

## パラメータ

| パラメータ      | 説明                                             |
|---------|------------------------------------------------|
| `<str>` | 64 ビットの MurmurHash3 ハッシュ値を計算する対象の文字列 |

## 戻り値

入力文字列の 64 ビット MurmurHash3 ハッシュ値を返します。

いずれかの引数が NULL の場合は NULL を返します。

## 使用例

```sql
select murmur_hash3_64(null), murmur_hash3_64("hello"), murmur_hash3_64("hello", "world");
```

```text
+-----------------------+--------------------------+-----------------------------------+
| murmur_hash3_64(NULL) | murmur_hash3_64('hello') | murmur_hash3_64('hello', 'world') |
+-----------------------+--------------------------+-----------------------------------+
|                  NULL |     -3215607508166160593 |               3583109472027628045 |
+-----------------------+--------------------------+-----------------------------------+
```
