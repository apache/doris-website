## 説明

複数の文字列から 256 ビットの SM3 ダイジェストを計算します

## 構文

```sql
SM3SUM( <str> [ , <str> ... ] )
```

## パラメータ

| パラメータ | 説明 |
|-----------|-------------|
| `<str>`   | SM3 ダイジェストを計算する対象の文字列   |

## 戻り値

入力した複数の文字列の SM3 ダイジェストを返します

## 使用例

```sql
select sm3sum("ab","cd");
```

```text
+------------------------------------------------------------------+
| sm3sum('ab', 'cd')                                               |
+------------------------------------------------------------------+
| 82ec580fe6d36ae4f81cae3c73f4a5b3b5a09c943172dc9053c69fd8e18dca1e |
+------------------------------------------------------------------+
```
