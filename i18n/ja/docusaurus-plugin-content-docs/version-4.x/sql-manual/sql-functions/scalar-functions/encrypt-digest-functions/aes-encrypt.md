## 説明

AES 暗号化関数です。この関数は MySQL の `AES_ENCRYPT` 関数と同じ動作をします。デフォルトのアルゴリズムは `AES_128_ECB`、パディング方式は `PKCS7` です。

AES_ENCRYPT 関数は、渡された鍵をそのまま使用せず、さらに処理します。具体的な手順は次のとおりです。
1. 使用する暗号化アルゴリズムに応じて鍵のバイト数を決定します。たとえば、AES_128_ECB アルゴリズムを使用する場合、鍵のバイト数は `128 / 8 = 16` です（AES_256_ECB アルゴリズムを使用する場合は `256 / 8 = 32`）。
2. 次に、ユーザーが入力した鍵の `i` 番目のバイトと `16*k+i` 番目のバイトを XOR します。ユーザーが入力した鍵が 16 バイト未満の場合は、末尾に 0 を追加します。
3. 最後に、新しく生成した鍵を使用して暗号化します。

## 構文

```sql
AES_ENCRYPT( <str>, <key_str>[, <init_vector>][, <encryption_mode>])
```

## パラメータ

| パラメータ          | 説明 |
|---------------------|------|
| `<str>`             | 暗号化するテキスト |
| `<key_str>`         | 鍵です。この鍵は十六進数でエンコードされたものではなく、エンコードされた文字列表現です。たとえば、128 ビット鍵による暗号化では、`key_str` の長さを 16 にします。鍵の長さが足りない場合は **ゼロ埋め** で補い、長すぎる場合は循環 XOR で最終的な鍵を求めます。たとえば、アルゴリズムで使用する 128 ビット鍵を `key` とすると、`key[i] = key_str[i] ^ key_str[i+128] ^ key_str[i+256] ^ ...` となります。 |
| `<init_vector>`     | 省略可能。アルゴリズムで使用する初期化ベクトルです。特定のアルゴリズムでのみ有効です。省略した場合、Doris は組み込みのベクトルを使用します。 |
| `<encryption_mode>` | 省略可能。暗号化アルゴリズムです。指定できる値は変数に示されています。 |


## 戻り値

暗号化されたバイナリデータを返します。

## 使用例

AES_128_ECB アルゴリズムを使用する場合
```sql
set block_encryption_mode='';
select to_base64(aes_encrypt('text','F3229A0B371ED2D9441B830D21A390C3'));
```

```text
+----------------------------------------------------------+
| to_base64(aes_encrypt('text', '***', '', 'AES_128_ECB')) |
+----------------------------------------------------------+
| wr2JEDVXzL9+2XtRhgIloA==                                 |
+----------------------------------------------------------+
```

AES_256_CBC アルゴリズムを使用する場合
```sql
set block_encryption_mode="AES_256_CBC";
select to_base64(aes_encrypt('text','F3229A0B371ED2D9441B830D21A390C3'));
```

```text
+----------------------------------------------------------+
| to_base64(aes_encrypt('text', '***', '', 'AES_256_CBC')) |
+----------------------------------------------------------+
| 3dym0E7/+1zbrLIaBVNHSw==                                 |
+----------------------------------------------------------+
```

AES_256_CBC アルゴリズムを使用し、初期化ベクトルを設定する場合
```sql
select to_base64(aes_encrypt('text','F3229A0B371ED2D9441B830D21A390C3', '0123456789'));
```

```text
+--------------------------------------------------------------------+
| to_base64(aes_encrypt('text', '***', '0123456789', 'AES_256_CBC')) |
+--------------------------------------------------------------------+
| tsmK1HzbpnEdR2//WhO+MA==                                           |
+--------------------------------------------------------------------+
```
