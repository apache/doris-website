## 説明

FROM_BASE64_BINARY 関数は Base64 でエンコードされた文字列をデコードし、VARBINARY 値として返します。

特別なケース:

- 入力文字列が有効な Base64 エンコード文字列でない場合、NULL を返します。

## 構文

```sql
FROM_BASE64_BINARY ( <str> )
```

## 引数

| 引数 | 説明                                            |
| --------- | ------------------------------------------------------ |
| `<str>`   | デコードする Base64 エンコード文字列。               |

## 戻り値

`<str>` を Base64 からデコードし、VARBINARY 値として返します。

特別なケース:

- 入力文字列が無効（Base64 エンコードで使用できない文字を含む）な場合は NULL を返します。

## 例

```sql
SELECT FROM_BASE64_BINARY('MQ==');
```

```text
+--------------------------------------------------------+
| FROM_BASE64_BINARY('MQ==')                             |
+--------------------------------------------------------+
| 0x31                                                   |
+--------------------------------------------------------+
```

```sql
SELECT FROM_BASE64_BINARY('MjM0');
```

```text
+--------------------------------------------------------+
| FROM_BASE64_BINARY('MjM0')                             |
+--------------------------------------------------------+
| 0x323334                                               |
+--------------------------------------------------------+
```

```sql
SELECT FROM_BASE64_BINARY(NULL);
```

```text
+----------------------------------------------------+
| FROM_BASE64_BINARY(NULL)                           |
+----------------------------------------------------+
| NULL                                               |
+----------------------------------------------------+
```
