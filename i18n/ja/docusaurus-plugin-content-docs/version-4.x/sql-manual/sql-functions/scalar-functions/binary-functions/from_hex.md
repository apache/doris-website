## 説明

入力したバイナリデータを 十六進数で表した文字列に変換します。

## 別名

FROM_BINARY

## 構文

```sql
FROM_HEX ( <varbinary> )
```

## 引数

| 引数 | 説明 |
|-------|--------------|
| `<varbinary>` | 入力するバイナリデータ |

## 戻り値

入力したバイナリデータを 十六進数で表した文字列を返します。

## 例

```sql
SELECT FROM_HEX(NULL);
```

```text
+----------------+
| FROM_HEX(NULL) |
+----------------+
| NULL           |
+----------------+
```

```sql
SELECT FROM_HEX(X'AB');
```

```text
+-----------------+
| FROM_HEX(X'AB') |
+-----------------+
| AB              |
+-----------------+
```
