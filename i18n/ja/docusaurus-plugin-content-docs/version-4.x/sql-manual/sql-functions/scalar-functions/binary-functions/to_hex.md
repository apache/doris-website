## 説明

入力文字列の 十六進数表現を対応するバイト列に変換します。

## 別名

TO_BINARY

## 構文

```sql
TO_HEX(<str>)
```

## 引数

| 引数 | 説明 |
| -- | -- |
| `<str>` | 変換する文字列データ |

## 戻り値

デコードした VARBINARY 値を返します（表示時は 0x を付けた 十六進数形式）。
次のいずれかに該当する場合は NULL を返します。
入力が NULL。
入力の長さが 0。
入力の長さが奇数。
入力に [0-9a-fA-F] 以外の文字が含まれる。
デコード結果の長さが 0（デコードに失敗）。

## 例

```sql
select to_hex(NULL),to_hex('a');
```

```text
+----------------------------+--------------------------+
| to_hex(NULL)               | to_hex('a')              |
+----------------------------+--------------------------+
| NULL                       | NULL                     |
+----------------------------+--------------------------+
```

```sql
select to_hex('ab');
```

```text
+----------------------------+
| to_hex('ab')               |
+----------------------------+
| 0xAB                       |
+----------------------------+
```

```sql
select to_hex('000A');
```

```text
+--------------------------------+
| to_hex('000A')                 |
+--------------------------------+
| 0x000A                         |
+--------------------------------+
```
