## 説明

TO_BASE64_BINARY 関数は入力したバイナリ文字列を Base64 形式にエンコードします。Base64 エンコードでは、任意のバイナリデータを 64 種類の文字で構成される文字列に変換します。

## 構文

```sql
TO_BASE64_BINARY(<bin>)
```

## 引数
| 引数 | 説明                                    |
| --------- | ---------------------------------------------- |
| `<bin>` | Base64 でエンコードするバイナリ値。型: VARBINARY |

## 戻り値

Base64 でエンコードされた文字列を VARCHAR 型で返します。

特別なケース:
- 入力が NULL の場合は NULL を返します。
- 入力が空の VARBINARY（ゼロバイト）の場合は空文字列を返します。

## 例

1. 単一バイトをエンコード
```sql
SELECT to_base64_binary(x'12');
```
```text
+-------------------------+
| to_base64_binary(x'12') |
+-------------------------+
| Eg==                    |
+-------------------------+
```

2. 複数バイトをエンコード
```sql
SELECT to_base64_binary(x'234AAA');
```
```text
+-----------------------------+
| to_base64_binary(x'234AAA') |
+-----------------------------+
| I0qq                        |
+-----------------------------+
```
