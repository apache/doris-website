## 説明

Map から重複したキーを除去します。
Doris は通常、データのインポート時などに生成される Map のキーを重複排除します。
ただし、外部テーブルから読み取ったデータや文字列から変換した Map など、特定の状況で得られる Map では重複が除去されていないことがあります。
この関数を使用すると Map 型のキーを重複排除できます。

## 構文

```sql
DEDUPLICATE_MAP(<map>)
```

## パラメータ

- `<map>`: 入力する Map の内容。

## 戻り値

`Map`: 重複を除去した Map を返します (型は入力引数と同じです)。

## 使用例
    ```sql
    select m, deduplicate_map(m) from (select cast('{"a": 123, "a": 345}' as map<string, int>) m ) t;
    ```

    ```text
    +--------------------+--------------------+
    | m                  | deduplicate_map(m) |
    +--------------------+--------------------+
    | {"a":123, "a":345} | {"a":345}          |
    +--------------------+--------------------+
    ```
> 文字列から変換した Map のキーは自動的には重複排除されません。
