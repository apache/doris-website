## 説明

指定した `map` を `ARRAY<STRUCT<key, value>>` に変換します。

返される配列の各要素は、`key` と `value` という名前のフィールドを持つ構造体です。どちらのフィールドも NULL を許容します。
`key` と `value` フィールドの型は、それぞれ Map のキーと値の型と同じです。

## 構文

```sql
MAP_ENTRIES(<map>)
```

## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<map>` | 入力する Map の内容 |

## 戻り値

Map のエントリを表す構造体の配列を返します。`<map>` が `NULL` の場合は `NULL` を返します。

## 使用例

```sql
select 
  map_entries(map()),
  map_entries(map(1, '100', 0.1, '2'));
```

```text
+--------------------+--------------------------------------------------------+
| map_entries(map()) | map_entries(map(1, '100', 0.1, '2'))                   |
+--------------------+--------------------------------------------------------+
| []                 | [{"key":1.0, "value":"100"}, {"key":0.1, "value":"2"}] |
+--------------------+--------------------------------------------------------+
```
