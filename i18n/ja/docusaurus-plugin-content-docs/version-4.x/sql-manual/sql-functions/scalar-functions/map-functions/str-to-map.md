## 説明

文字列から `Map<String, String>` を作成します。

:::tip
この関数はバージョン 3.0.6 以降でサポートされます。
:::

## 構文

```sql
STR_TO_MAP(<str> [, <pair_delimiter> [, <key_value_delimiter>]])
```

## パラメータ
- `<str>` MAP に変換する文字列。
- `<pair_delimiter>` 文字列内のペア間の区切り文字。デフォルトは `,` です。
- `<key_value_delimiter>` 文字列内のキーと値の区切り文字。デフォルトは `:` です。

## 戻り値

文字列から作成した `Map<String, String>` を返します。

## 例

```sql
select str_to_map('a=1&b=2&c=3', '&', '=') as map1, str_to_map('x:10|y:20|z:30', '|', ':') as map2;
```

```text
+-----------------------------+--------------------------------+
| map1                        | map2                           |
+-----------------------------+--------------------------------+
| {"a":"1", "b":"2", "c":"3"} | {"x":"10", "y":"20", "z":"30"} |
+-----------------------------+--------------------------------+
```
