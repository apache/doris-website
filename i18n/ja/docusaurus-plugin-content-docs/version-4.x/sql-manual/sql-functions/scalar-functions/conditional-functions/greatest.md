## 説明

複数の式を比較し、最大値を返します。いずれかの引数が `NULL` の場合は `NULL` を返します。

## 構文

```sql
GREATEST(<expr> [, ...])
```

## パラメータ
### 必須パラメータ
- `<expr>`: `TINYINT`、`SMALLINT`、`INT`、`BIGINT`、`LARGEINT`、`FLOAT`、`DOUBLE`、`STRING`、`DATETIME`、`DECIMAL` 型をサポートします。
### 任意のパラメータ
- 複数の引数を指定できます。

## 戻り値
- 指定した式の中で最大の値を返します。
- いずれかの引数が `NULL` の場合は `NULL` を返します。

## 使用上の注意
1. 引数には同じ型を指定することを推奨します。型が異なる場合、この関数は同じ型への変換を試みます。変換規則は [型変換](../../../basic-element/sql-data-types/conversion/overview.md) を参照してください。
2. いずれかの引数が NULL の場合、結果は NULL になります。

## 例
1. 例 1
    ```sql
    SELECT GREATEST(-1, 0, 5, 8);
    ```
    ```text
    +-----------------------+
    | GREATEST(-1, 0, 5, 8) |
    +-----------------------+
    |                     8 |
    +-----------------------+
    ```
2. NULL 引数
    ```sql
    SELECT GREATEST(-1, 0, 5, NULL);
    ```
    ```text
    +--------------------------+
    | GREATEST(-1, 0, 5, NULL) |
    +--------------------------+
    | NULL                     |
    +--------------------------+
    ```
3. 型変換
    ```sql
    SELECT GREATEST(6, 4.29, 7);
    ```
    ```text
    +----------------------+
    | GREATEST(6, 4.29, 7) |
    +----------------------+
    |                 7.00 |
    +----------------------+
    ```
    > 三番目の引数 "7" は Decimal 型に変換されます。
4. 日付型
    ```sql
    SELECT GREATEST('2022-02-26 20:02:11', '2020-01-23 20:02:11', '2020-06-22 20:02:11');
    ```
    ```text
    +-------------------------------------------------------------------------------+
    | GREATEST('2022-02-26 20:02:11', '2020-01-23 20:02:11', '2020-06-22 20:02:11') |
    +-------------------------------------------------------------------------------+
    | 2022-02-26 20:02:11                                                           |
    +-------------------------------------------------------------------------------+
    ```
