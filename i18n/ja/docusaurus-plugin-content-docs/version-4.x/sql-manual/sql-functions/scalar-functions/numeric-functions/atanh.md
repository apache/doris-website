## 説明

`x` の逆双曲線正接を返します。`NULL` を返すのは、`x` が `-1` から `1` までの範囲（`-1` と `1` を除く）にない場合です。

## 構文

```sql
ATANH(<x>)
```

## パラメータ

| パラメータ | 説明 |  
| -- | -- |  
| `<x>` | 逆双曲線正接を計算する値 |  

## 戻り値  

引数 `x` の逆双曲線正接の値を返します。

## 特殊なケース

- `x` が 0 の場合は 0 を返します
- `x` が 1 または -1 の場合は `NULL` を返します
- `x` が範囲 (-1, 1) の外にある場合は `NULL` を返します
- `x` が NaN の場合は NaN を返します
- `x` が正または負の無限大の場合は `NULL` を返します
- `x` が NULL の場合は NULL を返します

## 使用例

```sql
select atanh(0.0);
```

```text
+------------+
| atanh(0.0) |
+------------+
|          0 |
+------------+
```

```sql
select atanh(-1.0);
```

```text
+-------------+
| atanh(-1.0) |
+-------------+
|        NULL |
+-------------+
```

```sql
select atanh(1.0);
```

```text
+------------+
| atanh(1.0) |
+------------+
|       NULL |
+------------+
```

```sql
select atanh(0.5);
```

```text
+--------------------+
| atanh(0.5)         |
+--------------------+
| 0.5493061443340548 |
+--------------------+
```

```sql

```

```text
+---------------------------+
```

```sql

```

```text
+---------------------------+
| atanh(cast('inf' AS DOUBLE)) |
+---------------------------+
| NULL                      |
+---------------------------+
```
