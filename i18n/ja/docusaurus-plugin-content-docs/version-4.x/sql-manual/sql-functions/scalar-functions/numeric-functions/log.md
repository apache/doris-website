## 説明

`x` の、底 `b` に対する対数を返します。

## 構文

```sql
LOG([<b>, ]<x>)
```

## パラメータ

| パラメータ | 説明 |
|-----------|------------|
| `<b>`     | 省略可能。底は 0 より大きく、1.0 と等しくない必要があります。省略した場合は、自然対数（底 e）を計算します。 |
| `<x>`     | 真数は 0 より大きい必要があります。 |

## 戻り値

浮動小数点数を返します。特殊なケースは次のとおりです。

- b IS NULL または x IS NULL の場合は、NULL を返します。
- いずれかのパラメータが NaN の場合は、NaN を返します。
- パラメータが入力条件を満たさない場合は、NULL を返します。

## 例

```sql
select log(5,1);
```

```text
+---------------+
| log(5.0, 1.0) |
+---------------+
|             0 |
+---------------+
```

```sql
select log(3),ln(3);
```

```text
+--------------------+--------------------+
| log(3)             | ln(3)              |
+--------------------+--------------------+
| 1.0986122886681098 | 1.0986122886681098 |
+--------------------+--------------------+
```

```sql
select log(3,20);
```

```text
+--------------------+
| log(3.0, 20.0)     |
+--------------------+
| 2.7268330278608417 |
+--------------------+
```

```sql
select log(2,65536);
```

```text
+-------------------+
| log(2.0, 65536.0) |
+-------------------+
|                16 |
+-------------------+
```

```sql
select log(5,NULL);
```

```text
+------------------------------+
| log(cast(5 as DOUBLE), NULL) |
+------------------------------+
|                         NULL |
+------------------------------+
```

```sql
select log(NULL,3);
```

```text
+------------------------------+
| log(NULL, cast(3 as DOUBLE)) |
+------------------------------+
|                         NULL |
+------------------------------+
```

```sql
select log(2 ,cast('nan' as double));
```

```text
+-------------------------------+
| log(2 ,cast('nan' as double)) |
+-------------------------------+
|                           NaN |
+-------------------------------+
```

```sql
select log(2 ,-1);
```

```text
+------------+
| log(2 ,-1) |
+------------+
|       NULL |
+------------+
```
