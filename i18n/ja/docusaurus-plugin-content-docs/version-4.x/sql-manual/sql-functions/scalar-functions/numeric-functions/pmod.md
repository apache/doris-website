## 説明

剰余演算 x mod y における最小の正の解を返します。これは (x % y + y) % y を計算して求められます。

## 構文

```sql
PMOD(<x> , <y>)
```

## 引数

| 引数 | 説明 |
|-----------|------------|
| `<x>` | 被除数 |
| `<y>` | 除数。0 は指定できません |

## 戻り値

整数または浮動小数点数を返します。特殊なケースは次のとおりです。

- x = 0 の場合、0 を返します。
- x または y が NULL の場合、NULL を返します。

## 使用例

```sql
SELECT PMOD(13,5);
```

```text
+-------------+
| pmod(13, 5) |
+-------------+
|           3 |
+-------------+
```

```sql
SELECT PMOD(-13,5);
```

```text
+--------------+
| pmod(-13, 5) |
+--------------+
|            2 |
+--------------+
```

```sql
SELECT PMOD(0,-12);
```

```text
+--------------+
| pmod(0, -12) |
+--------------+
|            0 |
+--------------+
```

```sql
SELECT PMOD(0,null);
```

```text
+-------------------------------+
| pmod(cast(0 as DOUBLE), NULL) |
+-------------------------------+
|                          NULL |
+-------------------------------+
```
