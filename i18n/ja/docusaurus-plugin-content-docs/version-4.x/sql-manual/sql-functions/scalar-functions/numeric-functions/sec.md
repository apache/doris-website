## 説明

x の正割を返します。x はラジアン単位の値です。入力と出力は DOUBLE 型のみをサポートします。入力が NULL の場合は NULL を返します。

## 構文

```sql
SEC(<x>)
```

## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<x>` | 正割を計算する DOUBLE 型の値 |

## 戻り値

x の正割を表す DOUBLE 型の値を返します。入力が NULL の場合は NULL を返します。

## 特殊なケース
- `x` が NaN の場合、NaN を返します
- `x` が正または負の無限大の場合、NaN を返します
- `x` が NULL の場合、NULL を返します

## 使用例

```sql
select sec(1),sec(2),sec(1000);
```

```text
+--------------------+--------------------+--------------------+
| sec(1)             | sec(2)             | sec(1000)          |
+--------------------+--------------------+--------------------+
| 1.8508157176809255 | -2.402997961722381 | 1.7781600385912715 |
+--------------------+--------------------+--------------------+
```

入力が NULL の場合。

```sql
select sec(null);
```

```text
+--------------------+
| sec(null)          |
+--------------------+
|      NULL          |
+--------------------+
```

```sql
select sec(cast('nan' as double));
```

```text
+---------------------------+
| sec(cast('nan' AS DOUBLE))|
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select sec(cast('inf' as double));
```

```text
+---------------------------+
| sec(cast('inf' AS DOUBLE))|
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select sec(cast('-inf' as double));
```

```text
+----------------------------+
| sec(cast('-inf' AS DOUBLE))|
+----------------------------+
| NaN                        |
+----------------------------+
```
