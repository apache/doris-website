## 説明

`x` の底 `2` の対数を返します。

## 構文

```sql
LOG2(<x>)
```

## パラメータ

| パラメータ | 説明 |
|-----------|------|
| `<x>`   | 真数は 0 より大きい必要があります |

## 戻り値

浮動小数点数を返します。特殊なケースは次のとおりです。

- x が NULL の場合、`NULL` を返します
- x が NaN の場合、NaN を返します

## 例

```sql
select log2(1);
```

```text
+-------------------------+
| log2(cast(1 as DOUBLE)) |
+-------------------------+
|                     0.0 |
+-------------------------+
```

```sql
select log2(2);
```

```text
+-------------------------+
| log2(cast(2 as DOUBLE)) |
+-------------------------+
|                     1.0 |
+-------------------------+
```

```sql
select log2(10);
```

```text
+--------------------------+
| log2(cast(10 as DOUBLE)) |
+--------------------------+
|       3.3219280948873626 |
+--------------------------+
```

```sql
select log2(NULL);
```

```text
+------------+
| log2(NULL) |
+------------+
|       NULL |
+------------+
```

```sql
select log2(cast('Nan' as double));
```

```text
+-----------------------------+
| log2(cast('Nan' as double)) |
+-----------------------------+
|                         NaN |
+-----------------------------+
```
