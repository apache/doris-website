## 説明

`x` の逆双曲線正弦を返します。

## 構文

```sql
ASINH(<x>)
```

## パラメーター

| パラメーター | 説明 |
| -- | -- |
| `<x>` | 逆双曲線正弦を計算する値 |

## 戻り値

パラメーター `x` の逆双曲線正弦値。

## 特殊なケース

- `x` が NaN の場合、NaN を返します
- `x` が正の無限大の場合、Infinity を返します
- `x` が負の無限大の場合、-Infinity を返します
- `x` が +0.0 の場合、0 を返します
- `x` が -0.0 の場合、-0 を返します
- 絶対値が非常に大きい場合、オーバーフローして Infinity/-Infinity になることがあります（例：±1e308）
- `x` が NULL の場合、NULL を返します

## 例

```sql
select asinh(0.0);
```

```text
+------------+
| asinh(0.0) |
+------------+
|          0 |
+------------+
```

```sql
select asinh(1.0);
```

```text
+-------------------+
| asinh(1.0)        |
+-------------------+
| 0.881373587019543 |
+-------------------+
```

```sql
select asinh(-1.0);
```

```text
+--------------------+
| asinh(-1.0)        |
+--------------------+
| -0.881373587019543 |
+--------------------+
```

```sql
select asinh(cast('nan' as double));
```

```text
+------------------------------+
| asinh(cast('nan' AS DOUBLE)) |
+------------------------------+
| NaN                          |
+------------------------------+
```

```sql
select asinh(cast('inf' as double));
```

```text
+------------------------------+
| asinh(cast('inf' AS DOUBLE)) |
+------------------------------+
| Infinity                     |
+------------------------------+
```

```sql
select asinh(cast('-inf' as double));
```

```text
+-------------------------------+
| asinh(cast('-inf' AS DOUBLE)) |
+-------------------------------+
| -Infinity                     |
+-------------------------------+
```
