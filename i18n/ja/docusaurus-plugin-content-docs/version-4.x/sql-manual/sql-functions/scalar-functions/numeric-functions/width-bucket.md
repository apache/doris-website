## 説明

ヒストグラムの範囲を等幅の区間に分割し、式の値が属するバケット番号を返します。特別なケースは次のとおりです。

- 関数は整数値または NULL を返します。いずれかの入力が NULL の場合は NULL を返します。

## 構文

```sql
WIDTH_BUCKET(<expr>, <min_value>, <max_value>, <num_buckets>)
```

## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<expr>` | ヒストグラムを作成する対象の式です。評価結果は数値、または暗黙的に数値へ変換できる値である必要があります。値は `-(2^53 - 1)` から `2^53 - 1` までの範囲（両端を含む）に収まる必要があります。 |
| `<min_value>` | 式の許容範囲の下限値です。数値であり、`<max_value>` と異なる必要があります。値は `-(2^53 - 1)` から `2^53 - 1` までの範囲（両端を含む）に収まる必要があります。また、上限値と下限値の差は `2^53` 未満である必要があります（例: `abs(max_value - min_value) < 2^53)`）。 |
| `<max_value>` | 式の許容範囲の上限値です。数値であり、`<min_value>` と異なる必要があります。値は `-(2^53 - 1)` から `2^53 - 1` までの範囲（両端を含む）に収まる必要があります。また、上限値と下限値の差は `2^53` 未満である必要があります（例: `abs(max_value - min_value) < 2^53)`）。 |
| `<num_buckets>` | バケットの数です。正の整数である必要があります。関数は式の値をバケットに割り当て、対応するバケット番号を返します。 |

## 戻り値

式の値が属するバケット番号を返します。式の値が範囲外の場合は、次の規則に従います。

- 式の値が `min_value` より小さい場合は、0 を返します。
- 式の値が max_value 以上の場合は、`num_buckets + 1` を返します。
- いずれかのパラメータが `null` の場合は、`null` を返します。

## 例

```sql
DROP TABLE IF EXISTS width_bucket_test;

CREATE TABLE IF NOT EXISTS width_bucket_test (
`k1` int NULL COMMENT "",
`v1` date NULL COMMENT "",
`v2` double NULL COMMENT "",
`v3` bigint NULL COMMENT ""
) ENGINE=OLAP
DUPLICATE KEY(`k1`)
DISTRIBUTED BY HASH(`k1`) BUCKETS 1
PROPERTIES (
"replication_allocation" = "tag.location.default: 1",
"storage_format" = "V2"
);

INSERT INTO width_bucket_test VALUES  
(1, "2022-11-18", 290000.00, 290000),
(2, "2023-11-18", 320000.00, 320000),
(3, "2024-11-18", 399999.99, 399999), 
(4, "2025-11-18", 400000.00, 400000), 
(5, "2026-11-18", 470000.00, 470000), 
(6, "2027-11-18", 510000.00, 510000), 
(7, "2028-11-18", 610000.00, 610000), 
(8, null, null, null);
```
