## 説明

`x` の逆双曲線余弦を返します。`NULL` を返すのは、`x` が `1` 未満の場合です。

## 構文

```sql
ACOSH(<x>)
```

## パラメータ

| パラメータ | 説明 |  
| -- | -- |  
| `<x>` | 逆双曲線余弦を計算する値 |  

## 戻り値  

引数 `x` の逆双曲線余弦値を返します。

## 特殊なケース

- `x` が 1 の場合、0 を返します
- `x` が 1 未満の場合、`NULL` を返します
- `x` が NaN の場合、NaN を返します
- `x` が正の無限大の場合、Infinity を返します
- `x` が負の無限大の場合、`NULL` を返します
- `x` が NULL の場合、NULL を返します

## 使用例

```sql
select acosh(0.0);
```

```text
+------------+
| acosh(0.0) |
+------------+
|       NULL |
+------------+
```

```sql
select acosh(-1.0);
```

```text
+-------------+
| acosh(-1.0) |
+-------------+
|        NULL |
+-------------+
```

```sql
select acosh(1.0);
```

```text
+------------+
| acosh(1.0) |
+------------+
|          0 |
+------------+
```

```sql
select acosh(1.0000001);
```

```text
+-------------------------+

+-------------------------+
| 0.0004472135918947727   |
+-------------------------+
```

+----------------------------+
```

```
