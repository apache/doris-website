## 説明

浮動小数点数と固定小数点数を指定した桁で切り上げ、切り上げ後の浮動小数点数または固定小数点数を返します。

## 構文

```sql
CEIL(<a>[, <d>])
```

## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<a>` | 切り上げの対象となる浮動小数点数（Double）または固定小数点数（Decimal） |
| `<d>` | 省略可能な整数。切り上げる対象の桁数を指定します。正の値は次の小数点以下の桁への切り上げ、負の値も次の小数点以下の桁への切り上げを意味し、`0` は整数への切り上げを意味します。省略した場合は `<d> = 0` と同じです。 |

## 戻り値

次の規則に従って、`<a>` 以上となる最小の切り上げ後の数値を返します。

`1/(10^d)` の位に切り上げます。つまり、結果が `1/(10^d)` の整数倍になるようにします。`1/(10^d)` を正確に表せない場合、切り上げる単位には、対応するデータ型で最も近い値を使用します。

`<a>` が `Decimal(p, s)` 型の場合、戻り値の型は次のとおりです。

- `Decimal(p, 0)`：`<d> <= 0` の場合
- `Decimal(p, <d>)`：`0 < <d> <= s` の場合
- `Decimal(p, s)`：`<d> > s` の場合

いずれかの入力パラメータが NULL の場合は、NULL を返します。

## 別名

- DCEIL
- CEILING

## 例

```sql
select ceil(123.456);
```

```text
+---------------+
| ceil(123.456) |
+---------------+
|           124 |
+---------------+
```

```sql
select ceil(123.456, 2);
```

```text
+------------------+
| ceil(123.456, 2) |
+------------------+
|           123.46 |
+------------------+
```

```sql
select ceil(123.456, -2);
```

```text
+-------------------+
| ceil(123.456, -2) |
+-------------------+
|               200 |
+-------------------+
```

```sql
select ceil(123.45, 1), ceil(123.45), ceil(123.45, 0), ceil(123.45, -1);
```

```text
+-----------------+--------------+-----------------+------------------+
| ceil(123.45, 1) | ceil(123.45) | ceil(123.45, 0) | ceil(123.45, -1) |
+-----------------+--------------+-----------------+------------------+
|           123.5 |          124 |             124 |              130 |
+-----------------+--------------+-----------------+------------------+
```

```sql
select ceil(x, 2) from ( select cast(123.456 as decimal(6,3)) as x from numbers("number"="5") )t;
```

```text
+------------+
| ceil(x, 2) |
+------------+
|     123.46 |
|     123.46 |
|     123.46 |
|     123.46 |
|     123.46 |
+------------+
```

```sql
select ceil(NULL);
```

```text
+------------+
| ceil(NULL) |
+------------+
|       NULL |
+------------+
```
