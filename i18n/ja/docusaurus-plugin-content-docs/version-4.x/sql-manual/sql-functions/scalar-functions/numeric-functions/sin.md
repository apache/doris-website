## 説明

パラメーターの正弦値を計算します。

## 構文

```sql
SIN(<a>)
```

## パラメーター

| パラメーター | 説明 |
| -- | -- |
| `<a>` | 正弦値を計算する角度。ラジアン単位の浮動小数点数です。 |

## 戻り値

ラジアンで指定されたパラメーター `<a>` の正弦値を返します。

## 特殊なケース

- `a` が NaN の場合、NaN を返します
- `a` が正または負の無限大の場合、NaN を返します
- `a` が NULL の場合、NULL を返します

## 例

```sql
select sin(1);
```

```text
+------------------------+
| sin(cast(1 as DOUBLE)) |
+------------------------+
|     0.8414709848078965 |
+------------------------+
```

```sql
select sin(0);
```

```text
+------------------------+
| sin(cast(0 as DOUBLE)) |
+------------------------+
|                    0.0 |
+------------------------+
```

```sql
select sin(Pi());
```

```text
+------------------------------------+
| sin(pi())                          |
+------------------------------------+
| 0.00000000000000012246467991473532 |
+------------------------------------+
```

```sql
select sin(cast('nan' as double));
```

```text
+----------------------------+
| sin(cast('nan' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select sin(cast('inf' as double));
```

```text
+----------------------------+
| sin(cast('inf' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select sin(cast('-inf' as double));
```

```text
+-----------------------------+
| sin(cast('-inf' AS DOUBLE)) |
+-----------------------------+
| NaN                         |
+-----------------------------+
```
