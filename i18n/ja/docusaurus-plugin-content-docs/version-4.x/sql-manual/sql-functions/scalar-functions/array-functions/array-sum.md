### 機能

`ARRAY_SUM` 関数は配列内のすべての数値要素の合計を計算します。

## 構文

```SQL
ARRAY_SUM(ARRAY<T>)
```

## パラメータ

`ARRAY<T>`: **数値型**の要素を含む配列。

## 戻り値

- 配列内の `NULL` 以外のすべての要素の合計を返します。

    - すべての要素が `NULL` の場合は `NULL` を返します。

## 使用上の注意

1. 要素の加算には `+` 演算子を使用します。

2. `NULL` の要素は自動的に無視されます。

3. 配列に文字列など数値型以外の要素が含まれると、実行時エラーになります。

## 使用例

1. 基本例

    ```SQL
    SELECT ARRAY_SUM([1, 2, 3, 4]);
    +-------------------------+
    | ARRAY_SUM([1, 2, 3, 4]) |
    +-------------------------+
    |                      10 |
    +-------------------------+
    ```

2. 配列内の `NULL` 値の処理

    ```SQL
    SELECT ARRAY_SUM([1, NULL, 3]); 
    +-------------------------+
    | ARRAY_SUM([1, NULL, 3]) |
    +-------------------------+
    |                       4 |
    +-------------------------+

    SELECT ARRAY_SUM(NULL);
    +-----------------+
    | ARRAY_SUM(NULL) |
    +-----------------+
    |            NULL |
    +-----------------+

    SELECT ARRAY_SUM([NULL, NULL]); 
    +-------------------------+
    | ARRAY_SUM([NULL, NULL]) |
    +-------------------------+
    |                    NULL |
    +-------------------------+
    ```
