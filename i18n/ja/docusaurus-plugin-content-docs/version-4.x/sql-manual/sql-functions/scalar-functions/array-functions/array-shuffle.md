## 機能

配列の要素の順序をランダムに入れ替えます。

:::note
Apache Doris 4.2 以降、`seed` は定数である必要があり、任意の `BIGINT` 値の 64 ビットすべてが使用されます。また、定数の `arr` も行ごとにシャッフルされます。そのため、同じ `seed` を指定しても、4.0 および 4.1 とは異なる順序になります。4.0 および 4.1 では、定数でない `seed` を指定してもエラーにはなりませんが、各バッチの最初の行のシードだけが使用されます。負の値または 4294967295 を超える値を `seed` に指定するとエラーになり、定数の `arr` はすべての行で同じ順序になります。
:::

## 構文

- `ARRAY_SHUFFLE(arr)`
- `ARRAY_SHUFFLE(arr, seed)`

## パラメータ

- `arr`: `ARRAY<T>`。
- `seed`: 省略可能な乱数シード。定数の `BIGINT` である必要があります。

## 戻り値

- 入力と同じ型の配列を返します。要素の順序はランダムに変わりますが、要素数と型は変わりません。

## 使用上の注意

- 入力 `arr` が `NULL` の場合は `NULL` を返します。`seed` が `NULL` の場合も `NULL` を返します。
- `arr` が定数でも、各行を個別にシャッフルします。同じ配列を持つ行でも、要素の順序が異なる場合があります。
- `seed` は `0` や `1 + 1` などの定数である必要があります。列や定数以外の式を渡すとエラーになります。
- 負の値を含む任意の `BIGINT` 値を `seed` にできます。64 ビットすべてを使用するため、`-1` と `4294967295` では結果が異なります。
- 行はバッチ単位で処理されます。各バッチは `seed` から乱数列を開始し、行はその列から順番に乱数を受け取ります。このため、`ARRAY_SHUFFLE([1, 2, 3, 4], 0)` の単独呼び出しは毎回同じ結果になりますが、多数の行を処理する場合、バッチへの分割方法によって特定の行の順序が変わることがあります。
- `seed` を省略すると、各バッチは新しい乱数シードで開始するため、実行ごとに結果が異なることがあります。
- `ARRAY_SHUFFLE` の別名は `SHUFFLE` で、両者は同等です。

## 使用例

- 基本的な使用例:
  - `ARRAY_SHUFFLE([1, 2, 3, 4])` -> 例: `[3, 1, 4, 2]` (ランダムな順序)
  - `ARRAY_SHUFFLE(['a', null, 'b'])` -> 例: `['b', 'a', null]`

- 固定シードを使う場合 (結果を再現可能):
  - `ARRAY_SHUFFLE([1, 2, 3, 4], 0)` -> `[2, 1, 3, 4]` を毎回返します

- 定数配列も行ごとにシャッフルされます:
  - `SELECT number, ARRAY_SHUFFLE([1, 2, 3, 4, 5], 0) FROM numbers("number" = "3") ORDER BY number` -> `[3, 1, 2, 4, 5]`、`[3, 5, 4, 2, 1]`、`[4, 5, 1, 3, 2]` がそれぞれの行に表示されます

- 負のシードも使用でき、64 ビットすべてが使われます:
  - `ARRAY_SHUFFLE([1, 2, 3, 4], -1)` -> `[4, 1, 3, 2]`、一方 `ARRAY_SHUFFLE([1, 2, 3, 4], 4294967295)` -> `[2, 4, 3, 1]`

- 定数でないシードはエラーになります:
  - `SELECT ARRAY_SHUFFLE(arr, id) FROM t` -> エラー `The seed of array_shuffle must be a constant`
