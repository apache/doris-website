<a id="function"></a>

## 説明 {#description}

配列内の要素の順序をランダムに並べ替え、要素とその数を保持します。入力配列またはシードが NULL の場合は NULL を返します。`SHUFFLE` はこの関数の別名です。

:::caution 動作変更（4.1.5）

Doris 4.1 系列では 4.1.5 以降、`seed` は定数である必要があります。負の値を含む任意の BIGINT 値を受け付け、64 ビットすべてを使用します。定数配列も行ごとに個別にシャッフルされるため、同じシードでも以前のバージョンとは異なる結果になる場合があります。それ以前の 4.1 バージョンでは、各バッチの最初の行のシードだけを使用し、負のシードおよび 4294967295 を超えるシードを拒否し、定数配列ではすべての行で同じ順序を生成していました。

:::

## 構文 {#syntax}

```sql
ARRAY_SHUFFLE(<arr> [, <seed>])
```

## パラメータ {#parameters}

| パラメータ | 説明 |
| --- | --- |
| `<arr>` | シャッフル対象の ARRAY。 |
| `<seed>` | 省略可能な定数 BIGINT のランダムシード。定数式をサポートします。省略すると、各バッチで新しいランダムシードを使用します。 |

## 戻り値 {#return-value}

入力と同じ型の配列を返し、要素はランダムに並べ替えられます。要素数と型は保持されます。配列またはシードが NULL の場合は NULL を返し、空の入力配列には空の配列を返します。

<a id="usage-notes"></a>

行はバッチ単位で処理されます。シードを指定すると、各バッチはそのシードからランダム系列を開始し、バッチ内の行はその系列を順番に使用します。そのため、ある行の並べ替え結果はバッチ境界に依存する場合があります。シードを指定しても、同一の配列に対して同一の並べ替えが保証されるわけではありません。定数配列も行ごとに個別にシャッフルされます。

<a id="examples"></a>

## 例 {#example}

シャッフルした配列をソートすると、要素が保持されていることを確認できます。負のシードと定数式のどちらも有効です：

```sql
SELECT ARRAY_SORT(ARRAY_SHUFFLE([1, 2, 3, 4], -1)),
       ARRAY_SORT(ARRAY_SHUFFLE([1, 2, 3, 4], 1 + 1));
```

```text
[1, 2, 3, 4]    [1, 2, 3, 4]
```

NULL と空の配列：

```sql
SELECT ARRAY_SHUFFLE(CAST(NULL AS ARRAY<INT>), 1),
       ARRAY_SHUFFLE([1, 2, 3], NULL), ARRAY_SHUFFLE([], 1);
```

```text
NULL    NULL    []
```

シードとして列を使用すると、次の内容を含むエラーが報告されます：

```sql
SELECT ARRAY_SHUFFLE([1, 2, 3], number) FROM numbers("number" = "2");
```

```text
The seed of array_shuffle must be a constant
```
