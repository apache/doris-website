## 説明

比較条件は、ある式を別の式と比較します。比較結果は TRUE、FALSE、または UNKNOWN になります。

## 演算子の概要

| 演算子 | 機能 | 例 |
| ------------------- | ----------------------------------------------------------- | ------------------- |
| `=` | 等価比較。比較のいずれか一方が UNKNOWN の場合、結果は UNKNOWN になります。 | `SELECT 1 = 1` |
| `<=>` | NULL セーフな等価比較。通常の等価比較とは異なり、NULL を比較可能な値として扱います。両辺が NULL の場合は TRUE、片方だけが NULL の場合は FALSE を返します。この演算子は UNKNOWN を返しません。 | `SELECT NULL <=> NULL` |
| `!=` `<>` | 非等価比較 | `SELECT 1 != 1` |
| `<` `>` | 大小比較 | `SELECT 1 > 1` |
| `<=` `>=` | 以上または以下の比較 | `SELECT 1 >= 1` |
| `<x> BETWEEN <y> AND <z>` | `<x> >= <y> and <x> <= <z>` と同等です。`<y>` 以上、`<z>` 以下かどうかを比較します。 | `SELECT 1 BETWEEN 0 AND 2` |
