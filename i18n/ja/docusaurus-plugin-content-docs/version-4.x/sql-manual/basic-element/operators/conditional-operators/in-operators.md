## 説明 {#description}

IN 演算子は、値が値のリストまたはサブクエリのメンバーかどうかを判定します。

## 演算子の概要 {#operator-introduction}

| 演算子 | 機能 | 例 |
| ------- | ------------------------------------------------ | ------------------------------ |
| IN     | いずれかのメンバーと等しいかどうかをテストします。等しい場合は TRUE を返します。 | `SELECT 1 IN (SELECT 2)` |
| NOT IN | すべてのメンバーと等しくないかどうかをテストします。等しくない場合は TRUE を返します。 | `SELECT 1 NOT IN (3, 4, 5)` |

## 型の制約 {#type-constraints}

`IN` と `NOT IN` は、スカラーの基本型の値のみをサポートします。`ARRAY`、`MAP`、`STRUCT` などの複合型、およびオブジェクト型は、左辺の式または `IN` リスト内の値として使用できません。

たとえば、次のステートメントは無効です。

```sql
SELECT STRUCT(1, 2) IN (STRUCT(1, 2));
SELECT [1, 2] IN ([1, 2]);
SELECT MAP('a', 1) IN (MAP('a', 1));
```
