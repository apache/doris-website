## 説明

IN 演算子は、値が値の一覧またはサブクエリの結果に含まれるかどうかを判定します。

## 演算子の概要

| 演算子 | 機能 | 例 |
| ------- | ------------------------------------------------ | ------------------------------ |
| IN     | いずれかの要素と等しいかどうかを判定します。等しい場合は TRUE を返します。 | `SELECT 1 IN (SELECT 2)` |
| NOT IN | すべての要素と異なるかどうかを判定します。すべてと異なる場合は TRUE を返します。 | `SELECT 1 NOT IN (3, 4, 5)` |
