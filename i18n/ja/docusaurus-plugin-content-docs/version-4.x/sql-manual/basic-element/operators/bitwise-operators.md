## 説明  

ビット演算子は、一つまたは二つの式に対してビット単位の演算を行います。引数には `BIGINT` 型のみを使用できるため、演算対象の式は `BIGINT` 型に変換されます。  

## 演算子の概要  

| 演算子 | 機能                                                                                     | 例         |  
|----------|----------------------------------------------------------------------------------------------|-----------------|  
| `&`      | ビット単位の AND 演算を行います。対応するビットが両方とも `1` の場合、結果は `1` になり、それ以外の場合は `0` になります。 | `SELECT 1 & 2` |  
| `\|`     | ビット単位の OR 演算を行います。対応するビットのいずれかが `1` の場合、結果は `1` になり、それ以外の場合は `0` になります。  | `SELECT 1 &#124; 2` |  
| `^`      | ビット単位の XOR 演算を行います。対応するビットが異なる場合、結果は `1` になり、それ以外の場合は `0` になります。   | `SELECT 1 ^ 2` |  
| `~`      | ビット単位の NOT 演算を行います。各ビットを反転し、`1` を `0` に、`0` を `1` にします。                          | `SELECT ~1`    |
