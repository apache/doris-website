## VARBINARY
### 説明
可変長のバイナリバイト列で、M は最大長（バイト単位）を表します。

VARCHAR とは異なり、文字セットや照合順序を使用せず、データをバイト単位で保存・比較します。ファイルの断片、ハッシュ、暗号化・圧縮されたデータなど、任意のバイナリデータに適しており、最大長は 2,147,483,647 バイトです。

現在、VARBINARY 列はマテリアライズドビューの作成時にサポートされず、GROUP BY キー、JOIN キー、比較述語にも使用できません。

バージョンと制限：4.0 以降でサポートされています。ただし、現在 Doris のテーブル作成とデータ保存に使用する列の型としてはサポートされていません。外部システムの BINARY/VARBINARY フィールドは、Catalog を介して Doris の VARBINARY にマッピングし、クエリできます。

### キーワード
VARBINARY
