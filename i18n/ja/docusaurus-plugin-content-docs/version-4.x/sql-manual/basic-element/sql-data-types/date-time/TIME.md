# TIME

## 説明

TIME(p) 型は時間値を格納します。p は精度を表し、指定できる値は `[0, 6]`、デフォルトは 0 です。つまり、TIME は TIME(0) と同等です。

値の範囲は `[-838:59:59.999..., 838:59:59.999...]` で、デフォルトの出力形式は 'HH:mm:ss.SSS...' です。小数点以下の桁数は p 桁です。たとえば、TIME(6) の範囲は `[-838:59:59.999999, 838:59:59.999999]` です。

TIME 型は計算の中間値として使用され、入力と出力は可能ですが、OLAP テーブルの列として保存することは**できません**。

他の型から TIME 型への変換方法と、変換時に受け付ける入力については、[TIME 型への変換](../conversion/time-conversion.md)を参照してください。

日付・時刻型には、算術演算子を直接適用できません。算術演算を行う場合は、日付・時刻型が先に数値型へ暗黙的に変換され、その後に演算が実行されます。

## 例

```sql
select cast('-123:00:02.9' as time);
```

```text
+------------------------------+
| cast('-123:00:02.9' as time) |
+------------------------------+
| -123:00:03                   |
+------------------------------+
```

```sql
select cast('838:59:59.999999' as time(6));
```

```text
+-------------------------------------+
| cast('838:59:59.999999' as time(6)) |
+-------------------------------------+
| 838:59:59.999999                    |
+-------------------------------------+
```
