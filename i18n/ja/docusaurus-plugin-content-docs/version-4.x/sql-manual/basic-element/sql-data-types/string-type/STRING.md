## STRING
### 説明
可変長文字列です。デフォルトでは 1048576 バイト (1M) までサポートし、2147483643 バイト (2G) まで調整できます。また、STRING 型の長さは、BE の設定項目 string_type_length_soft_limit_bytes (STRING 型の長さに対するソフトリミット) によっても制限されます。STRING 型は値列でのみ使用でき、キー列、パーティション列、バケット列には使用できません。

注: 可変長文字列は UTF-8 で格納されるため、通常、英語の文字は 1 バイト、中国語の文字は 3 バイトを占めます。
