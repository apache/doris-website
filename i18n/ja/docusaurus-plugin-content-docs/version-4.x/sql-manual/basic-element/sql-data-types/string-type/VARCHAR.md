## VARCHAR
### 説明
VARCHAR(M)
可変長文字列です。M は可変長文字列のバイト単位の長さを表します。M の範囲は 1-65533 です。

注: 可変長文字列は UTF-8 エンコーディングで保存されるため、通常、英字は 1 バイト、中国語の文字は 3 バイトを占めます。

### キーワード
VARCHAR
