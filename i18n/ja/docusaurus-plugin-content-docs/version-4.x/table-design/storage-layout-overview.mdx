Apache Doris は、ディスク上のストレージレイアウトをユーザーが調整できるパラメータとして公開しています。ストレージレイアウトを適切に設定すると、テーブルモデルやクエリを変更せずに、ストレージコストを削減し、ワイドテーブルに対するポイントクエリを高速化し、履歴データやコールドデータのストレージ負荷を軽減できます。
