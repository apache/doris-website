<!-- Applicable scenarios: Disaster recovery / Accidental deletion recovery / Cross-cluster migration / Test data preparation -->

Doris は、データベース、テーブル、またはパーティションのバックアップと復元をサポートします。データをスナップショットとしてリモートストレージ（S3、Azure、GCP、OSS、HDFS など）に保存し、必要なときに任意の Doris クラスターに復元できます。

## 適用シナリオ

| シナリオ | 説明 | 推奨操作 |
| --- | --- | --- |
| 誤削除したデータの復旧 | 誤って削除したテーブルまたはパーティションを、特定の時点の状態に復元する | [特定のテーブルまたはパーティションを復元する](./restore) |
| 定期的な災害対策用バックアップ | クラスターの障害やハードウェアの損傷に備えて、データベース全体を定期的にバックアップする | [データベース全体をバックアップする](./backup) |
| クラスター間のデータ移行 | 移行元クラスターから移行先クラスターへデータを移行する | [バックアップ](./backup)してから[復元](./restore)する |
| テスト環境用データの準備 | 本番環境の特定のテーブルまたはパーティションをテスト用クラスターに復元する | [特定のテーブルをバックアップ](./backup)してから[復元](./restore)する |
| 増分バックアップに近い運用 | 新規または変更されたパーティションのみをバックアップし、増分バックアップに近い運用を行う | [特定のパーティションをバックアップする](./backup) |

## 基本概念

<!-- Knowledge type: Concept definition -->

| 概念 | 定義 |
| --- | --- |
| スナップショット | データベース、テーブル、またはパーティションの、ある時点のデータを記録したものです。作成時にスナップショットのラベルを指定する必要があり、完了時にタイムスタンプが生成されます。スナップショットは、リポジトリ、ラベル、タイムスタンプの組み合わせで一意に識別されます。 |
| リポジトリ（Repository） | バックアップファイルを保存するリモートの場所です。保存先として S3、Azure、GCP、OSS、COS、MinIO、HDFS、およびその他の S3 互換ストレージを使用できます。 |
| バックアップ操作 | 対象オブジェクトのスナップショットを作成し、そのファイルをリポジトリにアップロードして、関連するメタデータを保存します。 |
| 復元操作 | リポジトリからスナップショットをダウンロードし、対象の Doris クラスターに復元します。 |

## 前提条件

- **権限**: 操作を実行するアカウントには **ADMIN** 権限が必要です。
- **デプロイモード**: ストレージとコンピュートが統合されたモードのみをサポートします。**ストレージとコンピュートの分離モードでは、バックアップと復元はサポートされません**。

## 制限事項

| 制限事項 | 説明 |
| --- | --- |
| ストレージとコンピュートの分離モードは非対応 | ストレージとコンピュートが分離されたデプロイモードでは、バックアップと復元を利用できません。 |
| 非同期マテリアライズドビュー（MTMV）は非対応 | 非同期マテリアライズドビューはバックアップに含まれず、復元後に手動で再構築する必要があります。 |
| ストレージポリシーを使用するテーブルは非対応 | [ストレージポリシー](../../../table-design/tiered-storage/remote-storage)を使用するテーブルでは、バックアップと復元はサポートされません。 |
| フルバックアップのみをサポート | 現在、増分バックアップはサポートされていません。特定のパーティションをバックアップすると、増分バックアップに近い効果を得られます。 |
| `colocate_with` 属性は保持されない | 復元後、コロケーションテーブルの `colocate_with` 属性を再設定する必要があります。 |
| 動的パーティショニングは手動で有効化が必要 | 復元後、`ALTER TABLE` を使用して動的パーティション属性を手動で有効にしてください。 |
| 同時実行できるタスク数の制限 | 同じデータベース内で同時に実行できるバックアップまたは復元タスクは一つだけです。 |

## 操作ガイド

- [バックアップ](./backup): リポジトリを作成し、データベース、テーブル、またはパーティションのフルバックアップを実行します。
- [復元](./restore): リポジトリ内のスナップショットから、データベース、テーブル、またはパーティションを対象クラスターに復元します。
