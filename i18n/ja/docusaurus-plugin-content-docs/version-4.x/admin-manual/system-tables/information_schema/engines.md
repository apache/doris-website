## 概要

このテーブルは MySQL の動作との互換性を保つためだけに使用されます。常に空です。

## データベース


`information_schema`

| ENGINE       | varchar(64) |      |
| SUPPORT      | varchar(8)  |      |
| COMMENT      | varchar(80) |      |
| TRANSACTIONS | varchar(3)  |      |
| XA           | varchar(3)  |      |
| SAVEPOINTS   | varchar(3)  |      |
