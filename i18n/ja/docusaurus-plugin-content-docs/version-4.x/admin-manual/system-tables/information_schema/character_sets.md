## 概要

サポートされている文字セットを確認できます。このテーブルは MySQL の動作との互換性のためだけに用意されており、Doris で実際に使用される文字セットを正確に反映するものではありません。

## データベース


`information_schema`


## テーブル情報

| カラム名             | 型           | 説明                                               |
| -------------------- | ------------ | -------------------------------------------------- |
| CHARACTER_SET_NAME   | varchar(512) | 文字セット名                                       |
| DEFAULT_COLLATE_NAME | varchar(64)  | デフォルトの照合順序名                             |
| DESCRIPTION          | varchar(64)  | 文字セットの詳細な説明                             |
| MAXLEN               | bigint       | 文字セット内の一文字が占める最大バイト数           |
