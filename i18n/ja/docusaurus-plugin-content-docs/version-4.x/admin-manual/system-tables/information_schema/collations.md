## 概要

文字セットのすべての照合順序を表示します。このテーブルは MySQL との互換性のためだけに使用され、実用上の意味はありません。Doris で実際に使用される文字の照合順序を正確に反映するものではありません。

## データベース


`information_schema`


## テーブル情報

| カラム名           | 型           | 説明                                                     |
| ------------------ | ------------ | -------------------------------------------------------- |
| COLLATION_NAME     | varchar(512) | 文字セットの照合順序の名前                               |
| CHARACTER_SET_NAME | varchar(64)  | 対応する文字セットの名前                                 |
| ID                 | bigint       | 照合順序の ID                                            |
| IS_DEFAULT         | varchar(64)  | 現在のデフォルトの照合順序かどうかを示します             |
| IS_COMPILED        | varchar(64)  | サービスに組み込まれているかどうかを示します             |
| SORTLEN            | bigint       | この照合順序アルゴリズムが使用するメモリに関する値       |
