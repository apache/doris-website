# 概要

Apache Doris の運用管理を補う Open API は、主にデータベース管理者が管理操作を行うために使用します。

:::note
Open API は現在安定していないため、開発者がテスト目的で使用する場合に限り推奨します。今後のバージョンでインターフェースの動作が変更される可能性があります。
本番環境では、SQL コマンドを使用して操作することを推奨します。
:::

## セキュリティ認証

次の設定により、FE と BE の API で認証を有効にできます。

| 設定項目 | 設定ファイル | デフォルト値 | 説明 |
| --- | ---| --- | --- |
| `enable_all_http_auth` | `be.conf` | `false` | BE の HTTP ポート（デフォルトは 8040）の認証を有効にします。有効にすると、BE の HTTP API にアクセスするには ADMIN ユーザーとしてログインする必要があります。 |
| `enable_brpc_builtin_services` | `be.conf` | true | brpc の組み込みサービス（デフォルトは 8060）を外部に公開するかどうかを指定します。無効にすると、HTTP ポート 8060 にアクセスできなくなります。（バージョン 2.1.7 以降でサポート） |
| `enable_all_http_auth` | `fe.conf` | `false` | FE の HTTP ポート（デフォルトは 8030）の認証を有効にします。有効にすると、FE の HTTP API にアクセスするには対応するユーザー権限が必要です。 |

:::info NOTE
FE と BE の HTTP API に必要な権限はバージョンによって異なります。詳細は該当する API のドキュメントを参照してください。
:::
