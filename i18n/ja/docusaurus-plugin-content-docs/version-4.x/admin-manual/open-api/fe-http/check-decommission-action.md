# 廃止可否確認アクション

## リクエスト

`GET /api/check_decommission`

## 説明

指定した BE を廃止できるかどうかを判定します。たとえば、ノードの廃止後も、残りのノードで必要な空き容量とレプリカ数を満たせるかどうかを確認します。
    
## パスパラメータ

なし

## クエリパラメータ

* `host_ports`

    一つ以上の BE をカンマで区切って指定します。例: `ip1:port1,ip2:port2,...`。

    port には BE のハートビートポートを指定します。

## リクエストボディ

なし

## レスポンス

廃止可能なノードの一覧を返します。

```
{
	"msg": "OK",
	"code": 0,
	"data": ["192.168.10.11:9050", "192.168.10.12:9050"],
	"count": 0
}
```
    
## 例

1. 指定した BE ノードを廃止できるかどうかを確認します。

    ```
    GET /api/check_decommission?host_ports=192.168.10.11:9050,192.168.10.12:9050
    
    Response:
    {
    	"msg": "OK",
    	"code": 0,
    	"data": ["192.168.10.11:9050", "192.168.10.12:9050"],
    	"count": 0
    }
    ```
