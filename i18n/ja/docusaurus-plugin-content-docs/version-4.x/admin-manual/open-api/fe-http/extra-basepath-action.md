# ベースパスの取得（Extra Basepath Action）

## リクエスト

`GET /api/basepath`

## 説明

HTTP のベースパスを取得します。
    
## パスパラメータ

なし

## クエリパラメータ

なし

## リクエストボディ

なし

## レスポンス

```
{
    "msg":"success",
    "code":0,
    "data":{"enable":false,"path":""},
    "count":0
}
```
