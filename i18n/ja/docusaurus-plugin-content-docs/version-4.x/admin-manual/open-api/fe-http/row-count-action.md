# 行数更新アクション

## リクエスト

`GET /api/rowcount`

## 説明

指定したテーブルの行数統計を手動で更新します。更新時には、テーブルとロールアップに対応する行数も JSON 形式で返します。
    
## パスパラメータ

なし

## クエリパラメータ

* `db`

    データベースを指定します。

* `table`

    テーブルを指定します。

## リクエストボディ

なし

## レスポンス

```
{
	"msg": "success",
	"code": 0,
	"data": {
		"tbl1": 10000
	},
	"count": 0
}
```
    
## 例

1. 指定したテーブルの行数を更新して取得します。

    ```
    GET /api/rowcount?db=example_db&table=tbl1
    
    Response:
    {
    	"msg": "success",
    	"code": 0,
    	"data": {
    		"tbl1": 10000
    	},
    	"count": 0
    }
    ```
