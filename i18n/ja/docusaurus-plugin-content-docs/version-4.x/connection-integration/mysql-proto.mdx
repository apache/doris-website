Apache Doris は **MySQL ネットワーク通信プロトコル**と完全に互換性があります。そのため、このプロトコルに対応するクライアントツール、可視化ツール、および主要なプログラミング言語向けの MySQL ドライバーやライブラリは、**Doris 専用のドライバーをインストールせずに** Doris に直接接続できます。

> Doris FE はデフォルトでポート `9030` で MySQL プロトコルのサービスを提供します。このポートは `fe.conf` の `query_port` 設定項目に対応します。

## 主なユースケース {#typical-use-cases}

用途に応じて、MySQL プロトコルによる接続は次のような場面で使用します。

| 利用場面 | 主な用途 | 推奨する方法 |
| --- | --- | --- |
| コマンドライン / スクリプトからのアクセス | 運用時の問題調査、アドホッククエリ、自動化スクリプト | MySQL CLI |
| アプリケーションとの統合 | バックエンドサービス、データ処理プログラム、ETL ジョブ | 対応する言語の MySQL ドライバー（Java / Go / Rust / Python / C++ など） |

## 接続前の準備 {#preparation-before-connecting}

接続する前に、次の情報を確認してください。

| 項目 | 説明 | 例 |
| --- | --- | --- |
| `FE_IP` | Doris FE ノードの IP アドレスまたはホスト名 | `172.20.63.118` |
| `FE_QUERY_PORT` | FE の MySQL プロトコルサービスのポート。`fe.conf` の `query_port` に対応 | `9030` |
| `USER` | ログインアカウント | `root` |
| `PASSWORD` | ログインパスワード（デフォルトでは `root` アカウントのパスワードは空） | - |

> ポートを変更する場合は、FE ノードの `fe.conf` にある `query_port` 設定項目を変更し、FE を再起動してください。

<TabItem value="mysql-cli" label="MySQL CLI" default>

コマンドラインでの操作、アドホッククエリ、スクリプトからの呼び出しなどに適しています。

### 1. MySQL クライアントをダウンロードして展開する {#1-download-and-extract-the-mysql-client}

[MySQL 公式サイト](https://dev.mysql.com/downloads/mysql/)から MySQL クライアントをダウンロードします。Doris は **MySQL 5.7 以降**のクライアントバージョンと互換性があります。

展開後、`bin/` ディレクトリに `mysql` コマンドラインツールがあります。

### 2. Doris に接続する {#2-connect-to-doris}

次のコマンドを実行して Doris に接続します。

```shell
mysql -h FE_IP -P FE_QUERY_PORT -u USER -p
```

Enter キーを押した後、パスワードを入力します（`root` アカウントにはデフォルトでパスワードがないため、そのまま Enter キーを押します）。

### 3. ログインを確認する {#3-verify-login}

ログインに成功すると、次のメッセージが表示されます。

```text
Welcome to the MySQL monitor.  Commands end with ; or \g.
Your MySQL connection id is 236
Server version: 5.7.99 Doris version doris-2.0.3-rc06-37d31a5

Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

mysql>
```

<TabItem value="java" label="Java">

Java アプリケーションから Doris を利用する場合に適しています。Doris では、接続に **MySQL JDBC Connector** を使用することを推奨します。

### 1. JDBC ドライバーを追加する {#1-add-the-jdbc-driver}

プロジェクトに MySQL JDBC Connector の依存関係を追加します（MySQL 5.1.49 以降を推奨します）。

### 2. 接続コードを記述する {#2-write-the-connection-code}

```java
String user = "user_name";
String password = "user_password";
String url = "jdbc:mysql://FE_IP:FE_QUERY_PORT/demo"
        + "?useUnicode=true"
        + "&characterEncoding=utf8"
        + "&useTimezone=true"
        + "&serverTimezone=Asia/Shanghai"
        + "&useSSL=false"
        + "&allowPublicKeyRetrieval=true";

try (Connection conn = DriverManager.getConnection(url, user, password);
     Statement stmt = conn.createStatement();
     ResultSet rs = stmt.executeQuery("show databases")) {

    ResultSetMetaData metaData = rs.getMetaData();
    int columnCount = metaData.getColumnCount();
    while (rs.next()) {
        for (int i = 1; i <= columnCount; i++) {
            System.out.println(rs.getObject(i));
        }
    }
} catch (SQLException e) {
    log.error("get JDBC connection exception.", e);
}
```

### 3. よく使う JDBC URL パラメーター {#3-common-jdbc-url-parameters}

| パラメーター | 意味 | 推奨値 / 例 | 必須 |
| --- | --- | --- | --- |
| `useUnicode` | Unicode 文字セットを使用するかどうか | `true` | いいえ |
| `characterEncoding` | 文字エンコーディング | `utf8` | いいえ |
| `useTimezone` | タイムゾーン変換を有効にするかどうか | `true` | いいえ |
| `serverTimezone` | サーバーのタイムゾーン | `Asia/Shanghai` | いいえ |
| `useSSL` | 接続に SSL を使用するかどうか | `false` | いいえ |
| `allowPublicKeyRetrieval` | サーバーから公開鍵を取得できるようにするかどうか（通常、MySQL 8 ドライバーで必要） | `true` | いいえ |
| `sessionVariables` | 接続時に初期化するセッション変数 | `key1=val1,key2=val2` | いいえ |

### 4. セッション変数を初期化する（任意） {#4-initialize-session-variables-optional}

接続時にセッション変数を初期化する場合は、次の URL 形式を使用します。

```text
jdbc:mysql://FE_IP:FE_QUERY_PORT/demo?sessionVariables=key1=val1,key2=val2
```
