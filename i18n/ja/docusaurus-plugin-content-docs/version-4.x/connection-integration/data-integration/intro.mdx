# データ統合 {#data-integration}

Apache Dorisは、幅広いデータエコシステムのツールとの連携に対応しています。用途に合ったツールを選ぶことで、Dorisをデータ可視化、データ移行と同期、リアルタイム取り込み、ログとオブザーバビリティの分析、データベースの開発と管理、データモデリングと変換に活用できます。
