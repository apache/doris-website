# データ連携

Apache Doris は、データエコシステムの幅広いツールとの連携に対応しています。用途に適したツールを選ぶことで、Doris をデータの可視化、移行と同期、リアルタイムの取り込み、ログと可観測性の分析、データベースの開発と管理、データモデリングと変換に活用できます。
