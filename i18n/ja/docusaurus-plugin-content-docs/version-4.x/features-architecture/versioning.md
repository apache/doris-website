## バージョン番号とは？

Apache Doris は三つの部分からなるバージョン番号（X.Y.Z）を使用します。それぞれの数字は異なるリリースの種類を表します。

| 位置 | 名称 | 説明 |
|------------------|------|-------------|
| X | メジャーバージョン | 主要な機能のリリースまたはアーキテクチャのアップグレード。おおむね 1 年周期 |
| Y | マイナーバージョン | 重要な機能と性能の改善。おおむね四半期ごと |
| Z | パッチバージョン | バグ修正と性能の改善。2-4 週間周期 |

**例**：バージョン `2.1.0` は、メジャーバージョンが 2、マイナーバージョンが 1、パッチバージョンが 0 であることを示します。

## アップグレード前に知っておくべきこと

### バージョン番号の位置による互換性の違い

| バージョンの種類 | メタデータ／データ形式の変更 | 互換性に関する注意事項 |
|--------------|--------------------------------|---------------------|
| メジャーバージョン（X） | 変更される可能性あり | 前方互換性はありますが、後方互換性は保証されません |
| マイナーバージョン（Y） | 変更なし | 新機能を使用しない限り、前方互換性と後方互換性の両方が保証されます |
| パッチバージョン（Z） | 変更なし | 前方互換性と後方互換性が完全にあり、自由にアップグレードまたはダウングレードできます |

:::warning 重要
メジャーバージョンをアップグレードした場合、**古いバージョンへのダウングレードは保証されません**。アップグレード前にデータをバックアップしてください。
:::

### アップグレード前のチェックリスト

-  アップグレード先がメジャー、マイナー、パッチのどのリリースに当たるか確認する
-  重要なデータとメタデータをバックアップする
-  テスト環境でアップグレード手順を検証する
-  バージョンの互換性に関する注意事項があれば確認する

## バージョンの選び方

Apache Doris は、最新のバージョンとして二つのブランチを維持しています。

| バージョンの種類 | 用途 | 説明 |
|--------------|-----------|-------------|
| **Latest** | POC、性能テスト、新機能の試用 | 最新の機能が含まれますが、不安定な場合があります |
| **Stable** | 本番環境 | バグ修正が継続され、安定性が高いバージョンです |

**選択の目安**：
- 本番環境：**Stable** を選択
- 調査とテスト：**Latest** を選択

## CPU の種類とバイナリの選択

Doris は、異なる CPU 命令セットに対応する三種類のバイナリを提供しています。

| バージョン | 対応する CPU | 説明 |
|---------|----------------|-------------|
| x64 (avx2) | avx2 命令セットに対応する x86_64 CPU | 最高の性能 |
| x64 (no avx2) | avx2 に対応していない x86_64 CPU | 互換性を優先 |
| ARM64 | ARM アーキテクチャの CPU | Apple M シリーズ、Kunpeng など |

### CPU が avx2 に対応しているか確認する方法

```bash
cat /proc/cpuinfo | grep avx2
```

このコマンドで出力が得られた場合、CPU は avx2 命令セットに対応しています。性能を高めるには x64 (avx2) ビルドを選択できます。

## よくある質問

### Q: 2.0 から 3.1 にアップグレードできますか？

はい。ただし、メジャーバージョンのアップグレードではデータ形式が変更される場合があります。アップグレード前に、次の準備をしてください。

1. データをバックアップする
2. テスト環境で検証する
3. ロールバック計画を立てる

### Q: パッチバージョンはいつでもアップグレードできますか？

はい。パッチバージョン（2.1.0 から 2.1.1 など）は前方互換性と後方互換性の両方が保証されているため、いつでもアップグレードまたはダウングレードできます。

### Q: 現在の Doris のバージョンを確認するにはどうすればよいですか？

`SELECT VERSION();` を実行すると、現在のバージョンを確認できます。

### Q: Latest と Stable はどこからダウンロードできますか？

すべてのバージョンのダウンロードリンクについては、[Apache Doris のダウンロードページ](https://doris.apache.org/download)を参照してください。
