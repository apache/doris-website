# データ整合性の問題

このドキュメントでは、Doris の使用中によく発生するデータ整合性の問題を記録します。内容は定期的に更新します。

「テーブル内のキー重複データ」とは、Merge-on-Write 方式の Unique Key テーブルで同じキーを持つデータが重複して現れることを指します。この問題は、[フルコンパクションを実行する](../admin-manual/trouble-shooting/repairing-data)ことで修復できます。その他のデータ整合性の問題は、状況に応じた個別の対処が必要になる場合があります。支援が必要な場合は、コミュニティサポートにお問い合わせください。
