実行チューニングは、実行時に明らかになるパフォーマンスのボトルネックに対処します。たとえば、不適切な並列度、適時に効果を発揮しない RuntimeFilter、Shuffle のデータスキュー、オプティマイザの選択に手動で介入する必要がある場合などです。まず Profile で症状を特定し、対応するチューニング方法を選んでください。
