Apache Doris の適応型オプティマイザと Pipeline 実行エンジンにより、多くのワークロードは特別な調整なしで動作します。ただし、本番環境では通常、体系的なパフォーマンスチューニングが必要です。まずチューニングの進め方に沿ってボトルネックを特定し、次にクエリまたはデータ取り込みの具体的なシナリオに合わせて最適化します。実行計画の解釈が難しい場合は、その背景にある仕組みを理解するために最適化技術の仕組みを参照してください。
