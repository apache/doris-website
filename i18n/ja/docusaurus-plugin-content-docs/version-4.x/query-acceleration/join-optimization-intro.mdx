Apache Doris は、ほとんどの JOIN クエリで初期設定のままでも良好な性能を発揮します。ただし、性能要件が厳しい場合は、テーブルのコロケーションを設定し、ヒントを使ってオプティマイザを誘導することで、さらに最適化できます。まず Colocation Join を使用して、バケット分割列の等価 JOIN でネットワークシャッフルをなくすことを推奨します。そのうえで、オプティマイザの選択が最適でない場合は、Distribute Hint と Leading Hint を使ってシャッフル方式と JOIN 順序を調整します。
