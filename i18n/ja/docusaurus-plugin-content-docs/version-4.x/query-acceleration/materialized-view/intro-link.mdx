マテリアライズドビューは、計算ロジックとデータの両方を含むエンティティです。クエリの高速化、軽量な ETL モデリング、レイクハウスのフェデレーテッドクエリの高速化に使用できます。まず概念を理解し、次にデータの鮮度に関する要件に応じて同期マテリアライズドビューと非同期マテリアライズドビューのどちらかを選択してください。

詳しくは、[マテリアライズドビュー](./intro)の関連ドキュメントを参照してください。
