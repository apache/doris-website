このドキュメントでは、`CREATE CATALOG` 文を使用して Google Dataproc Metastore に接続し、アクセスする際にサポートされるパラメータについて説明します。

| プロパティ名 | 説明 | デフォルト値 | 必須 |
| ----------- | ---- | ------------ | ---- |
| `hive.metastore.uri` | Metastore の URI アドレス。[Dataproc Metastore Services](https://console.cloud.google.com/dataproc/metastore) ページで確認できます。 | なし | はい |
