# 統計情報

Doris は、Hive、Iceberg、Paimon などの外部データソースのテーブルに対して、統計情報の自動収集と手動収集をサポートしています。統計情報の精度はコスト見積もりの精度を直接左右し、最適なクエリプランの選択にとって重要です。これにより、特に複雑なクエリで実行効率を大幅に改善できます。

詳しくは、[統計情報](../query-acceleration/optimization-technology-principle/statistics#external-table-collection)ドキュメントの「外部テーブルの統計情報収集」セクションを参照してください。
