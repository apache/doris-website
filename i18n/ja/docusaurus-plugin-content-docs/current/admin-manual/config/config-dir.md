# 設定ファイルディレクトリ

FE と BE の設定ファイルディレクトリは `conf/` です。既定の fe.conf や be.conf などを保存するほか、各種設定ファイルの共通の保存先としても使用します。

ユーザーはこのディレクトリに設定ファイルを配置できます。システムはそれらを自動的に読み込みます。

## hdfs-site.xml と hive-site.xml

Doris の一部の機能では、HDFS 上のデータや Hive メタストアにアクセスする必要があります。

これらの機能で使用するステートメントに、HDFS/Hive の各種パラメータを手動で指定できます。

ただし、パラメータの数が多いため、すべてを手動で指定するのは手間がかかります。

そのため、ユーザーは HDFS または Hive の設定ファイルである hdfs-site.xml/hive-site.xml を `conf/` ディレクトリに直接配置できます。Doris はこれらの設定ファイルを自動的に読み込みます。

ユーザーがコマンドで指定した設定は、設定ファイル内の設定項目を上書きします。

これにより、ユーザーは少数の設定項目を指定するだけで HDFS/Hive にアクセスできます。
