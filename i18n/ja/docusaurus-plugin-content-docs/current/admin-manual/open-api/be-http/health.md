# 稼働確認

## リクエスト

`GET /api/health`

## 説明

監視サービスが BE の稼働状態を確認するための API です。BE が稼働している場合は応答を返します。

## クエリパラメータ

なし

## リクエストボディ

なし

## レスポンス

    ```
    {"status": "OK","msg": ""}
    ```

## 例


    ```
    curl http://127.0.0.1:8040/api/health
    ```
