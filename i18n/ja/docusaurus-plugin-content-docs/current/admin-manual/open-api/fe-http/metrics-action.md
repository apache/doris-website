# メトリクスの取得（Metrics Action）

## リクエスト

`GET /api/metrics`

## 説明

Doris のメトリクスを取得します。

## パスパラメータ

なし

## クエリパラメータ

* `type`

    省略可能です。デフォルトではすべてのメトリクスを表示します。指定できる値は次のとおりです。
    - `core` コアメトリクスを出力します。
    - `json` メトリクスを JSON 形式で出力します。

## リクエストボディ

なし

## レスポンス

追記予定
