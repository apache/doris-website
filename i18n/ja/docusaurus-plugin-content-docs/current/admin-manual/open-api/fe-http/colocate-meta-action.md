# Colocate メタアクション

## リクエスト

`GET /api/colocate`
`POST/DELETE /api/colocate/group_stable`
`POST /api/colocate/bucketseq`

## 説明

Colocate グループの情報を取得または変更するために使用します。
    
## パスパラメータ

なし

## クエリパラメータ

* `db_id`

    データベース ID を指定します。

* `group_id`
    
    グループ ID を指定します。
