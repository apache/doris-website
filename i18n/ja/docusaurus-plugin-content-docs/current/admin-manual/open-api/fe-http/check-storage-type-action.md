# ストレージタイプの確認（Check Storage Type Action）

## リクエスト

`GET /api/_check_storagetype`

## 説明

指定したデータベース内のテーブルのストレージ形式が行ストレージ形式かどうかを確認します。（行ストレージ形式は非推奨です）
    
## パスパラメータ

なし

## クエリパラメータ

* `db`

    データベースを指定します。

## リクエストボディ

なし

## レスポンス

```
{
	"msg": "success",
	"code": 0,
	"data": {
		"tbl2": {},
		"tbl1": {}
	},
	"count": 0
}
```

テーブル名の後に内容がある場合は、ストレージ形式が行ストレージ形式のベーステーブルまたはロールアップテーブルが表示されます。

## 例

1. 指定したデータベース内の次のテーブルのストレージ形式が行ストレージ形式かどうかを確認します。

    ```
    GET /api/_check_storagetype
    
    Response:
    {
    	"msg": "success",
    	"code": 0,
    	"data": {
    		"tbl2": {},
    		"tbl1": {}
    	},
    	"count": 0
    }
    ```
