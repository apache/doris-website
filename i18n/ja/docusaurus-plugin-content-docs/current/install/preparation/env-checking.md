この文書では、Doris のデプロイに必要なハードウェアとソフトウェア環境の目安を示します。

## ハードウェア環境の確認

<!-- Knowledge type: Hardware requirements -->

| 確認項目 | 最小構成 | 推奨構成 |
| -------- | -------- | -------- |
| CPU | AVX2 命令セットに対応 | AVX2 命令セットに対応 |
| メモリ | CPU コア数 × 4 GB | CPU コア数 × 8 GB |
| ストレージ | SSD または HDD | SSD |
| ファイルシステム | ext4 または xfs | ext4 または xfs |
| ネットワークカード | 1GbE | 10GbE + リンクアグリゲーション |

### CPU の確認

Doris は AVX2 ベクトル化を使ってクエリを高速化します。AVX2 命令セットに対応したマシンを推奨します。

```bash
cat /proc/cpuinfo | grep avx2
```

出力があれば AVX2 に対応しています。対応していない場合は、AVX2 非対応版の Doris インストールパッケージを使用できます。

### メモリの確認

<!-- Knowledge type: Memory configuration reference -->

Doris はメモリの上限を強制しません。本番環境には次の構成を推奨します。

| コンポーネント | 最小メモリ | 推奨メモリ |
| ---- | -------- | -------- |
| FE | 16 GB | 64 GB+ |
| BE | CPU コア数 × 4 GB | CPU コア数 × 8 GB |

### ストレージの確認

<!-- Knowledge type: Storage selection reference -->

| 用途 | 推奨ストレージ |
| ---- | ------------ |
| 大規模データへの高並列ポイントクエリ | SSD |
| 大規模データの高頻度更新 | SSD |
| コールドデータのアーカイブ | HDD / オブジェクトストレージ |

### ファイルシステムの確認

| ファイルシステム | 適した用途 |
| -------- | -------- |
| ext4 | 汎用的で安定性が高い |
| xfs | 大規模データ、高並列の書き込み |

### ネットワークカードの確認

10GbE 以上のネットワークを推奨します。ネットワークカードが複数ある場合は、リンクアグリゲーションで帯域幅と冗長性を高めます。

## 推奨サーバー構成

<!-- Knowledge type: Server specification reference -->

x86-64 と ARM64 の両アーキテクチャに対応しています。

### 開発環境とテスト環境

FE と BE は同じサーバーに配置できます。

- 単一のサーバーに 1 FE + 1 BE を配置します（複数インスタンスは推奨しません）
- データを 3 レプリカにする場合は、少なくとも 3 台のサーバーに BE を 1 台ずつ配置します

| モジュール | 最小 CPU | 最小メモリ | 最小ディスク | ネットワーク | インスタンス数 |
| -------- | -------- | -------- | ----------------- | -------------- | ------ |
| Frontend | 8 コア | 8 GB | SSD/SATA、10 GB+ | 1GbE/10GbE | 1 |
| Backend | 8 コア | 16 GB | SSD/SATA、50 GB+ | 1GbE/10GbE | 1 |

### 本番環境

FE と BE は別々のサーバーに配置することを推奨します。資源が限られていて同居させる場合は、データを別々のディスクに配置してください。

| モジュール | 推奨 CPU | 推奨メモリ | 推奨ディスク | ネットワーク | インスタンス数 |
| -------- | -------- | -------- | ----------------- | ------- | ------ |
| Frontend | 16 コア+ | 64 GB+ | SSD、100 GB+ | 10GbE | 1 |
| Backend | 16 コア+ | 64 GB+ | SSD/SATA、100 GB+ | 10GbE | 3 |

## ディスク容量の計算

<!-- Knowledge type: Storage capacity calculation -->

| コンポーネント | 推奨容量 | 説明 |
| ---- | -------- | ---- |
| FE | 100 GB+ | メタデータ保存用の SSD |
| BE | データ総量 × 3 × 1.4 | LZ4 圧縮率 0.3-0.5、3 レプリカに加えてバックグラウンドのコンパクション用に 40% の余裕を確保 |

> 上記の BE ストレージ容量の計算は、主に**ストレージ・コンピュート一体型**を対象としています。**ストレージ・コンピュート分離型**では、すべてのデータを共有ストレージに保存し、ローカルディスクはキャッシュにのみ使用します。そのため、必要なローカルディスク容量はホットデータの量によって決まります。

## Java 環境の確認

<!-- Knowledge type: Java version requirements -->

Doris のすべてのプロセスは Java に依存します。

| Doris のバージョン | Java のバージョン | 推奨バージョン |
| ---------- | --------- | -------- |
| 2.1 以前（当該バージョンを含む） | Java 8 | jdk-8u352+ |
| 3.0 以降（当該バージョンを含む） | Java 17 | jdk-17.0.10+ |
