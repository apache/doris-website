数値リテラルを使用して固定小数点数と浮動小数点数を指定します。

## 整数リテラル

整数は数字の並びで表され、符号を付けることもできます。例：+1、-2、345。

Doris は入力値に基づいて整数リテラルを格納する型を決定します。値の範囲と型の対応を次の表に示します。

| 値の範囲            | 型       |
| :------------------ | :------- |
| -2^7 ～ 2^7 - 1     | TINYINT  |
| -2^15 ～ 2^15 - 1   | SMALLINT |
| -2^31 ～ 2^31 - 1   | INT      |
| -2^63 ～ 2^63 - 1   | BIGINT   |
| -2^127 ～ 2^127 - 1 | LARGEINT |

## 固定小数点数と浮動小数点数のリテラル

固定小数点数と浮動小数点数のリテラルは、整数部、小数部、またはその両方を持つことができます。符号を付けることもできます。例：1、.2、3.4、-5、-6.78、+9.10。

仮数部と指数部を含む科学的記数法でも表せます。どちらか一方、または両方に符号を付けることができます。例：1.2E3、1.2E-3、-1.2E3、-1.2E-3。

この形式で表した数値は、優先的に固定小数点数として解析されます。サポートされる固定小数点数の範囲は、変数 `enable_decimal256` によって決まります。`enable_decimal256` が `TRUE` の場合、最大精度は 76 です。`enable_decimal256` が `FALSE` の場合、最大精度は 38 です。

数値に必要な精度が固定小数点数で表現できる最大値を超える場合、その数値は DOUBLE 型の浮動小数点数として解析されます。
