## 説明

コメントを使うと、アプリケーションを読みやすく、保守しやすくできます。たとえば、文の中にコメントを記述して、その文がアプリケーション内で果たす目的を説明できます。SQL 文中のコメント（HINT を除く）は、文の実行に影響しません。HINT でこの形式のコメントを使用する方法については、[HINT](../../query-acceleration/tuning/tuning-plan/adjusting-join-shuffle)のセクションを参照してください。

SQL 文では、コメントをキーワード、パラメータ、記号の間のどこにでも記述できます。文にコメントを記述する方法は、次の二つです。

- 複数行コメント: スラッシュとアスタリスク（`/*`）で始め、その後にコメントのテキストを記述します。テキストは複数行にわたって記述できます。アスタリスクとスラッシュ（`*/`）で終えます。開始記号や終了記号とテキストの間に、スペースや改行を入れる必要はありません。
- 単一行コメント: 二つのハイフン（`--`）で始め、その後にコメントのテキストを記述します。テキストを次の行まで続けることはできません。コメントは改行文字で終わります。

## 例

### 複数行コメント

```sql
SELECT /* This is a multi-line comment
          that can span multiple lines */
       column_name
FROM   table_name;
```

### 単一行コメント

```sql
SELECT column_name -- This is a single-line comment
FROM   table_name;
```
