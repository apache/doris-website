## 説明

算術演算子は、一つまたは二つの引数を使って、数値の符号反転、加算、減算、乗算、除算を行います。一部の演算子は、日付と時刻の間隔に対する算術演算にも使用します。演算子の引数は、数値型として解析できるデータ型、または数値型に暗黙的に変換できるデータ型である必要があります。

単項算術演算子は、引数の数値型と同じデータ型を返します。二項算術演算子では、Doris は暗黙的な型変換の規則に従って引数を計算に適した型に変換し、結果に適した型を返します。具体的な変換規則については、「型変換」セクションを参照してください。

## 使用上の注意

算術式では、次の点に注意してください。
1. 二重否定を表すためにマイナス記号を連続させた `--` を使用しないでください（SQL のコメント記号です）。
2. 必要に応じて、`-(-5)` または `- -5` のように、括弧やスペースで区切ってください。
3. コメントに関する詳しい規則については、「コメント」セクションを参照してください。
