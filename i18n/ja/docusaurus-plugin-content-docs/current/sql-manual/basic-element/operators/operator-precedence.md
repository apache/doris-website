## 説明

演算子の優先順位は、式の中で演算子を評価する順序を決めます。式に複数の演算子がある場合、Doris は優先順位の高いものから計算します。

## 演算子の優先順位

表の上から下に向かって優先順位が下がります。最上段が最も優先されます。

| 優先順位 | 演算子 |
|------------|----------|
| 1          | !        |
| 2          | +（単項プラス）、-（単項マイナス）、~（単項ビット NOT）、^ |
| 3          | *, /, %, DIV |
| 4          | -, +     |
| 5          | &        |
| 6          | \|       |
| 7          | =（比較）, <=>, >=, >, <=, <, <>, !=, IS, LIKE, REGEXP, MATCH, IN |
| 8          | NOT      |
| 9          | AND, &&  |
| 10         | XOR      |
| 11         | OR       |
| 12         | \|\|     |
