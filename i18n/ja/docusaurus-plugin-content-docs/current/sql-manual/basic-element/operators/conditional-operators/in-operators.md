## 説明 {#description}

IN 演算子は、値が値のリストまたはサブクエリの結果に含まれるかどうかを判定します。

## 演算子の概要 {#operator-introduction}

| 演算子 | 機能 | 例 |
| ------- | ------------------------------------------------ | ------------------------------ |
| IN     | いずれかの要素と等しいかどうかを判定します。等しい場合は TRUE を返します。 | `SELECT 1 IN (SELECT 2)` |
| NOT IN | すべての要素と等しくないかどうかを判定します。すべての要素と等しくない場合は TRUE を返します。 | `SELECT 1 NOT IN (3, 4, 5)` |

## 型の制約 {#type-constraints}

`IN` と `NOT IN` は、スカラーのプリミティブ値のみをサポートします。`ARRAY`、`MAP`、`STRUCT` などの複合型やオブジェクト型は、左辺の式にも `IN` リスト内の値にも使用できません。

たとえば、次の文は無効です。

```sql
SELECT STRUCT(1, 2) IN (STRUCT(1, 2));
SELECT [1, 2] IN ([1, 2]);
SELECT MAP('a', 1) IN (MAP('a', 1));
```
