# S3 {#s3}

## 説明 {#description}

S3 テーブル値関数（TVF）を使用すると、S3 互換のオブジェクトストレージに保存されたファイルを、リレーショナルテーブル形式のデータとして読み取り、アクセスできます。現在、`csv/csv_with_names/csv_with_names_and_types/json/parquet/orc` ファイル形式をサポートしています。

## 構文 {#syntax}

```sql
S3(
    "uri" = "<uri>",
    "s3.access_key" = "<s3_access_key>",
    "s3.secret_key" = "<s3_secret_key>",
    "s3.region" = "<s3_region>",
    "s3.endpoint" = "<s3_endpoint>",
    "format" = "<format>"
    [, "<optional_property_key>" = "<optional_property_value>" [, ...] ]
  )
```

## 必須パラメータ {#required-parameters}

| パラメータ | 説明 |
|-----------------|---------------------------------------------------------------------------------------------------------------------------------------|
| `uri`           | S3 にアクセスするための URI。ワイルドカードと範囲パターンをサポートします。詳細は[ファイルパスパターン](../../basic-element/file-path-pattern)を参照してください。`use_path_style` パラメータに応じて、Path Style または Virtual-hosted Style を使用します。 |
| `s3.access_key` | S3 のアクセスキー |
| `s3.secret_key` | S3 のシークレットキー |
| `s3.region`     | S3 のリージョン |
| `s3.endpoint`   | S3 のエンドポイントアドレス |
| `format`        | ファイル形式。`csv/csv_with_names/csv_with_names_and_types/json/parquet/orc` をサポートします。 |

## 注意事項 {#notes}

1. AWS S3 の標準的な URI 形式には、以下があります。

   - AWS Client Style（Hadoop S3 Style）

      ```
      s3://my-bucket/path/to/file?versionId=abc123&partNumber=77&partNumber=88
      ```

   - Virtual Host Style

      ```
      https://my-bucket.s3.us-west-1.amazonaws.com/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   - Path Style

      ```
      https://s3.us-west-1.amazonaws.com/my-bucket/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   これら 3 つの標準的な URI 形式のほかに、あまり一般的ではありませんが、以下の URI 形式もサポートしています。

   - Virtual Host AWS Client（Hadoop S3）混合形式

      ```
      s3://my-bucket.s3.us-west-1.amazonaws.com/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   - Path AWS Client（Hadoop S3）混合形式

      ```
      s3://s3.us-west-1.amazonaws.com/my-bucket/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   詳しい使用例は、以下の例を参照してください。

2. TVF を直接クエリする場合や、この TVF を基に View を作成する場合は、Resource に対する USAGE 権限が必要です。TVF を基に作成した View をクエリする場合は、その View に対する SELECT 権限のみが必要です。

## 例 {#examples}

- S3 互換のオブジェクトストレージ上の CSV 形式のファイルを読み取る

  ```sql
  select * from s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                  "s3.access_key"= "minioadmin",
                  "s3.secret_key" = "minioadmin",
                  "s3.endpoint" = "http://127.0.0.1:9312",
                  "s3.region" = "us-east-1",
                  "format" = "csv",
                  "use_path_style" = "true") order by c1;
  ```


- `desc function` と組み合わせて使用する

  ```sql
  desc function s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                   "s3.access_key"= "minioadmin",
                   "s3.secret_key" = "minioadmin",
                   "s3.endpoint" = "http://127.0.0.1:9312",
                   "s3.region" = "us-east-1",
                   "format" = "csv",
                   "use_path_style" = "true");
  ```

- **CSV 形式**

  S3 テーブル値関数はテーブルスキーマを事前に把握していないため、ファイルを一度読み取ってテーブルスキーマを解析します。

  `csv` 形式：S3 テーブル値関数は S3 上のファイルを CSV ファイルとして読み取り、先頭行を使ってテーブルスキーマを解析します。先頭行の列数 `n` をテーブルスキーマの列数とし、列名には `c1, c2, ..., cn` を自動的に割り当てます。すべての列の型は `String` になります。例：

  `student1.csv` ファイルの内容：

  ```
  1,ftw,12
  2,zs,18
  3,ww,20
  ```

  S3 TVF の使用例：

    ```sql
    select * from s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                     "s3.access_key"= "minioadmin",
                     "s3.secret_key" = "minioadmin",
                     "s3.endpoint" = "http://127.0.0.1:9312",
                     "s3.region" = "us-east-1",
                     "format" = "csv",
                     "use_path_style" = "true") order by c1;

    +------+------+------+
    | c1   | c2   | c3   |
    +------+------+------+
    | 1    | ftw  | 12   |
    | 2    | zs   | 18   |
    | 3    | ww   | 20   |
    +------+------+------+
    ```

  `desc function S3()` でテーブルスキーマを確認できます：

    ```sql
    Desc function s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                     "s3.access_key"= "minioadmin",
                     "s3.secret_key" = "minioadmin",
                     "s3.endpoint" = "http://127.0.0.1:9312",
                     "s3.region" = "us-east-1",
                     "format" = "csv",
                     "use_path_style" = "true");

    +-------+------+------+-------+---------+-------+
    | Field | Type | Null | Key   | Default | Extra |
    +-------+------+------+-------+---------+-------+
    | c1    | TEXT | Yes  | false | NULL    | NONE  |
    | c2    | TEXT | Yes  | false | NULL    | NONE  |
    | c3    | TEXT | Yes  | false | NULL    | NONE  |
    +-------+------+------+-------+---------+-------+
    ```

- **`csv_with_names` 形式**

  `csv_with_names` 形式：ファイルの先頭行からテーブルスキーマの列数と列名を解析します。すべての列の型は `String` になります。例：

  `student_with_names.csv` ファイルの内容：

  ```
  id,name,age
  1,ftw,12
  2,zs,18
  3,ww,20
  ```

  S3 TVF の使用例：

  ```sql
  select * from s3("uri" = "http://127.0.0.1:9312/test2/student_with_names.csv",
                    "s3.access_key"= "minioadmin",
                    "s3.secret_key" = "minioadmin",
                    "s3.endpoint" = "http://127.0.0.1:9312",
                    "s3.region" = "us-east-1",
                    "format" = "csv_with_names",
                    "use_path_style" = "true") order by id;

  +------+------+------+
  | id   | name | age  |
  +------+------+------+
  | 1    | ftw  | 12   |
  | 2    | zs   | 18   |
  | 3    | ww   | 20   |
  +------+------+------+
  ```

- 同様に、`desc function S3()` でテーブルスキーマを確認できます

  ```sql
  desc function s3("uri" = "http://127.0.0.1:9312/test2/student_with_names.csv",

                    "s3.secret_key" = "minioadmin",
                    "s3.endpoint" = "http://127.0.0.1:9312",
                    "s3.region" = "us-east-1",
                    "format" = "csv_with_names",
                    "use_path_style" = "true");

    +-------+------+------+-------+---------+-------+
    | Field | Type | Null | Key   | Default | Extra |
    +-------+------+------+-------+---------+-------+
    | id    | TEXT | Yes  | false | NULL    | NONE  |
    | name  | TEXT | Yes  | false | NULL    | NONE  |
    | age   | TEXT | Yes  | false | NULL    | NONE  |
    +-------+------+------+-------+---------+-------+
  ```

- **`csv_with_names_and_types` 形式**

  `csv_with_names_and_types` 形式：現在、CSV ファイルからの列の型の解析には対応していません。この形式を使用すると、S3 TVF は先頭行からテーブルスキーマの列数と列名を解析し、すべての列の型を String に設定します。ファイルの 2 行目は無視します。

  `student_with_names_and_types.csv` ファイルの内容：

  ```
  id,name,age
  INT,STRING,INT
  1,ftw,12
  2,zs,18
  3,ww,20
  ```

  S3 TVF の使用例：

  ```sql
  select * from s3("uri" = "http://127.0.0.1:9312/test2/student_with_names_and_types.csv",
                   "s3.access_key"= "minioadmin",
                   "s3.secret_key" = "minioadmin",
                   "s3.endpoint" = "http://127.0.0.1:9312",
                   "s3.region" = "us-east-1",
                   "format" = "csv_with_names_and_types",
                   "use_path_style" = "true") order by id;

  +------+------+------+
  | id   | name | age  |
  +------+------+------+
  | 1    | ftw  | 12   |
  | 2    | zs   | 18   |
  | 3    | ww   | 20   |
  +------+------+------+
  ```

  同様に、`desc function S3()` でテーブルスキーマを確認できます：

  ```sql
  Desc function s3("uri" = "http://127.0.0.1:9312/test2/student_with_names_and_types.csv",
                    "s3.access_key"= "minioadmin",
                    "s3.secret_key" = "minioadmin",
                    "s3.endpoint" = "http://127.0.0.1:9312",
                    "s3.region" = "us-east-1",
                    "format" = "csv_with_names_and_types",
                    "use_path_style" = "true");

    +-------+------+------+-------+---------+-------+
    | Field | Type | Null | Key   | Default | Extra |
    +-------+------+------+-------+---------+-------+
    | id    | TEXT | Yes  | false | NULL    | NONE  |
    | name  | TEXT | Yes  | false | NULL    | NONE  |
    | age   | TEXT | Yes  | false | NULL    | NONE  |
    +-------+------+------+-------+---------+-------+
  ```

- **JSON 形式**

  `json` 形式：JSON 形式には多くのオプションパラメータがあります。各パラメータの意味については、[JSON データロード](../../../data-operate/import/file-format/json)を参照してください。S3 TVF で JSON 形式のファイルをクエリする場合、`json_root` と `jsonpaths` パラメータに基づいて JSON オブジェクトを特定します。オブジェクト内の `key` をテーブルスキーマの列名として使用し、すべての列の型を String に設定します。例：

  `data.json` ファイルの内容：

  ```
  [{"id":1, "name":"ftw", "age":18}]
  [{"id":2, "name":"xxx", "age":17}]
  [{"id":3, "name":"yyy", "age":19}]
  ```

  S3 TVF を使用したクエリ：

  ```sql
  select * from s3(
      "uri" = "http://127.0.0.1:9312/test2/data.json",
      "s3.access_key"= "minioadmin",
      "s3.secret_key" = "minioadmin",
      "s3.endpoint" = "http://127.0.0.1:9312",
      "s3.region" = "us-east-1",
      "format" = "json",
      "strip_outer_array" = "true",
      "read_json_by_line" = "true",
      "use_path_style"="true");
  +------+------+------+
  | id   | name | age  |
  +------+------+------+
  | 1    | ftw  | 18   |
  | 2    | xxx  | 17   |
  | 3    | yyy  | 19   |
  +------+------+------+

  select * from s3(
      "uri" = "http://127.0.0.1:9312/test2/data.json",
      "s3.access_key"= "minioadmin",
      "s3.secret_key" = "minioadmin",
      "s3.endpoint" = "http://127.0.0.1:9312",
      "s3.region" = "us-east-1",
      "format" = "json",
      "strip_outer_array" = "true",
      "jsonpaths" = "[\"$.id\", \"$.age\"]",
      "use_path_style"="true");

  +------+------+
  | id   | age  |
  +------+------+
  | 1    | 18   |
  | 2    | 17   |
  | 3    | 19   |
  +------+------+
  ```

- **Parquet 形式**

  `parquet` 形式：S3 TVF は、Parquet ファイルからテーブルスキーマの列名と型を解析できます。例：

  ```sql
  select * from s3(
     "uri" = "http://127.0.0.1:9312/test2/test.snappy.parquet",
     "s3.access_key"= "minioadmin",
     "s3.secret_key" = "minioadmin",
     "s3.endpoint" = "http://127.0.0.1:9312",
     "s3.region" = "us-east-1",
     "format" = "parquet",
     "use_path_style"="true") limit 5;
  ```

- **ワイルドカードを含む URI**

  URI にはワイルドカードと範囲パターンを使用して、複数のファイルを読み取ることができます。`*`、`?`、`[...]`、`{1..10}` による範囲展開を含む詳しい構文は、[ファイルパスパターン](../../basic-element/file-path-pattern)を参照してください。注意：ワイルドカードを使用する場合は、すべてのファイルが同じ形式であることを確認してください。特に、`csv`、`csv_with_names`、`csv_with_names_and_types` はそれぞれ異なる形式です。S3 TVF は最初のファイルを使ってテーブルスキーマを解析します。

  次の 2 つの CSV ファイルがある場合：

  ```
  // file1.csv
  1,aaa,18
  2,qqq,20
  3,qwe,19

  // file2.csv
  5,cyx,19
  6,ftw,21
  ```

  URI にワイルドカードを指定してクエリできます：

  ```sql
  select * from s3(
          "uri" = "http://127.0.0.1:9312/test2/file*.csv",
          "s3.access_key"= "minioadmin",
          "s3.secret_key" = "minioadmin",
          "s3.endpoint" = "http://127.0.0.1:9312",
          "s3.region" = "us-east-1",
          "format" = "csv",
          "use_path_style"="true");

  +------+------+------+
  | c1   | c2   | c3   |
  +------+------+------+
  | 1    | aaa  | 18   |
  | 2    | qqq  | 20   |
  | 3    | qwe  | 19   |
  | 5    | cyx  | 19   |
  | 6    | ftw  | 21   |
  +------+------+------+
  ```

- **S3 TVF と `insert into`、`cast` の組み合わせ**

  ```sql
  -- Create Doris internal table
  CREATE TABLE IF NOT EXISTS ${testTable}
      (
          id int,
          name varchar(50),
          age int
      )
      COMMENT "my first table"
      DISTRIBUTED BY HASH(id) BUCKETS 32
      PROPERTIES("replication_num" = "1");

  -- Insert data using S3
  insert into ${testTable} (id,name,age)
  select cast (id as INT) as id, name, cast (age as INT) as age
  from s3(
      "uri" = "${uri}",
      "s3.access_key"= "${ak}",
      "s3.secret_key" = "${sk}",
      "s3.endpoint" = "http://127.0.0.1:9312",
      "s3.region" = "us-east-1",
      "format" = "${format}",
      "strip_outer_array" = "true",
      "read_json_by_line" = "true",
      "use_path_style" = "true");
  ```
