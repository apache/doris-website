# S3

## 説明

S3 テーブル値関数 (TVF) を使用すると、S3 互換オブジェクトストレージ上のファイルをリレーショナルテーブル形式のデータとして読み取れます。現在、`csv/csv_with_names/csv_with_names_and_types/json/parquet/orc` 形式をサポートしています。

## 構文

```sql
S3(
    "uri" = "<uri>",
    "s3.access_key" = "<s3_access_key>",
    "s3.secret_key" = "<s3_secret_key>",
    "s3.region" = "<s3_region>",
    "s3.endpoint" = "<s3_endpoint>",
    "format" = "<format>"
    [, "<optional_property_key>" = "<optional_property_value>" [, ...] ]
  )
```

## 必須パラメータ

| パラメータ | 説明 |
|-----------------|---------------------------------------------------------------------------------------------------------------------------------------|
| `uri` | S3 にアクセスするための URI。ワイルドカードと範囲パターンを使用できます。詳細は[ファイルパスパターン](../../basic-element/file-path-pattern)を参照してください。`use_path_style` パラメータに応じて、パス形式または仮想ホスト形式が使用されます。 |
| `s3.access_key` | S3 のアクセスキー |
| `s3.secret_key` | S3 のシークレットキー |
| `s3.region` | S3 のリージョン |
| `s3.endpoint` | S3 のエンドポイントアドレス |
| `format` | ファイル形式。`csv/csv_with_names/csv_with_names_and_types/json/parquet/orc` をサポートします。 |


## オプションパラメータ

| パラメータ | デフォルト | 説明 | 備考 |
|---------------------------------|---------|-----------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------|
| `s3.session_token` | - | S3 のセッショントークン | |
| `use_path_style` | `false` | S3 SDK はデフォルトで仮想ホスト形式を使用します。一部のオブジェクトストレージは仮想ホスト形式をサポートしません。このパラメータを設定すると、パス形式でのアクセスが強制されます。たとえば、MinIO はデフォルトでパス形式のみを許可するため、MinIO にアクセスする際は `use_path_style=true` を設定します。 | |
| `force_parsing_by_standard_uri` | `false` | 非標準の URI を標準の URI として強制的に解析します。 | |
| `column_separator` | `\t` | 列の区切り文字 | |
| `line_delimiter` | `\n` | 行の区切り文字 | |
| `compress_type` | `UNKNOWN` | 圧縮形式。現在、`UNKNOWN`/`PLAIN`/`GZ`/`LZO`/`BZ2`/`LZ4FRAME`/`DEFLATE`/`SNAPPYBLOCK` をサポートし、`uri` の末尾に基づいて自動判定します。 | |
| `read_json_by_line` | `"true"` | JSON 形式の読み込みに使用します。 | [JSON のロード](../../../data-operate/import/file-format/json) |
| `strip_outer_array` | `"false"` | JSON 形式の読み込みに使用します。 | [JSON のロード](../../../data-operate/import/file-format/json) |
| `json_root` | 空 | JSON 形式の読み込みに使用します。 | [JSON のロード](../../../data-operate/import/file-format/json) |
| `jsonpaths` | 空 | JSON 形式の読み込みに使用します。 | [JSON のロード](../../../data-operate/import/file-format/json) |
| `num_as_string` | `false` | JSON 形式の読み込みに使用します。 | [JSON のロード](../../../data-operate/import/file-format/json) |
| `fuzzy_parse` | `false` | JSON 形式の読み込みに使用します。 | |
| `trim_double_quotes` | `false` | CSV 形式の読み込み時に、各フィールドの最も外側の二重引用符を除去します。 | |
| `skip_lines` | `0` | CSV ファイルの先頭から N 行をスキップします。`csv_with_names` または `csv_with_names_and_types` 形式では、このパラメータは無効です。 | |
| `path_partition_keys` | - | ファイルパス内のパーティション列名を指定します。たとえば、パスが `/path/to/city=beijing/date="2023-07-09"` の場合、`path_partition_keys="city,date"` を設定すると、パスから列名と値を自動的に読み取ります。 | |
| `resource` | - | Resource 名を指定します。S3 TVF は既存の S3 Resource を使用して S3 に直接アクセスできます。S3 Resource の作成方法は [CREATE-RESOURCE](../../sql-statements/cluster-management/compute-management/CREATE-RESOURCE) を参照してください。バージョン 2.1.4 以降でサポートされます。 | |
| `enable_mapping_varbinary` | `false` | PARQUET/ORC の読み込み時、BYTE_ARRAY 型は STRING 型にマッピングされます。有効にすると、代わりに VARBINARY 型にマッピングされます。 | バージョン 4.0.3 以降でサポート |
| `enable_mapping_timestamp_tz` | デフォルトは `false` です。PARQUET (`TIMESTAMP` に `isAdjustedToUTC` が設定されている場合) または ORC (`TIMESTAMP_INSTANT`) の読み込み時、型は `DATETIME` にマッピングされます。有効にすると、`TIMESTAMPTZ` 型にマッピングされます。 | バージョン 4.0.3 以降でサポート |

## 注意事項

1. AWS S3 の標準的な URI 形式には、次のものがあります。

   - AWS クライアント形式 (Hadoop S3 形式)
   
      ```
      s3://my-bucket/path/to/file?versionId=abc123&partNumber=77&partNumber=88
      ```

   - 仮想ホスト形式
   
      ```
      https://my-bucket.s3.us-west-1.amazonaws.com/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   - パス形式
   
      ```
      https://s3.us-west-1.amazonaws.com/my-bucket/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   これら三つの標準的な URI 形式のほかに、次の形式もサポートされています (ただし、使用頻度は低くなります):

   - 仮想ホストと AWS クライアント (Hadoop S3) の混合形式
      
      ```
      s3://my-bucket.s3.us-west-1.amazonaws.com/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   - パス形式と AWS クライアント (Hadoop S3) の混合形式

      ```
      s3://s3.us-west-1.amazonaws.com/my-bucket/resources/doc.txt?versionId=abc123&partNumber=77&partNumber=88
      ```

   具体的な使用方法は、以下の例を参照してください。

2. TVF を直接クエリする場合、またはこの TVF に基づく View を作成する場合は、Resource に対する USAGE 権限が必要です。TVF に基づいて作成された View をクエリする場合は、その View に対する SELECT 権限のみが必要です。

## 例

- S3 互換オブジェクトストレージ上の CSV 形式のファイルを読み取る

  ```sql
  select * from s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                  "s3.access_key"= "minioadmin",
                  "s3.secret_key" = "minioadmin",
                  "s3.endpoint" = "http://127.0.0.1:9312",
                  "s3.region" = "us-east-1",
                  "format" = "csv",
                  "use_path_style" = "true") order by c1;
  ```


- `desc function` と組み合わせて使用する

  ```sql
  desc function s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                   "s3.access_key"= "minioadmin",
                   "s3.secret_key" = "minioadmin",
                   "s3.endpoint" = "http://127.0.0.1:9312",
                   "s3.region" = "us-east-1",
                   "format" = "csv",
                   "use_path_style" = "true");
  ```

- **CSV 形式**

  S3 テーブル値関数はテーブルスキーマを事前に把握できないため、ファイルを一度読み取ってテーブルスキーマを解析します。

  `csv` 形式: S3 テーブル値関数は S3 上のファイルを CSV ファイルとして読み取り、先頭行を使ってテーブルスキーマを解析します。先頭行の列数 `n` がテーブルスキーマの列数となり、列名は `c1, c2, ..., cn` と自動的に付けられます。すべての列の型は `String` に設定されます。例:

  `student1.csv` ファイルの内容:

  ```
  1,ftw,12
  2,zs,18
  3,ww,20
  ```

  S3 TVF を使用する場合:

    ```sql
    select * from s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                     "s3.access_key"= "minioadmin",
                     "s3.secret_key" = "minioadmin",
                     "s3.endpoint" = "http://127.0.0.1:9312",
                     "s3.region" = "us-east-1",
                     "format" = "csv",
                     "use_path_style" = "true") order by c1;

    +------+------+------+
    | c1   | c2   | c3   |
    +------+------+------+
    | 1    | ftw  | 12   |
    | 2    | zs   | 18   |
    | 3    | ww   | 20   |
    +------+------+------+
    ```

  `desc function S3()` でテーブルスキーマを確認できます:

    ```sql
    Desc function s3("uri" = "http://127.0.0.1:9312/test2/student1.csv",
                     "s3.access_key"= "minioadmin",
                     "s3.secret_key" = "minioadmin",
                     "s3.endpoint" = "http://127.0.0.1:9312",
                     "s3.region" = "us-east-1",
                     "format" = "csv",
                     "use_path_style" = "true");

    +-------+------+------+-------+---------+-------+
    | Field | Type | Null | Key   | Default | Extra |
    +-------+------+------+-------+---------+-------+
    | c1    | TEXT | Yes  | false | NULL    | NONE  |
    | c2    | TEXT | Yes  | false | NULL    | NONE  |
    | c3    | TEXT | Yes  | false | NULL    | NONE  |
    +-------+------+------+-------+---------+-------+
    ```

- **`csv_with_names` 形式**

  `csv_with_names` 形式: ファイルの先頭行からテーブルスキーマの列数と列名を解析します。すべての列の型は `String` に設定されます。例:

  `student_with_names.csv` ファイルの内容:

  ```
  id,name,age
  1,ftw,12
  2,zs,18
  3,ww,20
  ```

  S3 TVF を使用する場合:

  ```sql
  select * from s3("uri" = "http://127.0.0.1:9312/test2/student_with_names.csv",
                    "s3.access_key"= "minioadmin",
                    "s3.secret_key" = "minioadmin",
                    "s3.endpoint" = "http://127.0.0.1:9312",
                    "s3.region" = "us-east-1",
                    "format" = "csv_with_names",
                    "use_path_style" = "true") order by id;

  +------+------+------+
  | id   | name | age  |
  +------+------+------+
  | 1    | ftw  | 12   |
  | 2    | zs   | 18   |
  | 3    | ww   | 20   |
  +------+------+------+
  ```

- 同様に、`desc function S3()` でテーブルスキーマを確認できます

  ```sql
  desc function s3("uri" = "http://127.0.0.1:9312/test2/student_with_names.csv",
                    "s3.access_key"= "minioadmin",
                    "s3.secret_key" = "minioadmin",
                    "s3.endpoint" = "http://127.0.0.1:9312",
                    "s3.region" = "us-east-1",
                    "format" = "csv_with_names",
                    "use_path_style" = "true");

    +-------+------+------+-------+---------+-------+
    | Field | Type | Null | Key   | Default | Extra |
    +-------+------+------+-------+---------+-------+
    | id    | TEXT | Yes  | false | NULL    | NONE  |
    | name  | TEXT | Yes  | false | NULL    | NONE  |
    | age   | TEXT | Yes  | false | NULL    | NONE  |
    +-------+------+------+-------+---------+-------+
  ```

- **`csv_with_names_and_types` 形式**

  `csv_with_names_and_types` 形式: 現在、CSV ファイルからの列の型の解析には対応していません。この形式を使用すると、S3 TVF は先頭行からテーブルスキーマの列数と列名を解析し、すべての列の型を String に設定します。ファイルの二行目は無視されます。

  `student_with_names_and_types.csv` ファイルの内容:

  ```
  id,name,age
  INT,STRING,INT
  1,ftw,12
  2,zs,18
  3,ww,20
  ```

  S3 TVF を使用する場合:

  ```sql
  select * from s3("uri" = "http://127.0.0.1:9312/test2/student_with_names_and_types.csv",
                   "s3.access_key"= "minioadmin",
                   "s3.secret_key" = "minioadmin",
                   "s3.endpoint" = "http://127.0.0.1:9312",
                   "s3.region" = "us-east-1",
                   "format" = "csv_with_names_and_types",
                   "use_path_style" = "true") order by id;

  +------+------+------+
  | id   | name | age  |
  +------+------+------+
  | 1    | ftw  | 12   |
  | 2    | zs   | 18   |
  | 3    | ww   | 20   |
  +------+------+------+
  ```

  同様に、`desc function S3()` でテーブルスキーマを確認できます:

  ```sql
  Desc function s3("uri" = "http://127.0.0.1:9312/test2/student_with_names_and_types.csv",
                    "s3.access_key"= "minioadmin",
                    "s3.secret_key" = "minioadmin",
                    "s3.endpoint" = "http://127.0.0.1:9312",
                    "s3.region" = "us-east-1",
                    "format" = "csv_with_names_and_types",
                    "use_path_style" = "true");

    +-------+------+------+-------+---------+-------+
    | Field | Type | Null | Key   | Default | Extra |
    +-------+------+------+-------+---------+-------+
    | id    | TEXT | Yes  | false | NULL    | NONE  |
    | name  | TEXT | Yes  | false | NULL    | NONE  |
    | age   | TEXT | Yes  | false | NULL    | NONE  |
    +-------+------+------+-------+---------+-------+
  ```

- **JSON 形式**

  `json` 形式: JSON 形式には多数のオプションパラメータがあります。各パラメータの意味は [JSON のロード](../../../data-operate/import/file-format/json) を参照してください。S3 TVF で JSON 形式のファイルをクエリすると、`json_root` と `jsonpaths` パラメータに基づいて JSON オブジェクトを特定し、そのオブジェクトの `key` をテーブルスキーマの列名として使用します。すべての列の型は String に設定されます。例:

  `data.json` ファイルの内容:

  ```
  [{"id":1, "name":"ftw", "age":18}]
  [{"id":2, "name":"xxx", "age":17}]
  [{"id":3, "name":"yyy", "age":19}]
  ```

  S3 TVF でクエリする場合:

  ```sql
  select * from s3(
      "uri" = "http://127.0.0.1:9312/test2/data.json",
      "s3.access_key"= "minioadmin",
      "s3.secret_key" = "minioadmin",
      "s3.endpoint" = "http://127.0.0.1:9312",
      "s3.region" = "us-east-1",
      "format" = "json",
      "strip_outer_array" = "true",
      "read_json_by_line" = "true",
      "use_path_style"="true");
  +------+------+------+
  | id   | name | age  |
  +------+------+------+
  | 1    | ftw  | 18   |
  | 2    | xxx  | 17   |
  | 3    | yyy  | 19   |
  +------+------+------+
  
  select * from s3(
      "uri" = "http://127.0.0.1:9312/test2/data.json",
      "s3.access_key"= "minioadmin",
      "s3.secret_key" = "minioadmin",
      "s3.endpoint" = "http://127.0.0.1:9312",
      "s3.region" = "us-east-1",
      "format" = "json",
      "strip_outer_array" = "true",
      "jsonpaths" = "[\"$.id\", \"$.age\"]",
      "use_path_style"="true");

  +------+------+
  | id   | age  |
  +------+------+
  | 1    | 18   |
  | 2    | 17   |
  | 3    | 19   |
  +------+------+
  ```

- **Parquet 形式**

  `parquet` 形式: S3 TVF は Parquet ファイルからテーブルスキーマの列名と型を解析できます。例:

  ```sql
  select * from s3(
     "uri" = "http://127.0.0.1:9312/test2/test.snappy.parquet",
     "s3.access_key"= "minioadmin",
     "s3.secret_key" = "minioadmin",
     "s3.endpoint" = "http://127.0.0.1:9312",
     "s3.region" = "us-east-1",
     "format" = "parquet",
     "use_path_style"="true") limit 5;

  +-----------+------------------------------------------+----------------+----------+-------------------------+--------+-------------+---------------+---------------------+
  | p_partkey | p_name                                   | p_mfgr         | p_brand  | p_type                  | p_size | p_container | p_retailprice | p_comment           |
  +-----------+------------------------------------------+----------------+----------+-------------------------+--------+-------------+---------------+---------------------+
  |         1 | goldenrod lavender spring chocolate lace | Manufacturer#1 | Brand#13 | PROMO BURNISHED COPPER  |      7 | JUMBO PKG   |           901 | ly. slyly ironi     |
  ```

- **ワイルドカードを含む URI**

  URI にはワイルドカードと範囲パターンを使用して、複数のファイルを読み取れます。`*`、`?`、`[...]`、`{1..10}` による範囲展開など、構文の詳細は[ファイルパスパターン](../../basic-element/file-path-pattern)を参照してください。ワイルドカードを使用する場合は、すべてのファイルが同じ形式であることを確認してください (特に `csv`、`csv_with_names`、`csv_with_names_and_types` はそれぞれ異なる形式です)。S3 TVF は最初のファイルを使ってテーブルスキーマを解析します。
  
  次の二つの CSV ファイルがあるとします:

  ```
  // file1.csv
  1,aaa,18
  2,qqq,20
  3,qwe,19
  
  // file2.csv
  5,cyx,19
  6,ftw,21
  ```

  URI にワイルドカードを指定してクエリできます:

  ```sql
  select * from s3(
          "uri" = "http://127.0.0.1:9312/test2/file*.csv",
          "s3.access_key"= "minioadmin",
          "s3.secret_key" = "minioadmin",
          "s3.endpoint" = "http://127.0.0.1:9312",
          "s3.region" = "us-east-1",
          "format" = "csv",
          "use_path_style"="true");

  +------+------+------+
  | c1   | c2   | c3   |
  +------+------+------+
  | 1    | aaa  | 18   |
  | 2    | qqq  | 20   |
  | 3    | qwe  | 19   |
  | 5    | cyx  | 19   |
  | 6    | ftw  | 21   |
  +------+------+------+
  ```

- **S3 TVF と `insert into`、`cast` の併用**

  ```sql
  -- Create Doris internal table
  CREATE TABLE IF NOT EXISTS ${testTable}
      (
          id int,
          name varchar(50),
          age int
      )
      COMMENT "my first table"
      DISTRIBUTED BY HASH(id) BUCKETS 32
      PROPERTIES("replication_num" = "1");
  
  -- Insert data using S3
  insert into ${testTable} (id,name,age)
  select cast (id as INT) as id, name, cast (age as INT) as age
  from s3(
      "uri" = "${uri}",
      "s3.access_key"= "${ak}",
      "s3.secret_key" = "${sk}",
      "s3.endpoint" = "http://127.0.0.1:9312",
      "s3.region" = "us-east-1",
      "format" = "${format}",
      "strip_outer_array" = "true",
      "read_json_by_line" = "true",
      "use_path_style" = "true");
  ```
