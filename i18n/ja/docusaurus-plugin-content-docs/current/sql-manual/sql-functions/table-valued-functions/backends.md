## 説明

このテーブル関数は一時テーブル backends を生成し、現在の Doris クラスター内の BE ノード情報を表示します。

## 構文
```sql
BACKENDS()
```

## アクセス制御要件

| 権限  | オブジェクト | 備考 |
| :--------- |:-------|:------|
| SELECT_PRIV | internal.information_schema | デフォルトでは、すべてのユーザーにこのデータベースへのアクセス権があります |

## 戻り値
| フィールド                       | 説明                                                                                                            |
|-----------------------------|------------------------------------------------------------------------------------------------------------------------|
| **BackendId**               | 各 BE ノードの一意の識別子。                                                                           |
| **Host**                    | BE ノードの IP アドレスまたはホスト名。                                                                        |
| **HeartbeatPort**           | ヘルスチェック（ハートビート）に使用するポート。                                                                           |
| **BePort**                  | クエリの実行時に BE ノードとクラスター間の通信に使用するポート。                          |
| **HttpPort**                | BE ノードの HTTP ポート。                                                                                     |
| **BrpcPort**                | BRPC 通信に使用するポート。                                                                                  |
| **ArrowFlightSqlPort**      | Arrow Flight SQL のポート（高性能なデータ転送のために Apache Arrow と連携する際に使用）。                |
| **LastStartTime**           | BE ノードが最後に起動した時刻のタイムスタンプ。                                                             |
| **LastHeartbeat**           | BE ノードから最後に受信したハートビートのタイムスタンプ。                                                   |
| **Alive**                   | BE ノードが稼働中かどうか（true/false）。                                                                        |
| **SystemDecommissioned**    | BE ノードが廃止対象になっているかどうか。                                                                      |
| **TabletNum**               | BE ノードが管理するタブレットの数。                                                                     |
| **DataUsedCapacity**        | BE ノードが使用しているディスク容量（MB）。                                                             |
| **TrashUsedCapacity**       | ゴミ箱が使用しているディスク容量（MB）。                                                                        |
| **AvailCapacity**           | BE ノードで使用可能なディスク容量。                                                                          |
| **TotalCapacity**           | BE ノードの総ディスク容量。                                                                           |
| **UsedPct**                 | BE ノードのディスク容量の使用率。                                                              |
| **MaxDiskUsedPct**          | すべてのタブレットにおけるディスク使用率の最大値。                                                                  |
| **RemoteUsedCapacity**      | リモートストレージが使用しているディスク容量（該当する場合）。                                                                 |
| **Tag**                     | BE ノードに関連付けられたタグ。通常は場所などによる分類に使用します。                             |
| **ErrMsg**                  | BE ノードから報告されたエラーメッセージ。                                                                           |
| **Version**                 | BE ノードのバージョン。                                                                                       |
| **Status**                  | タブレットに関する成功・失敗の報告、ロード時刻、クエリの状態などを含む BE ノードの現在の状態。 |
| **HeartbeatFailureCounter** | ハートビートの失敗回数（失敗がある場合）。                                                                               |
| **NodeRole**                | BE ノードのロール。たとえば `mix` は、ノードがストレージとクエリ処理の両方を担当することを意味します。           |
| **CpuCores**                | BE ノードの CPU コア数。                                                                           |
| **Memory**                  | BE ノードのメモリ容量。                                                                              |
