## 説明

このテーブル関数は frontends 一時テーブルを生成し、現在の Doris クラスターにある FE ノードの情報を確認できるようにします。

## 構文
```sql
FRONTENDS()
```

## アクセス制御の要件

| 権限  | 対象 | 備考 |
| :--------- |:-------|:------|
| SELECT_PRIV | internal.information_schema | デフォルトでは、すべてのユーザーにこのデータベースに対する権限があります |

## 戻り値
| フィールド                    | 説明                                                                                             |
|--------------------------|---------------------------------------------------------------------------------------------------------|
| **Name**                 | FE ノードの一意の名前。                                                                   |
| **Host**                 | FE ノードの IP アドレスまたはホスト名。                                                        |
| **EditLogPort**          | 編集ログの通信に使用するポート。                                                               |
| **HttpPort**             | FE ノードの HTTP ポート。                                                                    |
| **QueryPort**            | FE ノードでのクエリ実行に使用するポート。                                                 |
| **RpcPort**              | RPC 通信に使用するポート。                                                                    |
| **ArrowFlightSqlPort**   | Arrow Flight SQL のポート（Apache Arrow と連携して高速にデータを転送するために使用）。 |
| **Role**                 | FE ノードのロール（例：`FOLLOWER`）。                                                       |
| **IsMaster**             | FE ノードがマスターノードかどうか（true/false）。                                               |
| **ClusterId**            | FE ノードが属するクラスターの識別子。                                      |
| **Join**                 | FE ノードがクラスターに参加しているかどうか（true/false）。                                     |
| **Alive**                | FE ノードが稼働しているかどうか（true/false）。                                                   |
| **ReplayedJournalId**    | FE ノードが最後に再生したジャーナルの ID。                                             |
| **LastStartTime**        | FE ノードを最後に起動した時刻のタイムスタンプ。                                              |
| **LastHeartbeat**        | FE ノードから最後に受信したハートビートのタイムスタンプ。                                   |
| **IsHelper**             | FE ノードがヘルパーノードかどうか（true/false）。                                      |
| **ErrMsg**               | FE ノードが報告したエラーメッセージ。                                                       |
| **Version**              | FE ノードのバージョン。                                                                       |
| **CurrentConnected**     | FE ノードが現在クラスターに接続されているかどうか（Yes/No）。                     |
