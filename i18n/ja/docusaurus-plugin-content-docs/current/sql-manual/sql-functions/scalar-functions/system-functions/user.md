## 説明

現在の Doris 接続のユーザー名と IP アドレスを取得します。

## 構文

```sql
USER()
```

## 戻り値

現在の Doris 接続のユーザー名と IP アドレスを返します。
形式:`<user_name>@<ip>`

## 例

```sql
select user();
```

```text
+---------------------+
| user()              |
+---------------------+
| 'root'@'10.244.2.5' |
+---------------------+
```
