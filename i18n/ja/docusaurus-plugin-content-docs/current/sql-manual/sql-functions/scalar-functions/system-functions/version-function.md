## 説明

MySQL プロトコルとの互換性のための関数で、実用上の意味はありません。

## 構文

```sql
VERSION()
```

## 戻り値

MySQL プロトコルとの互換性のため、固定値 "5.7.99" を返します。

## 例

```sql
select version();
```

```text
+-----------+
| version() |
+-----------+
| 5.7.99    |
+-----------+
```
