## 説明

有効な POINT ジオメトリの Y 座標を返します。地理空間データでは、Y 座標は通常、緯度に対応し、範囲は [-90.0, 90.0] 度です。

## 構文

```sql
ST_Y( <point>)
```

## パラメータ

| パラメータ   | 説明      |
|------|----------|
| `<point>` | Y 座標を取り出す対象の、有効な 2D POINT ジオメトリ。Y 値（緯度）は [-90.0, 90.0]、X 値（経度）は [-180.0, 180.0] の範囲内である必要があります。 |

## 戻り値

入力された POINT の Y 座標を DOUBLE PRECISION FLOAT 型で返します。

有効な POINT を入力した場合、Y 座標（緯度）を返します。
入力が NULL、空の点（POINT EMPTY）、3D の点、または無効な点（緯度が [-90.0, 90.0] の範囲外である場合など）の場合は NULL を返します。

## 例

有効な点

```sql
SELECT ST_Y(ST_Point(24.7, 56.7));
```

```text
+----------------------------+
| ST_Y(ST_Point(24.7, 56.7)) |
+----------------------------+
| 56.7                       |
+----------------------------+
```

空の点（POINT EMPTY）

```sql
mysql> SELECT ST_Y(ST_GeometryFromText("POINT EMPTY"));
+------------------------------------------+
| ST_Y(ST_GeometryFromText("POINT EMPTY")) |
+------------------------------------------+
|                                     NULL |
+------------------------------------------+
```
3D の点（非対応）

```sql
mysql> SELECT ST_Y(ST_GeometryFromText("POINT (10 20 30)"));
+-----------------------------------------------+
| ST_Y(ST_GeometryFromText("POINT (10 20 30)")) |
+-----------------------------------------------+
|                                          NULL |
+-----------------------------------------------+
```


NULL 入力

```sql
mysql> SELECT ST_Y(NULL);
+------------+
| ST_Y(NULL) |
+------------+
|       NULL |
+------------+
```

無効な緯度（範囲外）

```sql
mysql> SELECT ST_Y(ST_Point(116.4, 91));
+---------------------------+
| ST_Y(ST_Point(116.4, 91)) |
+---------------------------+
|                      NULL |
+---------------------------+
```

無効な経度（範囲外）

```sql
mysql> SELECT ST_Y(ST_Point(190, 39.9));
+---------------------------+
| ST_Y(ST_Point(190, 39.9)) |
+---------------------------+
|                      NULL |
+---------------------------+
```
