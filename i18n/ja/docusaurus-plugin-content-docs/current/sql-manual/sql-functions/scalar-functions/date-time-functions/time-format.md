## 説明

TIME_FORMAT 関数は、指定した書式文字列に従って時刻値を文字列に変換します。`TIME`、`DATETIME`、`TIMESTAMP_NS`、`TIMESTAMPTZ` 型の値をサポートします。

この関数は、MySQL の [time_format 関数](https://dev.mysql.com/doc/refman/8.4/en/date-and-time-functions.html#function_time-format) と同じ動作をします。

## 構文

```sql
TIME_FORMAT(<time_or_datetime_expr>, <format>)
```

## パラメータ

| パラメータ                 | 説明                                                                                                                                                |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<time_or_datetime_expr>` | 有効な `TIME`、`DATETIME`、`TIMESTAMP_NS`、または `TIMESTAMPTZ` 型の値。                                                                                       |
| `<format>`                | 時刻の出力書式を指定する `varchar` 型の値。書式文字列に日付用またはサポートされていない書式指定子が含まれる場合、NULL を返します。 |

サポートされる書式指定子：

| 書式指定子 | 説明                                   |
| --------- | --------------------------------------------- |
| %f        | マイクロ秒（000000-999999）                  |
| %n        | ナノ秒（000000000-999999999）。精度が低い型では、不足する桁をゼロで埋めます。 |
| %H        | 時（00-23）                                  |
| %h        | 時（01-12）                                  |
| %I        | 時（01-12）                                  |
| %i        | 分、数値（00-59）                      |
| %k        | 時（0-23）                                   |
| %l        | 時（1-12）                                   |
| %p        | AM または PM                                      |
| %r        | 12 時間表記の時刻（hh:mm:ss の後に AM または PM） |
| %S        | 秒（00-59）                               |
| %s        | 秒（00-59）                               |
| %T        | 24 時間表記の時刻（hh:mm:ss）                      |
| %%        | リテラルの % 文字を表します。              |

## 戻り値

書式に従って整形された時刻文字列を Varchar 型で返します。

特別なケース：
- `time_or_datetime_expr` または `format` が NULL の場合、NULL を返します。
- `format` 文字列に日付用の書式指定子が含まれる場合：
    - `%Y`：`0000` を返します。
    - `%y`、`%m`、`%d`：`00` を返します。
    - `%c`、`%e`：`0` を返します。
    - その他の日付用書式指定子（`%a`、`%b`、`%D`、`%j`、`%M`、`%u`、`%U`、`%v`、`%V`、`%w`、`%W`、`%x`、`%X`）：NULL を返します。
- 時刻値の時の部分が 23 を超える場合、書式指定子 `%H` と `%k` は 23 より大きい値を出力します。その他の時を表す書式指定子は、時の値を 12 で割った余りを出力します。

## 例

```sql
SELECT TIME_FORMAT(
    CAST('2024-02-29 12:34:56.123456789' AS TIMESTAMP_NS),
    '%H:%i:%s.%n'
) AS result;
```

```text
+--------------------+
| result             |
+--------------------+
| 12:34:56.123456789 |
+--------------------+
```
