## 説明

指数が `x`、底が `e` のべき乗値を返します。

## 別名

- DEXP

## 構文

```sql
EXP(<x>)
```

## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<x>` | 独立変数 |

## 戻り値

double 型の値を返します。特別な場合は次のとおりです。
- パラメータが NULL の場合、NULL を返します
- パラメータが非常に大きい場合、Infinity を返します

## 例

```sql
select exp(2);
```

```text
+------------------+
| exp(2.0)         |
+------------------+
| 7.38905609893065 |
+------------------+
```

```sql
select exp(3.4);
```

```text
+--------------------+
| exp(3.4)           |
+--------------------+
| 29.964100047397011 |
+--------------------+
```

```sql
select exp(1000000);
```

```text
+--------------+
| EXP(1000000) |
+--------------+
|     Infinity |
+--------------+
```
