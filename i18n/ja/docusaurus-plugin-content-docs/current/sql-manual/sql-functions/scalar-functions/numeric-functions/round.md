## 説明

数値 `x` を指定した桁数に丸めます。
- `d` を指定しない場合、`x` を最も近い整数に丸めます。
- `d` が負の場合、小数点より左側の桁を `d` の絶対値に応じて丸めます。
- `x` または `d` が `null` の場合、`null` を返します。
- `d` が列で、最初の引数が `Decimal` 型の場合、結果の `Decimal` の小数桁数は入力の `Decimal` と同じになります。


## 別名

- `DROUND`

## 構文

```sql
ROUND(<x> [ , <d> ])
```

## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<x>` | 丸める数値 |
| `<d>` | 省略可能。丸める小数桁数 |

## 例

```sql
select round(2.4);
```

```text
+------------+
| round(2.4) |
+------------+
|          2 |
+------------+
```

```sql
select round(2.5);
```

```text
+------------+
| round(2.5) |
+------------+
|          3 |
+------------+
```

```sql
select round(-3.4);
```

```text
+-------------+
| round(-3.4) |
+-------------+
|          -3 |
+-------------+
```

```sql
select round(-3.5);
```

```text
+-------------+
| round(-3.5) |
+-------------+
|          -4 |
+-------------+
```

```sql
select round(1667.2725, 2);
```

```text
+---------------------+
| round(1667.2725, 2) |
+---------------------+
|             1667.27 |
+---------------------+
```

```sql
select round(1667.2725, -2);
```

```text
+----------------------+
| round(1667.2725, -2) |
+----------------------+
|                 1700 |
+----------------------+
```

## 使用上の注意
2.5 は 3 に丸められます。2 に丸めたい場合は、`round_bankers` 関数を使用してください。
