## 説明

度単位の `x` をラジアンに変換した値を返します。

## 構文

```sql
RADIANS(<x>)
```

## パラメータ

| パラメータ | 説明 |
|-----------|------------|
| `<x>`   | ラジアンに変換する度単位の角度。 |

## 戻り値

整数または浮動小数点数を返します。特別な場合は次のとおりです。

- パラメータ x が NULL の場合、NULL を返します。

## 例

```sql
select radians(0);
```

```text
+----------------------------+
| radians(cast(0 as DOUBLE)) |
+----------------------------+
|                        0.0 |
+----------------------------+
```

```sql
select radians(30);
```

```text
+-----------------------------+
| radians(cast(30 as DOUBLE)) |
+-----------------------------+
|          0.5235987755982988 |
+-----------------------------+
```

```sql
select radians(90);
```

```text
+-----------------------------+
| radians(cast(90 as DOUBLE)) |
+-----------------------------+
|          1.5707963267948966 |
+-----------------------------+
```
