## 説明

引数 x の符号を反転した値を返します。

## 構文

```sql
NEGATIVE(<x>)
```

## パラメータ

| パラメータ | 説明 |
|-----------|------------|
| `<x>` | `BIGINT, DOUBLE, and DECIMAL` 型を指定できます。 |

## 戻り値

整数または浮動小数点数を返します。特別なケースは次のとおりです。

- 引数が NULL の場合、NULL を返します。
- 引数が 0 の場合、0 を返します。

## 例

```sql
SELECT negative(-10);
```

```text
+---------------+
| negative(-10) |
+---------------+
|            10 |
+---------------+
```

```sql
SELECT negative(12);
```

```text
+--------------+
| negative(12) |
+--------------+
|          -12 |
+--------------+
```

```sql
SELECT negative(0);
```

```text
+-------------+
| negative(0) |
+-------------+
|           0 |
+-------------+
```

```sql
SELECT negative(null);
```

```text
+----------------+
| negative(NULL) |
+----------------+
|           NULL |
+----------------+
```
