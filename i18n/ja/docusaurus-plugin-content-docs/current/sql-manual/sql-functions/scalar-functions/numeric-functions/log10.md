## 説明

`x` の底 `10` の対数を返します。

## 別名

- DLOG10

## 構文

```sql
LOG10(<x>)
```

## パラメータ

| パラメータ | 説明 |
|-----------|------------|
| `<x>`   | 真数。0 より大きい必要があります。 |

## 戻り値

浮動小数点数を返します。特殊なケースは次のとおりです。

- x が NULL の場合は `NULL` を返します。
- x が NaN の場合は NaN を返します。

## 例

```sql
select log10(1);
```

```text
+--------------------------+
| log10(cast(1 as DOUBLE)) |
+--------------------------+
|                      0.0 |
+--------------------------+
```

```sql
select log10(10);
```

```text
+---------------------------+
| log10(cast(10 as DOUBLE)) |
+---------------------------+
|                       1.0 |
+---------------------------+
```

```sql
select log10(16);
```

```text
+---------------------------+
| log10(cast(16 as DOUBLE)) |
+---------------------------+
|        1.2041199826559248 |
+---------------------------+
```

```sql
select log10(NULL);
```

```text
+-------------+
| log10(NULL) |
+-------------+
|        NULL |
+-------------+
```

```sql
select log10(cast('nan' as double));
```

```text
+------------------------------+
| log10(cast('nan' as double)) |
+------------------------------+
|                          NaN |
+------------------------------+
```
