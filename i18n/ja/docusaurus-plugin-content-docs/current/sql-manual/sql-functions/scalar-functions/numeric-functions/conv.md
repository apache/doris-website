## 説明

入力値の基数を変換します。

## 構文

```sql
CONV(<input>, <from_base>, <to_base>)
```

## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<input>` | 変換する値。文字列または整数を指定します。 |
| `<from_base>` | 変換元の基数。数値で指定し、範囲は `[2,36]` です。 |
| `<to_base>` | 変換先の基数。数値で指定し、範囲は `[2,36]` です。 |

## 戻り値

変換先の基数 `<to_base>` で表した値を文字列として返します。
いずれかの入力パラメータが NULL の場合は、NULL を返します。
`<from_base>` または `<to_base>` が指定範囲外の場合は、NULL を返します。

## 例

```sql
SELECT CONV(15,10,2);
```

```text
+-----------------+
| conv(15, 10, 2) |
+-----------------+
| 1111            |
+-----------------+
```

```sql
SELECT CONV('ff',16,10);
```

```text
+--------------------+
| conv('ff', 16, 10) |
+--------------------+
| 255                |
+--------------------+
```

```sql
SELECT CONV(230,10,16);
```

```text
+-------------------+
| conv(230, 10, 16) |
+-------------------+
| E6                |
+-------------------+
```

```sql
SELECT CONV(230,10,NULL);
```

```text
+-------------------+
| CONV(230,10,NULL) |
+-------------------+
| NULL              |
+-------------------+
```

```sql
SELECT CONV(230,10,56);
```

```text
+-----------------+
| CONV(230,10,56) |
+-----------------+
| NULL            |
+-----------------+
```
