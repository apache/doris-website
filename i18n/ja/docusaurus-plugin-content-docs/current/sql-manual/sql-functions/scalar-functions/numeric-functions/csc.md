## 説明

x の余割を返します。x はラジアン単位の値です。入力と出力は DOUBLE 型のみをサポートします。入力が NULL の場合は NULL を返します。

## 構文

```sql
CSC(<x>)
```

## 引数

| 引数 | 説明 |
| -- | -- |
| `<x>` | 余割を計算する値 |

## 戻り値

x の余割を表す DOUBLE 型の値を返します。

## 特殊なケース
- `x` が NaN の場合、NaN を返します
- `x` が正または負の無限大の場合、NaN を返します
- `x` が NULL の場合、NULL を返します

## 使用例

```sql
select csc(1),csc(2),csc(1000);
```

```text
+--------------------+--------------------+------------------+
| csc(1)             | csc(2)             | csc(1000)        |
+--------------------+--------------------+------------------+
| 1.1883951057781212 | 1.0997501702946164 | 1.20936599707935 |
+--------------------+--------------------+------------------+
```

入力が NULL の場合。

```sql
select csc(null);
```

```text
+--------------------+
| csc(null)          |
+--------------------+
|      NULL          |
+--------------------+
```

```sql
select csc(cast('nan' as double));
```

```text
+---------------------------+
| csc(cast('nan' AS DOUBLE))|
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select csc(cast('inf' as double));
```

```text
+---------------------------+
| csc(cast('inf' AS DOUBLE))|
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select csc(cast('-inf' as double));
```

```text
+----------------------------+
| csc(cast('-inf' AS DOUBLE))|
+----------------------------+
| NaN                        |
+----------------------------+
```
