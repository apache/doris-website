## 説明

十進数を二進数の文字列に変換します。

## 構文

```sql
BIN(<a>)
```

## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<a>` | 変換する十進数値（型: BigInt） |

## 戻り値

パラメータ `<a>` の二進数表現を返します。`<a>` が負数の場合、結果はその 64 ビットの補数表現です。
`a` が NULL の場合は NULL を返します。

## 例

```sql
select bin(0);
```

```text
+--------+
| bin(0) |
+--------+
| 0      |
+--------+
```

```sql
select bin(-1);
```

```text
+------------------------------------------------------------------+
| bin(-1)                                                          |
+------------------------------------------------------------------+
| 1111111111111111111111111111111111111111111111111111111111111111 |
+------------------------------------------------------------------+
```

```sql
select bin(123);
```

```text
+----------+
| bin(123) |
+----------+
| 1111011  |
+----------+
```

```sql
select bin(NULL);
```

```text
+-----------+
| bin(NULL) |
+-----------+
| NULL      |
+-----------+
```
