## 説明

0 から 1 までの乱数を返します。引数を指定した場合は、その値に応じた乱数を返します。

- 注意：すべての引数は定数である必要があります。

## 別名

- RAND

## 構文

```sql
RANDOM() -- Generates a random number between 0 and 1

RANDOM(<seed>) -- Generates a fixed sequence of random numbers between 0 and 1 based on the seed value

RANDOM(<a> , <b>) -- Generates a random number between a and b
```

## パラメータ

| パラメータ | 説明 |
|-----------|------------|
| `<seed>` | 乱数生成器のシード値。0 から 1 までの乱数の固定された系列を返します。 |
| `<a>` | 乱数の下限値。 |
| `<b>` | 乱数の上限値。下限値より大きい必要があります。 |

## 戻り値

- 引数を指定しない場合：0 から 1 までの乱数を返します。

- シード値だけを指定した場合：0 から 1 までの乱数の固定された系列を返します。

- 引数として a と b を指定した場合：a から b までのランダムな整数を返します。

## 例

```sql
select random();
```

```text
+--------------------+
| random()           |
+--------------------+
| 0.8047437125910604 |
+--------------------+
```

```sql
select rand(1.2);
```

```text
+---------------------+
| rand(1)             |
+---------------------+
| 0.13387664401253274 |
+---------------------+
```

```sql
select rand(-20, -10);
```

```text
+------------------+
| random(-20, -10) |
+------------------+
|              -10 |
+------------------+
```
