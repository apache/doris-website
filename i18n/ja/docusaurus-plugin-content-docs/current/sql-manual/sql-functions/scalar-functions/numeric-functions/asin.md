## 説明

`x` の逆正弦を返します。`NULL` を返すのは、`x` が `-1` から `1` の範囲外の場合です。

## 構文

```sql
ASIN(<x>)
```

## パラメータ  

| パラメータ | 説明 |  
| -- | -- |  
| `<x>` | 逆正弦を計算する値 |  

## 戻り値  

パラメータ `x` の逆正弦値をラジアン単位で返します。

## 特殊なケース

- `x` が 0 の場合、0 を返します
- `x` が 1 の場合、π/2 を返します
- `x` が -1 の場合、-π/2 を返します
- `x` が [-1, 1] の範囲外の場合、`NULL` を返します
- `x` が NaN の場合、NaN を返します
- `x` が正または負の無限大の場合、`NULL` を返します
- `x` が NULL の場合、NULL を返します

## 例

```sql
select asin(0.5);
```

```text
+---------------------+
| asin(0.5)           |
+---------------------+
| 0.52359877559829893 |
+---------------------+
```

```sql
select asin(0.0);
```

```text
+------------+
| asin(0.0)  |
+------------+
|          0 |
+------------+
```

```sql
select asin(1.0);
```

```text
+--------------------+
| asin(1.0)          |
+--------------------+
| 1.570796326794897  |
+--------------------+
```

```sql
select asin(-1.0);
```

```text
+---------------------+
| asin(-1.0)          |
+---------------------+
| -1.570796326794897  |
+---------------------+
```

```sql
select asin(2);
```

```text
+------------+
| asin(2.0)  |
+------------+
|       NULL |
+------------+
```

```sql
select asin(cast('nan' as double));
```

```text
+---------------------------+
| asin(cast('nan' AS DOUBLE)) |
+---------------------------+
| NaN                       |
+---------------------------+
```

```sql
select asin(cast('inf' as double));
```

```text
+---------------------------+
| asin(cast('inf' AS DOUBLE)) |
+---------------------------+
| NULL                      |
+---------------------------+
```
