## 説明

数値を通貨形式で出力します。整数部は三桁ごとにカンマで区切り、小数部は二桁で表示します。

## 構文

```sql
MONEY_FORMAT(<number>)
```

## パラメータ

| パラメータ | 説明 |
|-----------|------------|
| `<number>`   | 書式設定する数値 |

## 戻り値

通貨形式の文字列を返します。特別なケースは次のとおりです。

- パラメータが NULL の場合は、NULL を返します。

## 例

```sql
select money_format(17014116);
```

```text
+------------------------+
| money_format(17014116) |
+------------------------+
| 17,014,116.00          |
+------------------------+
```

```sql
select money_format(1123.456);
```

```text
+------------------------+
| money_format(1123.456) |
+------------------------+
| 1,123.46               |
+------------------------+
```

```sql
select money_format(1123.4);
```

```text
+----------------------+
| money_format(1123.4) |
+----------------------+
| 1,123.40             |
+----------------------+
```
