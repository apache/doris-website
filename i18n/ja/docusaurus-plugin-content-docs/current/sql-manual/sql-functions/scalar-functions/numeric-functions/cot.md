## 説明

x の余接を返します。x はラジアン単位の値です。入力と出力は DOUBLE 型のみをサポートします。NULL を入力すると NULL を返します。

## 構文

```sql
COT(<x>)
```

## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<x>` | 余接を計算するラジアン単位の値。入力は DOUBLE 型です。 |

## 戻り値

x の余接を表す DOUBLE 型の値を返します。x が NULL の場合は NULL を返します。

## 特殊なケース
- `x` が NaN の場合、NaN を返します
- `x` が正または負の無限大の場合、NaN を返します
- `x` が NULL の場合、NULL を返します

## 例

```sql
select cot(1),cot(2),cot(1000);
```

```text
+--------------------+----------------------+--------------------+
| cot(1)             | cot(2)               | cot(1000)          |
+--------------------+----------------------+--------------------+
| 0.6420926159343306 | -0.45765755436028577 | 0.6801221323348698 |
+--------------------+----------------------+--------------------+
```

NULL を入力した場合。

```sql
select cot(null);
```

```text
+--------------------+
| cot(null)          |
+--------------------+
|      NULL          |
+--------------------+
```

```sql
select cot(cast('nan' as double));
```

```text
+----------------------------+
| cot(cast('nan' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select cot(cast('inf' as double));
```

```text
+----------------------------+
| cot(cast('inf' AS DOUBLE)) |
+----------------------------+
| NaN                        |
+----------------------------+
```

```sql
select cot(cast('-inf' as double));
```

```text
+-----------------------------+
| cot(cast('-inf' AS DOUBLE)) |
+-----------------------------+
| NaN                         |
+-----------------------------+
```
