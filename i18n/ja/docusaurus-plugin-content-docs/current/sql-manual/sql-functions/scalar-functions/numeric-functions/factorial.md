## 説明

`x` の階乗を返します。`NULL` を返すのは、`x` が `0` から `20` までの範囲（`0` と `20` を含む）にない場合です。

## 構文

```sql
FACTORIAL(<x>)
```

## パラメータ

| パラメータ | 説明 |  
| -- | -- |  
| `<x>` | 階乗を計算する対象の値 |  

## 戻り値  

引数 `x` の階乗の値を返します。

## 特殊なケース

- `x` が 0 の場合、1 を返します
- `x` が [0, 20] の範囲外の場合、`NULL` を返します
- `x` が NULL の場合、NULL を返します

## 例

```sql
select factorial(0);
```

```text
+--------------+
| factorial(0) |
+--------------+
|            1 |
+--------------+
```

```sql
select factorial(-1);
```

```text
+---------------+
| factorial(-1) |
+---------------+
|          NULL |
+---------------+
```

```sql
select factorial(21);
```

```text
+---------------+
| factorial(21) |
+---------------+
|          NULL |
+---------------+
```

```sql
select factorial(20);
```

```text
+---------------------+
| factorial(20)       |
+---------------------+
| 2432902008176640000 |
+---------------------+
```

```sql
select factorial(NULL);
```

```text
+-----------------+
| factorial(NULL) |
+-----------------+
|            NULL |
+-----------------+
```
