## 説明

浮動小数点数 a を b で割った余りを計算します。整数型には mod 関数を使用してください。

## 構文

```sql
FMOD(<col_a> , <col_b>)
```

## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<col_a>` | 被除数 |
| `<col_b>` | 除数（0 は指定できません） |

## 戻り値

浮動小数点数を返します。特殊なケースは次のとおりです。

- いずれかの入力パラメータが NULL の場合、NULL を返します。

## 使用例

```sql
select fmod(10.1, 3.2);
```

```text
+--------------------+
| fmod(10.1, 3.2)    |
+--------------------+
| 0.4999999999999991 |
+--------------------+
```

```sql
select fmod(10.1, 0);
```

```text
+---------------+
| fmod(10.1, 0) |
+---------------+
|          NULL |
+---------------+
```

```sql
select fmod(10.1, NULL);
```

```text
+------------------+
| fmod(10.1, NULL) |
+------------------+
|             NULL |
+------------------+
```
