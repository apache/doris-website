# MAP

## 説明

複数組のキーと値のペアから、指定した型の [`MAP<K, V>`](../../../basic-element/sql-data-types/semi-structured/MAP.md) を構築します。

## 構文

```sql
MAP( <key1> , <value1> [, <key2>, <value2> ... ])
```

## パラメータ
### 任意の引数
- `<key1>`: Map のキーを構築します。複数の型をサポートします ([`MAP<K, V>`](../../../basic-element/sql-data-types/semi-structured/MAP.md) を参照)。
- `<value1>`: Map の値を構築します。
### 可変長引数
キーと値のペアを複数組指定できます。

## 戻り値

複数組のキーと値のペアから構築した、指定した型の `MAP<K, V>` を返します。

## 注意事項
1. 引数の数は偶数である必要があります (0 個も可)。そうでない場合はエラーになります。
2. キー引数は重複して指定できますが、Doris が重複したキーを除去します。
3. キーには NULL を指定できます。複数の NULL キーは重複排除されます。

## 使用例
1. 通常の引数
    ```sql
    select map(1, "100", 0.1, 2),map(1, "100", 0.1, 2)[1];
    ```

    ```text
    +-----------------------+--------------------------+
    | map(1, "100", 0.1, 2) | map(1, "100", 0.1, 2)[1] |
    +-----------------------+--------------------------+
    | {1.0:"100", 0.1:"2"}  | 100                      |
    +-----------------------+--------------------------+
    ```
2. 引数がない場合
    ```sql
    select map();
    ```
    ```text
    +-------+
    | map() |
    +-------+
    | {}    |
    +-------+
    ```
3. NULL 引数
    ```sql
    select map(null, 2, 3, null);
    ```
    ```text
    +-----------------------+
    | map(null, 2, 3, null) |
    +-----------------------+
    | {null:2, 3:null}      |
    +-----------------------+
    ```
4. キーが重複する場合は重複排除されます
    ```sql
    select map(1, 2, 2, 11, 1, 3, null, "null 1", null, "null 2");
    ```
    ```text
    +--------------------------------------------------------+
    | map(1, 2, 2, 11, 1, 3, null, "null 1", null, "null 2") |
    +--------------------------------------------------------+
    | {2:"11", 1:"3", null:"null 2"}                         |
    +--------------------------------------------------------+
    ```
