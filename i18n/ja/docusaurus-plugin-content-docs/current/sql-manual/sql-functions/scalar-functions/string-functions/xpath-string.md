## 説明

XPATH_STRING 関数は XML 文字列を解析し、[XPath](https://www.w3.org/TR/xpath-10/) 式に一致する最初の XML ノードを返します。

:::tip
この関数はバージョン 3.0.6 以降でサポートされています。
:::

## 構文

```sql
XPATH_STRING(<xml_string>, <xpath_expression>)
```

## パラメータ
| パラメータ | 説明                                   |
| --------- | ----------------------------------------------|
| `<xml_string>` | 入力文字列。型: VARCHAR             |
| `<xpath_expression>` | [XPath](https://www.w3.org/TR/xpath-10/) 式。型: VARCHAR    |

## 戻り値

VARCHAR 型の値を返します。値は、XPath 式に一致する最初の XML ノードの内容を表します。

特殊なケース:
- XML または XPath の形式が不正な場合、エラーが発生します。

## 例

1. 基本的なノード値の抽出
```sql
SELECT xpath_string('<a>123</a>', '/a');
```
```text
+-----------------------------------+
| xpath_string('<a>123</a>', '/a')  |
+-----------------------------------+
| 123                               |
+-----------------------------------+
```

2. ネストした要素の抽出
```sql
SELECT xpath_string('<a><b>123</b></a>', '/a/b');
```
```text
+--------------------------------------------+
| xpath_string('<a><b>123</b></a>', '/a/b')  |
+--------------------------------------------+
| 123                                        |
+--------------------------------------------+
```

3. 属性の使用
```sql
SELECT xpath_string('<a><b id="1">123</b></a>', '//b[@id="1"]');
```
```text
+----------------------------------------------------------+
| xpath_string('<a><b id="1">123</b></a>', '//b[@id="1"]') |
+----------------------------------------------------------+
| 123                                                      |
+----------------------------------------------------------+
```

4. 位置述語の使用
```sql
SELECT xpath_string('<a><b>1</b><b>2</b></a>', '/a/b[2]');
```
```text
+----------------------------------------------------+
| xpath_string('<a><b>1</b><b>2</b></a>', '/a/b[2]') |
+----------------------------------------------------+
| 2                                                  |
+----------------------------------------------------+
```

5. CDATA とコメントの処理
```sql
SELECT xpath_string(NULL, '/a');
```
```text
+--------------------------+
| xpath_string(NULL, '/a') |
+--------------------------+
| NULL                     |
+--------------------------+
```
