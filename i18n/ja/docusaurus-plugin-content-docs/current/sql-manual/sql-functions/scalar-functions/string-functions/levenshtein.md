## 説明

`LEVENSHTEIN` 関数は、二つの文字列間の[レーベンシュタイン編集距離](https://en.wikipedia.org/wiki/Edit_distance)を計算します。

レーベンシュタイン編集距離は、一方の文字列をもう一方の文字列に変換するために必要な、一文字単位の編集操作の最小回数です。次の編集操作を使用できます。

- 文字を挿入する
- 文字を削除する
- 文字を置換する

この関数は、バイト単位ではなく UTF-8 の文字単位で距離を計算します。そのため、漢字などのマルチバイト文字も一文字として扱います。

## エイリアス

- `LEVENSHTEIN_DISTANCE`
- `EDIT_DISTANCE`

## 構文

```sql
LEVENSHTEIN(<str1>, <str2>)
LEVENSHTEIN_DISTANCE(<str1>, <str2>)
EDIT_DISTANCE(<str1>, <str2>)
```

## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<str1>` | 一つ目の文字列。型: VARCHAR |
| `<str2>` | 二つ目の文字列。型: VARCHAR |

## 戻り値

二つの文字列間のレーベンシュタイン編集距離を表す INT 型の値を返します。

特殊なケース:

- いずれかの引数が NULL の場合は、NULL を返します。
- 二つの文字列が同一の場合は、0 を返します。
- 一方の文字列が空の場合は、もう一方の文字列の文字数を返します。
- この関数は可換です。つまり、`LEVENSHTEIN(a, b)` と `LEVENSHTEIN(b, a)` は同じ結果を返します。

## 例

1. 基本的な使い方

```sql
SELECT levenshtein('kitten', 'sitting');
```

```text
+----------------------------------+
| levenshtein('kitten', 'sitting') |
+----------------------------------+
|                                3 |
+----------------------------------+
```

`kitten` は 3 回の編集操作で `sitting` に変換できます。`k` を `s` に置換し、`e` を `i` に置換して、末尾に `g` を挿入します。

2. 同一の文字列

```sql
SELECT levenshtein('abc', 'abc');
```

```text
+---------------------------+
| levenshtein('abc', 'abc') |
+---------------------------+
|                         0 |
+---------------------------+
```

3. 空文字列

```sql
SELECT levenshtein('', 'abc'), levenshtein('数据库', '');
```

```text
+------------------------+------------------------------+
| levenshtein('', 'abc') | levenshtein('数据库', '')    |
+------------------------+------------------------------+
|                      3 |                            3 |
+------------------------+------------------------------+
```

4. UTF-8 の文字

```sql
SELECT levenshtein('你好世界', '你好世间');
```

```text
+---------------------------------------------+
| levenshtein('你好世界', '你好世间')         |
+---------------------------------------------+
|                                           1 |
+---------------------------------------------+
```

`界` を `间` に置換するには、1 回の編集操作が必要です。

5. 隣接する文字の入れ替えは二回の編集操作として数える

```sql
SELECT levenshtein('abcd', 'abdc');
```

```text
+-----------------------------+
| levenshtein('abcd', 'abdc') |
+-----------------------------+
|                           2 |
+-----------------------------+
```

レーベンシュタイン距離では、隣接する文字の入れ替えを一回の操作として扱いません。そのため、`abcd` と `abdc` の距離は 2 です。

6. エイリアスの使用

```sql
SELECT levenshtein_distance('abcd', 'abdc'), edit_distance('kitten', 'sitting');
```

```text
+--------------------------------------+------------------------------------+
| levenshtein_distance('abcd', 'abdc') | edit_distance('kitten', 'sitting') |
+--------------------------------------+------------------------------------+
|                                    2 |                                  3 |
+--------------------------------------+------------------------------------+
```

7. NULL 引数

```sql
SELECT levenshtein(NULL, 'abc'), levenshtein('abc', NULL);
```

```text
+--------------------------+--------------------------+
| levenshtein(NULL, 'abc') | levenshtein('abc', NULL) |
+--------------------------+--------------------------+
|                     NULL |                     NULL |
+--------------------------+--------------------------+
```
