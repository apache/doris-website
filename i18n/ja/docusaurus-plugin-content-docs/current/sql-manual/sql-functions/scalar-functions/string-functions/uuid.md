## 説明

UUID 関数はランダムな汎用一意識別子（UUID）を生成します。生成される UUID は RFC 4122 に準拠し、ハイフンを含めて 36 文字の 8-4-4-4-12 形式です。

既存の `UUID()` は引き続き `VARCHAR` を返します。[UUID_V4](../uuid-functions/uuid-v4.md) 関数と [UUID_V7](../uuid-functions/uuid-v7.md) 関数は、ネイティブの [UUID 型](../../../basic-element/sql-data-types/uuid.md)を返します。

## 構文

```sql
UUID()
```

## パラメータ

パラメータはありません。

## 戻り値

ランダムに生成された UUID 文字列を VARCHAR 型で返します。

特殊なケース:
- 呼び出すたびに異なる UUID を生成します
- UUID の形式: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
- 生成された UUID はグローバルに一意です

## 例

1. 基本的な使い方: 単一の UUID を生成する
```sql
SELECT UUID();
```
```text
+--------------------------------------+
| UUID()                               |
+--------------------------------------+
| 29077778-fc5e-4603-8368-6b5f8fd55c24 |
+--------------------------------------+
```

2. 複数回の呼び出しで異なる UUID を生成する
```sql
SELECT UUID(), UUID();
```
```text
+--------------------------------------+--------------------------------------+
| UUID()                               | UUID()                               |
+--------------------------------------+--------------------------------------+
| a1b2c3d4-e5f6-47a8-b9c0-d1e2f3a4b5c6 | f7e8d9c0-b1a2-4938-8756-c4d3e2f1a0b9 |
+--------------------------------------+--------------------------------------+
```

### キーワード

    UUID
