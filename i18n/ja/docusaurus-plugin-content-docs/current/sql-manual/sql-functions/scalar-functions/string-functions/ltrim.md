## 説明

LTRIM 関数は、文字列の左側（先頭）に連続する空白または指定した文字集合に含まれる文字を削除します。文字列の左端から走査し、対象の文字集合に含まれない文字に達するまで、連続する対象文字をすべて削除します。

## 構文

```sql
LTRIM(<str> [, <trim_chars>])
```

## パラメータ

| パラメータ | 説明 |
|-----------|------|
| `<str>` | 左側の文字を削除する対象の文字列。型: VARCHAR |
| `<trim_chars>` | 省略可能。削除する文字の集合を指定します。省略した場合は、デフォルトで空白文字を削除します。型: VARCHAR |

## 戻り値

VARCHAR 型を返します。値は、左側から指定した文字を削除した後の文字列です。

削除の規則:
- 文字列の左側（先頭）からのみ文字を削除します。
- trim_chars に含まれる文字が連続する限り、すべて削除します。
- trim_chars に含まれない文字に達すると、削除を停止します。
- trim_chars を指定しない場合は、デフォルトで空白文字（スペース、タブ、改行など）を削除します。

特殊なケース:
- いずれかの引数が NULL の場合は、NULL を返します。
- str が空文字列の場合は、空文字列を返します。
- trim_chars が空文字列の場合は、元の文字列を返します。
- 文字列全体が trim_chars に含まれる文字で構成される場合は、空文字列を返します。

## 例

1. 左側の空白を削除する
```sql
SELECT LTRIM('   ab d');
```
```text
+-------------------+
| LTRIM('   ab d')  |
+-------------------+
| ab d              |
+-------------------+
```

2. 指定した文字を削除する
```sql
SELECT LTRIM('ababccaab', 'ab');
```
```text
+----------------------------+
| LTRIM('ababccaab', 'ab')   |
+----------------------------+
| ccaab                      |
+----------------------------+
```

3. NULL 値の扱い
```sql
SELECT LTRIM(NULL), LTRIM('test', NULL);
```
```text
+-------------+---------------------+
| LTRIM(NULL) | LTRIM('test', NULL) |
+-------------+---------------------+
| NULL        | NULL                |
+-------------+---------------------+
```
