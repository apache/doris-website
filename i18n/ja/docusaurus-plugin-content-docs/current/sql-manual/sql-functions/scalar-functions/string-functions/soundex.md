## 説明

SOUNDEX 関数は、文字列の [Soundex 符号](https://en.wikipedia.org/wiki/Soundex)を計算します。Soundex は、英単語を発音を表す符号に変換する音声アルゴリズムです。発音が似ている単語は同じ符号になります。

符号化規則: 大文字の英字一文字に数字三桁が続く 4 文字の符号を返します（例: S530）。

## 構文

```sql
SOUNDEX(<expr>)
```

## パラメータ

| パラメータ | 説明 |
| -------- | ----------------------------------------- |
| `<expr>` | Soundex 符号を計算する文字列（ASCII 文字のみサポート）。型: VARCHAR |

## 戻り値

文字列の Soundex 符号を表す VARCHAR(4) 型の値を返します。

特殊なケース:
- 引数が NULL の場合は NULL を返します
- 文字列が空、または英字を含まない場合は空文字列を返します
- ASCII 英字のみを処理し、それ以外の文字は無視します
- 非 ASCII 文字が含まれるとエラーになります

## 例

1. 基本的な使い方: 単語の符号化
```sql
SELECT soundex('Doris');
```
```text
+------------------+
| soundex('Doris') |
+------------------+
| D620             |
+------------------+
```

2. 発音が似ている単語は同じ符号になります
```sql
SELECT soundex('Smith'), soundex('Smyth');
```
```text
+------------------+------------------+
| soundex('Smith') | soundex('Smyth') |
+------------------+------------------+
| S530             | S530             |
+------------------+------------------+
```

3. 空文字列の処理
```sql
SELECT soundex('');
```
```text
+-------------+
| soundex('') |
+-------------+
|             |
+-------------+
```

4. NULL 値の処理

```sql
SELECT soundex(NULL);
```

```text
+---------------+
| soundex(NULL) |
+---------------+
| NULL          |
+---------------+
```

5. 空文字列の場合は空文字列を返します

```sql
SELECT soundex('');
```

```text
+-------------+
| soundex('') |
+-------------+
|             |
+-------------+
```

6. 英字以外の文字のみの場合は空文字列を返します

```sql
SELECT soundex('123@*%');
```

```text
+-------------------+
| soundex('123@*%') |
+-------------------+
|                   |
+-------------------+
```

7. 英字以外の文字を無視します

```sql
SELECT soundex('R@b-e123rt'), soundex('Robert');
```

```text
+-----------------------+-------------------+
| soundex('R@b-e123rt') | soundex('Robert') |
+-----------------------+-------------------+
| R163                  | R163              |
+-----------------------+-------------------+
```

9. 非 ASCII 文字のみの場合のエラーの例

```sql
SELECT soundex('你好');  
```
```text
ERROR 1105 (HY000): errCode = 2, detailMessage = Not Supported: Not Supported: soundex only supports ASCII, but got: 你
```

```sql
SELECT soundex('Apache Doris 你好');
```

```text
+--------------------------------+
| soundex('Apache Doris 你好')   |
+--------------------------------+
| A123                           |
+--------------------------------+
```
