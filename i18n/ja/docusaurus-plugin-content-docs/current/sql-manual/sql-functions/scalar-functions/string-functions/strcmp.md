## 説明

STRCMP 関数は、二つの文字列を辞書順で比較します。比較結果を示す整数値を返します。

## 構文

```sql
STRCMP(<str0>, <str1>)
```

## パラメータ
| パラメータ | 説明 |
| --------- | ----------------------------------------- |
| `<str0>` | 比較する最初の文字列。型: VARCHAR |
| `<str1>` | 比較する次の文字列。型: VARCHAR |

## 戻り値

比較結果を示す TINYINT 型の値を返します。
- 0 を返す: str0 と str1 が等しい場合
- 1 を返す: str0 が辞書順で str1 より大きい場合
- -1 を返す: str0 が辞書順で str1 より小さい場合

特殊なケース:
- いずれかの引数が NULL の場合は、NULL を返します。

## 例

1. 同一の文字列を比較する
```sql
SELECT strcmp('test', 'test');
```
```text
+------------------------+
| strcmp('test', 'test') |
+------------------------+
|                      0 |
+------------------------+
```

2. 最初の文字列のほうが大きい場合
```sql
SELECT strcmp('test1', 'test');
```
```text
+-------------------------+
| strcmp('test1', 'test') |
+-------------------------+
|                       1 |
+-------------------------+
```

3. 最初の文字列のほうが小さい場合
```sql
SELECT strcmp('test', 'test1');
```
```text
+-------------------------+
| strcmp('test', 'test1') |
+-------------------------+
|                      -1 |
+-------------------------+
```
