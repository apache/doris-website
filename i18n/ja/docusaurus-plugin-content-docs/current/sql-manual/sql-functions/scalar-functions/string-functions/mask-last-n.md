## 説明

MASK_LAST_N 関数は文字列の末尾 N バイトをマスクします。末尾 N バイトに含まれる大文字を `X`、小文字を `x`、数字を `n` に置き換えます。

## 構文

```sql
MASK_LAST_N(<str>[, <n>])
```

## 引数

| 引数 | 説明 |
| ------- | ----------------------------------------- |
| `<str>` | マスクする文字列。型: VARCHAR |
| `<n>` | 末尾からマスクするバイト数（省略可能。省略時は文字列全体をマスク）。型: INT |

## 戻り値

VARCHAR 型の値を返します。返される文字列では、末尾 N バイトがマスクされています。

特殊なケース:
- いずれかの引数が NULL の場合、NULL を返します
- 英数字以外の文字は変更されません
- `<n>` が文字列の長さより大きい場合、文字列全体をマスクします

## 使用例

1. 基本的な使い方: 末尾 4 バイトをマスク
```sql
SELECT mask_last_n('1234-5678', 4);
```
```text
+-----------------------------+
| mask_last_n('1234-5678', 4) |
+-----------------------------+
| 1234-nnnn                   |
+-----------------------------+
```

2. n を指定しない場合（文字列全体をマスク）
```sql
SELECT mask_last_n('abc123');
```
```text
+----------------------+
| mask_last_n('abc123') |
+----------------------+
| xxxnnn               |
+----------------------+
```

3. n が文字列の長さを超える場合
```sql
SELECT mask_last_n('Hello', 100);
```
```text
+---------------------------+
| mask_last_n('Hello', 100) |
+---------------------------+
| Xxxxx                     |
+---------------------------+
```

4. NULL 値の扱い
```sql
SELECT mask_last_n(NULL, 5);
```
```text
+----------------------+
| mask_last_n(NULL, 5) |
+----------------------+
| NULL                 |
+----------------------+
```

5. n が 0 の場合（文字はマスクされない）
```sql
SELECT mask_last_n('Hello123', 0);
```
```text
+----------------------------+
| mask_last_n('Hello123', 0) |
+----------------------------+
| Hello123                   |
+----------------------------+
```

6. n が文字列の長さを超える場合（文字列全体をマスク）
```sql
SELECT mask_last_n('Test', 100);
```
```text
+--------------------------+
| mask_last_n('Test', 100) |
+--------------------------+
| Xxxx                     |
+--------------------------+
```

7. メールアドレスのドメイン部分をマスク
```sql
SELECT mask_last_n('user@example.com', 11);
```
```text
+-------------------------------------+
| mask_last_n('user@example.com', 11) |
+-------------------------------------+
| user@xxxxxxx.xxx                    |
+-------------------------------------+
```

8. 電話番号の末尾 4 桁をマスク
```sql
SELECT mask_last_n('13812345678', 4);
```
```text
+-------------------------------+
| mask_last_n('13812345678', 4) |
+-------------------------------+
| 1381234nnnn                   |
+-------------------------------+
```

9. 英字、数字、特殊文字が混在する場合
```sql
SELECT mask_last_n('ABC-123-xyz', 7);
```
```text
+--------------------------------+
| mask_last_n('ABC-123-xyz', 7)  |
+--------------------------------+
| ABC-nnn-xxx                    |
+--------------------------------+
```

10. UTF-8 文字の扱い（バイト単位でマスク）
```sql
SELECT mask_last_n('Hello你好123', 9);
```
```text
+--------------------------------+
| mask_last_n('Hello你好123', 9) |
+--------------------------------+
| Hello你好nnn                   |
+--------------------------------+
```

```sql
SELECT mask_last_n('eeeéèêëìí1234');
```
```text
+------------------------------------+
| mask_last_n('eeeéèêëìí1234')       |
+------------------------------------+
| xxxéèêëìínnnn                      |
+------------------------------------+
```
