## 説明

REPEAT 関数は、指定した文字列を指定した回数繰り返して新しい文字列を生成します。この関数は、埋め込み用の文字の生成、区切り文字の作成、テストデータの生成などによく使用します。

## 構文

```sql
REPEAT(<str>, <count>)
```

## 引数

| 引数 | 説明 |
| -- | -- |
| `<str>` | 繰り返す元の文字列。型: VARCHAR |
| `<count>` | 繰り返す回数。非負の整数を指定します。型: INT |

## 戻り値

VARCHAR 型の値を返します。指定した回数だけ繰り返した文字列を表します。

繰り返しの規則:
- count が 0 より大きい場合、str を count 回繰り返した結果を返します
- count が 0 の場合、空文字列を返します
- count が 0 より小さい場合、空文字列を返します
- 結果の文字列が長すぎる場合、文字列長の制限を受けることがあります

特殊なケース:
- いずれかの引数が NULL の場合、NULL を返します
- str が空文字列の場合、count に関係なく空文字列を返します
- count が 0 の場合、空文字列を返します
- count が負の場合、空文字列を返します

## 使用例

1. 文字を繰り返す基本的な例
```sql
SELECT REPEAT('a', 3);
```
```text
+----------------+
| REPEAT('a', 3) |
+----------------+
| aaa            |
+----------------+
```

2. 複数文字の文字列を繰り返す例
```sql
SELECT REPEAT('hello', 2);
```
```text
+--------------------+
| REPEAT('hello', 2) |
+--------------------+
| hellohello         |
+--------------------+
```

3. 繰り返し回数がゼロの場合
```sql
SELECT REPEAT('test', 0);
```
```text
+-------------------+
| REPEAT('test', 0) |
+-------------------+
|                   |
+-------------------+
```

4. 繰り返し回数が負の場合
```sql
SELECT REPEAT('a', -1);
```
```text
+-----------------+
| REPEAT('a', -1) |
+-----------------+
|                 |
+-----------------+
```

5. NULL 値の扱い
```sql
SELECT REPEAT(NULL, 3), REPEAT('a', NULL);
```
```text
+------------------+-------------------+
| REPEAT(NULL, 3)  | REPEAT('a', NULL) |
+------------------+-------------------+
| NULL             | NULL              |
+------------------+-------------------+
```

6. 空文字列を繰り返す例
```sql
SELECT REPEAT('', 5);
```
```text
+----------------+
| REPEAT('', 5)  |
+----------------+
|                |
+----------------+
```

7. 特殊文字を繰り返す例
```sql
SELECT REPEAT('-', 10), REPEAT('*', 5);
```
```text
+------------------+-----------------+
| REPEAT('-', 10)  | REPEAT('*', 5)  |
+------------------+-----------------+
| ----------       | *****           |
+------------------+-----------------+
```

8. UTF-8 文字を繰り返す例
```sql
SELECT REPEAT('ṭṛì', 3), REPEAT('ḍḍu', 2);
```
```text
+-------------------+-------------------+
| REPEAT('ṭṛì', 3)  | REPEAT('ḍḍu', 2)  |
+-------------------+-------------------+
| ṭṛìṭṛìṭṛì          | ḍḍuḍḍu            |
+-------------------+-------------------+
```

9. 数字と記号が混在する文字列を繰り返す例
```sql
SELECT REPEAT('123', 3), REPEAT('@#', 4);
```
```text
+-------------------+------------------+
| REPEAT('123', 3)  | REPEAT('@#', 4)  |
+-------------------+------------------+
| 123123123         | @#@#@#@#         |
+-------------------+------------------+
```

10. UTF-8 文字を繰り返す例
```sql
SELECT REPEAT('ṭṛìṭṛì', 3);
```
```text
+--------------------------------------------------+
| REPEAT('ṭṛìṭṛì', 3)                              |
+--------------------------------------------------+
| ṭṛìṭṛìṭṛìṭṛìṭṛìṭṛì                               |
+--------------------------------------------------+
```
