## 説明

指定したテキストを UTF-8 で URL エンコードします。通常、URL の一部として渡すパラメータ情報のエンコードに使用します。

## 構文

```sql
URL_ENCODE(  <str>  ) 
```

## 必須パラメータ
| パラメータ | 説明 |
|------|------|
| `<str>` | エンコードする文字列 |

## 戻り値


指定したテキストを UTF-8 で URL エンコードした結果を返します。

## 例

```sql
select  URL_ENCODE('Doris Q&A');
```

```text
+-------------------------+
| url_encode('Doris Q&A') |
+-------------------------+
| Doris+Q%26A             |
+-------------------------+

```
