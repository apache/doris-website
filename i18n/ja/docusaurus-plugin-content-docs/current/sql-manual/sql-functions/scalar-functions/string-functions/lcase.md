## 説明

LCASE 関数（別名: LOWER）は、文字列内のすべての大文字を小文字に変換します。

## 構文

```sql
LCASE(<str>)
LOWER(<str>)
```

## パラメータ

| パラメータ | 説明 |
|---------|--------------|
| `<str>` | 小文字に変換する文字列。型: VARCHAR |

## 戻り値

小文字に変換した文字列を表す VARCHAR 型の値を返します。

変換規則:
- 文字列内のすべての大文字を、対応する小文字に変換します。
- 数字、記号、空白などは変更しません。
- すでに小文字の文字は変更しません。

特殊なケース:
- 引数が NULL の場合は、NULL を返します。
- 文字列が空の場合は、空文字列を返します。
- 文字列に大文字が含まれない場合は、元の文字列を返します。

## 例

1. 英字の基本的な変換
```sql
SELECT LOWER('AbC123'), LCASE('AbC123');
```
```text
+-----------------+-----------------+
| LOWER('AbC123') | LCASE('AbC123') |
+-----------------+-----------------+
| abc123          | abc123          |
+-----------------+-----------------+
```

2. 異なる種類の文字が混在する場合
```sql
SELECT LOWER('Hello World!'), LCASE('TEST@123');
```
```text
+----------------------+------------------+
| LOWER('Hello World!') | LCASE('TEST@123') |
+----------------------+------------------+
| hello world!         | test@123         |
+----------------------+------------------+
```

3. NULL 値の処理
```sql
SELECT LOWER(NULL), LCASE(NULL);
```
```text
+-------------+-------------+
| LOWER(NULL) | LCASE(NULL) |
+-------------+-------------+
| NULL        | NULL        |
+-------------+-------------+
```
