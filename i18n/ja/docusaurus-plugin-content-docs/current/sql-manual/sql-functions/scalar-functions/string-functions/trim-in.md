## 説明

TRIM_IN 関数は、文字列の先頭と末尾から指定した文字を取り除きます。文字セットを指定しない場合は、先頭と末尾の空白を取り除きます。文字セットを指定した場合は、セット内の順序に関係なく、指定された文字を両端からすべて取り除きます。

TRIM_IN の特徴は、指定したセット内の文字を任意の組み合わせで取り除くことです。一方、TRIM 関数は文字列の完全一致に基づいて文字を取り除きます。

## 構文

```sql
TRIM_IN(<str>[, <rhs>])
```

## パラメータ

| パラメータ | 説明 |
| --------- | ------------------------------------------------------------------------ |
| `<str>` | 処理対象の文字列。型: VARCHAR |
| `<rhs>` | 省略可能。取り除く文字のセット。型: VARCHAR |

## 戻り値

処理後の文字列を表す VARCHAR 型の値を返します。

特殊なケース:
- str が NULL の場合、NULL を返します
- rhs を指定しない場合、先頭と末尾の空白をすべて取り除きます
- rhs を指定した場合、rhs に含まれない文字に達するまで、両端から rhs に含まれる文字をすべて取り除きます

## 例

1. 先頭と末尾の空白を取り除く
```sql
SELECT trim_in('   ab d   ') str;
```
```text
+------+
| str  |
+------+
| ab d |
+------+
```

2. 指定した文字セットに含まれる文字を取り除く
```sql
SELECT trim_in('ababccaab', 'ab') str;
```
```text
+------+
| str  |
+------+
| cc   |
+------+
```

3. TRIM 関数との比較
```sql
SELECT trim_in('ababccaab', 'ab'), trim('ababccaab', 'ab');
```
```text
+----------------------------+-------------------------+
| trim_in('ababccaab', 'ab') | trim('ababccaab', 'ab') |
+----------------------------+-------------------------+
| cc                         | cca                     |
+----------------------------+-------------------------+
```

4. 文字セット内の順序は結果に影響しない
```sql
SELECT trim_in('abcHelloabc', 'cba');
```
```text
+--------------------------------+
| trim_in('abcHelloabc', 'cba')  |
+--------------------------------+
| Hello                          |
+--------------------------------+
```

5. UTF-8 の文字への対応
```sql
SELECT trim_in('+++ṭṛì ḍḍumai+++', '+');
```
```text
+--------------------------------------+
| trim_in('+++ṭṛì ḍḍumai+++', '+')    |
+--------------------------------------+
| ṭṛì ḍḍumai                           |
+--------------------------------------+
```

6. NULL 値の扱い
```sql
SELECT trim_in(NULL, 'abc');
```
```text
+-----------------------+
| trim_in(NULL, 'abc')  |
+-----------------------+
| NULL                  |
+-----------------------+
```

7. 空文字列の扱い
```sql
SELECT trim_in('', 'abc'), trim_in('abc', '');
```
```text
+--------------------+--------------------+
| trim_in('', 'abc') | trim_in('abc', '') |
+--------------------+--------------------+
|                    | abc                |
+--------------------+--------------------+
```

### キーワード

    TRIM_IN, TRIM
