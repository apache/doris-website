## 説明

MASK 関数は、機密情報を保護するためにデータをマスクします。デフォルトでは大文字を `X`、小文字を `x`、数字を `n` に変換します。

## 構文

```sql
MASK(<str>[, <upper>[, <lower>[, <number>]]])
```

## パラメータ

| パラメータ | 説明 |
| ---------- | ----------------------------------------- |
| `<str>` | マスクする文字列。型: VARCHAR |
| `<upper>` | 大文字の置換に使用する文字。デフォルトは `X`（省略可）。型: VARCHAR |
| `<lower>` | 小文字の置換に使用する文字。デフォルトは `x`（省略可）。型: VARCHAR |
| `<number>` | 数字の置換に使用する文字。デフォルトは `n`（省略可）。型: VARCHAR |

## 戻り値

文字と数字を置換した文字列を VARCHAR 型で返します。

特殊なケース:
- いずれかの引数が NULL の場合は、NULL を返します。
- 英数字以外の文字は変更されません。
- 置換文字を指定する引数に複数の文字が含まれる場合は、最初の文字だけを使用します。

## 例

1. 基本的な使用方法: デフォルトの置換規則
```sql
SELECT mask('abc123XYZ');
```
```text
+-------------------+
| mask('abc123XYZ') |
+-------------------+
| xxxnnnXXX         |
+-------------------+
```

2. 置換文字を指定する
```sql
SELECT mask('abc123XYZ', '*', '#', '$');
```
```text
+----------------------------------+
| mask('abc123XYZ', '*', '#', '$') |
+----------------------------------+
| ###$$$***                        |
+----------------------------------+
```

3. 特殊文字は変更されない
```sql
SELECT mask('Hello-123!');
```
```text
+--------------------+
| mask('Hello-123!') |
+--------------------+
| Xxxxx-nnn!         |
+--------------------+
```

4. NULL 値の扱い
```sql
SELECT mask(NULL);
```
```text
+------------+
| mask(NULL) |
+------------+
| NULL       |
+------------+
```

5. 数字だけの文字列
```sql
SELECT mask('1234567890');
```
```text
+--------------------+
| mask('1234567890') |
+--------------------+
| nnnnnnnnnn         |
+--------------------+
```

6. 英字だけの文字列
```sql
SELECT mask('AbCdEfGh');
```
```text
+------------------+
| mask('AbCdEfGh') |
+------------------+
| XxXxXxXx         |
+------------------+
```

7. 空文字列の扱い
```sql
SELECT mask('');
```
```text
+----------+
| mask('') |
+----------+
|          |
+----------+
```

8. 複数文字を指定した場合、最初の文字で置換する
```sql
SELECT mask('Test123', 'ABC', 'xyz', '999');
```
```text
+--------------------------------------+
| mask('Test123', 'ABC', 'xyz', '999') |
+--------------------------------------+
| Axxx999                              |
+--------------------------------------+
```

9. クレジットカード番号をマスクする
```sql
SELECT mask('1234-5678-9012-3456');
```
```text
+-----------------------------+
| mask('1234-5678-9012-3456') |
+-----------------------------+
| nnnn-nnnn-nnnn-nnnn         |
+-----------------------------+
```

10. メールアドレスをマスクする
```sql
SELECT mask('user@example.com');
```
```text
+--------------------------+
| mask('user@example.com') |
+--------------------------+
| xxxx@xxxxxxx.xxx         |
+--------------------------+
```

```sql
SELECT mask('eeeéèêëìí1234');
```
```text
+-----------------------------+
| mask('eeeéèêëìí1234')       |
+-----------------------------+
| xxxéèêëìínnnn               |
+-----------------------------+
```
