## 説明

REVERSE 関数は入力シーケンスの順序を逆にします。文字列引数の場合は文字の順序を逆にした文字列を返し、配列引数の場合は要素の順序を逆にした配列を返します。文字列は文字単位で反転するため、UTF-8 のマルチバイト文字も正しく処理できます。

## 構文

```sql
REVERSE(<seq>)
```

## パラメータ

| パラメータ | 説明 |
|---------|----------------|
| `<seq>` | 順序を逆にする文字列または配列。型：VARCHAR または ARRAY |

## 戻り値

入力と同じ型の、順序を逆にしたシーケンスを返します。
- 文字列を入力した場合：文字の順序を逆にした VARCHAR 型の文字列を返します。
- 配列を入力した場合：要素の順序を逆にした ARRAY 型の配列を返します。

特殊なケース：
- 引数が NULL の場合、NULL を返します。
- 空文字列の場合、空文字列を返します。
- 空の配列の場合、空の配列を返します。
- 一文字の文字列は、反転しても変わりません。

## 例

1. 基本的な文字列の反転
```sql
SELECT REVERSE('hello');
```
```text
+------------------+
| REVERSE('hello') |
+------------------+
| olleh            |
+------------------+
```

2. 配列の要素の反転
```sql
SELECT REVERSE(['hello', 'world']);
```
```text
+-----------------------------+
| REVERSE(['hello', 'world']) |
+-----------------------------+
| ["world", "hello"]          |
+-----------------------------+
```

3. NULL 値の処理
```sql
SELECT REVERSE(NULL);
```
```text
+---------------+
| REVERSE(NULL) |
+---------------+
| NULL          |
+---------------+
```

4. 空文字列と空の配列
```sql
SELECT REVERSE(''), REVERSE([]);
```
```text
+-------------+-------------+
| REVERSE('') | REVERSE([]) |
+-------------+-------------+
|             | []          |
+-------------+-------------+
```

5. 一文字の文字列と要素が一つの配列
```sql
SELECT REVERSE('A'), REVERSE(['single']);
```
```text
+--------------+--------------------+
| REVERSE('A') | REVERSE(['single']) |
+--------------+--------------------+
| A            | ["single"]         |
+--------------+--------------------+
```

6. 数字と特殊文字
```sql
SELECT REVERSE('12345'), REVERSE('!@#$%');
```
```text
+------------------+------------------+
| REVERSE('12345') | REVERSE('!@#$%') |
+------------------+------------------+
| 54321            | %$#@!            |
+------------------+------------------+
```

7. UTF-8 のマルチバイト文字
```sql
SELECT REVERSE('ṭṛì ḍḍumai'), REVERSE('ḍḍumannàri');
```
```text
+--------------------------------+----------------------------+
| REVERSE('ṭṛì ḍḍumai')          | REVERSE('ḍḍumannàri')      |
+--------------------------------+----------------------------+
| iamuḍḍ ìṛṭ                     | irànnamuḍḍ                 |
+--------------------------------+----------------------------+
```

8. 異なる種類の文字を含む文字列
```sql
SELECT REVERSE('Hello123'), REVERSE('test@email.com');
```
```text
+---------------------+--------------------------+
| REVERSE('Hello123') | REVERSE('test@email.com') |
+---------------------+--------------------------+
| 321olleH            | moc.liame@tset           |
+---------------------+--------------------------+
```

9. 複数要素の配列
```sql
SELECT REVERSE([1, 2, 3, 4, 5]), REVERSE(['a', 'b', 'c']);
```
```text
+---------------------------+------------------------+
| REVERSE([1, 2, 3, 4, 5])  | REVERSE(['a', 'b', 'c']) |
+---------------------------+------------------------+
| [5, 4, 3, 2, 1]           | ["c", "b", "a"]        |
+---------------------------+------------------------+
```

10. 回文の確認
```sql
SELECT REVERSE('level'), REVERSE('12321');
```
```text
+------------------+-------------------+
| REVERSE('level') | REVERSE('12321')  |
+------------------+-------------------+
| level            | 12321             |
+------------------+-------------------+
```
