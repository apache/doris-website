# CHAR

## 説明

CHAR 関数は各引数を整数として解釈し、その整数のコード値が表す文字を連結した文字列を返します。

## 構文

```sql
CHAR(<expr>[, <expr> ...] [USING <charset_name>])
```

## パラメータ

| パラメータ | 説明 |
| ------------------ | ----------------------------------------- |
| `<expr>` | 文字に変換する整数のコード値。型: INT |

## 戻り値

VARCHAR 型の値を返します。値は、引数の整数コード値に対応する文字を連結した文字列です。

特殊なケース:
- 引数のいずれかが NULL の場合は、空文字列を返します
- 結果の文字列が指定された文字セットで無効な場合は、NULL を返します
- 255 を超える引数はマルチバイト文字に変換されます。たとえば、`CHAR(15049882)` は `CHAR(229, 164, 154)` と同じです

## 例

1. 基本的な使い方: ASCII 文字の生成
```sql
SELECT CHAR(68, 111, 114, 105, 115);
```
```text
+--------------------------------------+
| CHAR(68, 111, 114, 105, 115)         |
+--------------------------------------+
| Doris                                |
+--------------------------------------+
```

2. マルチバイト UTF-8 文字（中国語）
```sql
SELECT CHAR(15049882, 15179199, 14989469);
```
```text
+--------------------------------------------+
| CHAR(15049882, 15179199, 14989469)        |
+--------------------------------------------+
| 多睿丝                                     |
+--------------------------------------------+
```

3. 無効な文字は NULL を返す
```sql
SELECT CHAR(255);
```
```text
+-------------------+
| CHAR(255)             |
+-------------------+
| NULL              |
+-------------------+
```

4. NULL 値の扱い
```sql
SELECT CHAR(NULL);
```
```text
+------------+
| CHAR(NULL) |
+------------+
|            |
+------------+
```
