## 説明

SUBSTRING 関数は、文字列から部分文字列を抽出します。開始位置と長さを指定でき、文字列の先頭側または末尾側から位置を数えて抽出できます。文字列の最初の文字の位置は 1 です。

## 別名

SUBSTR

MID

## 構文

```sql
SUBSTRING(<str>, <pos> [, <len>])

SUBSTRING(<str> FROM <pos> [FOR <len>])
```

## パラメータ
| パラメータ | 説明 |
| --------- | ---- |
| `<str>` | 抽出元の文字列。型: VARCHAR |
| `<pos>` | 抽出を開始する位置。負の値も指定できます。型: INT |
| `<len>` | 省略可能。抽出する長さ。型: INT |

## 戻り値

抽出した部分文字列を表す VARCHAR 型の値を返します。

特殊なケース:
- いずれかの引数が NULL の場合は、NULL を返します
- pos が 0 の場合は、空文字列を返します
- pos が負の場合は、文字列の末尾から逆方向に位置を数えます
- pos が文字列の長さを超える場合は、空文字列を返します
- len を指定しない場合は、pos から文字列の末尾までのすべての文字を返します

## 例

1. 基本的な使い方（開始位置を指定）
```sql
SELECT substring('abc1', 2);
```
```text
+-----------------------------+
| substring('abc1', 2)        |
+-----------------------------+
| bc1                         |
+-----------------------------+
```

2. 負の位置を指定
```sql
SELECT substring('abc1', -2);
```
```text
+-----------------------------+
| substring('abc1', -2)       |
+-----------------------------+
| c1                          |
+-----------------------------+
```

3. 位置が 0 の場合
```sql
SELECT substring('abc1', 0);
```
```text
+----------------------+
| substring('abc1', 0) |
+----------------------+
|                      |
+----------------------+
```

4. 位置が文字列の長さを超える場合
```sql
SELECT substring('abc1', 5);
```
```text
+-----------------------------+
| substring('abc1', 5)        |
+-----------------------------+
|                             |
+-----------------------------+
```

5. 長さを指定
```sql
SELECT substring('abc1def', 2, 2);
```
```text
+-----------------------------+
| substring('abc1def', 2, 2)  |
+-----------------------------+
| bc                          |
+-----------------------------+
```

6. FROM と FOR を使用
```sql
SELECT substring('foobarbar' FROM 4 FOR 3);
```
```text
+-------------------------------------+
| substring('foobarbar' FROM 4 FOR 3) |
+-------------------------------------+
| bar                                 |
+-------------------------------------+
```

7. FROM を使用
```sql
SELECT substring('foobarbar' FROM 4);
```
```text
+-------------------------------+
| substring('foobarbar' FROM 4) |
+-------------------------------+
| barbar                        |
+-------------------------------+
```

8. 別名 MID を使用した NULL の例
```sql
SELECT MID(NULL, 2);
```
```text
+--------------+
| MID(NULL, 2) |
+--------------+
| NULL         |
+--------------+
```

9. 別名 SUBSTR を使用
```sql
SELECT SUBSTR('Hello World', 7, 5);
```
```text
+------------------------------+
| SUBSTR('Hello World', 7, 5)  |
+------------------------------+
| World                        |
+------------------------------+
```

10. UTF-8 のマルチバイト文字
```sql
SELECT SUBSTRING('ṭṛì ḍḍumai hello', 5, 6);
```
```text
+--------------------------------------+
| SUBSTRING('ṭṛì ḍḍumai hello', 5, 6)  |
+--------------------------------------+
| ḍḍumai                               |
+--------------------------------------+
```

11. 抽出元が空文字列の場合
```sql
SELECT substring('', 1, 3);
```
```text
+---------------------+
| substring('', 1, 3) |
+---------------------+
|                     |
+---------------------+
```

12. `substring` に直接 NULL を渡す場合（別名 `MID` の例は 8 を参照）
```sql
SELECT substring(NULL, 1, 3);
```
```text
+-----------------------+
| substring(NULL, 1, 3) |
+-----------------------+
| NULL                  |
+-----------------------+
```

### キーワード

    SUBSTRING, SUBSTR, MID
