## 説明

FORMAT_NUMBER 関数は、数値を単位記号付きの文字列に整形します。使用できる単位は K（千）、M（百万）、B（十億）、T（一兆）、Q（千兆）です。

## 構文

```sql
FORMAT_NUMBER(<val>)
```

## パラメータ

| パラメータ | 説明 |
| -------- | ----------------------------------------- |
| `<val>` | 整形する数値。型: DOUBLE |

## 戻り値

単位記号付きの整形済み文字列を VARCHAR 型で返します。

特殊なケース:
- パラメータが NULL の場合、NULL を返します
- 1000 未満の数値は単位を付けずにそのまま返します
- 単位の換算規則:
  - K: 千（1,000）
  - M: 百万（1,000,000）
  - B: 十億（1,000,000,000）
  - T: 一兆（1,000,000,000,000）
  - Q: 千兆（1,000,000,000,000,000）

## 例

1. 基本的な使い方: 千（K）
```sql
SELECT format_number(1500);
```
```text
+---------------------+
| format_number(1500) |
+---------------------+
| 1.50K               |
+---------------------+
```

2. 百万（M）
```sql
SELECT format_number(5000000);
```
```text
+------------------------+
| format_number(5000000) |
+------------------------+
| 5.00M                  |
+------------------------+
```

3. 千未満の数値
```sql
SELECT format_number(999);
```
```text
+----------------------------------+
| format_number(cast(999 as DOUBLE))|
+----------------------------------+
| 999                              |
+----------------------------------+
```

4. NULL 値の扱い
```sql
SELECT format_number(NULL);
```
```text
+---------------------+
| format_number(NULL) |
+---------------------+
| NULL                |
+---------------------+
```
