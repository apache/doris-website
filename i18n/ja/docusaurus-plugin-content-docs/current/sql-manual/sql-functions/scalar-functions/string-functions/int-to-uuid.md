## 説明

エンコードされた LARGEINT 値を元の UUID 文字列に変換します。

この関数の戻り値は文字列です。ネイティブの [UUID 型](../../../basic-element/sql-data-types/uuid.md)に移行するには、`CAST(INT_TO_UUID(<int128>) AS UUID)` を使用してください。LARGEINT と UUID の間で直接 CAST することはできません。

## 構文

```sql
INT_TO_UUID(<int128>)
```

## パラメータ

| パラメータ | 説明 |
|------------|-----------------|
| `<int128>` | エンコードされた LARGEINT 値 |

## 戻り値

引数 `<int128>` に対応する元の UUID 文字列を返します。

- 入力が NULL の場合は NULL を返します。

## 例

```sql
SELECT INT_TO_UUID(95721955514869408091759290071393952876)
```

```text
+-----------------------------------------------------+
| int_to_uuid(95721955514869408091759290071393952876) |
+-----------------------------------------------------+
| 6ce4766f-6783-4b30-b357-bba1c7600348                |
+-----------------------------------------------------+
```

```sql
SELECT INT_TO_UUID(NULL);
```

```text
+-------------------+
| INT_TO_UUID(NULL) |
+-------------------+
| NULL              |
+-------------------+
```
