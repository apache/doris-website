## 説明

引数が有効な UUID の場合は 1、無効な UUID の場合は 0、NULL の場合は NULL を返します。

UUID は、長さが正しく、使用できる文字（大文字または小文字の十六進数字、任意のハイフンおよび波括弧）のみを含む場合に有効とみなされます。次の三つの形式のいずれかで表せます。
```text
aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
aaaaaaaabbbbccccddddeeeeeeeeeeee
{aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee}
```

この関数のテキスト検証規則は、ネイティブの [UUID 型](../../../basic-element/sql-data-types/uuid.md) と異なります。この関数は波括弧で囲まれた標準形式の UUID を受け入れますが、ネイティブのパーサーは受け入れません。ネイティブの UUID カラムに格納するテキストを検証するには、[TO_UUID_OR_NULL](../uuid-functions/to-uuid-or-null.md) または `TRY_CAST(<str> AS UUID)` を使用してください。

## 構文

```sql
IS_UUID ( <str> )
```

## パラメータ
| パラメータ  | 説明 |
|------------|-----------------|
| `<str>` | 文字列 |


## 戻り値

`<str>` が有効な UUID の場合は 1、それ以外の場合は 0 を返します。

特殊なケース:
- 引数が NULL の場合は NULL を返します。
