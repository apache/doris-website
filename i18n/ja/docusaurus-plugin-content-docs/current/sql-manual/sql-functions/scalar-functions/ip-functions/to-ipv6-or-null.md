## 説明
IPv6 アドレスの文字列表現を受け取り、IPv6 型の値を返します。無効な入力または NULL 入力の場合は NULL を返します。

## 構文
```sql
TO_IPV6_OR_NULL(<ipv6_str>)
```

### パラメータ
- `<ipv6_str>`: 文字列型の IPv6 アドレス

### 戻り値
戻り値の型: IPv6（NULL 許容）

戻り値の意味:
- IPv6 型の値を返します。そのバイナリ表現は `ipv6_string_to_num` 関数の戻り値のバイナリ表現と同じです
- 入力が NULL または無効な IPv6 アドレスの場合は NULL を返します

### 使用上の注意
- `to_ipv6_or_null` は `IPv6` 型を返すため、`IPv6` 列を持つテーブルでの使用に適しています
- 無効な入力でも例外を発生させず、代わりに NULL を返します

## 例

IPv6 文字列 `2001:1b70:a1:610::b102:2` を `IPv6` 型に変換します。
```sql
SELECT to_ipv6_or_null('2001:1b70:a1:610::b102:2') as v6;
+-------------------------------+
| v6                            |
+-------------------------------+
| 2001:1b70:a1:610::b102:2      |
+-------------------------------+
```

NULL 入力の場合は NULL を返します。
```sql
SELECT to_ipv6_or_null(NULL) as v6;
+------+
| v6   |
+------+
| NULL |
+------+
```

無効な IPv6 文字列の場合は NULL を返します。
```sql
SELECT to_ipv6_or_null('not-an-ip') as v6;
+------+
| v6   |
+------+
| NULL |
+------+
```

### キーワード

TO_IPV6_OR_NULL
