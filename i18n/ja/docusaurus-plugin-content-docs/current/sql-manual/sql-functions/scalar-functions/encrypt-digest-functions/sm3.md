## 説明

256 ビットの SM3 ダイジェストを計算します

## 構文

```sql
SM3( <input> )
```

## パラメータ


| パラメータ | 説明 |
|-----------|-------------|
| `<input>`   | SM3 ダイジェストを計算する対象の値。文字列型とバイナリ型を受け付けます  |

## 戻り値
入力値の SM3 ダイジェストを返します

## 使用例

```sql
-- vb (VarBinary) and vc (VarChar) used the same string during insertion.
SELECT * FROM mysql_catalog.binary_test.binary_test;
```
```text
+------+------------+------+
| id   | vb         | vc   |
+------+------------+------+
|    1 | 0x616263   | abc  |
|    2 | 0x78797A   | xyz  |
|    3 | NULL       | NULL |
+------+------------+------+
```

```sql
SELECT SM3(vb), SM3(vc) FROM mysql_catalog.binary_test.binary_test;
```
