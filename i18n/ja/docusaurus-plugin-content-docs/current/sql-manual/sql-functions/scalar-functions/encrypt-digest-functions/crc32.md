## 説明

CRC32 を使用して CRC 値を計算します。

## 構文
```sql
CRC32( <str> )
```
## パラメータ

| パラメータ | 説明 |
| -- | -- |
| `<str>` | CRC の計算に使用する値 |

## 戻り値

この文字列の巡回冗長検査（CRC）値を返します。

## 例

```sql
select crc32("abc"),crc32("中国");
```
```text
+--------------+-----------------+
| crc32('abc') | crc32('中国')   |
+--------------+-----------------+
|    891568578 |       737014929 |
+--------------+-----------------+
```
