## 説明

32 ビットの MurmurHash3 ハッシュ値を計算します。

- 注: ハッシュ値を計算する際は、`xxhash_32` を `murmur_hash3_32` の代わりに使用することを推奨します。

## 構文

```sql
MURMUR_HASH3_32( <str> [ , <str> ... ] )
```

## パラメータ

| パラメータ | 説明 |
|-----------|------|
| `<str>`   | 32 ビットの MurmurHash3 ハッシュ値を計算する対象の文字列 |

## 戻り値

入力文字列の 32 ビット MurmurHash3 ハッシュ値を返します。

- 引数が NULL の場合は NULL を返します。

## 使用例

```sql
select murmur_hash3_32(null), murmur_hash3_32("hello"), murmur_hash3_32("hello", "world");
```

```text
+-----------------------+--------------------------+-----------------------------------+
| murmur_hash3_32(NULL) | murmur_hash3_32('hello') | murmur_hash3_32('hello', 'world') |
+-----------------------+--------------------------+-----------------------------------+
|                  NULL |               1321743225 |                         984713481 |
+-----------------------+--------------------------+-----------------------------------+
```
