## 説明

複数の文字列から 128 ビットの MD5 チェックサムを計算します

## 構文

```sql
MD5SUM( <str> [ , <str> ... ] )
```

## パラメータ

| パラメータ | 説明 |
|---------| -- |
| `<str>` | MD5 値を計算する対象の文字列 |

## 戻り値

複数の文字列の MD5 値を返します

## 使用例

```sql
select md5("abcd"),md5sum("ab","cd");
```

```text
+----------------------------------+----------------------------------+
| md5('abcd')                      | md5sum('ab', 'cd')               |
+----------------------------------+----------------------------------+
| e2fc714c4727ee9395f324cd2e7f331f | e2fc714c4727ee9395f324cd2e7f331f |
+----------------------------------+----------------------------------+
```
