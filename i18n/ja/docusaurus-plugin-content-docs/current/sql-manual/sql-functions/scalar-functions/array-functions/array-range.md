## 機能

数値または日時の等差数列を配列として生成します。
- 数値型の場合、デフォルトの間隔は 1 です。
- 日時型の場合、デフォルトの間隔は 1 日です。

## 構文

- `ARRAY_RANGE(end)`
- `ARRAY_RANGE(start, end)`
- `ARRAY_RANGE(start, end, step)`
- `ARRAY_RANGE(start_dt, end_dt)`
- `ARRAY_RANGE(start_dt, end_dt, interval step unit)`

## パラメータ

- `start`、`end`: 非負の整数です。`end` は上限であり、結果には含まれません。
- `step`: 正の整数である必要があります。要素間の間隔を指定します。デフォルトは 1 です。
- `start_dt`、`end_dt`: `DATETIME` または `TIMESTAMP_NS` です。両方の引数は同じ型である必要があります。引数を二つ指定する形式では、デフォルトの間隔は 1 DAY です。
- `interval step unit`: 日時の間隔です。`unit` には `YEAR|QUARTER|MONTH|WEEK|DAY|HOUR|MINUTE|SECOND` を指定できます。`step` は正の整数である必要があります。

## 戻り値

- `ARRAY<T>` を返します。不正な引数の場合は `NULL` を、範囲が空の場合は空の配列 `[]` を返します。
- 要素の型 `T` は入力に対応します。整数を入力すると `INT`、`DATETIME` または `TIMESTAMP_NS` を入力すると対応する日時型になります。

## 使用上の注意

- 数値の数列: `start` から始め、`step` ずつ増加させ、`end` の直前まで生成します（左閉右開）。
- 日時の数列: `start_dt` から始め、`step` ずつ、指定した `unit` 単位で増加させ、`end_dt` の直前まで生成します。引数を二つ指定する形式は `interval 1 day` と同等です。
- 不正な引数は `NULL` を返します。
  - 数値: `start < 0`、`end < 0`、`step <= 0`。
  - 日時: `start_dt` または `end_dt` が無効な場合、または `step <= 0` の場合。
- `ARRAY_RANGE` と `SEQUENCE` は同等です。

## 使用例

- 数値: `start` のデフォルトは 0、`step` のデフォルトは 1 です。
  - `ARRAY_RANGE(5)` -> `[0, 1, 2, 3, 4]`
  - `ARRAY_RANGE(0, 5)` -> `[0, 1, 2, 3, 4]`

- 数値: `end` は上限であり、結果には含まれません。
  - `ARRAY_RANGE(2, 6, 2)` -> `[2, 4]`
  - `ARRAY_RANGE(3, 3)` -> `[]`

- 数値: `end` が `start` 以上でない場合は `[]` を返します。
   - `ARRAY_RANGE(3, 2)` -> `[]`

- 数値: `start` と `end` は非負の整数、`step` は 0 より大きい値である必要があります。
  - `ARRAY_RANGE(-1, 3)` -> `NULL`
  - `ARRAY_RANGE(1, 3, 0)` -> `NULL`

- 日時: `step` のデフォルトは 1 日です。
  - `ARRAY_RANGE('2022-05-15 12:00:00', '2022-05-17 12:00:00')` -> `['2022-05-15 12:00:00', '2022-05-16 12:00:00']`
  - `ARRAY_RANGE('2022-05-15 12:00:00', '2022-05-17 12:00:00', interval 1 day)` -> `['2022-05-15 12:00:00', '2022-05-16 12:00:00']`

- 日時: `unit` には `YEAR|QUARTER|MONTH|WEEK|DAY|HOUR|MINUTE|SECOND` を指定できます。
   - `ARRAY_RANGE('2022-05-15 12:00:00', '2024-05-17 12:00:00', interval 1 year)` -> `["2022-05-15 12:00:00", "2023-05-15 12:00:00"]`
   - `ARRAY_RANGE('2022-05-15 12:00:00', '2023-05-17 12:00:00', interval 1 quarter);` -> `["2022-05-15 12:00:00", "2022-08-15 12:00:00", "2022-11-15 12:00:00", "2023-02-15 12:00:00"] `
   - `ARRAY_RANGE('2022-05-15 12:00:00', '2022-07-17 12:00:00', interval 1 month);` -> `["2022-05-15 12:00:00", "2022-06-15 12:00:00"]`
   - `ARRAY_RANGE('2022-05-15 12:00:00', '2022-05-17 12:00:00', interval 1 day)` -> `['2022-05-15 12:00:00', '2022-05-16 12:00:00']`
   - `ARRAY_RANGE('2022-05-15 12:00:00', '2022-05-15 14:00:00', interval 1 hour)` -> `["2022-05-15 12:00:00", "2022-05-15 13:00:00"]`
   - `ARRAY_RANGE('2022-05-15 12:00:00', '2022-05-15 12:02:00', interval 1 minute)` -> `["2022-05-15 12:00:00", "2022-05-15 12:01:00"]`
   - `ARRAY_RANGE('2022-05-15 12:00:00', '2022-05-15 12:00:02', interval 1 second)` -> `["2022-05-15 12:00:00", "2022-05-15 12:00:01"]`

- `TIMESTAMP_NS` は、生成される要素のナノ秒精度を保持します。
  - `ARRAY_RANGE(CAST('2022-05-15 12:00:00.123456789' AS TIMESTAMP_NS), CAST('2022-05-15 12:00:02.123456789' AS TIMESTAMP_NS), INTERVAL 1 SECOND)` -> `["2022-05-15 12:00:00.123456789", "2022-05-15 12:00:01.123456789"]`
