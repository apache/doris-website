## 説明

データベース内のすべてのカスタムキーを表示します。データベースを指定した場合はそのデータベースを照会し、指定しない場合は現在のセッションのデータベースを照会します。

## 構文

```sql
SHOW ENCRYPTKEYS [ { IN | FROM } <db> ] [ LIKE '<key_pattern>']
```

## オプションのパラメータ

**1. `<db>`**

> 対象データベースの名前。
> 例：`db1`（`db1.my_key` のようなキー名の場合）。

**2. `<key_pattern>`**

> キー名を絞り込むためのパターンパラメータ（ワイルドカードによる一致をサポート）。

## 戻り値

| 列                  | 説明          |
|:--------------------|:--------------|
| `EncryptKey Name`   | キーの名前    |
| `EncryptKey String` | キーの値      |

## アクセス権限の要件

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限         | オブジェクト      | 備考                                                                          |
|:-------------|:------------------|:------------------------------------------------------------------------------|
| `ADMIN_PRIV` | ユーザー / ロール | 暗号化キーを表示するには、対象のユーザーまたはロールに対する `ADMIN_PRIV` 権限が必要です。 |

## 使用上の注意

データベースを明示的に指定した場合、システムは指定されたデータベース内の暗号化キーを照会します。指定しない場合は、現在のセッションのデータベース内のキーを自動的に照会します。

## 例

- 現在のセッションのデータベース内のすべてのカスタムキーを一覧表示します。

    ```sql
    SHOW ENCRYPTKEYS;
    ```
    ```text
    +-----------------+-------------------+
    | EncryptKey Name | EncryptKey String |
    +-----------------+-------------------+
    | testdb.test_key | ABCD123456789     |
    +-----------------+-------------------+
    ```
- 指定したデータベース内のすべてのカスタムキーを一覧表示します。

    ```sql
    SHOW ENCRYPTKEYS FROM example_db ;
    ```
    ```text
    +---------------------+-------------------+
    | EncryptKey Name     | EncryptKey String |
    +---------------------+-------------------+
    | example_db.my_key   | ABCD123456789     |
    | example_db.test_key | ABCD123456789     |
    +---------------------+-------------------+
    ```

- 指定したデータベース内で、名前のパターンに一致するキーを絞り込みます。

    ```sql
    SHOW ENCRYPTKEYS FROM example_db LIKE "%my%";
    ```
    ```text
    +-------------------+-------------------+
    | EncryptKey Name   | EncryptKey String |
    +-------------------+-------------------+
    | example_db.my_key | ABCD123456789     |
    +-------------------+-------------------+
    ```
