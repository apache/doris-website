## 説明

カスタムキーを削除します。削除するキーの名前を正確に指定する必要があります。

## 構文

```sql
DROP ENCRYPTKEY [IF EXISTS] <key_name>
```

## 必須パラメータ

**1. `<key_name>`**

> 削除するキーの名前を指定します。データベース識別子を含めることもできます。
> 例: `db1.my_key`

## オプションパラメータ

**1. `[IF EXISTS]`**

> 指定すると、存在しないキーを削除しようとしてもエラーが発生しません。

## アクセス制御要件

この SQL コマンドを実行するユーザーには、最低限、次の権限が必要です。

| 権限         | オブジェクト      | 備考                                                                  |
|:-------------|:------------------|:----------------------------------------------------------------------|
| `ADMIN_PRIV` | ユーザー / ロール | キーを削除するには、ユーザーまたはロールに `ADMIN_PRIV` 権限が必要です。 |

## 例

- キーを削除する

  ```sql
  DROP ENCRYPTKEY my_key;
  ```
- キーが存在しない場合もエラーを発生させずに削除する

  ```sql
  DROP ENCRYPTKEY IF EXISTS testdb.my_key;
  ```
