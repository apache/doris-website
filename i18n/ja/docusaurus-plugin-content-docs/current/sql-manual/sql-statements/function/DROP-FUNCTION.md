## 説明

カスタム関数を削除します。

## 構文

```sql
DROP [ GLOBAL ] FUNCTION <function_name> ( <arg_type> )
```

## 必須パラメータ

**1. `<function_name>`**

> 削除する関数の名前を指定します。
>
> 関数名は、関数の作成時に指定した名前と完全に一致する必要があります。

**2. `<arg_type>`**

> 削除する関数の引数リストを指定します。
>
> 各引数の位置に対応するデータ型を入力する必要があります。

## オプションパラメータ

**1.`GLOBAL`**

> GLOBAL はオプションパラメータです。
>
> GLOBAL を指定すると、関数をグローバルに検索して削除します。
>
> GLOBAL を指定しない場合は、現在のデータベース内で関数を検索して削除します。

## アクセス制御要件

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限       | オブジェクト   | 備考                  |
|:-----------|:---------------|:----------------------|
| ADMIN_PRIV | カスタム関数   | DROP は管理操作です。 |


## 使用上の注意

- 関数を削除できるのは、関数名とパラメータの型が一致する場合のみです。

## 例

```sql
DROP FUNCTION my_add(INT, INT)
```

```sql
DROP GLOBAL FUNCTION my_add(INT, INT)
```
