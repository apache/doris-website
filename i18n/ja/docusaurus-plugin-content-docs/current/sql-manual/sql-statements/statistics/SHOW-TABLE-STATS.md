## 説明

このステートメントは、テーブルの統計情報の概要を表示するために使用します。

## 構文

```SQL
SHOW TABLE STATS <table_name>;
```

## 必須パラメータ

**1. `<table_name>`**

> テーブル名

## オプションパラメータ

**なし**

## 戻り値

| カラム | 説明 |
| -- | -- |
| updated_rows | テーブルで更新された行数 |
| query_times | テーブルへのクエリ実行回数 |
| row_count | テーブルの行数 |
| updated_time | テーブルの最終更新日時 |
| columns | 分析済みのカラム一覧 |
| trigger | 前回の分析を開始した方法 |
| new_partition | 新しいパーティションへの初回ロードを示すフラグ |
| user_inject | ユーザーによる統計情報の投入を示すフラグ |
| enable_auto_analyze | 自動分析が有効かどうかを示すフラグ |
| last_analyze_time | 前回の分析日時 |

## アクセス制御要件

この SQL を実行するユーザーには、少なくとも次の権限が必要です。

| 権限 | オブジェクト | 説明 |
|:--------------| :------------- |:------------------------------------------------|
| SELECT_PRIV | テーブル | SHOW を実行するには、対象テーブルに対する SELECT_PRIV 権限が必要です。 |

## 使用例

1. テーブル test1 の統計情報の概要を表示します。

```sql
SHOW TABLE STATS test1;
```
