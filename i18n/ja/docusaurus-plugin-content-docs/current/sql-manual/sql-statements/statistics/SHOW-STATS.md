## 説明

このステートメントは、テーブルの列統計を表示するために使用します。

## 構文

```SQL
SHOW COLUMN [CACHED] STATS <table_name> [ (<column_name> [, ...]) ];
```

## 必須パラメータ

**1. `<table_name>`**

> 列統計を表示するテーブルの名前。

## 省略可能なパラメータ

**1. `CACHED`**

> FE キャッシュ内の列統計を表示します。指定しない場合は、デフォルトで統計テーブルに永続化された情報を表示します。

**2. `<column_name>`**

> 表示する列名を指定します。列名はテーブル内に存在する必要があります。複数の列名はカンマで区切ります。指定しない場合は、デフォルトですべての列の情報を表示します。

## 戻り値

| 列 | 説明           |
| -- |--------------|
| column_name | 列名           |
| index_name |   インデックス名           |
| count | 列の行数           |
| ndv | 列の異なる値の数         |
| num_null | 列の NULL 値の数           |
| data_size |   列の総データサイズ           |
| avg_size_byte |  列の平均サイズ           |
| min | 最小値         |
| max | 最大値           |
| method |   収集方法          |
| type | 収集タイプ           |
| trigger | ジョブの起動方法         |
| query_times | クエリ回数          |
| updated_time |   更新時刻           |
| update_rows | 前回の ANALYZE 実行時の更新行数           |
| last_analyze_row_count | 前回の ANALYZE 実行時のテーブル行数         |
| last_analyze_version | 前回の ANALYZE 実行時のテーブルバージョン         |

## 必要な権限

この SQL を実行するユーザーには、少なくとも次の権限が必要です。

| 権限 | オブジェクト | 備考                                    |
|:--------------| :------------- |:------------------------------------------------|
| SELECT_PRIV   | テーブル    | SHOW を実行するには、対象テーブルに対する SELECT_PRIV 権限が必要です。 |
