## 説明

現在のユーザーが利用権限を持つコンピュートグループの一覧を表示します。

- **ストレージとコンピュートを分離したモード**: 現在のユーザーが利用権限を持つコンピュートグループの一覧を返します。
- **ストレージとコンピュートを結合したモード**: バージョン 4.1.4 以降でサポートされます。このモードでは、BE のリソースグループ（`location` タグ）がコンピュートグループにマッピングされます。4.1.4 より前にこのモードでこのステートメントを実行すると、`ERR_NOT_CLOUD_MODE` が返されます。

## 構文

```sql
SHOW COMPUTE GROUPS
```

## 戻り値

現在のユーザーが利用権限を持つコンピュートグループの一覧を返します。返される列はモードによって異なります。

**ストレージとコンピュートを分離したモード:**

- Name - コンピュートグループの名前
- IsCurrent - 現在のユーザーがこのコンピュートグループを使用しているかどうか
- Users - このコンピュートグループをデフォルトのコンピュートグループに設定しているユーザー名
- BackendNum - このコンピュートグループに属するバックエンドの数
- SubComputeGroups / Policy / Properties - 仮想コンピュートグループに関する情報

**ストレージとコンピュートを結合したモード（4.1.4 以降）:**

- Name - コンピュートグループの名前。BE のリソースグループ（`location` タグ）を指します
- BackendNum - このコンピュートグループに属するバックエンドの数

結果はコンピュートグループ名でソートされます。

## 例

`compute_cluster` という名前のコンピュートグループの使用を指定します。

```sql
SHOW COMPUTE GROUPS;
```

結果は次のとおりです。

```sql
+-----------------+-----------+-------+------------+
| Name            | IsCurrent | Users | BackendNum |
+-----------------+-----------+-------+------------+
| compute_cluster | TRUE      |       | 3          |
+-----------------+-----------+-------+------------+
```

## アクセス制御要件

バージョン 4.1.4 以降、ストレージとコンピュートを結合したモードでこのステートメントを実行する際に、グローバル権限の `ADMIN_PRIV` または `NODE_PRIV` は**不要**です。これはストレージとコンピュートを分離したモードと同様で、現在のユーザーには、自身のコンピュートグループが利用を許可されているリソースグループだけが表示されます。

## 使用上の注意

- 現在のユーザーがどのコンピュートグループに対しても権限を持たない場合、`SHOW COMPUTE GROUPS` は空の一覧を返します。
- ストレージとコンピュートを結合したモードでは、現在のセッションのコンピュートグループが `INVALID_COMPUTE_GROUP` の場合も空の結果セットを返します。
- `SHOW CLUSTERS` は同等のステートメントです。ストレージとコンピュートを結合したモードでは、列名は `cluster` と `backend_num` です。
