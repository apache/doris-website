## 説明

ストレージポリシーを削除します。ストレージポリシーの詳細については、「ストレージポリシー」の章を参照してください。

## 構文

```sql
DROP STORAGE POLICY <policy_name>
```
## 必須パラメータ

**<policy_name>**

> ストレージポリシーの名前

## 権限管理

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限       | 対象         | 備考 |
| :--------- | :----- | :---- |
| ADMIN_PRIV | グローバル   |      |

## 例

1. policy1 という名前のストレージポリシーを削除します。

    ```sql
    DROP STORAGE POLICY policy1
    ```
