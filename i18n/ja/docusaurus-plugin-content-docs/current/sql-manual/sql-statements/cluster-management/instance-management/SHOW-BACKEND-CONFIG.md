## 説明

BACKEND（BE）の設定項目と現在の値を表示します。

## 構文

```sql
[ ADMIN ] SHOW BACKEND CONFIG [ LIKE <config_key_pattern> ] [ FROM <backend_id> ]
```

## オプションパラメータ

**<config_key_pattern>**

> BE の設定項目に一致させるワイルドカードパターンを指定します。照合規則は LIKE 式と同じです。記述方法については、「Matching Expressions（マッチング式）」セクションを参照してください。

**<backend_id>**

> BE の ID。指定した ID の BE の設定を表示するために使用します。BE の ID は SHOW BACKENDS コマンドで取得できます。詳細については、SHOW BACKENDS コマンドを参照してください。

## 戻り値

- BackendId: BE の ID
- Host: BE のホストアドレス
- Key: 設定項目の名前
- Value: 設定項目に対応する値
- Type: 設定値の型

## アクセス制御要件

この SQL コマンドを実行するユーザーには、少なくとも ADMIN_PRIV 権限が必要です。

## 例

### すべての設定項目を照会する

```sql
SHOW BACKEND CONFIG
```
結果:

```sql
+-----------+--------------+--------------------------------+-------+--------------------------+-----------+
| BackendId | Host         | Key                            | Value | Type                     | IsMutable |
+-----------+--------------+--------------------------------+-------+--------------------------+-----------+
| 12793     | 172.16.123.1 | LZ4_HC_compression_level       | 9     | int64_t                  | true      |
| 12793     | 172.16.123.1 | agent_task_trace_threshold_sec | 2     | int32_t                  | true      |
...
| 12794     | 172.16.123.2 | zone_map_row_num_threshold     | 20    | int32_t                  | true      |
+-----------+--------------+--------------------------------+-------+--------------------------+-----------+
```

### 指定した BE ID の設定項目を照会する

```sql
SHOW BACKEND CONFIG FROM 12793
```

結果:

```sql
+-----------+--------------+--------------------------------+-------+--------------------------+-----------+
| BackendId | Host         | Key                            | Value | Type                     | IsMutable |
+-----------+--------------+--------------------------------+-------+--------------------------+-----------+
| 12793     | 172.16.123.1 | LZ4_HC_compression_level       | 9     | int64_t                  | true      |
| 12793     | 172.16.123.1 | agent_task_trace_threshold_sec | 2     | int32_t                  | true      |
...
| 12793     | 172.16.123.1 | zone_map_row_num_threshold     | 20    | int32_t                  | true      |
+-----------+--------------+--------------------------------+-------+--------------------------+-----------+
```

### 指定したパターンに一致する設定項目を照会する

```sql
SHOW BACKEND CONFIG LIKE '%compression_level%'
```

結果:

```sql
+-----------+--------------+--------------------------+-------+---------+-----------+
| BackendId | Host         | Key                      | Value | Type    | IsMutable |
+-----------+--------------+--------------------------+-------+---------+-----------+
| 12793     | 172.16.123.1 | LZ4_HC_compression_level | 9     | int64_t | true      |
| 12794     | 172.16.123.2 | LZ4_HC_compression_level | 9     | int64_t | true      |
+-----------+--------------+--------------------------+-------+---------+-----------+
```
