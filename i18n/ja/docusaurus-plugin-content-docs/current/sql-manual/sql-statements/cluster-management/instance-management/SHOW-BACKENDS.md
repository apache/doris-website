## 説明

このステートメントは、BE ノードの基本的なステータス情報を表示します。

## 構文

```sql
 SHOW BACKENDS
```

## 戻り値

| カラム | 説明 |
|-------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BackendId | 現在の BE の ID です。 |
| Host | 現在の BE の IP アドレスまたはホスト名です。 |
| HeartbeatPort | 現在の BE のハートビートサービスの通信ポートです。 |
| BePort | 現在の BE の Thrift RPC 通信ポートです。 |
| HttpPort | 現在の BE の HTTP 通信ポートです。 |
| BrpcPort | 現在の BE の bRPC 通信ポートです。 |
| ArrowFlightSqlPort | 現在の BE の ArrowFlight プロトコルの通信ポートです。 |
| LastStartTime | 現在の BE が起動した時刻を示すタイムスタンプです。 |
| LastHeartbeat | 現在の BE が最後に正常に送信したハートビートのタイムスタンプです。 |
| Alive | 現在の BE が稼働しているかどうかを示します。 |
| SystemDecommissioned | 値が true の場合、現在の BE ノードが安全な廃止処理中であることを示します。 |
| TabletNum | 現在の BE に保存されているタブレットの数です。 |
| DataUsedCapacity | 現在の BE のデータが占有するディスク容量です。 |
| TrashUsedCapacity | 現在の BE のゴミ箱内のデータが占有するディスク容量です。 |
| AvailCapacity | 現在の BE で利用可能なディスク容量です。 |
| TotalCapacity | 現在の BE のディスク総容量です。TotalCapacity = AvailCapacity + TrashUsedCapacity + DataUsedCapacity + その他のユーザーデータ以外のファイルが占有するディスク容量、という関係になります。 |
| UsedPct | 現在の BE のディスク総容量に対する使用済み容量の割合です。 |
| MaxDiskUsedPct | 現在の BE の各ディスクにおける使用済み容量の割合の最大値です。 |
| RemoteUsedCapacity | 現在の BE でホット・コールド階層化機能を使用した後、リモートストレージにアップロードされたデータが占有する容量です。 |
| Tag | 現在の BE のタグ情報で、JSON 形式で表示されます。保存されるタグ情報はデプロイモードによって異なります。ストレージとコンピューティングの統合モードでは現在の BE のリソースグループ名が保存され、ストレージとコンピューティングの分離モードでは追加の情報も保存されます。 |
| ErrMsg | 現在の BE のハートビートが失敗したときのエラーメッセージです。 |
| Version | 現在の BE のバージョン情報です。 |
| Status | 現在の BE のステータス情報の一部で、JSON 形式で表示されます。lastSuccessReportTabletsTime、lastStreamLoadTime、isQueryDisabled、isLoadDisabled などが含まれます。保存される情報はバージョンによって若干異なる場合があります。 |
| HeartbeatFailureCounter | 現在の BE で連続して失敗したハートビートの回数です。この回数が FE Master で設定された `max_backend_heartbeat_failure_tolerance_count`（デフォルト値は 1）を超えると、`Alive` フィールドが false に設定されます。 |
| NodeRole | 現在の BE のロールです。二種類あり、`mix` はデフォルトのロール、`computation` は現在のノードがフェデレーテッド分析クエリにのみ使用されることを示します。 |

## アクセス制御要件

この SQL を実行するユーザーには、少なくとも以下の権限が必要です。

| 権限 | オブジェクト | 備考 |
|------------|----|----|
| SELECT_PRIV | internal.information_schema | すべてのユーザーは、デフォルトでこのデータベースに対する権限を持っています。 |

## 使用上の注意

クエリ結果をさらに絞り込む必要がある場合は、テーブル値関数 [backends()](../../../sql-functions/table-valued-functions/backends.md) を使用できます。SHOW BACKENDS は次のステートメントと同等です。
```sql
SELECT * FROM BACKENDS();
```
