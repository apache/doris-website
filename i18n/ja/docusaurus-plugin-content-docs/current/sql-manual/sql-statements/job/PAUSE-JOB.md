## 説明

RUNNING 状態のジョブを一時停止すると、実行中のタスクが中断され、ジョブの状態が PAUSED に変更されます。停止したジョブは RESUME 操作で再開できます。

## 構文

```sql
PAUSE JOB WHERE jobname = <job_name> ;
```

## 必須パラメータ

**1. `<job_name>`**
> 一時停止するジョブの名前。

## アクセス制御要件

この SQL コマンドを実行するユーザーには、少なくとも以下の権限が必要です。

| 権限 | オブジェクト | 実行種別 | 備考 |
|:--------------|:-----------|:------------------------|:------------------------|
| ADMIN_PRIV | データベース | 非ストリーミング | 現時点では、この操作の実行には **ADMIN** 権限のみがサポートされています |
| LOAD_PRIV | データベース | ストリーミング | この操作は **LOAD** 権限で実行できます |

## 例

- example という名前のジョブを一時停止します。

   ```sql 
   PAUSE JOB where jobname='example'; 
   ```
