## 説明

バックグラウンドで実行中のインデックス構築タスクを取り消します。

## 構文


```sql
CANCEL BUILD INDEX ON <table_name> [ job_list ]
```

各要素は次のとおりです。

```sql
job_list
  : (<job_id1>[ , job_id2 ][ ... ])
```
## 必須パラメータ

**<table_name>**

> テーブルの識別子（名前）を指定します。所属するデータベース内で一意である必要があります。
>
> 識別子は英字で始める必要があります（Unicode 名が有効な場合は任意の言語の文字でも可）。全体をバッククォートで囲まない限り、空白や特殊文字は使用できません（例: `My Object`）。
>
> 識別子には予約語を使用できません。
>
> 詳細は「識別子の要件と予約語」を参照してください。

## 任意パラメータ

**<job_list>**

> インデックス構築タスクの識別子をカンマ区切りで指定し、括弧で囲みます。
>
> 識別子は数値で、SHOW BUILD INDEX で確認できます。

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限  | 対象 | 説明                                                        |
| :--------- | :----- | :----------------------------------------------------------- |
| ALTER_PRIV | Table  | CANCEL BUILD INDEX はテーブルに対する ALTER 操作として扱われます |

## 使用上の注意

- 現在は転置インデックスにのみ有効で、BloomFilter インデックスなどには適用できません。
- 現在はストレージとコンピュートの一体型モードにのみ有効で、分離型モードには適用できません。
- BUILD INDEX の進捗と構築タスクは SHOW BUILD INDEX で確認できます。

## 例

- table1 のすべてのインデックス構築タスクを取り消します

  ```sql
  CANCEL BUILD INDEX ON table1
  ```

- table1 のインデックス構築タスク jobid1 と jobid2 を取り消します

  ```sql
  CANCEL BUILD INDEX ON table1(jobid1, jobid2)
  ```
