## 説明

テーブルのインデックス情報を表示します。現在は転置インデックスと ANN インデックスのみをサポートします。

## 構文

```SQL
SHOW INDEX [ ES ] FROM [ <db_name>. ] <table_name> [ FROM <db_name> ];
```

## 別の構文

```SQL
SHOW KEY[ S ] FROM [ <db_name>. ] <table_name> [ FROM <db_name> ];
```
## 必須パラメータ

**1. `<table_name>`**: インデックスが属するテーブル名。

## 任意パラメータ

**1. `<db_name>`**: データベース名。省略可能で、指定しない場合は現在のデータベースを使用します。

## 戻り値

| 列名    | Type   | Description                                                                                                    |
|----------------|--------|----------------------------------------------------------------------------------------------------------------|
| Table          | string | インデックスが属するテーブル名。                                                              |
| Non_unique     | int    | インデックスが一意かどうかを示します。<br> - `0`: 一意インデックス <br> - `1`: 非一意インデックス                   |
| Key_name       | string | インデックス名。                                                                                          |
| Seq_in_index   | int    | インデックス内での列の位置。複数列で複合インデックスを構成する場合の列の順序を示します。 |
| Column_name    | string | インデックス対象の列名。                                                                                 |
| Collation      | string | インデックス列の並び順。<br> - `A`: 昇順 <br> - `D`: 降順。                          |
| Cardinality    | int    | インデックス内の一意な値の数。クエリ効率の推定に使用され、値が高いほどインデックスの選択性とクエリ効率が高くなります。 |
| Sub_part       | int    | インデックスが使用する接頭辞の長さ。インデックス列が文字列型の場合、`Sub_part` は先頭からインデックス化する文字数を表します。 |
| Packed         | string | インデックスが圧縮されているかどうか。                                                                                 |
| Null           | string | `NULL` 値を許可するかどうか。<br> - `YES`: NULL 値を許可 <br> - `NO`: NULL 値を許可しない       |
| Index_type     | string | インデックスの種類。<br> - `BTREE`: B+ 木インデックス（MySQL のデフォルト）<br> - `HASH`: ハッシュインデックス <br> - `RTREE`: R 木インデックス <br> - `INVERTED`: 転置インデックス（全文検索インデックスなど） |
| Comment        | string | インデックスのコメントまたは説明。通常はユーザーが記述します。                                               |
| Properties     | string | インデックスの追加プロパティ。                                                                             |


## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限  | 対象    | 説明 |
|:-----------|:----------|:------|
| SHOW_PRIV  | Database  |       |

## 例

- 指定した `table_name` のインデックスを表示します

     ```SQL
      SHOW INDEX FROM example_db.table_name;
     ```
