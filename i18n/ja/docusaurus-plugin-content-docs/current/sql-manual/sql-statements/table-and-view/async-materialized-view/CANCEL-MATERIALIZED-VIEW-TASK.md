## 説明

このステートメントは、マテリアライズドビューのタスクをキャンセルするために使用します。

## 構文

```sql
CANCEL MATERIALIZED VIEW TASK <task_id> ON <mv_name>
```

## 必須パラメータ
**1. `<task_id>`**
> マテリアライズドビューのタスク ID を指定します。


**2. `<mv_name>`**
> マテリアライズドビューの名前を指定します。
>
> マテリアライズドビューの名前は文字で始める必要があります。Unicode 名のサポートが有効な場合は、任意の言語の文字で始めることができます。名前全体をバッククォートで囲まない限り、空白や特殊文字は使用できません（例: `My Object`）。
>
> マテリアライズドビューの名前に予約語は使用できません。
>
> 詳細については、予約語を参照してください。

## 必要な権限
この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限  | オブジェクト | 備考                                        |
| :--------- | :----- | :------------------------------------------- |
| ALTER_PRIV | マテリアライズドビュー  | CANCEL はマテリアライズドビューに対する ALTER 操作です |

## 例

- マテリアライズドビュー mv1 の ID が 1 のタスクをキャンセルします。

    ```sql
    CANCEL MATERIALIZED VIEW TASK 1 on mv1;
    ```
