## 説明

この文は、指定したタブレットと、それらが属するテーブルの情報を表示します。

## 構文

```sql
SHOW TABLETS BELONG <tablet_id> [, <tablet_id>]...;
```

## 必須パラメータ

**1. `<tablet_id>`**

> 一つ以上のタブレット ID をカンマで区切って指定します。同じ ID を複数回指定した場合、結果では重複が除かれます。

## 戻り値

`SHOW TABLETS BELONG <tablet_id> [, <tablet_id>]...` を実行すると、次の列が返されます。

| 列名          | データ型 | 説明                                                   |
|---------------|----------|------------------------------------------------------------------------|
| DbName        | String   | タブレットが属するデータベースの名前。                 |
| TableName     | String   | タブレットが属するテーブルの名前。                     |
| TableSize     | String   | テーブルのサイズ（例: "8.649 KB"）。                  |
| PartitionNum  | Int      | テーブル内のパーティション数。                         |
| BucketNum     | Int      | テーブル内のバケット数。                               |
| ReplicaCount  | Int      | テーブル内のレプリカ数。                               |
| TabletIds     | Array    | テーブルに属するタブレット ID の一覧。                 |

## アクセス制御要件

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限       | オブジェクト   | 備考                                                                                     |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------|
| Admin_priv | データベース   | テーブルやパーティションの管理、システムレベルのコマンドなど、データベースに対する管理操作の実行に必要です。 |

## 例

特定のタブレットの情報を表示します。

```sql
SHOW TABLETS BELONG 10145;
```

```text
+--------+-----------+-----------+--------------+-----------+--------------+-----------+
| DbName | TableName | TableSize | PartitionNum | BucketNum | ReplicaCount | TabletIds |
+--------+-----------+-----------+--------------+-----------+--------------+-----------+
| test   | sell_user | 8.649 KB  | 1            | 4         | 4            | [10145]   |
+--------+-----------+-----------+--------------+-----------+--------------+-----------+
```

複数のタブレットの情報を表示します。

```sql
SHOW TABLETS BELONG 27028,78880,78382,27028;
```

```text
+---------------------+-----------+-----------+--------------+-----------+--------------+----------------+
| DbName              | TableName | TableSize | PartitionNum | BucketNum | ReplicaCount | TabletIds      |
+---------------------+-----------+-----------+--------------+-----------+--------------+----------------+
| default_cluster:db1 | kec       | 613.000 B | 379          | 604       | 604          | [78880, 78382] |
| default_cluster:db1 | test      | 1.874 KB  | 1            | 1         | 1            | [27028]        |
+---------------------+-----------+-----------+--------------+-----------+--------------+----------------+
```
