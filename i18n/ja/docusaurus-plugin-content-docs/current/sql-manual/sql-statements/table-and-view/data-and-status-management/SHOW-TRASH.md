## 説明

このステートメントは、バックエンドでゴミデータが占有している容量を表示します。

## 構文

```sql
SHOW TRASH [ON ("<be_host>:<be_heartbeat_port>" [, ...])];
```

## オプションパラメータ

**1. `[ON ("<be_host>:<be_heartbeat_port>" [, ...])]`**

表示対象のバックエンドを指定します。ON を指定しない場合、デフォルトですべてのバックエンドが表示されます。


## アクセス権限の要件

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。


| 権限  | 対象 | 説明                                        |
| :--------- | :----- | :------------------------------------------- |
| ADMIN_PRIV または NODE_PRIV | ユーザーまたはロール  | ADMIN_PRIV または NODE_PRIV 権限を持つユーザーまたはロールのみが SHOW TRASH 操作を実行できます。 |


## 例

1. すべての BE ノードのゴミデータの使用容量を表示します。


```sql
SHOW TRASH;
```

2. '192.168.0.1:9050' のゴミデータの使用容量を表示します（ディスク情報が表示されます）。


```sql
SHOW TRASH ON "192.168.0.1:9050";
```
