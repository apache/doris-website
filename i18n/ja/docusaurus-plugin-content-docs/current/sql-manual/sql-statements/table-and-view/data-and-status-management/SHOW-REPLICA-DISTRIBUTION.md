## 説明

このステートメントは、テーブルまたはパーティションのレプリカの状態に関する情報を表示します。

## 構文

```sql
SHOW REPLICA DISTRIBUTION FROM [ <database_name>.]<table_name> [<partition_list>] 
[where_clause]
```
ここで:

```sql
partition_list
  : PARTITION (<partition_name>[ , ... ])
```

ここで:

```sql
where_clause
: WHERE <output_column_name> = <value>
```

## 必須パラメータ

**1. `<table_name>`**

> テーブルの識別子（名前）。データベース（Database）内で一意である必要があります。
>
> 識別子は英字（Unicode 名がサポートされている場合は、サポート対象言語の文字も可）で始める必要があります。識別子全体をバッククォートで囲む場合（例: My Object）を除き、空白や特殊文字を含めることはできません。
>
> 予約語は識別子として使用できません。
>
> 詳細については、識別子の要件と予約語を参照してください。


## オプションパラメータ

**1. `<db_name>`**

> データベースの識別子（名前）。クラスター（Cluster）内で一意である必要があります。
>
> 識別子は英字（Unicode 名がサポートされている場合は、サポート対象言語の文字も可）で始める必要があります。識別子全体をバッククォートで囲む場合（例: My Object）を除き、空白や特殊文字を含めることはできません。
>
> 予約語は識別子として使用できません。
>
> 詳細については、識別子の要件と予約語を参照してください。

**2. `<partition_list>`**

> テーブル（Table）内で一意である必要があるパーティションの識別子（名前）を、カンマで区切って指定します。
>
> 識別子は英字（Unicode 名がサポートされている場合は、サポート対象言語の文字も可）で始める必要があります。識別子全体をバッククォートで囲む場合（例: My Object）を除き、空白や特殊文字を含めることはできません。
>
> 予約語は識別子として使用できません。
>
> 詳細については、識別子の要件と予約語を参照してください。


## 戻り値

| 列          | データ型 | 説明                                                        |
|-------------|----------|-------------------------------------------------------------|
| BackendId   | Int      | レプリカが配置されている BE（Backend）ノードの ID。           |
| ReplicaNum  | Int      | この BE ノード上のレプリカ数。                                |
| ReplicaSize | Int      | この BE ノード上の全レプリカが占めるストレージの合計サイズ（バイト単位）。 |
| NumGraph    | String   | レプリカ数の割合を > 記号で視覚的に表したもの。             |
| NumPercent  | String   | レプリカ数の割合を百分率で表したもの（例: 100.00%）。        |
| SizeGraph   | String   | レプリカのストレージサイズの割合を > 記号で視覚的に表したもの。 |
| SizePercent | String   | レプリカのストレージサイズの割合を百分率で表したもの（例: 100.00%）。 |

## アクセス制御要件

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限       | 対象         | 備考                                                                           |
|:-----------|:-------------|:-------------------------------------------------------------------------------|
| Admin_priv | データベース | テーブルやパーティションの管理、システムレベルのコマンドなど、データベースに対する管理操作を実行するために必要です。 |


## 例

- テーブルのレプリカの分布を表示する

  ```sql
  SHOW REPLICA DISTRIBUTION FROM sell_user;
  ```

  ```text
  *************************** 1. row ***************************
  BackendId: 10009
   ReplicaNum: 4
  ReplicaSize: 8857
     NumGraph: >>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>
   NumPercent: 100.00%
    SizeGraph: >>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>
  SizePercent: 100.00%
  ```

- テーブルのパーティションのレプリカの分布を表示する

  ```sql
  SHOW REPLICA DISTRIBUTION FROM db1.tbl1 PARTITION(p1, p2);
  ```
