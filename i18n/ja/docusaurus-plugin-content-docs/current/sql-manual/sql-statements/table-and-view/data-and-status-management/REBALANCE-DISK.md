## 説明 {#description}

`REBALANCE DISK` 文は、Backend（BE）ノード上のデータ配置を最適化するために使用します。この文には次の機能があります。

- 指定した BE ノードのデータを均衡化できます。
- クラスター内のすべての BE ノード間でデータを均衡化できます。
- クラスター全体の均衡状態に関係なく、指定したノードのデータの均衡化を優先します。

## 構文 {#syntax}

```sql
ADMIN REBALANCE DISK [ ON ( "<host>:<port>" [, ... ] ) ];
```

## オプションパラメーター {#optional-parameters}

**1. `"<host>:<port>"`**

> 均衡化する BE ノードの一覧を指定します。
>
> 各ノードは、ホスト名（または IP アドレス）とハートビートポートで構成されます。
>
> このパラメーターを指定しない場合は、すべての BE ノードを均衡化します。

## アクセス権限 {#access-control-requirements}

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限       | 対象      | 備考                                         |
| :-------------- | :---------- | :-------------------------------------------- |
| ADMIN           | システム      | このコマンドを実行するには、ADMIN 権限が必要です。 |

## 使用上の注意 {#usage-notes}

- このコマンドのデフォルトのタイムアウトは 24 時間です。この期間が過ぎると、指定した BE のディスクデータの均衡化は優先されなくなります。均衡化を続けるには、コマンドを再実行する必要があります。
- 指定した BE ノードのディスクデータの均衡化が完了すると、そのノードの優先設定は自動的に無効になります。
- このコマンドは、クラスターが不均衡な状態でも実行できます。

## 例 {#examples}

- クラスター内のすべての BE ノード間でデータを均衡化する場合：

```sql
ADMIN REBALANCE DISK;
```

- 指定した二つの BE ノードのデータを均衡化する場合：

```sql
ADMIN REBALANCE DISK ON ("192.168.1.1:1234", "192.168.1.2:1234");
```
