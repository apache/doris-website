## 説明

`SET TABLE STATUS` ステートメントは、OLAP テーブルのステータスを手動で設定するために使用します。このステートメントには、次の機能があります。

- OLAP テーブルのステータスの設定にのみ対応しています。
- テーブルのステータスを指定した状態に変更できます。
- テーブルのステータスが原因でタスクがブロックされる問題の解消に使用します。

**サポートされる状態**：

| 状態              | 説明                                 |
|-------------------|--------------------------------------|
| NORMAL            | テーブルが正常な状態であることを示します。 |
| ROLLUP            | テーブルで ROLLUP 操作が進行中であることを示します。 |
| SCHEMA_CHANGE     | テーブルでスキーマ変更が進行中であることを示します。 |
| BACKUP            | テーブルでバックアップ操作が進行中であることを示します。 |
| RESTORE           | テーブルで復元操作が進行中であることを示します。 |
| WAITING_STABLE    | テーブルが安定した状態になるのを待っていることを示します。 |

## 構文

```sql
ADMIN SET TABLE <table_name> STATUS PROPERTIES ("<key>" = "<value>" [, ...]);
```

ここで：

```sql
<key>
  : "state"

<value>
  : "NORMAL"
  | "ROLLUP"
  | "SCHEMA_CHANGE"
  | "BACKUP"
  | "RESTORE"
  | "WAITING_STABLE"
```

## 必須パラメータ

**1. `<table_name>`**

> ステータスを設定するテーブルの名前を指定します。
>
> テーブル名は、そのデータベース内で一意である必要があります。

**2. `PROPERTIES ("state" = "<value>")`**

> テーブルの変更先のステータスを指定します。
>
> "state" プロパティは必須で、その値にはサポートされる状態のいずれかを指定する必要があります。

## アクセス制御要件

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限            | オブジェクト | 備考                                      |
| :-------------- | :----------- | :---------------------------------------- |
| ADMIN           | システム     | このコマンドの実行には ADMIN 権限が必要です。 |

## 使用上の注意

- このコマンドは緊急時の障害復旧を目的としています。慎重に使用してください。
- OLAP テーブルにのみ対応し、ほかの種類のテーブルには対応していません。
- テーブルがすでに指定した状態である場合、このコマンドは無視されます。
- 状態を不適切に設定するとシステムに異常が生じる可能性があります。テクニカルサポートの指導の下で使用することを推奨します。
- ステータスを変更した後は、速やかにシステムの稼働状況を監視することを推奨します。

## 例

- テーブルのステータスを NORMAL に設定します。

    ```sql
    ADMIN SET TABLE tbl1 STATUS PROPERTIES("state" = "NORMAL");
    ```

- テーブルのステータスを SCHEMA_CHANGE に設定します。

    ```sql
    ADMIN SET TABLE tbl2 STATUS PROPERTIES("state" = "SCHEMA_CHANGE");
    ```
