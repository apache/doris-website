## 説明

テーブル ID に対応するデータベース名とテーブル名を検索します。

## 構文

```sql
SHOW TABLE <table_id>
```

## 必須パラメータ

**1. `<table_id>`**
> データベース名とテーブル名を調べる対象の `<table_id>` を指定します。

## 戻り値

| 列名（Column） | 型（DataType） | 説明（Notes） |
|:--------------------|:-------------|:----------|
| DbName | String | データベース名 |
| TableName | String | テーブル名 |
| DbId | String | データベース ID |

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限（Privilege） | 対象（Object） | 説明（Notes） |
|:--------------|:-----------|:------------------------|
| ADMIN_PRIV | テーブル（table） | 現在、この操作を実行できるのは **ADMIN** 権限を持つユーザーのみです |

## 例

- テーブル ID に対応するデータベース名とテーブル名を検索します

   ```sql
   SHOW TABLE 2261121
   ```

   ```text
   +--------+------------+---------+
   | DbName | TableName  | DbId    |
   +--------+------------+---------+
   | demo   | test_table | 2261034 |
   +--------+------------+---------+
   ```
