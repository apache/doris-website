## 説明  
設定済みの SQL ブロックルールを表示します。ルール名を指定しない場合は、すべてのルールを表示します。  

## 構文  
```sql
SHOW SQL_BLOCK_RULE [FOR <rule_name>];
```

## オプションパラメータ  

`<rule_name>`

表示する SQL ブロックルールの名前です。省略した場合は、すべてのルールを表示します。

## アクセス権限要件  

このコマンドを実行するユーザーには、次の権限が必要です。  

| 権限 | 対象        | 備考  |
|-----------|--------------|--------|
| `ADMIN`   | ユーザーまたはロール | この操作の実行に必要です。 |

## 例  

1. すべての SQL ブロックルールを表示する  
```sql
SHOW SQL_BLOCK_RULE;
```

```text
+------------+------------------------------+---------+--------------+-----------+-------------+--------+--------+
| Name       | Sql                          | SqlHash | PartitionNum | TabletNum | Cardinality | Global | Enable |
+------------+------------------------------+---------+--------------+-----------+-------------+--------+--------+
| test_rule  | select * from order_analysis | NULL    | 0            | 0         | 0           | true   | true   |
| test_rule2 | NULL                         | NULL    | 30           | 0         | 10000000000 | false  | true   |
+------------+------------------------------+---------+--------------+-----------+-------------+--------+--------+
```

2. 特定の SQL ブロックルールを表示する  
```sql
SHOW SQL_BLOCK_RULE FOR test_rule2;
```

```text
+------------+------+---------+--------------+-----------+-------------+--------+--------+
| Name       | Sql  | SqlHash | PartitionNum | TabletNum | Cardinality | Global | Enable |
+------------+------+---------+--------------+-----------+-------------+--------+--------+
| test_rule2 | NULL | NULL    | 30           | 0         | 10000000000 | false  | true   |
+------------+------+---------+--------------+-----------+-------------+--------+--------+
```
