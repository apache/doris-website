## 説明

指定した接続 ID の接続を終了します。この接続に関連付けられたクエリも終了します。

## 構文

```sql
KILL [ CONNECTION ] <connection_id>
```

## 必須パラメータ

**<connection_id>**

> 接続の ID です。SHOW PROCESSLIST 文で確認できます。

## アクセス権限

この SQL コマンドを実行するユーザーは、対象の接続の所有者であるか、少なくとも `ADMIN_PRIV` 権限を持っている必要があります。

## 例

`connection_id` を確認します。

```sql
show processlist;
```

結果：

```sql
+------------------+----+------+-----------------+---------------------+----------+------+---------+------+-------+-----------------------------------+------------------+--------------+--------------+
| CurrentConnected | Id | User | Host            | LoginTime           | Catalog  | Db   | Command | Time | State | QueryId                           | Info             | FE           | CloudCluster |
+------------------+----+------+-----------------+---------------------+----------+------+---------+------+-------+-----------------------------------+------------------+--------------+--------------+
| Yes              | 16 | root | 127.0.0.1:63746 | 2024-11-04 20:18:07 | internal | test | Query   | 0    | OK    | e4d69a1cce81468d-91c9ae32b17540e9 | show processlist | 172.16.123.1 | NULL         |
+------------------+----+------+-----------------+---------------------+----------+------+---------+------+-------+-----------------------------------+------------------+--------------+--------------+
```

KILL コマンドを実行します。

```sql
KILL CONNECTION 16;
```
