## 説明

ユーザーが実行しているスレッドを表示します。  
このコマンドでは、現在の FE の接続情報のみを表示できます。  
クラスター全体の接続情報を表示するには、次のセッション変数を設定します。
```
SET SHOW_ALL_FE_CONNECTION = TRUE;
```

## 構文

```sql
SHOW [FULL] PROCESSLIST
```

## 任意パラメータ

**1. `FULL`**

> 他のユーザーの接続情報を表示するかどうかを指定します。

## 戻り値

| 列               | 説明 |
|------------------|------|
| CurrentConnected | 現在の接続かどうか |
| Id               | このスレッドの一意の識別子 |
| User             | このスレッドを開始したユーザー |
| Host             | リクエストを送信したクライアントの IP アドレスとポート番号 |
| LoginTime        | 接続が確立された時刻 |
| Catalog          | コマンドが現在実行されているデータディレクトリ |
| Db               | コマンドが実行されているデータベース。データベースが指定されていない場合は NULL |
| Command          | スレッドが現在実行しているコマンド |
| Time             | 前のコマンドが送信されてから現在の状態に至るまでの時間（秒） |
| State            | スレッドの状態 |
| QueryId          | 現在のクエリ文の ID |
| Info             | 通常はスレッドが実行した文。デフォルトでは先頭の 100 文字のみを表示します |

主な Command の種類は次のとおりです。

| 値 | 説明 |
| -- | -- |
| Query | スレッドが文を実行中 |
| Sleep | クライアントからの実行文を待機中 |
| Quit | スレッドが終了処理中 |
| Kill | KILL 文を実行中 |

## 必要な権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限         | 対象     | 説明 |
|:-------------|:---------|:-----|
| ADMIN_PRIV   | DATABASE | 他のユーザーの接続情報を表示するには ADMIN 権限が必要です |

## 例

```sql
SHOW PROCESSLIST
```
