## 説明

このコマンドは、クエリまたはロードの過去のプロファイルをすべて手動でクリアします。

## 構文

```sql
CLEAN ALL PROFILE
```

## アクセス制御要件

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限       | 対象         | 備考                                               |
|:-----------|:-------------|:---------------------------------------------------|
| ADMIN_PRIV | グローバル   | すべてのプロファイルをクリアするには ADMIN 権限が必要です。 |

## 例

```sql
CLEAN ALL PROFILE
```
