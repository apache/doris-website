## 説明

指定したデータベースまたはコンピュートグループに切り替えます。

## 構文

```SQL
USE { [<catalog_name>.]<database_name>[@<compute_group_name>] | @<compute_group_name> }
```

## 必須パラメータ

指定したデータベースに切り替えます。

**1. `<database_name>`**
> 切り替え先のデータベース名。
> カタログを省略すると、デフォルトで現在のカタログを使用します。

指定したコンピュートグループのみに切り替えます。

**1. `<compute_group_name>`**
> 切り替え先のコンピュートグループ名。

## 任意パラメータ

指定したデータベースに切り替えます。

**1. `<catalog_name>`**
> 切り替え先のカタログ名。

**2. `<compute_group_name>`**
> 切り替え先のコンピュートグループ名。

## 必要な権限

| 権限   | 対象                | 説明                                                                |
|-------------|-----------------------|----------------------------------------------------------------------|
| SELECT_PRIV | Catalog, Database     | 切り替え先のカタログまたはデータベースに対する SELECT_PRIV 権限が必要です。 |
| USAGE_PRIV  | Compute Group         | 切り替え先のコンピュートグループに対する USAGE_PRIV 権限が必要です。  |

## 例

1. `demo` データベースが存在する場合、それに切り替えます。

   ```sql
   use demo;
   ```

2. `demo` データベースが `hms_catalog` カタログにある場合、`hms_catalog` に切り替えて使用します。

    ```sql
    use hms_catalog.demo;
    ```

3. 現在のカタログに `demo` データベースがあり、'cg1' というコンピュートグループを使用する場合は、次のように指定します。

    ```sql
    use demo@cg1;
    ```

4. 'cg1' というコンピュートグループだけを使用する場合は、次のように指定します。

    ```sql
    use @cg1;
    ```
