## 説明

この文はデータベースを削除するために使用します。

## 構文

```sql
DROP DATABASE [IF EXISTS] <db_name> [FORCE];
```

## 必須パラメータ

**1. `<db_name>`**
> データベース名

## 省略可能なパラメータ

**1. `FORCE`**
> ごみ箱に移さずに強制的に削除します。

## 権限

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限 | 対象 | 説明 |
|:-----------|:------|:---------------|
| DROP_PRIV | 対象のデータベース | 対象のデータベースに対する削除権限が必要です。 |


## 注意事項

DROP DATABASE FORCE を実行すると、システムはデータベース内に未完了のトランザクションがあるかどうかを確認しません。データベースは直接削除され、復元できません。通常、この操作は推奨されません。

## 例

準備として、削除例の対象となる `db_test` を作成します。

```sql
CREATE DATABASE db_test;
```

- データベース db_test を削除します。

    ```sql
    DROP DATABASE db_test;
    ```
