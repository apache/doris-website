## 説明

このステートメントは、現在作成されているリポジトリを表示します。

## 構文

```sql
SHOW REPOSITORIES;
```

## 戻り値

| フィールド | 説明 |
|------------|------|
| **RepoId** | リポジトリの一意の識別子（ID） |
| **RepoName** | リポジトリの名前 |
| **CreateTime** | リポジトリの作成日時 |
| **IsReadOnly** | リポジトリが読み取り専用かどうか。`false` は読み取り専用ではないこと、`true` は読み取り専用であることを示します |
| **Location** | リポジトリ内でデータのバックアップに使用するルートディレクトリ |
| **Broker** | - |
| **Type** | リポジトリの種類。現在、S3 と HDFS をサポートしています |
| **ErrMsg** | リポジトリのエラーメッセージ。エラーが発生していない場合は通常 `NULL` です |


## 例

作成済みのリポジトリを表示します。

```sql
SHOW REPOSITORIES;
```
```text
+--------+--------------+---------------------+------------+----------+--------+------+--------+
| RepoId | RepoName     | CreateTime          | IsReadOnly | Location | Broker | Type | ErrMsg |
+--------+--------------+---------------------+------------+----------+--------+------+--------+
| 43411  | example_repo | 2025-01-17 18:50:47 | false      | s3://rep1  | -      | S3   | NULL   |
+--------+--------------+---------------------+------------+----------+--------+------+--------+
```
