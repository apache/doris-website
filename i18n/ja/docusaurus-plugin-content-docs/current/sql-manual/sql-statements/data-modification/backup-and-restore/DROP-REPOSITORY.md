## 説明

このステートメントは、作成済みのリポジトリを削除するために使用します。

## 構文

```sql
DROP REPOSITORY <repo_name>;
```

## 必須パラメータ
**<repo_name>**
> リポジトリの一意の名前。

## アクセス権限の要件

| 権限               | 対象                         | 備考                                               |
|:-------------------|:-----------------------------|:----------------------------------------------------|
| ADMIN_PRIV         | クラスター全体の管理権限 | root ユーザーまたはスーパーユーザーだけがリポジトリを作成できます |


## 使用上の注意
- リポジトリを削除しても、Doris 内のマッピングが削除されるだけで、実際のリポジトリデータは削除されません。削除後も、同じ LOCATION を指定すればリポジトリを再びマッピングできます。

## 例

example_repo という名前のリポジトリを削除します。

```sql
DROP REPOSITORY `example_repo`;
```
