## 説明

このステートメントは、正常に実行された削除タスクの履歴を表示します。

## 構文

```sql
SHOW DELETE [FROM <db_name>]
```

## オプションパラメータ
**<db_name>** : 表示するデータベースの名前

## 戻り値
| 列                | 説明                                                         |
|-------------------|--------------------------------------------------------------|
| `TableName`       | 削除操作を実行したテーブルの名前。                             |
| `PartitionName`   | 削除操作の対象となったパーティションの名前。                   |
| `CreateTime`      | 削除操作が発行された時刻。                                     |
| `DeleteCondition` | 削除された行を指定する、削除操作に使用した条件。               |
| `State`           | 削除操作の状態。                                               |


## 例

1. テスト用データベースに移動し、過去の削除タスクをすべて表示する
     ```sql
    show delete;
    ```
    ```text
    +---------------+---------------+---------------------+-----------------+----------+
    | TableName     | PartitionName | CreateTime          | DeleteCondition | State    |
    +---------------+---------------+---------------------+-----------------+----------+
    | iceberg_table | *             | 2025-03-14 15:53:32 | id EQ "1"       | FINISHED |
    +---------------+---------------+---------------------+-----------------+----------+
    ```

2. データベースの過去の削除タスクをすべて表示する

     ```sql
     show delete from tpch;
     ```
     ```
     +-----------+---------------+---------------------+-------------------+----------+
     | TableName | PartitionName | CreateTime          | DeleteCondition   | State    |
     +-----------+---------------+---------------------+-------------------+----------+
     | customer  | *             | 2025-03-14 15:45:19 | c_custkey EQ "18" | FINISHED |
     +-----------+---------------+---------------------+-------------------+----------+
     ```
