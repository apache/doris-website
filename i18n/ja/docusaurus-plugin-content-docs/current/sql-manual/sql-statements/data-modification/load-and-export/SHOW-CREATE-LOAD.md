## 説明

このステートメントは、インポートジョブの作成ステートメントを表示します。

## 構文

```sql
SHOW CREATE LOAD FOR <load_name>;
```

## 必須パラメータ

**`<load_name>`**

> 定期インポートジョブの名前。

## アクセス権の要件

この SQL コマンドを実行するユーザーには、少なくとも以下の権限が必要です。

| 権限 | オブジェクト | 備考 |
| :---------------- | :------------- | :---------------------------- |
| ADMIN/NODE_PRIV | データベース | クラスター管理者権限が必要です。 |

## 戻り値

指定したインポートジョブの作成ステートメントを返します。

## 例

- デフォルトのデータベースにある指定したインポートジョブの作成ステートメントを表示します。

```sql
SHOW CREATE LOAD for test_load
```
