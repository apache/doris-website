## 説明

過去のインポートジョブのラベルを手動でクリーンアップします。クリーンアップしたラベルは再利用できます。
プログラムで設定した自動インポートタスクで、繰り返し実行する際に固定の文字列をインポートのラベルとして指定する場合によく使用します。
各インポートタスクを開始する前に、このステートメントを実行してラベルをクリーンアップします。

## 構文  

```sql
CLEAN LABEL [ <label> ] FROM <db_name>;
```

## 必須パラメータ

**1. `<db_name>`**  
  データベース名。

## オプションパラメータ

**1. `<label>`**    
  クリーンアップするラベル。省略すると、デフォルトでは現在のデータベース内のすべてのラベルが対象になります。

## アクセス制御要件

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限                  | オブジェクト | 備考                                             |
|:----------------------|:-------------|:-------------------------------------------------|
| ALTER_PRIV            | データベース | データベースに対する変更権限が必要です。           |


## 例

- データベース db1 からラベル label1 をクリーンアップします。

   ```sql
   CLEAN LABEL label1 FROM db1;
   ```

- データベース db1 からすべてのラベルをクリーンアップします。

   ```sql
   CLEAN LABEL FROM db1;
   ```
