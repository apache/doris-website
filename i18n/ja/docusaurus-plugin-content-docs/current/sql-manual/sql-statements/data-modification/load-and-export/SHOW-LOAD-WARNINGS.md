## 説明

インポートタスクが失敗し、エラーメッセージが `ETL_QUALITY_UNSATISFIED` の場合は、インポートデータの品質に問題があることを示します。このステートメントは、品質に問題があるインポートタスクを確認するために使用します。

## 構文

```sql
SHOW LOAD WARNINGS
[FROM <db_name>]
[
   WHERE
   [LABEL  = [ "<your_label>" ]]
   [LOAD_JOB_ID = ["<job_id>"]]
]
```

## オプションパラメータ

**1. `<db_name>`**

> `db_name` を指定しない場合は、現在のデフォルトデータベースが使用されます。

**2. `<your_label>`**

> `LABEL = <your_label>` を指定した場合は、指定したラベルに完全一致するタスクを検索します。

**3. `<job_id>`**

> `LOAD_JOB_ID = <job_id>` を指定した場合は、指定した JOB_ID に完全一致するタスクを検索します。

## アクセス制御要件

この SQL コマンドを実行するユーザーには、少なくとも次の権限が必要です。

| 権限 | オブジェクト | 備考 |
| :---------------- | :------------- | :---------------------------- |
| LOAD_PRIV | データベース | データベース内のテーブルに対するインポート権限が必要です。 |

## 戻り値

指定したデータベースのインポートタスクで、品質に問題があるデータを返します。

## 例

- 指定したデータベースのインポートタスクから、ラベルが "load_demo_20210112" の品質に問題があるデータを表示します。

```sql
SHOW LOAD WARNINGS FROM demo WHERE LABEL = "load_demo_20210112" 
```
