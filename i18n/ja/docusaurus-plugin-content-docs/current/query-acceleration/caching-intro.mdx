Apache Doris は、複数の階層でキャッシュを使用してクエリを高速化します。結果レベルのキャッシュは、同一の SQL に対するクエリ結果を再利用します。セグメントレベルのキャッシュは、フィルタ条件の計算結果を再利用します。ファイルレベルのキャッシュは、リモートのレイクハウスデータと、コンピュートとストレージを分離したモードにおける内部テーブルのデータをローカルディスクにキャッシュします。ワークロードの特性に応じて適切なキャッシュ方式を選択してください。
