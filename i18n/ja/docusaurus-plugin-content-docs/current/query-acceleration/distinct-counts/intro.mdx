重複排除は、分析処理の中でも特に多くのリソースを消費する操作の一つです。Apache Doris は、`COUNT DISTINCT` の代わりに使用できる二つの専用データ型を提供し、メモリ使用量とレイテンシーを抑えて重複を排除します。正確な結果が必要な場合は **BITMAP** を、ストレージ使用量を抑えるために 1%–2% の誤差を許容できる場合は **HLL** を選択してください。
