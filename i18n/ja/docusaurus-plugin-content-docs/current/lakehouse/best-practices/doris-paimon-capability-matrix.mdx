以下の表は、Doris で現在利用できる Paimon Catalog の機能をまとめたものです。行は機能分野ごとにグループ化され、バックエンドごとの列は、Doris が対応するメタデータサービスを使用する場合に各操作を実行できるかどうかを示します。✅ は Doris がその操作をサポートしていることを、❌ は現時点ではサポートしていないことを示します。

DLF 列は `paimon.catalog.type=dlf` を指します。この設定では Hive 互換のメタストアクライアントを使用し、OSS または OSS-HDFS のストレージ設定が必要です。`paimon.catalog.type=rest` 経由でアクセスする DLF は REST 列に含まれます。
