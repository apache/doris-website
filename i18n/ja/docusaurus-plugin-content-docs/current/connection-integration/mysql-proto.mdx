Apache Doris は **MySQL ネットワーク通信プロトコル**に完全に対応しています。そのため、このプロトコルに準拠したクライアントツール、可視化ツール、主要なプログラミング言語向けの MySQL ドライバーやライブラリは、**Doris 専用のドライバーをインストールすることなく** Doris に直接接続できます。

> Doris FE はデフォルトでポート `9030` から MySQL プロトコルのサービスを提供します。このポートは `query_port` 設定項目に対応し、`fe.conf` で設定します。

## 主な利用シーン {#typical-use-cases}

MySQL プロトコルによる接続は、用途に応じて主に次の 2 つに分けられます。

| シーン | 主な用途 | 推奨される方法 |
| --- | --- | --- |
| コマンドライン / スクリプトからのアクセス | 運用上の問題の調査、アドホッククエリ、自動化スクリプト | MySQL CLI |
| アプリケーションとの連携 | バックエンドサービス、データ処理プログラム、ETL ジョブ | 対応する言語の MySQL ドライバー（Java / Go / Rust / Python / C++ など） |

## 接続前の準備 {#preparation-before-connecting}

接続する前に、次の情報を確認してください。

| 項目 | 説明 | 例 |
| --- | --- | --- |
| `FE_IP` | Doris FE ノードの IP アドレスまたはホスト名 | `172.20.63.118` |
| `FE_QUERY_PORT` | FE の MySQL プロトコルサービスのポート。`query_port` 設定項目に対応し、`fe.conf` で設定します | `9030` |
| `USER` | ログインアカウント | `root` |
| `PASSWORD` | ログインパスワード（デフォルトでは `root` アカウントのパスワードは空です） | - |

> ポートを変更する場合は、FE ノードの `query_port` 設定項目を `fe.conf` で変更し、FE を再起動してください。

<TabItem value="mysql-cli" label="MySQL CLI" default>

コマンドラインでの操作、アドホッククエリ、スクリプトからの呼び出しなどに適しています。

### 1. MySQL クライアントのダウンロードと展開 {#1-download-and-extract-the-mysql-client}

[MySQL 公式サイト](https://dev.mysql.com/downloads/mysql/)から MySQL クライアントをダウンロードします。Doris は **MySQL 5.7 以降**のクライアントに対応しています。

展開後、`bin/` ディレクトリに `mysql` コマンドラインツールがあります。

### 2. Doris への接続 {#2-connect-to-doris}

次のコマンドを実行して Doris に接続します。

```shell
mysql -h FE_IP -P FE_QUERY_PORT -u USER -p
```

Enter キーを押した後、パスワードを入力します（`root` アカウントにはデフォルトでパスワードがないため、そのまま Enter キーを押します）。

### 3. ログインの確認 {#3-verify-login}

ログインに成功すると、次のメッセージが表示されます。

```text
Welcome to the MySQL monitor.  Commands end with ; or \g.
Your MySQL connection id is 236
Server version: 5.7.99 Doris version doris-2.0.3-rc06-37d31a5

Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

mysql>
```

<TabItem value="java" label="Java">

Java アプリケーションから Doris に接続する場合に適しています。Doris では、接続に **MySQL JDBC Connector** を使用することを推奨します。

### 1. JDBC ドライバーの追加 {#1-add-the-jdbc-driver}

プロジェクトに MySQL JDBC Connector の依存関係を追加します（MySQL 5.1.49 以降を推奨します）。

### 2. 接続コードの記述 {#2-write-the-connection-code}

```java
String user = "user_name";
String password = "user_password";
String url = "jdbc:mysql://FE_IP:FE_QUERY_PORT/demo"
        + "?useUnicode=true"
        + "&characterEncoding=utf8"
        + "&useTimezone=true"
        + "&serverTimezone=Asia/Shanghai"
        + "&useSSL=false"
        + "&allowPublicKeyRetrieval=true";

try (Connection conn = DriverManager.getConnection(url, user, password);
     Statement stmt = conn.createStatement();
     ResultSet rs = stmt.executeQuery("show databases")) {

    ResultSetMetaData metaData = rs.getMetaData();
    int columnCount = metaData.getColumnCount();
    while (rs.next()) {
        for (int i = 1; i <= columnCount; i++) {
            System.out.println(rs.getObject(i));
        }
    }
} catch (SQLException e) {
    log.error("get JDBC connection exception.", e);
}
```

### 3. 主な JDBC URL パラメーター {#3-common-jdbc-url-parameters}

| パラメーター | 意味 | 推奨値 / 例 | 必須 |
| --- | --- | --- | --- |
| `useUnicode` | Unicode 文字セットを使用するかどうか | `true` | いいえ |
| `characterEncoding` | 文字エンコーディング | `utf8` | いいえ |
| `useTimezone` | タイムゾーン変換を有効にするかどうか | `true` | いいえ |
| `serverTimezone` | サーバーのタイムゾーン | `Asia/Shanghai` | いいえ |
| `useSSL` | 接続に SSL を使用するかどうか | `false` | いいえ |
| `allowPublicKeyRetrieval` | サーバーからの公開鍵の取得を許可するかどうか（通常、MySQL 8 ドライバーで必要です） | `true` | いいえ |
| `sessionVariables` | 接続の確立時に初期化するセッション変数 | `key1=val1,key2=val2` | いいえ |

### 4. セッション変数の初期化（任意） {#4-initialize-session-variables-optional}

接続の確立時にセッション変数を初期化する場合は、次の URL 形式を使用します。

```text
jdbc:mysql://FE_IP:FE_QUERY_PORT/demo?sessionVariables=key1=val1,key2=val2
```
