# データ統合 {#data-integration}

Apache Doris は、幅広いデータエコシステムのツールとの統合に対応しています。用途に合ったツールを選ぶことで、データの可視化、移行と同期、リアルタイムの取り込み、ログとオブザーバビリティの分析、データベースの開発と管理、データモデリングと変換に Doris を活用できます。
