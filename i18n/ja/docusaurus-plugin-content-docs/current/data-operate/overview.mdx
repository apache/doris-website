Apache Doris は、データの取り込みからエクスポートまでの一連の処理をカバーするデータ操作機能を備えています。さまざまなデータソースからデータをロードし、トランザクション保証のもとでデータを更新・削除し、クエリ結果やテーブルデータを外部ストレージシステムにエクスポートできます。

また、Apache Doris は Apache Iceberg のテーブルデータを直接管理できます。これには、Iceberg テーブルに対する直接クエリの高速化、書き込み、更新、削除が含まれます。詳しくは、Iceberg Catalog のデータ管理セクションを参照してください。
