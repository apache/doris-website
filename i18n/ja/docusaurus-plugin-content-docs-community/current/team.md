# Doris チーム

<!-- Knowledge type: Concept introduction -->
<!-- Use cases: Understand community governance / Find the members list -->

Apache Doris は、Apache Software Foundation（ASF）のオープンなガバナンスモデルに従い、世界各地のコントリビューターによって開発・保守されています。コミュニティには、権限と責任が異なる三つの役割があります。

## コミュニティの役割

| 役割 | 権限と責任 |
|------|----------------------------------|
| **PMC（プロジェクト管理委員会）** | プロジェクトの全体方針、バージョンのリリース、コミュニティの運営、新しいコミッターと PMC メンバーの推薦・投票を担当する委員会のメンバー |
| **コミッター** | コードリポジトリへのコミット権限を持ち、コード、ドキュメント、Issue、PR のレビューとマージを担当する活発なコントリビューター |
| **コントリビューター** | PR、Issue、ドキュメント、普及活動、質疑応答などを通じてコミュニティに参加するすべての貢献者 |

コントリビューターからコミッターや PMC メンバーになるまでの道筋については、[コミュニティ貢献ガイド](how-to-contribute/contribute-to-doris.mdx)を参照してください。

## 最新のメンバー一覧

PMC メンバーとコミッターの完全な最新一覧は、Apache の公式ページで管理されています。

| 一覧 | リンク |
|------|-------|
| Apache の公式コミッター一覧 | <https://people.apache.org/committers-by-project.html#doris> |
| PMC 議長と現メンバー | <https://projects.apache.org/committee.html?doris> |

## コントリビューター

Apache Doris にコード、ドキュメント、Issue を提供してくださったすべてのコントリビューターに感謝します。全員の一覧はこちらで確認できます。

- **GitHub コントリビューター**: <https://github.com/apache/doris/graphs/contributors>
