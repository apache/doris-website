# Apache Doris コミュニティへの参加 {#join-the-apache-doris-community}

<!-- Knowledge type: Procedure -->
<!-- Applicable scenario: New user onboarding / Joining the community -->

[Apache Doris](https://github.com/apache/doris) は、世界中のユーザーと開発者が維持するオープンソースのリアルタイムデータウェアハウスプロジェクトです。2022 年 6 月に Apache Incubator を卒業し、Apache トップレベルプロジェクト（TLP）になりました。このページでは、コミュニティの公式な連絡窓口を紹介します。自分に合う窓口を選び、議論への参加や最新情報の確認に活用してください。

:::tip コミュニティに貢献したい方へ

コード開発、コンテンツ作成、コミュニティ活動を通じて Apache Doris に貢献したい場合は、[コミュニティ貢献ガイド](how-to-contribute/contribute-to-doris.mdx)から始めてください。

:::

## コミュニティの公式窓口 {#overview-of-official-community-channels}

各窓口の目的と用途は次のとおりです。

| 窓口 | 目的 | 参加先 |
|------|------|------|
| Slack | リアルタイムの議論、質問、回答（初めてのユーザーに推奨） | [https://doris.apache.org/slack](https://doris.apache.org/slack?utm_source=website&utm_medium=docs&utm_content=community_join_page) |
| GitHub | ソースコード、Issue、PR、リリースノート | <https://github.com/apache/doris> |
| メーリングリスト | Apache の公式な非同期の議論と意思決定 | [メーリングリストの購読](subscribe-mail-list.md)を参照 |
| Twitter | 世界各地の導入事例、リリース情報、イベントのお知らせ | <https://twitter.com/doris_apache> |
| LinkedIn | 技術者との交流、採用情報、業界の最新情報 | <https://www.linkedin.com/company/doris-apache/> |
| YouTube | 海外 Meetup と技術共有セッションの録画 | <https://www.youtube.com/hashtag/apachedoris> |
| Bilibili | 中国国内 Meetup と技術共有セッションの録画 | <https://space.bilibili.com/362350065> |

## 目的に合う窓口を選ぶ {#choose-a-channel-by-scenario}

<!-- Knowledge type: Scenario routing -->

- **気軽に質問したり、日々の議論に参加したい**：[Slack](https://doris.apache.org/slack?utm_source=website&utm_medium=docs&utm_content=community_join_page) に参加してください。
- **バグを報告したり、コードを提出したい**：[GitHub](https://github.com/apache/doris) を開き、[フィードバック](feedback.md)と[コミュニティ貢献ガイド](how-to-contribute/contribute-to-doris.mdx)を参照してください。
- **コミュニティの意思決定やリリース情報を確認したい**：[メーリングリストを購読](subscribe-mail-list.md)してください。
- **導入事例や技術的な知見を知りたい**：[Twitter](https://twitter.com/doris_apache) と [LinkedIn](https://www.linkedin.com/company/doris-apache/) をフォローしてください。
- **Meetup や技術共有セッションの録画を見たい**：[YouTube](https://www.youtube.com/hashtag/apachedoris) または [Bilibili](https://space.bilibili.com/362350065) を開いてください。
