# Apache Doris メーリングリストの購読

<!-- Knowledge type: Procedural steps -->
<!-- Applicable scenarios: New user onboarding / Joining the community / Following community decisions -->

メーリングリストは、Apache コミュニティで広く利用されている連絡手段です。日々の質問、技術的な議論、意思決定に使われます。非同期で参加者全員にメールを届けられるため、世界各地にメンバーがいるオープンソースコミュニティに適しています。このページでは、Apache Doris の `dev` メーリングリストを 5 つの手順で購読する方法を説明します。

## メーリングリストのメールアドレス一覧

購読、議論、購読解除には、それぞれ異なるメールアドレスを使用します。

| 用途 | メールアドレス | 備考 |
|---------|---------------|-------|
| 購読 | `dev-subscribe@doris.apache.org` | 件名と本文は任意 |
| 確認 | `dev-help@doris.apache.org` | 自動返信メール。購読を確定するには、そのメールへの返信が必要 |
| 日々の議論 | `dev@doris.apache.org` | 購読後の質問や議論に使用 |
| 購読解除 | `dev-unsubscribe@doris.apache.org` | 件名と本文は任意 |

## 購読手順

### 1. 購読メールを送信する

メールクライアントで新規メールを作成し、`dev-subscribe@doris.apache.org` に送信します。件名と本文は任意です。

![手順 1：購読メールを送信する](/images/subscribe-mail-list-step1.png)

### 2. dev-help からの確認メールを受信する

手順 1 を完了すると、`dev-help@doris.apache.org` から確認メールが届きます。

> しばらく待ってもメールが届かない場合は、受信がブロックされていないか、または「購読（Subscriptions）」「迷惑メール（Spam）」「プロモーション（Promotions）」などのフォルダーに自動的に振り分けられていないか確認してください。

![手順 2：dev-help からの確認メールを受信する](/images/subscribe-mail-list-step2.png)

### 3. 確認メールに返信する

前の手順で受信したメールについて、次のいずれかの方法を選びます。

- **方法 A**：そのメールに直接返信します。
- **方法 B**：新規メールを作成し、宛先に前のメールに記載された「Reply-To」アドレスを設定します。

どちらの方法でも、件名と本文は任意です。

![手順 3：確認メールに返信する](/images/subscribe-mail-list-step3.png)

### 4. ウェルカムメールを受信する

手順 3 を完了すると、件名が **WELCOME to dev@doris.apache.org** のウェルカムメールが届きます。これで購読は完了し、このメーリングリストを通じてコミュニティの最新情報が届くようになります。

![手順 4：ウェルカムメールを受信する](/images/subscribe-mail-list-step4.png)

### 5. メールで議論を始める（任意）

購読後、`dev@doris.apache.org` にメールを送信すると議論を始められます。そのメールはすべての購読者に届きます。

## メーリングリストの購読解除

購読を解除するには、`dev-unsubscribe@doris.apache.org` に任意の件名と本文でメールを送信し、返信メールの案内に従って確認してください。
