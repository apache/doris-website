## 五種類のコミュニティバッジ {#badges}

それぞれのバッジは、異なる形の貢献をたたえるものです。Contributor バッジは現在受け取れます。Committer バッジと PMC Member バッジは PMC から送られるため、申請は不要です。2026 年の二種類のバッジはコミュニティが授与します。授与基準と手順が決まり次第、このページに追記します。

## デジタルバッジを受け取る {#digital-badge}

Contributor バッジを受け取る方は、四つのステップをすべて行ってください。Holopin が招待メールを送る前に各申請を手作業で確認するため、最初の二つのステップで GitHub アカウントが本人のものか確認します。コミッターと PMC メンバーは、PMC から招待メールが届くため、最初の二つのステップを省略し、[ステップ 3 から](#committer-pmc-badges)始めます。

### コミッターまたは PMC メンバーの方はこちらから {#committer-pmc-badges}

この二種類のバッジには申請が必要ありません。Doris PMC は公式の[コミッター一覧](https://people.apache.org/committers-by-project.html#doris)と[PMC メンバー一覧](https://projects.apache.org/committee.html?doris)を確認し、掲載されている方全員に Holopin の招待メールを直接送ります。コミッターには Committer バッジ、PMC メンバーには PMC Member バッジと Committer バッジの両方が届きます。メールが届いたらステップ 3 から進んでください。その後のバッジの公開方法と実物のバッジの申請方法は、Contributor バッジと同じです。

Contributor バッジも希望しますか？ マージ済みのプルリクエストがあれば対象となるので、ステップ 1 と 2 から申請してください。

<div className="badge-step-why">まだメールが届いていない場合は、まずプロモーションタブと迷惑メールフォルダーを確認し、その後 <a href="#questions">Slack</a> でお問い合わせください。</div>

</div>
</div>

### Holopin でバッジを受け取る {#step-3}

Holopin から招待メールが届きます。Contributor バッジの場合は PR の確認後、Committer バッジと PMC Member バッジの場合は PMC が招待を送った後です。**Claim Badge** をクリックしてください。Holopin のアカウントは無料で作成できます。

<Admonition type="tip" title="メールアドレスでサインイン">
  <p>現在、GitHub から直接サインインする際に問題があるため、ご自身のメールアドレスで Holopin に登録し、サインインすることをお勧めします。</p>
</Admonition>

メールが見つからない場合は、プロモーションタブまたは迷惑メールフォルダーを確認してください。Holopin の招待メールがそこに振り分けられることがあります。

### バッジを公開する {#step-4}

このバッジには、あなたの貢献をコミュニティが評価しているという意味があります。好きな場所に掲載してください。

<Tabs groupId="badge-showoff">
<TabItem value="github" label="GitHub プロフィール" default>

<div className="badge-ministeps">

1. Holopin で **Your Profile** を開きます。
2. Apache Doris のバッジを **Board** に追加します。複数のバッジがある場合は、移動、サイズ変更、回転ができます。
3. Board の下に表示されるコードをコピーし、GitHub プロフィールの README に貼り付けます。

</div>

コードは一行の Markdown です。次は `morningman` アカウントの例です。自分のコードには自分のユーザー名が入ります。

```markdown
[![An image of @morningman's Holopin badges, which is a link to view their full Holopin profile](https://holopin.me/morningman)](https://holopin.io/@morningman)
```

表示例は [github.com/morningman](https://github.com/morningman) と、その元となる [README](https://github.com/morningman/morningman/blob/main/README.md) で確認できます。
