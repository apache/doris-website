## 描述  
CENTURY 函数用于提取指定日期或时间值中的世纪部分，返回整数形式的世纪。支持处理 DATE、DATETIME、TIMESTAMP_NS 类型。

## 语法  
```sql
CENTURY(`<date_or_time_expr>`)
```

## 参数
| 参数                    | 说明                                                                                                                                                                                                                                                                        |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<date_or_time_expr>` | 要提取世纪的日期或时间值，支持 `DATE`、`DATETIME` 或 `TIMESTAMP_NS` 类型。 |

## 返回值
返回 `INT`，表示输入日期所属的世纪。例如，1901 年至 2000 年属于 20 世纪。

- 若输入的参数为 NULL，返回 NULL

## 举例
```sql
-- 提取DATE类型的世纪
SELECT CENTURY('2024-01-01') AS century_date;
+-----------------+
| century_date    |
+-----------------+
| 21              |
+-----------------+

-- 提取DATETIME类型的世纪（忽略时分秒）
SELECT CENTURY('2024-05-20 14:30:25') AS century_datetime;
+----------------------+
| century_datetime     |
+----------------------+
| 21                   |
+----------------------+

-- 输入为NULL（返回NULL）
SELECT CENTURY(NULL) AS null_input;
+----------------+
| null_input     |
+----------------+
| NULL           |
+----------------+

-- 输入无效日期（返回NULL）
SELECT CENTURY('10000-01-01') AS invalid_date;
+-------------------+
| invalid_date      |
+-------------------+
| NULL              |
+-------------------+

```
