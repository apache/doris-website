## 描述

计算参数的伽马函数值，伽马函数是阶乘在实数上的推广。

## 语法

```sql
GAMMA(<a>)
```

## 参数

| 参数 | 说明 |
| -- | -- |
| `<a>` | 浮点参数 |

## 返回值

返回参数 `<a>` 的伽马函数值，浮点数。

对于正整数 `n`，`gamma(n)` 等于 `(n - 1)!`，因此 `gamma(5)` 为 `4! = 24`。由于结果以双精度
浮点数计算，`gamma(5)` 实际返回的值为 `24.000000000000004`。其他取值遵循标准伽马函数，
例如 `gamma(0.5)` 为 `sqrt(pi)`。注意 `gamma(1) = 1`、`gamma(2) = 1`，分别对应 `0!` 和 `1!`。

## 特殊情况

- 当 `a` 为 `0`（包括 `-0.0`）或负整数（`-1`、`-2` ……）时，函数存在极点，返回 NULL
- 当 `a` 为负无穷时，返回 NULL
- 当 `a` 为 NaN 时，返回 NaN
- 当 `a` 为正无穷时，返回 Infinity
- 当 `a` 大到超出双精度表示范围时（例如 `172`），返回 Infinity
- 当 `a` 为极小的正数时，`gamma(a)` 约为 `1 / a`，同样会溢出为 Infinity（例如 `1e-320`，甚至最小的次正规数 `5e-324`）
- 当 `a` 为绝对值很大的负非整数时，结果极接近 0，可能下溢为带符号的零，例如 `gamma(-1000.5)` 返回 `-0.0`
- 当 `a` 为 NULL 时，返回 NULL

## 举例

```sql
select gamma(5);
```

```text
+--------------------+
| gamma(5)           |
+--------------------+
| 24.000000000000004 |
+--------------------+
```

```sql
select gamma(0.5);
```

```text
+-------------------+
| gamma(0.5)        |
+-------------------+
| 1.772453850905516 |
+-------------------+
```

```sql
select gamma(-2.5);
```

```text
+---------------------+
| gamma(-2.5)         |
+---------------------+
| -0.9453087204829418 |
+---------------------+
```

```sql
select gamma(0);
```

```text
+----------+
| gamma(0) |
+----------+
|     NULL |
+----------+
```

```sql
select gamma(-1);
```

```text
+-----------+
| gamma(-1) |
+-----------+
|      NULL |
+-----------+
```

```sql
select gamma(cast('nan' as double));
```

```text
+------------------------------+
| gamma(cast('nan' as double)) |
+------------------------------+
|                          NaN |
+------------------------------+
```

```sql
select gamma(cast('inf' as double));
```

```text
+------------------------------+
| gamma(cast('inf' as double)) |
+------------------------------+
|                     Infinity |
+------------------------------+
```

```sql
select gamma(cast('-inf' as double));
```

```text
+-------------------------------+
| gamma(cast('-inf' as double)) |
+-------------------------------+
|                          NULL |
+-------------------------------+
```

```sql
select gamma(172);
```

```text
+------------+
| gamma(172) |
+------------+

+------------+
```
