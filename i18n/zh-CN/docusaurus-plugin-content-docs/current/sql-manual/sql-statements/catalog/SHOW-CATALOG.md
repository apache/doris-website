## 描述

该语句用于显示已存在是数据目录（catalog）属性

## 属性脱敏

统一脱敏规则计划在 Doris 4.2.0、5.0 及后续版本支持。敏感属性展示为 `*XXX`，部分内部属性直接省略；明确的 JDBC 连接串整值遮蔽，普通 URI 按值清理 userinfo、秘密参数和签名。完整规则见 [Catalog 属性脱敏](../../../lakehouse/catalog-property-masking.md)。下例使用此规则，不表示 4.0、4.1 或 3.x 的行为。

## 语法

```sql
SHOW CATALOG <catalog_name>
```


## 必填参数

**1. `<catalog_name>`**

需要显示 catalog 的名字

## 返回值


## 权限控制

| 权限（Privilege）                                                                                | 对象（Object） | 说明（Notes）      |
|:---------------------------------------------------------------------------------------------|:-----------|:---------------|
| ADMIN_PRIV / SELECT_PRIV / LOAD_PRIV / ALTER_PRIV / CREATE_PRIV / SHOW_VIEW_PRIV / DROP_PRIV | Catalog    | 需要有上述权限中的一种就可以 |
