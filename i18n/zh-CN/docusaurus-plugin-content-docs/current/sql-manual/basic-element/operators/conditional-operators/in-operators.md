## 描述

IN 操作符测试一个值是否属于某个值列表或子查询中的成员。

## 操作符介绍

| 操作符 | 作用                                            | 示例                        |
| ------ | ----------------------------------------------- | --------------------------- |
| IN     | 测试是否等于任意的成员。如果是，则返回 TRUE。   | `SELECT 1 IN (SELECT 2)`    |
| NOT IN | 测试是否不等于所有的成员。如果是，则返回 TRUE。 | `SELECT 1 NOT IN (3, 4, 5)` |

## 类型限制

`IN` 和 `NOT IN` 仅支持标量基本类型。`ARRAY`、`MAP` 和 `STRUCT` 等复杂类型，以及对象类型，不能作为左侧表达式或 `IN` 列表中的值。

以下语句无效：

```sql
SELECT STRUCT(1, 2) IN (STRUCT(1, 2));
SELECT [1, 2] IN ([1, 2]);
SELECT MAP('a', 1) IN (MAP('a', 1));
```
